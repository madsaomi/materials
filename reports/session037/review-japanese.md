# Независимый просмотр японских правок037

Дата: 2026-10-25. Проверяющий: english_bank037, без записи в японские заметки.

Результат: существенных ошибок в изменённых фрагментах не найдено. Прочитан diff относительно снимка после036 для всех15 изменённых файлов, с контекстом заданий и ключей. Пять пар core имеют одинаковые текущие байты; их повторные изменения сверены попарно. Уникальные дополнения usage просмотрены отдельно.

- Исправления усталости/жары, прошедшего времени, ながら в задании на ながら и конкретизированных условий согласованы с заданиями. В паре «жизненный опыт / поездка вчера» уточнение вопроса устраняет неоднозначный ожидаемый ключ.
- Для правила て/てから источник прямо поддерживает последовательность и у простой て-формы; результативное ている и 知りません также подтверждены. [TUFS: て](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/051.html), [состояния](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/045.html).
- Проверены непосредственно первичные пояснения о событии с で/ある, предложении с ましょう, конечных формах у たり и присоединении N/NA＋だ перед と思う. Новые формулировки избегают прежних абсолютных обобщений. [TUFS: местонахождение/мероприятие](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/006.html), [ましょう](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/063.html), [たり](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/050.html), [と思う](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/077.html).
- Изменения から/ので соответствуют источнику, включая だ/な и отсутствие деления на истинную/субъективную причину. [TUFS: причина](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/081.html).
- Ограничение учебного примера с непосредственно видимой красотой и особое よさそう проверены по примечанию преподавателю; в отчёте нет универсального запрета всех контекстов с きれいそう. [Japan Foundation: BTS00094](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00094/ja/render.do).

Повторный read-only запуск japanese.ts с абсолютным путём снимка прошёл. Указанные им407 прежних ID/111 внутренних href, неизменные036-префиксы, метаданные и закрытые details сохранены. Вызов без обязательного аргумента ожидаемо отклонён защитой до записи; затем проверка выполнена с корректным аргументом. Японские файлы при просмотре не записывались.

Это обзор конкретного исправляющего diff, а не повторная сертификация всех старых японских банков, аудио, фонетики или экзаменационной полноты. Общий аудит корпуса и HTTP остаются отдельными проверками корневого агента.
