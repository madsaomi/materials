## Изменения

- Удалены прежние app.py, catalog.py, verify.py, requirements.txt, gunicorn.conf.py,
  Jinja-шаблоны templates/ и старая копия static/. Рабочие ресурсы public/static/ сохранены.
- Удалён уже выполненный одноразовый скрипт реорганизации папок. Повторять миграцию нельзя.
- Обновление содержания перенесено в scripts/refresh-contents.ts: по умолчанию только
  просмотр изменений, запись через pnpm contents:refresh --apply.
  Сохраняются авторские страницы, исходное оформление метаданных и прежние HTML-якоря.
- Проверка служебных маркеров перенесена в scripts/check-unit-markers.ts
  (pnpm notes:markers). Удалён редакторский Python-скрипт, дублировавший сохранённый
  TypeScript-помощник.
- Учебный проверяющий скрипт программирования больше не ищет локальный Python автоматически.
  Запуск Python-примеров возможен при явно заданном LESSON_PYTHON;
  LESSON_GO и LESSON_RUSTC также остаются необязательными.
- Актуализированы инструкции запуска, архитектуры и работы агентов. Исторические отчёты сохранены.

В хранилищах остаются два самостоятельных Python-помощника: knowledge/count_stats.py
и knowledge/knowledge/tools/export_to_anki.py. Последний связан с заметкой и может использовать
необязательный genanki для APKG. Они не нужны сайту или обычному обслуживанию базы.
Учебный курс Python сохранён полностью. Python с компьютера не удалялся.
