# Unit 3 — Práctica

## Ejercicio 1: Императив (usted)

Вставьте форму вежливого императива:

1. ______ (tomar) la primera calle a la derecha.
2. ______ (girar) a la izquierda.
3. ______ (cruzar) el puente.
4. ______ (seguir) todo recto.
5. ______ (bajar) en la parada siguiente.

## Ejercicio 2: Перевод

Переведите на испанский:

1. Поверните направо. → ______
2. Аптека напротив вокзала. → ______
3. Мы едем в банк. → ______
4. Рядом есть метро? → ______
5. Здесь нет банков. → ______

## Ejercicio 3: Предлоги

Вставьте: cerca de, enfrente de, al lado de, lejos de, a la derecha

1. El banco está ______ del hotel. (рядом с)
2. La farmacia está ______ de la parada. (напротив)
3. El supermercado está ______. (справа)
4. La estación está ______ de aquí. (далеко)
5. El parque está ______ del museo. (рядом с)

## Ejercicio 4: Выбор

Выберите правильный вариант:

1. ¿Hay / Está una parada aquí?
2. No hay / está metro en este barrio.
3. El hotel hay / está en el centro.
4. Gire a / en la derecha.
5. El billete cuesta veinte / doscientos euros. (20)

## Ejercicio 5: Диалог

Расположите реплики в правильном порядке:

- [ ] Muchas gracias.
- [ ] Está enfrente del banco, en la calle Mayor.
- [ ] No, está cerca.
- [ ] ¿Y cómo puedo ir?
- [ ] Puede ir a pie.
- [ ] Perdón, ¿dónde está la farmacia?
- [ ] ¿Está lejos?
