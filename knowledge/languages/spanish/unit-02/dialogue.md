# Unit 2 — Diálogo: En el restaurante

## Диалог

```
Camarero: ¡Buenas tardes! ¿Qué desea?
Cliente:  Buenas tardes. ¿Qué me recomienda?
Camarero: Tenemos una paella muy buena y tapas de jamón.
Cliente:  Muy bien. Quiero una paella para dos personas.
Camarero: ¿Quiere beber algo?
Cliente:  Sí, quiero una jarra de agua y dos vasos de vino tinto.
Camarero: ¿Quiere pedir un postre?
Cliente:  ¿Qué tienen de postre?
Camarero: Tenemos flan, helado y fruta.
Cliente:  Me gustaría un flan, por favor.
Camarero: ¿Algo más?
Cliente:  No, nada más. La cuenta, por favor.
Camarero: Son cuarenta euros.
Cliente:  Aquí tiene. ¡Muchas gracias!
Camarero: ¡De nada! ¡Hasta luego!
```

## Traducción

| Español | Перевод |
|---------|---------|
| ¡Buenas tardes! | Добрый день! |
| ¿Qué desea? | Что желаете? |
| ¿Qué me recomienda? | Что вы мне посоветуете? |
| Tenemos una paella muy buena y tapas de jamón. | У нас очень хорошая паэлья и тапас с хамоном. |
| Quiero una paella para dos personas. | Я хочу паэлью на двоих. |
| ¿Quiere beber algo? | Хотите что-нибудь выпить? |
| una jarra de agua | кувшин воды |
| dos vasos de vino tinto | два стакана красного вина |
| ¿Quiere pedir un postre? | Хотите заказать десерт? |
| ¿Qué tienen de postre? | Что у вас есть из десертов? |
| Me gustaría un flan, por favor. | Я бы хотел флан, пожалуйста. |
| ¿Algo más? | Что-нибудь ещё? |
| No, nada más. | Нет, больше ничего. |
| La cuenta, por favor. | Счёт, пожалуйста. |
| Son cuarenta euros. | С вас сорок евро. |
| Aquí tiene. | Вот, пожалуйста. |
| ¡De nada! | Пожалуйста! |
| ¡Hasta luego! | До встречи! |
