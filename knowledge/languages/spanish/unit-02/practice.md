# Unit 2 — Práctica

## Ejercicio 1: Спряжение глаголов

Вставьте правильную форму (querer, poder, pedir):

1. Yo ______ (querer) una paella.
2. Ella ______ (poder) pedir el postre.
3. Nosotros ______ (pedir) tapas.
4. ¿Qué ______ (querer) tomar, señor?
5. Ellos ______ (poder) pagar la cuenta.

**Варианты:** quiero, puede, pedimos, quiere, pueden

## Ejercicio 2: Перевод

Переведите на испанский:

1. Я хотел бы кофе. → ______
2. Ты должен оплатить счёт. → ______
3. Есть свободный стол? → ______
4. Я ничего не хочу. → ______
5. Паэлья очень вкусная. → ______

## Ejercicio 3: lo / la / los / las

Вставьте местоимение прямого дополнения:

1. La paella, ______ pido.
2. El vino, ______ quiero.
3. Las tapas, ______ pedimos.
4. Los postres, ______ tomo.
5. La cuenta, ______ pago.

## Ejercicio 4: Выбор

Выберите правильный вариант:

1. ¿Hay / Está un restaurante cerca?
2. El baño hay / está al fondo.
3. Hay / Está tres personas en la mesa.
4. No quiero nada / nadie.
5. No veo nada / nadie en la cocina.

## Ejercicio 5: Диалог

Расположите реплики в правильном порядке:

- [ ] ¿Y de postre?
- [ ] Son quince euros.
- [ ] Quiero una paella y un vaso de vino.
- [ ] Un flan, por favor.
- [ ] La cuenta, por favor.
- [ ] Buenas tardes. ¿Qué desea?
