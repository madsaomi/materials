# Unit 2 — 문법 (Грамматика)

## 1. 하다 глаголы

Многие корейские глаголы образуются от существительных + 하다:

```
공부하다     — учиться (공부 + 하다)
운동하다     — заниматься спортом (운동 + 하다)
일하다       — работать (일 + 하다)
청소하다     — убирать (청소 + 하다)
요리하다     — готовить (요리 + 하다)
```

**Спряжение:**
```
하다 → 해요 (неформ. вежл.)
하다 → 합니다 (форм. вежл.)
하다 → 했어요 (прош. неформ.)
하다 → 했습니다 (прош. форм.)
```

## 2. 아/어/여요 (неформально-вежливое окончание)

**Правило:**
- Если последняя гласная ㅏ или ㅗ → **아요**
  - 가다 → 가요
  - 보다 → 봐요
  - 살다 → 살아요

- Если последняя гласная другая (не ㅏ/ㅗ) → **어요**
  - 먹다 → 먹어요
  - 읽다 → 읽어요
  - 마시다 → 마셔요
  - 공부하다 → 공부해요

- 하다 всегда → **해요**

## 3. Прошедшее время (았/었/였어요)

**Правило:**
- ㅏ/ㅗ → **았어요**
  - 가다 → 갔어요
  - 보다 → 봤어요
  - 살다 → 살았어요

- Другие гласные → **었어요**
  - 먹다 → 먹었어요
  - 읽다 → 읽었어요
  - 마시다 → 마셨어요

- 하다 → **했어요**
  - 공부하다 → 공부했어요

## 4. 에 (локативная частица)

**에 — местонахождение / время / направление:**

```
집에 있어요.          — Я дома.
학교에 가요.          — Иду в школу.
3시에 만나요.         — Встречаемся в 3 часа.
서울에 살아요.        — Живу в Сеуле.
```

## 5. 에서 (место действия)

```
학교에서 공부해요.     — Учусь в школе.
집에서 밥을 먹어요.    — Ем дома.
회사에서 일해요.       — Работаю в офисе.
```

## 6. 부터...까지 (от...до)

```
9시부터 6시까지 일해요.  — Работаю с 9 до 6.
서울부터 부산까지 가요.  — Еду от Сеула до Пусана.
```

## 7. 만 (только)

```
한 명만 있어요.        — Есть только один человек.
물만 마셔요.           — Пью только воду.
5분만 기다려 주세요.   — Подождите только 5 минут.
```

## 연습

1. "Я встаю в 7 часов" → __________
2. "Я завтракаю в 8 часов" → __________
3. "Работаю с 9 до 6" → __________
4. "Вчера я учился" → __________
5. "Я живу в Сеуле" → __________

**Ответы:**
1. 7시에 일어나요 / 일어납니다
2. 8시에 아침을 먹어요 / 먹습니다
3. 9시부터 6시까지 일해요 / 일합니다
4. 어제 공부했어요 / 공부했습니다
5. 서울에 살아요 / 삽니다
