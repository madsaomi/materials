# Unit 2 — 대화: 하루 일과 (Распорядок дня)

## 대화

```
수진: 민수 씨, 매일 몇 시에 일어나요?
민수: 보통 7시에 일어나요. 수진 씨는요?
수진: 저는 6시에 일어나요. 아침에 조깅을 해요.
민수: 아, 그래요? 부럽네요! 아침에 뭐 드세요?
수진: 주로 토스트랑 커피를 마셔요. 민수 씨는요?
민수: 저는 밥하고 김치를 먹어요. 한국식 아침이 좋아요.
수진: 몇 시에 출근해요?
민수: 9시까지 회사에 가야 해요. 지하철로 30분 걸려요.
수진: 퇴근은 몇 시에 해요?
민수: 보통 6시에 퇴근해요. 가끔 야근도 해요.
수진: 저녁에 뭐 하세요?
민수: 운동하거나 친구를 만나요. 주말에는 영화를 봐요.
```

## 번역

| 한국어 | Русский |
|--------|---------|
| 일어나다 | Вставать |
| 보통 | Обычно |
| 조깅하다 | Бегать трусцой |
| 부럽다 | Завидую |
| 드시다 | Есть/пить (уваж.) |
| 주로 | В основном |
| 토스트 | Тосты |
| 출근하다 | Идти на работу |
| 퇴근하다 | Заканчивать работу |
| 지하철 | Метро |
| 걸리다 | Занимать (время) |
| 가끔 | Иногда |
| 야근하다 | Работать сверхурочно |
| 운동하다 | Заниматься спортом |
| 만나다 | Встречаться |
