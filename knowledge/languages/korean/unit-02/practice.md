# Unit 2 — 연습 (Практика)

## 연습 1: 빈칸 (Заполните)

1. 저는 매일 7시___ 일어나요.
2. 학교___ 공부해요.
3. 9시___ 6시___ 일해요.
4. 집___ 있어요.
5. 커피___ 마셔요. (только)

**Варианты:** 에, 에서, 부터...까지, 만, 을/를

## 연습 2: 번역

1. Я встаю в 7 утра. → __________
2. Я завтракаю. → __________
3. Я иду в школу. → __________
4. Я учусь в библиотеке. → __________
5. Я ложусь спать в 11 часов. → __________

## 연습 3: Спряжение

| 읽다 | | |

## 연습 4: Распорядок дня

Опишите свой день, используя подсказки:

1. 7:00 → __________ (일어나다)
2. 8:00 → __________ (먹다)
3. 9:00 → __________ (가다)
4. 12:00 → __________ (먹다)
5. 18:00 → __________ (집에 가다)
6. 23:00 → __________ (자다)

## 연습 5: 대화 완성

Закончите диалог о распорядке дня:

```
A: 몇 시에 ___? (встаёте)
B: 7시에 일어나요. 아침에 ___? (что делаете)
A: 조깅을 해요. 아침을 ___? (едите)
B: 네, 토스트랑 커피를 먹어요.
A: 몇 시에 ___? (идёте на работу)
B: 9시까지 회사에 가요.
```

**연습 3:**
가다 → 가요 / 갔어요
먹다 → 먹어요 / 먹었어요
읽다 → 읽어요 / 읽었어요
공부하다 → 공부해요 / 공부했어요
일하다 → 일해요 / 일했어요
