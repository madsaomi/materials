# Корейский — Микро-детали

## 1. Произносительные тонкости

### 1.1 Ассимиляция — полные правила

**ㄴ → ㄹ после ㄹ:**
- 설날 (соллаль) — Новый год
- 진리 (질리) — истина (редко)

**ㄴ → ㅁ после ㅁ, ㅂ:**
- 감니다 (камнида) от ㅂ + ㄴ
- 합니다 (хамнида)

**ㄱ → ㅇ перед ㄴ/ㅁ:**
- 국물 (궁물) — бульон
- 먹는다 (멍는다) — ест

**ㅂ → ㅁ перед ㄴ:**
- 입니다 (임니다) — является
- 없습니다 (엄씀니다) — нет

**Палатализация (ㄷ + ㅣ → ㅈ):**
- 굳이 (구지) — упрямо
- 같이 (가치) — вместе
- 밭이 (바치) — поле

**ㅎ выпадение:**
- 좋다 (조타) → 좋은 (조은) — хороший
- 많다 (만타) → 많은 (마는) — много

**ㄹ выпадение:**
- 들다 → 드세요 — кушайте
- 알다 → 압니다 — знаю

**Правила 연음 (связывания):**
- Final consonant + vowel → carry-over
- 한국어 → [한구거] (хан-гу-го)
- 먹었다 → [먹거다] (мого-да)
- 있다 → [이다] (ида)
- 있잖아요 → [이잔아요]

**Правила 시음 (придыхания) и 경음 (твёрдых согласных):**
- After ㄹ, ㅁ, ㅂ, ㅅ at end of word: next word's initial consonant becomes tense
- 꽃이 → [꼬끼] (kkot-i)
- 밥을 → [바빨] (bap-eul)
- 끝까지 → [끝뺄까] (kkeut-kkaji)

### 1.2 Твёрдые согласные

ㄲ, ㄸ, ㅃ, ㅆ, ㅉ — произносятся с напряжением голосовых связок.
Разница между 평음 и 경음:

| 평음 (мягкий) | 경음 (твёрдый) |
|---------------|----------------|
| 가구 (кагу) — мебель | 까꾸 (ккакку) — ? |
| 달 (таль) — луна | 딸 (тталь) — дочь |
| 불 (пуль) — огонь | 뿔 (ппуль) — рог |
| 살 (саль) — мясо/возраст | 쌀 (ссаль) — рис |
| 자다 (чада) — спать | 짜다 (ччада) — солёный |

**Местоимение напряжения:**
- 경음 произносится с более сильным взрывом, как ударение на consonant
- Тренировка: произнесите 가 и 까 с разной силой — 까 должно быть «жёстче»

### 1.3 Придыхательные

ㅋ, ㅌ, ㅍ, ㅊ — с сильным выдохом:
- 가다 (када) — идти vs 카다 (кхада) — не слово
- 다리 (тари) — нога vs 타리 (тхари) — ? vs 따리 (ттари) — ?
- 바다 (пада) — море vs 파다 (пхада) — копать

**Упражнение для различения:**
- Положите руку перед ртом и произнесите: 카 → вы почувствуете сильный выдох
- 가 → менее сильный выдох
- Тренируйтесь с ㅋ/가, ㅌ/타, ㅍ/파, ㅊ/차

### 1.4 Связывание (연음)

Конечная согласная → к следующей гласной:
- 한국어 → [한구거] (хан-гу-го)
- 책을 → [채글] (чхэ-гыль)
- 같이 → [가치] (ка-чхи)
- 좋다 → [조타] (чо-та)
- 맛있다 → [마스시타] (ма-ссы-та)

**Правила 연음 по типам согласных:**

| Конечная | Переносится на | Пример |
|----------|----------------|--------|
| ㄱ | ㄱ, ㅇ | 강아지 → [강아지] |
| ㄴ | ㄴ, ㅁ, ㅇ | 선생님 → [선씀님] |
| ㄷ | ㄷ, ㅈ, ㅊ, ㅌ | 밥을 → [바빨] |
| ㄹ | ㄹ, ㅇ | 말이 → [마리] |
| ㅂ | ㅂ, ㅁ, ㅇ | 국밥 → [궁빱] |
| ㅅ | ㅅ, ㅆ, ㅈ, ㅊ, ㅌ | 맛있다 → [마스시타] |
| ㅇ | 无 (без эффекта) | 있다 → [이다] |

### 1.5 Интонационные паттерны

| Тип | Паттерн | Пример |
|-----|---------|--------|
| Вопрос да/нет | ↗ | 밥 먹었어? ↗ |
| WH-вопрос | ↘ | 뭐 해? ↘ |
| Удивление | ↗↘ | 진짜? ↗↘ |
| Команда | ровно | 빨리 와! → |
| Вежливое приветствие | ↗↘ (плавно) | 안녕하세요~ |
| Утверждение | ↘ | 그래요 ↘ |
| Задержка/неуверенность | ↗... | 나... maybe? |

**Интонация в диалогах:**
- Вопросы с вопросительными словами обычно нисходящие: 뭐 해요?↘
- Вопросы да/нет восходящие: 좋아요?↗
- Восклицания: высокая начальная нота с падением: 정말로!↘
- Паузы: в корейском разговоре много пауз для указания на интонационные клаузы

### 1.6 Высокий тон (Высокий тон корейского)

Хотя корейский не является тональным языком, существует концепция «высокого тона»:
- Первый слог часто произносится с более высокой нотой
- 서울 (соуль) — высокий на первый слог
- 사람 (сарам) — высокий на 사
- Эффект усиливается при эмоциональной окраске

## 2. Грамматические микро-детали

### 2.1 은/는 vs 이/가 — исчерпывающее

| 은/는 — тема, контраст, общее | 이/가 — субъект, новое, специфика |
|-------------------------------|-----------------------------------|
| 저는 학생입니다 (говорим обо мне) | 제가 하겠습니다 (ИМЕННО я сделаю) |
| 오늘은 바빠요 (а в другие дни — нет) | 오늘이 좋아요 (именно сегодня) |
| 인생은 아름답다 (общий факт) | 누가 왔어요? (кто?) |
| 커피는 안 마셔요 (а чай пью) | 민수 씨가 왔어요 (Минсу пришёл — новость) |
| 한국어는 재미있다 (корейский в целом) | 한국어가 재미있다 (именно корейский мне интересен) |
| 나는 키가 크다 (я — сравнение с другими) | 내가 Winner이다 (я — победитель, новость) |
| 차는 마셔도 괜찮아요 (чай — в общем) | 차가 맛있어요 (чай — конкретно этот) |

**Правила выбора:**
- Используйте 은/는, когда хотите установить тему для дальнейшего обсуждения
- Используйте 이/가, когда представляете новый элемент или спрашиваете «кто/что»
- Вопросительные слова всегда используют 이/가: 무엇이, 누구가, 어디가

**Частые ошибки:**
- ❌ 저는 학생이입니다 → ✅ 저는 학생입니다
- ❌ 사과가 먹어요 → ✅ 사과를 먹어요 (нужен объектный падеж!)

### 2.2 에 vs 에서 — движение vs действие

| 에 — местонахождение / направление | 에서 — место действия / отправления |
|------------------------------------|-------------------------------------|
| 학교에 있다 (быть в школе) | 학교에서 공부하다 (учиться в школе) |
| 집에 가다 (идти домой) | 집에서 나가다 (выходить из дома) |
| 의자에 앉다 (сесть на стул) | 서울에서 오다 (приехать из Сеула) |
| 병원에 가다 (идти в больницу) | 병원에서 오래 앓다 (долго болеть в больнице) |
| 미국에 살다 (жить в США) | 한국에서 태어나다 (родиться в Корее) |
| 교실에 있다 (быть в классе) | 교실에서 수업하다 (учиться в классе) |

**Особые случаи:**
- 시간 + 에: 내일 학교에 가요 (завтра иду в школу — направление)
- 시간 + 에서: 3시간동안 공부해요 (3 часа учу — длительность)

### 2.3 가다 vs 오다 — выбор точки отсчёта

| 가다 (идти туда) | 오다 (приходить сюда) |
|------------------|-----------------------|
| Speaker уходит от точки | Speaker в точке |
| 지금 집에 가요 (сейчас иду домой) | 지금 집에 와요 (сейчас прихожу домой — я дома или рядом) |
| 내일 한국에 가요 (завтра еду в Корею) | 내일 한국에 와요 (завтра приезжаю в Корею — я в Корее) |
| 학교에서 집에 가요 | 집에서 학교로 와요 |

**Правило:** представьте себя на карте. Если стрелка уходит от вас → 가다. Если стрелка к вам → 오다.

**Важное исключение:**
- 가다/오다 + 시간: 3시에 가요 (пойду в 3 часа) / 3시에 와요 (приду в 3 часа)
- 가다/오да +場所: 어디 가요? куда идёшь? / 어디 왔어요? откуда приехал?

### 2.4 아/어서 vs (으)니까 — причина

| 아/어서 — объективная причина, не с императивом | (으)니까 — субъективная, с императивом/предложением |
|------------------------------------------------|----------------------------------------------------|
| 비가 와서 집에 있어요 (идёт дождь, поэтому дома) | 비가 오니까 집에 있자 (дождь идёт, давай останемся) |
| 배가 아파서 병원에 갔어요 (живот болит → больница) | 늦었으니까 빨리 가자 (опоздали, пошли быстрее) |
| 너무 추워서 문을 닫아요 (слишком холодно → закрываю окно) | 너무 추우니까 창문을 닫자 (слишком холодно → давай закроем) |
| 학생이라서 쉬어요 (студент → отдыхаю) | 학생이니까 오늘 수업 취소하자 (студенты → давай отменим) |

**Мнемоника:**
- -아/어서 = «потому что» (нейтрально)
- -으니까 = «давай...» (предложение)

### 2.5 고 vs 서 — последовательность

| 고 — простое перечисление (и...) | 서 — последовательность/способ (затем) |
|----------------------------------|---------------------------------------|
| 밥 먹고 TV 봤어요 (ел и смотрел ТВ — порядок неважен) | 밥 먹으러 식당에 가요 (иду в ресторан есть) |
| 학교에 가고 친구를 만났어요 (пошёл в школу и встретил друга) | 일찍 일어나서 운동해요 (рано встаю и делаю зарядку) |
| 한국어를 배우고 있어요 (учу и продолжаю) | 공부하고 싶어서 열심히 해요 (хочу учить → делаю усердно) |

**Различие в значении:**
- 고: перечисление действий без акцента на порядок
- 서: указывает на цель, способ или причину следующего действия

### 2.6 지만 vs 는데 — контраст vs фон

| 지만 — прямой контраст (но) | 는데 — фон, контраст, мягкое "но" |
|----------------------------|-----------------------------------|
| 비싸지만 살 거예요 (дорого, но куплю) | 비싼데 살 거예요? (дороговато... будешь брать?) |
| 작지만 좋아요 (маленький, но хороший) | 어제 갔는데 없었어요 (вчера пошёл, а его не было) |
| 바빠지만 행복해요 (занят, но счастлив) | 오늘 날씨 좋은데? (какая сегодня погода?) |
| 한국어가 어렵지만 재미있다 (сложный, но интересный) | 한국어를 배우는데 어려워? (ты учишь корейский? как сложно?) |

**Мнемоника:**
- 지만 = жёсткое «но» → как русское «но»
- 는데 = мягкое «но» + вопрос/комментарий → как «а вот...»

### 2.7 아/어 있다 vs 고 있다

| 아/어 있다 — состояние (результат) | 고 있다 — процесс (действие) |
|-----------------------------------|-----------------------------|
| 앉아 있다 (сидит — уже сел и сидит) | 앉고 있다 (садится прямо сейчас) |
| 문이 열려 있다 (дверь открыта) | 문을 열고 있다 (открывает дверь) |
| 서 있다 (стоит) | 서고 있다 (встаёт) |
| 누워 있다 (лежит) | 눕고 있다 (ложится) |
| 생각하고 있다 (думает — результат) | 생각하고 있다 (думает — процесс) |

**Различие:**
- 아/어 있다 = результат видим, состояние установилось
- 고 있다 = действие происходит прямо сейчас

**Специфические случаи:**
- 쉬다: 쉬고 있다 (отдыхаю — процесс) / 쉬어 있다 (отдыхаю — состояние, отдых)
- 서다: 서 있고 싶다 (хочу постоять) / 서고 싶다 (хочу начать стоять)

### 2.8 -고 있다 vs -고 싶다 vs -고 있다

| Форма | Значение | Пример |
|-------|-----------|--------|
| -고 있다 | действие в процессе | 먹고 있다 (ем сейчас) |
| -고 싶다 | желание после действия | 먹고 싶다 (хочу поесть) |
| -아/어 보다 | опыт, проба | 먹어 보다 (попробую поесть) |
| -고 있다/없다 | наличие/отсутствие | 앉아 있다 / 앉아 있지 않다 |

### 2.9 -아/어 보다 vs -ㄴ/은 적이 있다

| -아/어 보다 | -ㄴ/은 적이 있다 |
|-------------|------------------|
| Проба/опыт | Опыт в прошлом |
| 한국어를 처음으로 먹어 보다 (попробую впервые) | 한국에 가 본 적이 있어요 (есть опыт посещения) |
| 맛을 보다 (попробить) | 한국영화를 본 적이 있어요 (ранее смотрел) |

### 2.10 -아/어 주다 vs -아/어 주세요 vs -아/어 주다

| Форма | Значение |
|-------|-----------|
| -아/어 주다 | кто-то делает для меня |
| -아/어 주세요 | прошу сделать для меня |
| -아/어 주겠다 | собираюсь сделать для кого-то |
| -아/어 주지 않다 | не делаю для кого-то |

**Примеры:**
- 커피를 주세요 (дайте кофе)
- 나를 도와주세요 (помогите мне)
- 선생님이 알려주셨어요 (учитель объяснил)
- 친구가 가방을 들어주었어요 (друг понёс сумку)

### 2.11 -아/어 지다 vs -아/어지다

| -아/어 지다 | -아/어지다 |
|-------------|------------|
| состояние (стать) | процесс (становиться) |
- 유명해지다 (стать знаменитым) | 유명해져요 (становлюсь известным) |
- 학생이 되다 (стать студентом) | 학생이 되어요 (становлюсь студентом) |
- 날씨가 추워지다 (становится холодно) | 날씨가 점점 추워져요 |

### 2.12 -고 있는데 vs -는데

| -고 있는데 | -는데 |
|-------------|--------|
| «... и при этом...» | «... но...» / «... потому что...» |
- 먹고 있는데 먹을 게 없어요 (ем, но нет еды) | 가고 있는데 버스가 안 와요 (еду, но автобус не пришёл) |
- 바쁘는데 밥을 못 먹어요 (занят, не могу поесть) | 비가 오는데 우산이 없어요 (дождь, но зонт нет) |

## 3. Глагольные микро-детали

### 3.1 Полный список неправильных глаголов

** ㄷ-неправильные (ㄷ → ㄹ перед гласной):**
| Глагол | Значение | Основа | Вежливая |
|--------|----------|--------|----------|
| 듣다 | слушать | 들 | 들어요 |
| 걷다 | ходить | 걸 | 걸어요 |
| 묻다 | спрашивать | 물 | 물어요 |
| 싣다 | грузить | 실 | 실어요 |
| 깨닫다 | осознавать | 깨달 | 깨달아요 |
| 맞다 | быть правильным | 맞 | 맞아요 |
| 답하다 | отвечать | 답 | 답해요 |
| 입다 (глагол-прилаг.) | входить | 입 | 들어요 |

**Исключения (правильные):**
- 받다 (получать) → 받아요 (не 발아요)
- 닫다 (закрывать) → 닫아요
- 믿다 (верить) → 믿어요
- 얻다 (получать) → 얻어요

** ㅂ-неправильные (ㅂ → 우):**
| Глагол | Значение | Основа | Вежливая |
|--------|----------|--------|----------|
| 춥다 | холодно | 추우 | 추워요 |
| 덥다 | жарко | 더우 | 더워요 |
| 쉽다 | легко | 쉬우 | 쉬워요 |
| 어렵다 | трудно | 어려우 | 어려워요 |
| 맵다 | острый | 매우 | 매워요 |
| 돕다 | помогать | 도우 | 도와요 |
| 눕다 | ложиться | 누우 | 누워요 |
| 기쁘다 | радостный | 기뻐 | 기뻐요 |
| 쓰다 | писать | 써 | 써요 |
| 크다 | большой | 커 | 커요 |
| 예쁘다 | красивый | 예뻐 | 예뻐요 |
| 아프다 | больно | 아파 | 아파요 |
| 고프다 | голоден | 고파 | 고파요 |
| 바쁘다 | занят | 바빠 | 바빠요 |
| 슬프다 | грустен | 슬퍼 | 슬퍼요 |
| 부르다 | звать | 불러 | 불러요 |
| 자르다 | резать | 잘라 | 잘라요 |
| 고르다 | выбирать | 골라 | 골라요 |
| 다르다 | другой | 달라 | 달라요 |
| 서두르다 | спешить | 서둘러 | 서둘러요 |

**Исключения:**
- 좁다 (узкий) → 좁아요 (правильный)
- 입다 (надевать) → 입어요
- 씹다 (жевать) → 씹어요
- 낫다 (выздоравливать) → 나아요
- 긋다 (чертить) → 그어요

** 르-неправильные:**
| Глагол | Значение | Вежливая |
|--------|----------|----------|
| 모르다 | не знать | 몰라요 |
| 빠르다 | быстрый | 빨라요 |
| 부르다 | звать | 불러요 |
| 자르다 | резать | 잘라요 |
| 고르다 | выбирать | 골라요 |
| 다르다 | другой | 달라요 |

### 4.2 Исключения при счёте

| 1 | 2 | 3 | 4 | 20 |
|---|---|---|---|---|
| 하나 (хана) → 한 (хан) | 둘 (туль) → 두 (ту) | 셋 (сет) → 세 (се) | 넷 (нет) → 네 (не) | 스물 → 스무 |

- 한 개 (не 하나 개)
- 두 명 (не 둘 명)
- 세 시 (не 셋 시)
- 네 명 (не 넷 명)
- 스무 살 (не 스물 살)

**Дополнительные исключения:**
- 열 → 열한, 열두, 열셋, 열넷, 열다섯...
- 하지만 열한, 열두, 열셋 (двадцать один — 스물하나, не 열두하나)

### 4.3 Несчастливые числа

- 4 (사, са) — смерть, избегают в лифтах (F → 3, 4 → F)
- 14 (십사) — звучит как 십사 (十死) — десять смертей
- 44 (사십사) — очень плохо
- 18 (십팔) — сленг для 욕 (十八 = shit)
- 1004 (천사, чхонса) — 천사 = ангел (хорошее) → но может звучать жутко
- 7 (칠, чхиль) — иногда считается несчастливым (звучит как «голод» в некоторых диалектах)

## 8. Культурные заметки по юнитам

### 8.1 Unit 1: Знакомство и этикет

- **Поклоны (절):** Чем старше собеседник, тем ниже поклон. Обычный поклон — 30°, глубокий — 45°+, самый глубокий — 90°. При представлении используйте правую руку, левую поддерживая запястье.
- **Имена и обращения:** Фамилия + 씨 (씨). Никогда не называйте по имени без приглашения. Для учителей: 선생님 (сонсэнним). Для пожилых: 할머니/할아버지 с уважением.
- **Обувь:** Снимайте при входе в дом, ресторан с флор-полом, некоторые школы. Обувь ставят носком к двери.
- **Подарки (선물):** Протягивайте двумя руками. Не дарите: обувь (уйдёт), красные ручки (смерть), парные предметы (нечётное число — лучше). Цвета: белый (похороны), чёрный (скорбь), красный (счастье).

### 8.2 Unit 2: Еда и культура питания

- **Правила за столом:**
  - Старший начинает есть первым
  - Не ешьте, пока не налили всем
  - Не втыкайте палочки вертикально в рис (это похоронный ритуал)
  - Наливайте напитки другим, не себе; пьют, повернувшись от старших
  - 팔짝 (пальчан) — скрещивание рук считается грубым
- **Кимчи (김치):** Национальное блюдо, ферментированные овощи. Более 200 видов. Каждая семья имеет «рецепт бабушки». Хранится в специальных погребах (김치냉장고).
- **Чамсик (참식):** Формальная трапеза с несколькими блюдами (12+, иногда 30+). Все блюда ставятся одновременно.

### 8.3 Unit 3: Транспорт и городская культура

- **Метро Сеула:** Один из самых чистых и эффективных в мире. Станции названы в хангыле, англоязычно и китайскими иероглифами. Выходите на следующей станции, если сели не туда — это нормально.
- **Такси:** Белые (обычные) и чёрные «модельные». Водитель помощник, если просите. Оплата: картой или наличными. Мелочь оставляют как чаевые (не обязательно, но принято).
- **Тотэмные знаки:** Запрещено курить в общественных местах (штраф 100 000 вон). Очередь — строго, без толкания. Шум в общественном транспорте — табу.

### 8.4 Unit 4: Ресторанная культура

- **Чонсон (정션):** Формальный ужин в корейском стиле. Обслуживание — это искусство. Счёт обычно приносят по запросу.
- **Банчан (반찬):** Бесплатные закуски к каждому заказу еды. Их количество зависит от заведения. Не убирайте, если не просите.
- **Соджу (소주):** Самый популярный алкоголь. Пьют с помощью «пуксук» (палочка для пьяниц). Тосты — всегда старший.
- **Макколи (막걸리):** Традиционное напиток, слабоалкогольный. Пьют в мисках, заливают снег зимой (막걸리빙수).
- **Чжинджа (진짜?):** Если еда вкусная — говорят «진짜!» или «진짜 맛있다!» и хлопают в ладоши.

### 8.5 Unit 5: Хобби и развлечения

- **PC-бан (PC방):** Компьютерные залы — культура. Играть в StarCraft, League of Legends. Открыты 24/7.
- **Нораэбанг (노래방):** Караоке-кабинки. Аренда за час, заказ еды и напитков. Популярно на вечеринки.
- **Хванхо (환호):** Толпа фанатов K-pop на концертах. Синхронные световые шоу.
- **Пучхум (풀업):** Фитнес-тренировки на улице (особенно в парках).

### 8.6 Unit 6: Телефон и коммуникации

- **Телефонный этикет:**
  - Первое rings —接听 (ответить)
  - Говорить с улыбкой (слышно в голосе)
  - Говорить тихо в общественном транспорте
  - Звонок = «여보세요?» (ёбосё?) — «Говорите?»
- **Смс и KakaoTalk:** Главное мессенджер в Корее. Используют стикеры (이모티콘). Чтение сообщений — немедленное.
- **Пукты (부탁):** «Чхаль путакхабнида» (잘 부탁드립니다) — «Прошу любить и жаловать». Ключевая фраза при знакомстве.

### 8.7 Unit 7: Умения и образование

- **Система образования:** Экстремально конкурентная. Дополнительные занятия (학원 — хаквон) после школы до 22:00. Успех определяется экзаменами (수능 — суджонг).
- **«한국어 공부해요»:** Утверждение «я учу корейский» обычно вызывает восторг и предложения помощи.
- **-ㄹ 수 있다 / -(으)ㄹ 수 없다:** Умения выражаются через эту конструкцию. «Начну» = «해볼게요». «Попробую» = «해보세요».
- **Культурный контекст:** В Корее значение «잘하다» (делать хорошо) очень важно. Неудачу считают shameful (체면이 안 돼서).

### 8.8 Unit 8: Дарение и социальные связи

- **Система подарков:**
  - Деньги в конвертах (황색/розовый для свадьбы, чёрный для похорон)
  - Подарки при визите: фрукты, продукты, алкоголь
  - Два руками всегда
  - Не открывайте подарок при дарителе
- **Чхонхол (청혼):** Предложение руки и сердца. Мужчина на коленях с кольцом.
- **Конфетта (콘фет):** Похороны — белые цветы, свадьба — розовые.

### 8.9 Unit 9: Шопинг

- **Ттаекбэ (따끔):** «Это дорого!» Торговаться ожидается в традиционных рынках (재래시장). В магазинах — нет.
- **Сонхвам (선물):** Магазины часто дают подарки к покупке (особенно косметика).
- **Квонджонхамнида (권장합니다):** «Я рекомендую» — продавец часто уговаривает.
- **Пчхонхва (변화):** «Изменить» — обмен товара обычно возможен в течение 7 дней.
- **Культура шопинга:** Корея — мировая столица K-beauty и моды. Масс-маркет бренды: Olive Young, Musinsa.

### 8.10 Unit 10: Путешествия по Корее

- **Система перевозок:** T-money карта для метро и автобусов. Скидки при пересадках.
- **Ханбок (한복):** Ношение традиционной одежды — популярное развлечение. При аренде ханбока приятно надевать и фотографироваться в дворцах.
- **Чхамджиго (참치기):** «Я пошёл/пришёл» — часто говорят «다녀왔다» (пошёл и вернулся).
- **Ок-халь (오킬):** «Всё включено» — поездка без дополнительных расходов.
- **Культурные различия:** В Корее публичные поцелуи — табу. Поцелуи в щёку — нет.

### 8.11 Unit 11: Работа и рынок труда

- **Социальная иерархия:** Возраст — ключевой фактор. Даже среди сверстников старший по месяцу рождения считается старшим.
- **Ильчо (일처):** «Работа» — строгая культура. Корейцы работают одни из самых долгих часов в мире.
- **Сонбим (손빔):** «Пожатие рук» — редкость. Чаще — клан и приветствие.
- **Сисим (시험):** Экзамены определяют будущее. Суджонг (대학수학능력시험) — экзамен для поступления в вуз, весь народ останавливается в этот день.

### 8.12 Unit 12: 존댓말 и социальные иерархии

- **Система 존댓말:** Одни из самых сложных в мире. Отражает конфуцианские ценности: 효도 (хёдо — уважение к родителям), 예의 (ёи — этикет), 의리 (уири — долг).
- **Почему так сложно:** Возраст определяет уровень вежливости. Даже на 1 день старше = 존칭. Поэтому Корейцы часто спрашивают возраст в первые минуты знакомства.
- **Начало диалога:** «언제 태어났어요?» (Когда вы родились?) — нормальный вопрос!
- **Датные формы:** -세요, -십니다, -으세요 — разные уровни 존칭.
- **반말:** Используется только между близкими друзьями, после взаимного согласия «사귀기로 했어요» (решили дружить).

### 8.13 Unit 13: Условия и гипотезы

- **Культурный контекст условий:** В Корее фраза «-으면 좋겠다» («если бы... было бы хорошо») часто используется для выражения надежд, а не реальных условий.
- **Если-структура в общении:** Корейцы предпочитают мягкие формы: «-면 안 될까요?» (не лучше ли...?), «-았으면 좋겠습니다» (надеюсь, что...).
- **Отказ:** Корейцы редко говорят «нет» прямо. Вместо этого: «잘 안 되는데요» (сложно...) или «고려해 보겠습니다» (подумаю).

### 8.14 Unit 14: Письменная речь

- **격식체 vs 비격식체:** Официальное письмо использует 격식체 (-ㅂ니다, -옵니다). Неофициальное — 비격식체 (-요, -아/어).
- **Письменные нормы:** В деловой переписке — вежливые формы, вежливые обращения (존칭), формальное завершение.
- **Дневники:** Корейские дневники (일기) часто начинаются с 날씨 (погода): «오늘 날씨가 좋다» — традиция от конфуцианских текстов.
- **Карточки (명함):** Обмен визитками — ритуал. Принимайте двумя руками, изучите, положите на стол перед собой. Не пишите на визитку в присутствии владельца.

### 8.15 Unit 15: Слухи и передача информации

- **-다고 하다:** Передача чужих слов. В Корее слухи (소문) распространяются очень быстро. «XX 한다고 했어» (говорят, что XX).
- **Медиа и доверие:** Корейцы критически относятся к новостям. «소문은 사실이 될 수 있다» (слухи могут стать事实).
- **Культура мнений:** «어떻게 생각해요?» (что ты думаешь?) — частый вопрос. Открытое выражение мнения — нормально в дружеских беседах.

## 9. 🏛️ Корейская культура: глубокие погружения

### 9.1 История корейского языка и создание хангыля

#### Предыстория

До создания хангыля корейцы использовали:
- **Идго (이도):** Китайские иероглифы для значений + корейские словоизменения
- **Идунмун (이순문):** Письменность на основе китайских иероглифов, адаптированная для корейского
- Проблема: Китайские иероглифы были сложны для простого народа. Только аристократия и учёные умели писать.

#### Седжон Великий (세종 대왕, 1418–1450)

**Король Седжон Великий** — четвёртый правитель династии Чосон — создал хангыль в 1443 году.

**Мотивация:**
- Простой народ не мог выражать мысли на родном языке
- Китайские иероглифы не подходили для фонетической структуры корейского
- Научный подход к созданию письменности

**Научная основа:**
- Каждая буква моделирует положение артикуляторов:
  - ㄱ: язык у нёба (заднее место произношения)
  - ㄴ: язык у зубов (переднее)
  - ㅁ: губы (губной звук)
  - ㅅ: зубы (альвеолярный)
- Гласные основаны на небесной (ㅇ), земной (ㅡ) и человеческой (ㅣ) стихиях (теория Самган)

**Название:**
- Хангыль (한글) — «письмо Корейской области»
- Хунминджонгым (훈민정음) — «правильные звуки для наставления народа»
- Опубликован в 1446 году как «훈민정음 자제해체»

**Исторический контекст:**
- 1443: Создание алфавита
- 1446: Публикация трактата «Хунминджонгым»
- 19 век: Борьба за использование хангыля против китайских иероглифов
- 1948: Хангыль становится официальной письменностью Республики Корея
- 1970: Отказ от китайских иероглифов в Северной Корее
- 2014: Хангыль включён в список нематериального наследия ЮНЕСКО

#### Современное значение

- Хангыль — один из самых научных и эффективных алфавитов в мире
- Термины «хангульский алфавит» (Hunminjeongeum) признаны шедевром
- Хангыль — единственный алфавит, специально созданный учёными и имеющий собственный праздник (9 октября — День хангыля)

### 9.2 Система 존댓말 (вежливости)

#### Исторические корни

Система 존댓말 основана на конфуцианских принципах:
- **효도 (хёдо)** — сыновняя почтительность
- **예의 (ёи)** — этикет и правильность
- **신의 (сини)** — доверие
- **충 (чхунг)** — верность

#### Современная структура

| Уровень | Окончание | Контекст | Пример |
|---------|-----------|----------|--------|
| 하소서체 | -나이다 | Императорский, архаический | 가나이다 |
| 존칭/합쇼체 | -ㅂ니다/습니다 | Официальный, нейтральный | 갑니다 |
| 하오체 | -ㅂ니다/오 | Литературный, старинный | 가오 |
| 해체 (ха) | -아/어 | Неформальный, равные | 가 |
| 해요체 | -아요/어요 | Вежливый разговорный | 가요 |
| 해라체 | -다 | Повествовательный, книги | 간다 |

**Правила использования:**
1. С незнакомцами → 합쇼체 или 해요체
2. С друзьями → 해체 (после взаимного согласия)
3. С младшими → 할 수 있으면 해체 (но часто используют 해요че даже с младшими из вежливости)
4. В сервисах → 합쇼체
5. В СМИ → 합쇼체
6. В литературе → 해라체 или 하오체

**Тайминг перехода к 반말:**
- Обычно после 6 месяцев общения и взаимного согласия
- Фраза: «우리 반말하자» (давай поговорим на банмале)
- В компаниях: после 3 лет работы часто переходят

## 10. 🇰🇷🇷🇺 Сравнение корейской и русской культуры

### 10.6 Общие черты

Несмотря на различия, корейская и русская культуры имеют общие черты:
- **Глубокая литературная традиция:** Корейская классическая поэзия (시조) ↔ русская классика
- **Ценность гостеприимства:** Обе культуры щедры к гостям
- **Важность семьи:** И корейская, и русская семьи ценят семейные узы
- **Трудолюбие:** Обе культуры высоко ценят усердный труд
- **Льготное отношение к старшим:** И в Корее, и в России уважают пожилых
- **Любовь к еде:** Обе культуры любят обильную еду и считают вкусную еду важным

### 10.7 Культурные нюансы для русскоязычных

- **Не бойтесь пожаловаться:** «매우 비싸요» (очень дорого) — в Корее это ожидаемо при торговле, но без agresivnosti
- **Тосты:** Пейте, повернувшись от старших
- **Подарки:** Дарите нечётное количество; не дарите 4, 7, 10 (несчастливые)
- **Обувь:** Всегда снимайте при входе в дом
- **Возраст:** Не стесняйтесь спрашивать — это нормально
- **Отказы:** «조금 어렵습니다» (немного сложно) = «нет»; «고려해 보겠습니다» = «подумаю» (необязательно)
- **Публичные поцелуи:** Табу — не демонстрируйте близость на публике

## 11. 📜 История корейского языка

### 11.1 Доисторический период (до VII века н.э.)

- Корейский язык — один из старейших языков Восточной Азии
- Предки корейцев (시조, сиджо) говорили на языке, который назывался **구비어 (кубио)** — «древний язык»
- Взаимопонимание с современным корейским ограничено
- Влияние: китайский, японские, монгольские и тюркские элементы

### 11.2 Период трех корейских государств (57 г. до н.э. — 668 г. н.э.)

- **Когурё (고구려):** Самое большое государство. Язык находился под сильным влиянием китайского
- **Пэкче (백제):** Влияние японского и китайского языков
- **Силла (신라):** Объединил три государства в 668 году. Создание **이도 (идо)** — системы на основе китайских иероглифов

### 11.3 Период Корё (918–1392)

- **Кочхон (국어):** Появление первых грамматических описаний корейского
- **Нунсин (훈민정음):** Идея создания корейской письменности возникает задолго до Седжона
- **Идунмун (이순문):** Система письма, смешивающая иероглифы и корейскую грамматику
- **Гугьо (국어):** Утверждение корейского языка как отдельного языка

### 11.4 Период Чосон (1392–1910)

- **1443:** Создание хангыля королём Седжоном Великим
- **1446:** Публикация «Хунминджонгым» — трактата о хангыле
- **15-18 века:** Золотой век корейской литературы: 칠흥체 (весенняя поэзия), 정조 (правление Чонджо)
- **19 век:** Влияние западной культуры, появление новых слов

### 11.5 Современный период (1910 — настоящее время)

- **1910–1945:** Японская оккупация — запрет на хангыль, принуждение к японскому
- **1945:** Освобождение, восстановление хангыля
- **1948:** Республика Корея — хангыль официальная письменность
- **1950–1953:** Корейская война — влияние на язык (новая лексика, военная терминология)
- **1960–1990-е:** Экономический рост — развитие терминологии, заимствования из английского
- **1990-е — настоящее время:** Глобализация, K-поп, K-дорамы — корейский язык становится мировым

### 11.6 Диалекты корейского языка

#### Диалектная карта Кореи

Корейский язык имеет множество диалектов (방언), которые можно разделить на:

| Диалект | Область | Особенности |
|---------|---------|-------------|
| 서울 방언 (Сеульский) | Сеул и окрестности | Стандартная основа, наиболее распространённый |
| 경기도 방언 (Кёнгидо) | Провинция Кёнгидо | Близок к сеульскому с некоторыми отличиями |
| 충청 방언 (Чхунчхон) | Провинция Чхунчхон | Мягкое произношение, другие интонации |
| 전라 방언 (Чолла) | Провинция Чолла | Выразительная интонация, другие окончания |
| 경상 방언 (Кёнсан) | Провинция Кёнсан | Жёсткое произношение, отличные окончания |
| 강원 방언 (Канвон) | Провинция Канвон | Влияние северокорейского диалекта |
| 제주 방언 (Чеджу) | Остров Чеджу | Очень отличается, иногда считается отдельным языком |
| 평안 방언 (Пхёнан) | Провинция Пхёнан | Основа для северокорейского стандарта |
| 함경 방언 (Хамгён) | Провинция Хамгён | Наиболее отличается от сеульского |
| 황해 방언 (Хванхэ) | Провинция Хванхэ | Исключительные черты |

#### Основные различия диалектов

**Сеульский vs Кёнсанский:**
- Сеульский: 맛있어 (ма시со) vs Кёнсанский: 맛싸 (масса)
- Сеульский: 좋아요 (чоаё) vs Кёнсанский: 조아 (чоа)

**Сеульский vs Чоллинский:**
- Сеульский: 안녕하세요 (аннёнхасэё) vs Чоллинский: 안녕하시다 (аннёнхасида)
- Сеульский: ㅓ (ʌ) vs Чоллинский: ㅘ (wa) в некоторых позициях

**Северокорейский стандарт:**
- Использует Пхёнанский диалект
- Сохраняет некоторые архаичные формы
- Заимствования из русского и китайского (после войны)
- Различия в лексике: «빵» (ппан) vs «호빵» (хоббан) — булочка

**Чедджуский диалект:**
- Иногда рассматривается как отдельный язык
- Уникальные слова, отсутствующие в стандартном корейском
- Влияние японского (период оккупации)
- Женский диалект — более выраженная интонация

### 12.10 Корейская поэзия и лирика

>
