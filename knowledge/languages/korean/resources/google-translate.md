# Google Translate — озвучивание и перевод

> 🔗 Внешний ресурс: <https://translate.google.com/?sl=ko>

- Быстрое озвучивание корейского текста (TTS).
- Перевод отдельных слов и фраз для проверки.
- Полезно для экстенсивного слушания коротких фраз.

## Как использовать в курсе

1. Вставлять фразу из упражнения.
2. Слушать озвучку при медленной скорости.
3. Сверять свой перевод с предложенным, но не полагаться слепо.
