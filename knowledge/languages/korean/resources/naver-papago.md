# Naver Papago — перевод с аудио

> 🔗 Внешний ресурс: <https://papago.naver.com/>

- Корейский машинный перевод и озвучивание (TTS).
- Надёжнее для корейского, чем многие общие переводчики.
- Полезно для перевода фраз и прослушивания произношения.

## Как использовать в курсе

1. Перевести незнакомую фразу.
2. Слушать аудио-озвучку.
3. Сравнить с грамматическим разбором из [учебника](../textbook.md).
