# Korean Bible — библейские тексты для экстенсивного чтения

> 🔗 Внешний ресурс: <https://www.bible.com/versions/KE-KRIV-ko>

- Корейский перевод Библии (KRIV).
- Формальный, но понятный язык; повторяющиеся конструкции.
- Полезно для экстенсивного чтения и аудирования.

## Как использовать в курсе

1. Читать по 1 главе, не вникая в каждое слово.
2. Слушать аудио-версию параллельно.
3. Выписывать только самые частотные новые слова.
