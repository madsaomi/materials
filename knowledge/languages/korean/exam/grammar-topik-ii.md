# Грамматика TOPIK II (3–6급) — конструкции с примерами

> Примерная привязка по экзамену: 3급 — повседневно-деловое; 4급 — аналитика, новости; 5–6급 — академика, абстракция.
> Конструкция дана с примером предложения и переводом. + = более формальная, = нейтральная.

## 3급 — средний уровень

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 기 위해서 | «для того чтобы» | 성공하기 위해서 열심히 노력해요. — Усердно стараюсь, чтобы добиться успеха. |
| (으)려고 하다 | «намереваться, собираться» | 주말에 고향에 내려가려고 해요. — Собираюсь поехать на родину в выходные. |
| (으)려던 참이다 | «как раз собирался» | 지금 나가려던 참이었어요. — Как раз собирался выходить. |
| 다가 | «делал … и вдруг» | 길을 걷다가 친구를 만났어요. — Шёл по улице и вдруг встретил друга. |
| 더라고요 | «я заметил, что…» | 그 영화가 정말 재미있더라고요. — Я заметил, что фильм правда интересный. |
| 네요 (감탄) | выражение удивления | 날씨가 참 좋네요! — Какая хорошая погода! |
| (으)ㄴ 적이 있다 | «был опыт» | 제주도에 가 본 적이 있어요. — Бывал на Чеджу. |
| 아/어 보다 | «попробовать / был опыт (разг.)» | 김치를 직접 만들어 봤어요. — Попробовал сделать кимчи сам. |
| 는 편이다 | «скорее … (отност.)» | 저는 아침을 일찍 먹는 편이에요. — Я обычно завтракаю рано. |
| (으)ㄹ 줄 알다/모르다 | «уметь / не уметь» | 자전거를 탈 줄 알아요. — Умею ездить на велосипеде. |
| 게 되다 | «оказалось, что … / получилось» | 서울에서 일하게 되었어요. — Получилось так, что я работаю в Сеуле. |
| 어/아 주고 싶다 | «хочу сделать для» | 어머니께 선물을 사 주고 싶어요. — Хочу купить подарок маме. |
| 감사하다고 하다 | «передавать слова благодарности» (чужая речь с глаголом) | 선생님 감사하다고 전해 주세요. — Передайте учителю благодарность. |
| 는 대신에 | «вместо того чтобы» | 밥을 먹는 대신에 샌드위치를 먹었어요. — Ел сэндвич вместо риса. |
| 어/아야겠다 | «надо будет» | 물을 마셔야겠어요. — Надо будет выпить воды. |
| (으)ㄹ까 봐 | «боясь, что…» | 늦을까 봐 택시를 탔어요. — Взял такси из страха опоздать. |
| (으)ㄴ/는 데다가 | «плюс к тому (до 3급/4급 границы)» | 예쁜 데다가 성격도 좋아요. — Красивая, и характер хороший. |
| (으)ㄹ 뿐만 아니라 | «не только … но и» | 예쁠 뿐만 아니라 똑똑해요. — Не только красивая, но и умная. |
| 기는 하지만 | «хотя и …» | 힘들기는 하지만 재미있어요. — Хотя и тяжело, но интересно. |
| 어/아서 좋다 | «приятно, что… (следствие)» | 날씨가 좋아서 기분이 좋아요. — Погода хорошая, и настроение хорошее. |
| (으)ㄹ 정도로 | «до такой степени, что…» | 울 정도로 기뻤어요. — Был счастлив до слёз. |
| 어/아 놓다 | «сделать заранее (результат сохраняется)» | 문을 잠가 놓았어요. — Закрыл дверь (и оставил закрытой). |
| 어/아 가다 / 오다 | «делать постепенно/по ходу» | 차츰 익숙해져 가요. — Постепенно привыкаю. |
| (으)ㄹ 뻔하다 | «чуть не…» | 넘어질 뻔했어요. — Чуть не упал. |
| (으)ㄹ 텐데 | «наверняка…, но» | 좋을 텐데 왜 안 가요? — Наверняка было бы хорошо, почему не идёшь? |
| 웃으면서 말해요 | обстоятельственный оборот -면서 | 웃으면서 말해요. — Говорит с улыбкой. |

## 4급 — продвинутый средний

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 더니 | «видел(а), что…, и затем» | 지난번에 몸이 안 좋더니 이제 다 나았네요. — Раз было плохо, теперь уже выздоровел. |
| (으)ㄴ/는 반면에 | «в то время как / и хотя» | 이 제품은 비싼 반면에 품질이 좋아요. — Хоть товар дорогой, качество хорошее. |
| (으)ㄴ/는데다가 | «вдобавок» | 비가 오는데다가 바람도 불어요. — Идёт дождь, и вдобавок дует ветер. |
| (으)ㄴ/는 셈이다 | «можно считать» | 한 시간 걸린 셈이에요. — Можно считать, что прошёл час. |
| (으)ㄴ/는 탓에 | «из-за (негатив)» | 비가 온 탓에 경기가 취소됐어요. — Из-за дождя матч отменили. |
| 기에 앞서 | «прежде чем» | 시작하기에 앞서 인사를 드릴게요. — Прежде чем начать, поприветствую вас. |
| (으)로 인해 | «вследствие» | 사고로 인해 지연됐습니다. — Задержан вследствие происшествия. |
| 에 달려 있다 | «зависит от» | 성공은 노력에 달려 있어요. — Успех зависит от старания. |
| (으)ㅁ으로써 | «тем самым» | 대화함으로써 문제를 풀었어요. — Решил проблему тем, что поговорил. |
| (으)ㄹ 따름이다 | «всего лишь» | 제가 할 일을 했을 따름이에요. — Я просто сделал своё дело. |
| (으)ㄹ 만하다 | «стоит того, чтобы» | 이 책은 읽을 만해요. — Эту книгу стоит прочитать. |
| 더군요 | «я увидел, что… (прошлое мнение)» | 값이 정말 싸더군요. — Я увидел, что это правда дёшево. |
| (으)ㄴ/는 대로 | «как только / как есть» | 도착하는 대로 전화할게요. — Позвоню, как только приеду. |
| 어/아 두다 | «сделать заранее (для будущего)» | 자료를 미리 모아 두었어요. — Собрал материалы заранее. |
| 게 되겠네요 | (модальн. соединение) | 이번에 함께하게 되겠네요. — Видимо, теперь будем сотрудничать. |
| (으)ㄹ 리가 없다 | «не может быть, чтобы…» | 그런 일이 있을 리가 없어요. — Не может быть, чтобы такое произошло. |
| (으)ㄹ 수밖에 없다 | «не остаётся ничего, кроме» | 기다릴 수밖에 없어요. — Остаётся только ждать. |
| 얼마나 (으)ㄴ/는지 | «насколько» | 얼마나 긴장했는지 몰라요. — И не скажешь, как нервничал. |
| (으)ㄴ/는지 알다/모르다 | «знать/не знать, что ли…» | 제가 틀렸는지 모르겠어요. — Не знаю, ошибся ли я. |
| 과거-의도: -(으)려던 | «собирался было» | 사려던 책을 샀어요. — Купил книгу, которую собирался было. |

## 5–6급 — продвинутый / высокий

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 는 법이다 | «естественно, что…» | 연습하면 실력이 늘기는 법이에요. — Практика естественно развивает умения. |
| (으)니만큼 | «поскольку / раз уж» | 시간이 없으니만큼 빨리 시작합시다. — Раз времени нет, начнём поскорее. |
| 기에 망정이지 | «к счастью / едва не…» | 일찍 출발했기에 망정이지 늦을 뻔했어요. — Раз выехали рано, то чуть не опоздали (хорошо, что). |
| (으)ㄹ 지경이다 | «до такой степени (перех.)» | 울 지경이었어요. — Был на грани слёз. |
| 는/은 대로 | «как есть / как только» | 설명한 대로 하세요. — Делайте, как объяснил. |
| (으)로 미루어 보아 | «судя по» | 성적으로 미루어 보아 노력한 것 같다. — Судя по оценкам, он приложил усилия. |
| 는 마당에 | «в обстановке, когда…» | 모두 힘든 마당에 남을 탓할 수 없어요. — Раз всем тяжело, нельзя винить других. |
| 는 둥 마는 둥 | «спустя рукава» | 일을 하는 둥 마는 둥 해요. — Делает работу спустя рукава. |
| (으)랴 마냐 | «то ли… то ли…» | 좋으랴 마냐, 걱정만 쌓여요. — То ли рад, то ли нет — только тревога копится. |
| (으)나 마나 | «будь так/этак» | 물어보나 마나 결과는 같아요. — Спросишь или нет — итог один. |
| (으)ㄹ 뻔하다가 | «чуть не и…» (сложн.) | 놓칠 뻔하다가 구했어요. — Чуть не потерял, но успел спасти. |
| (으)ㄴ들 | «даже если бы…» | 아무리 좋은들 무슨 소용이에요. — Даже если бы было хорошо, какой толк. |
| 어/아지다 + 고 싶다 | «хочется становиться» | 긍정적으로 생각해지고 싶다. — Хочется научиться думать позитивно. |
| 어/아 보니(까) | «после того как попробовал, оказалось» | 해 보니까 쉬웠어요. — Как попробовал, оказалось легко. |
| 는 셈 치다 | «считать, что… (условно)» | 늦은 셈 치고 쉬자. — Будем считать, что опоздали, и отдохнём. |
| (으)ㄴ/는 게 아니라 | «не…, а…» | 화난 게 아니라 당황한 거예요. — Не злой, а растерялся. |
| (으)ㅁ/음으로 인해 | формализованная причина | 지진으로 인해 항공편이 취소됐다. — Из-за землетрясения рейс отменили. |

## Специальные темы TOPIK II

### Пассив (피동) и каузатив (사동) — часто в заданиях듣기/읽기

| Тип | Пример полной пары |
|-----|--------------------|
| Пассив -이/히/리/기 | 보다 → 보이다 (виднеться); 읽다 → 읽히다 (быть прочитан) |
| Пассив 지다 | 준비되다 — быть подготовленным |
| Каузатив -이/히/리/기/-우/구/추 | 먹다 → 먹이다 (кормить); 살다 → 살리다 (спасать/оживить) |
| Каузатив 게 하다 | 일하게 하다 — заставить/позволить работать |
| Каузатив 시키다 | 공부시키다 — заставить учиться (учебн.) |

### Чужая речь (간접 화법) — рабочий инструмент 3–6급

| Высказывание | Преобразование в косв. речь |
|--------------|------------------------------|
| 명사 + 이다 | (이)라고 하다 |
| 동사 -다/고 시키다 | 고 하다 (велено) |
| 조동사 -겠- | 겠다고 하다 |
| 의문사 의문문 | (는)지 물어보다 |
| 부탁 | 달라고 하다 |
| 명령 | (으)라고 하다 |

## Частые ловушки в экзаменационных вариантах

1. **-는데 vs -지만:** -는데 даёт фон/контекст, -지만 жёсткое «но».
2. **-도록 vs -게:** -도록 «так, чтобы/пока», -게 «результат-состояние».
3. **-다가 vs -면서:** 다가 — смена действия, 면서 — параллельность.
4. **-았/었던 vs -던:** -았던 отсылает к завершённому прошлому, -던 к «как было».
5. **-ㄴ 채로 vs -는 와중에:** состояние сохранности vs «в разгар».
6. **되다/하다 в пассиве:** -된다 (произошло само) vs -한다 (делают).
