# Лексика TOPIK: сколько слов нужно по уровням

## Объёмы по диапазонам (общепринятые ориентиры)

| Уровень | TOPIK I / II | Активный запас | Пассивный (узнавание) | ~4–5 тыс. из них |
|---------|--------------|----------------|------------------------|------------------|
| 1급 | TOPIK I | ~800 | ~1000 | базовая бытовая лексика |
| 2급 | TOPIK I | ~1500 | ~1800 | повседневное + простые социальные темы |
| 3급 | TOPIK II | ~2000–2500 | ~3000 | быт + работа/учёба + СМИ упрощённо |
| 4급 | TOPIK II | ~3000–3500 | ~4000 | новости, рассуждения, деловая переписка |
| 5급 | TOPIK II | ~4000–4500 | ~5000 | публицистика, лекции, дискуссии |
| 6급 | TOPIK II | ~5000–6000+ | ~6000+ | академика, профессиональная сфера |

Цифры условные: официальных списков «слов 1급» нет, но частотные списки и учебники сходятся примерно на этих порядках.

## Распределение лексики по частям речи

| Часть речи | Доля в активном списке | Примеры |
|------------|------------------------|---------|
| Существительные | ~50% | жизнь, работа, учёба, семья, еда, транспорт, время |
| Глаголы | ~18–20% | действие, движение, речь, восприятие |
| Прилагательные | ~12–15% | качество, эмоции, оценка |
| Наречия / наречные выражения | ~8–10% | частота (항상, 보통), время (아침, 내일), модальность (아마, 아마도) |
| Функциональные (частицы, связки, служебные) | ~8–10% | 은/는, 에, 에서, -지 않다, -고 있다 |

## По секциям экзамена

### 1–2급 (базис)

- Приветствия, этикет, время/числа, семья, еда, дом, транспорт, одежда, погода.
- Глагол движения (가다, 오다), восприятия (보다, 듣다), бытовые (먹다, 자다, 일하다).
- Числительные обеих систем + счётные слова (개, 명, 시, 살, 분).
- Местоимения, указательные, вопросительные слова.
- **База для 듣기:** вывески, объявления, инструкции на 1–2 фразы.

### 3–4급 (средний)

- Деловая лексика: 회사, 직원, 계약, 프로젝트, 회의, 업무.
- Образование: 강의, 리포트, 전공, 시험, 등록금.
- СМИ: 뉴스, 기자, 보도, 조사, 설문, 증가/감소, 원인/결과.
- Рассуждение: 의견, 주장, 근거, 반대, 찬성, 결론.
- 한자어 (китайские корни) начинают доминировать: 예약, 결정, 발견, 확실.
- **База для 쓰기 53/54:** синонимы и связки: 또한, 그래서, 그런데, 반면, 끝으로.

### 5–6급 (продвинутый)

- Абстрактная и академическая: 현상, 이론, 가설, 분석, 연구, 결과, 영향.
- Идиомы и фразеология: 눈이 높다, 손이 크다, 발이 넓다 (см. база, раздел идиом).
- Формальный письменный стиль: -ㄴ다고 볼 수 있다, -(으)로 미루어 보아, -기에 앞서.
- Профессиональная терминология по вашей сфере + термины экономики/политики (경제, 정치, 사회, 환경).
- Социальные клише: 협의, 합의, 조정, 규정, 위원회.

## Что учить в первую очередь (восходящая приоритетность)

1. **Частотные 1000 слов** — покроют >80% бытовых текстов.
2. **Слова 1–2급 из пробников спрятанных** — каждый встреченный в пробнике глосс → карточка.
3. **Синонимы и антонимы** — заданий в стилистике TOPIK много: «выберите близкое по значению».
4. **연어/коллокации** — 아니 «похож не…»; 여행을 다니다; 시험을 치다; 약속을 잡다.
5. **한자어 (слова с китайскими корнями)** — знать корень = знать ±10 слов.

## Методы набора лексики по уровням

| Уровень | Метод |
|---------|-------|
| 1–2급 | карточки Anki 10–15 слов/день; тематические списки; обязателен хангыль |
| 3급 | читать заголовки новостей; выписывать связки; группировка по темам |
| 4급 | long-form тексты (эссе) + «пересказ» на корейском; синонимические ряды |
| 5–6급 | корни 한자어, антонимы к слову, идиомы; пересказ статьи вслух |
| любо | правильная колода: слово → предложение → перевод; встретил в пробнике → карточка |

## Калькулятор дней

- 1급 (800 слов): 800 ÷ 12 слов/день ≈ 67 дней + повторы (Anki автоматически).
- 2급 (1500): ещё ~700 слов ≈ 60 дней.
- 3급 (~2000–2500): плюс ~1000 слов ≈ 3–4 месяца при поддержке чтения.
- 4급 (~3000–3500): ещё ~1000 слов ≈ 3 месяца с текстами.
- 5–6급 (~5000+): ещё ~1500–2000 слов + идиомы и письменные клише ≈ 4–6 месяцев.

Итог: ~1.5–2 года систематичных 30–45 мин/день для уверенного 5–6급 по лексике. Темп Anki — главный рычаг.
