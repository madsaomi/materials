# Стратегия дня экзамена TOPIK

## Неделя до экзамена

| День | Что делать |
|------|-----------|
| −7 | Полный пробник под тайминг. Разбор ошибок, список из 10 слабых конструкций. |
| −6…−3 | Повтор грамматики из списка; лёгкие наборы слов; письмо 51–53 по шаблонам. |
| −2 | НЕ решать новых пробников. Только Anki-повторы и чтение конспекта. |
| −1 | Собрать сумку, проверить документы, лечь не позже 23:00. Без кофеина после 17:00. |
| День экзамена | Расписание по времени + прибытие за 60 мин до регистрации. |

## Документы и вещи (утром перепроверить)

- [ ] 수험표 (печать посадочного места) — распечатать
- [ ] Паспорт или документ из регистрации (주민등록증 для граждан РК / паспорт иностранца)
- [ ] Карандаш (연필) и ластик (компьютерный лист ответов — контур, если есть правила)
- [ ] Чёрная/синяя шариковая ручка для 쓰기
- [ ] Бутылка воды без этикетки (в некоторых центрах нельзя — уточнить)
- [ ] Часы механические (электронике запрещено — смарт-часы не брать!)
- [ ] Лёгкий перекус для большого перерыва

## Запрещено на экзамене

- Телефоны, смарт-часы, плееры, любые электронные устройства (даже выключенные — изымаются).
- Свои шпаргалки, заметки, бумага — всё на столе только из комплекта.
- Выход без разрешения 감독관 (наблюдателя).
- Общение с другими участниками.

## Стратегия по секциям

### 듣기 (аудирование)
1. В перерыве между заданиями **читайте варианты следующего** — даёт контекст для прослушивания.
2. На коротких диалогах определяйте **намерение** (просьба/отказ/совет), а не только факты.
3. Не пишите на черновике — темп высокий; отмечайте прямо в сборнике.
4. После 30-й (TOPIK II) части — переходы длиннее, дышите, слушайте первую интонацию.
5. Если пропустили ответ — не паникуйте, ставьте предположение и идём дальше.

### 읽기 (чтение)
1. Первые 30 вопросов — быстро (лексика/грамматика проста, ~40 сек).
2. Длинные тексты 43–50: сначала прочитайте вопросы, потом текст.
3. Сино-производные слова (한자어) — обращайте внимание на корень.
4. Для заданий «порядок предложений» (13–22): ищите связки и логику повествования.
5. Оставьте 10 мин в конце: перепроверить нерешительные ответы.

### 쓰기 (письмо)
1. Тайминг: 51–52 (10 мин) → 53 (15 мин) → 54 (25 мин) → проверка (5–10 мин).
2. 51–52: форма точная: окончание, врем. форма, частица. Проверьте дважды.
3. 53 (график): шаблон «проценты + сравнение + причина» — пишите цифры правильно.
4. 54: структура введения — 2 аргумента — контраргумент — вывод. Не отклоняйтесь от темы.
5. Пишите разборчиво: неаккуратный почерк теряет баллы «норм письменной речи».

## Чек-лист дня

- [ ] Прибыли за 60 мин до регистрации
- [ ] Выспались (7–8 ч) — сон важнее последнего прогона
- [ ] Утро: лёгкий завтрак, вода, зарядка
- [ ] Проверили допуск (수험표 + паспорт)
- [ ] Выключили телефон полностью (не «беззвучно»)
- [ ] Первый час: соберитесь, читайте вопросы внимательно
- [ ] Середина: правильный темп, не застревайте >2 мин на вопросе
- [ ] Последние 10 мин каждый части: проверка переноса ответов на бланк (OMR)
- [ ] После экзамена: зафиксируйте ощущения — пригодится для следующей попытки

## Заполнение бланка ответов

- Одинаковые пустые квадраты топнуть ровно — считывание автоматическое.
- Стирать ластиком чисто: грязный лист = ошибка распознавания.
- Отметки только в своей строке (questions grid); не путайте номер вопроса и номер ответа.

## 15 частых ошибок подготовки

1. **Начинают без самооценки.** Нужен пробник «вслепую» в первую неделю → точный фокус.
2. **Учат слова без предложений.** Слово из карточки «хангуг-хангуг» живёт только в контексте.
3. **Пренебрегают письмом (у кого TOPIK II).** Многие годами делают только 듣기/읽기 → провал 쓰기.
4. **Не решают полные пробники.** Деление секций «как получится» не учит таймингу → паника на экзамене.
5. **Игнорируют бланк ответов.** На первом же экзамене теряют баллы из-за кривого переноса.
6. **Зазубривают «модные» конструкции, но путают синонимику.** TOPIK любит различать близкие формы: -는데/지만, -도록/게.
7. **Забывают про 듣기 дома.** «Понимаю текст, но не речь» — нужны аудио ежедневно.
8. **Переводят всё в голове.** TOPIK II не даёт времени — надо понимать «корейски».
9. **Тратит время на редкую лексику 6급, не имея базы.** Сначала 800/1500 слов, потом экзотика.
10. **Не разбирают ошибки.** 10 пробников без разбора = 0 прогресса. Ошибка → карточка.
11. **Пишут сочинения без таймера.** 54 на 40 минут ≠ 54 на час — тренируйте темп.
12. **Сидят ночью последние 3 дня.** Выгорание и бессонница убивают результат больше, чем 1 час повтора.
13. **Не проверяют правила актуального года.** Формат меняется (말하기-пилот, сроки подачи) — смотрите topik.go.kr.
14. **Игнорируют почерк.** В 쓰기 51–52 корявые 글자 - балл теряется автоматически.
15. **Сдаются после первого провала.** Средний путь к 4급 — 2–3 попытки; анализ и повторная сдача = норма.

## Чего НЕ делать в день экзамена

- Не учить новое утром экзамена (только указатели/списки).
- Не есть непривычную еду.
- Не обсуждать ответы в перерыве — сбивает фокус.
- Не брать запрещённые устройства «на всякий случай» — аннулирование результата.
