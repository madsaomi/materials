# Грамматика TOPIK I (1–2급) — конструкции с примерами

> Формула чтения: `конструкция | значение | пример (перевод)`.
> Все формы даны в стандартной письменной нотации; для разговорной речи упрощения не показаны.

## 1급 — базовый уровень

### Частицы (падежи)

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 은/는 | тема, контраст | 저는 학생이에요. — Я — студент. |
| 이/가 | субъект (новое/фокус) | 친구가 왔어요. — Пришёл друг. |
| 을/를 | объект действия | 밥을 먹어요. — Ем рис. |
| 에 | место/время «в/на» | 학교에 가요. — Иду в школу. |
| 에서 | место действия «в» | 집에서 텔레비전을 봐요. — Смотрю ТВ дома. |
| 에게 / 한테 | дательный «кому» | 친구에게 편지를 써요. — Пишу письмо другу. |
| 의 | родительный | 나의 책 — моя книга. |
| 도 | «тоже» | 저도 학생이에요. — Я тоже студент. |
| 만 | «только» | 물만 마셔요. — Пью только воду. |
| 하고 / 와-과 | «с», сочинение | 친구하고 영화를 봤어요. — Посмотрел фильм с другом. |
| 부터 … 까지 | «от … до» | 아침부터 저녁까지 일해요. — Работаю с утра до вечера. |
| 에서 … 까지 | «из … в» | 부산에서 서울까지 — из Пусана в Сеул. |
| 쯤 | «около, примерно» | 두 시쯤 만나요. — Встретимся около двух. |

### Окончания и связки

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 습니다/ㅂ니다 | формально-вежливое окончание | 학교에 갑니다. — Иду в школу. |
| 아/어요 | вежливо-разговорное окончание | 편지를 써요. — Пишу письмо. |
| 았/었어요 | прошедшее (разг.) | 어제 영화를 봤어요. — Вчера смотрел фильм. |
| 겠다 | намерение / предположение | 내일 가겠어요. — Завтра пойду. |
| ㄹ 거예요 | будущее (с высокой уверенностью) | 주말에 여행할 거예요. — В выходные поеду в путешествие. |
| 고 있다 | длительное действие | 지금 공부하고 있어요. — Сейчас учусь. |
| 고 (connecting) | «и», порядок действий | 밥을 먹고 잤어요. — Поел и уснул. |
| 고 싶다 | «хочу» | 한국에 가고 싶어요. — Хочу поехать в Корею. |
| 아/어 주다 | делать для кого-то | 물을 좀 주세요. — Дайте воды, пожалуйста. |
| 아/어 보다 | «попробовать» | 김치를 먹어 봤어요. — Попробовал кимчи. |
| 지만 | «но» | 비싸지만 맛있어요. — Дорого, но вкусно. |
| 아/어서 | причина/последовательность «и поэтому» | 배가 아파서 못 갔어요. — Живот болел, поэтому не пошёл. |
| 도 … 도 | «и … и» | 또 밥도 빵도 먹어요. — Ем и рис, и хлеб. |
| 아/어도 되다 | «можно» | 여기 앉아도 돼요? — Можно здесь сесть? |
| 면 안 되다 | «нельзя» | 여기서 담배를 피우면 안 돼요. — Здесь курить нельзя. |
| 아/어야 하다 | «нужно, должен» | 내일 일찍 일어나야 해요. — Завтра надо встать рано. |
| 아/어지다 (прил.) | «становиться» | 날씨가 추워졌어요. — Погода стала холодной. |
| 은채로 / ㄴ 채로 | «оставаясь в состоянии» (ранний ввод) | 신발을 신은 채로 들어왔어요. — Вошёл, не снимая обуви. |
| 에게서 | «у кого-то» (источник) | 선생님에게서 책을 받았어요. — Получил книгу от учителя. |

### Связки и вспомогательные конструкции

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 이다 | связка «быть» | 저는 회사원입니다. — Я офисный работник. |
| 아니다 | «не быть» | 그것은 책이 아니에요. — Это не книга. |
| 있다 | «иметь, есть, находиться» | 시간이 있어요. — У меня есть время. |
| 없다 | «нет, не иметь» | 돈이 없어요. — Денег нет. |
| 은/는 … 입니다 | именное сказуемое (форм.) | 이것은 사과입니다. — Это яблоко. |
| ㄴ 것 같다 (вводно) | «кажется» | 비가 올 것 같아요. — Кажется, пойдёт дождь. |
| 수 있다 (базово) | «мочь, уметь» | 한국어를 조금 할 수 있어요. — Могу немного говорить по-корейски. |

## 2급 — средний уровень (базовый TOPIK I)

### Связки придаточных

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 기 때문에 | «потому что» | 비가 오기 때문에 못 가요. — Не могу идти, потому что идёт дождь. |
| 는데 | фон/контраст/«кстати» | 날씨가 좋은데 뭐 할까요? — Погода хорошая, что будем делать? |
| 느데 (после прил.) | «хоть/при том что» | 싼데 좋아요. — Хоть и дёшево, но хорошо. |
| (으)면 | условие «если» | 비가 오면 집에 있어요. — Если пойдёт дождь, буду дома. |
| 되다 (с -면) | «если … , то подойдёт» | 이 길로 가면 됩니다. — Если пойдёте по этой дороге, так и будет правильно. |
| (으)면서 | «делая одновременно» | 음악을 들으면서 달려요. — Бегаю, слушая музыку. |
| (으)ㄴ 후에 | «после того как» | 공부한 후에 쉬었어요. — Отдохнул после учёбы. |
| 기 전에 | «до того как» | 자기 전에 이를 닦아요. — Чищу зубы перед сном. |
| (으)ㄴ/도록 | «так, чтобы / пока» (уровень 2+ вариант) | 늦지 않도록 일찍 나가요. — Выхожу рано, чтобы не опоздать. |
| (으)ㄴ/는 동안 | «в течение, пока» | 수업하는 동안 조용히 하세요. — Будьте тише во время урока. |

### Модальные и волевые

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)ㄹ 수 있다 | «мочь» | 한글로 읽을 수 있어요. — Могу читать на хангыле. |
| (으)ㄹ 수 없다 | «не мочь» | 이해할 수 없어요. — Не могу понять. |
| (으)ㄹ 줄 알다 | «уметь» | 수영을 할 줄 알아요. — Умею плавать. |
| (으)ㄹ 줄 모르다 | «не уметь» | 노래를 부를 줄 몰라요. — Не умею петь. |
| 아/어야 되다 | «нужно» (более разг., чем -아야 하다) | 표를 예약해야 돼요. — Нужно забронировать билет. |
| 아/어도 괜찮다 | «не страшно / не против» | 여기 앉아도 괜찮아요. — Здесь сесть можно (не помешает). |

### Дополнительные стандартные конструкции 2급

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)려고 하다 | «намереваться» | 시험을 보려고 해요. — Намерен сдавать экзамен. |
| (으)ㄹ게요 | «(я) сделаю» (обещание) | 제가 먼저 갈게요. — Я пойду первый. |
| (으)ㄹ까요? | «сделать ли? / как насчёт?» | 같이 영화 볼까요? — Сходим вместе в кино? |
| (으)ㄴ 적이 있다 | «был опыт» | 한국에 가 본 적이 있어요. — Бывал в Корее. |
| (으)ㄴ 적이 없다 | «нет опыта» | 스키를 타 본 적이 없어요. — Никогда не катался на лыжах. |
| 아/어 있다 | «находиться в состоянии» | 창문이 열려 있어요. — Окно открыто. |
| 기로 하다 | «решить / договориться» | 다음 주에 만나기로 했어요. — Договорились встретиться на следующей неделе. |
| (으)ㄴ/는 것 같다 | «похоже, кажется» | 피곤한 것 같아요. — Похоже, вы устали. |
| (으)ㄴ/는 모양이다 | «похоже (по виду)» | 비가 온 모양이에요. — Похоже, шёл дождь. |
| (으)ㄴ데요 | вежливый контекст/междометие | 지금 바쁜데요. — Я сейчас занят (вот как). |
| (으)ㄹ 텐데 | «должно быть, что...» (вероятность+фон) | 바쁠 텐데 전화했어요. — Позвонил, хоть ты наверняка занят. |
| 지 않다 | длинное отрицание | 가지 않아요. — Не иду. |
| (으)ㄴ 다음에 | «после того как» | 밥을 먹은 다음에 운동해요. — После еды занимаюсь спортом. |
| 자주/보통/항상 | наречия частотности | 저는 보통 집에서 저녁을 먹어요. — Обычно ужинаю дома. |
| 아/어서 어때요? | «как насчёт сделать?» | 같이 밥 먹어서 어때요? — Как насчёт поесть вместе? |
| (으)ㄴ/는 게 좋다 | «лучше сделать» | 차라리 쉬는 게 좋아요. — Лучше всё же отдохнуть. |

## Мини-практика (TOPIK I)

1. Вставьте: ____ 꽃이 있어요. (тут/там) — 여기에 꽃이 있어요.
2. 번역: «Я умею готовить кимчи.» — 김치를 만들 수 있어요.
3. Выберите: 비가 오___ 못 갔어요. (가지-는?-서) — 비가 와서 못 갔어요.
4. Переведите вопрос: 커피를 마실까요? — Выпьем кофе?
5. Порядок: ___ ___ 갔어요. (친구와 / 영화를) — 친구와 영화를 / 갔어요.

## Памятка по TOPIK I

- В TOPIK I проверяются **только 듣기 и 읽기**, но грамматика 2급 отлично готовит основу для письма TOPIK II.
- Высокочастотные 1급 частицы: 은/는, 이/가, 을/를, 에, 에서 — на них приходится ~40% тестовых пунктов.
- Вопрос «вставьте конструкцию» часто проверяет разницу: -는데 vs -지만, -면서 vs -고, -니까 vs -서.
