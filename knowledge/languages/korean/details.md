# Корейский — Микро-детали

## 1. Произносительные тонкости

### 1.1 Ассимиляция — полные правила

**ㄴ → ㄹ после ㄹ:**
- 설날 (соллаль) — Новый год
- 진리 (질리) — истина (редко)

**ㄴ → ㅁ после ㅁ, ㅂ:**
- 감니다 (камнида) от ㅂ + ㄴ
- 합니다 (хамнида)

**ㄱ → ㅇ перед ㄴ/ㅁ:**
- 국물 (궁물) — бульон
- 먹는다 (멍는다) — ест

**ㅂ → ㅁ перед ㄴ:**
- 입니다 (임니다) — является
- 없습니다 (엄씀니다) — нет

**Палатализация (ㄷ + ㅣ → ㅈ):**
- 굳이 (구지) — упрямо
- 같이 (가치) — вместе
- 밭이 (바치) — поле

**ㅎ выпадение:**
- 좋다 (조타) → 좋은 (조은) — хороший
- 많다 (만타) → 많은 (마는) — много

**ㄹ выпадение:**
- 들다 → 드세요 — кушайте
- 알다 → 압니다 — знаю

### 1.2 Твёрдые согласные

ㄲ, ㄸ, ㅃ, ㅆ, ㅉ — произносятся с напряжением голосовых связок.
Разница между 평음 и 경음:

| 평음 (мягкий) | 경음 (твёрдый) |
|---------------|----------------|
| 가구 (кагу) — мебель | 까꾸 (ккакку) — ? |
| 달 (таль) — луна | 딸 (тталь) — дочь |
| 불 (пуль) — огонь | 뿔 (ппуль) — рог |
| 살 (саль) — мясо/возраст | 쌀 (ссаль) — рис |
| 자다 (чада) — спать | 짜다 (ччада) — солёный |

### 1.3 Придыхательные

ㅋ, ㅌ, ㅍ, ㅊ — с сильным выдохом:
- 가다 (када) — идти vs 카다 (кхада) — не слово
- 다리 (тари) — нога vs 타리 (тхари) — ? vs 따리 (ттари) — ?
- 바다 (пада) — море vs 파다 (пхада) — копать

### 1.4 Связывание (연음)

Конечная согласная → к следующей гласной:
- 한국어 → [한구거] (хан-гу-го)
- 책을 → [채글] (чхэ-гыль)
- 같이 → [가치] (ка-чхи)

### 1.5 Интонационные паттерны

| Тип | Паттерн | Пример |
|-----|---------|--------|
| Вопрос да/нет | ↗ | 밥 먹었어? ↗ |
| WH-вопрос | ↘ | 뭐 해? ↘ |
| Удивление | ↗↘ | 진짜? ↗↘ |
| Команда | ровно | 빨리 와! → |
| Вежливое приветствие | ↗↘ (плавно) | 안녕하세요~ |

## 2. Грамматические микро-детали

### 2.1 은/는 vs 이/가 — исчерпывающее

| 은/는 — тема, контраст, общее | 이/가 — субъект, новое, специфика |
|-------------------------------|-----------------------------------|
| 저는 학생입니다 (говорим обо мне) | 제가 하겠습니다 (ИМЕННО я сделаю) |
| 오늘은 바빠요 (а в другие дни — нет) | 오늘이 좋아요 (именно сегодня) |
| 인생은 아름답다 (общий факт) | 누가 왔어요? (кто?) |
| 커피는 안 마셔요 (а чай пью) | 민수 씨가 왔어요 (Минсу пришёл — новость) |

### 2.2 에 vs 에서 — движение vs действие

| 에 — местонахождение / направление | 에서 — место действия / отправления |
|------------------------------------|-------------------------------------|
| 학교에 있다 (быть в школе) | 학교에서 공부하다 (учиться в школе) |
| 집에 가다 (идти домой) | 집에서 나가다 (выходить из дома) |
| 의자에 앉다 (сесть на стул) | 서울에서 오다 (приехать из Сеула) |

### 2.3 가다 vs 오다 — выбор точки отсчёта

| 가다 (идти туда) | 오다 (приходить сюда) |
|------------------|-----------------------|
| Speaker уходит от точки | Speaker в точке |
| 지금 집에 가요 (сейчас иду домой) | 지금 집에 와요 (сейчас прихожу домой — я дома или рядом) |
| 내일 한국에 가요 (завтра еду в Корею) | 내일 한국에 와요 (завтра приезжаю в Корею — я в Корее) |

### 2.4 아/어서 vs (으)니까 — причина

| 아/어서 — объективная причина, не с императивом | (으)니까 — субъективная, с императивом/предложением |
|------------------------------------------------|----------------------------------------------------|
| 비가 와서 집에 있어요 (идёт дождь, поэтому дома) | 비가 오니까 집에 있자 (дождь идёт, давай останемся) |
| 배가 아파서 병원에 갔어요 (живот болит → больница) | 늦었으니까 빨리 가자 (опоздали, пошли быстрее) |

### 2.5 고 vs 서 — последовательность

| 고 — простое перечисление (и...) | 서 — последовательность/способ (затем) |
|----------------------------------|---------------------------------------|
| 밥 먹고 TV 봤어요 (ел и смотрел ТВ — порядок неважен) | 밥 먹으러 식당에 가요 (иду в ресторан есть) |
| 학교에 가고 친구를 만났어요 (пошёл в школу и встретил друга) | 일찍 일어나서 운동해요 (рано встаю и делаю зарядку) |

### 2.6 지만 vs 는데 — контраст vs фон

| 지만 — прямой контраст (но) | 는데 — фон, контраст, мягкое "но" |
|----------------------------|-----------------------------------|
| 비싸지만 살 거예요 (дорого, но куплю) | 비싼데 살 거예요? (дороговато... будешь брать?) |
| 작지만 좋아요 (маленький, но хороший) | 어제 갔는데 없었어요 (вчера пошёл, а его не было) |

### 2.7 아/어 있다 vs 고 있다

| 아/어 있다 — состояние (результат) | 고 있다 — процесс (действие) |
|-----------------------------------|-----------------------------|
| 앉아 있다 (сидит — уже сел и сидит) | 앉고 있다 (садится прямо сейчас) |
| 문이 열려 있다 (дверь открыта) | 문을 열고 있다 (открывает дверь) |
| 서 있다 (стоит) | 서고 있다 (встаёт) |
| 누워 있다 (лежит) | 눕고 있다 (ложится) |

## 3. Глагольные микро-детали

### 3.1 Полный список неправильных глаголов

** ㄷ-неправильные (ㄷ → ㄹ перед гласной):**
| Глагол | Значение | Основа | Вежливая |
|--------|----------|--------|----------|
| 듣다 | слушать | 들 | 들어요 |
| 걷다 | ходить | 걸 | 걸어요 |
| 묻다 | спрашивать | 물 | 물어요 |
| 싣다 | грузить | 실 | 실어요 |
| 깨닫다 | осознавать | 깨달 | 깨달아요 |

**Исключения (правильные):**
- 받다 (получать) → 받아요 (не 발아요)
- 닫다 (закрывать) → 닫아요
- 믿다 (верить) → 믿어요
- 얻다 (получать) → 얻어요

** ㅂ-неправильные (ㅂ → 우):**
| Глагол | Значение | Основа | Вежливая |
|--------|----------|--------|----------|
| 춥다 | холодно | 추우 | 추워요 |
| 덥다 | жарко | 더우 | 더워요 |
| 쉽다 | легко | 쉬우 | 쉬워요 |
| 어렵다 | трудно | 어려우 | 어려워요 |
| 맵다 | острый | 매우 | 매워요 |
| 돕다 | помогать | 도우 | 도와요 |
| 눕다 | ложиться | 누우 | 누워요 |

**Исключения:**
- 좁다 (узкий) → 좁아요 (правильный)
- 입다 (надевать) → 입어요
- 씹다 (жевать) → 씹어요

** 르-неправильные:**
| Глагол | Значение | Вежливая |
|--------|----------|----------|
| 모르다 | не знать | 몰라요 |
| 빠르다 | быстрый | 빨라요 |
| 부르다 | звать | 불러요 |
| 자르다 | резать | 잘라요 |
| 고르다 | выбирать | 골라요 |
| 다르다 | другой | 달라요 |
| 서두르다 | спешить | 서둘러요 |

** ㅅ-неправильные (ㅅ выпадает):**
| Глагол | Значение | Вежливая |
|--------|----------|----------|
| 낫다 | выздоравливать | 나아요 |
| 긋다 | чертить | 그어요 |
| 잇다 | соединять | 이어요 |
| 붓다 | наливать | 부어요 |

** ㅎ-неправильные (ㅎ выпадает):**
| Прилагательное | Значение | Вежливая |
|----------------|----------|----------|
| 빨갛다 | красный | 빨개요 |
| 파랗다 | синий | 파래요 |
| 노랗다 | жёлтый | 노래요 |
| 하얗다 | белый | 하얘요 |
| 까맣다 | чёрный | 까매요 |
| 그렇다 | такой | 그래요 |
| 어떻다 | какой | 어때요 |

** 으-неправильные:**
| Глагол | Значение | Вежливая |
|--------|----------|----------|
| 쓰다 | писать/использовать | 써요 |
| 크다 | большой | 커요 |
| 기쁘다 | радостный | 기뻐요 |
| 예쁘다 | красивый | 예뻐요 |
| 아프다 | больно | 아파요 |
| 고프다 | голоден | 고파요 |
| 바쁘다 | занят | 바빠요 |
| 슬프다 | грустен | 슬퍼요 |

### 3.2 Есть (먹다) — полный спектр вежливости

| Уровень | Форма | Контекст |
|---------|-------|----------|
| Официальный | 먹습니다 | Новости, доклады |
| Вежливый | 먹어요 | Повседневный вежливый |
| Полуформальный | 먹게 | Между равными (стар.) |
| Простой (друзья) | 먹어 | Банмаль |
| Сниженный | 먹는다 | Литературный |
| Почтительный (к старшему) | 드세요 — 드시다 | К старшим |
| Скромный (о себе) | 먹습니다 (не заменяет) | — |
| Офиц-уважит. | 잡수시다 / 진지 드시다 | Очень уважительно |
| Приглашение | 드십시오 | Почтительное приглашение |

## 4. Числительные — микро-детали

### 4.1 Когда что использовать

| Ситуация | Система | Пример |
|----------|---------|--------|
| Возраст | Исконная | 25살 (스무다섯 살) |
| Часы | Исконная | 3시 (세 시) |
| Минуты | Китайская | 15분 (십오 분) |
| Счёт предметов | Исконная | 3개 (세 개) |
| Деньги | Китайская | 5,000원 (오천 원) |
| Номер телефона | Китайская | 010-1234 |
| Дата | Китайская | 2024년 3월 |
| Этаж | Исконная + китайская | 3층 (삼 층) |
| Порядок | Китайская | 첫째 (первый, иск.) |
| Математика | Китайская | 3+5=8 |

### 4.2 Исключения при счёте

| 1 | 2 | 3 | 4 | 20 |
|---|---|---|---|---|
| 하나 (хана) → 한 (хан) | 둘 (туль) → 두 (ту) | 셋 (сет) → 세 (се) | 넷 (нет) → 네 (не) | 스물 → 스무 |

- 한 개 (не 하나 개)
- 두 명 (не 둘 명)
- 세 시 (не 셋 시)
- 네 명 (не 넷 명)
- 스무 살 (не 스물 살)

### 4.3 Несчастливые числа

- 4 (사) — смерть, избегают в лифтах (F → 3, 4 → F)
- 14 (십사) — звучит как 십사 (十死) — десять смертей
- 44 (사십사) — очень плохо
- 18 (십팔) — сленг для 욕 (十八 = shit)
- 1004 (천사) — 천사 = ангел (хорошее)

## 6. Часто путаемые слова

| Слово 1 | Значение | Слово 2 | Значение |
|---------|----------|---------|----------|
| 아버지 | отец | 어버지 | не слово |
| 형 (муж.) | ст. брат | 오빠 (жен.) | ст. брат |
| 누나 (муж.) | ст. сестра | 언니 (жен.) | ст. сестра |
| 가르치다 | учить | 가리키다 | указывать |
| 그러면 | тогда (если) | 그런데 | но, однако |
| 예쁘다 | красивый | 밉다 | противный |
| 맛있다 | вкусно | 맛없다 | невкусно |
| 이상하다 | странный | 이성적 | рациональный |
| 주문하다 | заказывать | 계약하다 | заключать контракт |

## 7. Сленг и разговорные сокращения

| Полная | Сленг | Значение |
|--------|-------|----------|
| ~는 거예요 | ~는 거야 | простое объяснение |
| 무슨 | 뭔 | какой (разг.) |
| 무엇 | 뭐 | что |
| 아니요 | 아니 | нет |
| 저는 | 전 | я |
| 그것 | 그거 | то, это |
| 이것 | 이거 | это |
| 무엇을 | 뭘 | что (объект) |
| 나는 | 난 | я |
| 그렇지 | 그치 | правда ведь |
| 싫어요 | 시러요 | не хочу (интернет) |
| 감사합니다 | 감사 / ㄳ | спасибо (сокращение) |
| 죄송합니다 | 죄송 / ㅈㅅ | извините (сокращение) |
