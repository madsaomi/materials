# Корейский язык — Полный конспект

## Введение

Корейский язык (한국어, хангуго / 조선말, чосонмаль) — язык корейской ветви алтайской языковой семьи. Около 80 миллионов носителей. Государственный язык Республики Корея и КНДР.

**Ключевые особенности:**
- Собственная фонетическая письменность хангыль (한글)
- Порядок слов SOV
- Развитая система вежливости (7 уровней)
- Агглютинативный строй (частицы + окончания)

## 1. Хангыль (한글) — корейский алфавит

Создан в XV веке королём Седжоном Великим. Научно обоснованная система: форма букв моделирует положение языка и губ.

### 1.3 Слоговая структура

Слоги записываются блоками: C + V (+ C)

Примеры:
- 한 (хан) = ㅎ + ㅏ + ㄴ
- 글 (кыль) = ㄱ + ㅡ + ㄹ
- 한국 (хангук) = 한 + 국
- 언어 (оно) = 언 + 어

### 1.4 Правила произношения

**Ассимиляция согласных:**
- ㄱ + ㄴ → ㅇ + ㄴ: 국물 → 궁물 (кунмуль)
- ㅂ + ㄴ → ㅁ + ㄴ: 합니다 → 함니다 (хамнида)
- ㄹ + ㄴ → ㄹ + ㄹ: 설날 → 설랄 (соллаль)
- ㄷ + ㅎ → ㅌ: 닫히다 → 다티다 (татхида → татхида → тачхида)

**Озвончение начальных согласных:**
- ㄱ → [ɡ] между гласными
- ㄷ → [d] между гласными
- ㅂ → [b] между гласными
- ㅈ → [dʑ] между гласными

## 2. Грамматика

### 2.1 Структура предложения (SOV)

```
저는 사과를 먹습니다.
Чонын сагуарыль моксымнида.
Я яблоко ем.
```

### 2.2 Частицы (조사)

**Именительный падеж (кто/что):**
- 이 после согласной: 책이 (чхэги)
- 가 после гласной: 사과가 (сагвага)
- 께서 — уважительная

**Винительный падеж (объект):**
- 을 после согласной: 책을 (чхэгыль)
- 를 после гласной: 사과를 (сагварыль)

**Родительный падеж (принадлежность):**
- 의 (е/ый): 나의 책 (нае чхэк) — моя книга

**Дательный падеж (кому/чему):**
- 에게 (люди): 친구에게 (чхингуеге)
- 한테 (разг.): 친구한테
- 께 (уваж.): 선생님께
- 에 (место/время): 학교에 (хаккёе)

**Творительный падеж (чем/кем):**
- 로 после гласной: 버스로 (посыро) — автобусом
- 으로 после согласной: 연필으로 (ёнпирыро) — карандашом

**Местный падеж (где):**
- 에서 — в/на (действие): 학교에서 공부해요

**Совместный (с кем):**
- 와 после гласной: 친구와
- 과 после согласной: 친구과

**Тема/фокус (маркеры темы):**
- 은 после согласной: 나는 (нанын)
- 는 после гласной: 저는 (чонын)

### 2.3 Спряжение глаголов

Корейские глаголы делятся на правильные и неправильные (особые основы).

**Словарная форма:** глагол + 다 (та)
- 먹다 (мокта) — есть
- 가다 (када) — идти
- 보다 (пода) — смотреть

**Основа глагола:** убрать 다
- 먹 (мок)
- 가 (ка)
- 보 (по)

**Настоящее время (формальный стиль):**

| Тип | Суффикс | Пример |
|-----|---------|--------|
| ㄹ-основа | ㅂ니다 | 갑니다 (камнида) |
| гласная | ㅂ니다 | 봅니다 (помнида) |
| согласная | 습니다 | 먹습니다 (моксымнида) |

**Настоящее время (неформальный вежливый):**
- Гласная + 아/어 + 요
  - 가 + 아요 → 가요 (каё)
  - 먹 + 어요 → 먹어요 (могоё)
  - 하 + 여요 → 해요 (хэё)

**Прошедшее время:**
- Основа + 았/었 + 다
- 가 + 았다 → 갔다 (катта) — пошёл
- 먹 + 었다 → 먹었다 (моготта) — поел
- 하 + 였다 → 했다 (хэтта) — сделал

**Будущее время:**
- Основа + 겠다
- 가겠다 (кагетта) — пойду
- 먹겠다 (моккетта) — поем

**Непрерывное действие (-고 있다):**
- 먹고 있다 (мокко итта) — ем (сейчас)
- 가고 있다 (каго итта) — иду

**Намерение (-려고 하다 / -ㄹ 것이다):**
- 갈 것이다 (каль косида) — собираюсь пойти
- 먹으려고 한다 (могырёго ханда) — намерен есть

### 2.4 Неправильные глаголы

**1. ㄷ-неправильные (ㄷ → ㄹ перед гласной):**
- 듣다 (дытта) → 들어요 (дыроё) — слушать
- 걷다 (котта) → 걸어요 (короё) — ходить
- 묻다 (мутта) → 물어요 (муроё) — спрашивать

**2. ㅂ-неправильные (ㅂ → 우):**
- 춥다 (чхупта) → 추워요 (чхувоё) — холодно
- 덥다 (топта) → 더워요 (товоё) — жарко
- 쉽다 (свипта) → 쉬워요 (свивоё) — легко

**3. 르-неправильные (르 → ㄹ라/ㄹ러):**
- 모르다 (морыда) → 몰라요 (моллаё) — не знать
- 빠르다 (ппарыда) → 빨라요 (ппаллаё) — быстрый

**4. ㅅ-неправильные (ㅅ выпадает):**
- 낫다 (натта) → 나아요 (нааё) — выздоравливать
- 긋다 (кытта) → 그어요 (кыоё) — чертить

**5. ㅎ-неправильные (ㅎ выпадает):**
- 빨갛다 (ппальгатха) → 빨개요 (ппальгэё) — красный

**6. 으-неправильные (으 выпадает):**
- 쓰다 (ссыда) → 써요 (ссоё) — писать
- 크다 (кхыда) → 커요 (кхоё) — большой

### 2.5 Прилагательные

Корейские прилагательные спрягаются как глаголы.

| Словарная | Основа | Вежливая форма | Значение |
|-----------|--------|----------------|----------|
| 크다 (кхыда) | 크 (кхы) | 커요 (кхоё) | большой |
| 작다 (чакта) | 작 (чак) | 작아요 (чагаё) | маленький |
| 예쁘다 (еппыда) | 예쁘 (еппы) | 예뻐요 (еппоё) | красивый |
| 좋다 (чохта) | 좋 (чох) | 좋아요 (чоаё) | хороший |
| 나쁘다 (наппыда) | 나쁘 (наппы) | 나빠요 (наппаё) | плохой |
| 따뜻하다 (ттаттытхада) | 따뜻하 (ттаттытха) | 따뜻해요 (ттаттытхэё) | тёплый |
| 재미있다 (чэмиитта) | 재미있 (чэмиис) | 재미있어요 (чэмииссоё) | интересный |

**Сравнение:**
- A보다 B가 더 + прилагательное
- 사과보다 바나나가 더 커요 (сагвабода пананага то кхоё) — банан больше, чем яблоко

**Превосходная:**
- 가장 / 제일 + прилагательное
- 이것이 제일 좋아요 (игоси чеиль чоаё) — это самый хороший

### 2.6 Числительные

Две системы: **исконно корейская** (для счёта, возраста) и **китайская** (для дат, денег, времени).

**Исконно корейские:**

| Число | Слово |
|-------|-------|
| 1 | 하나 (хана) |
| 2 | 둘 (туль) |
| 3 | 셋 (сет) |
| 4 | 넷 (нет) |
| 5 | 다섯 (тасот) |
| 6 | 여섯 (ёсот) |
| 7 | 일곱 (ильгоп) |
| 8 | 여덟 (ёдоль) |
| 9 | 아홉 (ахоп) |
| 10 | 열 (ёль) |

**Счётные слова (с исконными числами):**
- 명 (мён) — люди: 두 명 (ту мён) — 2 человека
- 개 (ке) — предметы: 사과 세 개 (сагва се ке) — 3 яблока
- 잔 (чан) — чашки: 커피 한 잔 (кхопи хан чан) — чашка кофе
- 병 (пён) — бутылки: 맥주 두 병 (мэкчу ту пён) — 2 бутылки пива
- 시 (си) — часы: 두 시 (ту си) — 2 часа
- 살 (саль) — возраст: 스무 살 (сыму саль) — 20 лет

**Числа 11-19 (исконные):**
열 + число: 열하나 (ёльхана) — 11, 열둘 (ёльтуль) — 12...

**Десятки (исконные):**
- 스물 (сымуль) — 20
- 서른 (сорын) — 30
- 마흔 (махын) — 40
- 쉰 (свин) — 50
- 예순 (йесун) — 60
- 일흔 (ильхын) — 70
- 여든 (ёдын) — 80
- 아흔 (ахын) — 90

**Китайские числительные:**

| Число | Слово |
|-------|-------|
| 1 | 일 (иль) |
| 2 | 이 (и) |
| 3 | 삼 (сам) |
| 4 | 사 (са) |
| 5 | 오 (о) |
| 6 | 육 (юк) |
| 7 | 칠 (чхиль) |
| 8 | 팔 (пхаль) |
| 9 | 구 (ку) |
| 10 | 십 (сип) |
| 100 | 백 (пэк) |
| 1000 | 천 (чхон) |
| 10000 | 만 (ман) |

**Даты:** 년 (год) + 월 (месяц) + 일 (день)
- 2024년 3월 15일

**Деньги:** 원 (вон)
- 오천 원 (очхон вон) — 5000 вон
- 만 원 (ман вон) — 10000 вон

### 2.7 Уровни вежливости

| Уровень | Суффикс | Пример | Использование |
|---------|---------|--------|---------------|
| Хасёчхе (하소서체) | -나이다 | - | император, архаично |
| Хапсёчхе (합쇼체) | -ㅂ니다/습니다 | 갑니다 | официальный, новости |
| Хаойчхе (하오체) | -오 | 가오 | формальный, редко |
| Хэгечхе (하게체) | -게 | 가게 | между равными (уст.) |
| Хэрачхе (해라체) | -다 | 간다 | книги, детям |
| Хэёчхе (해요체) | -아/어요 | 가요 | вежливый разговорный |
| Хэчхе (해체) | -아/어 | 가 | друзья, банмаль |

**Самые используемые в жизни:**
- **해요체 (хэёчхе)** — вежливо-неформальный (повседневный)
- **해체 (хэчхе)** — банмаль (с близкими)
- **합쇼체 (хапсёчхе)** — официально-формальный

### 2.8 Отрицание

**Краткое:**
- 안 + глагол: 안 가요 (ан каё) — не иду
- 못 + глагол (не мочь): 못 가요 (мот каё) — не могу идти

**Долгое:**
- -지 않다: 가지 않아요 (каджи анаё) — не иду
- -지 못하다: 가지 못해요 (каджи мотхэё) — не могу идти

**Отрицание существования:**
- 있다 → 없다: 있어요 → 없어요 — нет

### 2.9 Связка 이다

| Время | Форма | Пример |
|-------|-------|--------|
| Наст. | 이다 / 예요 | 학생이에요 (студент) |
| Прош. | 이었다 / 이었어요 | 학생이었어요 |
| Буд. | 일 것이다 / 일 거예요 | 학생일 거예요 |

**Негативная связка:** 아니다 (анида)
- 학생이 아니에요 — не студент

## 4. Диалоги

### 4.1 Знакомство

```
A: 안녕하세요? 저는 마이클이라고 해요.
   Аннёнхасэё? Чонын Майкхырираго хэё.
   Здравствуйте? Меня зовут Майкл.

B: 네, 반갑습니다. 저는 수진이에요.
   Нэ, пангапсымнида. Чонын Суджиниэё.
   Да, приятно познакомиться. Я Суджин.

A: 만나서 반갑습니다. 한국어를 공부하고 있어요.
   Маннасопангапсымнида. Хангугорыль конбухаго иссёё.
   Приятно познакомиться. Я учу корейский.

B: 정말요? 한국말 잘 하시네요!
   Чонмальё? Хангунмаль чаль хасинэё!
   Правда? Вы хорошо говорите по-корейски!
```

### 4.2 В ресторане

```
A: 뭐 드시겠어요?
   Мво дысигессоё?
   Что будете есть?

B: 비빔밥 하나 주세요.
   Пибимпап хана чусэё.
   Один пибимпап, пожалуйста.

A: 그리고 뭐 마실래요?
   Кыриго мво масиллерё?
   И что будете пить?

B: 냉수 주세요.
   Нэнсу чусэё.
   Холодную воду, пожалуйста.

A: 네, 잠시만요.
   Нэ, чамсиманнё.
   Да, минутку.
```

### 4.3 В такси

```
A: 명동까지 가 주세요.
   Мёндонккаджи ка чусэё.
   Отвезите в Мёндон, пожалуйста.

B: 네, 얼마나 걸려요?
   Нэ, ольмана кольрёё?
   Да, сколько времени займёт?

A: 약 20분 걸려요.
   Як исиппун кольрёё.
   Около 20 минут.

B: 여기서 세워 주세요.
   Ёгисо свео чусэё.
   Остановите здесь, пожалуйста.

A: 얼마예요?
   Ольмайеё?
   Сколько?

B: 만 이천 원입니다.
   Ман ичхон вонимнида.
   12000 вон.
```

### 4.4 В магазине

```
A: 이거 얼마예요?
   Иго ольмайеё?
   Сколько это?

B: 오천 원이에요.
   Очхон вониэё.
   5000 вон.

A: 좀 비싸요. 깎아 주세요.
   Чом писсаё. Ккага чусэё.
   Дороговато. Сделайте скидку.

B: 죄송합니다. 정가예요.
   Чвэсонхамнида. Чонгайеё.
   Извините, фиксированная цена.
```

## 6. Фонетика и интонация

### 6.1 Интонация

- **Повествование:** ровная или слегка нисходящая
- **Вопрос (да/нет):** восходящая (안녕하세요↗)
- **Вопрос с вопросительным словом:** нисходящая (뭐 해요↘)
- **Команда:** ровная, твёрдая

### 6.2 Ударение

В корейском нет тонов, но есть музыкальное ударение. Первый слог произносится с более высокой интонацией:
- 서울 (соуль) — выше на 첫 (первый слог)
- 사람 (сарам) — выше на 사

### 6.3 Связывание (연음)

Конечная согласная переносится на следующий слог, если он начинается с гласной:
- 한국어 [한구거] (хан-гу-го)
- 책이 [채기] (чхэ-ги)
- 물을 [무를] (му-рыль)

## 8. Культурные заметки

- **Поклоны** — обязательны. Чем старше человек, тем ниже поклон.
- **Имена** — сначала фамилия, потом имя. Не называют по имени без приглашения, только фамилия + 씨 (сси) / 님 (ним).
- **Обувь** — снимают при входе в дом.
- **Еда** — старший начинает есть первым. Не втыкают палочки в рис. Не едят, пока не налили всем.
- **Подарки** — протягивают двумя руками. Не дарят обувь (убежит), красную ручку (смерть).
- **Число 4 (사, са)** — несчастливое (звучит как смерть). Лифты часто пропускают 4-й этаж.
- **Возраст** — в Корее считают иначе: при рождении 1 год, +1 с Новым годом.
- **Критика** — смягчают, избегают прямого отказа. "Да" не всегда означает согласие.
- **За столом** — наливают друг другу, не себе. Пьют, повернувшись от старших.
- **Соло** — не принято есть в одиночку.
- **팔짱 (пальччан)** — скрещивание рук считается грубым.

## 10. Частые ошибки

1. **Путаница между 은/는 и 이/가**
   - 은/는 — тема (контраст)
   - 이/가 — субъект (новое)

2. **Неправильный порядок слов**
   - Глагол всегда в конце

3. **Забывают про банмаль**
   - Не используют 반말 с незнакомцами

4. **Неправильные глаголы**
   - 듣다 → 들어요 (а не 듣어요)

5. **Путаница между исконными и китайскими числами**
   - Возраст: исконные (스무 살)
   - Дата: китайские (3월 15일)

6. **Опускание частиц**
   - В разговорной речи опускают, но лучше использовать

7. **ㅇ как начальная буква**
   - Не произносится, если стоит первым в слоге
