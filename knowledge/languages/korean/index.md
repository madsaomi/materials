# Корейский язык — Полный конспект

> 📘 **Начните отсюда:** [Учебник — программа курса, методика, трекер прогресса](textbook.md)

## Введение

Корейский язык (한국어, хангуго / 조선말, чосонмаль) — язык корейской ветви алтайской языковой семьи. Около 80 миллионов носителей. Государственный язык Республики Корея и КНДР.

**Ключевые особенности:**
- Собственная фонетическая письменность хангыль (한글)
- Порядок слов SOV
- Развитая система вежливости (7 уровней)
- Агглютинативный строй (частицы + окончания)

## 1. Хангыль (한글) — корейский алфавит

Создан в XV веке королём Седжоном Великим. Научно обоснованная система: форма букв моделирует положение языка и губ.

### 1.3 Слоговая структура

Слоги записываются блоками: C + V (+ C)

Примеры:
- 한 (хан) = ㅎ + ㅏ + ㄴ
- 글 (кыль) = ㄱ + ㅡ + ㄹ
- 한국 (хангук) = 한 + 국
- 언어 (оно) = 언 + 어

### 1.4 Правила произношения

**Ассимиляция согласных:**
- ㄱ + ㄴ → ㅇ + ㄴ: 국물 → 궁물 (кунмуль)
- ㅂ + ㄴ → ㅁ + ㄴ: 합니다 → 함니다 (хамнида)
- ㄹ + ㄴ → ㄹ + ㄹ: 설날 → 설랄 (соллаль)
- ㄷ + ㅎ → ㅌ: 닫히다 → 다티다 (татхида → татхида → тачхида)

**Озвончение начальных согласных:**
- ㄱ → [ɡ] между гласными
- ㄷ → [d] между гласными
- ㅂ → [b] между гласными
- ㅈ → [dʑ] между гласными

## 2. Грамматика

### 2.1 Структура предложения (SOV)

```
저는 사과를 먹습니다.
Чонын сагуарыль моксымнида.
Я яблоко ем.
```

### 2.2 Частицы (조사)

**Именительный падеж (кто/что):**
- 이 после согласной: 책이 (чхэги)
- 가 после гласной: 사과가 (сагвага)
- 께서 — уважительная

**Винительный падеж (объект):**
- 을 после согласной: 책을 (чхэгыль)
- 를 после гласной: 사과를 (сагварыль)

**Родительный падеж (принадлежность):**
- 의 (е/ый): 나의 책 (нае чхэк) — моя книга

**Дательный падеж (кому/чему):**
- 에게 (люди): 친구에게 (чхингуеге)
- 한테 (разг.): 친구한테
- 께 (уваж.): 선생님께
- 에 (место/время): 학교에 (хаккёе)

**Творительный падеж (чем/кем):**
- 로 после гласной: 버스로 (посыро) — автобусом
- 으로 после согласной: 연필으로 (ёнпирыро) — карандашом

**Местный падеж (где):**
- 에서 — в/на (действие): 학교에서 공부해요

**Совместный (с кем):**
- 와 после гласной: 친구와
- 과 после согласной: 친구과

**Тема/фокус (маркеры темы):**
- 은 после согласной: 나는 (нанын)
- 는 после гласной: 저는 (чонын)

### 2.3 Спряжение глаголов

Корейские глаголы делятся на правильные и неправильные (особые основы).

**Словарная форма:** глагол + 다 (та)
- 먹다 (мокта) — есть
- 가다 (када) — идти
- 보다 (пода) — смотреть

**Основа глагола:** убрать 다
- 먹 (мок)
- 가 (ка)
- 보 (по)

**Настоящее время (формальный стиль):**

| Тип | Суффикс | Пример |
|-----|---------|--------|
| ㄹ-основа | ㅂ니다 | 갑니다 (камнида) |
| гласная | ㅂ니다 | 봅니다 (помнида) |
| согласная | 습니다 | 먹습니다 (моксымнида) |

**Настоящее время (неформальный вежливый):**
- Гласная + 아/어 + 요
  - 가 + 아요 → 가요 (каё)
  - 먹 + 어요 → 먹어요 (могоё)
  - 하 + 여요 → 해요 (хэё)

**Прошедшее время:**
- Основа + 았/었 + 다
- 가 + 았다 → 갔다 (катта) — пошёл
- 먹 + 었다 → 먹었다 (моготта) — поел
- 하 + 였다 → 했다 (хэтта) — сделал

**Будущее время:**
- Основа + 겠다
- 가겠다 (кагетта) — пойду
- 먹겠다 (моккетта) — поем

**Непрерывное действие (-고 있다):**
- 먹고 있다 (мокко итта) — ем (сейчас)
- 가고 있다 (каго итта) — иду

**Намерение (-려고 하다 / -ㄹ 것이다):**
- 갈 것이다 (каль косида) — собираюсь пойти
- 먹으려고 한다 (могырёго ханда) — намерен есть

### 2.4 Неправильные глаголы

**1. ㄷ-неправильные (ㄷ → ㄹ перед гласной):**
- 듣다 (дытта) → 들어요 (дыроё) — слушать
- 걷다 (котта) → 걸어요 (короё) — ходить
- 묻다 (мутта) → 물어요 (муроё) — спрашивать

**2. ㅂ-неправильные (ㅂ → 우):**
- 춥다 (чхупта) → 추워요 (чхувоё) — холодно
- 덥다 (топта) → 더워요 (товоё) — жарко
- 쉽다 (свипта) → 쉬워요 (свивоё) — легко

**3. 르-неправильные (르 → ㄹ라/ㄹ러):**
- 모르다 (морыда) → 몰라요 (моллаё) — не знать
- 빠르다 (ппарыда) → 빨라요 (ппаллаё) — быстрый

**4. ㅅ-неправильные (ㅅ выпадает):**
- 낫다 (натта) → 나아요 (нааё) — выздоравливать
- 긋다 (кытта) → 그어요 (кыоё) — чертить

**5. ㅎ-неправильные (ㅎ выпадает):**
- 빨갛다 (ппальгатха) → 빨개요 (ппальгэё) — красный

**6. 으-неправильные (으 выпадает):**
- 쓰다 (ссыда) → 써요 (ссоё) — писать
- 크다 (кхыда) → 커요 (кхоё) — большой

### 2.5 Прилагательные

Корейские прилагательные спрягаются как глаголы.

| Словарная | Основа | Вежливая форма | Значение |
|-----------|--------|----------------|----------|
| 크다 (кхыда) | 크 (кхы) | 커요 (кхоё) | большой |
| 작다 (чакта) | 작 (чак) | 작아요 (чагаё) | маленький |
| 예쁘다 (еппыда) | 예쁘 (еппы) | 예뻐요 (еппоё) | красивый |
| 좋다 (чохта) | 좋 (чох) | 좋아요 (чоаё) | хороший |
| 나쁘다 (наппыда) | 나쁘 (наппы) | 나빠요 (наппаё) | плохой |
| 따뜻하다 (ттаттытхада) | 따뜻하 (ттаттытха) | 따뜻해요 (ттаттытхэё) | тёплый |
| 재미있다 (чэмиитта) | 재미있 (чэмиис) | 재미있어요 (чэмииссоё) | интересный |

**Сравнение:**
- A보다 B가 더 + прилагательное
- 사과보다 바나나가 더 커요 (сагвабода пананага то кхоё) — банан больше, чем яблоко

**Превосходная:**
- 가장 / 제일 + прилагательное
- 이것이 제일 좋아요 (игоси чеиль чоаё) — это самый хороший

### 2.6 Числительные

Две системы: **исконно корейская** (для счёта, возраста) и **китайская** (для дат, денег, времени).

**Исконно корейские:**

| Число | Слово |
|-------|-------|
| 1 | 하나 (хана) |
| 2 | 둘 (туль) |
| 3 | 셋 (сет) |
| 4 | 넷 (нет) |
| 5 | 다섯 (тасот) |
| 6 | 여섯 (ёсот) |
| 7 | 일곱 (ильгоп) |
| 8 | 여덟 (ёдоль) |
| 9 | 아홉 (ахоп) |
| 10 | 열 (ёль) |

**Счётные слова (с исконными числами):**
- 명 (мён) — люди: 두 명 (ту мён) — 2 человека
- 개 (ке) — предметы: 사과 세 개 (сагва се ке) — 3 яблока
- 잔 (чан) — чашки: 커피 한 잔 (кхопи хан чан) — чашка кофе
- 병 (пён) — бутылки: 맥주 두 병 (мэкчу ту пён) — 2 бутылки пива
- 시 (си) — часы: 두 시 (ту си) — 2 часа
- 살 (саль) — возраст: 스무 살 (сыму саль) — 20 лет

**Числа 11-19 (исконные):**
열 + число: 열하나 (ёльхана) — 11, 열둘 (ёльтуль) — 12...

**Десятки (исконные):**
- 스물 (сымуль) — 20
- 서른 (сорын) — 30
- 마흔 (махын) — 40
- 쉰 (свин) — 50
- 예순 (йесун) — 60
- 일흔 (ильхын) — 70
- 여든 (ёдын) — 80
- 아흔 (ахын) — 90

**Китайские числительные:**

| Число | Слово |
|-------|-------|
| 1 | 일 (иль) |
| 2 | 이 (и) |
| 3 | 삼 (сам) |
| 4 | 사 (са) |
| 5 | 오 (о) |
| 6 | 육 (юк) |
| 7 | 칠 (чхиль) |
| 8 | 팔 (пхаль) |
| 9 | 구 (ку) |
| 10 | 십 (сип) |
| 100 | 백 (пэк) |
| 1000 | 천 (чхон) |
| 10000 | 만 (ман) |

**Даты:** 년 (год) + 월 (месяц) + 일 (день)
- 2024년 3월 15일

**Деньги:** 원 (вон)
- 오천 원 (очхон вон) — 5000 вон
- 만 원 (ман вон) — 10000 вон

### 2.7 Уровни вежливости

| Уровень | Суффикс | Пример | Использование |
|---------|---------|--------|---------------|
| Хасёчхе (하소서체) | -나이다 | - | император, архаично |
| Хапсёчхе (합쇼체) | -ㅂ니다/습니다 | 갑니다 | официальный, новости |
| Хаойчхе (하오체) | -오 | 가오 | формальный, редко |
| Хэгечхе (하게체) | -게 | 가게 | между равными (уст.) |
| Хэрачхе (해라체) | -다 | 간다 | книги, детям |
| Хэёчхе (해요체) | -아/어요 | 가요 | вежливый разговорный |
| Хэчхе (해체) | -아/어 | 가 | друзья, банмаль |

**Самые используемые в жизни:**
- **해요체 (хэёчхе)** — вежливо-неформальный (повседневный)
- **해체 (хэчхе)** — банмаль (с близкими)
- **합쇼체 (хапсёчхе)** — официально-формальный

### 2.8 Отрицание

**Краткое:**
- 안 + глагол: 안 가요 (ан каё) — не иду
- 못 + глагол (не мочь): 못 가요 (мот каё) — не могу идти

**Долгое:**
- -지 않다: 가지 않아요 (каджи анаё) — не иду
- -지 못하다: 가지 못해요 (каджи мотхэё) — не могу идти

**Отрицание существования:**
- 있다 → 없다: 있어요 → 없어요 — нет

### 2.9 Связка 이다

| Время | Форма | Пример |
|-------|-------|--------|
| Наст. | 이다 / 예요 | 학생이에요 (студент) |
| Прош. | 이었다 / 이었어요 | 학생이었어요 |
| Буд. | 일 것이다 / 일 거예요 | 학생일 거예요 |

**Негативная связка:** 아니다 (анида)
- 학생이 아니에요 — не студент

## 6. Фонетика и интонация

### 6.1 Интонация

- **Повествование:** ровная или слегка нисходящая
- **Вопрос (да/нет):** восходящая (안녕하세요↗)
- **Вопрос с вопросительным словом:** нисходящая (뭐 해요↘)
- **Команда:** ровная, твёрдая

### 6.2 Ударение

В корейском нет тонов, но есть музыкальное ударение. Первый слог произносится с более высокой интонацией:
- 서울 (соуль) — выше на 첫 (первый слог)
- 사람 (сарам) — выше на 사

### 6.3 Связывание (연음)

Конечная согласная переносится на следующий слог, если он начинается с гласной:
- 한국어 [한구거] (хан-гу-го)
- 책이 [채기] (чхэ-ги)
- 물을 [무를] (му-рыль)

## 8. Культурные заметки

- **Поклоны** — обязательны. Чем старше человек, тем ниже поклон.
- **Имена** — сначала фамилия, потом имя. Не называют по имени без приглашения, только фамилия + 씨 (сси) / 님 (ним).
- **Обувь** — снимают при входе в дом.
- **Еда** — старший начинает есть первым. Не втыкают палочки в рис. Не едят, пока не налили всем.
- **Подарки** — протягивают двумя руками. Не дарят обувь (убежит), красную ручку (смерть).
- **Число 4 (사, са)** — несчастливое (звучит как смерть). Лифты часто пропускают 4-й этаж.
- **Возраст** — в Корее считают иначе: при рождении 1 год, +1 с Новым годом.
- **Критика** — смягчают, избегают прямого отказа. "Да" не всегда означает согласие.
- **За столом** — наливают друг другу, не себе. Пьют, повернувшись от старших.
- **Соло** — не принято есть в одиночку.
- **팔짱 (пальччан)** — скрещивание рук считается грубым.

## 10. Частые ошибки

1. **Путаница между 은/는 и 이/가**
   - 은/는 — тема (контраст)
   - 이/가 — субъект (новое)

2. **Неправильный порядок слов**
   - Глагол всегда в конце

3. **Забывают про банмаль**
   - Не используют 반말 с незнакомцами

4. **Неправильные глаголы**
   - 듣다 → 들어요 (а не 듣어요)

5. **Путаница между исконными и китайскими числами**
   - Возраст: исконные (스무 살)
   - Дата: китайские (3월 15일)

6. **Опускание частиц**
   - В разговорной речи опускают, но лучше использовать

7. **ㅇ как начальная буква**
   - Не произносится, если стоит первым в слоге

## 12. 🧠 Подробная методика изучения корейского

### 12.1 Принципы эффективного изучения

Корейский язык требует системного подхода из-за своей агглютинативной природы и сложной системы вежливости. Ниже — научно обоснованная методика, адаптированная для русскоязычных учащихся.

**Принцип 1: Интервальные повторения (SRS)**
Мозг забывает по кривой Эббингауза: через 1 час — 50%, через 1 день — 70%, через 7 дней — 90%. Используйте Anki для автоматического планирования повторений. Карточки с хангылем → транскрипция → перевод → пример в предложении.

**Принцип 2: Многоканальное кодирование**
Одновременно задействуйте зрение (чтение хангыля), слух (аудирование), речь (чтение вслух) и моторику (писение от руки). Исследования показывают, что сочетание каналов увеличивает запоминание на 40–60%.

**Принцип 3: Контекстное изучение лексики**
Не зубрите слова изолированно. Изучайте каждое слово в контексте фразы или мини-сюжета. Например, «밥» (рис/еда) → «매일 밥을 먹어요» (я ем каждый день) → микросюжет: «Я просыпаюсь, иду на кухню и ем 밥».

**Принцип 4: Приоритет хангыля**
Первые 2 недели — исключительно хангыль. Умеете читать? Тогда вы уже на полпути. Транскрипция — временная опора, которая должна быть убрана как можно скорее.

**Принцип 5: Знакомство с банмаль с первого дня**
Не избегайте неформальной речи. Слушайте K-drama, K-pop, корейские YouTube-каналы в банмале. Это даст понимание реального языка и мотивацию.

### 12.2 Методика изучения каждого урока

Каждый урок проходит в три этапа:

**Этап 1: Знакомство (день 1)**
- Прочитайте диалог 3 раза вслух
- Выпишите новую грамматику в тетрадь
- Выучите 15–20 новых слов через Anki
- Прочитайте текст для чтения

**Этап 2: Углубление (дни 2–3)**
- Выполните письменные дриллы
- Запишите себя, читая диалог, и сравните с носителем
- Переведите 5 предложений из диалога без справочника
- Повторите карточки Anki за предыдущие уроки

**Этап 3: Закрепление (день 4–5)**
- Пройдите тест — целевой ≥80%
- Пересмотрите ошибки
- Напишите мини-сочинение (5–7 предложений) по теме урока
- Проведите «тихий день» — только повторение карточек

### 12.3 Стратегия работы с грамматикой

Корейская грамматика строится как конструктор: основа + частица + окончание + вспомогательный глагол. Подход:

1. **Сначала основа.** Вырежьте основу из словарной формы и запомните отдельно.
2. **Затем окончания.** Примените основу ко всем типам окончаний.
3. **Затем контекст.** Используйте каждую конструкцию в 3–5 предложениях.
4. **Наконец, автоматизация.** Через 2 недели использования конструкция станет автоматической.

### 12.4 Работа с текстами для чтения

- **Уровень 1 (уроки 1–5):** читайте с хангылем, без словаря, отмечая незнакомые слова
- **Уровень 2 (уроки 6–10):** читайте, используя словарь только для ключевых слов
- **Уровень 3 (уроки 11–15):** читайте без словаря, проверяя понимание после

### 12.5 Работа с аудированием

- Слушайте диалоги из уроков 2 раза: первый — общий смысл, второй — с текстом
- Используйте podcasts: Korean Unnie, Talk To Me In Korean, Seoul Korean
- Метод «теневого чтения»: повторяйте за диктором с задержкой 2–3 секунды
- Записывайте свою речь и сравнивайте с оригиналом

## 15. ❓ Часто задаваемые вопросы (FAQ)

### 15.1 Общие вопросы

**В: Сколько времени нужно для изучения корейского до уровня TOPIK II?**
О: При занятиях 30–60 минут ежедневно — 9–12 месяцев. При 1–2 часах в день — 6–8 месяцев. Факторы: предыдущий опыт изучения языков, регулярность, погружение.

**В: Нужно ли учить ханчу (китайские иероглифы)?**
О: Для уровня TOPIK I — необязательно, но желательно знать 100–200 иероглифов. Для TOPIK II — необходимо (500+ иероглифов). Подробнее: [ханча](hanja/index.md).

**В: Какой уровень вежливости использовать в первую очередь?**
О: Начинайте с **해요체 (хэёчхе)** — он универсален для повседневного общения и не оскорбит никого. Когда поймёте систему, переходите к 합쇼체 для формальных ситуаций.

**В: Можно ли изучать корейский без учителя?**
О: Да, с данным учебником, Anki, приложениями и ресурсами для аудирования. Но носитель языка ускорит прогресс в 2–3 раза. Используйте HelloTalk или italki.

**В: Хватит ли знать только 해요체?**
О: Для базового общения — да. Но без 합쇼체 вы не сможете обращаться к старшим, в официальных ситуациях, на телевидении. Цель — знать оба уровня.

### 15.2 Грамматика

**В: Чем отличается 은/는 от 이/가?**
О: **은/는** — маркер темы (о чём речь), создаёт контраст с остальным. **이/가** — маркер субъекта (кто делает действие), вводит новую информацию. Подробно: [раздел 2.2](#22-частицы-조사) и [micro-details](details.md#21-은는-vs-이가-исчерпывающее).

**В: Когда использовать 에, а когда 에서?**
О: **에** — указывает на местоположение или направление («в школу», «в школе»). **에서** — указывает на место действия или отправления («учусь в школе», «выходю из дома»). Подробнее: [details.md §2.2](details.md#22-에-vs-에서-движение-vs-действие).

**В: Что выбрать — 고 있다 или 아/어 있다?**
О: **고 있다** — процесс действия (я иду: 가고 있다). **아/어 있다** — результат/состояние (я сел и сижу: 앉아 있다). Подробнее: [details.md §2.7](details.md#27-아어-있다-vs-고-있다).

**В: Почему 듣다 → 들어요, а не 듣어요?**
О: Это ㄷ-неправильный глагол: ㄷ → ㄹ перед гласной. Аналогичные: 걷다 → 걸어요, 묻다 → 물어요, 싣다 → 실어요. Подробнее: [details.md §3.1](details.md#31-полный-список-неправильных-глаголов).

**В: Как правильно использовать -아/어서 vs (으)니까?**
О: **-아/어서** — объективная причина (дождь идёт → я дома). **(으)니까** — субъективная причина с предложением (дождь идёт → давай останемся). Подробнее: [details.md §2.4](details.md#24-아어서-vs-으니까-причина)).

### 15.3 Хангыль и произношение

**В: Почему ㅇ не произносится?**
О: ㅇ — это «пустой» звук. Когда он стоит первым в слоге (예: 아이), он не произносится. Когда он стоит в конце слога (예: 강), он произносится как [ŋ] (носовой звук).

**В: Почему 한국어 произносится как 한구거?**
О: Из-за явления 연음 (связывания): конечная согласная переходит на следующий слог. 한국어: 한 + 구 + 어 → [한구거]. Подробнее: [details.md §1.4](details.md#14-связывание-연음).

**В: В чём разница между 평음 и 경음?**
О: **평음** — обычный мягкий звук (가, 다, 바). **경음** — напряжённый твёрдый звук (가, 따, 빠). Разница в напряжении голосовых связок, как в итальянском doppio.

**В: Как улучшить произношение?**
О: 1) Записывайте себя на диктофон. 2) Сравнивайте с носителем на Forvo.com. 3) Используйте метод теневого чтения. 4) Обратите внимание на 서음→이음 ассимиляцию. 5) Слушайте корейские тантсы (песни) для музыкальности.

### 15.4 Лексика

**В: Как запоминать новые слова эффективно?**
О: Используйте метод FEAT:
- **F**eel (чувствуйте) — создайте эмоцию для слова
- **E**xaggerate (преувеличьте) — сделайте образ абсурдным
- **A**ct (действуйте) — используйте слово в предложении
- **T**est (проверьте) — проверьте себя через Anki
Подробнее: [мнемотехники](../../mnemonics/index.md).

**В: Сколько слов нужно знать для базового общения?**
О: ~500 слов для простых диалогов, ~1000 для свободного общения, ~2000 для понимания текстов и фильмов. Подробнее: [vocabulary milestones](textbook.md#вехи-лексики-детальные-цели).

**В: Какие слова учить первыми?**
О: Начните с: приветствия, местоимения, глаголы быта (есть, пить, идти, говорить), числительные, частицы. Затем — тематическая лексика (еда, транспорт, работа).

### 15.5 Культура и язык

**В: Почему корейский так сложный?**
О: Корейский сложен для русскоязычных из-за: 1) другой системы вежливости (нет аналога в русском), 2) порядок слов SOV, 3) система частиц, 4) неправильные глаголы. Но хангыль — один из самых простых алфавитов в мире (занимает ~2 недели).

**В: Чем корейский отличается от японского и китайского?**
О: Корейский — агглютинативный язык с SOV порядком и собственной письменностью. Японский — агглютинативный с SOV и тремя письменностями. Китайский — изолирующий с иероглифами и SVO порядком. Подробнее о сравнении: [сравнение языков](../comparison/index.md).

**В: Почему важна система 존댓말?**
О: 존댓말 (вежливая речь) отражает конфуцианские ценности уважения к старшим. Неправильное использование может быть оскорблением. Подробнее: [details.md §9.2](details.md#92-система-존댓말-вежливости).

### 15.6 Экзамен и сертификация

**В: Что такое TOPIK и какие уровни?**
О: TOPIK (Test of Proficiency in Korean) — официальное тестирование уровня корейского. 6 уровней: 1-2 (начальный), 3-4 (средний), 5-6 (продвинутый). Подробнее: [подготовка к TOPIK](exam/index.md).

**В: Сколько баллов нужно для TOPIK II 4 уровня?**
О: Для TOPIK II 4-го уровня обычно достаточно 50-60% правильных ответов (из 300). Для 5 уровня — 70%+, для 6 — 85%+.

**В: Стоит ли сдавать TOPIK?**
О: Да, если планируете учёбу в Корее, работу в корейских компаниях или подтверждение уровня для визы. TOPIK 3+ открывает многие возможности.

### 15.7 Ресурсы и инструменты

**В: Какой переводчик лучший для корейского?**
О: Papago — лучший для корейского. Google Translate — средний. Naver Dictionary — лучший для слов.

**В: Какой учебник выбрать?**
О: Для русскоязычных: данный учебник + Korean Grammar in Use (Mid/Advanced). Дополнительно: TTMIK (бесплатные подкасты и PDF).

**В: Как найти носителя языка для практики?**
О: HelloTalk, Tandem (приложения), italki (платные уроки), языковые обмены в вашем городе, r/Korean на Reddit.

## 17. 📖 Глоссарий грамматических терминов корейского языка

### Агглютинация (Agglutination / 꼬리말 결합)
Способ словообразования, при котором к основе последовательно добавляются суффиксы (частицы, окончания). Каждый суффикс несёт одно грамматическое значение.

### Банмаль (반말)
Неформальный стиль речи, используемый между друзьями, членами семьи, сверстниками. Без окончаний вежливости (-요, -습니다).

### Выпадение согласной (Consonant Elision / 자음 탈락)
Прекращение произношения согласной в определённых позициях: ㅎ-выпадение, ㅅ-выпадение, ㄹ-выпадение.

### Вопросительное слово (Wh-word / 의문사)
Слово, образующее вопрос: 뭐 (что), 어디 (где), 언제 (когда), 왜 (почему), 어떻게 (как), 누구 (кто), 무엇 (что).

### Глагол (동사 / dongsa)
Слово, обозначающее действие: 가다 (идти), 먹다 (есть), 하다 (делать).

### Глагольная основа (Verb Stem / 동사 어간)
Форма глагола без окончания -다: 먹- (от 먹다), 가- (от 가다), 보- (от 보다).

### Гипотетическая форма (Hypothetical / 가정형)
Форма, выражающая условие: -(으)면 (если), -다면 (если), -더라도 (даже если).

### Дательный падеж (Dative / 간접목적어)
Падеж, обозначающий получателя действия: -에게, -한테, -께.

### Истинный подлежащий (True Subject / 주어)
Подлежащее, которое логически является агентом действия, в отличие от маркера темы.

### Итатив (Itative / ~ㄹ 것이다 / ~ㄹ게요)
Выражение намерения, обещания: 갈게요 (пойду).

### Каллиграфия (서예 / seoye)
Искусство письма хангылем и ханча с использованием кисти (붓), туши (먹) и бумаги (한지).

### Каузатив (Causative / 사동사)
Грамматическая конструкция, выражающая причинение действия: -게 하다 (сделать так, чтобы...).

### Коннегвиданс (Connegitive / 접속사)
Форма глагола, используемая для соединения предложений: -고 (и), -아서 (потому что), -지만 (но).

### Культурный имплект (Cultural Implicitness / 문화적 암묵성)
Значение, которое не выражается прямо, но подразумевается культурным контекстом: 예절 (этикет) в корейском языке.

### Маркер темы (Topic Marker / 주제격 조사)
Частица 은/는, указывающая на тему обсуждения, а не на субъект: 저는 학생입니다 (говорим обо мне).

### Медиация (Medial / 중세)
Средняя форма глагола между словарной и вежливой: -게 (между равными).

### Множественное число (Plural / 복수)
В корейском нет специфической формы множественного числа для существительных; множественность выражается контекстом или счётными словами.

### Намерение (Intention / 의지)
Выражение воли к действию: -려고 하다 (намерение), -ㄹ 것이다 (предсказание намерения).

### Непрерывное действие (Progressive / 진행형)
Форма -고 있да, обозначающая действие в процессе: 먹고 있다 (ем прямо сейчас).

### Неправильный глагол (Irregular Verb / 불규칙 동사)
Глагол, не подчиняющийся стандартным правилам спряжения: 듣다→들어요, 춥다→추워요, 빨갛다→빨개요.

### Окончание (Ending / 어미)
Грамматический суффикс, определяющий стиль и тон высказывания: -습니다 (формальный), -요 (вежливый), -다 (простой).

### Пассив (Passive / 피동)
Грамматическая конструкция, делающая субъект получателем действия: -이/히/리/기 (быть сделанным).

### Порядок слов SOV (SOV Word Order / SOV 어순)
Порядок слов: Субъект — Объект — Сказуемое (Verb-final). Язык корейский: 저는 사과를 먹습니다.

### Персперсив (Perceptive / 희망)
Выражение пожелания или наблюдения от первого лица: -아/어 주다 (позволить, сделать для меня).

### Прилагательное (형용사 / hyeongyongsah)
Слово, описывающее свойство: 크다 (большой), 예쁘다 (красивый). Спрягается как глагол.

### Придыхание (Aspiration / 거친 소리)
Особое произношение согласных с сильным выдохом: ㅋ, ㅌ, ㅍ, ㅊ.

### Причинно-следственная связь (Causality / 인과)
Связь причины и следствия, выраженная через -아/어서, -기 때문에, (으)니까.

### Пассивный залог (Passive Voice / 수동태)
Конструкция, в которой субъект страдает: 문이 열렸다 (дверь была открыта).

### Реалис (Realis / 서술법)
Прямое, реальное высказывание: -습니다, -어요, -다 (против императива или оптатива).

### Ретрофлексия (Retroflexion / 설측음)
Произношение, при котором язык загибается назад: ㄹ (р/л).

### Субъект (Subject / 주어)
Выполняющий действие агент, маркируемый частицей 이/가: 학생이 왔다 (студент пришёл).

### Союз (Conjunction / 접속사)
Слово, соединяющее предложения: 그리고 (и), 하지만 (но), 그래서 (поэтому).

### Система вежливости (Politeness System / 존댓말 체계)
Иерархическая система уровней речи в корейском языке: 7 уровней от 하소서체 (императорского) до 해체 (неформального).

### Тема (Topic / 주제)
Грамматическая конструкция, при которой говорящий «обозначает» предмет обсуждения с помощью 은/는: 한국어는 재미있다 (корейский — интересный).

### Транскрипция (Transcription / 로마자 표기)
Запись хангыля латинскими буквами (Ревизионная Романизация): 한국어 → Hangugeo.

### Фонема (Phoneme / 음소)
Минимальная единица звука, различающая значение слов: ㅂ [p] vs ㅍ [pʰ] (разница в придыхании).

### Числительное (Numeral / 수사)
Слово, обозначающее число: 하나 (один), 둘 (два), 십 (десять). Две системы: исконная и китайская.

### Шифт регистра (Register Shift / 화폐)
Изменение уровня вежливости в ходе диалога от 더 존경 (более уважительного) к 반말 (неформальному).
