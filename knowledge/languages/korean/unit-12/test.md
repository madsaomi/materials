1) 존댓말은 친한 사람에게 사용한다. (  )

3) "-요"체는 일상에서 많이 사용한다. (  )
4) "드시다"는 "먹다"의 높임말이다. (  )
5) 요즘 젊은 사람들 사이에서 존댓말 사용이 늘어나고 있다. (  )

### 3. 다음 한국어 문장을 러시아어로 번역하세요. (Переведите на русский.)

1) 존댓말은 높은 사람에게 사용하고, 반말은 친한 사람에게 사용한다.
2) 존댓말을 사용하는 것이 항상 쉬운 것은 아니다.
3) 존댓말은 한국 문화의 중요한 부분이기 때문이다.
4) 우리는 존댓말을 잘 사용하여 예의 바른 사람이 되어야 한다.
5) 존댓말을 사용하면 다른 사람에게 좋은 인상을 줄 수 있다.

### 6. 다음 중 알맞은 것을 고르세요. (Выберите правильный вариант.)
