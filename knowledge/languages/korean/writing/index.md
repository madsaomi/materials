## 1. Обзор курса письма (1. Writing course overview)

### 1.1 Цель раздела

Раздел «Письмо» (글쓰기 / geulseutgi) предназначен для освоения ручного письма на корейском языке (한국어 / Hangugeo). В нём вы изучите:

- Как правильно писать каждый символ хангыль (한글 / Hangeul) — от первого до последнего штриха (획 / hyeot).
- Как собирать штрихи в слоговые блоки (음절 블록 / eumjeul beulkeu).
- Как развить аккуратный и быстрый почерк (필체 / pilche).
- Как тренироваться ежедневно с помощью структурированного 90-дневного плана.
- Как проверять своё письмо с помощью рубрик самодиагностики (자가 평가 / jaga pyeongga).

### 1.2 Что такое хангыль

Хангыль (한글 / Hangeul) — алфавит корейского языка, созданный в 1443 году учёным Седжоном Великим (세종대왕 / Sejong Daewang) и его комиссией. Он состоит из:

- **14 основных согласных** (자음 / jajeum): ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ
- **10 основных гласных** (모음 / moeum): ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ
- **11 двойных гласных** (쌍모음 / ssang moeum): ㅐ ㅒ ㅔ ㅖ ㅘ ㅙ ㅝ ㅞ ㅟ ㅢ
- **27 итоговых согласных** (받침 / batchim): ㄱ ㄲ ㄳ ㄴ ㄵ ㄶ ㄷ ㄹ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅁ ㅂ ㅄ ㅅ ㅆ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ

### 1.3 Почему важно писать от руки

Исследования когнитивных наук показывают, что ручное письмо (필기 / pilgi) улучшает запоминание символов и способствует лучшему усвоению фонологической системы языка. Для изучающих корейский как иностранный (한국어 외국인 학습자 / Hangugeo oegukin hakgsaeng) письмо от руки — это не просто бонус, а обязательный элемент программы.

> 💡 **Совет**: каждый раз, когда вы изучаете новый символ, пишите его в воздухе (공중 글씨 / gongjung geulsi), по пальцам, а затем на бумаге. Это закрепляет моторную память.

### 1.4 Необходимые материалы

| Материал (재료 / jaimul) | Описание (설명 / seolmyeong) |
|---|---|
| Линованная бумага (선칼라 용지 / seonkalla yongji) | Клетка 5 мм для точного выравнивания символов |
| Графический карандаш (연필 / yeonpil) | HB или 2B — мягкий, но контролируемый |
| Ластик (지우개 / jiuga-e) | Мягкий, без следов |
| Разлиновочный шаблон (지필 모양 틀 / jipil mo-yang teul) | Шаблон для тренировки квадратных блоков |
| Губка для чернил (수첩 연마판 / sucheop yeonma-pan) | Для отработки в тетради |
| Цифровое приложение (디지털 앱 / deijiteul apeu) | WriteHangeul, Hangeul Writer — для дополнительной практики |

### 1.5 Формат записи в этом руководстве

Каждый символ и каждое слово в этом документе записаны в трёх форматах:

1. **Хангыль** (한국어 / Hangugeo): 실제 문자 / haengsang munja
2. **Розн. транслит.** (Латинская транслитерация по системе Мёллера-Ришеу / Revised Romanization): **RR**
3. **Русский перевод** (러시아어 번역 / Reussiaeo beonyeok): перевод

Пример:

> **ㄱ** · **giyeok** · «к» (издалека, «г»)

### 2.2 Детальное описание штрихов каждого согласного

#### ㄱ giyeok (기역)

```
  ㄱ
```

- **Штрих 1**: Вертикальная линия (수 / su), пишется сверху вниз.
- **Штрих 2**: Горизонтальная линия слева направо (횡 / hwang), пересекает вертикальную в середине.
- **Место начала**: верхний правый угловой точке (오른쪽 위 모서리 / oreunjjok wi mo-seori).
- **Направление**: первый штрих — вниз, второй — вправо.
- **RR**: giyeok
- **Произношение**: [g] (начальная позиция), [k] (финальная позиция / 받침)
- **Примеры**: 가 (ga, 가다 / kadа — идти), 강 (gang, 강역 / gangyeok — река), 길 (gil, 길 찾기 / kiir chatgi — поиск пути)

> 📝 **Задание**: Напишите ㄱ пять раз подряд, считая каждый штрих. Затем напишите слово 가 (ga) пять раз.

#### ㄴ nieop (니은)

```
  ㄴ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Диагональная линия сверху-влево-вниз (대각선 / daegaksen), начинается в верхней правой части, идёт вниз-влево.
- **Направление**: первый штрих — вертикально вниз, второй — диагонально вниз-влево.
- **RR**: nieop
- **Произношение**: [n]
- **Примеры**: 나 (na, 나무 / namu — дерево), 네 (ne, 네 번 / ne beon — четыре раза), 누 (nu, 눈 / nun — глаз)

> 📝 **Задание**: Напишите ㄴ десять раз. Затем запишите: 나, 너, 네, 누 — по 3 раза каждое.

#### ㄷ dikeut (디귿)

```
  ㄷ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия справа налево (횡 / hwang), начинается в верхней правой точке.
- **Штрих 3**: Дополнительный короткий штрих (약획 / hapyeot) в правой части, пересекающий вертикальную.
- **RR**: dikeut
- **Произношение**: [d] (начальная), [t] (финальная / 받침)
- **Примеры**: 다 (da, 다리 / dari — мост), 딸 (ttal, 딸 / ttal — дочь), 돋다 (dodda, 빛이 돋다 / bichi dodda — светить)

> 📝 **Задание**: Напишите ㄷ восемь раз. Запишите слова: 다, 돌, 돋, 딸 — по 4 раза.

#### ㄹ rieul (리을)

```
  ㄹ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Диагональный штрих вниз-вправо (역훈장 / yeokhunjang), начиная от середины вертикальной линии.
- **Штрих 3**: Начальный вертикальный штрих (시초부 / sichobu) — лёгкий штрих в верхней левой части.
- **RR**: rieul
- **Произношение**: [r/l] — флап (рядом с гласной), [l] (в конце слога)
- **Примеры**: 라 (ra, 라디오 / radio — радио), 러브 (reobeu, 러브 레스토랑 / reobeu reseutorang — ресторан), 돌아가다 (dolaga-da, 돌아가다 / dolagada — вернуться)

> 📝 **Задание**: Это самый сложный согласный! Напишите ㄹ двадцать раз. Попробуйте различить начальную и конечную форму: ㄹ в начале слога vs ㄹ в конце.

#### ㅁ mieum (미음)

```
  ㅁ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Две горизонтальные линии (횡 / hwang) — одна в верхней части, одна в нижней.
- **Форма**: напоминает распятую фигуру или столб с двумя перекладинами.
- **RR**: mieum
- **Произношение**: [m]
- **Примеры**: 마 (ma, 마이크 / maikeu — микрофон), 몸 (mom, 몸 / mom — тело), 엄마 (eomma, 엄마 / eomma — мама)

> 📝 **Задание**: Напишите ㅁ пятнадцать раз. Затем запишите: 엄마, 맘, 모, 말 — по 5 раз каждое.

#### ㅂ bieup (비읍)

```
  ㅂ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Две горизонтальные линии (횡 / hwang) — подобно ㅁ, но без нижней перекладины (ближе к форме «Б»).
- **RR**: bieup
- **Произношение**: [b] (начальная), [p] (финальная / 받침)
- **Примеры**: 바 (ba, 바나나 / banana — банан), 밥 (bap, 밥 먹다 / bap meokda — есть рис), 불 (bul, 불 / bul — огонь)

> 📝 **Задание**: Напишите ㅂ двенадцать раз. Отличие от ㅁ: в ㅂ нет нижней горизонтальной черты. Проверьте себя!

#### ㅅ si-eut (시읍)

```
  ㅅ
```

- **Штрих 1**: Плавная кривая сверху вниз (곡선 / gokseon), начинается в верхней правой точке.
- **Штрих 2**: Кривая продолжается вниз и заканчивается слева, образуя форму «с» или «ж».
- **RR**: si-eut
- **Произношение**: [s] (начальная), [t] (финальная / 받침 после ㅅ)
- **Примеры**: 사 (sa, 사과 / sagwa — яблоко), 선 (seon, 선물 / seonmul — подарок), 쓰다 (seuda, 쓰다 / seuda — писать)

> 📝 **Задание**: Напишите ㅅ двадцать раз. Обратите внимание: ㅅ начинается справа сверху и заканчивается слева внизу.

#### ㅇ ieung (이응)

```
  ㅇ
```

- **Начальная позиция (초성 / choseong)**: Пустой символ (빈 블록 / bin beulkeu), означает глоттальный замок. Не пишется как отдельный штрих — это «пустое место» для гласной.
- **Финальная позиция (종성 / jongseong)**: Пишется как ㅇ, произносится как [ng] (как в русском «инженер»).
- **RR**: ieung
- **Произношение**: ничего (начальная) / [ŋ] (финальная)
- **Примеры**: 아 (a, 아버지 / abeoji — отец), 앉 (anat, 앉다 / andada — сесть), 생 (saeng, 생선 / saengseon — рыба)

> 📝 **Задание**: Запишите ㅇ в начальной и финальной позициях: 아, 앉, 강, 생. Обратите внимание на разницу в написании!

#### ㅈ jieut (지읍)

```
  ㅈ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия слева направо (횡 / hwang), в середине вертикальной.
- **Штрих 3**: Дополнительный штрих (약획 / hapyeot), замыкающий правую часть.
- **RR**: jieut
- **Произношение**: [dz/j] (начальная), [t] (финальная / 받침)
- **Примеры**: 자 (ja, 자전거 / jajeongeo — велосипед), 저 (je, 저기 / jeogi — там), 주 (ju, 주다 / juda — давать)

> 📝 **Задание**: Напишите ㅈ пятнадцать раз. Напоминает форму «8» на боку или цифру «3».

#### ㅊ chieut (치읍)

```
  ㅊ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия в середине (횡 / hwang).
- **Штрих 3**: Дополнительный штрих справа (약획 / hapyeot).
- **Отличие от ㅈ**: Четвёртый штрих добавляет «хвостик» внизу, отличая ㅊ от ㅈ.
- **RR**: chieut
- **Произношение**: [ch]
- **Примеры**: 차 (cha, 차가리 / chagari — креветка), 춤 (chum, 춤추다 / chumchuda — танцевать), 체 (che, 체하다 / chehada — страдать)

> 📝 **Задание**: Сравните ㅈ и ㅊ. Напишите оба символа по 10 раз, затем запишите 차와 자, 춤과 전 — по 5 раз.

#### ㅋ kieuk (키읓)

```
  ㅋ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия слева направо (횡 / hwang), в верхней части.
- **Штрих 3**: Диагональный штрих сверху-влево (대각선 / daegaksen), начиная от правой части горизонтальной.
- **RR**: kieuk
- **Произношение**: [k] (всегда безголосный)
- **Примеры**: 코 (ko, 코 / ko — нос), 키 (ki, 키 / ki — рост), 크다 (keuda, 크다 / keuda — большой)

> 📝 **Задание**: Напишите ㅋ восемнадцать раз. Отличие от ㄱ: ㅋ имеет диагональный штрих и всегда безголосный.

#### ㅌ tieut (티읍)

```
  ㅌ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия в верхней части (횡 / hwang).
- **Штрих 3**: Диагональный штрих сверху-влево (대각선 / daegaksen).
- **Отличие от ㄷ**: ㅌ имеет диагональный штрих и всегда безголосный.
- **RR**: tieut
- **Произношение**: [t] (всегда безголосный)
- **Примеры**: 토 (to, 토끼 / tokki — кролик), 터 (teo, 터지다 / teojida — лопнуть), 튜브 (tyubeu, 튜브 / tyubeu — трубка)

> 📝 **Задание**: Напишите ㅌ двенадцать раз. Сравните с ㄷ — оба имеют три штриха, но ㅌ безголосный и имеет диагональ.

#### ㅍ pieup (피읍)

```
  ㅍ
```

- **Штрих 1**: Вертикальная линия сверху вниз (수 / su).
- **Штрих 2**: Горизонтальная линия в верхней части (횡 / hwang).
- **Штрих 3**: Диагональный штрих сверху-влево (대각선 / daegaksen).
- **Отличие от ㅂ**: ㅍ имеет диагональный штрих и всегда безголосный.
- **RR**: pieup
- **Произношение**: [p] (всегда безголосный)
- **Примеры**: 포 (po, 포도 / podo — виноград), 편 (pyeon, 편지 / pyeonji — письмо), 풍부 (pungbu, 풍부하다 / pungbu-hada — богатый)

> 📝 **Задание**: Напишите ㅍ десять раз. Запомните: ㅂ = [b/p], ㅍ = [p] (всегда беззвучный).

#### ㅎ hieut (히읗)

```
  ㅎ
```

- **Штрих 1**: Две диагональные линии (대각선 / daegaksen), пересекающиеся в центре — левая сверху-вправо, правая сверху-влево, образуя крест.
- **Штрих 2**: Иногда добавляется маленький завиток в правой нижней части.
- **RR**: hieut
- **Произношение**: [h] (начальная), [t] (финальная / 받침)
- **Примеры**: 하 (ha, 행복 / haengbok — счастье), 호 (ho, 호랑이 / horang-i — тигр), 꽃 (kkot, 꽃을 / kkot-eul — цветок)

> 📝 **Задание**: Напишите ㅎ пятнадцать раз. Это единственный согласный, который состоит из двух пересекающихся диагональных линий.

## 3. Базовые штрихи (3. Basic strokes)

### 3.1 Шесть базовых штрихов хангыль

Все символы хангыль состоят из шести базовых штрихов (기본 획 / gibeon hyeot):

| № | Штрих | RR | Форма | Пример в символе |
|---|-------|-----|-------|------------------|

### 3.2 Описание каждого базового штриха

#### 획 (hyeot) — точка / короткий штрих

- **Форма**: короткая вертикальная или диагональная линия, похожая на точку или короткий штрих.
- **Направление**: сверху вниз или слева направо вниз.
- **Длина**: примерно 1/3 высоты символа.
- **Использование**: нижняя часть ㅂ, ㅍ; дополнительный штрих в ㄱ, ㄷ, ㅈ.
- **Техника**: быстрое движение снизу вверх или слева направо, без задержки.

#### 점 (jeom) — точка

- **Форма**: маленькая точка (•), похоже на русскую запятую без изгиба.
- **Направление**: движение сверху вниз с лёгким нажимом.
- **Использование**: верхняя точка в ㅈ, ㅠ, ㅑ, ㅖ; точка под ㄷ.
- **Техника**: быстрое касание пера / карандаша к бумаге, без скольжения.

#### 횡 (hwang) — горизонтальная линия

- **Форма**: прямая линия слева направо.
- **Направление**: слева направо, слегка наклонённая сверху вниз (на 5–10°).
- **Длина**: примерно 2/3 ширины ячейки.
- **Использование**: в ㄱ, ㄷ, ㄸ, ㅏ, ㅓ, ㅣ, ㅐ, ㅔ и многих других.
- **Техника**: равномерное движение слева направо, не торопясь.

#### 수 (su) — вертикальная линия

- **Форма**: прямая линия сверху вниз.
- **Направление**: строго вертикально (или с лёгким отклонением вправо на 2–3°).
- **Длина**: примерно 3/4 высоты ячейки.
- **Использование**: в ㄱ, ㄴ, ㄷ, ㅁ, ㅇ, ㅡ, ㅣ и многих других.
- **Техника**: равномерное движение сверху вниз, равномерное давление.

#### 우 (u) — левая дуга (свечение)

- **Форма**: дуга, идущая слева вниз и затем вправо (похожа на «γ» или «⌐»).
- **Направление**: начинается сверху слева, идёт вниз, затем закручивается вправо.
- **Использование**: в ㄹ, ㅅ, ㅊ, ㄷ (в нижней части).
- **Техника**: плавное движение от верхнего левого угла вниз-вправо, с плавным завершением.

#### 내 (nae) — внутренняя перевязка

- **Форма**: пересечение двух линий внутри символа, похоже на «十» (крест) или «丿」с «一».
- **Направление**: вертикальная линия пересекает горизонтальную внутри символа.
- **Использование**: в ㅈ, ㅍ, ㄷ, ㄲ, ㄸ, ㅃ, ㅆ, ㅉ.
- **Техника**: первая линия — вертикальная, вторая — горизонтальная, пересекаются в центре.

### 3.3 Порядок штрихов (획 순서 / hyeot sunib)

Общие правила порядка написания штрихов:

1. **Слева направо** (왼쪽에서 오른쪽 / oleunjjeseo oenjjeok).
2. **Сверху вниз** (위에서 아래로 / wieseo arilo).
3. **Наружу внутрь** (바깥에서 안으로 / bakkateseo annaero).
4. **Горизонтальная первая** (가로막대 먼저 / garo makdae meonjeo).
5. **Вертикальная пересекает** (세로가 가로를 지름 / seoro-ga garoreul jireum).

## 4. Правила написания согласных (4. Rules for writing consonants)

### 4.1 Общие правила

1. **Каждый согласный начинается с верхней точки или линии.** (각 자음은 위에서 시작합니다 / gag jajeumeun wieseo sijakhabnida.)
2. **Строгается слева направо.** (왼쪽에서 오른쪽으로 획합니다 / oleunjjeseo oenjjeogireul hyeothabnida.)
3. **Вертикальные линии пишутся раньше горизонтальных.** (세로선은 가로선보다 먼저 씁니다 / seoroseoneun garoseon-boda meonjeo sseumnida.)
4. **Кривые линии пишутся после прямых.** (곡선은 직선 뒤에 씁니다 / gokseoneun jeokseun dwe-ssseumnida.)
5. **Внутренние штрихи пишутся после внешних.** (안쪽 획은 바깥 획 뒤에 씁니다 / anjjok hyeoreun bakkat hyeot dwe-ssseumnida.)

### 4.2 Особенности написания каждого согласного

| Согласный | Особенность | Совет |
|-----------|-------------|-------|
| ㄱ | Два штриха: вертикаль + горизонталь | Не делайте горизонталь слишком длинной |
| ㄴ | Вертикаль + диагональ вниз-влево | Диагональ должна быть плавной |
| ㄷ | Три штриха: вертикаль + горизонталь + перекрестие | Перекрестие — последний штрих |
| ㄹ | Три штриха: вертикаль + дуга + лёгкий начальный штрих | Практикуйте дугу отдельно |
| ㅁ | Три штриха: вертикаль + две горизонтали | Две горизонтали одинаковой длины |
| ㅂ | Два штриха: вертикаль + горизонталь | Похож на ㅁ, но без нижней горизонтали |
| ㅅ | Одна кривая линия | Практикуйте плавность кривой |
| ㅇ | Нет штрихов (пустой символ) | Начальная: пустая; финальная: как ㅇ |

## 5. Правила написания гласных (5. Rules for writing vowels)

### 5.1 Классификация гласных

Корейские гласные (모음 / moeum) делятся на три группы по форме:

#### Группа 1: Монофтонги (단모음 / dan moeum)

| Символ | RR | Структура блока | Описание |
|--------|-----|-----------------|----------|
| ㅏ | a | ㅏ = 횡 + 수 | Горизонталь сверху + вертикаль снизу |
| ㅓ | eo | ㅓ = 횡 + 우 | Горизонталь сверху + левая дуга снизу |
| ㅗ | o | ㅗ = 횡 + 원 (circle) | Горизонталь сверху + круг снизу |
| ㅜ | u | ㅜ = 횡 + 원 (circle) | Горизонталь сверху + закрытый круг снизу |
| ㅡ | eu | ㅡ = 횡 + 수 (внутри) | Горизонталь сверху + вертикаль внутри |
| ㅣ | i | ㅣ = 수 + 수 | Две вертикальные линии |

#### Группа 2: Двойные гласные (쌍모음 / ssang moeum)

| Символ | RR | Структура | Описание |
|--------|-----|-----------|----------|
| ㅐ | ae | ㅐ = 횡 + 점 | Горизонталь + точка |
| ㅔ | e | ㅔ = 횡 + точка (нижняя) | Горизонталь + нижняя точка |
| ㅚ | oe | ㅚ = 횡 + 원 + точка | Горизонталь + круг + точка |
| ㅟ | wi | ㅟ = 수 + 원 (точка внутри) | Вертикаль + круг с точкой |
| ㅢ | ui | ㅢ = ㅡ + ㅣ | Две части: ㅡ сверху, ㅣ снизу |

#### Группа 3: Фонологические гласные (순모음 / sun moeum)

| Символ | RR | Структура | Описание |
|--------|-----|-----------|----------|
| ㅑ | ya | ㅑ = 점 + 횡 + 수 | Точка сверху + горизонталь + вертикаль |
| ㅕ | yeo | ㅕ = 점 + 횡 + 우 | Точка + горизонталь + дуга |
| ㅛ | yo | ㅛ = 점 + 횡 + 원 | Точка + горизонталь + круг |
| ㅠ | yu | ㅠ = 점 + 횡 + 원 (закрытый) | Точка + горизонталь + закрытый круг |
| ㅒ | yae | ㅒ = 점 + 횡 + 점 | Точка + горизонталь + точка |
| ㅖ | ye | ㅖ = 점 + 횡 + точка (нижняя) | Точка + горизонталь + нижняя точка |

### 5.2 Правила написания гласных

1. **Гласные в начальной позиции (초성 / choseong)** пишутся внутри квадратной ячейки (네모 칸 / nemo kan).
2. **Горизонтальные линии (횡 / hwang)** располагаются **сверху**.
3. **Вертикальные линии (수 / su)** располагаются **внизу и слева** (для ㅏ, ㅓ) или **справа** (для ㅜ, ㅠ).
4. **Точки (점 / jeom)** ставятся **сверху** перед другими штрихами.
5. **Круг (원 / won)** формируется **снизу** от горизонтальной линии.
6. **Гласная занимает центральную ячейку** (중성 블록 / jungseong beulkeu).

### 5.3 Подробное описание каждой гласной

#### ㅏ a (아)

- **Штрих 1**: горизонтальная линия (횡 / hwang), слева направо, в верхней части ячейки.
- **Штрих 2**: вертикальная линия (수 / su), сверху вниз, начиная от середины горизонтальной, идёт вниз.
- **Форма**: похоже на букву «н» в русском или «丿」с «一».
- **RR**: a
- **Произношение**: [a] (как «а» в русском «мама»)
- **Примеры**: 아버지 (abeoji — отец),나라 (nara — страна), 사과 (sagwa — яблоко)

#### ㅓ eo (어)

- **Штрих 1**: горизонтальная линия (횡 / hwang), слева направо, в верхней части.
- **Штрих 2**: левая дуга (우 / u), начиная от правой части горизонтали, идёт вниз и закручивается.
- **Форма**: похоже на «ω» или «ʌ».
- **RR**: eo
- **Произношение**: [ʌ] (губно-губной средний гласный, между «о» и «ы»)
- **Примеры**: 언어 (eon-eo — язык), 거실 (geosil — гостиная), 법률 (beollyeol — закон)

#### ㅗ o (오)

- **Штрих 1**: горизонтальная линия (횡 / hwang), в верхней части.
- **Штрих 2**: круг (원 / won), нарисованный ниже горизонтали.
- **Форма**: похоже на цифру «8» или «θ» (без верхней линии).
- **RR**: o
- **Произношение**: [o] (как «о» в русском «море»)
- **Примеры**: 오빠 (oppa — старший брат для девушки), 소 (so — корова), 도 (do — 도끼 — топор)

#### ㅜ u (우)

- **Штрих 1**: горизонтальная линия (횡 / hwang), в верхней части.
- **Штрих 2**: закрытый круг (원 / won), нарисованный ниже горизонтали.
- **Форма**: похоже на «U» или «ɔ».
- **RR**: u
- **Произношение**: [u] (как «у» в русском «мур»)
- **Примеры**: 우유 (uyu — молоко), 우산 (usan — зонт), 문화 (munhwa — культура)

#### ㅡ eu (으)

- **Штрих 1**: горизонтальная линия (횡 / hwang), в верхней части.
- **Штрих 2**: вертикальная линия (수 / su), в нижней части, внутри квадрата.
- **Форма**: похожа на «ᅳ» или «ア」в вертикальной ориентации.
- **RR**: eu
- **Произношение**: [ɯ] (задневерхний средний гласный, между «ы» и «у»)
- **Примеры**: 은색 (eunsaek — серебряный), 그릇 (geureut — тарелка), 으르렁 (eureureong — рычание)

#### ㅣ i (이)

- **Штрих 1**: вертикальная линия (수 / su), сверху вниз, слева.
- **Штрих 2**: вертикальная линия (수 / su), сверху вниз, справа (параллельна первой).
- **Форма**: две параллельные вертикальные линии.
- **RR**: i
- **Произношение**: [i] (как «и» в русском «итог»)
- **Примеры**: 이다 (ida — быть), 아이 (ai — ребёнок), 비행기 (bihagki — самолёт)

## 6. Композиция символов (6. Character composition)

### 6.1 Принципы композиции хангыль

Хангыль — это **монослогный алфавит** (음소 문자 / eumso munja), где каждый блок (글자 / geulja) представляет один слог. Блок формируется из:

- **초성 (choseong)** — начальный согласный (начальный согласный)
- **중성 (jungseong)** — средняя гласная (средняя гласная)
- **종성 (jongseong)** — конечный согласный (конечный согласный / 받침 / batchim)

### 6.2 Структура блока

```
  ┌──────────────┐
  │  초성  중성  │   ← 2 строки, 2 ячейки (верхняя строка: 초성+중성)
  │              │
  │     종성     │   ← Нижняя строка: 종성 (если есть)
  └──────────────┘
```

Или в трёхчастном формате:

```
  ┌───────────────────┐
  │  초성  │ 중성  │  ← Начальный + Гласная
  │        │        │
  │        │ 종성  │  ← Конечный (если есть)
  └───────────────────┘
```

### 6.3 Правила размещения компонентов

| Компонент | Позиция | Описание |
|-----------|---------|----------|
| 초성 (choseong) | Верхняя левая ячейка | Начальный согласный |
| 중성 (jungseong) | Верхняя правая ячейка | Средняя гласная |
| 종성 (jongseong) | Нижняя ячейка (под 중성) | Конечный согласный / 받침 |

## 7. Структура слогового блока (7. Syllable block structure / 초중종)

### 7.1 Что такое 초중종

Слоговый блок хангыль состоит из трёх частей:

- **초성 (초성 / choseong)** — начальный согласный (начальный согласный)
- **중성 (중성 / jungseong)** — средняя гласная (средняя гласная)
- **종성 (종성 / jongseong)** — конечный согласный / 받침 (конечный согласный / 받침)

### 7.2 Типы слоговых блоков

| Тип | Структура | Пример | Описание |
|-----|-----------|--------|----------|
| CV | 초성 + 중성 | 가 (ga) | Два компонента: согласный + гласная |
| CVV | 초성 + 중성 (двойная гласная) | 곰 (gom — медведь) | Три компонента (초성 + ㅗ + ㅛ) |
| CVC | 초성 + 중성 + 종성 | 값 (gat — цена) | Три компонента с 받침 |
| CCV | 종성 이전 블록 + 초성 | 김치 (kimchi) | Два блока: 김 + 치 |
| CVCC | 초성 + 중성 + 종성 + 종성 | 꽃 (kkot — цветок) | 받침 ㄱ + ㄱ |

### 7.3 Правила формирования блоков

1. **초성 всегда в верхнем левом углу** (항상 왼쪽 위 모서리에 / hangang oliveun jwile obeo jebal-e).
2. **중성 пишется справа от 초성а** (중성은 초성의 오른쪽 / jungseong-eun choseong-ui oenjjeog-e).
3. **종성 пишется под 중성** (종성은 중성 아래 / jongseong-eun jungseong arae-e).
4. **Когда нет 종성, нижняя ячейка остаётся пустой** (종성이 없으면 아래 칸은 비웁니다 / jongseong-i eopsumyeon arae kan-eun biwmnida).
5. **Размер компонентов пропорционален** (구성 요소의 크기는 비례합니다 / guseong yoso-ui keureuneun biryeohabnida).

### 7.4 Визуальное представление

```
  ┌────────────────┬────────────────┐
  │                │                │
  │   초성         │   중성         │
  │   (choseong)   │   (jungseong)  │
  │                │                │
  ├────────────────┼────────────────┤
  │                │                │
  │   종성         │   (пусто)      │
  │   (jongseong)  │   (jongseong   │
  │                │    absent)     │
  │                │                │
  └────────────────┴────────────────┘
```

Пример: **한** (han — Корея)

```
  ┌──────────┬──────────┐
  │          │          │
  │  ㅎ      │  ㅏ      │
  │ (hieut)  │    a     │
  │          │          │
  ├──────────┼──────────┤
  │          │          │
  │  ㄴ      │          │
  │ (nieop)  │          │
  │          │          │
  └──────────┴──────────┘
```

## 11. Частые ошибки письма (11. Common writing mistakes)

### 11.1 Обзор частых ошибок

Russian speakers (러시아 학습자 / Reussiao hakgsaeng) часто допускают следующие ошибки при письме на корейском:

| № | Ошибка | Причина | Решение |
|---|--------|---------|---------|
| 1 | Путаница ㅂ/ㅍ | Влияние русского «б/п» | ㅂ = [b], ㅍ = [p] (всегда беззвучный) |
| 2 | Путаница ㄷ/ㅌ | Влияние русского «д/т» | ㄷ = [d], ㅌ = [t] (всегда беззвучный) |
| 3 | Путаница ㄱ/ㅋ | Влияние русского «г/к» | ㄱ = [g], ㅋ = [k] (всегда беззвучный) |
| 4 | Пропуск 받침 | Незнание правил placing | Изучить все 27 받침 |
| 5 | Неверный порядок штрихов | Русское письмо (С-по-А) | Корейский: сверху вниз, слева направо |
| 6 | Путаница ㅏ/ㅐ | Оба звучат как «а» | ㅏ = [a], ㅐ = [ɛ] |
| 7 | Путаница ㅓ/ㅔ | Оба звучат как «э» | ㅓ = [ʌ], ㅔ = [e] |
| 8 | Неверная форма ㅜ/ㅠ | ㅜ не включает точку | ㅜ — без точки, ㅠ — с точкой |
| 9 | Неверная форма ㄹ | Слишком прямая или изогнутая | Практиковать дугу 우 |
| 10 | Пропуск точки в ㅈ | Забывают точку сверху | ㅈ = 수 + 횡 + 점 |

### 11.2 Детальное описание ошибок

#### Ошибка 1: Путаница ㅂ и ㅍ

> ❌ **Неправильно**: 밥을 써요 → ㅂ = [p]
> ✅ **Правильно**: 밥을 써요 → ㅂ = [b]
> ✅ **Правильно**: 피스를 써요 → ㅍ = [p]

**Объяснение**: В русском языке «б» и «п» различаются по озвучению. В корейском ㅂ означает [b] (озвученный), а ㅍ — всегда [p] (неозвученный). Это ключевое различие!

**Дрилл**: Напишите 10 слов, используя ㅂ и ㅍ поочерёдно:

```
밥, 불, 봄, 바다, 버스 / 피스, 포도, 편지, 풍부, 픽
```

#### Ошибка 2: Путаница ㄷ и ㅌ

> ❌ **Неправильно**: 학교을 → ㄷ = [t]
> ✅ **Правильно**: 학교을 → ㄷ = [d]
> ✅ **Правильно**: 타업을 → ㅌ = [t]

**Объяснение**: ㄷ = [d] (озвученный), ㅌ = [t] (всегда неозвученный). Не путайте с русскими «д» и «т»!

**Дрилл**:

```
다, 도, 딸, 땅 / 타, 터, 튜브, 틀
```

#### Ошибка 3: Путаница ㄱ и ㅋ

> ❌ **Неправильно**: 가게을 → ㄱ = [k]
> ✅ **Правильно**: 가게을 → ㄱ = [g]
> ✅ **Правильно**: 카레을 → ㅋ = [k]

**Объяснение**: ㄱ = [g] (озвученный), ㅋ = [k] (всегда неозвученный).

**Дрилл**:

```
가, 거, 길, 그림 / 카, 케이크, 코, 크다
```

#### Ошибка 4: Неправильное размещение 받침

> ❌ **Неправильно**: 한국을 → 받침 ㄹ в неправильном месте
> ✅ **Правильно**: 한국을 → 받침 ㄹ под 中성 ㅏ

**Объяснение**: 받침 (конечный согласный) всегда помещается в нижнюю ячейку блока, под 중성. Never forget this rule!

**Дрилл**: Напишите правильные блоки с 받침:

```
강, 감, 값, 꽃, 국, 숭, 핑, 뭇
```

#### Ошибка 5: Неверный порядок штрихов

> ❌ **Неправильно**: Пишут ㄷ слева направо (как в русском)
> ✅ **Правильно**: Пишут ㄷ сверху вниз, затем горизонталь, затем перекрестие

**Объяснение**: Порядок штрихов в хангыль: сверху вниз, слева направо, снаружи внутрь. Это отличается от русского алфавита!

| Размер и пропорции | Идеальные | Хорошие | Неравномерные | Сильно неравномерные | Нечитаемые |
| Расположение в блоке | Идеально | Почти идеально | Иногда смещены | Часто смещены | Хаотично |
| Скорость | Уверенная и быстрая | Уверенная | Медленная, но аккуратная | Медленная и неуклюжая | Очень медленная |
| **Итого** | **25** | **20** | **15** | **10** | **5** |

### 12.5 Самооценка: «Я могу...»

Отметьте, можете ли вы:

- [ ] Написать все 14 согласных от памяти
- [ ] Написать все 17 гласных от памяти
- [ ] Составить CV-блок (например, 가, 나, 다)
- [ ] Составить CVC-блок (например, 강, 감, 값)
- [ ] Написать 50 корейских символов подряд без ошибок
- [ ] Написать своё имя на корейском
- [ ] Написать простое предложение (например, 나는 학생입니다)
- [ ] Различить ㅂ/ㅍ, ㄷ/ㅌ, ㄱ/ㅋ по письму
- [ ] Правильно разместить 받침 в блоке
- [ ] Писать аккуратно и быстро
