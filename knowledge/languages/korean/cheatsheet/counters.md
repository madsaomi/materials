# Числительные и счётные суффиксы

> Две системы чисел + полный список счётных слов (звукоподражательные/счётные слова корейского: 개념수사).

---

## 1. Числа: когда какая система

| Использование | Система | Пример |
|---------------|---------|--------|
| Часы (не время суток) | исконная | 세 시 — 3 часа |
| Счёт предметов/людей | исконная | 세 명 — 3 человека |
| Возраст | исконная | 스무 살 — 20 лет |
| Цены, деньги | сино | 오천 원 — 5000 вон |
| Минуты | сино | 십오 분 — 15 минут |
| Даты (месяц/день/год) | сино | 3월 15일 — 15 марта |
| Номера телефонов | сино | 010-… |
| Математика | сино | 이 더하기 이 = 사 |
| Точное время (час+мин) | искон.+сино | 세 시 십오 분 |
| Порядок (слова, корпус) | сино (제일/첫째 и т.д.) | 첫 번째 — первый |

## 2. Исконно корейские числа (1–99)

| Число | Хангыль | Транскр. | Перед счётным словом |
|-------|---------|----------|----------------------|
| 1 | 하나 | хана | **한** (хан) |
| 2 | 둘 | туль | **두** (ту) |
| 3 | 셋 | сет | **세** (сэ) |
| 4 | 넷 | нет | **네** (нэ) |
| 5 | 다섯 | тасот | 다섯 |
| 6 | 여섯 | ёсот | 여섯 |
| 7 | 일곱 | ильгоп | 일곱 |
| 8 | 여덟 | ёдоль | 여덟 |
| 9 | 아홉 | ахоп | 아홉 |
| 10 | 열 | ёль | 열 |

**Важно:** числа 1–4 меняют форму перед счётным словом: 한 명, 두 병, 세 개, 네 명. Аналогично «스물» → «스무» перед счётным: 스무 살 (20 лет).

## 3. Сино-корейские (китайские) числа

| Число | Хангыль | Число | Хангыль |
|-------|---------|-------|---------|
| 0 | 영 / 공 | 6 | 육 (юк) |
| 1 | 일 (иль) | 7 | 칠 (чхиль) |
| 2 | 이 (и) | 8 | 팔 (паль) |
| 3 | 삼 (сам) | 9 | 구 (ку) |
| 4 | 사 (са) | 10 | 십 (сип) |
| 5 | 오 (о) | 100 | 백 (пэк) |

| Состав | Хангыль | Транскр. |
|--------|---------|----------|
| 11 | 십일 | сибиль |
| 12 | 십이 | сиби |
| 15 | 십오 | сибо |
| 20 | 이십 | исип |
| 25 | 이십오 | исибо |
| 99 | 구십구 | кусипку |
| 100 | 백 | пэк |
| 123 | 백이십삼 | пэгисипсам |
| 345 | 삼백사십오 | сампэксасибо |
| 1000 | 천 | чхон |
| 1999 | 천구백구십구 | чхонкупэк кусипку |
| 10000 | 만 | ман |
| 100000 | 십만 | симман |

## 4. Счётные слова (counter) — список

Порядок слов: **N + исконное число + счётный суффикс** (사과 세 개). Суффиксы с сино-числами — только с сино.

### 4.1 Люди и существа

| Суффикс | С чем | Пример |
|---------|-------|--------|
| 명 (мён) | человек (неформ.) | 친구 두 명 — два друга |
| 분 (пун) | человек (вежл.) | 고객 세 분 — три клиента |
| 마리 (мари) | животные | 강아지 두 마리 — два щенка |
| 마리 | рыба | 물고기 세 마리 |
| 사 (са) | птицы | 새 두 사 — редк., обычно 마리 |

### 4.2 Предметы и вещи

| Суффикс | Значение | Пример |
|---------|----------|--------|
| 개 (ке) | универсальный предмет | 사과 다섯 개 — 5 яблок |
| 장 (чан) | листы/плоские | 종이 세 장 — 3 листа бумаги |
| 권 (квон) | книги | 책 두 권 — 2 книги |
| 자루 (чару) | длинные рукоятки | 연필 한 자루 — один карандаш |
| 병 (пён) | бутылки | 물 두 병 — 2 бутылки воды |
| 캔 (кхен) | банки | 콜라 한 캔 — банка колы |
| 봉지 (пончжи) | пакеты | 과자 두 봉지 — 2 пакета чипсов |
| 통 (тхон) | контейнеры/бочки | 물 한 통 — ведро воды |
| 묶음 (муккым) | связки | 채소 한 묶음 |
| 다발 (табаль) | букет/связка | 꽃 한 다발 — букет цветов |
| 송이 (сони) | соцветия/грозди | 장미 세 송이 — 3 розы |
| 조각 (чогаг) | куски | 빵 한 조각 — ломоть хлеба |
| 켤레 (кхёллё) | пары обуви/носков | 신발 한 켤레 — пара обуви |
| 벌 (поль) | костюмы/компл. | 옷 두 벌 — два комплекта одежды |
| 채 (чхэ) | дома/здания | 집 한 채 — один дом |
| 대 (тэ) | машины/аппараты | 자동차 두 대 — 2 машины |
| 번 (пон) | разы | 한 번, 두 번 — раз, два |
| 통 (тхон) - повторить | звонки | 전화 한 통 — один звонок |
| 부 (пу) | пары очков/веер | 안경 한 부 — очки |
| 장 (чан) | билеты | 표 두 장 — 2 билета |

### 4.3 Еда и посуда

| Суффикс | Значение | Пример |
|---------|----------|--------|
| 그릇 (кырыт) | миски/тарелки | 밥 한 그릇 — миска риса |
| 접시 (чопси) | блюда | 김치 한 접시 |
| 잔 (чан) | чашки/бокалы | 커피 한 잔 — чашка кофе |
| 공기 (конги) | порции риса | 공기 두 그릇? — 밥 두 공기 |
| 인분 (инбун) | порции еды | 파전 두 인분 — 2 порции |
| 판 (пхан) | подносы/блинные | 청계 소 틀? 칼국수 한 판 |
| 쪽 (ччок) | дольки/страницы | 마늘 한 쪽 — зубчик чеснока |
| 포기 (пхоги) | кочаны | 배추 한 포기 — кочан капусты |
| 개수 (кэссу) | количество (форм.) | 몇 개입니까? |

### 4.4 Время (важно!)

| Суффикс | Система | Значение | Пример |
|---------|---------|----------|--------|
| 시 (си) | исконная | час | 두 시 — 2 часа (ночи/дня) |
| 분 (пун) | сино | минута | 십오 분 — 15 минут |
| 시간 (сиган) | исконная | час (продолж.) | 두 시간 — 2 часа времени |
| 초 (чхо) | сино | секунда | 삼십 초 — 30 секунд |
| 일 (иль) | сино | день | 사월 오일 — 5 апреля |
| 주일 (чуиль) | сино | неделя | 두 주일 (или 이 주) |
| 개월 (квеволь) | сино | месяц (продолж.) | 두 개월 — 2 месяца |
| 달 (таль) | исконная | месяц (прош.) | 두 달 전에 — 2 месяца назад |
| 년 (нён) | сино | год | 이천이십사 년 — 2024 год |
| 살 (саль) | исконная | возраст | 스무 살 — 20 лет |
| 세 (сэ) | сино | возраст (форм.) | 나이가 30세? — 연세 (о вежл.) |
| 번째 (понччэ) | (порядок) | -й раз | 첫 번째 — первый |
| 등 (тын) | сино | место (рейтинг) | 1등 — первое место |
| 층 (чхын) | сино | этаж | 삼 층 — 3-й этаж |
| 회 (хве) | сино | раз | 두 회 — дважды |
| 월 (воль) | сино | месяц года | 구월 — сентябрь |
| 요일 (ёиль) | — | день недели | 월요일 — понедельник |

## 5. Время на часах (правильная комбинация)

| Время | Корейский | Чтение |
|-------|-----------|--------|
| 1:00 | 한 시 | хан си |
| 1:05 | 한 시 오 분 | хан си о пун |
| 2:30 | 두 시 반 (30 мин) | ту си пан |
| 3:15 | 세 시 십오 분 | сэ си сибо пун |
| 4:00 | 네 시 | нэ си |
| 6:00 | 여섯 시 | ёсот си |
| 7:30 | 일곱 시 삼십 분 | ильгоп си самсип пун |
| 8:15 | 여덟 시 십오 분 | ёдоль си сибо пун |
| 9:45 | 아홉 시 사십오 분 | ахоп си сасибо пун |
| 10:00 | 열 시 | ёль си |
| 11:00 | 열한 시 | ёльхан си |
| 12:00 | 열두 시 | ёльту си |

**반 (пан)** — «половина»: 아침 7시 반 — 7:30 утра.
**Утро/день/ночь:** 오전 (до полудня), 오후 (после полудня), 밤 (ночь): 밤 11시 — 11 вечера.

## 6. Даты

| Компонент | По-корейски | Пример |
|-----------|-------------|--------|
| Год | 년 (сино) | 2024년 = 이천이십사년 |
| Месяц | 월 (сино) | 3월 = 삼월 |
| День | 일 (сино) | 15일 = 십오일 |
| Дата целиком | 2024년 3월 15일 | чхон-ку-пэк-исип-са нён сам воль сибо иль |

**Месяцы:** 1월•일월(ильволь), 2월•이월(иволь), 3월•삼월(самволь), 4월•사월(саволь), 5월•오월(оволь), 6월•유월(юволь!), 7월•칠월(чхирволь), 8월•팔월(пхальволь), 9월•구월(куволь), 10월•시월(сиволь!), 11월•십일월(сибильволь), 12월•십이월(сибиволь).

**Исключения с ассимиляцией:** 유월 (6月), 시월 (10月) — почему: у/си + 월 → потеря औ звука.

**Неделя:** 그 주 — на той неделе; 담 주 — на следующей; 지난주 — прошлая неделя.
