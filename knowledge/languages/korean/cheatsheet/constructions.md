# 100+ грамматических конструкций — таблица-шпаргалка

> Каждая строка: конструкция → значение → пример (хангыль, транскрипция, перевод).

Кратность строк: в таблицах 110+ конструкций. Группы по функциям.

---

## A. Повелительные и просьбы

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)세요 | пожалуйста, сделайте | 앉으세요 (анджусэё) — присаживайтесь |
| 아/어 주세요 | сделайте для меня | 도와주세요 (товаджусэё) — помогите |
| 아/어 드리세요 | сделайте (уваж.) | 말씀해 주세요 (мальссымане джусэё) — скажите |
| 주시겠어요? | не могли бы вы? | 들어와 주시겠어요? (дыро ва джюсигессёё) |
| (으)ㄹ까요? | (можно?) мне сделать? | 창문을 닫을까요? (чханмуныль тадыльккаё) — закрыть окно? |
| 지 마세요 | не делайте | 가지 마세요 (каджи масэё) — не уходите |
| (으)ㅂ시다 | давайте (форм.) | 식사합시다 (сиксахапсида) — давайте поедим |
| (으)ㄹ래요? | хочешь? (интимно) | 커피 마실래요? (кхопи масиллерё) |
| 게 하다 | заставить (каузатив) | 기다리게 해요 (кидариге хэё) — заставляю ждать |
| 아/어 버리다 (+해 버려요) | сделать до конца | 먹어 버렸어요 (мого порёссоё) — съел всё |

## B. Разрешение и запрет

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 아/어도 되다 | можно | 앉아도 돼요 (анджадо твэё) — можно сесть |
| (으)면 안 되다 | нельзя | 여기서 담배 피면 안 돼요 (ёнгисо тамбэ пхимён ан твэё) |
| 아/어도 괜찮다 | можно/нормально | 늦어도 괜찮아요 (ныджидо квэнчханаё) — можно опоздать |
| 안 아/어도 되다 | не обязательно | 안 가도 돼요 (ан кадо твэё) — можно не идти |
| (으)ㄹ 필요가 있다/없다 | иметь/не иметь смысл | 갈 필요 없어요 (каль пхирё опсоё) — не надо идти |
| 지 않으면 안 되다 | иначе нельзя (необх.) | 가기지 않으면 안 되요 → 가지 않으면 안 돼요 (каджи анхымён ан твэё) — обязан |

## C. Умение и возможность

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)ㄹ 수 있다 | мочь/уметь | 한국어를 할 수 있어요 (хангугорыль халь су иссоё) |
| (으)ㄹ 수 없다 | не мочь | 못 갈 수 있어요? нет — 갈 수 없어요 (каль су опсоё) |
| (으)ㄹ 줄 알다/모르다 | уметь/не уметь (навык) | 수영할 줄 알아요 (суёнхаль чуль араё) — умею плавать |
| (으)ㄹ 수밖에 없다 | нет другого выхода | 참을 수밖에 없어요 (чхамыль субике опсоё) |
| (으)ㄹ 리가 없다 | не может быть, что | 그럴 리가 없어요 (кыроль рига опсоё) |

## D. Долженствование

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 아/어야 하다 | должен | 공부해야 해요 (конбухэя хэё) — надо учиться |
| 아/어야 되다 | должен (разг.) | 가야 돼요 (кая твэё) — надо идти |
| 지 말아야 하다 | не должен | 늦지 말아야 해요 (нытчи марая хэё) — не должен опаздывать |
| 아/어야만 하다 | непременно должен | 직접 가야만 해요 (чикчоп каяман хэё) |
| (으)ㄹ 의무가 있다 | обязанность (форм.) | 지킬 의무가 있어요 (чикиль ыймуга иссоё) |

## E. Условие и «если»

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)면 | если | 비가 오면 (пига омён) — если пойдёт дождь |
| 았/었으면 | если бы (в прошлом) | 알았으면 (арассымын) — если бы знал |
| (으)면 좋겠다 | хотелось бы | 방학이었으면 좋겠어요 (панхагииэссымын чохкессоё) |
| 아/어야 (만) | только если | 노력해야 성공해요 (норёкхэя сонгонхэё) |
| 아/어도 | даже если | 비가 와도 (пига вадо) — даже если дождь |
| -든지 -든지 | будь то… или | 커피든지 차든지 (кхопидынчжи чхадынчжи) — кофе или чай |
| 아/어서라도 | пусть даже ценой | 무리해서라도 (мурихессорадо) — даже превозмогая |

## F. Цель и намерение

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)러 가다/오다 | идти (чтобы) | 밥 먹으러 가요 (пап могыро каё) — иду есть |
| (으)려고 | чтобы | 사러 왔어요 (саро вассоё) — пришёл купить |
| (으)려고 하다 | намерен | 이사하려고 해요 (исахарёго хэё) — собираюсь переезжать |
| 기 위해서 | ради | 성공하기 위해서 (сонгонхаги вихесо) — ради успеха |
| (으)ㄹ 계획이다 | планирую | 여행할 계획이에요 (ёхэнхаль кехвегиэё) |
| (으)ㄹ 예정이다 | по плану | 출발할 예정이에요 (чхульбальхаль йеджонъиэё) |
| 기로 하다 | решить | 그만두기로 했어요 (кымандугиро хэссоё) — решил бросить |
| 려던 참이다 | как раз собирался | 가려던 참이에요 (карёдон чхамиэё) |

## G. Причина

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)니까 | потому что (обоснование) | 비가 오니까 (пига оника) — раз идёт дождь |
| 아/어서 | из-за (причина) | 배가 아파서 (пэга апасо) — живот болит, поэтому |
| 때문에 | из-за | 비 때문에 (пи ттэмуне) — из-за дождя |
| 기 때문에 | потому что (книжн.) | 늦었기 때문에 (ныджотки ттэмуне) — потому что опоздал |
| 거든요 | видишь ли (объяснение) | 시간이 없거든요 (сигани опкогынднё) |
| 잖아요 | ведь (апелляция) | 약속했잖아요 (яксокхэтчаннаё) — ведь договорились |
| 려 | хотя и… но (недовольство) | 사려고 샀지만 (сарёго сатчиман) — хотя купил |
| 아/어서 그런지 | возможно из-за | 날씨가 더워서 그런지 (нальссига товосо кырынчи) |

## H. Время и последовательность

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)ㄹ 때 | когда (момент) | 어릴 때 (ориль ттэ) — когда был ребёнком |
| 기 전에 | до того как | 자기 전에 (чхаги чонэ) — перед сном |
| (으)ㄴ 후에 | после того как | 밥을 먹은 후에 (пабыль могын хуэ) — после еды |
| 고 나서 | после того как | 씻고 나서 (сситкко насо) — после умывания |
| 아/어서 | и затем | 일어나서 씻어요 (иронасо ссиссоё) |
| 자마자 | как только | 오자마자 (оджамаджа) — как только придёт |
| (으)ㄴ 지 … 되다 | с тех пор как | 세 달 됐어요 (сэ таль твэссоё) — уже 3 месяца |
| 는 동안 | в течение | 잠자는 동안 (чамчжанын тонъан) — пока сплю |
| 는 중이다 | в процессе | 요리하는 중이에요 (ёриханын чунгиэё) |
| (으)ㄹ 때마다 | каждый раз когда | 들을 때마다 (дырыль ттэмада) |
| 아/어 놓다 | заранее сделать | 미리 예약해 놓았어요 (мири йеягхе ноассоё) |
| 아/어 두다 | оставить (на будущее) | 돈을 모아 두었어요 (тоныль моа дуоссоё) |
| 아/어 보다 | попробовать сделать | 입어 보세요 (ибо посэё) — примерьте |

## I. Опыт и воспоминания

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (으)ㄴ 적이 있다 | иметь опыт | 한국에 가 본 적이 있어요 (хангуге ка бон чоги иссоё) |
| (으)ㄴ 적이 없다 | никогда не | 처음이에요 (чхоымиэё) — впервые |
| (으)ㄹ 뻔하다 | чуть не | 넘어질 뻔했어요 (номоджиль ппонхэссоё) — чуть не упал |
| 아/어 버리다 | каюсь/окончательно | 잊어버렸어요 (иджоборёссоё) — забыл совсем |
| 고 말다 | в итоге сделал | 참 고 말았어요? — не выдержал |
| 았/었던 | тот, что когда-то | 읽었던 책 (илготтон чхэк) — книга, что читал |
| (으)ㄴ 김에 | заодно | 오는 김에 (онын киме) — раз уж иду |

## J. Желание и предпочтение

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 고 싶다 | хочу | 만나고 싶어요 (маннаго сипоё) — хочу встретиться |
| 고 싶어하다 | он хочет | 아이가 자고 싶어해요 (аига чаго сипохэё) |
| (으)ㄹ래요 | хочу (простое) | 저는 김치 먹을래요 (чонын кимчхи могыльлерё) |
| (으)ㄹ까 (생각하다) | думаю, может | 갈까 생각 중이에요 (калькка сэнгак чунгиэё) |
| 기를 원하다 | желать (форм.) | 도움을 원해요 (томумыль вонхэё) |

## K. Последовательное/одновременное

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 고 | и (перечисление) | 사과를 사고 먹었어요 (сагварыль саго могыссоё) |
| 고 … 고 | и то и другое | 읽고 쓰고 해요 (икткко ссыгко хэё) |
| 거나 | или | 마시거나 먹을 거예요 (масигона могыль гоиё) |
| 면서 | одновременно | 노래를 부르면서 걸어요 (норэрыль пурымёнсо короё) |
| 다가 | пока… вдруг | 걷다가 (коттага) — шёл и вдруг |
| 는데 | а/но/в то время | 날씨가 좋은데 (нальссига чоындэ) — погода хорошая, и… |
| 지만 | но | 비싸지만 (писсаджиман) — дорого, но |
| 는데요 (конец) | однако (сожалею) | 아직 몰라요… 시간이 없는데요 (сигани опнындэё) |
| (으)ㄴ/는 것 같다 | кажется, что | 될 것 같아요 (твэль кот катаё) — похоже получится |
| 아/어 보이다 | выглядит | 젊어 보여요 (чольмо поёё) — выглядишь моложе |
| (으)ㄹ 듯하다 | похоже | 성공할 듯해요 (сонгонхаль дытхэё) |

## L. Чужая речь и мнение

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 다고 하다 | слышал, что | 내일 온다고 해요 (нэиль ондаго хэё) |
| 라고 하다 (имя) | имя/называется | 수진이라고 해요 (суджинираго хэё) |
| (이)라고 하다 | говорят, что… | 학생이라고 해요 (хаксэнъиранго хэё) |
| 는대요 | говорят, что (разг.) | 바쁘대요 (паппыдэё) |
| 대요 / 냬요 | говорят (пересказ.) | 온대요 (ондэё) — сказали, придёт |
| 거든요 (18) | (уже в G) | — |
| 았/었겠다 | наверное, был(о) | 피곤했겠어요 (пхигонхэткес’соё) — наверное устали |
| (으)ㄹ 텐데 | наверное… ведь | 싫을 텐데 (сирыль тхэндэ) — наверное не захочет |
| (으)ㄹ까 봐 | боюсь, что | 울까 봐 (улькка пва) — боюсь заплакать |
| 는 바람에 | из-за неожиданного | 비 오는 바람에 (пи онын параме) |

## M. Именная связка / определение (атрибуты)

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| (명사) + 를/을 좋아하다 | любить N | 피자를 좋아해요 (пхиджарыль чоахэё) |
| -(으)ㄴ/는 소리 | звук | 우는 소리 (унын сори) — плач |
| -(으)ㄴ 후, -(으)ㄴ 전 | до/после | 일주일 전에 (ильджуиль чонэ) — неделю назад |
| 대신에 | вместо | 커피 대신에 (кхопи тэсине) |
| 뿐만 아니라 | не только… но и | 맛있을 뿐만 아니라 (масиссыль ппунман анира) |
| 에 따라 | в зависимости от | 사람에 따라 (сараме ттара) |
| 으로 인해 | вследствие | 사고로 인해 (сагоры инхэ) |
| 을/를 포함해서 | включая | 택배비 포함해서 (тхэкпэби похамхесо) |
| (이)라도 | хотя бы/ даже’ | 주말이라도 (чумарирадо) — хотя бы в выходные |

## N. Количество / степень

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 가장 / 제일 | самый | 제일 좋아해요 (чеиль чоахэё) |
| 더 | более / ещё | 더 주세요 (то чусэё) — дайте ещё |
| 조금씩 | понемногу | 조금씩 먹어요 (чогымссик могё) |
| 너무 | слишком | 너무 비싸요 (ному писсаё) |
| 아주 | очень | 아주 맛있어요 (ажу масиссоё) |
| 정말 | действительно | 정말 좋아요 (чонмаль чоаё) |
| 거의 | почти | 거의 다 됐어요 (коый та твэссоё) |
| 좀 더 | немного ещё | 좀 더 봐요 |
| 몇 + счёт. суф. | сколько | 몇 명 왔어요? (мёд мён вассоё) |

## O. Прочее (союзы в начале предложения)

| Слово | Значение | Пример |
|-------|----------|--------|
| 그래서 | поэтому | 그래서 늦었어요 (кырэсо ныджоссоё) |
| 그런데 | однако/а | 그런데 뭐예요? (кырындэ мвоеё) |
| 그리고 | и затем | 그리고 음악을 들어요 |
| 그러면 | тогда | 그러면 같이 가요 (кырымён катхи каё) |
| 하지만 | но | 하지만 어려워요 (хачхиман орёвоё) |
| 아니면 | или | 아니면 걷자 (анимён котча) |
| 왜냐하면 | потому что | 왜냐하면 시간이 없거든요 (вэняхамён сигани опкогыднё) |
