# Корейский — Грамматическая шпаргалка (1 страница)

## Частицы
```
이/가 (и/га) — субъект           은/는 (ын/нын) — тема
을/를 (ыль/рыль) — объект        에 (э) — место/время
에서 (эсо) — действие в/из       으로/로 (ыро/ро) — направление/инструмент
과/와 (ква/ва) — и/с              하고 (хаго) — и/с (разг.)
도 (то) — тоже                   만 (ман) — только
부터 (путхо) — с/от              까지 (ккаджи) — до
의 (ый) — принадлежность         에게 (эге) — кому (человеку)
한테 (хантхэ) — кому (разг.)     께 (кке) — кому (уваж.)
```

## Формальность (конечные окончания)

| Уровень | Форма | Пример |
|---------|-------|--------|
| Высокий формал | ㅂ니다/습니다 | 합니다 |
| Высокий неформ | 아/어요 | 해요 |
| Низкий | 다/한다 | 한다 |
| Низкий неформ | 아/어 | 해 |

## Спряжение глаголов

### Правильные

| Словарная | 해요 | ㅂ니다 | прош. | отрицание |
|-----------|------|--------|-------|-----------|
| 가다 (идти) | 가요 | 갑니다 | 갔어요 | 안 가요 |
| 먹다 (есть) | 먹어요 | 먹습니다 | 먹었어요 | 안 먹어요 |
| 공부하다 (уч.) | 공부해요 | 공부합니다 | 공부했어요 | 안 공부해요 |
| 읽다 (читать) | 읽어요 | 읽습니다 | 읽었어요 | 안 읽어요 |
| 마시다 (пить) | 마셔요 | 마십니다 | 마셨어요 | 안 마셔요 |

### Неправильные

| Тип | Правило | Пример |
|-----|---------|--------|
| ㅂ-непр | ㅂ→우/오 | 돕다→도와요, 춥다→추워요 |
| ㄷ-непр | ㄷ→ㄹ | 듣다→들어요, 걷다→걸어요 |
| 르-непр | 르→ㄹ + ㄹ라 | 모르다→몰라요, 빠르다→빨라요 |
| ㅅ-непр | ㅅ→Ø | 낫다→나아요, 짓다→지어요 |
| ㅎ-непр | ㅎ→Ø | 빨갛다→빨개요, 그렇다→그래요 |

## Числа

### Синокорейские (количество, минуты, даты)
```
일 이 삼 사 오 육 칠 팔 구 십
11=십일, 20=이십, 30=삼십, 100=백, 1000=천
```

### Исконные (часы, счёт, возраст)
```
하나(한) 둘(두) 셋(세) 넷(네) 다섯 여섯 일곱 여덟 아홉 열
20=스물, 30=서른, 40=마흔, 50=쉰
```

## Основные конструкции

| Конструкция | Значение | Пример |
|------------|----------|--------|
 | (으)려면 | если хотите | 가려면 |
| (으)세요 | пожалуйста(сд.) | 앉으세요 |
| 아/어도 되다 | можно | 앉아도 돼요 |
| (으)면 안 되다 | нельзя | 앉으면 안 돼요 |
| 아/어 주세요 | сделайте для меня | 도와주세요 |
| (으)ㄹ 거예요 | будущее | 갈 거예요 |
| 아/어 보다 | пробовать | 먹어 봐요 |
| (으)ㄹ 수 있다 | мочь | 할 수 있어요 |
| (으)ㄹ 수 없다 | не мочь | 할 수 없어요 |
| 아/어야 하다 | должен | 가야 해요 |
| 지만 | но | 비싸지만 |
| (으)니까 | потому что | 바쁘니까 |
| 고 | и | 하고 있어요 |

## Время

```
# Часы (исконные) + Минуты (сино)
1:00 = 한시       1:05 = 한시 오분
2:30 = 두시 반     3:15 = 세시 십오분
```

## Дни недели
```
월요일 — пн     화요일 — вт     수요일 — ср
목요일 — чт     금요일 — пт     토요일 — сб
일요일 — вс
```

## Вопросительные слова
```
누구 (нугу) — кто            무엇/뭐 (муот/мво) — что
어디 (оди) — где               언제 (ондже) — когда
왜 (вэ) — почему               어떻게 (оттокхе) — как
얼마 (ольма) — сколько (цена)   몇 (мёт) — сколько (число)
```

