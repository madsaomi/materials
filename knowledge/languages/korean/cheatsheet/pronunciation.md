# Хангыль и произношение — правила ассимиляции

> Дополнение к основной шпаргалке: как реально читать корейские слова и почему буквы «меняют звук».

Транскрипция в этом файле: русская (кириллица) + МФА в квадратных скобках. Условные обозначения: `받침` — конечная согласная слога, `Ø` — пропуск / выпадение звука.

---

## 1. Слоговая структура

Корейский слог записывается одним блоком: (C) + V + (C).

| Схема | Пример | Разбор |
|-------|--------|--------|
| CV | 가 | ㄱ(к) + ㅏ(а) → ка |
| CVC | 간 | ㄱ + ㅏ + ㄴ → кан |
| V | 아 | Ø + ㅏ → а |
| VC | 안 | Ø + ㅏ + ㄴ → ан |
| CCV | 좌 | ㅈ + ㅘ(ва) → чва |
| CVCC | 값 | ㄱ + ㅏ + ㅂ + ㅅ → кап (читается [캅]) |

**Ключевые факты:**
- `ㅇ` в начале слога — **немой знак** (не читается). В конце слога — носовой **нг** [ŋ].
- У слога может быть **две и даже три концевые согласные** (받침: ㄳ, ㄵ, ㄶ, ㄺ, ㄻ, ㄼ, ㄽ, ㄾ, ㄿ, ㅀ, ㅄ), но читается из них **только одна**.
- Букв 40: 19 согласных + 21 гласная. Звуков — 8 чистых гласных + 4 йотированные + 13 дифтонгов.

## 2. Согласные: звук по месту образования

| Место | Ненапр. | Придыхат. | Напряж. | Звонкий между гласными |
|-------|---------|-----------|---------|------------------------|
| Губные | ㅂ [p] | ㅍ [pʰ] | ㅃ [p͈] | б |
| Зубные/альвеолярные | ㄷ [t] | ㅌ [tʰ] | ㄸ [t͈] | д |
| Велярные | ㄱ [k] | ㅋ [kʰ] | ㄲ [k͈] | г |
| Аффрикаты | ㅈ [tɕ] | ㅊ [tɕʰ] | ㅉ [tɕ͈] | дж |
| Фрикативные | ㅅ [s] | — | ㅆ [s͈] | — |
| Носовые | ㄴ [n] | — | — | н |
| | ㅁ [m] | — | — | м |
| | ㅇ [ŋ] (в конце) | — | — | — |
| Боковой | ㄹ [ɾ]/[l] | — | — | р/ль |
| Глоттальный | ㅎ [h] | — | — | — |

**Придыхательные** (ㅋㅌㅍㅊ) слышны как сильный выдох воздуха — аналог русского «кх», «тх», «пх», «чх».
**Напряжённые** (ㄲㄸㅃㅆㅉ) произносятся с напряжением гортани, без придыхания — коротко и резко.

## 3. Гласные

### 3.1 Согласование гласных (гармония)

Корейские гласные делятся на «светлые» (ㅏ, ㅗ) и «тёмные» (ㅓ, ㅜ, ㅡ, ㅣ). Это влияет на выбор окончания 아/어.

| Светлые (позитивные, «солнце/небо») | Тёмные (негативные, «луна/земля») |
|-------------------------------------|-----------------------------------|
| ㅏ а, ㅗ о | ㅓ о, ㅜ у, ㅡ ы, ㅣ и |
| ㅑ я, ㅛ ё | ㅕ ё, ㅠ ю |
| ㅐ э, ㅘ ва, ㅚ ве | ㅔ е, ㅝ во, ㅞ ве, ㅟ ви, ㅢ ый |
| ㅒ йэ | ㅖ йе |

Запоминалка: «светлые» = долгие открытые, «тёмные» = короткие/закрытые зоны языка.

### 3.2 Практика различения похожих звуков

| Буквы | Разница | Пары для тренировки |
|-------|---------|---------------------|
| ㅐ э vs ㅔ е | сейчас почти не различаются | 개(пёс) vs 게(краб) |
| ㅓ о vs ㅗ о | ㅓ — мягкое «о» (губы плоские), ㅗ — «о» с округлёнными губами | 어 vs 오 |
| ㅡ ы vs ㅣ и | ㅡ — по-русски «ы», ㅣ — «и» | 으 vs 이 |
| ㅚ/ㅞ ве | дифтонг в/э, губы вытянуты | 외 vs 웨 |
| ㅢ ый | читается по-разному (см. ниже) | 의사 (ыйса) |

### 3.3 Три чтения дифтонга ㅢ

| Позиция | Читается | Пример |
|---------|----------|--------|
| Начало слова | ый ([으이]) | 의자 (ыйджа) — стул |
| После согласной | и | 희망 (химан) — надежда |
| Притяжательная частица 의 | е ([에]) | 나의 (нае) — мой |

## 4. Конечные согласные (받침): 7 базовых звуков

В конце слога реально произносится **только один из 7 звуков**: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ. Все остальные конечные буквы «упрощаются».

| Произносится | Записывается | Примеры |
|--------------|--------------|---------|
| [k] | ㄱ, ㅋ, ㄲ, ㄳ, ㄺ | 책(книга), 부엌(кухня), 밖(снаружи), 값(цена) |
| [n] | ㄴ, ㄵ, ㄶ | 산(гора), 앉다(сидеть), 많다(много) |
| [t] | ㄷ, ㅌ, ㅅ, ㅆ, ㅈ, ㅊ, ㅎ, ㄽ, ㅄ, ㄾ | 낯(лицо), 끝(конец), 숫자, 밭(поле) |
| [l] | ㄹ, ㄼ, ㄿ, ㅀ | 발(стопа), 여덟(8), 읊다(декл.) |
| [m] | ㅁ, ㄻ | 심장(сердце), 삶(жизнь) |
| [p] | ㅂ, ㅍ, ㅄ, ㄿ | 입(рот), 앞(перед), 없다(нет) |
| [ŋ] | ㅇ | 공(мяч), 방(комната) |

**Картинка для запоминания:** ㄱ→ㄲ→ㅋ→ㄳ→ㄺ «стреляют» в [к]; ㄷ,ㅌ,ㅅ,ㅆ,ㅈ,ㅊ,ㅎ «бьют» в [т]; ㅂ,ㅍ,ㅄ — в [п].

---

## 5. Связывание (연음, ёным)

Если следующий слог начинается с гласной, конечная согласная **переносится** на него. Двойная 받침: первая остаётся, вторая переносится.

| Слово | Читается | Буквально |
|-------|----------|-----------|
| 한국어 | [한구거] хан-гу-го | корейский язык |
| 책이 | [채기] чхэ-ги | книга (им. п.) |
| 물을 | [무를] му-рыль | вода (вин. п.) |
| 읽어요 | [일거요] иль-го-ё | читаю |
| 없어요 | [업써요] оп-ссо-ё | нет (нету) |
| 꽃이 | [꼬치] кко-чхи | цветок (им. п.) |
| 좋아요 | [조아요] чо-а-ё | хорошо |
| 앉아요 | [안자요] ан-джа-ё | сажусь |
| 밟아요 | [발바요] паль-ба-ё | наступаю |

## 6. Ассимиляция по звонкости (울림의 법칙)

Начало слова после гласных принимает **звонкий** вариант для ㄱㄷㅂㅈ. Это не фонема, но слышится: 내기 [nɛgi], 바다 [bada], 아기 [agi], 지다 [dʑida].

| Слово | Начало | Чтение |
|-------|--------|--------|
| 기타 (гита) | к | китха |
| 피아노 (пиано) | п | пхиано |
| 아니요 (нет) | а | анийо |
| 사람 (человек) | с | сарам |

Правило: ㄱ→[ɡ], ㄷ→[d], ㅂ→[b], ㅈ→[dʑ] в интервокальной позиции (между гласными) и после сонорных.

---

## 7. Носовая ассимиляция (비음화, пимыхва)

Согласные ㄱㄷㅂ перед носовыми ㄴㅁ превращаются в носовые ㅇㄴㅁ.

| Согласная | Перед ㄴ/ㅁ | Примеры |
|-----------|-----------|---------|
| ㄱ → ㅇ [ŋ] | | 국물 → [궁물] кунмуль |
| | | 한국말 → [한궁말] хан-гун-маль |
| ㄷ → ㄴ | | 믿는다 → [민는다] миннында |
| | | 신문 (не ассимиляция) |
| ㅂ → ㅁ | | 합니다 → [함니다] хамнида |
| | | 입니다 → [임니다] имнида |
| | | 밥물 → [밤물] паммуль |
| ㄹ → ㄴ | перед ㅁ (губная) | 설마 → [설마/선마] сольма |

**Практические слова:** 합니다 [함니다] «делаю», 입니다 [임니다] «есть/являюсь», 작년 [장년] «прошлый год», 국민 [궁민] «гражданин».

---

## 8. Ассимиляция ㄹ (유음화, юмымхва)

- `ㄴ + ㄹ` → `ㄹ + ㄹ`
- `ㄹ + ㄴ` → `ㄹ + ㄹ`

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 설날 | [설랄] соллаль | Соллаль (Новый год) |
| 진리 | [질리] чилли | истина |
| 신라 | [실라] силла | Силла (государство) |
| 만년필 | [만년필 → 만녈필] маннёльпхиль | ручка |

**Особый случай:** если ㄹ стоит последним слогом перед гласной после ㅇ, читается как ль: 서울 → [서울].

---

## 9. Придыхательная ассимиляция (격음화, кёгымхва)

Конечные `ㅂ ㄷ ㄱ ㅈ` сливаются со слогом на `ㅎ` (и наоборот) в придыхательные `ㅍ ㅌ ㅋ ㅊ`.

| Сочетание | Результат | Пример |
|-----------|-----------|--------|
| ㅂ + ㅎ | ㅍ [pʰ] | 좋아? нет; 잡히다 → [자피다] чапхида |
| ㄷ + ㅎ | ㅌ [tʰ] | 닫히다 → [다티다] татхида |
| ㄱ + ㅎ | ㅋ [kʰ] | 백화점 ↔ [배콰점] пэкхваджом |
| ㅈ + ㅎ | ㅊ [tɕʰ] | 옳지? нет; 맞히다 → [마치다] мачхида |
| ㅎ + ㄱ | ㅋ | 놓고 → [노코] нокхо |
| ㅎ + ㄷ | ㅌ | 좋다 → [조타] чотха |
| ㅎ + ㅂ | ㅍ | 깊다 → [키프타] кипхта |
| ㅎ + ㅈ | ㅊ | 괜찮지? → [괜찬치] квэнчханчхи |

**Запомнить:** 좋다 читается [조타], 많다 — [만타], 않다 — [안타] (ㅎ сливается или выпадает, см. §11).

---

## 10. Палатализация (구개음화, кугэымхва)

`ㄷ/ㅌ` + `이` → `ㅈ/ㅊ`.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 같이 | [가치] качхи | вместе |
| 굳이 | [구지] куджи | нарочно |
| 맏이 | [마지] маджи | старший ребёнок |
| 닫히다 | [다치다] тачхида | закрываться |
| 해돋이 | [해도지] хэдоджи | восход |

## 11. Выпадение и ослабление ㅎ

| Контекст | Эффект | Пример |
|----------|--------|--------|
| 좋아요 | ㅎ выпадает | [조아요] чоаё |
| 안녕히 | ㅎ почти не слышен | [안녕이 → 안녕히] аннёнгхи |
| 않아요 | 않 → [아나요] анаё |
| 못해 | ㅎ выпадает | [모태 → 모테] мотхэ? → [모테] мотхэ |
| 힘들다 | ㅎ в двусложной 받침 | [힘들다 → 힘들다] химдыльда |

Примечание: ㅎ не выпадает после слоа на тёмные гласные в позиции напряжённой — исключение 다집합 (часто пишут читаемо). На практике: 않는ㄴ: 않는다 → [안는다].

---

## 12. Усиление (경음화, кёнымхва)

После конечных ㄹ, ㄴ, ㅁ, ㅇ и после ㅂ 앞 согласные ㄱㄷㅂㅅㅈ становятся **напряжёнными** (двойными).

| Слово | Чтение | Правило |
|-------|--------|---------|
| 할 수 | [할쑤] халь-ссу | ㄹ + ㅅ → ㅆ |
| 식사 | [식싸] сик-сса | ㄱ(받침) + ㅅ → ㅆ |
| 국밥 | [국빱] кук-ппап | ㄱ + ㅂ → ㅃ |
| 학자 | [학짜] хак-чча | ㄱ + ㅈ → ㅉ |
| 있다 | [읻따] ит-тта | ㅅ(받침) + ㄷ → ㄸ |
| 없다 | [업따] оп-тта | ㅂ + ㄷ → ㄸ |
| 닫고 | [닫꼬] тат-кко | ㄷ + ㄱ → ㄲ |
| 갈까 | [갈까] каль-кка | ㄹ + ㄱ → ㄲ |
| 합니다 | [함니다] хам-ни-да | ㅂ→ㅁ (носавая) |

**Правило звука №1 в корейском:** «после глухого/носового — смычка напрягается».

## 14. Интонация и «ударение»

В корейском нет тонального ударения — фразовая интонация:

| Тип высказывания | Интонация |
|------------------|-----------|
| Утверждение | ровная, слегка вниз |
| Общий вопрос | вверх ↗ (안녕하세요?) |
| Специальный вопрос | вниз ↘ (뭐 해요?) |
| Приказ/просьба | ровная твёрдая |
| Удивление | резкий подъём |

Долгота гласной (старшее поколение): 밤[пам] — ночь vs 밤:[паам] — каштан; 눈[нун] — глаз vs 눈:[нуун] — снег. В современном языке различие почти исчезло.

## 15. Чек-лист «главных» правил (мини-свод)

1. ㅇ в начале — нет звука; в конце — [ŋ].
2. Любая конечная согласная → 7 звуков (ㄱㄴㄷㄹㅁㅂㅇ).
3. ㄱㄷㅂ перед ㄴㅁ → ㅇㄴㅁ (합니다 [함니다]).
4. ㄴㄹ ↔ стало ㄹㄹ (신라 [실라]).
5. ㄷㄱㅂㅎ → придыхательные (좋다 [조타]).
6. ㄷ/ㅌ + 이 → ㅈ/ㅊ (같이 [가치]).
7. ㄱㄷㅂㅅㅈ после ㄹ/받침 → напряжённые (할 수 [할쑤]).
8. Конечная согласная переносится на следующий слог (읽어요 [일거요]).
9. ㅐ/ㅔ, ㅚ/ㅞ уже почти не различаются на слух.
