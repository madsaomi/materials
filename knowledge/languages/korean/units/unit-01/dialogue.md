# Unit 1 — 대화: 안녕하세요! (Здравствуйте!)

## 대화 (Диалог)

```
민수: 안녕하세요! 저는 김민수입니다. 이름이 뭐예요?
지영: 안녕하세요! 저는 박지영이에요. 만나서 반갑습니다!
민수: 저도 반가워요! 지영 씨는 학생이에요?
지영: 네, 저는 학생이에요. 서울대학교에서 공부해요. 민수 씨는요?
민수: 저는 회사원이에요. 삼성에서 일해요.
지영: 아, 그래요? 몇 살이에요?
민수: 스물다섯 살이에요. 지영 씨는요?
지영: 저는 스물두 살이에요.
민수: 한국어를 잘하시네요! 어디에서 한국어를 배웠어요?
지영: 학교에서 배웠어요. 아직 잘 못해요.
민수: 아니에요, 아주 잘해요!
지영: 감사합니다! 다음에 또 만나요!
민수: 네, 안녕!
```

## 대화 2: 카페에서 (В кафе)

```
민수: 지영 씨, 안녕하세요!
지영: 안녕하세요, 민수 씨! 오랜만이에요!
민수: 네, 오랜만이에요. 지영 씨는 뭐 할 거예요?
지영: 커피 한 잔 마실 거예요. 같이 가요?
민수: 좋아요! 같이 가요.
지영: 민수 씨, 커피를 좋아해요?
민수: 네, 아주 좋아해요. 그런데 설탕은 안 넣어요.
지영: 저도 설탕 없이 마셔요.
민수: 정말요? 저는 건강을 생각해서 그래요.
지영: 저도 건강이 중요해요. 자, 어서 가요!
```

|--------|---------|

| 같이 | вместе |

### 문법 포인트 (Грамматические заметки)

- **-ㄹ 거예요** — будущее время: *마실 거예요* «буду пить», *할 거예요* «буду делать».
- **-지요? / -죠?** — ожидание согласия: *좋지요?* «же хорошо, правда?»
- **같이 + глагол** — «вместе»: *같이 가요* «пойдём вместе».

## 대화 3: 전화 (По телефону)

```
민수: 여보세요?
지영: 여보세요? 민수 씨세요?
민수: 네, 저예요. 지영 씨예요?
지영: 네, 맞아요. 오늘 시간 있어요?
민수: 잠깐만요. 지금 약속이 있어요.
지영: 그럼 내일은 어때요?
민수: 내일은 괜찮아요. 몇 시에 만날까요?
지영: 두 시에 만나요. 어디에서요?
민수: 학교 앞에서 만나요.
지영: 좋아요. 그럼 내일 봐요!
민수: 네, 내일 봐요!
```

### 문법 포인트 (Грамматические заметки)

- **-ㄹ까요?** — предложение / предположение: *몇 시에 만날까요?* «во сколько встретимся?»
- **-어요?** форма вопроса поднимающимся тоном: *민수 씨세요?*
- **씨 + 이다** для вежливого обращения: *민수 씨 + 이에요 → 씨예요* (гласная).

## 대화 4: 새 친구 (Новый друг)

```
민수: 안녕하세요! 저는 김민수예요. 이름이 뭐예요?
마이클: 안녕하세요! 저는 마이클이에요. 만나서 반갑습니다.
민수: 저도 반갑습니다! 어디에서 왔어요?
마이클: 미국에서 왔어요.
민수: 와, 미국! 무엇을 공부해요?
마이클: 한국어를 공부해요. 한국에 일 년 있어요.
민수: 대단하네요! 한국 친구가 있어요?
마이클: 네, 한국 친구가 두 명 있어요. 같이 공부해요.
민수: 부러워요! 저도 외국 친구가 있었으면 좋겠어요.
마이클: 우리는 이제 친구예요. 자주 만나요!
민수: 좋아요! 그럼 자주 같이 밥 먹어요!
```

### 문법 포인트 (Грамматические заметки)

- **-에서 왔어요** — «приехать из»: *미국에서 왔어요* «приехал из Америки».
- **-었으면 좋겠어요** — «хотелось бы»: *외국 친구가 있었으면 좋겠어요* «хотелось бы иметь иностранного друга».
- **명** — счётное слово для людей: *두 명* «два человека».
