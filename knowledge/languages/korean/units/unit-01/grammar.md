# Unit 1 — 문법 (Грамматика)

## 1. 이다 (быть)

**Структура:** [сущ.] + 이/가 + [сущ.] + 이다

```
저는 학생입니다.       — Я студент.
이것은 책입니다.       — Это книга.
저는 김민수입니다.     — Я Ким Минсу.
```

**Неформально-вежливо:** 예요 / 이에요
```
학생이에요.           — Я студент.
책이에요.             — Это книга.
민수예요?             — Это Минсу?
```

**Отрицание:** 아니다 / 이/가 아니다
```
학생이 아닙니다.      — Я не студент.
책이 아니에요.        — Это не книга.
```

## 2. 은/는 (тематическая частица)

После согласной: **은**, после гласной: **는**

```
저는 학생이에요.      — Я (тема) студент.
이것은 책이에요.      — Это (тема) книга.
민수는 회사원이에요.  — Минсу (тема) офисный работник.
```

## 3. 이/가 (субъектная частица)

После согласной: **이**, после гласной: **가**

```
이것이 책이에요.      — Это (именно эта) книга.
누가 왔어요?          — Кто пришёл?
한국어가 어려워요.    — Корейский (субъект) сложный.
```

## 4. Вопросы

**예/아니오 ответы на вопросы с 이다:**
```
학생이에요? — 네, 학생이에요. / 아니요, 학생이 아니에요.
```

**Вопросительные слова:**
| 한국어 | Чтение | Перевод |
|--------|--------|---------|
| 누구 | нугу | кто |
| 무엇/뭐 | муот/мво | что |
| 어디 | оди | где |
| 언제 | ондже | когда |
| 왜 | вэ | почему |
| 어떻게 | оттокхе | как |
| 몇 | мёт | сколько |
| 얼마 | ольма | сколько (цена) |

## 5. 에 있다 / 없다 (находиться / не находиться)

```
집에 있어요.          — Я дома.
학교에 없어요.        — Меня нет в школе.
어디에 있어요?        — Где (находится)?
```

## 6. Числа (исконные)

| Число | Хангыль | Чтение |
|-------|---------|--------|
| 1 | 하나 | хана |
| 2 | 둘 | туль |
| 3 | 셋 | сэт |
| 4 | 넷 | нэт |
| 5 | 다섯 | тасот |
| 6 | 여섯 | ёсот |
| 7 | 일곱 | ильгоп |
| 8 | 여덟 | ёдоль |
| 9 | 아홉 | ахоп |
| 10 | 열 | ёль |

Для возраста используем исконные числа + 살:
```
한 살, 두 살, 세 살, 네 살...
스무 살 (20), 서른 살 (30)
```

## 7. Вежливое окончание: ㅂ니다/습니다

После гласной: **ㅂ니다**
После согласной: **습니다**
```
합니다            — Делаю.
먹습니다          — Ем.
갑니다            — Иду.
```

## 8. 에 대한 — о/об

Пример в этом уроке не используется, оставим на потом.

3. Вопрос: "Вы студент?" → __________

**Ответы:**

5. 저는 민수입니다 / 민수예요

## 9. 을/를 (винительная частица)

После согласной: **을**, после гласной: **를**. Обозначает объект действия.

```
밥을 먹어요.            — Ем рис.
물을 마셔요.            — Пью воду.
한국어를 공부해요.      — Учу корейский.
이름을 써요.            — Пишу имя.
```

**Вопрос «что»:** 무엇을 / 뭘
```
뭘 좋아해요?            — Что (ты) любишь?
뭘 배워요?              — Что (ты) учишь?
```

## 10. 에 / 에서 (место и направление)

**에** — направление (куда) и местонахождение (где):
```
학교에 가요.            — Иду в школу.
집에 있어요.            — Я дома.
```

**에서** — место действия (где происходит) и исходная точка (откуда):
```
학교에서 공부해요.      — Учусь в школе.
한국에서 왔어요.        — Приехал(а) из Кореи.
집에서 이야기해요.      — Разговариваю дома.
```

## 11. 의 (притяжательная частица)

Показывает принадлежность: [чей] + 의 + [что].

```
나의 책 = 내 책        — моя книга
저의 이름 = 제 이름    — моё имя (вежл.)
친구의 집              — дом друга
한국의 수도            — столица Кореи
```

После местоимений 나/저 의 часто опускают: **내 책, 제 이름**.

## 12. Прошедшее время: -았/었어요

Основа на гласные ㅏ/ㅗ + **았어요**, остальные + **었어요**, 하 + **했어요**:
```
가다 → 갔어요          — пошёл (ходил)
먹다 → 먹었어요        — поел
하다 → 했어요          — сделал
책을 읽었어요.         — Прочитал книгу.
친구를 만났어요.       — Встретил друга.
```

Связка 이다 в прошедшем: после согласной **이었어요**, после гласной **였어요**:
```
학생이었어요.          — Был(а) студентом(кой).
의사였어요.            — Был(а) врачом.
그때는 몰랐어요.       — Тогда я не знал(а).
```

## 13. Будущее время: -ㄹ 거예요

После гласной: **-ㄹ 거예요**, после согласной: **-을 거예요**.
Выражает намерение или предположение о будущем.

```
갈 거예요.             — Пойду (собираюсь пойти).
공부할 거예요.         — Буду учиться.
먹을 거예요.           — Буду есть.
내일 뭐 할 거예요?     — Что будешь делать завтра?
```

Связка 이다: **일 거예요**
```
내일은 쉬는 날일 거예요. — Завтра, наверное, выходной.
```

## 14. 예요 / 이에요 — правило выбора

После гласной: **예요**, после согласной: **이에요**.

```
민수예요.               — Это Минсу. (гласная ㅜ + 예요)
책이에요.               — Это книга. (согласная ㄱ + 이에요)
이름이 뭐예요?          — Как тебя зовут? (뭐 + 예요)
마이클이에요.           — Это Майкл. (согласная ㄹ + 이에요)
```

Ошибкой будет «민수이에요» — имена на гласную присоединяют только 예요.

## 15. 하고 / 와·과 (союз «и»)

Соединяют существительные. После гласной: **와**, после согласной: **과**. **하고** — универсальный, разговорный.

```
밥하고 김치를 먹어요.   — Ем рис и кимчи.
친구하고 이야기해요.    — Разговариваю с другом.
사과와 바나나를 좋아해요. — Люблю яблоки и бананы.
돈과 시간이 필요해요.   — Нужны деньги и время.
```

## 16. -네요 и -죠? (удивление и согласие)

**-네요** — восхищение / удивление от факта:
```
한국어 잘하시네요!      — Как хорошо вы говорите по-корейски!
날씨가 좋네요!         — Какая хорошая погода!
집이 크네요!           — Какой большой дом!
```

**-죠? (-지요)** — просьба согласия / взаимное подтверждение:
```
한국 사람이지요?        — Вы ведь кореец?
오늘 바쁘지요?          — Ты ведь сегодня занят?
재미있지요?             — Интересно же, правда?
```

## 17. 반말 (банмаль — дружеская форма)

Краткая форма для близких друзей и младших:
```
나는 학생이야.          — Я студент.
이름이 뭐야?            — Как зовут?
밥 먹었어?              — Поел?
잘 지내?                — Как дела?
```

| Вежливо (해요체) | Банмаль (해체) |
|---------|---------|
| 안녕하세요 | 안녕 |
| 감사합니다 | 고마워 |
| 이름이 뭐예요? | 이름이 뭐야? |
| 학생이에요 | 학생이야 |

## 18. Отрицание: 안 / 못

**안** — простое отрицание «не», **못** — «не может / не умеет».
```
학교에 안 가요.         — Не иду в школу.
밥을 안 먹어요.         — Не ем.
한국어를 못 해요.       — Не умею говорить по-корейски.
한국에 못 가요.         — Не могу поехать в Корею.
```

Для связки 이다 используем **아니다**:
```
학생이 아니에요.        — Я не студент.
제가 아닙니다.          — Это не я.
```

## 19. Частые ошибки Unit 1

1. **예요 vs 이에요**
   - 민수예요 ✓ (после гласной)
   - 책이에요 ✓ (после согласной)
   - 민수이에요 ✗
2. **저가?** — неправильно. Говорим только **저는** (тема). Для субъекта — 제가/내가.
3. **Возраст:** спрашиваем «몇 살이에요?», а не о «년/년».
4. **Порядок слов:** сказуемое всегда в конце предложения. *학교에 갑니다* ✓, *갑니다 학교에* ✗.
5. **못 vs 안:** 못 해요 — не могу/не умею, 안 해요 — просто не делаю.
