## 1. 주다 / 드리다 / 받다 («Давать / Получать»)

### Значение

| Глагол | Значение | Уровень вежливости |
|--------|----------|-------------------|
| 주다 | давать | нейтральный |
| 드리다 | давать (вежливо) | вежливый (я → старший/стажёр) |
| 받ать | получать | нейтральный |

### Спряжение 주다

| Форма | Пример | Перевод |
|-------|--------|---------|
| 주다 (инфинитив) | 줘 | давай |
| 줘요 (вежливо) | 줘요 | дайте, пожалуйста |
| 줬어요 (прош.) | 줬어요 | дал(а) |
| 줄 거예요 (буд.) | 줄 거예요 | дам |
| 안 줘요 (отриц.) | 안 줘요 | не даю |
| 주지 않아요 (отриц.) | 주지 않아요 | не даю (более формально) |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Дай мне, пожалуйста. | 저한테 주세요. | Jeohante juseyo. |
| Он дал мне книгу. | 그는 저한테 책을 줬어요. | Geuneun jeohante chaeg-eul jwosseoyo. |
| Я получила подарок. | 저는 선물을 받았어요. | Jeoneun seonmul-eul badassoyo. |
| Она дарит цветы. | 그녀는 꽃을 줘요. | Geunyeoneun kkoch-eul jwoyo. |

### Спряжение 드리다

| Форма | Пример | Перевод |
|-------|--------|---------|
| 드리다 (инфинитив) | 드려 | дарю/вручаю |
| 드려요 (вежливо) | 드려요 | вручаю (вежливо) |
| 드렸어요 (прош.) | 드렸어요 | вручил(а) |
| 드릴 거예요 (буд.) | 드릴 거예요 | вручу |

### Примеры с 드리다

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Это подарок для вас. | 이것은 선물이에요. 전해 드려요. | Igeoseun seonmul-ieyo. Jeonhae deuryeoyo. |
| Я вручаю вам это. | 이걸 드릴게요. | Igeol deurilgeyo. |
| Я дал(а) это учителю. | 선생님께 드렸어요. | Seonsaengnimkke deuryeosseoyo. |
| Возьмите, пожалуйста. | 받아 주세요. | Bad-a juseyo. |

### Сравнение: кому и что

| Ситуация | Глагол | Пример |
|----------|--------|--------|
| Я → ты (нейтр.) | 주다 | 이거 줘. (Дай это) |
| Я → старший | 드리다 | 이거 드릴게요. (Вам это) |
| Ты → мне | 주다 | 이거 줘. (Дай мне это) |
| Старший → мне | 주시다 (вежл.) | 이거 주셨어요. (Он дал мне) |
| Я → получить | 받다 | 이거 받았어요. (Я получил это) |

## 2. -아/어 주다 («Сделать что-то для кого-то»)

### Значение

Конструкция **-아/어 주다** используется, чтобы сказать, что кто-то **сделал что-то для вас** или **вы делаете что-то для кого-то**. Акцент на **благодеянии**.

### Образование

```
Глагол + 아/어 + 주다
```

| Глагол | Корень | + -아/어 주다 | Перевод |
|--------|--------|---------------|---------|
| 읽다 | 읽 | 읽어 주다 | прочитать для кого-то |
| 쓰다 | 쓰 | 써 주다 | написать для кого-то |
| 사다 | 사 | 사 주다 | купить для кого-то |
| 만들다 | 만들 | 만들어 주다 | сделать для кого-то |
| 가르치다 | 가르치 | 가르쳐 주다 | научить кого-то |
| 도와주다 | 도와 | 도와 주다 | помочь кому-то |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Купи мне, пожалуйста, кофе. | 커피를 사 줘. | Keopi-reul sa jwo. |
| Она прочитала для меня. | 그녀는 저한테 읽어 줬어요. | Geunyeoneun jeohante ilgeo jwosseoyo. |
| Ты написал(а) для меня? | 저한테 써 줬어요? | Jeohante sseo jwosseoyo? |
| Учитель объяснил нам. | 선생님께서 설명해 주셨어요. | Seonsaengnimkkeseo seolmyeonghae jusyeosseoyo. |
| Помоги мне, пожалуйста. | 좀 도와 줘. | Jom dowa jwo. |
| Мама приготовила мне еду. | 엄마가 밥을 해 줬어요. | Eommaga babeul hae jwosseoyo. |

### Вежливая форма: -아/어 드리다

Когда **вы** делаете что-то для **старшего** или **начальника**:

```
Глагол + 아/어 드리다
```

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я сделаю это для вас. | 제가 해 드릴게요. | Jega hae deurilgeyo. |
| Я помогу вам. | 제가 도와 드릴게요. | Jega dowa deurilgeyo. |

## 3. -(으)ㄹ게요 («Я сделаю…» / Обещание)

### Значение

**(으)ㄹ게요** выражает **обещание** или **намерение** говорящего сделать что-то. Более мягкая и личная форма, чем -(으)ㄹ 거예요.

### Образование

```
Глагол (согласный) + 을게요
Глагол (гласный) + ㄹ게요
```

| Глагол | Корень | + -(으)ㄹ게요 | Перевод |
|--------|--------|--------------|---------|
| 하다 | 하 | 할게요 | я сделаю |
| 가다 | 가 | 갈게요 | я пойду |
| 오다 | 올 | 옙게요 | я приду |
| 먹다 | 먹 | 먹을게요 | я поем |
| 보다 | 볼 | 볼게요 | я посмотрю |
| 기다리다 | 기다리 | 기다릴게요 | я подожду |
| 알다 | 알 | 알게요 | я понял(а) |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я сделаю это. | 제가 할게요. | Jega halgeyo. |
| Я пойду домой. | 저는 집에 갈게요. | Jeoneun jib-e galgeyo. |
| Я подожду тебя. | 기다릴게요. | Gidarilgeyo. |
| Я позвоню тебе завтра. | 내일 전화할게요. | Naeil jeonhwa-halgeyo. |
| Хорошо, я помогу. | 네, 도와 드릴게요. | Ne, dowa deurilgeyo. |
| Я не буду шуметь. | 조용히 할게요. |Joyonghi halgeyo. |

### -(으)ㄹ게요 vs -(으)ㄹ 거예요

| Форма | Значение | Фокус |
|-------|----------|-------|
| -(으)ㄹ게요 | обещание, решение | «Я сделаю (обещаю)» — для собеседника |
| -(으)ㄹ 거예ой | план, намерение | «Я буду делать» — описание факта |

| Пример | Разница |
|--------|---------|
| 갈게요 — Я пойду (обещаю, решаю сейчас) | Вы решаете в моменте |
| 갈 거예요 — Я пойду (это мой план) | Вы описываете свой план |

## 4. Уровни вежливости при дарении

| Ситуация | Форма | Пример |
|----------|-------|--------|
| Друг → друг (нейтр.) | 주다 | 이거 줘. |
| Я → старший (вежл.) | 드리다 | 이거 드릴게요. |
| Старший → мне (вежл.) | 주시다 | 이거 주셨어요. |
| Продавец → покупатель | 주다 | 이거 드릴게요. (вежл. в магазине) |
| Коллега → коллега | 주다 / 드리다 | 이거 줘요 / 드려요. |

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 저는 책을 줘요 ✓ | — | Нейтральная форма |
| 저는 책을 드려요 ✓ | — | Вежливая форма (я → старший) |
| 저한테 책을 주세요 ✓ | — | Вежливая просьба |
| 주세요가 맞아요 ✓ | — | Пожалуйста, дайте |
| 저는 갈게요 ✓ | — | Обещание «я пойду» |
| 저는 갈 거예요 ✓ | — | План «я пойду» |
| 주다 vs 드리다 — разница в вежливости ✓ | — | Дрида — более формально |

## 7. -(으)려고 하다 («Намереваться / собираться»)

### Значение

Конструкция **-(으)려고 하다** выражает **намерение** или **план** что-то сделать: «собираться», «намереваться».

### Образование

```
Глагол + (으)려고 하다
```

| Глагол | Корень | + (으)려고 하다 | Перевод |
|--------|--------|----------------|---------|
| 사다 | 사 | 사려고 해요 | собираюсь купить |
| 주다 | 주 | 주려고 해요 | собираюсь дать |
| 보내다 | 보내 | 보내려고 해요 | собираюсь отправить |
| 읽다 | 읽 | 읽으려고 해요 | собираюсь прочитать |
| 만들다 | 만들 | 만들려고 해요 | собираюсь сделать |
| 받다 | 받 | 받으려고 해요 | собираюсь получить |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я собираюсь купить подарок маме. | 엄마에게 선물을 사려고 해요. | Eomma-ege seonmul-eul saryeogo haeyo. |
| Я хочу подарить цветы. | 꽃을 주려고 해요. | Kkoch-eul juryeogo haeyo. |
| Я собираюсь отправить открытку. | 카드를 보내려고 해요. | Kadeu-reul bonaeryeogo haeyo. |

## 8. -아/어 보다 («Пробовать делать»)

### Значение

**-아/어 보다** выражает **попытку** или **опыт**: «пробовать что-то сделать».

### Образование

```
Глагол + 아/어 + 보다
```

| Глагол | + 아/어 보다 | Перевод |
|--------|-------------|---------|
| 열다 | 열어 보다 | попробовать открыть |
| 먹다 | 먹어 보다 | попробовать съесть |
| 살다 | 살아 보다 | попробовать жить |
| 보다 | 봐 보다 | попробовать посмотреть |
| 입다 | 입어 보다 | примерить (одежду) |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Открой и посмотри! | 열어 봐! | Yeoreo bwa! |
| Попробуй этот торт. | 이 케이크를 먹어 봐. | I keikeu-reul meogeo bwa. |
| Я хотел бы попробовать надеть его. | 입어 보고 싶어요. | Ibeo bogo sipeoyo. |

## 9. 마음에 들다 («Нравиться»)

### Значение

**마음에 들다** — идиоматическое выражение «быть по душе», «нравиться».

### Спряжение

| Форма | Хангыль | Романизация |
|-------|---------|-------------|
| Является по душе (наст.) | 마음에 들어요 | Maeum-e deureoyo |
| Было по душе (прош.) | 마음에 들었어요 | Maeum-e deureosseoyo |
| Будет по душе (буд.) | 마음에 들 거예요 | Maeum-e deul geoyeyo |
| Не нравится (отриц.) | 마음에 안 들어요 | Maeum-e an deureoyo |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Этот подарок нравится мне. | 이 선물이 마음에 들어요. | I seonmul-i maeum-e deureoyo. |
| Надеюсь, оно понравится тебе. | 마음에 들면 좋겠어요. | Maeum-e deulmyeon jokesseoyo. |
| Подарок маме понравился. | 엄마가 선물을 마음에 들어 하셨어요. | Eommaga seonmul-eul maeum-e deureo hasyeosseoyo. |

## 10. -들에게 / -께 («Кому» — дательный падеж)

### Значение

Разные частицы дательного падежа для слова «кому» в зависимости от уровня вежливости.

| Частица | Уровень | Пример |
|---------|---------|--------|
| 에게 | нейтральный | 친구에게 선물을 줬어요. |
| 한테 | разговорный (то же что 에게) | 친구한테 선물을 줬어요. |
| 께 | вежливый (старшему) | 선생님께 선물을 드렸어요. |
| 드리다 | вежливый глагол «давать» | — |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я дарю подарок другу. | 친구에게 선물을 줘요. | Chingu-ege seonmul-eul jwoyo. |
| Я дарю подарок учителю. | 선생님께 선물을 드려요. | Seonsaengnimkke seonmul-eul deuryeoyo. |
| Я получил(а) письмо от мамы. | 엄마한테서 편지를 받았어요. | Eomma-hanteseo pyeonji-reul badasseoyo. |

## 11. -고 싶다 («Хотеть делать»)

### Значение

**-고 싶다** выражает **желание** «хотеть что-то сделать».

### Образование

```
Глагол + 고 싶다
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я хочу подарить ей серьги. | 그녀에게 귀걸이를 주고 싶어요. | Geunyeo-ege gwigeori-reul jugo sipeoyo. |
| Я хочу получить на день рождения книгу. | 생일에 책을 받고 싶어요. | Saeng-il-e chaeg-eul batgo sipeoyo. |
| Я не хочу идти на вечеринку. | 파티에 가고 싶지 않아요. | Pati-e gago sipji anayo. |
| Ты хочешь попробовать? | 먹어 보고 싶어요? | Meogeo bogo sipeoyo? |

## 12. 대접하다 / 초대하다 (Угощать и приглашать)

### Значение

Связанные с гостеприимством глаголы, часто используемые в темах подарков.

| Глагол | Значение | Пример |
|--------|----------|--------|
| 초대하다 | приглашать | 파티에 초대했어요. |
| 대접하다 | угощать | 저녁을 대접했어요. |
| 사 주다 | «угостить» (купить за свой счёт) | 점심을 사 줬어요. |
| 접대하다 | принимать гостей (офиц.) | 손님을 접대했어요. |

### Разница 사 주다 vs 대접하다

| Выражение | Значение | Фокус |
|-----------|----------|-------|
| 밥을 사 주다 | угостить обедом (я плачу) | оплата |
| 대접하다 | угощать, принимать | гостеприимство |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я угощу вас обедом. | 점심을 사 드릴게요. | Jeomsim-eul sa deurilgeyo. |
| Мама хорошо угостила гостей. | 엄마가 손님을 잘 대접했어요. | Eommaga sonnim-eul jal daejeophaesseoyo. |
| Приглашаю тебя на вечеринку. | 파티에 초대할게요. | Pati-e chodaehalgeyo. |

## 13. Ау: выражение искренней благодарности

Для благодарности в разных ситуациях используются разные выражения.

| Выражение | Уровень | Когда |
|-----------|---------|-------|
| 감사합니다 | формальный | старшим, официально |
| 감사해요 | вежливо-неформ. | знакомым |
| 고마워요 | вежливо-неформ. | знакомым (ближе) |
| 고마워 | неформальный | друзьям, близким |
| 정말 고마워요 | с усилением | «очень спасибо» |
| 감사드립니다 | очень формальный | официальные случаи |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Очень благодарен за подарок. | 선물 정말 고마워요. | Seonmul jeongmal gomawoyo. |
| Большое спасибо за всё. | 모든 것에 감사드립니다. | Modeun geos-e gamsadeurimnida. |

## 14. Типичные ошибки (дополнительно)

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 저는 선생님께 꽃을 줬어요 | 저는 선생님께 꽃을 드렸어요 | старшему — 드리다 |
| 친구한테 선물을 드렸어요 | 친구한테 선물을 줬어요 | младшему/ровне — 주다 |
| 열다 보세요 | 열어 보세요 | 형은 -아/어 보다, не 다 |
| 마음에 들어요 ✓ | — | «нравится» (не 들어가요) |
| 받다 vs 받으시다 | 받으시다 — уваж. | о старшем, если он получает |
| 꽃을 사 줘서 고마워요 ✓ | — | «спасибо, что купил цветы» |
