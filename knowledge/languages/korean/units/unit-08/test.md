# 유닛 08 테스트: 선물

## 테스트

### 1. 다음 빈칸을 채우세요. (Заполните пропуски.)

1) 나는 친구에게 ______을 줬다.
2) 친구는 ______ 찍기를 좋아한다.
3) 나는 ______에서 중고 카메라를 찾았다.
4) 선물 상자에는 빨간 ______을 묶었다.
5) 선물의 가격이 중요한 것이 아니라, ______이 중요한 것이다.

### 2. 다음 문장이 맞으면 O, 틀리면 X 표시하세요. (Правильные/неправильные утверждения.)

1) 나는 비싼 카메라를 샀다. (  )
2) 친구는 선물을 보고 기뻐하지 않았다. (  )
3) 친구는 나에게 과일 바구니와 편지를 줬다. (  )
4) 글쓴이는 선물에 돈을 많이 쓰는 편이다. (  )
5) 가장 좋은 선물은 상대방이 정말 필요로 하는 것이다. (  )

### 3. 다음 한국어 문장을 러시아어로 번역하세요. (Переведите на русский.)

1) 나는 친구에게 어떤 선물을 줄지 오랫동안 고민했다.
2) 선물의 가격이 중요한 것이 아니라, 마음이 중요한 것이다.
3) 작은 선물이라도 정성이 담겨 있으면 그것으로 충분하다.
4) 친구는 바로 카메라로 사진을 찍기 시작했다.
5) 선물은 단순한 물건이 아니라, 사랑과 우정의 상징이다.

### 4. 다음 물음에 대답하세요. (Ответьте на вопросы.)

1. 왜 나는 중고 카메라를 사기로 했나요?
2. 카메라는 어떤 상태였나요?
3. 나는 선물 상자에 어떤 색 리ibbon을 묶었나요?
4. 친구가 나에게 선물을 준 것은 언제였나요?
5. 왜 그 선물이 감동적이었나요?

### 5. 다음 대화를 완성하세요. (Завершите диалог.)

A: 생일 축하해! 이 선물은 내가 네가 좋아할 만한 것을 골랐어.

A: 사진 찍기를 좋아한다고 해서 카메라를 샀어.
B: 와, ______! 바로 사용해 보고 싶어!
A: 응, ______! 항상 행복하길 바래.

### 6. 다음 빈칸에 주세요 또는 드릴게요를 넣으세요. (Вставьте 주세요 или 드릴게요.)

1) 손님께 이 물건을 ______. (дарю гостю)
2) 친구한테 이 책을 ______. (дарю другу)
3) 선생님께 이 꽃을 ______. (дарю учителю)
4) 저한테 커피를 ______. (дай мне кофе)
5) 후배에게 이걸 ______. (дарю младшему)

### 7. 다음 문장이 맞으면 O, 틀리면 X 표시하세요.

1) 선생님께 선물을 줬어요. (  ) — Вежливо для старшего.
2) 친구에게 선물을 드렸어요. (  ) — другу.
3) 이 선물이 마음에 들어요. = «Этот подарок мне нравится». (  )
4) 열다 보세요 = «Откройте и посмотрите». (  )
5) 꽃을 사 줘서 고마워요 = «Спасибо, что купил цветы». (  )

### 8. 다음 한국어를 러시아어로 번역하세요.

1) 저는 엄마에게 꽃다발을 사려고 해요.
2) 제가 점심을 사 드릴게요.
3) 이 귀걸이가 너한테 잘 어울려요.
4) 할머니께 카네이션을 드렸어요.
5) 이 선물을 준비하는 동안 정말 행복했어요.

### 9. 다음 물음에 대답하세요.

3. -아/어 주다의 의미는 무엇인가요?
4. -(으)ㄹ게요는 무엇을 표현하나요?

### 10. 다음 문장을 완성하세요. (Завершите предложения.)

### 6. 주세요 / 드릴게요
1) 드릴게요 (гостю — вежливо)
2) 줄게요 (другу — ровня)
3) 드릴게요 (учителю — вежливо)
4) 주세요 (мне — просьба)
5) 줄게요 (младшему)

### 7. O/X
1) X — правильно: 선생님께 선물을 드렸어요 (старшему — 드리다).
2) X — правильно: 친구에게 선물을 줬어요 (ровне — 주다).
3) O
4) X — правильно: 열어 보세요.
5) O

### 8. 번역
1) Я собираюсь купить маме букет цветов.
2) Я угощу вас обедом.
3) Эти серьги тебе идут.
4) Я подарил бабушке гвоздику.
5) Пока я готовил(а) этот подарок, был(а) очень счастлив(а).

### 9. 대답
1) «선물 감사합니다» / «고마워요» (спасибо за подарок).
2) 주다 — нейтральный «давать», 드리다 — вежливая форма (старшим).
3) Означает «сделать что-то для кого-то».
4) Обещание или намерение «я сделаю».
