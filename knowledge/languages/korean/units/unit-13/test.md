# 테스트 2: 가정 문법 실전 문제

## 1. 다음 중 -(으)면의 올바른 활용은? (Выберите правильную форму.)

1) 가다 → ______ (пойти, если)
2) 먹다 → ______ (поесть, если)
3) 하다 → ______ (сделать, если)
4) 살다 → ______ (жить, если)

## 2. 다음 빈칸에 알맞은 것을 고르세요. (Выберите верное.)

1) 만약에 시간이 ______ 더 공부할 텐데. (있다면 / 있으면)
2) 비가 ______ 우리는 축구를 할 거예요. (오면 / 오더라도) — «даже если»
3) 돈을 ______ 여행을 갈 수 있어요. (모으면 / 모아야)
4) 만약에 내가 ______ 세상을 바꿀 거예요. (대통령이라면 / 대통령이면)

## 3. 다음 문장이 맞으면 O, 틀리면 X. (Верно/неверно.)

1) -아/어도는「даже если」의 의미이다. (  )
2) -았/었더라면은 미래의 조건을 나타낸다. (  )
3) -(이)라면은 명사와 함께 쓴다. (  )
4) -은/는은 조건을 나타내는 문법이다. (  )

## 4. 다음 한국어 문장을 러시아어로 번역하세요. (Переведите.)

1) 비가 오더라도 우리는 갈 거예요.

3) 만약에 다시 태어난다면 나무가 되고 싶어요.
4) 시험이 어려울 테니까 미리 공부할게요.
5) 뭐든지 물어보세요.

## 6. 빈칸에 들어갈 접속사를 고르세요. (Выберите подходящий союз.)
