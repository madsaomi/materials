## Задание 8: Выберите правильную форму
Вставьте -(으)ㄹ 수 있다/없다 или 잘/못.

1. 저는 계산대에서 결제할 ________. (я могу оплатить на кассе)
2. 그녀는 요리를 ________ 해요. (она хорошо готовит)
3. 우리는 일요일에 ________ 없어요. (мы не можем прийти в воскресенье)
4. 제 동생은 노래를 ________ 해요. (мой младший брат плохо поёт)
5. 당신은 운전하실 ________? (вы умеете водить машину?)

## Задание 9: Вставьте -(으)ㄹ 줄 알다/모르다

1. 저는 수영할 ________. (не умею плавать)
2. 언니는 피아노를 칠 ________. (умеет играть на пианино)
3. 그는 컴퓨터를 할 ________. (умеет работать с компьютером)
4. 저는 요리할 ________. (не умею готовить)
5. 친구는 기타를 칠 ________. (умеет играть на гитаре)

## Задание 10: Поставьте -아/어 보다
Изменение по значению «пробовать».

1. 이 한국 음식을 ______ 보세요. (попробуйте поесть)
2. 이 드라마를 ______ 봤어요. (посмотрел (опыт))
3. 저는 제주도에 가 ______ 싶어요. (хочу попробовать поехать)
4. 친구에게 ______ 봤어요. (спросил (попытку))
5. 내일 ______ 볼게요. (попробую сделать)

## Задание 11: Поставьте -는데요 / 것 같아요

4. 오늘은 시간이 없 ______. (контекст)
5. 그는 무엇이든 만들 ______. (кажется)
