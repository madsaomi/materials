# Unit 2 — 문법 (Грамматика)

## 1. 하다 глаголы

Многие корейские глаголы образуются от существительных + 하다:

```
공부하다     — учиться (공부 + 하다)
운동하다     — заниматься спортом (운동 + 하다)
일하다       — работать (일 + 하다)
청소하다     — убирать (청소 + 하다)
요리하다     — готовить (요리 + 하다)
```

**Спряжение:**

```
하다 → 해요 (неформ. вежл.)
하다 → 합니다 (форм. вежл.)
하다 → 했어요 (прош. неформ.)
하다 → 했습니다 (прош. форм.)
```

## 2. 아/어/여요 (неформально-вежливое окончание)

**Правило:**

- Если последняя гласная ㅏ или ㅗ → **아요**
  - 가다 → 가요
  - 보다 → 봐요
  - 살다 → 살아요

- Если последняя гласная другая (не ㅏ/ㅗ) → **어요**
  - 먹다 → 먹어요
  - 읽다 → 읽어요
  - 마시다 → 마셔요
  - 공부하다 → 공부해요

- 하다 всегда → **해요**

## 3. Прошедшее время (았/었/였어요)

**Правило:**

- ㅏ/ㅗ → **았어요**
  - 가다 → 갔어요
  - 보다 → 봤어요
  - 살다 → 살았어요

- Другие гласные → **었어요**
  - 먹다 → 먹었어요
  - 읽다 → 읽었어요
  - 마시다 → 마셨어요

- 하다 → **했어요**
  - 공부하다 → 공부했어요

## 4. 에 (локативная частица)

**에 — местонахождение / время / направление:**

```
집에 있어요.          — Я дома.
학교에 가요.          — Иду в школу.
3시에 만나요.         — Встречаемся в 3 часа.
서울에 살아요.        — Живу в Сеуле.
```

## 5. 에서 (место действия)

```
학교에서 공부해요.     — Учусь в школе.
집에서 밥을 먹어요.    — Ем дома.
회사에서 일해요.       — Работаю в офисе.
```

## 6. 부터...까지 (от...до)

```
9시부터 6시까지 일해요.  — Работаю с 9 до 6.
서울부터 부산까지 가요.  — Еду от Сеула до Пусана.
```

## 7. 만 (только)

```
한 명만 있어요.        — Есть только один человек.
물만 마셔요.           — Пью только воду.
5분만 기다려 주세요.   — Подождите только 5 минут.
```

## 9. 은/는 и 이/가 (тема и субъект)

```
- 은/는 — маркер темы: речь идёт об уже известном (контраст)
- 이/가 — маркер субъекта: новое или ответ на вопрос "кто/что"

저는 학생이에요.            — Что касается меня, я студент. (тема)
수미 씨가 왔어요.           — Пришла Суми. (субъект, отвечает на "кто?")
이 책은 재미있어요.         — Эта книга интересная. (тема)
한국어가 어려워요.          — Корейский трудный. (новый факт)
나는 커피는 마셔요, 차는 안 마셔요. — Кофе пью, а чай не пью. (контраст)
```

## 10. -고 있다 (длительное действие)

**Правило:** основа глагола + 고 있다 — действие происходит прямо сейчас.

```
지금 뭐 하고 있어요?      — Что ты сейчас делаешь?
아침을 먹고 있어요.        — Ем завтрак (прямо сейчас).
책을 읽고 있어요.          — Читаю книгу.

 먹다 → 먹고 있어요
 가다 → 가고 있어요
 자다 → 자고 있어요
```

## 11. 안 и 못 (отрицание)

```
- 안 + глагол — простое отрицание: "не делаю"
- 못 + глагол — "не могу / не получается"

오늘 안 일해요.            — Сегодня не работаю.
아침을 안 먹었어요.        — Не позавтракал.
지하철을 못 타요.          — Не могу сесть на метро.
어제 못 잤어요.            — Вчера не смог поспать.
```

## 12. -아/어야 하다 (долженствование)

**Правило:**

- ㅏ/ㅗ основа → 아야 하다: 가다 → 가야 해요
- другие → 어야 하다: 먹다 → 먹어야 해요
- 하다 → 해야 하다: 공부하다 → 공부해야 해요

```
7시에 일어나야 해요.       — Должен встать в 7.
9시까지 출근해야 해요.     — Должен добраться до работы к 9.
오늘 야근해야 해요.        — Сегодня придётся работать сверхурочно.
```

## 13. -아/어도 되다 (разрешение «можно»)

**Правило:** как в разделе выше (아요/어요), но + 도 되다.

```
여기 앉아도 돼요?          — Здесь можно сесть?
창문을 열어도 돼요?        — Можно открыть окно?
벌써 집에 가도 돼요?       — Уже можно идти домой?
네, 가도 돼요.             — Да, можно идти.
```

## 14. -고 (последовательность действий)

```
-고 соединяет два действия в порядке выполнения:

아침에 일어나고 샤워해요.  — Встаю, (потом) принимаю душ.
밥을 먹고 학교에 가요.     — Ем и (затем) иду в школу.
일하고 운동해요.           — Работаю, потом занимаюсь спортом.
```

## 15. -어서 (причина или способ)

```
-어서 обозначает причину/основание или способ действия:

피곤해서 일찍 잤어요.      — Устал, поэтому лёг рано спать.
바빠서 전화 못 했어요.     — Был занят, поэтому не позвонил.
걸어서 학교에 가요.        — Хожу в школу пешком (способ).
친구를 만나서 같이 밥을 먹어요. — Встречаю друга и вместе едим.
```

## 16. -(으)러 가다 (идти, чтобы...)

**Правило:** основа + (으)러 가다 — цель движения (после согласной 으러, после гласной 러).

```
밥을 먹으러 식당에 가요.   — Иду в столовую поесть.
운동하러 체육관에 가요.    — Иду в зал заниматься.
커피를 마시러 카페에 와요. — Прихожу в кафе попить кофе.
```

## 17. -마다 (каждый) и -쯤 (примерно)

```
아침마다 커피를 마셔요.     — Каждое утро пью кофе.
주말마다 등산해요.          — Каждые выходные хожу в горы.
저녁마다 산책해요.          — Каждый вечер гуляю.

7시쯤 일어나요.             — Встаю около 7.
몇 시쯤 퇴근해요?           — Во сколько примерно заканчиваешь работу?
5분쯤 기다렸어요.           — Прождал около 5 минут.
```

## 18. Будущее время (-ㄹ 거예요)

**Правило:** основа + ㄹ/을 거예요 — намерение/план (+ 존댓말 -거예요).

```
내일 일찍 일어날 거예요.   — Завтра встану рано.
주말에 집에서 쉴 거예요.   — В выходные буду отдыхать дома.
다음 주에 시험을 볼 거예요. — На следующей неделе будет экзамен.
어디에서 지낼 거예요?      — Где будешь находиться?
```

## 19. 몇 시에 vs 몇 시간

```
몇 시에? — во сколько? (момент времени)
몇 시간? — сколько часов? (длительность)

몇 시에 일어나요?          — Во сколько встаёшь?  → 아침 6시에.
몇 시간 자요?              — Сколько часов спишь?  → 7시간.
두 시에 학교에 가요.       — Иду в школу в 2 часа (момент).
두 시간 동안 공부해요.     — Учусь два часа (длительность).
```

## 20. -(으)로 (инструмент / способ / направление)

**Правило:** после гласной 로, после согласной 으로.

```
지하철로 출근해요.         — Еду на работу на метро.
버스로 학교에 가요.        — Еду в школу на автобусе.
펜으로 써요.               — Пишу ручкой.
왼쪽으로 가세요.           — Идите налево.
```

## 연습

1. "Я встаю в 7 часов" → __________
2. "Я завтракаю в 8 часов" → __________
3. "Работаю с 9 до 6" → __________
4. "Вчера я учился" → __________
5. "Я живу в Сеуле" → __________

**Ответы:**

1. 7시에 일어나요 / 일어납니다
2. 8시에 아침을 먹어요 / 먹습니다
3. 9시부터 6시까지 일해요 / 일합니다
4. 어제 공부했어요 / 공부했습니다
5. 서울에 살아요 / 삽니다

## 연습 2 (дополнительно)

1. "Я должен встать в 7" → __________
2. "Здесь можно сидеть?" → __________
3. "Сейчас ем (в процессе)" → __________
4. "Не могу пойти на работу" → __________
5. "Иду поесть в столовую" → __________
6. "Каждое утро пью кофе" → __________
7. "Во сколько примерно встаёшь?" → __________
8. "Завтра буду отдыхать" → __________
9. "Еду на работу на метро" → __________
10. "Встаю и принимаю душ" → __________

**Ответы:**

1. 7시에 일어나야 해요.
2. 여기 앉아도 돼요?
3. 지금 먹고 있어요.
4. 출근하지 못해요 / 못 가요.
5. 밥을 먹으러 식당에 가요.
6. 아침마다 커피를 마셔요.
7. 몇 시쯤 일어나요?
8. 내일 쉴 거예요.
9. 지하철로 출근해요 / 지하철을 타고 가요.
10. 일어나고 샤워해요.
