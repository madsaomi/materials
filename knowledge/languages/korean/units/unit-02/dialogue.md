# Unit 2 — 대화: 하루 일과 (Распорядок дня)

## 대화

```
수진: 민수 씨, 매일 몇 시에 일어나요?
민수: 보통 7시에 일어나요. 수진 씨는요?
수진: 저는 6시에 일어나요. 아침에 조깅을 해요.
민수: 아, 그래요? 부럽네요! 아침에 뭐 드세요?
수진: 주로 토스트랑 커피를 마셔요. 민수 씨는요?
민수: 저는 밥하고 김치를 먹어요. 한국식 아침이 좋아요.
수진: 몇 시에 출근해요?
민수: 9시까지 회사에 가야 해요. 지하철로 30분 걸려요.
수진: 퇴근은 몇 시에 해요?
민수: 보통 6시에 퇴근해요. 가끔 야근도 해요.
수진: 저녁에 뭐 하세요?
민수: 운동하거나 친구를 만나요. 주말에는 영화를 봐요.
```

## 번역

| 한국어 | Русский |
|--------|---------|
| 일어나다 | Вставать |
| 보통 | Обычно |
| 조깅하다 | Бегать трусцой |
| 부럽다 | Завидую |
| 드시다 | Есть/пить (уваж.) |
| 주로 | В основном |
| 토스트 | Тосты |
| 출근하다 | Идти на работу |
| 퇴근하다 | Заканчивать работу |
| 지하철 | Метро |
| 걸리다 | Занимать (время) |
| 가끔 | Иногда |
| 야근하다 | Работать сверхурочно |
| 운동하다 | Заниматься спортом |
| 만나다 | Встречаться |

# Unit 2 — 대화 2: 주말에 뭐 해요? (Выходные)

## 대화

```
수진: 민수 씨, 주말에 보통 뭐 하세요?
민수: 토요일에는 늦게 일어나서 오전에 집에서 쉬어요.
수진: 저는 주말마다 등산을 가요.
민수: 등산? 어디로 가요?
수진: 북한산에 가요. 민수 씨도 같이 갈래요?
민수: 좋아요! 그런데 밥은 어떻게 해요?
수진: 등산하고 나서 식당에서 김치찌개를 먹어요.
민수: 정말요? 기대돼요!
```

## 해석

| 한국어 | Русский |
|--------|---------|
| 민수 씨, 주말에 보통 뭐 하세요? | Минсу, что ты обычно делаешь на выходных? |
| 토요일에는 늦게 일어나서 오전에 집에서 쉬어요. | В субботу встаю поздно и утром отдыхаю дома. |
| 저는 주말마다 등산을 가요. | Я каждые выходные хожу в горы. |
| 북한산에 가요. 민수 씨도 같이 갈래요? | Хожу на Пукхансан. Минсу, не хочешь пойти вместе? |
| 좋아요! | С удовольствием! |
| 등산하고 나서 식당에서 김치찌개를 먹어요. | После похода едим кимчи-ччиге в столовой. |
| 정말요? 기대돼요! | Правда? Уже жду! |

## 새 단어

| 한글 | 읽기 | 번역 |
|------|------|------|
| 주말 | чумаль | выходные |
| 토요일 | тхоёиль | суббота |
| 일요일 | ирёиль | воскресенье |
| 늦게 | нытке | поздно |
| 등산하다 | тынсанхада | ходить в горы |
| 북한산 | пукхансан | гора Пукхансан |
| 같이 | катки | вместе |
| 나서 | насо | после того как |
| 식당 | сикттан | столовая, ресторан |
| 김치찌개 | кимчхиччигэ | кимчи-ччиге |
| 기대되다 | кидэдведа | ожидать с нетерпением |
| 어떻게 | оттокхе | как |

## 문법 포인트

- **늦게 일어나서** — -아서: причина/обстоятельство (늦게 일어나다 + 서).
- **주말마다** — -마다: каждый. 주말마다 = каждые выходные.
- **갈래요?** — -ㄹ래요: разговорное приглашение «не хочешь ли…?».
- **등산하고 나서** — -고 나서: «после того как сделал что-то».

# Unit 2 — 대화 3: 식당에서 (В столовой)

## 대화

```
종업원: 손님, 뭐 드시겠어요?
민수: 불고기 하나하고 냉면 둘 주세요.
종업원: 음료수는 뭐 드릴까요?
수진: 콜라 두 잔하고 냉수 주세요.
종업원: 네, 잠시만요.
...
종업원: 여기 있습니다. 맛있게 드세요!
민수: 잘 먹겠습니다!
수진: 카드로 계산할게요.
종업원: 네, 그쪽 계산대에서 해 주세요.
```

## 해석

| 한국어 | Русский |
|--------|---------|
| 손님, 뭐 드시겠어요? | Гость, что будете есть? |
| 불고기 하나하고 냉면 둘 주세요. | Бульгоги одно и два хрустящих хлебца, пожалуйста. |
| 음료수는 뭐 드릴까요? | Какой напиток подать? |
| 콜라 두 잔하고 냉수 주세요. | Две колы и холодную воду, пожалуйста. |
| 네, 잠시만요. | Да, минутку. |
| 여기 있습니다. 맛있게 드세요! | Вот, пожалуйста. Приятного аппетита! |
| 잘 먹겠습니다! | Спасибо, приятного аппетита! |
| 카드로 계산할게요. | Оплачу картой. |
| 그쪽 계산대에서 해 주세요. | Оплатите вон там, на кассе. |

## 새 단어

| 한글 | 읽기 | 번역 |
|------|------|------|
| 종업원 | чонобон | официант |
| 손님 | соним | гость |
| 불고기 | пульгоги | бульгоги |
| 냉면 | нэнмён | нэнмён (холодная лапша) |
| 음료수 | ымнёсу | напиток |
| 콜라 | кхолла | кола |
| 잔 | чан | стакан/чашка (счётн.) |
| 잠시만요 | чамсиманнё | минутку |
| 맛있게 드세요 | маситке дысэё | приятного аппетита |
| 계산하다 | кесанхада | платить |
| 계산대 | кесандэ | касса |
| 카드 | кхады | карта |

## 문법 포인트

- **드시겠어요?** — 드시다 (уваж. «есть») + -시- (уваж.) + -겠- (будущее) + 어요.
- **불고기 하나하고 냉면 둘** — числительное стоит после существительного при счёте.
- **드릴까요?** — 드리다 (уваж. «давать») + -ㄹ까요? «что…?» (вопрос-предложение).
- **-ㄹ게요** — намерение говорящего: 계산할게요 «я (вот) оплачу».

# Unit 2 — 대화 4: 전화로 약속 (По телефону)

## 대화

```
수진: 여보세요? 민수 씨, 저예요. 수진이에요.
민수: 아, 수진 씨! 안녕하세요.
수진: 내일 같이 시험 공부 할래요?
민수: 내일은 좀 바빠요. 이틀 후에 어때요?
수진: 좋아요. 그럼 때까지 몇 시에 만날까요?
민수: 저녁 7시쯤 도서관에서 만나요.
수진: 좋아요. 그러면 만나서 봐요!
민수: 네, 그때 봐요. 안녕히 계세요!
```

## 해석

| 한국어 | Русский |
|--------|---------|
| 여보세요? 민수 씨, 저예요. 수진이에요. | Алло? Минсу, это я, Су Джин. |
| 아, 수진 씨! 안녕하세요. | А, Суджин! Здравствуйте. |
| 내일 같이 시험 공부 할래요? | Завтра не хочешь заниматься вместе к экзамену? |
| 내일은 좀 바빠요. 이틀 후에 어때요? | Завтра я немного занят. Как насчёт через два дня? |
| 좋아요. 그럼 몇 시에 만날까요? | Хорошо. Тогда во сколько встретимся? |
| 저녁 7시쯤 도서관에서 만나요. | Встретимся около 7 вечера в библиотеке. |
| 좋아요. 그러면 그때 봐요! | Отлично. Тогда до встречи! |
| 네, 그때 봐요. 안녕히 계세요! | Да, до встречи. До свидания! |

## 새 단어

| 한글 | 읽기 | 번역 |
|------|------|------|
| 여보세요 | ёбосэё | алло |
| 시험 | сихом | экзамен |
| 같이 | катки | вместе |
| 바쁘다 | паппыйда | быть занятым |
| 이틀 | итыль | два дня |
| 후에 | хуге | после, через (время) |
| 그럼/그러면 | кыром/кыромён | тогда, в таком случае |
| 몇 시에 | мёт сигэ | во сколько |
| 도서관 | тосогван | библиотека |
| 만나다 | маннада | встречаться |
| 안녕히 계세요 | аннёнхи гесэё | до свидания (вы уходите) |

## 문법 포인트

- **여보세요?** — стандартное приветствие по телефону.
- **할래요?** — -ㄹ래요: предложение «давай…?» / «не хочешь…?».
- **어때요?** — от 어떻다 «какой»: «как насчёт…?».
- **몇 시에 만날까요?** — -ㄹ까요?: совместное обсуждение «встретимся во сколько?».
- **7시쯤** — -쯤: примерно, около.
