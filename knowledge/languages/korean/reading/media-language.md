# 미디어 언어 — Язык корейских СМИ

## 1. Особенности газетных заголовков

Корейский газетный заголовок — это особая «телеграфная» грамматика. От обычной речи он отличается рядом приёмов:

1. **Опущение частиц.** Частицы темы/субъекта (은/는, 이/가) и другие опускаются, остаётся «скелет» фразы:
   - `정부, 물가안정 대책 발표` (а не 정부는 ...을 발표했음)
2. **Настоящее время вместо прошедшего.** Событие передаётся как происходящее прямо сейчас (так называемое «заголовочное настоящее»):
   - `국민연금, 인상 결정` — «национальная пенсия приняла решение о повышении».
3. **Инфинитивные/причастные формы (관형형).** Номинальные конструкции, где глагол превращается в определение:
   - `늘어난 1인 가구`, `떨어지는 출산율`.
4. **Один длинный композит.** Несколько определений перед одним существительным:
   - `기록적 폭염에 전력 수요 급증` — «из-за рекордной жары резкий рост спроса на электроэнергию».
5. **Излюбленные глаголы:** `밝히다` (сообщить), `발표하다` (объявить), `결정하다` (решить), `지적하다` (указать), `예상되다` (ожидается).
6. **Перечисление через `·` и `〜`:** `3·1절`, `물가·주가`, `35~40%`.

**Примеры типичных заголовков:**

| Заголовок | Перевод |
|-----------|---------|
| 물가 상승률 사상 최고치 기록 | Инфляция ставит исторический рекорд |
| 정부, 출산 장려 정책 발표 | Правительство объявляет политику стимулирования рождаемости |
| 코로나 이후 첫 대규모 보양식 수요 | Впервые после ковида — массовый спрос на укрепляющие блюда |
| 글로벌 공급망 위기, 제조업 직격탄 | Кризис глобальных поставок — прямой удар по промышленности |
| 기후 변화로 작년 단풍 시기도 변화 | Из-за изменения климата сместился и сезон осенней листвы |
| 저출산·고령화, 지방 소멸 가속 우려 | Низкая рождаемость и старение — опасения ускоренного угасания регионов |

## 3. Канцелярские обороты официальных документов

Цитата, статистика, официальная отчётность используют устойчивые рамки:

| Выражение | Перевод | Пример |
|-----------|---------|--------|
| ~에 따르면 | согласно | 기상청 예보에 따르면 |
| ~을/를 두고 | по поводу, вокруг | 물가 대책을 두고 논란이 일었다 |
| 제기되고 있다 | выдвигается (вопрос) | 우려가 제기되고 있다 |
| ~이/가 우려된다 | есть опасения | 고공학적 악화가 우려된다 |
| 도입을 검토 중이다 | рассматривается введение | 탄소세 도입을 검토 중이다 |
| 시행을 앞두고 있다 | на пороге введения | 새 규정 시행을 앞두고 있다 |
| 지적했다 | указали | 전문가들은 지적했다 |
| ~하는 것으로 나타났다 | оказалось, что... | 소비 심리가 위축된 것으로 나타났다 |

## 4. Официально-деловые клише для переписки (비스니스)

Деловая переписка (см. texts-advanced.md) строится на фиксированных формулах:

1. **Вступление:** `안녕하십니까, ...입니다.`, `늘 관심 감사드립니다.`
2. **Отрыв деловой части:** `다름이 아니라, ...`, `본론으로 들어가면, ...`
3. **Просьба:** `알려 주시면 감사하겠습니다.`, `부탁드립니다.`, `회신 부탁드립니다.`
4. **Приложение:** `첨부 파일을 확인해 주시기 바랍니다.`
5. **Заключение:** `수고하십시오.`, `안녕히 계십시오.`, `감사합니다.`
6. **Подпись:** `한빛무역 대리 김수진 드림`

**Уважительные глаголы в деловых письмах:** `드리다` (давать, уваж.), `여쭤 보다` (спрашивать), `말씀드리다` (сообщать), `찾아뵙다` (навещать, уваж.), `보시고` (посмотрев — вместо 보다).

## 5. Игра с заголовком: тренировка «제목 고르기»

В TOPIK II задания 21–22 — выбрать заголовок к заметке. Алгоритм:

1. Прочитайте первый абзац (тезис) и последнюю фразу (вывод).
2. Сопоставьте: заголовок должен синтезировать **обе** идеи.
3. Отбросьте варианты:
   - слишком узкие (деталь, а не суть),
   - слишком широкие (общая тема без конкретики),
   - те, где факт искажён (преувеличение или перевёрнутая причинность).
4. Помните: заголовок в газете почти всегда пишется в «заголовочном настоящем», без частиц — значит, и в вариантах ответа ищите такую форму.
