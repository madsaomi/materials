# Корейский — Тексты для чтения

## Текст 1: 자기 소개 (Знакомство)

```
안녕하세요! 저는 김민수입니다.
한국 사람이고, 스물다섯 살입니다.
서울대학교에서 공부하고 있습니다.
전공은 컴퓨터공학입니다.
취미는 독서와 운동입니다.
만나서 반갑습니다!

번역:
Здравствуйте! Я Ким Минсу.
Я кореец, мне 25 лет.
Учусь в Сеульском национальном университете.
Моя специальность — компьютерная инженерия.
Хобби — чтение и спорт.
Приятно познакомиться!

새로운 단어:
취미 — хобби
독서 — чтение
운동 — спорт
```

## Текст 2: 하루 일과 (Распорядок дня)

```
저는 매일 아침 7시에 일어납니다.
세수를 하고, 아침을 먹습니다.
8시에 집을 나와서 학교에 갑니다.
수업은 9시부터 3시까지입니다.
점심은 학교 식당에서 먹습니다.
오후에는 도서관에서 공부합니다.
저녁에 친구와 만나서 이야기합니다.
밤 11시에 잡니다.

번역:
Я каждый день встаю в 7 утра.
Умываюсь и завтракаю.
В 8 выхожу из дома и иду в школу.
Уроки с 9 до 3.
Обедаю в школьной столовой.
После обеда учусь в библиотеке.
Вечером встречаюсь с другом и разговариваю.
В 11 ночи ложусь спать.
```

## Текст 3: 한국의 명절 (Корейские праздники)

```
한국에는 설날과 추석이 가장 큰 명절입니다.
설날은 음력 1월 1일입니다.
가족이 모여서 떡국을 먹고, 세배를 합니다.
추석은 음력 8월 15일입니다.
송편을 만들고, 성묘를 갑니다.
두 명절 모두 고향에 가서 가족과 시간을 보냅니다.

번역:
В Корее самые большие праздники — Соллаль и Чхусок.
Соллаль — 1 января по лунному календарю.
Семья собирается, едят ттоккук, делают себэ (поклон).
Чхусок — 15 августа по лунному календарю.
Делают сонпён, ходят на могилы предков.
Оба праздника проводят в родных краях с семьёй.
```

## Текст 4: 지하철 에티켓 (Этикет метро)

```
한국 지하철에서는 몇 가지 에티켓이 있습니다.
먼저, 지하철 안에서 음식을 먹지 마세요.
휴대폰으로 통화하지 마세요. 문자를 보내세요.
노약자석에는 앉지 마세요.
내릴 때는 먼저 내리는 사람이 있도록 기다리세요.
출퇴근 시간에는 지하철이 매우 복잡합니다.
줄을 서서 기다리는 것이 중요합니다.

번역:
В корейском метро есть несколько правил этикета.
Во-первых, не ешьте в метро.
Не разговаривайте по телефону. Пишите смс.
Не садитесь на места для пожилых.
При выходе подождите, пока выйдут выходящие.
В часы пик метро очень загружено.
Важно стоять в очереди.

새로운 단어:
지하철 — метро
에티켓 — этикет
음식 — еда
휴대폰 — мобильный телефон
통화하다 — разговаривать (по тел.)
문자 — сообщение
노약자석 — места для слабых
내리다 — выходить (из транспорта)
출퇴근 시간 — часы пик
복잡하다 — сложный/загруженный
줄을 서다 — стоять в очереди
```

## Текст 5: 한국 길거리 음식 (Уличная еда Кореи)

```
한국에는 맛있는 길거리 음식이 많습니다.
떡볶이는 매운 떡 요리입니다. 길거리에서 가장 인기 있습니다.
김밥은 김에 밥과 여러 재료를 넣어 만듭니다.
순대는 돼지 창자에 당면과 야채를 넣어 만듭니다.
튀김은 감자, 고구마, 김말이 등을 튀긴 겁니다.
호떡은 반죽 안에 설탕과 견과류를 넣어 구운 빵입니다.
가격은 보통 1000원에서 3000원 사이입니다.

번역:
В Корее много вкусной уличной еды.
Ттокпокки — острое блюдо из рисовых палочек. Самое популярное.
Кимбап — рис с начинкой, завёрнутый в водоросли.
Сундэ — свиная кишка, начинённая лапшой и овощами.
Твигим — жареные овощи (картофель, батат, ким).
Хотток — жареный пирожок с сахаром и орехами.
Цена обычно 1000-3000 вон.

새로운 단어:
길거리 — улица
음식 — еда
떡볶이 — ттокпокки
매운 — острый
김밥 — кимбап
순대 — сундэ
튀김 — твигим (жареное)
호떡 — хотток
가격 — цена
```
