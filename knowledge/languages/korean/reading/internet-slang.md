# 인터넷 언어 — Сокращения и интернет-сленг

Краткая справка: пригодится для чтения комментариев, чатов, драм и KakaoTalk. Для серьёзных текстов (газет, экзаменов TOPIK) эти формы не используются.

## 1. Условные сокращения (초성체)

Корейцы сокращают слова до начальных согласных (초성). Наиболее частые:

| Сокращение | Расшифровка | Перевод |
|------------|-------------|---------|
| ㄱㅅ | 감사 | спасибо |
| ㄱㄱ | 고고 | поехали! (go go) |
| ㅇㅋ | 오케이 | окей |
| ㅇㅇ | 응응 | ага, угу |
| ㄴㄴ | 노노 | нет-нет |
| ㄷㅊ | 다행 | повезло, к счастью |
| ㄱㄷ | 기달려 (기다려) | жди |
| ㅈㅅ | 죄송 | извини |
| ㅊㅋ | 축하 | поздравляю |
| ㅊㅊ | 축축 (축하 축하) | поздравляю-поздравляю |
| ㅅㄱ | 셤개?/사과 | (часто) самореклама / извинение — по контексту |
| ㅇㅈ | 인정 | согласен, признаю |
| ㅇㄷ | 어디 | где? |
| ㄹㄷ | 루디 | сел (мем) — гримаса |
| ㅋㅋ | (ха-ха) | смех |
| ㅎㅎ | (хе-хе) | лёгкий смех |
| ㅠㅠ / ㅜㅜ | (плач) | обида, грусть |
| ㅡㅡ | (прямая мина) | безэмоционально |
| ㄷㄷ | (дрожь) | круто/офигеть (букв. постукивание зубов) |
| ㅁㄴㅇ | (случайные клавиши) | «просто печатаю», чтобы чат не закрылся / ничегонеделание |

**ㅁㄴㅇ (чикенджцене):** когда собеседник пишет «сейчас», «минуту», но ещё печатает, собеседники тоже «стучат» случайными клавишами, чтобы диалог не завершился. Отсюда и употребление: сигнал «я тут, пишу».

**Пример переписки:**

```
A: 밥 먹었어?
B: ㅇㅇ ㅋㅋ 방금
A: ㅇㅋ 그럼 오늘 ㄱㄱ?
B: ㅅㄱ ㅅㄱ ㅎㅎ 
A: ㅊㅋㅊㅋ 오늘 내 생일이야
B: 어어 진짜? ㅊㅋㅊㅋ!! ㄱㅅ
```

## 3. Символы и эмодзи-заменители

| Символ | Значение |
|--------|----------|
| ㅋㅋㅋㅋ | сильный смех |
| ㅎㅎㅎ | мягкий смех, стеснение |
| ㅠㅠ / ㅜㅜ | горе, жалость |
| ㅠㅡㅠ | усиленный плач |
| ㅡㅡ | равнодушие/недовольство |
| ^^ | улыбка (традиционная) |
| T_T | слёзы (западный стиль) |
| 🤣👍 | эмодзи-замена смеха и одобрения |

## 4. Культурная оговорка

- 초성체 пишут **только** в неформальной переписке с равными и близкими. В официальных сообщениях, на работе, в письмах старшим сокращения недопустимы — там полный вежливый стиль.
- Часть сокращений меняет значение: `ㄱㄱ` может значить «пойдём», а `ㄱㅅ` — «спасибо», поэтому ориентируйтесь на контекст.
- Для подготовистов TOPIK: в экзамене такие формы не встречаются, но их знание помогает понимать современную речь, комменты под роликами и живые диалоги на KakaoTalk.
