# Unit 3 — 연습 (Практика)

## 연습 1: 빈칸 (Заполните)

1. 지하철역이 어디___ 있어요?
2. 오른쪽___ 가세요.
3. 명동___ 가려면 4호선을 타세요.
4. 여기___ 사진을 찍어도 돼요?
5. 서울___ 부산___ 기차로 2시간 걸려요.

**Варианты:** 에, (으)로, 에서...까지, 에, 에서

## 연습 2: 번역

1. Где находится станция метро? → __________
2. Идите прямо, пожалуйста. → __________
3. Поверните направо. → __________
4. Сколько минут идти пешком? → __________
5. Садитесь на 4-ю линию. → __________

## 연습 3: (으)려면

Составьте предложения с (으)려면:

1. 명동 / 가다 / 4호선 / 타다 → __________
2. 한국어 / 배우다 / 열심히 / 공부하다 → __________
3. 서울 / 가다 / 기차 / 타다 → __________
4. 밥 / 먹다 / 식당 / 가다 → __________

## 연습 4: 아/어도 되다 / (으)면 안 되다

Ответьте на вопросы, используя можно/нельзя:

1. 여기에서 담배를 피워도 돼요?
   → 아니요, __________
2. 여기 앉아도 돼요?
   → 네, __________
3. 사진을 찍어도 돼요?
   → 아니요, __________

## 연습 5: 대화

Составьте диалог "Как пройти до музея":
- Турист спрашивает дорогу
- Местный объясняет (прямо, поворот, ориентиры)
- Сколько времени
- Благодарность

## 답안 (Ответы)

**연습 1:**
1. 에
2. (으)로
3. 에
4. 에서
5. 에서...까지

**연습 2:**
1. 지하철역이 어디에 있어요?
2. 직진하세요.
3. 오른쪽으로 가세요 / 도세요.
4. 걸어서 몇 분 걸려요?
5. 4호선을 타세요.

**연습 3:**
1. 명동에 가려면 4호선을 타세요.
2. 한국어를 배우려면 열심히 공부해야 해요.
3. 서울에 가려면 기차를 타세요.
4. 밥을 먹으려면 식당에 가세요.

**연습 4:**
1. 여기에서 담배를 피우면 안 돼요.
2. 네, 앉아도 돼요.
3. 아니요, 사진을 찍으면 안 돼요.
