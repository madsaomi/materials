# Unit 3 — 대화: 길을 묻다 (Спрашиваем дорогу)

## 대화

```
관광객: 실례합니다. 지하철역이 어디에 있어요?
지나가는 사람: 저쪽에 있어요. 여기서 직진하세요.
관광객: 얼마나 걸려요?
지나가는 사람: 걸어서 5분쯤 걸려요.
관광객: 감사합니다. 그리고 명동에 가려면 어떻게 해요?
지나가는 사람: 지하철 4호선을 타세요. 명동역에서 내리세요.
관광객: 몇 정거장이에요?
지나가는 사람: 세 정거장이에요.
관광객: 아, 네. 고맙습니다!
지나가는 사람: 아니에요. 즐거운 여행 되세요!
```

## 번역

| 한국어 | Русский |
|--------|---------|
| 실례합니다 | Извините |
| 어디에 있어요 | Где находится? |
| 저쪽 | Вон там |
| 직진하다 | Идти прямо |
| 얼마나 걸려요 | Сколько времени займёт? |
| 걸어서 | Пешком |
 | ~쯤 | Примерно |
| 명동 | Мёндон (район) |
| 가려면 | Если хотите пойти |
| 호선 | Линия метро |
| 타다 | Садиться (на транспорт) |
| 내리다 | Выходить (из транспорта) |
| 정거장 | Остановка/станция |
| 고맙습니다 | Спасибо |
| 즐거운 여행 | Счастливого пути |

## 대화 2: 기차역에서 (На вокзале)

```
A: 실례합니다. 부산까지 기차표를 사고 싶어요.
B: 일반석이에요, 아님 특실이에요?
A: 일반석으로 주세요. 편도로 한 장 주세요.
B: 네, 출발 시간은 언제로 할까요?
A: 오후 3시쯤으로 해 주세요.
B: 오후 3시 기차는 이미 매진됐어요. 4시가 어때요?
A: 괜찮아요. 4시로 해 주세요. 얼마예요?
B: 오천육백 원입니다.
```

### 번역

```
A: Извините. Хочу купить билет на поезд до Пусана.
B: Обычный класс или первый класс (специальное купе)?
A: Обычный класс, пожалуйста. Один билет в одну сторону.
B: Хорошо. На какое время отправления?
A: Сделайте, пожалуйста, около 3 часов дня.
B: Поезд на 3 дня уже продан (нет мест). Как насчёт 4 часов?
A: Хорошо. Сделайте на 4 часа. Сколько это?
B: 5600 вон.
```

### 새 단어 и разбор

| 한국어 | 읽기 | 번역 / разбор |
|--------|------|--------|
| 기차표 | кичхапхё | железнодорожный билет |
| 사고 싶어요 | саго сипхоё | хочу купить (-고 싶다 — хотеть) |
| 일반석 | ильбансок | обычный класс |
| 특실 | тхыксиль | купе / первый класс |
| 편도 | пхёндо | в одну сторону |
| 한 장 | хан чан | один билет (счётное слово) |
| 출발 시간 | чхульбаль сиган | время отправления |
| ~쯤 | ччым | около, примерно |
| 매진되다 | мэджинтведа | быть распроданным |
| 어때요 | оттхэё | как насчёт? (как тебе?) |

## 대화 3: 길을 못 찾을 때 (Когда не можете найти дорогу)

```
A: 죄송한데요. 여기 근처에 은행이 있어요?
B: 네, 있어요. 시청 건물 맞은편이에요.
A: 시청은 어떻게 가야 해요?
B: 이 길을 따라 직진해서 사거리에서 왼쪽으로 도세요.
A: 사거리에서 왼쪽으로요?
B: 네. 그러면 바로 보여요. 10분쯤 걸려요.
A: 잘 알겠습니다. 정말 감사합니다.
B: 천만에요. 조심히 가세요.
```

### 번역

```
A: Извините. Рядом есть банк?
B: Да, есть. Он напротив здания мэрии.
A: Как дойти до мэрии?
B: Идите прямо по этой улице и на перекрёстке поверните налево.
A: На перекрёстке налево?
B: Да. Тогда сразу увидите. Займёт около 10 минут.
A: Понял. Большое спасибо.
B: Не за что. Идите осторожно.
```

### 새 단어 и разбор

| 한국어 | 읽기 | 번역 / разбор |
|--------|------|--------|
| 죄송한데요 | чвэсонъхандеё | извините (с контекстом -는데) |
| 근처 | кынчхо | рядом, поблизости |
| 맞은편 | маджынпхён | напротив |
| 따라 직진하다 | ттара чикчинхада | идти прямо вдоль |
| 사거리 | сагори | перекрёсток |
| 도세요 | тосэё | поверните (вежл. повелит.) |
| ~면 | мён | если (условие) |
| 바로 보여요 | паро поёё | сразу видно |
| 천만에요 | чхонманэё | не за что, не стоит |
| 조심하다 | чосимхада | быть осторожным |

## 대화 4: 환승하기 (Делаем пересадку)

```
A: 실례합니다. 이 버스가 공항에 가요?
B: 아니요. 이 버스는 시청까지만 가요.
A: 그럼 공항에 가려면 어디에서 환승해야 해요?
B: 시청 정류장에서 6015번 버스로 갈아타세요.
A: 6015번이 자주 와요?
B: 네, 10분마다 와요. 걸어서가 아니라 버스로 가는 게 편해요.
A: 알겠어요. 정류장은 어디에 있어요?
B: 저 건물 앞이에요. 신호등 건너편에 있어요.
A: 정말 고맙습니다. 잘 갈게요!
```

### 번역

```
A: Извините. Этот автобус едет в аэропорт?
B: Нет. Этот автобус едет только до мэрии.
A: Тогда где нужно сделать пересадку, чтобы поехать в аэропорт?
B: На остановке у мэрии пересядьте на автобус 6015.
A: Автобус 6015 ходит часто?
B: Да, приходит каждые 10 минут. Не пешком, а на автобусе удобнее.
A: Понял. Где находится остановка?
B: Перед тем зданием. За светофором, напротив.
A: Большое спасибо. Пойду!
```

### 새 단어 и разбор

| 한국어 | 읽기 | 번역 / разбор |
|--------|------|--------|
| 환승하다 | хвансынхада | делать пересадку |
| ~까지 | ккаджи | до (места/предела) |
| 그럼 | кыром | тогда (в таком случае) |
| 갈아타다 | каратхада | пересесть (на др. транспорт) |
| 자주 오다 | чаджу ода | часто приходить |
| 10분마다 | сиппунмада | каждые 10 минут (-마다 — каждый) |
| 알겠어요 | альгессоё | понял |
| 신호등 | синходын | светофор |
| 건너편 | коннопион | по ту сторону |

## 대화 5: 택시에서 (В такси)

```
A: 기사님, 명동역까지 가 주세요.
B: 네, 명동역이요? 어느 쪽 출구로 갈까요?
A: 4번 출구요. 그런데 시간이 얼마나 걸려요?
B: 지금은 길이 막혀서 30분쯤 걸려요.
A: 아, 조금 늦네요. 빨리 가 주세요.
B: 최선을 다할게요. 이 근처에는 공사 중이라 조심해서 운전할게요.
A: 안전하게 가 주세요. 잠깐, 여기서 잠깐 세워 주세요.
B: 여기요? 아직 역이 좀 남았는데요.
A: 괜찮아요. 저기 보이는 커피숍 앞에서 내릴게요.
B: 네, 알겠습니다. 요금은 만 칠천 원입니다.
```

### 번역

```
A: Водитель, отвезите, пожалуйста, на станцию Мёндон.
B: Да, станция Мёндон? К какому выходу?
A: К выходу 4. Кстати, сколько времени займёт?
B: Сейчас дорога загружена, так что около 30 минут.
A: А, немного поздно. Пожалуйста, быстрее.
B: Сделаю всё возможное. Здесь рядом идут работы, поеду осторожно.
A: Поезжайте безопасно. Минуту, остановите здесь ненадолго.
B: Здесь? До станции ещё немного осталось.
A: Нормально. Выйду у кофейни, которую видать там.
B: Да, понял. Плата 17000 вон.
```
