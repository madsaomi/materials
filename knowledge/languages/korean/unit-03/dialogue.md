# Unit 3 — 대화: 길을 묻다 (Спрашиваем дорогу)

## 대화

```
관광객: 실례합니다. 지하철역이 어디에 있어요?
지나가는 사람: 저쪽에 있어요. 여기서 직진하세요.
관광객: 얼마나 걸려요?
지나가는 사람: 걸어서 5분쯤 걸려요.
관광객: 감사합니다. 그리고 명동에 가려면 어떻게 해요?
지나가는 사람: 지하철 4호선을 타세요. 명동역에서 내리세요.
관광객: 몇 정거장이에요?
지나가는 사람: 세 정거장이에요.
관광객: 아, 네. 고맙습니다!
지나가는 사람: 아니에요. 즐거운 여행 되세요!
```

## 번역

| 한국어 | Русский |
|--------|---------|
| 실례합니다 | Извините |
| 어디에 있어요 | Где находится? |
| 저쪽 | Вон там |
| 직진하다 | Идти прямо |
| 얼마나 걸려요 | Сколько времени займёт? |
| 걸어서 | Пешком |
 | ~쯤 | Примерно |
| 명동 | Мёндон (район) |
| 가려면 | Если хотите пойти |
| 호선 | Линия метро |
| 타다 | Садиться (на транспорт) |
| 내리다 | Выходить (из транспорта) |
| 정거장 | Остановка/станция |
| 고맙습니다 | Спасибо |
| 즐거운 여행 | Счастливого пути |
