# Unit 1 — 대화: 안녕하세요! (Здравствуйте!)

## 대화 (Диалог)

```
민수: 안녕하세요! 저는 김민수입니다. 이름이 뭐예요?
지영: 안녕하세요! 저는 박지영이에요. 만나서 반갑습니다!
민수: 저도 반가워요! 지영 씨는 학생이에요?
지영: 네, 저는 학생이에요. 서울대학교에서 공부해요. 민수 씨는요?
민수: 저는 회사원이에요. 삼성에서 일해요.
지영: 아, 그래요? 몇 살이에요?
민수: 스물다섯 살이에요. 지영 씨는요?
지영: 저는 스물두 살이에요.
민수: 한국어를 잘하시네요! 어디에서 한국어를 배웠어요?
지영: 학교에서 배웠어요. 아직 잘 못해요.
민수: 아니에요, 아주 잘해요!
지영: 감사합니다! 다음에 또 만나요!
민수: 네, 안녕!
```
