# Unit 1 — 문법 (Грамматика)

## 1. 이다 (быть)

**Структура:** [сущ.] + 이/가 + [сущ.] + 이다

```
저는 학생입니다.       — Я студент.
이것은 책입니다.       — Это книга.
저는 김민수입니다.     — Я Ким Минсу.
```

**Неформально-вежливо:** 예요 / 이에요
```
학생이에요.           — Я студент.
책이에요.             — Это книга.
민수예요?             — Это Минсу?
```

**Отрицание:** 아니다 / 이/가 아니다
```
학생이 아닙니다.      — Я не студент.
책이 아니에요.        — Это не книга.
```

## 2. 은/는 (тематическая частица)

После согласной: **은**, после гласной: **는**

```
저는 학생이에요.      — Я (тема) студент.
이것은 책이에요.      — Это (тема) книга.
민수는 회사원이에요.  — Минсу (тема) офисный работник.
```

## 3. 이/가 (субъектная частица)

После согласной: **이**, после гласной: **가**

```
이것이 책이에요.      — Это (именно эта) книга.
누가 왔어요?          — Кто пришёл?
한국어가 어려워요.    — Корейский (субъект) сложный.
```

## 4. Вопросы

**예/아니오 ответы на вопросы с 이다:**
```
학생이에요? — 네, 학생이에요. / 아니요, 학생이 아니에요.
```

**Вопросительные слова:**
| 한국어 | Чтение | Перевод |
|--------|--------|---------|
| 누구 | нугу | кто |
| 무엇/뭐 | муот/мво | что |
| 어디 | оди | где |
| 언제 | ондже | когда |
| 왜 | вэ | почему |
| 어떻게 | оттокхе | как |
| 몇 | мёт | сколько |
| 얼마 | ольма | сколько (цена) |

## 5. 에 있다 / 없다 (находиться / не находиться)

```
집에 있어요.          — Я дома.
학교에 없어요.        — Меня нет в школе.
어디에 있어요?        — Где (находится)?
```

## 6. Числа (исконные)

| Число | Хангыль | Чтение |
|-------|---------|--------|
| 1 | 하나 | хана |
| 2 | 둘 | туль |
| 3 | 셋 | сэт |
| 4 | 넷 | нэт |
| 5 | 다섯 | тасот |
| 6 | 여섯 | ёсот |
| 7 | 일곱 | ильгоп |
| 8 | 여덟 | ёдоль |
| 9 | 아홉 | ахоп |
| 10 | 열 | ёль |

Для возраста используем исконные числа + 살:
```
한 살, 두 살, 세 살, 네 살...
스무 살 (20), 서른 살 (30)
```

## 7. Вежливое окончание: ㅂ니다/습니다

После гласной: **ㅂ니다**
После согласной: **습니다**
```
합니다            — Делаю.
먹습니다          — Ем.
갑니다            — Иду.
```

## 8. 에 대한 — о/об

Пример в этом уроке не используется, оставим на потом.

## 연습 (Упражнения)

1. Переведите: "Я студент" → __________
2. Переведите: "Это книга" → __________
3. Вопрос: "Вы студент?" → __________
4. Отрицание: "Я не учитель" → __________
5. "Меня зовут Минсу" → __________

**Ответы:**
1. 저는 학생입니다 / 학생이에요
2. 이것은 책입니다 / 책이에요
3. 학생이에요? / 학생입니까?
4. 저는 선생님이 아닙니다 / 아니에요
5. 저는 민수입니다 / 민수예요
