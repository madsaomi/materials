# Unit 1 — 연습 (Практика)

## 연습 1: 빈칸 채우기 (Заполните пропуски)

1. 저___ 김민수입니다.
2. 이것___ 책이에요.
3. 학생이___? — 네, 학생이에요.
4. 저___ 선생님이 아닙니다.
5. 이름___ 뭐예요?

**Варианты:** 은, 는, 이, 가, 이에요

## 연습 4: 대화 완성 (Закончите диалог)

```

B: ___, 회사원이에요.
A: 몇 ___이에요?

```
