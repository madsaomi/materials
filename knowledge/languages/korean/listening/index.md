## 1. Введение — почему аудирование трудно и стратегия

<a id="1-введение"></a>

### Почему аудирование — самая сложная дисциплина

Для русскоязычных учащихся корейский язык представляет уникальные вызовы на уровне аудирования. Ниже перечислены главные причины трудностей и способы их преодоления.

**1. Система слоговых окончаний (batchim / 받침).**
Корейские слова часто заканчиваются согласными, которые меняют произношение следующего слова. Например, `많다` (ман-та, «много») при связной речи превращается в `만타`. Русский язык не имеет аналогичной системы финальных согласных, поэтому уши обучены воспринимать каждое слово как отдельный блок.

**2. Тense consonants (경음절 / 겹자음).**
Пары `ㄱ/ㄲ`, `ㄷ/ㄸ`, `ㅂ/ㅃ`, `ㅅ/ㅆ`, `ㅈ/ㅉ` различаются по степени напряжённости. В быстрой речи `ㄲ` звучит как усиленный `ㄱ`, что заставляет начинающих терять границу между словами.

**3. Двойные гласные (이중 모음).**
`ㅘ`, `ㅙ`, `ㅚ`, `ㅟ`, `ㅢ`, `ㅒ` — эти дифтонги не имеют прямых аналогов в русской фонетике. `ㅚ` (ой) и `ㅟ` (и) особенно коварны, поскольку русские часто подменяют их монофтонгами.

**4. Ритм и ударение.**
Корейский — язык с равноударным ритмом (по принципу морной ударенности). Каждый слог получает примерно равное время, в отличие от русского, где акцент падает на определённый слог. Это делает темп корейской речи кажущимся однородным и быстрым для неподготовленного уха.

**5. Дополнительные звуки (예외음).**
Произношения `ㅃ` [пп], `ㄸ` [тт], `ㄲ` [кк], `ㅆ` [сс], `ㅉ` [чч] не имеют точных аналогов в русском. Звук `ㄹ` — ретрофлексный боковой [ɾ] — ближе к быстрому американскому «r», а не к русскому «р» или «л».

### Стратегия аудирования: три уровня обработки

Эффективное аудирование строится на трёх уровнях:

```
┌──────────────────────────────────────────────────────────┐
│  УРОВЕНЬ 3: СЕМАНТИЧЕСКОЕ ПОНИМАНИЕ                      │
│  «Что автор хотел сказать? Какова суть высказывания?»    │
│  → Критическое мышление, выводы, интерпретация          │
├──────────────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: ПАРАГРАФНОЕ ПОНИМАНИЕ                        │
│  «Какие ключевые слова я ловлю? Какая грамматика?»        │
│  → Лексика + грамматические формы в контексте            │
├──────────────────────────────────────────────────────────┤
│  УРОВЕНЬ 1: ФОНЕМИЧЕСКОЕ ВОСПРИЯТИЕ                      │
│  «Какие звуки я слышу? Какие окончания?»                 │
│  → Различение ㄱ/ㄲ, batchim, звуков ㅂ/p, ㄹ/r и др.   │
└──────────────────────────────────────────────────────────┘
```

**Принцип:** Не переходите к Уровню 2 и 3, пока Уровень 1 не станет автоматическим. Первые 4–6 недель тренируйтесь исключительно на различиях звуков.

### Три режима прослушивания

Каждую тренировку используйте три режима:

| Режим | Цель | Как делать |
|-------|------|------------|
| **Extensive** (экстенсивное) | Общее понимание | Слушайте длинные тексты (подкасты, драмы) без остановки, не ищите каждое слово |
| **Intensive** (интенсивное) | Детальный разбор | Слушайте короткий фрагмент (20–40 сек), останавливайте, разбирайте каждое слово, сопоставляйте с текстом |
| **Shadowing** (теневое) | Производство речи | Повторяйте за носителем с задержкой 0.5–1 сек, копируя интонацию, ритм и ударения |

### Рекомендуемая структура занятия (30–45 минут)

```
┌──────────────────────────────────────────────────────────┐
│  1. Warm-up (3 мин) — лёгкий Extensive: новостная       │
│     зарисовка или погода на корейском                    │
│                                                          │
│  2. Phonics drill (5 мин) — различение batchim, tense   │
│     согласных, двойных гласных                           │
│                                                          │
│  3. Shadowing (10 мин) — основной режим: текущее         │
│     юнит-скрипт или подкаст                              │
│                                                          │
│  4. Dictation (7 мин) — услышанное записываем            │
│                                                          │
│  5. Review (5 мин) — сопоставление с оригиналом,        │
│     отметка непонятных фраз                               │
│                                                          │
│  6. Extensive (5 мин) — свободное слушание для           │
│     удовольствия: драма, ютуб                               │
│                                                          │
│  ИТОГО: ~35 минут                                        │
└──────────────────────────────────────────────────────────┘
```

### Частые ошибки русскоязычных при аудировании

| Ошибка | Пример | Как исправить |
|--------|--------|---------------|
| Подмена ㄹ на р/л | `말` = [мал] вместо [мɑɾɭ] | Тренируйте ретрофлексный [ɾ] отдельно |
| Подмена ㅂ/p на б | `방` = [бан] вместо [пан] | Слушайте минимальные пары: 파/바, 포/보 |
| Игнорирование batchim | `학교` → [학꾜] вместо [학쑈] | Проработайте таблицу batchim в разделе 2 |
| Подмена ㄷ/ㄸ | `밥` = [бап] вместо [пап] | Отличайте тense от plain по длительности |
| Пропуск финальных ㄹ | `전화` → [전허] вместо [전화] | Тренируйте окончания в monologue-скриптах |
| Путаница ㅓ/ㅗ | `오빠` vs `언니` | Изолированная работа с задними гласными |

### 2.1 Batchim (받침) — окончания согласных

Batchim — это финальный согласный, который закрывает слог. В корейском более 20 видов batchim, и каждый влияет на произношение следующего слова. Для аудирования критично понимать, какой именно batchim стоит в слове.

#### Правила batchim при соединении слов

Когда слово с batchim стоит перед словом на гласной, batchim «перескакивает» и влияет на произношение следующего слога. Для аудирования это критически важно.

```
Example: 학교 + 예요

학교 = 학 + 쑈 (batchim ㄱ → [k] перед ㅑ)
Полная форма: 학쑈
Слияние: [학쑈예요] → [hak.k͈jʌ.jo.jo]
```

```
Example: 입 + 닫다

입 = ㅂ → [p] перед ㄷ
ipta-da → [ip.t͈a.da]
```

```
Example: 값 + 사이

값 = ㅂ → [p] перед ㅅ
Polssi → [pʰo.s͈i]
```

### 2.2 Tense consonants (경음절) — удвоенные согласные

Tense consonants — это ключ к пониманию ритма корейской речи. Они произносятся с большей силой и длительностью, чем обычные согласные.

#### Минимальные пары для тренировки

| Plain | Tense | Русский | Пример 1 (plain) | Пример 2 (tense) |
|-------|-------|---------|-------------------|-------------------|
| ㄱ | ㄲ | г/к | 가다 (када) — идти | 까다 (ккада) — трудный |
| ㄷ | ㄸ | д/т | 다다 (тада) — дойти | 딸다 (ттада) — переплыть |
| ㅂ | ㅃ | б/п | 바다 (пада) — море | 뽀다 (ппотта) — лопнуть |
| ㅅ | ㅆ | с/с | 사다 (сада) — покупать | 쌔다 (ссада) — нечётный |
| ㅈ | ㅉ | ч/ч | 자다 (чада) — спать | 쟈다 (ччада) — (нет стандарта) |

**Как слушать:** Tense consonant ощущается как «щелчок» или «импульс» в середине слова. При прослушивании закройте глаза и попробуйте почувствовать пульс: каждый тense consonant — это маленький удар.

#### Где встречаются tense consonants в обычной речи

- В словах с двойными согласными: `깨다` (разбудить), `뛰다` (бежать), `쏘다` (бросать)
- В заимствованиях: `싸이` (sa-i, от «сай»), `쁘띠` (pputi, petite)
- В именах собственных: `싸이월드` (сайволд, Cyworld)

### 2.3 Двойные гласные (이중 모음)

Двойные гласные — это комбинации двух гласных, произносимые как один дифтонг. Для русскоязычного уха они часто звучат как отдельные гласные, что приводит к неправильному разбиению слов на слоги.

| Дифтонг | Произношение | Ближайший аналог в русском | Пример | Значение |
|---------|--------------|---------------------------|--------|----------|
| ㅘ | [wa] | «ва» | 와 = ва | да |
| ㅙ | [wɛ] | «вэ» | 혜 = вэ (редко) | редко |
| ㅚ | [we] или [œ] | «ой» (но короткое) | 소 = со (но ㅜ+ㅣ) | нет прямого |
| ㅝ | [wʌ] | нет прямого | 워 = во | нет прямого |
| ㅞ | [we] | «вэ» | 워 = вэ | нет прямого |
| ㅟ | [wi] или [ɯi] | «и» (губное) | 위 = ви | над |
| ㅢ | [ɯi] или [i] | «ыи» | 의 = э (предлог) | 所属 |
| ㅒ | [jɛ] | «йэ» | 예 = йэ | да |
| ㅖ | [je] | «йэ» | 져 = йэ (редко) | нет |

**Практическое правило:** Когда вы слышите две гласные подряд в корейском слове, не разбивайте их на два слога. Слушайте как единый дифтонг.

#### Тренировочный список минимальных пар с дифтонгами

```
고 (ко) vs 과 (ва)
거 (ко) vs 걔 (кйэ)
눌 (нуль) vs 놀 (ноль)
부 (пу) vs 바 (па)
누 (ну) vs 나 (на)
```

### 2.4 Звук ㄹ (리을)

Звук ㅏ — один из самых сложных звуков для русскоязычных. Это ретрофлексный боковой аппроксимант [ɾ].

- **В начале слова:** [ɾ] — быстрый, как американское «r» в «radio»
- **В середине слова:** [ɾ] — ударный, как в англском «pero»
- **В конце слова перед ㄴ:** [ɭ] — утолщённый, как «ль»
- **В конце слова перед гласной:** [ɾ] или [l] — зависит от диалекта

#### Тренировка восприятия ㄹ

```
말 → [mɑɾɭ] — не [маль] и не [мал]
여자 → [jʌ.dʑɑ] — не [ельча] и не [екча]
학교 → [хаккё] — ㄹ в середине отсутствует здесь, но в 다른 словах критично
```

#### Минимальные пары с ㄹ

| Слова | Произношение | Значение |
|-------|--------------|----------|
| 라면 | [라.mʌn] | рамен |
| 마늘 | [마.넬] | чеснок |
| 밤 | [бам] | ночь |
| 람 | [лам] | (букв.) |
| 불 | [пул] | огонь |
| 률 | [рюль] | (суффикс) |

### 2.5 ㅂ/ㅍ vs б/п

Один из самых частых источник ошибок. В корейском:

- ㅂ (пиып) = глухой губно-губной [p]
- ㅍ (пхиып) = глухой губно-губной с придыханием [pʰ]
- В русском аналог: ㅂ ≈ «п» (непридыханное), ㅍ ≈ «п» (придыханное, как в «пирог»)

**Коварный момент:** Когда ㅂ стоит в конце слова перед ㅂ или ㅍ, он может произноситься как [p], а при batchim-перескакивании — как [p] или [pʰ].

```
좋다 (чо-да) → [чо.та] — ㅂ → [т] перед ㄷ
잘 (чаль) → [чаль] — ㅂ → [л] перед ㄹ
학교 (хак-ё) → [хаккё] — ㅂ → [к] перед ㅑ
```

### 2.6 Звук ㅎ (히읗) — aspiration и утрата

Звук ㅎ — самое непредсказуемое место для аудирования:

- В начале слова: [h] — как русское «х»
- После гласной: часто **утрачивается** или становится [ㅎ] → гласная удлиняется
- Перед ㄴ, ㅁ, ㅇ: может пропадать или превращаться в [n]

```
해 (хэ) → [хэ] — день
했어 (хэ-со) → [хэ.so] — было
했는데 → [х�.нун] — но (ㅎ слабое)
행복 (хэнгbok) → [хэŋbok] — счастье
```

**Ловушка для слуха:** В быстрой речи `했어` может звучать как [хэ.so], и начинающий может не различить слово `해` и `했어`.

### 2.7 Гласный ㅓ vs ㅗ

| Гласный | Произношение | Ближайший аналог | Пример | Значение |
|---------|--------------|------------------|--------|----------|
| ㅓ | [ʌ] — центрально-задняя, короткая | нет прямого; «э» в «есть», но ближе к «ы» | 거 = кэ | этот |
| ㅗ | [o] — задняя округлённая | «о» в «море» | 고 = ко | этот |
| ㅏ | [a] — передняя открытую | «а» в «мама» | 가 = ка | этот |

**Правило различения:** Поднимите губы: если губы округлены → ㅗ [o]. Если губы не округлены и язык средней высоты → ㅓ [ʌ]. В быстрой речи ㅓ часто сливается с ㅗ, поэтому тренируйтесь слушать контекст.

### 2.8 Слияние гласных (모음 동화)

В быстрой речи гласные часто сливаются:

```
가요 (ка-йо) → [ка-йо] — нормально, но в быстрой речи: [кæ.jo]
있어 (ис-со) → [ис.so] — сливается
있는데 → [이.ㄴ.ㄴ] → [иннун] — утрата
모아 (мо-а) → [мо.а] → [мо:a] — удлинение
```

### 2.9 Удлинение гласных (모음 장음)

Когда за краткой гласной следует ㅣ или ㅎ, гласная может удлиняться:

```
먹다 (мок-та) → [мог-та] — ㅓ удлиняется в быстрой речи
있었어 (ис-со) → [ис-со] — слияние
있었다 → [이셨따] — слияние + утренник
```

### 2.10 Чек-лист фонетических навыков

Проверьте себя по каждому пункту. Если не уверены — вернитесь к соответствующему разделу.

- [ ] Различаю ㄱ/ㄲ (박치기) в быстрой речи
- [ ] Различаю ㄷ/ㄸ (밥/빨) в быстрой речи
- [ ] Различаю ㅂ/p и ㅍ (파/바) в быстрой речи
- [ ] Понимаю, какой batchim стоит в слове
- [ ] Знаю, как batchim перескакивает на следующее слово
- [ ] Различаю ㅓ и ㅗ по контексту
- [ ] Слышу ㄹ как [ɾ], а не как русское «р» или «л»
- [ ] Отслеживаю утрату ㅎ в быстрой речи
- [ ] Понимаю слияние гласных (모음 동화)
- [ ] Слышу разницу между ㅐ и ㅔ (пока нет, но к TOPIK II пригодится)

## 3. Метод Shadowing — полный протокол

<a id="3-shadowing"></a>

### Что такое Shadowing

Shadowing (теневое повторение) — техника, при которой вы повторяете за носителем языка практически одновременно, с минимальной задержкой. Метод разработан Лейном Уилкинсоном в 1970-х для подготовки переводчиков ООН и с тех пор является золотым стандартом аудирования.

### Почему Shadowing работает

1. **Мозг вынужден обрабатывать аудио в реальном времени** — нет возможности «отпаузить» и вернуться, как при повторном прослушивании.
2. **Моторная память голосовых связок** — вы не просто слышите, а произносите, что закрепляет фонемы в моторном аппарате.
3. **Интонация и ритм «вшиваются»** — вы копируете мелодику корейского предложения, а не только отдельные слова.
4. **Сокращение латентности** — время от услышанного к произнесённому сокращается с нескольких секунд до долей секунды.

### Протокол Shadowing — три уровня

#### Уровень 1: Delayed Shadowing (задержка 1–2 сек)

Подходит для начального этапа.

```
Шаг 1: Нажмите «Play» на аудио юнита.
Шаг 2: Слушайте 1–2 предложения, затем начните повторять.
Шаг 3: Попробуйте повторить с задержкой 1–2 секунды.
Шаг 4: Не останавливайтесь, даже если не поняли слово.
Шаг 5: После окончания фрагмента — проверьте текст.
Шаг 6: Запишите непонятные слова и их произношение.
Шаг 7: Повторите фрагмент ещё 2 раза с задержкой.
```

#### Уровень 2: Simultaneous Shadowing (без задержки)

Подходит после 2–3 недель практики Уровня 1.

```
Шаг 1: Начните воспроизведение аудио.
Шаг 2: Начните говорить одновременно с носителем, с задержкой 0–0.5 сек.
Шаг 3: Следите за темпом, не отставайте.
Шаг 4: Копируйте интонацию, громкость, эмоцию.
Шаг 5: Если отстали — не останавливайтесь, продолжайте слушать.
Шаг 6: После фрагмента — прочитайте текст и отметьте пробелы.
Шаг 7: Повторите фрагмент 3 раза без текста, 2 раза с текстом.
```

#### Уровень 3: Whisper Shadowing (шёпот)

Продвинутый уровень. Произносите шёпотом вслед за носителем.

```
Шаг 1: Включите аудио на низкой громкости.
Шаг 2: Повторяйте шёпотом, слегка опережая носителя.
Шаг 3: Это заставляет артикуляционный аппарат работать быстрее.
Шаг 4: Фокус на окончаниях: -아/어, -고, -ㄴ/는, -요/습니다.
Шаг 5: После 5 минут — снять нарастание громкости и говорить обычным голосом.
Шаг 6: Запишите себя и сравните с оригиналом.
```

### Детальный протокол для скриптов юнитов


### Рекомендуемая скорость

| Тип скрипта | Скорость (wpm) | Количество слов в минуту | Для кого |
|-------------|----------------|--------------------------|----------|
| Slow | 130 | ~20 слов/мин | Начинающие (TOPIK I) |
| Natural | 170–180 | ~28 слов/мин | Средний (TOPIK I–II) |
| Monologue | 150–160 | ~24 слова/мин | Все уровни |
| Native speech | 200–250 | ~35+ слов/мин | Продвинутые (TOPIK II) |

### Частые ошибки при Shadowing

| Ошибка | Решение |
|--------|---------|
| Читаете текст вместо прослушивания | Сначала слушайте, потом повторяйте — не читайте |
| Говорите слишком медленно | Постепенно ускоряйтесь, начинайте с задержки 2 сек |
| Не копируете интонацию | Записывайте себя и сравнивайте с оригиналом |
| Останавливаются на незнакомом слове | Не останавливайтесь — контекст подскажет |
| Забывают окончания | Фокус на -요/-습니다, -아/어, -는/ㄴ |
| Говорят «на корейском, но с русским акцентом» | Снимайте запись, сравнивайте, корректируйте |

### Контрольные точки прогресса в Shadowing

```
Неделя 1–2:   Задержка 2 сек, slow audio, часто останавливаются
Неделя 3–4:   Задержка 1 сек, slow audio, стабильно держат темп
Неделя 5–6:   Задержка 0.5 сек, natural audio, начинают подстраиваться
Неделя 7–8:   Simultaneous, natural audio, 80% точности
Неделя 9–10:  Simultaneous, natural audio, 90% точности
Неделя 11–12: Whisper shadowing, natural audio, 95% точности
```

## 4. Диктант — Hear and Write

<a id="4-диктант"></a>

### Методика Dictation (аудио-диктант)

Dictation — один из самых мощных методов связки аудирования и письменной речи. Вы учитесь не только слышать, но и записывать то, что слышите, что оттачивает фонематическое восприятие до совершенства.

### Виды диктанта

| Вид | Описание | Когда использовать |
|-----|----------|-------------------|
| **Full dictation** | Записать весь текст целиком | После 2 недель shadowing |
| **Sentence dictation** | Записать предложения по 1–2 реплики | Основной метод для всех уровней |
| **Partial dictation** | Записать только определённые слова (например, глаголы) | Для работы с грамматикой |
| **Gap dictation** | Текст с пропусками — впишите пропущенные слова | Для работы с batchim |

### Протокол Sentence Dictation

```
Шаг 1: Включите аудио (slow, 130 wpm).
Шаг 2: Слушайте ОДНО предложение.
Шаг 3: Остановите аудио.
Шаг 4: Запишите то, что услышали на корейском (hangul).
Шаг 5: Проверьте по тексту.
Шаг 6: Если есть ошибки — запишите правильный вариант 3 раза.
Шаг 7: Запишите это слово в Anki.
Шаг 8: Перейдите к следующему предложению.
```

### Скрипт для Dictation — Unit 06: 전화와 약속 (пример)

#### Предложение 1 (медленное, 130 wpm):

```
여보세요, 지영 씨? 민수예요.
```

**Запись ученика:** 여보세요, 지영 씨? 민수예요.

**Проверка:** Совпадает / Не совпадает.

**Ошибки:** Если вы записали `여보세요` как `여보세` — обратите внимание на окончание ㅂ→ㅂ+ㅔ.

**Анализ:** Здесь важно слышать окончание `요` после `여보세`. В быстрой речи `여보세요` → `여보세`.

#### Предложение 2 (медленное, 130 wpm):

```
내일 주말인데, 같이 놀러 갈까 해서 전화했어요.
```

**Ошибки типичные:**
- `갈까` → записано как `갈까` (правильно) или `갈카` (ошибка)
- `전화했어요` → записано как `전화헤요` (ошибка, не слышен ㅅ)
- `있어요` → пропущено `있`

### Таблица частых фонетических ошибок в диктанте

| Слышится как | На самом деле | Причина |
|-------------|---------------|---------|
| [네] | [네] | 올바чно |
| [네] | [아니] | Утрата ㅅ в `아닙니다` |
| [만나] | [만나] | `만나요` → встреча |
| [만나] | [만나] | В быстрой речи `만나요` → [만나] |
| [가] | [가] | `가요` → идёт |
| [했] | [했] | `했어요` → сделал |
| [있] | [있어] | `있어` → есть |

### Диктант + Shadowing: комбинированный метод

Самый эффективный подход — чередовать shadowing и диктант:

```
Понедельник: Shadowing slow audio (30 мин)
Среда:       Dictation sentence (20 мин) + Review (10 мин)
Пятница:     Shadowing natural audio (30 мин)
Воскресенье: Full dictation одного текста (40 мин)
```

### Оценка прогресса диктанта

Отслеживайте процент правильных записей по предложениям:

- [ ] Неделя 1–2: 40–50% правильных
- [ ] Неделя 3–4: 55–65% правильных
- [ ] Неделя 5–6: 70–80% правильных
- [ ] Неделя 7–8: 80–90% правильных
- [ ] Неделя 9–10: 85–95% правильных
- [ ] Неделя 11–12: 90–98% правильных

## 5. Формат TOPIK Listening — типы вопросов

<a id="5-topik-listening"></a>

### Общая структура TOPIK Listening

TOPIK Listening (слушательный тест) состоит из 4 частей с вариантами ответов. Количество вопросов и время зависят от уровня.

#### TOPIK I (уровни 1–2)

| Часть | Кол-во вопросов | Время | Тип |
|-------|-----------------|-------|-----|
| Part 1 | 20 | ~20 мин | Информация, картинки, короткие диалоги |
| Part 2 | 10 | ~10 мин | Короткие вопросы и ответы |
| **Итого** | **30** | **30 мин** | |

#### TOPIK II (уровни 3–6)

| Часть | Кол-во вопросов | Время | Тип |
|-------|-----------------|-------|-----|
| Part 1 | 15 | ~15 мин | Информация, картинки |
| Part 2 | 15 | ~15 мин | Диалоги и монологи |
| Part 3 | 10 | ~10 мин | Понимание контекста |
| **Итого** | **40** | **40 мин** | |

### Тип 1: 정보선택 (Выбор информации)

**Описание:** На экране показывается картинка или перечисляются варианты. Вы слышите диалог/вопрос и выбираете правильный вариант.

**Пример формата:**

```
[Изображение: карта с отметками]
남자: 민수 씨, 어디에 가요?
여자: 일산에 갈 거예요.
[Вопрос] 남자는 어디에 가나요?
(a) 서울
(b) 일산
(c) 부산
(d) 대전
```

**Стратегия:**
1. Прочитайте варианты ответов ДО начала аудио.
2. Обратите внимание на ключевые слова в вариантах.
3. Слушайте конкретные места, имена, числа.
4. Исключите заведомо неверные варианты.

**Типичные ловушки:**
- Диалог говорит одно место, а вопрос — другое (меняется подлежащее)
- Вариант содержит слово из диалога, но в другом контексте
- Вариант говорит о будущем, а диалог — о прошлом

### Тип 2: 대화상황 (Ситуация диалога)

**Описание:** Вы слышите диалог и понимаете ситуацию, в которой он происходит, отношения между спикерами, или что они планируют сделать.

**Пример:**

```
여자: 민수 씨, 주말에 같이 놀러 갈까?
남자: 좋아요. 어디에 가려고 해요?
여자: 남산에 가려고 해요. 벌써 날씨가 좋아져서요.
남자: 좋아요. 아홉 시에 만나는 게 어때요?
여자: 아홉 시는 좀 이른 것 같아요. 열 시에 만나요.
```

**Вопрос:** 남자와 여자가 무엇을 계획하고 있나요?
(a) работа
(b) встреча с другом
(c) телефонный разговор
(d) покупка подарка

**Стратегия:**
1. Определите отношения между спикерами (друзья? коллеги? семейные?).
2. Найдите глаголы действия (갈까, 만나요, 전화했어요).
3. Обратите внимание на местоимения и окончания вежливости.
4. Выберите ответ, который охватывает все реплики, а не одну.

### Тип 3: 발음별 (По произношению)

**Описание:** Вы слышите слово или фразу и выбираете, какое слово/фраза было произнесено из предложенных вариантов. Это проверяет знание batchim, tense consonants и дифтонгов.

**Пример:**

[Слышится: 학쑈]
(a) 학교
(b) 학수
(c) 할수
(d) 한수

**Ответ:** (a) 학교

**Стратегия:**
1. Слушайте batchim финального согласного.
2. Обращайте внимание на tense consonants (ㄲ, ㄸ, ㅃ, ㅆ).
3. Помните о правилах перескока batchim.
4. Отделяйте слова друг от друга в быстрой речи.

### Тип 4: 세부 내용 (Детальная информация)

**Описание:** Вы слышите длинный диалог или монолог и отвечаете на вопросы о конкретных деталях: когда, где, сколько, зачем.

**Пример:**

```
여자: 민수 씨, 내일 뭐 해요?
남자: 아, 내일은 주말이니까 넥센하고 같이 영화를 볼 거예요.
여자: 몇 시에요?
남자: 3시에 만나서 4시에 시작해요.
여자: 그럼 2시 50분에 역에서 만나요.
```

**Вопрос:** 남자와 여자는 언제 만나는요?
(a) 2시 50분
(b) 3시
(c) 4시
(d) 2시

**Ответ:** (a) 2시 50분 (встреча)

**Стратегия:**
1. Отмечайте время, место, число при первом прослушивании.
2. Вопросы часто меняют формулировку: «몇 시에» → «언제».
3. Следите за словами-ссылками: 그래서, 하지만, 그런데, 그리고.
4. Не выбирайте ответ, содержащий число из текста, если вопрос о другом.

### Тип 5: 추론 (Выводы)

**Описание:** Вы слышите диалог/монолог и делаете выводы: что человек думает, чувствует, планирует, но прямо не говорит.

**Пример:**

```
남자: 이 영화 재밌는데, 점심은 아직 안 먹었어요.
여자: 아, 그래요? 우리 밥 먹고 볼까요?
```

**Вопрос:** 두 사람은 지금 어디에 있어요?
(a) в ресторане
(b) в кино
(c) перед тем как пойти в кино
(d) дома

**Ответ:** (c) перед тем как пойти в кино

**Стратегия:**
1. Обратите внимание на контрастные союзы: 그런데, 하지만, 아니면.
2. Следите за изменением тона голоса.
3. Используйте метод исключения.
4. Предполагайте наиболее логичный вывод.

### Тип 6: 일치/불일치 (Совпадение/Несовпадение)

**Описание:** Вы слышите утверждение и определяете, соответствует ли оно тому, что вы слышали.

**Пример:**

```
[Аудио: 남자: 오늘 날씨가 정말 좋네요.]

다음 설명이 맞습니까?
"남자는 날씨가 좋지 않다고 했다."
(a) 맞음 (совпадает)
(b) 틀림 (не совпадает)
```

**Ответ:** (b) 틀림

**Стратегия:**
1. Слушайте отрицания: 않다, 못, 아니, 안.
2. Обратите внимание на слова-обесцениватели: 별로, 많이, 좀.
3. Помните, что «не совпадает» — самый частый правильный ответ.

### Общие стратегии для TOPIK Listening

1. **Читайте варианты до начала аудио** — это даёт контекст и фокус.
2. **Не паникуйте при пропуске** — пропущенное слово не означает провал; переходите к следующему.
3. **Отмечайте ключевые слова** — используйте маркер, чтобы отмечать время, место, имена.
4. **Учите лексику по темам** — TOPIK часто повторяет одни и те же ситуации.
5. **Тренируйте скорость** — при TOPIK II 40 вопросов за 40 минут, что даёт 1 минуту на вопрос.
6. **Используйте процесс исключения** — в тройном варианте шансы 33%, при исключении одного — 50%.
7. **Следите за временными маркерами** — 이전, 다음, 먼저, 나중에, 다시.

### Словарный запас TOPIK Listening по темам

## 6. 15 юнитов — скрипты с аудированием

<a id="6-скрипты-юнитов"></a>

> ⚠️ Каждый скрипт предназначен для трёх режимов прослушивания:
> - **Slow** (130 wpm) — для shadowing и диктанта
> - **Natural** (170–180 wpm) — для интенсивного аудирования
> - **Monologue** (150–160 wpm) — для тренировки понимания длинных высказываний
>
> Каждый скрипт включает hangul, Revised Romanization и русский перевод.
> После каждого скрипта — 5 вопросов на понимание.

## 7. План практики на 90 дней

<a id="7-90-дней"></a>

### Структура 90-дневного плана

План разделён на три фазы:

```
┌──────────────────────────────────────────────────────────┐
│              ФАЗА 1: ФУНДАМЕНТ (Дни 1–30)               │
│  Цель: фонетика, минимальные пары, slow shadowing       │
│  Ежедневная нагрузка: 30 мин                             │
│                                                          │
│  ФАЗА 2: РАЗВИТИЕ (Дни 31–60)                           │
│  Цель: natural shadowing, dictation, TOPIK题型          │
│  Ежедневная нагрузка: 40 мин                             │
│                                                          │
│  ФАЗА 3: УСОВЕРШЕНСТВОВАНИЕ (Дни 61–90)                 │
│  Цель: native speech, тайминг, стратегии TOPIK II       │
│  Ежедневная нагрузка: 45–60 мин                          │
└──────────────────────────────────────────────────────────┘
```

### Неделя 1–2: Знакомство со звуками

| День | Активность | Время |
|------|-----------|-------|
| Пн | Фонетика: batchim + tense consonants | 20 мин |
| Вт | Shadowing Unit 01 (slow) | 30 мин |
| Ср | Dictation Unit 01 sentences | 20 мин |
| Чт | Shadowing Unit 02 (slow) | 30 мин |
| Пт | Phonics review: ㄹ, ㅂ/p, ㅎ | 15 мин |
| Сб | Full dictation Unit 01 | 40 мин |
| Вс | Отдых + лёгкое Extensive (подкаст) | 15 мин |

**Цели недели:**
- [ ] Различаю batchim в слове
- [ ] Различаю tense и plain consonants
- [ ] Пропущу shadowing 2 юнитов (slow)
- [ ] Запишу 10 новых слов в Anki

### Неделя 3–4: Первые диалоги

| День | Активность | Время |
|------|-----------|-------|

### Рекомендации по коррекции

Если по итогам недели вы не достигли целевых метрик:

| Проблема | Причина | Решение |
|----------|---------|---------|
| Slow <50% | Batchim не различает | Вернитесь к разделу 2, тренируйте batchim |
| Natural <30% | Слишком быстрая речь | Снизьте скорость до slow, вернитесь к Section 3 |
| Dictation <40% | Не слышите окончания | Фокус на -아/어, -는/ㄴ, -요/-습니다 |
| Shadowing <30% | Слишком большая задержка | Снизьте задержку до 2 сек, начните с Level 1 |
| TOPIK <30% | Не знакомы с форматом | Прочитайте раздел 5, потренируйте по типам |
| ㄹ не слышу | Русский акцент | Тренируйте ㄹ отдельно, смотрите корейские драмы |
| ㅂ/p путается | Подмена на б | Тренируйте минимальные пары 파/바 |
