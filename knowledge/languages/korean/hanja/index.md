# Корейский — Ханча (китайские иероглифы в корейском)

## Что такое ханча?
Ханча (한자/漢字) — китайские иероглифы, заимствованные в корейский язык.
Около 60% корейской лексики имеет китайское происхождение.
Ханча используется в газетах, научных текстах, именах.
