# Повседневность (일상, ильсан)

> Раздел о повседневной жизни в Корее: офисный этикет, транспорт, магазины (конбини), учёба (학원, 수능), армия (의무) и бытовые реалии.

---

## 1. Офисный этикет (회사 문화, хвеса мунхва)

### Иерархия на работе

- **직급 (чикып)** — должность. Все завязано на звании и стаже.
- Старший по должности или возрасту — **선배 (сонбэ)**, младший — **후배 (хубэ)**.
- Сонбэ/хубэ — отношения не только на работе, но и в учебных заведениях, клубах.

### Правила

1. **Обращение по должности + 님** — например, 과장님 (куваджанним), 부장님 (пуджанним).
2. **Начинают и заканчивают работу младшие первыми** (приходят раньше, уходят позже — но это не строгое правило).
3. **Кофе/напитки** младший может подать старшим (в традиционном коллективе).
4. **Отпуск и отгулы** — согласовывают с руководством заблаговременно.
5. **Совещания** — слово предоставляется по старшинству.
6. **Выполнение просьб** — даже если это вне обязанностей, вежливо согласиться и сделать.

### Фразы офисного обихода

| Фраза | Транскрипция | Перевод |
|-------|-------------|---------|
| 어떻게 오셨어요? | оттокхе осёссойо? | по какому делу пришли? |
| 잠시만요 | чамсиманнё | минутку |
| 밥 먹었어요? | пап могосойо? | ели? (приветствие) |
| 힘내세요 | химнаэсэйо | держитесь / взялись |
| 수고하셨습니다 | сугохасёмнида | хорошо поработали |
| 죄송하지만 | чвэсонхачиман | извините, но... |
| 미안합니다 | мианхамнида | извините |
| 잘 부탁드립니다 | чаль путактыримнида | рассчитываю на вас |

### Политический/отношенческий аспект

- **Прямой отказ** избегают — отвечают «посмотрим», «попробуем». Отрицательный ответ смягчают.
- Публичная критика начальника недопустима.
- Внутренние конфликты решают непублично, сохраняя лицо.
- Корпоративная культура поощряет **가족 (каджок)** — восприятие коллектива как семьи.

## 2. Метро и букварь общественного транспорта

### Метро Сеула

- **자동차세 (джадончхасе)?** — нет, речь о кори. Система линий (1–9 + облегчённые ветки).
- Оплата: **교통카드 (кётхонкхады)** — транспортная карта (T-money).

### Основные термины метро

| Корейский | Транскрипция | Перевод |
|-----------|-------------|---------|
| 지하철 | чихачхоль | метро |
| 역 | ёк | станция |
| 환승 | хвансын | пересадка |
| 출구 | чхулькку | выход |
| 승강장 | сынганджан | платформа |
| 다음 역 | таым ёк | следующая станция |
| 종착역 | чончхагёк | конечная |
| 화장실 | хваджансиль | туалет |
| 에스컬레이터 | эсыкхоллеито | эскалатор |
| 엘리베이터 | эллибэйто | лифт |

### Этикет в транспорте

1. **Места для пожилых/беременных** (노약자석) — обязательны к уступке.
2. **Уступают место** старшим, инвалидам, беременным.
3. **Не громко разговаривают** по телефону — короткие звонки.
4. **Не едят** в транспорте.
5. **Очередь при посадке** — заходят аккуратно, выпускают выходящих.

### Поиск пути

```
실례합니다, 이 역은 어느 쪽으로 나가면 돼요?
(силехамнида, и ёгын оно тчогыро нагамён твэё?)
— Извините, в какую сторону выйти на этой станции?
```

## 3. Конбини (편의점, пхёныйджжом)

**편의점** — круглосуточный магазин у дома (CU, GS25, 7-Eleven, Mini Stop). Важная часть повседневности.

### Что там покупают

- **삼각김밥 (самгаккимпап)** — треугольные кимпап
- **라면 (рамён)** — лапша быстрого приготовления
- **도시락 (тосирак)** — ланч-боксы
- **음료/커피** — напитки и кофе
- **과자/아이스크림** — сладости, мороженое
- Готовую еду и закуски

### Особенности

- Часто есть **кипящая вода** для рамена и микроволновки.
- Оплачивают картой/t-money/мобильным.
- Круглосуточная работа (24/7).
- Азартная «специальная» полка с новинками.

### Полезный диалог

```
카운터: 어서 오세요! (осёосэйо) — Добро пожаловать!
Покупатель: 이거 얼마예요? (иго ольмайеё?) — Сколько это стоит?
카운터: 3,000원이에요. (самчхон вониэё) — 3000 вон.
Покупатель: 여기 있어요. (ёги иссойо) — Вот, держите.
카운터: 감사합니다. 봉투 필요하세요? (камсахамнида, понту пхирёхасэйо?) — Спасибо, нужен пакет?
```

## 4. Учёба (학원, 수능)

### 학원 (Хагвон)

**학원** — частные учебные институты/курсы после школы. Обучение на курсах математики, английского, музыки, спорта. Хагвоны — огромная индустрия (частные дополнительные занятия).

| Тип | Назначение |
|-----|-----------|
| 수학 학원 | математика |
| 영어 학원 | английский |
| 과학 학원 | естественные науки |
| 피아노/미술 학원 | музыка/изобразительное |
| 태권도 학원 | тхэквондо |
| 입시 학원 | подготовка к вступительным |

### 수능 (Сунын) — Национальный экзамен

**수능 (대학수학능력시험)** — вступительный экзамен в университеты. Проводится один раз в год (конец ноября).

**Особенности:**
- Один из самых важных дней в жизни корейских школьников.
- Во время экзамена **задерживают полёты самолётов** (чтобы не мешать аудированию).
- Общество оказывает поддержку: выезжают на дорогах, сопровождают опаздывающих (полиция везёт на мотоцикле).
- Вся страна молится за успех абитуриентов.
- Результат определяется жёсткими рейтингами.

**Связанная лексика:**
- **수험생 (сухомсэн)** — абитуриент, сдающий экзамен
- **입시 (ипси)** — вступительные экзамены
- **대학 (тэхак)** — университет
- **합격 (хапкёк)** — поступление

### Школьный распорядок

- Корейские школьники учатся с понедельника по пятницу + иногда суббота.
- После уроков — хагвоны.
- Нагрузка высокая, особенно у старшеклассников.

## 5. Армия (군대, кундэ)

### Обязательная военная служба

- Южная Корея — обязательный призыв **по мужскому полу** (대한민국 국군).
- Срок службы: **около 18–21 месяца** (сухопутные войска ~18, ВМС ~20, ВВС ~21).
- Старт ~18 лет, отсрочки возможны для студентов.

### Значение в культуре

- Служба считается **обязательной вехой взросления** мужчины.
- Кандидаты в айдолы и знаменитости часто «уходят в армию» — это пауза в карьере.
- **이등병 (идынпён)** — рядовой, начальный чин.
- Армейский опыт — тема общения между мужчинами.

### Базовая армейская лексика

| Корейский | Транскрипция | Перевод |
|-----------|-------------|---------|
| 군대 | кундэ | армия |
| 의무 | ыйму | обязанность (воинская) |
| 입대 | иптхэ | призыв на службу |
| 제대 | четэ | демобилизация |
| 훈련 | хуллён | тренировка/учения |
| 병사 | пёнса | солдат |
| 장교 | чанъгё | офицер |

### Призыв и демобилизация

- **입대 (иптхэ)** — отправка на службу.
- **전역 (чонъёк)** — завершение службы.
- При увольнении дают **просмотреть/есть** и поздравляют (пословица «всем мужчинам Кореи»).

## 6. Примеры бытовых диалогов

### В метро / на улице

```
A: 실례합니다, 지하철역이 어디예요?
   (Виноват, где станция метро?)
B: 저기, GS25 옆에 있어요.
   (Вон там, рядом с GS25.)
A: 감사합니다!
   (Спасибо!)
```

### На кассе конбини

```
A: 라면 하나 주세요.
   (Один рамен, пожалуйста.)
B: 네, 여기 있어요. 1,500원이에요.
   (Да, вот. 1500 вон.)
A: 네, 여기 있어요.
   (Да, держите.)
```

### В школе/колледже

```
A: 오늘 수업 몇 시부터예요?
   (Во сколько занятие сегодня?)
B: 두 시부터예요.
   (С двух часов.)
A: 시험 날짜 알았어요?
   (Узнали дату экзамена?)
B: 아직 몰라요.
   (Пока не знаю.)
```

## Итог

Повседневная жизнь в Корее строится вокруг **иерархии и ритма**: иерархия (сонбэ/хубэ, 직급) в офисе и школе, эффективный транспорт (метро с T-money), удобные конбини (круглосуточная забота), учебная гонка (хагвоны и сунын) и обязательная воинская служба (кундэ). Знание этих реалий помогает понимать язык и поведение носителей в обычной жизни.
