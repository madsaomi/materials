# Корейская культура

## Обзор

Корейская культура (한국 문화) — это уникальное сочетание тысячелетних традиций и динамичной современности. Корейский полуостров обладает богатым культурным наследием, которое сформировалось под влиянием конфуцианства, буддизма, шаманизма и географического положения между Китаем и Японией.

---

## Традиции и обычаи

### Конфуцианские ценности

Корейское общество глубоко пронизано конфуцианскими принципами, которые определяют социальные отношения:

- **효도 (хёдо)** — уважение и забота о родителях и старших
- **의리 (уири)** — долг и долг перед обществом
- **예의 (ёи)** — этикет и вежливость
- **충 (чхунг)** — верность и преданность
- **신의 (сини)** — доверие и верность слову

### Система родства

Корейская система родства одна из самых сложных в мире. Существуют строгие правила обращения в зависимости от возраста, пола и степени родства:

| Отношение | Корейское название | Особенности |
|-----------|-------------------|-------------|
| Отец | 아버지 (абёджи) | Формальное |
| Мать | 어머니 (омони) | Формальное |
| Старший брат | 형 (хён) / 오빠 (оппа) | Для мужчин / для женщин |
| Старшая сестра | 누나 (нуна) / 언니 (онни) | Для мужчин / для женщин |
| Младший брат | 남동생 (намдонсэн) | Без различия пола |
| Младшая сестра | 여동생 (ёдонсэн) | Без различия пола |
| Дедушка | 할아버지 (харабёджи) | |
| Бабушка | 할머니 (хальмёни) | |

### Подарки и обмен

- Подарки принято дарить обеими руками
- Не стоит открывать подарок при дарителе
- Деньги обычно дарят в конвертах
- При приёме подарка от старшего нужно отвернуться

## Праздники

### 설날 (Соллаль) — Корейский Новый год

**Дата:** 1-й день по лунному календарю (январь-февраль)

**Традиции:**
- Вся семья собирается вместе
- Совершаются обряды предкам (차례 — чхарё)
- Едят ттоккук (떡국 — суп с рисовыми лепёшками)
- Дети кланяются старшим (세배 — сэбэ) и получают деньги
- Носят ханбок (한복 — традиционную одежду)
- Играют в народные игры (윷놀이 — юнори)

**세배 (Сэбэ) — обряд поклона:**
```
어르신, 새해 복 많이 받으세요!
(Эрушин, сэхэ бок мани бадэусё!)
— Старший, получите много счастья в новом году!
```

### 추석 (Чхусок) — День урожая

**Дата:** 15-й день 8-го месяца по лунному календарю

**Традиции:**
- Семейные встречи и путешествия
- Готовят особые блюда: 송편 (сонпён — полулунные рисовые пирожки)
- Посещают могилы предков (성묘 — сонмё)
- Танцуют под луной (강강술래 — kanggangsullae)

**Традиционные блюда 추석:**
| Блюдо | Описание |
|-------|----------|
| 송편 (сонпён) | Полулунные рисовые пирожки с начинкой |
| 삼계삼 (самгэтхэн) | Курица с рисом и женьшенем |
| 잡채 (чапчхэ) | Стеклянная лапша с овощами |
| 전 (чон) | Жареные лепёшки с мясом и овощами |

## Традиционная одежда — 한복 (Ханбок)

한복 — традиционная корейская одежда, которая носится во время праздников и особых случаев.

### Женский ханбок
| Элемент | Название | Описание |
|---------|----------|----------|

| Юбка | 치마 (чхима) | Длинная пышная юбка |
| Пояс | 노리개 (норигэ) | Украшение на поясе |

### Мужской ханбок
| Элемент | Название | Описание |
|---------|----------|----------|

### Цвета ханбока

## Этикет (예절)

### Обращение и речь

Корейская система вежливой речи (존댓말) — одна из самых сложных в мире:

| Уровень | Использование | Пример |
|---------|---------------|--------|
| 해요체 | Общий, вежливый | 좋아요 (хорошо) |
| 합쇼체 | Формальный | 좋습니다 (хорошо) |
| 하오체 | Литературный | 좋소 (хорошо) |
| 해체 | Неформальный | 좋아 (хорошо) |
| 해라체 | Повествовательный | 좋다 (хорошо) |

### Правила этикета

1. **Два рукопожатия:** При встрече со старшими пожимайте правую руку, поддерживая левое предплечье
2. **Питьё:** Never pour напиток себе самому; наливайте другим и позволяйте им наливать вам
3. **Возраст:** Всегда учитывайте возраст при общении
4. **Тосты:** Первый тост произносит старший по возрасту
5. **Еда:** Не начинайте есть до того, как начнёт старший
6. **Обувь:** Снимайте обувь при входе в дом или ресторан сLOOR-системой

### Наложение денег

- При посещении похорон кладут деньги в чёрном конверте (조의금)
- На свадьбу — в белом или розовом конверте (축의금)
- Всегда передавайте и принимайте деньги двумя руками

## Корейская кухня (한국 음식)

### Основные принципы

Корейская кухня основана на принципах:
- **균형 (гюнхён)** — баланс вкусов: острое, солёное, кислое, сладкое
- **다양성 (даёнсон)** — разнообразие закусок (반찬)
- **발효 (балхё)** — использование ферментированных продуктов
- **신선함 (синсёнхам)** — свежие ингредиенты

## Традиционное искусство

### 한글 (Хангыль) — корейская письменность

Создана в 1443 году королём 세종 대왕 (Седжон Великий). Считается одной из самых научных систем письма в мире.

**Структура хангыля:**
| Буква | Звук | Описание |
|-------|------|----------|
| ㄱ | g/k | Нёбкая согласная |
| ㄴ | n | Альвеолярный носовой |
| ㄷ | d/t | Нёбкая взрывная |
| ㄹ | r/l | Плавная согласная |
| ㅁ | m | Губной носовой |
| ㅂ | b/p | Губная взрывная |
| ㅅ | s | Альвеолярный фрикатив |
| ㅇ | ng/- | Носовой или молчаливый |
| ㅈ | j | Аффриката |
| ㅎ | h | Глоттальный фрикатив |
| ㅏ | a | Открытый гласный передний |
| ㅓ | eo | Полуоткрытый гласный |
| ㅗ | o | Закрытый гласный задний |
| ㅜ | u | Закрытый гласный задний |
| ㅡ | eu | Неогубленный гласный |
| ㅣ | i | Передний гласный |

### 서예 (Соэ) — каллиграфия

Корейская каллиграфия использует хангыль и ханча. Основные инструменты:
- 붓 (бу트) — кисть
- 먹 (мок) — тушь
- 한지 (ханджи) — бумага
- 벼루 (пёру) — камень для туш

### 도예 (Тое) — гончарное дело

Корейская керамика славится своей простотой и элегантностью:
- 청자 (чхонджа) — голубая керамика
- 백자 (бэкджа) — белая керамика
- 분청사기 (бунчхонсаги) — розовая керамика

## Интересные факты

1. **Номера телефонов:** В Корее мобильные номера начинаются с 010
2. **Этикет в лифте:** Старшие идут первыми
3. **Число 4:** Считается несчастным (четвёртый этаж пропускают)
4. **Кровати на полу:** Корейцы traditionally спали на тёплых полах (온돌)
5. **Скорость:** Корея — страна с одним из самых быстрых ритмов жизни
6. **Алкоголь:** 소주 (сочо) — самая популярная водка, пьют с пищалкой (빨대)
