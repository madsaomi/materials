## 3. Anki — микродетали настройки

### 3.1 Оптимальные настройки

```
Новых карт в день: 10-20
Макс. повторений в день: 100-200
Steps (в минутах): 1 10 1440
Graduating interval: 21 день
Easy interval: 4 дня
Starting ease: 250%
Interval modifier: 100%
Maximum interval: 365 дней
Leech threshold: 8 лагов
Leech action: Tag only
```

### 3.2 Типы карточек

**Базовая (слово → перевод):**
```
Front: 食べる
Back: есть / табэру
```

**Обратная:**
```
Front: есть (яп.)
Back: 食べる / たべる
```

**С чтением:**
```
Front: 食べる
Back: たべる — есть
       Example: ご飯を食べる
```

**С контекстом:**
```
Front: ご飯を___。
       (есть)
Back: 食べる
```

### 3.3 Формула интервалов SRS

## 4. Аудирование — микродетали

### 4.1 Методы

**Пассивное:** фоном во время дел (1-3 часа/день)
- Подкасты, музыка, радио
- Не требует внимания

**Активное:** полное внимание (15-30 мин/день)
- С субтитрами → без субтитров
- Shadowing: повторять вслух за диктором

**Интенсивное:** детальный разбор (15 мин/день)
- 30-60 секунд аудио
- Разобрать каждое слово
- Переписать на слух (диктант)

### 4.2 Shadowing — протокол

1. **Без текста:** слушай и повторяй (3 раза)
2. **С текстом:** следи + повторяй (2 раза)
3. **Без текста:** повторяй по памяти (2 раза)
4. **Запись:** запиши себя → сравни с оригиналом

### 4.3 Прогрессия сложности

```
Уровень 1: Подкасты для изучающих (Nihongo Con Teppei, ChinesePod)
Уровень 2: Медленные новости (NHK Easy News, Slow Chinese)
Уровень 3: Естественная речь (нативные подкасты)
Уровень 4: Фильмы/сериалы с субтитрами
Уровень 5: Нативные фильмы без субтитров
Уровень 6: Теледебаты, лекции, радио
```

## 5. Чтение — микродетали

### 5.1 Прогрессия

```
Уровень 1: Graded readers (тексты по уровню)
     → Furigana/пиньинь

Уровень 2: Детские книги, комиксы
     → Простой язык, картинки

Уровень 3: Манга/вебтуны (по уровню)
     → Разговорный язык

Уровень 4: Новости для изучающих
     → NHK Easy / The Chairman's Bao

Уровень 5: Нативные новости
     → NHK, BBC, Naver News

Уровень 6: Художественная литература
     → Романы, рассказы

Уровень 7: Специализированные тексты
     → Научные, юридические, технические
```

### 5.2 Метод интенсивного чтения

```
1. Читать абзац
2. Подчеркнуть незнакомые слова
3. Проверить в словаре
4. Перечитать абзац
5. Письменно пересказать
6. Озвучить вслух
```

### 5.3 Сколько читать

| Уровень | В день | В неделю |
|---------|--------|----------|
| Новичок (1-3 мес) | 1-2 абзаца | 1 страница |
| Средний (6-12 мес) | 1/2 страницы | 3-5 страниц |
| Продвинутый (1+ год) | 2-3 страницы | 15-20 стр |
| Свободный (2+ года) | 10+ страниц | 1 книга |

## 6. Разговор — микродетали

### 6.1 Прогрессия

```
Уровень 1: iTalki — уроки с преподавателем (структурированно)
     → 2-3 раза в неделю

Уровень 2: HelloTalk/Tandem — текстовые собеседники
     → Ежедневно

Уровень 3: HelloTalk — голосовые сообщения
     → Ежедневно

Уровень 4: Языковой обмен (видеозвонки)
     → 1-2 раза в неделю

Уровень 5: Спонтанные разговоры (вживую)
     → При возможности
```

### 6.2 Разговорные шаблоны

**Вопросы:**
- Что ты думаешь о ____?
- Как прошёл день?
- Что ты делал на выходных?
- Какой твой любимый ____?
- Почему ты решил(а) ____?

**Выражение мнения:**
- Я думаю, что...
- По-моему...
- Мне кажется...
- С одной стороны... с другой стороны...
- Я согласен / не согласен

**Заполнители (для пауз):**
- Japanese: えっと, あの, そうですね
- Chinese: 嗯, 那个, 这个
- Korean: 음, 저, 그게

## 9. Мнемотехники

### 9.1 Метод ключевых слов

Для запоминания слов через ассоциации с родным языком:

```
Пример: яп. 猫 (neko) — кошка
Ассоциация: «Нэко» звучит как «нега» (негатив)
Представляю: кошка с недовольной мордой = подходит

Пример: кит. 苹果 (píngguǒ) — яблоко
Ассоциация: Ping + guo = «пинг» + «го»
Представляю: яблоко, подпрыгивающее со звуком «пинг»
```

### 9.2 Дворец памяти

1. Выбрать знакомое место (дом, маршрут)
2. Определить 10-20 локаций
3. Связать слова с локациями
4. Прогуляться по дворцу для повторения

### 9.3 Интервальное повторение (Leitner)

```
Коробка 1: каждый день
Коробка 2: раз в 3 дня
Коробка 3: раз в неделю
Коробка 4: раз в 2 недели
Коробка 5: раз в месяц

✅ Правильный ответ → следующая коробка
❌ Неправильный → коробка 1
```
