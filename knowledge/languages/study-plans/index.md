# Планы изучения языков

Общие принципы, ежедневные рутины, ресурсы и трекинг для каждого языка.

---

## 1. Общая методология

### 1.1 Принципы эффективного изучения

1. **Ежедневность** — 30 минут каждый день лучше 3 часов раз в неделю
2. **Разнообразие** — смена активностей (чтение, аудирование, речь, письмо)
3. **SRS (Spaced Repetition System)** — Anki для запоминания слов
4. **Погружение** — контент на целевом языке (YouTube, подкасты, сериалы)
5. **Вывод из пассивного в активное** — не просто понимать, но и использовать
6. **Терпение** — язык не выучить за 3 месяца, это марафон

### 1.2 Примерный прогресс (CEFR)

| Уровень | Слова | Часов | Описание |
|---------|-------|-------|----------|
| A1 | 500 | 80–100 | Базовые фразы |
| A2 | 1500 | 200–300 | Простые диалоги |
| B1 | 3000 | 400–500 | Разговор на бытовые темы |
| B2 | 5000 | 600–800 | Свободное общение |
| C1 | 8000+ | 1000+ | Почти носитель |

### 1.3 Ежедневный план (минимум 30 мин)

| Блок | Время | Активность |
|------|-------|------------|
| 1 | 10 мин | Anki (новые + повторение) |
| 2 | 10 мин | Вводный контент (YouTube/TV) |
| 3 | 10 мин | Чтение / Грамматика / Письмо |

**Оптимальный (1.5–2 часа):**

| Блок | Время | Активность |
|------|-------|------------|
| 1 | 15 мин | Anki |
| 2 | 30 мин | Аудирование (подкаст/видео) |
| 3 | 30 мин | Чтение + словарь |
| 4 | 15 мин | Разговор (iTalki/HelloTalk) |
| 5 | 15 мин | Письмо (дневник/LangCorrect) |

## 2. Японский язык

### 2.1 Дорожная карта

**Фаза 1 — Хирагана/Катакана (1–2 недели):**

- Выучить обе азбуки
- Чтение простых слов
- Письмо от руки (каждую букву)

**Фаза 2 — База (1–3 месяца):**

- 100–200 кандзи (JLPT N5)
- Базовая грамматика: частицы, глаголы, прилагательные
- 500–800 слов
- Простые предложения

**Фаза 3 — Выживание (3–6 месяцев):**

- 300–400 кандзи (N4)
- Грамматика N4
- 1500 слов
- Понимание медленной речи
- Простой разговор

**Фаза 4 — Средний (6–12 месяцев):**

- 650 кандзи (N3)
- Грамматика N3
- 3000+ слов
- Чтение простых статей/манги
- Разговор на бытовые темы

**Фаза 5 — Продвинутый (1–2 года):**

- 1000+ кандзи (N2)
- 6000+ слов
- Чтение новостей, смотрение аниме без субтитров
- Работа на японском

### 2.2 Ресурсы

| Ресурс | Для чего |
|--------|----------|
| **WaniKani** | Кандзи по радикалам |
| **BunPro** | Грамматика по JLPT |
| **Anki (Core 2k/6k)** | Слова |
| **Genki I + II** | Учебник |
| **NHK Easy News** | Чтение |
| **Satori Reader** | Чтение с аудио |
| **HelloTalk** | Разговор с носителями |
| **iTalki** | Уроки с преподавателем |
| **JapanesePod101** | Аудио уроки |
| **Tae Kim's Guide** | Грамматика (бесплатно) |
| **jisho.org** | Словарь |
| **よめチャンネル** | YouTube (медленная речь) |

### 2.3 Ежедневная рутина (японский)

```
[ ] Anki — 15 мин (кандзи + слова)
[ ] Чтение NHK Easy или Satori Reader — 15 мин
[ ] Аудирование (подкаст/аниме) — 15 мин
[ ] BunPro — 10 мин (грамматика)
[ ] Дневник на японском — 5 мин
```

### 2.4 Цели

- [ ] N5 (100 кандзи, 800 слов)
- [ ] N4 (300 кандзи, 1500 слов)
- [ ] N3 (650 кандзи, 3700 слов)
- [ ] N2 (1000 кандзи, 6000 слов)
- [ ] N1 (2000 кандзи, 10000 слов)

## 3. Китайский язык

### 3.1 Дорожная карта

**Фаза 1 — Пиньинь и тоны (1–2 недели):**

- Выучить пиньинь
- Практика тонов (хотя бы 1–4)
- Прослушивание минимальных пар (mā, má, mǎ, mà)

**Фаза 2 — База (1–3 месяца):**

- 100–150 иероглифов
- Базовая грамматика (пылесос из 把/被/了/过)
- 300–500 слов
- Порядок черт

**Фаза 3 — HSK 3 (3–6 месяцев):**

- 300–600 иероглифов
- Грамматика HSK 3
- 600+ слов
- Простые диалоги

**Фаза 4 — HSK 4 (6–12 месяцев):**

- 600–1000 иероглифов
- 1200 слов
- Чтение простых статей
- Понимание медленных новостей

**Фаза 5 — HSK 5+ (1–2 года):**

- 1000–1500 иероглифов
- 2500+ слов
- Беглое чтение
- Дискуссии

## 4. Корейский язык

### 4.1 Дорожная карта

**Фаза 1 — Хангыль (1 неделя):**

- Выучить все буквы хангыля
- Чтение слоговых блоков
- Правила произношения (ассимиляция)

**Фаза 2 — База (1–3 месяца):**

- Базовая грамматика: частицы, спряжения, уровни вежливости
- Чтение простых текстов

**Фаза 3 — TOPIK I (3–6 месяцев):**

- 800–1500 слов
- Грамматика TOPIK 1–2
- Понимание простых диалогов

**Фаза 4 — TOPIK II (6–12 месяцев):**

- 3000+ слов

- Чтение новостей
- Разговор на бытовые темы

**Фаза 5 — TOPIK II High (1–2 года):**

## 6. Общие советы

1. **Не учи "из-под палки"** — язык должен приносить удовольствие
2. **Окружи себя языком** — телефон, соцсети, уведомления → на целевом
3. **Говори вслух** — даже если один (shadowing)
4. **Ошибки — часть процесса** — без них не выучить
5. **Записывай свой голос** — лучший способ услышать ошибки
6. **Найди причину** — аниме, k-pop, дорамы, работа, путешествия
7. **Меняй ресурсы** — если скучно, переключись
8. **Не сравнивай** — у каждого свой темп
