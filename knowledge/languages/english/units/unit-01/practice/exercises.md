# Фонетика и произношение — упражнения

## Упражнение 3: Минимальные пары — выбери правильное слово

Прочитай пару. Дай букву слова, которое соответствует переводу.

1. ship / sheep — «овца»: a) ship b) sheep → b
2. bit / beat — «ударять»: a) bit b) beat → b
3. live / leave — «уезжать»: a) live b) leave → b
4. pull / pool — «бассейн»: a) pull b) pool → b
5. cap / cup — «чашка»: a) cap b) cup → b
6. think / sink — «раковина»: a) think b) sink → b
7. wine / vine — «вино»: a) wine b) vine → a
8. ship / chip — «чип»: a) ship b) chip → b

## Упражнение 4: Долгие и короткие гласные — распредели слова

Разложи слова на два столбика: /iː/ (долгий) и /ɪ/ (короткий). Слова: see, big, meet, fish, tree, sit, week, milk, green, six.

- /iː/: see, meet, tree, week, green
- /ɪ/: big, fish, sit, milk, six

## Упражнение 8: Найди лишнее слово

В каждой строке одно слово звучит НЕ так, как остальные.

1. see, tree, red, three, green → red (/e/, остальные /iː/)
2. cat, bag, pen, man, map → pen (/e/, остальные /æ/)
3. book, foot, good, food, look → food (/uː/, остальные /ʊ/)
4. think, thing, mother, three, month → mother (/ð/, остальные /θ/)
5. job, orange, juice, girl, bridge → girl (/ɜː/, остальные /dʒ/)

## Упражнение 9: Ударение — обведи ударный слог

Поставь ударение (выдели заглавными) в словах по образцу: waTER → waTER? Нет: следуй правилам из grammar.md.

1. water → WAter /ˈwɔːtə/
2. arrive → arRIVE /əˈraɪv/
3. teacher → TEAcher /ˈtiːtʃə/
4. begin → beGIN /bɪˈɡɪn/
5. family → FAMily /ˈfæməli/
6. police → poLICE /pəˈliːs/
7. tomorrow → toMORrow /təˈmɒrəʊ/
8. bedroom → BEDroom /ˈbedruːm/

## Упражнение 10: Интонация — расставь ↗ и ↘
