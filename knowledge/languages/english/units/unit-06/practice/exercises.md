# Unit 06 — Practice (A2-B1 Level)

## Упражнение 1: Weather vocabulary — заполните

1. The sun is ___ (shine). → shining
2. It is ___ (rain) heavily. → raining
3. The wind is ___ (blow). → blowing
4. It is very ___ (cloud) today. → cloudy
5. The temperature is very ___ (low). → low
6. Take an umbrella, it looks like ___ (rain). → rain
7. The sky is ___ (clear) after the storm. → clear
8. It is ___ (snow) outside. → snowing

## Упражнение 2: Present Continuous — заполните

1. It ___ (rain) right now. → is raining
2. Look! The sun ___ (shine). → is shining
3. Listen! The birds ___ (sing). → are singing
4. Be careful! The baby ___ (sleep). → is sleeping
5. They ___ (walk) in the park. → are walking
6. The leaves ___ (fall) from the trees. → are falling
7. The wind ___ (blow) strongly today. → is blowing

## Упражнение 3: Prepositions of place — заполните

1. The book is ___ the table. → on
2. The cat is ___ the chair. → under
3. The school is ___ the bank. → next to
4. He is ___ the room. → in
5. The park is ___ the house. → behind
6. The lake is ___ the two mountains. → between
7. The birds fly ___ the trees. → above
8. There is a deer ___ the river. → near

## Упражнение 4: Перевод на английский

1. Идёт дождь. — It is raining.
2. Солнечная погода. — It is sunny.
3. Птицы поют. — The birds are singing.
4. Книга на столе. — The book is on the table.
5. Дом рядом с парком. — The house is next to the park.
6. Летом жарче, чем весной. — Summer is hotter than spring.
7. Зима — самое холодное время года. — Winter is the coldest season.
8. Возьми зонт, будет дождь. — Take an umbrella, it will rain.

## Упражнение 5: There is / There are — выберите

## Упражнение 6: Comparatives and Superlatives — заполните

1. Summer is ___ (hot) than spring. → hotter
2. Winter is the ___ (cold) season. → coldest
3. The river is ___ (long) than the stream. → longer
4. The ocean is ___ (big) than the sea. → bigger (more)
5. Everest is the ___ (high) mountain. → highest
6. Autumn is ___ (beautiful) than winter. → more beautiful
7. This is the ___ (good) weather today. → best

## Упражнение 7: Will for forecasts — заполните

2. The sun ___ (shine) on Sunday. → will shine
3. It ___ (not be) cold tonight. → won't be
4. The temperature ___ (drop) below zero. → will drop
5. ___ it ___ (snow) next week? → Will it snow
6. There ___ (be) a storm. → will be

## Упражнение 10: Present Simple или Continuous? Выберите форму

1. It (rains / is raining) now. → is raining
2. It often (rains / is raining) in autumn. → rains
3. Look, it (snows / is snowing)! → is snowing
4. The sun (shines / is shining) brightly today. → is shining
5. It always (snows / is snowing) in January here. → snows
6. Be quiet, the baby (sleeps / is sleeping). → is sleeping

## Упражнение 11: Лексика природы — выберите правильное слово

1. A very big mountain is called a ___ (hill / peak). → peak
2. Water that falls from a high place is a ___ (waterfall / pond). → waterfall
3. A hot, dry place with little rain is a ___ (forest / desert). → desert
4. Land completely surrounded by water is an ___ (island / ocean). → island
5. A large company of trees is a ___ (field / forest). → forest
6. The deepest blue place where the water is salt is the ___ (lake / sea). → sea
7. A small, slow river is a ___ (stream / waterfall). → stream

## Упражнение 12: Переведите фразы на русский

1. It's raining cats and dogs. → Льёт как из ведра.
2. I'm under the weather today. → Я сегодня неважно себя чувствую.
3. What's the weather like? → Какая погода?
4. The sky is clear. → Небо ясное.
5. It looks like rain. → Похоже на дождь.

## Упражнение 13: Составьте предложения из слов

1. rain / will / it / tomorrow. → It will rain tomorrow.
2. is / the / shining / sun. → The sun is shining.
3. hotter / summer / spring / than / is. → Summer is hotter than spring.
4. a / in / deer / there / forest / is / the. → There is a deer in the forest.
5. in / snows / it / often / winter. → It often snows in winter.

## Упражнение 14: Исправьте ошибки

1. There are a river. → There is a river.
2. It snow now. → It is snowing now.
3. Winter is more cold than autumn. → Winter is colder than autumn.
4. The forecast say it will rain. → The forecast says it will rain.
5. There is many birds in the sky. → There are many birds in the sky.
