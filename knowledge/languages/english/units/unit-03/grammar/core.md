# Unit 03 — Grammar (A1-A2 Level)

## 3.1. Adjectives — степени сравнения

### Положительная степень (Positive)

| Категория | Слово | Пример |
|-----------|-------|--------|
| Размер | big, small | a big house |
| Возраст | old, young | an old man |
| Цвет | red, blue | a red car |
| Качество | good, bad | a good book |
| Состояние | happy, sad | a happy child |
| Физическое | tall, short | a tall person |

### Сравнительная степень (Comparative)

| Правило | Формула | Пример |
|---------|---------|--------|
| Короткие прилагательные (1 слог) | Adj + -er | tall → taller |
| Длинные прилагательные (2+ слога) | more + Adj | more interesting |
| Исключения | особая форма | good → better, bad → worse |

### Превосходная степень (Superlative)

| Правило | Формула | Пример |
|---------|---------|--------|
| Короткие | the + Adj + -est | the tallest |
| Длинные | the most + Adj | the most interesting |
| Исключения | особая форма | the best, the worst |

### Неправильные формы (Irregular Forms)

| Positive | Comparative | Superlative |
|----------|-------------|-------------|
| good | better | best |
| bad | worse | worst |
| far | farther/further | farthest/furthest |
| little | less | least |
| much/many | more | most |

## 3.2. Adverbs (Наречия)

### Типы наречий

| Тип | Функция | Примеры |
|-----|---------|---------|
| Времени | когда | always, never, often, sometimes, usually, today, tomorrow |
| Места | где | here, there, outside, inside, up, down |
| Образа действия | как | quickly, slowly, carefully, well, badly |
| Частоты | как часто | always, often, sometimes, rarely, never |
| Степени | насколько | very, quite, rather, too, enough |

### Сравнение наречий

| Правило | Формула | Пример |
|---------|---------|--------|
| Короткие | -er | faster, slower |
| Длинные | more | more carefully |
| Исключения | особая форма | better, worse, best, worst, more, less |

## 3.3. Sentence Structure (Структура предложения)

### Утверждение (Positive)

```
Subject + Verb + Object + Adverb
I   + eat + breakfast + every day.
She + works + hard + always.
```

### Отрицание (Negative)

```
Subject + do/does/did + not + Verb + Object
I   + do + not (don't) + like + coffee.
She + does + not (doesn't) + work + here.
```

### Вопрос (Question)

```
Do/Does/Did + Subject + Verb + Object + ?
Do + you + like + coffee?
Does + she + work + here?
Did + you + go + to school?
```

# Unit 03 — Numbers & Counting, Countable Words, Shopping (A1-A2 Level)

## 3.4. Числа 1-100: образование (Forming Numbers)

При написании составных чисел 21-99 ставятся дефисы:

| Диапазон | Формула | Примеры |
|----------|---------|---------|
| 13-19 | основа + teen | thirteen, fourteen, fifteen... |
| 20, 30, ... 90 | основа + ty | twenty, thirty, forty, fifty... |
| 21-99 (кроме круглых) | ty + дефис + unit | twenty-one, thirty-five, ninety-nine |
| 100 | a / one hundred | a hundred, one hundred |

Запомните особые формы: 2 → twenty, 3 → thirty, 4 → forty (без "u"), 5 → fifty, 8 → eighty.

| Число | Английский | Число | Английский |
|-------|------------|-------|------------|
| 11 | eleven | 21 | twenty-one |
| 12 | twelve | 33 | thirty-three |
| 15 | fifteen | 42 | forty-two |
| 20 | twenty | 57 | fifty-seven |
| 30 | thirty | 68 | sixty-eight |
| 40 | forty | 74 | seventy-four |
| 50 | fifty | 82 | eighty-two |
| 90 | ninety | 99 | ninety-nine |

## 3.5. Порядковые числительные: образование (Ordinal Numbers)

| Правило | Формула | Примеры |
|---------|---------|---------|
| 1, 2, 3 (особые) | first, second, third | 1st, 2nd, 3rd |
| Числа 4-19 | основа + th | fourth, fifth, sixth... |
| Круглые десятки | y → ie + th | twenty → twentieth |
| Составные | меняем только последнюю часть | twenty-first, thirty-second |

Исключения в своих группах: 8 → eighth (без t), 9 → ninth (без e), 12 → twelfth, 5 → fifth, 40 → fortieth (без u).

| Порядковое | Сокращение | Пример |
|------------|-----------|--------|
| first | 1st | the 1st of May |
| second | 2nd | the 2nd floor |
| third | 3rd | the 3rd price |
| twentieth | 20th | the 20th century |
| twenty-first | 21st | the 21st century |

Порядковые числительные почти всегда употребляются с определённым артиклем `the`: **the** first, **the** third book.

## 3.6. Артикли a / an (Articles)

### a перед согласными, an перед гласными звуками

| Артикль | Перед | Примеры |
|---------|-------|---------|
| a | согласный звук | a book, a sweater, a useful item (звук /j/) |
| an | гласный звук | an apple, an umbrella, an hour (h не читается) |

### Нулевой артикль с неисчисляемыми

| Неисчисляемое | Пример | Правило |
|---------------|--------|---------|
| money | Do you have money? | нет a/an с неисчисляемыми |
| bread / milk / water | I drink water. | обычно без артикля |
| luggage / information | useful information | без артикля |

При покупках `a/an` часто означают «один / порцию»: **a** kilo of apples, **an** apple, **a** loaf of bread.

## 3.7. some / any / no

| Слово | Употребление | Пример |
|-------|--------------|--------|
| some | утверждения, предложения, просьбы | I need some milk. / Can I have some tea? |
| any | вопросы, отрицания | Do you have any change? / I don't have any cash. |
| no | отрицание (= not any) | I have no money. |

Правило-подсказка: **some** — в утвердительных и вежливых просьбах, **any** — в вопросах и отрицаниях, **no** — с уже отрицательным смыслом.

| Пример | Перевод |
|--------|---------|
| I want some apples. | Я хочу несколько яблок. |
| Do you have any bananas? | У тебя есть бананы? |
| There isn't any sugar. | Сахара нет. |
| I have no time. | У меня нет времени. |

## 3.8. many / much / a lot of

| Слово | Исчисляемость | Пример |
|-------|---------------|--------|
| many | исчисляемые (apples, books) | How many apples? Many friends. |
| much | неисчисляемые (money, water) | How much money? Not much water. |
| a lot of | и исчисляемые, и неисчисляемые | a lot of friends / a lot of money |
| lots of | то же, разговорный | lots of people |

### many/much чаще в вопросах и отрицаниях

| Форма | Пример | Перевод |
|-------|--------|---------|
| How many | How many shirts do you need? | Сколько рубашек тебе нужно? |
| How much | How much does it cost? | Сколько это стоит? |
| not many | There aren't many people. | Людей не много. |
| not much | I don't have much money. | У меня не много денег. |
| a lot of (утверждение) | I have a lot of work. | У меня много работы. |

Порядок с much/many при описании количества: `much/many + существительное`. Например: many sizes, much juice.

## 3.9. few / little (мало) и a few / a little (немного)

| Слово | Исчисляемость | Значение | Пример |
|-------|---------------|----------|--------|
| a few | исчисляемые | несколько (чуть-чуть, положительно) | a few apples |
| few | исчисляемые | мало, почти нет (отрицательно) | few people came |
| a little | неисчисляемые | немного (положительно) | a little sugar |
| little | неисчисляемые | мало, почти нет (отрицательно) | little money |

| Пример | Перевод | Смысл |
|--------|---------|-------|
| I have a few dollars. | У меня есть несколько долларов. | есть, положительно |
| I have few dollars. | У меня (почти) нет долларов. | мало, отрицательно |
| Add a little salt. | Добавь немного соли. | немного |
| There is little milk left. | Молока почти не осталось. | мало |

Запомните рифму-подсказку: **a few / a little** = «чуть-чуть есть» (позитив), **few / little** = «почти нет» (негатив).

## 3.10. How much / How many (Вопросы о количестве и цене)

| Вопрос | Применение | Ответ |
|--------|------------|-------|
| How much is this? | цена одного предмета | It's ten dollars. |
| How much are these? | цена нескольких | They're twenty dollars. |
| How much (water) | количество неисчисляемого | Not much. / A lot. |
| How many (apples) | количество исчисляемого | A few. / Three. / Many. |

### Разбор

- **How much is this?** — «Сколько это стоит?» (личное местоимение this в значении «это»).
- **How much does it cost?** — то же, с глаголом cost (стоить).
- **How much + неисчисляемое** — о количестве: *How much milk do you need?*
- **How many + исчисляемое** — о количестве: *How many eggs do you want?*

| Пример | Перевод |
|--------|---------|
| How much is this T-shirt? | Сколько стоит эта футболка? |
| How much does this jacket cost? | Сколько стоит эта куртка? |
| How much sugar do you need? | Сколько сахара тебе нужно? |
| How many pairs of shoes do you have? | Сколько пар обуви у тебя есть? |

## 3.11. this / that / these / those (Указательные местоимения)

| Форма | Число | Близко | Далеко | Пример |
|-------|-------|--------|--------|--------|
| this | единственное | этот, эта, это | — | This shirt is blue. |
| that | единственное | — | тот, та, то | That dress is expensive. |
| these | множественное | эти | — | These shoes are small. |
| those | множественное | — | те | Those jeans are cheap. |

| Пример | Перевод |
|--------|---------|
| This is my size. | Это мой размер. |
| That one is too big. | Тот слишком большой. |
| These are on sale. | Эти на распродаже. |
| Those are the most popular. | Те самые популярные. |

При покупках: *Do you have this in a larger size?* (этот предмет), *I'll take those.* (те, дальше).

## 3.12. there is / there are (Оборот «имеется, есть»)

| Форма | Число | Пример |
|-------|-------|--------|
| There is (There's) | единственное | There is a bakery near here. |
| There is + неисчисляемое | неисчисляемое | There is some milk in the fridge. |
| There are | множественное | There are two shops on the corner. |
| There isn't / aren't | отрицание | There isn't any bread. |
| Is there / Are there | вопрос | Is there a fitting room? |

### Схема

```
There is/are + предмет + место
There is  + a supermarket + near the station.
There are + many customers + in the shop.
```

| Пример | Перевод |
|--------|---------|
| There is a sale on Friday. | В пятницу распродажа. |
| There are three shelves in the shop. | В магазине три полки. |
| Is there any change? | Есть сдача? |
| Are there any discounts? | Есть скидки? |

### Правило-подсказка
**There is** + единственное/неисчисляемое, **there are** + множественное. С а тут обратный порядок: незнакомый предмет вводится оборотом there is/are, а повторно упоминается через it/they.
