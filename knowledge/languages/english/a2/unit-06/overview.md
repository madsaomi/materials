# Английский · Урок 06 — Погода и ощущения: -ing / -ed

Этот урок организован вокруг задачи: **погода и ощущения: -ing / -ed**. Сначала разберите короткую модель, затем примените её в речи и проверьте себя. Подробная грамматика содержит и дополнительные темы: не обязательно проходить весь справочный объём за один подход.

## Чему вы научитесь

- Объяснять своими словами: Для описания погоды по-английски обычно нужно формальное подлежащее it.
- Разбирать учебный пример по ролям участников и значению формы.
- Самостоятельно решать задачу: Выберите: The lesson was interesting, so I was very ___. (interested / interesting)
- Применять правило в двух новых фразах, а не только узнавать готовый ответ.

## Короткое объяснение

Для описания погоды по-английски обычно нужно формальное подлежащее it. Прилагательные на -ing описывают вызывающее чувство свойство, а на -ed — испытываемое чувство. Это различие относится к смыслу, а не к одушевлённости само по себе.

**Пример с разбором.** It is raining. — Идёт дождь. The film is boring. — Фильм скучный. I am bored. — Мне скучно. Причина скуки и ощущение выражены разными формами.
