# Unit 07 — Грамматика: Умения и возможности

**Фокус юнита:** 可能补语 (听得懂/听不懂), 得/不得

---

## 1. 可能补语 — Структура V得/不+результат

Возможностное дополнение выражает **результативную возможность** («могу ли я достичь результата?»).

### Структура

```
肯定: V + 得 + результат/направление
Отрицание: V + 不 + результат/направление
```

| Положительное | Отрицательное | Значение |
|---------------|---------------|----------|
| 听得懂 | 听不懂 | понимаю на слух / не понимаю |
| 看得见 | 看不见 | вижу / не вижу |
| 吃得完 | 吃不完 | могу доесть / не могу доесть |
| 买得起 | 买不起 | могу купить (по средствам) / не могу |
| 走得动 | 走不动 | могу идти (physically) / не могу |
| 做得到 | 做不到 | могу сделать / не могу |

### Примеры

```
这个字太难了，我看不懂。
  — Это иероглиф слишком сложный, я не могу его прочитать.

他说得太快，我听不懂。
  — Он говорит слишком быстро, я не понима。

这个箱子太重了，我提不动。
  — Этот ящик слишком тяжёлый, я не могу его поднять.

你听得懂日语吗？
  — Ты понимаешь японский?

这条路太远了，我们走不到。
  — Эта дорога слишком длинная, мы не дойдём.
```

### Вопросительная форма

```
你看得见黑板上的字吗？
  — Ты видишь буквы на доске?

他吃得完这么多菜吗？
  — Он может столько съесть?

这本书你看得完吗？
  — Ты можешь закончить эту книгу?
```

## 3. 得/不得 — Долженствование и запрет

### 3.1. 得 (děi) — «должен, нужно, приходится»

```
我得去医院检查一下。
  — Мне нужно сходить в больницу на осмотр.

明天得早起。
  — Завтра нужно встать рано.

你得好好学习。
  — Ты должен хорошо учиться.

这件事你得告诉我。
  — Ты должен мне об этом рассказать.
```

Отрицание: **不得** используется в формальном стиле:

```
不得迟到。               — Опаздывать不得 (не разрешается).
不得大声喧哗。           — Шуметь不得.
```

### 3.2. 不得不 — «не могу не / вынужден»

```
我不得不去。
  — Мне приходится идти (я не могу не пойти).

他不得不承认错误。
  — Он вынужден признать ошибку.

我不得不改变计划。
  — Мне пришлось изменить планы.
```

> 不得不 — более сильное, чем 得. Это выражение **внешней необходимости**, вынужденности.

## 4. 能 vs 可以 vs 得 vs 可能补语 — Сравнение

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 能 + V | физическая/умственная способность | 我能吃辣的。 — Я могу есть острое. |
| 可以 + V | разрешение / возможность | 你可以在这里停车。 — Можно парковаться здесь. |
| 得 (děi) | необходимость (должен) | 我得走了。 — Мне пора идти. |
| V得+结果 | результативная возможность | 我看得懂。 — Я могу понять (прочитав). |
| 可能 + V | вероятность | 他可能不来。 — Он, возможно, не придёт. |

### Примеры для сравнения

```
我能游泳。             — Я умею плавать. (способность)
我可以游泳吗？         — Можно мне поплавать? (разрешение)
我游得动。             — Я могу проплыть (physically). (результат)
我会游泳。             — Я умею плавать. (навык)
```

```
我能听懂中文。         — Я понимаю китайский на слух. (способность)
我听得懂中文。         — Я могу понять китайский (результативно). (результат)
```

## 7. Направленное дополнение с 得/不 (趋向补语)

Три ключевые особенности: в отличие от результативных дополнений, **направленные глаголы** (来, 去, 出来, 起来, 上来, 下来, 过去, 过来, 到…) тоже могут получать 得/不:

```
肯定: V + 得 + 方向 + (宾语)
Отрицание: V + 不 + 方向 + (宾语)
```

| Положительное | Отрицательное | Значение |
|---------------|---------------|----------|
| 说出来 | 说不出来 | могу выразить словами / не могу выразить |
| 拿出来 | 拿不出来 | могу достать / не могу достать |
| 想起来 | 想不起来 | вспоминается / не могу вспомнить |
| 站起来 | 站不起来 | могу встать / не могу встать |
| 走过去 | 走不过去 | могу перейти (дорогу) / не могу перейти |
| 爬上去 | 爬不上去 | могу забраться / не могу забраться |
| 放进去 | 放不进去 | помещается / не помещается |
| 住下来 | 住不下来 | могу остаться жить / не могу остаться |
| 忙过来 | 忙不过来 | успеваю все дела / не успеваю |
| 帮上忙 | 帮不上忙 | могу помочь / не могу помочь |

### Примеры

```
我想不起来他的名字了。
  — Я не могу вспомнить его имя.

这些行李太重了，他拿不出来。
  — Этот багаж слишком тяжёлый, он не может его достать.

这双鞋太小了，我的脚放不进去。
  — Эти туфли слишком маленькие, нога не влезает.

这段时间太忙了，忙得连觉都睡不过来。
  — В последнее время так занят, что даже со сном не успеваю.

这个忙我帮不上，对不起。
  — Я не могу помочь, извини.
```

## 8. 程度补语 (V得+прилагательное) — не путать с 可能补语

Один и тот же 得 (de) может вставляться в разных значениях:

| Форма | Смысл | Пример |
|-------|-------|--------|
| V得 + результат/направление | результативная **возможность** | 他跑得动 — у него есть силы бежать |
| V得 + прилагательное | **степень**, качество действия | 他跑得快 — он бегает быстро |

### Пары-ловушки

```
他说得清楚。     — Он говорит (ясно). [степень]
他说得出来。     — Он может выразить это словами. [возможность]

她看得清楚。     — Она видит (чётко). [степень]
她看得见。       — Она может видеть (есть зрение). [возможность]

我听得很明白。   — Я всё хорошо понял. [степень]
我听得懂。       — Я понимаю на слух. [возможность]
```

> Запоминайте: если после 得 идёт **прилагательное** — это про то, КАК делается действие; если идёт **глагол/результат** — это про ВОЗМОЖНОСТЬ достичь результата.

### Структура степени с дополнением

```
S + V + 得 + (很/非常…) + прилагательное
他 说 得 很 快。
他 写 得 非常 漂亮。
```

## 9. Три «де»: 得 (děi), 得 (de) и 得 в 可能补语

| Форма | Произношение | Функция | Пример |
|-------|-------------|---------|--------|
| 得 | děi | должен, вынужден | 我得走了。 — Мне пора идти. |
| 得 | de | степень / качество действия | 他说得很快。 — Он говорит быстро. |
| 得 | (лёгкое, между V и результатом) | возможность | 听得懂 — понимаю на слух |

### Как не перепутать

```
听得懂   — 听 + 得 + 懂   [возможность]
听懂了   — 听 + 懂 + 了   [уже понял, завершённость]
听得很懂 — ✗ так не говорят (нужно 听得很明白)
```

- 得 (de) в степени всегда ударяется слабо и стоит между глаголом и прилагательным.
- 得 (děi) всегда читается с третьим-четвёртым тоном и означает «должен».
- 得 в 可能补语 — это «прокладка» между двумя глаголами/результатами, ударения нет.

## 10. Фиксированные пары 可能补语 (это нужно знать наизусть)

Многие пары стали **лексическими единицами** — их переводят целыми словами:

| Пара | Значение | Пример |
|------|----------|--------|
| 来得及 / 来不及 | успеть / не успеть | 现在去还来得及。 |
| 吃得消 / 吃不消 | выдержать / не выдержать | 工作太多，我吃不消。 |
| 靠得住 / 靠不住 | надёжный / ненадёжный | 他靠不住。 |
| 数得清 / 数不清 | сосчитать / не сосчитать | 天上的星星数不清。 |
| 认得出 / 认不出 | узнать / не узнать | 我认不出他了。 |
| 想得到 / 想不到 | ожидать / не ожидать | 想不到你这么厉害！ |
| 记得住 / 记不住 | запомнить / не запомнить | 生词太多，记不住。 |
| 答得上 / 答不上 | смочь ответить / не смочь | 这个问题我答不上来。 |
| 买得起 / 买不起 | по карману / не по карману | 这车我买不起。 |
| 陪得起 / 陪不起 | мочь себе позволить / не позволить | 我可等不起。 |

## 11. Вопросительная форма V得…V不…

Кроме обычного 吗, 可能补语 часто спрашивают **A-not-A** формой: **V得…V不…?**. Это очень естественно в разговорном языке.

```
你看得见看不见？         — Ты видишь или не видишь?
这本书你看得完看不完？   — Ты можешь закончить эту книгу?
你帮得上忙帮不上忙？     — Можешь помочь или нет?
她听得懂听不懂中文？     — Она понимает китайский на слух?
```

### Краткие ответы

```
看得见。 → 看得见。 / 看不见。
帮得上忙。 → 帮得上。 / 帮不上。
```

В полной форме V повторяется один раз, а результат и 得/不 — вместе с ним:

```
V + 得 + P / V + 不 + P
看 得见 / 看 不见  →  看得见看不见
```

## 12. Когда 能 и 会 НЕ заменяют 可能补语

Формы близки, но есть случаи, когда **только V得/不** звучит естественно.

### 1. Неожиданность / нарушение ожидания

```
这么难的题他也答得出来！      — Даже такую сложную задачу он может решить!
(d当 начальном этапе не говорят 能答出来)
```

### 2. Отрицание после факта

```
我打不开这个瓶子。            — Я не могу открыть эту бутылку.
(d自然нее, чем 不能打开)
```

### 3. Устойчивые выражения

```
想不起来     —  не могу вспомнить
数不清       —  не счесть
看不出来     —  не видно, что…
吃不下       —  не могу больше есть
听不出来     —  не могу различить на слух
```

> Практическое правило: когда речь о **достижении результата**, а не об умении вообще, предпочитайте V得/不. 能/会 — общая способность, V得/不 — конкретный результат здесь и сейчас.

## 13. Конструкции «все/ничего» с 什么 + 都 + V得/不

Подчёркивают всеохватность способности или её отсутствие:

```
他什么都会。                — Он все умеет.
他什么都学不会。            — Он ничего не может выучить.
我什么都看得懂。            — Я всё понимаю (при чтении).
她什么都做得出来。          — Она на всё способна.
我什么都记不住。            — Я ничего не запоминаю.
```

Структура: **什么 + 都/也 + V得/不 + результат / V + 得/不 + P**

```
什么 都 学 不 会     (не+会 = result)
什么 都 听 得 懂     (得+懂 = result)
```

## 14. Фраза «多…就…» — мотивация и результат

Очень частый разговорный паттерн: «сделай побольше X — и получится», часто сочетается с 可能补语.

```
多练就好了。                — Побольше практикуйся — и всё получится.
多听几遍就记住了。          — Послушай несколько раз — и запомнишь.
多读几遍就背下来了。        — Прочитай несколько раз — и выучишь наизусть.
多问问就明白了。            — Побольше расспрашивай — и поймёшь.
```

Структура: **多 + V + (число + сч. слово) + 就 + результат + 了**

> 就 (jiù) здесь означает «сразу, автоматически» — условие → быстрый результат.
