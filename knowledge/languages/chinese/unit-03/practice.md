# Unit 3 — 练习 (Практика)

## 练习 1：填空

Вставьте: 从, 到, 离, 往, 在

1. ___这儿___车站很远。
2. ___前走五分钟就到了。
3. 图书馆___公园旁边。
4. 学校___我家很近。
5. 我___北京___上海。

## 练习 2：翻译

1. Как пройти до библиотеки? → __________
2. Идите прямо до светофора. → __________
3. Поверните направо на перекрёстке. → __________
4. Отсюда до станции далеко? → __________
5. Выйдите на станции "Парк". → __________

## 练习 3：Дайте указания

Client находится у метро "Пекинский университет".
Он хочет дойти до музея.

Напишите маршрут (5 инструкций):
1. Выйти из метро
2. Идти прямо
3. Повернуть
4. Ориентиры
5. Прибытие

## 练习 4：Соедините

Соедините части предложений:

| 左边 | прямо |
| 右边 | слева |
| 往前走 | справа |
| 对面 | рядом |
| 旁边 | напротив |

## 练习 5：Диалог

Составьте диалог "Как пройти до отеля":
- Турист спрашивает дорогу
- Местный объясняет
- Уточнение (далеко ли? сколько минут?)
- Благодарность

## 答案

**练习 1:**
1. 从/到
2. 往
3. 在
4. 离
5. 从/到

**练习 2:**
1. 去图书馆怎么走？
2. 一直走到红绿灯。
3. 在路口往右转。
4. 从这儿到车站远吗？
5. 在公园站下车。

**练习 4:**
左边 — слева
右边 — справа
往前走 — прямо
对面 — напротив
旁边 — рядом
