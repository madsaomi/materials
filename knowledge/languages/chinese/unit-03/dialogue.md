# Unit 3 — 对话: 问路 (Как пройти)

## 对话

```
A: 你好！请问，去故宫怎么走？
B: 你一直往前走，到第二个红绿灯右转。
A: 右转？好的。
B: 然后走大概五分钟，你会看到一个很大的门。
A: 那个门就是故宫吗？
B: 对，那就是故宫的午门。
A: 坐地铁方便吗？
B: 方便。你坐一号线，到天安门东站下车。
A: 从天安门东站走过去远吗？
B: 不远，从A口出来，走三分钟就到了。
A: 太好了，谢谢你！
B: 不客气。祝你玩得愉快！
```
