# Unit 1 — 阅读 (Чтение)

## 我的家庭 (Моя семья)

```
我的家有四口人：爸爸、妈妈、哥哥和我。
爸爸是医生，在医院工作。
妈妈是老师，在学校教中文。
哥哥是大学生，学计算机。
我是高中生，学习汉语和英语。
我们住在北京。
我家有一只猫，很可爱。
```

### 生词

| 汉字 | 拼音 | 翻译 |
|------|------|------|
| 家庭 | jiātíng | семья |
| 口 | kǒu | счётное слово (члены семьи) |
| 爸爸 | bàba | папа |
| 妈妈 | māma | мама |
| 哥哥 | gēge | старший брат |
| 医生 | yīshēng | врач |
| 医院 | yīyuàn | больница |
| 教 | jiāo | учить (преподавать) |
| 大学生 | dàxuéshēng | студент |
| 学 | xué | учить, изучать |
| 高中 | gāozhōng | старшая школа |
| 英语 | yīngyǔ | английский язык |
| 住 | zhù | жить |
| 北京 | Běijīng | Пекин |
| 只 | zhī | сч. слово для животных |
| 可爱 | kě'ài | милый |

### 翻译

В моей семье 4 человека: папа, мама, старший брат и я.
Папа — врач, работает в больнице.
Мама — учительница, преподаёт китайский в школе.
Брат — студент, изучает компьютеры.
Я — старшеклассник, учу китайский и английский.
Мы живём в Пекине.
У нас есть кошка, очень милая.

### 问题 (Вопросы)

1. 他家有几口人？
2. 爸爸做什么工作？
3. 妈妈在哪儿工作？
4. 哥哥学什么？
5. 他们家住在哪儿？
6. 他家有没有宠物？

**Ответы:**
1. 四口人。
2. 爸爸是医生。
3. 妈妈在学校工作。
4. 哥哥学计算机。
5. 他们住在北京。
6. 有一只猫。

# Расширение Unit 1 — 阅读 (Чтение)

## 我的学校 (Моя школа)

```
我的学校在北京。学校很大，也很漂亮。
学校里有很多老师和学生。
我的老师姓王，她教我们汉语。她非常好，我们都很喜欢她。
我每天八点上课，下午三点放学。
学校里有一个大操场和一个图书馆。
我喜欢在学校里读书和打球。
我的朋友李明也在这个学校。我们常常一起学习、一起玩。
```

### 生词 (Новые слова)

| 汉字 | 拼音 | 翻译 |
|------|------|------|
| 学校 | xuéxiào | школа |
| 很 | hěn | очень |
| 老师 | lǎoshī | учитель |
| 姓 | xìng | фамилия |
| 教 | jiāo | преподавать |
| 每天 | měitiān | каждый день |
| 上课 | shàngkè | идти на урок |
| 放学 | fàngxué | заканчивать занятия |
| 操场 | cāochǎng | спортивная площадка |
| 图书馆 | túshūguǎn | библиотека |
| 读书 | dúshū | читать, учиться |
| 打球 | dǎqiú | играть в мяч |
| 一起 | yìqǐ | вместе |
| 玩 | wán | играть, развлекаться |

### 翻译 (Перевод)

Моя школа в Пекине. Школа большая и очень красивая.
В школе много учителей и учеников.
Мой учитель по фамилии Ван, она преподаёт нам китайский. Она очень хорошая, мы все её любим.
Каждый день у меня занятия в 8 часов, после обеда в 3 часа заканчивается школа.
В школе есть большая спортивная площадка и библиотека.
Я люблю читать и играть в мяч в школе.
Мой друг Ли Мин тоже в этой школе. Мы часто вместе учимся и играем.

### 问题 (Вопросы)

1. 学校在哪儿？
2. 老师的姓是什么？
3. 王老师教什么？
4. 我每天几点上课？
5. 学校里有什么？
6. 我的好朋友是谁？

**Ответы:**
1. 学校在北京。
2. 老师姓王。
3. 王老师教汉语。
4. 我每天八点上课。
5. 学校里有一个大操场和一个图书馆。
6. 我的好朋友是李明。

## 我的爱好 (Мои увлечения)

```
我叫小华，我是学生。我的爱好很多。
我喜欢打篮球，也喜欢游泳。周末我常常和朋友们一起运动。
我也喜欢看书，晚上我喜欢看中文小说。
我还喜欢听音乐。我喜欢的音乐是流行音乐。
我每天听音乐，一边听一边学习汉语。
我不喜欢玩电脑游戏，因为我觉得那浪费时间。
我的朋友们都说我是一个认真的人。
```

### 生词 (Новые слова)

| 汉字 | 拼音 | 翻译 |
|------|------|------|
| 爱好 | àihào | увлечение, хобби |
| 打篮球 | dǎ lánqiú | играть в баскетбол |
| 游泳 | yóuyǒng | плавать |
| 运动 | yùndòng | спорт |
| 看书 | kànshū | читать книги |
| 小说 | xiǎoshuō | роман, проза |
| 音乐 | yīnyuè | музыка |
| 流行音乐 | liúxíng yīnyuè | поп-музыка |
| 一边...一边 | yìbiān...yìbiān | одновременно... |
| 电脑游戏 | diànnǎo yóuxì | компьютерная игра |
| 浪费时间 | làngfèi shíjiān | тратить время |
| 认真 | rènzhēn | серьёзный, старательный |

### 翻译 (Перевод)

Меня зовут Сяо Хуа, я ученик. У меня много увлечений.
Я люблю играть в баскетбол и люблю плавать. По выходным я часто занимаюсь спортом вместе с друзьями.
Ещё я люблю читать книги: вечером я читаю китайские романы.
Я также люблю слушать музыку. Из музыки мне нравится поп-музыка.
Я каждый день слушаю музыку, слушаю и одновременно учу китайский.
Я не люблю играть в компьютерные игры, потому что считаю, что это зря тратит время.
Мои друзья говорят, что я серьёзный человек.

2. 他周末常常做什么？
3. 晚上他喜欢做什么？
4. 他喜欢什么音乐？
5. 他为什么不喜欢玩电脑游戏？
6. 朋友们怎么说他？

**Ответы:**
1. 他的爱好是打篮球、游泳、看书和听音乐。
2. 他周末常常和朋友们一起运动。
3. 晚上他喜欢看中文小说。
4. 他喜欢流行音乐。

6. 朋友们说他是一个认真的人。

## 我的家 (Моя семья — подробнее)

```
我的家在上海。我家有五口人：爷爷、爸爸、妈妈、妹妹和我。
爷爷今年七十岁，他已经退休了。他每天早上在公园里锻炼身体。
爸爸是老师，他教英语。妈妈是医生，她在医院工作，每天很忙。
妹妹今年五岁，她还没有上学。她很喜欢画画。
我已经上大学了，学的是中文专业。
周末我们全家常常一起吃饭、看电影。
虽然爸爸妈妈很忙，但是我们很幸福。
```

### 生词 (Новые слова)

| 汉字 | 拼音 | 翻译 |
|------|------|------|
| 上海 | Shànghǎi | Шанхай |
| 岁 | suì | лет (возраст) |
| 退休 | tuìxiū | выйти на пенсию |
| 公园 | gōngyuán | парк |
| 锻炼 | duànliàn | тренироваться |
| 专业 | zhuānyè | специальность |
| 画画 | huàhuà | рисовать |
| 虽然 | suīrán | хотя |
| 但是 | dànshì | но |
| 幸福 | xìngfú | счастливый |
| 全家 | quánjiā | вся семья |
| 电影 | diànyǐng | фильм |

### 翻译 (Перевод)

Моя семья живёт в Шанхае. В моей семье пять человек: дедушка, папа, мама, младшая сестра и я.
Дедушке в этом году 70 лет, он уже на пенсии. Каждое утро он занимается физкультурой в парке.
Папа — учитель, он преподаёт английский. Мама — врач, она работает в больнице и каждый день очень занята.
Младшей сестре 5 лет, она ещё не ходит в школу. Она очень любит рисовать.
Я уже учусь в университете, моя специальность — китайский язык.
По выходным вся семья часто вместе обедает и смотрит фильмы.
Хотя папа и мама очень заняты, мы счастливы.
