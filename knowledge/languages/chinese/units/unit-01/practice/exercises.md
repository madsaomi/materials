# Unit 1 — 练习 (Практика)

## 练习 1：填空 (Заполните пропуски)

1. 你___什么名字？
2. 我___中国人。
3. 她___老师。
4. 这是谁___书？
5. 他___喜欢咖啡。

**Варианты:** 叫, 是, 的, 不, 很

## 练习 2：翻译 (Переведите)

1. Меня зовут Ли Мин. → __________
2. Я студент. → __________
3. Ты русский? → __________
4. Это моя книга. → __________
5. Спасибо, до свидания! → __________

## 练习 3：对话 (Диалог)

Расположите реплики в правильном порядке:

- [ ] 再见！
- [ ] 我叫王明。你呢？
- [ ] 你好！你叫什么名字？
- [ ] 我叫李芳。很高兴认识你！
- [ ] 我也很高兴认识你！
- [ ] 这是我的电话号码。12345678。

## 练习 4：选择 (Выберите правильное)

1. 你(叫/是)什么名字？
2. 我(没/不)是俄罗斯人。
3. 他(不/没)吃饭。
4. 你学习汉语(多长时间/什么)。
5. 我(的/了)家在市中心。

## 练习 5：写自我介绍 (Напишите о себе)

5 предложений:

1. 我叫... / Приветствие
2. 我是... / Кто вы
3. 我住在... / Где живёте
4. 我学习... / Что учите
5. 我的电话... / Контакт

## 答案 (Ответы)

**练习 1:**

1. 叫
2. 是
3. 是/不是
4. 的
5. 不

**练习 2:**

1. 我叫李明。
2. 我是学生。
3. 你是俄罗斯人吗？
4. 这是我的书。
5. 谢谢，再见！

**练习 3:**

2. 我叫李芳。很高兴认识你！
3. 我叫王明。你呢？

## 练习 7：排序 (Составьте предложения из слов)

1. 我 / 学生 / 是 → __________
2. 他 / 汉语 / 学习 → __________
3. 你 / 哪国人 / 是 → __________
4. 她的 / 手机 / 新 / 很 → __________
5. 我们 / 明天 / 去 / 商店 → __________

## 练习 8：选择 不/没 (Выберите правильное отрицание)

1. 我____是中国人。(не)
2. 他昨天____去学校。(не пошёл)
3. 她____喜欢咖啡。(не любит)
4. 我____有钱。(нет денег)
5. 明天我____上班。(не пойду на работу)

```

```

**Напишите свои ответы** (например, 我叫安娜 / 我是俄罗斯人 / 我住在莫斯科).

## 练习 11：选词填空 (Вставьте подходящее слово)

2. 你是老师____？
3. 我____一个哥哥。

## 练习 12：翻译成中文 (Переведите на китайский)

1. Меня зовут Анна. → __________
2. Я русская. → __________
3. У меня есть два друга. → __________
4. Моя мама — врач. → __________
5. Я живу в Москве. → __________

## 练习 13：错误辨析 (Найдите и исправьте ошибки)

1. 我不是学生。→ (верно/неверно?) ______
2. 我妈妈是老师。→ (версия без 的) ______
3. 她很漂亮。→ (без 很) ______
4. 我没是中国人。→ (правильно?) ______
5. 我家有六口人。→ (смысл) ______

## 练习 14：用 也 造句 (Составьте предложения с 也)

1. 我喜欢茶，____________。(она)
2. 我是学生，____________。(он)
3. 我住在北京，____________。(они)
