# Unit 5 — 对话: 天气和爱好 (Погода и хобби)

## 对话

```
李明: 今天天气真好！不冷也不热。
王芳: 是啊，今天出太阳了。天气预报说明天要下雨。
李明: 那我明天不出去玩了，在家看书。
王芳: 你喜欢看书吗？
李明: 喜欢。我喜欢看中文小说。你呢？
王芳: 我喜欢听音乐和画画。
李明: 你还会画画？真厉害！
王芳: 我从小就喜欢画画，一有时间就画。
李明: 那你画得一定很好！
王芳: 还可以。你除了看书以外，还有什么爱好？
李明: 我还喜欢跑步和游泳。
王芳: 我夏天也喜欢游泳，冬天就只喜欢待在家里。
李明: 冬天太冷了，我也喜欢在家喝热茶。
王芳: 天气越来越冷了，你要多穿衣服。
李明: 谢谢，你也是！
王芳: 对了，你周末一般做什么？
李明: 周末我通常会去公园跑步，有时候也去爬山。
王芳: 爬山？你喜欢爬山吗？
李明: 喜欢，我觉得爬山既能锻炼身体，又能欣赏风景。
王芳: 那我们周末可以一起去爬山！
李明: 好啊！不过明天可能要下雨，我们还是在家看书吧。
王芳: 好吧，那明天我在家画画，你看书。
李明: 好的。你画完以后可以给我看看你的画吗？
王芳: 当然可以！到时候我给你看。
李明: 那我们明天见！
王芳: 明天见！
```
