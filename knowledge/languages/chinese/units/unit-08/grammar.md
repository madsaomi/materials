# Unit 08 — Грамматика: Дарение и услуги

**Фокус юнита:** 给/帮, 把字句 (углубление), 双宾语

---

## 1. 给 — Предлог «для / кому-либо»

### 1.1. 给 + косвенное дополнение («кому»)

```
我把礼物给她。         — Я даю подарок ей.
妈妈给我买了新衣服。   — Мама купила мне новую одежду。
他给我打了一个电话。   — Он мне позвонил。
请把这本书给老师。     — Пожалуйста, отдай эту книгу учителю。
```

### 1.2. V + 给 + кому + что

```
送给你一个礼物。       — Дарю тебе подарок.
卖给我一辆车。         — Продал мне машину.
还给他一本书。         — Вернул ему книгу.
```

### 1.3. 给 + V («делать для кого-то»)

```
我给你做饭。           — Я готовлю для тебя.
他帮我搬家。           — Он помогает мне переезжать.
```

### Таблица: 给 как предлог vs глагол

| Роль | Пример | Перевод |
|------|--------|---------|
| предлог (кому) | 给她写信 | писать ей письмо |
| глагол (дать) | 我给你一本书 | я даю тебе книгу |
| после V (направление) | 送给他 | подарить ему |
| «для» | 给孩子做饭 | готовить для ребёнка |

---

## 2. 帮 — «помогать»

### Структура

```
帮 + (кого-то) + V + (что-то)
```

```
帮我一个忙。           — Сделай мне одолжение.
你帮我看看这篇文章。   — Помоги мне посмотреть эту статью.
他帮妈妈做家务。       — Он помогает маме по дому.
谁能帮我一下？         — Кто может мне помочь?
她帮我翻译了这封信。   — Она помогла мне перевести это письмо.
```

### 帮 vs 给

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 给我做饭 | готовить **для меня** (не обязательно помогая) | 我给你做饭。 |
| 帮我做饭 | **помогать** мне готовить | 你帮我做饭吧。 |
| 给我开门 | **открыть дверь для меня** | 请给我开门。 |
| 帮我开门 | **помочь открыть дверь** | 你能帮我开门吗? |

> **Разница:** 给 = «для кого-то»; 帮 = «помогая кому-то».

## 3. 把字句 — Углубление (把 + O + V + дополнение)

Конструкция с **把** ставит объект **перед** глаголом для акцента на результате действия.

### Структура

```
主语 + 把 + объект + V + дополнение (результат, направление, завершение)
```

### 3.1. 把 + O + V + 在/到/给 + Where/Whom

```
请把书放在桌子上。     — Положи книгу на стол.
请把车停到路边。       — Поставь машину на обочину.
我把礼物送给了她。     — Я подарил подарок ей.
他把钱还给了我。       — Он вернул мне деньги.
```

### 3.2. 把 + O + V + 成 («превратить в»)

```
她把中文翻译成了英文。 — Она перевела китайский на английский.
他把牛奶做成了奶酪。   — Он превратил молоко в сыр.
我把错的改成了对的。   — Я исправил неправильное на правильное.
```

### 3.3. 把 + O + V + 完/好/干净 (результат)

```
请把作业做完。         — Закончи домашнее задание.
我把房间收拾好了。     — Я привёл комнату в порядок.
你把桌子擦干净。       — Протри стол досуха.
我把菜做咸了。         — Я пересолил блюдо.
```

### 3.4. 把 + O + V + 一下 (мягкий приказ)

```
请把门关一下。         — Закрой, пожалуйста, дверь.
把窗户打开一下。       — Открой, пожалуйста, окно.
你把声音调小一点。     — Тише, пожалуйста.
```

### Важные правила для 把

| Правило | Пример |
|---------|--------|
| Объект должен быть **известным** (конкретным) | 把那本书给我。(✓) 把书给我。(✓) 把一本书给我。(✗) |
| После V **обязательно** дополнение | 把门关了。(✓) 把门关。(✗) |
| Нельзя с беспри挚ными глаголами | 看见, 知道, 喜欢 — ❌ с 把 |

## 4. 双宾语 — Двойное дополнение (V + IO + DO)

Некоторые глаголы принимают **два дополнения**: косвенное (кому) и прямое (что).

### Структура

```
主语 + V + IO (кому) + DO (что)
```

### Типичные глаголы

| Глагол | Пример | Перевод |
|--------|--------|---------|
| 给 | 他给我一本书。 | Он дал мне книгу. |
| 送 | 她送我一条围巾。 | Она подарила мне шарф. |
| 教 | 老师教我们汉语。 | Учитель учит нас китайскому. |
| 问 | 我问你一个问题。 | Я задаю тебе вопрос. |
| 回答 | 他回答我一个问题。 | Он отвечает мне на вопрос. |
| 告诉 | 告诉我一件事。 | Расскажи мне одну вещь. |

### Примеры

```
妈妈送我一个生日礼物。   — Мама подарила мне подарок на день рождения.
他教我弹吉他。           — Он учит меня играть на гитаре.
请告诉我你的名字。       — Пожалуйста, скажи мне своё имя.
老师给我们留了作业。     — Учитель задал нам домашнее задание.
```

### 双宾语 vs 把字句

| Форма | Пример |
|-------|--------|
| 双宾语 | 他送我一本书。 |
| 把字句 | 他把那本书送给我了。 |

Обе формы правильны, но 把字句 подчёркивает **результат** и **известность объекта**.

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 请把书给我。 | ✅ (верно) | — |
| 请把书给我在桌子上。 | 请把书放在桌子上。 | 不 нужна 目的地, 不 把 |
| 我把一封信给他了。 | 我给他了一封信。 / 我把那封信给他了。 | Конкретный объект для 把 |
| 请把门关。 | 请把门关上。 / 请把门关了。 | После V с 把 нужно дополнение |
| 他帮我了搬家。 | 他帮我搬家。 / 他帮我搬了家。 | 不 挺 placement |
| 我给他在写信。 | 我在给他写信。 | Время ставится перед 给 |
| 你把作业做完不？ | 你把作业做完了吗？ | Вопрос с 吗, не 不 |

## 7. Сравнение: 比 (bǐ)

### 7.1. Базовая структура

```
A + 比 + B + (更/还) + прилагательное
```

```
这个礼物比那个（更）好看。  — Этот подарок красивее того.
哥哥比我高。                — Старший брат выше меня.
她比我小三岁。             — Она младше меня на три года.
这件衣服比那件贵得多。     — Эта одежда намного дороже той.
```

### 7.2. Степень разницы: 得多 / 一点儿 / 一些

| Фраза | Значение |
|-------|----------|
| 比…得多 | намного… |
| 比…一点儿 | чуть-чуть… |
| 比…一些 | немного… |

```
红色比黄色好看得多。   — Красный намного красивее жёлтого.
这个比那个便宜一点儿。 — Это чуть дешевле того.
```

### 7.3. Отрицание сравнения: 没有 / 不如

```
A + 没有 + B + Adj     — A не такой …, как B
A + 不如 + B + Adj     — A не такой хороший, как B
```

```
这个礼物没有那个好看。 — Этот подарок не такой красивый, как тот.
他的手表不如我的贵。   — Его часы не такие дорогие, как мои.
```

### 7.4. 比 с глаголами

```
他比我会做菜。         — Он умеет готовить лучше меня.
我比他喜欢学习。       — Я люблю учиться больше, чем он.
```

> **Важно:** после 比 нельзя ставить 很. Говорим «比…好», «比…更好», но не «比…很好».

## 8. Превосходная степень: 最 (zuì)

### Структура

```
最 + прилагательное / 最 + глагол-предпочтение
```

```
这是最漂亮的礼物。     — Это самый красивый подарок.
她是我们班最高的。     — Она самая высокая в нашем классе.
我最喜欢蓝色的围巾。   — Мне больше всего нравится голубой шарф.
```

### 最…之一 — «один из самых…»

```
中国是世界上最美丽的国家之一。
— Китай — одна из самых красивых стран мира.
```

### 比 vs 更 vs 最

| Конструкция | Функция | Пример |
|-------------|---------|--------|
| 比 | сравнение двух предметов | 他比我高。 |
| 更 | «ещё» на фоне сравнения | 他比我更高。 |
| 最 | превосходная среди всех | 他是最高的。 |

## 9. Дополнение результата (结果补语)

### Структура

```
V + 完 / 好 / 对 / 错 / 到 / 见 / 懂 / 住
```

| Дополнение | Значение | Пример |
|------------|----------|--------|
| 完 | завершить | 作业做完了吗？— Уроки сделал? |
| 好 | готово, качественно | 礼物包扎好了。— Подарок упакован. |
| 对 | правильно | 这道题做对了。— Решил правильно. |
| 错 | ошибочно | 我把地址写错了。— Я ошибся адресом. |
| 到 | достичь, достать | 我买到了票。— Я достал билет. |
| 见 | увидеть | 你看见我的手机了吗？— Ты видел мой телефон? |
| 懂 | понять | 我听懂了他的话。— Я понял его слова. |
| 住 | зафиксировать | 他记住了我的名字。— Он запомнил моё имя. |

### Отрицание: 没 + V + 结果

```
礼物还没送到。         — Подарок ещё не доставлен.
我没听懂你的话。       — Я не понял твоих слов.
```

### 把 + O + V + 结果

```
请把礼物包装好。       — Упакуй подарок как следует.
我把房间打扫干净了。   — Я вычистил комнату.
```

## 10. Дополнение направления (趋向补语)

### 10.1. Простое направление: V + 来 / 去

```
V + 来 — действие к говорящему
V + 去 — действие от говорящего
```

```
妈妈带来了一束花。     — Мама принесла букет цветов (сюда).
他送去了一件包裹。     — Он отправил посылку (туда).
```

### 10.2. Составное направление

| Глагол | 来 | 去 |
|--------|----|----|
| 进 (входить) | 进来 | 进去 |
| 出 (выходить) | 出来 | 出去 |
| 上 (вверх) | 上来 | 上去 |
| 下 (вниз) | 下来 | 下去 |
| 回 (назад) | 回来 | 回去 |
| 过 (мимо/через) | 过来 | 过去 |
| 起 (подняться) | 起来 | — |

```
他拿出来了礼物。       — Он достал подарок.
她把书放回去了。       — Она поставила книгу обратно.
把礼物捡起来！         — Подними подарок!
```

### 10.3. 起来 — начало состояния

```
天气暖和起来了。       — Погода стала тёплой.
他笑了起来。           — Он засмеялся.
```

## 11. Дополнение степени (程度补语)

### Структура

```
Adj/V + 得 + 很 / 不得了 / 要死 / 不行
Adj + 极了 / 死了 / 坏了
```

```
礼物包装得漂亮极了。   — Подарок упакован очень красиво.
我高兴得不得了。       — Я необыкновенно рад.
他紧张得要死。         — Он ужасно нервничает.
这份心意珍贵极了。     — Это внимание бесценно.
```

### Таблица степеней

| Конструкция | Оттенок | Пример |
|-------------|---------|--------|
| 得很 | очень | 这件礼物好得很。 |
| 极了 | чрезвычайно | 这个蛋糕好吃极了。 |
| 死了 | ужасно (очень) | 我累死了。 |
| 不得了 | невероятно | 她开心得不得了。 |

## 12. Дополнение количества (动量/时量补语)

### 12.1. Сколько раз: V + 次 / 遍 / 趟 / 下

```
我去过三次中国。       — Я ездил в Китай три раза.
这本书我看了两遍。     — Эту книгу я прочитал дважды.
麻烦你跑一趟。         — Сходи туда, пожалуйста.
请再说一遍。           — Повторите, пожалуйста.
```

### 12.2. Сколько времени: V + 了 + время + (了)

```
我等了他一个小时。           — Я ждал его час.
她在商场逛了两个小时。       — Она гуляла по торговому центру два часа.
```

### 12.3. Порядок слов

| Тип | Порядок | Пример |
|-----|---------|--------|
| 动量 (сколько раз) | V + 次 | 我去过三次。 |
| 时量 (как долго) | V + 了 + время | 我等了一小时。 |

## 13. Усилительная конструкция 是…的

### Структура

```
S + 是 + (时间/地点/方式) + V + 的
```

Подчёркивает **обстоятельство** действия (когда, где, как).

```
我是昨天买的礼物。           — Я купил подарок ВЧЕРА.
这个礼物是在北京买到的。     — Этот подарок куплен В ПЕКИНЕ.
他是坐飞机来的。             — Он приехал НА САМОЛЁТЕ.
我们是走路上学的。           — Мы ходим в школу ПЕШКОМ.
```

### Отрицание и вопрос

```
我不是坐高铁来的。           — Я приехал НЕ на скоростном поезде.
你是跟谁一起去的？           — С кем ты ходил?
你在哪里买的？               — Где ты это купил?
```

> **Внимание:** «是…的» нельзя опускать — это не просто связка, а смысловой акцент.

## 14. Связки предложений

### 14.1. 一边…一边 — одновременность

```
他一边走一边听音乐。   — Он идёт и слушает музыку.
我一边喝茶一边看书。   — Я пью чай и читаю.
```

### 14.2. 不但…而且 — «не только…, но и…»

```
她不但漂亮，而且很聪明。         — Она не только красивая, но и умная.
这不但是礼物，而且是心意。       — Это не просто подарок, а знак внимания.
```

### 14.3. 因为…所以 — причина и следствие

```
因为下雨，所以我们不去了。       — Из-за дождя мы не идём.
因为我喜欢她，所以想送她礼物。   — Я хочу подарить ей подарок, потому что она мне нравится.
```

### Таблица связок

| Связка | Функция | Пример |
|--------|---------|--------|
| 一边…一边 | одновременность | 一边说话一边吃饭 |
| 不但…而且 | добавление | 不但便宜，而且好用 |
| 因为…所以 | причина-следствие | 因为忙，所以没来 |
| 虽然…但是 | уступка | 虽然贵，但是很好 |

## 15. Типичные ошибки (часть 2)

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 这个比那个很好。 | 这个比那个更好。 | После 比 нельзя 很 |
| 他是我班最高的人。✓ | — | 最 + Adj правильно |
| 我把作业做。 | 我把作业做完了。 | С 把 нужен результат |
| 我去了过中国。 | 我去过中国。 | Путают 了 и 过 |
| 我买东西了在商场。 | 我在商场买东西了。 | Место перед глаголом |
| 他是昨天去。 | 他是昨天去的。 | 是…的 не опускается |
| 他一边吃饭一边玩手机。✓ | — | Оба действия одновременно |
| 这件礼物是很漂亮。 | 这件礼物很漂亮。/ 这件礼物是很漂亮的。 | 很 достаточно, 是…的 не нужно для качества |
| 他把我〜給老师了。(запутанно) | 他把书给老师了。 | Объект после 把 ясен, без 〜 |
| 我们互送了礼物。✓ | — | 互 = «друг друга» |

> После юнита 11 (被动 被字句) сравните: 把 — акцент на объекте и результате, 被 — акцент на действии над субъектом.
