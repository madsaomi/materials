# Unit 3 — 语法 (Грамматика)

## 1. 怎么 + V (как сделать)

```
去故宫怎么走？         — Как пройти к Запретному городу?
这个汉字怎么写？       — Как пишется этот иероглиф?
去车站怎么坐车？       — На каком автобусе ехать до вокзала?
```

## 2. 往 + направление + V

```
往前走               — Иди вперёд
往右拐               — Поверни направо
往左走               — Иди налево
往后看               — Посмотри назад
```

## 3. 离 (от... до... расстояние)

```
地铁站离这儿远吗？    — Станция метро далеко отсюда?
学校离我家很近。      — Школа близко от моего дома.
北京离上海很远。      — Пекин далеко от Шанхая.
```

**Структура:** [место1] 离 [место2] + 远/近/距离

## 4. 从...到... (от... до...)

```
从这儿到车站走五分钟。   — Отсюда до вокзала идти 5 мин.
从早上八点到下午五点。   — С 8 утра до 5 вечера.
从北京到上海坐高铁。     — Из Пекина в Шанхай на скоростном поезде.
```

## 5. 坐 + транспорт

```
坐地铁               — На метро
坐公交车             — На автобусе
坐出租车             — На такси
坐飞机               — На самолёте
```

## 6. 到 + место (прибыть)

```
到站了。             — Приехали (на станцию).
到天安门东站下车。    — Выйти на станции Тяньаньмэнь Восточная.
到了吗？             — Уже приехали?
```

## 7. 就 (именно, тогда, сразу)

```
往前走就到了。       — Иди вперёд и сразу придёшь.
我就来。             — Я сейчас приду.
这就是我的家。       — Это и есть мой дом.
```

## 8. 还 (ещё / всё ещё)

```
还没到。             — Ещё не приехали.
还要走十分钟。       — Ещё идти 10 минут.
还要别的吗？         — Нужно что-то ещё?
```

## 9. 吧 (предположение / предложение)

```
走吧！               — Пошли!
你是学生吧？         — Ты студент, наверное?
坐地铁去吧。         — Поедем на метро.
```

## 10. 往/向 + 方向词 (направление движения)

**往 и 向** — оба обозначают "по направлению". 往 чаще для маршрутов, 向 для более формальных фраз.

```
往北走                — Иди на север
向东边走              — Иди в восточном направлении
火车向北京开去        — Поезд едет в Пекин
请往这边走            — Пройдите сюда, пожалуйста
```

**Различие:**

- 往 + 左/右/前/后 — бытовая речь о маршруте
- 向 + 方向 — немного формальнее, часто в официальных объявлениях

## 11. Сколько времени занимает — 要 + время

Структура: **V + 要 + [время]** — насколько долго

```
走路要二十分钟。     — Пешком займёт 20 минут.
坐地铁要十分钟。     — На метро займёт 10 минут.
去机场要一个小时。   — До аэропорта ехать час.
从这里开车要多久？   — Сколько времени отсюда на машине?
```

**Вопросительная форма:** 要多长时间? (duō cháng shíjiān?) — сколько времени?

## 12. 第一/第二... 个 — порядковые числительные

**第 + число + 个/量词** — порядковый номер

```
第一个路口           — первый перекрёсток
第二个红绿灯         — второй светофор
第三个出口           — третий выход
第一次去中国         — первый раз еду в Китай
第一次来              — первый раз здесь
```

**Порядковые числительные** всегда требуют 第 перед числом, без него это обычное количество.

## 13. 大概 / 左右 (приблизительно)

```
大概五分钟           — примерно 5 минут
五分钟左右           — около 5 минут
大概十块钱           — примерно 10 юаней
一个小时左右         — около часа
```

**Разница:**

- 大概 + [количество] — перед числом
- [количество] + 左右 — после числа
- Оба передают приблизительность

## 14. 先...再... (сначала... потом...)

Выражает последовательность действий.

```
先坐地铁，再换公交车。   — Сначала на метро, потом на автобус.
先下车，再上车。         — Сначала выйти, потом сесть.
先往左走，再往右拐。     — Сначала налево, потом направо.
先去吃饭，再去公园。     — Сначала поесть, потом в парк.
```

**Структура:** 先 + действие1 (+逗号) 再 + действие2

## 15. 把 — конструкция с объектом (в теме маршрутов)

```
把车停在停车场。         — Поставь машину на парковку.
把地图给我看看。         — Покажи мне карту.
把行李放在车上。         — Положи багаж в машину.
```

**Структура:** **S + 把 + O + V + 处所/方向**

## 16. 得 — комплемент степени (怎么+得)

```
坐地铁去比较快。         — На метро быстрее.
骑自行车比较方便。       — На велосипеде удобнее.
这条路比较近。           — Эта дорога короче.
```

**Вопросительная форма сравнения:**

- 坐地铁去还是打车去？ — На метро или на такси?
- 哪个比较快？ — Что быстрее?

## 17. 还是 — выбор (или)

```
坐地铁还是打车？        — На метро или на такси?
走这条路还是那条路？    — Пойти этой дорогой или той?
往左还是往右？          — Налево или направо?
```

**Структура:** 选择1 + 还是 + 选择2

## 18. 一边...一边... (одновременно)

```
一边走一边看手机。      — Идти и одновременно смотреть в телефон.
一边开车一边打电话。    — Вести машину и говорить по телефону.
```

## 19. 被 — пассивная конструкция (в маршрутах)

```
被堵在路上了。          — Застрял в пробке.
地图被弄丢了。          — Карту потеряли.
```
