# Unit 3 — 练习 (Практика)

## 练习 1：填空

Вставьте: 从, 到, 离, 往, 在

2. ___前走五分钟就到了。
3. 图书馆___公园旁边。
4. 学校___我家很近。
5. 我___北京___上海。

## 练习 6：Порядковые числительные

## 练习 7：Выберите правильное слово

3. 请___地铁二号线。
4. 一直___，不要转。
5. 到了车站，请在北方___下车。

## 练习 15：Закончите предложения
