# Unit 2 — 语法 (Грамматика)

## 1. 想 / 要 (хотеть / нужно)

**想** — желание, хотелось бы:
```
我想买一件T恤衫。     — Я хочу купить футболку.
我想去中国。          — Я хочу поехать в Китай.
你想吃什么？          — Что ты хочешь есть?
```

**要** — намерение, необходимость:
```
我要这个。            — Я возьму это (буду брать).
明天我要去学校。       — Завтра мне нужно в школу.
要不要咖啡？           — Будешь кофе?
```

## 2. 可以 / 能 / 会 (мочь)

**可以** — разрешение / возможность:
```
可以试穿吗？          — Можно примерить?
这里可以抽烟吗？      — Здесь можно курить?
```

**能** — физическая возможность:
```
我能来。             — Я могу прийти.
你能帮我吗？         — Ты можешь мне помочь?
```

**会** — умение / будущее:
```
我会说汉语。         — Я умею говорить по-китайски.
明天会下雨。         — Завтра будет дождь.
```

## 3. 有没有? (есть ли?)

```
有没有蓝色的？     — Есть ли синий?
你有没有钱？       — У тебя есть деньги?
你有没有哥哥？     — У тебя есть старший брат?
```

## 4. 太...了 (слишком / очень)

```
太大了！         — Слишком большой!
太好了！         — Отлично!
太贵了！         — Слишком дорого!
太便宜了！       — Слишком дёшево!
```

## 5. 一点儿 (немного)

```
大一点儿。        — Немного побольше.
便宜一点儿。      — Немного подешевле.
我有一点儿钱。    — У меня есть немного денег.
```

## 6. 一下儿 (немного / один раз)

```
我看一下儿。      — Я посмотрю.
你等一下儿。      — Подожди немного.
请试一下儿。      — Примерьте, пожалуйста.
```

## 7. 怎么 (как / почему)

```
怎么去？          — Как пройти?
怎么做？          — Как сделать?
你怎么不去？      — Почему ты не идёшь?
```

## 8. Счётные слова для покупок

| 量词 | Для | Пример |
|------|-----|--------|
| 件 | одежда | 一件T恤 |
| 条 | длинное | 一条裤子 |
| 双 | пара | 一双鞋 |
| 个 | общее | 一个包 |
| 瓶 | бутылка | 一瓶水 |
| 斤 | цзинь (500г) | 一斤苹果 |

# Дополнение — продвинутая грамматика Unit 2

## 9. 两 (liǎng) vs 二 (èr) — два

**两** ставится перед счётным словом при счёте предметов; **二** — в составе чисел, номерах, датах.

| Ситуация | Пример |
|----------|--------|
| 两 + счётное слово | 两个苹果 (два яблока), 两块钱 (два юаня), 两个人 |
| 两 + 丈量 (меры) | 两斤苹果, 两米布 |
| 二 в числах | 十二 (12), 二十 (20), 二百 (200) |
| 二 в номерах | 电话号是 122 (yī èr èr) |
| 两点 — время | 两点半 (2:30) |

```
我要买两件毛衣。          — Я хочу купить два свитера.
这双鞋二百块。            — Эти туфли стоят 200 юаней.
现在两点半。              — Сейчас 2:30.
```

## 10. 斤 и меры веса при покупках

На рынке продукты взвешивают и называют цену **за 斤 (цзинь = 500 г)**:

| Мера | Название | Соотношение |
|------|----------|-------------|
| 斤 | jīn | 500 г (0,5 кг) |
| 公斤 | gōngjīn | 1 кг |
| 克 | kè | грамм |
| 两 | liǎng | 50 г |

```
苹果多少钱一斤？      — Сколько стоит цзинь яблок?
三块五一斤。          — 3,5 юаня за цзинь.
我要两公斤。          — Мне нужно два килограмма.
```

## 11. Вопросы A-not-A (……不……?)

Удвоение прилагательного/глагола для вопроса «… или нет?»:

| Вопрос | Перевод |
|--------|---------|
| 贵不贵？ | Дорого или нет? |
| 好看不好看？ | Красиво или нет? |
| 大不大？ | Большой или нет? |
| 你要不要？ | Тебе нужно или нет? |
| 你去不去市场？ | Ты идёшь на рынок или нет? |

```
这件衣服贵不贵？          — Эта одежда дорогая?
你喜不喜欢这个颜色？      — Тебе нравится этот цвет?
```

## 12. 多少钱 — цена и способы ответа

Вопрос о цене и типовые ответы:

```
这个多少钱？           — Сколько это стоит?
这本书十块钱。         — Эта книга стоит 10 юаней.
一把葱两块五。         — Пучок лука — 2,5 юаня.
一共多少钱？           — Сколько всего?
一共三十五块八。       — Всего 35,8 юаня.
```

Правила озвучивания цен:
- **元 / 块** (юань), **角 / 毛** (0,1 юаня), **分** (0,01 юаня)
- 2,5 юаня = 两块五 (пропуская 毛: 两块 + 五毛)
- 3,05 юаня = 三块零五分 (обязательно 零)

## 13. Указательные местоимения 这 / 那 / 哪 + сч. слово

Указание на конкретный предмет должно включать счётное слово:

```
这个苹果                  — это яблоко
那件衣服                  — та одежда
哪个书包？                — какой портфель?
这件多少钱？              — сколько стоит эта (вещь)?
那位售货员很热情。         — тот продавец очень приветливый.
```

**哪个?** — вопрос «который?». Ответ — 这/那 + счётное слово.

## 14. 的 в определительных конструкциях

Прилагательное/местоимение + **的** + существительное:

```
蓝色的衬衫              — синяя рубашка
便宜的东西              — дешёвая вещь
我的朋友                — мой друг
红色的还是黑色的？       — красный или чёрный?
```

**的** опускается в коротких устойчивых сочетаниях: 红衬衫, 黑鞋, 新衣服 (без 的).

## 15. 还是 — вопрос с выбором «или»

```
你要大的还是小的？         — Тебе большой или маленький?
你喜欢红色还是蓝色？       — Тебе нравится красный или синий?
买新的还是旧的？           — Купить новый или старый?
```

**还是** — только в вопросе выбора. В утверждении «или» = **或者** (huòzhě).

## 16. Вежливые просьбы: 可以…吗？ / 能不能…？

```
可以便宜一点吗？          — Можно подешевле?
能不能试穿？              — Можно примерить?
可以开发票吗？            — Можно получить чек?
能不能帮我包起来？        — Не могли бы упаковать мне это?
```

Совершенствование вежливости: впереди **请** (пожалуйста) → 请给我…, 请问….

## 17. 大概 / 差不多 — приблизительность

```
大概多少钱？              — Примерно сколько?
差不多一百块。            — Примерно 100 юаней.
差不多贵。                — Примерно одинаково дорого.
我大概买了十件衣服。       — Я купил примерно десять вещей одежды.
```

**大概** — перед числом/действием («около»), **差不多** — «почти, примерно такой же».

## 18. 了 — изменение состояния

**了** в конце фразы указывает на новое состояние после действия:

```
现在便宜了。              — Теперь стало дешевле.
老板同意了。              — Хозяин согласился.
我买了。                  — Я купил (теперь у меня есть).
天冷了，我想买毛衣。      — Стало холодно, я хочу купить свитер.
```

Отличие от 太…了: 太贵了 (слишком дорого) — оценка; 便宜了 (стало дешевле) — произошло изменение.
