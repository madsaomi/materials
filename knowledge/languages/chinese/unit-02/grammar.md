# Unit 2 — 语法 (Грамматика)

## 1. 想 / 要 (хотеть / нужно)

**想** — желание, хотелось бы:
```
我想买一件T恤衫。     — Я хочу купить футболку.
我想去中国。          — Я хочу поехать в Китай.
你想吃什么？          — Что ты хочешь есть?
```

**要** — намерение, необходимость:
```
我要这个。            — Я возьму это (буду брать).
明天我要去学校。       — Завтра мне нужно в школу.
要不要咖啡？           — Будешь кофе?
```

## 2. 可以 / 能 / 会 (мочь)

**可以** — разрешение / возможность:
```
可以试穿吗？          — Можно примерить?
这里可以抽烟吗？      — Здесь можно курить?
```

**能** — физическая возможность:
```
我能来。             — Я могу прийти.
你能帮我吗？         — Ты можешь мне помочь?
```

**会** — умение / будущее:
```
我会说汉语。         — Я умею говорить по-китайски.
明天会下雨。         — Завтра будет дождь.
```

## 3. 有没有? (есть ли?)

```
有没有蓝色的？     — Есть ли синий?
你有没有钱？       — У тебя есть деньги?
你有没有哥哥？     — У тебя есть старший брат?
```

## 4. 太...了 (слишком / очень)

```
太大了！         — Слишком большой!
太好了！         — Отлично!
太贵了！         — Слишком дорого!
太便宜了！       — Слишком дёшево!
```

## 5. 一点儿 (немного)

```
大一点儿。        — Немного побольше.
便宜一点儿。      — Немного подешевле.
我有一点儿钱。    — У меня есть немного денег.
```

## 6. 一下儿 (немного / один раз)

```
我看一下儿。      — Я посмотрю.
你等一下儿。      — Подожди немного.
请试一下儿。      — Примерьте, пожалуйста.
```

## 7. 怎么 (как / почему)

```
怎么去？          — Как пройти?
怎么做？          — Как сделать?
你怎么不去？      — Почему ты не идёшь?
```

## 8. Счётные слова для покупок

| 量词 | Для | Пример |
|------|-----|--------|
| 件 | одежда | 一件T恤 |
| 条 | длинное | 一条裤子 |
| 双 | пара | 一双鞋 |
| 个 | общее | 一个包 |
| 瓶 | бутылка | 一瓶水 |
| 斤 | цзинь (500г) | 一斤苹果 |

## 练习

1. "Можно примерить?" → __________
2. "Слишком дорого!" → __________
3. "Немного подешевле" → __________
4. "У вас есть синий цвет?" → __________
5. "Я хочу купить книгу" → __________

**Ответы:**
1. 可以试穿吗？
2. 太贵了！
3. 便宜一点儿
4. 有没有蓝色的？
5. 我想买一本书。
