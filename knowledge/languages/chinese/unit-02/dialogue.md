# Unit 2 — 对话: 买东西 (Покупки)

## 对话

```
售货员: 你好！欢迎光临！你想买什么？
顾客: 你好！我想买一件T恤衫。
售货员: 你喜欢什么颜色？
顾客: 我喜欢蓝色。有没有蓝色的？
售货员: 有。这件怎么样？
顾客: 可以试穿一下吗？
售货员: 当然可以。试衣间在那边。
顾客: 大小很合适。多少钱？
售货员: 一百五十块。
顾客: 太贵了！能不能便宜一点儿？
售货员: 嗯... 给你打个九折。一百三十五块。
顾客: 好吧，我要了。可以刷卡吗？
售货员: 可以。请到收银台付款。
```
