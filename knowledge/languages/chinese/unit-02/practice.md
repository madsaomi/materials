# Unit 2 — 练习 (Практика)

## 练习 1：填空

Вставьте: 想, 要, 可以, 能, 会

1. 我___买一件新衣服。
2. 你___说汉语吗？
3. 我明天不___去学校。
4. 这里不___抽烟。
5. 你___帮我一下吗？

## 练习 2：翻译

1. Сколько это стоит? → __________
2. Слишком дорого, дайте скидку. → __________
3. Можно примерить? → __________
4. У вас есть красный цвет? → __________
5. Я возьму это. → __________

## 练习 3：Диалог в магазине

Составьте диалог (покупатель + продавец):
- Покупатель хочет купить обувь
- Спрашивает размер и цвет
- Меряет
- Спрашивает цену
- Торгуется
- Покупает

## 练习 4：Счётные слова

Вставьте правильное счётное слово: 件, 条, 双, 瓶, 个

1. 一___T恤
2. 一___裤子
3. 一___鞋
4. 一___水
5. 一___书包

## 练习 5：Переведите числа

1. 150元 → __________
2. 35块 → __________
3. 两千 → __________
4. 一百零八 → __________
5. 九折 → __________

## 答案

**练习 1:**
1. 想
2. 会
3. 要
4. 可以/能
5. 能

**练习 2:**
1. 多少钱？
2. 太贵了，打折吧。
3. 可以试穿吗？
4. 有没有红色的？
5. 我要这个。

**练习 4:**
1. 件
2. 条
3. 双
4. 瓶
5. 个

**练习 5:**
1. 150 юаней
2. 35 юаней
3. 2000
4. 108
5. 10% скидка
