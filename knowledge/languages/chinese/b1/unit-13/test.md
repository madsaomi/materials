## 1. Лексика (выберите правильный перевод)

1. 如果 — a) потому что b) если c)although
2. 假设 — a) потому что b) предположение c) если
3. 万一 — a) если вдруг b) конечно c)maybe
4. 既然 — a) раз уж b) если c)хотя
5. 就算 — a) если b) потому что c) даже если
6. 要是 — a) если (разг.) b) потому что c)although

## 2. Грамматика (вставьте 如果, 要是 или 假如)

1. ______你来，我们一起玩。 (if → 如果 )
2. ______我是你，我会去。 (if I were → 假如 )
3. ______你不喜欢，可以不买。 (if → 如果 )
4. ______明天不下雨，我们去公园。 (if → 如果 )
5. ______他是老板，他也不会同意。 (even if → 就算 )
6. ______你知道答案，就告诉我。 (if → 如果 )

## 7. Дополнительный тест (логика условных конструкций)

Выбери правильное слово: 只要 / 只有 / 除非 / 无论 / 不管 / 既然

1. ______有太阳，花儿就能开。 (достаточно)
2. ______认真练习，才能弹好琴。 (только)
3. ______下大雨，否则照常出发。 (если только не)
4. ______怎么说，他都不同意。 (как ни)
5. ______你已经决定了，就执行吧。 (раз уж)
6. ______明天是晴天还是阴天，我们都要去。 (что бы ни)

## 8. Исправление ошибок (выбери верный вариант)

1. 只要努力，___成功。 a) 才 b) 就 c) 也
2. 即使下雨，我___要去。 a) 才 b) 就 c) 也
3. 与其抱怨，___行动。 a) 不如 b) 但是 c) 反而
4. 只有坚持，___能胜利。 a) 就 b) 也 c) 才
5. 无论多难，___不放弃。 a) 就 b) 都 c) 才

## 9. Соответствие конструкций и значений

1. 只要…就… — a) только если…, тогда…
2. 只有…才… — b) достаточно…, и тогда…
3. 除非…否则… — c) даже если…
4. 无论…都… — d) если только не…, иначе…
5. 哪怕…也… — e) как бы ни…, всё равно…
6. 与其A…不如B — f) лучше B, чем A

## 12. Выбери правильный порядок слов
