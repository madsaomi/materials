## HSK 1 (150 слов)

### Что нужно знать
- Пиньинь и тоны
- 150 слов
- Базовая грамматика

### Темы
Приветствия, числа, время, семья, еда, цвета, погода

### Грамматика HSK 1
| Конструкция | Пример |
|-------------|--------|
| 是 + N | 我是学生 |
| 很 + Adj | 很好 |
| 有 / 没有 | 我有书 |
| 在 + место | 我在家 |
| 会 + V | 我会说 |
| 了 (новое состояние) | 我饿了 |
| 的 (притяжание) | 我的书 |

### Стратегия
1. Пиньинь + тоны (1 нед)
2. 150 слов Anki (3 нед)
3. Прослушивание (1 нед)
4. Пробный тест

## HSK 2 (300 слов)

### Добавляется
- 150 новых слов
- Простые прилагательные
- 了, 过, 在 (прогрессив)

### Новая грамматика
| Конструкция | Значение |
|-------------|----------|
| 比 | сравнение |
| 要 / 想 | хотеть |
| 可以 / 能 | мочь |
| 从...到... | от...до... |
| 离 | расстояние |
| 还没 | ещё не |
| 因为...所以 | потому что |

## HSK 3 (600 слов)

### Грамматика
| Конструкция | Значение |
|-------------|----------|
| 把 + O + V | управление объектом |
| 被 | пассив |
| 比 | сравнение |
| 越来越 | всё больше |
| 结果补语 | результатив (做完, 看见) |
| 可能补语 | возможн. (做得完, 做不完) |
| 除了...以外 | кроме |
| 一边...一边 | одновременно |
| 先...然后 | сначала...потом |

### Типичные ошибки
- 了 vs 过
- 的 vs 地 vs 得
- 会 vs 能 vs 可以
- 二 vs 两

## HSK 4 (1200 слов)

### Что важно
- 成语 (20-30 основных)
- Сложные придаточные
- Пассивные конструкции
- Деловая лексика
- Устойчивые выражения

### Тематика письма
1. Описание человека
2. Рассказ о событии
3. Мнение о проблеме
4. План/предложение
5. Сравнение

### Требования к письму
- 100-120 иероглифов
- Логическая структура
- Использование связок
- Без грубых ошибок

## Общие советы

### Аудирование
- Смотреть дорамы без субтитров
- Слушать подкасты (Slow Chinese)
- Записывать и разбирать непонятые места

### Чтение
- Du Chinese (по уровням)
- The Chairman's Bao
- HSK Reading — тексты с вопросами
- Читать 10-15 мин ежедневно

### Письмо
- 50-100 иероглифов в день
- Писать сочинения на заданные темы
- Использовать изученную грамматику

### Грамматика
- Chinese Grammar Wiki (лучший ресурс)
- Разбор по темам, а не по порядку
- Примеры из реальных диалогов

### Ресурсы
- **Словарь**: Pleco (обязательно)
- **Карточки**: Anki с озвучкой
- **Тоны**: HelloChinese, ChineseSkill
- **Практика**: HelloTalk, Tandem
