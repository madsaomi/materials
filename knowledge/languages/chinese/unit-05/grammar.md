# Unit 5 — 语法 (Грамматика)

## 1. Сравнение с 比 (углубление)

Базовая структура: `A 比 B + прилагательное` — "A более…, чем B".

```
今天比昨天冷。         — Сегодня холоднее, чем вчера.
他比我高。             — Он выше меня.
夏天比冬天热。         — Летом жарче, чем зимой.
```

Можно добавить степень различия:

| Структура | Значение | Пример |
|-----------|----------|--------|
| A 比 B + 形容词 + 一点儿 | немного | 今天比昨天冷一点儿。 |
| A 比 B + 形容词 + 很多 | намного | 他比我高很多。 |
| A 比 B + 形容词 + 多了 | гораздо | 北京的冬天比上海冷多了。 |

Отрицание — структура `A 没有 B + 形容词` ("A не так…, как B"):

```
他跑得没有我快。       — Он бегает не так быстро, как я.
冬天没有夏天热。       — Зимой не так жарко, как летом.
```

Сравнение равенства: `A 跟/和 B 一样` — "A такой же, как B":

```
我的爱好和他的爱好一样。   — Мои увлечения такие же, как у него.
```

## 2. 越来越 (всё более…)

Показывает нарастание признака. Структура: `越来越 + прилагательное/глагол`.

```
天气越来越冷了。       — Погода становится всё холоднее.
他的汉语越来越好。     — Его китайский всё лучше и лучше.
喜欢运动的人越来越多。 — Любителей спорта становится всё больше.
```

## 3. 如果…就… (если…, то…)

Условное предложение: `如果 + условие, 就 + результат`. 就 стоит перед глаголом в главной части.

```
如果明天天气好，我们就去公园。   — Если завтра будет хорошая погода, мы пойдём в парк.
如果下雨，我们就不去了。         — Если пойдёт дождь, мы не пойдём.
如果你有空，就来我家玩。         — Если у тебя будет время, приходи ко мне играть.
```

## 4. 除了…以外 (кроме…)

Два значения:

1. "Все, кроме…" — с 都:
```
除了我以外，大家都来了。   — Пришли все, кроме меня.
```
2. "Кроме…, ещё и…" — с 还/也:
```
除了中文以外，他还学英语。   — Кроме китайского, он ещё учит английский.
除了跑步以外，我也喜欢游泳。 — Кроме бега, я также люблю плавать.
```

## 5. 喜欢做 / 爱做 (любить делать)

喜欢 — нравится, любить (слабее). 爱 — любить (сильнее, ближе к "обожать").

```
我喜欢看书。           — Мне нравится читать.
他爱跑步。             — Он обожает бегать.
我不喜欢下雨天。       — Я не люблю дождливые дни.
```
Отрицание: 不喜欢 / 不爱. С 爱 к человеку: 我爱我的家人。 — Я люблю свою семью.

## 6. 可能 (возможно)

Наречие вероятности, ставится перед глаголом или прилагательным.

```
明天可能下雨。         — Завтра, возможно, будет дождь.
他可能不来。           — Он, возможно, не придёт.
天气预报说可能下雪。   — Прогноз погоды говорит, что, возможно, пойдёт снег.
```

## 7. 应该 (следует, должен)

Выражает долженствование, рекомендацию. Отрицание: 不应该.

```
你应该多穿衣服。           — Тебе следует одеваться теплее.
我们应该多运动。           — Мы должны больше заниматься спортом.
天气不好，你不应该出去。   — Погода плохая, тебе не следует выходить.
```

## 练习 (Упражнения)

1. Вставьте 比: 今天___昨天冷。
2. Переведите: "Погода становится всё холоднее." → __________
3. Составьте: 下雨 / 如果 / 就 / 我们 / 不去 / 了 → __________
4. Вставьте 可能: 明天___下雪。
5. Переведите: "Кроме китайского, я ещё учу английский." → __________

**Ответы:**
1. 比
2. 天气越来越冷了。
3. 如果下雨，我们就不去了。
4. 可能
5. 除了中文以外，我还学英语。
