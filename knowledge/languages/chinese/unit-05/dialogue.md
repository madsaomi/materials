# Unit 5 — 对话: 天气和爱好 (Погода и хобби)

## 对话

```
李明: 今天天气真好！不冷也不热。
王芳: 是啊，今天出太阳了。天气预报说明天要下雨。
李明: 那我明天不出去玩了，在家看书。
王芳: 你喜欢看书吗？
李明: 喜欢。我喜欢看中文小说。你呢？
王芳: 我喜欢听音乐和画画。
李明: 你还会画画？真厉害！
王芳: 我从小就喜欢画画，一有时间就画。
李明: 那你画得一定很好！
王芳: 还可以。你除了看书以外，还有什么爱好？
李明: 我还喜欢跑步和游泳。
王芳: 我夏天也喜欢游泳，冬天就只喜欢待在家里。
李明: 冬天太冷了，我也喜欢在家喝热茶。
王芳: 天气越来越冷了，你要多穿衣服。
李明: 谢谢，你也是！
```
