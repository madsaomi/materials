# Китайский — Грамматическая шпаргалка (1 страница)

## Тоны
```
1-й: ā (ровный)      mā 妈 — мама
2-й: á (восходящ.)   má 麻 — конопля
3-й: ǎ (нисх-восх.)  mǎ 马 — лошадь
4-й: à (нисходящий)  mà 骂 — ругать
Нейтр.         ma 吗 — вопрос
```

**Правила изменения тонов:**
- 3+3 → 2+3: 你好 (nǐ hǎo → ní hǎo)
- 不 (bù) + 4 → bú: 不是 (bù shì → bú shì)
- 一 (yī) + 4 → yí: 一个 (yī gè → yí gè)

## Вопросы
```
吗 (ma) — да/нет              你好吗？
什么 (shénme) — что           你吃什么？
谁 (shuí) — кто              他是谁？
哪 (nǎ) — который            哪个？
怎么 (zěnme) — как           怎么去？
为什么 (wèi shénme) — почему  为什么不来？
几 (jǐ) — сколько? (мало)    几点了？
多少 (duōshao) — ск. (много)  多少钱？
呢 (ne) — а/же              你呢？
多 + прил — насколько        多大？/多长？
```

### 2.4 Пять тонов подробнее

| Тон | Обозначение | Цифрой (часто) | Характер | Пример |
|-----|-------------|----------------|----------|--------|
| 1-й | ā | 55 | высокий, ровный, как нота | 妈 mā — мама |
| 2-й | á | 35 | восходящий, как вопрос | 麻 má — конопля |
| 3-й | ǎ | 214 | вниз-вверх (долгий, низкий) | 马 mǎ — лошадь |
| 4-й | à | 51 | резкий вниз, как команда | 骂 mà — ругать |
| Нейтр. | a | 0 | короткий, лёгкий | 吗 ma — вопросит. частица |

**Приёмы запоминания (рукой):**
- 1-й тон — рука на уровне плеча, держим ровно.
- 2-й тон — рука летит вверх.
- 3-й тон — рука уходит вниз и возвращается вверх (галочка).
- 4-й тон — резкий удар ребром ладони вниз.

**Нейтральный тон встречается в:**
- частицах: 的, 了, 吗, 呢, 吧, 着, 过;
- вторых слогах повторов: 妈妈 māma, 谢谢 xièxie;
- суффиксах: 们 (-men), 子 (-zi), 头 (-tou).

### 2.5 Правила «полного» третьего тона

Третий тон в китайском имеет **две реализации**:

| Ситуация | Как произносится | Пример |
|----------|------------------|--------|
| Изолированное слово | полный 214 (вниз-вверх) | 好 hǎo — медленно, целиком |
| Конец фразы/пауза | полный или половинный 21 | 很好！hěn hǎo — «хэнь-хао» |
| **Перед 1-м тоном** | полу-третий 21 (без подъёма) | 老师 lǎoshī → «лао-ши» (полу-третий) |
| **Перед 2-м тоном** | полу-третий 21 | 语言 yǔyán → «юй-янь» |
| **Перед 4-м тоном** | полу-третий 21 | 好吃 hǎochī... 注意: 好吃 hǎochī — это 3+?, покрыто выше |
| **Перед нейтральным** | полу-третий 21 | 姐姐 jiějie → «цзе-цзе» |
| **Перед 3-м тоном (3+3)** | первый становится 2-м | 你好 nǐ hǎo → ní hǎo |
| Три 3-х подряд | 2+2+3 | 我很懂 wǒ hěn dǒng → wó hén dǒng |

> 💡 **Суть:** в связной речи 3-й тон почти никогда не звучит полностью — он «режется» до низкого нисходящего 21 и только перед 3-м становится восходящим (как 2-й).

### 2.6 Правило «не»: 不 (bù)

| Ситуация | Произношение | Пример |
|----------|--------------|--------|
| 不 перед 1-м тоном | bù (4-й) | 不说 bù shuō |
| 不 перед 2-м тоном | bù (4-й) | 不来 bù lái |
| 不 перед 3-м тоном | bù (4-й) | 不走 bù zǒu |
| **不 перед 4-м тоном** | **bú (2-й!)** | 不是 bú shì, 不对 bú duì, 不要 bú yào |
| Одиночный / в конце | bù (4-й) | 不！bù!, 好不好 hǎobuhǎo |

**Памятка:** 不是 búshì (не есть), 不用 búyòng (не нужно), 不会 búhuì (не умею), 不客气 búkèqi (не за что).

## 3. 📘 Грамматика: конструкции-пазлы

### 3.1 Порядок слов (SVO) и «принцип вагонов»

Базовое предложение: **Кто + (когда) + (где) + (как) + что делает + что**

| # | Позиция | Примерные элементы | Пример |
|---|---------|-------------------|--------|
| 1 | Тема | 我 wǒ | Я |
| 2 | Время | 明天 míngtiān | завтра |
| 3 | Место | 在图书馆 | в библиотеке |
| 4 | Образ действия | 认真 rènzhēn | усердно |
| 5 | Глагол | 学习 xuéxí | учу |
| 6 | Объект | 汉语 Hànyǔ | китайский |

> 🧠 Всё, что отвечает на вопросы «когда/где/как», вставлется **между** подлежащим и глаголом — как вагоны поезда. Порядок вагонов менять нельзя.

**Отрицание и вопросы:**
- Отрицание: 不 + глагол (不学 bù xué — не учусь), 没 + глагол (没学 méi xué — не учился).
- Вопрос: 吗 в конце (你学吗？) или A不A (你学不学？).
- «Ещё не» — 还没...呢: 我还没吃饭呢 (wǒ hái méi chīfàn ne) — я ещё не ел.

### 3.2 Частицы-рабочие лошадки: 的 / 了 / 很 / 吗 / 呢 / 吧

| Частица | Роль | Пример | Перевод |
|---------|------|--------|---------|
| 的 (de) | притяжание/атрибут | 我的书, 红色的 | моя книга, красный |
| 的 (de) | связка «прил + сущ» | 好吃的东西 | вкусная вещь |
| 的 (de) | акцент (是...的) | 我是昨天来的 | я пришёл **вчера** |
| 了 (le) | завершённость | 吃了, 看完了 | поел, досмотрел |
| 了 (le) | новое состояние | 天冷了 | стало холодно |
| 了 (le) | побуждение/просьбу смягчает | 走吧！| пошли же! |
| 很 (hěn) | «очень», но часто просто связка | 很好, 我很忙 | хорошо; я занят |
| 吗 (ma) | вопрос да/нет | 你好吗？| как дела? |
| 呢 (ne) | переспрос | 你呢？| а ты? |
| 呢 (ne) | процесс | 他在看书呢 | он (как раз) читает |
| 吧 (ba) | предложение/побуждение | 走吧！睡觉吧 | пошли! иди спать |
| 吧 (ba) | смягчение предположения | 你是老师吧？| ты учитель, наверно? |

**Разграничение 很:**
- 很好 = «хорошо» (в утверждении прилагательное без 很 звучит «оторвано»).
- 我很好的 + 很 + 形容词 — стандартная связка: 天气热 tiānqì rè (звучит как «жарко, и точка»), 天气很热 — «погода жаркая».

**了 в двух позициях (правило для HSK):**
- После глагола (了¹) — завершённость действия: 我吃了饭 (я поел).
- В конце предложения (了²) — изменение состояния: 下雨了 (пошёл дождь).
- Оба вместе — подчёркнутая завершённость: 我吃了饭了.

**Как сказать время:**

### 3.5 Вопросительные слова: полный набор

| Слово | Пиньинь | Перевод | Пример |
|-------|---------|---------|--------|
| 什么 | shénme | что? | 这是什么？ |
| 谁 | shuí | кто? | 他是谁？ |
| 哪里/哪儿 | nǎlǐ / nǎr | где? куда? | 你去哪儿？ |
| 为什么 | wèi shénme | почему? | 为什么不去？ |
| 怎么 | zěnme | как? почему? | 怎么去？ |
| 怎么样 | zěnme yàng | как насчёт? как? | 怎么样？/最近怎么样？ |
| 多少 | duōshao | сколько? (много) | 多少钱？ |
| 几 | jǐ | сколько? (мало, <10) | 几点了？/几点？ |
| 哪个 | nǎge | который? | 哪个是你的？ |
| 什么时候 | shénme shíhou | когда? | 什么时候到？ |

**Схема вопроса:** вопросительное слово стоит НА МЕСТЕ ответа:
- 你吃*什么*？ → 我吃*饺子*。
- *谁*来了？ → *小王*来了。

### 3.6 Обороты-конструкции: 是...的 / 把 / 被 / 比

**是...的 — акцент на факте (было/сделано когда, где, как):**

| Пример | Акцент |
|--------|--------|
| 我是昨天来的 | пришёл **вчера** (не сегодня) |
| 他是坐飞机来的 | прилетел **самолётом** |
| 我是跟自己爸妈来的 | пришёл **с родителями** |

> Схема: 是 + [когда/где/как] + глагол + 的. Говорим о прошедшем, но 的 ставится в конец.

**把 (bǎ) — перенос объекта вперёд, подчёркивает результат:**

```
S + 把 + O + V + [дополнение/результат]
我把 书 放在桌子上了。
Я положил книгу на стол.
他把我手机拿走了。
Он забрал мой телефон.
```

> Используется, когда объект конкретный, известный, и действие доведено до результата. Не используется с глаголами без результата (喜欢, 知道, 有).

**被 (bèi) — пассивный залог:**

```
S + 被 + (кем) + V + 了
我的手机 被 (人) 偷了。
Мой телефон украли.
饭 被 他 吃完了。
Еду он доел (еда была доедена им).
```

> «Неприятные» события обычно в пассиве: 被偷 (украли), 被打破 (разбили), 被骂 (поругали). Нейтральные не требуют 被.

**比 (bǐ) — сравнение:**

```
A + 比 + B + 形容词 (+ количество)
我 比他 高。
Я выше него.
他比我大两岁。
Он на 2 года старше меня.
这个比那个便宜(得多)。
Это дешевле того (намиого).
```

> Отрицание: 我不比他高 (не выше него, но не обязательно ниже). «Не такой, как» — 没有 B + 形容词: 我没有他高 (я не так высок, как он).

## 10. 🚦 Быстрые правила, которые спасают в разговоре

| Правило | Пример |
|---------|--------|
| Прилагательное после 很 — без «очень» понимается как «такой-сякой» | 她很漂亮 — она красивая (а не «очень») |
| 了 в конце = «уже/стало» | 下雨了 — пошёл дождь |
| 两点 (два часа) vs 两块钱 (два юаня) | перед 点 → 二; перед деньгами → 两(块) |
| Вопрос A不A для глаголов (но НЕ для 有: 有没有) | 去不去？/ 有没有钱？ |
| 没 перед глаголом для прошедшего отрицания | 我没去 (не ходил), но 我不去 (не пойду) |
| 一点 + прил = чуть-чуть | 大一点 — чуть больше |
| 一下 = «на секунду» | 等一下 — подожди секунду |
| Местоимение + 的 не опускается перед существ. | 我的书 (не 我书) |
| 二 ставится с 十/百, 两 с счётными словами | 二十, 两百, но 两个人 |
| 岁 после числа в возрасте | 我二十岁 — мне 20 лет |
