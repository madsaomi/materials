# Китайский — Грамматическая шпаргалка (1 страница)

## Тоны
```
1-й: ā (ровный)      mā 妈 — мама
2-й: á (восходящ.)   má 麻 — конопля
3-й: ǎ (нисх-восх.)  mǎ 马 — лошадь
4-й: à (нисходящий)  mà 骂 — ругать
Нейтр.         ma 吗 — вопрос
```

**Правила изменения тонов:**
- 3+3 → 2+3: 你好 (nǐ hǎo → ní hǎo)
- 不 (bù) + 4 → bú: 不是 (bù shì → bú shì)
- 一 (yī) + 4 → yí: 一个 (yī gè → yí gè)

## Вопросы
```
吗 (ma) — да/нет              你好吗？
什么 (shénme) — что           你吃什么？
谁 (shuí) — кто              他是谁？
哪 (nǎ) — который            哪个？
怎么 (zěnme) — как           怎么去？
为什么 (wèi shénme) — почему  为什么不来？
几 (jǐ) — сколько? (мало)    几点了？
多少 (duōshao) — ск. (много)  多少钱？
呢 (ne) — а/же              你呢？
多 + прил — насколько        多大？/多长？
```

## Основные конструкции

| Конструкция | Значение | Пример |
|------------|----------|--------|
| 是...的 | акцент | 我是昨天来的 |
| 把 + O + V | управление | 把书放在桌子上 |
| 被 | пассив | 被他打了 |
| 比 | сравнение | 比他高 |
| 有 | наличие | 有钱 |
| 正在 | процесс | 正在吃饭 |
| 了 | завершённость | 吃了 |
| 过 | опыт | 去过 |
| 着 | состояние | 开着 |
| 会 | будущее/умение | 会来 |
| 想 | желание | 想去 |
| 要 | необходимость | 要去 |
| 能 | возможность | 能去 |
| 可以 | разрешение | 可以进来 |
| 应该 | должен | 应该学习 |
| 越来越 | всё более | 越来越好 |
| 除了...以外 | кроме | 除了他以外 |

## Время
```
昨天 zuótiān — вчера
今天 jīntiān — сегодня
明天 míngtiān — завтра
早上 zǎoshang — утро (6-9)
上午 shàngwǔ — до полудня (9-12)
中午 zhōngwǔ — полдень (12-13)
下午 xiàwǔ — день (13-18)
晚上 wǎnshang — вечер (18-24)
点 diǎn — час: 3点
分 fēn — минута: 30分
半 bàn — пол: 点半
刻 kè — четверть: 一刻
差 chà — без: 差五分三点
```

## Дни недели
```
周一 / 星期一 — понедельник
周二 / 星期二 — вторник
...
周日 / 星期天 — воскресенье
```

## Модальные глаголы (сравнение)

| Глагол | Сила | Пример |
|--------|------|--------|
| 会 | умею (научился) | 我会游泳 |
| 能 | могу (физ. возможность) | 我能来 |
| 可以 | можно (разрешение) | 你可以进去 |
| 想 | хочу (желание) | 我想去 |
| 要 | нужно (намерение) | 我要这个 |
| 应该 | должен (морально) | 你应该学习 |
```

## Местоимения
```
我 wǒ — я      我们 wǒmen — мы
你 nǐ — ты      你们 nǐmen — вы
他 tā — он      他们 tāmen — они
她 tā — она     她们 tāmen — они (ж)
它 tā — оно
```

## Порядок слов
```
Субъект + Время + Место + Образ + Глагол + Объект
我    明天    在图书馆  认真   学习     汉语
Я    завтра  в библ.  усердно  учу     кит. язык
```
