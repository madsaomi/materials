# Китайский язык — Полный конспект

> 📘 **Начните отсюда:** [Учебник — программа курса, методика, трекер прогресса](textbook.md)

## Введение

Китайский язык (中文, чжунвэнь / 汉语, ханьюй) — язык сино-тибетской семьи. Крупнейший язык мира по числу носителей (около 1.3 миллиарда). Стандартный диалект — путунхуа (普通话) на основе пекинского диалекта.

**Ключевые особенности:**
- Тоновый язык (4 тона + нейтральный)
- Отсутствие спряжений, падежей, родов
- Иероглифическая письменность (логографическая система)
- Порядок слов SVO

## 1. Система тонов

### 1.1 Четыре тона

| Тон | Обозначение | Характер | Пример (ма) | Значение |
|-----|------------|----------|-------------|----------|
| Первый | ā | высокий ровный | 妈 (mā) | мама |
| Второй | á | восходящий | 麻 (má) | конопля |
| Третий | ǎ | нисходяще-восходящий | 马 (mǎ) | лошадь |
| Четвёртый | à | резкий нисходящий | 骂 (mà) | ругать |

**Нейтральный тон** — лёгкий, короткий:
- 吗 (ma) — вопросительная частица
- 的 (de) — притяжательная частица

### 1.2 Правила изменения тонов (Tone Sandhi)

**Третий тон + третий тон → второй + третий:**
- 你好 (nǐ hǎo) → [ní hǎo]
- 很好 (hěn hǎo) → [hén hǎo]

**不 (bù) + четвёртый тон → второй:**
- 不是 (bù shì) → [bú shì]
- 不对 (bù duì) → [bú duì]

**一 (yī) перед четвёртым → второй:**
- 一个 (yī gè) → [yí gè]
- 一次 (yī cì) → [yí cì]

## 2. Письменность

### 2.1 Структура иероглифа

Иероглиф состоит из **черт**. Базовые черты:

| Черта | Название | Пример |
|-------|----------|--------|
| 丶 | точка | 太 |
| 一 | горизонтальная | 大 |
| 丨 | вертикальная | 中 |
| 丿 | левая откидная | 人 |
| ㇏ | правая откидная | 八 |
| ㇀ | восходящая | 习 |
| 亅 | крюк | 小 |

**Порядок написания черт:**
1. Сверху вниз (三: 一 → 二 → 三)
2. Слева направо (川: 丿 → 丨 → 丨)
3. Горизонтальная перед вертикальной (十: 一 → 丨)
4. Внешнее перед внутренним (日: 冂 → 二 → 一)
5. Закрывающая после внутреннего (口: 冂 → 匚 → 一)
6. Середина перед боками (小: 亅 → 丿 → 丶)

### 2.2 Типы иероглифов

1. **Пиктограммы (象形字)** — рисунки:
   - 日 (rì) — солнце
   - 月 (yuè) — луна
   - 山 (shān) — гора
   - 水 (shuǐ) — вода
   - 木 (mù) — дерево

2. **Идеограммы (指事字)** — абстрактные:
   - 上 (shàng) — верх
   - 下 (xià) — низ
   - 一 (yī) — один
   - 中 (zhōng) — середина

3. **Фоноидеограммы (形声字)** — ключ + фонетик (80%+ иероглифов):
   - 妈 (mā) = 女 (женщина) + 马 (mǎ — фонетик)
   - 饭 (fàn) = 饣 (еда) + 反 (fǎn — фонетик)
   - 请 (qǐng) = 讠 (речь) + 青 (qīng — фонетик)

4. **Логические комбинации (会意字):**
   - 休 (xiū) — человек (亻) + дерево (木) = отдыхать (прислонившись к дереву)
   - 家 (jiā) — крыша (宀) + свинья (豕) = дом
   - 林 (lín) — два дерева = роща
   - 森 (sēn) — три дерева = лес

### 2.3 Ключи (радикалы)

| Ключ | Вариант | Значение | Примеры |
|------|---------|----------|---------|
| 人 | 亻 | человек | 你, 他, 们 |
| 水 | 氵 | вода | 海, 河, 酒 |
| 火 | 火, 灬 | огонь | 烧, 热, 照 |
| 木 | 木 | дерево | 林, 桌, 椅 |
| 金 | 钅 | металл | 银, 钱, 铁 |
| 言 | 讠 | речь | 说, 话, 认 |
| 心 | 忄, 心 | сердце | 想, 情, 意 |
| 手 | 扌 | рука | 打, 拍, 拉 |
| 土 | 土 | земля | 地, 城, 场 |
| 口 | 口 | рот | 吃, 喝, 唱 |
| 目 | 目 | глаз | 看, 眼, 睡 |
| 食 | 饣 | еда | 饭, 饮, 饱 |
| 辵 | 辶 | движение | 进, 过, 远 |
| 门 | 门 | ворота | 问, 间, 闻 |
| 雨 | 雨 | дождь | 雪, 电, 云 |

### 2.4 Пиньинь (拼音)

Система латинской транскрипции. Начальные и конечные согласные:

**Инициали:**
b, p, m, f, d, t, n, l, g, k, h, j, q, x, zh, ch, sh, r, z, c, s, y, w

**Финали:**
a, o, e, i, u, ü, ai, ei, ao, ou, an, en, ang, eng, ong, ia, ie, iu, in, ing, ua, uo, ui, un, üe, ün

**Важное произношение:**
- c — [tsʰ] (как "ц")
- q — [tɕʰ] (как "ч")
- x — [ɕ] (мягкое "сь")
- zh — [ʈʂ] (твёрдое "чж")
- ch — [ʈʂʰ] (придыхательное "ч")
- sh — [ʂ] (твёрдое "ш")
- z — [ts] ("дз")
- r — [ʐ] (как "ж", но кончик языка загнут назад)

## 3. Грамматика

### 3.1 Структура предложения

**SVO** — подлежащее-сказуемое-дополнение.

```
我 吃 苹果。
Wǒ chī píngguǒ.
Я ем яблоко.
```

### 3.2 Частицы и служебные слова

| Частица | Функция | Пример |
|---------|---------|--------|
| 的 (de) | притяжательная / атрибутивная | 我的书 (моя книга) |
| 了 (le) | завершённость / изменение | 我吃了 (я поел) |
| 着 (zhe) | длительность действия | 我看着 (я смотрю) |
| 过 (guo) | опыт в прошлом | 我去过 (я был) |
| 在 (zài) | действие прямо сейчас | 我在学习 (я учусь сейчас) |
| 吗 (ma) | вопрос (да/нет) | 你好吗? |
| 呢 (ne) | переспрос / продолжение | 你呢? (а ты?) |
| 吧 (ba) | предложение / побуждение | 走吧! (пошли!) |
| 啊 (a) | восклицание / подтверждение | 好啊! (хорошо же!) |

### 3.3 Глаголы — нет спряжений

Глагол не меняется по лицам, числам, временам. Время выражается контекстом или частицами.

| Китайский | Транскрипция | Перевод |
|-----------|-------------|---------|
| 我吃 | wǒ chī | я ем / я буду есть |
| 你吃 | nǐ chī | ты ешь |
| 他吃 | tā chī | он ест |
| 我们吃 | wǒmen chī | мы едим |

**Прошедшее время:** 了 (le)
- 我吃了早饭 (Wǒ chīle zǎofàn) — Я позавтракал.

**Будущее время:** 会 (huì) / 要 (yào) / 将 (jiāng)
- 我明天会去 (Wǒ míngtiān huì qù) — Я завтра пойду.

**Длительное действие:** 在 (zài) или 正在 (zhèngzài)
- 我在看电视 (Wǒ zài kàn diànshì) — Я смотрю телевизор.

**Опыт:** 过 (guo)
- 我去过中国 (Wǒ qùguo Zhōngguó) — Я был в Китае.

**Продолжающееся состояние:** 着 (zhe)
- 门开着 (Mén kāizhe) — Дверь открыта.

### 3.4 Прилагательные — предикативы

Прилагательные могут выступать как глаголы (не нужна связка).

| Китайский | Транскрипция | Перевод |
|-----------|-------------|---------|
| 她很漂亮 | tā hěn piàoliang | она красивая |
| 这本书很好 | zhè běn shū hěn hǎo | эта книга хорошая |
| 天气很热 | tiānqì hěn rè | погода жаркая |

**Сравнение:** 比 (bǐ)
- 我比他高 (Wǒ bǐ tā gāo) — Я выше него.

**Превосходная степень:** 最 (zuì)
- 这是最好的 (Zhè shì zuì hǎo de) — Это самый лучший.

### 3.5 Счётные слова (量词)

Каждое существительное требует счётного слова.

| Слово | Для чего | Пример |
|-------|----------|--------|
| 个 (gè) | универсальное | 一个苹果, 一个人 |
| 本 (běn) | книги | 一本书 |
| 张 (zhāng) | плоские предметы | 一张纸, 一张桌子 |
| 只 (zhī) | животные (один) | 一只猫 |
| 条 (tiáo) | длинные, рыбы | 一条鱼, 一条狗 |
| 把 (bǎ) | с ручкой (стул, нож) | 一把椅子 |
| 杯 (bēi) | напитки | 一杯茶 |
| 碗 (wǎn) | еда в миске | 一碗饭 |
| 双 (shuāng) | пары | 一双鞋 |
| 件 (jiàn) | дела, одежда | 一件事 |
| 辆 (liàng) | транспорт | 一辆车 |

### 3.6 Вопросы

**1. Да/нет — частица 吗 (ma):**
```
你是学生吗？ (Nǐ shì xuésheng ma?) — Ты студент?
```

**2. Альтернативный — A-not-A:**
```
你是不是学生？ (Nǐ shì bù shì xuésheng?) — Ты студент или нет?
你去不去？ (Nǐ qù bù qù?) — Ты идёшь или нет?
```

**3. Вопросительные слова:**
| Слово | Транскрипция | Перевод |
|-------|-------------|---------|
| 什么 | shénme | что? |
| 谁 | shuí | кто? |
| 哪里 / 哪儿 | nǎlǐ / nǎr | где? куда? |
| 什么时候 | shénme shíhou | когда? |
| 为什么 | wèishénme | почему? |
| 怎么 | zěnme | как? |
| 多少 | duōshao | сколько? |
| 几 | jǐ | сколько? (<10) |
| 哪个 | nǎge | который? |

### 3.7 Модальные глаголы

| Глагол | Значение | Пример |
|--------|----------|--------|
| 会 (huì) | уметь | 我会说中文 (я умею говорить по-китайски) |
| 能 (néng) | мочь (физически) | 我能走路 (я могу ходить) |
| 可以 (kěyǐ) | можно | 我可以进来吗? (можно войти?) |
| 应该 (yīnggāi) | должен | 你应该学习 (ты должен учиться) |
| 要 (yào) | хотеть / нуждаться | 我要水 (мне нужна вода) |
| 想 (xiǎng) | хотеть (желание) | 我想去 (я хочу пойти) |

### 3.8 Конструкция 把 (bǎ)

Выделяет объект, который подвергается действию:
```
我把书放在桌子上。
Wǒ bǎ shū fàng zài zhuōzi shang.
Я кладу книгу на стол.
```

Структура: **S + 把 + O + V + (дополнение)**

### 3.9 Дополнение результата (结果补语)

Глагол + дополнительный глагол/прилагательное:

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 看见 | kànjiàn | увидеть (смотреть + видеть) |
| 听见 | tīngjiàn | услышать |
| 做完 | zuòwán | закончить делать |
| 吃完 | chīwán | доесть |
| 打开 | dǎkāi | открыть |
| 关上 | guānshàng | закрыть |
| 记住 | jìzhù | запомнить |
| 学会 | xuéhuì | выучить (научиться) |

### 3.10 Дополнение возможности

V + 得 (de) / 不 (bù) + Result

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 听得懂 | tīngde dǒng | могу понять на слух |
| 听不懂 | tīngbu dǒng | не могу понять |
| 看得见 | kànde jiàn | могу увидеть |
| 看不见 | kànbu jiàn | не вижу |

## 5. Диалоги

### 5.1 Знакомство

```
A: 你好！我叫李明，你叫什么名字？
   Nǐ hǎo! Wǒ jiào Lǐ Míng, nǐ jiào shénme míngzì?
   Привет! Меня зовут Ли Мин, а тебя?

B: 你好！我叫安娜，我是美国人。
   Nǐ hǎo! Wǒ jiào Ānnà, wǒ shì Měiguórén.
   Привет! Меня зовут Анна, я американка.

A: 很高兴认识你！
   Hěn gāoxìng rènshi nǐ!
   Очень приятно!

B: 我也是！
   Wǒ yě shì!
   Мне тоже!
```

### 5.2 В ресторане

```

A: 好，来一份饺子，还要一碗米饭。

```

## 8. Культурные заметки

- **Фамилия + имя** — сначала фамилия, потом имя. Обращение по фамилии + 先生 (xiānsheng — господин) / 女士 (nǚshì — госпожа).
- **Визитки** — протягивать двумя руками, текст к собеседнику.
- **Подарки** — не открывают при госте. Не дарят часы (символ смерти), зонты (разлука), зелёные шляпы (измена).
- **Цифры:** 4 (四, sì) = смерть (死). 8 (八, bā) = богатство (发, fā). 9 (九, jiǔ) = долговечность.
- **Чайная культура** — гостю наливают чай. Постучать пальцами по столу — благодарность.
- **Лицо (面子, miànzi)** — репутация, достоинство. Потеря лица — серьёзная проблема.
- **Громкие звуки** — норм. Чавкать, плеваться — не считается грубым.
- **Физический контакт** — минимальный. Личное пространство меньше, но прикосновения — только близким.

## 9. Фонетические особенности

### 9.1 Палатализация

**j, q, x** произносятся только перед **i, ü**:
- 鸡 (jī) — курица
- 七 (qī) — семь
- 西 (xī) — запад

**zh, ch, sh, r** — ретрофлексные (загнутый язык):
- 吃 (chī) — есть
- 是 (shì) — быть
- 日 (rì) — день

**z, c, s** — передние (язык у зубов):
- 子 (zǐ) — ребёнок
- 次 (cì) — раз
- 四 (sì) — четыре

### 9.2 Ü и его замена

**ü** после **j, q, x, y** пишется как **u** (читается как ü):
- 去 (qù) — идти
- 女 (nǚ) — женщина

Но после **n, l** пишется **ü**:
- 绿 (lǜ) — зелёный
- 女孩 (nǚhái) — девочка

## 13. Методика изучения китайского

### 13.1 Как учить иероглифы

Иероглифы — самая сложная, но и самая увлекательная часть китайского. Без правильного подхода зубрёжка не работает: нужно **понимание структуры + регулярное повторение**.

**Шаг 1 — Разбейте на компоненты.** Каждый иероглиф = ключ (радикал) + фонетика или семантика. Например:
- 河 (hé) = 氵(вода) + 可(можно) → «можно через воду» = река
- 防 (fáng) = 阝(стена) + 方(направление) → «защитить стеной»
- 饭 (fàn) = 饣(еда) + 反(fǎn) → «перевёрнутая еда» = еда

Подробнее о ключах — в разделе [2.3 Ключи (радикалы)](index.md#23-ключи-радикалы).

**Шаг 2 — Используйте мнемонические истории.** Образы запоминаются в 10 раз лучше абстрактных символов. Смотрите:
- [Ханцзы-истории](../../mnemonics/hanzi-chinese.md) — истории для запоминания иероглифов
- [Канжи-истории](../../mnemonics/kanji-stories.md) — японские вариации (много общих символов)
- [Шпаргалка мнемоник](../../mnemonics/cheatsheet.md) — техники keyword-метода

**Шаг 3 — Пишите по-настоящему.** Не просто копируйте — запоминайте **порядок черт**. Смотрите [порядок написания](index.md#2-письменность) в разделе 2.1. Используйте:
- [Практика написания](writing/index.md) — тренировка кистью и клавиатуры

**Шаг 4 — Учащайте по частоте.** Не учите иероглифы от 1 до 5000. Сначала:
1. Иероглифы HSK 1–2 (~300 символов) → [подготовка к HSK](exam/index.md)
2. Частотный словарь → [частотный словарь](vocabulary/index.md)
3. Иероглифы по ключам → [иероглифика по ключам](kanji/index.md)

**Шаг 5 — Интервальные повторения (SRS).** Анки с китайской колодой: 1 карточка = иероглиф + пиньинь + значение + один пример. Цель: 30–50 новых иероглифов в неделю.

---

### 13.2 Как выучить тоны

Тоны — второй барьер после иероглифов. Носители русского языка не имеют тонального различия, поэтому это тренировка слуха и мышц речевого аппарата.

**Фаза 1 — Осязание тонов (1–2 недели):**
1. Слушайте каждый тон отдельно. Воспроизведите сразу: ā á ǎ à.
2. Практикуйте «махание» рукой: 1-й тон — ровно на уровне плеча; 2-й — рука идёт вверх; 3-й — рука вниз-вверх; 4-й — резкий удар вниз.
3. Запишите свой голос и сравните.

**Фаза 2 — Тоны в контексте (2–4 недели):**
- Учите каждое слово **сразу с тоном**: не мā, а именно mā с первым тоном.
- Повторяйте диалоги из раздела [5. Диалоги](index.md#5-диалоги) — там тоны уже расставлены.
- Слушайте аудирование: [аудирование](listening/index.md)

**Фаза 3 — Tone Sandhi (3+ недели):**
- Третий тон + третий тон → второй + третий: [правила изменения тонов](index.md#12-правила-изменения-тонов-tone-sandhi)
- Нейтральный тон — самая тонкая вещь: практикуйте с частицами 的 (de), 吗 (ma), 吧 (ba).

**Полезные ресурсы:**
- [Пиньинь и тональная сеть](details.md) — подробная фонетика
- [Мнемоники для тонов](../../mnemonics/cheatsheet.md#тональные-приёмы) — ассоциативные приёмы
- YouTube-канал: «Yoyo Chinese», «Chinese with Yoyo» — лучшая тональная тренировка

### 13.3 Как осваивать грамматику

Китайская грамматика — одна из простых для носителей индоевропейских языков. Главное — **переверните русское мышление**.

**Принцип 1 — Китайская грамматика = английская грамматика.**
Оба языка: SVO, нет спряжений, нет падежей. Если вы говорите по-английски — вы уже знаете ~60% китайской грамматики.

**Принцип 2 — Учите грамматику через фразы, не правила.** Не зубрите «образуйте прошедшее с 了». Вместо этого выучите 10 фраз с 了:
- 我吃了 (wǒ chīle) — я поел
- 他看了电视 (tā kànle diànshì) — он посмотрел телевизор
- 妈妈笑了 (māma xiào le) — мама улыбнулась

**Принцип 3 — Организация по частицам.** Весь китайский строится на ключевых частицах:

| Частица | Что делает | Где практиковать |
|---------|-----------|------------------|
| 了 | завершённость | [3.3 Глаголы — нет спряжений](index.md#33-глаголы-нет-спряжений) |
| 的 | притяжание/атрибут | [3.2 Частицы и служебные слова](index.md#32-частицы-и-служебные-слова) |
| 得 | возможность/степень | [3.10 Дополнение возможности](index.md#310-дополнение-возможности) |
| 把 | выделение объекта | [3.8 Конструкция 把](index.md#38-конструкция-把-bǎ) |
| 在 | действие в процессе | [3.3 Глаголы — нет спряжений](index.md#33-глаголы-нет-спряжений) |
| 过 | опыт в прошлом | [3.3 Глаголы — нет спряжений](index.md#33-глаголы-нет-спряжений) |

**Принцип 4 — Гребёнка частых ошибок.** Русскоязычные ученики путают:
- 的/地/得 → [частые ошибки](common-mistakes/index.md)
- 了/过/着 → [частые ошибки](common-mistakes/index.md)
- 把/被 → [частые ошибки](common-mistakes/index.md)

**Принцип 5 — Ежедневное погружение.** Читайте тексты для чтения: [тексты для чтения](reading/index.md). Слушайте: [аудирование](listening/index.md). Пишите: [письмо](writing/index.md).

### 13.4 Общая стратегия обучения

**Ежедневный минимум (30 минут):**
- 10 минут — новые иероглифы (5–8 символов) + SRS
- 10 минут — тоны и произношение (повтор диалогов)
- 10 минут — грамматика + 5 фраз с новой конструкцией

**Еженедельный максимум (2–3 часа):**
- 1 диалог из раздела [5. Диалоги](index.md#5-диалоги) наизусть
- 1 урок из курса [units](unit-01/dialogue.md)
- 1 сессия аудирования
- 1 письменное упражнение

**Мнемотехника для китайского:**
Для запоминания лексики используйте keyword-метод: китайское слово → русский звук → абсурдный образ. Смотрите:
- [Универсальная лексика](../../mnemonics/universal-vocabulary.md) — keyword-метод для любого языка

## 15. Часто задаваемые вопросы (FAQ)

### В1. Сколько времени нужно, чтобы выучить китайский?

Зависит от цели:
- **Базовое общение (HSK 1–2):** 3–6 месяцев при 30 мин/день.
- **Быт и работа (HSK 3–4):** 1–2 года.
- **Свободное владение (HSK 5–6):** 3–5 лет.
- **Носитель (HSK 6+):** 5+ лет или среда общения.

Смотрите [HSK (Hanyu Shuiping Kaoshi)](index.md#114-hsk-hanyu-shuiping-kaoshi) для уровней.

### В2. Нужен ли мне мандаринский или можно начать с диалекта?

**Всегда начинайте с мандаринского (путунхуа)**. Это стандартный язык, на котором говорят везде в Китае. Диалекты (кантонский, шанхайский, фуцзянь) изучайте позже, если есть конкретная необходимость.

### В3. Уже 3 месяца учу, но не слышу тоны. Что делать?

Это нормально — так называемый «тоновой глухота». Через 3–6 месяцев интенсивного прослушивания мозг начинает различать тоны автоматически:
- Слушайте [аудирование](listening/index.md) ежедневно
- Используйте [тональные приёмы](../../mnemonics/cheatsheet.md) из мнемоник
- Не переключайтесь на родной язык — говорите по-китайски даже с ошибками

### В4. Какое приложение лучше для изучения китайского?

Топ-3 для русскоязычных:
1. **HelloChinese** — интерактивные уроки, хорошая тональная тренировка
2. **Pleco** — словарь №1 + flashcards
3. **Anki** — SRS-карточки с пользовательскими колодами китайских иероглифов

### В5. Нужно ли учить традиционные иероглифы?

Если вы учите мандаринский (Китай, Сингапур) — **упрощённые**. Если планируете Тайвань, Гонконг — **традиционные**. Упрощённые легче выучить, но знать традиционные полезно для чтения классических текстов и переключения между системами. [Подробно о разнице](index.md#10-упрощённые-vs-традиционные).

### В6. Что такое 把 (bǎ) конструкция и обязательно ли её учить?

**Конструкция 把** выделяет объект действия: S + 把 + O + V. Например: 我把书放在桌子上 (Я кладу книгу на стол). Она не обязательна для начала, но критична для HSK 3+ и естественной речи. Ученики HSK 1–2 обходятся без неё, но продвинутые не могут без неё. [Подробнее — раздел 3.8](index.md#38-конструкция-把-bǎ).

### В7. Как запомнить 5000+ иероглифов для HSK 6?

Не нужно запоминать все 5000. Стратегия:
- 2500 иероглифов HSK 6 — не все используются в обычной речи
- Фокус на **пиктограммах + фоноидеограммах** (80% всех символов)
- Используйте [истории для ханцзы](../../mnemonics/hanzi-chinese.md) для запоминания ключей
- Каждый новый иероглиф привязывайте к уже известному: 家 (jiā) = 宀(крыша) + 豕(свинья) → «дом со свиньёй»

### В8. Можно ли говорить по-китайски без иероглифов?

Да, если цель — устная речь. Пиньинь + голосовой ввод (в Pleco и WeChat) заменяют написание. Но **чтение без иероглифов невозможно** — каждый текст состоит из иероглифов. Минимум: уметь читать 300–500 символов для базового понимания. [Письмо](writing/index.md) поможет развить навык.

### В9. В чём разница между 学习 и 學習 и другие упрощённые/традиционные пары?

| Упрощённые (简体字) | Традиционные (繁體字) | Значение |
|---------------------|----------------------|----------|
| 学习 | 學習 | учиться |
| 中国 | 中國 | Китай |
| 电脑 | 電腦 | компьютер |
| 书 | 書 | книга |
| 说话 | 說話 | говорить |
| 门 | 門 | дверь |
| 马 | 馬 | лошадь |

См. [раздел 10 — Упрощённые vs традиционные](index.md#10-упрощённые-vs-традиционные) для полного списка.

### В10. Как не забывать уже выученное?

Три принципа:
1. **Интервальные повторения (SRS)** — Anki или бумажный Лейтнер. Повторяйте в интервалах 1 день → 3 → 7 → 14 → 30 дней.
2. **Используйте в контексте** — не учите слова отдельно, а в предложениях и диалогах.
3. **Ежедневное погружение** — хотя бы 15 минут чтения/слушания на китайском каждый день. [Тексты для чтения](reading/index.md) и [аудирование](listening/index.md) помогут.

### В11. Чем отличается китайская грамматика от русской?

Главные отличия:
- **Нет спряжений**: 我吃, 你吃, 他吃 — глагол не меняется
- **Нет падежей**: порядок слов фиксирован (SVO), нет падежных окончаний
- **Нет родов**: 他 (он), 她 (она), оно — всё одинаково, она (tā)
- **Частицы вместо форм**: 了 = прошедшее, 的 = притяжание, 着 = длительное
- **Счётные слова обязательно**: ❌ 我吃苹果, ✅ 我吃**一个**苹果
- **Главное отличие**: нет инфлексии — каждое слово работает как есть. [Подробнее в грамматике](index.md#3-грамматика).

### В12. Как подготовиться к HSK?

Структура подготовки:
1. Определите уровень: [таблица уровней HSK](index.md#114-hsk-hanyu-shuiping-kaoshi)
2. Выберите учебник: [HSK Standard Course](index.md#112-учебники)
3. Изучите лексику: [частотный словарь](vocabulary/index.md)
4. Практикуйте чтение: [тексты для чтения](reading/index.md)
5. Тренируйте аудирование: [аудирование](listening/index.md)
6. Пройдите пробный тест: [подготовка к HSK](exam/index.md)
7. Повторите грамматику: [грамматическая шпаргалка](cheatsheet/index.md)

### В13. Можно ли изучать китайский параллельно с другими языками?

Да, но с умом:
- **С японским или корейским** — отличная связка: много общих иероглифов (кандзи/ханьцзы). Параллельно изучайте через [ханцзы-истории](../../mnemonics/hanzi-chinese.md) + [канжи-истории](../../mnemonics/kanji-stories.md).
- **С английским или европейским языком** — возможно, но не в один день. Дайте каждому языку минимум 40 минут сессии.
- **Мнемотехника универсальна**: [универсальная лексика](../../mnemonics/universal-vocabulary.md) и [классический курс](../../mnemonics/classic-mnemonics.md) работают с любым языком.

### В14. Нужно ли учить «палатализацию» (j/q/x)?

Обязательно! j/q/x произносятся только перед i/ü — это фундамент пиньиня:
- 鸡 (jī) ≠ 季 (jì) ≠ 吉 (jí) — тона меняют значение полностью
- 女 (nǚ) ≠ 努 (nǔ) — ü vs u

См. [фонетические особенности](index.md#9-фонетические-особенности) для подробностей.

### В15. Как читать китайские новости и тексты на уровне HSK 1–2?

Поэтапный подход:
1. Начните с [простых текстов](reading/index.md) по уровням HSK
2. Используйте Pleco для каждого незнакомого иероглифа
3. Читать 5–10 минут в день — к HSK 2 вы будете читать адаптированные тексты
4. Переходите к [настоящим текстам](reading/index.md) после HSK 3
