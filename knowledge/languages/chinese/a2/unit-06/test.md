# Unit 06 — Тест: Телефон и планы

> Проходной балл: 80%. Не переходите к следующему юниту, пока не наберёте.

## 1. Лексика (выберите правильный перевод)

1. 打电话 — a) позвонить b) ответить c) повесить трубку
2. 接电话 — a) перезвонить b) ответить на звонок c) набрать номер
3. 计划 — a) встреча b) сигнал c) план
4. 约会 — a) свидание b) звонок c) сообщение
5. 号码 — a) время b) номер c) место
6. 短信 — a) звонок b) sms-сообщение c) письмо
7. 占线 — a) свободный b) занят (линия) c) включённый

## 2. Грамматика (вставьте нужную форму)

1. 我现在____电话。 (talk → 正在打电话 )
2. 你明天有什么____？ (plans → 计划 )
3. 请____时间。 (confirm → 确认 )
4. 他从不____。 (be late → 迟到 )
5. 请____联系。 (keep → 保持联系 )
6. 我们____八点见面。 (will → 会 )
7. 你____带充电器吗？ (should → 要 )

## 3. Перевод (с русского на китайский)

1. Позвони мне завтра.
2. Что ты делаешь на выходных?
3. Я опоздал на пять минут.
4. Пожалуйста, подтверди время.
5. Давай встретимся в другой раз.
6. Линия занята.
7. Я сейчас разговариваю по телефону.

## 4. Соответствие (соедините пары)

1. 信号不好 — a) вовремя
2. 手机没电 — b) плохой сигнал
3. 准时到 — c) разряженный телефон
4. 占线 — d) линия занята
5. 回电话 — e) перезвонить
6. 通话中 — f) в разговоре

## 5. Заполните пропуск

3. 我们____明天见。 (会)
