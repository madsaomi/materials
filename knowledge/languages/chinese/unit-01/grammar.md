# Unit 1 — 语法 (Грамматика)

## 1. Порядок слов SVO

Китайский — SVO (Subject-Verb-Object), как в английском и русском:

```
我 学习 汉语。     — Я учу китайский.
你 吃 米饭。       — Ты ешь рис.
他 看 电影。       — Он смотрит кино.
```

## 2. 是 (быть)

```
我是中国人。     — Я китаец.
你是学生吗？     — Ты студент?
这不是我的书。   — Это не моя книга.
```

**Отрицание:** 不 + 是
```
我不是老师。     — Я не учитель.
```

**Вопрос:** 吗 в конце
```
你是学生吗？     — Ты студент?
他是中国人吗？   — Он китаец?
```

## 3. 的 (притяжательная частица)

```
我的书          — моя книга
你的手机        — твой телефон
老师的办公室    — кабинет учителя
```

## 4. 很 (очень) + прилагательное

```
很好     — очень хорошо
很大     — очень большой
很漂亮   — очень красивый
```

Примечание: 很 перед прилагательным часто не означает "очень", а просто соединяет подлежащее и прилагательное:
```
她漂亮。 — Она красивая. (грамматически неполно)
她很漂亮。 — Она красивая. (правильно, без значения "очень")
```

## 5. Вопросы с вопросительными словами

| 疑问词 | Пиньинь | Значение |
|--------|---------|----------|
| 什么 | shénme | что |
| 谁 | shuí | кто |
| 哪 | nǎ | который |
| 哪儿 | nǎr | где |
| 什么时候 | shénme shíhou | когда |
| 为什么 | wèishénme | почему |
| 怎么 | zěnme | как |
| 多少 | duōshao | сколько |
| 几 | jǐ | сколько (немного) |

## 6. 吗 (вопрос да/нет)

```
你好吗？         — Как дела? (букв. "ты хорошо?")
你是学生吗？     — Ты студент?
你喜欢咖啡吗？   — Ты любишь кофе?
```

## 7. 不 / 没 (отрицание)

**不** — для настоящего/будущего/привычного:
```
我不喜欢咖啡。       — Я не люблю кофе.
明天我不去学校。     — Завтра я не пойду в школу.
```

**没** — для прошедшего (не сделал):
```
我没去学校。         — Я не ходил в школу.
我没吃早饭。         — Я не завтракал.
```

注意: 是 отрицается только через 不是, не через 没

## 8. 了 (частица завершённости)

```
我吃了。           — Я поел.
我去学校了。       — Я сходил в школу.
我学汉语半年了。   — Я учу китайский полгода (уже).
```

## 9. Счётные слова

| 量词 | Для чего | Пример |
|------|----------|--------|
| 个 | общее | 一个人, 两个苹果 |
| 本 | книги | 一本书 |
| 张 | плоское | 一张纸, 一张桌子 |
| 只 | животные | 一只猫 |
| 条 | длинное | 一条鱼, 一条路 |
| 杯 | напитки | 一杯水 |
| 块 | кусок / юань | 一块钱 |
| 口 | члены семьи | 三口人 |

## 练习 (Упражнения)

1. Переведите: "Я китаец" → __________
2. Переведите: "Ты студент?" → __________
3. Сделайте отрицание: "Я не учитель" → __________
4. Вставьте частицу: 这是谁___书?
5. Составьте: 我 / 学习 / 汉语 / 学校 / 在 → __________

**Ответы:**
1. 我是中国人。
2. 你是学生吗？
3. 我不是老师。
4. 的
5. 我在学校学习汉语。

# Расширение Unit 1 — 语法 (Грамматика)

## 10. 呢 (ne) — переспрос и продолжение

Частица 呢 задаёт встречный вопрос или возвращает вопрос собеседнику:

```
我是中国人，你呢？        — Я китаец, а ты?
我很好，你呢？            — У меня всё хорошо, а у тебя?
我不去，你呢？            — Я не пойду, а ты?
```

**Сравнение 吗 и 呢:**

| Частица | Функция | Пример |
|---------|---------|--------|
| 吗 | вопрос да/нет | 你是学生吗？ Ты студент? |
| 呢 | переспрос/вопрос обратно | 我是学生，你呢？ Я студент, а ты? |

**注意:** 呢 также указывает на продолжение действия: 我在看书呢。 Я сейчас читаю книгу.

## 11. 也 (yě) — тоже

Слово 也 ставится **перед глаголом**:

```
我是学生，他也是学生。    — Я студент, и он тоже студент.
我喜欢茶，她也喜欢茶。    — Я люблю чай, и она тоже.
你学习汉语，我也学习汉语。— Ты учишь китайский, и я тоже учу.
```

**注意:** Отрицание с 也: 也不 = "тоже не".

## 12. Притяжательное 的 — подробнее

Кроме притяжательности, 的 связывает определение с существительным:

```
我的书            — моя книга
学校的老师        — учитель школы
红色的车          — красная машина
我的朋友          — мой друг (всегда с 的)
```

**Важно для родственников:** 妈妈/(мой) папа — можно без 的:
```
我妈妈           — моя мама (принято, без 的)
我的妈妈         — тоже верно
```
Для не-родственников обычно используем 的: 我的朋友 (мой друг).

## 13. Связка 是 — обязательно!

**注意:** 是中国ек, 是 студент — конструкция N + 是 + N. НО перед прилагательными 是 НЕ ставится:

```
✅ 她是老师。              — Она учитель.
❌ 她是漂亮。              — НЕВЕРНО (с прилагательным)
✅ 她很漂亮。              — Она красивая.
```

**Учим таблицу 是:**

| Структура | Пример | Перевод |
|-----------|--------|---------|
| A 是 B | 我是学生。 | Я студент. |
| A 不是 B | 我不是老师。 | Я не учитель. |
| A 是 B + 吗 | 你是学生吗？ | Ты студент? |
| A 是不是 B? | 你是不是学生？ | Ты студент? (A-not-A) |

## 14. A-not-A 疑问句 (вопрос «или нет»)

Помимо 吗, вопрос можно построить через V + 不 + V:

```
你是不是学生？          — Ты студент?
你去不去？              — Ты идёшь?
你喜欢不喜欢？          — Тебе нравится?
你有没有钱？            — У тебя есть деньги?
```

**Сравнение двух способов:**

| Способ | Пример | Оттенок |
|--------|--------|---------|
| 吗 | 你去吗？ | Нейтральный вопрос |
| A-not-A | 你去不去？ | Подчёркнутый, уточняющий |

## 15. 有 (yǒu) — иметь, наличие

Глагол 有 означает наличие/обладание:

```
我有一个哥哥。          — У меня есть старший брат.
他有手机吗？            — У него есть телефон?
我们没有钱。            — У нас нет денег.
```

**注意:** Отрицание через 没, а не 不: 没有, никогда 不有.

**有 для родственников (семейный счёт):**
```
你家有几口人？          — Сколько человек в твоей семье?
我家有四口人。          — В нашей семье 4 человека.
```

## 16. 几 (jǐ) vs 多少 (duōshao) — «сколько»

| Слово | Когда | Пример |
|-------|-------|--------|
| 几 (jǐ) | ожидается небольшое число (<10), со счётным словом | 你有几个哥哥？ |
| 多少 (duōshao) | любое число, для денег и больших величин | 多少钱？, 多少人？ |

**Примеры:**
```
你有几个朋友？          — Сколько у тебя друзей? (ожидается немного)
这个多少钱？            — Сколько это стоит? (всегда 多少)
你家有几口人？          — Сколько человек в семье?
```

## 17. Местоимения множественного числа на 们

Суффикс 们 образует множественное число только для людей:

```
我 → 我们   (мы)
你 → 你们   (вы)
他/她/它 → 他们/她们/它们 (они)
```

**注意:** 们 НЕ используется с неодушевлёнными и обычно опускается после существительных типа 老师 (учителя — не всегда 老师们).

**Мы («включающее»):** 咱们 (zánmen) — «мы с тобой», инклюзив.

## 18. Порядок слов с обстоятельствами времени и места

Обстоятельство времени стоит ПЕРЕД глаголом (иногда в начале), обстоятельство места обычно перед глаголом:

```
我明天去学校。              — Завтра я пойду в школу. (время + место)
我八点起床。                — Я встаю в 8.
我在学校学习汉语。          — Я учу китайский в школе.
```

**Схема:** S + (время) + (место) + V + O
```
我      明天        在咖啡厅    喝        咖啡。
Я      завтра      в кафе      пью      кофе.
```

## 19. 很 + прилагательное — без значения «очень»

**注意:** В утвердительных предложениях прилагательное почти всегда идёт с 很, даже если «очень» не имеется в виду — иначе предложение звучит как сравнение:

```
她很高。            — Она высокая. (просто факт, 很 = связка)
她高。              — Она высокая. (подразумевает «выше обычного / в сравнении»)
```

**Но в вопросах и отрицаниях 很 не нужен:**
```
她高吗？            — Она высокая?
她不高。            — Она невысокая.
```

## 20. 太...了 — «слишком», восклицание

Конструкция 太 + прилагательное + 了:

```
太好了！            — Отлично! (букв. слишком хорошо)
太贵了！            — Слишком дорого!
太多了！            — Слишком много!
太漂亮了！          — Как красиво!
```

**注意:** Здесь 了 означает изменение состояния / сильную степень, а не прошедшее время.

## 22. Сравнительная таблица: отрицания 不 / 没

| Критерий | 不 (bù) | 没 (méi) |
|----------|---------|----------|
| Время | настоящее/будущее/привычка | прошедшее / отсутствие |
| Перед 是 | ✅ 不是 | ❌ (используй 不是) |
| Перед 有 | ❌ 不有 | ✅ 没有 |
| Глагол-действие | 我不去。Не пойду. | 我没去。Не пошёл. |
| Прилагательное | 不好。Нехорошо. | — |

## 23. Тонкие моменты меры времени: 多长时间

Вопрос о длительности:

```
你学汉语多长时间了？      — Как долго ты учишь китайский?
我学了半年了。            — Я учусь полгода (уже).
我学了一年。              — Я учился год.
```

**Структура:** V + 了 + длительность + 了 (для продолжающегося действия).
