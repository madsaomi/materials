# Unit 1 — 对话: 你好！(Привет!)

## 对话

```
李明: 你好！你叫什么名字？
王芳: 你好！我叫王芳。你叫什么？
李明: 我叫李明。很高兴认识你！
王芳: 我也很高兴认识你！你是哪国人？
李明: 我是中国人。你呢？
王芳: 我是俄罗斯人。我学习汉语。
李明: 你学习汉语多长时间了？
王芳: 我学了半年了。还不太流利。
李明: 你说得很好！你住在哪儿？
王芳: 我住在学校附近。你呢？
李明: 我住在市中心。
王芳: 你的电话号码是多少？
李明: 我的电话是 138-1234-5678。
王芳: 好，我记下来了。再见！
李明: 再见！
```

## 翻译

| 中文 | 翻译 |
|------|------|
| 你好 | Привет |
| 你叫什么名字 | Как тебя зовут? |
| 很高兴认识你 | Приятно познакомиться |
| 你是哪国人 | Из какой ты страны? |
| 我是中国人 | Я китаец |
| 你学习汉语多长时间了 | Как долго учишь китайский? |
| 我学了半年了 | Я учусь полгода |
| 流利 | Бегло |
| 你说得很好 | Ты хорошо говоришь |
| 你住在哪儿 | Где ты живёшь? |
| 市中心 | Центр города |
| 电话号码 | Номер телефона |
| 我记下来了 | Я записал(а) |
