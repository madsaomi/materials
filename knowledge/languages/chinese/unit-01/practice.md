# Unit 1 — 练习 (Практика)

## 练习 1：填空 (Заполните пропуски)

1. 你___什么名字？
2. 我___中国人。
3. 她___老师。
4. 这是谁___书？
5. 他___喜欢咖啡。

**Варианты:** 叫, 是, 的, 不, 很

## 练习 2：翻译 (Переведите)

1. Меня зовут Ли Мин. → __________
2. Я студент. → __________
3. Ты русский? → __________
4. Это моя книга. → __________
5. Спасибо, до свидания! → __________

## 练习 3：对话 (Диалог)

Расположите реплики в правильном порядке:

- [ ] 再见！
- [ ] 我叫王明。你呢？
- [ ] 你好！你叫什么名字？
- [ ] 我叫李芳。很高兴认识你！
- [ ] 我也很高兴认识你！
- [ ] 这是我的电话号码。12345678。

## 练习 4：选择 (Выберите правильное)

1. 你(叫/是)什么名字？
2. 我(没/不)是俄罗斯人。
3. 他(不/没)吃饭。
4. 你学习汉语(多长时间/什么)。
5. 我(的/了)家在市中心。

## 练习 5：写自我介绍 (Напишите о себе)

5 предложений:
1. 我叫... / Приветствие
2. 我是... / Кто вы
3. 我住在... / Где живёте
4. 我学习... / Что учите
5. 我的电话... / Контакт
