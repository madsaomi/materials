# Unit 4 — 语法 (Грамматика)

## 1. 一边…一边… (одновременно)

Указывает, что два действия выполняются одновременно. Оба действия относятся к одному подлежащему.

```
我一边吃饭，一边看电视。     — Я ем и (при этом) смотрю телевизор.
他一边听音乐，一边学习。     — Он слушает музыку и учится.
我们一边喝茶，一边聊天。     — Мы пьём чай и болтаем.
```

Второе действие — главное (более важное), первое — фон.

## 2. 有点儿 / 一点儿 (немного)

**有点儿 + прилагательное** — перед прилагательным, выражает "немного, слегка" (часто с оттенком недовольства):

```
这个菜有点儿辣。       — Это блюдо немного острое.
汤有点儿咸。           — Суп немного солёный.
今天有点儿冷。         — Сегодня немного холодно.
```

**一点儿** — после существительного или после прилагательного, обозначает количество ("немножко"):

```
我要一点儿糖。         — Мне чуть-чуть сахара.
请你快一点儿。         — Пожалуйста, побыстрее.
我吃了一点儿米饭。     — Я немного поел риса.
```

## 3. 动词 + 得 + 形容词 (дополнение степени)

Служит для описания того, КАК выполняется действие. Структура: `Подлежащее + Глагол + 得 + Наречие/Прилагательное`.

```
她唱歌唱得很好。         — Она очень хорошо поёт.
他写汉字写得很漂亮。     — Он очень красиво пишет иероглифы.
菜做得真好吃！           — Еда приготовлена очень вкусно!
```

Если у глагола есть дополнение, его можно вынести вперёд:

```
她做菜做得很香。     =  她菜做得很香。    — Она вкусно готовит.
他中文说得很流利。       — Он бегло говорит по-китайски.
```

## 4. 会 / 能 / 可以 (мочь, уметь, можно)

| Слово | Значение | Пример |
|-------|----------|--------|
| 会 | уметь (навык, умение) | 你会做饭吗？ — Ты умеешь готовить? |
| 能 | мочь (возможность, разрешение) | 我现在不能吃辣的。 — Сейчас я не могу есть острое. |
| 可以 | можно (разрешено) | 我可以进来吗？ — Можно войти? |

Вежливая просьба строится через 可以…吗？ / 能…吗？:

```
可以给我看一下菜单吗？   — Можно посмотреть меню?
你能帮我一下吗？         — Ты не мог бы мне помочь?
请问，我可以坐这儿吗？   — Скажите, можно сесть здесь?
```

## 5. 再来 (ещё раз, добавьте)

Используется при заказе ещё одной порции. 再 = "ещё", 来 = "принесите/дайте".

```
再来一碗米饭。       — Ещё одну миску риса.
再来一杯茶。         — Ещё чашку чая.
服务员，再来一个饺子！— Официант, ещё один пельмень!
```

## 6. 买单 / 结账 (оплатить счёт)

Оба выражения означают "оплатить счёт". 买单 — разговорный вариант, 结账 — более официальный.

```
服务员，买单！           — Официант, счёт!
我要结账。               — Я хочу оплатить счёт.
我们买单，一共多少钱？   — Мы платим, сколько всего?
一起买单还是分开买单？   — Платим вместе или раздельно?
```

## 7. 不好意思 (извините / неловко)

Мягкое извинение или выражение смущения. Слабее, чем 对不起 (серьёзное извинение).

```
不好意思，请问洗手间在哪儿？   — Извините, где туалет?
不好意思，让你久等了。         — Извините, что заставил(а) вас ждать.
他有点不好意思。               — Ему немного неловко.
```

## 练习 (Упражнения)

1. Вставьте 一边: 我___吃饭，___看手机。
2. Переведите: "Я умею готовить китайскую еду." → __________
3. Переведите: "Ещё одну чашку зелёного чая." → __________
4. Вставьте 得: 她做饭___很好吃。
5. Переведите: "Официант, счёт, пожалуйста!" → __________

**Ответы:**
1. 一边 / 一边
2. 我会做中国菜。
3. 再来一杯绿茶。
4. 得
5. 服务员，买单！
