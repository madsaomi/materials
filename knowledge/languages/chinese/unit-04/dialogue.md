# Unit 4 — 对话: 在饭店 (В ресторане)

## 对话

```
服务员: 欢迎光临！请问几位？
李明: 我们两个人。
服务员: 请坐。这是菜单。你们想吃什么？
李明: 我要一个麻婆豆腐，一个宫保鸡丁。
王芳: 我要一个西红柿炒鸡蛋，再来一碗米饭。
服务员: 你们喝点什么？
王芳: 来两杯绿茶吧。
服务员: 好。你们还要别的吗？
李明: 不要了，谢谢。
王芳: 我特别喜欢这个麻婆豆腐，就是有一点儿辣。
李明: 是，这儿的菜做得真好吃！
服务员: 你们吃好了吗？
王芳: 吃好了，请买单。
服务员: 一共六十八块钱。
李明: 给你一百块。
服务员: 找你三十二块。这是发票。
王芳: 谢谢！欢迎下次再来！
```

## 翻译

| 中文 | 翻译 |
|------|------|
| 欢迎光临 | Добро пожаловать |
| 请问几位 | Скажите, сколько вас (человек)? |
| 菜单 | Меню |
| 想吃什么 | Что хотите заказать? |
| 麻婆豆腐 | Тофу мапо (острое) |
| 宫保鸡丁 | Курица гунбао |
| 西红柿炒鸡蛋 | Помидоры с яйцом |
| 再来一碗米饭 | Ещё одну миску риса |
| 喝点什么 | Что будете пить? |
| 来两杯绿茶吧 | Принесите, пожалуйста, две чашки зелёного чая |
| 别的 | Что-нибудь ещё |
| 有点儿辣 | Немного острый |
| 做得真好吃 | Приготовлено очень вкусно |
| 吃好了 | Поели (закончили есть) |
| 买单 | Счёт (оплатить) |
| 一共 | Всего |
| 找钱 | Сдача |
| 发票 | Чек |
| 下次再来 | Приходите ещё |
