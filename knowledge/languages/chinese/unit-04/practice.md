# Unit 4 — 练习 (Практика)

## 练习 1：填空 (Заполните пропуски)

1. 我___喝咖啡，___看书。
2. 这个菜___辣，我不能吃。
3. 她做菜做___很好吃。
4. 服务员，___一碗米饭！
5. 我___做中国菜，但是做得不太好。

**Варианты:** 一边, 得, 有点儿, 会, 再来

## 练习 2：翻译 (Переведите)

1. Я хочу заказать курицу гунбао. → __________
2. Ты умеешь пользоваться палочками? → __________
3. Официант, счёт, пожалуйста! → __________
4. Этот суп немного солёный. → __________
5. Я ем и смотрю телевизор. → __________

## 练习 3：对话 (Диалог)

Расположите реплики в правильном порядке:

- [ ] 欢迎光临！请问几位？
- [ ] 我要一个麻婆豆腐和一个宫保鸡丁。
- [ ] 请坐。这是菜单。你们想吃什么？
- [ ] 一共六十八块钱。
- [ ] 我们两个人。
- [ ] 服务员，买单！

## 练习 4：选择 (Выберите правильное)

1. 这个菜(有一点儿/一点儿)辣。
2. 我(会/能)说中文。
3. 你(吃/喝)绿茶还是咖啡？
4. 请(再来/再见)一杯茶。
5. 她唱歌唱(得/的)很好听。
