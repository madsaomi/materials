# Unit 10 — Грамматика: Путешествие в Пекин

**Фокус юнита:** 如果/要是, 就/才, 过 (опыт), 听说

---

## 1. 如果/要是…就… — Условие (если…, то…)

### Структура

```
如果 + условие, 就 + результат
要是 + условие, (就) + результат
```

要是 — более разговорная версия 如果.

### Примеры

```
如果明天天气好，我们就去公园。
  — Если завтра будет хорошая погода, мы пойдём в парк.

如果下雨，我们就不去了。
  — Если пойдёт дождь, мы не пойдём.

要是你有空，就来我家玩吧。
  — Если у тебя будет время, приходи ко мне играть.

要是我有钱，我就买一辆车。
  — Если бы у меня были деньги, я бы купил машину.
```

### Нулевое условие (общая закономерность)

```
如果加热，水就会开。
  — Если нагреть, вода закипит. (всегда)

如果努力学习，就能学好。
  — Если старательно учиться, можно хорошо выучить.
```

### Сокращение

- 如果 можно опустить: 明天天气好，我们就去公园。
- 就 можно опустить: 如果你来，(就)打电话给我。

## 2. 就 vs 才 — Раньше/позже ожидаемого

### 2.1. 就 (jiu) — «раньше / быстрее / легче ожидаемого»

```
他六点就起床了。       — Он встал в шесть (очень рано).
她五分钟就做完了。     — Она закончила за пять минут (очень быстро).
我还没说他就笑了。     — Я ещё не сказал, а он уже засмеялся.
如果你来，我就高兴了。 — Если ты придёшь, я сразу обрадуюсь.
```

### 2.2. 才 (cai) — «позже / медленнее / труднее ожидаемого»

```
他八点才起床。         — Он встал только в восемь (позже обычного).
她两个小时才做完。     — Она закончила только через два часа (долго).
我等了很久他才来。     — Я долго ждал, и только потом он пришёл.
如果你来，我才高兴。   — Только если ты придёшь, я обрадуюсь.
```

### Таблица: 就 vs 才

| Маркер | Оттенок | Пример |
|--------|---------|--------|
| 就 | рано, быстро, легко | 他六点就起了。 (очень рано) |
| 才 | поздно, медленно, трудно | 他八点才起。 (позже обычного) |

### 就 в условных предложениях

```
如果你来，我就去。     — Если ты придёшь, я пойду. (легко, само собой)
如果你不来，我就不去。 — Если ты не придёшь, я не пойду.
```

### 才 в условных предложениях

```
如果你来，我才去。     — Только если ты придёшь, я пойду. (иначе не пойду)
如果你不道歉，我才会原谅你。 — Только когда извинишься, я прощу.
```

> **Разница:** 就 = условие sufficient («если да, то Easily»). 才 = условие necessary («только если»).

## 3. 过 — Опытный аспект (был/делал когда-то)

### Структура

```
主语 + V + 过 + объект
```

### Примеры

```
我去过中国。           — Я был в Китае. (один раз или несколько)
你吃过中国菜吗？       — Ты ел китайскую еду? (когда-нибудь?)
他学过汉语。           — Он учил китайский (в прошлом).
我没有去过日本。       — Я не был в Японии.
她从来没看过这部电影。 — Она никогда не смотрела этот фильм.
```

### Вопрос

```
你去过中国吗？         — Ты был в Китае?
你吃过北京烤鸭吗？     — Ты ел пекинскую утку?
他学过法语吗？         — Он учил французский?
```

### Отрицание

```
我没有去过中国。       — Я не был в Китае.
我没学过日语。         — Я не учил японский.
他从来没吃过寿司。     — Он никогда не ел суши.
```

### 过 vs 了

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| V + 了 | конкретное действие в прошлом | 我去了中国。 — Я съездил в Китай. (один раз) |
| V + 过 | опытный аспект «когда-то делал» | 我去过中国。 — Я был в Китае. (опыт) |

```
我去了中国三次。       — Я был в Китае три раза. (конкретные случаи)
我去过中国。           — Я бывал в Китае. (опыт в целом)
我去了中国。           — Я съездил в Китай. (одно конкретное событие)
```

## 4. 听说 — «Говорят, что… / Я слышал, что…»

### Структура

```
听说 + предложение (факт / слух)
```

### Примеры

```
听说你要去中国了？     — Говорят, ты едешь в Китай?
听说他辞职了。         — Говорят, он уволился.
我听说中国菜很好吃。   — Я слышал, что китайская еда очень вкусная。
听说明天会下雨。       — Говорят, завтра будет дождь.
```

### 听说 как вводное слово

```
听说，他找到新工作了。 — Как я слышал, он нашёл новую работу.
我听说，那个餐厅很不错。 — Я слышал, что тот ресторан очень хороший.
```

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 如果明天下雨，就我去。 | 如果明天下雨，我就去。 | 就 ставится перед глаголом |
| 要是你来，我就去。 | ✅ (верно) | — |
| 他六点才起床。 | ✅ (если это поздно для говорящего) | 才 = позже ожидаемого |
| 他六点就起床。 | ✅ (если это рано для говорящего) | 就 = раньше ожидаемого |
| 我去过中国三次。 | 我去过中国三次。 / 我去中国去了三次。 | 过 可 с количеством |
| 他没去过中国吗？ | ✅ (верно, вопрос) | — |
| 听说他去中国了。 | ✅ (верно) | 听说 + полное предложение |
| 我没过去中国。 | 我没去过中国。 | 过 ставится после V |

## 7. 除了…以外，还/都… — «Кроме…, ещё / …все…»

### Структура

```
除了 + объект + 以外，还 + действие      — кроме…, ещё и…
除了 + объект + 以外，(其他)都 + …      — кроме…, все (остальные)…
```

以外 часто опускается, но 除了 остаётся.

### Примеры

```
除了故宫以外，我还去了长城。
  — Кроме Запретного города, я побывал ещё и на Великой стене.

除了北京以外，我还想去西安看看。
  — Помимо Пекина, мне хочется ещё съездить посмотреть Сиань.

除了小王以外，我们班的人都到齐了。
  — Кроме Сяо Вана, все из нашей группы собрались.

除了星期一，图书馆每天都开。
  — Кроме понедельника, библиотека открыта каждый день.
```

### 注意

- 除了…以外，还… — «дополнительно к этому»; 除了…以外，都… — «исключение из группы».
- В обоих случаях используется 除了, а смысл (还/都) задаёт вторая часть предложения.

## 8. 一边…一边… — Одновременные действия

### Структура

```
主语 + 一边 + 动作1 + 一边 + 动作2
```

Оба действия выполняются одновременно.

### Примеры

```
我们一边喝茶，一边聊天。
  — Мы пьём чай и беседуем.

他一边走路，一边听音乐。
  — Он идёт и слушает музыку.

我一边看地图，一边找酒店。
  — Я смотрю на карту и ищу отель.

她一边拍照，一边说：“真美！”
  — Она фотографирует и приговаривает: «Красота!»
```

### 注意

- Порядок всегда: 一边 + V1 + 一边 + V2; оба 一边 стоят перед глаголами.
- Не употребляется с действиями, которые не могут идти одновременно.
- Первый 一边 можно опустить: 我们喝茶聊天 — но тогда теряется оттенок одновременности.

## 9. 先…然后…最后… — Последовательность действий

### Структура

```
先 + действие1，然后 + действие2，(最后 + действие3)。
```

### Примеры

```
我们先买机票，然后订酒店，最后收拾行李。
  — Сначала покупаем билеты, потом бронируем отель и наконец собираем чемоданы.

来北京以后，我们先去天安门，然后去故宫。
  — Приехав в Пекин, мы сначала пойдём на Тяньаньмэнь, потом в Запретный город.

先吃饭，然后去机场。
  — Сначала поешь, потом в аэропорт.
```

### 注意

- 然后 — «потом», связывает два следующих действия.
- 最后 — «наконец, в конце», завершает цепочку действий.
- 然后 может встречаться несколько раз в длинной цепочке, а 最后 — только в конце.

## 10. 越…越… — «Чем…, тем…»

### Структура

```
越 + прил. / V + 越 + прил. / V
```

### Примеры

```
天气越来越热了。
  — Погода становится всё жарче и жарче.

长城越走越高。
  — Чем дальше идёшь по стене, тем она выше.

我越看越喜欢北京。
  — Чем больше я смотрю, тем больше люблю Пекин.

雨越下越大。
  — Дождь усиливается.
```

### Частые сочетания

| Сочетание | Перевод |
|---|---|
| 越来越好 | всё лучше и лучше |
| 越来越多 | всё больше и больше |
| 越来越快 | всё быстрее |
| 越来越冷 | всё холоднее |
| 越说越高兴 | чем больше говорит, тем радостнее |

## 11. 一…就… — «Как только…, сразу…»

### Структура

```
一 + V1 + 就 + V2
```

### Примеры

```
我一到北京就给你打电话。
  — Как только приеду в Пекин, сразу тебе позвоню.

他一上飞机就睡觉。
  — Стоит ему сесть в самолёт, он сразу засыпает.

我们一下车就去前台办理入住。
  — Как только мы вышли из машины, сразу пошли на стойку регистрации.

她一听到这个消息就哭了。
  — Как только она услышала эту новость, сразу заплакала.
```

### 注意

- Первое действие — короткое и первое по времени, второе — быстрый результат сразу после него.
- 一…就… подчёркивает тесную временную связь: второе действие происходит сразу же за первым.

## 12. 快要/就要/快…了 — «Скоро случится»

### Структура

```
就要 + V + 了          (возможно указание времени перед конструкцией)
快要/快 + V + 了       (без указания конкретного времени)
```

### Примеры

```
飞机快要起飞了。
  — Самолёт скоро взлетит.

火车快到了。
  — Поезд скоро прибудет.

我们就要出发了。
  — Мы вот-вот отправляемся.

他下个月就要回国了。
  — Он в следующем месяце поедет домой.

十二点了，现在就要吃午饭了。
  — Уже двенадцать, сейчас будем обедать.
```

### 注意

- 就要 допускает временное слово: 明天就要考试了。
- 快要/快 не употребляются с точным временем: ✗ 明天快考试了。
- Частица 了 в конце обязательна.

## 13. 还是 vs 或者 — «Или»

### Таблица

| Слово | Употребление | Пример |
|---|---|---|
| 还是 | вопрос с выбором | 你想喝茶还是咖啡？ |
| 或者 | утверждение, выбор из вариантов | 我们可以去长城或者故宫。 |

### Примеры

```
你坐飞机还是坐火车去上海？
  — Ты поедешь в Шанхай самолётом или поездом?

你想参观故宫还是去爬长城？
  — Ты хочешь осмотреть Запретный город или забраться на стену?

明天或者后天去都可以。
  — Пойдём завтра или послезавтра — подойдёт любой день.

我们坐地铁或者打车去都行。
  — На метро или такси — оба варианта подходят.
```

### 注意

- 还是 — только в вопросах с выбором.
- 或者 — в утвердительных предложениях, даёт варианты.
- Устойчивая конструкция «无论…还是…都…» — «независимо от того… или…»: 无论晴天还是下雨，他都去跑步。 — Неважно, солнце или дождь — он всё равно идёт бегать.

## 14. 从…到… — «От… до…»

### Структура

```
从 + начало + 到 + конец
```

Передаёт диапазон места, времени или количества.

### Примеры

```
从莫斯科到北京坐飞机大概九个小时。
  — От Москвы до Пекина на самолёте около девяти часов.

我们每天从早上八点旅游到晚上六点。
  — Мы гуляем каждый день с восьми утра до шести вечера.

从星期一到星期五我都上课。
  — С понедельника по пятницу у меня занятия.

这家店从九点营业到十一点。
  — Этот магазин работает с девяти до одиннадцати.
```

### Устойчивые выражения

| Сочетание | Перевод |
|---|---|
| 从早到晚 | с утра до вечера |
| 从古到今 | из древности до наших дней |
| 从这里到那里 | отсюда до туда |
| 从头到尾 | с начала до конца |

## 15. Путеводитель: полезные рамки для разговора о поездке

Часто используемые схемы для планирования путешествия:

| Схема | Пример | Перевод |
|---|---|---|
| 我想去…旅行 | 我想去北京旅行。 | Хочу поехать путешествовать в Пекин. |
| 我打算… | 我打算下个月出发。 | Планирую отправиться в следующем месяце. |
| 听说… | 听说颐和园很美。 | Говорят, Летний дворец красив. |
| 除了…以外，还… | 除了故宫以外，我还想去天坛。 | Кроме Запретного города, хочу ещё в Храм Неба. |
| 如果…就… | 如果有时间，我就多玩几天。 | Если будет время, задержусь на несколько дней. |
| 值得一去 | 颐和园值得一去。 | Летний дворец стоит посетить. |
| 有机会的话，… | 有机会的话，我想去西安。 | При случае хочу поехать в Сиань. |
| 帮我…一下 | 帮我订一下机票。 | Забронируй мне билет, пожалуйста. |
| 到了…就… | 到了北京就给你打电话。 | Приеду в Пекин — сразу позвоню. |
| 一路平安 | 祝你一路平安！ | Счастливого пути! |

### 注意

- Эти рамки — готовые скелеты: подставляйте свои слова.
- 值得一去 — «стоит посетить» — частый совет при рекомендациях.
- 帮我…一下 — вежливая просьба сделать что-то «немного / быстро».
