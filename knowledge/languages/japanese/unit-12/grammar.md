# Unit 12 — Грамматика: 敬語（三種類の敬語)

## 1. Три вида кэйго —— карта

| Вид | Направление | Пример «есть» |
|-----|-------------|----------------|
| 尊敬語（そんけいご) | возвышаю ДРУГОГО | 召し上がります |
| 謙譲語（けんじょうご) | принижаю СЕБЯ | いただきます |
| 丁寧語（ていねいご) | украшаю речь | 食べます |

## 2. 尊敬語: два механизма

**А. Спецслова (запомнить наизусть):**

| Обычный | Уважительный | Значение |
|---------|--------------|----------|
| いる・行く・来る | いらっしゃる | быть/приходить |
| 言う | おっしゃる | говорить |
| 食べる・飲む | 召し上がる | есть/пить |
| 見る | ご覧になる | смотреть |
| 知っている | ご存知だ | знать |
| する | なさる | делать |
| 寝る | お休みになる | спать |
| くれる | 下さる | давать мне |

**Б. Формула お／ご＋основа＋になる:**

```
書く → お書きになります。（Вы пишете)
待つ → お待ちになります。
```

⚠️ Исключения：おっしゃる・いらっしゃる・なさる・下さる・いらっしゃいます（не ～られる!):
❌ いらっしゃられる → ✅ いらっしゃいます

## 3. 謙譲語: два механизма

**А. Спецслова:**

| Обычный | Скромный | Значение |
|---------|----------|----------|
| 行く・来る | 参る（まいる) | идти/приходить |
| する | 致す（いたします) | делать |
| 言う | 申す（もうす) / 申し上げる | говорить |
| 食べる・もらう | いただく | есть/получать |
| 見る | 拝見する（はいけん) | смотреть |
| 会う | お目にかかる | встречать |
| 知っている | 存じ上げる / 存じます | знать |

**Б. Формула お／ご＋основа＋する／いたす:**

```
案内する → ご案内いたします。（я вас провожу)
電話する → お電話いたします。
```

## 4. 丁寧語: お／ご-украшения

Исконные слова + お, китайские заимствования + ご:

```
お金 · お茶 · お名前（исконные)
ご飯 · ご意見 · ご連絡（китайские)
```

⚠️ Исключения на -о：お電話、お勉強（китайские с о).

## 5. Просьбы сверхвежливые

| Форма | Уровень |
|-------|---------|
| ～てください | стандарт |
| ～てもらえますか | мягко |
| ～ていただけますか | вежливо |
| ～ていただけませんでしょうか | максимум |

Ответ клиента на вашу услугу часто「どうも」—— вам отвечают「いえ、とんでもございません」.

## 6. ～ております = ています（скромно)

В сервисе о себе говорите через おります:

```
店長は今、会議中でおります。？ нет—— это про 店長 уважительно：
店長はただいま会議中でございます。
私は山田の部下でございます。
```

## 7. Типичные ошибки

❌ 社長が申しました。→ ✅ 社長が**おっしゃいました**。（申す —— только о себе!)
❌ 私が召し上がります。→ ✅ 私が**いただきます**。
❌ 先生に伺いましたか？（спрашиваете у друга об учителе) → ✅ 先生に**聞きました**か。（伺う только если вы сами шли к учителю)

> 💡 **Главное правило направления:** кэйго «течёт» вверх по социальной лестнице. Уважительное —— к собеседнику/третьему лицу выше вас; скромное —— к своим действиям.
