# Unit 12 — Чтение: お客様は神様ですか？（Клиент всегда прав?)

## Текст

```
　　サービス業と敬語

「お客様は神様です」という言葉がありますが、
最近ではこの考えを見直す企業も増えています。

確かに、丁寧な敬語を使い、笑顔で接することは
サービスの基本です。しかし、客だからといって、
店員を不当に怒鳴ったり、侮辱したりする権利が
あるわけではありません。

あるカフェでは、「クレーマー対応マニュアル」を作り、
店員が不当な扱いを受けた場合、すぐに店長を
呼ぶルールを決めました。

敬語は道具です。相手を尊重するために使うもので、
自分を踏みつけられるためのものではありません。
正しい敬語と正しい心構え、両方を持ちましょう。
```

## Вопросы к тексту

1. Какие предприятия пересматривают принцип «клиент — бог»?
2. Что является базой сервиса по тексту?
3. Что сделало одно кафе для защиты сотрудников?
4. Как автор называет кэйго?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 見直す | みなおす | пересматривать |
| 接する | せっする | обращаться с кем-то |
| 不当に | ふとうに | несправедливо |
| 怒鳴る | どなる | кричать |
| 侮辱する | ぶじょくする | оскорблять |
| 権利 | けんり | право |
| クレーマー | — | вечный жалобщик |
| 対応 | たいおう | реагирование |
| 心構え | こころがまえ | внутренняя установка |

## Разбор грамматики в тексте

**見直す企業も増えています**
→ относительное предложение перед существительным.

**〜からといって〜わけではない**
→ «из того, что…, ещё не следует»: 客だからといって＝даже если это клиент.

**不当な扱いを受けた場合**
→ 場合 «в случае» + пассив受ける.

**踏みつけられるためのものではない**
→ пассив неудобства + のだ-номинализация: кэйго существует НЕ для того, чтобы вас топтали.
