# Unit 6 — Грамматика: Форма ている, приглашения, ておく

## 1. Форма 〜ている («делаю сейчас» / «находится в состоянии»)

Образуется: **тэ-форма + いる**. В разговоре いる сокращается до る.

**Два значения:**

1) Действие происходит прямо сейчас:
```
今、雨が降っています。     — Сейчас идёт дождь.
彼は本を読んでいます。     — Он (сейчас) читает книгу.
```

2) Состояние после действия (результат сохраняется):
```
結婚しています。           — Я женат/замужем (и до сих пор).
田中さんを知っています。   — Я знаю Танаку.
ドアが開いています。       — Дверь открыта (кто-то открыл, и она открыта).
```

> ⚠️ 「行っています」не значит «иду» в момент речи! 行く → 行っている = «уехал и находится там».

## 2. 〜ているところです («как раз сейчас»)

Подчёркивает, что действие в самый разгар:
```
ちょうど昼ご飯を食べているところです。 — Как раз обедаю.
```

## 3. Приглашение: 〜ませんか и 〜ましょう

| Форма | Оттенок | Пример |
|-------|---------|--------|
| 〜ませんか | мягкое приглашение «не хотите ли...?» | 映画を見ませんか。(Не посмотреть ли фильм?) |
| 〜ましょう | «давайте...» (решение принято) | じゃ、行きましょう。(Ну, пойдёмте.) |
| 〜ましょうか | «давайте я помогу / сделаем?» | 手伝いましょうか。(Помочь вам?) |

Ответ на приглашение:
```
ええ、ぜひ。         — Да, с удовольствием.
すみません、ちょっと… — Извините, как-то неловко... (мягкий отказ)
```

## 4. 〜ておる → 〜ておく («сделать заранее, впрок»)

Тэ-форма + おく: действие выполняется заранее ради будущего.
```
チケットを買っておきます。     — Куплю билеты заранее.
宿題をしておきました。        — Я сделал домашку заранее.
お弁当を作っておいたほうがいい。— Лучше приготовить бэнто заранее.
```

## 5. Условие с なら («если уж речь о...»)

Тема + なら выделяет вариант из разговора:
```
A: 十時は早いなあ。
B: 十一時なら大丈夫です。 — Если (речь о) 11, то нормально.
```

## 6. 〜そうです (по слухам)

Основа прилагательного/глагола + そうです: «говорят, что...»
```
予報では晴れるそうです。     — По прогнозу, будет ясно (так говорят).
田中さんは来ないそうです。   — Говорят, Танака не придёт.
```
Не путать с 美味しそうです («выглядит вкусно») — там другой механизм присоединения.

## 7. Сравните три формы

| Форма | Значение | Пример |
|-------|----------|--------|
| ドアを開ける | открыть дверь (действие) | ドアを開けてください。 |
| ドアが開いている | дверь открыта (состояние) | ドアが開いていますよ。 |
| ドアを開けておく | открыть заранее (впрок) | 風通しのためドアを開けておく。 |

---

## 8. 〜ておく: расширенный разбор

Тэ-форма + おく — «сделать сейчас, чтобы потом было хорошо».

**Три типичных сценария:**

1) Подготовка к будущему событию:
```
明日の会議の資料を作っておきます。
Подготовлю материалы к завтрашней встрече.
```

2) Действие «впрок», чтобы потом не думать:
```
水を沸かしておいて。
Вскипяти воду заранее (чтобы была готова).
```

3) Устранение проблемы на будущее:
```
この書類はコピーしておいたほうがいい。
Эти документы лучше отксерить заранее.
```

**Отрицание:** 〜ておかない / 〜ないでおく:
```
今日は洗濯しないでおこう。
Сегодня не буду стирать (отложу).
```

**Прошедшее:** 〜ておいた:
```
レストランを予約しておきました。
Я заранее забронировал ресторан.
```
> Разговорное сокращение: 〜とく — 買っといた（かっといた）＝ купил заранее.

## 9. Приглашения и предложения: полная лестница

| Форма | Вежливость | Оттенок | Пример |
|-------|------------|---------|--------|
| 行こう | друзья | «пойдёмте!» | じゃ、行こう！ |
| 行きましょう | стандарт | «давайте пойдём» | 一緒に行きましょう。 |
| 行きませんか | стандарт+ | мягкое приглашение | 映画を見ませんか。 |
| 行きましょうか | стандарт+ | «может, сходим?» + предложение помощи | 手伝いましょうか。 |
| 行ったらどうですか | совет | «может, сходить?» | 医者に行ったらどうですか。 |
| 行きませんでしょうか | очень вежливо | деловое приглашение | ご一緒しませんでしょうか。 |

**Ответы на приглашение:**

| Ответ | Значение |
|-------|----------|
| ええ、ぜひ。 | Да, непременно! |
| いいですね、行きましょう。 | Отлично, пойдём. |
| すみません、ちょっと… | Извините, как-то неловко... (отказ) |
| また誘ってください。 | Пригласите ещё раз (мягкий отказ). |

## 10. 〜つもり и 〜予定 — планы

### 〜つもりだ（намерение）
Словарная форма / най-форма + つもり:
```
週末は家でゆっくりするつもりです。
На выходных собираюсь отдохнуть дома.
```
```
誰にも言わないつもりだった。
Не собирался никому говорить.
```

### 〜予定だ（расписание, план по факту）
Существительное の / словарная форма + 予定:
```
来月、大阪へ出張する予定です。
В следующем месяце планирую командировку в Осаку.
```
```
三時に着く予定でしたが、遅れました。
Должен был приехать в три, но опоздал.
```
> **Разница:** つもり — моё желание; 予定 — план/расписание (моё или чужое).

## 11. までに vs まで — «к сроку» vs «до момента»

| Частица | Значение | Пример |
|---------|----------|--------|
| まで | действие длится ДО точки | 夜中まで勉強した。Учился до полуночи. |
| までに | произойдёт НЕ ПОЗЖЕ точки | 六時までに帰ります。Вернусь к шести. |

```
金曜日までにレポートを出してください。
Сдайте отчёт не позднее пятницы.
```
> **Ловушка:** 「六時まで待ちます」= буду ждать до шести; 「六時までに着く」= приеду к шести.

---

## 12. 〜かどうか — «или нет»

Прямой вопрос внутри сложного предложения:
```
田中さんが来るかどうか、まだ分かりません。
Ещё не знаю, придёт ли Танака.
```
```
おいしいかどうか食べてみましょう。
Попробуем — вкусно или нет.
```
Вопросительное слово сохраняет частицу か:
```
どこに住んでいるか教えてください。
Скажите, где вы живёте.
```

## 14. Частые ошибки юнита

❌ **今、宿題をする。** → ✅ 今、宿題をして（い）ます。
Сейчас делаю домашку — прогресс требует ている.

❌ **結婚していますか？— いいえ、結婚していませんでした。**
→ ✅ …結婚していません。
Состояние в вопросе «женаты?» живёт в настоящем.

❌ **十時まで会いませんか。** → ✅ 十時に会いませんか。
«Не встретиться в 10?» — точка встречи берётся に, не まで.

❌ **チケットを買っておきてください。**
→ ✅ 買っておいてください。
После тэ-формы всегда て, никогда おきて.

❌ **雨が降りそうですね。— はい、降るそうです。**
Путаница видов そう: прогноз = слухи → 降るそうです ✓.

## 16. 〜てある («оставленное состояние с целью»)

Тэ-форма + ある: действие **кто-то выполнил специально**, и результат сохраняется намеренно. В отличие от 〜ている, 〜てある подчёркивает, что состояние было создано **нарочно** для какой-то цели.

```
ドアが開けてあります。      — Дверь открыта (специально открыли).
壁に写真が飾ってあります。  — Фотографии повешены на стену (нарочно).
```
> ⚠️ Обратите внимание: в 〜てある объект оформляется частицей **が**, а не を.

**Сравнение** | ている | てある | ておく
---|---|---|---
Значение | просто состояние / прогрес | состояние, созданное намеренно | действие «впрок, заранее»
Субъект есть? | есть (動作主) | нет (фокус на результате) | есть

```
ドアが開いています。      — Дверь просто открыта.
ドアが開けてあります。     — Дверь открыта (кто-то открыл специально).
ドアを開けておきました。   — Я открыл дверь заранее (действие).
```

## 17. 〜ために и 〜ように — «для того чтобы»

Обе конструкции переводятся «чтобы», но различаются по контролю результата.

**〜ために** (намеренное действие, цель прямо под контролем):
```
日本語を勉強するために、毎日練習します。
Чтобы учить японский, тренируюсь каждый день.
```
Между ために можно вставить の: 勉強のために、本を買いました。

**〜ように** (цель, результат **не** в нашем контроле — привычки, состояния):
```
聞こえるように、大きな声で話してください。
Говорите громко, чтобы было слышно.
```
**Запомнить:** перед ように часто стоит отрицание или непереходный глагол / потенциальная форма.

| Суффикс | Когда |
|---------|-------|
| 〜ために | цель достижима усилием, субъект действует напрямую |
| 〜ように | желательное условие, привычка, результат не контролируется |

## 18. 〜前（に） и 〜後（で） — «до» и «после»

**〜前に** — словарная форма глагола + 前に «перед тем как»:
```
食事の前に手を洗います。    — Мою руки перед едой.
寝る前に本を読みます。      — Читаю книгу перед сном.
```

**〜後で** — та-форма + 後で «после того как»:
```
宿題をした後で、遊びます。  — Поиграю после того, как сделаю уроки.
仕事の後で、飲みに行きます。— Пойду выпить после работы.
```
> 💡 С существительными: 午前の前に / 会議の後で — всё по тому же принципу (の前に / の後で).

---

## 19. 〜たり〜たりする — «то… то…»

Перечисление действий/состояний как *примеров*. Последний глагол ставим в основную форму.

```
週末は映画を見たり、買い物をしたりします。
На выходных то фильмы смотрю, то по магазинам хожу (и т.п.).
```
```
忙しかったり、暇だったりします。
Бывает то занят, то свободен.
```

---

## 20. 〜んです／〜のです — «дело в том, что…»

Форма объяснения: добавляет причину, контекст или оправдание. Очень частотна в телефонных разговорах.

```
A: どうして遅れたんですか。         — Почему опоздали?
B: 電車が遅れたんです。             — Дело в том, что поезд опоздал.
```
```
明日は行けないんです。休みの約束があるんです。
Завтра не смогу — у меня уже есть договорённость об отпуске.
```
Образование:
- な-прилагательное / существительное + なんです
- い-прилагательное / глагол + んです

---

## 21. 〜ことにする и 〜ことになる — «решить/договориться»

**〜ことにする** — своё личное решение:
```
明日からダイエットすることにしました。
Решил сесть на диету с завтрашнего дня.
```

**〜ことになる** — решение внешнее, договорённость, так сложилось:
```
来月、大阪に出張することになりました。
Так вышло, что в следующем месяце еду в командировку в Осаку.
```
Пару часто путают. Ключ: **にする = я решаю; になる = решило что-то внешнее / по договорённости**.

## 22. Одно-словные отглагольные существительные

В деловых договорённостях по телефону часто используют отглагольные существительные с する. Запомните основные пары.

| Существительное | Чтение | Перевод |
|-----------------|--------|---------|
| 連絡 | れんらく | связь, сообщение |
| 確認 | かくにん | подтверждение |
| 予約 | よやく | бронь |
| 変更 | へんこう | изменение |
| 延期 | えんき | перенос |
| 中止 | ちゅうし | отмена |

Примеры с する:
```
予約を確認**して**ください。      — Проверьте бронь.
会議を延期**しました**。          — Совещание перенесли.
また連絡**します**。              — Свяжусь ещё раз.
```

## 24. Типичные фразы делового звонка (грамматика на практике)

Когда звоните в офис или договариваетесь о встрече, эти готовые конструкции работают без ошибок:

```
お世話になっております。〜と申します。        — Спасибо за внимание, меня зовут ~.
お手数ですが、伝言をお願いできますか。        — Простите за беспокойство, передадите сообщение?
承知しました。少々お待ちください。            — Принято, подождите минутку.
折り返し、お電話いたします。                  — Я вам перезвоню.
また後で連絡します。                          — Свяжусь позже.
```
> Обратите внимание на 申します (思う/言う → скромная форма) и いたします (する → скромная форма). Это кэндо:го в самом простом виде — подробнее в Unit 12.
