## Мнемотехники (по Heisig)

| Кандзи | Разбор | Запоминалка |
|--------|--------|-------------|
| 元 (хадзимэ) | 二(два)+儿(ноги) | Два человека — начало |
| 天 (тэн) | 一+大 | Единица + большой = небо |
| 空 (сора) | 穴+工 | Пещера + работа = небо |
| 休 (ясуму) | 人+木 | Человек у дерева = отдых |
| 好 (суки) | 女+子 | Женщина + ребёнок = нравится |
| 男 (отоко) | 田+力 | Поле + сила = мужчина |
| 安 (ясуй) | 宀+女 | Крыша + женщина = дёшево/спокойно |
| 家 (иэ) | 宀+豕 | Крыша + свинья = дом |
| 楽 (раку) | 白+木 | Белый + дерево = легко/музыка |
| 道 (мити) | 首+辶 | Голова + идти = дорога |
| 聞 (кику) | 門+耳 | Ворота + ухо = слушать |
| 話 (ханасу) | 言+舌 | Слово + язык = говорить |
| 読 (ёму) | 言+売 | Слово + продавать = читать |
| 書 (каку) | 聿+曰 | Кисть + говорить = писать |
| 教 (осиэру) | 孝+攵 | Почтительность + рука = учить |
