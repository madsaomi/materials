# Тренажёр чтения: хирагана и катакана (かなドリル)

> **Цель:** довести чтение обеих азбук до автоматизма за 2–3 недели. Это практикум: минимум теории, максимум дриллов.
>
> **Как пользоваться:**
> 1. Читайте вслух — молча кана не закрепляется
> 2. Сначала закройте ответы (они под спойлерами)
> 3. Норма: 15 минут в день, один блок за подход
> 4. Вернитесь к каждому блоку через день, затем через неделю
>
> **Легенда транскрипции:** латиница = Хэпбёрн (стандарт для учебников), русская строка — для самопроверки произношения.
>
> Связанные материалы: [Теория письменности](index.md) · [Учебник](../textbook.md) · [Компендиум кандзи](../kanji/compendium-n5-n4.md)

## 2. Дакутэн（゛）и хандакутэн（゜）

Две чёрточки озвончают согласную: か→が, さ→ざ, た→だ, は→ば. Кружочек только у ряда は: は→ぱ.

| Ряд | Знаки | Слово | Чтение | Перевод |
|-----|-------|-------|--------|---------|
| が行 | がぎぐげご | がっこう | gakkou | школа |
| ざ行 | ざじずぜぞ | ざっし | zasshi | журнал |
| だ行 | だぢづでど | でんしゃ | densha | поезд |
| ば行 | ばびぶべぼ | おべんとう | obentou | бэнто |
| ぱ行 | ぱぴぷぺぽ | えんぴつ | enpitsu | карандаш |

**⚠️ Внимание:** じ = «дзи», ぢ = «дзи» (редко), ず = «дзу».

**Дрилл А — прочитайте:**

```
ぎんこう  ごはん    げんき
じかん    ぜんぶ    そこ
だいたい  でぐち    どこ
ばんごはん びょういん ぶどう
ぱん      ぴあの    プール→ぷーる
```

<details>
<summary>Ответы</summary>

ginkou (банк) · gohan (рис/еда) · genki (бодрый)
jikan (время) · zenbu (всё) · soko (там)
daitai (примерно) · deguchi (выход) · doko (где)
bangohan (ужин) · byouin (больница) · budou (виноград)
pan (хлеб) · piano · puuru (бассейн)

</details>

**Дрилл Б — минимальные пары (различайте на слух!):**

```
かさ / がさ     てんき / でんき    はし / はし(橋/箸)
さかな / ざかな  とき / どき       ふたつ / ぶたつ✗
```

<details>
<summary>Ответы</summary>

kasa (зонт) / gasa (повязка) · tenki (погода) / denki (электричество)
hashi (палочки) / hashi (мост) — различаются интонацией!
sakana (рыба) / zakanа (жареная рыба) · toki (время) / doki (время, разговорн.)

</details>

Маленький знак слитно с предыдущим: きゃ = «кя» (один слог!).

| Сочетание | Romaji | Слово | Перевод |
|-----------|--------|-------|---------|
| きゃ・きゅ・きょ | kya kyu kyo | きょう | kyō — сегодня |
| しゃ・しゅ・しょ | sha shu sho | しゃしん | shashin — фото |
| ちゃ・ちゅ・ちょ | cha chu cho | おちゃ | ocha — чай |
| にゃ・にゅ・にょ | nya nyu nyo | にゃんこ | nyanko — котик |
| ひゃ・ひゅ・ひょ | hya hyu hyo | ひゃく | hyaku — сто |
| みゃ・みゅ・みょ | mya myu myo | みらい | mirai — будущее |
| りゃ・りゅ・りょ | rya ryu ryo | りょうり | ryōri — готовка |

**Дрилл А — прочитайте:**

```
きょう    しゅくだい  ちゃいろ
じゅぎょう でんしゃ   おちゃ
ひゃく    しょくどう  ちゅうがっこう
りゅがく（留学）      きゃく（客）
```

<details>
<summary>Ответы</summary>

kyou (сегодня) · shukudai (домашка) · chairo (коричневый)
jugyou (урок) · densha (поезд) · ocha (чай)
hyaku (сто) · shokudou (столовая) · chuugakkou (средняя школа)
ryuugaku (учёба за границей) · kyaku (гость)

</details>

**Дрилл Б — большие vs маленькие (не путайте!):**

```
よく（часто） vs よこ（бок）
じゃ（ну）    vs じや ✗
ちゃいろ vs ちはいろ ✗
```

## 4. Сокуон っ и долгие гласные

### 4.1 Сокуон — удвоение согласной

Маленькая つ пауза перед следующим звуком: きって = kit-te (пауза между т и т).

| Слово | Чтение | Перевод | Без っ |
|-------|--------|---------|--------|
| がっこう | ga-k-kou | школа | がこう ✗ |
| きって | ki-t-te | марка | きて（着て）— другое слово! |
| きっぷ | ki-p-pu | билет | きふ ✗ |
| ざっし | za-s-shi | журнал | ざし ✗ |
| ちょっと | cho-t-to | немного | ちよと ✗ |
| もってくる | mo-t-te kuru | приносить | もてくる ✗ |

**Дрилл — прочитайте, держите паузу:**

```
けっこう  ざっぱん  きって  はっぴょう
しっぱい  かった    いっぱい ろっぷん
```

<details>
<summary>Ответы</summary>

kekkou (отлично) · zabuton (подушка для сиденья) · kitte (марка) · happyou (доклад)
shippai (провал) · katta (купил) · ippai (полный/много) · roppun (шесть минут)

</details>

### 4.2 Долгие гласные — разница в смысл!

В хирагане долгота пишется:
- после а-ряда → あ: おかあさん (okaasan — мама)
- после и/э-ряда → い: おにいさん (oniisan — старший брат), せんせい
- после у/о-ряда → う: くうこう (kuukou — аэропорт), おはよう

| Короткое | Длинное | Разница |
|----------|---------|---------|
| おばさん тётя | おばあさん бабушка | ! |
| ゆき снег | ゆうき смелость | ! |
| ここ здесь | こうこう старшая школа | ! |
| とり птица | とおり улица | ! |
| くろ чёрный | くろう трудности | ! |

**Дрилл — прочитайте, растягивайте гласные:**

```
がくせい  せんせい  とうきょう  くうこう
おねえさん おおきい  じゅういち  れい
```

<details>
<summary>Ответы</summary>

gakusei (студент) · sensei (учитель) · Toukyou (Токио!) · kuukou (аэропорт)
oneesan (старшая сестра) · ookii (большой) · juuichi (одиннадцать) · rei (ноль)

</details>

## 11. Практика письма

### 11.1 Правила прописей

1. **Клетка генкоёси (原稿用紙):** каждый знак занимает один квадрат, пишите крупно
2. **Порядок черт:** сверху вниз → слева направо; горизонталь перед вертикалью
3. **Норма:** каждый новый знак ×10 строк по 5 знаков = 50 повторений за день
4. **Проверка:** напишите ряд наизусть, сравните с распечаткой таблицы
