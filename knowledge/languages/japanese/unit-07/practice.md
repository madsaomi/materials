# Unit 7 — Workbook: 可能形 и ことができる

> 💡 Делайте письменно и вслух. Формы 可能形 должны стать рефлексом: увидел глагол → мгновенно образовал потенциал.

---

## I. Лексика — навыки и хобби

**A. Соедините:**

1. 得意 ___ a) слабое место
2. 苦手 ___ b) сильная сторона
3. 習う ___ c) тренироваться
4. 練習する ___ d) учиться (у кого-то)
5. 楽器 ___ e) музыкальный инструмент

**B. Заполните:**

`水泳 / 自転車 / 楽器 / 得意 / 苦手 / 習う`

1. ＿＿＿ ができますか。
2. ＿＿＿ に乗れますか。
3. 何か ＿＿＿ が弾けますか。
4. 数学が ＿＿＿ です。
5. ピアノを十年 ＿＿＿ ました。

## II. 可能形 — образование

**A. Образуйте потенциальную форму:**

| Словарная | Потенциал |  | Словарная | Потенциал |
|-----------|-----------|--|-----------|-----------|
| 書く | ＿＿＿ | | 食べる | ＿＿＿ |
| 読む | ＿＿＿ | | 見る | ＿＿＿ |
| 話す | ＿＿＿ | | 起きる | ＿＿＿ |
| 泳ぐ | ＿＿＿ | | する | ＿＿＿ |
| 買う | ＿＿＿ | | 来る | ＿＿＿ |
| 待つ | ＿＿＿ | | 借りる | ＿＿＿ |

**B. Исправьте ошибки (частица + форма):**

1. 私は日本語**を**話せます。 → ＿＿＿
2. 水泳**を**ことができます。 → ＿＿＿
3. 富士山**を**見えます。 → ＿＿＿
4. ピアノ**が弾くこと**ができます。 → ＿＿＿

**C. Переведите с потенциалом:**

1. Я умею плавать. → ＿＿＿
2. Здесь можно фотографировать? → ＿＿＿ (撮る)
3. Я немного говорю по-японски. → ＿＿＿

---

## III. 見える / 聞こえる vs 見られる / 聞ける

**A. Выберите верно:**

1. 二階から海が ＿＿＿。 (видно без усилия → 見える)
2. 日曜日なら映画が ＿＿＿。 (есть возможность → 見られる)
3. 隣の部屋から音楽が ＿＿＿。 (слышно → 聞こえる)
4. ラジオで音楽が ＿＿＿。 (могу послушать → 聞ける)

**B. Составьте предложения:**

1. 富士山が見えます！→ ＿＿＿ (переведите: Видна Фудзи!)
2. 生の音楽が聞ける。→ ＿＿＿ (Можно услышать живую музыку)

---

## IV. ことができる и желание

**A. Перефразируйте (可能形 ↔ ことができる):**

1. ギターが弾けます。 → ギターを ＿＿＿ ことができます。
2. 日本語を話すことができます。 → 日本語が ＿＿＿。

**B. Напишите о желании (〜たい):**

1. Хочу научиться водить. → ＿＿＿
2. Хочу играть на гитаре. → ＿＿＿

## VIII. みえる / きこえる — выберите слово

**A. Вставьте 見える / 見られる / 聞こえる / 聞ける:**

**B. Исправьте или поясните разницу:**

## XII. Диалог — вставьте пропущенное

```
アリス：田中さんは料理ができますか。
田中：ええ、簡単なもの＿＿＿（1）作れますよ。
アリス：どんな料理が＿＿＿（2）ですか。
田中：カレーと天ぷらです。でも、アリスさんのほうが上手そうですね。
アリス：私はプロの料理人になりたいから、毎日練習＿＿＿（3）います。
田中：すごい！魚もさばけますか。
アリス：はい、魚を＿＿＿（4）ことができます。
田中：じゃあ、今度＿＿＿（5）食べたいです。
```

**XII:**
1. なら (簡単なものなら) — «что касается простого»
2. 作れる (どんな料理が作れる)
3. して (練習しています)
4. さばく (魚をさばくことができます)
5. 食べ (今度食べたいです) — на самом деле: 食べたい（×）правильно 食べてみたい (хочу попробовать)

> 💡 **Примечание XII:** правильный вариант пункта 5 — 「今度食べてみたいです」= «хочу как-нибудь попробовать». 食べたい просто означает «хочу есть».
