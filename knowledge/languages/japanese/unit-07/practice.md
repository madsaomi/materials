# Unit 7 — Практика: Потенциальная форма

## 1. Образуйте потенциальную форму

1. 書く → ＿＿＿＿
2. 読む → ＿＿＿＿
3. 食べる → ＿＿＿＿
4. 来る → ＿＿＿＿
5. する → ＿＿＿＿
6. 話す → ＿＿＿＿
7. 会う → ＿＿＿＿
8. 見る → ＿＿＿＿

## 2. Исправьте ошибки

1. 私は日本語を話せます。
2. 水泳をことができます。
3. 富士山を見えます。
4. ピアノが弾くができます。

## 3. Ответьте о себе

Полными предложениями:

1. 何ができますか。(три вещи)
2. 苦手なことは何ですか。
3. 子供の時、何ができましたか。
4. 今、何を習いたいですか。

## 4. Переведите

На японский:
1. Я умею плавать, но не умею ездить на велосипеде.
2. Можно ли здесь фотографировать? *(撮る)*
3. Я хочу научиться играть на гитаре.
4. Слышно музыку.

## 5. Интервью

Задайте партнёру вопросы (можно себе):

1. スポーツができますか。何ができますか。
2. 楽器が弾けますか。
3. 外国語が話せますか。
4. 料理を作ることができますか。得意な料理は？
