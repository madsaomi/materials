# Unit 7 — Диалог: できること話 (Разговор об умениях)

## Ситуация

Алиса и Танака обсуждают, что они умеют делать. Речь заходит о спорте, музыке и языках. Отрабатывается потенциальная форма (可能形) и конструкция ことができる.

## Диалог

```
アリス：田中さんはスポーツができますか。
田中：うん、水泳ができるよ。アリスさんは？
アリス：私は泳げません。でも、自転車に乗れます。
田中：すごい！僕は自転車に乗れないんだ。
アリス：ええ？本当ですか。子供の時、乗らなかったの？
田中：うん、怖くてね。それで、走るのは得意だよ。
アリス：音楽はどうですか。何か楽器が弾けますか。
田中：ギターが少し弾ける。アリスさんは？
アリス：ピアノを弾くことができます。十年習いました。
田中：十年！それは上手ですね。
アリス：いいえ、まだまだです。あ、そうだ。日本語が少し話せるようになりました。
田中：本当に？どんどん上手になってるね。頑張ってるんだね。
アリス：ありがとう。毎日三十分钟ずつ勉強していますから。
```

## Перевод

| Японский | Русский |
|----------|---------|
| スポーツができる | уметь заниматься спортом |
| 水泳ができる | уметь плавать |
| 泳げません | не умею плавать |
| 自転車に乗れる | уметь ездить на велосипеде |
| 子供の時 | в детстве |
| 怖くて | страшно, поэтому... |
| 走るのが得意 | хорошо бегаю |
| 楽器が弾ける | уметь играть на инструменте |
| ピアノを弾くことができる | мочь играть на пианино |
| 十年習いました | занималась десять лет |
| まだまだです | мне ещё далеко до... (скромность) |
| 話せるようになりました | научился(лась) говорить |
| どんどん上手になってる | становишься всё лучше и лучше |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 水泳 | すいえい | плавание |
| 自転車 | じてんしゃ | велосипед |
| 子供 | こども | ребёнок |
| 怖い | こわい | страшный |
| 得意 | とくい | сильная сторона |
| 楽器 | がっき | музыкальный инструмент |
| 習う | ならう | учиться (у кого-то) |
| 上手 | じょうず | умелый |
| 頑張る | がんばる | стараться |

## Культурная заметка

**«まだまだです»** — типичный японский ответ на комплимент. Даже если вы отлично играете на пианино десять лет, вежливо ответить «нет-нет, я ещё только учусь». Хвастовство в японской культуре не принято. Аналогично работает «いいえ、とんでもない» («что вы!»).

**得意／苦手 (とくい／にがて)** — важная пара слов: «сильная сторона» и «слабое место». Японцы часто спрашивают 「苦手なものは？」— вопрос не про ненависть, а про то, что плохо получается: еда, спорт, предмет.

# Диалог 2 — 料理の腕前 (Кулинарные способности)

## Ситуация

Мария и Сато готовят ужин. Мария хвастается своими кулинарными навыками, Сато скромничает. Отрабатываются 料理ができる, 〜方（かた）и 〜やすい／〜にくい.

## Диалог

```
マリア：サトウさん、料理はできますか。
佐藤：うーん、簡単なものなら作れますよ。
マリア：何が一番得意ですか。
佐藤：カレーかな。でもマリアさんは上手そうですね。
マリア：私はプロの料理人になりたいから、毎日練習しています。
佐藤：すごいですね！どんな料理が作れますか。
マリア：お寿司や天ぷらが作れます。特に魚の切り方が上手です。
佐藤：切り方？魚をさばけるんですか。
マリア：はい、魚をさばくことができます。三年間、寿司屋で修行しました。
佐藤：驚きました。じゃあ、今日の夕食は任せてもいいですか。
マリア：もちろん！包丁の使い方を見せながら料理しますよ。
佐藤：楽しみです。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 簡単なものなら | если что-то простое |
| 作れます | могу приготовить |
| 一番得意 | самое сильное место |
| プロの料理人 | профессиональный повар |
| 毎日練習しています | тренируюсь каждый день |
| 魚をさばく | разделывать рыбу |
| さばける | уметь разделывать |
| 寿司屋で修行した | стажировался в суши-ресторане |
| 任せてもいいですか | можно доверить? |
| 包丁の使い方 | способ использования ножа |
| 見せながら | показывая (одновременно) |
| 楽しみです | жду с нетерпением |

## Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| カレー | — | карри |
| 天ぷら | — | тэмпура |
| 切り方 | きりかた | способ нарезки |
| さばく | — | разделывать (рыбу) |
| 修行する | しゅぎょうする | стажироваться, учиться |
| 包丁 | ほうちょう | кухонный нож |
| 使い方 | つかいかた | способ использования |
| 任せる | まかせる | доверять, поручать |
| 驚く | おどろく | удивляться |
| 楽しみ | たのしみ | предвкушение, радость |

## Разбор ключевых конструкций

| Конструкция | Пример | Значение |
|-------------|--------|----------|
| 〜なら | 簡単なものなら | если речь о... (топик) |
| 可能形 | 作れます / さばける | умею делать |
| 切り方 | 切り方が上手 | способ нарезки (〜方) |
| 見せながら | 見せながら料理する | готовя и показывая (〜ながら) |
| に (+место работы) | 寿司屋で修行 | в суши-ресторане (で) |
| 任せてもいい | 任せてもいいですか | можно доверить? |

> **Нюанс:** 〜なら в ответе маркирует тему и переводится «что касается...». 「簡単なものなら作れます」= «если дело касается простого, то приготовлю».

# Диалог 3 — 頼みごと (Просьба: «можешь помочь?»)

## Ситуация

Юки просит Такэру помочь перевезти мебель. Такэру оценивает, что может и не может сделать. Отрабатываются 〜てもらえる, 可能形 в просьбах и 難しい／できない.

## Диалог

```
ゆき：タケル君、ちょっと手伝ってもらえますか。
タケル：いいよ、何をするの？
ゆき：新しい机を部屋に運びたいんだけど、一人では運べないの。
タケル：机か。何キロぐらいなの？
ゆき：三十キロぐらいかな。
タケル：三十キロなら一人でも持てるよ。でも玄関の階段が狭いから気をつけて。
ゆき：ありがとう。じゃあ、お願いしてもいい？
タケル：うん、任せて。あ、でもテーブルも運ぶなら、二人で持ち上げないと無理だよ。
ゆき：そうだね。じゃあ、二人で持ち上げよう。
タケル：よし。重いものほど二人で協力したほうが安全だからね。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 手伝ってもらえる | (ты) можешь мне помочь? |
| 何をするの | что делать? |
| 運びたいんだけど | хочу перенести, но... |
| 一人では運べない | в одиночку не нести |
| 何キロぐらい | примерно сколько килограмм |
| 一人でも持てる | и один подниму |
| 階段が狭い | лестница узкая |
| 気をつけて | будь осторожен |
| お願いしてもいい | можно попросить? |
| 任せて | положись на меня |
| 持ち上げないと無理 | если не поднимем вдвоём, никак |
| 持ち上げよう | давай поднимем вдвоём |
| 協力したほうが安全 | безопаснее помогать вместе |

## Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 手伝う | てつだう | помогать |
| 机 | つくえ | письменный стол |
| 運ぶ | はこぶ | переносить |
| 玄関 | げんかん | прихожая, вход |
| 階段 | かいだん | лестница |
| 狭い | せまい | узкий |
| 持ち上げる | もちあげる | поднимать |
| 重い | おもい | тяжёлый |
| 協力する | きょうりょくする | сотрудничать |
| 安全 | あんぜん | безопасность |

## Разбор ключевых конструкций

| Конструкция | Пример | Значение |
|-------------|--------|----------|
| 〜てもらえる | 手伝ってもらえますか | можешь мне помочь? (вежливая просьба) |
| 可能形 | 運べない / 持てる | мочь перенести / поднять |
| だけど | 運びたいんだけど | ...но (мягкое объяснение) |
| 〜ないと無理 | 持ち上げないと無理 | без X никак |
| 〜ほうが安全 | 協力したほうが安全 | безопаснее (рекомендация) |
| 〜よう | 持ち上げよう | давай поднимем (волеизъявление) |

> **Нюанс:** 〜てもらえる — это разновидность 〜てもらう 「кому-то делают одолжение». Форма もらえる (возможность) делает просьбу вежливой: «а можно ли мне получить твою помощь?».

> **身内語 (интимная речь):** В разговоре с друзьями используются краткие формы: なの（です слущ.）, んだけど（のだ слущ.）, いいよ.

# Диалог 4 — 語学の挑戦 (Изучение языков)

## Ситуация

Дмитрий и Каори обсуждают изучение иностранных языков. Дмитрий изучает японский, Каори — русский. Отрабатываются 話せる, 読める, 聞き取れる и желание 〜たい.

## Диалог

```
ディミートリー：カオリさんはロシア語を勉強していますか。
かおり：はい、少しだけ話せます。でもまだ単語が足りなくて。
ディミートリー：私は日本語を三年勉強しています。
かおり：そうなんですか。漢字は読めるようになりましたか。
ディミートリー：簡単な漢字は読めますが、新聞はまだ難しいです。
かおり：私もロシア語の新聞が読めたらいいな。
ディミートリー：毎日少しずつ聞き取る練習をすれば、必ず聞き取れるようになりますよ。
かおり：そうですね。耳が慣れることが大事ですよね。
ディミートリー：お互い頑張りましょう。私はまだ四つまでしか数えられませんから。四つ（よっつ）…
かおり：四つは「よっつ」ですね。私はロシア語の「да, нет, спасибо」だけできます。
ディミートリー：いいですね。少しずつ始めましょう！
```

## Перевод

| Японский | Русский |
|----------|---------|
| 少しだけ話せる | могу немного говорить |
| 単語が足りなくて | потому что не хватает слов |
| 漢字が読めるようになった | научился читать кандзи |
| 簡単な漢字 | простые кандзи |
| 新聞 | газета |
| まだ難しい | пока сложно |
| 聞き取る練習 | практика восприятия на слух |
| 必ず聞き取れるようになる | обязательно научусь понимать на слух |
| 耳が慣れる | ухо привыкает |
| お互い頑張りましょう | давайте стараться вместе |
| 四つまでしか数えられない | умею считать только до четырёх |
| 少しずつ | понемногу |

| 足りない | たりない | не хватать |
| 新聞 | しんぶん | газета |
| 聞き取る | ききとる | понимать на слух |
| 慣れる | なれる | привыкать |

| 始める | はじめる | начинать |

## Разбор ключевых конструкций

| Конструкция | Пример | Значение |
|-------------|--------|----------|
| 〜だけ | 少しだけ話せる | только немного |
| 〜なくて | 単語が足りなくて | потому что не хватает (причина) |
| ようになる | 読めるようになった | научился (постепенно) |
| 〜たらいいな | 読めたらいいな | хорошо бы, если бы мог читать |
| 〜ば 〜よ | 練習すれば聞き取れるよ | если тренироваться, то получится |
| 〜までしか〜ない | 四つまでしか数えられない | умею считать только до четырёх |
| 〜ながら | （—） | одновременно |

> **Нюанс — までしか〜ない:** конструкция «только до X и не дальше». 四つまでしか数えられない = «не могу сосчитать дальше четырёх». Это ограничительное отрицание, где しか всегда парный с отрицанием.

> **〜ば〜よ:** условная форма, дающая совет или обещание: 「練習すれば、聞き取れるようになりますよ」— «если поупражняетесь, то сможете понимать на слух». Форма вежливая, но дружная.
