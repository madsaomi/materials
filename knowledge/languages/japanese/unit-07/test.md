# Unit 7 — Тест

## Часть 1: Образуйте потенциальную форму

1. 泳ぐ → ＿＿＿＿
2. 飲む → ＿＿＿＿
3. 起きる → ＿＿＿＿
4. 勉強する → ＿＿＿＿

## Часть 2: Выберите правильный вариант

**1. 私は刺身が食べ＿＿＿。**
- а) る
- б) られます
- в) たいです

**2. 富士山が＿＿＿！**
- а) 見えます
- б) 見られます
- в) 見ます

**3. ピアノを弾く＿＿＿できます。**
- а) の
- б) こと
- в) が

## Часть 3: Правда или ложь?

「田中さんは泳げますが、ピアノが弾けません。」

1. 田中さんは水泳ができる。（　）
2. 田中さんは楽器が上手だ。（　）
3. 田中さんは自転車に乗れない。（　）

## Часть 4: Переведите на японский

1. Я немного умею говорить по-японски.
2. Не могу есть острое. *(辛い)*
3. Хочу научиться водить машину.
