# Unit 5 — Грамматика: Прошедшее время, выражение причин, связки

## Учебное ядро: Рассказать о прошлом и связать действия с причиной
## Прошедшее меняется вместе с типом сказуемого

Вежливое прошедшее глагола: 読みます→読みました. Для простой た-формы используйте чередования て-формы, меняя て→た, で→だ: 書いて→書いた, 読んで→読んだ, 行って→行った. する→した, 来る→来た（きた）. Не образуйте 行きた по аналогии с 行きます.

| Тип сказуемого | Прошедшее | Отрицательное прошедшее |
|---|---|---|
| Глагол | 食べました / 食べた | 食べませんでした / 食べなかった |
| い-прилагательное | 寒かったです | 寒くなかったです |
| な-прилагательное | 静かでした | 静かではありませんでした |
| Существительное | 休みでした | 休みではありませんでした |

Исключение いい использует основу よ-: よかったです — «было хорошо». きれい относится к な-прилагательным несмотря на конечное い: きれいでした. В 寒かったです прошлое выражено в самом прилагательном; 寒いでした неверно.

## Перечень примеров или порядок действий

日曜日は洗濯したり、料理を作ったりしました。— «В воскресенье, среди прочего, стирал и готовил». Модель Vた＋り、Vた＋りする перечисляет характерные действия, не обязательно весь список и не обязательно в таком порядке. Время задаёт конечное します / しました: 明日は本を読んだりします — «Завтра, например, буду читать» — тоже возможно.

Для последовательности: 朝ご飯を食べてから、出かけました。— «Позавтракал, затем вышел». てから подчёркивает, что первое действие предшествовало второму. Не используйте たり как обещание строгого порядка.

## Причина и результат: から／ので

寒かったので、窓を閉めました。— «Было холодно, поэтому я закрыл окно». 原因 «причина» стоит перед связкой. У существительного / な-прилагательного непрошедшего: 休みだから / 休みなので; 静かだから / 静かなので. У глагола: 疲れたから / 疲れたので. Вежливые формы перед обеими связками тоже встречаются.

から часто подчёркивает довод говорящего, ので представляет объяснение как фон ситуации и бывает удобным в вежливой речи. Это тенденции, а не разделение на «субъективную выдумку» и «объективную истину». 雨が降っていたので、出かけませんでした — «Шёл дождь, поэтому не вышел» — рассказывает о причине прошлого решения.

## 1. Прошедшее время (ました / た-форма)

**ます → ました (вежливое прош.):**

```
食べます → 食べました    — ел
行きます → 行きました    — ходил
見ます → 見ました        — смотрел
勉強します → 勉強しました — учился
```

**た-форма (прост. прош.):**

```
食べる → 食べた
行く → 行った
見る → 見た
する → した
来る → 来た(きた)
```

**Прилагательные в прош.:**

- い-прил: конечное い→かった; исключение いい→よかった
  - 高い → 高かった (был дорогой)
  - 美味しい → 美味しかった (было вкусно)

- な-прил: だった
  - 元気 → 元気だった (был здоров)
  - 静か → 静かだった (было тихо)

- 名詞 + だった:
  - 学生 → 学生だった (был студентом)

**Отрицание прош.:**

- 食べない → 食べなかった
- 高くない → 高くなかった
- 学生じゃない → 学生じゃなかった

## 2. 〜たり〜たりする (перечисление действий)

```
食べたり飲んだりしました。   / Ел и пил (и делал то и сё).
テレビを見たり本を読んだりします。 / Смотрю телевизор, читаю книгу и т.д.
```

## 3. 〜から / 〜ので (потому что)

```
**から** (субъективная причина):
疲れたから、休みます。     — Устал, поэтому отдохну.
安いから、買います。       — Дешёво, поэтому куплю.

**ので** (объяснение как фон ситуации; часто мягче по тону, без гарантии объективности):
雨が降ったので、行きませんでした。 — Пошёл дождь, поэтому не пошли.
```

## 4. 〜とき (когда)

```
子供のとき、日本に住んでいました。 — Когда был ребёнком, жил в Японии.
ご飯を食べるとき、「いただきます」と言います。 — Когда едим, говорим "итадакимасу".
```

## 5. 〜なければなりません (должен)

```
勉強しなければなりません。    — Должен учиться.
薬を飲まなければなりません。  — Должен принять лекарство.
```

Разговорный вариант: 〜なきゃ

## 6. 〜てもいいです / 〜てはいけません

```
ここで写真を撮ってもいいです。  — Здесь можно фотографировать.
ここでタバコを吸ってはいけません。 — Здесь нельзя курить.
```

## 7. Счётные суффиксы

| 〜人(にん) | люди | 一人、二人、三人 |
| 〜匹(ひき) | животные | 一匹、二匹、三匹 |
| 〜個(こ) | предметы | 一個、二個、三個 |
| 〜本(ほん) | длинные предметы | 一本、二本、三本 |
| 〜杯(はい) | напитки | 一杯、二杯、三杯 |
| 〜枚(まい) | плоское | 一枚、二枚、三枚 |

## Упражнения

1. "Вчера я поел суши" → __________
2. "Было вкусно" → __________
3. "Я читал книгу и смотрел телевизор" (〜たり) → __________
4. "Потому что жарко, пью воду" → __________
5. "Должен учиться" → __________

**Ответы:**

1. 昨日寿司を食べました。
2. 美味しかったです。
3. 本を読んだりテレビを見たりしました。
4. 暑いから、水を飲みます。
5. 勉強しなければなりません。

## 8. 〜ように (чтобы / в порядке)

**Цель (чтобы):**

```
日本語が話せるように、勉強しています。 — Учусь, чтобы говорить по-японски。
早く起きられるように、今度アラームを買います。 — Куплю будильник, чтобы суметь вставать раньше.
```

В выражении цели перед ように здесь стоит желаемое состояние или возможность: 話せる / 起きられる. Не добавляйте ように механически к любому собственному волевому действию. [Japan Foundation, Irodori: цель с ように](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf#page=156).

**Указание с ように言う:**

```
気をつけるように言われました。 — Мне сказали быть осторожным.
早く来るように言われました。 — Мне велели прийти пораньше.
```

## 9. 〜ば (если)

```
雨が降れば、出かけません。 — Если пойдёт дождь, не выйду。
勉強すれば、わかります。 — Если учиться, поймёшь。
早ければ、間に合います。 — Если рано, успею。
```

## 10. 〜ものだ / 〜ことだ (привычка / естественный порядок)

**ものだ** (привычка, естественный ход вещей):

```
朝はパンを食べるものだ。 — По утрам (как принято) есть хлеб。
日本ではお正月に家族で集まるものだ。 — В Японии на Новый год принято собираться с семьёй。
```

**ことだ** (долженствование):

```
毎日運動することだ。 — Нужно заниматься спортом каждый день。
早く勉強することだ。 — Нужно поскорее учиться。
```

## 11. 〜ておく (заранее сделать)

```
前もって勉強しておきます。 — Заранее учусь。
料理を作っておきます。 — Приготовлю еду заранее。
```

## 12. 〜てしまう (сделать и пожалеть / завершить)

```
間違えてしまいました。 — Ошибся (и жалею)。
全部食べてしまいました。 — Съел всё; завершённость, а сожаление определяется контекстом.
```

## 13. 〜ながら (одновременные действия)

Два действия одновременно. ながら прикрепляется к масу-основе глагола (без ます). Основное действие — в конце.

```
音楽を聞きながら、勉強します。         — Учусь, слушая музыку.
テレビを見ながら、ご飯を食べます。     — Ем, смотря телевизор.
歩きながら、電話をしました。           — Говорил по телефону на ходу.
```

## 14. 〜たことがあります (опыт)

Рассказ об опыте в прошлом.

```
日本に行ったことがあります。            — Я был(а) в Японии (есть такой опыт).
すき焼きを食べたことがありません。      — Никогда не ел(а) сукияки.
京都で着物を着たことがありますか？      — Ты когда-нибудь надевал кимоно в Киото?
```

Отрицание: 〜たことがありません.

## 15. 〜たいです (хочу)

Желание говорящего.

```
日本で働きたいです。                    — Хочу работать в Японии.
新しい着物を買いたいです。              — Хочу купить новое кимоно.
お正月には故郷に帰りたいです。          — На Новый год хочу вернуться на родину.
```

Для наблюдаемого желания третьего лица подходит 〜たがっています. Цитата с 〜たいと言っています тоже возможна:
行きたい → 行きたがっています (хочет пойти — по его/её поведению).

## 16. 〜つもりです (намерение)

Планируемое действие.

```
来年日本に行くつもりです。              — Собираюсь в следующем году поехать в Японию.
今週はお酒を飲まないつもりです。        — На этой неделе не планирую пить.
無駄遣いをしないつもりです。            — Не собираюсь тратить деньги впустую.
```

## 17. 〜のに (хотя, но)

〜のに связывает факт с результатом, противоречащим ожиданию; говорящий может выражать удивление или недовольство. Перед ним простая форма, а у непрошедших утвердительных существительного и な-прилагательного — な: 休みなのに / 静かなのに. В отличие от причины с から, здесь результат не следует из ожидаемой связи. [TUFS: противопоставление](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/082.html).

```
雨なのに、出かけました。                — Хотя шёл дождь, всё равно вышли.
高いのに、買ってしまいました。          — Хотя было дорого, я купил (и жалею).
勉強したのに、テストに落ちました。      — Хотя учился, провалил тест.
```

## 18. 〜すぎます (слишком)

Превышение нужной степени. У глагола: основа перед ます + すぎる (食べます→食べすぎる). У い-прилагательного убирается конечное い (辛い→辛すぎる); у な-прилагательного берётся основа без な (静か→静かすぎる). Конечное い в きれい — часть основы, поэтому きれいすぎる. [Japan Foundation: образование すぎる, §5](https://ba.jpf.go.jp/wp-content/uploads/2022/03/Akiko6_bunpoo382002.pdf#page=3).

```
この料理は辛すぎます。                  — Это блюдо слишком острое.
昨日食べすぎました。                    — Вчера переел.
テレビを見すぎて、寝るのが遅くなった。 — Слишком много смотрел ТВ, лёг спать поздно.
```

## 19. 〜そうです (по виду)

Вывод о свойстве по наблюдаемым признакам. У い-прилагательного убирается конечное い: 眠い→眠そう; у な-прилагательного берётся основа без な: 元気→元気そう. Особая форма いい→よさそう. Когда непосредственно оцениваете видимую красоту, обычно достаточно きれいですね; в таком задании не требуется きれいそうです. [Japan Foundation: そう по признакам и ограничения учебных примеров](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00094/ja/render.do).

```
美味しそうですね。                      — Выглядит вкусно!
このお寺は古そうです。                  — Этот храм выглядит старым.
子供は眠そうでした。                    — Ребёнок выглядел сонным.
```

Не путать с 形容詞 + です: 美味しいです — «вкусный (факт)»; 美味しそうです — «выглядит вкусным (по виду)».

## 20. 〜らしい (по слухам / типичный)

Слухи, чужие слова или характерность.

```
天気予報によると、明日は雪らしいです。  — Говорят (по прогнозу), завтра будет снег.
あの店のラーメンはおいしいらしいです。  — Говорят, рамен в том магазине вкусный.
田中さんは日本人らしいですね。          — Танака ведёт себя как типичный японец.
```
