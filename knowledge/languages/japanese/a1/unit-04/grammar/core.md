# Unit 4 — Грамматика: Приглашения, намерения, выражение чувств

## Учебное ядро: Приглашение, помощь и собственное желание
## Выберите, чьё решение вы обсуждаете

映画を見たいです — «Хочу посмотреть фильм» — сообщает ваше желание, но само по себе не приглашает собеседника. 一緒に映画を見ませんか — «Не хотите вместе посмотреть фильм?» — запрашивает его согласие. じゃ、見ましょう — «Тогда давайте посмотрим» — предлагает совместное действие. Эти формы нельзя выбирать только по русскому переводу «давай».

Все три используют основу перед ます: 見ます→見たい / 見ませんか / 見ましょう; 行きます→行きたい / 行きませんか / 行きましょう. Форма たい изменяется подобно い-прилагательному: 行きたくないです — «Не хочу идти», 行きたかったです — «Хотел пойти». Вопрос «хотели бы вы?» возможен, но приглашение 飲みませんか часто уместнее прямого выяснения желания 飲みたいですか.

## Предложить помощь и сообщить о плане

荷物を持ちましょうか。— «Мне понести вещи?» Здесь действие предлагает выполнить говорящий. 一緒に考えましょうか — «Может, подумаем вместе?» — совместное предложение: ましょうか не ограничивается помощью одного человека. По контексту определите, кто действует.

来月、日本に行くつもりです — «В следующем месяце намереваюсь поехать в Японию». Перед つもり стоит словарная или отрицательная форма: 行かないつもりです — «Намерен не ехать». たい выражает желание, つもり — намерение; ни одно окончание не подтверждает, что уже куплен билет.

## Чужие желания: назовите основание

Прямое たい в обычном утверждении прежде всего выражает собственное внутреннее желание. О Рине можно сказать リナさんは旅行したいと言っていました — «Рина говорила, что хочет путешествовать». 旅行したがっています — «Она проявляет желание путешествовать» — представляет желание через наблюдаемые признаки. Запрет «никогда нельзя たい о третьем лице» неверен: цитата явно сообщает источник.

С переходным глаголом возможны 水を飲みたい и 水が飲みたい — «Хочу воды / хочу выпить воды». Для вещи без действия: 新しい傘がほしいです — «Хочу новый зонт». Не образуйте 傘をほしい или 食べるたい. При отказе на приглашение 今度の土曜日は用事があります — «В эту субботу у меня дела» — объясняет конкретное препятствие без выдуманного правила обязательного отказа.

## 1. 〜ませんか (приглашение)

```
映画を見ませんか。        — Не хотите посмотреть фильм?
一緒にご飯を食べませんか。 — Не хотите вместе поесть?
コーヒーを飲みませんか。  — Не выпьете кофе?
```

Вежливое приглашение. Ответы:

```
はい、いいですね。      — Да, отлично.
はい、ぜひ。            — Да, обязательно.
すみません、ちょっと…   — Извините, но...
また今度お願いします。  — В следующий раз.
```

## 2. 〜ましょう (давайте сделаем)

```
会いましょう。       — Давайте встретимся.
行きましょう。       — Давайте пойдём.
食べましょう。       — Давайте поедим.
```

## 3. 〜たい (хочу сделать)

**Присоединяется к основе ます-формы:**

```
食べます → 食べたい    — хочу есть
飲みます → 飲みたい    — хочу пить
行きます → 行きたい    — хочу идти
見ます → 見たい        — хочу посмотреть

日本に行きたいです。   — Хочу поехать в Японию.
何を食べたいですか。   — Что вы хотите есть?
```

**たい в прошедшем:**

```
食べたかった — хотел есть
行きたかった — хотел пойти
```

## 4. 〜と思う (думаю, что〜)

Перед と стоит простая форма: 行くと思います / 面白いと思います. У непрошедших утвердительных существительного и な-прилагательного сохраните だ: 学生だと思います / 静かだと思います. Не заменяйте эту связку на な и не присоединяйте と к 学生です в данной модели. [TUFS: と思います](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/077.html).

```
明日雨が降ると思います。     — Думаю, завтра будет дождь.
この映画は面白いと思います。 — Думаю, этот фильм интересный.
日本に行きたいと思います。   — Думаю, хочу поехать в Японию.
```

## 5. 〜そう (выглядит / похоже)

```
面白そうですね。     — Выглядит интересно!
美味しそうですね。   — Выглядит вкусно!
大変そうですね。     — Выглядит тяжело!
```

**Правило:** у い-прилагательного убираем い: 面白い→面白そう. У な-прилагательного берём основу без な: 大変→大変そう. Особая форма いい→よさそう. Это вывод по признакам, а не просто украшение слова «красивый»: если красоту предмета вы непосредственно видите, скажите きれいですね. [Japan Foundation: そう по признакам и ограничения учебных примеров](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00094/ja/render.do).

## 6. 〜が (но / а)

```
日本語は難しいですが、面白いです。 — Японский сложный, но интересный.
行きたいですが、時間がありません。 — Хочу пойти, но нет времени.
```

## 7. Цели: 〜に (для чего, куда)

```
映画を見に行きます。  — Иду смотреть фильм.
本を買いに行きます。  — Иду покупать книгу.
ご飯を食べに行きます。— Иду есть.
```

**Структура:** [ます-основа] + [に] + [глагол движения]

## 8. 〜ながら (делая что-то одновременно)

```
歩きながら電話をします。 — Разговариваю по телефону, идя。
食べながらテレビを見ます。 — Смотрю телевизор, едя。
音楽を聞きながら勉強します。 — Учусь, слушая музыку。
```

## 9. 〜たびに (каждый раз, когда)

```
日本に行くたびに、お土産を買います。 — Каждый раз, когда еду в Японию, покупаю сувениры。
会うたびに、笑顔になります。 — Каждый раз, когда вижу, улыбаюсь。
```

## 10. 〜限り (пока, насколько)

```
元気な限り、頑張ります。 — Пока здоров, буду стараться。
時間がある限り、勉強します。 — Пока есть время, учусь。
```

## 11. 〜つつ (пока делаю одно, делаю другое)

```
歩きつつ考えます。 — Иду и думаю。
食べつつ話します。 — Ем и разговариваю。
```

## 12. 〜ましょうか (давайте / предложение)

Говорящий предлагает сделать что-то **вместе** или предлагает помощь. Оттенок — «давайте-ка…» / «разрешите я?».

```
映画を見ましょうか。          — Давайте посмотрим кино?
手伝いましょうか。            — Вам помочь? (могу помочь)
テーブルを片付けましょうか。  — Давайте уберём со стола.
待ち合わせ場所を変えましょうか。 — Давайте поменяем место встречи.
```

**Сравнение форм приглашения:**

| Форма | Смысл | Нюанс |
|-------|-------|-------|
| 〜ませんか | приглашение | «Не хотите ли…?» — ждём решения собеседника |
| 〜ましょう | совместное предложение / переход к действию | «Давайте сделаем»; может вводить предложение или следовать за согласием |
| 〜ましょうか | предложение / помощь | «Давайте сделаем?» — мягкое предложение или помощь |

## 13. 〜てもいいですか (можно?)

Просьба разрешения — важна, когда договариваетесь о времени или заходите в гости.

```
ここに座ってもいいですか。       — Можно сесть сюда?
写真を撮ってもいいですか。       — Можно сфотографировать?
来週にしてもいいですか。         — Можно перенести на следующую неделю?
コーヒーを飲んでもいいですか。   — Можно выпить кофе?
```

**Ответы:** はい、いいですよ。 / ええ、どうぞ。 / すみません、ちょっと…

## 14. 〜てください (вежливая просьба)

При договорённостях собеседника просят что-то сделать заранее.

```
駅の東口で待ってください。      — Пожалуйста, ждите у восточного выхода.
チケットを予約してください。    — Пожалуйста, забронируйте билеты.
写真を見せてください。          — Покажите фотографии, пожалуйста.
お弁当を持ってきてください。    — Принесите, пожалуйста, бэнто.
```

**Отрицательная просьба:** 〜ないでください — «пожалуйста, не…».

```
心配しないでください。 — Пожалуйста, не волнуйтесь.
```

## 15. 〜てみる (попробовать)

Обозначает действие, которое делают, чтобы **узнать результат**.

```
この料理を食べてみてください。— Попробуйте это блюдо.
一度カラオケに行ってみたいです。— Хочу однажды попробовать караоке.
着物を着てみました。           — Примерила кимоно.
新しいレシピを作ってみる。     — Пробую новый рецепт.
```

## 16. 〜たことがある (опыт)

«Приходилось когда-либо делать».

```
日本に行ったことがあります。— Был(а) в Японии (когда-то).
桜を見たことがあります。    — Видел(а) сакуру.
富士山に登ったことがありません。— Ни разу не поднимался(ась) на Фудзи.
```

**Вопрос:** 〜たことがありますか。**Отрицание:** 〜たことがありません (или ないです).

## 17. ほしい (хочу вещь) vs 〜たい (хочу сделать)

| Выражение | Для чего | Пример |
|-----------|----------|--------|
| ほしい | вещь | 新しいカメラがほしいです |
| 〜たい | действие | 新しいカメラで撮りたいです |
| 〜てほしい | чтобы другой сделал | 一緒に来てほしいです |

**Внимание:** с вещью перед ほしい основная модель — が. С переходным глаголом на 〜たい возможны を и が: 水を飲みたい / 水が飲みたい.

## 18. 〜つもりです (намерение) и 〜予定です (план)

- **つもりです** — собственное намерение, «собираюсь».
- **予定です** — план/расписание, часто согласованное с другими.

```
来年留学するつもりです。    — Намерен(а) поехать учиться в следующем году.
毎週運動するつもりです。    — Собираюсь заниматься спортом каждую неделю.
土曜日に映画に行く予定です。— Планирую пойти в кино в субботу.
京都に3日間滞在する予定です。— В планах пробыть в Киото 3 дня.
```

**Отрицание намерения:** 〜つもりはないです — «не собираюсь».

```
来週は旅行するつもりはないです。 — На следующей неделе путешествовать не собираюсь.
```

## 19. 〜たら (если / когда)

Условная форма: 行ったら, 時間があったら, 暇だったら. Часто используется в приглашениях как мягкое условие.

```
時間があったら、一緒に散歩しませんか。 — Если будет время, не прогуляться ли вместе?
木村さんが来たら、始めましょう。      — Как придёт Кимура, начнём.
暇だったら、カラオケに行きましょう。  — Если свободен, давай сходим в караоке.
安かったら、買います。                 — Если дёшево, куплю.
```

## 20. 〜といいですね (было бы хорошо)

Пожелание с надеждой на хороший результат — для планов и приглашений.

```
晴れるといいですね。          — Хорошо бы вышло солнце.
明日休みだといいですね。      — Хорошо бы завтра выходной.
席が取れるといいですね。      — Хорошо бы достались места.
楽しくなるといいですね。      — Хорошо бы было весело.
```

## 21. 〜んです / 〜んですよ (объяснение)

Перед んです ставится простая форма, но у непрошедших утвердительных существительного и な-прилагательного だ меняется на な: 学生なんです / 苦手なんです. С глаголом: 行くんです / 行かないんです. При отказе такая форма связывает объяснение с ситуацией; сама по себе она не делает любой отказ мягким. [Japan Foundation, Irodori: объяснительное んです](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf#page=110).

```
用事があるんです。              — У меня дела (вот в чём дело).
ちょっと都合が悪いんです。      — Понимаете, мне неудобно.
おなかが痛いんです。            — У меня живот болит.
実は料理が苦手なんです。        — Вообще-то, готовлю я неважно.
```

**Схема вежливого отказа:** объяснение с んです → предложение в другой раз.

```
すみません、週末は旅行するんです。また今度お願いします。
```
