# Unit 1 — Диалог: 初めまして (Приятно познакомиться)

## Разговор по ролям: назвать себя и владельца вещи

Прочитайте сцену за двух участников, затем закройте одну роль. Это письменная тренировка реплик; готовой аудиозаписи здесь нет.

### Новая учебная сцена

**Место:** первый урок. Книга лежит возле Миры, тетрадь — возле Кена. Это новая учебная сцена; роли фиксированы.

> ミラ：はじめまして。ミラです。よろしくお願いします。  
> ケン：ケンです。よろしくお願いします。学生ですか。  
> ミラ：はい、学生です。ケンさんも学生ですか。  
> ケン：はい、私も学生です。それはミラさんの本ですか。  
> ミラ：はい、私の本です。それはケンさんのノートですか。  
> ケン：はい、私のノートです。

**Подсказка к пространству:** Кен указывает それ на книгу возле Миры, а Мира — на тетрадь возле Кена. Расположение предметов во время разговора не меняется.

### Понять участников и результат

1. Оба ли участника студенты? Найдите реплику с «тоже».
2. Чья книга? Чья тетрадь? Ответьте группами с の.
3. Почему оба участника говорят それ, хотя указывают на разные предметы? Кто сообщает владельца книги?

<details>
<summary>Проверить понимание новой сцены</summary>

1. Да. ケン говорит 私も学生です — «я тоже студент».
2. ミラさんの本 и ケンさんのノート. Для ответа Миры естественно 私の本.
3. Каждый указывает на предмет возле собеседника. それ зависит от текущего говорящего. Кен спрашивает о книге Миры, Мира подтверждает 私の本. Принадлежность сообщает группа с の, а не само указательное слово.

</details>

### Сыграть с новой карточкой

Вдвоём используйте два реальных предмета. Представьтесь, задайте вопрос о роли и уточните владельца. Перед каждой репликой договоритесь, у кого лежит предмет. Проверка: чужое имя + さん, тема + は/も, владелец + の + вещь; не произносите своё имя с さん.

[Подготовить слова](vocabulary/words.md) · [Модель в чтении](reading.md) · [Самопроверка](test.md)

## Ситуация

Танака и Сато познакомились на вечеринке у общего друга. Они стоят у балкона, наливают себе чай. Танака — новый студент в университете, Сато — уже второй курс. Они только что узнали, что учатся в одной программе.

## Диалог

```
Танака: あのう、すみません。お名前は？
佐藤: 佐藤です。佐藤美咲です。よろしくお願いします。
田中: 田中太郎です。はじめまして。よろしくお願いします。
佐藤: はじめまして！大学はどちらですか。
田中: 東京大学です。大学院で日本語を勉強しています。
佐藤: そうですか！私は工学部の2年生です。田中さんは大学院なんですね。
田中: はい。でもまだ日本語がうまくできません。
佐藤: いいえ、大丈夫ですよ。一緒に勉強しましょう！
田中: ありがとうございます。助かります。
佐藤: それより、田中さんは何が趣味ですか。
田中: 読書と映画鑑賞です。あなたは？
佐藤: 料理と旅行です。暇なときは新しいレシピを試します。
田中: おもしろいですね！いつか一緒に料理しましょう。
佐藤: いいですね！それは楽しみです。
```

## Перевод

| Японский | Русский |
|----------|---------|
| あのう、すみません | Э-э, простите (чтобы привлечь внимание) |
| お名前は？ | Как вас зовут? (контекстный вежливый вопрос) |
| 佐藤です。佐藤美咲です | Я Сато. Сато Мисаки |
| よろしくお願いします | Прошу вас / Буду признателен |
| 田中太郎です | Я Танака Таро |
| はじめまして | Приятно познакомиться |
| 大学はどちらですか | В каком университете вы учитесь? |
| 東京大学です | В Токийском университете |
| 大学院で日本語を勉強しています | Учу японский в аспирантуре |
| 工学部の2年生です | Второкурсник инженерного факультета |
| 一緒に勉強しましょう | Давайте учиться вместе |
| 趣味は何ですか | Какое у вас хобби? |
| 読書と映画鑑賞です | Чтение и просмотр фильмов |
| 新しいレシピを試します | Пробую новые рецепты |
| 一緒に料理しましょう | Давайте приготовим вместе |

# Диалог 2: 買い物 (Покупки)

## Ситуация

Мисаки идёт в магазин и покупает яблоки. Она спрашивает цену у продавца.

## Диалог

```
ミサキ: すみません、りんごはありますか。
店員: はい、ございます。こちらです。
ミサキ: りんごはいくらですか。
店員: 一つ百円です。
ミサキ: じゃあ、りんごを三つください。
店員: 合計で三百円です。三百円をください。
ミサキ: はい、どうぞ。ありがとうございます。
店員: ありがとうございました。またお待ちしています。
```

## Перевод

| Японский | Русский |
|----------|---------|
| りんごはありますか | У вас есть яблоки? |
| はい、ございます | Да, есть (вежливо) |
| 一つ百円です | Одно — сто иен |
| りんごを三つください | Дайте три яблока |
| 合計で三百円です | Итого триста иен |
| またお待ちしています | Ждём вас снова |

## Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| りんご | — | яблоко |
| 円 | эн | иена |
| 合計 | го:кэй | итого |
| 三つ | мицу | три (шт.) |
| あります | аримасу | имеется (неодуш.) |
| ございます | годзаимасу | имеется (вежл.) |

# Диалог 3: 電車で (В электричке)

## Ситуация

Таро спрашивает у незнакомца, доедет ли он до станции Сибуя на этой линии.

## Диалог

```
田中: すみません、この電車は渋谷へ行きますか。
人: はい、行きますよ。渋谷は次ですか。
田中: いいえ、渋谷は三つ目です。
人: そうですか。なら、三つ目の駅で降りてください。
田中: 電車でどのくらいかかりますか。
人: 二十分ぐらいです。
田中: 分かりました。どうもありがとうございます。
人: いいえ、どういたしまして。
```

## Перевод

| Японский | Русский |
|----------|---------|
| この電車は渋谷へ行きますか | Эта электричка идёт до Сибуя? |
| 渋谷は次ですか | Сибуя — следующая (станция)? |
| 渋谷は三つ目です | Сибуя — третья остановка |
| 降りてください | Сойдите, пожалуйста |
| どのくらいかかりますか | Сколько времени займёт? |
| 二十分ぐらいです | Около двадцати минут |
| どういたしまして | Не за что |

## Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 電車 | дэнся | электричка |
| 渋谷 | сибуя | Сибуя (район Токио) |
| 駅 | эки | станция |
| 次 | цуги | следующий |
| 降りる | ориру | сходить (с транспорта) |
| どのくらい | доно курай | сколько/насколько |
| 二十分 | нидзюппун | двадцать минут |
| ぐらい | гурай | около, примерно |

# Диалог 4: レストランで (В ресторане)

## Ситуация

Мисаки и Таро обедают вместе. Они заказывают еду.

## Диалог

```
店員: いらっしゃいませ。ご注文はお決まりですか。
ミサキ: はい、お願いします。私はラーメンをください。
田中: 僕は寿司をください。あと、ビールを一本ください。
店員: かしこまりました。ラーメンと寿司とビールですね。
田中: はい、そうです。
ミサキ: すみません、お茶もください。
店員: かしこまりました。少々お待ちください。
```

## Перевод

| Японский | Русский |
|----------|---------|
| ご注文はお決まりですか | Вы готовы сделать заказ? |
| 私はラーメンをください | Мне рамэн, пожалуйста |
| 寿司をください | Дайте мне суши |
| ビールを一本ください | Одно пиво, пожалуйста |
| 少々お待ちください | Немного подождите |
| かしこまりました | Принято (вежливое подтверждение) |

## Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ご注文 | готю:мон | заказ (вежл.) |
| 決まり | кимари | решено |
| 寿司 | суси | суши |
| ビール | би:ру | пиво |
| 一本 | иппон | одна (длинный предмет) |
| 少々 | сё:сё: | немного, чуть-чуть |
