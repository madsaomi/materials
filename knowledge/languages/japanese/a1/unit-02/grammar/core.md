# Unit 2 — Грамматика: Время, распорядок, частицы направления

## Учебное ядро: Вежливая форма глагола и распорядок дня
## Сначала найдите группу глагола

Вежливая форма не образуется добавлением ます к полной словарной форме. В группе 1 конечная мора ряда u переходит в ряд i: 読む→読みます, 書く→書きます, 買う→買います. В группе 2 убирается る: 起きる→起きます, 食べる→食べます. Отдельно запомните する→します и 来る（くる）→来ます（きます）.

Глагол на -る не обязательно относится к группе 2: 帰る→帰ります, 入る→入ります. Для неизвестного глагола проверяйте группу по словарю. Форма ます не меняется по лицам: 私も母も働きます — «И я, и мама работаем».

| Значение | Вежливая форма | Пример |
|---|---|---|
| Обычное / будущее действие | 読みます | 毎晩、本を読みます。— Каждый вечер читаю книгу. |
| Отрицание | 読みません | 今日は読みません。— Сегодня читать не буду. |
| Прошлое | 読みました | 昨日読みました。— Вчера прочитал / читал. |
| Прошлое отрицание | 読みませんでした | 昨日は読みませんでした。— Вчера не читал. |

## Частицы распределяют роли в распорядке

七時に家を出ます。— «В семь выхожу из дома». 七時に — момент; 家を — место, которое покидают; 出ます — действие. У を есть и значения пути/исходной точки, поэтому не считайте каждое を прямым объектом.

八時から十二時まで図書館で勉強します。— «С восьми до двенадцати занимаюсь в библиотеке». から / まで ограничивают период, で обозначает место действия. 学校に行きます — «Иду в школу», バスで行きます — «Еду на автобусе»: цель и способ поездки выполняют разные роли.

に обычно ставят с обозначением момента: 六時に, 三月に. 今日, 明日, 毎朝 в обычном временном употреблении идут без に: 明日働きます. С днями недели に может опускаться: 月曜日（に）会います. Длительность оформляется иначе: 二時間勉強します — «Занимаюсь два часа», а не 二時間に.

## Частота не равна действию прямо сейчас

毎日泳ぎます — «Плаваю каждый день»; 今泳いでいます — «Сейчас плаваю». У あまり〜ません значение «не очень / нечасто»: あまりテレビを見ません — «Не очень часто смотрю телевизор». В этой модели требуется отрицание. Ошибки 帰ます, 食べるます исправляются как 帰ります, 食べます.

## 1. Частица に для времени

Ставится после указания времени (но не после слов "сегодня", "завтра" и т.д.)

```
6時に起きます。          — Встаю в 6.
8時に家を出ます。        — Выхожу из дома в 8.
9時から5時まで働きます。 — Работаю с 9 до 5.

今日(×に)起きました。    — Сегодня встал. (без に)
```

## 2. Частица で (инструмент / место действия)

```
電車で行きます。    — Еду на поезде.
ペンで書きます。     — Пишу ручкой.
レストランで食べます。 — Ем в ресторане.
学校で勉強します。  — Учусь в школе.
```

## 3. Частицы направления: に и へ

```
家に帰ります。      — Возвращаюсь домой.
会社に行きます。    — Иду на работу.
日本へ行きます。    — Еду в Японию.
```

**に** — акцент на цели. **へ** — акцент на направлении.

## 4. から〜まで (от〜до)

```
9時から5時まで働きます。 — Работаю с 9 до 5.
東京から大阪まで行きます。 — Еду из Токио до Осаки.
```

## 5. Спряжение ます-формы (продолжение)

**Группа I (五段):**

- 会う → 会います
- 書く → 書きます  
- 話す → 話します
- 待つ → 待ちます
- 死ぬ → 死にます
- 読む → 読みます
- 飛ぶ → 飛びます
- 走る → 走ります
- 歌う → 歌います

**Правило:** Последний звук меняется на звук из い-ряда.

**Группа II (一段):** る → ます

- 食べる → 食べます
- 見る → 見ます

**Группа III (不規則):**

- する → します
- 来る → 来ます (きます)

## 6. を (объектная частица)

```
朝ごはんを食べます。    — Ем завтрак.
コーヒーを飲みます。    — Пью кофе.
テレビを見ます。       — Смотрю телевизор.
```

## 7. Наречия частоты

| Слово | Перевод |
|-------|---------|
| いつも | всегда |
| たいてい | обычно |
| よく | часто |
| 時々 (ときどき) | иногда |
| あまり〜ない | не очень (с отриц.) |
| ぜんぜん〜ない | совсем не (с отриц.) |
| たまに | изредка |
| めったに〜ない | редко (с отриц.) |

**Примеры:**

```
いつもコーヒーを飲みます。     — Всегда пью кофе.
あまりテレビを見ません。      — Не очень часто смотрю телевизор.
時々映画を見ます。            — Иногда смотрю кино.
```

## 8. 〜ています (действие в процессе / результат)

**Образование:** глагол в тэ-форме + います

| Ситуация | Пример | Значение |
|----------|--------|----------|
| Длительное действие | 食べています | Я ем (сейчас) |
| Результат | 部屋が汚れています | Комната грязная (состояние) |
| Действие в процессе | 新聞を読んでいます | Я читаю газету |

**Отличие от ている:**

- ている — простая форма
- ています — соответствующая вежливая форма; сама вежливость не меняет значение действия в процессе или состояния

**Примеры:**

```
今何をしていますか。     — Что вы делаете сейчас?
私はテレビを見ています。  — Я смотрю телевизор.
日本語を勉強しています。  — Я изучаю японский.
```

## 9. 〜ながら (делая что-то одновременно)

Основа перед ます + ながら: 聞きます→聞きながら. В этой модели один человек выполняет оба действия; главное действие стоит после ながら. 音楽を聞きながら勉強します сообщает прежде всего об учёбе, на фоне которой слушают музыку. [Japan Foundation, Irodori: ながら](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf#page=153).

```
歩きながら電話をします。 — Разговариваю по телефону, идя。
食べながらテレビを見ます。 — Смотрю телевизор, едя。
音楽を聞きながら勉強します。 — Учусь, слушая музыку。
```

## 10. 〜たびに (каждый раз, когда)

```
会うたびに、笑顔になります。 — Каждый раз, когда вижу, улыбаюсь。
日本に行くたびに、お土産を買います。 — Каждый раз, когда еду в Японию, покупаю сувениры。
```

## 11. 〜限り (пока, насколько)

```
元気な限り、頑張ります。 — Пока здоров, буду стараться。
時間がある限り、勉強します。 — Пока есть время, учусь。
```

## 12. 〜つつ (пока делаю одно, делаю другое)

```
歩きつつ考えます。 — Иду и думаю。
食べつつ話します。 — Ем и разговариваю。
```

## 13. 〜から (потому что)

```
暑いから、水を飲みます。 — Потому что жарко, пью воду。
遅いから、急いでください。 — Поздно, пожалуйста, поторопитесь。
```

## 14. Длительность: 〜時間, 〜分

Длительность действия передаётся суффиксами 〜時間 (часов) и 〜分 (минут). Читаются они по онному (китайскому) чтению.

| Счёт | Чтение | | Счёт | Чтение |
|------|--------|-|------|--------|
| 1時間 | いちじかん | | 1分 | いっぷん |
| 2時間 | にじかん | | 2分 | にふん |
| 3時間 | さんじかん | | 3分 | さんぷん |
| 4時間 | よじかん | | 4分 | よんぷん |
| 5時間 | ごじかん | | 5分 | ごふん |
| 6時間 | ろくじかん | | 6分 | ろっぷん |
| 7時間 | ななじかん | | 7分 | ななふん |
| 8時間 | はちじかん | | 8分 | はっぷん |
| 9時間 | くじかん | | 9分 | きゅうふん |
| 10時間 | じゅうじかん | | 10分 | じゅっぷん |

**Примеры:**

```
毎日8時間働きます。      — Работаю каждый день 8 часов.
宿題を2時間します。      — Делаю домашку 2 часа.
映画は2時間半かかります。 — Фильм идёт два с половиной часа.
```

> 🔗 Сложности с 分 (ふん/ぷん): [Микро-детали — чтение цифр](../../../reference/core/details.md)

## 15. 〜ごろ и 〜半 (приблизительное время и половина)

- **〜ごろ** — «около, примерно»: 7時**ごろ**起きます。
- **〜半** — «половина»: 7時**半**に起きます。 (ровно 7:30)

```
7時ごろ家を出ます。          — Выхожу из дома около 7.
12時半に昼ごはんを食べます。  — Обедаю в 12:30.
```

**Важно:** после ごろ に не обязательна: 7時ごろ起きます — «Встаю около семи». Для указанного момента используйте 7時半に起きます — «Встаю в 7:30». 今日 / 昨日 в обычном указании времени не требуют に. Не переносите правило точного момента на все временные выражения. [Japan Foundation, Irodori: время и ごろ](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf#page=26).

## 16. 毎＋существительное (еже-)

Слова 毎日, 毎朝, 毎晩, 毎週, 毎月 образуются по схеме 毎 (в каждый) + период.

```
毎朝ジョギングをします。   — Каждое утро бегаю.
毎晩お風呂に入ります。     — Каждый вечер принимаю ванну.
```

**Важно:** после 毎〜 частица に **не** ставится: 毎朝に(×)→毎朝 起きます。

## 17. まず〜それから〜 (сначала〜затем〜)

Перечисление действий по порядку:

```
まず顔を洗って、それから朝ごはんを食べます。
Сначала умываюсь, потом завтракаю.

まず電車で会社に行って、それから仕事をします。
Сначала еду на поезде на работу, потом работаю.
```

## 18. 〜てから (после того как)

Тэ-форма + から = «после того, как сделаю X» (одно действие завершилось и началось другое).

```
ご飯を食べてから、勉強します。      — После еды учусь.
家に帰ってから、シャワーを浴びます。  — Вернувшись домой, приму душ.
歯を磨いてから、寝ます。            — Почищу зубы и лягу спать.
```

**Отличие от простой тэ-формы:** 〜てから явно связывает второе действие с завершением первого. Простая て-форма тоже может передавать последовательность: 帰って、寝ました — «Вернулся и лёг спать». У неё есть и другие связи, включая перечисление и причину; значение устанавливается по контексту. [TUFS: て и てから](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/051.html).

## 19. Двойное も (и〜и тоже)

Две частицы も в одном предложении = «и X, и Y»:

```
昨日は朝ごはんも晩ごはんも食べませんでした。
Вчера не ел ни завтрак, ни ужин.

私は日本語も英語も話せます。
Я говорю и по-японски, и по-английски.
```

## 20. 〜たい (хотеть) и 〜ほしい (хотеть что-л.)

- **〜たい** — хочу что-то СДЕЛАТЬ (глагол в основе масу-формы + たい)
- **ほしい** — хочу что-то ПОЛУЧИТЬ (вещь; требует が)

```
日本に行きたいです。          — Хочу поехать в Японию.
今コーヒーが飲みたいです。     — Сейчас хочу выпить кофе.
(飲む → 飲み + たい)

水がほしいです。              — Хочу воды.
新しい靴がほしいです。         — Хочу новые туфли.
```

**Внимание:** 〜たい изменяется подобно い-прилагательному: 飲みたい→飲みたくない→飲みたかった. С переходным глаголом здесь возможны コーヒーを飲みたい и コーヒーが飲みたい. Частица が в последнем примере стоит после желаемого напитка; это не выбор между 私は и 私が. [TUFS: желание и частицы](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/067.html).

## 21. Приглашение и предложение: 〜ましょう / 〜ませんか

- **〜ましょう** — «давайте сделаем» (предложение, инициатива)
- **〜ませんか** — «не хотите ли〜?» (мягкое приглашение)

```
お昼ご飯を食べましょう。         — Давайте пообедаем.
一緒にコーヒーを飲みませんか。    — Не выпьете ли кофе со мной?
明日映画を見ませんか。           — Не посмотреть ли завтра кино?
```

**Ответ:** на 〜ませんか можно ответить いいですね (звучит отлично) или すみません、今日はちょっと… (извините, сегодня не получится).

## 22. 〜つもり (планировать, намереваться)

Показывает намерение. Схема: словарная форма / форма на ない + つもりです: 行くつもりです / 行かないつもりです. 行きますつもりです не образуется. Намерение само по себе не означает, что все приготовления закончены.

```
週末は友達に会うつもりです。     — В выходные собираюсь встретиться с другом.
今年は日本に行くつもりです。     — В этом году планирую поехать в Японию.
留学するつもりはありません。     — Не намерен учиться за границей (отрицание).
```

**Отличие от 〜たい:** 〜たい — желание («хочу»), 〜つもり — конкретный план («собираюсь»).

1. Переведите: «я работаю 8 часов каждый день» → __________
2. Переведите: «я встаю около 7 и выхожу из дома в 7:40» → __________
3. Исправьте ошибку: 毎朝にプールに行きます。 → __________

7. Переведите: «хочу пить кофе» → __________
8. Переведите: «не хотите ли пойти в кино?» → __________
9. Переведите: «завтра собираюсь поехать в Киото» → __________
10. Составьте предложение: 私は / 旅行 / が / 楽しみ / です → __________

**Ответы:**

2. 7時ごろ起きて、7時40分に家を出ます。

5. 家に帰ってから、寝ました。
6. 朝も晩も時間がありません。
7. コーヒーが飲みたいです。
8. 一緒に映画に行きませんか。
9. 明日京都に行くつもりです。
10. 私は旅行が楽しみです。 (досл. «путешествие — моя радость», означает «жду путешествия с нетерпением»)
