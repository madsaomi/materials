# 日本語を学ぼう — Учебник японского языка

> Добро пожаловать в полный курс японского: от первой хираганы до уровня JLPT N4. Это не набор справочников — это **программа обучения**, выстроенная как классические учебники (Genki, Minna no Nihongo), но адаптированная для самостоятельного прохождения на русском языке.
>
> **Время прохождения:** ~9–12 месяцев при 30–60 минутах в день.
> **Результат:** свободное чтение простых текстов, бытовая речь, готовность к JLPT N4.

---

## Как устроен этот учебник

Каждый урок (юнит) — это законченный «день из жизни» героини курса Алисы в Японии:

```
📖 Диалог     → живая ситуация: увидите грамматику в действии
📝 Грамматика → объяснения по пунктам, таблицы, типичные ошибки
📚 Лексика    → слова по темам, с чтениями и примерами
✏️ Практика   → дриллы и переводы (делайте письменно!)
📰 Чтение     → связный текст с разбором
✅ Тест       → самопроверка перед переходом дальше
```

**Золотое правило:** не двигайтесь дальше, пока тест текущего урока не решён на 80%+. Язык — это лестница: пропущенная ступень = падение через три урока.

## Методика: как заниматься

### Ежедневный цикл (30–60 минут)

```
┌─────────────────────────────────────────────────┐
│ 1. Anki / повторение слов      10 мин           │
│ 2. Новый материал урока        15 мин           │
│ 3. Дриллы письменно            10 мин           │
│ 4. Чтение вслух                 5 мин           │
├─────────────────────────────────────────────────┤
│ + 2 раза в неделю: аудирование 15 мин           │
│ + каждую неделю: 8 новых кандзи                  │
└─────────────────────────────────────────────────┘
```

### Четыре опоры запоминания

**1. Интервальные повторения (SRS).**
Мозг забывает по кривой Эббингауза. Anki покажет карточку ровно тогда, когда вы почти её забыли — это момент максимальной пользы. Нет Anki — бумажные карточки Лейтнера.

**2. Письмо от руки.**
Прописывайте кандзи и новые слова. Моторная память держит лучше зрительной. Возьмите генкоёси (клетчатую бумагу) — пишите красиво, по квадратам.

**3. Голос вслух.**
Японский ритм ставится только голосом. Читайте диалоги за обоих героев, копируя интонацию. Стыдно? Никто не слышит. Через месяц будете звучать естественно.

**4. Контекст вместо зубрёжки.**
Не «tabemasu = ем», а сцена: столик в кафе, горячий рамэн, официант рядом. Придумывайте микросюжеты к каждому слову — они и есть крючки памяти.

### Правила для самостоятельных

- Не стремитесь понять **всё** в диалоге сразу — ловите структуру.
- Ошибки в практике — норма; ошибки без проверки — опасны. Всегда сверяйтесь с ответами.
- Пропустили 3+ дня? Не «навёрстывайте» двойной нормой — вернитесь к обычному темпу с повторения.

## Частые вопросы

**Можно ли начать прямо с урока 6, если что-то уже знаю?**
Пройдите тесты уроков 1–5. Если везде 80%+ — да.

**Нужен ли учебник Genki параллельно?**
Не обязательно. Курс покрывает ту же грамматическую программу N5→N4. Genki пригодится как источник дополнительных упражнений.

**Сколько слов учить в день?**
10 новых + повторение старых. Больше — только если успеваете удерживать.

**Что делать при выгорании на середине?**
Снизьте норму вдвое, но не пропускайте дни полностью. Полтора месяца «по минимуму» сохранят привычку; две недели перерыва — убьют её.
