## 日本の年中行事 (Годовой цикл событий)

```
日本には四季があり、それぞれの季節に伝統的な行事があります。

春の代表的な行事はお花見です。
3月から4月にかけて、桜が咲きます。
会社や学校の仲間と公園で集まって、
お弁当を食べたりお酒を飲んだりしながら桜を楽しみます。
夜の桜はライトアップされて、とても幻想的です。

夏は花火大会とお盆です。
7月から8月にかけて、各地で花火大会が開かれます。
浴衣を着て、屋台で買い物をしながら花火を見ます。
お盆は先祖の霊を迎える行事で、
家族が集まってお墓参りに行きます。

秋は紅葉と収穫の季節です。
山や公園が赤や黄色に染まります。
月見という行事もあり、満月を鑑賞しながらお団子を食べます。

冬は正月が一番大切な行事です。
大晦日には除夜の鐘を聞きながら年越しそばを食べます。
新年には初詣に行き、新年の願い事をします。
子供たちはお年玉をもらって喜びます。
```

### 翻訳

В Японии четыре сезона, и в каждом есть традиционные события.

Весеннее代表事件 — любование сакурой.
С марта по апрель цветёт сакура.
Коллеги с работы или учебы собираются в парке,
наслаждаются сакурой, поедая бэнто и выпивая.
Ночью сакура подсвечивается, выглядит очень фантастично.

Лето — фейерверки и Обон.
С июля по август в разных местах проводят фейерверки.
Надевают юкату, гуляют по киоскам и смотрят на фейерверки.
Обон — праздник встречи душ предков,
семья собирается и идёт на могилы.

Осень — сезон красных листьев и урожая.
Горы и парки окрашиваются в красный и жёлтый.
Есть также обычай Цукими — любование полной луной с рисовыми шариками.

Зимой самый важный праздник — Новый год.
В канун НГ слушают колокол и едят лапшу тосикоси.
В Новый год первый раз идут в храм и загадывают желания.
Дети радуются отосидама (денежным подаркам).

### 質問

1. 日本の四季は何ですか。
2. 春の代表的な行事は何ですか。
3. お花見で何をしますか。
4. 夏の行事は何と何ですか。
5. お盆はどんな行事ですか。
6. 秋にどんな行事がありますか。
7. 大晦日に何をしますか。
8. 子供たちはお年玉をもらってどうですか。

**Ответы:**
1. 春夏秋冬です。
2. お花見です。
3. 桜を見ながら食べたり飲んだりします。
4. 花火大会とお盆です。
5. 先祖の霊を迎える行事です。
6. 紅葉と月見があります。
7. 除夜の鐘を聞いて年越しそばを食べます。
8. 喜びます。

### 翻译 (Перевод)

Прошлым летом Алиса впервые пошла на летний мацури. Вместе с Юки.

Алиса надела юкату. Это было впервые, так что было немного сложно. Но очень красиво!

На фестивале было много народу. С лотка ела такояки. Потом и какигори тоже. Вечером был салют. Фейерверки были огромные и красивые.

Алиса сказала: «Было супер!» Хочет пойти и в следующем году.

**Ответы:**
1. ゆきちゃんと行きました。
2. ゆかたを着ました。難しかったですが、きれいでした。
3. 花火大会がありました。

## テキスト４：せつぶん（Сэцубун — проводы зимы）

```
節分は、春の始まりを迎えるための古い行事です。毎年2月3日ごろにあります。

節分の夜、家族は「鬼は外！福は内！」と言いながら、豆をまきます。鬼は悪いもの、福は幸せの意味です。

まき終わったら、自分の年と同じ数の豆を食べます。そうすると、一年中病気にならないと言われています。

節分には「恵方巻き」という太い寿司を食べる習慣もあります。恵方巻きは、その年のいい方角を向いて、黙って一気に食べます。恵方巻きを最後まで食べると、願い事がかなうと言われています。

最近では、お寺や神社で豆まきのイベントを開くところも多いです。ニュースで、有名な俳優や力士が豆をまく様子が放送されます。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 節分 | せつぶん | Сэцубун (проводы зимы) |
| まく (撒く) | まく | бросать, разбрасывать |
| 鬼 | おに | демон, злой дух |
| 福 | ふく | счастье, удача |
| 一年中 | いちねんじゅう | круглый год |
| 病気 | びょうき | болезнь |
| 恵方巻き | えほうまき | эхомаки (рисовый ролл) |
| 方角 | ほうがく | направление, сторона |
| 黙って | だまって | молча |
| 一気に | いっきに | залпом, одним махом |
| かなう (叶う) | かなう | сбываться |
| 俳優 | はいゆう | актёр |
| 力士 | りきし | сумоист |
| 放送する | ほうそうする | транслировать |

### 翻訳 (Перевод)

Сэцубун — древний праздник, с помощью которого встречают начало весны. Проводится примерно 3 февраля.

В ночь Сэцубуна семья разбрасывает бобы со словами «Они ва сото! Фуку ва ути!» («Злые духи — вон! Счастье — в дом!»). Они — это злые духи, фуку — счастье.

Когда бобы разбросаны, съедают столько же бобов, сколько человеку исполнилось лет. Говорят, тогда весь год не болеешь.

На Сэцубун есть и обычай есть «эхомаки» — толстый ролл. Эхомаки едят молча, повернувшись в благоприятную сторону года. Говорят, если доесть ролл до конца, желание сбудется.

В последнее время храмы и святилища устраивают мероприятия с разбрасыванием бобов. По новостям показывают, как известные актёры и сумоисты бросают бобы.

### 質問 (Вопросы)

1. 節分はいつごろありますか。
2. 節分に何をまきますか。
3. 何と言いながら豆をまきますか。
4. 豆はいくつ食べますか。
5. 恵方巻きはどうやって食べますか。

**Ответы:**
1. 毎年2月3日ごろです。
2. 豆をまきます。
3. 「鬼は外！福は内！」と言いながらまきます。
4. 自分の年の数と同じ数だけ食べます。
5. いい方角を向いて、黙って一気に食べます。

## テキスト５：おとしだま（Отосидама — новогодние деньги）

```
冬休みになると、子供たちは祖父母や親戚からお年玉をもらいます。お年玉は、大人が子供にあげるお金のことです。

「お年玉」という名前は「年魂（としだま）」という言葉から来ています。年魂は「新しい年の魂」という意味で、新しい年を元気に迎えるためのお金だと言われています。

お年玉は「ぽち袋」という小さな袋に入れて渡します。袋には「お年玉」と書いてあります。

もらうとき、子供は「ありがとうございます」と言って、両手で受け取ります。お礼の気持ちを込めて、軽く頭を下げる子もいます。

お年玉の金額は、小学生なら500円から3000円ぐらいです。高校生になると、5000円から10000円もらうこともあります。

お年玉をもらった子供は、貯金したり、欲しかったものを買ったりします。中には、全部使ってしまって、あとで後悔する子もいます。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| お年玉 | おとしだま | новогодние деньги (подарок) |
| 冬休み | ふゆやすみ | зимние каникулы |
| 祖父母 | そふぼ | бабушка и дедушка |
| 親戚 | しんせき | родственники |
| 年魂 | としだま | «душа года» (старое значение) |
| ぽち袋 | ぽちぶくろ | маленький конверт для денег |
| 受け取る | うけとる | получать, принимать |
| 気持ちを込める | きもちをこめる | вкладывать чувства |
| 頭を下げる | あたまをさげる | склонить голову (полуклон) |
| 金額 | きんがく | сумма, количество денег |
| 小学生 | しょうがくせい | ученик начальной школы |
| 高校生 | こうこうせい | старшеклассник |
| 貯金する | ちょきんする | копить, откладывать |
| 後悔する | こうかいする | сожалеть |

### 翻訳 (Перевод)

Когда наступают зимние каникулы, дети получают отосидама от бабушек, дедушек и родственников. Отосидама — это деньги, которые взрослые дарят детям.

Название «отосидама» произошло от слова «тосидама» («душа года»). Считается, что это деньги, чтобы с новыми силами встретить новый год.

Отосидама передают в маленьком конвертике «потибукуро». На конвертике написано «お年玉».

Получая, ребёнок говорит «спасибо» и принимает обеими руками. Некоторые дети слегка кланяются, вкладывая в жест благодарность.

Сумма зависит от возраста: у младшеклассников примерно 500–3000 иен, а у старшеклассников бывает 5000–10000 иен.

Получив деньги, дети копят их или покупают давно желанную вещь. Некоторые тратят всё сразу, а потом жалеют.

### 質問 (Вопросы)

1. お年玉は誰からもらいますか。
2. 「お年玉」という名前はどこから来ましたか。
3. お年玉は何に入れて渡しますか。
4. もらうとき、子供はどうしますか。
5. 小学生のお年玉はいくらぐらいですか。

**Ответы:**
1. 祖父母や親戚からもらいます。
2. 「年魂」という言葉から来ました。
3. ぽち袋に入れて渡します。
4. 「ありがとうございます」と言って、両手で受け取ります。
5. 500円から3000円ぐらいです。

## Как работать с текстами урока 5

1. **Прошедшее время во всех формах:** でした・かった・行きました・言いました — подчёркивайте их в текстах.
2. **Культурная заметка:** привозить коллегам/одноклассникам сувенир из поездки (おみやげ) — обязательная японская традиция!
3. **Мини-задание:** напишите 5–7 предложений о своей недавней поездке в прошедшем времени.
