# Unit 5 — Диалог: 日本の文化と習慣 (Культура и обычаи)

## Диалог

```
アリス: 日本の習慣についてもっと知りたいです。
田中: そうですか。例えばどんなことですか。
アリス: 初詣やお花見について教えてください。
田中: 初詣は新年に神社やお寺に行くことです。
　　　1月1日から1月7日ぐらいまで行きます。
アリス: お花見は桜を見るイベントですね。
田中: そうです。春に友達や家族と公園で集まって、
　　　食べたり飲んだりしながら桜を楽しみます。
アリス: いいですね！他にはどんな習慣がありますか。
田中: 大晦日に年越しそばを食べる習慣もあります。
　　　長く生きられるようにという願いが込められています。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 習慣 | Обычай |
| 初詣 | Первое посещение храма в новом году |
| お花見 | Любование цветением сакуры |
| 神社 | Синтоистский храм |
| お寺 | Буддийский храм |
| 新年 | Новый год |
| 集まる | Собираться |
| 楽しむ | Наслаждаться |
| 大晦日 | Канун Нового года (31 дек.) |
| 年越しそば | Гречневая лапша в канун НГ |
| 長く生きられる | Долго жить |
| 願い | Желание |
