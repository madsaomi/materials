## Упражнение 2: 〜たり〜たり

Составьте предложения с 〜たり〜たり:

1. Вчера: смотрел телевизор + слушал музыку + отдыхал
   → __________
2. В выходные: читал + гулял + готовил
   → __________

   → __________

## Упражнение 3: 〜から (причина)

Соедините предложения:

1. 暑いです。窓を開けます。 → __________
2. お腹が空きました。ご飯を食べます。 → __________
3. 日本語が難しいです。でも面白いです。 → __________

## Упражнение 4: Счётчики

Заполните:

1. 友達が3___います。
2. 猫が2___います。
3. ビールを3___飲みました。
4. 本を5___買いました。
5. 写真を10___撮りました。

**Варианты:** 杯、匹、枚、人、冊

## Упражнение 5: Культурные факты

Ответьте на вопросы по японской культуре:

1. 初詣はいつ行きますか。→ __________
2. お花見は何をしますか。→ __________
3. 大晦日に何を食べますか。→ __________
4. 「いただきます」はいつ言いますか。→ __________
5. お土産は何ですか。→ __________

## Ответы

**Упражнение 1:**
食べました, 行きました, 飲みました, しました, 来ました, 高かったです, 元気でした

**Упражнение 2:**
1. 昨日テレビを見たり音楽を聞いたり休んだりしました。
2. 週末本を読んだり散歩したり料理したりしました。
3. 日本で寿司を食べたりお寺を見たり温泉に行ったりしました。

**Упражнение 3:**
1. 暑いから、窓を開けます。
2. お腹が空いたから、ご飯を食べます。
3. 日本語は難しいですが、面白いです。

**Упражнение 4:**
1. 人, 2. 匹, 3. 杯, 4. 冊, 5. 枚

**Упражнение 5:**
1. 1月1日から7日ごろまで
2. 桜を見ながら食べたり飲んだりします
3. 年越しそば
4. ご飯を食べる前
5. 旅行先で買ってくるお菓子や工芸品
