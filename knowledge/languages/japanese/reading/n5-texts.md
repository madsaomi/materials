## Текст 1: わたしのともだち（Мой друг）

```
わたしには　ともだちが　います。
なまえは　ゆきです。
ゆきは　がっこうで　いっしょです。
ゆきは　まいにち　６じに　おきます。
そして、ジョギングを　します。
ゆきは　スポーツが　だいすきです。
でも、べんきょうは　あまり　しません。
しゅうまつは　よく　こうえんへ　いきます。
```

**Перевод:**
У меня есть друг. Её зовут Юки. Мы учимся в одной школе. Юки встаёт каждый день в шесть. Потом делает пробежку. Юки очень любит спорт. Но занимается учёбой не очень много. По выходным часто ходит в парк.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 友達 | ともだち | друг |
| 一緒 | いっしょ | вместе |
| 毎日 | まいにち | каждый день |
| 起きる | おきる | вставать |
| ジョギング | — | бег трусцой |
| 大好き | だいすき | очень любить |
| 勉強 | べんきょう | учёба |
| 公園 | こうえん | парк |

**Вопросы:**
1. ゆきさんは　なんじに　おきますか。
2. ゆきさんは　しゅうまつに　どこへ　いきますか。

*(Ответы: 1. 六時に起きます。 2. よく公園へ行きます。)*

## Текст 2: あさの　じかんわり（Распорядок утра）

```
まいあさ　６じはんに　おきます。
まず、かおを　あらいます。
それから、ちょうりを　します。
ごはんを　たべて、コーヒーを　のみます。
７じ３０ふんに　いえを　でます。
えきまで　あるいて、１０ぷんぐらいです。
でんしゃで　かいしゃへ　いきます。
```

**Перевод:**
Каждое утро встаю в полседьмого. Сначала умываюсь. Потом готовлю. Поем и выпью кофе. В семь тридцать выхожу из дома. До станции иду пешком минут десять. На электричке еду в офис.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 時間割 | じかんわり | распорядок |
| 半 | はん | половина |
| 顔を洗う | かおをあらう | умываться |
| 出る | でる | выходить |
| 駅 | えき | станция |
| 歩く | あるく | идти пешком |
| 会社 | かいしゃ | компания |

**Вопросы:**
1. なんじに　いえを　でますか。
2. えきまで　どうやって　いきますか。

*(Ответы: 1. 7時30分に出ます。 2. 歩いて行きます。)*

## Текст 3: わたしの　かぞく（Моя семья）

```
わたしの　かぞくは　４にんです。
ちちは　びょういんで　はたらいて　います。
ははは　りょうりが　じょうずです。
あには　だいがくせいです。
すうがくを　べんきょうして　います。
いもうとは　まだ　ちいさいです。
でも、ひらがなが　よめます。
```

**Перевод:**

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 家族 | かぞく | семья |
| 病院 | びょういん | больница |
| 働く | はたらく | работать |
| 上手 | じょうず | умелый |
| 兄 | あに | старший брат |
| 数学 | すうがく | математика |
| 妹 | いもうと | младшая сестра |
| みんな | — | все |

**Вопросы:**
1. おとうさんは　どこで　はたらいて　いますか。
2. どようびに　なにを　しますか。

*(Ответы: 1. 病院ではたらいています。 2. みんなでえいがを見ます。)*

## Текст 4: コンビニで（В круглосуточном магазине）

```
コンビニは　２４じかん　あいて　います。
とても　べんりです。
パンや　おにぎりや　のみものが　あります。
お弁当も　かえます。
コンビニで　きっても　かえます。
コピーも　できます。
夜も　あいているので、
しごとの　あとで　かいものが　できます。
```

**Перевод:**
Конбини открыты 24 часа. Очень удобно. Есть хлеб, онигири и напитки. Можно купить бэнто. В конбини продаются даже марки. Есть копир. Так как открыто и ночью, можно делать покупки после работы.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ２４時間 | にじゅうよじかん | 24 часа |
| 開く | あく | быть открытым |
| 便利 | べんり | удобный |
| 売れる／買える | うれる／かえる | продаваться / мочь купить |
| 切手 | きって | почтовая марка |
| 夜 | よる | ночь |
| 買い物 | かいもの | покупки |

**Вопросы:**
1. コンビニで　なにが　かえますか。
2. どうして　べんりですか。

*(Ответы: 1. パン、おにぎり、飲み物、弁当、切手など。 2. 24時間開いていますから。)*

## Текст 5: てんきと　やてい（Погода и планы）

```
きょうの　てんきよほうを　みました。
あしたの　あさは　はれそうです。
でも、ごごは　くもりになるそうです。
こんしゅうまつ、こうえんで　ピクニックを　します。
だから、あした　サンドイッチを　つくって　おきます。
もし　あめが　ふったら、うちで　えいがを　みます。
```

**Перевод:**
Посмотрел сегодняшний прогноз погоды. Завтра утром, похоже, будет ясно. Но после обеда, говорят, станет облачно. В эти выходные устраиваем пикник в парке. Поэтому завтра заранее сделаю сэндвичи. Если пойдёт дождь — посмотрим дома фильм.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 天気予報 | てんきよほう | прогноз погоды |
| 晴れ | はれ | ясно |
| 曇り | くもり | облачно |
| ピクニック | — | пикник |
| 作っておく | つくっておく | сделать заранее |
| もし | — | если вдруг |

**Вопросы:**
1. あしたのごごは　どんな　てんきですか。
2. あめが　ふったら、なにを　しますか。

*(Ответы: 1. くもりになるそうです。 2. うちでえいがを見ます。)*

## Текст 6: わたしの　まち（Мой город)

```
わたしの　まちは　ちいさいですが、
とても　いいところです。
えきの　まえに　スーパーが　あります。
みせの　となりに　ほんやが　あります。
こうえんも　ふたつ　あります。
こどもたちが　まいにち　あそんで　います。
しんかんせんの　えきは　とおいですが、
バスで　３０ぷんぐらいです。
```

**Перевод:**
Мой городок маленький, но очень хорошее место. Перед станцией есть супермаркет. Рядом с магазином — книжный. Парков тоже два. Дети играют там каждый день. Станция синкансэна далеко, но на автобусе минут тридцать.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 町 | まち | городок |
| 所 | ところ | место |
| 本屋 | ほんや | книжный магазин |
| 二つ | ふたつ | два |
| 子供 | こども | ребёнок |
| 遊ぶ | あそぶ | играть |
| 新幹線 | しんかんせん | синкансэн |

**Вопросы:**
1. スーパーは　どこに　ありますか。
2. こうえんは　いくつ　ありますか。

*(Ответы: 1. 駅の前にあります。 2. 二つあります。)*

## Текст 7: しゅうまつの　やすみ（Выходные)

```
どようびの　あさ、ゆっくりねました。
ひるごはんは　ともだちと　ラーメンを　たべました。
ごご、ほんやへ　いきました。
新しい　ざっしを　かいました。
その　あと、こうえんを　さんぽしました。
にちようびは　いえでの　べんきょうでした。
でも、ちょっと　つかれました。
```

**Перевод:**
В субботу утром выспался. На обед с другом поел рамэн. После обеда сходил в книжный. Купил новый журнал. Потом гулял в парке. Воскресенье было домашним днём учёбы. Но немного устал.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ゆっくり | — | спокойно, не спеша |
| ラーメン | — | рамэн |
| 雑誌 | ざっし | журнал |
| 散歩 | さんぽ | прогулка |
| 日曜日 | にちようび | воскресенье |
| 疲れる | つかれる | уставать |

**Вопросы:**
1. ひるごはんは　だれと　たべましたか。
2. ほんやで　なにを　かいましたか。

*(Ответы: 1. ともだちと食べました。 2. 新しい雑誌を買いました。)*

## Текст 8: わたしの　しゅみ（Моё хобби)

```
わたしの　しゅみは　しゃしんです。
まちや　しぜんの　しゃしんを　とります。
カメラは　ちいさいですが、いいカメラです。
しゅうまつには　よく　でかけます。
ときどき　うみへ　いきます。
うみの　しゃしんは　とても　きれいです。
らいねん、にほんへ　いって、
ふじさんの　しゃしんを　とりたいです。
```

**Перевод:**
Моё хобби — фотография. Снимаю город и природу. Фотоаппарат маленький, но хороший. По выходным часто выбираюсь куда-нибудь. Иногда езжу к морю. Фотографии моря очень красивые. В следующем году хочу съездить в Японию и сфотографировать Фудзи.

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 趣味 | しゅみ | хобби |
| 写真 | しゃしん | фотография |
| 自然 | しぜん | природа |
| カメラ | — | фотоаппарат |
| 出かける | でかける | выбираться |
| 海 | うみ | море |
| 来年 | らいねん | следующий год |

**Вопросы:**
1. どんな　しゃしんを　とりますか。
2. らいねん　なにを　したいですか。

*(Ответы: 1. まちやしぜんの写真をとります。 2. 日本へ行って、富士山の写真をとりたいです。)*

## Как работать с этими текстами

1. **Первое чтение** — только японский, без словаря. Отметьте непонятные места.
2. **Второе чтение** — со словарём и таблицей слов.
3. **Проговаривание вслух** — прочитайте текст громко 2 раза (отработка произношения).
4. **Свой пересказ** — расскажите содержание своими словами (по-японски или по-русски).
5. **Через неделю** перечитайте текст — он должен стать лёгким.
