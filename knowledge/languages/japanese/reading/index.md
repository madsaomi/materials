# Японский — Тексты для чтения

## Текст 1: 自己紹介 (Знакомство)

```
初めまして、田中太郎です。
東京大学の2年生です。
専攻はコンピュータサイエンスです。
趣味は読書と料理です。
どうぞよろしくお願いします。

翻訳:
Приятно познакомиться, я Танака Таро.
Я второкурсник Токийского университета.
Моя специальность — компьютерные науки.
Мои хобби — чтение и готовка.
Прошу любить и жаловать.

単語:
初めまして — приятно познакомиться
専攻 — специальность
趣味 — хобби
料理 — готовка, кухня
```

## Текст 2: 私の一日 (Мой день)

```
私は毎日6時に起きます。
まず、顔を洗って、朝ごはんを食べます。
7時に家を出て、電車で学校に行きます。
学校は9時から3時までです。
午後は図書館で勉強します。
夕方、友達と遊びます。
夜はテレビを見たり、本を読んだりします。
11時に寝ます。

翻訳:
Я каждый день встаю в 6 часов.
Сначала умываюсь и завтракаю.
В 7 выхожу из дома и еду на поезде в школу.
Школа с 9 до 3.
После обеда учусь в библиотеке.
Вечером играю с друзьями.
Ночью смотрю телевизор или читаю книгу.
В 11 ложусь спать.
```

## Текст 3: 日本の季節 (Времена года Японии)

```
日本には四季があります：春、夏、秋、冬。
春は3月から5月までです。
桜がとても綺麗です。
夏は6月から8月までです。
とても暑くて、湿度が高いです。
秋は9月から11月までです。
紅葉が美しいです。
冬は12月から2月までです。
寒いですが、雪景色が綺麗です。

翻訳:
В Японии четыре сезона: весна, лето, осень, зима.
Весна с марта по май.
Сакура очень красивая.
Лето с июня по август.
Очень жарко и влажно.
Осень с сентября по ноябрь.
Осенние листья красивы.
Зима с декабря по февраль.
Холодно, но снежные пейзажи красивы.
```

## Текст 5: 電車の中 (В поезде)

```
電車の中では、携帯電話で話さないでください。
マナーモードにしてください。
優先席の近くでは、携帯電話の電源を切ってください。
電車を降りるときは、降りる人のために道を開けてください。
混んでいる電車の中では、大きな声で話さないでください。
本を読むときは、他の人の邪魔にならないようにしてください。

翻訳:
В поезде не разговаривайте по мобильному телефону.
Поставьте на беззвучный режим.
Рядом с приоритетными местами выключайте телефон.
При выходе из поезда освободите дорогу выходящим.
В переполненном поезде не говорите громко.
При чтении книги старайтесь не мешать другим.

単語:
電車 (でんしゃ) — поезд
携帯電話 (けいたいでんわ) — мобильный
マナーモード — режим без звука
優先席 (ゆうううせき) — приоритетные места
電源 (でんげん) — питание
降りる (おりる) — выходить
混む (こむ) — быть переполненным
邪魔 (じゃま) — помеха
```

## Текст 6: 好きな食べ物 (Любимая еда)

```
私の好きな食べ物はラーメンです。
特にとんこつラーメンが大好きです。
週に一回ぐらいラーメン屋に行きます。
スープは豚骨で、とても濃い味です。
麺は細めんで、固めが好きです。
チャーシューと煮卵がのっています。
値段はだいたい800円から1000円です。
安くて美味しいので、学生に人気があります。

翻訳:
Моя любимая еда — рамэн.
Особенно люблю тонкоцу рамэн.
Хожу в рамэнную примерно раз в неделю.
Бульон свиной, очень насыщенный вкус.
Лапша тонкая, люблю твёрдую.
Сверху чашу и варёное яйцо.
Цена примерно 800-1000 иен.
Недорого и вкусно, поэтому популярен у студентов.

単語:
ラーメン — рамэн
とんこつ — свиная кость (тонкоцу)
スープ — суп/бульон
豚骨 (とんこつ) — свинина
濃い (こい) — густой/насыщенный
麺 (めん) — лапша
細い (ほそい) — тонкий
固い (かたい) — твёрдый
チャーシュー — чашу (свинина)
煮卵 (にたまご) — варёное яйцо
学生 (がくせい) — студент
人気 (にんき) — популярность
```
