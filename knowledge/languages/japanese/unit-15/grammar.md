# Unit 15 — Грамматика: 伝聞と推測（передача чужих слов)

## 1. Три степени передачи информации

| Форма | Уверенность | Стиль | Пример |
|-------|-------------|-------|--------|
| ～そうだ（слух) | «так сказали» | нейтрально | 雨が降るそうです。|
| ～らしい | «судя по источникам» | разговорно+ | 田中さんは忙しいらしい。|
| ～って | «говорят» | очень разговорно | 彼、結婚するって！|

Все три присоединяются к ПОЛНОЙ форме предложения（словарная/та/ない/た).

## 2. そうだ（слух): детали

```
天気予報によると、明日は雪が降るそうです。
По прогнозу, завтра пойдёт снег.

田中さんは転勤するそうだ。— Говорят, Танаку переводят.
```

**Прошедшее тоже передаётся полной формой:**
```
試験は難しかったそうです。— Говорят, экзамен был сложным.
```

❌ Нельзя спрягать：降るそうですよ ✓ / 降るそそうです ✗

Источник：〜によると／〜の話では.

## 3. らしい: слух + собственный вывод

らしい = то, что вы слышали, + лёгкая оценка правдоподобия:

```
あの店、美味しいらしいよ。
Говорят, тот магазин вкусный（сам не пробовал, но люди говорят уверенно).
```

Отличие от そうだ：
- そうだ —— чистая передача（«так сказали»)
- らしい —— передача + «похоже на правду»

らしい может идти и от существительных：彼は医者らしい。— Похоже, он врач（ведёт себя как врач).

## 4. Разговорные сокращения

| Полная форма | Разговорная | Пример |
|--------------|-------------|--------|
| ～そうだ | ～って / ～ってさ | 彼、転職するって。|
| ～らしい | ～って / ～らしいよ | 二人、別れたらしい。|
| ～と言っていた | ～って言ってた | ユキが言ってたよ。|

**って** заменяет と в цитатах вообще:
```
「遅れる」って言ってた。— Сказал, что опоздает.
ケンタって人 — человек по имени Кэнта.
```

## 5. ～とか — «или что-то такое»

Неопределённость источника или содержания:
```
北海道へ行くとか行かないとか… 
То ли едут в Хоккайдо, то ли нет…
```

## 6. Передача просьб/приказов: ～ように言われた

Продолжение юнита 11:
```
先生にレポートを出すように言われた。
Учитель велел сдать отчёт.

母に早く帰ってくるって言われて… 
Мама сказала вернуться пораньше（разг.)
```

---

## 7. Типичные ошибки

❌ 雨が降るそだそうです。→ ✅ 雨が降る**そうです**。(один そう!)
❌ 先生は学生だと聞いた（о учителе уважительно) → ✅ …と聞きました。（или：先生は学生**だそうだ**—— если источник надёжен)
❌ 美味しいそうな店。→ ✅ 美味し**いそうな**店。（い-прил. сохраняет い перед そう-слухом! Вкусно СОГЛАСНО слухам)
⚠️ Но：美味しそうな店 = выглядит вкусно（другая конструкция!)

## 8. Таблица различий そう（вид）/そう(слух)/らしい

| Форма | Источник | Пример | Перевод |
|-------|----------|--------|---------|
| おいしいそうだ | кто-то сказал | 聞いた話ではおいしいそうだ | говорят, вкусно |
| おいしそうだ | вид еды | 見ただけでおいしそう | выглядит вкусно |
| おいしいらしい | общее мнение | みんな言ってる、おいしいらしい | вроде вкусно |

# ЧАСТЬ 2 — Сводный справочник всего курса (итог N3-трека)

> Unit 15 — финальный. Ниже собраны ключевые конструкции юнитов 11–15 как единый справочник для итогового повторения.

## 9. 受身（пассив）— юнит 11

**Образование:**
- Глагол 1-й группы: 書く → 書**かれる**、話す → 話**される**
- Глагол 2-й группы: 食べる → 食べ**られる**
- する → される、来る → 来られる

```
友達にパソコンを壊された。
Мне сломали компьютер (комп был сломан другом).
```
- に — кто делает (агенс)
- を — что сделано с вами
- Часто выражает «мне неудобно, что это случилось»

## 10. 使役（каузатив）— юнит 11

**Образование:**
- 1-я группа: 書く → 書**かせる**、行く → 行**かせる**
- 2-я группа: 食べる → 食べ**させる**
- する → させる、来る → 来させる

```
母は私に宿題をさせる。
Мама заставляет меня делать домашку。
```
- С вежливостью: ～させてください (позвольте мне...)

**Каузатив-пассив（使役受身）:**
- 1-я группа: 書か**される**、行か**される**
- 2-я группа: 食べ**させられる**
- Значение: «меня заставляют» («быть вынужденным»)

```
毎日残業させられる。
Меня заставляют работать сверхурочно каждый день.
```

## 11. 敬語（кэйго）— юнит 12

**Три уровня вежливости:**

| Словарь | Тэйнгэй（丁寧) | Сонкэйго（尊敬) | Кэндзёго（謙譲) |
|---------|-------------|---------------|---------------|
| 行く | 行きます | いらっしゃる | 参る |
| 言う | 言います | おっしゃる | 申す |
| 食べる | 食べます | 召し上がる | いただく |
| する | します | なさる | 致す |
| 見る | 見ます | ご覧になる | 拝見する |
| 聞く | 聞きます | お聞きになる | 伺う |
| 知っている | 知っています | ご存じだ | 存じている |

**Сонкэйго（возвышение собеседника):** форма お＋ます語幹＋になる
```
お読みになる、お書きになる
```

**Кэндзёго（принижение себя):** форма お＋ます語幹＋する／いたす
```
お待ちする、ご案内いたす
```

**Вежливое просить：お～ください / ご～ください**
```
少々お待ちください。— Пожалуйста, подождите минуту.
ご確認ください。— Пожалуйста, проверьте.
```

## 12. Условия（と・ば・たら・なら・ても・のに）— юнит 13

| Форма | Функция | Пример |
|-------|---------|--------|
| ～と | естественный результат / повтор | 春になると桜が咲く |
| ～ば | условие (предположение) | 安ければ買います |
| ～たら | если (после этого, реальное) | 時間があったら行きます |
| ～なら | если речь о... (совет) | 京都なら秋がいいよ |
| ～ても | даже если / хоть | 雨でも行きます |
| ～のに | несмотря на, хотя | 勉強したのに合格しなかった |

**Отличия:**
- と — не используется для воли/просьбы в главной части（✗雨が降ると行く)
- たら — самое универсальное, подходит к большинству случаев
- なら — реагирует на тему собеседника

## 13. Опыт и завершение（ことがある・たばかり・ている）— юнит 10/6

```
日本に行ったことがありますか？
Вы бывали в Японии?
```
- ことがある + та-форма = «имел опыт»

```
ご飯を食べたばかりです。
Только что поел.
```
- たばかり = только что

## 14. である体（письменный стиль）— юнит 14

**Соответствия разговорный ↔ письменный:**

| Разговорный | Письменный |
|-------------|------------|
| だ | である |
| ではない | ではない |
| だと思う | であると考える |
| ます／です | る（та-форма / 辞書形) |
| い_form です | い_form ー |
| から | ので / なぜなら |
| のに | にもかかわらず |
| しかし | しかし／一方 |

**Пример:**
```
（口語）私は毎日勉強します。
（文語）我々は毎日勉強する。
```

## 15. 複合動詞（сложные глаголы）— юнит 14

| Состав | Значение | Пример |
|--------|----------|--------|
| ～始める | начать делать | 読み始める |
| ～終わる | закончить | 読み終わる |
| ～出す | внезапно начать | 怒り出す |
| ～続ける | продолжать | 走り続ける |
| ～抜く | довести до конца | 生き抜く |
| ～直す | переделать | 書き直す |
| ～過ぎる | слишком | 食べ過ぎる |
| ～合う | делать вместе | 話し合う |

## 16. 伝聞（そうだ・らしい・って・そうな）— итог юнита 15

**Полная таблица выбора правильной формы:**

| Контекст | Форма | Пример |
|----------|-------|--------|
| Услышал от кого-то (новость) | ～そうだ | 雨が降るそうです |
| Общее мнение / похоже | ～らしい | 彼女は医者らしい |
| Разговорный стиль | ～って | 明日休みだって |
| Внешний вид (вижу) | ～そう(な) | おいしそうなケーキ |
| Ссылка на источник | ～によると | 天気予報によると… |

**Ключевое отличие そう（слух) от そう（вид):**
- おいし**い**そう = «говорят, вкусно»（слух, い сохраняется)
- おい**し**そう = «выглядит вкусным»（вид, い→し)

## 17. ～てしまう・～ておく・～てみる（вспомогательные глаголы）

| Форма | Значение | Пример |
|-------|----------|--------|
| ～てしまう | завершить (жаль/внезапно) | 忘れてしまった |
| ～ておく | сделать заранее | 予約しておきました |
| ～てみる | попробовать | やってみます |
| ～ていく | продолжать/уходить делая | 歩いていく |
| ～てくる | прийти делая / начало | 覚えてきた |

# ЧАСТЬ 3 — Дополнительные конструкции: регистры передачи информации

## 19. Регистры передачи: от официального к «на ушко»

| Регистр | Форма | Пример | Перевод |
|---------|-------|--------|---------|
| Официальный (письмо/новости) | ～とのことだ | 明日、会議があるとのことです | Имею сообщить, что завтра совещание |
| Книжный / МАСС-медиа | ～ということだ | 政府が新法を検討しているということだ | Сообщается, что правительство рассматривает новый закон |
| Нейтральный | ～そうだ | 雨が降るそうです | Говорят, будет дождь |
| Разговорный | ～らしい | 彼は辞めるらしい | Вроде как он уходит |
| Семейный / «на ушко» | ～って | 夏休み、短いって | Говорят, каникулы короткие |

Форма определяется не содержанием, а **аудиторией**. Студент, пересказывающий новости родителям, использует って, а в отчёте для прессы — とのことだ.

## 20. ～ということだ — «суть в том, что…»

Живёт на стыке двух функций:
1) **Передача содержания чужого высказывания** (книжно):
```
専門家は「早めに寝るべきだ」と言っているということだ。
Смысл слов эксперта в том, что ложиться надо раньше.
```
2) **Косвенный вывод из фактов** (не цитата, а интерпретация):
```
彼が毎日遅くまで働いている。つまり、残業しているということだ。
Он каждый день работает допоздна. То есть суть в том, что он перерабатывает.

朝起きられないということは、夜更かししているということだ。
Раз ты не можешь встать утром — значит, засиживаешься ночами.
```

Обычно раскрывает **вывод/суть**, тогда как そうだ просто передаёт новость.

## 21. ～とのことだ — официальное уведомление

Используется в объявлениях, письмах, отчётах и пересказах по третьему лицу о третьем лице.
```
社長から急用とのことで、会議は延期になった。
По сообщению (слов) директора — срочные дела, совещание перенесли.

台風の接近に伴い、明日のイベントは中止とのことです。
Имею сообщить: из-за приближения тайфуна завтрашнее мероприятие отменяется.
```
Особенности:
- Часто сопровождает глагол 伺う/承る (получить уведомление): 〜とのこと伺いました。
- После とのことだ обычно **не следует** личное мнение без связки (для мнения есть と思う).

## 22. Формулы источника информации

| Формула | Оттенок | Пример |
|---------|---------|--------|
| 〜によると | стандарт (по новостям, прогнозам) | 天気予報によると、晴れるそうだ |
| 〜の話では | устный источник | 友達の話では、あの店は安いらしい |
| 〜によれば | формальнее, письменно | 調査によれば、八割が賛成だという |
| 〜が言うには | прямой говорящий | 彼が言うには、事故だったらしい |
| 会社として／私としては | от лица организации/человека | 会社としては、延期を予定しているとのことです |

⚠️ によると всегда тянет за собой форму слуха（そうだ／らしい／とか). Нельзя：〜によると、雨だ。✅ 〜によると、雨だそうだ。

## 23. みたいだ vs らしい детально

| Критерий | みたいだ | らしい |
|----------|---------|--------|
| Стиль | ещё разговорнее | разговорно-нейтрально |
| Откуда | не всегда слух: сходство/ирония | обычно сообщёние + оценка |
| な-прил. | 静かみたい ✗ → 静かなみたい | 静からしい |
| Сравнение/метафора | アニメみたいな世界 (мир как в аниме) | ✗（не выражает «как будто» o сравнении-образе) |
| Интонация | наивное наблюдение | чуть увереннее |

```
雲の形が犬みたいだ。（= похоже на собаку — образ)
彼は犬が好きらしい。（= судя по тому, что слышал — слух)
```

## 24. ～そうにない / ～そうもない — «вряд ли сделает»

Отрицание そう（вид): «и не похоже, что будет». Образуется от **ます-основы**.
```
雨がやみそうにない。
И не похоже, что дождь прекратится.

彼は来週までに終わりそうもない。
Совсем не похоже, что он закончит к следующей неделе.
```
Смысловой контраст:
- 終わりそうによくない: 終わりそうでない → «не похоже, что закончит» ✓
- НЕ путать с 終わりそうではない（неправильно для этого смысла).

Для слуха «вряд ли» есть отдельная форма: 〜なさそうだ（быть, казаться отсутствующим):
```
経験はなさそうだ。— Похоже, опыта нет.
```

## 25. ～っぽい — разговорная оценка «похоже на…»

Только для な-прилагательных, существительных и **воли глаголов** (через そう). Отличается от らしい:
- らしい = объективное сходство/слух
- っぽい = субъективное впечатление, часто с лёгкой иронией

```
あの店員、中国人っぽい。（на вид похож — впечатление)
彼は子供っぽい。（ведёт себя по-детски — оценка)
忘れっぽい人。（яз.вный: забывчивый буквально)
```

⚠️ っぽい не заменяет らしい в передаче новостей：✗ 明日、雨っぽい。（нет для погодных новостей; верно 明日雨らしい)

## 26. ～ってば / ～ったら — «я же говорю…»

Разговорные реактивные частицы (не передача информации, а реакция на неё):
```
早く来てってば！ — Да иди же скорее!
うちの課長ったら、また噂を信じてるの。 — Этот наш начальник — опять верит слухам.
```
- ってば — настаивание на просьбе/содержании
- ったら — удивление/укор о человеке-теме
Полезно в сплетнях для выражения раздражения «и как он такой…».

## 27. ～なんて — преуменьшение/недоумение в передаче

Способ внести оценку «да ну!» или «подумаешь».
```
噂なんて信じないよ。 — Да в такие слухи я не верю!
まさか、会社を辞めるなんて言わないでよね。
Не говори, мол, что увольняешься (это немыслимо)!
```
Если перед なんて стоит придаточное, его часть цитаты маркируется как «нелепая».

## 28. Прямая и косвенная речь: полный разбор

| Мысль оригинала | Прямая （直接話法) | Косвенная （間接話法) |
|-----------------|-------------------|----------------------|
| 「行きます」 | 彼は「行く」と言った | 彼は行くと言った（と + словарная) |
| 「行きましょう」 | 「行こう」と言った | 行こうと言った / 行くと言っていた |
| 「行ってください」 | 「行ってください」と言った | 行くように言った |
| просьба-отрицание | 「行かないで」 | 行かないように言った |
| вопрос | 「行きますか？」 | 行くかと聞いた / 行くかどうか聞いた |

Ключевые переходы:
- 命令 → ように
- 禁止 → ないように
- 質問-да/нет → 〜か／かどうか
- 質問-открытый → вопросительное слово + か

## 29. ～という話だ / ～という噂だ — устойчивые речевые обороты слуха

```
彼が社長になるという話だ。 — Есть разговоры, что он станет директором.
噂では、来月閉店するという噂が流れている。
По слухам, ходят разговоры о закрытии в следующем месяце.
```
Различие:
- という話だ — «есть разговоры/сообщения» (нейтрально)
- という噂だ — «распускают слух» (устойчивое, с оттенком «может, и неправда»)

## 30. Расширенный список ошибок + шпаргалка выбора

**Новые типичные ловушки:**
1. ❌ によると + 本心 → 天気予報によると、寒い。（голый факт) → ✅ 寒いそうだ。
2. ❌ することだ спутали с ということだ → ✅ したということだ（суть), することだ = «надо делать» (совет).
3. ❌ 彼は医者っぽい для «говорят, врач» → ✅ 彼は医者らしい。
4. ❌ みたい сделать передачей официальной новости → официально: であるそうだ / とのことだ.
5. ❌ そうにない после た-формы → そうにない только от ます-основы: 行きそうにない ✓.

**Шпаргалка принятия решения за 3 шага:**
1. Моя ли это собственная оценка по внешнему виду → **そう（вид)/そうにない**
2. Говорю, что слышал от конкретного человека → **そうだ（слух)/って/とのことだ**
3. Слышал краем уха + сам чуть сужу о правдоподобии → **らしい/みたいだ**

# ЧАСТЬ 4 — Сводный справочник-шпаргалка всего курса (иерархическая ревизия)

> Единая логика всей грамматики: сначала строится «голая» фраза, затем добавляются слои — вежливость, время, оценка, передача чужой речи. Ниже — 12 финальных справочных подразделов с примерами и связками.

## 31. Порядок наращивания слоёв в предложении

```
裸の文（голая фраза)
　↓ ① 時制（настоящее/прошедшее)
　↓ ② 共通の意味（可能・受身・使役・意向)
　↓ ③ 評価（そう・みたい・らしい)
　↓ ④ 伝聞（って・そうだ・とのこと)
　↓ ⑤ 丁寧（ます・です・敬語)
```

**Пример наращивания:**
```
食べる（есть)
→ 食べた（ел)
→ 食べられる（может есть / быть съеденным)
→ 食べられそう（похоже, может съесть)
→ 食べられそうだ（говорят, может съесть)
→ 食べられそうだと聞いた（слышал, что…)
```

## 37. 伝聞 полный выбор по уверенности и источнику

```
//
Уверен (видел сам)   → ～そうだ（вид）/ ～みたいだ
Услышал от конкретного → ～そうだ（слух）/ ～って
Оценка правдоподобия  → ～らしい
Официально/книжно     → ～とのことだ / ～ということだ
Пересказ чужой воли   → ～ように言われた / ～と言っていた
Неуверенность в деталях→ ～とか
```

## 38. Кэйго: быстрый поиск нужной формы

| Действие | Сонкэйго（для других) | Кэндзёго（для себя) |
|----------|----------------------|---------------------|
| идти/быть/приходить | いらっしゃる | 参る / 伺う |
| говорить | おっしゃる | 申す |
| есть/пить | 召し上がる | いただく |
| делать | なさる | 致す |
| видеть | ご覧になる | 拝見する |
| знать | ご存じだ | 存じている / 存じ上げる |

Правило выбора: если действие совершает **собеседник/вышестоящий** — сонкэйго; если **сам говорящий** по отношению к вышестоящему — кэндзёго.

## 39. Пассив и каузатив: идентификация «кто что делает»

```
Пассив（受身): XはYに〜される —— «над X совершают действие»
 例: 私は母に起こされる。（Меня будит мама)
Каузатив（使役): XはYに〜させる —— «X заставляет Y делать»
 例: 母は私に宿題をさせる。（Мама заставляет меня делать уроки)
Каузатив-пассив: 〜させられる —— «меня заставляют»
 例: 毎日残業させられる。（Меня заставляют перерабатывать)
```

## 40. Испорченный телефон: цепочка форм передачи

```
「噂をすれば影」—— слух обрастает преувеличениями.
Практика пересказа:
最初の人：山田さんが新しい仕事を始めるそうだ。
二人目　：山田さん、転職するらしいよ。
三人目　：山田さん、海外で働くって！
四人目　：山田さん、結婚するんだって！
```
Каждый шаг — новая форма. Задача: удержать суть, меняя лишь форму передачи.

## 41. Разговорные сокращения и реакции

| Разговорное | Полное | Значение |
|-------------|--------|----------|
| ってば / ったら | — | «я же говорю» (настаивание/укор) |
| なんて | — | «да уж эти...» (пренебрежение) |
| そういう | そのような | «такого рода» |
| マジで | 本当に | серьёзно? правда? (разг.) |
| やばい | 大変だ | «круто/плохо» (разг.) |
| すごい | 素晴らしい | потрясающе (разг.) |
| らしいよ | らしいです | вроде бы так (дружелюбно) |
| ってさ | そうだ | говорят (разг.) |

## 42. Итоговая шпаргалка принятия решения (3 уровня)

1. **Вижу сам** → そう（вид）／そうにない／みたいだ（образ)
2. **Услышал + передаю** → そうだ（слух）／って
3. **Слышал + оцениваю правдоподобие** → らしい
4. **Официально / письменно** → とのことだ／ということだ
5. **Перед этим — источник** → によると／の話では／によれば
