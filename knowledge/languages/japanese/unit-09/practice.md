# Unit 9 — Практика: Сравнения

## 1. Соедините в сравнения

Образец: 飛行機／電車／速い → 飛行機は電車より速いです。

1. 夏／冬／暑い → ＿＿＿＿＿＿＿＿＿＿
2. コーヒー／お茶／好き → ＿＿＿＿＿＿＿＿＿＿
3. 東京／大阪／大きい → ＿＿＿＿＿＿＿＿＿＿

## 2. Выбор из двух

Ответьте с のほうが:

1. 犬と猫とどちらが好きですか。
2. 海と山とどちらのほうが行きたいですか。
3. 手で書くのとパソコンで打つのとどちらが早いですか。

2. 日本料理の中で一番食べたいものは？
3. 家族の中で一番背が高いのは？

## 4. Заполните диалог

店員：何をお＿＿＿ですか。
客：カメラを探しています。一万円＿＿＿で。
店員：でしたら、こちらはいかがですか。
客：もう少し安いのはありませんか。
店員：では、こちらの＿＿＿が一千円安いですよ。
客：じゃ、それを＿＿＿。
