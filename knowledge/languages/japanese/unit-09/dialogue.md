# Unit 9 — Диалог: 電気屋さんで (В магазине электроники)

## Ситуация

Алиса выбирает новый ноутбук. Продавец помогает ей сравнить две модели. Отрабатываются сравнения (より/のほうが), вопросы о цене и качестве.

## Диалог

```
店員：いらっしゃいませ。何をお探しですか。
アリス：ノートパソコンを探しています。
店員：ご予算はどのくらいですか。
アリス：十万円ぐらいまでです。
店員：でしたら、こちらの二つがおすすめです。
　　A型とB型ですが、どちらがいいと思いますか。
アリス：うーん。A型のほうが軽いですね。
店員：そうです。でも、B型のほうが画面が大きくて、
　　処理も速いですよ。
アリス：値段はどうですか。
店員：A型は九万円、B型は十一万円です。B型のほうが
　　一万円高いですが、性能は上です。
アリス：どちらが人気がありますか。
店員：学生にはA型が一番人気です。会社員にはB型ですね。
アリス：私は学生なので…じゃあ、A型をください。
店員：かしこまりました。今、お包みします。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 何をお探しですか | Что вы ищете? |
| ご予算はどのくらい | Каков ваш бюджет? |
| おすすめ | рекомендация |
| どちらがいい | который из двух лучше? |
| A型のほうが軽い | модель A легче |
| 画面が大きくて | экран больше, и... |
| 処理も速い | обработка тоже быстрая |
| 性能は上 | характеристики выше |
| 一番人気 | самый популярный |
| 今、お包みします | сейчас упакую |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 店員 | てんいん | продавец |
| 探す | さがす | искать |
| 予算 | よさん | бюджет |
| 軽い | かるい | лёгкий |
| 画面 | がめん | экран |
| 処理 | しょり | обработка |
| 速い | はやい | быстрый |
| 値段 | ねだん | цена |
| 人気 | にんき | популярность |

## Культурная заметка

**Торговаться не принято.** В отличие от рынков многих стран, в японских магазинах цену не сбивают — это считается невежливым. Зато есть другие способы сэкономить: налоговые скидки для туристов (免税, めんぜい) при покупке от 5000円, сезонные распродажа (セール), балльные карты магазинов.

**Сервис:** в японском магазине вас провожают до двери с поклоном и кричат «ありがとうざいました». Упаковка — отдельное искусство: даже булочку красиво завернут в бумагу.

## Диалог 2: スーパーで (В супермаркете)

## Ситуация

Борис покупает продукты в супермаркете, сравнивает цены и решает, где выгоднее. Отрабатывается сравнение товаров.

## Диалог

```
店員：いらっしゃいませ。お会計はこちらです。
ボリス：すみません、このりんごは一ついくらですか。
店員：このりんごは一個百円です。あちらの安いのは
　　一個五十円です。
ボリス：大きいのはどちらですか。
店員：こちらのほうが少し大きいですが、高いです。
　　味はどちらも同じくらいですよ。
ボリス：じゃ、安いほうを六個ください。
店員：かしこまりました。全部で三百円になります。
ボリス：袋は有料ですか。
店員：はい、一枚五円です。エコバッグを持っていますか。
ボリス：持っています。ありがとうございます。
```

## Перевод

| Японский | Русский |
|----------|---------|
| お会計はこちらです | Оплата здесь |
| 一ついくらですか | Сколько стоит один? |
| あちらの安いの | вон тот дешёвый |
| 少し大きい | немного больше |
| 同じくらい | примерно одинаково |
| 全部で三百円 | всего 300 иен |
| 袋は有料ですか | пакет платный? |
| 一枚五円 | пять иен за штуку |
| 持っています | у меня есть (с собой) |

## Разбор грамматики

**安いほう** — «тот, что дешевле»; ほう (сторона) со сравнением: выбираем сторону.
**同じくらい** — «примерно одинаково»: 同じ + くらい (≈ «уровень тот же»).
**全部で** — «всего, в сумме», счётчик + で.

## Слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 会計 | かいけい | оплата, касса |
| りんご | — | яблоко |
| 一つ | ひとつ | один (штука) |
| 味 | あじ | вкус |
| 六個 | ろっこ | шесть штук |
| 有料 | ゆうりょう | платный |
| 無料 | むりょう | бесплатный |
| エコバッグ | — | эко-сумка |

## Диалог 3: 靴屋で (В обувном магазине)

## Ситуация

Катя хочет купить кроссовки, сомневается между двумя парами по размеру и цене. Отрабатываются 〜てほしい, 試着, сравнение.

## Диалог

```
店員：いらっしゃいませ。何かお探しですか。
カーチャ：ランニングシューズを探しています。
店員：こちらはいかがですか。今一番人気です。
カーチャ：ちょっと高いですね。もう少し安いのはありますか。
店員：こちらは半額です。でも、サイズが大きめです。
カーチャ：私のサイズに合うのがありますか。
店員：はい、二十三センチならあります。試着しますか。
カーチャ：はい、お願いします。
　　　　…ちょっと小さいです。もう一つのほうが良さそうです。
店員：では、そちらに交換しましょうか。
カーチャ：お願いします。あと、紐が短いのがありますか。
　　　　長いのを付けてほしいです。
店員：かしこまりました。少々お待ちください。
```

## Перевод

| Японский | Русский |
|----------|---------|
| ランニングシューズ | кроссовки для бега |
| 半額 | половина цены |
| 大きめ | чуть большего размера |
| サイズに合う | подходит по размеру |
| 試着します | примеряю |
| 良さそう | выглядит хорошо |
| 交換しましょう | давайте поменяем |
| 紐 | шнурки |
| 付けてほしい | хочу, чтобы прикрепили |

## Разбор грамматики

**〜がほしい** повторение в 紐が短いのがありますか — «есть те, у кого шнурки короче?»
**〜てほしい** — 付けてほしい: «хочу, чтобы (вы) прикрепили» — просьба другим.
**ーめ** (大きめ) — суффикс «слегка, с перевесом»: 大きめ (большеват), 小さめ (маловат).

## Слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 靴 | くつ | обувь |
| 靴屋 | くつや | обувной магазин |
| 半額 | はんがく | половина цены |
| 大きめ | おおきめ | чуть больше |
| サイズ | — | размер |
| 紐 | ひも | шнурки |
| 合う | あう | подходить |
| 交換 | こうかん | обмен |

## Диалог 4: 返品する (Возврат товара)

## Ситуация

Дима купил камеру, но она оказалась неисправной. Он возвращает товар. Отрабатываются вежливые просьбы и извинения.

## Диалог

```
ディマ：すみません。昨日こちらでカメラを買ったんですが、
　　　壊れてしまいました。
店員：あ、申し訳ございません。レシートはお持ちですか。
ディマ：はい、これです。
店員：ありがとうございます。どのように壊れましたか。
ディマ：電源が入りません。
店員：では、同じ商品と交換いたします。
ディマ：それでお願いします。もしまた壊れたら、
　　　返金はできますか。
店員：はい、保証書があれば返金できます。こちらが保証書です。
ディマ：助かりました。ありがとうございます。
店員：ご迷惑をおかけして、申し訳ございませんでした。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 壊れてしまいました | сломалась (неприятно) |
| 申し訳ございません | приносим извинения (очень вежливо) |
| レシート | чек |
| お持ちですか | у вас есть (вежл.) |
| 電源が入らない | не включается |
| 交換いたします | обменяем (谦逊) |
| 返金 | возврат денег |
| 保証書 | гарантийный талон |
| 助かりました | очень помогло |
| ご迷惑をおかけして | доставив вам неудобства |

## Разбор грамматики

**〜てしまいました** — 買ったんですが壊れてしまいました: 〜てしまう = «неприятно, что случилось».
**〜んですが** — объяснение причины перед просьбой: 買ったんですが (дело в том, что купил…).
**〜いたします** — 謙譲語 (кэндзёго) от する: «сделаю» (о своих действиях — смиренно).
**〜ば〜ます** — 保証書があれば返金できます: «если есть гарантия, можно вернуть деньги».

## Слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 壊れる | こわれる | ломаться |
| 電源 | でんげん | питание, электропитание |
| 交換 | こうかん | обмен |
| 返金 | へんきん | возврат денег |
| 保証書 | ほしょうしょ | гарантийный талон |
| 迷惑 | めいわく | неудобство, помеха |
| 助かる | たすかる | быть вырученным |
| レシート | — | чек |
