# Unit 9 — Диалог: 電気屋さんで (В магазине электроники)

## Ситуация

Алиса выбирает новый ноутбук. Продавец помогает ей сравнить две модели. Отрабатываются сравнения (より/のほうが), вопросы о цене и качестве.

## Диалог

```
店員：いらっしゃいませ。何をお探しですか。
アリス：ノートパソコンを探しています。
店員：ご予算はどのくらいですか。
アリス：十万円ぐらいまでです。
店員：でしたら、こちらの二つがおすすめです。
　　A型とB型ですが、どちらがいいと思いますか。
アリス：うーん。A型のほうが軽いですね。
店員：そうです。でも、B型のほうが画面が大きくて、
　　処理も速いですよ。
アリス：値段はどうですか。
店員：A型は九万円、B型は十一万円です。B型のほうが
　　一万円高いですが、性能は上です。
アリス：どちらが人気がありますか。
店員：学生にはA型が一番人気です。会社員にはB型ですね。
アリス：私は学生なので…じゃあ、A型をください。
店員：かしこまりました。今、お包みします。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 何をお探しですか | Что вы ищете? |
| ご予算はどのくらい | Каков ваш бюджет? |
| おすすめ | рекомендация |
| どちらがいい | который из двух лучше? |
| A型のほうが軽い | модель A легче |
| 画面が大きくて | экран больше, и... |
| 処理も速い | обработка тоже быстрая |
| 性能は上 | характеристики выше |
| 一番人気 | самый популярный |
| 今、お包みします | сейчас упакую |

## Культурная заметка

**Торговаться не принято.** В отличие от рынков многих стран, в японских магазинах цену не сбивают — это считается невежливым. Зато есть другие способы сэкономить: налоговые скидки для туристов (免税, めんぜい) при покупке от 5000円, сезонные распродажа (セール), балльные карты магазинов.

**Сервис:** в японском магазине вас провожают до двери с поклоном и кричат «ありがとうざいました». Упаковка — отдельное искусство: даже булочку красиво завернут в бумагу.
