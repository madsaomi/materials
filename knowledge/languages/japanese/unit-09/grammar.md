# Unit 9 — Грамматика: Сравнения и превосходство

## 1. Сравнение двух предметов: AよりBのほうが

```
A より B のほうが прилагательное
飛行機は電車より速いです。
= 電車より飛行機のほうが速いです。 — Самолёт быстрее поезда.
```

Порядок гибкий: より-часть может идти в начало.

## 2. Выбор из двух: どちらが

```
AとBとどちらが好きですか。
コーヒーとお茶とどちらがいいですか。 — Что вы предпочитаете: кофе или чай?
```
Ответ:
```
コーヒーのほうがいいです。 — Кофе (из этих двух).
```
> 💡 どちら используется строго для выбора из **двух**. Из трёх и более — どれ/何.

## 3. Превосходство: いちばん

```
クラスで一番背が高い人は誰ですか。 — Кто самый высокий в классе?
日本料理の中で寿司が一番好きです。 — Из японской кухни суши люблю больше всего.
```
Формула: **область + で + 一番 + прилагательное**

## 4. Прилагательные в сравнении

| Тип | Соединение | Пример |
|-----|------------|--------|
| い-прил. | くて | 軽くて、安い (лёгкий и дешёвый) |
| な-прил. | で | 静かで、きれい (тихое и красивое) |

Цепочка качеств: 大きくて、明るくて、便利な部屋。

## 5. Наречия степени

| Слово | Значение | Пример |
|-------|----------|--------|
| ずっと | намного, гораздо | B型のほうがずっと速い。 |
| 少し／ちょっと | немного | A型のほうが少し安い。 |
| くらい／ぐらい | примерно | 十万円ぐらい |
| まで | до (предел) | 十万円までです |

## 6. Хотеть иметь: 〜がほしい

```
新しいパソコンがほしいです。 — Хочу новый компьютер.
時間がほしいなあ。          — Эх, нужно больше времени.
```
> ⚠️ ほしい — это прилагательное! Отрицание: ほしくない。

## 7. Вопрос о выборе в магазине

| Вопрос продавца | Ответ покупателя |
|-----------------|------------------|
| 何をお探しですか。 | ノートを探しています。 |
| ご予算は？ | 五千円までです。 |
| こちらはいかがですか。 | ちょっと高いですね… |
| どちらになさいますか。 | じゃ、こちらをください。 |

## 8. Типичная ошибка

❌ コーヒーよりお茶が好きですか。(два предмета → лучше どちら)
✅ コーヒー**と**お茶**と**どちらが好きですか。
❌ 一番**に**好きです。
✅ 一番好きです。(без частицы)

---

## 9. 〜の中で — область превосходства

Формула: **область + の中で + 一番**
```
果物の中で何が一番好きですか。
Из фруктов какой любите больше всего?
```
```
一年の中で三月が一番忙しいです。
В году март самый загруженный.
```
С глаголами область берётся через の中でも／中で:
```
日本料理の中でも、ラーメンが一番食べたい。
Из японской кухни больше всего хочется рамэн.
```

## 10. Вопросительные слова для сравнения

| Слово | Когда | Пример |
|-------|-------|--------|
| どちら | из ДВУХ | AとBとどちらがいい？ |
| どれ | из многих (вещи) | この中でどれが安い？ |
| だれ | люди | クラスでだれが一番高い？ |
| どこ | места | ここらでどこが有名？ |
| いつ | время | 一年でいつが好き？ |
| どんな | качества | どんな車が欲しい？ |

> **Ловушка:** どちら может спрашивать и о направлении: どちらへ行きますか。— Куда направляетесь?

## 11. Степени сравнения без сравнения

Японский не имеет морфологических степеней (быстрее/быстрейший) — только конструкции:

| Смысл | Конструкция | Пример |
|-------|-------------|--------|
| более X | AよりBのほうが… | 今日のほうが涼しい。 |
| самый X | 一番 | 一番高い山 |
| намного X | ずっと | ずっと安い店 |
| чуть X | 少し／ちょっと | ちょっと大きいかな |
| всё более X | ますます／どんどん | どんどん高くなる |

## 12. ほしい и たい: желания

### ほしい（хочу вещь）
Прилагательное! Отрицание ほしくない:
```
新しいスマホがほしくてたまらない。
Очень-очень хочу новый смартфон.
```
### 〜たい（хочу действие）
Основа масу + たい; спрягается как い-прил.:
```
日本に行きたくても、時間がない。
Хочу в Японию, но нет времени.
```
### Хочу, чтобы кто-то сделал: 〜てほしい
Тэ-форма + ほしい:
```
早く来てほしいです。
Хочу, чтобы вы пришли поскорее.
```
> **Разница:** 行きたい — я хочу пойти; 行ってほしい — хочу, чтобы ТЫ пошёл.

## 13. В магазине: полезные формулы покупателя

| Фраза | Значение |
|-------|----------|
| これ、いくらですか。 | Сколько это стоит? |
| もう少し安いのはありますか。 | Есть подешевле? |
| 試着してもいいですか。 | Можно примерить? |
| 他の色はありますか。 | Есть другие цвета? |
| これをください。 | Давайте этот. |
| カードで払えますか。 | Можно картой? |
| 袋はいらないです。 | Пакет не нужен. |
| 領収書をください。 | Чек, пожалуйста. |

Ответы продавца:
```
いらっしゃいませ！— Добро пожаловать!
こちらいかがですか。— Как насчёт этого?
少々お待ちください。— Одну минуточку.
〇〇円になります。— С вас ... иен.
ありがとうございました！— Спасибо за покупку!
```

# Расширение грамматики Unit 9

## 15. 〜より〜のほうが с существительными и целыми фразами

Сравнивать можно не только прилагательные, но и глаголы, и целые конструкции:

```
電車に乗るよりバスに乗るほうが安いです。
Сесть на автобус дешевле, чем на поезд.
```
```
外で食べるより家で食べるほうが好きです。
Есть дома мне нравится больше, чем есть вне дома.
```

Если второй элемент понятен из контекста, のほうが может опускаться:
```
A：紅茶にしますか、コーヒーにしますか。
B：コーヒーにします。 (подразумевается «кофе предпочтительнее»)
```

## 16. 同じくらい — одинаково, наравне

Когда предметы не различаются, используют 同じくらい (одинаково, примерно столько же):
```
A型とB型は同じくらい軽いです。
Модель A и модель B примерно одинаково лёгкие.
```
```
私のパソコンと友達のパソコンは同じくらい古いです。
Мой компьютер и компьютер друга примерно одинаково старые.
```

> Вопрос: どちらが軽いですか？ → 同じくらいです。 (Одинаково.)

## 17. 一番 и формы «один из самых»

Чтобы сказать «один из самых», используют 一番…の一つ или 最も…の一つ (書面):
```
富士山は日本で一番高い山です。
Фудзи — самая высокая гора Японии.
```
```
東京は世界で一番人口が多い都市の一つです。
Токио — один из самых населённых городов мира.
```
> **Ловушка:** популярный оборот 一番…の一つ дословно «одна из самых» — допустим и для вещей.

## 18. ほど〜ない — «не такой … как»

Антоним конструкции より: ほど с отрицанием означает «не настолько … как»:
```
この机はあの机ほど高くないです。
Этот стол не такой дорогой, как тот.
```
```
日本語は英語ほど簡単じゃないです。
Японский не такой простой, как английский.
```

## 19. 比較的 и 割と — «сравнительно»

Наречия «сравнительно, относительно», полезные при описании товаров:
```
このカメラは比較的安いです。
Эта камера сравнительно дешёвая.
```
```
このノートは割と軽いです。
Этот ноутбук довольно лёгкий.
```
> **Разница:** 比較的 — нейтрально книжно; 割と／わりと — разговорное «довольно-таки».

## 20. 〜ば〜ほど — «чем … тем …»

Сравнительная «чем больше X, тем больше Y»:
```
安ければ安いほどいいです。
Чем дешевле, тем лучше.
```
```
大きければ大きいほど便利ですか。
Чем больше, тем удобнее?
```
> **Важно:** второй ほど обязателен: 「大きいほど便利だ」опущение допустимо только в беглой речи.

## 21. どちらでも／どちらも — «любой из двух / оба»

С частицами も и でも:
```
A：コーヒーと紅茶、どちらが好きですか。
B：どちらも好きです。 (люблю и то, и другое)
B：どちらでもいいです。 (любой подойдёт)
```
```
どちらでもいいから、早く決めてください。
Любой из двух подойдёт, решай быстрее.
```

## 22. 一番 + 場所・時間 (где/когда больше всего)

一番 можно сочетать с «где» и «когда»:
```
この都市で一番にぎやかな所はどこですか。
Какое место самое оживлённое в этом городе?
```
```
一年で一番寒い月は何月ですか。
Какой месяц самый холодный в году?
```

## 23. Сравнение качества: のほうがいいでしょ

Разговорная форма でしょう при сравнении — мягкая просьба согласиться:
```
もっと明るい色のほうがいいでしょ？
Свет от вам пойдёт больше, не так ли?
```
```
安い方はよく売れていますよ。
Дешёвые продаются хорошо.
```
