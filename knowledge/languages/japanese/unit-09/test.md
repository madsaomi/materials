# Unit 9 — Тест

## Часть 1: Выберите правильный вариант

**1. 電車より飛行機の＿＿＿が速いです。**
- а) こそ
- б) ほう
- в) より

**2. 犬と猫と＿＿＿が好きですか。**
- а) どちら
- б) だれ
- в) いつ

**3. 日本料理の中＿＿寿司が一番好きです。**
- а) を
- б) の
- в) で

**4. 新しいスマホが＿＿＿です。**
- а) ほしい
- б) ほしく
- в) ほしかった

## Часть 2: Соедините

1. 免税 — а) сдача
2. お釣り — б) скидка
3. 割引 — в) без налога (для туристов)
