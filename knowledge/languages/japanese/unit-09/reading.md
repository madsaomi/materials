# Unit 9 — Чтение: ネットショッピングと実店舗 (Онлайн vs офлайн)

## Текст

```
最近、物を買う時、ネットショップと
実際の店とどちらを使うか迷う人が多い。

ネットショッピングは店より便利だ。
家にいながら買い物ができて、
値段も少し安いことが多い。
特に、重い物や大きい物は
届けてもらえるので楽だ。

しかし、実際に手に取って見られない
という欠点がある。服なら、
試着できないと心配だし、色も
画面と違うことがある。

私の意見はこうだ。日常品はネットで、
服や靴など、自分に合うか確かめたい物は
実際の店で買うのが一番だと思う。
どちらも長所と短所があるから、
上手に使い分けたい。
```

## Вопросы к тексту

1. Назовите два преимущества онлайн-покупок из текста.
2. Почему автор осторожен с одеждой в интернете?
3. В чём состоит мнение автора?
4. Что означает выражение 使い分ける?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 実際 | じっさい | на самом деле |
| 迷う | まよう | сомневаться |
| 届ける | とどける | доставлять |
| 楽 | らく | легко, удобно |
| 手に取る | てにとる | взять в руки |
| 欠点 | けってん | недостаток |
| 試着する | しちゃくする | примерять |
| 意見 | いけん | мнение |
| 日常品 | にちじょうひん | товары повседневные |
| 長所／短所 | ちょうしょ／たんしょ | достоинства / недостатки |
| 使い分ける | つかいわける | использовать по назначению |

## Разбор грамматики в тексте

**買い物ができて**
→ て-соединение: «можешь делать покупки, и...».

**届けてもらえるので**
→ てもらう + 可能形: «могу получить доставку».

**試着できないと心配だし**
→ と условие + し перечисление причин: «если не могу примерить — беспокоюсь, и...».

**買うのが一番だと思う**
→ の номинализация + 一番 + と思う: «думаю, лучше всего покупать...».
