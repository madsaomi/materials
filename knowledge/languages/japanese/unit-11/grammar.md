# Unit 11 — Грамматика: 受身と使役（пассив и каузатив)

## 1. Пассивная форма（受身形)

Образуется как потенциальная у группы 2, но с другим смыслом:

| Группа | Правило | Пример |
|--------|---------|--------|
| 1 | -у ряд → -а ряд + れる | 書く → 書かれる |
| 2 | る → られる | 食べる → 食べられる |
| 3 | する→される、来る→来られる | — |

⚠️ Совпадает с потенциальной у группы 2 и 3! Различие —— только по контексту и частицам.

### Два типа пассива

**Прямой пассив**（объект действия становится подлежащим):
```
弟は先生に褒められました。
Младшего брата похвалил учитель.
```

**Пассив страдания/неудобства:** действие постороннего причиняет вам неудобство:

| Ситуация | Фраза |
|----------|-------|
| Дождь пошёл, когда вы вышли | 雨に降られました。 |
| Ребёнок плакал всю ночь | 赤ちゃんに泣かれて、眠れなかった。 |
| Друг одолжил деньги и не вернул | 友達にお金を貸されて困っている。 |
| В метро на ногу наступили | 電車の中で足を踏まれた。 |

Формула: **пострадавший は + источник に + глагол-受身**

## 2. Каузатив（使役形) — «заставить / позволить»

| Группа | Правило | Пример |
|--------|---------|--------|
| 1 | -у → -а + せる | 書く → 書かせる |
| 2 | る → させる | 食べる → 食べさせる |
| 3 | する→させる、来る→来させる | — |

**Два оттенка:**
- Заставить（принуждение): 母は私に野菜を食べさせました。— Мама заставила меня есть овощи.
- Позволить（разрешение): 先生は学生たちに質問させました。— Учитель дал студентам задать вопросы.

Частица при исполнителе —— を（жёсткое принуждение）или に（мягкое/разрешение):
```
母が子供を野菜を食べさせた。（жёстко)
母が子供に好きなだけ遊ばせた。（разрешила играть сколько хочет)
```

## 3. Каузативно-пассивная форма（使役受身) — «меня заставили»

Каузатив + 受身：самая «страдательная» форма японского.

```
行く → 行かせる → 行かされる
言う → 言わせる → 言わされる
残る → 残らせる → 残らされる
```

```
昨日、二時間も待たされました。
Вчера меня заставили ждать целых два часа.

部長に酒を飲まされて、頭が痛い。
Начальник споил меня（заставил выпить), голова болит.
```

> 💡 Всегда несёт оттенок「мне это не нравилось」. Если заставили делать что-то приятное， используют обычный каузатив или ～てもらう.

## 4. ～ように言われる — «велели сделать»

Косвенное поручение через чужой голос:
```
店長にレジを覚えるように言われました。
Заведующая велела мне освоить кассу.

医者にタバコをやめるように言われた。
Врач сказал бросить курить（досл.: был сказан бросить).
```

## 5. Переходные и непереходные пары

Японский обожает пары 自動詞/他動詞. Пассив непереходного часто означает「сломалось само」, активного переходного，「кто-то сломал」:

| Непереходный（сам) | Переходный（кто-то) |
|--------------------|---------------------|
| ドアが開いている（открыта) | ドアを開けてある（открыл кто-то) |
| 電気がついている（горит) | 電気をつけた（зажёг) |
| 窓が閉まっている（закрыта) | 窓を閉めた（закрыл) |
| 落ちる（упасть) | 落とす（уронить) |
| 壊れる（сломаться) | 壊す（сломать) |

---

## 6. Типичные ошибки

❌ 私は先生が褒められた。→ ✅ 私は先生**に**褒められた。(источник —— に)
❌ 子供に野菜**が**食べさせた。→ ✅ 子供**に**野菜**を**食べさせた。
❌ 雨が降られて…（нейтральное описание) → ✅ 雨に降られて困った。(есть оттенок неудобства)
❌ 来られる = «прийти» в вежливой форме И «быть пришедшим» —— различайте по контексту!

---

## 7. Мини-сравнение трёх форм

| Форма | Кто действует | Оттенок | Пример |
|-------|---------------|---------|--------|
| 書く | я пишу | нейтрально | 手紙を書いた。|
| 書かれる | письмо написано мной／меня написали? нет—— меня критиковали письменно | пассив | 部長に名前を書かれた。|
| 書かせる | я заставляю писать | каузатив | 弟に手紙を書かせた。|
| 書かされる | меня заставили писать | каузатив+пассив | 宿題を書かされた。|

---

## 8. Практика устами диалога

Найдите в диалоге юнита все формы и классифицируйте:

```
着替えてください → просьба（обычная)
着替えさせます → каузатив（позволяю переодеться)
扫いておいてください → ておく + просьба
扫かされた → каузативно-пассив（Кэнту заставляли)
切らされた / 出させられた → то же
注文したのは紅茶 → относительное предложение
お持ちします → скромный кэйго（謙譲語) —— предвестие юнита 12!
残ってもらいます → てもらう в вежливой речи начальника
残らされるんですか → каузативно-пассив + объяснение んです
```
