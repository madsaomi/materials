# Unit 14 — Грамматика: 文章体（письменный стиль)

## 1. である体: правила переключения

| Разговорный（です・ます) | Письменный（だ・である) |
|--------------------------|--------------------------|
| 学生です | 学生である / 学生だ |
| 高いです | 高い（い-прил. без изменений!) |
| 静かです | 静かである / 静かだ |
| 勉強します | 勉強する |
| 勉強しません | 勉強しない |
| 勉強しました | 勉強した |

**Ключ:** глаголы и い-прилагательные просто отбрасывают вежливость; な-прил. и существительные получают である/だ.

## 2. Маркеры письменного стиля

| Разговорный | Письменный | Значение |
|-------------|-----------|----------|
| ～けど、～でも | ～が、～しかし | но |
| ～から | ～ため、～ので（форм.) | потому что |
| ～と | ～ということは | это значит |
| ちょっと | やや、少し | немного |
| たくさん | 多くの、多数の | много |
| これ／それ | 本件、同様、当該 | формальные указатели |
| 言う | 述べる、指摘する | утверждать, отмечать |

## 3. 複合動詞 — составные глаголы

Глагол + вспомогательный глагол = точный оттенок:

| Составной | Разбор | Значение |
|-----------|--------|----------|
| 働き始める | 働く+始める | начать работать |
| 働き続ける | +続ける | продолжать работать |
| 働き過ぎる | +過ぎる | переработать |
| 直し始める | 直す+始める | начать чинить |
| 見直す | 見+直す | пересмотреть |
| 話し合う | 話す+合う | беседовать（взаимно) |
| 助け合う | +合う | помогать друг другу |
| 食べ終わる | +終わる | закончить есть |
| 売り切れる | 売る+切れる | распродано |

Формула：основа масу + [始める/続ける/直す/合う/過ぎる/終わる/切れる/出す].

## 4. ～について / ～に関して

Письменные маркеры темы:

```
留学生の生活について書く。— писать о жизни студентов.
環境問題に関して意見を述べる。— высказаться по экологии.
```
関して формальнее ついて —— для резюме и статей.

## 5. Формальные связки эссе

| Связка | Функция | Пример |
|--------|---------|--------|
| しかしながら | однако（книжн.) | Однако… |
| その結果 | в результате | В результате выросло… |
| 一方 | с другой стороны | Одна сторона рынка… другая… |
| したがって | следовательно | Следовательно необходимо… |
| 例えば | например | Например… |
| 要するに | короче говоря | Итого… |

Каркас эссе：まず現状を述べる → 次に問題点を挙げる → 最後に提案する。

## 6. Типичные ошибки

❌ 私は週五日働いています。（в статье) → ✅ 筆者は週五日勤務している。
❌ とても面白いだ。→ ✅ とても面白い。（い-прил. не берёт だ!) или 面白いのである。
❌ 私について話します。→ ✅ 自分について述べる。（письм.)
❌ である調で「〜ましょう」→ ✅ 提案したい / ～すべきである。

## 7. Мини-эссе целиком（образец)

```
留学生とアルバイト

筆者は一年前より、喫茶店でアルバイトをしている。
きっかけは経済的な必要性であったが、今では
日本社会を学ぶ貴重な機会となっている。

実際、店長に厳しく指導され、何度も失敗もした。
しかし、働き続けるうちに敬語が自然に使えるように
なり、客との会話も楽しく感じられるようになった。

要するに、アルバイトは単なる収入源ではなく、
生きた教科書であると言えるだろう。
```

Найдите：である ×2 · だった · ～うちに · ～ようになった · 要するに · と言えるだろう。

## 8. Парадигма письменного стиля

Полная таблица для всех форм (без ます):

| Форма | 書く | 食べる | する | 来る |
|-------|------|--------|------|------|
| Словарная | 書く | 食べる | する | 来る |
| Отрицание | 書かない | 食べない | しない | 来ない |
| Прошедшее | 書いた | 食べた | した | 来た |
| Отрицат. прош. | 書かなかった | 食べなかった | しなかった | 来なかった |
| Эмфаза | 書くのである | 食べるのである | するのである | 来るのである |
| Возможность | 書ける | 食べられる | できる | 来られる |
| Пассив | 書かれる | 食べられる | される | 来られる |
| Каузатив | 書かせる | 食べさせる | させる | 来させる |
| べき | 書くべきだ | 食べるべきだ | すべきだ | 来るべきだ |

Отрицание и прошедшее — те же, что в разговорном; меняется только связка и финальная вежливость.

## 9. のである / のだ — вывод и эмфаза

В письменном стиле のだ произносится и пишется のである:

| Контекст | Разговорный | Письменный |
|----------|-------------|------------|
| Объяснение факта | 学生は忙しいのだ | 学生は忙しいのである |
| Вывод из данных | つまり…という意味だ | ゆえに…のである |
| Обобщение | それが現実だ | これが現実なのである |

```
若者は金銭以上に経験を重視し始めたのである。
— Молодёжь именно что начала ценить опыт больше денег.
```

## 10. Причина: ため / ゆえに / ～からには

Разговорное から в статье звучит слабо. Формальные варианты причины:

| Выражение | Значение | Пример |
|-----------|----------|--------|
| ～ため（に） | из-за, вследствие | 人手不足のため、対応が遅れている。 |
| ～ゆえに | поэтому (книжн.) | 経験不足ゆえに失敗した。 |
| ゆえの | проистекающий из | 準備不足ゆえの失敗である。 |
| したがって | следовательно | したがって、対策が必要である。 |

注意: ～ため ≠ «для того чтобы»; в этом значении ために (цель) различают по контексту.

## 11. Маркеры темы: に関して / をめぐって / を対象に

Три уровня формальности темы:

```
〜について    — нейтрально: アルバイトについて書く。
〜に関して    — официально: 環境問題に関して意見を述べる。
〜をめぐって  — спорно, конфликтно: 予算をめぐって論争が起きた。
```

Для опросов вводят объект через を対象とする / を対象に:

```
全国の大学生を対象に調査を行った。
— Провели опрос, объектом которого стали студенты по всей стране.
```

## 12. として — «в роли, в качестве»

Письменный эквивалент «как (в качестве)»:

```
事例として 上げる。      — привести как пример.
参考として 挙げる。      — привести как справку.
結論として 述べる。      — заявить в качестве вывода.
留学の条件として 課す。  — требовать как условие учёбы.
```

С として постройте роли: 筆者として・当事者として・研究者として.

## 13. 上 (うえ): три модели

| Модель | Значение | Пример |
|--------|----------|--------|
| Nの上で・Vた上で | после того как | 検討した上で決定する。 |
| Nの上で | в (+ области) | 学業の上で支障が出る。 |
| Vる上で | при, в процессе | 読む上で注意すべき点がある。 |
| N上（じょう） | с точки зрения | 法律上・教育上・経済上 |

`上で` (после) и `上` (じょう, аспект) не путайте: 確認のうえ = после проверки, 法律じょう = юридически.

## 14. Формальный пассив и ～られる в статьях

Пассив — фирменный знак объективного стиля:

| Разговорный | Письменный |
|-------------|------------|
| 私は注意されました | 注意を受けた。 |
| 人が批判している | 批判されている。 |
| 僕は言われた | 指摘された。 |
| みんな期待してる | 期待されている。 |

Безличные пассивы: 考えられる（считается)· 認められる（признаётся)· 懸念される（вызывает опасения).

## 15. Уступительные: とはいえ / にもかかわらず / ものの

| Выражение | Значение | Пример |
|-----------|----------|--------|
| とはいえ | хотя и…, но всё же | 便利とはいえ、危険も伴う。 |
| にもかかわらず | несмотря на | 努力にもかかわらず失敗した。 |
| ものの | правда…, но | 買ったものの使っていない。 |
| としても | даже если | 賛成しても問題は残る。 |

Разговорный でも/けど уступает место этим конструкциям в абзацах-возражениях.

## 16. Цитирование: と述べる / とのこと / と指摘される

| Форма | Использование | Пример |
|-------|---------------|--------|
| ～と述べている | автор говорит | 筆者は…と述べている。 |
| ～と指摘される | отмечается | 専門家の間で指摘されている。 |
| ～としている | принято считать | 政府は…としている。 |
| ～とのことだ | сообщается (в сводках) | 中止とのことだ。 |

Письменное цитирование строит цепочку: 誰が（座）→ 何を（こと）→ と述べる.

## 17. Определения: すなわち / いわゆる / つまり

| Маркер | Функция | Пример |
|--------|---------|--------|
| すなわち | переформулировка | 六割、すなわち過半数が賛成した。 |
| いわゆる | название известного явления | いわゆる「Ｚ世代」である。 |
| つまり | итог (менее формально) | つまり結論は変わらない。 |

В статьях само определение оформляют через とは…である:

```
信頼とは、約束を守ることである。
— Доверие — это соблюдение обещаний.
```

## 18. 一方 / 反面 — противопоставление

| Связка | Значение | Пример |
|--------|----------|--------|
| 一方（で） | с другой стороны (контраст фактов) | 都市は混雑する一方、地方は過疎化する。 |
| 反面（はんめん） | зато, с обратной стороны | 便利な反面、依存の危険もある。 |
| に対して | по отношению к | 学生に対して説明する。 |

一方 чаще в статьях с параллельными данными; 反面 — для «плюс/минус» одного явления.

## 19. Числа и проценты в письменном стиле

| Разговорный | Письменный |
|-------------|------------|
| 68パーセント | 六十八パーセント（全角・漢数字) |
| 半分 | 五割・過半数 |
| 20時間 | 二十時間超・週二十時間以上 |
| だいたい | 約・およそ |
| ちょっと | やや |

Правило статей: проценты словами-кандзи, цифры прописи — 数字を漢数字に統一する.

## 20. Полные формы: сокращения → письменные

| Разговорный | Письменный |
|-------------|------------|
| じゃ | では |
| してない | していない |
| しちゃった | してしまった |
| ～しよう | ～するべきである / ～を提案する |
| ～ないだろう | ～ないであろう |

Ключевое правило: в である体 не используют 縮約（しゃくやく）— только полные формы.

## 21. Структура абзаца и каркас статьи

Классическая пирамида абзаца:

```
① トピック・センテンス — тезис
② 支持文(しじぶん)     — пример, данные, цитата
③ 結論文               — микро-вывод / переход
```

Каркас всей статьи: **序論**（現状＋問題提起）→ **本論**（根拠＋反論処理）→ **結論**（提案＋将来展望）.

## 22. Частые ошибки второй части

❌ です/ます в てもいい → ✅ してもよい。（письменно よろしい）
❌ 私は思います。→ ✅ 筆者は考える。／～と考えられる。
❌ つまり in начале абзаца → ✅ 要するに、こう言える。
❌ 大丈夫 → ✅ 問題ない。／支障はない。
❌ いくつ → ✅ 複数の（например 複数の問題点）。
❌ とても → ✅ 極めて・非常に（в научном тексте).
