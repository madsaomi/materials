# Unit 13 — Грамматика: 条件の極意（условия мастерство)

## Учебное ядро: Выбор условия: と・ば・たら・なら
## Условие выбирают для целой ситуации

Не существует надёжной таблицы «будущее = たら, логика = ば, разговор = なら» для всех случаев. Сначала решите, связываете ли вы обычный результат, отдельное событие, необходимое условие или уже допущенную собеседником ситуацию. Формы частично пересекаются; разные варианты могут быть грамматичны с разным акцентом.

| Что выделено | Пример | Разбор |
|---|---|---|
| Обычный результат действия | このボタンを押すと、画面が変わります。— Нажмёте кнопку — экран изменится. | Инструкция о работе устройства. |
| Условие достаточности | パスワードが分かれば、ログインできます。— Если знаете пароль, сможете войти. | Значение условия, при котором действие возможно. |
| После наступления события | 家に帰ったら、連絡してください。— Когда вернётесь домой, свяжитесь со мной. | Сначала возвращение, затем связь. |
| Реакция на предполагаемый план | 京都に行くなら、先に宿を予約してください。— Если собираетесь в Киото, сначала забронируйте жильё. | Совет может выполняться до поездки. |

## Образование без потери типа слова

と: словарная / отрицательная форма＋と; существительное и な-прилагательное в утверждении сохраняют だ: 休みだと. ば: 書く→書けば, 食べる→食べれば, する→すれば, 来る→来れば（くれば）; 安い→安ければ, いい→よければ. Для имени: 学生なら / 学生であれば.

たら: простая прошедшая＋ら — 書いたら, 安かったら, 静かだったら. なら: 行くなら, 行かないなら, 静かなら, 学生なら; в последних двух непрошедшее だ перед なら не ставят.

## Проверяйте ограничения, не объявляя все альтернативы ошибкой

Обычное условное と не используют для прямого приглашения «наступит X — давайте сделаем Y»: 時間があったら、一緒に話しましょう лучше, чем 時間があると、話しましょう. Но устойчивое Vるといい является отдельной моделью совета.

У ば возможность просьбы зависит от содержания условия: よければ、座ってください — «Если вам удобно, садитесь» — корректно. При условии, обозначающем намеренное действие того же лица, и следующей просьбе чаще требуется другой способ связи. Для первого шага выбирайте конкретное たら, когда важна последовательность, но не исправляйте любое ば без разбора смысла.

## «Даже если» не равно «поэтому»

雨が降っても、出かけます — «Выйду, даже если будет дождь». 雨が降っているのに、出かけました — «Хотя идёт дождь, вышел»: результат представлен вопреки ожиданию. 雨だから、傘を持ってきました — «Из-за дождя принёс зонт» — причина. のに не заменяет нейтральное «и»; само предложение с неожиданным сочетанием может быть правильным при подходящем ожидании.

## 1. Четыре условия: решающая таблица

| Форма | Функция | Ключевое слово | Пример |
|-------|---------|----------------|--------|
| と | автоматизм, закон | «каждый раз» | 春になると桜が咲く。 |
| ば | логика, гипотеза | «если выполнится условие» | 安ければ買う。 |
| たら | конкретный случай, будущее | «как только / если вдруг» | 雨が降ったら中止。 |
| なら | реакция на тему разговора | «если уж речь о…» | 京都なら新幹線。 |

### Тест на выбор за 3 секунды

1. Это происходит КАЖДЫЙ РАЗ автоматически？ → **と**
2. Я РАССУЖДАЮ логически？ → **ば**
3. Это КОНКРЕТНЫЙ случай в будущем？ → **たら**
4. Собеседник УПОМЯНУЛ тему， я реагирую？ → **なら**

### Отрицательные формы

```
行かなければ、分からない。（не пойдёшь —— не узнаешь)
行かないと、怒られるよ。(не пойдёшь —— отругают)
```

〜ないと часто опускает вторую часть：宿題をしないと…（и что будет —— и так ясно).

## 2. ば: особые случаи

**Прилагательные:** 安ければ · 高ければ · 楽しければ
**Существительные:** 学生であれば
**Исключение:** いい → よければ

**Ограничения зависят от содержания условия:**

```
✅ 安ければ、旅行に行きましょう。— Если будет недорого, давайте поедем. Условие описывает состояние/цену и допускает приглашение.
✅ 安くなったら、旅行に行きましょう。— Когда/если подешевеет, давайте поедем. Здесь добавлен смысл изменения цены.
よければ、来てください。— Если удобно, приходите. Не запрещайте волю и просьбы после любой формы ば: ограничения отдельных моделей с действиями нельзя переносить на условия состояния.
```

## 3. ～ても: даже если

Тэ-форма + も = уступка вопреки:

```
雨でも行く。— Даже в дождь пойду.
何回聞いても分からない。— Сколько ни слушаю —— непонятно.
誰に聞いても同じ答えだった。— У кого ни спрашивал —— один ответ.
```

## 4. ～のに vs ～から／ので

| Связка | Направление | Эмоция |
|--------|-------------|--------|
| ので | причина → следствие | нейтрально, мягко |
| から | причина → следствие | прямо |
| のに | следствие вопреки причине | сожаление, удивление |

```
勉強したのに、落ちました。— Учился, а провалился（обида!).
勉強したから、受かりました。— Учился, поэтому сдал.
```

Связка のに представляет результат вопреки ожиданию; сила и вид эмоции зависят от контекста. Отдельное のに со значением назначения разбирается иначе.

## 5. もし～たら

もし усиливает гипотетичность：

```
もし宝くじが当たったら、家を買う。
Если（вдруг) выиграю в лотерею —— куплю дом.
```

## 6. ～ば～ほど: чем… тем…

```
日本語は勉強すればするほど面白い。
Чем больше учишь японский, тем интереснее.

この店は近ければ近いほど込んでいる。
Чем ближе этот магазин, тем он многолюднее.
```

Для глагола: 勉強すればするほど; для い-прилагательного: 高ければ高いほど. Называйте тип слова: перед ほど сохраняется 高い, а не глагольная форма.

## 7. Типичные ошибки

❌ 行くば、知らせてください。→ ✅ 行っ**たら**、知らせてください。（если/когда поедете; форма た от 行く — 行った)
❌ 高かれば高いほどいい。→ ✅ 高けれ**ば**高いほどいい。（у 高い правильная условная форма 高ければ, не 高かれば)
雨なのに傘を持ってきた — грамматически возможно, если именно наличие зонта неожиданно в контексте. Для обычного объяснения «взял зонт из-за дождя»: 雨だから、傘を持ってきた. Это различие смысла и ожидания, а не неисправная форма のに.
十時になると閉まります — естественно о регулярном закрытии в десять. 十時になれば閉まります тоже может выражать условие наступления этого времени; не объявляйте ば неграмматичным без контекста.

## 8. Диалог как полигон

Найдите в диалоге юнита:

```
貯金があれば → ば（логика Юки)
失敗したら → たら（страх Танаки)
失敗しても → ても（упрямство Юки)
見つかればまだしも → ば + まだしом（уступка с оговоркой)
本気なら → なら（Алиса реагирует на тему)
教えてもらおうかな → волitional + かな（раздумье)
```

Восемь условий в одном споре —— вот почему японцы спорят изящно.

## 9. ～ことにする vs ～ことになる

Разница между личным решением и внешне сложившимся положением:

| Форма | Смысл | Пример |
|-------|-------|--------|
| ～ことにする | лично решил | 会社を辞めてカフェを開く**ことにした**。— Решил открыть кафе（сам） |
| ～ことになる | получилось, так вышло | 転勤**することになった**。— Получилось, что меня переводят |
| ～ことにしたんだ | решил（и делюсь с собеседником) | 明日から朝早く起きることにしたんだ。 |

```
ダイエットをすることにした。— Я решил сесть на диету（мой выбор）。
会議は来週に延期されることになった。— Сложилось так, что встречу перенесли。
```

## 10. ～つもりだ：намерение и ложная уверенность

| Форма | Смысл |
|-------|-------|
| ～つもりだ | намереваюсь (на самом деле） |
| ～つもりだった | собирался（но не сделал) |
| ～つもりで | с мыслью, как будто |
| ～たつもりで | считая, что сделал |

```
来年カフェを開くつもりです。— На следующий год собираюсь открыть кафе。
買うつもりはなかった。— Не собирался покупать。
死んだつもりで頑張る。— Буду стараться изо всех сил（словно забыв о риске）。
```

## 11. ～わけにはいかない：никак нельзя

Выражает внутренний или социальный запрет「не могу позволить себе」:

```
お金がないから、旅行するわけにはいかない。
Денег нет, так что никак не могу позволить себе поездку。
客が待っているから、休むわけにはいかない。
Ждут клиенты —— никак не могу отдыхать。
```

## 12. ～はずだ：предположение с логикой

- はずだ — «должно быть, потому что так логично»
- はずがない — «не может быть, что…»

```
練習すれば、上手になるはずだ。— Если тренироваться, должно получиться лучше。
宝くじに当たるはずがない。— Не может быть, чтобы я выиграл в лотерею。
予約したから、席は空いているはずだ。— Я бронировал, так что место должно быть。
```

## 13. ～って：разговорное сокращение（тема, цитата)

В диалоге Юки часто опускает と、は、と聞いた —— разговорный стиль:

| Полная форма | Разговорная | Пример |
|--------------|-------------|--------|
| ～と思います | ～って思う | いい**って**思う |
| ～と言う | ～って言う | 彼は来る**って** |
| ～は | ～って | カフェ**って**いいね |

```
この店、人気があるって聞いたよ。— Слыхал, этот магазин популярный。
アリスさんが来るって言ってた。— Алиса говорила, что придёт。
```

## 14. ～ばかり：только и делает

| Форма | Смысл |
|-------|-------|
| ～ばかり | только этим и занимается |
| ～てばかり | только и делает, что… |
| ～ばかりだ | только растёт/ухудшается |

```
毎日残業ばかりだ。— Каждый день только переработки。
ゲームしてばかりいる。— Только и делает, что играет。
借金は増えるばかりだ。— Долги только растут。
```

## 15. ～がち・～ぎみ：склонность к чему-то

- ～がち — склонность, привычка（часто негативная）
- ～ぎみ — лёгкое состояние, чуть-чуть

```
病気がちの子。— Ребёнок, часто болеющий。
遠回しに言いがちだ。— Склонен говорить обиняками。
疲れ気味だ。— Чуть устал。
風邪ぎみだ。— Слегка простужен。
```

Противопоставление 夢見がち（витающий в облаках）из диалога.

## 16. 条件 в вопросительных и вежливых просьбах

- ～たらどう？ — «а что если…?»（предложение)
- ～すればいい — «достаточно будет, если…»
- ～たらいいのに — «хорошо бы, если…»（жаль, что не так)

```
バイトでカフェを勉強すればいいんじゃない？
Не лучше ли изучить кафе через подработку？（предложение Алисы из диалога）
もっと早く言ってくれればよかったのに。
Хорошо бы, если бы ты сказал мне раньше。
```
