# Unit 11 — Чтение: アルバイト白書（Доклад о подработках)

## Короткое чтение: подготовка выставки

**Задача:** проследить исполнителя, получателя действия и того, кто поручил работу. Сцена вымышленная; неудобство не следует из любого пассива автоматически.

### Текст о кружке фотографии

> 写真クラブでは、日曜日に小さな展示会を開きます。  
> きのう、先生がアンナさんをほめました。  
> アンナさんは先生にほめられて、うれしかったです。  
> 先生はケンさんに案内の紙を書かせました。  
> ケンさんは紙を書いてから、入口にはりました。  
> アンナさんは自分の写真について話したいと言いました。  
> 先生は「では、アンナさんにも説明させましょう」と言いました。

### Опорные слова

| Запись | Чтение и значение |
|---|---|
| 展示会 | てんじかい — выставка |
| ほめる / ほめられる | хвалить / быть похваленным |
| 案内の紙 | あんないのかみ — информационный листок |
| 書かせる | かかせる — поручить/дать написать |
| 入口にはる | いりぐちにはる — прикрепить у входа |
| 説明させる | せつめいさせる — дать/поручить объяснить |

### Четыре вопроса до перевода

1. Кто похвалил Анну? Два первых сообщения о похвале — одно событие или два?
2. Кто поручил написать листок, а кто написал и повесил его?
3. Радовалась ли Анна похвале? Как это ограничивает толкование пассива как «страдания»?
4. Кто сам захотел рассказать о фотографии? В последнем предложении речь скорее о разрешении или о наказании? Обоснуйте по ситуации.

<details>
<summary>Перевод короткого текста</summary>

В фотокружке в воскресенье проведут небольшую выставку. Вчера преподаватель похвалил Анну. Анна обрадовалась похвале преподавателя. Преподаватель поручил Кену написать информационный листок. Кен написал его и прикрепил у входа. Анна сказала, что хочет рассказать о своей фотографии. Преподаватель сказал: «Тогда дадим и Анне объяснить».

</details>

<details>
<summary>Объяснённые ответы о действующих лицах</summary>

1. **Преподаватель; одно событие с разной перспективой.** 先生が…ほめました выделяет действующего; アンナさんは先生にほめられて — получателя похвалы. Участники не поменялись местами.
2. **Поручил преподаватель, выполнил Кен.** В 先生はケンさんに紙を書かせました Кен — исполнитель, 紙を — объект письма. Нельзя переводить это как «Кен заставил преподавателя писать».
3. **Да: うれしかったです.** Этот пассив описывает приятное действие. Оценку ситуации определяют слова и контекст.
4. **Анна сама выразила желание; преподаватель предоставляет возможность.** Каузатив 説明させる может выражать разрешение. Из формы нельзя без контекста вывести наказание или принуждение.

</details>

## Текст

```
　　日本の学生とアルバイト

日本では、大学生の七割以上がアルバイトをしています。
有名なのは、コンビニ、カフェ、家庭教師です。
最近は、動画の編集をする学生も増えています。

アンケートによると、学生がアルバイトを選ぶ時、
一番大切なのは「シフトの自由さ」だそうです。
給料より、自分の予定に合わせられるかどうかが
重要だという答えが多かったのです。

また、「店長に怒られた」「嫌な客に文句を言われた」
という経験がある学生も少なくありません。
ある学生は「初めての日、五時間も立たされて、
足が棒になった」と話していました。

それでも、アルバイトは貴重な経験だと
多くの学生が答えています。
お金を稼ぐ大変さを知り、社会人の言葉遣いを
学ぶことができるからです。
```

## Вопросы к тексту

1. Какой процент японских студентов работает?
2. Что студенты считают важнее зарплаты при выборе работы?
3. Какие неприятности упоминаются в тексте?
4. Почему, по мнению студентов, подработка ценна?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 七割以上 | ななわりじょう | более 70% |
| 家庭教師 | かていきょうし | репетитор |
| 編集 | へんしゅう | монтаж/редактирование |
| アンケート | — | опрос |
| 合わせる | あわせる | подстраиваться |
| 重要 | じゅうよう | важный |
| 少なくない | すくなくない | немало |
| 足が棒になる | あしがぼうになる | ноги одеревенели |
| 貴重 | きちょう | ценный |
| 稼ぐ | かせぐ | зарабатывать |
| 言葉遣い | ことばづかい | манера речи |

## Разбор грамматики в тексте

**編集をする学生も増えています**
→ относительное предложение: «студенты, которые монтируют».

**合わせられるかどうか**
→ потенциальная + かどうか: «может ли подстроиться или нет».

**文句を言われた**
→ пассив неудобства: «на них жаловались».

**立たされて**
→ 使役受身 от 立つ: «меня заставили стоять» —— типичная жалоба на первую смену!

**学ぶことができるからです**
→ ことができる + から: причина в конце, формальный стиль объяснения.

## Текст 2: シフトの交渉（Разговор о сменах)

```
　　シフトを変えてもらう

私の職場では、シフトは毎週日曜日に発表されます。
先週、急に親戚の結婚式があることが分かり、
私は店長に週末のシフトを替えてもらえないか頼みました。

店長は「代わりを見つけられたらいいよ」と言いました。
私は先輩の木村さんに頼んで、一日のシフトを交換して
もらうことができました。木村さんには、後で飲み物を
ごちそうすることにしました。

シフトを替えてもらうのはなかなか大変ですが、
互いに助け合えば問題は解決します。
職場では、頼むことも頼まれることも、どちらも
大切なスキルだと思います。
```

## Вопросы к тексту 2

1. Когда объявляют расписание смен?
2. Почему автору понадобилось поменять смену?
3. Кто помог автору и как?
4. Что автор подарил в благодарность?

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 職場 | しょくば | рабочее место |
| 発表する | はっぴょうする | объявлять |
| 急に | きゅうに | внезапно |
| 親戚 | しんせき | родственник |
| 結婚式 | けっこんしき | свадьба |
| 替える | かえる | менять, заменять |
| 交渉 | こうしょう | переговоры |
| ごちそうする | — | угощать |
| 助け合う | たすけあう | помогать друг другу |

## Разбор грамматики в тексте 2

**替えてもらえないか頼みました**
→ もらう + 可能 + 否定疑問：«нельзя ли попросить, чтобы поменяли»—— вежливая просьба.

**代わりを見つけられたらいいよ**
→ 条件ば + いい：«было бы хорошо, если…»—— мягкое согласие начальника.

**頼むことも頼まれることも**
→ ことも…ことも：перечисление двух ролей（просить/быть просимым) через пассив.

## Текст 3: バイトと学業の両立（Работа и учёба)

```
　　バイトと学業

大学生にとって、バイトと勉強を両立させるのは
簡単なことではありません。シフトに入りすぎると、
授業を休んだり、寝不足になったりします。

ある調査では、週十五時間を超えると、学業への影響が
大きくなると言われています。逆に、全く働かないより
少し働いた方が、時間の使い方が上手になるという
意見もあります。

私の友人は毎週二十時間働いていますが、バイト先で
弁当を食べさせてもらえることと、レポートの空き時間に
勉強させてもらえることから、苦しくないと言います。
上司や同僚の理解も大事なようです。
```

## Вопросы к тексту 3

1. Что происходит, если работать слишком много?
2. Что говорит опрос про 15 часов в неделю?
3. Какое преимущество работы упоминается?
4. Почему друг автора не мучается, работая 20 часов?

## Разбор грамматики в тексте 3

**食べさせてもらえること**
→ каузатив + もらう + 可能：«мне дают возможность есть»—— высочайший уровень опосредованного разрешения.

**勉強させてもらえることから**
→ から (причина) + こと：«благодаря тому, что дают заниматься»—— объяснение.

**言われています**
→ пассив + ている：«считается»（букв.: говорится)—— безличное мнение общества.

**バイトと学業を両立させる**
→ させる(他動) от 両立する：«совмещать»—— постановка цели в каузативе.
