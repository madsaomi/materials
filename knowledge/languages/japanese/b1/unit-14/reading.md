# Unit 14 — Чтение: 若者の「脱・アルバイト」傾向（Молодёжь уходит из подработок?)

## Короткое чтение: отчёт об учебной встрече

**Задача:** прочитать текст в стиле である, отделить локальные данные от общего вывода. Все числа — вымышленный пример, не результаты реального исследования.

### Пример письменного отчёта

> 本稿は、写真クラブの学習会についての報告である。  
> 参加者は十人であった。  
> 六人はスマートフォンを使い、四人はカメラを使った。  
> 学習会は午後二時に始まり、三時半に終わった。  
> 参加者は写真を見せ合い、明るさについて話し合った。  
> この記録だけでは、どちらの道具がよいかは判断できない。  
> 次回は、同じ場所で撮った写真を比べる予定である。

### Опорные слова

| Запись | Чтение и значение |
|---|---|
| 本稿 / 報告 | ほんこう / ほうこく — данный текст / отчёт |
| 参加者 | さんかしゃ — участники |
| であった | прошедшая форма である |
| 見せ合う | みせあう — показывать друг другу |
| 明るさ | あかるさ — яркость, освещённость |
| 記録 | きろく — запись, данные |
| 判断できない | はんだんできない — нельзя сделать вывод/определить |
| 予定である | よていである — запланировано |

### Четыре вопроса до перевода

1. Сколько участников пользовались смартфонами и сколько камерами? Совпадает ли сумма с общим числом?
2. Во сколько началась и закончилась встреча? Сколько она длилась по этим данным?
3. Доказано ли, что смартфон лучше камеры? Как автор ограничивает вывод?
4. Выпишите два окончания, указывающих на письменный регистр. Все ли предложения должны оканчиваться именно на である?

<details>
<summary>Перевод письменного отчёта</summary>

Этот текст — отчёт об учебной встрече фотокружка. Участников было десять. Шестеро пользовались смартфонами, четверо — камерами. Встреча началась в два часа дня и закончилась в половине четвёртого. Участники показывали фотографии друг другу и обсуждали яркость. Только по этой записи нельзя определить, какой инструмент лучше. В следующий раз планируется сравнить фотографии, снятые в одном месте.

</details>

<details>
<summary>Объяснённые ответы о данных и регистре</summary>

1. **6 и 4; сумма 10.** Числа описывают участников именно этой вымышленной встречи, а не всех фотографов.
2. **14:00–15:30, полтора часа.** Это 90 минут. Не принимайте 三時半 за 14:30.
3. **Нет:** この記録だけでは…判断できない. Количество пользователей не определяет качество инструмента; здесь отсутствуют результаты контролируемого сравнения.
4. **報告である / 十人であった / 予定である.** Глагольные предложения сохраняют простые формы 使った / 始まり / 終わった; не нужно механически добавлять である после любого глагола или い-прилагательного.

</details>

### Перенос после чтения

Перепишите первые два предложения в вежливом стиле です/ます, сохранив время: «это отчёт» и «участников было десять». Регистровое изменение не должно менять числа или факты.

## Текст

```
　　学生アルバイト実態調査（抜粋)

本稿では、全国の大学生一千名を対象に実施した
アルバイトに関する調査結果を報告する。

まず、就業率であるが、回答者の六十八パーセントが
何らかの形で勤務していた。内訳は、飲食業が最も多く、
次いでコンビニエンスストア、家庭教師と続く。

興味深いのは、勤務理由の変化である。
従来は「学費のため」という回答が多数を占めていたが、
近年は「社会経験を積むため」が第一位となった。
すなわち、若者は金銭以上に経験を重視し始めたのである。

一方で、労働時間が学業に影響を与えている事例も
報告されている。週二十時間を超える勤務者は、
成績低下の傾向が顕著に見られた。

したがって、本稿は以下を提言する。大学側は
勤務時間の上限についてガイドラインを設けるべきであり、
学生自身は学業との両立を第一に考えるべきである。

（調査期間：二〇二五年十月〜十二月)
```

## Вопросы к тексту

1. Сколько студентов участвовало в опросе и какая доля работала?
2. Какая отрасль лидирует по занятости?
3. Что изменилось в мотивации за последние годы?
4. Что обнаружилось у работающих более 20 часов?
5. Какие две рекомендации даёт автор?

## Словарь к тексту

| Слово | Чтение | Русский |
|-------|--------|---------|
| 本稿 | ほんこう | настоящая статья |
| 対象 | たいしょう | целевая группа |
| 回答者 | かいとうしゃ | респондент |
| 内訳 | うちわけ | разбивка |
| 従来 | じゅうらい | прежде |
| 占める | しめる | занимать（долю) |
| 重視する | ちょううしする | придавать значение |
| 事例 | じれい | случай, пример |
| 顕著 | けんちょ | заметный |
| 提言 | ていげん | предложение, рекомендация |
| 両立 | りょうりつ | совмещение |

## Разбор грамматики в тексте

**本稿では〜報告する**
→ では（формальный で) + словарная форма в конце —— классический である体.

**勤務理由の変化である**
→ である-связка вместо です.

**借りるしかない**
（повторение из юнита 13) единственный вариант.

**超える勤務者は、傾向が顕著に見られた**
→ относительное предложение + формальный глагол 見られた.

**設けるべきであり、…考えるべきである**
→ ～べきだ в письменной форме：べきであり / べきである.

## Текст 2: デジタル教科書の導入（Внедрение цифровых учебников)

```
　　大学におけるデジタル教科書の現状

近年、多くの大学が紙の教科書をデジタル版へ移行しつつある。その利点は明らかである。
まず、重量の問題が解消される。通学時に重い冊子を持ち歩く必要がなくなるからだ。
さらに、検索機能により、復習の効率が飛躍的に向上する。

一方で、課題も指摘されている。長時間の画面閲覧が目の疲れを招き、
集中力の低下につながるという報告もある。また、購入後の転売ができない
デジタル版は、経済的な負担がむしろ増える可能性がある。

以上を踏まえると、紙とデジタルの併用が当面は現実的な選択であると言えよう。
完全な移行ではなく、特性に応じた使い分けが望ましいのではないか。
```

## Текст 3: 図書館と私（Библиотека и я)

```
　　図書館と私

私は幼少期から本が好きだった。母に連れられて
近所の図書館へ通い、夏休みには一日に三冊
借りるのが習慣となっていた。

しかし、大人になるにつれて、読む量は減った。
スマートフォンが知識の入口を変えてしまったからである。
とはいえ、図書館には今も価値がある。
それは「選び取る」体験をくれる場所だからだ。

帰路に図書館に立ち寄り、棚を眺める。手に取った一冊が
偶然の出会いをもたらすことこそ、図書館の醍醐味である。
読書の速度を晩年に後悔しないためにも、私は本屋の棚を歩き続けたい。
```

1. Что любил делать автор в детстве?
2. Почему количество чтения уменьшилось?
3. Какую ценность библиотеки подчёркивает автор?
4. Найдите в тексте эмфазу с のである и объясните её роль.

## Текст 4: シンポジウム報告（Отчёт о круглом столе)

```
　　アルバイトに関するシンポジウム報告

去る四月十二日、本学にて「学生とアルバイト」をテーマとし、
シンポジウムが開催された。参加者は約七十名、内訳は学生四十五名、
教員二十名、地域事業者五名であった。

基調講演では、労働時間の上限規制に関する最新の研究結果が示された。
その結果を踏まえ、パネル討論では、大学側がガイドラインを作成する
ことの必要性が主として議論された。

質疑応答では、「健康悪化を招かない範囲で、どの程度の勤務が
許容されるか」という質問が相次いだ。登壇者は、個別の判断に
委ねつつも、学業を優先する原則は守るべきであると答えた。

本シンポジウムの論点は、今後開かれる検討会に引き継がれる予定である。
```

**Вопросы к тексту 4:**

1. Сколько участников и какие группы составили аудиторию?
2. Что было главным предметом обсуждения?
3. Какой вопрос задавали из зала и каким был ответ?
4. Что произойдёт с выводами дальше?
5. Выделите пассивные формы и объясните их роль.

**Словарь к тексту 4:**

| Слово | Чтение | Русский |
|-------|--------|---------|
| シンポジウム | しんぽじうむ | симпозиум, круглый стол |
| 去る | さる | прошедший (о времени) |
| 開催される | かいさいされる | проводиться |
| 基調講演 | きちょうこうえん | основная лекция |
| 上限規制 | じょうげんきせい | ограничение потолка |
| パネル討論 | ぱねるとうろん | дискуссия экспертов |
| 質疑応答 | しつぎおうとう | вопросы и ответы |
| 相次ぐ | あいつぐ | следовать одно за другим |
| 登壇者 | とうだんしゃ | выступавший |
| 委ねる | ゆだねる | полагаться на |
| 原則 | げんそく | принцип |
| 引き継がれる | ひきつがれる | быть переданным |

**Разбор грамматики в тексте 4:**

- **をテーマとして** — тема оформлена через として (в роли темы).
- **なすことの必要性** — глагольная группа стала существительным через こと + の.
- **委ねつつ** — つつ классический книжный «одновременно / в то же время».
- **予定である** — плановое будущее в である体.
- Пассивы: 示された・評価された· 議論された — формальная дистанцированность.
