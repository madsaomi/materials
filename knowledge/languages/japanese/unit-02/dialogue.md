# Unit 2 — Диалог: 一日の生活 (Распорядок дня)

## Диалог

```
木村: おはようございます。毎日何時に起きますか。
山田: 6時に起きます。それからジョギングをします。
木村: すごいですね。朝ごはんは何を食べますか。
山田: いつもパンと卵とコーヒーです。
木村: 何時に家を出ますか。
山田: 8時に出ます。電車で会社に行きます。
木村: 会社は何時からですか。
山田: 9時から5時までです。
木村: 仕事の後は何をしますか。
山田: たいてい家に帰って、テレビを見ます。
木村: 何時に寝ますか。
山田: 11時半ごろ寝ます。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 毎日何時に起きますか | Во сколько вы встаёте каждый день? |
| 6時に起きます | Встаю в 6 |
| ジョギングをします | Делаю пробежку |
| 朝ごはん | Завтрак |
| いつも | Всегда |
| 家を出ます | Выхожу из дома |
| 電車で | На поезде |
| 仕事の後 | После работы |
| たいてい | Обычно |
| 家に帰ります | Возвращаюсь домой |
| 〜ごろ | Около (времени) |
