# Unit 2 — Грамматика: Время, распорядок, частицы направления

## 1. Частица に для времени

Ставится после указания времени (но не после слов "сегодня", "завтра" и т.д.)

```
6時に起きます。          — Встаю в 6.
8時に家を出ます。        — Выхожу из дома в 8.
9時から5時まで働きます。 — Работаю с 9 до 5.

今日(×に)起きました。    — Сегодня встал. (без に)
```

## 2. Частица で (инструмент / место действия)

```
電車で行きます。    — Еду на поезде.
ペンで書きます。     — Пишу ручкой.
レストランで食べます。 — Ем в ресторане.
学校で勉強します。  — Учусь в школе.
```

## 3. Частицы направления: に и へ

```
家に帰ります。      — Возвращаюсь домой.
会社に行きます。    — Иду на работу.
日本へ行きます。    — Еду в Японию.
```

**に** — акцент на цели. **へ** — акцент на направлении.

## 4. から〜まで (от〜до)

```
9時から5時まで働きます。 — Работаю с 9 до 5.
東京から大阪まで行きます。 — Еду из Токио до Осаки.
```

## 5. Спряжение ます-формы (продолжение)

**Группа I (五段):**
- 会う → 会います
- 書く → 書きます  
- 話す → 話します
- 待つ → 待ちます
- 死ぬ → 死にます
- 読む → 読みます
- 飛ぶ → 飛びます
- 走る → 走ります
- 歌う → 歌います

**Правило:** Последний звук меняется на звук из い-ряда.

**Группа II (一段):** る → ます
- 食べる → 食べます
- 見る → 見ます

**Группа III (不規則):**
- する → します
- 来る → 来ます (きます)

## 6. を (объектная частица)

```
朝ごはんを食べます。    — Ем завтрак.
コーヒーを飲みます。    — Пью кофе.
テレビを見ます。       — Смотрю телевизор.
```

## 7. Наречия частоты

| Слово | Перевод |
|-------|---------|
| いつも | всегда |
| たいてい | обычно |
| よく | часто |
| 時々 (ときどき) | иногда |
| あまり〜ない | не очень (с отриц.) |
| ぜんぜん〜ない | совсем не (с отриц.) |
| たまに | изредка |
| めったに〜ない | редко (с отриц.) |

**Примеры:**
```
いつもコーヒーを飲みます。     — Всегда пью кофе.
あまりテレビを見ません。      — Не очень часто смотрю телевизор.
時々映画を見ます。            — Иногда смотрю кино.
```

## 8. 〜ています (действие в процессе / результат)

**Образование:** глагол в тэ-форме + います

| Ситуация | Пример | Значение |
|----------|--------|----------|
| Длительное действие | 食べています | Я ем (сейчас) |
| Результат | 部屋が汚れています | Комната грязная (состояние) |
| Продолжение | 新闻を読んでいます | Я читаю газету |

**Отличие от ている:**
- ている — простое продолжение
- ています — более формальная/вежливая форма

**Примеры:**
```
今何をしていますか。     — Что вы делаете сейчас?
私はテレビを見ています。  — Я смотрю телевизор.
日本語を勉強しています。  — Я изучаю японский.
```

1. Составьте предложение: я / встаю / в 7 часов → __________
2. Составьте предложение: ем / в ресторане → __________
3. Переведите: японский / я / изучаю → __________
4. Вставьте частицу: 電車___行きます。
5. Переведите: обычно я смотрю телевизор → __________
6. Переведите: я сейчас учу японский → __________
7. Переведите: что вы делаете? → __________

**Ответы:**
1. 7時に起きます。
2. レストランで食べます。
3. 日本語を勉強しています。
4. で
5. たいていテレビを見ます。
6. 今日本語を勉強しています。
7. 何をしていますか。

## 9. 〜ながら (делая что-то одновременно)

```
歩きながら電話をします。 — Разговариваю по телефону, идя。
食べながらテレビを見ます。 — Смотрю телевизор, едя。
音楽を聞きながら勉強します。 — Учусь, слушая музыку。
```

## 10. 〜たびに (каждый раз, когда)

```
会うたびに、笑顔になります。 — Каждый раз, когда вижу, улыбаюсь。
日本に行くたびに、お土産を買います。 — Каждый раз, когда еду в Японию, покупаю сувениры。
```

## 11. 〜限り (пока, насколько)

```
元気な限り、頑張ります。 — Пока здоров, буду стараться。
時間がある限り、勉強します。 — Пока есть время, учусь。
```

## 12. 〜つつ (пока делаю одно, делаю другое)

```
歩きつつ考えます。 — Иду и думаю。
食べつつ話します。 — Ем и разговариваю。
```

## 13. 〜から (потому что)

```
暑いから、水を飲みます。 — Потому что жарко, пью воду。
遅いから、急いでください。 — Поздно, пожалуйста, поторопитесь。
```
