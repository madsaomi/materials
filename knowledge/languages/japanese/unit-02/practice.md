# Unit 2 — Практика

## Упражнение 1: Частицы

Вставьте правильную частицу: に、で、を、へ

1. 毎朝6時___起きます。
2. 電車___会社___行きます。
3. レストラン___ご飯___食べます。
4. 図書館___日本語___勉強します。
5. 家___帰ります。

## Упражнение 3: Распорядок дня

Опишите свой день, используя подсказки:

1. 6:00 → __________
2. 7:30 → __________
3. 9:00 → __________
4. 12:00 → __________
5. 18:00 → __________
6. 23:00 → __________

**Пример:** 6時に起きます。

## Упражнение 6: Диалог по ситуации

Прочитайте диалог и заполните пропуски:

**Ситуация:** Утренние сборы на работу.

アリス: おはよう、マーク。
マーク: おはよう、アリス。今日は______？
アリス: ええ、調子はいいよ。朝ごはんは食べた？
マーク: いいえ、急いでるんだ。______？
アリス: コンビニでパンとコーヒーを買ったよ。
マーク: それで大丈夫？
アリス: はい、大丈夫です。じゃあ、______！
マーク: お疲れ様！

1. Какой вопрос задаёт Марк в первой реплике? → __________
2. Что отвечает Алиса на вопрос про завтрак? → __________
3. Что спрашивает Марк про завтрак? → __________
4. Что отвечает Алиса? → __________
5. Как прощаются? → __________

## Ответы

4. で, を
5. に/へ
