# Unit 2 — Практика

## Упражнение 1: Частицы

Вставьте правильную частицу: に, で, を, へ

1. 毎朝6時___起きます。
2. 電車___会社___行きます。
3. レストラン___ご飯___食べます。
4. 図書館___日本語___勉強します。
5. 家___帰ります。

## Упражнение 3: Распорядок дня

Опишите свой день, используя подсказки:

1. 6:00 → __________
2. 7:30 → __________
3. 9:00 → __________
4. 12:00 → __________
5. 18:00 → __________
6. 23:00 → __________

**Пример:** 6時に起きます。

## Упражнение 4: Перевод

1. Я каждый день встаю в 7 часов. → __________
2. Я завтракаю в 8 часов. → __________
3. Я еду на работу на поезде. → __________
4. Я возвращаюсь домой в 7 вечера. → __________
5. Я ложусь спать в 11 часов. → __________

## Ответы

**Упражнение 1:**
1. に
2. で, へ/に
3. で, を
4. で, を
5. に/へ

**Упражнение 2:**
会います, 書きます, 話します, 待ちます, 読みます, 食べます, 来ます, します

**Упражнение 4:**
1. 毎日7時に起きます。
2. 8時に朝ごはんを食べます。
3. 電車で会社に行きます。
4. 午後7時に家に帰ります。
5. 11時に寝ます。
