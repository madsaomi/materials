## Часть 9: Чтение — меню (30 баллов)

```
ようこそ、さくら食堂へ！

・ラーメン　　　600円
・カレーライス　700円
・天ぷら定食　　900円
・うどん　　　　550円

※ライスのおかわりは無料です。
定休日：水曜日
営業時間：午前10時〜午後9時
```

51. 一番高いメニューは何ですか。
52. 一番安いメニューはいくらですか。
53. ラーメンとカレーライスを一つずつもらうといくらですか。
54. 水曜日に来たら、どうなりますか。
55. 午後10時に来たら、何を食べられますか。

**Ответы:**
51. 天ぷら定食（900円）です。
52. うどん（550円）です。
53. 1300円です。（600+700）
54. 閉まっています。（定休日）
55. 何も食べられません。（午後9時まで）
