# Unit 2 — Текст для чтения

## 私の一日 (Мой день)

```
私は毎朝6時に起きます。
顔を洗って、歯を磨きます。
7時に朝ごはんを食べます。
いつもパンと卵とコーヒーです。
8時に家を出て、学校に行きます。
学校では日本語と英語を勉強します。
12時に友達と昼ごはんを食べます。
午後3時に学校が終わります。
家に帰って、少し休みます。
夕方6時に晩ごはんを作ります。
夜はテレビを見たり、本を読んだりします。
11時ごろ寝ます。
```

### 単語

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 顔 | かお | лицо |
| 洗う | あらう | мыть |
| 歯 | は | зуб |
| 磨く | みがく | чистить |
| 終わる | おわる | заканчиваться |
| 少し | すこし | немного |
| 休む | やすむ | отдыхать |
| 夕方 | ゆうがた | вечер (ранний) |
| 晩ごはん | ばんごはん | ужин |
| 〜たり〜たり | — | и... и... (перечисление) |

### 翻訳

Я каждый день встаю в 6 утра.
Мою лицо, чищу зубы.
В 7 завтракаю.
Всегда хлеб, яйцо и кофе.
В 8 выхожу из дома и иду в школу.
В школе учу японский и английский.
В 12 обедаю с другом.
В 3 дня школа заканчивается.
Возвращаюсь домой, немного отдыхаю.
В 6 вечера готовлю ужин.
Ночью смотрю телевизор или читаю книгу.
Около 11 ложусь спать.

### 質問

1. 何時に起きますか。
2. 朝ごはんに何を食べますか。
3. 学校で何を勉強しますか。
4. 何時に学校が終わりますか。
5. 夜は何をしますか。

**Ответы:**
1. 6時に起きます。
2. パンと卵とコーヒーを食べます。
3. 日本語と英語を勉強します。
4. 午後3時に終わります。
5. テレビを見たり、本を読んだりします。
