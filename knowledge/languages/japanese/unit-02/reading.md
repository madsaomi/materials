# Unit 2 — Текст для чтения

## 私の一日 (Мой день)

```
私は毎朝6時に起きます。
顔を洗って、歯を磨きます。
7時に朝ごはんを食べます。
いつもパンと卵とコーヒーです。
8時に家を出て、学校に行きます。
学校では日本語と英語を勉強します。
12時に友達と昼ごはんを食べます。
午後3時に学校が終わります。
家に帰って、少し休みます。
夕方6時に晩ごはんを作ります。
夜はテレビを見たり、本を読んだりします。
11時ごろ寝ます。
```

### 単語

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 顔 | かお | лицо |
| 洗う | あらう | мыть |
| 歯 | は | зуб |
| 磨く | みがく | чистить |
| 終わる | おわる | заканчиваться |
| 少し | すこし | немного |
| 休む | やすむ | отдыхать |
| 夕方 | ゆうがた | вечер (ранний) |
| 晩ごはん | ばんごはん | ужин |
| 〜たり〜たり | — | и... и... (перечисление) |

### 翻訳

Я каждый день встаю в 6 утра.
Мою лицо, чищу зубы.
В 7 завтракаю.
Всегда хлеб, яйцо и кофе.
В 8 выхожу из дома и иду в школу.
В школе учу японский и английский.
В 12 обедаю с другом.
В 3 дня школа заканчивается.
Возвращаюсь домой, немного отдыхаю.
В 6 вечера готовлю ужин.
Ночью смотрю телевизор или читаю книгу.
Около 11 ложусь спать.

### 質問

1. 何時に起きますか。
2. 朝ごはんに何を食べますか。
3. 学校で何を勉強しますか。
4. 何時に学校が終わりますか。
5. 夜は何をしますか。

**Ответы:**
1. 6時に起きます。
2. パンと卵とコーヒーを食べます。
3. 日本語と英語を勉強します。
4. 午後3時に終わります。
5. テレビを見たり、本を読んだりします。

## テキスト２：がっこうの　おべんとう（Школьный обед)

```
アリスさんは　まいにち　おべんとうを　もって　きます。
おかあさんが　つくります。
おべんとうには　ごはんと　たまごやきと
やさいが　はいっています。
ともだちは　がっこうの　しょくどうで
たべます。しょくどうの　ラーメンは
２５０えんで、やすいです。
でも、アリスさんは　おかあさんの
おべんとうが　いちばん　すきです。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 弁当 | べんとう | бэнто (обед с собой) |
| 持ってくる | もってくる | приносить |
| 作る | つくる | готовить |
| 卵焼き | たまごやき | омлет по-японски |
| 野菜 | やさい | овощи |
| 入っている | はいっている | содержаться |
| 食堂 | しょくどう | столовая |
| 一番 | いちばん | больше всего |

### 翻訳 (Перевод)

Алиса каждый день приносит бэнто. Его готовит мама. В бэнто — рис, тамагояки и овощи.
Друзья едят в школьной столовой. Рамэн в столовой стоит 250 иен — дёшево.
Но Алиса больше всего любит мамин бэнто.

### 質問 (Вопросы)

1. だれが　おべんとうを　つくりますか。
2. おべんとうに　なにが　はいっていますか。
3. しょくどうの　ラーメンは　いくらですか。
4. アリスさんは　なにが　いちばん　すきですか。

**Ответы:**
1. お母さんが作ります。
2. ごはんと卵焼きと野菜です。
3. 250円です。
4. お母さんの弁当です。

## テキスト３：ゆうびんきょくの　じかん（Часы работы почты)

```
これは　ゆうびんきょくの　お知らせです。

　　営業時間：月曜日〜金曜日
　　　　　　　午前９時〜午後５時
　　土曜日　：午前９時〜午後１２時
　　日曜日　：休み

　※切手はいつでも買えます。

アリスさんは　水曜日の　午後６時に
ゆうびんきょくへ　行きました。
でも、閉まっていました。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 郵便局 | ゆうびんきょく | почта |
| お知らせ | おしらせ | объявление |
| 営業時間 | えいぎょうじかん | часы работы |
| 月曜日〜金曜日 | げつようび〜きんようび | понедельник–пятница |
| 休み | やすみ | выходной |
| 切手 | きって | марки |
| 閉まる | しまる | быть закрытым |

### 翻译 (Перевод)

Это объявление почты.

Часы работы: понедельник–пятница с 9:00 до 17:00.
Суббота: с 9:00 до 12:00.
Воскресенье: закрыто.
*Марки можно купить в любое время.*

Алиса пришла на почту в среду в шесть вечера. Но она была закрыта.

### 質問 (Вопросы)

1. 土曜日は　何時まで　あいて　いますか。
2. アリスさんは　なぜ　入れませんでしたか。

**Ответы:**
1. 午後12時まであいています。
2. 水曜日は午後5時までだから。（水曜の午後6時は営業時間外）

## Как работать с текстами урока 2

1. **Текст 3 — первый «документ»**: объявления и расписания — половина экзамена JLPT! Учитесь выхватывать цифры и дни недели.
2. **Найдите в текстах:** время（〜時〜分）, частицы を・に・で・から, форму ～たり～たり.
3. **Мини-задание:** составьте расписание своего дня по-японски (6–8 строк, как в тексте урока).
