# Японская культура

## Обзор

Японская культура (日本文化) — уникальное сочетание древних традиций и ультрасовременности. На протяжении тысяч лет Япония впитывала иностранные влияния и переосмысливала их, создавая собственный неповторимый культурный код.

## Традиции и обычаи

### Концепции

| Концепция | Кандзи | Значение |
|-----------|--------|----------|
| 和 | wa | гармония |
| 礼 | rei | этикет, уважение |
| 忠義 | chūgi | верность |
| 美 | bi | красота |
| 物の哀れ | mono no aware | осознанность вещей |
| 侘び寂び | wabi-sabi | красота несовершенства |
| 頑張る | ganbaru | стараться изо всех сил |
| 本音と建前 | honne to tatemae | истинное мнение и общепринятое |

### Система вежливости (敬語 keigo)

| Уровень | Использование | Пример |
|---------|---------------|--------|
| 丁寧語 (teineigo) | Вежливый | 食べます (табэмасу) |
| 尊敬語 (sonkeigo) | Уважительный к старшемu | 食べられます (таберарэру) |
| 謙譲語 (kenjōgo) | Смирительный (о себе) | 食べさせていただきます |

### Церемония приёма чая (茶道 sadō)

茶道 — «Путь чая» — одна из самых важных традиционных церемоний:

| Этап | Описание |
|------|----------|
| 入室 | Вход в чайную комнату (через низкую дверь — покорность) |
| 拝見 | Осмотр чайных принадлежностей |
| 準備 | Подготовка чая |
| 点前 | Приготовление матча |
| 奉茶 | Подача чая |
| 退室 | Уход |

**Принципы:**
- 一期一会 (ichigo ichie) — «один момент, одна встреча» — ценить каждую встречу
- 清らか (kiyoraka) — чистота
- 静寂 (seijaku) — тишина

### Икэбана (生け花)

Искусство составления букетов:
- 三条の法则 — три линии: небо, человек, земля
- Сезонность — использование сезонных растений
- Простота — меньше значит больше

## Праздники

### 正月 (Сёгatsu) — Японский Новый год

**Дата:** 1-3 января

**Традиции:**
- Очистка дома (大掃除 — тайсōдзи)
- Украшение врата воротами (門松 — кадомацу)
- Приготовление осэти (おせち) — новогодних блюд
- Посещение храма (初詣 — хатимёдэ)
- Подарки в конвертах (お年玉 — отосидама)
- Письма с поздравлениями (年賀状 — нэнгадзё)

**Осэти — традиционные новогодние блюда:**

| Блюдо | Кандзи | Значение |
|-------|--------|----------|
| 黒豆 | kuromame | Чёрные бобы — усердие |
| 数の子 | kazunoko | Икра сельди — плодородие |
| 海老 | ebi | Креветка — долголетие |
| 大根 | daikon | Редис — спокойствие |
| 伊達巻 | datemaki | Сладкий омлет — учёность |
| ちくわの築き | chikuba no tsuki | Бамбуковые трубочки — процветание |
| 関東煮 | oden | Тушёные блюда — здоровье |

### お盆 (О-Бон)

**Дата:** 13-16 августа (或 13-16 июля по лунному календарю)

**Традиции:**
- Возвращение духов предков
- Зажигание фонариков (迎え火 — мукаэби)
- Танец танабата (盆踊り — бон-одори)
- Отпуск для работников

### 花見 (Ханами) — Цветение сакуры

**Дата:** Март-апрель

**Традиции:**
- Пикники под цветущими деревьями
- Пение и танцы
- Фотографирование
- Любование преходящей красотой цветения

**Концепция 物の哀れ (mono no aware):**
Ощущение грусти от осознания быстротечности красоты. Цветы сакуры — идеальный пример: они расцветают на две недели и опадают.

```
Старый пруд — лягушка прыгает — звук воды
```

## Интересные факты

1. **В Японии более 80 000 храмов** и святилищ
2. **Число 4** считается несчастным (四 звучит как 死 — смерть)
3. **Число 7** — счастливым
4. **Матча** — национальный напиток
5. **Спальные вагоны** — японское изобретение
6. **Лифты** — стоять по краям, не в центре
7. **Стикерфоны** — появлись в Японии
8. **Вендинговые автоматы** — везде и для всего
9. **Пунктуальность** — поездка опаздывает на 1 минуту — извиняются
10. **Мусор** — мусорных баков почти нет, мусор несут домой
