# Дневник слушателя (リスニング日記)

> 📓 Шаблон для ежедневного отслеживания аудирования. Ведение дневника превращает «просто послушал» в измеряемый прогресс: видно, какие материалы идут хорошо, какие трудности повторяются, сколько реально времени вы уделяете навыку.
> Связано с: [Задания](tasks.md) · [Ресурсы](resources.md) · [Методика](methodology.md)

---

## 1. Зачем вести дневник

| Проблема | Решение дневником |
|----------|-------------------|
| «Не знаю, что делать сегодня» | план на неделю + список материалов |
| «Прослушал, но ничего не осталось» | записываете новые слова и фразы |
| «Кажется, прогресса нет» | % понимания и метрики по датам |
| «Не могу сказать, что мешает» | колонка «трудность» подсвечивает повторяющуюся причину |

## 2. Шаблон дневной записи

```
## 📅 20__-__-__ (день недели)

**Материал:** (название, источник: tasks/подкаст/NHK/драмa)
**Уровень:** N5 / N4 / N3 / N2 / N1
**Формат:** интенсивный / экстенсивный / shadowing / диктовка
**Длительность:** __ мин
**Прослушиваний:** 1-й / 2-й / 3-й раз

### Понимание (0–100%): __%

### Новые слова (3–10):
1. ____ (читается: ____) → значение
2. ____
3. ____

### Фразы для shadowing (2–3):
1. 「＿＿＿＿＿＿＿＿＿＿」
2. 「＿＿＿＿＿＿＿＿＿＿」

### Что было трудно расслышать:
- [ ] незнакомое слово
- [ ] стяжение (〜てる / 〜ちゃう / 〜とく)
- [ ] высокая скорость
- [ ] звукоподражание
- [ ] интонация (не понял вопрос/q или чувство говорящего)
- [ ] часть звука «проглочена» (редукция です→дэс)

**Конкретно:** （например: «не разобрал 売り切れちゃう в задаче 4»）

### Диктовка (запишите, что услышали):
（пишите хираганой; сверка с текстом ниже）
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Пересказ одной фразой:
「きょうの びでお は 〜 について の はなし でした。」

### План на завтра:
（что слушаю, какое задание/эпизод, сколько минут）
```

## 4. Пример заполненной записи (образец)

```
## 📅 2026-08-30 (воскресенье)

**Материал:** Задание 4, «Телефонный звонок» (listening/tasks.md)
**Уровень:** N4
**Формат:** интенсивный (этапы A–D)
**Длительность:** 25 мин
**Прослушиваний:** 2-е

### Понимание (0–100%): 70%

### Новые слова:
1. 売り切れる (うりきれる) → раскупаться
2. 予約 (よやく) → бронирование
3. 夕方 (ゆうがた) → вечер (16–18 ч)

### Фразы для shadowing:
1. 「明日までに予約しないと」 
2. 「売り切れちゃうんだって」

### Трудность:
- [x] стяжение: 売り切れちゃう (＝売り切れてしまう)
- [x] высокая скорость в «予約しないと売り切れちゃうんだって»

**Конкретно:** «ちゃう» слилось с «と» — расслышал только после 2-го прослушивания с текстом.

### Диктовка:
うりきれちゃう ＝ うりきれてしまう　（проверка: ✓）

### Пересказ:
「あおい と ゆき が、しゅうまつ の えいが の チケット を よやく する はなし でした。」

### План на завтра:
Задание 5 «Объявление в транспорте» + 2 минуты shadowing с прошлой записи (TTS, 0.8x).
```

## 5. Ежемесячный обзор (в последний день месяца)

Сверьте все недельные таблицы и ответьте:
- [ ] Сколько минут суммарно за месяц? (цель: 300+ мин = 10 мин/день)
- [ ] Средний % понимания подрос на ~5–10%?
- [ ] Какая трудность повторялась чаще всего? Работали с ней целенаправленно?
- [ ] Сколько новых слов добавлено (в дневник и Anki)?
- [ ] Что слушали с удовольствием — это продолжать, или менять жанр?
- [ ] Новая цель на следующий месяц: （например: «дойти до 80% понимания NHK Easy News», «пройти 8 из 10 заданий tasks.md»)

---

## 6. Правила ведения

1. **5 минут на запись** — не превращайте дневник в сочинение.
2. **Честные цифры.** «70% понимания» лучше, чем «почти всё» — потом видно динамику.
3. **Одна главная трудность в день** — разбирайте её до конца, а не собирайте список из десяти.
4. **Диктовка обязательна** хотя бы из 1–2 фраз: именно она покажет реальное «слышу vs знаю».
5. Пропустили день — не заполняйте «задним числом» за три дня. Просто продолжайте с сегодня.
