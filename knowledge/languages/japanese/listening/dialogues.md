# Диалоги для аудирования (会話の練習)

> 🎧 Тематические диалоги с хираганой, переводом, словарём и вопросами на понимание. Ключи — в конце каждой темы.
> Связано с: [Методика](methodology.md) · [Монологи](monologues.md)

Условные обозначения: **A/B/店員/客** — реплики. Хирагана — чтение (рукописная/на слух), курсором выделен кандзи-вариант.

---

# 1. В магазине (を店 で)

**Ситуация:** покупатель выбирает футболку.

```
客：すみません、このシャツ、試着してもいいですか。
店員：はい、どうぞ。試着室はあちらです。
客：いっかい着てみます。
（少し後）
客：サイズが少し小さいですね。一つ大きいのはありますか。
店員：はい、こちらです。色は何色にしますか。
客：白にします。これをください。
店員：はい、ありがとうございます。レジでお会計をお願いします。
```

**Хирагана:**
```
きゃく：すみません、このシャツ、しちゃくしてもいいですか。
てんいん：はい、どうぞ。しちゃくしつはあちらです。
きゃく：いっかいきてみます。
（すこしあと）
きゃく：サイズがすこしちいさいですね。ひとつおおきいのはありますか。
てんいん：はい、こちらです。いろはなにいろにしますか。
きゃく：しろにします。これをください。
てんいん：はい、ありがとうございます。レジでおかいけいをおねがいします。
```

**Перевод:**
- Покупатель: Извините, можно примерить эту футболку?
- Продавец: Да, пожалуйста. Примерочная вон там.
- Покупатель: Сейчас примерю.
- (немного позже) Покупатель: Размер немного маленький. Есть на один побольше?
- Продавец: Да, вот этот. Какой цвет выбрать?
- Покупатель: Возьму белый. Дайте вот это.
- Продавец: Хорошо, спасибо. Оплата у кассы.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| 試着 しちゃく | примерка | |
| 試着室 しちゃくしつ | примерочная | |
| サイズ | размер | |
| 色 いろ | цвет | |
| レジ | касса | |
| お会計 おかいけい | расчёт, оплата | |

**Вопросы на понимание:**
1. 客は何をしますか。 a) 買うだけ b) 試着する c) 返す
2. シャツはどうでしたか。 a) 大きい b) ちょうどいい c) 小さい
3. 客は何色にしますか。 a) 黒 b) 白 c) 青

**Ключи:** 1. b · 2. c · 3. b

# 2. В поезде (電車 で)

**Ситуация:** в электричке спрашивают про пересадку.

```
A：すみません、この電車は大阪へ行きますか。
B：いいえ、これは特急で、大阪へは行きません。京都までは行きます。
A：大阪へはどう行けばいいですか。
B：京都で乗り換えてください。新幹線に乗ったら、三十分で着きます。
A：次は何時に出ますか。
B：十分後です。急いでください。
A：ありがとうございます！
```

**Хирагана:**
```
A：すみません、このでんしゃはおおさかへいきますか。
B：いいえ、これはとっきゅうで、おおさかへは いきません。きょうとまではいきます。
A：おおさかへはどういけばいいですか。
B：きょうとでのりかえてください。しんかんせんにのったら、さんじゅっぷんでつきます。
A：つぎはなんじにでますか。
B：じゅっぷんごです。いそいでください。
A：ありがとうございます！
```

**Перевод:**
- А: Извините, этот поезд идёт в Осаку?
- Б: Нет, это экспресс, в Осаку он не идёт. До Киото идёт.
- А: Как доехать до Осаки?
- Б: Пересядьте в Киото. Если сядете на синкансэн, за 30 минут доедете.
- А: Когда отправляется следующий?
- Б: Через десять минут. Поторопитесь.
- А: Спасибо большое!

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| 電車 でんしゃ | электричка, поезд | |
| 特急 とっきゅう | экспресс | |
| 乗り換える のりかえる | делать пересадку | |
| 新幹線 しんかんせん | синкансэн | |
| 出る でる | отправляться | |
| 急ぐ いそぐ | торопиться | |

**Вопросы:**
1. この電車はどこまで行きますか。 a) 大阪 b) 京都 c) 東京
2. 大阪へはどう行きますか。 a) このまま b) 京都で乗り換え c) タクシー
3. 次の電車はいつですか。 a) 五分後 b) 十分後 c) 三十分後

**Ключи:** 1. b · 2. b · 3. b

# 3. Объявление на вокзале (駅 のアナウンス)

**Ситуация:** объявление по громкоговорителю на платформе.

```
まもなく、三番線に、東京行きの電車がまいります。本日は、新宿駅で人身事故のため、運転が遅れています。お急ぎのところ、大変ご迷惑をおかけしております。東京行きの電車は、遅れて、十分後に、到着いたします。ご注意ください。
```

**Хирагана:**
```
まもなく、さんばんせんに、とうきょうゆきのでんしゃがまいります。ほんじつは、しんじゅくえきでじんしんじこのため、うんてんがおくれています。おいそぎのところ、たいへんごめいわくを おかけしております。とうきょうゆきのでんしゃは、おくれて、じゅっぷんごに、とうちゃくいたします。ごちゅういください。
```

**Перевод:**
- В скором времени на третью платформу прибывает поезд на Токио. Сегодня из-за происшествия с человеком на станции Синдзюку движение задерживается. Приносим большие извинения тем, кто спешит. Поезд на Токио прибудет с опозданием, через десять минут. Просим вас быть внимательными.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| まもなく | в скором времени | |
| 三番線 さんばんせん | третья платформа | |
| 東京行き とうきょうゆき | на Токио | |
| 人身事故 じんしんじこ | происшествие с человеком | |
| 運転 うんてん | движение (поездов) | |
| 遅れる おくれる | опаздывать | |
| 迷惑 めいわく | беспокойство, неудобство | |
| 到着 とうちゃく | прибытие | |

**Вопросы:**
1. 何番線に電車が来ますか。 a) 一番 b) 三番 c) 五番
2. なぜ遅れていますか。 a) 台風 b) 事故のため c) 雪
3. 電車はいつ着きますか。 a) 今すぐ b) 五分後 c) 十分後

**Ключи:** 1. b · 2. b · 3. c

# 4. Погода (天気)

**Ситуация:** разговор о погоде на выходных.

```
A：今日は本当に暑いですね。
B：そうですね。三十五度もあるらしいですよ。
A：週末はどうですか。
B：土曜日は晴れて、日曜日は雨だそうです。
A：じゃあ、土曜日に海に行きましょうか。
B：いいですね。でも、熱中症に気をつけてくださいね。
A：大丈夫です。水をたくさん持っていきます。
```

**Хирагана:**
```
A：きょうはほんとうにあついですね。
B：そうですね。さんじゅうごどもあるらしいですよ。
A：しゅうまつはどうですか。
B：どようびははれて、にちようびはあめだそうです。
A：じゃあ、どようびにうみにいきましょうか。
B：いいですね。でも、ねっちゅうしょうにきをつけてくださいね。
A：だいじょうぶです。みずをたくさんもっていきます。
```

**Перевод:**
- А: Сегодня и правда жарко.
- Б: Да. Говорят, аж 35 градусов.
- А: Как на выходных?
- Б: В субботу ясно, а в воскресенье, говорят, дождь.
- А: Тогда пойдём в субботу на море?
- Б: Хорошо. Но, берегитесь теплового удара.
- А: Не волнуйся. Возьму много воды.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| 暑い あつい | жаркий | |
| 週末 しゅうまつ | выходные | |
| 晴れる はれる | быть ясным | |
| 熱中症 ねっちゅうしょう | тепловой удар | |
| 気をつける きをつける | быть осторожным | |
| 持っていく もっていく | брать с собой | |

**Вопросы:**
1. 今日は何度ですか。 a) 二十五度 b) 三十五度 c) 四十五度
2. 日曜日の天気は？ a) 晴れ b) 雨 c) 雪
3. いつ海に行きますか。 a) 土曜日 b) 日曜日 c) 今日

**Ключи:** 1. b · 2. b · 3. a

# 6. Телефонный звонок (電話 の会話)

**Ситуация:** просьба перенести встречу.

```
A：もしもし、アリスです。
B：あ、アリスさん、田中です。ごめんください。
A：どうしましたか。
B：実は、明日の予定なんですが、急用ができてしまって、行けなくなってしまいました。
A：そうですか。じゃあ、明後日はどうですか。
B：明後日なら大丈夫です。何時にしましょうか。
A：午後二時でお願いします。
B：はい、分かりました。ごめんなさいね。
```

**Хирагана:**
```
A：もしもし、アリスです。
B：あ、アリスさん、たなかです。ごめんください。
A：どうしましたか。
B：じつは、あしたのよていなんですが、きゅうようができてしまって、いけなくなってしまいました。
A：そうですか。じゃあ、あさってはどうですか。
B：あさってならだいじょうぶです。なんじにしましょうか。
A：ごごにじでおねがいします。
B：はい、わかりました。ごめんなさいね。
```

**Перевод:**
- А: Алло, это Алиса.
- Б: О, Алиса-сан, это Танака. Извините.
- А: Что случилось?
- Б: Насчёт завтрашних планов — возникло срочное дело, и я не смогу прийти.
- А: Понятно. Тогда послезавтра как?
- Б: Послезавтра могу. На какое время?
- А: В два часа дня, пожалуйста.
- Б: Хорошо, понял. Извини.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| 実は じつは | на самом деле | |
| 予定 よてい | план, расписание | |
| 急用 きゅうよう | срочное дело | |
| 明後日 あさって | послезавтра | |
| 午後 ごご | после полудня | |

**Вопросы:**
1. なぜ行けなくなりましたか。 a) 風邪 b) 急用 c) 雨
2. いつ会いますか。 a) 明日 b) 明後日 c) 来週
3. 何時に会いますか。 a) 午後一時 b) 午後二時 c) 午後三時

**Ключи:** 1. b · 2. b · 3. b

# 7. Рабочая встреча (会議 の前)

**Ситуация:** обсуждение отчёта перед совещанием.

```
田中：課長、昨日の資料、ご覧になりましたか。
課長：はい、見ました。よくまとまっていましたね。
田中：ありがとうございます。ただ、最後のページの数字が少し気になります。
課長：ええ、確かに。そこを直してもらえますか。
田中：では、今から直して、会議までに準備しておきます。
課長：お願いします。あと、パソコンとプロジェクターも準備しておいてください。
田中：はい、承知しました。
```

**Хирагана:**
```
たなか：かちょう、きのうのしりょう、ごらんになりましたか。
かちょう：はい、みました。よくまとまっていましたね。
たなか：ありがとうございます。ただ、さいごのページのすうじがすこしきになります。
かちょう：ええ、たしかに。そこをなおしてもらえますか。
たなか：では、いまからなおして、かいぎまでにじゅんびしておきます。
かちょう：おねがいします。あと、パソコンとプロジェクターもじゅんびしておいてください。
たなか：はい、しょうちしました。
```

**Перевод:**
- Танака: Начальник, вы посмотрели вчерашние материалы?
- Начальник: Да, посмотрел. Хорошо составлено.
- Танака: Спасибо. Но меня немного смущают цифры на последней странице.
- Начальник: Да, точно. Не могли бы вы это исправить?
- Танака: Тогда исправлю сейчас и подготовлю к совещанию.
- Начальник: Пожалуйста. И ещё подготовьте компьютер и проектор.
- Танака: Хорошо, понял.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|
| 課長 かちょう | начальник отдела | |
| 資料 しりょう | материалы, документы | |
| ご覧になる ごらんになる | смотреть (вежл.) | |
| 数字 すうじ | цифры | |
| 気になる きになる | беспокоить | |
| 直す なおす | исправлять | |
| 会議 かいぎ | совещание | |
| 承知 しょうち | понимание, согласие | |

**Вопросы:**
1. 課長は資料をどう思いましたか。 a) 悪い b) よくまとまっている c) 分からない
2. 何を直しますか。 a) 文章 b) 数字 c) 写真
3. 田中さんは他に何を準備しますか。 a) 資料 b) 会場 c) パソコンとプロジェクター

**Ключи:** 1. b · 2. b · 3. c

# 9. В банке (銀行 で)

**Ситуация:** открытие счёта.

```
A：すみません、口座を開きたいんですが。
B：はい、こちらへどうぞ。身分証明書はお持ちですか。
A：はい、パスポートがあります。
B：では、この用紙に住所と名前を書いてください。
A：銀行印は必要ですか。
B：印鑑でもサインでも、どちらでも大丈夫です。
A：分かりました。あと、カードはいつもらえますか。
B：こちらで発行しますので、今日お渡しできます。
```

**Хирагана:**
```
A：すみません、こうざをひらきたいんですが。
B：はい、こちらへどうぞ。みぶんしょうめいしょはおもちですか。
A：はい、パスポートがあります。
B：では、このようしにじゅうしょとなまえをかいてください。
A：ぎんこういんはひつようですか。
B：いんかんでもサインでも、どちらでもだいじょうぶです。
A：わかりました。あと、カードはいつもらえますか。
B：こちらではっこうしますので、きょうおわたしできます。
```

**Перевод:**
- А: Извините, хочу открыть счёт.
- Б: Пожалуйста, сюда. У вас есть документ, удостоверяющий личность?
- А: Да, есть паспорт.
- Б: Тогда напишите в этой форме адрес и имя.
- А: Нужна ли печать банка (личная печать)?
- Б: Можно и печать, и подпись — любое.
- А: Понял. И когда я получу карту?
- Б: Мы выпустим её здесь, так что смогу выдать сегодня.

**Словарь:**
| Слово | Чтение | Значение |
|-------|--------|----------|

- Вчера вечером в людном районе Токио произошёл пожар. Пострадавших не было, но три здания сгорели полностью. Причиной огня, вероятно, считается небрежное обращение с сигаретой. Полиция выясняет подробности.

**Вопросы:**
1. いつ火事がありましたか。 a) 今朝 b) 昨日の夜 c) 先週
2. 何軒全焼しましたか。 a) 一軒 b) 二軒 c) 三軒
3. 怪我をした人は？ a) いた b) いなかった c) 分からない

**Ключи:** 1. b · 2. c · 3. b

# 20. JLPT-формат: два мнения (综合理解の一部)

```
田中さんは、毎日スマートフォンを長時間使っています。医者に「目が疲れるから、もっと休むべきです」と言われました。しかし、田中さんは仕事で仕方なく使っています。代わりに、休憩時間には目を休めるようにしています。
```

**Хирагана:**
```
たなかさんは、まいにちスマートフォンをちょうじかんつかっています。いしゃに「めがつかれるから、もっとやすむべきです」といわれました。しかし、たなかさんはしごとでしかたなくつかっています。かわりに、きゅうけいじかんにはめをやすめるようにしています。
```

**Перевод:**
- Г-н Танака каждый день долго пользуется смартфоном. Врач сказал ему: «Глаза устают, надо больше отдыхать». Однако Танака пользуется им вынужденно, из-за работы. Вместо этого он старается отдыхать глазами в перерывах.

**Вопросы:**
1. 医者は何と言いましたか。 a) 休むべき b) もっと使うべき c) 運動すべき
2. なぜスマホを使いますか。 a) 趣味 b) 仕事 c) ゲーム
3. 田中さんはどうしますか。 a) 使うのをやめる b) 休憩に目を休める c) 医者を変える

**Ключи:** 1. a · 2. b · 3. b
