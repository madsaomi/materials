# Аудиозадания 1–10: готовые скрипты для разбора (聴解タスク)

> 🎧 Десять готовых заданий: магазин, вокзал, ресторан, звонок, транспортные объявления, прогноз погоды, урок, новости, разговор друзей, экскурсия.
> Каждое: уровень JLPT · длительность · транскрипт · хирагана · перевод · ключевая лексика · вопросы с ключами.
> Связано с: [Методика](methodology.md) · [Диалоги](dialogues.md) · [Монологи](monologues.md)

**Как использовать каждое задание (25 мин, по [методике §10](methodology.md#10-пошаговый-разбор-одного-аудио-без-субтитров-с-субтитрами-shadowing)):**
1. Прочитайте тему и вопросы — запишите 5 слов, которые ожидаете услышать.
2. Прослушайте без текста (или попросите партнёра прочитать), ответьте на вопросы.
3. Прослушайте ещё раз — теперь с хираганой, отметьте, что не расслышали.
4. Перепишите 2–3 фразы хираганой под диктовку.
5. Сделайте shadowing по 1–2 реплики, сверьтесь с ключами.

## Задача 1. В магазине (コンビニ)

> JLPT N5 · ~45 сек · жанр: диалог (покупатель — продавец) · озвучить: TTS или партнёр

**Транскрипт:**

```
店員：いらっしゃいませ。
客：おにぎりはどこですか。
店員：あちら、飲み物のそばにあります。
客：さっき、イートインで食べたんですが、ごみはどこに捨てますか。
店員：店内にはごみ箱がございません。すみませんが、ごみはお持ち帰りください。
客：そうですか。じゃあ、おにぎりとお茶をお願いします。
店員：はい。おにぎり百円、お茶百十円で、合計二百十円になります。
客：電子マネーで払います。
店員：かしこまりました。お預かりします。ありがとうございました。
```

**Хирагана:**

```
てんいん：いらっしゃいませ。
きゃく：おにぎりはどこですか。
てんいん：あちら、のみもののそばにあります。
きゃく：さっき、イートインでたべたんですが、ごみはどこにすてますか。
てんいん：てんないにはごみばこがございません。すみませんが、ごみはおもちかえりください。
きゃく：そうですか。じゃあ、おにぎりとおちゃをおねがいします。
てんいん：はい。おにぎりひゃくえん、おちゃひゃくじゅうえんで、ごうけいにひゃくじゅうえんになります。
きゃく：でんしマネーではらいます。
てんいん：かしこまりました。おあずかりします。ありがとうございました。
```

**Перевод:**
- Продавец: Добро пожаловать.
- Покупатель: Где онигири?
- Продавец: Вон там, рядом с напитками.
- Покупатель: Я только что ел в зоне для еды — куда выбрасывать мусор?
- Продавец: В магазине урн нет. Извините, заберите мусор с собой.
- Покупатель: Понятно. Тогда, пожалуйста, онигири и чай.
- Продавец: Да. Онигири 100 иен, чай 110 иен, всего 210 иен.
- Покупатель: Оплачу электронным кошельком.
- Продавец: Принято. Спасибо большое.

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| いらっしゃいませ | — | добро пожаловать (в магазине) |
| おにぎり | — | онигири, рисовый шарик |
| 飲み物 | のみもの | напитки |
| イートイン | — | еда в зале магазина |
| ごみ | — | мусор |
| ごみ箱 | ごみばこ | урна, ведро |
| 持ち帰る | もちかえる | забирать с собой |
| 合計 | ごうけい | итого, сумма |
| 電子マネー | でんしマネー | электронный кошелёк |

**Вопросы:**

1. おにぎりはどこにありますか。 a) 入り口のそば b) 飲み物のそば c) レジの前
2. 店内にごみ箱はありますか。 a) ある b) ない c) 店員も分からない
3. 合計はいくらですか。 a) 百円 b) 二百十円 c) 三百円
4. お客さんは何で払いますか。 a) 現金 b) カード c) 電子マネー

**Ключи:** 1. b · 2. b · 3. b · 4. c

## Задача 2. На вокзале (駅 で)

> JLPT N5 · ~40 сек · жанр: диалог (пассажир — прохожий/диспетчер)

**Транскрипт:**

```
A：すみません、京都へ行きたいんですが、どのホームですか。
B：京都行きは、四番ホームから出ますよ。あと十分で出発します。
A：急がないと。切符はどこで買えますか。
B：あそこの自動券売機で買えます。特急に乗るなら、特急券も必要ですよ。
A：普通で行きますから、いりません。
B：では、四番ホームへ上がってください。京都まで、電車で一時間半ぐらいです。
A：分かりました。ありがとうございます！
```

**Хирагана:**

```
A：すみません、きょうとへいきたいんですが、どのホームですか。
B：きょうとゆきは、よんばんホームからでますよ。あとじゅっぷんでしゅっぱつします。
A：いそがないと。きっぷはどこでかえますか。
B：あそこのじどうけんばいきでかえます。とっきゅうにのるなら、とっきゅうけんもひつようですよ。
A：ふつうでいきますから、いりません。
B：では、よんばんホームへあがってください。きょうとまで、でんしゃでいちじかんはんぐらいです。
A：わかりました。ありがとうございます！
```

**Перевод:**
- А: Извините, хочу в Киото — с какой платформы?
- Б: На Киото садятся с четвёртой платформы. Отправление через десять минут.
- А: Надо поспешить. Где можно купить билет?
- Б: Вон там, в автомате. Если ехать на экспрессе, нужен ещё билет на экспресс.
- А: Поеду на обычной, не нужен.
- Б: Тогда поднимитесь на четвёртую платформу. До Киото на поезде около полутора часов.
- А: Понял. Спасибо!

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| ホーム | — | платформа, перрон |
| 〜行き | 〜ゆき | направление на ~ |
| 出発 | しゅっぱつ | отправление |
| 切符 | きっぷ | билет |
| 自動券売機 | じどうけんばいき | билетный автомат |
| 特急券 | とっきゅうけん | билет на экспресс |
| 必要 | ひつよう | нужный, необходимый |
| 普通 | ふつう | обычный (поезд) |
| 上がる | あがる | подниматься (на платформу) |

**Вопросы:**

1. 京都行きは何番ホームですか。 a) 二番 b) 四番 c) 六番
2. 電車はいつ出発しますか。 a) あと五分 b) あと十分 c) あと三十分
3. 切符はどこで買いますか。 a) 窓口 b) 自動券売機 c) スマホ
4. 京都までどのくらいかかりますか。 a) 一時間 b) 一時間半 c) 二時間

**Ключи:** 1. b · 2. b · 3. b · 4. b

## Задача 3. В ресторане (レストラン で)

> JLPT N5–N4 · ~45 сек · жанр: диалог (официант — гость)

**Транскрипт:**

```
店員：いらっしゃいませ。ご注文はお決まりですか。
客：まだです。おすすめは何ですか。
店員：今日のおすすめは、海老と野菜の天ぷら丼です。味噌汁が付いて、千二百円です。
客：おいしそうですね。それでお願いします。
店員：かしこまりました。お飲み物はどうしますか。
客：冷たいお茶をお願いします。
店員：デザートはいかがですか。抹茶パフェが人気です。
客：じゃあ、それもお願いします。
```

**Хирагана:**

```
てんいん：いらっしゃいませ。ごちゅうもんはおきまりですか。
きゃく：まだです。おすすめはなんですか。
てんいん：きょうのおすすめは、えびとやさいのてんぷらどんです。みそしるがついて、せんにひゃくえんです。
きゃく：おいしそうですね。それでおねがいします。
てんいん：かしこまりました。おのみものはどうしますか。
きゃく：つめたいおちゃをおねがいします。
てんいん：デザートはいかがですか。まっちゃパフェがにんきです。
きゃく：じゃあ、それもおねがいします。
```

**Перевод:**
- Официант: Добро пожаловать. Вы уже определились с заказом?
- Гость: Пока нет. Что порекомендуете?
- Официант: Сегодняшняя рекомендация — донбури с крабами в темпуре и овощами. С мисо-супом, 1200 иен.
- Гость: Звучит вкусно. Тогда его, пожалуйста.
- Официант: Принято. Что будете пить?
- Гость: Холодный чай, пожалуйста.
- Официант: Как насчёт десерта? Популярен парфе с матчей.
- Гость: Тогда и его, пожалуйста.

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| 注文 | ちゅうもん | заказ |
| お決まり | おきまり | определились |
| おすすめ | — | рекомендация |
| 海老 | えび | креветка |
| 天ぷら丼 | てんぷらどん | донбури с темпурой |
| 味噌汁 | みそしる | мисо-суп |
| 冷たい | つめたい | холодный |
| 抹茶 | まっちゃ | маття (зелёный чай) |
| 人気 | にんき | популярный |

**Вопросы:**

1. 今日のおすすめは何ですか。 a) ラーメン b) 海老と野菜の天ぷら丼 c) 寿司
2. お値段はいくらですか。 a) 千円 b) 千二百円 c) 千五百円
3. お飲み物は何にしましたか。 a) コーヒー b) 冷たいお茶 c) ビール
4. デザートを頼みましたか。 a) はい b) いいえ

**Ключи:** 1. b · 2. b · 3. b · 4. a

## Задача 4. Телефонный звонок (電話)

> JLPT N4 · ~45 сек · жанр: разговор подруг (неформальный)

**Транскрипт:**

```
あおい：もしもし、ゆき？あおいだよ。
ゆき：あ、あおいちゃん、どうしたの？
あおい：週末の映画のチケット、明日までに予約しないと売り切れちゃうんだって。
ゆき：え、そうなの？じゃあ、今晩予約しようか。
あおい：うん、お願い。何時の回にする？私は午後なら大丈夫。
ゆき：私は夕方の六時頃がいいな。仕事が四時半に終わるから。
あおい：じゃあ、六時半の回はどう？
ゆき：いいね。それでお願い。
あおい：駅前のシネマでいい？
ゆき：うん、いいよ。ありがとう！
```

**Хирагана:**

```
あおい：もしもし、ゆき？あおいだよ。
ゆき：あ、あおいちゃん、どうしたの？
あおい：しゅうまつのえいがのチケット、あしたまでによやくしないとうりきれちゃうんだって。
ゆき：え、そうなの？じゃあ、こんばんよやくしようか。
あおい：うん、おねがい。なんじのかいにする？わたしはごごならだいじょうぶ。
ゆき：わたしはゆうがたのろくじごろがいいな。しごとがよじはんにおわるから。
あおい：じゃあ、ろくじはんのかいはどう？
ゆき：いいね。それでおねがい。
あおい：えきまえのシネマでいい？
ゆき：うん、いいよ。ありがとう！
```

**Перевод:**
- Аой: Алло, Юки? Это Аой.
- Юки: О, Аой-тян, что случилось?
- Аой: Говорят, билеты на фильм на выходных распродадут, если не забронировать до завтра.
- Юки: Правда? Тогда забронируем сегодня вечером?
- Аой: Да, буду признательна. На какой сеанс? Мне подойдёт после полудня.
- Юки: Мне лучше около шести вечера — работа заканчивается в половине пятого.
- Аой: Тогда сеанс в полседьмого?
- Юки: Хорошо, давай.
- Аой: Подходит кинотеатр у станции?
- Юки: Да, отлично. Спасибо!

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| 売り切れる | うりきれる | раскупаться, быть распроданным |
| 予約 | よやく | бронирование |
| 回 | かい | сеанс, раз (счётный) |
| 夕方 | ゆうがた | вечер (около 16–18 ч) |
| 映画館 | えいがかん | кинотеатр |
| シネマ | — | кинотеатр (заимств.) |
| 駅前 | えきまえ | район у станции |

**Вопросы:**

1. チケットはいつまでに予約しますか。 a) 今日まで b) 明日まで c) あさってまで
2. 映画は何時の回を見ますか。 a) 三時 b) 六時半 c) 八時
3. ゆきさんの仕事は何時に終わりますか。 a) 四時 b) 四時半 c) 五時
4. 映画館はどこにありますか。 a) 家の近く b) デパートの中 c) 駅前

**Ключи:** 1. b · 2. b · 3. b · 4. c

> 💡 На слух: 予約しないと (не забронируешь), 売り切れちゃう (распродают) — стяжение 〜てしまう→てちゃう. См. [Редкие трудности](difficulties.md).

## Задача 5. Объявление в транспорте (車内・駅 のアナウンス)

> JLPT N4 · ~50 сек · жанр: объявление по громкоговорителю (метро)

**Транскрипт:**

```
お客様にご案内いたします。本日、午後七時から、東京メトロ丸ノ内線は、車両点検のため、新宿駅と池袋駅の間で運転を一時休止いたします。ご利用のお客様には大変ご迷惑をおかけいたします。代わりに、振替輸送をご利用ください。通常の運転は、明日の始発から再開いたします。お急ぎのところ誠に申し訳ございません。皆様のご理解とご協力をお願いいたします。
```

**Хирагана:**

```
おきゃくさまにごあんないいたします。ほんじつ、ごごしちじから、とうきょうメトロまるのうちせんは、しゃりょうてんけんのため、しんじゅくえきといけぶくろえきのあいだでうんてんをいちじきゅうしいたします。ごりようのおきゃくさまにはたいへんごめいわくをおかけいたします。かわりに、ふりかえゆそうをごりようください。つうじょうのうんてんは、あしたのしはつからさいかいいたします。おいそぎのところまことにもうしわけございません。みなさまのごりかいとごきょうりょくをおねがいいたします。
```

**Перевод:**
- Сообщаем уважаемым пассажирам. Сегодня с семи часов вечера линия Маруноути токайского метро из-за технической проверки подвижного состава временно приостанавливает движение на участке между станциями Синдзюку и Икэбукуро. Приносим большие неудобства пользующимся линией пассажирам. Вместо неё воспользуйтесь, пожалуйста, перевозкой по альтернативным маршрутам. Обычное движение возобновится с первого рейса завтрашнего дня. Приносим искренние извинения тем, кто спешит. Просим вашего понимания и сотрудничества.

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| ご案内 | ごあんない | уведомление, справка |
| 車両点検 | しゃりょうてんけん | техпроверка составов |
| 間 | あいだ | промежуток, участок |
| 休止 | きゅうし | приостановка |
| 迷惑 | めいわく | неудобство |
| 振替輸送 | ふりかえゆそう | перевозка альтернативными маршрутами |
| 始発 | しはつ | первый рейс |
| 再開 | さいかい | возобновление |
| 申し訳ございません | もうしわけございません | приношу извинения (вежл.) |

**Вопросы:**

1. どの線の運転が休止しますか。 a) 千代田線 b) 丸ノ内線 c) 銀座線
2. いつから休止しますか。 a) 午後五時 b) 午後七時 c) 午後九時
3. なぜ休止しますか。 a) 事故 b) 工事 c) 車両点検
4. いつ再開しますか。 a) 今夜 b) 明日の始発から c) 来週

**Ключи:** 1. b · 2. b · 3. c · 4. b

## Задача 6. Прогноз погоды (天気予報)

> JLPT N4–N3 · ~45 сек · жанр: радио/телевизионный прогноз

**Транскрипт:**

```
それでは、明日の天気予報をお伝えします。明日の朝は、低気圧の影響で、午前中は関東地方を中心に雨が降るでしょう。お出かけの際は、傘をお持ちください。午後は雲が取れて、次第に晴れ間が広がる見込みです。明日の気温は、今日より五度ほど低く、十五度くらいでしょう。朝晩は冷えますので、上着が一枚あると安心です。週末はおおむね晴れて、過ごしやすい天気になる見込みです。
```

**Хирагана:**

```
それでは、あしたのてんきよほうをおつたえします。あしたのあさは、ていきあつのえいきょうで、ごぜんちゅうはかんとうちほうをちゅうしんにあめがふるでしょう。おでかけのさいは、かさをおもちください。ごごはくもがとれて、しだいにはれまがひろがるみこみです。あしたのきおんは、きょうよりごどほどひくく、じゅうごどくらいでしょう。あさばんはひえますので、うわぎがいちまいあるとあんしんです。しゅうまつはおおむねはれて、すごしやすいてんきになるみこみです。
```

**Перевод:**
- А теперь передаём прогноз на завтра. Завтра утром из-за влияния циклона в первой половине дня в районе Канто, преимущественно, ожидается дождь. Выходя из дома, возьмите зонт. Во второй половине дня облака рассеются, постепенно ожидается ясная погода. Температура завтра примерно на пять градусов ниже, чем сегодня, около пятнадцати градусов. Утром и вечером будет прохладно, так что хорошо иметь при себе куртку. На выходных ожидается в основном ясно, комфортная погода.

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| 天気予報 | てんきよほう | прогноз погоды |
| 低気圧 | ていきあつ | циклон |
| 影響 | えいきょう | влияние |
| 関東地方 | かんとうちほう | регион Канто |
| 晴れ間 | はれま | просвет (в облаках) |
| 見込み | みこみ | ожидание, прогноз |
| 冷える | ひえる | холодеть, охлаждаться |
| 上着 | うわぎ | куртка, верхняя одежда |
| 過ごしやすい | すごしやすい | комфортный (о погоде) |

**Вопросы:**

1. 明日の朝の天気はどうですか。 a) 晴れ b) 雨 c) 雪
2. 雨はどこを中心に降りますか。 a) 関東地方 b) 九州 c) 北海道
3. 明日の気温は今日よりどうですか。 a) 高い b) 五度ほど低い c) 同じ

## Задача 7. Урок (授業)

> JLPT N5–N4 · ~50 сек · жанр: объяснение учителя в классе

**Транскрипт:**

```
皆さん、今日は漢字のテストの練習をします。まず、ノートを出してください。次に、私が読みますから、聞いて漢字で書いてください。一つ目は「おんがく」です。二つ目は「べんきょう」です。全部で五つあります。では、始めます。
…（少し間）…
書き終わった人は、教科書の十五ページを開いて、練習問題をやってください。宿題は、ワークシートを仕上げることです。提出は金曜日までです。
```

**Хирагана:**

```
みなさん、きょうはかんじのテストのれんしゅうをします。まず、ノートをだしてください。つぎに、わたしがよみますから、きいてかんじでかいてください。ひとつめは「おんがく」です。ふたつめは「べんきょう」です。ぜんぶでいつつあります。では、はじめます。
…（すこしま）…
かきおわったひとは、きょうかしょのじゅうごページをひらいて、れんしゅうもんだいをやってください。しゅくだいは、ワークシートをしあげることです。ていしゅつはきんようびまでです。
```

**Перевод:**
- Всем, сегодня потренируемся перед тестом по кандзи. Сначала достаньте тетради. Затем я буду читать (слова) — слушайте и пишите кандзи. Первое — «онгаку». Второе — «бэнкё». Всего пять. Начинаем.
- Кто закончил писать, откройте учебник на пятнадцатой странице и делайте тренировочные задания. Домашнее задание — доделать рабочий лист. Сдача до пятницы.

| ノート | — | тетрадь |

| 教科書 | きょうかしょ | учебник |
| 練習問題 | れんしゅうもんだい | тренировочные задания |
| ワークシート | — | рабочий лист |

## Задача 8. Новости (ニュース)

> JLPT N3 · ~45 сек · жанр: радио-новости

**Транскрипт:**

```
今朝、大阪で地震がありました。震度は四で、建物が揺れましたが、大きな被害はありませんでした。電車は安全確認のため一時運転を見合わせましたが、午前九時には再開しました。気象庁は、今後一週間ほどは余震に注意するよう呼びかけています。通勤の時間帯でしたので、駅は一時、多くの人で混雑しました。
```

**Хирагана:**

```
けさ、おおさかでじしんがありました。しんどはよんで、たてものがゆれましたが、おおきなひがいはありませんでした。でんしゃはあんぜんかくにんのためいちじうんてんをみあわせましたが、ごぜんくじにはさいかいしました。きしょうちょうは、こんごいっしゅうかんほどはよしんにちゅういするようよびかけています。つうきんのじかんたいでしたので、えきはいちじ、おおくのひとでこんざつしました。
```

**Перевод:**
- Сегодня утром в Осаке произошло землетрясение. Сила толчков — 4, здания качало, но серьёзного ущерба не было. Поезда для проверки безопасности временно приостановили движение, но в девять утра оно возобновилось. Метеоагентство призывает быть осторожными с афтершоками в течение ближайшей недели. Так как это было время поездок на работу, станции временно были переполнены людьми.

| 揺れる | ゆれる | качаться, трястись |
| 被害 | ひがい | ущерб |
| 安全確認 | あんぜんかくにん | проверка безопасности |
| 運転を見合わせる | うんてんをみあわせる | временно остановить движение |
| 気象庁 | きしょうちょう | метеоагентство |
| 余震 | よしん | афтершок |
| 混雑 | こんざつ | давка, переполненность |

**Вопросы:**

## Задача 9. Разговор друзей (友達 の会話)

> JLPT N4 · ~45 сек · жанр: неформальный разговор (язык 友達口語)

**Транскрипт:**

```
けん：ねえ、今週の土曜日、暇？
みさ：うん、大丈夫だよ。何かあるの？
けん：海に行こうと思ってるんだけど、一緒に行かない？
みさ：いいね！でも、週間予報見た？土曜日は曇りって言ってたよ。
けん：えー、そうなの？じゃあ、日曜日は？
みさ：日曜日は晴れだって。日曜日にしよう！
けん：オッケー。じゃあ、朝九時に駅で待ち合わせね。
みさ：分かった。お弁当は私が作っていくよ。
けん：ありがとう！楽しみにしてる。
```

**Хирагана:**

```
けん：ねえ、こんしゅうのどようび、ひま？
みさ：うん、だいじょうぶだよ。なにかあるの？
けん：うみにいこうとおもってるんだけど、いっしょにいかない？
みさ：いいね！でも、しゅうかんよほうみた？どようびはくもりっていってたよ。
けん：えー、そうなの？じゃあ、にちようびは？
みさ：にちようびははれだって。にちようびにしよう！
けん：オッケー。じゃあ、あさくじにえきでまちあわせね。
みさ：わかった。おべんとうはわたしがつくっていくよ。
けん：ありがとう！たのしみにしてる。
```

**Перевод:**
- Кэн: Слушай, ты свободна в субботу?
- Миса: Да, нормально. Что-то случилось?
- Кэн: Хочу на море — не сходишь со мной?
- Миса: Хорошо! Но ты видел недельный прогноз? Говорили, в субботу облачно.
- Кэн: Э-э, правда? А в воскресенье?
- Миса: В воскресенье солнечно. Давай в воскресенье!
- Кэн: Окей. Тогда встречаемся в девять у станции.
- Миса: Поняла. Бэнто я приготовлю.
- Кэн: Спасибо! Жду с нетерпением.

**Ключевая лексика:**

| Слово | Чтение | Значение |
|-------|--------|----------|
| 暇 | ひま | свободное время |
| 週間予報 | しゅうかんよほう | недельный прогноз |
| 曇り | くもり | облачность |
| 待ち合わせ | まちあわせ | встреча (договорённая) |
| お弁当 | おべんとう | бэнто |
| 楽しみ | たのしみ | ожидание с радостью |

**Вопросы:**

1. 二人はいつ海に行きますか。 a) 土曜日 b) 日曜日 c) 今日
2. 土曜日の天気はどうですか。 a) 晴れ b) 曇り c) 雨
3. 何時にどこで会いますか。 a) 八時に家 b) 九時に駅 c) 十時に海
4. お弁当は誰が作りますか。 a) けん b) みさ c) お母さん

**Ключи:** 1. b · 2. b · 3. b · 4. b

> 💡 На слух: 行こうと思ってる (собираюсь пойти — 〜ている → てる), 見た? (видел? — неформальный вопрос), 晴れだって (говорят, солнечно — 伝聞 って). См. [Редкие трудности](difficulties.md).

## Задача 10. Экскурсия (観光案内)

> JLPT N4–N3 · ~1 мин · жанр: речь гида перед группой

**Транскрипт:**

```
皆さん、おはようございます。本日は一日、私がご案内いたします。午前中は、まず金閣寺を訪れます。その後、北野天満宮に行きます。昼食は、嵐山でとりますので、お好きなお店を選んで食べてください。午後は、竹林の小道を散策します。自由時間は、午後二時から三時までです。集合は、午後四時に嵐山の駅前です。バスは四時半に出発しますので、時間に余裕を持ってお集まりください。質問があれば、いつでも聞いてください。
```

**Хирагана:**

```
みなさん、おはようございます。ほんじつはいちにち、わたしがごあんないいたします。ごぜんちゅうは、まずきんかくじをたずねます。そのご、きたのてんまんぐうにいきます。ちゅうしょくは、あらしやまでとりますので、おすきなおみせをえらんでたべてください。ごごは、ちくりんのこみちをさんさくします。じゆうじかんは、ごごにじからさんじまでです。しゅうごうは、ごごよじにあらしやまのえきまえです。バスはよじはんにしゅっぱつしますので、じかんによゆうをもっておあつまりください。しつもんがあれば、いつでもきいてください。
```

**Перевод:**
- Всем, доброе утро. Сегодня в течение дня я буду вашим гидом. Утром сначала посетим Кинкакудзи (Золотой павильон). Затем поедем в Китано-Тэммангу. Обед пройдёт в Арасияма — выбирайте любое понравившееся заведение. Днём прогуляемся по тропе бамбуковой рощи. Свободное время — с двух до трёх часов дня. Сбор — в четыре часа у станции Арасияма. Автобус отправляется в половине пятого, так что пожалуйста, приходите с запасом времени. Если есть вопросы — спрашивайте в любое время.

| Слово | Чтение | Значение |
|-------|--------|----------|
| 案内 | あんない | сопровождение, экскурсия |
| 訪れる | たずねる | посещать |
| 金閣寺 | きんかくじ | Кинкакудзи |
| 北野天満宮 | きたのてんまんぐう | Китано-Тэммангу |
| 昼食 | ちゅうしょく | обед |
| 嵐山 | あらしやま | Арасияма |
