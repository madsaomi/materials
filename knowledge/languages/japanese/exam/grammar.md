# Грамматика по уровням: конструкции с примерами

> Формат: **конструкция / значение / пример**. Столбец 例文 — живое употребление; читайте вслух и составляйте по 2–3 своих предложения на каждую конструкцию — это и есть тренировка для секции 文法.

## N5 — ядро (〜です／ます и базовые связки)

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜は〜です | А есть Б | 私は学生です (я студент) |
| 〜は〜ではありません | А не есть Б | これは本ではありません (это не книга) |
| 〜ます／ました／ません | вежл. наст./прош./отриц. | 水を飲みます (пью воду) · 飲みました · 飲みません |
| 〜がいます／あります | неодуш./одуш. есть | 猫がいます (есть кот) · 本があります (есть книга) |
| 〜を | объект действия | 映画を見ます (смотрю фильм) |
| 〜に | время / направление / место | 七時に起きます (встаю в 7) · 学校に行きます |
| 〜で | место / средство | 公園で遊びます (играю в парке) · 電車で行きます |
| 〜へ | направление | 日本へ行きます (еду в Японию) |
| 〜から〜まで | от… до (время/место) | 九時から五時まで働きます |
| 〜と | вместе с | 友達と話します (говорю с другом) |
| 〜の | притяжательность | 私の本 (моя книга) |
| 〜てください | сделайте, пожалуйста | ドアを閉めてください |
| 〜てもいいです | можно | ここに座ってもいいです |
| 〜てはいけません | нельзя | ここで写真を撮ってはいけません |
| 〜てくださいませんか？ | не могли бы вы | 日本語で話してくださいませんか？ |
| 〜たい | хочу сделать | 京都に行きたいです |
| 〜たことがありません | не имел опыта | 富士山に登ったことがありません |
| 〜ましょう／ましょうか | давайте / не сделать ли | 一緒に勉強しましょう |
| 〜から | потому что (причина) | 寒いから、コーヒーを飲みます |
| 〜が、〜 | но | 高いですが、買いました |
| い-прил (大さい→大きくない→大きかった) | настоящее/отриц./прош. | 高いです · 高くない · 高かった |
| な-прил (元気な→元気じゃない) | то же для な- | 元気です · 元気じゃない · 元気だった |
| 〜があります／います | наличие | 時間がありません (нет времени) |
| 〜ましょうか？ | предложение помощи | 手伝いましょうか？ |
| お〜する | скромный (кэйго-старт) | お手伝いします |
| 数を数える (一つ、二つ…) | счётные суффиксы | りんごを三つください |

## N4 — развиваем предложение

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜たことがある | был опыт | 日本に行ったことがあります |
| 〜たら | если (универс. условие) | 雨が降ったら、行きません |
| 〜ば | если (логическое) | 安ければ買います |
| 〜なら | если речь о… | 京都なら、新幹線がいいです |
| 〜と | при условии (автоматизм) | 春になると桜が咲きます |
| 〜ても | даже если | 高くても買います |
| 〜のに | хотя, вопреки | 雨なのに出かけました |
| 〜ので | мягкая причина | 頭が痛いので休みます |
| 〜し | перечисление причин | 近いし、安いし、最高だ |
| 〜ながら | делая одновременно | 音楽を聞きながら勉強します |
| 〜てから | после того как | 仕事が終わってから飲みます |
| 〜たあとで | после | 食べたあとで出かけます |
| 〜ている | процесс / состояние / привычка | 本を読んでいます |
| 〜てしまう | завершить / сожалеть | 宿題を忘れてしまった |
| 〜ておく | сделать заранее | チケットを買っておきます |
| 〜てみる | попробовать | 食べてみてください |
| 〜てある | оставлено сделанным | ドアが開けてあります |
| 〜てもらう／てくれる | услуга мне | 辞書を貸してもらった |
| 〜てあげる | услуга другому | 弟に本を買ってあげます |
| 〜てほしい | хочу, чтобы сделал | 早く来てほしいです |
| 可能形（泳げる、食べられる） | могу | この漢字が読めます |
| 〜ことができます | (книжно) могу | 日本語を話すことができます |
| 受身形（〜られる／〜れる） | пассив | 先生に褒められました |
| 使役形（〜させる） | заставить | 子供に野菜を食べさせました |
| 使役受身（〜させられる） | быть вынужденным | 残業させられました |
| 〜ようになる | стать делать / научиться | 漢字が読めるようになった |
| 〜ようにする | стараться делать | 毎日運動するようにしています |
| 〜そうだ（様子） | выглядит ~ | おいしそうですね |
| 〜そうだ（伝聞） | говорят | 明日は晴れるそうです |
| 〜ようだ／みたいだ | похоже, что | 風邪のようです |
| 〜らしい | вроде бы / говорят | 彼は忙しいらしい |
| 〜はずだ | должно быть (по логике) | もう着いたはずです |
| 〜かもしれない | может быть | 電車が遅れるかもしれません |
| 〜だろう／でしょう | вероятно | 明日は晴れるでしょう |
| 〜すぎる | слишком | 食べすぎました |
| 〜やすい／にくい | легко / трудно | この字は読みにくい |
| 〜なければならない | должен | 薬を飲まなければなりません |
| 〜つもりだ | намерение | 留学するつもりです |
| 〜ことにする | решить самому | 毎日走ることにした |
| 〜ことになる | решено извне | 大阪へ転勤することになった |
| 〜予定だ | план | 来月帰国する予定です |
| 〜ために（目的) | чтобы / ради | 日本語を勉強するために辞書を買った |
| 〜前に | перед тем как | 寝る前に歯を磨きます |
| 〜たほうがいい | лучше бы | 早く寝たほうがいいです |
| 〜ないでください | пожалуйста, не | 遅刻しないでください |

## N3 — связность и нюансы значений

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜ように（願望・目標) | чтобы / с целью | 遅れないように早めに出発した |
| 〜ように言う／頼む | велеть/просить (передача речи) | 早く来るように言ってください |
| 〜ところだ | как раз (сейчас/до/после) | 今食べたところです (только что) |
| 〜ばかりだ | только что (し終えた) | 家に着いたばかりです |
| 〜ばかり | только (перебор) | ゲームばかりしています |
| 〜に比べて | по сравнению с | 去年に比べて暑いです |
| 〜に対して | по отношению к / на | 質問に対して答えます |
| 〜にとって | для / с точки зрения | 私にとって大事なことです |
| 〜について | о / относительно | 日本の文化について話します |
| 〜として | в качестве | 留学生として来ました |
| 〜によって／による | зависит от / благодаря / по | 天気によって変わります · 地震による被害 |
| 〜によると | по словам (источник) | ニュースによると、明日は暑い |
| 〜につれて | по мере того как | 慣れるにつれて楽しくなった |
| 〜に伴って | вместе с / по мере | 経済成長に伴って賃金も上がった |
| 〜に従って | согласно / по мере | 指示に従ってください |
| 〜とともに | вместе с / и то и | 年をとるとともに記憶力が落ちる |
| 〜にしては | для своего положения | 初心者にしては上手だ |
| 〜わりに | несоответствие | 高いわりにおいしくない |
| 〜に限らず | не только | 男性に限らず女性も参加した |
| 〜ばかりでなく | не только… но и | 値段ばかりでなく味も大事だ |
| 〜てもいい（許可) | можно | 帰ってもいいですよ |
| 〜てはじめて | только после того как | 失ってはじめて大事さがわかる |
| 〜たびに | каждый раз, когда | 会うたびに成長している |
| 〜うちに | пока / в течение | 明るいうちに帰りましょう |
| 〜最中に | в разгар | 会議の最中に電話が鳴った |
| 〜まま | (оставив) в состоянии | 電気をつけたまま寝た |
| 〜っぽい | похож по характеру | 彼は子供っぽい |
| 〜がちだ | склонен / часто | 冬は風邪を引きがちだ |
| 〜ぎみだ | слегка ~ | 今日は疲れ気味です |
| 〜げ | на вид / с видом | 楽しげに話しています |
| 〜ようがない | нет способа | 言いようがないほど美しい |
| 〜わけが／ない | no way / незачем | そんなわけがない |
| 〜からには | раз уж | 約束したからには守る |
| 〜とおりに | как (было сказано) | 説明のとおりにやります |
| 〜みたいだ | как будто | うそみたいですね |

## N2 — продвинутые связки и модальность

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜おかげで | благодаря (светлое) | 先生のおかげで合格した |
| 〜せいで | из-за (тёмное) | 雨のせいで試合が中止になった |
| 〜に基づいて | на основе | データに基づいて判断する |
| 〜に沿って | в соответствии (по линии) | 計画に沿って進める |
| 〜を問わず | независимо от | 年齢を問わず参加できます |
| 〜抜きに／抜きで | без | 説明抜きで始めよう |
| 〜に違いない | должно быть (уверенно) | 彼は合格したに違いない |
| 〜に過ぎない | не более чем | 推測に過ぎない |
| 〜に限って | именно ~ (ирония судьбы) | 大事な日に限って雨が降る |
| 〜とは限らない | не обязательно | 高いとは限らない |
| 〜とはいえ | хотя и | 便利とはいえ、ちょっと高い |
| 〜ざるを得ない | не могу не / вынужден | 認めざるを得ない |
| 〜に反して | вопреки | 予想に反して成功した |
| 〜に代わって | вместо / от имени | 社長に代わって挨拶した |
| 〜に応じて | в соответствии с | 収入に応じて払う |
| 〜を通じて／通して | через / посредством | 友達を通じて知り合った |
| 〜をはじめ | начиная с (главное) | 東京をはじめ各地で開かれる |
| 〜をめぐって | вокруг / по поводу | 問題をめぐって議論した |
| 〜にわたって | на протяжении | 三年にわたって研究した |
| 〜うちに／うちは | пока (в период) | 若いうちに色々経験したい |
| 〜一方で | с другой стороны | 批判がある一方で支持も多い |
| 〜反面 | в то время как (разн.) | 便利な反面、危険もある |
| 〜ところを | (прерывание) — тут | お忙しいところ失礼します |
| 〜たびに | каждый раз | 見るたびに驚きます |
| 〜がたい | трудно (эмоц.) | 信じがたいことだ |
| 〜かねない | не исключено, что | 事故を起こしかねない |
| 〜かねる | не могу / трудно (вежл.) | ご要望には応えかねます |
| 〜おそれがある | есть опасность | 遅れるおそれがある |
| 〜つつある | постепенно происходит | 経済は回復しつつある |
| 〜ところをみると | судя по тому, что | 顔色からすると疲れているようだ |
| 〜からすると／からいうと | судя/судя по (точка) | 値段からすると高級品だ |
| 〜からして | уже по одному ~ | 態度からして失礼だ |
| 〜ばかりに | именно из-за (сожаление) | 一声かけたばかりにトラブルになった |

## Как учить конструкции списком

1. **Одна функция = одна группа.** Соберите все «причины» вместе (から/ので/ため/せいで/おかげで) и противопоставьте.
2. **Пример — из своей жизни.** Шаблонное предложение из учебника не запоминается. Постройте своё: 私は〜に違いない、うちの犬は〜がちだ。
3. **Спряжение перед таблицей.** Для 〜ば и 〜たら сначала уверенно спрягайте любой глагол, потом ставьте конструкцию.
4. **N2→N1** идут синонимическими парами: 〜に違いない＝きっと〜だ、〜ざるを得ない＝〜しか選択肢がない.
5. **Повторение:** Anki-карточка «форма → 3 примера из курса → перевод» ; интервал 1-3-7-15 дней.

## Быстрая навигация по функциям

| Нужно выразить | Берите |
|----------------|--------|
| Причина | から (N5) · ので (N4) · ために (N4) · せいで／おかげで (N2) |
| Условие | と (N4) · ば (N4) · たら (N4) · なら (N4) |
| Время | とき (N5) · ながら／てから (N4) · うちに／ついでに／たびに (N3) |
| Предположение | でしょう (N4) · かもしれない (N4) · そうだ／ようだ／らしい (N4) · に違いない (N2) |
| Должен | なければならない (N4) · べきだ (N3) · ざるを得ない (N2) |
| Не надо | 〜なくていい (N4) · 〜わけにはいかない (N3/N2) |
| Противопоставление | が (N5) · のに (N4) · 一方で／反面 (N2) |
