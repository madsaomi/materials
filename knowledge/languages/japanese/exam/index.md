# Японский — JLPT подготовка

## JLPT N5 (100 кандзи, 800 слов)

### Что нужно знать
- Хирагана, катакана
- 100 кандзи
- Простые грамматические конструкции
- Базовая лексика

### Грамматика N5
| Конструкция | Значение |
|-------------|----------|
| 〜は〜です | А есть Б |
| 〜ます・〜ました | Вежливое настоящее/прошедшее |
| 〜てください | Сделайте, пожалуйста |
| 〜たい | Хочу сделать |
| 〜ましょう | Давайте сделаем |
| 〜てもいい | Можно сделать |
| 〜てはいけない | Нельзя |
| 〜ないでください | Пожалуйста, не делайте |
| 〜から | Потому что |
| 〜が、〜 | Но |

### Стратегия N5
1. Выучить хирагану и катакану (1-2 недели)
2. 100 кандзи (3 недели)
3. Грамматика (2 недели)
4. Лексика (3 недели)
5. Пробные тесты (2 недели)
Итого: ~3 месяца

## JLPT N2 (1000 кандзи, 6000 слов)

### Грамматика
| Конструкция | Значение |
|-------------|----------|
| 〜おかげで | Благодаря |
| 〜せいで | Из-за (вина) |
| 〜に伴って | Сопровождаясь |
| 〜に従って | По мере |
| 〜にわたって | На протяжении |
| 〜を通じて | Через/посредством |
| 〜抜きに | Без/исключая |
| 〜に違いない | Должно быть |
| 〜に過ぎない | Не более чем |
| 〜に限って | Только/именно |
| 〜とは限らない | Не обязательно |
| 〜ものか | Разве буду |

### Что нужно уметь
- Читать газетные статьи
- Понимать новости
- Участвовать в обсуждениях
- Писать эссе 400-600字
- Абстрактная лексика

### Лексика по темам
- Политика/экономика
- Наука/технологии
- Культура/искусство
- Социальные проблемы
- Формальная переписка

## JLPT N1 (2000 кандзи, 10000+ слов)

### Грамматика
| Конструкция | Значение |
|-------------|----------|
| 〜まい | Не буду / наверное не |
| 〜べからず | Нельзя (запрет) |
| 〜ざるを得ない | Не могу не |
| 〜かねる | Не могу / трудно |
| 〜かねない | Может / не исключено |
| 〜兼ねる | Трудно / не могу |
| 〜そびれる | Упустить момент |
| 〜に足る | Достойный |
| 〜を余儀なくされる | Быть вынужденным |
| 〜ずくめ | Сплошь |
| 〜がてら | Заодно |
| 〜をおいて | Кроме / только |

### Что нужно уметь
- Свободно читать любые тексты
- Понимать подтекст/иронию
- Формальная и письменная речь
- Академические тексты
- Классическая/архаичная лексика

### Стратегия для N1
1. Чтение книг/газет ежедневно
2. Аниме/дорамы без субтитров
3. Радио новости (NHK)
4. Эссе на сложные темы
5. Кандзи: он+кун чтения + контекст
