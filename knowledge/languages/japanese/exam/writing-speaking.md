# Клише и шаблоны: письменная часть и интервью

> ⚠️ **Важно понимать:** в самом JLPT письменного сочинения и собеседования **нет**. Этот файл — шаблоны, которые нужны в двух соседних ситуациях:
> 1. **Письменные задания JLPT-типа** — «сборка предложения» (文の組み立て) и «связный текст» (文章の文法): там решают именно связки и клише.
> 2. **Реальная коммуникация** — собеседование в японскую школу/компанию, эссе для EJU/университета, официальные письма.
>
> Связанные материалы: [Грамматика по уровням](grammar.md) · [Структура экзамена](exam-structure.md)

## Часть 1. Связки для текстов (使える接続表現)

### В начало текста (序論)

| Японски | Чтение | Значение |
|---------|--------|----------|
| はじめに | хадзимэни | во-первых, для начала |
| というのは | тою: но ва | дело в том, что |
| そもそも | сомосомо | вообще-то, с самого начала |
| 結論から言うと | кэцурон кара иу то | если говорить о выводе |
| 最近、〜が問題になっている | сайкин 〜 га мондай ни наттэ иру | в последнее время ~ стало проблемой |

### Переход к аргументам (本論)

| Японски | Чтение | Значение |
|---------|--------|----------|
| まず | мадзу | во-первых |
| 次に | цуги ни | во-вторых |
| さらに / また | сарани / мата | кроме того |
| 例えば | татоэба | например |
| 一方で | иппо: дэ | с другой стороны |
| 確かに〜しかし | тасика ни 〜 сикаси | действительно, ~, однако |
| その理由として | соно рию: тоситэ | в качестве причины этого |
| つまり | цумари | иными словами |
| 〜に関しては | ни канситэ ва | что касается |
| という観点から見ると | тою: кантэн кара миру то | если смотреть с точки зрения |

### Заключение (結論)

| Японски | Чтение | Значение |
|---------|--------|----------|
| このように | коно ё: ни | таким образом |
| 以上のことから | идзё: но кото кара | из вышесказанного |
| まとめると | матомэру то | если подытожить |
| 私は〜だと思う | ватаси ва 〜 да то омоу | я считаю, что ~ |
| 〜ではないだろうか | дэ ва най дарока | не является ли ~ (риторич.) |
| 〜と言える | то иэру | можно сказать, что ~ |
| 最後に | сайго ни | в заключение |

### Структура эссе «序論・本論・結論»

```
序論（1 абзац）:   тема + своя позиция.  「私は〜だと考える。」
本論（2–3 абзаца）:  аргумент → пример → вывод из примера.
結論（1 абзац）:   повтор позиции другими словами + вывод.
```

**Шаблон эссе 400–600字:**

```
はじめに、最近の〜をめぐって、さまざまな意見があると
言われている。私は〜だと考える。
まず、〜という理由がある。例えば、…（具体例）。また、…。
一方で、〜という意見もある。確かにそのとおりかもしれない。
しかし、私は〜の方が重要だと思う。
このように、…。最後に、これから〜ことが大切ではないだろうか。
```

## Часть 2. Официальные письма (手紙・ビジネスメール)

### Регистры общения

| Стиль | Форма глагола | Когда |
|-------|---------------|-------|
| 普通形 (прост.) | 食べる、行った | друзья, семья; эссе |
| 丁寧形 | 食べます、行きました | стандарт, собеседования |
| 尊敬語 (возвыш.) | いらっしゃる、ご覧になる | действия собеседника |
| 謙譲語 (приниж.) | うかがう、参る | свои действия |

### Клише писем

| Японски | Значение | Куда |
|---------|----------|------|
| 拝啓 | уважаемые (открытие) | начало письма |
| 敬具 | с уважением (закрытие) | конец письма |
| ご無沙汰しております | давно не писал(а) | начало (своему адресату) |
| お世話になっております | спасибо за заботу | начало (официально) |
| さて、本日は〜の件で… | Итак, по вопросу о ~ | переход к теме |
| お手数をおかけしますが | извините за хлопоты | просьба |
| よろしくお願いいたします | заранее благодарю | конец |
| 取り急ぎご連絡いたします | спешу сообщить | срочно |

**Шаблон служебной записки (для школы/офиса):**

```
お世話になっております。〇〇です。
本日は、〜についてご連絡いたしました。
〇月〇日までにご返答いただけますと幸いです。
お手数をおかけしますが、よろしくお願いいたします。
```

## Часть 3. Интервью / собеседование (面接)

### Заготовка «самопредставление» (自己紹介, ~30–60 сек)

```
初めまして、〇〇と申します。日本では〜年まで日本語を
勉強していました。現在は〜です。
日本語を勉強し始めたきっかけは〜です。
将来は〜になりたいと思っています。
よろしくお願いいたします。
```

| Блок | Клише |
|------|-------|
| Имя | 〇〇と申します（謙譲: 申す а не 言う） |
| Образование | 〇〇大学で〇〇を専攻しました |
| Работа | 現在は〇〇会社で働いています |
| Мотивация | 日本語に興味を持ったきっかけは〜です |
| План | 将来は〜を目指しています |

### Частые вопросы и ответы-шаблоны

| Вопрос | Шаблон ответа |
|--------|---------------|
| 趣味は何ですか？ | 〜です。特に〜ことを楽しんでいます |
| 長所は何ですか？ | 〜というところです。例えば、〜したことがあります |
| 短所は何ですか？ | 〜という点です。改善するために〜しています |
| なぜ日本で勉強したいですか？ | 日本でしかできない〜があるからです |
| なぜこの会社ですか？ | 御社の〜という点に魅力を感じました |
| 日本語能力はどのくらいですか？ | JLPT N3を取得しています（/ 5年勉強しています） |
| 将来の夢は？ | 〜分野で〜に貢献したいと思っています |

### Три правила интервью

1. **Ответы полными предложениями**, заканчивая 〜です／ます — никогда одной фразой «はい».
2. **Слабые стороны — с планом исправления**（克服するために〜している）.
3. **Вежливость 敬語**: свои действия в 謙譲語 (申す、参る、伺う), действия собеседника — в 尊敬語 (なさる、おっしゃる).

## Часть 4. Клише для заданий JLPT

### 文章の文法 (связный текст)

Связка в пропуске берётся из **предыдущего предложения** на 80%. Ориентиры:

| Маркер в тексте | Какая связка |
|-----------------|-------------|
| 〜だから → пропуск | 理由 объяснение |
| しかし → пропуск | 対比 противопоставление (〜一方で、〜にもかかわらず) |
| そのため → пропуск | 結果 следствие |
| 例えば → пропуск | 具体例 пример |
| つまり → пропуск | 言い換え перефраза |

### 文の組み立て (сборка предложения)

Рабочий порядок: **глагол-сказуемое → его маркеры (を/に/と) → обстоятельства времени и места → соединители (けど、ながら) → ответ в ★**.

Пример рабочего шаблона:
```
毎日 __ __ ★ __ しています。   →  毎日 体にいいから 運動を しています。
```

## Три клише, которые спасают на любой части

1. **Позиция автора** = глагол в конце: 〜と思う／〜と言える / 〜わけではない.
2. **Уступка** = 確かに〜しかし〜 — мгновенно строится в любом эссе.
3. **Вывод** = このように + 〜ではないだろうか — универсальное завершение.
