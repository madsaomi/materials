# Unit 3 — Диалог: 道を尋ねる (Спрашиваем дорогу)

## Ситуация

Алиса — туристка из России, приехавшая в Токио впервые. Она стоит у станции Сибуя, пытаясь найти ближайший кобукони (круглосуточный магазин), чтобы купить карту и перекусить. К ней подходит молодой человек в форме полицейского, замечающий её растерянность.

## Диалог

```
アリス: すみません、ちょっと分からなくて。
警官: 大丈夫ですか。何をお探しですか。
アリス: えっと、最寄りのコンビニはどこですか。
警官: あの、一番近いのはあの角を右に曲がったところです。
アリス: 右ですね。どのくらい歩きますか。
警官: 歩いて2分ぐらいです。コンビニの前に白いビルがあります。
アリス: わかりました！ありがとうございます。
警官: あ、そうだ。駅前の交差点に地図がありますよ。見てみてください。
アリス: ありがとうございます。助かります。
警官: 観光で日本に来たんですか。
アリス: はい、初めてです。東京はとても大きくて驚いています。
警官: そうですね、最初は迷いますよ。楽しんでくださいね！
アリス: ありがとうございます。よろしくお願いします。
```

## Перевод

| Японский | Русский |
|----------|---------|
| すみません、ちょっと分からなくて | Простите, я немного не понимаю |
| 何をお探しですか | Что вы ищете? |
| 最寄りのコンビニ | Ближайший кобукони |
| 一番近いのは | Самый близкий — |
| あの角を右に曲がったところ | Там, где повернуть направо у угла |
| 歩いて2分ぐらい | Пешком около 2 минут |
| 白いビル | Белое здание |
| 駅前の交差点 | Перекрёсток у станции |
| 地図 | карта |
| 見てみてください | Посмотрите, пожалуйста |
| 観光で来たんですか | Вы приехали как турист? |
| 初めてです | Впервые |
| 迷いますよ | Можно заблудиться |
| 楽しんでくださいね | Пожалуйста, наслаждайтесь |

## Культурная заметка

В Японии полицейские (警察官) часто помогают туристам и местным жителям, даже если они не в форме. У многих полицейских участков (交番, koban) на улицах есть сотрудники, которые могут помочь с направлением. Не стесняйтесь обращаться к ним — японцы очень готовы помочь!

## Диалог 2: タクシーで (В такси)

## Ситуация

Алиса устала идти пешком, поэтому вызывает такси, чтобы доехать до отеля у станции. Ей нужно объяснить водителю, куда ехать, и спросить про время и цену.

## Диалог

```
アリス: すみません、駅前のホテルまでお願いします。
運転手: どちらのホテルですか。
アリス: 「サクラホテル」です。駅の隣の白い建物です。
運転手: ああ、分かりました。交通が込んでいなければ、10分ぐらいです。
アリス: どのくらいかかりますか。
運転手: 今は込んでいないので、15分ぐらいですね。
アリス: そうですか。ここで降りてもいいですか。
運転手: すみません、ここから前にお願いします。この道で降ろします。
アリス: はい。ここで降ります。
運転手: ありがとうございます。1,200円です。
アリス: はい、どうぞ。お釣りは結構です。
運転手: どうもありがとうございます。気をつけてください。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 駅前のホテルまでお願いします | К отелю у станции, пожалуйста |
| どちらのホテルですか | К какому именно отелю? |
| 駅の隣の白い建物 | Белое здание рядом со станцией |
| 交通が込んでいなければ | Если не будет пробок |
| どのくらいかかりますか | Сколько времени займёт? |
| ここで降りてもいいですか | Можно выйти здесь? |
| この道で降ろします | Высажу на этой улице |
| お釣りは結構です | Сдачу не нужно |
| 気をつけてください | Осторожнее |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 交通 | こうつう | движение, транспорт |
| 込んでいる | こんでいる | переполнен, пробки |
| 前 | まえ | перед, вперёд |
| 降りる | おりる | выходить |
| 降ろす | おろす | высаживать |
| お釣り | おつり | сдача |
| 結構 | けっこう | не нужно (вежливый отказ) |
| タクシー | — | такси |
| 1,200円 | せんにひゃくえん | 1200 иен |

## Разбор

1. **〜までお願いします** — «до … пожалуйста» — стандартная фраза для такси.
2. **〜てもいいですか** — «можно …?»: ここで降りてもいいですか — «можно выйти здесь?».
3. **〜なければ** — «если не …»: 込んでいなければ — «если не пробки».
4. **お釣りは結構です** — вежливый способ сказать «сдачу оставьте себе».

## Диалог 3: 駅の案内所で (В справочном бюро станции)

## Ситуация

Алиса хочет доехать до Асакусы, но не знает, с какой платформы отправляется поезд, нужна ли пересадка и где купить билет. Она обращается в справочное бюро на станции.

## Диалог

```
アリス: すみません、浅草へ行きたいんですが。
駅員: 浅草ですか。どうぞ、こちらの窓口でお待ちください。…はい、何番線ですか。
アリス: 乗り換えが必要ですか。
駅員: いいえ、一本で行けます。4番線の電車に乗ってください。
アリス: 切符はどこで買えますか。
駅員: あの券売機で買えますよ。浅草まで240円です。
アリス: どのぐらいかかりますか。
駅員: 30分ぐらいです。浅草駅で降りてください。
アリス: 終電は何時ですか。
駅員: 夜の11時45分です。気をつけてください。
アリス: どうもありがとうございました。
駅員: いいえ、ごゆっくりどうぞ。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 浅草へ行きたいんですが | Хотела бы поехать в Асакусу |
| 案内所 | справочное бюро |
| 窓口 | окно (приёма) |
| 何番線ですか | С какой платформы? |
| 乗り換えが必要ですか | Нужна пересадка? |
| 一本で行けます | Можно доехать напрямую |
| 券売機 | билетный автомат |
| 240円 | 240 иен |
| 終電は何時ですか | Когда последний поезд? |
| ごゆっくりどうぞ | Приятной поездки |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 案内所 | あんないじょ | справочное бюро |
| 窓口 | まどぐち | окно, стойка |
| 番線 | ばんせん | номер платформы |
| 必要 | ひつよう | необходимость |
| 一本で行ける | いっぽんでいける | доехать без пересадки |
| 券売機 | けんばいき | билетный автомат |
| 終電 | しゅうでん | последний поезд |
| ごゆっくり | — | не спешите (пожелание) |

## Разбор

1. **〜んですが** — мягкий способ начать просьбу: 浅草へ行きたいんですが — «я хотел(а) бы в Асакусу…».
2. **〜てください** — просьба: 4番線の電車に乗ってください — «садитесь на поезд с 4-й платформы».
3. **〜で行けます** — «можно доехать на …»: 一本で行けます — «можно добраться напрямую».
4. **Suica и другие IC-карты** принимаются в большинстве поездов — прикладывайте карту на входе и на выходе.

## Диалог 4: 道に迷って、地下鉄の駅を探す (Потерялись, ищем станцию метро)

## Ситуация

Алиса вышла не на той остановке и теперь ищет станцию метро. Она расспрашивает прохожего, как пройти.

## Диалог

```
アリス: すみません、地下鉄の駅は、この近くにありますか。
人: ええ、ありますよ。ここから歩いて5分ぐらいです。
アリス: どのように行けばいいですか。
人: この道をまっすぐ行って、二つ目の信号を左に曲がってください。それからまっすぐです。
アリス: 左ですね。分かりました。
人: で、そのまま行くと、右手に銀行があります。その隣の地下階段が駅です。
アリス: 銀行の隣ですね。助かります。
人: ええ。地下鉄の入口に青い看板があるから、すぐ分かりますよ。
アリス: どうもありがとうございます。
人: いいえ、お気をつけて。
```

## Перевод

| Японский | Русский |
|----------|---------|
| この近くにありますか | Здесь есть по близости? |
| 歩いて5分ぐらい | Около 5 минут пешком |
| どのように行けばいいですか | Как лучше пройти? |
| 二つ目の信号 | Второй светофор |
| 左に曲がってください | Поверните налево |
| そのまま行くと | Если идти так дальше |
| 右手 | справа |
| 地下階段 | лестница вниз (к метро) |
| 青い看板 | синяя вывеска |
| すぐ分かります | Сразу поймёте, найдёте |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 信号 | しんごう | светофор |
| 二つ目 | ふたつめ | второй (по счёту) |
| 右手 | みぎて | правая рука, справа |
| 左手 | ひだりて | левая рука, слева |
| 看板 | かんばん | вывеска, табличка |
| ブルー/青い | あおい | синий |
| 口 | くち | вход (в данном случае) |
| すぐ | — | сразу, тотчас |

## Разбор

1. **〜ばいいですか** — «как лучше сделать»: どのように行けばいいですか — «как мне лучше пройти?».
2. **〜たら** — «если …»: そのまま行くと — «если пойдёте дальше» (порядок действий при указании пути).
3. При описании пути по-японски рекомендуют **повторять** ключевую информацию: 左ですね — «влево, да?» — чтобы убедиться, что всё поняли.
