# Unit 7 — Чтение: 私の特技 (Мои таланты)

## Текст

```
私の特技について書きます。

私は水泳ができます。小さい時から
毎週プールに行っていましたから、
今では五十メートルぐらい泳げます。

でも、自転車には乗れません。
大人になってから習おうと思いましたが、
怖くてまだ乗れません。

それから、少しピアノが弾けます。
子供の時に三年間習いました。
難しい曲は弾けませんが、
簡単な歌なら弾けるので、
家族の前で時々演奏します。

日本語はまだ話せませんが、
毎日勉強しています。
来年までには簡単な会話が
できるようになりたいです。

皆さんの特技は何ですか。
ぜひ教えてください。
```

## Вопросы к тексту

1. Каким спортом занимается автор и почему он это умеет?
2. Чему автор так и не научился и почему?
3. Сколько лет автор учился играть на пианино?
4. Какая цель у автора в японском?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 特技 | とくぎ | талант, особое умение |
| プール | — | бассейн |
| メートル | — | метр |
| 大人 | おとな | взрослый |
| 曲 | きょく | мелодия |
| 難しい | むずかしい | сложный |
| 簡単 | かんたん | простой |
| 演奏する | えんそうする | исполнять музыку |
| 目標 | もくひょう | цель |

## Разбор грамматики в тексте

**行っていましたから**
→ ている в прошедшем + ので/から: «потому что ходил регулярно».

**乗ろうと思いました**
→ волitional форма + と思う «думал сделать»: 習おうと思いました = собирался выучить.

**弾けるので**
→ потенциальная форма + ので: «так как могу играть».

**できるようになりたい**
→ ようになる «стать способным» + たい: хочу научиться.

## Письменное задание

Напишите о своих умениях (8–10 предложений):
- Что умеете (可能形 / ことができる)
- Чему не научились и почему (まだ〜ません)
- Чему хотите научиться (〜たい)

# Текст 2 — 田中さんの一日 (День Танаки)

## Текст

```
田中さんは会社員です。毎日七時に
起きることができますが、朝ご飯は
自分で作ることができません。
だから、駅の前のパン屋で買います。

田中さんは英語が読めますが、
話すことは少し苦手です。
でも、会議では簡単な英語で
自分の意見が言えます。

午後はパソコンで資料を作れます。
タイピングが速いので、一分間に
六十文字ぐらい打てます。

夜はジムに行きます。水泳が得意で、
泳げる距離は一千メートルです。
泳ぎ終わってから、お風呂に入って
日本語のニュースを見ます。
ニュースは速すぎて全部は聞き取れませんが、
だんだん分かるようになってきました。
```

## Вопросы к тексту

1. Что умеет и не умеет Танака по утрам?
2. О чём Танака говорит на английском хорошо, а о чём — плохо?
3. Сколько символов в минуту тайпит Танака?
4. Что Танака делает вечером и какова его цель в понимании новостей?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 会社員 | かいしゃいん | офисный работник |
| 起きる | おきる | просыпаться |
| パン屋 | パンや | булочная |
| 会議 | かいぎ | совещание |
| 意見 | いけん | мнение |
| 資料 | しりょう | материалы, документы |
| タイピング | — | набор текста |
| 一分間 | いっぷんかん | одна минута |
| 文字 | もじ | символ, буква |
| ジム | — | спортзал |
| 距離 | きょり | дистанция |
| ニュース | — | новости |
| 速い | はやい | быстрый |
| 聞き取る | ききとる | понимать на слух |
| お風呂 | おふろ | ванна |

## Разбор грамматики в тексте

**作ることができません**
→ словарная форма + ことができません — «не умеет делать» (формальное отрицание умения).

**話すことは少し苦手**
→ наименование действия через こと + は + 苦手: «что касается разговора — слабое место».

**言えます**
→ потенциальная форма от 言う — «может сказать, высказать мнение».

**泳げる距離**
→ потенциальная форма перед существительным: «дистанция, которую может проплыть».

**聞き取れませんが、だんだん分かるようになってきました**
→ отрицание способности + だんだん〜ようになってきました — «постепенно стало получаться».

# Текст 3 — 私の姉 (Моя сестра)

## Текст

```
私の姉は医者です。子どもの頃から
小さい動物が好きで、いつも助けたい
と思っていました。

姉は毎日たくさんの患者を診ることができます。
朝は八時から病院で働きます。
手術もできますが、簡単なものだけです。

姉はスペイン語と英語が話せます。
病院に来る外国人の患者と話せるから、
みんなから頼られています。

でも、姉は車の運転がとても苦手です。
試験は五回も受けて、やっと合格しました。
運転できても、駐車するのはまだ上手にできません。

あと、料理もあまり得意ではありません。
簡単な卵料理なら作れますが、
お寿司は作れません。
だから、週末はよく私の家に来て
一緒にご飯を食べます。

私は姉に英語を教えてもらえます。
姉のおかげで、私も少し英語がわかる
ようになりました。
```

## Вопросы к тексту

1. Чем занимается сестра и почему выбрала эту профессию?
2. На скольких языках говорит сестра и зачем ей это нужно?
3. Что сестра не умеет делать хорошо? Назовите две вещи.
4. Что сестра умеет готовить?
5. Как сестра помогает рассказчику?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 姉 | あね | моя старшая сестра |
| 医者 | いしゃ | врач |
| 患者 | かんじゃ | пациент |
| 診る | みる | принимать, осматривать (пациента) |
| 手術 | しゅじゅつ | операция |
| 外国人の患者 | がいこくじん | иностранный пациент |
| 頼られる | たよられる | быть тем, на кого полагаются |
| 試験 | しけん | экзамен |
| 合格する | ごうかくする | сдать, пройти |
| 駐車する | ちゅうしゃする | парковаться |
| 卵料理 | たまごりょうり | блюдо из яиц |
| おかげで | — | благодаря (кому-то) |
| 教えてもらえる | おしえてもらえる | могу получить урок |

## Разбор грамматики в тексте

**助けたいと思っていました**
→ たい + と思っている: «думал(а), что хочет помочь» — внутреннее намерение.

**診ることができます**
→ словарная форма + ことができる: «может принимать пациентов».

**話せるから、頼られています**
→ потенциальная форма + から (причина) + 頼られる (пассив: «на неё полагаются»).

**運転できても、駐車するのはまだ上手にできません**
→ て-форма услов + も: «даже если умеет водить, парковаться всё равно не получается».

**教えてもらえます**
→ もらえる: «могу попросить, чтобы она меня научила» — получение одолжения.

> **文化— 頼られる人（たよられるひと）:** Человек, на которого полагаются (頼られる), — очень положительная характеристика в японской культуре. Она означает, что вас уважают и доверяют вам.
