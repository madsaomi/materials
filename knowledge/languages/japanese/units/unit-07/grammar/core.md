# Unit 7 — Грамматика: Потенциальная форма и ことができる

## 1. Потенциальная форма (可能形) — «могу, умею»

Как образуется:

| Группа | Правило | Пример |
|--------|---------|--------|
| Группа 1 | -у звук меняется на -эру ряд: く→ける, む→める, つ→てる… | 書く → 書ける, 飲む → 飲める, 待つ → 待てる |
| Группа 2 | る → られる | 食べる → 食べられる, 見る → 見られる |
| Группа 3 | する → できる, 来る(くる) → 来られる(こられる) |

Полная таблица группы 1:

| Глагол | Потенц. | Глагол | Потенц. |
|--------|---------|--------|---------|
| 読む (читать) | 読める | 話す (говорить) | 話せる |
| 走る (бежать) | 走れる | 会う (встречать) | 会える |
| 遊ぶ (играть) | 遊べる | 帰る (возвращаться) | 帰れる |

> 💡 В разговорной речи группу 2 часто сокращают: 食べられる → 食べれる (так называемый ら抜き言葉). Понимать нужно обе формы, использовать в письме — полную.

## 2. Частица が при потенциальной форме

Объект действия ставится в が:
```
日本語が話せます。      — Могу говорить по-японски.
刺身が食べられます。    — Могу есть сашими.
漢字が読めます。        — Умею читать кандзи.
```

## 3. Конструкция ことができる

Формальный аналог потенциальной формы: **словарная форма + ことができる**
```
ギターを弾くことができます。 = ギターが弾けます。
```
Разница только в стиле: ことができる — книжнее/официальное.

## 4. Видеть и слышать: 見える / 見られる

| Форма | Значение | Пример |
|-------|----------|--------|
| 見られる | могу посмотреть (сам решаю) | 今日は映画が見られる。(Сегодня могу посмотреть фильм.) |
| 見える | видно (без усилия) | 富士山が見えます！(Видна гора Фудзи!) |
| 聞ける | могу услышать (есть возможность) | 生きの音楽が聞ける。 |
| 聞こえる | слышно (доносится) | 音楽が聞こえます。(Слышно музыку.) |

## 5. Пока не получается: まだ〜ません

```
まだ運転ができません。     — Я ещё не умею водить.
まだ漢字が読めません。     — Кандзи пока не читаю.
```

## 6. Хотеть научиться: 〜たい

Основа масу-формы + たい:
```
日本語を習いたいです。     — Хочу выучить японский.
泳ぎたいです。            — Хочу поплавать.
```
Частицу можно менять: 日本語が習いたい (акцент на объекте).

## 7. Типичные ошибки

❌ 日本語を話せます。→ ✅ 日本語が話せます。
❌ 泳ぎことができます。→ ✅ 泳ぐことができます。(словарная форма!)
❌ 富士山を見えます。→ ✅ 富士山が見えます。(見える уже значит «видно»)

---

## 8. 〜方（かた）— «способ делать»

Основа масу-формы + 方:
```
この漢字の書き方を教えてください。
Покажите, как пишется этот кандзи.
```
```
寿司の食べ方が分からない。
Не знаю, как есть суши.
```
Полезные: 作り方（つくりかた）способ приготовления · 行き方（いきかた）как добраться · 読み方（よみかた）чтение · 言い方（いいかた）формулировка.

---

## 9. 〜やすい／〜にくい — легко / трудно сделать

Основа масу + やすい／にくい. Образует и-прилагательные!
```
このペンは書きやすいですね。
Эта ручка удобно лежит в руке.
```
```
彼の字は読みにくいです。
Его почерк трудно читать.
```
Спряжение как у い-прил.: 書きやすかった、書きにくくない。

> **Нюанс:** 食べにくい может значить не только физически трудно, но и неловко (говорить): 言いにくいことですが… — «непросто сказать, но...»

---

## 10. 得意／上手／苦手／下手: тонкости

| Слово | Чтение | Кому применяют | Частица |
|-------|--------|----------------|---------|
| 得意 | とくい | чаще о себе | が |
| 上手 | じょうず | о других (вежливо) | が／な |
| 苦手 | にがて | что угодно | が |
| 下手 | へた | осторожно! может обидеть | な |

```
私は料理が得意です。— Я хорошо готовлю (о себе).
田中さんはピアノが上手ですね。— Вы прекрасно играете! (комплимент)
私は数学が苦手です。— Я слаб в математике.
彼は字が下手だ。— У него плохой почерк (грубо при нём!)
```
> **Культура:** о себе японцы говорят 下手（へた）даже когда умеют — это скромность: 私は日本語が下手ですが…

---

## 11. できる: три значения

1) **Уметь:** ピアノができます。
2) **Получиться, быть сделанным:** レポートができました。— Отчёт готов!
3) **Появиться (быть построенным):** 駅の前に新しいカフェができました。— У станции открылось кафе.

```
もう宿題はできましたか。— Домашка уже сделана?
新しく出来たラーメン屋（らーめんや）— новенькая рамэнная
```

---

## 12. 時（とき）с глаголами способностей

Когда умение привязано к времени:
```
子供の時、よく泳げました。
В детстве я мог хорошо плавать.
```
```
十年間練習して、ようやく弾けるようになりました。
После десяти лет практики наконец смог играть.
```
（ようになりました — «пришёл к способности», подробнее в старших юнитах.)

---

## 13. Спорт и хобби: глагольные связки

| Занятие | Правильный глагол | Пример |
|---------|-------------------|--------|
| спорт, игры | する | サッカーをする |
| инструмент (струнный/клавишный) | 弾く（ひく） | ギターを弾く |
| пение | 歌う（うたう） | カラオケで歌う |
| плавание | 泳ぐ（およぐ） | プールで泳ぐ |
| бег | 走る（はしる） | 公園を走る |
| горы | 登る（のぼる） | 富士山に登る |
| море (плавать) | 泳ぐ／行く | 海に行く |

> **Ловушка:** 球技（шар）→ 打つ（うつ）бить, 投げる（なげる）бросать, 蹴る（ける）пинать.

## 14. Мини-дриллы (с ответами)

**A. Переведите потенциальной формой:**

1. Я могу читать этот кандзи.
2. Здесь нельзя фотографировать.
3. Он умеет готовить.

<details><summary>Ответы</summary>

1. この漢字が読めます。
2. ここで写真が撮れません。／撮ってはいけません。
3. 彼は料理が作れます。／料理を作ることができます。
</details>

**B. 見える or 見られる?**

1. 二階から海が＿＿＿。
2. 日曜日なら映画が＿＿＿。

<details><summary>Ответы</summary>

1. 見えます (видно без усилия)
2. 見られます (есть возможность посмотреть)
</details>

**C. Исправьте ошибки:**

1. 私は水泳ができますことが好きです。
2. 彼女は歌うが上手です。

<details><summary>Ответы</summary>

1. 水泳をすることが好きです。（することが + 好き）
2. 彼女は歌うのが上手です。（наименование действия → の）
</details>

## 15. Отрицательная потенциальная форма

Образуется так же, как обычное отрицание, только от потенциального глагола:
- 書ける → 書けない → 書けません
- 食べられる → 食べられない → 食べられません
- できる → できない → できません

**Полная таблица потенциальных форм:**

| Глагол | Потенц. | Отриц. | Никкаку (вежл.) |
|--------|---------|--------|-----------------|
| 書く | 書ける | 書けない | 書けません |
| 読む | 読める | 読めない | 読めません |
| 話す | 話せる | 話せない | 話せません |
| 泳ぐ | 泳げる | 泳げない | 泳げません |
| 買う | 買える | 買えない | 買えません |
| 待つ | 待てる | 待てない | 待てません |
| 会う | 会える | 会えない | 会えません |
| 食べる | 食べられる | 食べられない | 食べられません |
| 見る | 見られる | 見られない | 見られません |
| 来る | 来られる | 来られない | 来られません |
| する | できる | できない | できません |

> 💡 Обратите внимание: потенциальные глаголы относятся ко **второй** группе спряжения, поэтому отрицание всегда заканчивается на **-ない**, даже если исходный глагол был группы 1.

---

## 16. Отрицание できない vs 〜できないことがある

- **できない** — «не умею / не могу» (постоянно):
  ```
  私は泳げない。
  Я не умею плавать.
  ```
- **できないことがある** — «иногда бывает, что не получается»:
  ```
  私は漢字が読めないことがあります。
  У меня бывает, что кандзи не читаются.
  ```

`できる` может использоваться для разрешения/возможности:
```
あした来られますか。
Сможете прийти завтра? (возможность/разрешение)
```

---

## 17. 〜られる vs 〜れる для разрешения почтительности

Когда хотите спросить разрешение вежливо, используйте потенциальную форму как форму возможности:
```
ここで写真を撮れますか。
Можно здесь сфотографировать?
```
```
この席に座れますか。
Можно сесть на это место?
```

Общее правило: 可能形 в вопросе = «возможно ли?» = мягкое разрешение. Это ключевой бытовой приём.

---

## 18. Порядок: できるようになる / できるようになった

| Форма | Значение | Пример |
|-------|----------|--------|
| できるようになりたい | хочу научиться | 泳げるようになりたい |
| できるようになる | научусь (стану способным) | 毎日練習すればできるようになります |
| できるようになった | научился | やっと日本語が話せるようになりました |
| できるようになっている | уже умею (состояние) | もう漢字が読めるようになっています |

**用 ようになる vs ようになる с なる:**
```
子供の時、泳げなかったけど、今は泳げるようになりました。
В детстве не умел плавать, но теперь научился.
```

---

## 19. 〜ながら: одновременные умения

Основа масу + ながら — «одновременно делая»:
```
ギターを弾きながら歌えます。
Могу петь, одновременно играя на гитаре.
```
```
歩きながら話せます。
Могу говорить на ходу.
```

> 💡 Это не путать с 見ながら vs 見るながら — всегда основа масу-формы: 弾きながら（はじきながら）, 歩きながら（あるきながら）.

---

## 20. Сравнение умений: より・のほうが

```
私はピアノよりギターのほうが上手です。
Гитара у меня получается лучше, чем пианино.
```
```
彼女は日本語より英語のほうが得意です。
Она владеет английским лучше, чем японским.
```

Используется с 上手／得意／苦手 для сравнения уровня навыков.

---

## 21. Возможность без вашего участия: 〜ことがある（не часто）

```
このレストランは休みのことがあります。
Этот ресторан иногда не работает.
```
```
時々、電車が遅れることがあります。
Поезда иногда опаздывают.
```
> Форма ことがある с глаголом = «бывает, что...». Отличать от ことができる («умею»). Ударение: こと**が**ある vs ことが**できる**.

## 22. Практика: мини-диалоги с 可能形

**A. 空き時間に:**

```
アリス：あした、映画を見に行けますか。
田中：ごめん、あしたは仕事があるから行けない。
```
**Перевод:** — Можешь завтра пойти в кино? — Извини, завтра работа, не могу.

> Форма 行ける（いける）— потенциальная от 行く. 行けない — «не могу пойти» (по причине занятости).

**B. В ресторане:**

```
店員：辛いものは大丈夫ですか。
客：すみません、辛いものが食べられません。
```
> 食べられません — «не могу есть острое» (аллергия/маленький порог). 辛い = からい — острый (не 辛い = трудно!).

## 23. Расширенные мини-дриллы

**A. Образуйте отрицательную потенциальную форму:**

1. 話す → ＿＿＿
2. 待つ → ＿＿＿
3. 見る → ＿＿＿

<details><summary>Ответы</summary>

1. 話せない
2. 待てない
3. 見られない
</details>

**B. Выберите: 見える / 見られる / 聞こえる / 聞ける**

1. このカフェからは海が＿＿＿。
2. 図書館なら静かに音楽が＿＿＿。
3. 隣の部屋から声が＿＿＿。
4. コンサートで生演奏が＿＿＿。

<details><summary>Ответы</summary>

1. 見える (видно отсюда)
2. 聞ける (есть возможность слушать)
3. 聞こえる (слышно через стенку)
4. 聞ける (можно услышать живую музыку)
</details>

**C. Переведите:**

1. Я научился готовить суши.
2. Бывает, что утром не могу проснуться.
3. Могу петь и одновременно играть на гитаре.

<details><summary>Ответы</summary>

1. お寿司が作れるようになりました。
2. 朝、起きられないことがあります。
3. ギターを弾きながら歌えます。
</details>
