# Unit 7 — Тест

## Часть 1: Образуйте потенциальную форму

1. 泳ぐ → ＿＿＿＿
2. 飲む → ＿＿＿＿
3. 起きる → ＿＿＿＿
4. 勉強する → ＿＿＿＿

## Часть 2: Выберите правильный вариант

**1. 私は刺身が食べ＿＿＿。**

- а) る
- б) られます
- в) たいです

**2. 富士山が＿＿＿！**

- а) 見えます
- б) 見られます
- в) 見ます

**3. ピアノを弾く＿＿＿できます。**

- а) の
- б) こと
- в) が

## Часть 3: Правда или ложь?

「田中さんは泳げますが、ピアノが弾けません。」

1. 田中さんは水泳ができる。（　）
2. 田中さんは楽器が上手だ。（　）
3. 田中さんは自転車に乗れない。（　）

## Часть 7: Соедините синонимы

1. 話せます a) することができます
2. 作れます b) 話すことができます
3. 食べられます c) 作ることができます
4. 泳げます d) 食べることができます
5. できます e) 泳ぐことができます

## Часть 8: Выберите 見える / 見られる / 聞こえる / 聞ける

3. 隣の部屋から話し声が（a. 聞こえる b. 聞ける）。

## Часть 13: Выберите правильный ответ

**1. 「料理ができますか」に対する正しい答えは？**

- а) はい、できます。
- б) はい、します。
- в) はい、なります。

**2. 「まだ運転ができません」の意味は？**

- а) Уже умею водить.
- б) Пока не умею водить.
- в) Хочу научиться водить.

**3. できるようになりましたの意味は？**

- а) умел раньше
- б) научился (стал мочь)
- в) хочу научиться

**4. 見えるの意味は？**

- а) могу посмотреть (есть возможность)
- б) видно (без усилия)
- в) смотрю

## Часть 14: Заполните пропуски в диалоге


## Часть 15: Краткий ответ (по-русски)

1. Чем отличается 見える от 見られる?
2. В каком случае используют ことができる вместо 可能形?
3. Что означает まだまだです и когда его говорят?
4. Почему о себе японцы говорят 下手, даже когда умеют?

## Итоговые ответы

<summary>Нажмите, чтобы увидеть ответы</summary>

**Часть 5:** 1-話せない, 2-待てない, 3-買えない, 4-見られない

**Часть 6:** 1-が, 2-が, 3-に (乗る), 4-を (見に行く), 5-で (место действия)

**Часть 7:** 1-b, 2-c, 3-d, 4-e, 5-a

**Часть 8:** 1-見える, 2-聞ける, 3-聞こえる, 4-見られる

**Часть 9:**

1. 私は日本語が話せません。
2. 私は料理を作ることができます。
3. 日本語が少し話せるようになりました。

**Часть 10:** 1-неверно (富士山**が**見えます), 2-неверно (泳**ぐ**ことができます), 3-неверно (日本語**が**話せます), 4-верно

**Часть 11:**

1. Пока не умею читать кандзи.
2. Если тренироваться каждый день, обязательно научишься плавать.
3. Он говорит на трёх языках.
4. В этом ресторане можно оплатить картой?

**Часть 12:** 1-b, 2-a, 3-c, 4-d, 5-e

**Часть 13:** 1-а, 2-б, 3-б, 4-б

**Часть 14:** 1-弾けます (A), 2-弾ける (B), 3-です (C — 三年です = три года), 4-下手 (D)

**Часть 15:**

1. 見える — что-то видно само собой (не прилагая усилий); 見られる — возможность посмотреть (по своему выбору).
2. ことができる используют в более официальной / письменной речи, а 可能形 — в разговорной.
3. まだまだです — «мне ещё далеко»; типичный скромный ответ на комплимент в японской культуре.
4. Согласно японской культуре скромности, хвастаться не принято, поэтому даже умелые люди принижают свои способности.
