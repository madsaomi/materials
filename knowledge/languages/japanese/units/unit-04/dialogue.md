# Unit 4 — Диалог: 趣味と誘い (Хобби и приглашения)

## Ситуация

Сузуки и Кимура — однокурсники, которые познакомились на занятиях по японскому языку. После пары они сидят в кафе на кампусе и разговаривают о своих увлечениях. Сузуки предлагает Кимуре сходить вместе на фильм в выходные.

## Диалог

```
鈴木: 木村さん、最近何か面白いことしてる？
木村: あまりそういうことないなあ。勉強ばかりだよ。
鈴木: そうなんだ。趣味は何？
木村: 読書と映画鑑賞だなあ。あなたは？
鈴木: 私は料理と写真撮りが好き。暇なときは新しいレシピに挑戦するの。
木村: 料理は上手なの？
鈴木: ほんの少しだけど、毎週新しいものを作ってるの。
木村: それはすごい！いつか私も教えてもらえる？
鈴木: もちろん！今週末一緒に映画に行かない？新しいSF映画が面白そうだよ。
木村: いいね。何の映画？
鈴木: 「宇宙の果て」っていうやつ。監督は前回の「海の底」もやった人。
木村: ああ、それ！トレイラーは見たことある。土曜日なら行けるかな。
鈴木: 土曜日の午後はどう？3時から始まるよ。
木村: ちょっと用事がある日曜日はダメなんだけど、土曜日なら大丈夫。
鈴木: じゃあ、土曜日の3時に駅の東口で待ち合わせは？
木村: いいね。駅の東口はわかりやすいから。
鈴木: 映画の後、近くにラーメン屋があるから、食べに行かない？
木村: おいしい！それは楽しみだなあ。
鈴木: そうだね！じゃあ、土曜日ね。
木村: よし、土曜日！
```

## Культурная заметка

В Японии приглашение на фильм — это распространённый способ провести время с друзьями. Важно заранее оговорить место встречи (通常、駅の出口で待ち合わせ). Восточный выход (東口) и западный выход (西口) — стандартные ориентиры на станциях. После фильма многие любят вместе поесть рамэн — это считается завершением приятного вечера.

## Диалог 2: ケーキ作りのお誘い (Приглашение испечь торт)

### Ситуация

Аяка хочет испечь торт на день рождения мамы и приглашает подругу Мэй помочь. Разговор на «ты», короткие и неформальные фразы — так японцы общаются среди близких друзей.

### Диалог

```
あやか: めいちゃん、今週末時間ある？
めい:  うん、あるよ。何かやることあるの？
あやか: 実は、お母さんの誕生日にケーキを作りたいの。
めい:  いいね！私も手伝うよ。
あやか: ほんと？助かる！材料を買いに行くんだけど、一緒に行く？
めい:  いいよ。いつ行く？
あやか: 土曜日の午前中はどう？スーパーが空いてると思う。
めい:  土曜の午前なら大丈夫。何のケーキにするの？
あやか: いちごのショートケーキを作ってみたいの。
めい:  おいしそう！作るのが楽しみだね。
あやか: うん、楽しみ！じゃあ、土曜日にね。
めい:  うん！楽しみにしてる。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 今週末時間ある？ | У тебя на выходных есть время? |
| 何かやることあるの？ | Что-нибудь нужно сделать? |
| 実は | Вообще-то |
| お母さんの誕生日 | День рождения мамы |
| 手伝うよ | Я помогу |
| 助かる！ | Спасибо, выручишь! (букв. «помогает») |
| 材料を買いに行くんだけど | Пойду купить продукты, так вот… |
| スーパーが空いてる | В супермаркете свободно |
| いちごのショートケーキ | Клубничный шорткейк |
| 作ってみたい | Хочу попробовать сделать |
| 作るのが楽しみだね | Как же приятно будет готовить |
| 楽しみにしてる | Буду ждать (с нетерпением) |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 誕生日 | たんじょうび | день рождения |
| 材料 | ざいりょう | ингредиенты |
| スーパー | — | супермаркет |
| ショートケーキ | — | шорткейк |
| いちご | — | клубника |
| 手伝う | てつだう | помогать |
| 助かる | たすかる | выручить, (букв.) это спасает |
| 空いている | あいている | свободный, пустой |

### Разбор грамматики

- 作りたい — 〜たい: хочу сделать (желание).
- 作ってみたい — 〜てみる + たい: хочу **попробовать** сделать.
- 行くんだけど — んだ (объяснение) + けど (мягкая пауза) — «хочу, понимаешь…».
- 空いてる — разговорный вариант 空いている.

## Диалог 3: 花見のお誘い (Приглашение на ханами)

### Ситуация

Хирото и Кэн — друзья. Хирото зовёт Кэна на любование сакурой в парк Уэно и обсуждает время, погоду и еду.

### Диалог

```
ひろと: けん、来週の土曜日に花見に行かない？
けん:  花見？いいね！どこで？
ひろと: 上野公園はどう？桜がきれいだと思うよ。
けん:  去年も行ったけど、人が多かったなあ。
ひろと: じゃあ、朝早く行こう。八時に行けば、席が取れると思う。
けん:  天気は大丈夫かな。
ひろと: 天気予報を見たら、晴れるそうだよ。
けん:  じゃあ、決まり！何を持って行こうか。
ひろと: お弁当は俺が作るよ。お茶とお菓子はけんお願い。
けん:  分かった。楽しみだね。
ひろと: 風が強くなかったら、最高だよ。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 花見に行かない？ | Не сходим ли на ханами? |
| 上野公園はどう？ | Что насчёт парка Уэно? |
| 桜がきれいだと思う | Думаю, сакура будет красивой |
| 人が多かったなあ | Людей было много, да… |
| 朝早く行こう | Давай пойдём рано утром |
| 八時に行けば、席が取れる | Если пойти в восемь, места достанутся |
| 天気は大丈夫かな | Интересно, погода будет нормальной? |
| 天気予報を見たら、晴れるそうだ | Посмотрел прогноз — говорят, будет ясно |
| 決まり！ | Решено! |
| 何を持って行こうか | Что возьмём с собой? |
| 俺が作るよ | Приготовлю я (по-мужски) |
| お茶とお菓子はけんお願い | Чай и сладости — на тебе, Кэн |
| 風が強くなかったら、最高だよ | Если ветра не будет, вообще замечательно |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 花見 | はなみ | ханами, любование сакурой |
| 桜 | さくら | сакура |
| 上野公園 | うえのこうえん | парк Уэно |
| 席が取れる | せきがとれる | достанутся места |
| 天気予報 | てんきよほう | прогноз погоды |
| 晴れる | はれる | проясниться (о небе) |
| お弁当 | おべんとう | бэнто |
| 最高 | さいこう | высший класс, отлично |

### Разбор грамматики

- 行かない？ — разговорное сокращение 行かないか: приглашение среди друзей.
- 行けば — форма ば: условие «если…, то…».
- 見たら — たら: «после того как посмотрел…».
- 晴れるそうだ — そうだ (по информации): «говорят, будет ясно».
- 風が強くなかったら — отрицание い-прилагательного + たら: «если ветер не будет сильным».

## Диалог 4: ハイキングの誘いと断り (Приглашение в поход и вежливый отказ)

### Ситуация

Юки приглашает Сатоси в поход, но их графики не совпадают — Сатоси вежливо отказывается (с объяснением причины), и они переносят встречу на следующую неделю.

### Диалог

```
ゆき:  さとしさん、日曜日にハイキングに行きませんか。
さとし: いいですね。行きたいですけど…
ゆき:  どうかしましたか。
さとし: 実は日曜日は用事があるんです。土曜日なら大丈夫です。
ゆき:  土曜日はちょっと…仕事があるんです。
さとし: そうですか。じゃあ、来週の土曜日はどうですか。
ゆき:  いいですね。来週の土曜日にしましょう。
さとし: どこに行きましょうか。
ゆき:  高尾山はどうですか。日帰りで行けますよ。
さとし: いいですね。一度行ってみたかったんです。
ゆき:  じゃあ、来週の土曜日の朝八時に駅で待ち合わせて、電車で行きましょう。
さとし: 分かりました。楽しみにしています。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 日曜日にハイキングに行きませんか | Не сходим ли в поход в воскресенье? |
| 行きたいですけど… | Хотел бы, но… |
| どうかしましたか | Случилось что-то? |
| 実は日曜日は用事があるんです | Понимаете, в воскресенье у меня дела |
| 土曜日なら大丈夫です | А в субботу — можно |
| ちょっと…仕事があるんです | Не выйдет… работа (причина) |
| 来週の土曜日にしましょう | Давайте в следующую субботу |
| どこに行きましょうか | Куда пойдём? |
| 高尾山はどうですか | Что насчёт горы Такао? |
| 日帰りで行けますよ | Можно съездить на один день |
| 一度行ってみたかったんです | Я как раз давно хотел попробовать |
| 待ち合わせて | встретившись (те-форма) |
| 電車で行きましょう | Поедем на электричке |
| 楽しみにしています | Буду ждать с удовольствием |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ハイキング | — | пеший поход |
| 用事がある | ようじがある | есть дела |
| 仕事 | しごと | работа |
| 高尾山 | たかおさん | гора Такао |
| 日帰り | ひがえり | поездка на один день |
| 電車 | でんしゃ | электричка, поезд |

| 楽しみにしている | たのしみにしている | ждать с радостью |

### Разбор грамматики

- 行けます — потенциальная форма: «могу пойти».
- 行ってみたかった — 〜てみる + たかった: «хотел когда-то попробовать».
- 用事があるんです — んです: объяснение причины отказа.
- 〜ましょう (しましょう) — давайте сделаем (решение вместе).

## Культурная заметка 2

Отказ в Японии почти никогда не бывает прямым. Вместо «нет» говорят すみません、ちょっと… или объясняют причину с んです и обязательно предлагают また今度 («в следующий раз»). Перенос, а не отмена — стандарт вежливости: собеседнику не «закрывают» приглашение, а сдвигают его.
