# Unit 1 — Грамматика

## 1. AはBです (А — это Б)

```
私は学生です。     — Я студент.
田中さんは先生です。 — Господин Танака — учитель.
これは本です。      — Это книга.
```

**Структура:** [Тема] は [Описание] です

**Отрицание:** では ありません / じゃ ありません

```
学生ではありません。 — Я не студент.
先生じゃありません。 — Я не учитель.
```

## 2. AはBですか (Вопрос)

```
学生ですか。        — Вы студент?
田中さんですか。    — Вы господин Танака?
これは本ですか。    — Это книга?
```

**Ответы:**

```
はい、そうです。     — Да, это так.
いいえ、違います。  — Нет, не так.
いいえ、そうじゃありません。 — Нет, это не так.
```

## 3. Указательные местоимения

| Слово | Значение | Пример |
|-------|----------|--------|
| これ | это (близко) | これは本です |
| それ | то (ближе к слуш.) | それはペンです |
| あれ | вон то (далеко) | あれは山です |
| この[N] | этот N | この本は面白い |
| その[N] | тот N | その人を知っています |
| あの[N] | вон тот N | あの建物は駅です |

## 4. の (притяжательная частица)

```
私の本      — моя книга
田中さんの電話 — телефон г-на Танаки
大学の先生  — учитель университета
```

## 5. も (тоже)

```
私も学生です。    — Я тоже студент.
これも本です。    — Это тоже книга.
```

## 7. Глаголы: ます-форма (вежливая)

| Группа | Слов. форма | ます-форма |
|--------|-------------|-----------|
| I | 行く (いく) | 行きます |
| I | 会う (あう) | 会います |
| I | 書く (かく) | 書きます |
| II | 食べる (たべる) | 食べます |
| II | 見る (みる) | 見ます |
| III | する | します |
| III | 来る (くる) | 来ます (きます) |

## 8. 〜ています (действие в процессе/состояние)

```
勉強しています。    — Учусь (в процессе).
住んでいます。      — Живу (состояние).
知っています。      — Знаю.
```

## 9. です vs だ (вежливая и простая форма)

**です** — вежливая форма (используется с незнакомыми, при формальной речи):

```
私は学生です。 — Я студент (вежливо).
```

**だ** — простая/разговорная форма (с друзьями, в письменной речи):

```
私は学生だ。 — Я студент (разговорное).
```

**Негативная форма:**

```
学生ではない。 / 学生じゃない。 — Я не студент.
```

## 10. を (частица объекта)

```
本を読みます。 — Читаю книгу。
日本語を勉強します。 — Учу японский。
```

## 11. に (направление, время, место пребывания)

**Направление:**

```
学校に行きます。 — Иду в школу。
東京に行きます。 — Еду в Токио。
```

**Время:**

```
9時に起きます。 — Встаю в 9 часов。
毎朝7時に起きます。 — Каждое утро встаю в 7。
```

**Место пребывания (с いる):**

```
日本に住んでいます。 — Живу в Японии。
```

## 12. で (место действия, инструмент)

**Место действия:**

```
図書館で勉強します。 — Учусь в библиотеке。
学校で友達と話します。 — Разговариваю с другом в школе。
```

**Инструмент (с глаголами действия):**

```
車で行きます。 — Еду на машине。
電車で行きます。 — Еду на электричке。
```

## 13. 〜ている (текущее действие / результат)

**Действие в процессе:**

```
本を読んでいます。 — Читаю книгу (сейчас).
```

**Результат (состояние):**

```
日本に住んでいます。 — Живу в Японии (результат: живу там).
```

**Отрицание:**

```
勉強していません。 — Не учусь (сейчас).
```

## 14. が (субъект и предпочтения)

**が** отмечает грамматического субъекта, особенно с глаголами чувств и наличия:

```
猫が好きです。      — Люблю кошек.
日本語が分かります。 — Понимаю японский.
水が欲しいです。    — Хочу воды.
雨が降っています。  — Идёт дождь.
```

**が vs は:** は вводит тему, が выделяет субъект/факт:

```
私は学生です。    — Я студент (про себя, тема).
私が学生です。    — Именно я студент (кто именно?).
```

## 15. と (с кем-то, и)

**と** — «с» (совместность) и соединительная частица «и»:

```
友達と話します。    — Разговариваю с другом.
田中さんと映画を見ます。 — Смотрю фильм с г-ном Танакой.
本とノートを買います。 — Покупаю книгу и тетрадь.
```

## 16. Отрицательная форма глаголов (〜ません)

| Вид | Форма | Пример |
|-----|-------|--------|
| Утверждение | 〜ます | 食べます |
| Отрицание | 〜ません | 食べません |
| Прошедшее | 〜ました | 食べました |
| Отриц. прош. | 〜ませんでした | 食べませんでした |

```
お茶を飲みません。   — Не пью чай.
昨日は勉強しませんでした。 — Вчера не занимался.
```

## 17. Прошедшее время: でした / でしたか

**です → でした** (вежливое прошедшее для именных + な-прил.):

```
昨日は日曜日でした。 — Вчера было воскресенье.
田中さんは医者でした。 — Г-н Танака был врачом.
昨日はひまでした。   — Вчера было свободное время.
```

**Вопрос в прошедшем:**

```
きのうは暇でしたか。 — Вчера было свободное время?
いいえ、忙しかったです。 — Нет, я был занят.
```

## 18. い-прилагательные: утверждение/отрицание

い-прилагательные спрягаются (отбрасываем い):

| Форма | Пример |
|-------|--------|
| Утверждение | 大きいです |
| Отрицание | 大きくないです |
| Прошедшее | 大きかったです |
| Отриц. прош. | 大きくなかったです |

```
この本は面白いです。   — Эта книга интересная.
この本は面白くないです。 — Эта книга не интересная.
```

## 19. とても / あまり (очень / не очень)

```
とてもおいしいです。    — Очень вкусно.
あまり高くないです。   — Не слишком дорого (досл. «не очень дорого»).
あまり好きじゃありません。 — Не очень люблю.
```

注意: あまり используется только с отрицанием.

## 20. 〜から (потому что) — в конце предложения

```
時間がないから、行きません。 — Потому что нет времени, не пойду.
好きだから、食べます。      — Люблю, поэтому ем.
```

から ставится после причины; сказуемое — в простой форме перед から.

## 21. どうぞ / ください — просьба и предложение

```
どうぞ。            — Пожалуйста (вот, берите).
水をください。       — Дайте воды, пожалуйста.
ラーメンを一つください。 — Дайте рамэн, один.
もう一度言ってください。 — Скажите ещё раз, пожалуйста.
```

## 22. 〜ますか — вежливый вопрос с глаголом

```
日本語を話しますか。 — Вы говорите по-японски?
コーヒーを飲みますか。 — Выпьете кофе?
今日は何をしますか。 — Что делаете сегодня?
```

Ответ: はい、話します。/ いいえ、話しません。
