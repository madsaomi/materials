# Unit 2 — Диалог: 一日の生活 (Распорядок дня)

## Ситуация

Кимура и Ямада — коллеги по офису. Они встретились у входа в здание утром, ещё до начала рабочего дня. Кимура замечает, что Ямада выглядит бодрым, и задаёт ему вопросы о его утреннем распорядке. Они планируют пообедать вместе после работы.

## Диалог

```
木村: おはようございます、山田さん。今日は元気ですか。
山田: おはようございます、木村さん。はい、ちょうどジョギングから帰ったところです。
木村: そうですか！早いですね。毎日ジョギングしますか。
山田: はい、週に3回はします。体のためだと思っています。
木村: なるほど。朝ごはんは何を食べましたか。
山田: 今朝はトーストと卵とコーヒーだけでした。急いでいたんです。
木村: そうですか。私も朝は時間がありません。コンビニで弁当を買ってきます。
山田: それも手ですか。コンビニのデリヘルは結構おいしいですよ。
木村: そうですね。今度一緒に昼休みにコンビニに行きませんか。
山田: いいですね！何時に会いましょう。
木村: 12時半に駅前で待ち合わせはどうですか。
山田: いいですね。じゃあ、12時半に駅前で。
木村: では、今日も一日頑張りましょう。
山田: はい、頑張りましょう！
```

## Перевод

| Японский | Русский |
|----------|---------|
| おはようございます | Доброе утро (вежл.) |
| 元気ですか | Как ваши дела? |
| ジョギングから帰ったところです | Только что вернулся с пробежки |
| 毎週3回はします | Делаю 3 раза в неделю |
| 体のためだと思っています | Думаю, это для тела |
| トースト | Тост |
| 卵 | Яйцо |
| 急いでいたんです | Спешил |
| コンビニで弁当を買ってきます | Куплю бенто в кобукони |
| デリヘル | Доставка еды (кобукони) |
| 昼休みに | во время обеденного перерыва |
| 待ち合わせ | Встреча (заранее оговоренная) |
| 駅前 | Перед станцией |
| 一日頑張りましょう | Давайте приложим усилия сегодня |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 元気 | げんき | бодрый, в порядке |
| ジョギング | — | пробежка |
| 毎週 | まいしゅう | каждую неделю |
| 体 | からだ | тело |
| トースト | — | тост |
| コンビニ | — | круглосуточный магазин |

## Диалог 2: 昼休みにコンビニへ (В обеденный перерыв — в конвини)

## Ситуация

Ровно в 12:30 Кимура и Ямада встречаются у станции и идут в конвини за обедом. Кимура забыл кошелёк, зато нашёл на витрине новый сэндвич.

## Диалог

```
木村: 山田さん、12時半ですね。駅前のコンビニに行きましょう。
山田: はい、お腹が空きましたね。何を買うつもりですか。
木村: 私はサンドイッチとお茶にします。山田さんは？
山田: 味噌汁と弁当にします。あ、水も買いたいです。
木村: 合わせてレジに向かいましょう。
店員: いらっしゃいませ。商品はこれでよろしいですか。
木村: はい、お願いします。
店員: 合わせて625円になります。
山田: 僕が払いますよ。木村さん、財布を忘れたでしょう。
木村: あ、すみません！本当にありがとうございます。今度は私が払います。
山田: いいえ、気にしないでください。どこで食べましょうか。
木村: 銀行の前のベンチで食べませんか。
山田: いいですね。日向は気持ちがいいですよ。
```

## Перевод

| Японский | Русский |
|----------|---------|
| お腹が空きましたね | Я проголодался |
| 何を買うつもりですか | Что собираетесь купить? |
| サンドイッチとお茶にします | Возьму сэндвич и чай |
| 味噌汁と弁当にします | Возьму мисо-суп и бенто |
| 合わせてレジに向かいましょう | Пойдём вместе к кассе |
| いらっしゃいませ | Добро пожаловать |
| 商品はこれでよろしいですか | Всё это будет? |
| 625円になります | С вас 625 иен |
| 財布を忘れたでしょう | Вы ведь забыли кошелёк |
| 気にしないでください | Не переживайте |
| 銀行の前のベンチ | Скамейка перед банком |
| 日向は気持ちがいいですよ | На солнышке так приятно |

## Разбор

1. **〜にします** — «беру/выбираю» в ресторане и магазине: サンドイッチ**にします** = «я возьму сэндвич».
2. **〜でしょう** — здесь не вопрос, а догадка с утверждением: 忘れた**でしょう** = «наверняка забыли».
3. **〜合わせて** — «итого, в сумме»: 合わせて625円になります = «с вас всего 625 иен».
4. **ベンチで食べませんか** — приглашение через 〜ませんか (мягкое предложение). Ответом может быть いいですね.
5. **お腹が空きました** — «проголодался»; дословно «желудок опустел».

## Диалог 3: 家族の朝 (Семейное утро)

## Ситуация

Воскресное утро дома у семьи Танака. Мама готовит завтрак, а дочь Мисаки ещё сонная и собирается в школу — сегодня у неё дополнительные занятия.

## Диалог

```
みさき: お母さん、おはよう。今日の朝ごはんは何？
母: おはよう、みさき。卵焼きとウィンナーよ。ご飯はもう炊いてあるわ。
みさき: やったー！でも、まだ眠いなあ。
母: 昨日は何時に寝たの？遅くまで起きていたでしょう。
みさき: 宿題がたくさんあって、11時半まで勉強していたんだ。
母: そう。じゃあ、今日は早く寝なさいね。何時に家を出るの？
みさき: 8時ごろ出るつもり。バスで学校に行くから。
母: 今日は雨だから、ちょっと早めに出たほうがいいわよ。
みさき: わかった。お母さん、布団は僕がしまっておくね。
母: ありがとう。じゃあ、みんなで食べましょう。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 卵焼き | Омлет по-японски (тамагояки) |
| ウィンナー | Сосиска |
| ご飯はもう炊いてあるわ | Рис уже сварила |
| やったー | Ура! |
| まだ眠いなあ | Всё ещё хочется спать |
| 何時に寝たの？ | Во сколько лёг спать? |
| 11時半まで勉強していた | Занимался до 11:30 |
| 今日は早く寝なさいね | Сегодня ложись пораньше |
| 何時に家を出るの？ | Во сколько выходишь из дома? |
| バスで学校に行くから | Потому что еду в школу автобусом |
| 早めに出たほうがいいわよ | Лучше выйти чуть пораньше |
| 布団は僕がしまっておくね | Футон соберу сам |

## Разбор

1. **〜てある** — указывает на результат, «уже сделано» (кем-то заранее): ご飯は炊い**てある** = «рис уже сварен».
2. **〜ておく** — «сделать заранее / приготовить на будущее»: 布団をしまっ**ておく** = «уберу футон (заранее)».
3. **〜ほうがいい** — совет «лучше сделать X»: 早めに出た**ほうがいい** = «лучше выйти пораньше».
4. Женский стиль: まだよ/〜わ/〜なさい — мама говорит мягче и с わ; замечаем разницу с 〜てください из диалога 1.
5. **〜なさい** — повелительное, но тёплое (к детям): 寝**なさい** = «ложись спать».

## Диалог 4: 週末の予定 (Планы на выходные)

## Ситуация

В пятницу вечером Кимура и Ямада после работы обсуждают планы на выходные. Хочется развеяться: может, кино, а может — новый итальянский ресторан у станции.

## Диалог

```
山田: 木村さん、週末は何か予定がありますか。
木村: 土曜日の午前中はジムに行くつもりですが、午後は何もありません。
山田: じゃあ、一緒に映画を見に行きませんか。新作のアクション映画を見たいんです。
木村: いいですね。何時の回にしましょうか。
山田: 2時の回はどうですか。開演の10分前に駅で会いましょう。
木村: わかりました。映画の後はどうしますか。
山田: 駅前に新しいイタリアンレストランができたそうです。行ってみませんか。
木村: いいですよ。楽しみですね！
山田: じゃあ、土曜日の1時50分に駅の改札前で待ち合わせましょう。
木村: 了解です。では、また明日！
```

## Перевод

| Японский | Русский |
|----------|---------|
| 週末は何か予定がありますか | Есть ли планы на выходные? |
| 午前中はジムに行くつもりです | В первой половине дня собираюсь в спортзал |
| 午後は何もありません | Во второй половине — ничего |
| 一緒に映画を見に行きませんか | Не пойти ли нам вместе в кино? |
| 何時の回にしましょうか | На какой сеанс пойдём? |
| 開演の10分前 | За 10 минут до начала |
| 映画の後はどうしますか | Что делаем после кино? |
| 行ってみませんか | Не попробуем ли сходить? |
| 楽しみですね | Как я рад! (с нетерпением жду) |
| 駅の改札前 | Перед турникетами станции |
| また明日 | До завтра |

## Разбор

1. **〜そうです** (слух) — «говорят, что〜»: できた**そうです** = «говорят, открылся».
2. **〜てみませんか** — «не попробовать ли〜?»: от 見る — «посмотреть, как получится». 行ってみる = «сходить (попробовать)».
3. **何時の回** — «сеанс/заход»: 回 = раз, для мероприятий в расписании.
4. **楽しみです** — устойчивое выражение радостного ожидания: «жду с нетерпением, мне радостно».
5. **〜ましょう** — в вопросе 何時にしましょうか = «давай решим, во сколько». Приглашение: 行きませんか.
