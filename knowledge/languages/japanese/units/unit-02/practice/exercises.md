## Упражнение 7: Частицы времени и направления (продвинутый набор)

2. 来週、京都___旅行します。

## Упражнение 8: Расставьте слова по порядку

Составьте правильные предложения (аккуратно с частицами):

1. 起きます / 6時に / 私は / 毎朝
2. 食べます / レストランで / 晩ごはんを / たまに
3. 勉強しています / 大学で / 私の弟は / 日本語を
4. 帰ります / いつも / 電車で / 10時ごろ / 家に
5. まいります… (нет) → 飲みます / コーヒーを / 朝 / たいてい

**Ответы:**

5. 私はたいてい朝コーヒーを飲みます。

## Упражнение 12: Мини-текст «佐藤さんの一日»

Прочитайте и ответьте на вопросы:

```
佐藤さんは午前7時に起きます。
朝ごはんを食べてから、8時に家を出ます。
会社にはいつも電車で行きます。
午後1時ごろ、会社の食堂で昼ごはんを食べます。
6時に仕事が終わります。疲れたから、急いで家に帰ります。
夜は映画を見たり、本を読んだりします。
```

1. 佐藤さんは何時に起きますか。
2. 朝ごはんを食べてから、何をしますか。
3. 何で会社に行きますか。
4. 昼ごはんはどこで食べますか。
5. なぜ急いで家に帰りますか。

**Ответы:**
1. 午前7時に起きます。
2. 8時に家を出ます。
3. 電車で会社に行きます。
4. 会社の食堂で食べます。
5. 疲れたからです。

## Упражнение 13: Заполните диалог (в конвини)

Вставьте пропущенные фразы:

```
木村: いらっしゃいませ。______？
山田: このサンドイッチを二つください。
木村: ______？
山田: はい、お茶も一つお願いします。
木村: 全部で450円になります。______。
山田: はい、お願いします。
木村: ありがとうございました。またお越しください。
```

Вопросы:
1. Что спрашивает продавец в первой реплике?
2. Что продавец спрашивает в третьей реплике?
3. Что продавец говорит в пятой реплике?
4. Сколько стоит покупка?

**Ответы:**
1. 何になさいますか / 何にしますか (Что будете брать?)
2. 何か飲み物はいかがですか / お飲み物はどうですか (Что-нибудь выпить?)
3. レジでどうぞ / 少々お待ちください (Проходите к кассе / Одну минуту)
4. 450円です。
