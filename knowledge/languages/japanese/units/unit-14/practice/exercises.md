# Unit 14 — Практика: 文章体

> Норматив ≥80%. Ответы внизу.

## 1. Переведите в письменный стиль

1. お金がありません。
2. とても面白いです。
3. 働きすぎて、疲れました。
4. これについて話しましょう。

## 2. Соберите 複合動詞

| Первая часть | Вторая | Значение |
|--------------|--------|----------|
| 食べ | ＿＿＿＿ | закончить есть |
| 売り | ＿＿＿＿ | распродано |
| 使い | ＿＿＿＿ | использовать слишком много |
| 助け | ＿＿＿＿ | помогать друг другу |
| 見 | ＿＿＿＿ | пересмотреть |

## 3. Выберите формальный вариант

1. （けど/しかし）、意見が分かれた。
2. 多くの学生（は/って)賛成している。
3. 環境問題（について/って)書いた。

## 4. Исправьте ошибки в фрагменте эссе

```
私はアルバイトについて話します。お金がないから
始めました。でも、今は楽しいです。みんなも
やってみましょう。
```

## 5. Переведите на японский（письменно)

1. Автор утверждает, что число студентов растёт.
2. Начал работать и продолжаю до сих пор.
3. Следовательно, необходимы изменения.

---

# Ответы

<details>
<summary>Открыть</summary>

**1:**
1 金がない。／金がないのである。
2 大変面白い。（い-прил. без だ!) / 面白いものである。
3 働き過ぎて、疲れた。
4 本件について協議する。

**2:** 食べ終わる · 売り切れる · 使い過ぎる · 助け合う · 見直す

**3:** 1-しかし; 2-は; 3-について

**4:** Вариант правки:

```
筆者はアルバイトについて述べる。経済的必要性から
始めたが、今では充実している。読者にも挑戦を
提案したい。
```

（исчезли 私/ます/ましょう, появился 笔者と提案)

**5:**
1 筆者は学生数が増加していると述べている。
2 働き始めて、今も働き続けている。
3 したがって、変革が必要である。

</details>

## 6. Перепишите переписку в である体

Отрывок из письма друга. Перепишите всё в письменном стиле:

```
私は先月から図書館で勉強しています。たくさん本を読んでいます。
でも、お金がありません。だから、働き始めました。
```

## 7. Выберите 複合動詞 из рамки

```
読み返す・書き終える・考え込む・言い切る・使い始める
```

1. ＿＿＿＿＿＿前に、一度原稿を確認した。
2. その可能性を ＿＿＿＿＿＿ すらできなかった。
3. このアプリは去年から ＿＿＿＿＿＿ ている。
4. 彼は絶対に成功すると ＿＿＿＿＿＿。
5. 一晩（ひとばん）かけて ＿＿＿＿＿＿、やっと提出した。

## 8. Найдите и исправьте 5 ошибок стиля

```
私はこの問題について話します。学生たちはとても元気だ。
いい天気だ。しかし、多くの学生はお金がない。
私は働きはじめました。
```

## 9. Соедините разговорное и письменное

| 1. ちょっと | а) 極めて |
| 2. とても | б) 複数の |
| 3. いくつも | в) やや |
| 4. たくさん | г) 本件 |
| 5. これ | д) 多くの |

## 10. Переведите на русский（фрагменты статей)

1. まず、就業率について述べる。
2. 回答者は、経済的必要性からアルバイトを始めている。
3. したがって、上限のガイドラインを設けるべきである。
4. 若者は金銭以上に経験を重視し始めたのである。

## 11. Постройте 3 предложения

Используйте данные конструкции о цифровых учебниках:

1. ～をめぐって（вокруг спора о введении)
2. ～を対象に（опрос студентов)
3. ～に関して（о качестве）

## 12. Расширьте черновик до формального вступления

Черновик: 「バイトは大変。でも楽しい。儲かる。」

Превратите в формальное введение (3 предложения, である体).

## 13. Вставьте связку

```
しかしながら・その結果・一方・例えば・要するに・したがって
```

1. まず問題を提示する。＿＿＿＿＿＿、具体例を挙げる。
2. 働く学生が増えた。＿＿＿＿＿＿、成績の低下が見られた。
3. ＿＿＿＿＿＿、女性の管理者はまだ少ない。
4. A案はコストが高い。＿＿＿＿＿＿、B案を採用する。
5. ＿＿＿＿＿＿、両立には工夫が必要である。

## 14. Трансформация: 5 фраз в двух стилях

Заполните таблицу:

| Разговорный | Письменный |

| Начало | Значение | Вторая часть |

# Ответы (продолжение)

<details>
<summary>Открыть</summary>

**6:** 筆者は先月から図書館で勉強している。多くの本を読んでいる。
経済的必要性から働き始めた。

**7:**
1 書き終える; 2 考え込む; 3 使い始め; 4 言い切った; 5 読み返して

**8:** Возможный вариант:

- 私は→筆者は; この問題について→本件について
- 話します→述べる
- とても→極めて; とても元気だ→意欲的である
- いい天気だ→天気は良い（い-прил. без だ)
- お金がない→資金が不足している
- 働きはじめました→働き始めた

**9:** 1-в · 2-а · 3-б · 4-д · 5-г

**10:**
1 Прежде всего сообщается о доле занятости.
2 Респонденты начали подрабатывать из экономической надобности.
3 Следовательно, следует установить конвенцию о верхнем пределе.
4 Молодёжь именно что начала ценить опыт больше денег.

**11:**
1 導入をめぐって、激しい議論が行われた。
2 五百名の大学生を対象に、インタビュー調査を行った。
3 教材の質に関しては、専門家の意見が分かれた。

**12:** Вариант:

```
アルバイトは体力を消耗するが、得られる教訓も多い。
金銭的な報酬には限界があるものの、経験の価値は大きい。
要するに、単なる収入源ではなく、学びの場である。
```

**13:**
1 例えば; 2 その結果; 3 一方; 4 したがって; 5 要するに

**14:**
1 図書館で本を読んだ。
2 多忙のため、本を読んでいない。
3 それが問題であると考えられる。
4 皆で検討すべきである。／対応を協議する。
5 やや高価である。／少々高めである。

**15:** 働き続ける · 売り切る · 助け合う · 考え込む · 直し直す（作り直す）

</details>
