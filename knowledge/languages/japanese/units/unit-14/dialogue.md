# Unit 14 — Диалог: 大学新聞への投稿（Статья в университетскую газету)

## Ситуация

Редактор университетской газеты Сато прочитал пост Алисы в блоге о жизни иностранного студента и приглашает написать полноценную статью. Алиса впервые пишет формальным стилем である —— без ます и с кандзи до горизонта. Редактор по электронной почте ведёт её через правки.

## Письма（диалог в переписке)

```
差出人：sato@daigaku-shinbun.ac.jp
件名：原稿のお願い

アリス様

先日はブログをお読みし、大変興味深く拝見いたしました。
ぜひ大学新聞に記事をご寄稿いただけないでしょうか。
テーマは「留学生のアルバイト実態」でいかがかと存じます。
文体は「である調」でお願いいたします。字数は800字程度。

編集長　佐藤

──────────────────────

差出人：alice@example.com
件名：RE：原稿のお願い

佐藤編集長

お世話になっております。アリスです。
喜んで書かせていただきます。一週間以内に
初稿を提出いたします。

アリス

──────────────────────

（一週間後)

件名：添削結果

アリス様

初稿を拝読しました。内容は excellent… 失礼、素晴らしいのですが、
文体が「です・ます調」になっている箇所が多数あります。
以下、修正例です：

× 私は週に五日働いています。
○ 筆者は週に五日勤務している。

× お金が必要だから始めました。
○ 経済的必要性から始めたのがきっかけである。

一人称の「私」は最小限に。「だ・である」で統一を。
期待しています。　　　　　　　佐藤
```

## Перевод ключевых мест

| Японский | Русский |
|----------|---------|
| 原稿のお願い | Просьба о рукописи |
| ご寄稿いただけないでしょうか | Не могли бы вы прислать статью? |
| である調 | стиль である |
| 拝読しました | Прочитал（скромно) |
| 添削結果 | Результаты правки |
| 勤務している | работаю（письм.) |
| 経済的必要性から始めたのがきっかけである | Началось из экономической необходимости |

## Культурная заметка

**Два стиля японского:** разговорный です/ます и письменный である сосуществуют как у нас «вы»-речь и научный текст. Газеты, эссе, резюме, диссертации —— всегда である. Ошибка студента：написать резюме в ます-стиле —— мгновенно выдаёт новичка.

## Диалог 2: Обсуждение правок（лицом к лицу)

> Сценарий: Алиса пришла в редакцию. Сато комментирует её черновик вслух.

```
アリス：編集長、初稿、読んでいただけましたか。
佐藤：ええ、拝読しました。内容は良いです。
　　　ただ、文体が混ざっているのが気になりますね。
アリス：「である」に直したつもりだったんですが…
佐藤：「つもり」が甘かったですね。ここ、見てください。
　　　「私は思います」ーこれは話し言葉です。
　　　「筆者は考える」にしましょう。
アリス：なるほど。原因は「私」ですね。
佐藤：そうです。一人称を消せば、自然に「である」に落ち着きます。
　さて、この「お金がないから始めました」もダメです。
アリス：えっと…「経済的必要性から始めた」でいいですか。
佐藤：完璧です。ここに「のがきっかけである」と付けましょう。
アリス：承知しました。今週中に書き直します。
佐藤：期待していますよ。では、お願いします。
```

**Разбор:**

| Японский | Русский |
|----------|---------|
| 読んでいただけましたか | Не могли бы вы прочитать? (скромно-почтительно) |
| 気になりますね | Меня это напрягает, да (неловкость) |
| 「である」に直したつもり | Собиралась исправить на である |
| つもりが甘かった | Намерение было слабовато |
| 一人称を消せば | Если убрать первое лицо |
| 落ち着きます | Здесь: само собой устаканится |
| 承知しました | Понял (формальное согласие) |

Совет: универсальный приём — **убрать 私, и стиль сам станет である**. Один художественный приём заменяет половину правок.

## Диалог 3: Пишем эссе вместе

> Сценарий: Алиса и однокурсница Мария обсуждают школьное эссе «мудразгания» (作文).

```
マリア：課題の作文、もう書いた？
アリス：まだのよ。テーマは「読書と私」なんだけど。
マリア：いいテーマね。字数は?
アリス：八百字。スタイルは「である」で、っていわれた。
マリア：まず序論で自分の立場を言って、そのあと具体例でしょ？
アリス：うん。でも、書き始めると、「です・ます」が
　　　　無意識に混ざっちゃうんだよね….
マリア：分かる分かる。とりあえず全部書いて、
　　　　後で「私」を抜いて、動詞を辞書形に直せばいい。
アリス：なるほど。それに、複合動詞も使うべきかな。
マリア：使うと自然よ。「読み始める」「読み返す」
　　　　「考え込む」みたいな。
アリス：ありがとう。じゃあ、いま、書き始めてみる。
マリア：がんばって。書き終えたら見せてね。
```

**Разбор:**

| Японский | Русский |
|----------|---------|
| 作文 | сочинение |
| 読書と私 | «Чтение и я» |
| でしょ？ | ведь так? (дружеский) |
| 混ざっちゃう | примешивается (っちゃう = てしまう) |
| 複合動詞 | составные глаголы |
| 書き終えたら見せてね | Как допишешь — покажи |

Мария советует правильный порядок: **сначала черновик в любом стиле → потом чистка**（私 → убрать, ます → словарная форма). Так и профессиональные авторы работают.

## Диалог 4: Заявка на конференцию

> Сценарий: Алиса хочет выступить на студенческой конференции. Переписка с профессором по эл. почте.

```
件名：研究発表への申し込み

田中教授
お忙しいところ失礼します。国際学部二年のアリスと申します。
来月の研究発表会で、「留学生の就労経験」について
発表したいと考えております。
同テーマのレポートを資料として添付いたしました。
ご確認の上、ご指導いただけますと幸いです。

アリス

─────────────────────

件名：RE：研究発表への申し込み

アリスさん
申込書を確認しました。発表枠は空きがあります。
ただし資料は二点修正が必要です。
第一に、参考文献の形を統一してください。
第二に、要旨は「である調」で四百字にまとめてください。
修正後、再来週の木曜日までに提出してください。

田中
```

**Разбор:**

| Японский | Русский |
|----------|---------|
| 研究発表会 | конференция (доклад студентов) |
| 申し込み | заявка, подача |
| であります…と考えております | вежливо: «думаю провести» |
| 添付いたしました | прикрепил (скромно) |
| ご確認の上 | после того как проверите |
| 幸いです | буду признателен |
| 再来週の木曜日 | четверг после следующего |
| 要旨 | тезисы, аннотация |

Обратите внимание: деловая переписка использует です/ます даже при である-задачах. Переключение стилей — это не ошибка, а норма: разговор с человеком — вежливый, сам текст — である.

## Диалог 5: Разговор двух студентов о словаре стиля

> Сценарий: Двое готовятся к экзамену и в шутку «переводят» разговорные фразы в официальные.

```
健：ちょっと、今日の授業、長かったね。
亮：うん。「先生の話が長い」を「である」で言うと?
健：うーん…「講義が長時間に及んだ」じゃない？
亮：いいね。じゃあ「めっちゃ眠かった」は?
健：「睡魔に襲われた」。
亮：あはは、それ小説みたい。じゃあ「間違えた」は?
健：「誤りを犯した」だろ。
亮：逆に「論文が面白い」を話し言葉にすると?
健：そりゃ「論文、すごく面白かった！」かな。
亮：なるほど、行き来できれば完璧だね。
健：だね。まずは文章で「である」、会話で「です・ます」を。
```

**Разбор:**

| Японский | Русский |
|----------|---------|
| 長かったね | долго было, да (нар. разговор) |
| 講義が長時間に及んだ | лекция затянулась (письменный стиль) |
| 睡魔に襲われた | напал сон (иронично-литературно) |
| 誤りを犯した | совершил ошибку (формально) |
| 行き来できれば | если сможешь переключаться |
| まずは | прежде всего |

Это упражнение — «стилистический перевод»: полезно играть в него с партнёром, чтобы чувствовать границу между стилями. Подробнее о стилях: [грамматика §8–20](grammar.md#8-парадигма-письменного-стиля).
