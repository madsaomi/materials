# Unit 14 — Лексика: письменный японский

## Формальные глаголы

| Разговорный | Письменный | Русский |
|-------------|-----------|---------|
| 言う | 述べる・指摘する | говорить/утверждать |
| 思う | 考えられる | считается |
| 見る | 拝見する・観察する | смотреть/наблюдать |
| する | 行う（おこなう) | проводить, осуществлять |
| 増える | 増加する（ぞうか) | расти |
| 減る | 減少する（げんしょう) | сокращаться |
| なる | ～となる | становиться |
| ある | 存在する（そんざい) | существовать |

| 序論 | じょろん | введение | 序論で問題を提示する。 |
| 本論 | ほんろん | основная часть | 本論で根拠を列挙する。 |
| 結論 | けつろん | заключение | 結論を簡潔にまとめる。 |
| 現状 | げんじょう | текущее положение | 現状をまず述べる。 |
| 背景 | はいけい | предыстория | 研究の背景を説明する。 |
| 課題 | かだい | задача, вызов | 今後の課題を明らかにする。 |
| 解決策 | かいけつさく | пути решения | 解決策を二つ挙げる。 |
| 根拠 | こんきょ | основание | 主張の根拠を示す。 |
| 主張 | しゅちょう | утверждение | 筆者の主張は明快である。 |
| 提案 | ていあん | предложение | 提案の具体策を述べる。 |
| 事実 | じじつ | факт | 事実に基づいて論じる。 |
| 結果 | けっか | результат | 調査の結果を報告する。 |
| 原因 | げんいん | причина | 原因を分析する。 |
| 目的 | もくてき | цель | 本稿の目的を確認する。 |

| 視点 | してん | перспектива | 若者の視点から見る。 |
