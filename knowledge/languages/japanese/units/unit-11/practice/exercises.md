# Unit 11 — Практика: 受身と使役

> Делайте письменно, потом проверяйте по ответам внизу. Норматив: ≥80%.

## 1. Образуйте пассив

1. 書く → ＿＿＿＿＿＿
2. 褒める → ＿＿＿＿＿＿
3. 来る → ＿＿＿＿＿＿
4. 踏む（наступить) → ＿＿＿＿＿＿
5. 飲む → ＿＿＿＿＿＿

## 2. Образуйте каузатив

1. 食べる → ＿＿＿＿＿＿
2. 待つ → ＿＿＿＿＿＿
3. する → ＿＿＿＿＿＿
4. 読む → ＿＿＿＿＿＿
5. 来る → ＿＿＿＿＿＿

## 3. Каузативно-пассивная форма

Переведите в 使役受身:

1. 行く → ＿＿＿＿＿＿＿＿
2. 言う → ＿＿＿＿＿＿＿＿
3. 働く → ＿＿＿＿＿＿＿＿

## 4. Выберите частицу: に или を

1. 私は母（　）野菜を食べさせられた。
2. 先生は学生（　）本を読ませた。
3. 私は電車の中で足（　）踏まれた。
4. 店長はアリスさん（　）レジを覚えさせた。

## 5. Переведите на японский

1. Меня заставили остаться после работы.
2. Меня похвалил заведующий.
3. Мама разрешает мне играть в игры по часу в день.
4. Вчера на меня нахамили в автобусе.

## 6. Найдите ошибку

1. 私は先生が褒められました。
2. 子供に野菜が食べさせました。
3. 雨が降られて、びしょ濡れになった。

---

# Ответы

<details>
<summary>Открыть</summary>

**1:** 書かれる · 褒められる · 来られる · 踏まれる · 飲まれる

**2:** 食べさせる · 待たせる · させる · 読ませる · 来させる

**3:** 行かされる · 言わされる · 働かされる

**4:** 1-に, 2-を, 3-を, 4-に

**5:**

1. 残業させられました。／閉店まで残らされました。
2. 店長に褒められました。
3. 母は私に一日一時間ゲームをさせています。
4. 昨日、バスの中で失礼なことを言われました。

**6:**

1. → 先生**に**褒められました。（источник пассива —— に)
2. → 子供**に**野菜**を**食べさ**せられ**ました？ нет：если「заставила есть」—— 子供**に**野菜**を**食べさせました。(частица объекта при каузативе —— を, исполнителя —— に)
3. → 雨に降られて、びしょ濡れになりました。（источник неудобства —— に)

</details>

# Дополнительные упражнения 7–16

## 7. Образуйте три формы от одного глагола

Заполните таблицу（パッシブ/カウザティブ/カウザティブ・パッシブ):

| Глагол | 受身 | 使役 | 使役受身 |
|--------|------|------|----------|
| 呼ぶ | | | |
| 帰る | | | |
| 書く | | | |

## 8. Пассив или каузатив? Выберите форму

Поставьте правильную форму（не перевод):

1. （勉強を）させる／させられる —— 先生は学生に　＿＿＿。
2. （褒める）褒められる —— 私は先生に　＿＿＿。
3. （休む）休ませる／休ませられる —— 母は私を　＿＿＿。
4. （掃く）掃かせる／掃かされる —— 私は店長に　＿＿＿。

## 9. Поставьте правильную частицу: に, を, が

1. 私は友達（　）プレゼントを買われた（были куплены⇒испортил сюрприз).
2. 子供は親（　）叱られた。
3. 部長は私（　）資料を読ませた。
4. 私は犬（　）噛まれた（укусили).
5. 先生は私（　）作文を書かせた。

## 10. Переведите на японский（使役受身 в центре)

1. Вчера меня заставили остаться до девяти.
2. Меня заставляют каждый день мыть окна.
3. Из-за дождя мне пришлось стоять под навесом.
4. Меня разбудили соседи своим шумом.

## 11. Соедините пары 自動詞/他動詞

| Автомация（непереходный） | Переходный |
|---------------------------|------------|
| 落ちる | ＿＿＿＿＿＿ |
| 壊れる | ＿＿＿＿＿＿ |
| 開く | ＿＿＿＿＿＿ |
| 閉まる | ＿＿＿＿＿＿ |

## 12. Найдите и исправьте ошибку

1. 社長は私に会社の秘密を言われました。
2. 母は私を宿題なさせた。
3. 私は店長にレジを打たされました。（—— есть ошибка ли?)

## 13. Смягчите приказ через ～させてください

Перепишите в вежливой просительной форме:

1. 手伝います → ＿＿＿＿＿＿
2. 確認します → ＿＿＿＿＿＿
3. 休憩します → ＿＿＿＿＿＿

## 14. Выберите ～てもらう / ～させてもらう по смыслу

1. （）てください —— попросить коллегу сделать.
2. （）てほしい —— «хочу, чтобы ты сделал».
3. （）いただきます —— «позвольте мне сделать»（моё собственное действие).

Укажите, где 使役(させる) присутствует обязательно.

## 15. Переведите на русский（тёмные места юнита)

1. 犬に吠えられて、猫は逃げていきました。
2. 父に一時間も話を聞かされました。
3. 座らせてもらえますか。
4. 足を踏まれて、痛かったです。

## 16. Напишите «жалобу» первой смены

Опишите 3–5 действий（придумайте), которые вас заставляли делать в первый день, используя ～させられました и ～たり…たりしました. Образец:

> 初日は、掃かされたり、皿を洗わせられたりしました。

# Ответы к упражнениям 7–16

<details>
<summary>Открыть</summary>

**7:**

| Глагол | 受身 | 使役 | 使役受身 |
|--------|------|------|----------|
| 呼ぶ | 呼ばれる | 呼ばせる | 呼ばされる |
| 帰る | 帰られる | 帰らせる | 帰らされる |
| 書く | 書かれる | 書かせる | 書かされる |

**8:** 1-させる（учитель даёт/заставляет учиться); 2-褒められる（меня хвалят); 3-休ませる（мама даёт мне отдохнуть); 4-掃かされる（меня заставили подметать).

**9:** 1-に, 2-に, 3-に, 4-に, 5-に（во всех—— исполнитель/источник соответствует に в пассиве или に у исполнителя каузатива; を ставится на объект действия, который здесь идёт отдельно).

**10:**

1. 昨日、九時まで残らされました。
2. 毎日、窓を拭かされています。
3. 雨に降られて、雨宿りをさせられました。
4. 隣の騒音で起こされました。

**11:** 落とす・壊す・開ける・閉める（непереходный→переходный）

**12:**

1. 社長に秘密を言われました（на мне—— 私「は」, но источник 社長「に」; имелось в виду 言われた —— подчинение)
2. 母は私に宿題をさせた（исполнитель каузатива—— に, объект—— を)
3. Ошибки нет：打たされる корректная 使役受身 от 打つ.

**13:**

1. 手伝わせてください。
2. 確認させてください。
3. 休憩させてください。

**14:** 1-してもらって; 2-してもらって; 3-させていただきます（только здесь させ- каузатив присутствует обязательно—— это своё собственное действие).

**15:**

1. Собака на меня залаяла, и кот убежал.
2. Отец заставил меня слушать рассказ целый час.
3. Можно мне сесть?（позволите мне сесть?)
4. Наступили на ногу, было больно.

**16:** Свободный ответ—— образец уже дан. Оцените: правильно ли использованы 受身/使役受身 и たり.

</details>
