# Unit 11 — Диалог: バイト初日（Первый день на подработке)

## Ситуация

Алиса устроилась на подработку в кафе「もみじ」неподалёку от университета. Первый рабочий день: заведующая Ямада-сан объясняет правила, коллега Кэнта（тот самый из юнита 7) помогает освоиться. За день с Алисой происходит всё, для чего японский придумал пассив и каузатив: ей дают поручения, её хвалят, на неё жалуются клиенты, её заставляют остаться после смены.

## Диалог

```
山田店長：アリスさん、初めまして。この店の店長の山田です。
　　　　　まず、制服に着替えてください。
アリス：はい、わかりました。着替えてもいいですか。
山田：ああ、更衣室で着替えさせます。それから、開店前に
　　　床を扫いておいてください。
アリス：はい！（掃除を始める)
ケンタ：アリスさん、上手だね。僕が入った時、
　　　　店長に三時間も扫かされたよ。
アリス：三時間？！うそでしょう。
ケンタ：うそじゃないよ。僕は最初の一週間、毎日
　　　　野菜を切らされたり、ゴミを出させられたりして…。
アリス：大変だったんだね。
客：すみません！注文したのは、コーヒーじゃなくて、紅茶なんですが。
アリス：（慌てて)あっ、すみません！すぐお持ちします！
山田：アリスさん、落ち着いて。丁寧にやればいいから。
　　　……そうそう、今日は閉店まで残ってもらいます。
アリス：えっ？残らされるんですか…？
山田：新しいメニューの練習をさせるからね。頑張って。
ケンタ：頑張って。終わったら、みんなでラーメン行こうよ。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 制服に着替えてください | Переоденьтесь в форму |
| 更衣室で着替えさせます | Дам переодеться в раздевалке |
| 床を扫いておいてください | Подметите пол заранее |
| 店長に三時間も扫かされた | Меня заставляли мыть целых три часа |
| 野菜を切らされた | Меня заставляли резать овощи |
| 注文したのは紅茶 | Заказан был чай（не кофе) |
| 残ってもらいます | Попрошу остаться |
| 残らされるんですか | Меня заставят остаться? |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 店長 | てんちょう | управляющий магазином/кафе |
| 制服 | せいふく | форма（одежда) |

| 開店 | かいてん | открытие（заведения) |
| 床 | ゆか | пол |
| 客 | きゃく | клиент, посетитель |

## Культурная заметка

**Байто（バイト)** — подработка студентов, почти национальный институт: почти каждый студент в Японии работает 15–25 часов в неделю. Конбини, кафе, идзакая, репетиторство. На первом дне принято приносить маленький подарок коллегам（お菓子) и говорить「本日よりお世話になります」.

**Иерархия байто:** стаж работы важнее возраста. «Сэмпай»（старший) учит «кохая», даже если кохаю 30 лет. Поэтому Кэнта, проработавший год, имеет право рассказывать про «заставляли мыть три часа» —— это обряд посвящения.

## Диалог 2: シフトを頼まれる（Просят подменить в смене)

Контекст: третья неделя работы. Алиса уже освоилась, но коллега просит подменить. Приходится отказывать —— снова пассив и каузатив в ходу.

```
ケンタ：アリスさん、すみません。明後日、代わりにシフトを
　      入ってもらえませんか。
アリス：あ、明後日は大学のレポートがありますから、難しいです。
ケンタ：そうか…。じゃあ、店長に聞いてもらえますか。
アリス：はい、店長に頼まれましたが、私は入れませんでした。
　      でも、田中さんに聞いてみてくれませんか。
ケンタ：そうする。ありがとう！じゃあ、今日は早く片付けさせて
　      もらってもいい？
アリス：いいですよ。私は残って洗いますから。
```

## Перевод и разбор диалога 2

| Японский | Русский |
|----------|---------|
| シフトを入れてもらえませんか | нельзя ли тебе встать в смену? |
| レポートがあります | есть доклад |
| 店長に頼まれました | меня попросил заведующий |
| 早く片付けさせてもらってもいい？ | можно мне побыстрее закончить уборку? |
| 残って洗います | останусь и вымою посуду |

> 💡 ～もらえませんか и ～もらってもいい—— просьба с каузативом：говорящий«просит дать себе сделать»·просит разрешение. Так отказывают мягко и избегают прямого「だめです」.

## Диалог 3: 面接の話（Разговор про собес）

Контекст: на смене болтают про прошлые подработки. Сато пришла из другого кафе, Кэнта рассказывал про первую неделю.

```
サト：私、前のカフェでは焼き立てのパンを任されていました。
アリス：へえ、すごいですね！何歳から始めたんですか。
サト：十七歳の時です。最初は掃除ばかりさせられて、
　     三ヶ月してやっとレジを任されました。
ケンタ：うちはすぐレジをやらせられたけどね。
サト：店によるんでしょうね。面接の時、どんな質問をされたか
　     覚えていますか、ケンタ君。
ケンタ：うーん、「徹夜できますか」と聞かれました。
サト：（笑う)それは変な質問だね！
```

## Перевод и разбор диалога 3

| Японский | Русский |
|----------|---------|
| 焼き立てのパンを任されていた | доверяли выпечку（пассив —— меня надрели) |
| 掃除ばかりさせられて | заставляли только убираться |
| やっとレジを任されました | наконец доверили кассу |
| レジをやらせられた | заставили сразу работать на кассе |
| 何を質問されましたか | о чём вас спрашивали? |
| 「徹夜できますか」と聞かれました | спросили «можешь не спать всю ночь?» |

> 💡 任される —— пассив от 任せる（доверять)：«мне доверили». Хорошее слово: показывает, что рост доверия —— пассив со стороны работника.

## Диалог 4: 客に文句を言われる（Клиент жалуется)

Контекст: заминка с заказом. Опытная Сато учит Алису справляться с жалобой спокойно —— в ход идёт каузатив-«позволение» и вежливые обороты.

```
客：おい、注文したコーヒーがまだ来ないんだけど！
アリス：（慌てて)すみません、すぐ確認します！
サト：（小声で)アリスちゃん、私に任せて。
サト：大変申し訳ございませんでした。今すぐお作りさせて
　     ください。代わりに、こちらをサービスさせていただきます。
客：（少し和らぐ)……じゃあ、お願いします。
アリス：さすがです！私は焦ってばかりでした。
サト：最初はみんなそうよ。落ち着いて、代わりの提案を
　     させてあげればいいんだから。
```

## Перевод и разбор диалога 4

| Японский | Русский |
|----------|---------|
| 私に任せて | доверься мне（позволь мне) |
| 大変申し訳ございませんでした | приношу глубочайшие извинения |
| お作りさせてください | позвольте приготовить |
| サービスさせていただきます | позвольте предложить комплимент（бесплатно) |
| 提案をさせてあげればいい | достаточно дать предложить выход |
| 焦ってばかりでした | только и делала, что нервничала |

> 💡 Закон вежливой жалобы：клиент——«источник», мы——«приёмник». Его слова «передаются» пассивом, наши предложения——каузативом-позволением. Чем больше ～させてください, тем спокойнее клиент.
