# Unit 11 — Тест

## Часть 1: Образуйте форму

1. 言う → пассив ＿＿＿＿＿
2. 死ぬ → каузатив ＿＿＿＿＿
3. 待つ → 使役受身 ＿＿＿＿＿＿
4. 遊ぶ → каузатив（разрешить играть) ＿＿＿＿＿＿

## Часть 2: Выберите верный вариант

**1. 昨日、先生に宿題を多く＿＿＿。**

- а) 出させた　б) 出させられた　в) 出された

**2. 私は電車で足＿＿踏まれた。**

- а) が　б) に　в) を

**3. 医者は患者に薬＿＿飲ませた。**

- а) が　б) に　в) を

**4. このドアは自動で＿＿。**

- а) 開ける　б) 開く　в) 開けさせる

## Часть 3: Правда/Ложь по диалогу

「ケンタは最初の一週間、毎日野菜を切らされたり、ゴミを出させられたりした。」

1. Кэнта сам вызвался резать овощи.（　）
2. Его заставляли и выносить мусор.（　）
3. Это длилось один день.（　）

## Часть 4: Перевод

На японский:

1. Меня хвалят за японский.
2. Родители не разрешают мне курить.
3. Вчера меня заставили мыть посуду два часа.

На русский:

4. 弟にゲームを取られた。
5. 社長に行かされることになった。

# Дополнительный блок（части 5–9)

## Часть 5: Образуйте форму（трудные глаголы)

1. 撮る（снимать）→ 使役受身 ＿＿＿＿＿
2. 訪ねる → 使役 ＿＿＿＿＿＿
3. 連れる（вести) → 使役受身 ＿＿＿＿＿＿
4. 押す → 受身 ＿＿＿＿＿
5. 頼む → 使役受身 ＿＿＿＿＿

## Часть 6: Заполните пропуск правильной формой

Выберите вариант из скобок：

1. 母は私に毎日野菜を＿＿＿。（食べさせる／食べさせられる)
2. 私は母に毎日野菜を＿＿＿。（食べさせる／食べさせられる)
3. 店長は新人に挨拶を＿＿＿。（させる／させられる)
4. 私は店長に挨拶を＿＿＿。（させる／させられる)
5. 雨に＿＿＿、風邪を引きました。（降られて／降らせて)

## Часть 7: Выберите верный вариант

**1. 犬に噛まれて、とても怖かった。** —— この文で「噛まれて」の主体は？

- а) 犬　б) 私　в) 噛む人

**2. 「せかさされて、急いでいます」—— 意味は?**

- а) я тороплю других　б) меня торопят　в) никто не торопит

**3. 正しい文はどれですか?**

- а) 私が先生に褒めました。
- б) 私は先生に褒められました。
- в) 私は先生に褒められましたが、先生は褒めました。

**4.「食べる」の使役受身は?**

- а) 食べさせる　б) 食べられる　в) 食べさせられる

## Часть 8: Правда/Ложь по траведиям юнита

「バスの乗客に足を踏まれて、痛かった。店長には掃かされたし、レジは覚えさせられた。忙しくて大変だったが、先輩には助けてもらった。」

1. Автор наступил кому-то на ногу.（　）
2. Заведующий заставил подметать.（　）
3. Автора заставляли освоить кассу.（　）
4. Старший коллега помог автору.（　）

## Часть 9: Перевод（расширенный)

На японский:

1. Меня похвалил учитель за чистописание.
2. Мама даёт мне смотреть телевизор один час.
3. Из-за опоздания автобуса я промок под дождём.
4. Начальник заставил меня остаться и дописать отчёт.

На русский:

5. 上司に早く帰らせてもらえました。
6. 弟に宿題を手伝わせられました。
7. 母に泣かれて、謝りました。
