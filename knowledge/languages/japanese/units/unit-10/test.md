# Unit 10 — Тест

## Часть 1: Выберите правильный вариант

**1. 雨が＿＿＿、試合は中止です。**

- а) 降るたら
- б) 降ったら
- в) 降りたら

**2. 私は刺身を食べた＿＿＿がありません。**

- а) こと
- б) もの
- в) とき

**3. 明日は遅れる＿＿＿しれない。**

- а) を
- б) が
- в) か

**4. 早く予約した＿＿＿いいよ。**

- а) ほうが
- б) ほうに
- в) より

## Часть 2: Правда или ложь?

「アリスは新幹線に乗ったことがない。ホテルはもう予約してある。」

1. アリスは新幹線の経験がある。（　）
2. ホテルの予約は終わった。（　）
3. 二人は京都へ行く予定だ。（　）

## Часть 3: Переведите

На японский:

1. Если будет время, позвоню.
2. Я ни разу не поднимался на Фудзи.
3. Похоже, идёт дождь.

На русский:

4. 高くても買いたい。
5. 何をすればいいですか。

## Часть 4: Выберите правильный вариант

**6. 刺身を食べて＿＿＿たいです。**

- а) み
- б) む
- в) ま

**7. ホテルを予約＿＿＿おきました。**

- а) して
- б) する
- в) しない

**8. 切符をなくして＿＿＿ました。**

- а) しま
- б) い
- в) み

**9. ＿＿＿新幹線の切符を買いましたか。**

- а) まだ
- б) もう
- в) もっと

**10. ここで写真を撮って＿＿＿ですか。**

- а) もいい
- б) はいけない
- в) ほうがいい

**11. このお店はちょっと高＿＿＿。**

- а) すぎる
- б) すぎた
- в) すぎです

**12. 疲れた＿＿＿、休んでください。**

- а) たら
- б) と
- в) ばかり

## Часть 5: Заполните пропуски

1. お寺を見たい＿＿＿、清水寺がいいです。
2. ＿＿＿予約してありますか。 — いいえ、＿＿＿です。
3. 写真を撮り＿＿＿すぎました。
4. 富士山に登った＿＿＿がありますか。

## Часть 6: Выберите верное слово (もう/まだ/てみる/ておく/てしまう)

1. Пришёл, ещё не ел. → （＿＿＿）食べていません。
2. Сказать заранее. → 先に知らせて（＿＿＿）ください。
3. Попробовать есть. → 食べて（＿＿＿）ください。
4. Произошло нечаянно. → 忘れて（＿＿＿）ました。

## Часть 7: Правда или ложь (по диалогу 3)

「ゆきは道に迷った。通行人は左に曲がれと言った。歩いて十分ぐらいかかる。」

1. ゆきは道に迷った。（　）
2. 通行人は右に曲がれと言った。（　）
3. 歩いて十分ぐらいかかる。（　）
