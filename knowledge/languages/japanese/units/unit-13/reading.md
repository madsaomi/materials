# Unit 13 — Чтение: 起業への道（Путь к своему делу)

## Текст

```
　　二十代の起業家が増えている

最近、二十代で会社を作る若者が増えている。
「大企業に就職しても、一生安泰とは限らない。
若いうちに挑戦した方がいい」と話すのは、
去年カフェを開いた田中さん（26歳)。

開店までの道のりは簡単ではなかった。
資金がなければ、銀行から借りるしかない。
場所を探せば探すほど、家賃の高さに驚くばかり。
それでも、「やりたいことがあるのに、やらないのは
もったいない」と思い続けたという。

今では、週末は行列ができる人気店になった。
「失敗しても後悔しない。挑戦しないことの方が
もっと後悔する」と田中さんは笑う。

ただし、専門家は注意も促す。「夢だけで始めると、
資金切れで潰れる店が多い。計画と貯金、
そして覚悟が必要です」。
```

## Вопросы к тексту

1. Что сказал Танака о трудоустройстве в крупную компанию?
2. Как он добывал деньги на открытие?
3. Какая фраза Танаки стала его девизом?
4. О чём предупреждают специалисты?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 就職 | しゅうしょく | трудоустройство |
| 安泰 | あんたい | безмятежность, стабильность |
| 挑戦 | ちょうせん | вызов, попытка |
| 道のり | みちのり | путь（долгий) |
| 借りる | かりる | брать в долг |
| 驚く | おどろく | удивляться |
| もったいない | — | жалко, расточительно |
| 行列 | ぎょうれつ | очередь |
| 後悔 | こうかい | сожаление |
| 促す | うながす | призывать, побуждать |
| 資金切れ | しきんぎれ | нехватка средств |
| 覚悟 | かくご | решимость |

## Разбор грамматики в тексте

**安泰とは限らない**
→ とは限らない «не обязательно»: даже крупная компания ≠ гарантия.

**挑戦した方がいい**
→ ～たほうがいい: совет «лучше попробовать пока молод».

**借りるしかない**
～しかない «ничего кроме»: единственный вариант.

**探せば探すほど**
→ ば～ほど с одним глаголом дважды: «чем больше ищешь…».

**やりたいことがあるのに、やらないのはもったいない**
→ のに（вопреки желанию) + のは（номинализация) + もったいない.

**失敗しても後悔しない。挑戦しないことの方がもっと後悔する**
→ контраст ても vs ないことの方が：сравнение двух сожалений.

## Задание после чтения

Напишите план своей мечты (5–7 предложений), использовав:

- ～たら（что будет, если осуществится)
- ～ても（какое препятствие не остановит)
- ～ば～ほど（что растёт вместе с усилиями)
- ～と言われる（что вам говорят окружающие)

Образец: 夢を実現したら、両親を喜ばせたいです。

## Текст 2: 小さい成功の積み重ね（Мелкие шаги к большому)

```
　　夢は一歩ずつ

「大きな目標を持つことは大切だ。でも、目標だけでは
何も始まらない」と、商店街の老舗の店主は言う。

彼は四十年前、小さな蕎麦屋を一軒から始めた。
「初めは客が来るかどうかも分からなかった。
失敗したら、また働きに行けばいい。そう思うと
気が楽になった」と振り返る。

「続ければ続けるほど、味も良くなるし、
客の顔も覚えてくれる。小さな成功を積み重ねれば、
自然と大きな店になるものだ」。

今日も老舗は、家族と従業員とともに、
朝から夜まで営業を続けている。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 老舗 | しにせ | старинная зарекомендовавшая себя лавка |
| 店主 | てんしゅ | владелец магазина |
| 蕎麦屋 | そばや | лапшичная |
| 客が来るかどうか | придёт ли клиент |
| 気が楽になる | становится легче на душе |
| 積み重ねる | つみかさねる | накапливать |
| 営業 | えいぎょう | работа, ведение дела |

### Разбор грамматики

```
客が来るかどうか分からない → かどうか（ли…）— «неизвестно, придёт ли»
失敗したら、また働きに行けばいい → たら + ばいい（если провалюсь — можно снова пойти работать)
続ければ続けるほど → ば～ほど（чем дольше продолжаешь…)
積み重ねれば、自然と大きくなる → ば（логичное следствие)
朝から夜まで → から～まで（с… до…)
```

### Вопросы

1. Что, по словам владельца, важнее большого желания?
2. Как он относился к возможной неудаче в начале пути?
3. Что происходит, когда продолжаешь дело долго?
4. Объясните смысл фразы「続ければ続けるほど」.

## Текст 3: リスクを取るか、安定を取るか（Риск или стабильность)

```
　　夢と安定のはざまで

会社員の佐藤さん（29歳）は、今、大きな決断を
迫られている。親が経営する会社を継ぐか、
それとも今の安定した仕事を続けるか。

「親の会社は小さいけれど、私がいなけれ
ば店を閉めなければならない。でも、もし継いでも
失敗したら、家族に申し訳ない」。

専門家は言う。「どちらを選んでも、正解はない。
大事なのは、自分が何を大切にしたいかだ。
決めたら、その道で精一杯やればいい」。

佐藤さんは、まだ迷っている。
「決断できるのは、自分しかいない」と呟く。
```

### Перевод

| Японский | Русский |
|----------|---------|
| はざま | 峡間 | промежуток, между |
| 決断 | けつだん | решительный выбор |
| 迫られる | せまられる | быть вынужденным, оказаться перед |
| 継ぐ | つぐ | наследовать（дело) |
| 閉める | しめる | закрывать |
| 申し訳ない | もうしわけない | виноват, мне стыдно |
| 正解 | せいかい | правильный ответ |
| 精一杯 | せいいっぱい | изо всех сил |
| 呟く | つぶやく | бормотать, шептать |

### Разбор грамматики

```
継ぐか、続けるか → か～か（ли… или…)
私がいなければ閉めなければならない → ば + なければならない（двойной条件)
どちらを選んでも、正解はない → ても（неважно что выбрать)
決めたら、その道で精一杯やればいい → たら + ばいい（совет)
決断できるのは、自分しかいない → のは（номинализация) + しか…ない
```

### Вопросы

1. Какая дилемма стоит перед Сато?
2. Что говорят специалисты об обоих выборах?
3. Найдите конструкцию「どちらを選んでも」и объясните её.
4. Как понять фразу「決断できるのは、自分しかいない」?
