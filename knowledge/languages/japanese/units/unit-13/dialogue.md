# Unit 13 — Диалог: もしも話（Разговор «а если бы»)

## Ситуация

Юки пришла к Алисе с новостью：она думает уволиться и открыть своё кафе. Танака скептичен. За чашкой чая разгорается спор, в котором каждая реплика —— упражнение на условия: если бы, когда бы, даже если бы.

## Диалог

```
ユキ：聞いて。私、会社を辞めて、カフェを開こうと思ってるの。
アリス：えっ！急だね。何かあったの？
ユキ：毎日残業ばかり。もっと自由に働きたいの。
タナカ：でも、お金はあるの？開店資金は三百万くらいかかるって。
ユキ：貯金があれば、なんとかなると思う。
タナカ：甘いなあ。もし失敗したら、どうするつもり？
ユキ：失敗しても、経験になるじゃない。
タナカ：経験だけでは食べていけないよ。場所が見つかれば
　　　　まだしも、今は不動産も高いし…。
アリス：二人とも、落ち着いて。ユキちゃんが本気なら、
　　　　まずアルバイトでカフェを勉強すればいいんじゃない？
ユキ：それもそうね。アリスさんの店で教えてもらおうかな。
タナカ：よし、それなら応援するよ。夢は大切だからね。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 会社を辞めて | уволиться с работы |
| 開店資金 | стартовый капитал |
| 貯金があれば、なんとかなる | Если есть накопления， как-нибудь выкрутимся |
| 失敗しても、経験になる | Даже если провалюсь —— опыт |
| 経験だけでは食べていけない | Опытом сыт не будешь |
| 場所が見つかればまだしも | Если бы нашлось место —— ладно бы |
| 本気なら | Если она серьёзно |
| 応援するよ | Поддержу тебя |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 辞める | やめる | увольняться |
| 開店資金 | かいてんしきん | капитал на открытие |
| 貯金 | ちょきん | накопления |
| 甘い | あまい | наивный（перен.) |
| 不動産 | ふどうさん | недвижимость |
| 本気 | ほんき | серьёзные намерения |
| 応援する | おうえんする | поддерживать |
| 夢 | ゆめ | мечта |

## Культурная заметка

**Японский страх перемен（リスク回避)**: фраза「まだしも」и подсчёт рисков до мечты —— типично японский стиль спора. Но молодое поколение всё чаще выбирает「起業」（предпринимательство): за последние годы число молодых кафе-владельцев выросло вдвое. Спор Юки и Танаки —— классика поколений.

## Диалог 2: 夢を語る夜（Вечер мечтаний）

### Ситуация

Через полгода после спора Юки уже работает в кафе Алисы и учится. Поздно вечером, убирая зал, они говорят о будущем.

```
アリス：今日も大変だったね。疲れてない？
ユキ：ううん、楽しい。ホントに自分が
　　　やりたかったことを、やってるんだ。
アリス：それなら、この仕事を選んでよかったね。
ユキ：うん。もしアリスさんが誘ってくれなかったら、
　　　今でも会社で残業してたと思う。
アリス：ユキちゃんはいつでもやろうと思えば
　　　できたんだよ。ただ、決心する勇気が
　　　なかっただけ。
ユキ：そうかな。今は、この日々があってよかったって
　　　心から思うよ。
アリス：じゃあ、いつ自分で店を持つつもり？
ユキ：三年で貯金をためて、五年で開きたいな。
アリス：いい計画だね。応援してるよ。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 疲れてない？ | Ты не устала? |
| 自分がやりたかったこと | То, что я хотела делать сама |
| この仕事を選んでよかった | Хорошо, что я выбрала эту работу |
| 誘ってくれなかったら | Если бы ты не позвала меня |
| 決心する勇気 | Смелость решиться |
| 心から思うよ | От всей души так думаю |
| 三年で貯金をためて | За три года накоплю денег |
| 応援してるよ | Я в тебя верю |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 疲れる | つかれる | уставать |
| 楽しい | たのしい | приятный, весёлый |
| 誘う | さそう | приглашать, звать |
| 決心 | けっしん | решимость, твёрдое решение |
| 勇気 | ゆうき | смелость |
| ためる | — | копить（деньги) |
| 心から | こころから | от души |
| 持つ | もつ | иметь, держать |

### Разбор грамматики

```
優しくなったら、また会えるね。→ たら（конкретное будущее）
誘ってくれなかったら、今でも残業してた。→ もし～たら в прошедшем（контрфакт: если бы не）
やろうと思えばできた。→ ば（логика) — «если захотеть, мог бы»
三年で貯金をためて、五年で開きたい。→ て-форма как «сначала…, потом…»
```
Обратите внимание на もし～たら + だった（прошедшее）—— это конструкция «что было бы, если»（контрфактив）, очень частый приём в мечтаниях.

## Диалог 3: お金の貸し借り（Деньги в долг）

### Ситуация

Танака пришёл к Юки просить денег взаймы на стартап. Юки вспоминает, как сама боялась рисков, и учит Танаку думать о последствиях.

```
タナカ：ユキちゃん、ちょっと相談があるんだけど。
ユキ：どうしたの？顔色が悪いけど。
タナカ：実は、急に店を持ちたくて、
　　　　君からお金を借りられないかな…。
ユキ：えっ、いくら必要なの？
タナカ：五百万。銀行は貸してくれないし、
　　　　君しか頼る人がいないんだ。
ユキ：待って。理由も計画もなしに、
　　　　借りるわけにはいかないよ。
タナカ：チャンスは今しかないと思って…。
ユキ：分かるけど、その気持ち、私も昔持ってた。
　　　でも、まず計画書を作って、リスクも
　　　考えた方がいいよ。それからまた話そう。
タナカ：そうだな…。急いでたのは確かだけど、
　　　　君の言う通りだ。計画を練ってくる。
ユキ：応援はするよ。でもお金は、計画のあとで。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 相談があるんだけど | Есть у меня просьба, понимаешь |
| 顔色が悪い | Плохой цвет лица |
| お金を借りられないかな | Не одолжишь ли мне денег? |
| 銀行は貸してくれないし | Банк не даёт, к тому же… |
| 君しか頼る人がいない | Нет никого, кроме тебя, на кого опереться |
| 借りるわけにはいかない | Не могу позволить себе одалживать |
| チャンスは今しかない | Такой шанс бывает только сейчас |
| 計画を練ってくる | Проработаю план |
| お金は、計画のあとで | Деньги — уже после плана |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 相談 | そうだん | совет, консультация |
| 顔色 | かおいろ | цвет лица |
| 必要 | ひつよう | необходимость |
| 頼る | たよる | полагаться, опираться |
| 計画書 | けいかくしょ | бизнес-план |
| リスク | — | риск |
| 後 | あと | после |
| チャンス | — | шанс |

### Разбор грамматики

```
借りられないかな → 可能形 借りられる + ないかな（мягкая просьба）
貸してくれないし → てくれない + し（перечисление причин) — «не даёт, и к тому же»
君しか頼る人がいない → しか…ない（никто кроме)
借りるわけにはいかない → わけにはいかない（внутренний запрет)
確かだけど → だけど（уступка: верно, но…)
```

## Диалог 4: 失敗からの学び（Урок из неудачи）

### Ситуация

Прошло три года. Юки открыла своё первое кафе, но оно оказалось малолюдным. Она закрывает его с мыслью о том, чему научилась. Алиса приходит поддержать.

```
アリス：ここ、今日で最後なんだね。
ユキ：うん。失敗したけど、後悔はしてない。
アリス：そう言えるのが、もう立派だよ。
ユキ：ばかりいたら、場所はいいのに
　　　　借りる人がいなかった。
アリス：最初から分かるわけないよ。
ユキ：そうだね。でも、ここで何でも学べた。
　　　次に開くときは、もっと調査してから
　　　決めたい。
アリス：その経験、きっと次に生きるよ。
ユキ：うん。失敗したからこそ、次が分かる。
　　　また一から始めるね。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 今日で最後 | Сегодня уже последний день |
| 後悔はしてない | Я не жалею |
| そう言えるのが立派だ | Уже то, что ты так говоришь, — достойно |
| 借りる人がいなかった | Не было желающих арендовать |
| 最初から分かるわけない | Откуда было знать заранее |
| 何でも学べた | Всему я здесь научилась |
| 調査してから決めたい | Хочу сначала изучить, потом решать |
| 次に生きるよ | Пригодится в следующий раз |
| 失敗したからこそ | Именно благодаря неудаче |
| 一から始める | Начать с самого начала |

### Новые слова

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 最後 | さいご | последний |
| 立派 | りっぱ | достойный, замечательный |
| 借り手 | かりて | арендатор |
| 学ぶ | まなぶ | учиться |
| 調査 | ちょうさ | исследование |
| 経験 | けいけん | опыт |
| 生きる | いきる | жить、（перен.) пригодиться |
| 一から | いちから | с нуля |

### Разбор грамматики

```
今日で最後 → で（предел, крайняя точка времени)
後悔はしてない → してない разговорное от していない
場所はいいのに → のに（вопреки: место хорошее, а желающих нет)
分かるわけない → わけがない（никак не могло быть известно)
調査してから決めたい → てから（сначала…, а потом…)
失敗したからこそ → からこそ（именно благодаря тому, что…)
```

Этот диалог — обратная сторона темы юнита: и мечта, и риск имеют цену. Грамматика「からこそ」и「てから」помогает выразить, что неудача — не конец, а ступень к успеху.
