# Unit 15 — Диалог: 噂の真相（Правда о слухах)

## Ситуация

По кампусу ползёт слух：Кэнта и Юки встречаются！Алиса узнаёт об этом от трёх разных людей —— и каждый передаёт информацию по-своему：кто-то через そうだ， кто-то через らしい， кто-то через разговорное って. В конце дня Алиса решает спросить у самих «виновников».

## Диалог

```
同級生Ａ：アリスさん、知ってる？ケンタとユキ、
　　　　　付き合ってるんだって。
アリス：えっ、本当？どこで闻いたの？
Ａ：バイト先の子から闻いた。確かだったよ。

同級生Ｂ：ねえ、聞いた？二人は来月、京都に
　　　　旅行するらしいよ。
アリス：へえ、そうなんだ。でも、確かな情報なの？
Ｂ：うん、ユキの友達が言ってたから、たぶん事実だと思う。

アリス：（独り言）噂は噂。直接本人に聞くのが一番だよね。

夕方、カフェで。

アリス：ケンタさん、実は…キャンパスで噂になってるみたいです。
　　　　ユキさんと付き合っているって。
ケンタ：えーっ、違う違う！ただ、共通の友人の結婚式で
　　　　一緒に幹事を頼まれただけなんだ。
アリス：そうだったんですか。
ケンタ：噂というのは、こうやって膨らむんだよ。
　　　　「一緒に仕事をした」→「デートした」→「来月結婚」。
アリス：面白いですね。情報の伝言ゲームみたい。
ケンタ：その通り。だから、最後は自分の目で確認すること。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 付き合ってるんだって | Говорят, они встречаются! |
| 確かだった | Точно было |
| 旅行するらしいよ | Кажется, едут в путешествие |
| たぶん事実だと思う | Думаю, это факт |
| 噂になってるみたい | Похоже, стало слухом |
| 幹事を頼まれた | Нас назначили организаторами（пассив!) |
| 膨らむ | Раздуваться |
| 伝言ゲーム | Испорченный телефон |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 噂 | うわさ | слух |
| 真相 | しんそう | правда, истина |
| 付き合う | つきあう | встречаться |
| 情報 | じょうほう | информация |
| 直接 | ちょくせつ | напрямую |
| 本人 | ほんにん | сам человек |
| 幹事 | かんじ | организатор мероприятия |
| 頼まれる | たのまれる | получить просьбу（пассив) |
| 膨らむ | ふくらむ | раздуваться |
| 確認する | かくにんする | проверять |

## Культурная заметка

**Умэвако（生き証人) правило японских слухов:** информация проходит через 2–3 человека и меняется до неузнаваемости. Отсюда пословица「噂をすれば影」（помянешь черта — он тут же) и привычка заканчивать непроверенное「って言ってたけど、ほんとうかな」—— «так говорили, но правда ли».

# Итоговые диалоги всего курса（разбор от Юнита 11 к 15)

> Ниже — сценарные диалоги, повторяющие ключевые конструкции N3-трека: пассив, каузатив, кэйго, условия и передачу информации.

## Диалог 2 — Подработка（пассив・使役・敬語）

### Ситуация

Юка впервые работает в кафе. Начальник даёт указания, старший коллега заставляет её учиться, а вечером приходит важный гость — и ей нужно говорить вежливо.

### Диалог

```
店長：ユカさん、今日のシフトは遅いから、早く来てもらえますか？
ユカ：はい、分かりました。何時までに来ればいいですか？
店長：九時までに来てください。開店前に準備をしてもらいます。

先輩：新入りのユカちゃん、何度も注意されてるよ。
ユカ：すみません、まだ慣れなくて。
先輩：大丈夫。でも明日の朝は早く来させられるよ。
ユカ：えっ、早く来させられるんですか？
先輩：うん、店長がみんなに早出をさせるから。

（夕方、大事なお客様が来店)
ユカ：いらっしゃいませ。お席にご案内いたします。
客 ：ありがとう。何かおすすめはある？
ユカ：本日のスープ、大変好評でございます。
客 ：じゃあそれをお願いします。あと、お水も。
ユカ：かしこまりました。少々お待ちくださいませ。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 来てもらえますか | てもらう + 可能 = «не могли бы вы прийти» |
| 何時までに来ればいい | ば conditional = «к какому времени прийти» |
| 注意されてる | пассив される = «получаю замечания» |
| 来させられる | каузатив-пассив = «меня заставляют прийти» |
| 早出をさせる | каузатив させる = «заставляет выходить раньше» |
| ご案内いたします | кэндзёго いたす = «могу проводить» (принижение себя) |
| 好評でございます | である-style вежливость = «очень известен» |
| 少々お待ちくださいませ | сонкэйго = «прошу подождать» |

## Диалог 3 — Планы на отпуск（条件・たら・なら）

### Ситуация

Акира и Мика обсуждают, куда поехать летом. Акира мечтает о Хоккайдо, Мика советует Киото.

### Диалог

```
アキラ：夏休み、どこに行く？
ミカ ：まだ決めてない。アキラは？
アキラ：北海道に行こうと思ってる。涼しいから。
ミカ ：いいね。でも、北海道なら冬のほうがきれいだよ。
アキラ：えっ、どうして？
ミカ ：雪の景色がすごくきれいなんだ。夏より冬のほうが好き。
アキラ：そうか。じゃあ、もし時間があったら、秋に行きたくなった。
ミカ ：おすすめ！でも、混んでたら早く予約したほうがいいよ。
アキラ：うん、飛行機を早めに予約しておくね。
ミカ ：よかったら、一緒に行かない？
アキラ：いいね、行こう！楽しみだな。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 行こうと思ってる | волевое + думаю = «думаю поехать» |
| 北海道なら | なら = «если речь о Хоккайдо» |
| 冷たい | い-прил. = «прохладный» |
| もし時間があったら | たら conditional = «если будет время» |
| 混んでたら | て-form + たら = «если будет людно» |
| 予約したほうがいい | совет = «лучше забронировать» |
| 予約しておく | ておく = «заранее забронировать» |
| よかったら | «если удобно» = «если не против» |

## Диалог 4 — Итоговый повтор（всё вместе：噂＋条件＋敬語）

### Ситуация

Перед выпускным вечером Алиса, Кэнта и Юка обсуждают, что говорят о предстоящем событии, договариваются о времени и вежливо уточняют детали у организаторов.

### Диалог

```
アリス：ねえ、聞いた？明日の卒業パーティー、あのホテルで
　　　　行われるらしいよ。
ケンタ：へえ、そうなの。町で噂になってたけど、本当だったんだ。
ユカ ：私は幹事からLINEをもらったよ。六時からだって。
アリス：そうですか。じゃあ、六時までに会場に着いていればいいね。
ケンタ：そうだね。もし遅れそうだったら、幹事に連絡しよう。
ユカ ：よかったら、私の車に乗らない？送ってあげるよ。
アリス：本当？助かるわ。でも、送ってもらうのは悪いかな。
ユカ ：大丈夫、帰りもみんな一緒だし。
アリス：（後で幹事に）明日、六時に伺ってもよろしいでしょうか？
幹事 ：はい、どうぞ。お気をつけてお越しください。
アリス：ありがとうございます。それでは、よろしくお願いいたします。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 行われるらしい | пассив + らしい = «говорят, пройдёт» |
| 噂になってた | なる + ている = «стала слухом» |
| もらった | もらう = «получил» |
| 六時までに着いていれば | ば = «если прибуду к шести» |
| 遅れそうだったら | そう（вид) + たら = «если похоже, что опоздаю» |
| 連絡しよう | волевое = «давай свяжемся» |
| 送ってあげる | あげる = «подвезу (тебе)» |
| 送ってもらう | もらう = «чтобы меня подвезли» |
| 伺ってもよろしいでしょうか | кэндзёго + вежливое «можно ли» |
| よろしくお願いいたします | кэндзёго いたす = «прошу, полагаюсь на вас» |

# Дополнительные диалоги: техника передачи слуха в разных кругах

## Диалог 5 — Офисный слух（って・そうだ・ということだ)

### Ситуация

Утром в офисе тана-румолл. Танака и Судзуки перешёптываются о кадровых новостях: говорят, начальника повышают. Сплетни передаются по цепочке — от って к более сдержанному ということだ.

### Диалог

```
田中：ねえ、聞いた？部長、来月で課長に昇進するって。
鈴木：えっ、マジで？どこからの話？
田中：庶務課の高橋さんの妹が総務にいて、その総務から
　　  聞いたんだって。
鈴木：ふーん…それって横流しの噂でしょ？
田中：いや、部長自身が今朝、「うちに辞令が来るらしい」って
　　  言ってたから、相当確からしいよ。
鈴木：そうなの？じゃあ、退職するっていう噂は？
田中：あれは間違い。人事異動のメールで確認した。
　　  つまり、部長は残るということだ。
鈴木：へえ。人の噂って、ほんとに大きくなるんだね。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 高橋さんの妹が…聞いたんだって | цепочка: «говорят-говорят-говорят» через って |
| 横流しの噂 | слух из вторых-третьих рук（横流し = «перетекающий») |
| 辞令が来るらしい | らしい — полууверенность в словах самого шефа |
| 確からしい | らしい от な-прил. 確か = «похоже, что достоверно» |
| 残るということだ | ということだ — вывод-суть из фактов |
| 人の噂 | сплетни про людей（человеческая молва) |

## Диалог 6 — SNS-фейк и его проверка（とか・によって・っぽい)

### Ситуация

В групповом чате всплыла вирусная новость «завтра отменяют занятия». Юки и Рё решают проверить её, а не пересылать дальше.

### Диалог

```
リン：ちょっと、聞いて！明日、学校休みだって！休講だとか！
レオ：それ、kimichan__というアカウントが上げてた
　　  スクリーンショットを回してるだけだよ。ヤバいっぽいね。
リン：え、でもみんな友達の友達から聞いてるって言ってたよ。
レオ：友達の友達？それこそ危険信号だよ。
　　  さっき大学の公式サイトを見たけど、休講の知らせは
　　  出ていないとのことだった。
リン：じゃあ、あの投稿ってデマなの？
レオ：おそらくね。ツイートの写真、編集してあるっぽいし。
　　  確認するまでは、回さないほうがいいよ。
リン：たしかに。情報源を確かめよう。正しく得られた情報だけ
　　  を信じることだね。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 休講だとか | とか — «то ли отменили, то ли что» (неточность содержания) |
| kimichan__というアカウント | という для идентификации имени/названия |
| 回してるだけ | だけ = «всего лишь пересылают» |
| ヤバいっぽい | っぽい — субъективная оценка «похоже, мутно» |
| 出ていないとのことだった | とのこと + た = официальное «значилось, что не вывешено» |
| 編集してあるっぽい | てある (сделано намеренно) + っぽい |
| 信じることだね | ことだ = «надо/лучше верить» (совет-норма) |

## Диалог 7 — Семейный пересказ новостей（とのことだ・そうだ.)

### Ситуация

Вечером звонит бабушка издалека и через маму передаёт семейные новости. Внук переспрашивает, мама пересказывает сначала разговорно, потом к вечеру — официально для отца.

### Диалог

```
母 ：おばあちゃんから電話があったの。来月、東京へ
　　  引っ越すそうよ。
息子：え、おばあちゃんが？東京に？
母 ：うん。おじさんがそっちで新しい仕事をすることになって、
　　  もう住む家も決まったとのこと。
息子：へえ、急だね。そういう話は、どこで聞いたの？
母 ：おばあちゃん本人が言ってたわよ。
　　  それに、今朝のメールには「来月から」って書いてあったし。
父 ：（帰宅）今、何の話だい？
母 ：東京の話よ。義母から連絡があって、皆で引っ越す
　　  そうなの。
父 ：そうか。じゃあ、次の休みに遊びに行こう。
息子：賛成！早く新住所を聞かなくちゃ。
母 ：じゃあ、あとで電話で確認しておくわね。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 引っ越すそうよ | そう（слух) — мама передаёт слова бабушки |
| ...とのこと | とのこと — официальный пересказ для важных фактов |
| 本人が言ってた | 本人 (сама) + てた (говорила) — усиление достоверности |
| 書いてあった | てある — намеренно записано |
| 確認しておくわ | ておく — заранее проверить |
| 賛成！ | разговорное согласие «поддерживаю!» |

## Диалог 8 — Сплетня и недоговорённость（ったら・なんて・てっきり)

### Ситуация

На обеде две подруги обсуждают новость о помолвке общей знакомой. Одна была уверена (てっきり), что у той другой парень, а оказалось — всё иначе.

### Диалог

```
ミナ：ねえ、知ってる？あゆみ、婚約したんだって！
ナナ：えーっ、マジ？相手は誰？
ミナ：大学時代のサークルの先輩なんだって。
　　  でも、誰なのかは教えてくれなかった。
ナナ：謎すぎる。てっきり、隣の課の佐藤くんと付き合ってる
　　  と思ってたのに。
ミナ：それがさ、その佐藤くんが「彼女に彼氏なんていない」
　　  って言ってたらしくて。
ナナ：なにそれ、こじらせてるね。噂話なんて、だいたい
　　  本当と違うんだから。
ミナ：でも私、あゆみ本人から「相手がいる」って聞いたよ。
ナナ：本人なのに隠す？あゆみったら、意外と秘密主義なんだ。
ミナ：とにかく、式に呼ばれたら、そのときに確認しよう。
ナナ：それ、いいね。直接聞くのが一番だわ。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 婚約したんだって | ん (объяснение) + だって (разговорный слух) |
| てっきり…と思ってた | てっきり = «была уверена (а оказалось нет)» |
| 言ってたらしくて | らしい внутри たら: «вроде он говорил» |
| こじらせてる | こじる = «накручивает/усложняет» |
| 噂話なんて | なんて — преуменьшение «да уж эти сплетни» |
| 本人なのに | のに — «несмотря на то, что сама» |
| あゆみったら | ったら — удивление/укор про человека |

# Финальные диалоги-повторение (весь курс)

> Три итоговых сценария, объединяющих все ключевые конструкции N3-трека: пассив, каузатив, кэйго, условия и передачу информации внутри одного разговора.

## Диалог 9 — Интервью о работе（敬語・伝聞・条件 вместе)

### Ситуация

Алиса проходит собеседование на подработку. Менеджер вежливо спрашивает, она скромно отвечает, а после собеседования пересказывает подробности подруге с использованием форм передачи информации.

### Диалог

```
面接官：では、どうしてこのアルバイトに応募したのですか？
アリス：はい、接客の経験を積みたいと思いまして。
面接官：平日の夜と土日、どちらが多いですか？
アリス：土日は他の用事がありますが、平日ならいつでも伺えます。
面接官：分かりました。では、健康診断の書類を提出していただけますか？
アリス：はい、来週までにお持ちします。
面接官：結果は一週間以内にメールでお知らせします。

（後で、友達に）
アリス：さっき面接に行ってきたよ。応募した店、
　　　　接客の経験が積めるらしい。
友達：どうだった？
アリス：健康診断の書類を出せって言われた。
　　　　来週までに持っていけばいいそうだ。
友達：面接官、優しそうだった？
アリス：うん、丁寧な人だったよ。結果は来週だって。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 応募したのです | の (объяснение) + です = «(дело в том, что) подала заявку» |
| 積みたいと思います | たい + と思う = «думаю, что хочу накопить» |
| 平日なら伺えます | なら + кэндзёго 伺う = «если будни, могу подойти» |
| 提出していただけますか | 〜ていただく + 可能 = «могли бы вы представить»（кэндзёго-просьба) |
| お持ちします | кэндзёго お〜する = «принесу» |
| 経験が積めるらしい | 可能 + らしい = «вроде можно накопить опыт» |
| 出せって言われた | пассив + って = «мне сказали, что сдать» |
| 持っていけばいいそうだ | ば + いい + そうだ = «говорят, надо принести» |
| 優しそうだった | そう（вид) = «выглядел добрым» |
| 結果は来週だって | って = «говорят, результат на следующей неделе» |

## Диалог 10 — Пересказ новостей семье（とのこと・によると・って)

### Ситуация

Сын пересказывает родителям новости о важном событии в городе. Сначала разговорно для мамы, потом официально для отца.

### Диалог

```
息子：ねえお母さん、駅前に新しい図書館ができるんだって。
母 ：へえ、それは楽しみだね。
息子：市のホームページによると、来年の春に開館するそうだよ。
母 ：そうなの。じゃあ、開館したら一緒に行きましょう。
息子：いいね！でも、工事が遅れてるって噂もあるらしい。
母 ：それは本当なの？
息子：うん、地元の掲示板に書いてあった。ただ、公式発表は
　　　まだないって言ってたから、信じていいか分からない。
父 ：（帰宅）ところで、新しい図書館の件、どうなった？
息子：市の発表によれば、来年春に開館予定とのことです。
父 ：そうか。楽しみだな。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| できるんだって | ん + だって = «говорят, появится» |
| によると…そうだ | источник + форма слуха |
| 開館したら | たら = «если/когда откроется» |
| 遅れてるって噂 | слух в виде って |
| なってるらしい | становится + らしい |
| 書いてあった | てある = «было написано» |
| 公式発表はまだないって | って = «говорят, ещё нет» |
| によれば…とのことです | формальный источник + официальная передача |
| 開館予定 | запланированное открытие |

## Диалог 11 — Лесная прогулка（条件・使役・感想)

### Ситуация

Рё и Мика гуляют в горах. Обсуждают планы, один предлагает идти быстрее, другой напоминает о правилах. Комбинируют условия и советы.

### Диалог

```
レオ：今日は天気がいいね。山頂まで行かない？
ミカ：いいね。でも、足元が濡れてたら滑りやすいよ。
レオ：大丈夫、ゆっくり歩けばいいから。
ミカ：そうだね。水筒を持ってきておいて正解だった。
レオ：そうしよう。もし疲れたら言ってね。
ミカ：うん。帰りは下りだから、途中で休めば大丈夫だよ。
レオ：頂上に着いたら、お弁当を食べよう！
ミカ：賛成。早く行きたいけど、無理はしないでね。
レオ：分かった。焦らずに行こう。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 山頂まで行かない | まで = «до вершины» |
| 濡れてたら | て-form + たら = «если намокшие» |
| 滑りやすい | 〜やすい = «легко скользить (скользко)» |
| 歩けばいい | ば + いい = «достаточно идти» |
| 持ってきておいて正解 | ておく + 正解 = «правильно, что заранее захватил» |
| 疲れたら言って | たら + совет = «если устанешь, скажи» |
| 休めば大丈夫 | ば = «если отдохнём, всё в порядке» |
| 頂上に着いたら食べよう | たら + волевое = «как дойдём, поедим» |
| 無理はしないで | 〜ないで = «не переусердствуй» |

## Диалог 12 — Сплетня на работе（все формы 伝聞）

### Ситуация

Утренний перерыв. Три сотрудника пересказывают одну и ту же новость разными способами — от официального до «на ушко».

### Диалог

```
佐藤：ねえ、聞いた？来月、社長が新しいプロジェクトを
　　　始めるそうだよ。
田中：そうなの？でも、私たちも参加するって聞いたよ。
佐藤：確か、部長がそう言ってた。でも詳しいことは
　　　まだ発表になってないらしい。
田中：じゃあ、今日の会議で話が出るかもしれないね。
佐藤：どうだろう。でも、もし聞けそうだったら、
　　　教えてね。
山田：（後で）社内のお知らせによると、来月から
　　　新プロジェクトを開始するとのことです。
田中：おお、正式に決まったんだ。
山田：会議で詳しい説明があるそうです。参加希望者は
　　　来週までに申し込むとのこと。
佐藤：じゃあ、早速申し込んでおいたほうがいいね。
```

### Перевод и разбор

| Японский | Разбор |
|----------|--------|
| 始めるそうだ | そうだ（слух) = «говорят, начнёт» |
| 参加するって聞いた | って + 聞く = «слышал, что участвуем» |
| 出版になってないらしい | らしい = «вроде ещё не объявлено» |
| 話が出るかもしれない | 〜かもしれない = «может, зайдут к разговору» |
| 聞けそうだったら | 可能 + そう + たら = «если сможешь узнать» |
| によると…とのことです | официальная передача с источником |
| 正式に決まったんだ | んだ (объяснение) |
| あるそうです | そうだ = «говорят, будет» |
| 申し込むとのこと | とのこと = «имею сообщить, что подать заявку» |
| 申し込んでおいたほうがいい | ておく + ほうがいい = «лучше подать заранее» |
