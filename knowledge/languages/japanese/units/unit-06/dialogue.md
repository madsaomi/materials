# Unit 6 — Диалог: 電話で予定を相談する (Договариваемся по телефону)

## Ситуация

Алиса хочет пригласить Танаку на выходных в музей. Она звонит ему. По телефону нельзя показывать жестами — приходится говорить ясно. В этом диалоге отрабатываются формы «сейчас делаю» (〜ている) и приглашения (〜ませんか / 〜ましょう).

## Диалог

```
アリス：もしもし、田中さん？アリスです。
田中：あ、アリスさん！どうしたの？
アリス：今、何をしていますか。
田中：部屋を掃除しているところだよ。
アリス：そうなんだ。実は、土曜日に美術館へ行きたいんですが、一緒にどうですか。
田中：美術館かあ。いいね！何時に行く？
アリス：十時に駅で会いませんか。
田中：十時はちょっと早いなあ。十一時なら大丈夫。
アリス：分かりました。じゃ、十一時に駅の前で待っています。
田中：うん、チケットはもう買ってある？
アリス：いいえ、まだです。今日買っておきます。
田中：僕も後でネットで調べてみるよ。天気が心配だけど。
アリス：大丈夫ですよ。予報では晴れるそうです。
田中：じゃ、日曜日はゆっくり休むとしよう。
```

## Перевод

| Японский | Русский |
|----------|---------|
| もしもし | Алло |
| 今、何をしていますか | Что ты сейчас делаешь? |
| 部屋を掃除しているところ | Как раз убираю комнату |
| 実は | Вообще-то, если честно |
| 一緒にどうですか | Как насчёт пойти вместе? |
| 十時に駅で会いませんか | Не встретиться ли в 10 у станции? |
| 十一時なら大丈夫 | Если в 11 — нормально |
| 駅の前で待っています | Буду ждать перед станцией |
| チケットはもう買ってある | Билеты уже куплены? |
| 買っておきます | Куплю заранее |
| ネットで調べてみる | Посмотрю в интернете |
| 晴れるそうです | Говорят, будет солнечно |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 電話 | でんわ | телефон |
| 予定 | よてい | план |
| 掃除 | そうじ | уборка |
| 美術館 | びじゅつかん | художественный музей |
| チケット | — | билет |
| 予報 | よほう | прогноз |
| 晴れる | はれる | быть ясным (о погоде) |
| 心配 | しんぱい | беспокойство |
| 待つ | まつ | ждать |
| 会う | あう | встречаться |

## Культурная заметка

**もしもし** — универсальное «алло» по телефону. По японскому этикету первым представляется звонящий: сначала «もしもし», затем своё имя — даже если собеседник вам хорошо знаком. Номер телефона набирают и на работе, и дома, но деловой разговор начинают не с «もしもし», а с названия компании.

**Договорённости важны:** опаздывать на встречу в Японии неприемлемо. Прийти за 5–10 минут до назначенного времени — норма. Если задерживаетесь, обязательно предупредите по телефону — молчать считается грубостью.

## Диалог 2: 出張の相談 (Обсуждаем командировку)

> Ситуация: Алиса работает в одной компании с Ямадой-сан и звонит ему, чтобы согласовать сроки командировки в Осаку.

```
アリス：もしもし、山田さん？アリスです。今、大丈夫ですか。
山田： あ、アリスさん。大丈夫ですよ。何か用事ですか。
アリス：来月の出張の予定なんですが、相談したいことがあります。
山田： はい、どうぞ。
アリス：来月の十五日から大阪へ出張することになりました。会社の資料を持って行く予定です。
山田： なるほど。何日まで大阪にいる予定ですか。
アリス：二十日までです。それまでに、取引先に連絡しておきたいんですが。
山田： 分かりました。折り返し、先方に電話して、日程を確認しておきますね。
アリス：ありがとうございます。お願いします。
山田： 来週の月曜日までに、また連絡しますね。
アリス：はい、待っています。それでは、失礼します。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 今、大丈夫ですか | Сейчас удобно? |
| 何か用事ですか | Есть какое-то дело? |
| 出張の予定なんですが | По поводу плана командировки |
| 十五日から大阪へ | С 15-го числа в Осаку |
| 出張することになりました | Так вышло, что еду в командировку |
| 取引先に連絡して | Связаться с партнёрами |
| 日程を確認しておきます | Заранее сверю расписание |
| それでは、失礼します | На этом до свидания |

### Разбор

**〜ことになりました** (出張することになりました) — «так решилось внешне», решение пришло не от меня лично (см. грамматику §21).

**〜ておきたい** (連絡しておきたい) — ておく + たい «хочу заранее сделать»: желание выполнить действие впрок.

**折り返し** — «в ответ, обратным звонком». Ключевое слово деловых переговоров (см. словарь: 折り返し電話する).

## Диалог 3: 遅刻の電話 (Звонок из-за опоздания)

> Ситуация: Юки опаздывает на встречу с Алисой и заранее предупреждает её по телефону — как этого требует японский этикет.

```
ゆき：もしもし、アリス？ゆきだけど。
アリス：ゆき？どうしたの？もう駅に着いた？
ゆき：ごめん、電車が遅れているんだ。まだ家を出ていないの。
アリス：え、どうして？
ゆき：寝坊しちゃって、準備に遅れてしまった。
アリス：そうなんだ。今、何をしているの？
ゆき：駅に向かっているところだけど、あと三十分はかかりそう。
アリス：分かった。じゃ、先にカフェで待ってるね。ゆっくりで大丈夫。
ゆき：ごめんね。着いたら、また電話するね。
アリス：うん、気をつけて来てね。
```

### Перевод

| Японский | Русский |
|----------|---------|
| 電車が遅れているんだ | Дело в том, что поезд опаздывает |
| まだ家を出ていない | Ещё не вышла из дома |
| 寝坊しちゃって | Проспала, и вот... |
| 準備に遅れてしまった | Задержалась со сборами |
| 駅に向かっているところ | Как раз иду к станции |
| あと三十分はかかりそう | Понадобится ещё минут тридцать |
| 先にカフェで待ってるね | Буду ждать тебя в кафе первой |
| 着いたら、また電話するね | Как приеду, снова позвоню |

### Разбор

**電車が遅れている** — ている в значении «находится в состоянии опоздания»: прогресс уже идёт.

**しちゃって / しまった** (寝坊しちゃって) — сокращение от 〜てしまう «к сожалению, получилось так». 寝坊してしまった → 寝坊しちゃった (разговорное).

**向かっているところ** — классический ているところ «как раз сейчас иду».

**〜そう** (かかりそう) — здесь не «по слухам», а **«кажется, будет так»** (по внешнему впечатлению). Сравните с そうです из грамматики §6.

**〜たら** (着いたら) — условное «когда приеду (и тогда)». Подробнее в Unit 13.

## Диалог 4: 予約の確認 (Подтверждение брони)

> Ситуация: Алиса звонит в ресторан, чтобы подтвердить бронь столика на завтрашний вечер.

```
店員：  はい、田中レストランでございます。
アリス：もしもし、アリスと申します。明日の夜、予約した者ですが。
店員：  承知しました。お名前と予約の時間をお願いします。
アリス：アリスです。時間は七時で予約してあります。
店員：  確認いたします。少々お待ちください。…はい、七時、お二人様でお間違いないですか。
アリス：はい、二人です。あ、一つ確認したいんですが、喫煙席と禁煙席、どちらがいいですか。
店員：  禁煙席をお願いします。
アリス：承知いたしました。では、明日七時にお待ちしております。
店員：  ありがとうございます。失礼します。
```

### Перевод

| Японский | Русский |
|----------|---------|
| でございます | есть/является (очень вежливое です) |
| 予約した者ですが | Я тот, кто забронировал |
| 予約してあります | Забронировано (состояние, намеренно) |
| 確認いたします | Проверю сейчас |
| お二人様 | На двоих (уважительно) |
| お間違いないですか | Верно ли, что... (вежливая проверка) |
| 受動席 | место гостя (букв. «место принятия») |
| お待ちしております | Будем вас ждать (скромно) |

### Разбор

**予約した者ですが** — 者 (моно) «человек, лицо» — скромное самоназвание: «я тот самый, кто...».

**予約してあります** — てある «намеренное состояние»: бронь создана специально и сохраняется (грамматика §16).

**確認いたします / 承知いたしました** — итасу — скромная форма する. Стандарт вежливого обслуживания.

**お二人様** — счётный суффикс 人 (ни) + уважительный 様. Ресторанный этикет.
