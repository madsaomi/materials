## II. Грамматика — ている

**A. Образуйте форму ている (прогресс / состояние).**

| Словарная | ている | Перевод |
|-----------|--------|---------|
| 書く | ＿＿＿＿＿＿ | сейчас пишет |
| 食べる | ＿＿＿＿＿＿ | сейчас ест |
| 話す | ＿＿＿＿＿＿ | сейчас говорит |
| 待つ | ＿＿＿＿＿＿ | сейчас ждёт |
| 買う | ＿＿＿＿＿＿ | сейчас покупает |
| する | ＿＿＿＿＿＿ | сейчас делает |
| 来る | ＿＿＿＿＿＿ | сейчас идёт (сюда) |
| 知る | ＿＿＿＿＿＿ | знает (состояние) |
| 結婚する | ＿＿＿＿＿＿ | женат/замужем |
| 住む | ＿＿＿＿＿＿ | живёт (где-то) |

**B. Выберите прогресс vs. состояние:**

1. 今、雨が ＿＿＿。 (降る → сейчас идёт)
2. 田中さんは結婚して ＿＿＿。 (состояние)
3. ドアが開いて ＿＿＿ よ。 (открыто — состояние)
4. 昼ご飯を食べて ＿＿＿ ところです。 (как раз сейчас)

**C. Переведите с ている:**

1. Что ты сейчас делаешь? → ＿＿＿＿＿＿＿＿＿＿＿＿
2. Я как раз убираю комнату. → ＿＿＿＿＿＿＿＿＿＿＿＿
3. Танака знает Юки. → ＿＿＿＿＿＿＿＿＿＿＿＿

## III. Грамматика — ておく, なら, そうです

**A. Заполните ておく (заранее):**

1. チケットを ＿＿＿ おきます。 (купить заранее → 買って)
2. 明日の会議の資料をコピーして ＿＿＿ いたほうがいい。
3. レストランを予約して ＿＿＿ きました。

**B. Выберите частицу/союз:**

1. 十一時（　）駅（　）会いませんか。
2. チケット（　）もう買ってありますか。
3. 十一時 ＿＿＿ 大丈夫です。 (если в 11 — нормально)
4. 天気予報 ＿＿＿ 晴れるそうです。 (по слухам)

**C. Составьте приглашение (ませんか / ましょう):**

Образец: 映画 → 一緒に映画を見ませんか。

1. 美術館 → ＿＿＿＿＿＿＿＿＿＿＿＿
2. 昼ご飯 → ＿＿＿＿＿＿＿＿＿＿＿＿
3. 公園を散歩 → ＿＿＿＿＿＿＿＿＿＿＿＿
4. Предложите помощь: 荷物 → ＿＿＿＿＿＿＿＿＿＿＿＿ (ましょうか)

## V. Ситуативные диалоги — допишите

1. **A:** 今、話してもいい？ **B:** ＿＿＿ *(я как раз ем → 今、食べているところです)*
2. **A:** 土曜日、暇？ **B:** ＿＿＿ *(согласитесь и предложите парк → ええ、公園へ行きませんか)*
3. **A:** 雨が降りそうですか。 **B:** ＿＿＿ *(по прогнозу — ясно → 予報では晴れるそうです)*
4. **A:** チケットは？ **B:** ＿＿＿ *(ещё не купил, но куплю заранее)*
5. **A:** 十時はどう？ **B:** ＿＿＿ *(раново-то, давай в 11 → 十時はちょっと早いです。十一時なら大丈夫です)*

**Ролевая игра (в парах или вслух за двоих):**

Вы звоните другу, договариваетесь о встрече в музее. Используйте:

- もしもし、〜です
- 今、何をしていますか
- 〜ませんか / 〜ましょう
- 〜ておきます
- 〜そうです (прогноз)

Запишите 6–8 реплик, затем проиграйте с разной интонацией (радостно / вежливо / шутливо).

## VII. Грамматика — てある (намеренное состояние)

**A. Перепишите в てある с が/を по контексту.**

Образец: 私はドアを開けました。→ ドアが開けてあります。

3. 私は資料をコピーしました。→ ＿＿＿＿＿＿＿＿

**B. Выберите ている / てある / ておく:**

## XIV. Комплексный мини-диалог
