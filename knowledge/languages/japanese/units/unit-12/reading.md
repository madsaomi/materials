# Unit 12 — Чтение: お客様は神様ですか？（Клиент всегда прав?)

## Текст

```
　　サービス業と敬語

「お客様は神様です」という言葉がありますが、
最近ではこの考えを見直す企業も増えています。

確かに、丁寧な敬語を使い、笑顔で接することは
サービスの基本です。しかし、客だからといって、
店員を不当に怒鳴ったり、侮辱したりする権利が
あるわけではありません。

あるカフェでは、「クレーマー対応マニュアル」を作り、
店員が不当な扱いを受けた場合、すぐに店長を
呼ぶルールを決めました。

敬語は道具です。相手を尊重するために使うもので、
自分を踏みつけられるためのものではありません。
正しい敬語と正しい心構え、両方を持ちましょう。
```

## Вопросы к тексту

1. Какие предприятия пересматривают принцип «клиент — бог»?
2. Что является базой сервиса по тексту?
3. Что сделало одно кафе для защиты сотрудников?
4. Как автор называет кэйго?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 見直す | みなおす | пересматривать |
| 接する | せっする | обращаться с кем-то |
| 不当に | ふとうに | несправедливо |
| 怒鳴る | どなる | кричать |
| 侮辱する | ぶじょくする | оскорблять |
| 権利 | けんり | право |
| クレーマー | — | вечный жалобщик |
| 対応 | たいおう | реагирование |
| 心構え | こころがまえ | внутренняя установка |

## Разбор грамматики в тексте

**見直す企業も増えています**
→ относительное предложение перед существительным.

**〜からといって〜わけではない**
→ «из того, что…, ещё не следует»: 客だからといって＝даже если это клиент.

**不当な扱いを受けた場合**
→ 場合 «в случае» + пассив受ける.

**踏みつけられるためのものではない**
→ пассив неудобства + のだ-номинализация: кэйго существует НЕ для того, чтобы вас топтали.

# Текст 2: 新人の挨拶（Приветствие новичка)

## Текст

```
　　入社したばかりの斎藤さんは、初日の挨拶で
緊張していました。部長に顔を合わせると、慌てて
こう言いました。

「おはようございまして…、あ、失礼しました。
おはようございます。本日からお世話になります。
斎藤と申します。よろしくお願いいたします。」

部長はにこにこしながら、
「こちらこそ、よろしくお願いします。肩の力を抜いて
頑張ってくださいね。」と答えました。

斎藤さんはほっとしました。敬語を完璧に話せなくても、
誠実な気持ちが伝わればいいのだと、そのとき思いました。
```

## Перевод

Только что поступивший на работу господин Сайто нервничал при первом приветствии. Увидев начальника отдела, он торопливо сказал:

«Доброе… простите. Доброе утро. С сегодняшнего дня я на вашем попечении. Меня зовут Сайто. Прошу любить и жаловать».

Начальник, улыбаясь, ответил: «С моей стороны тоже прошу. Расслабься и старайся». Сайто вздохнул с облегчением. Даже если не можешь говорить на идеальном кэйго, главное — чтобы искренность дошла, подумал он тогда.

## Вопросы к тексту

1. Почему Сайто нервничал?
2. Какую ошибку он допустил и как тут же исправился?
3. Что ответил начальник?
4. Какой вывод сделал Сайто в конце?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 入社する | にゅうしゃする | поступить на работу |
| 挨拶 | あいさつ | приветствие |
| 緊張する | きんちょうする | нервничать |
| 顔を合わせる | かおをあわせる | встретиться лицом к лицу |
| 慌てて | あわてて | в спешке, растерянно |
| 本日 | ほんじつ | сегодня（формально) |
| お世話になる | おせわになる | быть под попечением |
| にこにこ | — | с улыбкой |
| 肩の力を抜く | かたのちからをぬく | расслабиться |
| 誠実 | せいじつ | искренность |
| 伝わる | つたわる | доходить（о чувствах) |
| ほっとする | — | облегчённо вздохнуть |

## Разбор грамматики

**本日からお世話になります** —— から после данного дня + なる「становиться под（чьё-то) попечение」。

**よろしくお願いいたします** —— 謙譲のいたす: «прошу (о благосклонности), делая смиренно».

**肩の力を抜いて** —— идиома «выпусти силу из плеч» = расслабься.

**〜ばいいのだと、思いました** —— «стоит лишь…» + цитата с と.

# Текст 3: 敬語の失敗から学ぶ（Уроки из ошибок в кэйго)

## Текст

```
　　敬語は難しい。だからこそ、間違えることもある。
私の友人は初めてのバイトで、お客様にこう言って
しまいました。

「ありがとうございました。またどうぞおいでください。」

お客様は笑って、「どうも。」とだけ言って帰りました。

後で店長に聞くと、「おいでください」は友達には
使えますが、店員としてお客様に言うには「またのお越しを
お待ちしております」が正しいとのことでした。

間違いを恐れて敬語を使わなくなるより、間違えながら
学ぶほうが大切です。敬語は練習することで、自然に
身につきます。
```

## Перевод

Кэйго сложен. Именно поэтому можно и ошибаться. Моя подруга на первой подработке сказала клиенту так: «Спасибо. Приходите ещё». Клиент усмехнулся и, бросив лишь «спасибо», ушёл.

Позже выяснилось у управляющего: «おいでください» годится для друзей, но сотрудник клиенту должен говорить «またのお越しをお待ちしております». Лучше учиться, ошибаясь, чем бояться ошибок и вовсе не использовать кэйго. Кэйго осваивается естественно через практику.

## Вопросы к тексту

1. Что сказала подруга клиенту и почему это было не идеально?
2. Как правильно сказать клиенту «приходите ещё» в сервисе?
3. Какова главная мысль автора в конце?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| だからこそ | — | именно поэтому |
| 友人 | ゆうじん | друг |
| バイト | — | подработка |
| おいでください | — | приходите（для друзей) |
| 恐れる | おそれる | бояться |
| 身につく | みにつく | освоиться, прижиться |
| 自然に | しぜんに | естественно |

## Разбор грамматики

**間違えることもある** —— «иногда случается ошибиться»（こともある = тоже бывает).

**後で店長に聞くと、〜とのことでした** —— «когда спросил у управляющего, то…»（～と＝при обнаружении) + とのこと＝передача информации.

**〜より、〜ほうが大切です** —— «важнее X, чем Y»（сравнительная конструкция).

**練習することで、〜身につきます** —— через практику（ことで＝посредством) осваивается.

# Текст 4: おもてなしの心（Дух омотэнаси)

## Текст

```
　　日本のサービスには「おもてなし」という心があります。
おもてなしとは、相手のしてほしいことを先回りして
行うことです。

例えば、高級旅館では、お客様が部屋にいる時間を
考えて、お茶の温度を調整します。また、名前を覚えて
おくことで、二度目の来店でも「いつものお茶でよろしい
ですか」と聞くことができます。

おもてなしと敬語は切っても切れない関係です。敬語で
相手を尊重する言葉を選び、その気遣いを形にするのが
おもてなしです。言葉だけではなく、心を込めることが
何より大切です。
```

## Перевод

В японском сервисе есть дух «омотэнаси». Омотэнаси — это заранее предугадывать, что хочет сделать гость. Например, в дорогой рёкане регулируют температуру чая, думая, где гость находится в комнате. А запоминая имя, можно при втором визите спросить: «Вам как обычно, тот же чай?». Омотэнаси и кэйго неразрывно связаны. Кэйго — выбор слов уважения, а омотэнаси — воплощение этой заботы. Важнее всего не просто слова, а душа, вложенная в них.

## Вопросы к тексту

1. Что такое «омотэнаси» по определению текста?
2. Какие два примера «омотэнаси» приводятся?
3. Как связаны кэйго и омотэнаси согласно автору?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| おもてなし | — | гостеприимство |
| 先回りする | さきまわりする | предугадать заранее |
| 旅館 | りょかん | рёкан, постоялый двор |
| 調整する | ちょうせいする | регулировать |
| 二度目 | にどめ | второй раз |
| いつもの | — | как обычно |
| 切っても切れない | きってもきれない | неразрывный |
| 尊重する | そんちょうする | уважать |
| 気遣い | きづかい | забота, внимание |
| 形にする | かたちにする | воплотить |
| 何より | なにより | важнее всего |

## Разбор грамматики

**〜とは〜ことです** —— «X — это Y»（определение через とは〜ことです).

**先回りして行うこと** —— «делать, предугадывая заранее»（て+行う).

**〜ておくことで** —— «запомнив заранее, через это»（ておく＝сделать заранее＋ことで).

**切っても切れない関係** —— идиома «отношения, которые не разорвать».

**〜が何より大切です** —— «важнее всего».
