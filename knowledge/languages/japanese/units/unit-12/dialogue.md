# Unit 12 — Диалог: 敬語の世界（Мир вежливой речи)

## Ситуация

Месяц спустя. Алиса уже уверенно работает за кассой, но сегодня в кафе「もみじ」день особенный: проводится дегустация для постоянных клиентов, придёт сам владелец сети（社長), и Алиса впервые должна говорить чистым кэйго. Кэнта терпеливо тренирует её перед открытием.

## Диалог

```
ケンタ：アリスさん、今日は常連客と社長が来るから、
　　　　敬語、忘れないでね。
アリス：はい。「いらっしゃいませ」は大丈夫ですが…。
ケンタ：まず、社長が何か尋ねたら、「かしこまりました」。
　　　　自分のことは「私がいたします」。
アリス：先生がおっしゃるには、敬語は三種類ですよね。
　　　　尊敬語と謙譲語と丁寧語。
ケンタ：さすが！じゃあ練習。お客様が入ってきたら？
アリス：いらっしゃいませ！何になさいますか。
ケンタ：いいね。コーヒーを頼まれたら？
アリス：かしこまりました。ただいまお持ちいたします。

（昼、社長が来店)

社長：君が例の留学生か。日本語がお上手だそうだな。
アリス：恐れ入ります。まだまだ勉強中でございます。
社長：この店の評判を聞いていたよ。頑張っていると聞いている。
アリス：ありがとうございます。これからも精一杯努めます。
山田：アリスさん、社長にお茶をお出しして。
アリス：はい。（社長に)お茶でお口に合いましたら、ぜひ。
社長：ほう。行き届いているな。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 敬語、忘れないでね | Не забудь про кэйго! |
| おっしゃるには | Как говорит（учитель)… |
| 何になさいますか | Что будете（заказывать)? |
| かしこまりました | Слушаюсь! |
| お持ちいたします | Сейчас принесу（скромно) |
| 恐れ入ります | Я польщён/благодарю |
| まだまだ勉強中でございます | Ещё только учусь |
| 精一杯努めます | Буду стараться изо всех сил |
| お口に合いましたら | Если придётся по вкусу |
| 行き届いている | Всё продумано, безупречно |

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 常連客 | じょうれんきゃく | завсегдатай |
| 社長 | しゃちょう | президент компании |
| 尋ねる | たずねる | спрашивать |
| 三種類 | さんしゅるい | три вида |
| 来店 | らいてん | приход в заведение |
| 例の | れいの | тот самый |

| 行き届く | とどとく | быть безупречным |

## Культурная заметка

**Кэйго —— это не «вежливость», а социальная навигация.** Неправильное направление кэйго（возвысили себя, принизили клиента) оскорбительнее отсутствия вежливости. В кафе учат речевые шаблоны до автоматизма: «いらっしゃいませ» произносится хором всем персоналом при входе любого гостя.

**Уровневая речь в иерархии:** с 店長 говорите тэиннэй＋лёгкий кэйго; с 社長， полный кэйго; между коллегами-равными —— обычный вежливый стиль. Один и тот же факт рассказывается трёмя разными способами в зависимости от слушателя.

## Диалог 2: На приёме у доктора（病院での受付)

> Сценарий: Алиса пришла к врачу. Регистратура — идеальная отработка кэйго.

```
アリス：こんにちは。予約をしたアリスと申します。
アリス：Здравствуйте. Я Алиса, записалась на приём.
受付：ああ、アリス様ですね。お待ちしておりました。
受付：А, госпожа Алиса. Мы вас ждали.
アリス：保険証をこちらへお願いします。
アリス：Можно ваш страховой полис, пожалуйста.
受付：はい、拝見いたします。少々お待ちください。
受付：Да, я взгляну. Подождите немного.
（しばらくして)
（Через некоторое время)
受付：アリス様、お名前をお呼びしました。三番の診察室へどうぞ。
受付：Госпожа Алиса, я назвала ваше имя. Проходите в третий кабинет.
アリス：ありがとうございます。失礼いたします。
アリス：Спасибо. Извините за беспокойство.
```

**Разбор:**

| Фраза | Кэйго | Комментарий |
|-------|-------|-------------|
| と申します | 謙譲 | говорю（о себе) |
| 様 | 丁寧 | уважительный суффикс к имени |
| お待ちしておりました | 謙譲 | ждали（своё действие низко) |
| お願いします | 丁寧 | прошу, пожалуйста |
| 拝見いたします | 謙譲 | смотрю（удвоенно скромно) |
| お名前をお呼びしました | 謙譲 | назвал ваше имя |
| 失礼いたします | 謙譲 | извиняюсь, ухожу |

## Диалог 3: Телефонный разговор（電話での予約)

> Сценарий: Звонок в кафе「もみじ」—— бронирование столика на вечер.

```
人質（スタッフ)：お電話ありがとうございます。もみじでございます。
スタッフ：Спасибо за звонок. Это кафе «Момидзи».
客：もしもし。今夜、二人で予約したいのですが。
客：Алло. Хочу забронировать на двоих на сегодня вечером.
スタッフ：かしこまりました。お名前を伺ってよろしいでしょうか。
スタッフ：Принято. Могу узнать ваше имя?
客：佐藤と申します。
客：Меня зовут Сато.
スタッフ：佐藤様ですね。何時にご来店なさいますか。
スタッフ：Господин Сато. Во сколько пожалуете?
客：七時半ごろなら空いていますか。
客：На семь тридцать есть места?
スタッフ：少々お待ちください。…はい、七時半でお席を確保いたしました。
スタッフ：Подождите немного. …Да, на семь тридцать место зарезервировано.
客：ありがとうございました。
客：Спасибо большое.
スタッフ：またのお越しをお待ちしております。
スタッフ：Ждём вас снова.
```

**Разбор:**

| Фраза | Кэйго |
|-------|-------|
| でございます | 丁寧（про себя-заведение) |
| 伺ってよろしいでしょうか | 謙譲＋максимум вежливости |
| ご来店なさいますか | 尊敬（про клиента) |
| 確保いたしました | 謙譲（про своё действие) |

## Диалог 4: Жалоба клиента（クレーム対応)

> Сценарий: Клиент недоволен, что заказ ждали слишком долго. Алиса справляется.

```
客：ちょっと！注文してから三十分も待ったんだけど！
客：Слушайте! Я ждал тридцать минут после заказа!
アリス：大変申し訳ございません。お待たせしてしまい、恐れ入ります。
アリス：Приношу глубочайшие извинения. Простите, что заставила ждать.
客：コーヒーも冷めてるじゃない！
客：И кофе остыл!
アリス：すぐに新しいものをお持ちいたします。代わりにお席のほうへご案内いたします。
アリス：Сейчас принесу новый. А пока провожу вас к месту.
客：もういいわ。会計をお願い。
客：Хватит. Дайте счёт.
アリス：申し訳ございません。本日分はサービスさせていただきます。
アリス：Извините. Сегодняшний заказ — за наш счёт.
客：…それならいいわ。ごちそうさま。
客：…Ну ладно. Спасибо за угощение.
```

**Разбор:**

| Фраза | Кэйго |
|-------|-------|
| 大変申し訳ございません | максимальное извинение |
| お待たせしてしまい | 謙譲（заставили ждать — вина) |
| お持ちいたします | 謙譲（принесу) |
| ご案内いたします | 謙譲（провожу) |
| サービスさせていただきます | 謙譲（позвольте за ваш счёт) |

> 💡 Самая важная фраза при любой жалобе: **「大変申し訳ございません」** + сразу предложение исправить. Кэйго здесь не просто вежливость, а способ де-эскалации конфликта.
