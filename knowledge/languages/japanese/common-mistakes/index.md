# Частые ошибки при изучении японского

## 1. Путаница между は (ва) и が (га)

| | は (wa) | が (ga) |
|---|---------|---------|
| Функция | Маркер темы | Маркер субъекта |
| Когда использовать | Говорим о X | X делает действие |
| Пример | 私は学生です (я — студент) | 猫が好きです (кошку люблю) |

**Правило:** は выделяет тему предложения, が выделяет субъект действия.

## 2. Неправильный порядок слов

- Японский — **SOV** (субъект-объект-глагол), не SVO
- Глагол **всегда** в конце предложения
- Неправильно: 私は食べますりんご
- Правильно: 私はりんごを食べます

## 3. Опускание частицы を (о)

- В разговорной речи を часто опускают, но на письме она обязательна
- Неправильно: 本を読ます → Правильно: 本を読みます
- Неправильно: 東京行く → Правильно: 東京に行く

## 4. Путаница между に и で

| | に | で |
|---|-----|-----|
| Функция | Направление / время / цель | Место действия / инструмент |
| Пример | 学校に行く (иду в школу) | 公園で遊ぶ (играю в парке) |
| Пример | 3時に会う (встретимся в 3) | 電車で行く (еду на поезде) |

## 5. Неправильное использование い- и な- прилагательных

- **い-прилагательные** (истинные): 大きい, 高い, 安い, いい
  - Окончание -i, склоняются как глаголы
- **な-прилагательные** (полуистинные): 元気な, きれいな, 静かな
  - Перед существительным добавляется な

**Ошибка:** 大きな人 (неправильно, должно быть 大きい人)
**Ошибка:** 元気です (правильно) / 元きい (неправильно)

## 6. Забывают про счётные суффикы (助数詞)

- Счётные суффиксы обязательны при указании количества
- Неправильно: りんご三つ → Правильно: りんご三つ
- Неправильно: 三りんご → Правильно: りんご三つ

**Основные суффиксы:**
| Суффикс | Для чего |
|---------|----------|
| -つ (цу) | Общий счёт (1-10) |
| -人 (нин) | Люди |
| -枚 (май) | Плоские предметы |
| -本 (хон) | Длинные предметы |
| -匹 (хики) | Мелкие животные |
| -台 (дай) | Техника, машины |
| -冊 (сацу) | Книги |

## 7. Неправильное произношение длинных гласных

- おばさん (обасан) — тётя, не おばさん
- おばあさん (оба:сан) — бабушка, не おばあさん
- ゆき (юки) — снег, не юки
- ゆうき (ю:ки) — смелость, не юуки

## 8. Путаница между る и る verbs

- Глаголы на -る делятся на う-глаголы и る-глаголы
- る-глаголы: 食べる, 見る, 起きる, 着る
- У-глаголы с る: 帰る, 走る, 入る, 切る

## 9. Неправильное использование て形

- て形 используется для:
  - Последовательности действий: 食べて、眠る (поел и уснул)
  - Причины/основания: 天気が悪くて、行けなかった (плохая погода, не пошёл)
  - Условия: 時間があって、映画を見た (было время, посмотрел фильм)

## 10. Забывают про 敬語 (кэйго)

- В формальной обстановке обязательно использовать вежливую форму
- ます-форма — минимум вежливости
- Для начальства, клиентов, незнакомых людей — кэйго
- Ошибка: 使用します (использую) → Правильно: お使いします (вежливая форма)

## 11. Путаница между する и やる

- する — универсальный глагол «делать» (формальный)
- やる — «делать» (неформальный, грубоватый)
- В формальной речи всегда する

## 12. Неправильное использование 過去形

- Past tense образуется заменой последнего слога:
  - 食べる → 食べた (не 食べました — это вежливая форма)
  - 行く → 行った (не 行きました — вежливая)
- Для вежливой формы: 食べました, 行きました

## 13. Забывают про ておく и てある

- ておく — сделать заранее (для себя)
  - ドアを開けておく (открыть дверь заранее)
- てある — сделать заранее (для другого)
  - ドアが開けてある (дверь открыта — кто-то открыл)

## 14. Неправильное использование なら и ば

- なら — условие с конкретным предметом/ситуацией
  - 日本なら行く (если Япония — поеду)
- ば — общее условие
  - 行けばいい (если пойдёшь — хорошо)

## 15. Путаница между もらう, もらう, やる

| | もらう | くれる | やる |
|---|--------|--------|------|
| Направление | Мне | От третьего лица мне | Мне (от меня) |
| Вежливость | Нейтральный | Вежливый | Неформальный |
| Пример | 先生に本をもらう | 友達にプレゼントをもらう | 友達に手伝う |
