# Unit 9 — Чтение: ネットショッピングと実店舗 (Онлайн vs офлайн)

## Короткое чтение: три сумки и один бюджет

**Задача:** отдельно сравнить цену и массу, а затем объяснить выбор по бюджету. Цифры вымышлены для упражнения; они не описывают текущие магазинные цены.

### Таблица покупателя

| Сумка | Цена | Масса |
|---|---|---|
| A | 2000円 | 300グラム |
| B | 3000円 | 200グラム |
| C | 4000円 | 400グラム |

> 店には三つのバッグがあります。  
> Aは二千円、Bは三千円、Cは四千円です。  
> AよりBのほうが高いですが、Bのほうが軽いです。  
> この三つの中で、Aが一番安いです。  
> Bが一番軽いです。  
> アンナさんの予算は二千五百円です。  
> アンナさんは「今日はAを買います」と言います。

### Опоры к выбору сумки

| Запись | Чтение и значение |
|---|---|
| 三つの中で | みっつのなかで — среди этих трёх |
| 二千円 / 二千五百円 | にせんえん / にせんごひゃくえん — 2000 / 2500 иен |
| 高い / 安い | たかい / やすい — дорогой / дешёвый |
| 軽い / 重い | かるい / おもい — лёгкий / тяжёлый |
| 一番 | いちばん — самый, больше всего в заданной группе |
| 予算 | よさん — бюджет |

### Вопросы до перевода

1. Какая сумка дороже: A или B? Какая из них легче?
2. Какая самая дешёвая среди трёх? Какая самая лёгкая?
3. Какую покупку объявила Анна? Укладывается ли она в бюджет 2500円?
4. Доказывает ли таблица, что самая дорогая сумка самая качественная? Укажите, какие данные отсутствуют.

<details>
<summary>Перевод текста о сумках</summary>

В магазине три сумки. A стоит 2000 иен, B — 3000, C — 4000. B дороже A, но B легче. Среди этих трёх A самая дешёвая, B самая лёгкая. Бюджет Анны — 2500 иен. Анна говорит: «Сегодня куплю A».

</details>

<details>
<summary>Объяснённые ответы о цене и массе</summary>

1. **B дороже и легче A:** 3000 > 2000円; 200 < 300 граммов. В AよりBのほうが高いです характеристика 高い относится к B, а A — точка сравнения.
2. **Дешевле всех A; легче всех B.** 一番 действует в области この三つの中で; это не утверждение обо всех сумках в мире.
3. **A; да.** Её цена 2000円 меньше бюджета 2500円; B и C этот бюджет превышают. Выбор A сообщён прямо, не выведен только из цифр.
4. **Нет.** Материалы, долговечность и качество изготовления не указаны. Сравнение цены не заменяет сравнение качества.

</details>

## Текст

```
最近、物を買う時、ネットショップと
実際の店とどちらを使うか迷う人が多い。

ネットショッピングは店より便利だ。
家にいながら買い物ができて、
値段も少し安いことが多い。
特に、重い物や大きい物は
届けてもらえるので楽だ。

しかし、実際に手に取って見られない
という欠点がある。服なら、
試着できないと心配だし、色も
画面と違うことがある。

私の意見はこうだ。日常品はネットで、
服や靴など、自分に合うか確かめたい物は
実際の店で買うのが一番だと思う。
どちらも長所と短所があるから、
上手に使い分けたい。
```

## Вопросы к тексту

1. Назовите два преимущества онлайн-покупок из текста.
2. Почему автор осторожен с одеждой в интернете?
3. В чём состоит мнение автора?
4. Что означает выражение 使い分ける?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 実際 | じっさい | на самом деле |
| 迷う | まよう | сомневаться |
| 届ける | とどける | доставлять |
| 楽 | らく | легко, удобно |
| 手に取る | てにとる | взять в руки |
| 欠点 | けってん | недостаток |
| 試着する | しちゃくする | примерять |
| 意見 | いけん | мнение |
| 日常品 | にちじょうひん | товары повседневные |
| 長所／短所 | ちょうしょ／たんしょ | достоинства / недостатки |
| 使い分ける | つかいわける | использовать по назначению |

## Разбор грамматики в тексте

**買い物ができて**
→ て-соединение: «можешь делать покупки, и...».

**届けてもらえるので**
→ てもらう + 可能形: «могу получить доставку».

**試着できないと心配だし**
→ と условие + し перечисление причин: «если не могу примерить — беспокоюсь, и...».

**買うのが一番だと思う**
→ の номинализация + 一番 + と思う: «думаю, лучше всего покупать...».

- より / のほうが (сравнение)
- 一番 (превосходство)

## Текст 2: セールの日に (В день распродажи)

```
毎年一月、日本のデパートでは大きなセールがある。
冬の服や家電が安くなるので、
朝からたくさんの人が並ぶ。

私も去年、セールの日に買い物に行った。
人が多すぎて、試着室に入るのに三十分待った。
でも、気になっていたコートが半額だったので、
並んだ甲斐があった。

セールの日に気をつけたいのは、つい
余計な物まで買ってしまうことだ。
「安いから」と買った物は、後で使わないことも多い。
本当に必要な物だけを買うのが一番だと思う。
```

## Вопросы к тексту 2

1. Когда обычно бывают большие распродажи в Японии?
2. Почему автор пришёл раньше всех (стоял в очереди)?
3. Что он купил в итоге и почему?
4. Какой совет даёт автор в конце?
5. Что означает выражение 並んだ甲斐があった?

## Словарь к тексту 2

| Слово | Чтение | Перевод |
|-------|--------|---------|
| デパート | — | универмаг |
| セール | — | распродажа |
| 並ぶ | ならぶ | стоять в очереди |
| 試着室 | しちゃくしつ | примерочная |
| 待つ | まつ | ждать |
| 気になる | きになる | обращать внимание, беспокоить |
| コート | — | пальто |
| 半額 | はんがく | половина цены |
| 甲斐がある | かいがある | стоить того |
| 余計 | よけい | лишний |
| 必要 | ひつよう | необходимый |
| 本当に | ほんとうに | по-настоящему |

## Разбор грамматики в тексте 2

**並んだ甲斐があった** — 甲斐 (стоимость/толк) + がある: «не зря постоял». Частая разговорная конструкция.

**つい〜てしまう** — つい (нечаянно, против воли) + 〜てしまう: «неожиданно докупить лишнего».

**「安いから」と買った** — цитата причины + と: «купил, потому что (подумал) "дёшево"». だから → から в скобках как мысль.

**のが一番だと思う** — номинализация の + 一番 + と思う: «думаю, лучше всего…». Повторение из текста 1.

## Текст 3: 商品レビューを読む (Читаю отзывы о товаре)

```
ネットで物を買う時、私はいつも商品レビューを読む。
写真だけでは分からないことが多いからだ。

レビューは参考になるが、全部を信じるわけには
いかない。ひどいレビューは書く人が少ない、
特別に不満があった人だけかもしれない。
逆に、すごく褒めるレビューには
宣伝が混ざっていることもある。

だから私は、値段が同じくらいなら、
レビューの数が多い商品を選ぶ。
数が多いほど、平均的な評価が信用できると思う。
商品を選ぶ時は、値段より「誰が何のために
買ったか」を見るのが大切だと思う。
```

## Вопросы к тексту 3

1. Почему автор всегда читает отзывы?
2. Какие две ловушки отзывов упоминает автор?
3. Что автор делает, если цены одинаковые?
4. Почему автор думает, что много отзывов — это хорошо?
5. Что автор считает важнее цены при выборе товара?

|-------|--------|---------|
| 商品 | しょうひん | товар |
| レビュー | — | отзыв, обзор |
| 写真 | しゃしん | фотография |
| 参考 | さんこう | справка, ориентир |
| 信じる | しんじる | верить |
| 不満 | ふまん | недовольство |
| 逆に | ぎゃくに | наоборот |
| 褒める | ほめる | хвалить |

| 平均的 | へいきんてき | средний |
| 評価 | ひょうか | оценка |
| 信用する | しんようする | доверять |
| 大切 | たいせつ | важный |
| 選ぶ | えらぶ | выбирать |

## Разбор грамматики в тексте 3

**〜わけにはいかない** — 全部を信じるわけにはいかない: «нельзя (по моральным/логическим причинам) верить всему». Выражает невозможность-неследует.

**かもしれない** — 宣伝が混ざっていることもある／かもしれない: «может быть,». Спекуляция без уверенности.

**〜ば〜ほど** — 数が多いほど、平均的な評価が信用できる: «чем больше отзывов, тем надёжнее». Сравнительная конструкция «чем… тем…».

**〜より〜を見るのが大切** — 値段より「誰が買ったか」を見るのが大切: «важнее смотреть, кто купил, чем цену». Сравнение через より + のが大切.
