# Unit 6 — Грамматика: Форма ている, приглашения, ておく

## Учебное ядро: Процесс, результат и подготовка: ている・てある・ておく
## Окончание ている не переводится одним временем

Сначала определите, что означает глагол и что происходит в ситуации. 今、夕食を作っています — «Сейчас готовлю ужин» — процесс. 窓が開いています — «Окно открыто» — состояние после открытия. 東京に住んでいます — «Живу в Токио» — продолжающееся положение дел. У ている бывают также регулярное действие и опыт; слово «сейчас» не является обязательным переводом.

Образование: て-форма + いる; вежливо + います. 作っている→作っています, 開いている→開いています. В отрицании изменяется いる: 作っていない / 作っていません. Обычный ответ «не знаю» от 知る — 知りません, а утверждение — 知っています. Это отдельная устойчивая пара, а не правило для всех глаголов на ている.

## Состояние и действие ради будущего

| Что вы хотите выделить | Пример | Что известно |
|---|---|---|
| Нынешнее состояние | 窓が開いています。— Окно открыто. | Само по себе не сообщает, кто и зачем открыл. |
| Результат намеренной подготовки | 窓が開けてあります。— Окно оставлено открытым. | Использован переходный 開ける, действие было намеренным. |
| Подготовительное действие | 換気のため、窓を開けておきます。— Открою окно для проветривания. | Говорящий выполняет / планирует действие ради последующего состояния. |

てある присоединяют прежде всего к переходным глаголам: 書く→書いてある, 置く→置いてある. Основная модель здесь — 案内が書いてあります «указания написаны». У ておく сохраняется действие с объектом: 案内を書いておきます «заранее напишу указания». Другие частицы возможны в других конструкциях; таблица не запрещает их механически.

## Подготовка может быть и отказом менять состояние

明日のために、資料を読んでおきます。— «Заранее прочитаю материалы на завтра». 読んでおいた — уже прочитал заранее; 読んでおかなかった — не прочитал заранее. Отрицательная форма сама по себе не «отменяет сделанное»: для отмены брони нужен отдельный глагол キャンセルする.

そのままにしておいてください — «Оставьте как есть, пожалуйста» — тоже сохраняет состояние для дальнейшего. Разговорное 読んどく соответствует 読んでおく, 買っとく — 買っておく. На этапе разбора разворачивайте сокращение в полную форму, чтобы видеть границу глаголов.

## 1. Форма 〜ている («делаю сейчас» / «находится в состоянии»)

Образуется: **тэ-форма + いる**. В непринуждённой речи часто опускается именно い: **食べている → 食べてる**, **読んでいる → 読んでる**. Это сокращение сочетания, а не замена всего いる в любом предложении.

**Два употребления для сравнения ниже:**

1) Действие происходит прямо сейчас:

```
今、雨が降っています。     — Сейчас идёт дождь.
彼は本を読んでいます。     — Он (сейчас) читает книгу.
```

2) Состояние после действия (результат сохраняется):

```
結婚しています。           — Я женат/замужем (и до сих пор).
田中さんを知っています。   — Я знаю Танаку.
ドアが開いています。       — Дверь открыта (состояние; кто и зачем открыл, не сообщается).
```

> В подходящем контексте 行っています может означать «уехал и находится там», но это не единственное возможное употребление. Например, 今までに三回行っています сообщает об опыте трёх поездок. Определяйте смысл по контексту, а не по одному окончанию. См. [NINJAL: употребления ている](https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-68/).

## 2. 〜ているところです («как раз сейчас»)

Подчёркивает, что действие в самый разгар:

```
ちょうど昼ご飯を食べているところです。 — Как раз обедаю.
```

## 3. Приглашение: 〜ませんか и 〜ましょう

| Форма | Оттенок | Пример |
|-------|---------|--------|
| 〜ませんか | мягкое приглашение «не хотите ли...?» | 映画を見ませんか。(Не посмотреть ли фильм?) |
| 〜ましょう | «давайте...» — предложение совместного действия или принятие приглашения | じゃ、行きましょう。(Ну, пойдёмте.) |
| 〜ましょうか | «давайте я помогу / сделаем?» | 手伝いましょうか。(Помочь вам?) |

Ответ на приглашение:

```
ええ、ぜひ。         — Да, с удовольствием.
すみません、ちょっと… — Извините, как-то неловко... (мягкий отказ)
```

## 4. 〜ておく («сделать заранее, впрок»)

Тэ-форма + おく: действие выполняется заранее ради будущего.

```
チケットを買っておきます。     — Куплю билеты заранее.
宿題をしておきました。        — Я сделал домашку заранее.
お弁当を作っておいたほうがいい。— Лучше приготовить бэнто заранее.
```

## 5. Условие с なら («если уж речь о...»)

Тема + なら выделяет вариант из разговора:

```
A: 十時は早いなあ。
B: 十一時なら大丈夫です。 — Если (речь о) 11, то нормально.
```

## 6. 〜そうです (по слухам)

Простая форма законченного сообщения + そうです: «говорят, что...». Для существительного и な-прилагательного в непрошедшем утверждении сохраняется だ: 先生だそうです / 静かだそうです; у глагола — 来るそうです, у い-прилагательного — 高いそうです.

```
予報では晴れるそうです。     — По прогнозу, будет ясно (так говорят).
田中さんは来ないそうです。   — Говорят, Танака не придёт.
```

Не путать с 美味しそうです («выглядит вкусно») — там другой механизм присоединения.

## 7. Сравните три формы

| Форма | Значение | Пример |
|-------|----------|--------|
| ドアを開ける | открыть дверь (действие) | ドアを開けてください。 |
| ドアが開いている | дверь открыта (состояние) | ドアが開いていますよ。 |
| ドアを開けておく | открыть заранее (впрок) | 風通しのためドアを開けておく。 |

---

## 8. 〜ておく: расширенный разбор

Тэ-форма + おく — «сделать сейчас, чтобы потом было хорошо».

**Три типичных сценария:**

1) Подготовка к будущему событию:

```
明日の会議の資料を作っておきます。
Подготовлю материалы к завтрашней встрече.
```

2) Действие «впрок», чтобы потом не думать:

```
水を沸かしておいて。
Вскипяти воду заранее (чтобы была готова).
```

3) Устранение проблемы на будущее:

```
この書類はコピーしておいたほうがいい。
Эти документы лучше отксерить заранее.
```

**Различайте отрицание подготовки и решение воздержаться:** **予約しておかない** — «не бронировать заранее»; **今日は予約しないでおく** — «сегодня пока не буду бронировать». Во второй модели отрицательное действие + おく выражает выбранное сохранение положения дел; формы нельзя автоматически считать одинаковыми.

```
今日は洗濯しないでおこう。
Сегодня не буду стирать (отложу).
```

**Прошедшее:** 〜ておいた:

```
レストランを予約しておきました。
Я заранее забронировал ресторан.
```

> Разговорное сокращение: 〜とく — 買っといた（かっといた）＝ купил заранее.

## 9. Приглашения и предложения: полная лестница

| Форма | Вежливость | Оттенок | Пример |
|-------|------------|---------|--------|
| 行こう | друзья | «пойдёмте!» | じゃ、行こう！ |
| 行きましょう | стандарт | «давайте пойдём» | 一緒に行きましょう。 |
| 行きませんか | стандарт+ | мягкое приглашение | 映画を見ませんか。 |
| 行きましょうか | стандарт+ | «может, сходим?» + предложение помощи | 手伝いましょうか。 |
| 行ったらどうですか | совет | «может, сходить?» | 医者に行ったらどうですか。 |
| 行きませんでしょうか | очень вежливо | деловое приглашение | ご一緒しませんでしょうか。 |

**Ответы на приглашение:**

| Ответ | Значение |
|-------|----------|
| ええ、ぜひ。 | Да, непременно! |
| いいですね、行きましょう。 | Отлично, пойдём. |
| すみません、ちょっと… | Извините, как-то неловко... (отказ) |
| また誘ってください。 | Пригласите ещё раз (мягкий отказ). |

## 10. 〜つもり и 〜予定 — планы

### 〜つもりだ（намерение）
Словарная форма / най-форма + つもり:

```
週末は家でゆっくりするつもりです。
На выходных собираюсь отдохнуть дома.
```

```
誰にも言わないつもりだった。
Не собирался никому говорить.
```

### 〜予定だ（расписание, план по факту）
Существительное の / словарная форма + 予定:

```
来月、大阪へ出張する予定です。
В следующем месяце планирую командировку в Осаку.
```

```
三時に着く予定でしたが、遅れました。
Должен был приехать в три, но опоздал.
```

> **Разница:** つもり — намерение/решение действовать; 予定 — запланированное событие или расписание. Простое желание выражает たい; оно само по себе не означает принятого решения.

## 11. までに vs まで — «к сроку» vs «до момента»

| Частица | Значение | Пример |
|---------|----------|--------|
| まで | действие длится ДО точки | 夜中まで勉強した。Учился до полуночи. |
| までに | произойдёт НЕ ПОЗЖЕ точки | 六時までに帰ります。Вернусь к шести. |

```
金曜日までにレポートを出してください。
Сдайте отчёт не позднее пятницы.
```

> **Ловушка:** 「六時まで待ちます」= буду ждать до шести; 「六時までに着く」= приеду к шести.

---

## 12. 〜かどうか — «или нет»

Встроенный вопрос со смыслом «ли / или нет»:

```
田中さんが来るかどうか、まだ分かりません。
Ещё не знаю, придёт ли Танака.
```

```
おいしいかどうか食べてみましょう。
Попробуем — вкусно или нет.
```

Вопросительное слово сохраняет частицу か:

```
どこに住んでいるか教えてください。
Скажите, где вы живёте.
```

## 14. Частые ошибки юнита

Если нужно сказать «прямо сейчас делаю домашнюю работу», используйте **今、宿題をして（い）ます。** Фраза **今、宿題をする。** может означать решение «сейчас займусь домашней работой» и потому сама по себе не является грамматической ошибкой.

❌ **結婚していますか？— いいえ、結婚していませんでした。**
→ ✅ …結婚していません。
Состояние в вопросе «женаты?» живёт в настоящем.

❌ **十時まで会いませんか。** → ✅ 十時に会いませんか。
«Не встретиться в 10?» — точка встречи берётся に, не まで.

❌ **チケットを買っておきてください。**
→ ✅ 買っておいてください。
Здесь меняется вспомогательный глагол **おく → おいて**: **買って + おいて + ください**. Окончание おき- появляется, например, перед ます в **買っておきます**, но не образует て-форму おきて.

**雨が降りそうですね。** — «Похоже, пойдёт дождь» (оценка признаков). **予報では雨が降るそうです。** — «По прогнозу, будет дождь» (переданная информация). Собеседник может ответить сообщением из прогноза на наблюдение о тучах: сама смена источника информации не делает такой обмен ошибочным.

## 16. 〜てある («оставленное состояние с целью»)

Тэ-форма + ある: действие **кто-то выполнил специально**, и его результат сохраняется. В модели состояния 〜てある выделяет результат намеренного воздействия; само по себе 〜ている такого намерения не сообщает.

```
ドアが開けてあります。      — Дверь открыта (специально открыли).
壁に写真が飾ってあります。  — Фотографии повешены на стену (нарочно).
```

> В модели состояния предмет часто оформляется через が/は: ドアが開けてあります. Однако てある также допускает を, когда сообщается о заранее выполненной подготовке: 必要な資料をコピーしてあります. Не переносите схему が на все употребления てある.

**Сравнение** | ている | てある | ておく
---|---|---|---
Значение | просто состояние / прогрес | состояние, созданное намеренно | действие «впрок, заранее»
Что в фокусе? | процесс или состояние: при 開いている подлежащее — дверь, а не деятель | состояние предмета после намеренного действия; деятель часто не назван | действие ради будущего; деятель может быть назван или понятен из контекста

```
ドアが開いています。      — Дверь просто открыта.
ドアが開けてあります。     — Дверь открыта (кто-то открыл специально).
ドアを開けておきました。   — Я открыл дверь заранее (действие).
```

## 17. 〜ために и 〜ように — «для того чтобы»

Обе конструкции могут передавать цель «чтобы». В базовых моделях **ために** называет намеренное действие как цель, а **ように** — желательное состояние, способность или отсутствие нежелательного события. Это учебное сопоставление формулировки цели, а не проверка того, способен ли человек гарантировать результат в жизни.

**〜ために** (в этой базовой модели — намеренное действие как цель):

```
日本語を勉強するために、毎日練習します。
Чтобы учить японский, тренируюсь каждый день.
```

Перед **ために** различайте две модели: **глагол в словарной форме + ために** — **勉強するために**; **существительное + のために** — **勉強のために、本を買いました** («Купил книгу для учёбы»). の присоединяет существительное; его не вставляют произвольно после глагола.

**〜ように** (цель выражена как желательное состояние или возможность):

```
聞こえるように、大きな声で話してください。
Говорите громко, чтобы было слышно.
```

**Запомнить:** перед ように часто стоит отрицание или непереходный глагол / потенциальная форма.

| Суффикс | Когда |
|---------|-------|
| 〜ために | в базовой модели — намеренное действие как цель; V словарная форма / Nの |
| 〜ように | желательное состояние/возможность или предотвращение события; часто потенциальная или отрицательная форма |

## 18. 〜前（に） и 〜後（で） — «до» и «после»

**〜前に** — словарная форма глагола + 前に «перед тем как»:

```
食事の前に手を洗います。    — Мою руки перед едой.
寝る前に本を読みます。      — Читаю книгу перед сном.
```

**〜後で** — та-форма + 後で «после того как»:

```
宿題をした後で、遊びます。  — Поиграю после того, как сделаю уроки.
仕事の後で、飲みに行きます。— Пойду выпить после работы.
```

> 💡 С существительными: **会議の前に** — «перед совещанием», **会議の後で** — «после совещания»: **N + の前に / の後で**.

---

## 19. 〜たり〜たりする — «то… то…»

Перечисление действий/состояний как *примеров*, а не обязательный порядок событий. В базовом шаблоне **Vた + り、Vた + り + する** форму времени и вежливости получает **する**: **します / しました / しています**. Поэтому последнее действие списка тоже остаётся в форме たり; за ним в этом шаблоне следует подходящая форма する. Другие продолжения с たり возможны вне этого базового шаблона.

```
週末は映画を見たり、買い物をしたりします。
На выходных то фильмы смотрю, то по магазинам хожу (и т.п.).
```

```
忙しかったり、暇だったりします。
Бывает то занят, то свободен.
```

## 20. 〜んです／〜のです — «дело в том, что…»

Форма объяснения: добавляет причину, контекст или оправдание. Очень частотна в телефонных разговорах.

```
A: どうして遅れたんですか。         — Почему опоздали?
B: 電車が遅れたんです。             — Дело в том, что поезд опоздал.
```

```
明日は行けないんです。休みの約束があるんです。
Завтра не смогу — у меня уже есть договорённость об отпуске.
```

Образование:

- な-прилагательное / существительное + なんです
- い-прилагательное / глагол + んです

---

## 21. 〜ことにする и 〜ことになる — «решить/договориться»

**〜ことにする** — своё личное решение:

```
明日からダイエットすることにしました。
Решил сесть на диету с завтрашнего дня.
```

**〜ことになる** — решение внешнее, договорённость, так сложилось:

```
来月、大阪に出張することになりました。
Так вышло, что в следующем месяце еду в командировку в Осаку.
```

Пару часто путают. Ключ: **にする = я решаю; になる = решило что-то внешнее / по договорённости**.

## 22. Одно-словные отглагольные существительные

В деловых договорённостях по телефону часто используют отглагольные существительные с する. Запомните основные пары.

| Существительное | Чтение | Перевод |
|-----------------|--------|---------|
| 連絡 | れんらく | связь, сообщение |
| 確認 | かくにん | подтверждение |
| 予約 | よやく | бронь |
| 変更 | へんこう | изменение |
| 延期 | えんき | перенос |
| 中止 | ちゅうし | отмена |

Примеры с する:

```
予約を確認してください。      — Проверьте бронь.
会議を延期しました。          — Совещание перенесли.
また連絡します。              — Свяжусь ещё раз.
```

## 24. Типичные фразы делового звонка (грамматика на практике)

Когда звоните в офис или договариваетесь о встрече, эти готовые конструкции работают без ошибок:

```
お世話になっております。〜と申します。        — Спасибо за внимание, меня зовут ~.
お手数ですが、伝言をお願いできますか。        — Простите за беспокойство, передадите сообщение?
承知しました。少々お待ちください。            — Принято, подождите минутку.
折り返し、お電話いたします。                  — Я вам перезвоню.
また後で連絡します。                          — Свяжусь позже.
```

> **言う → 申す → 申します**, **する → いたす → いたします**. 申す здесь передаёт «говорить/называться»; это не форма глагола 思う («думать»). В классификации 文化庁 эти формы относятся к **謙譲語II（丁重語）**: говорящий учтиво сообщает о действиях своей стороны. Подробнее — Unit 12; [文化庁: виды кэйго](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter2/detail.html).
