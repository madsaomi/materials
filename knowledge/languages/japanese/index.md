>
> Японский (日本語, нихонго) — язык, на котором говорят около 125 миллионов человек. Относится к японо-рюкюской языковой семье. Трёхуровневая система письма: кандзи (иероглифы из китайского), хирагана (для грамматики) и катакана (для заимствований). Структура предложения — SOV: глагол всегда в конце.
>
> **Пример:**
> ```
> 私は りんごを 食べます。
> Ватаси ва ринго о табэмасу.
> Я — яблоко — ем.
> ```
> Сравните с русским: «Я ем яблоко». Порядок слов другой, но смысл тот же — если знаете, где искать подлежащее, объект и сказуемое.

> ## Быстрый старт за 5 минут
>
> Вот что стоит запомнить первым делом:
>
> 1. **Приветствие:** こんにちは (коннитива) — «добрый день»
> 2. **Благодарность:** ありがとうございます (аригато: годзаимасу) — «спасибо» (вежливо)
> 3. **Извинение:** すみません (сумимасэн) — «извините» / «простите»
> 4. **Приятно познакомиться:** 初めまして (хадзимэмаситэ)
> 5. **Порядок слов:** подлежащее → объект → глагол
> 6. **Главная частица:** は (ва) — отмечает тему предложения

## 1. Письменность

### 1.1 Хирагана (平仮名)

Основная слоговая азбука для грамматических частиц, окончаний, исконно японских слов.

| n | w | r | y | m | h | n | t | s | k | - |
|---|---|---|---|---|---|---|---|---|---|---|
| ん | わ | ら | や | ま | は | な | た | さ | か | あ a |
| | | り | | み | ひ | に | ち | し | き | い i |
| | | る | ゆ | む | ふ | ぬ | つ | す | く | う u |
| | | れ | | め | へ | ね | て | せ | け | え e |
| | を | ろ | よ | も | ほ | の | と | そ | こ | お o |

**Озвончение (гагигугэго, дзадзидзудзэдзо и т.д.):**
- か → が (ga), さ → ざ (za), た → だ (da), は → ば (ba)
- Полуозвончение: は → ぱ (pa)

**Маленькие знаки:**
- きゃ (kya), きゅ (kyu), きょ (kyo) — йотация
- っ — удвоение согласной (small tsu)

### 1.2 Катакана (片仮名)

Используется для заимствованных слов, иностранных имён, звукоподражаний, научных терминов.

| a | i | u | e | o |
|---|---|---|---|---|
| ア | イ | ウ | エ | オ |
| カ | キ | ク | ケ | コ |
| サ | シ | ス | セ | ソ |
| タ | チ | ツ | テ | ト |
| ナ | ニ | ヌ | ネ | ノ |
| ハ | ヒ | フ | ヘ | ホ |
| マ | ミ | ム | メ | モ |
| ヤ | ユ | ヨ | | |
| ラ | リ | ル | レ | ロ |
| ワ | ヲ | ン | | |

**Примеры катаканы:**
- コンピュータ (компью:та) — компьютер
- コーヒー (ко:хи:) — кофе
- タクシー (такуси:) — такси
- レストラン (рэсуторан) — ресторан

### 1.3 Кандзи (漢字)

Иероглифы, заимствованные из китайского. Каждый иероглиф имеет:
- **Онъёми (音読み)** — китайское чтение
- **Кунъёми (訓読み)** — японское чтение

**Основные иероглифы (JLPT N5):**

| Кандзи | Значение | Онъёми | Кунъёми | Пример |
|--------|----------|--------|---------|--------|
| 日 | солнце, день | нити, дзицу | хи, ка | 日曜日 (нитиё:би) — воскресенье |
| 月 | луна, месяц | гэцу, гацу | цуки | 月曜日 (гэцуё:би) — понедельник |
| 火 | огонь | ка | хи | 火曜日 (каё:би) — вторник |
| 水 | вода | суй | мидзу | 水曜日 (суйё:би) — среда |
| 木 | дерево | боку, моку | ки | 木曜日 (мокуё:би) — четверг |
| 金 | золото, деньги | кин, кон | канэ | 金曜日 (кинъё:би) — пятница |
| 土 | земля | до | цути | 土曜日 (доё:би) — суббота |
| 人 | человек | дзин, нин | хито | 日本人 (нихондзин) — японец |
| 山 | гора | сан, дзан | яма | 富士山 (Фудзисан) — гора Фудзи |
| 川 | река | сэн | кава | 小川 (огава) — ручей |
| 大 | большой | дай, тай | о:кии | 大学 (дайгаку) — университет |
| 小 | маленький | сё: | тиисай | 小さい (тиисай) — маленький |
| 中 | середина, внутри | тю:| нака | 中国 (Тю:гоку) — Китай |
| 上 | верх | дзё:, сё: | уэ | 上手 (дзё:дзу) — умелый |
| 下 | низ | ка, гэ | сита | 下手 (хэта) — неумелый |
| 一 | один | ити, ицу | хитоцу | 一つ (хитоцу) — один |
| 二 | два | ни | футацу | 二つ (футацу) — два |
| 三 | три | сан | мицу | 三つ (мицу) — три |
| 四 | четыре | си | ёцу, ён | 四つ (ёцу) — четыре |
| 五 | пять | го | ицуцу | 五つ (ицуцу) — пять |
| 六 | шесть | року | муцу | 六つ (муцу) — шесть |
| 七 | семь | сити | нанацу | 七つ (нанацу) — семь |
| 八 | восемь | хати | яцу | 八つ (яцу) — восемь |
| 九 | девять | ку, кю:| коконацу | 九つ (коконацу) — девять |
| 十 | десять | дзю: | то: | 十 (то:) — десять |

**Ключи (радикалы):** Базовые элементы кандзи. Например:
- 氵 (вода) — 海 (море), 酒 (сакэ), 洗 (мыть)
- 火 (огонь) — 焼 (жечь), 灯 (светильник)
- 木 (дерево) — 森 (лес), 林 (роща), 机 (стол)
- 言 (слово) — 語 (язык), 話 (говорить), 読 (читать)

## 2. Грамматика

### 2.1 Структура предложения

**SOV** — субъект-объект-глагол. В отличие от английского SVO.

```
私は りんごを 食べます。
Ватаси ва ринго о табэмасу.
Я яблоко ем.
```

### 2.2 Частицы

| Частица | Функция | Пример |
|---------|---------|--------|
| は (ва) | маркер темы | 私は学生です (я — студент) |
| が (га) | маркер субъекта | 猫が好きです (кошку люблю) |
| を (о) | маркер объекта | 本を読みます (читаю книгу) |
| に (ни) | направление / время / цель | 学校に行く (иду в школу) |
| で (дэ) | место действия / инструмент | 公園で遊ぶ (играю в парке) |
| へ (э) | направление | 日本へ行く (еду в Японию) |
| と (то) | совместность / цитата | 友達と話す (говорю с другом) |
| の (но) | притяжательность / связка | 私の本 (моя книга) |
| から (кара) | от / из / потому что | 東京から来た (приехал из Токио) |
| まで (мадэ) | до (предел) | 駅まで歩く (иду до станции) |

### 2.3 СПРЯЖЕНИЕ ГЛАГОЛОВ

Три группы:

**Группа 1 (Глаголы на -у):** 書く (каку) — писать
| Форма | Суффикс | Пример |
|-------|---------|--------|
| Словарная | -у | 書く |
| Масу-форма | -имасу | 書きます |
| Тэ-форма | -итэ | 書いて |
| Та-форма | -ита | 書いた |
| Отрицание | -анай | 書かない |
| Условная | -эба | 書けば |

**Группа 2 (Глаголы на -иру/-эру):** 食べる (табэру) — есть
| Форма | Суффикс | Пример |
|-------|---------|--------|
| Словарная | -ру | 食べる |
| Масу-форма | -масу | 食べます |
| Тэ-форма | -тэ | 食べて |
| Та-форма | -та | 食べた |
| Отрицание | -най | 食べない |

**Группа 3 (неправильные):** する (суру) — делать, 来る (куру) — приходить
| Форма | する | 来る |
|-------|-----|------|
| Словарная | する | 来る |
| Масу-форма | します | 来ます |
| Тэ-форма | して | 来て |
| Та-форма | した | 来た |
| Отрицание | しない | 来ない |

### 2.4 ПРИЛАГАТЕЛЬНЫЕ

**Истинные прилагательные (い-прилагательные):**
- 大きい (о:кий) — большой
  - 大きいです — большой (вежливо)
  - 大きくない — не большой
  - 大きかった — был большим
  - 大きくないです — не большой (вежливо)

**Полуистинные прилагательные (な-прилагательные):**
- 元気な (гэнки на) — здоровый, энергичный
  - 元気です — энергичен
  - 元気な人 — энергичный человек
  - 元気じゃない — не энергичен
  - 元気だった — был энергичен

### 2.5 СЧЁТНЫЕ СУФФИКСЫ

| Суффикс | Для чего | Пример |
|---------|----------|--------|
| -つ (цу) | общий (1-10) | 一つ (хитоцу) |
| -人 (нин) | люди | 三人 (саннин) |
| -枚 (май) | плоские предметы | 三枚 (санмай) |
| -本 (хон) | длинные предметы | 三本 (самбон) |
| -匹 (хики) | мелкие животные | 三匹 (самбики) |
| -台 (дай) | техника, машины | 三台 (сандай) |
| -冊 (сацу) | книги | 三冊 (сансацу) |

### 2.6 ВЕЖЛИВОСТЬ (КЭЙГО)

**Три уровня:**
1. **Кудайкэй (普遍形)** — простой (с друзьями, семьёй)
   - 食べる (табэру) — ем
2. **Тэйнгэй (丁寧形)** — вежливый (стандарт)
   - 食べます (табэмасу) — ем
3. **Кэйго (敬語)** — почтительный (для начальства, клиентов)
   - お食べになる / 召し上がる (мэсиагару) — кушаете

**Виды кэйго:**
- **Сонкэйго (尊敬語)** — возвышение собеседника
  - 行く → いらっしゃる
  - 食べる → 召し上がる
  - する → なさる
- **Кэндзё:го (謙譲語)** — принижение себя
  - 行く → 伺う (укагау)
  - 食べる → いただく
  - する → 致す (итасу)
- **Тэйнгэйго (丁寧語)** — вежливые слова (お, ご)
  - お金 (о-канэ) — деньги
  - ご飯 (го-хан) — еда

## 3. Лексика (по темам)

### 3.1 Приветствия и этикет

> 💡 **В реальной жизни:** На вокзале в Японии вы скажете `すみません` (сумимасэн), чтобы пройти мимо, а не `excuse me`. Это привычка, которую стоит запомнить — она используется везде.

| Японски | Чтение | Перевод | Когда использовать |
|---------|--------|---------|-------------------|
| おはようございます | охаё: годзаимасу | доброе утро | До 10:00, формально |
| こんにちは | коннитива | добрый день | Универсально |
| こんばんは | конбанва | добрый вечер | После 18:00 |
| さようなら | саё:нара | до свидания | При расставании |
| ありがとうございます | аригато: годзаимасу | спасибо | Универсально |
| すみません | сумимасэн | извините / простите | Для привлечения внимания, извинений |
| お願いします | онэгай симасу | пожалуйста | При просьбе |
| いただきます | итадакимасу | перед едой | Перед приёмом пищи |
| ごちそうさまでした | готисо:самадэсита | после еды | После приёма пищи |
| おやすみなさい | оясуми насай | спокойной ночи | Перед сном |

### 3.2 Семья

> 💡 **Контекст:** В Японии вежливость определяет, как вы называете родственников. `お父さん` (ото:сан) — это «отец» при обращении к чужому отцу, а `父` (тити) — «мой отец» в собственной речи. Это правило работает для всех членов семьи.

| Японски | Чтение | Перевод | Пример в предложении |
|---------|--------|---------|----------------------|
| 家族 | кадзоку | семья | 家族と旅行に行きました (поехал в путешествие с семьёй) |
| 父 | тити | мой отец | 父は医者です (мой отец — врач) |
| お父さん | ото:сан | отец (чужой) | お父さんは何歳ですか? (сколько вашему отцу?) |
| 母 | хаха | моя мать | 母が料理をします (мама готовит) |
| お母さん | ока:сан | мать (чужая) | お母さんを呼んでください (позовите маму) |
| 兄 | ани | мой старший брат | 兄は東京に住んでいます |
| お兄さん | они:сан | старший брат (чужой) | お兄さんは何をしていますか? |
| 姉 | анэ | моя старшая сестра | 姉は学生です |
| お姉さん | онэ:сан | старшая сестра (чужая) | お姉さんはかわいいです |
| 弟 | ото:то | младший брат | 弟と映画を見ました |
| 妹 | имо:то | младшая сестра | 妹は日本語が上手です |

> 🔗 Смотрите также: [Грамматика §2.2 — частица の (притяжательность)](index.md#22-частицы), [Частотный словарь](vocabulary/index.md) — слова «семья», «родственники»

### 3.3 Еда и напитки

> 💡 **В ресторане:** Когда официант приносит еду, принято сказать `いただきます` (итадакимасу) — буквально «принимаю». После еды — `ごちそうさまでした` (готисо:самадэсита) — «спасибо за угощение». Это неформальная вежливость, которую используют даже в дешёвых забегаловках.

| Японски | Чтение | Перевод | Пример |
|---------|--------|---------|--------|
| ご飯 | гохан | рис / еда | ご飯を食べます (ем рис) |
| パン | пан | хлеб | パンが好きです (люблю хлеб) |
| 肉 | никu | мясо | 肉を食べます (ем мясо) |
| 魚 | сакана | рыба | 魚は健康に良い (рыба полезна) |
| 野菜 | ясай | овощи | 野菜をたくさん食べます |
| 果物 | кудамоно | фрукты | 果物がおいしいです |
| 水 | мидзу | вода | 水を飲みます (пью воду) |
| お茶 | о-тя | чай | お茶が好きです |
| コーヒー | ко:хи: | кофе | コーヒーを飲みます |
| ビール | би:ру | пиво | ビールがおいしいです |
| 酒 | сакэ | сакэ | 週末に酒を飲みます |
| 美味しい | ойсий | вкусный | これはおいしいです |

> 🔗 Смотрите также: [Культура — кухня](culture/index.md), [Диалог «В ресторане»](#42-в-ресторане), [Частотный словарь](vocabulary/index.md) — еда и напитки

### 3.4 Цвета

> 💡 **Культурный нюанс:** Белый (白) в Японии ассоциируется со смертью и трауром (в отличие от Европы). Красный (赤) — энергия и жизнь. Зелёный (緑) — природа и свежесть.

| Японски | Чтение | Перевод | Пример |
|---------|--------|---------|--------|
| 赤 | ака | красный | 赤い車 (красная машина) |
| 青 | аой | синий / голубой | 青い空 (голубое небо) |
| 黄色い | киирой | жёлтый | 黄色い花 (жёлтый цветок) |
| 白い | сирой | белый | 白い雪 (белый снег) |
| 黒い | курой | чёрный | 黒い猫 (чёрный кот) |
| 緑 | мидори | зелёный | 緑の山 (зелёная гора) |
| 紫 | мурасаки | фиолетовый | 紫の花 (фиолетовый цветок) |
| 茶色 | тя-иро | коричневый | 茶色い犬 (коричневый пёс) |
| ピンク | пинку | розовый | ピンクのドレス (розовое платье) |
| オレンジ | орэндзи | оранжевый | オレンジの果物 (апельсин) |

> 🔗 Смотрите также: [Культура — интересные факты](culture/index.md) про число 4 и 7

### 3.5 Время и даты

> 💡 **Контекст:** Дни недели в японском образуются по шаблону `число + 月 (гацу)`. Понедельник — первый день, поэтому `月曜日` (гэцуё:би) буквально «день луны/первого дня месяца».

**Дни недели:**
- 月曜日 (гэцуё:би) — понедельник
- 火曜日 (каё:би) — вторник
- 水曜日 (суйё:би) — среда
- 木曜日 (мокуё:би) — четверг
- 金曜日 (кинъё:би) — пятница
- 土曜日 (доё:би) — суббота
- 日曜日 (нитиё:би) — воскресенье

**Месяцы:** Число + 月 (гацу)
- 一月 (итигацу) — январь → 二月 (нигацу) — февраль → 三月 (сангацу) — март
- 四月 (сигацу) — апрель → 五月 (гогацу) — май → 六月 (рокугацу) — июнь
- 七月 (ситигацу) — июль → 八月 (хатигацу) — август → 九月 (кугацу) — сентябрь
- 十月 (дзю:гацу) — октябрь → 十一月 (дзю:итигацу) — ноябрь → 十二月 (дзю:нигацу) — декабрь

**Числа от 1 до 10:**
1. 一 (ити)
2. 二 (ни)
3. 三 (сан)
4. 四 (си / ён) — избегают し из-за ассоциации со смертью (死)
5. 五 (го)
6. 六 (року)
7. 七 (сити / нана) — избегают し по той же причине
8. 八 (хати)
9. 九 (ку / кю:) — избегают く из-за ассоциации со страданием (苦)
10. 十 (дзю:)

> 🔗 Смотрите также: [Микро-детали — чтение цифр](details.md#15-чтение-цифр-по-японски-тонкости), [Культура — интересные факты](culture/index.md) про числа 4 и 7

### 3.6 Часто используемые глаголы

> 💡 **Совет:** Глаголы в японском меняют форму в зависимости от вежливости. Начните с масу-формы (ます) — это стандартный вежливый стиль. Спряжение по группам:
> - **Группа 1 (-у):** 书く → 書きます → 書いて → 書いた
> - **Группа 2 (-ру/-эру):** 食べる → 食べます → 食べて → 食べた
> - **Группа 3 (неправильные):** する → します → して → した; 来る → 来ます → 来て → 来た
>
> Подробнее: [Грамматика §2.3 — спряжение глаголов](#23-спряжение-глаголов)

| Словарная | Масу-форма | Перевод | Пример в контексте |
|-----------|-----------|---------|---------------------|
| 行く | 行きます | идти | 学校に行きます (иду в школу) |
| 来る | 来ます | приходить | 友達が来ます (придёт друг) |
| 見る | 見ます | смотреть | 映画を見ます (смотрю фильм) |
| 食べる | 食べます | есть | 昼ごはんを食べます (обедаю) |
| 飲む | 飲みます | пить | 水を飲みます (пью воду) |
| 読む | 読みます | читать | 本を読みます (читаю книгу) |
| 書く | 書きます | писать | 手紙を書きます (пишу письмо) |
| 話す | 話します | говорить | 日本語を話します (говорю по-японски) |
| 聞く | 聞きます | слушать / спрашивать | 先生に聞きます (спрашиваю у учителя) |
| する | します | делать | 宿題をします (делаю домашку) |
| 買う | 買います | покупать | 果物を買います (покупаю фрукты) |
| 待つ | 待ちます | ждать | バスを待ちます (жду автобус) |
| 勉強する | 勉強します | учиться | 毎日勉強します (учусь каждый день) |

> 🔗 Смотрите также: [Грамматика §2.3 — спряжение](index.md#23-спряжение-глаголов), [Частотный словарь](vocabulary/index.md) — глаголы 101-150

> 💡 **Как учить диалоги:** Не заучивайте наизусть — вместо этого представьте ситуацию и мысленно «проживите» её. Например, для диалога «В ресторане» представьте, что вы сидите за столиком, смотрите в меню и чувствуете запах рамэна. Это помогает запомнить фразы естественно.

### 4.1 Знакомство

```
А: 初めまして。田中と申します。

Б: 初めまして。鈴木です。よろしくお願いします。

А: よろしくお願いします。
   Ёросику онэгай симасу.
   Взаимно.
```

### 4.2 В ресторане

> Сценарий: Вы заходите в небольшой ресторан в Токио. Официант приветствует вас.

```
А: すみません、メニューを見せてください。
   Сумимасэн, мэнью: о мисэтэ кудасай.
   Извините, покажите меню, пожалуйста.

Б: はい、どうぞ。
   Хай, до:дзо.
   Да, пожалуйста.

А: これは何ですか？
   Корэ ва нан дэсу ка?
   Что это?

Б: それはラーメンです。
   Сорэ ва ра:мэн дэсу.
   Это рамэн.

А: じゃあ、ラーメンをください。
   Дзя:, ра:мэн о кудасай.
   Тогда дайте рамэн, пожалуйста.

Б: かしこまりました。
   Касикомаримасита.
   Принято.
```

> Сценарий: Вы в магазине сувениров в Киото. Хотите купить подарок, но цена кажется высокой.

## 5. Фонетика и произношение

> 💡 **Главное правило:** Японский произносится почти так, как пишется. Если вы можете прочитать кандзи — вы сможете произнести слово. Основные сложности: редуцирование гласных (гласные «i» и «u» почти исчезают между глухими согласными) и удвоение согласных (っ).
>
> Подробно о редуцировании, палатализации и диалектах: [Микро-детали](details.md)

### 5.1 Гласные

| Знак | МФА | Пример |
|------|-----|--------|
| あ | [a] | あさ (аса) — утро |
| い | [i] | いし (иси) — камень |
| う | [ɯ] | うみ (уми) — море |
| え | [e] | えき (эки) — станция |
| お | [o] | おと (ото) — звук |

**Долгие гласные:** Удваивают длительность.
- おばさん (обасан) — тётя
- おばあさん (оба:сан) — бабушка
- ゆき (юки) — снег
- ゆうき (ю:ки) — смелость

### 5.2 Интонация

Японский — акцентно-тоновый язык. Различают:
- **Хэйбан (平板)** — ровный (がくせい — студент)
- **Атамадака (頭高)** — высокий первый слог (はし — палочки)
- **Накадака (中高)** — высокий второй+ слог (あさって — послезавтра)
- **Одака (尾高)** — высокий до последнего (おとこ — мужчина)

**Минимальные пары:**
- 雨 (амэ) — дождь / 飴 (амэ) — конфета (разный акцент)
- 橋 (хаси) — мост / 箸 (хаси) — палочки для еды
- 神様 (камисама) — бог / 紙様 (камисама) — бумага

### 5.3 Редуцирование гласных

Гласные [i] и [ɯ] между глухими согласными редуцируются (почти исчезают):
- です → дэс (а не дэсу)
- ます → мас (а не масу)
- した → щта (а не сита)
- 聞く → кку (а не кику)

> 🔗 Подробно о редуцировании, палатализации и диалектах: [Микро-детали](details.md)

## 8. Частые ошибки

> 💡 **Совет:** Ошибки — нормальная часть обучения. Но некоторые ошибки повторяются снова и снова. Вот 6 главных ловушек, на которые стоит обратить внимание с самого начала.
>
> Подробный разбор каждой ошибки с упражнениями: [Частые ошибки](common-mistakes/index.md)

1. **Путаница между は (ва) и が (га)**
   - は — тема (говорим о X)
   - が — субъект (X делает)
   > 🔗 [Микро-детали §2.1](details.md#21-は-vs-が-тонкое-различие)

2. **Неправильный порядок слов**
   - Не SVO, а SOV. Глагол всегда в конце.
   > 🔗 [Грамматика §2.1](index.md#21-структура-предложения)

3. **Опускание を (о)**
   - В разговорной речи частицу を часто опускают, но на письме нужна.
   > 🔗 [Грамматика §2.2 — частицы](index.md#22-частицы)

4. **Путаница между に и で**
   - に — местонахождение / направление
   - で — место действия
   > 🔗 [Микро-детали §2.2](details.md#22-に-vs-で-vs-を-выбор-падежа-движения)

5. **Неправильное использование い- и な- прилагательных**
   - 大きい人 (о:кий хито) — большой человек (рост)
   - 元気な人 (гэнки на хито) — энергичный человек
   > 🔗 [Грамматика §2.4 — прилагательные](index.md#24-прилагательные)

6. **Забывают про счётные суффиксы**
   - 「りんご三つ」а не 「三りんご」
   > 🔗 [Микро-детали §2.4 — счётные суффиксы](details.md#24-счётные-суффиксы-все-тонкости)

## 9. Идиомы и устойчивые выражения

> 💡 **Как учить идиомы:** Не просто запоминайте перевод. Поймите образ. Например, `猫の手も借りたい` — «хочу взять даже кошачьи лапы» — это образ человека, настолько занятого, что он готов использовать любые руки, даже кошачьи. Такие образы запоминаются лучше, чем буквальный перевод.

| Выражение | Чтение | Значение | Когда использовать |
|-----------|--------|----------|---------------------|
| 猫の手も借りたい | нэко но тэ мо каритай | так занят, что даже кошачьи руки бы взял | Когда очень много работы |
| 猿も木から落ちる | сару мо ки кара оттиру | и обезьяна с дерева падает | Успех не гарантирован |
| 石の上にも三年 | иси но уэ ни мо саннэн | три года на камне | Терпение — ключ к мастерству |
| 口が滑る | кути гa субэру | оговориться, сболтнуть лишнее | Когда сказали лишнее |
| 目が高い | мэ га такай | иметь хороший вкус | Оцениваете что-то дорого |
| 鼻が高い | хана га такай | гордиться | Когда хвастаетесь |
| 足を運ぶ | аси о хакобу | нанести визит | Когда приходите в гости |
| 顔が広い | као га хирой | иметь широкие связи | Когда вас много кто знает |

## 11. Культурные заметки

> 💡 **Почему это важно:** Японский язык и японская культура неразделимы. Понимание культуры помогает понять, почему язык устроен именно так. Например, система вежливости (кэйго) отражает иерархическую структуру японского общества.

- **Поклоны** — важнее рукопожатий. Чем ниже поклон, тем больше уважения.
- **Визитки (名刺, мэйси)** — принимают двумя руками и внимательно изучают.
- **Обувь** — снимают перед входом в дом (гэнкан).
- **Чаевые** — не приняты. Хорошее обслуживание — само собой разумеющееся.
- **Онсэн (温泉)** — горячие источники, строгие правила (обязательно мыться перед входом).
- **Столовые палочки** — не втыкают в рис (ассоциируется с похоронами), не передают из палочек в палочки.

> 🔗 Подробно о культуре: [Культура](culture/index.md) — традиции, праздники, кухня, поп-культура
