# Полный грамматический справочник N5–N4

> **Как пользоваться:** 90 конструкций в порядке изучения. Номера 001–044 — базовый уровень N5, 045–090 — продолжение до N4. У каждой конструкции: форма, значение, примеры с транскрипцией (Поливановская система) и нюансы употребления.
>
> Связанные материалы: [Одностраничная шпаргалка](index.md) · [Юниты курса](../index.md) · [Компендиум кандзи](../kanji/compendium-n5-n4.md)

## Содержание

1. **Частицы (001–016)** — тема, субъект, объект, направление
2. **Формы глагола (017–032)** — масу, тэ, та, потенциал, приказ
3. **Существительные и прилагательные (033–038)**
4. **Связки и порядок мыслей (039–044)**
5. **Условия и причины (045–056)** — тара, ба, нарa, то
6. **Модальность и оценка (057–068)** — должен, наверное, похоже
7. **Служебные глаголы (069–078)** — тэ-оку, тэ-симay, ё:-ни нару
8. **Вежливость / кэйго (079–084)**
9. **Передача действий (085–090)** — агэру/курэру/морау

## 1. Частицы (001–016)

### 001. は — маркер темы
**Форма:** существительное + は
**Значение:** «что касается X...» — задаёт тему разговора.
```
私は学生です。
(ватаси-ва гакусэй дэсу) Я студент.
```
```
日本は物価が高いです。
(нихон-ва букка-га такай дэсу) В Японии цены высокие.
```
> **Нюанс:** пишется は, читается わ. Тема ≠ подлежащее: во втором примере тема «Япония», а подлежащее — «цены» (が).

### 002. が — маркер субъекта
**Форма:** существительное + が
**Значение:** выделяет подлежащее, новую информацию.
```
猫が魚を食べました。
(нэко-га сакана-о табэмасита) Кот съел рыбу (именно кот).
```
```
雨が降っています。
(амэ-га футтэ имасу) Идёт дождь.
```
> **Нюанс:** は vs が — классическая трудность. Правило на старте: известная тема → は; новая информация, вопросительные слова (誰が・何が), объекты чувств (好き・ほしい・できる) → が.

### 003. を — маркер объекта
**Форма:** существительное + を
**Значение:** прямой объект действия.
```
パンを食べます。
(пан-о табэмасу) Ем хлеб.
```
```
音楽を聞きます。
(онгаку-о кикимасу) Слушаю музыку.
```
> **Нюанс:** читается «о». В разговорной речи иногда опускается, на письме — нет.

### 004. に — направление, время, адресат
**Форма:** существительное + に
**Значение:** куда (точка прибытия), когда (точное время), кому.
```
七時に起きます。
(ситидзи-ни окимасу) Встаю в семь часов.
```
```
友達に手紙を送ります。
(томодати-ни тэгами-о окуримасу) Отправлю другу письмо.
```
> **Нюанс:** со словами 今日・明日・毎日 частица не нужна; с днями недели допустимо оба варианта.

### 005. で — место действия и средство
**Форма:** существительное + で
**Значение:** где происходит действие; чем делается.
```
図書館で勉強します。
(тосёкан-дэ бэнкё: симасу) Занимаюсь в библиотеке.
```
```
バスで行きます。
(басу-дэ икимасу) Поеду на автобусе.
```
> **Нюанс:** に vs で: に — точка назначения/существования (駅に着く), で — площадка действия (駅で待つ).

### 006. へ — направление
**Форма:** существительное + へ
**Значение:** движение в сторону чего-то.
```
日本へ行きたいです。
(нихон-э икитай дэсу) Хочу поехать в Японию.
```
> **Нюанс:** читается «э». Почти всегда взаимозаменяем с に; へ звучит чуть шире, «в сторону».

### 007. と — «и», «с», цитаты
**Форма:** A と B ／ фраза + と言う／思う
**Значение:** полное перечисление, совместность, оформление цитаты.
```
コーヒーとお茶をください。
(ко:хи: то о-тя о кудасай) Дайте кофе и чай.
```
```
田中さんと話しました。
(Танака-сан то ханасимасита) Поговорил с Танакой.
```
> **Нюанс:** と перечисляет всё без остатка; や — «и тому подобное». Перед 思う／言う обязательно と: 「行く」と思います。

### 008. や — неполное перечисление
**Форма:** A や B (+ など)
**Значение:** «A, B и прочее».
```
机の上に本やペンなどがあります。
(цукуэ-но уэ ни хон я пэн надо га аримасу) На столе книги, ручки и т.п.
```

### 009. の — принадлежность и связь
**Форма:** A の B
**Значение:** чей что; из чего сделано; связь существительных.
```
これは私の本です。
(корэ ва ватаси-но хон дэсу) Это моя книга.
```
```
大学の日本語の先生
(дайгаку-но нихонго-но сэнсэй) преподаватель японского университета
```
> **Нюанс:** также заменяет существительное: 赤いのをください — «дайте красный».

### 010. も — тоже
**Форма:** существительное + も
**Значение:** «тоже»; усиливает количество (何回も — целых X раз).
```
私も行きます。
(ватаси мо икимасу) Я тоже пойду.
```
```
三時間も待ちました。
(сандзикан мо матимасита) Ждал целых три часа!
```
> **Нюанс:** заменяет は/が, но ставится после を/に: 日本語も話せます。

### 011. から — от, из; потому что
**Форма:** точка + から ／ причина + から
**Значение:** исходная точка; причина в конце фразы.
```
九時から五時まで働きます。
(кудзи кара годзи мадэ хатаракимасу) Работаю с девяти до пяти.
```
```
忙しいから、行けません。
(исогасий кара, икэмасэн) Занят, поэтому не смогу.
```
> **Нюанс:** のд для причины мягче и официальнее (см. 052).

### 012. まで — до, предел
**Форма:** точка + まで
**Значение:** конечная точка времени/места.
```
駅まで歩いてください。
(эки мадэ арутэ кудасай) Пройдите до станции пешком.
```

### 013. より — чем (сравнение)
**Форма:** A より B ...
**Значение:** эталон сравнения.
```
電車よりバスのほうが安いです。
(дэнся ёри басу-но хо:га ясуй дэсу) Автобус дешевле поезда.
```
> **Нюанс:** порядок свободен: バスのほうが電車より安いです — то же самое.

### 014. か — вопрос и «или»
**Форма:** ...か ／ A か B
**Значение:** вопросительный оператор; выбор между вариантами.
```
これはペンですか。
(корэ ва пэн дэсу ка) Это ручка?
```
```
お茶かコーヒーを飲みます。
(о-тя ка ко:хи: о номимасу) Выпью чай или кофе.
```
> **Нюанс:** после か знак вопроса не нужен; интонация ровная.

### 015. ね — подтверждение
**Форма:** конец фразы + ね
**Значение:** «правда же?» — ищет отклик собеседника.
```
今日は暑いですね。
(кё: ва ацуй дэсу нэ) Сегодня жарко, не правда ли?
```

### 016. よ — новая информация
**Форма:** конец фразы + よ
**Значение:** уверенное сообщение того, чего собеседник не знает.
```
この店、安いですよ。
(коно мисэ ясуй дэсу ё) Этот магазин, кстати, недорогой!
```
> **Нюанс:** ね ищет согласие, よ сообщает новое. よね — «же ведь?»

## 2. Формы глагола (017–032)

### 017. ます／ません — вежливое настоящее-будущее
**Форма:** основа + ます／ません
**Значение:** вежливое утверждение и отрицание.
```
毎朝六時に起きます。夜はテレビを見ません。
(маиаса рокудзи ни окимасу. ёру ва тэрэби о мимасэн)
Каждое утро встаю в шесть. Вечером телевизор не смотрю.
```

### 018. ました／ませんでした — вежливое прошедшее
**Форма:** ました／ませんでした
**Значение:** вежливое прошлое и его отрицание.
```
昨日、映画を見ました。
(кино: эйга о мимасита) Вчера посмотрел фильм.
```
```
宿題をしませんでした。
(сюкудай о симасэн дэсита) Не сделал домашнее задание.
```

### 019. て-форма — универсальный мост
**Форма:** см. правила
**Значение:** соединяет действия; база десятков конструкций.

Правила группы 1:
```
う・つ・る → って   買う→買って, 待つ→待って, 帰る→帰って
む・ぶ・ぬ → んで   読む→読んで, 遊ぶ→遊んで, 死ぬ→死んで
く        → いて    書く→書いて
ぐ        → いで    泳ぐ→泳いで
す        → して    話す→話して
```
Группа 2: る → て (食べる → 食べて).
Исключения: 行く → 行って、する → して、来る → 来て。

> **Нюанс:** тэ-форма — фундамент языка: просьбы (020), разрешение (021), прогресс (юнит 6), услуги (085–090), подготовка (069).

### 020. 〜てください — просьба
**Форма:** тэ-форма + ください
**Значение:** «пожалуйста, сделайте».
```
ここに名前を書いてください。
(коко ни намаэ о кайтэ кудасай) Напишите здесь имя, пожалуйста.
```
> **Нюанс:** вежливо, но прямовато. Для сервиса — 〜ていただけませんか (084).

### 021. 〜てもいいですか — разрешение
**Форма:** тэ-форма + もいいですか
**Значение:** «можно ли...?»
```
写真を撮ってもいいですか。
(сясин о тоттэ мо ий дэсу ка) Можно фотографировать?
```
Ответ: いいですよ (можно) / すみません、ちょっと… (мягкий отказ).

### 022. 〜てはいけません — запрет
**Форма:** тэ-форма + はいけません
**Значение:** «нельзя» (правило, закон).
```
ここでタバコを吸ってはいけません。
(коко дэ табако о суттэ ва икэмасэн) Здесь нельзя курить.
```
> **Нюанс:** разговорное сокращение: 吸っちゃだめ。

### 023. 〜ないでください — отрицательная просьба
**Форма:** най-форма + でください
**Значение:** «пожалуйста, не делайте».
```
忘れないでください。
(васурэнаидэ кудасай) Пожалуйста, не забывайте.
```

### 024. 〜なければなりません — долженствование
**Форма:** най-форма → なければ + なりません
**Значение:** «обязан, надо».
```
明日早く起きなければなりません。
(асита хаяку окинакэрэба наримасэн) Завтра нужно встать пораньше.
```
> **Нюанс:** разговорные двойники: 〜ないといけない、〜なきゃ。Парадокс японского: «должен» выражается двойным отрицанием (не сделать = нехорошо).

### 025. 〜なくてもいいです — отсутствие обязанности
**Форма:** най-форма + なくてもいいです
**Значение:** «можете не делать».
```
今日は来なくてもいいです。
(кё: ва конакутэ мо ий дэсу) Сегодня можете не приходить.
```

### 026. 可能形 — «могу»
**Форма:** группа 1: у-ряд → э-ряд + る；группа 2: られる；する → できる
**Значение:** способность или возможность.
```
漢字が読めます。
(камдзи га ёмэмасу) Умею читать кандзи.
```
```
明日なら来られます。
(асита нара корарэмасу) Если завтра — смогу прийти.
```
> **Нюанс:** объект меняет を на が. Разговорное ら抜き言葉 (食べれる вместо 食べられる) понимать, но в письме не использовать.

### 027. ことができる — книжный потенциал
**Форма:** словарная форма + ことができる
**Значение:** то же, что 可能形, но формальнее.
```
日本語を話すことができます。
(нихонго о ханасу кото га дэкимасу) Могу говорить по-японски.
```

### 028. た-форма — простое прошедшее
**Форма:** тэ-форма с заменой て→た、で→だ
**Значение:** прошедшее в простой речи; база многих конструкций.
```
昨日、友達に会った。
(кино: томодати ни атта) Вчера встретил друга.
```

### 029. 〜たことがある — опыт
**Форма:** та-форма + ことがある
**Значение:** «когда-либо делал».
```
富士山に登ったことがありますか。
(Фудзисан ни ноботта кото га аримасу ка)
Поднимались когда-нибудь на Фудзи?
```
> **Нюанс:** только про опыт вообще, не про недавние события. Отрицание: 〜たことがない。

### 030. 〜たり〜たり — перечисление действий
**Форма:** та-форма + り ... та-форма + り (+ します)
**Значение:** «то..., то...» — примеры без полноты списка.
```
週末は本を読んだり、映画を見たりします。
(сю:мацу ва хон о ёндари эйга о митари симасу)
На выходных почитаю, посмотрю кино...
```

### 031. 意向形 — «давайте» и намерение
**Форма:** группа 1: у → о:+う (書こう)；группа 2: よう；しよう／来よう
**Значение:** приглашение; намерение с と思う.
```
一緒に行こう。
(иссё ни ико:) Пойдём вместе.
```
```
留学しようと思っています。
(рю:гаку сиё: то омоттэ имасу) Собираюсь учиться за границей.
```

### 032. 命令形 — приказ
**Форма:** группа 1: э (書け)；группа 2: ろ (食べろ)；しろ／来い
**Значение:** жёсткий приказ.
```
早く来い！
(хаяку кои!) Быстро сюда!
```
> **Нюанс:** грубо в быту; живёт в спорте, армии, мужской речи. Вежливая альтернатива — 〜てください／ご覧ください。

## 3. Существительные и прилагательные (033–038)

### 033. です — связка
**Форма:** существительное / な-прил. + です
**Значение:** «является»; несёт вежливость высказывания.
```
私はロシア人です。
(ватаси ва Росия-дзин дэсу) Я россиянин.
```
Отрицание: ではありません／じゃありません。Прошедшее: でした。

### 034. がある／がいる — существование
**Форма:** предмет + がある；живое + がいる
**Значение:** «имеется, находится».
```
机の上に本があります。
(цукуэ-но уэ ни хон га аримасу) На столе есть книга.
```
```
公園に子供がいます。
(ко:эн ни кодомо га имасу) В парке дети.
```

### 035. い-прилагательное: спряжение
**Форма:** 高い → 高くない／高かった／高くなかった／高くて
**Значение:** самостоятельное сказуемое.
```
この店は安くて、美味しいです。
(коно мисэ ва ясукутэ оисий дэсу) Этот магазин недорогой и вкусный.
```
> **Нюанс:** единственное исключение — いい: よくない／よかった.

### 036. な-прилагательное: спряжение
**Форма:** 元気 → 元気じゃない／元気だった／元気で
**Значение:** перед существительным требует な: 元気な人.
```
この町は静かで、便利です。
(коно мати ва сидзука дэ бэнри дэсу) Этот город тихий и удобный.
```

### 037. そうだ (вид) — «выглядит как»
**Форма:** основа слова + そうだ
**Значение:** впечатление на глаз.
```
このケーキは美味しそうです。
(коно кэ:ки ва оисисо: дэсу) Торт выглядит вкусным.
```
```
雨が降りそうです。
(амэ га фурисо: дэсу) Вот-вот пойдёт дождь.
```
> **Нюанс:** не путать со слухами (062)! Вид: основа слова; слух: полная форма.

### 038. すぎる — слишком
**Форма:** основа масу / основа прил. + すぎる
**Значение:** чрезмерность.
```
食べすぎました。
(табэсугимасита) Слишком много съел.
```
```
この問題は難しすぎます。
(коно мондай ва мудзукасисугимасу) Эта задача слишком сложная.
```

## 4. Связки и порядок мыслей (039–044)

### 039. そして／それから — «и потом»
**Значение:** последовательность событий.
```
朝ご飯を食べました。それから、会社へ行きました。
Позавтракал. Потом поехал в офис.
```

### 040. しかし／でも／けど — «но»
**Значение:** противопоставление; от формального (しかし) к разговорному (けど).
```
高いです。でも、欲しいです。
(такай дэсу. дэмо хосий дэсу) Дорого. Но хочу.
```

### 041. が — «но» внутри фразы
**Значение:** мягкое противопоставление, подводка к просьбе.
```
すみませんが、窓を開けてください。
(сумимасэн га мадо о акэтэ кудасай) Извините, откройте окно.
```

### 042. だから／そのため — «поэтому»
**Значение:** следствие; そのため формальнее.
```
雨でした。だから、行きませんでした。
Шёл дождь. Поэтому не пошёл.
```

### 043. それに／さらに — «более того»
**Значение:** добавление аргумента.
```
安いです。それに、近いです。
Недорого. К тому же близко.
```

### 044. まず／次に／最後に — структура рассказа
**Значение:** во-первых, во-вторых, наконец.
```
まず、水を沸かします。次に、麺を入れます。
Сначала вскипятить воду. Затем положить лапшу.
```

## 5. Условия и причины (045–056)

### 045. たら — универсальное условие
**Форма:** та-форма + ら
**Значение:** «если / когда» — самый частотный оператор.
```
雨が降ったら、試合は中止です。
(амэ га футтара сяи ва тю:си дэсу) Если пойдёт дождь, матч отменят.
```
```
家に帰ったら、電話してください。
(иэ ни каэттара дэнва ситэ кудасай) Когда вернётесь домой — позвоните.
```

### 046. ば — логическое условие
**Форма:** э-условная форма + ば
**Значение:** «если (условие), то (результат)».
```
安ければ買います。
(ясукэрэба каимасу) Если недорого — куплю.
```
> **Нюанс:** в результате плохо смотрится волевое действие говорящего; для приглашений берите たら.

### 047. なら — условие по теме разговора
**Форма:** существительное / словарная форма + なら
**Значение:** «если уж речь о...»
```
京都なら、新幹線が便利です。
(Кё:то нара синкансэн га бэнри дэсу) Если (едете) в Киото — удобен синкансэн.
```

### 048. と — естественное следствие
**Форма:** словарная форма + と
**Значение:** закономерность «как только..., так...».
```
春になると、桜が咲きます。
(хару ни нару то сакура га сакимасу) Как наступает весна, цветёт сакура.
```
> **Нюанс:** четыре условия: と — законы природы; ば — логика; たら — конкретный случай; なら — тема беседы.

### 049. ても — «даже если»
**Форма:** тэ-форма + も
**Значение:** уступка вопреки условию.
```
高くても買います。
(такакутэ мо каимасу) Куплю, даже если дорого.
```

### 050. ながら — одновременность
**Форма:** основа масу + ながら
**Значение:** «делая одновременно».
```
音楽を聞きながら勉強します。
(онгаку о кики нагара бэнкё: симасу) Учусь под музыку.
```
> **Нюанс:** оба действия делает один субъект.

### 051. 前に／てから — до и после
**Форма:** словарная форма + 前に ／ тэ-форма + から
**Значение:** «перед тем как / после того как».
```
寝る前に、歯を磨きます。
(нэру маэ ни ха о мигакимасу) Перед сном чищу зубы.
```
```
仕事が終わってから、飲みに行きます。
(сигото га онваттэ кара номи ни икимасу) После работы пойду выпить.
```

### 052. ので — причина (мягкая)
**Форма:** полная форма / най-форма + ので
**Значение:** «так как» — мягче и вежливее から.
```
頭が痛いので、帰ってもいいですか。
(атама га итай нодэ каэттэ мо ий дэсу ка)
У меня болит голова, можно я пойду домой?
```
> **Нюанс:** в объяснениях и просьбах почти всегда ので: 電車が遅れたので、遅刻しました。

### 053. し — перечисление причин
**Форма:** причина + し、причина + し
**Значение:** «и вообще..., и...» — аргументы складываются.
```
このアパートは安いし、駅にも近いし、最高です。
Эта квартира недорогая, да ещё и близко к станции — отлично!
```

### 054. とき — «когда»
**Форма:** словарная / та-форма + とき
**Значение:** момент времени события.
```
日本へ行ったとき、着物を買いました。
(нихон э итта токи камоно о каимасита) Когда был в Японии, купил кимоно.
```
> **Нюанс:** 行くとき = «когда поеду (до)», 行ったとき = «когда поехал (по прибытии)».

### 055. 間／間に — «в течение / пока»
**Форма:** словарная форма + 間（に）
**Значение:** 間 — всё время; 間に — какой-то момент внутри.
```
母が料理を作っている間、私はテレビを見ていました。
Пока мама готовила, я смотрел телевизор.
```

### 056. まま — состояние не меняется
**Форма:** та-форма / прил. / сущ.+の + まま
**Значение:** «не меняя состояния».
```
電気をつけたまま寝ました。
(дэнки о цукэта мама нэмасита) Уснул, не выключив свет.
```
```
靴のまま入らないでください。
Не входите в обуви (букв.: оставаясь в обуви).
```

## 6. Модальность и оценка (057–068)

### 057. つもり — намерение
**Форма:** словарная форма + つもりだ
**Значение:** твёрдый план.
```
来年、日本へ留学するつもりです。
(райнэн нихон э рю:гаку суру цумори дэсу) В следующем году собираюсь учиться в Японию.
```

### 058. ようになる — прийти к способности/привычке
**Форма:** потенциальная / словарная форма + ようになった
**Значение:** изменение состояния: «научился / стал делать».
```
漢字が読めるようになりました。
(камдзи га ёмэру ё:ни наримасита) Научился читать кандзи.
```

### 059. ようにする — стараться делать
**Форма:** словарная / най-форма + ようにする
**Значение:** сознательное усилие.
```
毎日運動するようにしています。
Стараюсь заниматься спортом каждый день.
```

### 060. ようとする — пытаться
**Форма:**意向形 + とする
**Значение:** попытка (часто неудачная).
```
ドアを開けようとしたが、鍵がなかった。
Хотел открыть дверь, но ключа не было.
```

### 061. ことにする／ことになる — решение
**Форма:** словарная форма + ことにする／ことになる
**Значение:** решить самому (にする) / решено извне (になる).
```
転職することにしました。
(тэнсёку суру кото ни симасита) Решил сменить работу.
```
```
来月、大阪に引っ越すことになりました。
Решилось (обстоятельствами), что переезжаю в Осаку.
```

### 062. そうだ (слух) — «говорят»
**Форма:** словарная / та-форма + そうだ
**Значение:** передача чужих слов без личной оценки.
```
天気予報によると、明日は晴れるそうです。
По прогнозу, завтра будет ясно (так говорят).
```
> **Нюанс:** источник вводится через によると. Форма не спрягается: 晴れるそうです、晴れなかったそうです。

### 063. ようだ／みたいだ — «похоже»
**Форма:** полная форма + ようだ（разговорное：みたいだ）
**Значение:** вывод по наблюдаемым признакам.
```
雨が降っているみたいです。
(амэ га футтэ иру митай дэсу) Похоже, идёт дождь.
```

### 064. らしい — «якобы, судя по слухам»
**Форма:** полная форма + らしい
**Значение:** информация из вторых рук + субъективное впечатление.
```
田中さんは最近忙しいらしい。
Говорят, Танака в последнее время занят.
```

### 065. はず — «должно быть» (логика)
**Форма:** полная форма + はずだ
**Значение:** уверенный вывод из логики.
```
彼はもう着いているはずです。
(карэ ва мо цуйтэ иру хадзу дэсу) Он уже должен быть здесь.
```

### 066. かもしれない — «может быть»
**Форма:** полная форма + かもしれない
**Значение:** вероятность ~50%.
```
遅れるかもしれないから、先に行ってください。
Могу опоздать, так что идите вперёд.
```
Шкала вероятности: 必ず (100%) → きっと (~90%) → でしょう (~70%) → かもしれない (~50%).

### 067. だろう／でしょう — «вероятно»
**Форма:** полная форма + だろう（вежливо：でしょう）
**Значение:** предположение ~70%.
```
明日は晴れるでしょう。
(асита ва харэру дэсё:) Завтра, вероятно, будет ясно.
```

### 068. べきだ — «следует»
**Форма:** словарная форма + べきだ
**Значение:** моральный долг (категорично).
```
約束は守るべきです。
Обещания нужно держать.
```
> **Нюанс:** звучит нравоучительно — используйте осторожно. Отрицание особое: すべきではない.

## 7. Служебные глаголы (069–078)

### 069. 〜ておく — сделать заранее
**Форма:** тэ-форма + おく
**Значение:** действие впрок, ради будущего.
```
チケットを買っておきます。
(тиккэтто о каттэ окимасу) Куплю билеты заранее.
```
```
ビールを冷やしておいた。
Пиво охладил заранее.
```

### 070. 〜てみる — попробовать
**Форма:** тэ-форма + みる
**Значение:** «попробовать и посмотреть, что выйдет».
```
この漢字、読んでみてください。
Попробуйте прочитать этот кандзи.
```

### 071. 〜てしまう — завершить / сожалеть
**Форма:** тэ-форма + しまう
**Значение:** 1) доделать до конца; 2) сожаление о случившемся.
```
宿題をしてしまいました。— Сделал домашку полностью (и славно).
財布を忘れてしまいました。— Уронил-таки: забыл кошелёк (досада).
```
> **Нюанс:** разговорно сокращается до 〜ちゃう: 忘れちゃった。

### 072. 〜ていく／てくる — изменение во времени
**Форма:** тэ-форма + いく／くる
**Значение:** развитие от прошлого к настоящему（くる）или в будущее（いく）.
```
日本の人口は減っていきます。
Население Японии будет уменьшаться.
```
```
だんだん暖かくなってきました。
Постепенно теплеет (стало теплее за время).
```

### 073. 〜ている — прогресс и состояние
**Форма:** тэ-форма + いる（разговорное：〜てる）
**Значение:** действие сейчас; результат сохраняется.
```
今、昼ご飯を食べています。
Сейчас ем обед.
```
```
田中さんは結婚しています。
Танака женат (состояние).
```
Подробный разбор: [Unit 6 — грамматика](../unit-06/grammar.md).

### 074. 〜てある — сделано кем-то, результат виден
**Форма:** транзитивный глагол в тэ-форме + ある
**Значение:** кто-то сделал, и результат налицо.
```
窓が開けてあります。
Окно открыто (кто-то открыл намеренно).
```
> **Нюанс:** сравните: 窓が開いている (открыто — просто состояние) vs 開けてある (кто-то открыл специально).

### 075. 〜やすい／にくい — легко/трудно сделать
**Форма:** основа масу + やすい／にくい
**Значение:** удобство действия.
```
このペンは書きやすいです。
Эта ручка удобно пишет (легко писать).
```
```
読みにくい字ですね。
Неудобочитаемый почерк.
```

### 076. 〜始める／出す — начало действия
**Форма:** основа масу + 始める／出す
**Значение:** 出す добавляет оттенок «вдруг, рвануло».
```
雨が降り出しました。
Вдруг полил дождь.
```

### 077. 〜続ける — продолжать
**Форма:** основа масу + 続ける
**Значение:** непрерывное продолжение.
```
三時間も歩き続けました。
Шли без остановки целых три часа.
```

### 078. 数量+も／しか — акценты количества
**Форма:** число + も ／ число+しか+否定
**Значение:** も — «целых»; しか…ない — «всего лишь».
```
十回も聞きました。— Спрашивал аж десять раз!
一冊しか持っていません。— У меня всего одна книга.
```

## 8. Вежливость / кэйго (079–084)

### 079. Три регистра речи
| Регистр | Когда | Пример «есть» |
|---------|-------|----------------|
| 普通体 | друзья, семья | 食べる |
| 丁寧体 | стандарт, незнакомцы | 食べます |
| 敬語 | начальство, клиенты | 召し上がります |

### 080. 尊敬語 — возвышение собеседника
**Форма:** お＋основа＋になる или спецслова
**Значение:** действия собеседника звучат уважительно.
```
社長がお帰りになりました。
Директор изволил вернуться.
```
Спецслова: 行く・来る・いる → いらっしゃる；食べる・飲む → 召し上がる；言う → おっしゃる；見る → ご覧になる。

### 081. 謙譲語 — принижение своих действий
**Форма:** お／ご＋основа＋する или спецслова
**Значение:** свои действия — скромно.
```
先生にお会いしました。
(сэнсэй ни о-ай симасита) Встретился с учителем (скромно).
```
Спецслова: 行く → 伺う・参る；食べる → いただく；言う → 申す・申し上げる；する → 致す。

### 082. 丁寧語 — приставки お／ご
**Форма:** お＋исконное слово ／ ご＋китайское слово
**Значение:** общая вежливость слова.
```
お金（おかね）деньги · ご飯（ごはん）еда · お茶（おちゃ）чай
```
> **Нюанс:** про свою семью чужим людям говорите скромно: 父・母; об их семье — уважительно: お父さん・お母さん.

### 083. 特殊敬語 — таблица замен
| Обычный | Уважительно (о другом) | Скромно (о себе) |
|---------|------------------------|-------------------|
| 行く・来る・いる | いらっしゃる | 参る・伺う |
| 食べる・飲む | 召し上がる | いただく |
| 言う | おっしゃる | 申す |
| 見る | ご覧になる | 拝見する |
| する | なさる | いたす |
| 知っている | ご存知だ | 存じ上げる |

### 084. 〜ていただけませんか — сверхвежливая просьба
**Форма:** тэ-форма + いただけませんか
**Значение:** «не могли бы Вы...» — сервис, начальство.
```
もう一度説明していただけませんか。
(мо: итидо сэцмэй ситэ итадакэмасэн ка)
Не могли бы Вы объяснить ещё раз?
```
Лестница вежливости: 〜て → 〜てください → 〜ていただけますか → 〜ていただけませんでしょうか.

## 9. Передача действий (085–090)

### 085. あげる — дать ОТ себя
**Форма:** дающий は получатель に предмет を あげる
**Значение:** передача от говорящего вовне.
```
私は妹に本をあげました。
Я подарил сестре книгу.
```

### 086. くれる — дать КО мне
**Форма:** дающий は（が） мне に предмет を くれる
**Значение:** кто-то даёт в мою сторону.
```
田中さんが私に本をくれました。
Танака подарил мне книгу.
```

### 087. もらう — получить
**Форма:** получатель は источник から/に предмет を もらう
**Значение:** получение с благодарным подтоном.
```
私は先生に辞書をもらいました。
Я получил словарь от учителя.
```
> **Нюанс:** одно событие можно описать двояко: 田中さんが本をくれた = 田中さんに本をもらった. Разница — фокус: кто активен.

### 088. 〜てあげる — услуга для другого
**Форма:** тэ-форма + あげる
**Значение:** «сделать для него».
```
友達に荷物を持ってあげました。
Помог другу донести вещи.
```
> **Нюанс:** по отношению к начальству НЕ используется (звучит свысока) — там させていただきます.

### 089. 〜てくれる — услуга для меня
**Форма:** тэ-форма + くれる
**Значение:** «сделали для меня» — встроенная благодарность.
```
母が弁当を作ってくれました。
Мама сделала мне бэнто (спасибо ей!).
```

### 090. 〜てもらう — попросить и получить услугу
**Форма:** тэ-форма + もらう
**Значение:** я попросил — и для меня сделали.
```
先生に作文を見てもらいました。
Учитель проверил моё сочинение (я его попросил).
```
Просьба: 〜てもらえますか／ていただけますか.
Полный разбор триады: [Unit 8 — грамматика](../unit-08/grammar.md).

## Шпаргалка: как выбрать условие

| Ситуация | Форма | Пример |
|----------|-------|--------|
| Закон природы, автоматизм | と | 春になると、桜が咲く。 |
| Логика: если A, то B | ば | 安ければ買う。 |
| Конкретный случай, будущее | たら | 雨が降ったら中止。 |
| Реакция на тему беседы | なら | 京都なら新幹線。 |
| Вопреки условию | ても | 高くても買う。 |

## Шпаргалка: шкала уверенности

| Уверенность | Слово | Пример |
|-------------|-------|--------|
| 100% | 必ず | 必ず来ます。 |
| ~90% | きっと | きっと大丈夫です。 |
| ~70% | でしょう | 明日は晴れるでしょう。 |
| ~50% | かもしれない | 遅れるかもしれない。 |
| По виду | そうだ(вид) | 雨が降りそう。 |
| По слухам | そうだ(слух) | 晴れるそうです。 |
| По признакам | ようだ／みたい | 雨みたいです。 |
| По логике | はず | もう着いたはずです。 |

## Как учить этот справочник

1. **Не подряд, а блоками по потребности** — готовите письмо? Берите раздел 6. Идёте в ресторан? Разделы 1 и 9.
2. **Каждую конструкцию — в свою фразу** — придумайте пример из своей жизни, запомнится в разы лучше.
3. **SRS:** лицевая сторона — номер и форма (например «046. ば»), обратная — значение + ваш пример.
4. **Сверяйтесь с юнитами** — каждая конструкция встречается в диалогах курса: контекст закрепляет правила.
5. **Норма:** 5 конструкций в неделю = весь справочник за 4 месяца осознанно, без зубрёжки.
