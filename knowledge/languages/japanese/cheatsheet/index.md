# Японский — Грамматическая шпаргалка (1 страница)

## Частицы
```
は (wa) — тема            が (ga) — субъект
を (o) — объект            に (ni) — направление/время
で (de) — место/инструм.   へ (e) — направление
と (to) — с/и              の (no) — принадлежность
から (kara) — от/потому    まで (made) — до
より (yori) — чем          だけ (dake) — только
しか (shika) — только(~не) も (mo) — тоже
や (ya) — и (неполное)     か (ka) — вопрос/или
```

## Спряжение глаголов

| Группа | Словарная | ます | て | た | ない | ば | 意向 |
|--------|-----------|------|----|----|------|-----|----|
| I (う) | 書く | 書きます | 書いて | 書いた | 書かない | 書けば | 書こう |
| I (う) | 読む | 読みます | 読んで | 読んだ | 読まない | 読めば | 読もう |
| I (う) | 待つ | 待ちます | 待って | 待った | 待たない | 待てば | 待とう |
| I (う) | 話す | 話します | 話して | 話した | 話さない | 話せば | 話そう |
| I (う) | 買う | 買います | 買って | 買った | 買わない | 買えば | 買おう |
| II (る) | 食べる | 食べます | 食べて | 食べた | 食べない | 食べれば | 食べよう |
| II (る) | 見る | 見ます | 見て | 見た | 見ない | 見れば | 見よう |
| III | する | します | して | した | しない | すれば | しよう |
| III | 来る | 来ます | 来て | 来た | 来ない | 来れば | 来よう |

**て-форма (правила):**
```
う/つ/る → って  (買う→買って, 待つ→待って, 帰る→帰って)
く → いて        (書く→書いて)
ぐ → いで        (泳ぐ→泳いで)
す → して        (話す→話して)
ぬ/ぶ/む → んで  (死ぬ→死んで, 遊ぶ→遊んで, 読む→読んで)
```

## Прилагательные

### い-прилагательные
```
高い (дорогой)
高くない (не дорогой)        高かった (был дорогой)
高くなかった (не был дорогой)  高くて (дорогой и...)
```

### な-прилагательные
```
元気な (здоровый)
元気じゃない                      元気だった
元気じゃなかった                    元気で
```

## Основные конструкции

| Конструкция | Значение | Пример |
|------------|----------|--------|
| 〜たい | хочу | 食べたい |
| 〜ながら | делая | 歩きながら |
| 〜かた | способ | 書き方 |
| 〜すぎる | слишком | 食べすぎる |
| 〜やすい | легко | 分かりやすい |
| 〜にくい | трудно | 読みにくい |
| 〜たことがある | был опыт | 行ったことがある |
| 〜てもいい | можно | 食べてもいい |
| 〜てはいけない | нельзя | してはいけない |
| 〜なければならない | должен | 行かなければならない |
| 〜そうです | говорят | 雨が降るそうです |
| 〜ようです | похоже | 雨が降るようです |
| 〜ために | для/ради | 日本のために |
| 〜つもり | намереваюсь | 行くつもり |
| 〜予定 | планирую | 行く予定 |

## Вежливость

| Глагол | 尊敬語 | 謙譲語 |
|--------|--------|--------|
| 行く | いらっしゃる | 伺う (うかがう) |
| する | なさる | 致す (いたす) |
| 食べる | 召し上がる | いただく |
| 言う | おっしゃる | 申す (もうす) |
| 見る | ご覧になる | 拝見する (はいけんする) |
| いる | いらっしゃる | おる |
