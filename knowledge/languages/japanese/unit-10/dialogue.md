# Unit 10 — Диалог: 京都旅行の計画 (Планируем поездку в Киото)

## Ситуация

Алиса и Юки планируют поездку в Киото на золотую неделю. Они обсуждают, что взять с собой, как добраться и что посмотреть. Отрабатываются условные формы (たら) и опыт (ことがある).

## Диалог

```
アリス：ゆきちゃん、ゴールデンウィークに京都へ行かない？
ゆき：いいね！行きたいと思ってたの。新幹線で行く？
アリス：うん、東京から二時間半ぐらいだって。
ゆき：私は新幹線に乗ったことがないから、楽しみだなあ。
アリス：本当？じゃあ、窓側の席を取るね。
　　富士山が見られるかもしれないよ。
ゆき：わあ、嬉しい！ホテルはもう予約した？
アリス：まだ。安くていいホテルを探してるんだけど、
　　もうほとんど埋まってるみたい。
ゆき：早く予約したほうがいいよ。
アリス：そうする。もし雨が降ったらどうしよう。
ゆき：雨でも楽しめる所があるから大丈夫。
　　お寺の中ならゆっくり見られるし。
アリス：良かった。何を持って行けばいいかな。
ゆき：歩くから、動きやすい靴が絶対必要だよ。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 行かない？ | не съездить ли? |
| 二時間半ぐらいだって | говорят, часа два с половиной |
| 乗ったことがない | ни разу не ездила |
| 窓側の席 | место у окна |
| 見られるかもしれない | возможно, будет видно |
| ホテルは予約した？ | отель уже забронирован? |
| 埋まってるみたい | кажется, всё занято |
| 早く予約したほうがいい | лучше забронировать заранее |
| もし雨が降ったらどうしよう | а если пойдёт дождь? |
| 雨でも楽しめる | даже в дождь можно развлечься |
| 何を持って行けばいいかな | что взять с собой? |
| 動きやすい靴 | удобная обувь |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 新幹線 | しんかんせん | синкансэн (скоростной поезд) |
| 窓側 | まどがわ | сторона у окна |
| 席 | せき | место |
| 予約 | よやく | бронирование |
| 埋まる | うまる | заполняться |
| お寺 | おてら | храм |
| 絶対 | ぜったい | обязательно |

## Культурная заметка

**Голден уик (ゴールデンウィーク)** — неделя праздников в конце апреля — начале мая (29 апреля — 5 мая). Весь Япония едет путешествовать: билеты и отели раскупают за месяцы. Если планируете поездку в это время — бронируйте заранее!

**Синкансэн:** места бывают 指定席 (しっていせき — с резервацией) и 自由席 (じゆうせき — свободная посадка). Место у окна со стороны горы Фудзи (при поездке из Токио в Киото — правый ряд, E-места) — маленькая хитрость туристов.

# Диалог 2: ホテルで (В отеле)

## Ситуация

Алиса заселяется в отель в Киото. Она спрашивает о завтраке, обмене валюты и Wi-Fi.

## Диалог

```
アリス：すみません、チェックインをお願いします。
フロント：はい、お名前は？
アリス：アリサ・スミスです。予約してあります。
フロント：お待ちください…。はい、ツインの二泊ですね。
アリス：はい。朝食は付いていますか？
フロント：はい、朝食付きです。朝は七時からです。
アリス：Wi-Fiは使えますか？
フロント：はい、無料です。パスワードはこのカードに書いてあります。
アリス：ありがとうございます。両替はここでできますか？
フロント：はい、できます。明日まで現金が足りるか、ちょっと確認してきてください。
アリス：そうですね。じゃあ、部屋は何階ですか？
フロント：五階です。エレベーターはあちらです。
アリス：ありがとうございました。
```

## Перевод

| Японский | Русский |
|----------|---------|
| チェックインをお願いします | Прошу заселения |
| 予約してあります | Забронировано (заранее) |
| ツインの二泊 | двухместный, две ночи |
| 朝食は付いていますか | Завтрак включён? |
| WiFiは使えますか | Wi-Fi работает? |
| 無料です | бесплатно |
| カードに書いてあります | написано на карточке |
| 両替はここでできますか | Здесь можно обменять валюту? |
| 現金が足りるか | хватит ли наличных |
| 何階ですか | на каком этаже |
| エレベーターはあちらです | лифт вон там |

# Диалог 3: 道で迷った (Потерялись по дороге)

## Ситуация

Юки заблудилась по дороге к храму и спрашивает дорогу у прохожего.

## Диалог

```
ゆき：すみません、清水寺へはどう行ったらいいですか？
通行人：清水寺ですか。この道をまっすぐ行って、
　　右に曲がったら、すぐ着きますよ。
ゆき：歩いてどのぐらいですか？
通行人：十分ぐらいだと思います。
　　歩きやすい靴で行ったほうがいいですよ。
ゆき：ありがとうございます。あの、途中にお寺がありますか？
通行人：ええ、いくつかあります。時間があれば、
　　寄ってみてください。きれいですよ。
ゆき：そうします。どうもありがとうございました。
通行人：いいえ、道に気をつけてね。
```

## Перевод

| Японский | Русский |
|----------|---------|
| どう行ったらいいですか | как лучше добраться |
| まっすぐ行って | идите прямо |
| 右に曲がったら | как повернёте направо |
| すぐ着きます | сразу доберётесь |
| 歩いてどのぐらいですか | сколько пешком |
| 歩きやすい靴 | удобная обувь |
| 寄ってみてください | загляните (попробуйте) |
| 時間があれば | если будет время |
| 道に気をつけて | осторожно на дороге |

# Диалог 4: お土産を買う (Покупаем сувениры)

## Ситуация

Перед отъездом Алиса покупает сувениры домой. Она сравнивает цены и советуется с продавцом.

## Диалог

```
アリス：すみません、この箸はいくらですか？
店員：それは五百円です。こちらのは八百円です。
アリス：八百円のほうが高いですね。でも、きれいですね。
店員：はい、これは京都の組みひもです。おすすめですよ。
アリス：じゃあ、その高いのを三つください。
店員：はい、ありがとうございます。包装はどうしますか？
アリス：プレゼントですから、包んでもらえますか。
店員：かしこまりました。こちらで少々お待ちください。
アリス：お菓子も買いたいんですけど、何がいいですか。
店員：抹茶のせんべいが人気ですよ。
アリス：じゃあ、それも一つお願いします。
```

## Перевод

| Японский | Русский |
|----------|---------|
| この箸はいくらですか | сколько стоят эти палочки |
| こちらのは八百円です | вот эти — 800 иен |
| ほうが高いですね | эти дороже |
| 組みひも | плетёный шнур (киото) |
| おすすめですよ | рекомендую |
| 包装はどうしますか | Как упаковать? |
| 包んでもらえますか | Можете упаковать? |
| 人気ですよ | популярно |
| それも一つお願いします | и ещё одно, пожалуйста |
