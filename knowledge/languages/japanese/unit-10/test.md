# Unit 10 — Тест

## Часть 1: Выберите правильный вариант

**1. 雨が＿＿＿、試合は中止です。**
- а) 降るたら
- б) 降ったら
- в) 降りたら

**2. 私は刺身を食べた＿＿＿がありません。**
- а) こと
- б) もの
- в) とき

**3. 明日は遅れる＿＿＿しれない。**
- а) を
- б) が
- в) か

**4. 早く予約した＿＿＿いいよ。**
- а) ほうが
- б) ほうに
- в) より
