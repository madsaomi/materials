# Unit 10 — Грамматика: Условия и опыт

## 1. Условие たら («если / когда»)

Образуется: та-форма глагола + ら
```
雨が降ったら、出かけません。   — Если пойдёт дождь, никуда не пойдём.
安くなったら、買います。       — Если подешевеет, куплю.
日本に行ったら、京都を見たい。  — Когда поеду в Японию, хочу в Киото.
```
> 💡 たら — самый универсальный условный оператор. Подходит и для «если», и для «когда (в будущем)».

Прилагательные:
- い-прил: 安かったら、買います。
- な-прил/сущ: 静かだったら、いいですね。

## 2. Совет с 〜たらどう / 〜たほうがいい

```
早く予約したほうがいいよ。    — Лучше забронировать заранее.
医者に行ったほうがいいです。  — Тебе лучше сходить к врачу.
```
Отрицание: 〜ないほうがいい (лучше не...):
```
夜ご飯を食べすぎないほうがいい。
```

## 3. Опыт: 〜たことがある

Та-форма + ことがある = «когда-либо делал»:
```
新幹線に乗ったことがありますか。 — Вы когда-нибудь ездили на синкансэне?
寿司を食べたことがない。         — Я никогда не ел суши.
一度富士山に登ったことがある。   — Один раз поднимался на Фудзи.
```

## 4. Может быть: かもしれない

Основа + かもしれない (= может случиться, ~30-70% уверенности):
```
富士山が見られるかもしれない。 — Возможно, будет видно Фудзи.
遅れるかもしれないから、先に行って。— Могу опоздать, так что идите вперёд.
```
Шкала вероятности:
| Слова | Уверенность |
|-------|-------------|
| 必ず | 100% |
| きっと | ~90% |
| だろう／でしょう | ~70% |
| かもしれない | ~50% |

## 5. Похоже на: 〜みたいだ

Существительное + みたい: «похоже, как будто»:
```
ほとんど埋まってるみたい。 — Кажется, всё почти занято.
雨が降ってるみたいです。   — Похоже, идёт дождь.
```

## 6. Даже если: 〜でも

```
雨でも楽しめる。     — Даже в дождь можно весело провести время.
高くても買います。   — Куплю, даже если дорого.
```

## 7. Что взять: ば-условие для советов

Форма еба: 「何を持って行けばいい？」= что взять, чтобы было хорошо?
```
どうすればいいですか。      — Что мне делать?
どこで切符を買えばいい？     — Где купить билет?
```

## 8. Типичные ошибки

❌ 行くたら → ✅ 行ったら (та-форма!)
❌ 乗ったことがありました → ✅ 乗ったことが**あります** (опыт не ставят в прошедшее)
❌ 雨が降るでも → ✅ 雨**が降っ**ても (тэ-форма + も)

## 9. たら в советах и пожеланиях

### 〜たらどうですか（может, стоит...?）
Та-форма + どう:
```
医者に行ったらどうですか。
Может, сходить к врачу?
```
### 〜たらいい（что делать, чтобы вышло хорошо）
Вопрос с interrogative:
```
どこで切符を買ったらいいですか。
Где мне купить билет?
```
Ответ-совет:
```
駅の窓口で買えばいいですよ。
Купите в кассе станции.
```
> **Связка:** вопрос с たらいい → ответ с ばいい. Это устойчивая пара.

### もし＋たら（если вдруг）
もし подчёркивает гипотетичность:
```
もし宝くじが当たったら、世界一周したい。
Если вдруг выиграю в лотерею — вокруг света!
```

## 10. ば-условие: полная таблица образования

| Глагол | Словарная | ば-форма |
|--------|-----------|----------|
| 書く | かく | かけば |
| 読む | よむ | よめば |
| 話す | はなす | はなせば |
| 待つ | まつ | まてば |
| 食べる | たべる | たべれば |
| 見る | みる | みれば |
| する | する | すれば |
| 来る | くる | くれば |
| いい | — | よければ |

Прилагательные:
- い-прил: 安い → 安ければ
- な-прил: 静か → 静かなら（ば）

## 11. Четыре условия: итоговое сравнение

| Форма | Функция | Пример | Перевод |
|-------|---------|--------|---------|
| と | автоматизм, каждый раз | 春になると桜が咲く | Как весна — так сакура |
| ば | логическое следствие | 時間があれば行く | Если будет время — пойду |
| たら | конкретный случай | 家に帰ったら電話する | Как вернусь домой — позвоню |
| なら | реакция на тему | 京都なら新幹線だ | Насчёт Киото — синкансэн |

> **Шпаргалка:** советы → たら／ば；законы → と；беседа → なら. В сомнении берите たら — она универсальна.

## 12. Опыт + частотные наречия

| Наречие | Значение | Пример |
|---------|----------|--------|
| 一度も…ない | ни разу | 一度も行ったことがない。 |
| 何度も | много раз | 何度も読んだことがある。 |
| ときどき | иногда | ときどき作ることがあります。 |
| あまり…ない | нечасто | あまり食べたことがありません。 |
| 初めて | впервые | 初めて食べました。 |

```
日本食は初めてですか。— Впервые пробуете японскую кухню?
いいえ、何度も食べたことがあります。
Нет, ел много раз.
```

## 13. みたい／よう：похожесть и сравнение

Существительное + の／な-прил + みたい:
```
夢みたいな景色ですね。
Пейзаж как во сне.
```
Глагол / い-прил + ように:
```
鳥のように飛びたいです。
Хочу летать как птица.
```
Вывод по признакам (см. также [справочник 063](../cheatsheet/full-grammar.md)):
```
誰もいないようだね。
Кажется, никого нет.
```

## 14. Мини-дриллы (с ответами)

**A. Образуйте たら:**

1. 会う → ＿＿＿＿
2. 高い → ＿＿＿＿
3. する → ＿＿＿＿

<details><summary>Ответы</summary>

1. 会ったら
2. 高かったら
3. したら
</details>

**B. Выберите условие (と/ば/たら/なら):**

1. 十円玉を落とす＿＿、音がする。
2. （会話で）北海道＿、冬が一番いいよ。
3. 疲れ＿＿、休みなさい。

<details><summary>Ответы</summary>

1. と (закономерность)
2. なら (реакция на тему разговора)
3. たら (совет в конкретной ситуации; допустимо ば)
</details>

**C. Переведите с ことがある:**

1. Я никогда не был в Осаке.
2. Он дважды поднимался на Фудзи.

<details><summary>Ответы</summary>

1. 大阪へは一度も行ったことがありません。
2. 彼は二回富士山に登ったことがあります。
</details>
