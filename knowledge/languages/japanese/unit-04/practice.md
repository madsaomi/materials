# Unit 4 — Практика

## Упражнение 1: Приглашения

Составьте приглашения, используя 〜ませんか:

1. 一緒に/コーヒー/飲む → __________
2. 今週末/映画/見る → __________
3. 一緒に/料理/作る → __________
4. 日曜日/公園/行く → __________

## Упражнение 2: Выражение желания (〜たい)

Переведите:

1. Хочу поесть суши. → __________
2. Хочу поехать в Японию. → __________
3. Хочу прочитать эту книгу. → __________
4. Что вы хотите делать сегодня? → __________
5. Хочу пить. → __________

## Упражнение 3: 〜と思う

Закончите предложения:

1. この映画は ___ と思います。(интересный)
2. 明日 ___ と思います。(дождь)
3. 日本語は ___ と思います。(сложный)
4. 彼女は ___ と思います。(красивая)

## Упражнение 4: Диалог

Составьте диалог приглашения друга в кафе, используя:
- 〜ませんか
- 〜たい
- 時間/日付
- 場所

## Упражнение 5: 〜に行く

Составьте предложения:

1. 映画/見る/行く → __________
2. 本/借りる/図書館/行く → __________
3. 買い物/する/行く → __________
4. 泳ぐ/海/行く → __________

## Ответы

**Упражнение 1:**
1. 一緒にコーヒーを飲みませんか。
2. 今週末映画を見ませんか。
3. 一緒に料理を作りませんか。
4. 日曜日公園に行きませんか。

**Упражнение 2:**
1. 寿司を食べたいです。
2. 日本に行きたいです。
3. この本を読みたいです。
4. 今日何をしたいですか。
5. 水を飲みたいです。

**Упражнение 3:**
1. 面白い
2. 雨が降る
3. 難しい
4. 綺麗だ(きれいだ)

**Упражнение 5:**
1. 映画を見に行きます。
2. 図書館に本を借りに行きます。
3. 買い物をしに行きます。
4. 海に泳ぎに行きます。
