# Unit 4 — Грамматика: Приглашения, намерения, выражение чувств

## 1. 〜ませんか (приглашение)

```
映画を見ませんか。        — Не хотите посмотреть фильм?
一緒にご飯を食べませんか。 — Не хотите вместе поесть?
コーヒーを飲みませんか。  — Не выпьете кофе?
```

Вежливое приглашение. Ответы:

```
はい、いいですね。      — Да, отлично.
はい、ぜひ。            — Да, обязательно.
すみません、ちょっと…   — Извините, но...
また今度お願いします。  — В следующий раз.
```

## 2. 〜ましょう (давайте сделаем)

```
会いましょう。       — Давайте встретимся.
行きましょう。       — Давайте пойдём.
食べましょう。       — Давайте поедим.
```

## 3. 〜たい (хочу сделать)

**Присоединяется к основе ます-формы:**

```
食べます → 食べたい    — хочу есть
飲みます → 飲みたい    — хочу пить
行きます → 行きたい    — хочу идти
見ます → 見たい        — хочу посмотреть

日本に行きたいです。   — Хочу поехать в Японию.
何を食べたいですか。   — Что вы хотите есть?
```

**たい в прошедшем:**
```
食べたかった — хотел есть
行きたかった — хотел пойти
```

## 4. 〜と思う (думаю, что〜)

```
明日雨が降ると思います。     — Думаю, завтра будет дождь.
この映画は面白いと思います。 — Думаю, этот фильм интересный.
日本に行きたいと思います。   — Думаю, хочу поехать в Японию.
```

## 5. 〜そう (выглядит / похоже)

```
面白そうですね。     — Выглядит интересно!
美味しそうですね。   — Выглядит вкусно!
大変そうですね。     — Выглядит тяжело!
```

**Правило:** 〜そう для い-прил (убираем い), для な-прил (добавляем к основе)

## 6. 〜が (но / а)

```
日本語は難しいですが、面白いです。 — Японский сложный, но интересный.
行きたいですが、時間がありません。 — Хочу пойти, но нет времени.
```

## 7. Цели: 〜に (для чего, куда)

```
映画を見に行きます。  — Иду смотреть фильм.
本を買いに行きます。  — Иду покупать книгу.
ご飯を食べに行きます。— Иду есть.
```

**Структура:** [ます-основа] + [に] + [глагол движения]

## Упражнения

1. Пригласите: "Не хотите посмотреть фильм?" → __________
2. Выразите желание: "Хочу поесть" → __________
3. Думаю, завтра будет дождь → __________
4. "Выглядит вкусно!" → __________
5. "Иду покупать книгу" → __________

**Ответы:**
1. 映画を見ませんか。
2. 食べたいです。
3. 明日雨が降ると思います。
4. 美味しそうですね！
5. 本を買いに行きます。

## 8. 〜ながら (делая что-то одновременно)

```
歩きながら電話をします。 — Разговариваю по телефону, идя。
食べながらテレビを見ます。 — Смотрю телевизор, едя。
音楽を聞きながら勉強します。 — Учусь, слушая музыку。
```

## 9. 〜たびに (каждый раз, когда)

```
日本に行くたびに、お土産を買います。 — Каждый раз, когда еду в Японию, покупаю сувениры。
会うたびに、笑顔になります。 — Каждый раз, когда вижу, улыбаюсь。
```

## 10. 〜限り (пока, насколько)

```
元気な限り、頑張ります。 — Пока здоров, буду стараться。
時間がある限り、勉強します。 — Пока есть время, учусь。
```

## 11. 〜つつ (пока делаю одно, делаю другое)

```
歩きつつ考えます。 — Иду и думаю。
食べつつ話します。 — Ем и разговариваю。
```
