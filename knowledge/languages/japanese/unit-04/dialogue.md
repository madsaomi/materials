# Unit 4 — Диалог: 趣味と誘い (Хобби и приглашения)

## Диалог

```
鈴木: 木村さんの趣味は何ですか。
木村: 読書と映画鑑賞です。鈴木さんは？
鈴木: 私は料理と写真です。よかったら、今週末一緒に映画を見ませんか。
木村: いいですね。何の映画を見たいですか。
鈴木: 新しいSF映画が面白そうですね。
木村: そうですね。いつがいいですか。
鈴木: 土曜日の午後はどうですか。
木村: 土曜日はちょっと用事があります。日曜日は大丈夫です。
鈴木: では、日曜日の3時はどうですか。
木村: いいですよ。どこで会いますか。
鈴木: 駅の東口はどうですか。
木村: わかりました。日曜日の3時に駅の東口で会いましょう。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 趣味は何ですか | Какое у вас хобби? |
| 読書 | Чтение книг |
| 映画鑑賞 | Просмотр фильмов |
| よかったら | Если хотите |
| 一緒に | Вместе |
| 〜ませんか | Не хотите ли〜? |
| 面白そう | Выглядит интересным |
| 用事があります | Есть дела |
| 大丈夫です | Всё в порядке/подходит |
| 東口 | Восточный выход |
| 会いましょう | Давайте встретимся |
