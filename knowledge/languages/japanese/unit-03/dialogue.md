# Unit 3 — Диалог: 道を尋ねる (Спрашиваем дорогу)

## Диалог

```
観光客: すみません、駅はどこですか。
警官: 駅ですか。あの信号を右に曲がってください。
観光客: 右ですね。どのくらいかかりますか。
警官: 歩いて5分ぐらいです。
観光客: あのう、この近くにコンビニはありますか。
警官: はい、駅の前にあります。
観光客: どうもありがとうございます。
警官: いいえ、気をつけてください。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 駅はどこですか | Где находится станция? |
| 信号 | Светофор |
| 右に曲がってください | Поверните направо |
| どのくらいかかりますか | Сколько времени займёт? |
| 歩いて | Пешком |
| 〜ぐらい | Примерно |
| この近く | Рядом (вблизи) |
| コンビニ | Круглосуточный магазин |
| 駅の前にあります | Есть перед станцией |
| 気をつけてください | Будьте осторожны |
