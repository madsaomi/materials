## 日本の交通 (Транспорт в Японии)

```
日本の電車はとても便利です。
時間通りに来ます。
駅の中に案内板があります。
切符は券売機で買えます。
SuicaやPasmoなどのICカードも使えます。
改札にカードをタッチして入ります。
電車の中では携帯電話を使ってはいけません。
優先席の近くでは電源を切ってください。
駅によってはエレベーターやエスカレーターがあります。
出口の案内に従ってください。
```

### 単語

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 便利 | べんり | удобный |
| 時間通り | じかんどおり | по расписанию |
| 案内板 | あんないばん | информационная табличка |
| 券売機 | けんばいき | билетный автомат |
| ICカード | アイシーカード | IC-карта |
| 改札 | かいさつ | турникет |
| タッチ | — | касание |
| 優先席 | ゆうせんせき | приоритетные места |
| 電源 | でんげん | питание |
| 切る | きる | выключать |
| エレベーター | — | лифт |
| エスカレーター | — | эскалатор |
| 従う | したがう | следовать |

### 翻訳

Японские поезда очень удобны.
Они приходят по расписанию.
На станциях есть информационные табло.
Билеты можно купить в автоматах.
Также можно использовать IC-карты вроде Suica или Pasmo.
Приложите карту к турникету, чтобы войти.
В поезде нельзя пользоваться мобильным телефоном.
Рядом с приоритетными местами выключите телефон.
На некоторых станциях есть лифты и эскалаторы.
Следуйте указателям к выходу.

### 質問

1. 日本の電車はどうですか。
2. 切符はどこで買えますか。
3. Suicaは何ですか。
4. 電車の中で何を使ってはいけませんか。
5. 優先席の近くでは何をしなければなりませんか。

**Ответы:**
1. とても便利です。
2. 券売機で買えます。
3. ICカードです。
4. 携帯電話を使ってはいけません。
5. 電源を切らなければなりません。

## テキスト２：えきへの　みち（Дорога к станции)

```
アリスさんは　はじめて　この　まちに
きました。ホテルへ　行きたいです。
でも、えきが　どこか　分かりません。

そこで、やさしい　おばあさんに　聞きました。

「すみません、えきは　どこですか。」
「えきですね。この　みちを　まっすぐ
　行ってください。信号を　右へ　曲がって、
　五ふんぐらい　歩いてください。」
「ありがとう　ございます。」
「いいえ、どういたしまして。
　気をつけてね。」

おばあさんの　言ったとおりに　行くと、
すぐ　えきが　見えました。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 初めて | はじめて | впервые |
| 分かる | わかる | понимать, знать |
| おばあさん | — | бабушка |
| まっすぐ | — | прямо |
| 信号 | しんごう | светофор |
| 曲がる | まがる | поворачивать |
| 言ったとおり | いったとおり | как сказано |
| 気をつける | きをつける | быть осторожным |

### 翻译 (Перевод)

Алиса впервые в этом городе. Хочет в отель. Но не знает, где станция.

Тогда спросила у доброй бабушки:

— Извините, где станция?
— Станция? Идите прямо по этой дороге. На светофоре поверните направо и минут пять пешком.
— Спасибо большое!
— Не за что. Осторожно там!

Когда пошла, как сказала бабушка, сразу увидела станцию.

### 質問 (Вопросы)

1. アリスさんは　だれに　聞きましたか。
2. 信号を　どちらへ　曲がりますか。
3. 歩いて　どのぐらい　かかりますか。

**Ответы:**
1. やさしいおばあさんに聞きました。
2. 右へ曲がります。
3. 五分ぐらいです。

## テキスト３：バスの　なかで（В автобусе)

```
バスは　まえの　ドアから　乗って、
おわりの　ドアから　降ります。
運賃は　おわりの　ドアの　そばの
機械で　払います。

カードでも　現金でも　いいです。
カードの　ほうが　便利ですが、
小さい　まちでは　現金しか
使えない　ことも　あります。

アリスさんは　カードを　持って
いませんでした。「いくらですか」
と　聞いたら、運転手さんは
「二百円です」と　言いました。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 乗る | のる | садиться |
| 降りる | おりる | выходить |
| 運賃 | うんちん | плата за проезд |
| 払う | はらう | платить |
| 現金 | げんきん | наличные |
| ～しか～ない | — | только (с отрицанием) |
| 運転手 | うんてんしゅ | водитель |

### 翻译 (Перевод)

В автобус входят через переднюю дверь, а выходят через заднюю. Проезд платят у автомата рядом с задней дверью.

Можно картой или наличными. Карта удобнее, но в маленьких городах иногда принимают только наличные.

У Алисы не было карты. Когда она спросила «сколько стоит?», водитель ответил: «двести иен».

### 質問 (Вопросы)

1. バスは　どこで　払いますか。
2. 小さい　まちでは　なにを　使えない　ことが　ありますか。
3. バスの　運賃は　いくらですか。

**Ответы:**
1. おわりのドアのそばの機械で払います。
2. カードを使えないことがあります。
3. 二百円です。

## Как работать с текстами урока 3

1. **Диалог внутри текста** (текст 2) — читайте за двух героев вслух.
2. **Найдите:** ここ・そこ・あそこ, направления（右・左・まっすぐ）, форму ～てください.
3. **Мини-задание:** нарисуйте схему своего района и подпишите по-японски: えき・みせ・こうえん・みち.
