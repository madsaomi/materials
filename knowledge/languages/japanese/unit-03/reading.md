## 日本の交通 (Транспорт в Японии)

```
日本の電車はとても便利です。
時間通りに来ます。
駅の中に案内板があります。
切符は券売機で買えます。
SuicaやPasmoなどのICカードも使えます。
改札にカードをタッチして入ります。
電車の中では携帯電話を使ってはいけません。
優先席の近くでは電源を切ってください。
駅によってはエレベーターやエスカレーターがあります。
出口の案内に従ってください。
```

### 翻訳

Японские поезда очень удобны.
Они приходят по расписанию.
На станциях есть информационные табло.
Билеты можно купить в автоматах.
Также можно использовать IC-карты вроде Suica или Pasmo.
Приложите карту к турникету, чтобы войти.
В поезде нельзя пользоваться мобильным телефоном.
Рядом с приоритетными местами выключите телефон.
На некоторых станциях есть лифты и эскалаторы.
Следуйте указателям к выходу.

### 質問

1. 日本の電車はどうですか。
2. 切符はどこで買えますか。
3. Suicaは何ですか。
4. 電車の中で何を使ってはいけませんか。
5. 優先席の近くでは何をしなければなりませんか。

**Ответы:**
1. とても便利です。
2. 券売機で買えます。
3. ICカードです。
4. 携帯電話を使ってはいけません。
5. 電源を切らなければなりません。
