# Unit 3 — Практика

## Упражнение 1: Направления

Посмотрите на карту и ответьте:

```
        コンビニ
          |
  駅 —— 交差点 —— 図書館
          |
        銀行
```

1. 駅の前に何がありますか。 → __________
2. 銀行はどこにありますか。 → __________
3. コンビニは駅の隣ですか。 → __________
4. 駅から図書館までどうやって行きますか。 → __________

## Упражнение 3: あります / います

Вставьте あります или います:

1. 駅の前にコンビニが___。
2. 公園に子供が___。
3. ここに名前が___。
4. あそこに田中さんが___。
5. 図書館に本が___。
