# Unit 1 — Текст для чтения

## 私の家族 (Моя семья)

```
私の家族は四人です。
父と母と妹と私です。
父は会社員です。
母は看護師です。
妹は高校生です。
私は大学生です。
私たちは東京に住んでいます。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 四人 | よにん | четыре человека |
| 父 | ちち | мой отец |
| 母 | はは | моя мать |
| 妹 | いもうと | младшая сестра |
| 会社員 | かいしゃいん | офисный работник |
| 看護師 | かんごし | медсестра |
| 高校生 | こうこうせい | старшеклассник |
| 大学生 | だいがくせい | студент |
| 住む | すむ | жить |

### 翻訳 (Перевод)

Моя семья — четыре человека.
Отец, мать, младшая сестра и я.
Отец — офисный работник.
Мать — медсестра.
Сестра — старшеклассница.
Я — студент университета.
Мы живём в Токио.

### 質問 (Вопросы к тексту)

1. 家族は何人ですか。
2. 父の仕事は何ですか。
3. 妹は学生ですか。
4. どこに住んでいますか。
5. 著者は学生ですか。

**Ответы:**
1. 四人です。
2. 会社員です。
3. はい、高校生です。
4. 東京に住んでいます。
5. はい、大学生です。
