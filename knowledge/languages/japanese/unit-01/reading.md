# Unit 1 — Текст для чтения

## 私の家族 (Моя семья)

```
私の家族は四人です。
父と母と妹と私です。
父は会社員です。毎日八時に出勤します。
母は看護師です。病院で働いています。
妹は高校生です。放課後、友達と勉強します。
私は大学生です。大学で日本語を勉強しています。
私たちは東京に住んでいます。
週末は一緒に映画を見たり、買い物をしたりします。
```

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 四人 | よにん | четыре человека |

| 母 | はは | моя мать |
| 妹 | いもうと | младшая сестра |
| 会社員 | かいしゃいん | офисный работник |
| 看護師 | かんごし | медсестра |
| 高校生 | こうこうせい | старшеклассник |
| 大学生 | だいがくせい | студент |
| 住む | すむ | жить |
| 出勤 | しゅっきん | выход на работу |
| 病院 | びょういん | больница |

| 放課後 | ほうかご | после школы |

### 翻訳 (Перевод)

Моя семья — четыре человека.
Отец, мать, младшая сестра и я.
Отец — офисный работник. Он каждый день приходит на работу в 8 утра.
Мать — медсестра. Она работает в больнице.
Сестра — старшеклассница. После школы она учится с друзьями.
Я — студент университета. Я изучаю японский в университете.
Мы живём в Токио.
По выходным мы вместе смотрим кино или ходим по магазинам.

### 質問 (Вопросы к тексту)

1. 家族は何人ですか。
2. 父の仕事は何ですか。
3. 妹は学生ですか。
4. どこに住んでいますか。
5. 著者は学生ですか。
6. 母はどこで働いていますか。
7. 週末に何をしますか。

**Ответы:**
1. 四人です。
2. 会社員です。
3. はい、高校生です。
4. 東京に住んでいます。
5. はい、大学生です。
6. 病院で働いています。
7. 一緒に映画を見たり、買い物をしたりします。

## テキスト２：はじめまして（Знакомство)

```
はじめまして。
わたしは　アリスです。ロシアから　きました。
いま　とうきょうの　がっこうで　にほんごを
べんきょうして　います。
かぞくは　五人です。父と　母と　兄と　妹と　わたしです。

しゅみは　おんがくと　スポーツです。
すきな　たべものは　ラーメンです。
どうぞ　よろしく　おねがいします。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ロシア | — | Россия |
| 来る | くる | приезжать |
| 五人 | ごにん | пять человек |
| 兄 | あに | старший брат |
| 趣味 | しゅみ | хобби |
| 音楽 | おんがく | музыка |
| 好きな | すきな | любимый |
| 食べ物 | たべもの | еда |
| どうぞよろしくおねがいします | — | прошу любить и жаловать |

### 翻訳 (Перевод)

Приятно познакомиться. Я Алиса. Приехала из России. Сейчас изучаю японский в токийской школе.
В моей семье пять человек: папа, мама, старший брат, младшая сестра и я.
Мои хобби — музыка и спорт. Любимая еда — рамэн.
Прошу любить и жаловать!

### 質問 (Вопросы)

1. アリスさんは　どこから　きましたか。
2. 何を　べんきょうして　いますか。
3. しゅみは　なんですか。

**Ответы:**
1. ロシアからきました。
2. 日本語を勉強しています。
3. 音楽とスポーツです。

## テキスト３：がっこうの　クラス（Класс в школе)

```
これは　わたしの　クラスです。
学生は　十五人　います。
男の　学生は　六人で、女の　学生は　九人です。
先生は　田中せんせいです。
田中せんせいは　やさしいです。

あの　人は　だれですか。
あれは　けんたさんです。
けんたさんは　私の　ともだちです。
二十さいです。アメリカじんです。
でも、にほんごが　とても　じょうずです。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| クラス | — | класс |
| 十五人 | じゅうごにん | пятнадцать человек |
| 男の人 | おとこのひと | мужчина |
| 女の人 | おんなのひと | женщина |
| やさしい | — | добрый, мягкий |
| だれ | — | кто |
| ～歳 | ～さい | … лет |
| アメリカ人 | アメリカじん | американец |

### 翻訳 (Перевод)

Это мой класс. В нём пятнадцать студентов: шесть юношей и девять девушек. Наш учитель — Танака-сэнсэй. Он очень добрый.

— Кто этот человек?
— Это Кэнта. Он мой друг. Ему двадцать лет. Он американец. Но по-японски говорит отлично.

### 質問 (Вопросы)

1. クラスに　学生は　何人　いますか。
2. 先生は　どんな　ひとですか。
3. けんたさんは　どこの　人ですか。

**Ответы:**
1. 十五人います。
2. やさしい先生です。
3. アメリカ人です。

## Как работать с текстами урока 1

1. **Прочитайте вслух** каждый текст два раза — ставьте произношение с первого дня.
2. **Закройте перевод**, попробуйте пересказать содержание по-русски.
3. **Найдите в тексте:** частицы は・も・の・と, форму です／ます.
4. **Мини-задание:** напишите своё «はじめまして» по образцу текста 2 (5–8 строк). Это ваш первый портфельный текст!

## テキスト４：休みの日 (Выходной день)

```
今日は　日曜日です。
私は　朝　九時に　起きました。
朝ごはんに　パンと　コーヒーを　食べました。
午後は　友達と　公園で　ボールを　しました。
夜は　一人で　家で　テレビを　見ました。
明日から　また　仕事です。
ちょっと　疲れましたが、楽しい　一日でした。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 休みの日 | ясуми но хи | выходной день |
| 起きました | окимасита | встал, проснулся |
| 朝ごはん | асагохан | завтрак |
| パン | пан | хлеб |
| 公園 | ко:эн | парк |
| ボール | бо:ру | мяч |
| 一人で | хиторидэ | один |
| テレビ | тэрэби | телевизор |
| 仕事 | сигото | работа |
| 疲れました | цукарэмасита | устал |
| 楽しい | таносий | весёлый, приятный |

### 翻訳 (Перевод)

Сегодня воскресенье. Утром я встал в девять часов. На завтрак съел хлеб и кофе. Днём играл с другом в парке в мяч. Вечером один смотрел телевизор дома. С завтрашнего дня снова работа. Немного устал, но день был приятный.

### 質問 (Вопросы)

1. 今日は何曜日ですか。
2. 朝、何時に起きましたか。
3. 午後はどこで何をしましたか。
4. 夜は何をしましたか。

**Ответы:**
1. 日曜日です。
2. 九時に起きました。
3. 公園でボールをしました。
4. 一人で家でテレビを見ました。

## テキスト５：私の好きなもの (Что я люблю)

```
私は　猫が　大好きです。
私の　家に　猫が　一匹　います。
名前は　「ミルク」です。三歳です。
ミルクは　白い　猫です。
毎朝　ミルクに　ご飯を　あげます。
ミルクは　魚が　好きです。
でも、野菜は　あまり　好きじゃありません。
ミルクと　一緒に　遊ぶのが　私の　楽しみです。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 猫 | нэко | кошка |
| 大好き | дайсуки | очень люблю |
| 一匹 | иппики | одна (мелкое животное) |
| 名前 | намаэ | имя |
| 三歳 | сансай | три года (возраст) |
| 白い | сирой | белый |
| ご飯 | гохан | еда, рис |
| あげます | агэмасу | давать (кому-то) |
| 魚 | сакана | рыба |
| 野菜 | ясай | овощи |
| 一緒に | иссёни | вместе |
| 遊ぶ | асобу | играть |
| 楽しみ | таносими | источник радости, удовольствие |

### 翻訳 (Перевод)

Я очень люблю кошек. У меня дома есть одна кошка. Её зовут «Милк». Ей три года. Милк — белая кошка. Каждое утро я даю Милк еду. Милк любит рыбу. Но овощи не очень любит. Играть вместе с Милк — моя радость.

### 質問 (Вопросы)

1. ミルクはどんな猫ですか。
2. ミルクは何歳ですか。
3. 毎朝、何をしますか。
4. ミルクは野菜が好きですか。

**Ответы:**
1. 白い猫です。
2. 三歳です。
3. ミルクにご飯をあげます。
4. いいえ、あまり好きじゃありません。
