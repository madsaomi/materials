# Unit 1 — Грамматика

## 1. AはBです (А — это Б)

```
私は学生です。     — Я студент.
田中さんは先生です。 — Господин Танака — учитель.
これは本です。      — Это книга.
```

**Структура:** [Тема] は [Описание] です

**Отрицание:** では ありません / じゃ ありません
```
学生ではありません。 — Я не студент.
先生じゃありません。 — Я не учитель.
```

## 2. AはBですか (Вопрос)

```
学生ですか。        — Вы студент?
田中さんですか。    — Вы господин Танака?
これは本ですか。    — Это книга?
```

**Ответы:**
```
はい、そうです。     — Да, это так.
いいえ、違います。  — Нет, не так.
いいえ、そうじゃありません。 — Нет, это не так.
```

## 3. Указательные местоимения

| Слово | Значение | Пример |
|-------|----------|--------|
| これ | это (близко) | これは本です |
| それ | то (ближе к слуш.) | それはペンです |
| あれ | вон то (далеко) | あれは山です |
| この[N] | этот N | この本は面白い |
| その[N] | тот N | その人を知っています |
| あの[N] | вон тот N | あの建物は駅です |

## 4. の (притяжательная частица)

```
私の本      — моя книга
田中さんの電話 — телефон г-на Танаки
大学の先生  — учитель университета
```

## 5. も (тоже)

```
私も学生です。    — Я тоже студент.
これも本です。    — Это тоже книга.
```

## 6. Вопросы с вопросительными словами

| Слово | Значение |
|-------|----------|
| 何 (なん/なに) | что |
| 誰 (だれ) | кто |
| どこ | где |
| いつ | когда |
| なぜ/どうして | почему |
| どのくらい | сколько/как долго |

## 7. Глаголы: ます-форма (вежливая)

| Группа | Слов. форма | ます-форма |
|--------|-------------|-----------|
| I | 行く (いく) | 行きます |
| I | 会う (あう) | 会います |
| I | 書く (かく) | 書きます |
| II | 食べる (たべる) | 食べます |
| II | 見る (みる) | 見ます |
| III | する | します |
| III | 来る (くる) | 来ます (きます) |

## 8. 〜ています (действие в процессе/состояние)

```
勉強しています。    — Учусь (в процессе).
住んでいます。      — Живу (состояние).
知っています。      — Знаю.
```
