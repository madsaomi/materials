# Unit 1 — Диалог: 初めまして (Приятно познакомиться)

## Диалог

```
田中: 初めまして、田中です。よろしくお願いします。
佐藤: 初めまして、佐藤です。こちらこそよろしくお願いします。
田中: お仕事は何ですか。
佐藤: エンジニアです。田中さんは？
田中: 私は学生です。大学で日本語を勉強しています。
佐藤: そうですか。どのくらい勉強していますか。
田中: 半年です。まだあまり上手じゃありません。
佐藤: いいえ、とても上手ですよ。
田中: ありがとうございます。頑張ります。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 初めまして | Приятно познакомиться |
| 田中です | Я Танака |
| よろしくお願いします | Прошу любить и жаловать |
| こちらこそ | Взаимно |
| お仕事は何ですか | Кем вы работаете? |
| エンジニアです | Я инженер |
| 学生です | Я студент |
| 日本語を勉強しています | Учу японский |
| どのくらい | Как долго / Насколько |
| 半年 | Полгода |
| まだあまり上手じゃありません | Ещё не очень хорошо |
| とても上手ですよ | Очень хорошо! |
| 頑張ります | Буду стараться |
