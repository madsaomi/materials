# Unit 1 — Диалог: 初めまして (Приятно познакомиться)

## Ситуация

Танака и Сато познакомились на вечеринке у общего друга. Они стоят у балкона, наливают себе чай. Танака — новый студент в университете, Сато — уже второй курс. Они только что узнали, что учатся в одной программе.

## Диалог

```
Танака: あのう、すみません。お名前はどちらですか。
佐藤: 佐藤です。佐藤美咲です。よろしくお願いします。
田中: 田中太郎です。はじめまして。よろしくお願いします。
佐藤: はじめまして！大学はどこからですか。
田中: 東京大学からです。大学院で日本語を勉強しています。
佐藤: そうですか！私は工学部の2年生です。田中さんは大学院なんですね。
田中: はい。でもまだ日本語がうまくできません。
佐藤: いいえ、大丈夫ですよ。一緒に勉強しましょう！
田中: ありがとうございます。助かります。
佐藤: それより、田中さんは何が趣味ですか。
田中: 読書と映画鑑賞です。あなたは？
佐藤: 料理と旅行です。暇なときは新しいレシピを試します。
田中: おもしろいですね！いつか一緒に料理しましょう。
佐藤: いいですね！それは楽しみです。
```

## Перевод

| Японский | Русский |
|----------|---------|
| あのう、すみません | Э-э, простите (чтобы привлечь внимание) |
| お名前はどちらですか | Как вас зовут? (вежл.) |
| 佐藤です。佐藤美咲です | Я Сато. Сато Мисаки |
| よろしくお願いします | Прошу вас / Буду признателен |
| 田中太郎です | Я Танака Таро |
| はじめまして | Приятно познакомиться |
| 大学はどこからですか | Вы из какого университета? |
| 東京大学からです | Из Токийского университета |
| 大学院で日本語を勉強しています | Учу японский в аспирантуре |
| 工学部の2年生です | Второкурсник инженерного факультета |
| 一緒に勉強しましょう | Давайте учиться вместе |
| 趣味は何ですか | Какое у вас хобби? |
| 読書と映画鑑賞です | Чтение и просмотр фильмов |
| 新しいレシピを試します | Пробую новые рецепты |
| 一緒に料理しましょう | Давайте приготовим вместе |
