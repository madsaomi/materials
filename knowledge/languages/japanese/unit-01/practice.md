# Unit 1 — Практика

## Упражнение 1: Заполните пропуски

1. 私___学生です。
2. これ___本ですか。
3. 田中さん___先生です。
4. 私___学生です(тоже)。
5. これは私___本です。

**Варианты:** は、の、も

## Упражнение 2: Переведите на японский

1. Доброе утро. → __________
2. Кто этот человек? → __________
3. Моя книга. → __________
4. Сколько это стоит? → __________
5. Извините, который час? → __________

## Упражнение 3: Выберите правильное

1. これは(私/あなた)の本です。— Это моя книга.
2. (どこ/だれ)ですか。— 田中です。
3. (いつ/なぜ)日本に行きますか。— 来年行きます。
4. 学生(です/ではありません)。— Я не студент.
5. はい、そう(です/ではありません)。— Да, это так.

## Упражнение 4: Постройте диалог

Расположите реплики в правильном порядке:

- [ ] はい、学生です。
- [ ] いいえ、違います。佐藤です。
- [ ] こちらこそ、よろしくお願いします。
- [ ] 初めまして、田中です。
- [ ] 学生ですか。
- [ ] 田中さんですか。
