# Unit 13 — Диалог: もしも話（Разговор «а если бы»)

## Ситуация

Юки пришла к Алисе с новостью：она думает уволиться и открыть своё кафе. Танака скептичен. За чашкой чая разгорается спор, в котором каждая реплика —— упражнение на условия: если бы, когда бы, даже если бы.

## Диалог

```
ユキ：聞いて。私、会社を辞めて、カフェを開こうと思ってるの。
アリス：えっ！急だね。何かあったの？
ユキ：毎日残業ばかり。もっと自由に働きたいの。
タナカ：でも、お金はあるの？開店資金は三百万くらいかかるって。
ユキ：貯金があれば、なんとかなると思う。
タナカ：甘いなあ。もし失敗したら、どうするつもり？
ユキ：失敗しても、経験になるじゃない。
タナカ：経験だけでは食べていけないよ。場所が見つかれば
　　　　まだしも、今は不動産も高いし…。
アリス：二人とも、落ち着いて。ユキちゃんが本気なら、
　　　　まずアルバイトでカフェを勉強すればいいんじゃない？
ユキ：それもそうね。アリスさんの店で教えてもらおうかな。
タナカ：よし、それなら応援するよ。夢は大切だからね。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 会社を辞めて | уволиться с работы |
| 開店資金 | стартовый капитал |
| 貯金があれば、なんとかなる | Если есть накопления， как-нибудь выкрутимся |
| 失敗しても、経験になる | Даже если провалюсь —— опыт |
| 経験だけでは食べていけない | Опытом сыт не будешь |
| 場所が見つかればまだしも | Если бы нашлось место —— ладно бы |
| 本気なら | Если она серьёзно |
| 応援するよ | Поддержу тебя |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 辞める | やめる | увольняться |
| 開店資金 | かいてんしきん | капитал на открытие |
| 貯金 | ちょきん | накопления |
| 甘い | あまい | наивный（перен.) |
| 不動産 | ふどうさん | недвижимость |
| 本気 | ほんき | серьёзные намерения |
| 応援する | おうえんする | поддерживать |
| 夢 | ゆめ | мечта |

## Культурная заметка

**Японский страх перемен（リスク回避)**: фраза「まだしも」и подсчёт рисков до мечты —— типично японский стиль спора. Но молодое поколение всё чаще выбирает「起業」（предпринимательство): за последние годы число молодых кафе-владельцев выросло вдвое. Спор Юки и Танаки —— классика поколений.
