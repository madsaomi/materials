# Unit 8 — Диалог: 誕生日のプレゼント (Подарок на день рождения)

## Ситуация

Скоро день рождения мамы Алисы. Она советуется с Юки, что подарить. Заодно вспоминают, кто кому что дарил и чем помогал — идеальный контекст для あげる/くれる/もらう.

## Диалог

```
アリス：ゆきちゃん、ちょっと相談があるんだけど、いい？
ゆき：うん、何でも聞いて。
アリス：来週、母の誕生日なんだ。何をあげたらいいかな。
ゆき：お母さんは何が好き？
アリス：花が大好き。それから、甘いものもよく食べるよ。
ゆき：じゃあ、花とケーキをあげたらどう？
アリス：いいね！去年はマフラーをあげたけど、今年は花にする。
ゆき：お母さんは喜ぶと思うよ。
アリス：そう言ってもらえると嬉しいな。
ゆき：あ、そうだ。誕生日カードも書いてあげたら？手書きの手紙って嬉しいよ。
アリス：そうだね。日本語で書いてみようかな。
ゆき：間違えても、心がこもってるから大丈夫。
アリス：ゆきちゃんがアドバイスしてくれて助かったよ。
ゆき：また分からないことがあったら、いつでも聞いてね。
```

## Перевод

| Японский | Русский |
|----------|---------|
| 相談がある | хочу посоветоваться |
| 何でも聞いて | спрашивай о чём угодно |
| 何をあげたらいいかな | что бы ей подарить? |
| 甘いもの | сладкое |
| 花とケーキをあげたらどう | как насчёт подарить цветы и торт? |
| 去年はマフラーをあげた | в прошлом году подарила шарф |
| 喜ぶと思う | думаю, обрадуется |
| カードも書いてあげたら | напиши ещё и открытку |
| 心がこもってる | от души |
| アドバイスしてくれて助かった | спасибо за совет, выручила |
| いつでも聞いてね | спрашивай в любое время |

## Новые слова из диалога

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 相談 | そうだん | консультация, совет |
| 誕生日 | たんじょうび | день рождения |
| プレゼント | — | подарок |
| 花 | はな | цветы |
| 甘い | あまい | сладкий |
| ケーキ | — | торт |
| マフラー | — | шарф |
| 喜ぶ | よろこぶ | радоваться |
| 助かる | たすかる | быть спасённым/вырученным |

## Культурная заметка

**О-каэси (お返し)** — японская традиция «возвращать» подарки. Получив подарок, японец чувствует обязанность ответить тем же (обычно вдвое дешевле). Летний подарок оти:гэн (お中元) и зимний осэйбо (お歳暮) поддерживают отношения между коллегами и родственниками.

**Что дарят:** деньги кладут только в специальный конверт (ぽち袋). Наборы из четырёх предметов не дарят — число 四 звучит как 死 (смерть). Ножницы и ножи символизируют «разрыв отношений» — их тоже избегают.

# Дополнительные диалоги

## Диалог 2: 母の日 (День матери) — сын помогает выбрать подарок

> Сценарий: Кэн и его младший брат Таро покупают маме подарок. Кэн предлагает, Таро сомневается.

```
ケン：もうすぐ母の日だね。何を買ってあげる？
タロウ：うーん、迷ってる。お母さんは何が欲しいかな。
ケン：前に「新しい財布が欲しい」って言ってたよ。
タロウ：本当？じゃあ、財布を買ってあげようか。
ケン：いいね。でも、一緒に選んでくれたら嬉しいよ。
タロウ：もちろん。二人で買ってあげよう。
ケン：よかった。お母さんに買ってもらったお金で、今度は僕たちが買ってあげる番だね。
タロウ：うん。ラッピングもお願いしよう。
ケン：そうしよう。母の日までに準備しておくよ。
タロウ：ありがとう、ケン兄。助かった！
ケン：どういたしまして。タロウが選んでくれて、花も追加で買っておくね。
```

### Перевод (диалог 2)

| Японский | Русский |
|----------|---------|
| 母の日 | День матери |
| 何を買ってあげる？ | что купим для мамы? |
| 迷ってる | сомневаюсь |
| 新しい財布 | новый кошелёк |
| 一緒に選んでくれたら嬉しい | был бы рад, если б ты выбрал вместе со мной |
| 二人で買ってあげよう | купим вдвоём (для неё) |
| 買ってもらったお金 | деньги, которые мы получили (от неё) |
| 買ってあげる番だ | наша очередь покупать ей |
| ラッピングもお願いしよう | попросим и упаковку |
| 花も追加で買っておくね | куплю ещё и цветы впрок |

### Разбор ключевых конструкций

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 買ってあげよう | давай купим для неё (〜てあげる) | 財布を買ってあげよう。 |
| 選んでくれたら | если бы ты помог выбрать (〜てくれる + услов.) | 一緒に選んでくれたら。 |
| 買ってもらったお金 | деньги, которые нам дали (〜てもらう) | お母さんに買ってもらった。 |
| 買っておく | купить заранее (〜ておく) | 花を買っておく。 |

## Диалог 3: お願い — просьба об услуге (в офисе)

> Сценарий: Ёко просит коллегу Сато помочь с переводом документа и потом благодарит. Демонстрирует 〜ていただけますか, 〜てくれる, 〜てもらう.

```
ヨウコ：さとうさん、ちょっとお願いがあるんですが…。
さとう：はい、何でしょう？
ヨウコ：この書類を翻訳していただけませんか。来週の会議までに必要なんです。
さとう：いいですよ。いつまでにお渡ししましょうか。
ヨウコ：金曜日までにお願いできますか。
さとう：分かりました。金曜日までに翻訳しておきますね。
ヨウコ：本当に助かります。ありがとうございます。
　（金曜日、さとうが書類を渡してくれる）
さとう：はい、翻訳した書類です。確認していただけますか。
ヨウコ：ありがとうございます。さとうさんに翻訳してもらえて、とても助かりました。
さとう：いいえ、どういたしまして。また何かあったら言ってください。
ヨウコ：次は私がお手伝いしますね！
```

### Перевод (диалог 3)

| Японский | Русский |
|----------|---------|
| お願いがある | у меня просьба |
| 翻訳していただけませんか | не могли бы вы перевести? (максимально вежливо) |
| 会議までに必要 | нужно к совещанию |
| いつまでにお渡ししましょうか | к какому сроку передать? (скромно) |
| 翻訳しておきます | переведу заранее (〜ておく) |
| 確認していただけますか | не могли бы проверить? |
| 翻訳してもらえて助かった | очень выручил, что перевёл |
| どういたしまして | не за что |
| 次は私がお手伝いします | в следующий раз я помогу |

### Разбор ключевых конструкций

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜ていただけませんか | максимально вежливая просьба | 翻訳していただけませんか。 |
| お渡しする | скромное «передать» (謙譲語) | 金曜日にお渡しします。 |
| 〜ておきます | сделать заранее | 翻訳しておきます。 |
| 翻訳してもらえて | мне перевели (благодарность) | 翻訳してもらえて助かった。 |
| お手伝いします | скромное «помогу» (お〜する) | 私がお手伝いします。 |

## Диалог 4: 引っ越しの手伝い (Помощь с переездом)

> Сценарий: Друг Кэна переезжает. Кэн и ещё один друг помогают. Показаны てあげる, てくれる, てくれるか, благодарность.

```
ケン：いよいよ明日、引っ越しだね。手伝いに行くよ。
エミ：本当？ありがとう。車を出してくれる？とても助かるんだけど。
ケン：もちろん。荷物はいつ運べばいい？
エミ：午前中に運んでもらえたら嬉しいな。
ケン：分かった。じゃあ、君の家に９時に行くね。
エミ：ありがとう、ケン。引っ越しの後、お昼をごちそうするよ。
ケン：それは楽しみ！じゃあ、午前中に荷物を持ってあげるよ。
エミ：お弁当も用意しておくね。
ケン：エミがお弁当を作ってくれるなんて、最高だよ！
エミ：ケンに手伝ってもらって、本当に安心したよ。
```

### Перевод (диалог 4)

| Японский | Русский |
|----------|---------|
| 引っ越し | переезд |
| 手伝いに行く | иду помогать |
| 車を出してくれる？ | подкинешь на машине? (для меня) |
| 運んでもらえたら嬉しい | буду рада, если перенесёшь |
| ごちそうする | угостить |
| 荷物を持ってあげる | понесу твои вещи (для тебя) |
| お弁当を用意しておく | приготовлю бэнто заранее |
| 作ってくれるなんて | что ты приготовишь для меня — это... |
| 手伝ってもらって安心した | очень спокойно, что ты помог |

### Разбор ключевых конструкций

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 〜てくれる？ | неофициальная просьба для меня | 車を出してくれる？ |
| 〜てもらえたら嬉しい | буду рада, если (мягкая просьба) | 運んでもらえたら嬉しい。 |
| 〜てあげる | сделать для другого | 荷物を持ってあげる。 |
| 〜てもらって安心 | спокойствие от получения помощи | 手伝ってもらって安心した。 |
