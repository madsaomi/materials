# Unit 8 — Чтение: お礼の手紙 (Благодарственное письмо)

## Текст

> Алиса пишет письмо японской хозяйке дома, где она гостила неделю.

```
佐藤様

一週間、大変お世話になりました。
毎日美味しい料理を作ってくださって、
本当にありがとうございました。

東京のいろいろな所へ連れて行って
もらって、とても楽しかったです。
特に美術館の案内をしてくださったのが
印象に残っています。

これ、あまり高価な物ではありませんが、
心ばかりの贈り物です。どうぞ
受取ってください。

今度はぜひロシアへ遊びに来てください。
私がご案内します。

アリスより
```

## Вопросы к тексту

1. За что Алиса благодарит госпожу Сато?
2. Что произвело самое сильное впечатление?
3. Что Алиса отправила вместе с письмом?
4. Какое приглашение она передала?

## Словарь к тексту

| Слово | Чтение | Перевод |
|-------|--------|---------|
| お世話になる | おせわになる | быть под опекой, пользоваться заботой |
| 連れて行く | つれていく | вести, отвозить |
| 特に | とくに | особенно |
| 案内 | あんない | экскурсия, сопровождение |
| 印象に残る | いんしょうにのこる | запомниться |
| 高価 | こうか | дорогой (о цене) |
| 心ばかり | こころばかり | скромный дар (устойчивое) |
| 受け取る | うけとる | принимать |
| 遊びに行く | あそびにいく | приезжать в гости |

## Разбор грамматики в тексте

**作ってくださって**
→ て + くださる (вежливый くれる): «вы готовили для меня».

**連れて行ってもらって**
→ てもらう: «меня водили (по её инициативе и моему согласию)».

**ご案内します**
→ 謙譲語: скромное «я вас провожу». Приставка ご/お + する принижает своё действие.

**アリスより**
→ より после имени = «от Алисы», формальное завершение письма.

## Письменное задание

Напишите благодарственное письмо (6–8 предложений) человеку, который вам помог:
- Используйте てくださって、ありがとうございました
- Упомяните конкретную услугу (〜てもらいました)
- Закончите приглашением (ぜひ〜てください)
