# Unit 8 — Грамматика: Дарение и услуги (あげる・くれる・もらう)

## 1. Три глагола передачи

Ключ к японскому вежливому мышлению: **направление** передачи.

| Глагол | Направление | Кто главный |
|--------|-------------|-------------|
| あげる | я → другой, другой → другому | даю Я |
| くれる | другой → мне (в мою сторону) | дают МНЕ |
| もらう | я получаю ← от другого | получаю Я |

```
私は田中さんに本をあげた。     — Я подарил Танаке книгу. (я → он)
田中さんが私に本をくれた。     — Танака подарил мне книгу. (он → я)
私は田中さんに本をもらった。   — Я получил книгу от Танаки.
```

## 2. Схема предложения

```
 giver は/が  receiver に  предмет を  あげる/くれる
 receiver は  giver から/に  предмет を  もらう
```
> ⚠️ При もらう источник — частица に или から.

## 3. Вежливые версии

| Обычный | Вежливый (уважение) | Скромный |
|---------|---------------------|----------|
| あげる | 差し上げる(さしあげる) | — |
| くれる | 下さる(くださる) | — |
| もらう | — | 頂く(いただく) |

```
先生が本をくださいました。     — Учитель дал мне книгу (вежливо).
先生に本をいただきました。     — Я получил книгу от учителя (скромно).
```

## 4. Услуги: тэ-форма + эти же глаголы

Тэ-форма + あげる/くれる/もらу = «сделать для кого-то / для меня»:

| Форма | Значение | Пример |
|-------|----------|--------|
| 〜てあげる | сделать ДЛЯ другого | 友達に荷物を持っててあげた。 |
| 〜てくれる | сделали ДЛЯ меня | 母が弁当を作ってくれた。(Мама сделала мне бэнто) |
| 〜てもらう | я попросил и мне сделали | 先生に作文を見てもらいました。(Учитель проверил моё сочинение) |

> 💡 〜てくれる выражает благодарность: 日本語を教えてくれてありがとう。

## 5. Просьба об услуге

```
写真を撮ってもらえますか。       — Не могли бы вы меня сфотографировать?
手伝っていただけますか。         — Не поможете ли? (вежливее)
教えてくれてありがとう。         — Спасибо, что научили.
```

## 6. Совет: 〜たらどう / 〜たらいい

Та-форма + どう/いい: «как насчёт того, чтобы...»
```
何をあげたらいいですか。    — Что мне подарить?
休んだらどうですか。        — Может, отдохнёшь?
```

## 7. Типичная ошибка

❌ 田中さんに本をもらいました (книга от Танаки → правильно с に, но запомните схему!)
✅ 田中さん**が**本をくれました = 田中さん**に**本をもらいました (одно и то же событие, разные фокусы)

## 8. Полная таблица: кто кому что

| Ситуация | Глагол | Пример |
|----------|--------|--------|
| Я → друг | あげる | 友達に花をあげた。 |
| Друг → я | くれる | 友達が（私に）花をくれた。 |
| Я ← от друга | もらう | 私は友達から花をもらった。 |
| Я → учитель | 差し上げる | 先生にお土産を差し上げました。 |
| Учитель → я | 下さる | 先生が本を下さいました。 |
| Я ← от учителя | 頂く | 先生から辞書を頂きました。 |

> **Запомните:** направление вверх по социальной лестнице = вежливые формы. К друзьям и семье — обычные.

## 9. 貸す／借りる — одолжить / взять

Направление противоположно русскому «одолжить»:
```
友達にお金を貸しました。— Одолжил другу денег (ДАЛ).
友達からお金を借りました。— Взял у друга в долг.
```
```
ペンを貸していただけますか。— Не одолжите ручку?
```
> **Ловушка:** русское «он мне одолжил» = 彼が（私に）貸してくれた — глагол ДАЮЩЕГО.

## 10. Просьбы: лестница вежливости

| Форма | Уровень | Пример |
|-------|---------|--------|
| 〜て | близкие | 待って！ |
| 〜てください | стандарт | 写真を撮ってください。 |
| 〜てもらえますか | мягко | 窓を開けてもらえますか。 |
| 〜てくれますか | дружелюбно | 手伝ってくれますか。 |
| 〜ていただけますか | вежливо | 教えていただけますか。 |
| 〜ていただけませんか | максимально | ご確認していただけませんでしょうか。 |

Ответ на услугу:
```
ありがとうございます。助かりました！
Спасибо! Вы меня выручили!
```

## 11. Благодарность за услугу: てくれて／てもらって

Тэ-форма + くれて + ありがとう — благодарность за сделанное для меня:
```
手伝ってくれてありがとう。
Спасибо, что помог (мне).
```
Через もらう — с оттенком «выручил»:
```
来てもらえて助かりました。
Что вы пришли — очень выручило.
```

## 12. Сожаление о несделанном: 〜てくれれば…のに

Условная форма + のに — «если бы ты сделал..., было бы хорошо»:
```
手伝ってくれればよかったのに。
Жаль, что не помог (а ведь мог бы).
```

## 13. Подарочная культура: полезные формулы

| Ситуация | Что говорят |
|----------|-------------|
| Вручаю подарок | つまらないものですが…（Скромный дар, но...） |
| Получаю подарок | ありがとうざいます。いただきます。 |
| Открываю при дарящем? | 開けてもいいですか。 |
| Хвалю подарок | 素敵ですね！大切にします。 |
| Отказываюсь от дорогого | 気持ちだけ受け取ります。 |

> **Культура:** японцы часто НЕ открывают подарок при дарящем — чтобы никого не смутить. Уточнить можно: 今、開けてもいいですか。

## 14. Мини-дриллы (с ответами)

**A. Выберите глагол (あげる/くれる/もらう):**

1. 姉が私にセーターを編んで＿＿＿。
2. 私は隣の人に荷物を持って＿ ＿ ＿。
3. 医者に見て＿ ＿ ＿。

<details><summary>Ответы</summary>

1. くれた（сестра → ко мне）
2. あげました（я → соседу）
3. もらいました（попросил врача — осмотрели меня）
</details>

**B. Перефразируйте через もらう:**

母が弁当を作ってくれた。

<details><summary>Ответы</summary>

私は母に弁当を作ってもらった。
</details>

**C. Переведите:**

1. Не могли бы вы подождать немного?
2. Спасибо, что научили меня кандзи!

<details><summary>Ответы</summary>

1. 少し待っていただけませんか。
2. 漢字を教えてくれてありがとう！（или：教えてくださって、ありがとうございます）
</details>
