## 1. Почему повторение важнее новой лексики

Кривая забывания (Эббингауз): без повторения через 24 часа остаётся ~33% информации. SRS (Spaced Repetition System — система интервальных повторений) перестраивает график так, чтобы карточка появлялась **ровно перед забыванием**.

| Без системы | С SRS |
|---|---|
| Повторение «волнами» перед тестом | Повторение каждый день по чуть-чуть |
| Через месяц — почти всё забыто | Через месяц — 90%+ в долговременной памяти |
| Мотивация падает от «зубрёжки» | Поток карточек маленький, но постоянный |
| Нет данных о слабых местах | Видно, какая карточка «умирает» чаще всего |

**Главное правило SRS:** новые карточки — маленькими порциями (5–20 в день), старые — с растущими интервалами (день, 3 дня, неделя, месяц, 3 месяца…).

## 2. График интервалов: классика 1-3-7-14-30-90

Рекомендуемая лесенка интервалов для самостоятельного изучения без Anki:

| Этап | Интервал | Что делать |
|---|---|---|
| 1 | сразу | Прочитали новый блок материала |
| 2 | +1 день | Первый активный тест: закрыли ответ рукой |
| 3 | +3 дня | Второй тест + записали проблемные пункты |
| 4 | +7 дней | Третий тест по всей теме |
| 5 | +14 дней | Четвёртый тест, смешали с соседней темой |
| 6 | +30 дней | Пятый тест «всё сразу» |
| 7 | +90 дней | Контрольный срез перед JLPT |

Практично: заведите в телефоне напоминание на интервалы **относительно даты первого изучения**. Одна карточка, пройденная по этой лесенке, не требует больше повторений кроме редких срезов.

## 3. Anki: настройки колоды

Anki — бесплатное приложение с открытым исходным кодом. Ниже — рекомендованные настройки для японского.

### 3.1 Основные настройки колоды (Deck Options)

| Параметр | Значение | Комментарий |
|---|---|---|
| New cards/day | 15 (максимум 20) | Больше — карточки накапливаются в очереди |
| Maximum reviews/day | 200 | Хватит с запасом, очередь редко превышает 150 |
| New card order | По дате добавления | Легче искать «хвосты» |
| Starting ease | 250% | Классический множитель роста интервала |
| Interval modifier | 100% | Оставляем как есть |
| Maximum interval | 365 дней | После года карточка почти не нуждается в повторе |
| Lapses (провалы) | откладывать на 1 день | Не «наказывать» себя большим сбросом |
| Bury new cards until next day | включено | Не смешивать новые и повторные в один замес |
| FSRS (если доступна) | включить, см. 3.2 | Современный алгоритм точнее SM-2 |

### 3.2 FSRS vs классический SM-2

| Параметр | SM-2 (классика) | FSRS |
|---|---|---|
| Формула интервала | Фиксированные множители 2.5 | Подгоняется под вашу статистику |
| Ответ «Again» | Интервал сбрасывается сильно | Сбрасывается мягко, по данным |
| Требует настройки | Нет | Да, один раз (R = 0.9 ideal retention) |
| Итог | Предсказуемо, надёжно | ±15% меньше повторений при той же памяти |

Для японского начинающим разница небольшая — главное включить одну из двух систем и не дёргать настройки бездумно. Если Anki предлагает FSRS — включите, параметр желаемого удержания (desired retention) поставьте **0.90**.

### 3.3 Разметка карточек в Anki (полезные поля)

| Поле | Содержание | Пример |
|---|---|---|
| Front | Вопрос: слово/кандзи/пример с пропуском | 図書館 の読み方と意味 |
| Back | Ответ: чтение, перевод, пример | としょかん — библиотека |
| Hint | Подсказка (доп. поле) | «место, где берут книги» |
| Tags | JLPT-уровень и тема | `jlpt_n5`, `читание`, `животные` |
| Note | Мнемоника или исключение | 本 → ほん, но 三本 → さんぼん |

Теги обязательны: по ним строятся подколоды для экзамена (regex «tag:jlpt_n5»).

## 4. Техника Лейтнера (Leitner Box)

Коробочный метод без компьютера: пачки карточек распределяются по конвертам/коробкам с растущими интервалами.

| Коробка | Интервал | Что попадает | Правило |
|---|---|---|---|
| Box 1 | Ежедневно | Новые карточки | Ответили верно → в Box 2; ошибка → остаётесь в Box 1 |
| Box 2 | Каждые 2–3 дня | Повторные | Верно → Box 3; ошибка → в Box 1 |
| Box 3 | Раз в неделю | Хорошо изученные | Верно → Box 4; ошибка → Box 1 |
| Box 4 | Раз в 2 недели | Прочные | Верно → Box 5; ошибка → Box 1 |
| Box 5 | Раз в месяц | «Пожизненный багаж» | Ошибка → Box 1 |

**Аналог на бумаге:** 5 конвертов с надписями «День», «3 дня», «Неделя», «2 недели», «Месяц». Каждое утро берёте тот конверт, чей срок наступил. Ошибка сбрасывает карточку в первый конверт — это нормально, «падает» информация, а не вы.

**Важно:** в коробку за «верный ответ» кладём только если ответили уверенно, без подглядывания. «Почти угадал» — ошибка.

## 5. Дневник повторения (как строить)

Дневник — таблица, в которой фиксируются темы, даты ближайших повторений и результаты тестов. Образец:

| Дата | Тема | Карточки | Результат | Ошибки | Следующий повтор |
|---|---|---|---|---|---|
| 14.03 | Частицы は/が | 20 новых + 15 повтора | 88% | が после 好き употреблён с は | 17.03 |
| 15.03 | Спряжение группы I | 25 новых | 76% | 行って и 行った фонетика | 18.03 |
| 16.03 | Счётные суффиксы | 30 новых | 92% | 三本 (さんぼん) | 19.03 |
| 17.03 | Повтор частиц | 35 повтора | 95% | — | 22.03 |
| 18.03 | Повтор спряжения | 28 повтора | 84% | — | 25.03 |

Правила ведения дневника:

1. Каждая строка = один день и одна заметная тема (не «переделал всё»).
2. Графа «Ошибки» — конкретные слова (не «забыл частицы»), их потом включаете в новые карточки.
3. Повтор слабой темы по схеме: **+1 день → +3 дня → +7 дней → +14 дней**. Дата в последней колонке = следующий шаг этой лесенки.
4. Раз в месяц — строка «срез» со всеми сомнительными карточками.
5. Оценка конвертируется в действия: ≥90% — прочный блок, 80–89% — повторить ещё раз, <80% — вернуться к теме и сделать новые карточки.

## 6. Годовой цикл: графики

### 6.1 Ежедневный график (15–20 минут)

| Время | Действие | Количество |
|---|---|---|
| 5:00 | Anki: новые карточки | 15 |
| 5:08 | Anki: повторы (дневная очередь) | до 50 |
| 5:15 | Переписывание проблемных кандзи (см. Box 1) | 5 |
| 5:18 | Одна мини-зона из Review 7 | 1 зона |

### 6.2 Еженедельный график

| День | Активность |
|---|---|
| Вт | Повтор коробок 3–4 Лейтнера |
| Чт | Контрольный мини-тест 10 вопросов из Review 6 |
| Сб | «Срез недели»: смешанный тест по всем темам недели + разбор ошибок в дневник |
| Вс | Один полный Review (1–2 или 6) в качестве самопроверки |

### 6.3 Помесячный график

| Неделя | Цель |
|---|---|
| 1 | Пройти полный Review (тест + разбор) |
| 2 | Обновить дневник: пересчитать все брошенные темы |
| 3 | Нарастить порцию Anki до 20 новых/день на текущую неделю |
| 4 | Итоговый срез + корректировка интервалов слабых карточек |

## 7. Ликбез: что добавлять в Anki, а что нет

| Добавляем | Не добавляем |
|---|---|
| Слова с примером из контекста | Слово без примера |
| Типичные ошибки из дневника | Целые диалоги из учебника |
| Кандзи с одним чтением за раз | Все чтения кандзи разом |
| Конструкции с пояснением «когда» | Голые правила (их учим в конспекте) |
| Готовые фразы для сдачи JLPT | Тексты, которые проще перечитывать |
