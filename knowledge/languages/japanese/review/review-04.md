## 1. Частицы: полный свод значений

### 1.1 は (ва) — маркер темы

| Значение | Пример | Перевод |
|---|---|---|
| Тема предложения | 私は学生です。 | Я — студент. |
| Контраст («а вот…») | 酒は飲みますが、タバコは吸いません。 | Сакэ пью, а вот табак не курю. |
| Тема + период | 今日は暑いですね。 | Сегодня жарко, правда? |
| После обстоятельства | 毎週はできます。 | Каждую неделю можно. |

### 1.2 が (га) — маркер субъекта

| Значение | Пример | Перевод |
|---|---|---|
| Субъект нового сообщения | 雨が降っています。 | Идёт дождь. |
| Объект при 好き/嫌い/上手/下手 | 猫が好きです。 | Люблю кошек. |
| При существовании いる/ある | 猫がいます。 | Есть кошка. |
| После вопросительного слова | 誰が来ましたか。 | Кто пришёл? |
| Противопоставление (га) | 高いが、おいしい。 | Дорого, но вкусно. |
| Смягчение начала | すみませんが… | Извините… |

### 1.3 に (ни) — направление, время, адресат

| Значение | Пример | Перевод |
|---|---|---|
| Направление (с идти/приехать) | 学校に行きます。 | Иду в школу. |
| Точка времени | 七時に起きます。 | Встаю в семь. |
| Адресат подарка/действия | 友達にお土産をあげます。 | Дарю другу сувенир. |
| Место существования | 本は机の上にあります。 | Книга на столе. |
| Цель движения | 本を買いに行きます。 | Иду покупать книгу. |
| Назначение/момент изменения | 医者になる。 | Стать врачом. |
| Частота в период | 一日に二回。 | Два раза в день. |
| Агенс в пассиве | 猫に噛まれた。 | Укушен кошкой. |

### 1.4 で (дэ) — место, способ, причина

| Значение | Пример | Перевод |
|---|---|---|
| Место действия | 公園で遊びます。 | Играю в парке. |
| Инструмент/способ | 箸で食べます。 | Ем палочками. |
| Язык/средство | 日本語で話します。 | Говорю по-японски. |
| Причина/материал | 風邪で休みます。 木で作る。 | Болею, поэтому отдыхаю. Делать из дерева. |
| Место действия группы людей | 家族で旅行します。 | Путешествую всей семьёй. |
| Сумма/период | 百円で買えます。 | Можно купить за 100 иен. |
| Предел в ряду | 三時間で読みました。 | Прочитал за три часа. |

### 1.5 を (о) — маркер объекта

| Значение | Пример | Перевод |
|---|---|---|
| Прямой объект | 本を読みます。 | Читаю книгу. |
| Место прохода/покидания | 橋を渡る。 家を出る。 | Переходить мост. Выходить из дома. |
| Маршрут движения | 公園を散歩する。 | Гулять по парку. |
| После する-глаголов | 日本語を勉強する。 | Учить японский. |

### 1.6 へ (э) — направление

| Значение | Пример | Перевод |
|---|---|---|
| Направление (формально) | 日本へ行きます。 | Еду в Японию. |
| Адресат письма | 友達へ手紙を書く。 | Пишу письмо другу. |

Частицы に и へ взаимозаменяемы в направлении, но へ подчёркивает путь, に — цель.

### 1.7 と (то) — совместность, цитата, перечисление

| Значение | Пример | Перевод |
|---|---|---|
| Совместное действие | 友達と映画を見ました。 | Смотрел фильм с другом. |
| Цитата (прямая/косвенная) | 「行く」と言いました。 | Сказал: «Иду». |
| Результат в условных с と | 春になると桜が咲く。 | Когда наступает весна, цветёт сакура. |
| Полное перечисление | 猫と犬と鳥がいる。 | Есть кошка, собака и птица. |

### 1.8 も (мо) — «тоже»

| Значение | Пример | Перевод |
|---|---|---|
| Тоже, также | 私も行きます。 | Я тоже пойду. |
| Даже (ослабленный) | 一度も行ったことがない。 | Ни разу не был. |
| Смешанное перечисление | 本もペンもあります。 | Есть и книга, и ручка. |
| Множество предметов | 医者も医者なら、先生も先生だ。 | (пары: и тот, и другой…) |

### 1.9 の (но) — притяжательность и ещё 6 значений

| Значение | Пример | Перевод |
|---|---|---|
| Притяжательность | 私の本 | моя книга |
| Пояснение/атрибут | 日本語の先生 | учитель японского |
| Субстантив (вместо существительного) | 赤いのがすき。 | Люблю красный (тот, красный). |
| Вопросительный союз | どこにいるの？ | Где ты? |
| Придаточное определение | 買ったのを見せて。 | Покажи то, что купил. |
| Аппозиция («со своей семьёй») | 家族のこと | дело/о семье |

### 1.10 Служебные пары: краткий свод

| Пара | Разница | Примеры |
|---|---|---|
| は vs が | は — тема/известное; が — субъект/новое | 私は田中。// 田中が来た。 |
| に vs で (место) | に — существование; で — действие | 部屋にいる。// 部屋で食べる。 |
| に vs へ | に — цель; へ — путь | 駅に行く。// 駅へ行く。 |
| と vs で | と — с кем; で — сколько человек | 友達と行く。// 二人で行く。 |
| を vs が | を — переходный; が — в построениях 好き/嫌い | 本を読む。// 本が好き。 |
| から vs まで | から — от/с; まで — до | 九時から五時まで。 |

### 2.3 Неправильные: する и 来る

| Форма | する | 来る (куру) |
|---|---|---|
| Словарная | する | 来る |
| ます-форма | します | 来ます (кимасу) |
| て-форма | して | 来て (китэ) |
| た-форма | した | 来た (кита) |
| Отрицание | しない | 来ない (конай) |
| Условная (ば) | すれば | 来れば (курэба) |
| Возможная | できる | 来られる (корарэру) |
| Побудительная | しよう | 来よう (коё:) |
| Повелительная | しろ! | 来い! (кой) |
| Страдательная | される | 来られる |
| Побудительная | させる | 来させる |
| ている | している | 来ている |

### 2.4 Мнемоника применения (мини-алгоритм выбора формы)

1. Вежливое настоящее → **ます-форма**.
2. Действие в процессе → **て-форма + いる**.
3. Прошедшее → **た-форма**.
4. Опыт → **たことがある**.
5. Хочу → **たい** (書い**たい** — к основе ます, без ます).
6. Могу → **возможная форма** (グループ I: 書ける; II: 食べられる; する→できる; 来る→来られる).
7. Приглашение → **ましょう** (一緒に行きましょう).
8. Делать для будущего → **ておく**.
9. Запланированный результат → **てある**.
10. «К сожалению, случилось» → **てしまう**.

## 3. Прилагательные: полная сводная таблица

### 3.1 い-прилагательные — 高い (такай — высокий/дорогой)

| Форма | 高い | Перевод |
|---|---|---|
| Настоящее утверждение | 高い | высокий |
| Вежливое настоящее | 高いです | высокий (вежливо) |
| Отрицание | 高くない | не высокий |
| Отрицание вежливое | 高くないです / 高くありません | не высокий (вежливо) |
| Прошедшее | 高かった | был высоким |
| Прошедшее отрицание | 高くなかった | не был высоким |
| て-соединение | 高くて | высокий и… |
| Условная (ば) | 高ければ | если высокий |
| ても (даже если) | 高くても | даже если дорого |
| Подача (～そうです) | 高そうです | выглядит дорогим |
| Подача по слухам (～そうだ) | 高いそうです | говорят, что дорого |
| Префикс お+なречия | 高く | (наречие) высоко |
| Хочу признак | 高くなりたい | хочу стать высоким |
| Сравнение | より/のほうが высокий | выше |

### 3.2 な-прилагательные — 静か (сидзука — тихий)

| Форма | 静か | Перевод |
|---|---|---|
| Настоящее | 静かだ | тихий |
| Вежливое | 静かです | тихий (вежливо) |
| Отрицание | 静かじゃない | не тихий |
| Отрицание вежливое | 静かじゃないです / 静かではありません | не тихий (вежливо) |
| Прошедшее | 静かだった | был тихим |
| Прошедшее отрицание | 静かじゃなかった | не был тихим |
| Атрибут | 静かな町 | тихий город |
| て-соединение | 静かで | тихий и… |
| Условная (ば) | 静かなら | если тихий |
| ても | 静かでも | даже если тихий |
| Подача (～そうです) | 静かそうです | выглядит тихим |
| Наречие | 静かに | тихо |

### 3.3 Главные различия い vs な

| Ситуация | い-прил. | な-прил. |
|---|---|---|
| Перед существительным | 高いビル | 静かな公園 |
| Отрицание | 高くない | 静かじゃない |
| Наречие | 高く + глагол | 静かに + глагол |
| て-форма | 高くて | 静かで |
| Подача (外見) | заменяется: 高そう | 静かそう |
| С единств. исключением | いい → よく(ない)/よかった | — |

**Неправильные い-прилагательные:**
- いい (хороший): いい → よくない → よかった → よければ (не いいくない!)
- かっこいい (крутой): かっこよくない, かっこよかった.

**Прилагательные, которые часто путают с на-прилагательными:**
- 大きい (о:кий) — い; большой
- 大きな (о:кина) — な-атрибутив перед сущ.: 大きな家 (большой дом) — без отрицания/наречия.
- 小さい (тиисай) — い; маленький; 小さな (тиисана) — な-атрибутив.

## 5. Кэйго-таблица (敬語)

### 5.1 Соответствие простых → вежливых → кэйго

### 5.2 Формулы вежливости (без таблицы исключений)

| Тип | Формула | Пример |
|---|---|---|
| Сонкэйго (правило) | お + ます-основа + になる | お読みになる |
| Кэндзё: (правило) | お + ます-основа + する | お読みします (устарело, но встречается) |
| Кэндзё: (более частое) | お + ます-основа + する → お願いします | お願いします |
| Просьба снизу вверх | ～てください → お…ください | お読みください |
| Предложение услуги | (кампания) | お持ちします (я понесу) |

### 5.3 Запомнить пары (самое ходовое)

- 行く/来る/いる → **いらっしゃる**
- 食べる/飲む → **召し上がる**
- 言う → **おっしゃる**
- 見る → **ご覧になる**
- する → **なさる**
- Я со стороны: 参る, 伺う, いただく, 申す, 拝見する, 致す
