## Матрица выбора техники — дерево решений

> Ответьте на вопросы сверху вниз — и вы найдёте свою технику за 30 секунд.

```
ЗАДАЧА: Что нужно запомнить?
│
├── ЦИФРЫ / ДАТЫ / НОМЕРА
│   ├── До 4 цифр (PIN, дата) → Major → цепочка или образ
│   ├── 4–10 цифр → Major → чанкинг по 3 → дворец или цепочка
│   ├── 10+ цифр (телефон, карта) → PAO (6 цифр/сцена) → дворец
│   └── Случайные длинные числа → Major + чанкинг + дворец (комбо)
│
├── СПИСОК (элементы в ПОРЯДКЕ)
│   ├── ≤7 элементов → Цепочка (быстро, 2 мин)
│   ├── 7–15 элементов → Цепочка-двойная или Цепочка+Дворец
│   ├── 10 фиксированных → Телесные пеги (5 мин, сразу)
│   ├── 15–30 элементов → Цепочка×2 (мост) или Дворец
│   └── 30+ элементов → Дворец (мега) или чанкинг + дворец
│
├── ТЕКСТ / РЕЧЬ / ЭЗОЧЕНИЕ
│   ├── Пересказ своими словами → Слоёный (каркас + блоки)
│   ├── Дословно (стих, цитата) → Слоёный + чанкинг + полировка
│   ├── Структура/порядок правил → Акроним или Акростих
│   └── Длинная речь/презентация → Дворец + слоёный (каркас в комнатах)
│
├── ИНОСТРАННЫЕ СЛОВА / ТЕРМИНЫ
│   ├── 1–10 слов → Keyword (30 сек/слово)
│   ├── 10+ слов → Keyword + дворец (каждое — на локус)
│   ├── Имена/лица → Keyword + деталь лица
│   └── Системаатические термины → Keyword + акроним (первые буквы)
│
├── ЭКЗАМЕН / БИЛЕТЫ
│   ├── 3–10 билетов → Дворец-билеты (комнаты)
│   ├── 10+ билетов → Дворец-город (районы)
│   └── Билеты с формулами → Дворец + PAO (формула = сцена)
│
├── МЕСТА / НАВИГАЦИЯ
│   ├── Маршрут → Дворец (свой путь)
│   ├── Расположение объектов → Дворец + пеги
│   └── Карта / схема → Дворец + визуальный чанкинг
│
└── КАРТЫ / СПОРТ ПАМЯТИ
    ├── До 26 карт → PAO чистый (1 карта = 1 сцена)
    ├── 26+ карт → PAO двойной (2 карты = 1 сцена) + дворец
    └── Быстрый запоминание → PAO + Major + цепочка (комбо)

БЫСТРЫЙ ВЫБОР (альтернатива дереву):
│
≤7 и порядок важен? → Цепочка
Нужен порядок, много? → Дворец
Цифры? → Major → чанкинг → дворец
Слова чужие? → Keyword
Структура/правила? → Акроним
Текст дословно? → Слоёный
Карты/скорость? → PAO
Экзамен-билеты? → Дворец-билеты
10 вещей прямо сейчас? → Телесные пеги
```

## Глубокое погружение: каждая техника — больше примеров и вариаций

### Цепочка — расширенный набор примеров

#### Пример Г — Химические элементы (8): водород → кислород → углерод → железо → золото → серебро → медь → азот

```
ВИДРОРОД (водород) ТАНЕТ КИСЛОРОД, который ГОРИТ, обугливая УГЛЕРОД,
уголь плавит ЖЕЛЕЗО, золото кружится над ЖЕЛЕЗОМ, СОСЁД (серебро)
лизует золото, медь ОКРАШИВАЕТ СОСЁД, азот ВЗРЫВАЕТ медь.
```

#### Пример Д — Этапы похудения (6): питание → спорт → вода → сон → стресс → мотивация

```
ТОСТ (питание) БЕЖИТ в зал (спорт), тренажёр ТОСТИТ бутылку ВОДЫ,
вода льётся на ПИРОГ (сон), пирог давит на МОТОР (стресс), мотор
крутит ФАНТАСТИКА (мотивация) — и он тащит тоста за руку.
```

#### Пример Е — Этапы мечты (7): образование → навык → проект → команда → деньги → свобода → счастье

```
КОНИКУС (образование) учит КЛУБ (навык) играть, клуб строит КОРАБЛЬ
(проект), корабль везёт ТАМБУРУ (команда), тамбура сыплет ДЕНЬГАМИ,
деньги парят над СВОБОДОЙ (парус), свобода везёт СЧАСТЬЕ (караван).
```

#### Вариация «Цепочка-визуализация» — каждый образ рисуете за 3 сек, складываете в монтаж. Мозг запоминает то, что нарисовали руками.

#### Вариация «Цепочка со звуком» — каждая связь произносится с эффектным звуком: «БАТОН! → (звук падения) → МОЛОКО! → (звук разбития) → ЯЙЦО!». Звуковая дорожка усиливает на 30%.

#### Вариация «Цепочка-мультфильм» — представьте всю цепочку как 30-секундный мультфильм с музыкой, титрами и финалом. Особенно работает для детей и людей с визуальным мышлением.

#### Вариация «Обратная и прямая» — учите и прямую, и обратную цепочку одновременно (для экзамена, где спрашивают и «Что первое?», и «Что последнее?»).

### Дворец — расширенный набор примеров

#### Пример Г — География (12 локусов «Мир путешествия»): Европа → Азия → Африка → Америка → Австралия → Антарктида → Северный Ледовитый → Тихий → Атлантический → Индийский → Арктический → Антарктический

```
На двери Европа стоит в шляпе, шляпа превращается в ЭЙФЕЛОВУ башню.
В Азии ШЛЮЗ (вход) закрывает КИТАЙскую стену — идёт реставрация.
В Африке ЛЕВ плачет у СФИНКСа. В Америке ПАВЛИН танцует на пирамиде.
```

#### Пример Д — Музыкальные жанры (10 локусов «Моя пластинка»): классика → рок → джаз → электроника → рэп → хиппи → фолк → метал → блюз → кантри

```
1. Плинтер (классика) — пластинка гудит
2. Фейерверк (рок) — взрывается над магнитолой
3. Саксофон (джаз) — играет сам по себе
4. Пульт (электроника) — пульт светится RGB
...
```

#### Вариация «Дворец по времени» — локусы = часы дня: 7:00 будильник, 8:00 автобус, 9:00 стол на работе... Для запоминания временных последовательностей (исторические эпохи, смены).

#### Вариация «Дворец по эмоциям» — локусы = эмоции: радость (комнатное растение), грусть (ванная), страх (чёрный шкаф). Каждый элемент встаёт в комнату эмоции. Помогает, если материал вызывает дезориентацию.

#### Вариация «Дворец-огород» — вместо комнат: грядки, сараи, погреб, крыша. Народный дворец, легко строится для детей и пожилых.

#### Вариация «Международный дворец» — локусы = известные здания (Эрмитаж, Лувр, Метрополитен). Полезно для архитектуры, туризма, искусства.

### Major — расширенный набор примеров

#### Кейс Д — Год в цифрах: 1984

```
1-т → ТОРТ, 9-п → ПИРОГ, 8-в → ВОДА, 4-р → РОЗА
→ ТОРТ-ПИРОГ с РОЗОЙ, тонущий в ВОДЕ — год тяжелый, но цветущий.
Альтернатива: 19 → ТАП (тащит пирог), 84 → ВОЗ (воз + с) → ТАП в ВОЗ
воды.
```

#### Кейс Е — Адрес: 12345

```
12 → ТОН → ТОНКИЙ, 34 → МАРа → МАРАфон
→ ТОНКИЙ МАРАфонец бежит по коду 45:
4-р → РЕКА, 5-л → ЛУНА → бежит по ЛУНЕ через РЕКУ.
```

#### Кейс Ж — Серия из 6 цифр 583147

```
58 → ЛОШАДЬ-ВАША → ЛОШАДЬ ПЬЁТ ВОДУ
31 → МУРАШКИ-ТОН → МУРАШКИ на ТОНКОЙ нитке
47 → РОКА-КОТ → РОКА (рога) кота щиплет нитку
→ Лошадь пьёт воду, из которой вылезают мурашки на тонкой нитке,
которую щиплет кот с рогами.
```

#### Вариация «Major + PAO» — каждые 2 цифры = персона (Major), 3-я цифра = действие (свой код), 4-я = объект. 4 цифры = PAO-сцена.

#### Вариация «Major + Major+» — двухзначные числа кодируются сразу одним словом: 12 = ТОНИЯ, 34 = МАРА. Каталог 00–99 для быстрого доступа.

#### Вариация «Major с эмоциями» — к каждому слову-якорю добавьте эмоцию: 25 (НОС-ЛУНА) = «НОС плачет на ЛУНЕ». Эмоция к кодовому слову удваивает запоминание.

#### Вариация «Major наоборот» — по образу восстанавливайте цифры: «Лошадь на Луне» → 5-л (Луна), ж-ш (лошадь?) — проверка: 58 → Лошадь. Тренирует двустороннее кодирование.

### Телесные пеги — расширенные вариации

#### Расширение «Одежда-пеги 2.0» (20 точек):

| № | Точка | Образ |
|---|-------|-------|
| 11 | Шея | Грузы на шее — гири |
| 12 | Уши | Свистки в ушах |
| 13 | Локоть | Ледяной стакан на локте |
| 14 | Ладонь | Раскалённая сковородка |
| 15 | Пальцы | Пальцы — спички |
| 16 | Спина | Доска на спине |
| 17 | Лопатки | Парус на лопатках |
| 18 | Бёдра | Велосипед на бёдрах |
| 19 | Голень | Стрела, вбитая в голень |
| 20 | Пятка | Ледяная шайба на пятке |

#### Вариация «Пеги + Major» — цифра 1 = макушка, 2 = лоб... 9 = стопы, 0 = «над головой в воздухе». Каждое число = своя точка тела. PIN-код 25 = лоб + луна → луна висит над лбом.

#### Вариация «Пеги + эмоции» — на каждую точку добавьте чувство: корона на макушке — ДАВИТ, лампа на лбу — ЖЁТ, нос-клоун — ХОЛОДНЫЙ. Тактильные ощущения усиливают.

#### Вариация «Пеги в движении» — вместо статичных образов: вода льётся с макушки вниз по телу, от макушки до стоп — водопад. Движение = прочность.

#### Вариация «Пеги + слово» — образ на точке сразу содержит слово (первый слог элемента). Ключ = КЛЮЧ застрял в глазах.

### Keyword — расширенные примеры и фокусы

#### Расширенный словарь-якорей (20 слов):

| Слово | Звук | Якорь | Сцена |
|-------|------|-------|-------|
| river | ривер | РИВЕР=река | Река течёт по реке (парадокс) |
| table | тэйбл | ТЭБ=тэб (стол) | Стол в буквальном виде ест стул |
| light | лайт | ЛАЙТ | Лайка (собака) светится фонариком |
| train |トレイン | ТРЕЙН | Поезд ТРЕНИРУЕТСЯ на рельсах |
| heart | харт | ХАРТ | Харт (олень) с сердцем на лбу |
| stone | стон | СТОН | Камень СТОНЕТ от боли |
| wind | винд | ВИНД | Виндсерфинг — ветер несёт |
| fire | фар | ФАР | Фара (headlight) бьёт по огню |
| sea | си | СИ | Си (цей) — цифра, море из цифр |
| tree | три | ТРИ | Дерево из Трёх мишурных лент |

#### Для абстрактных понятий:

```
«Время» → ТАЙМ → ТАЙМ-ленд (Страна Времени) — часы растут как деревья
«Любовь» → ЛАВ → ЛАВ → лавровая ветвь обнимает человека
«Справедливость» → СТРА → СТРАХ + РАЗ → Страшный РАЗГРОМ над палатой
«Инновация» → ИННО → ИННО-ВАЦИЯ → инопланетянин вакуумирует город
```

#### Вариация «Keyword + Major» — иностранное слово кодируем через Major: *photograph* → фо-тограф → 8+1(в+т) → ВОД+Т -> Вода+Тигр → образ. Смешанный код.

#### Вариация «Keyword для терминов» — научные термины бьём на слоги: *photosynthesis* → фо-то-синт-е-зис → ФОТО (образ) + СИНТЕЗ → Синтез-фабрика. Чанкинг+keyword.

#### Вариация «Keyword-история» — слово с историей: *butterfly* бабочка → «Батя ФЛАЙ → батя летит» и сразу рассказываете мини-историю «Батя на вечеринке залетел в окно как бабочка».

#### Вариация «Keyword + лицо» — для лиц и имён: имя человека = якорь + деталь лица (цвет глаз, форма носа, борода). Лицо Тимура + тимьяна → борода из тимьяна.

#### Вариация «Keyword-ретро» — для устойчивых устаревших слов (archaic, obsolete): берите корень слова и привязывайте к его этимологии. *decipher* (расшифровать) → де + крип → ДЕКО (памятник) + КРИП (крипта) → на памятнике крипта.

### Акронимы и акростихи — расширенные вариации

#### Пример Г — Формула Единого национального теста (ЕНТ) — 8 предметов:

```
Алгебра, Физика, Химия, Биология, Информатика, Русский, История, Иностранный
→ АФХБИРИИ → «Андрей ФИЗИЧЕСКИ ХОДИТ БОЛЬШИМ ИНТЕЛЛИГЕНТНЫМ РАЗРЕЗОМ,
И ИНТЕЛЛИГЕНТНО» — абсурд, запоминается.
```

#### Пример Д — Порядок действий при пожаре (8 шагов):

```
1. Вызвать пожарную службу 2. Спасти людей 3. Угрожать (эвакуировать)
4. Обезвредить 5. Сохранить имущество 6. Подать сигнал 7. Оценить 8. Задержать
→ «ВЕСЁЛ САМБУКИ ИЗ МЕДА ШУРШАТ У ПОДАРУШКИ»
```

#### Вариация «Акроним с цифрами» — буквам+цифрам: 5Б = «Пять Большие...» → фраза с числом. Для смешанных списков.

#### Вариация «Акроним + Major» — буквы кодируются Major-ом: Б=2 (н), П=7 (к) → 27-комбо образ.

#### Вариация «Акроним + дворец» — каждая буква акронима = объект в комнате: А (дверь), Ф (фонарь), К (конь)...

#### Вариация «Обратный акростих» — фраза читается с конца. Для контроля: если помните с конца — значит и с начала держите.

#### Вариация «Акроним с визуалом» — каждая буква = маленький персонаж-образ на линии, как мультфильм из букв.

### Чанкинг — расширенные примеры

#### Пример Е — ISBN книги 978-3-16-148410-0:

```
978 → 9(б/п)7(к/г)8(в/ф) → БукваКнига-ф? → КНИГА БЕЗ ОБЛОЖКИ
316 → М+Н+Л → МАНЬКИН(манекен)
148 → Р+Л+В/Ф → РОЛЕР-ВАФЛ? → РОЛЕР в вафле
410 → Р+А+З/С → РАЗ=разлом
→ КНИГА БЕЗ ОБЛОЖКИ, МАНЕКЕН в РОЛЕР-ВАФЛЕ, РАЗЛОМ.
Разложите по 4 локусам дворца.
```

#### Пример Ж — MAC-адрес: 00-1A-2B-3C-4D-5E:

```
00 → СОЛНЦЕ
1A → Л+А → ЛЕНТА
2B → Н+Б → НОЖ-БУР
3C → З+К → ЗУБ-КЛУШКА
4D → Р+Т → РОТОР-ТУРБИНА
5E → Л+Ж → ЛЕД-ЖАРА
→ СОЛНЦЕ на ЛЕНТЕ, НОЖ-БУР крутит ЗУБ на КЛУШКЕ, РОТОР-ТУРБИНА
передаёт ЛЕД-ЖАРУ в СОЛНЦЕ.
```

#### Вариация «Чанкинг по смыслу + Major» — сначала группируете по смыслу, потом каждый чанк кодируете Major-ом. Для научных данных.

#### Вариация «Чанкинг + PAO» — чанк из 3–4 элементов кодируется PAO-сценой: АБВ+ГДЕ+JKL = Персона-А + Действие-Г + Объект-K → сцена.

#### Вариация «Чанкинг с цветом» — каждый чанк = свой цвет в визуализации. Чёрный чанк, красный чанк — визуальные границы не дают потерять порядок.

#### Вариация «Чанкинг-аудио» — каждый чанк читается своей интонацией: первый чанк — мужской голос, второй — женский, третий — детский. Многоканальность.

### Слоёный метод — расширенные примеры

#### Пример Г — Научная статья (3 абзаца):

```
КАРКАС: Проблема → Метод → Результат

БЛОК 1 (Проблема): Вода загрязнена → образ: РЕКА с маслом и стиральным
порошком. Шов: нефть стекает в РЕКУ.

БЛОК 2 (Метод): Фильтр-уголь → образ: ШАРФ-уголь проглатывает нефть.
Шов: из РЕКИ поднимается пар и попадает в ШАРФ.

БЛОК 3 (Результат): Чистая вода → образ: ЧАША с чистой водой. Шов: из
ШАРФА капает чистая вода в ЧАШУ.

ПОЛИРОВКА: дословно «фильтр-абсорбент» — «ФИЛЬТРАЦИЯ + АБСОРБЦИЯ» →
фильтр поглощает абсорбент → абсорбент в форме швабры в чаше.
```

#### Пример Д — Этикет (10 правил) в слоях:

```
КАРКАС: Приветствие → Обед → Подарки → Прощание

БЛОК «Обед»: не шумите, не делитесь блюдом, не говорите «вкусно» = 3
локуса: ТАБУР(шум) — ТАБУР в вакууме, ТАРТ(блюдо) — тарт не делится,
ТОЧКА(вкусно) — точка на языке не звучит.

ПОЛИРОВКА: «не перебивайте» → ПЕРЕ (перейти) + БИВ (бивень) → Перебивающий
два бивня — слон на табуре.
```

#### Вариация «Слоёный + Major» — каждый элемент внутри блока кодируется Major-ом для дословных мест (даты, имена, термины).

#### Вариация «Слоёный + ключевая фраза» — вместо полировки выучите одну «ключевую фразу» блока (3–5 слов), остальное выводится из неё.

#### Вариация «Слоёный для цифр» — данные с цифрами внутри блоков: цифры → Major, остальное → образ. Слоёный + Major + чанкинг.

### PAO — расширенные примеры

#### Пример Г — Колода 3 карты: Король пик, Дама червей, Туз бубен

```
Король пик (Пират-рубит-сабля) + Дама червей (Дама-веет-зелье) +
Туз бубен (Дед-Молчит-барабан)

Сцена 1 (первый PAO двойной):
Персона(Кп) + Действие(Дч) + Объект(Тб) → ПИРАТ ВЕЕТ ЗЕЛЬЕМ В БАРАБАН
→ Пират дует на зелье в барабан, барабан шипит.

Сцена 2 (второй PAO двойной):
Персона(Дч) + Действие(Тб) + Объект(Кп) → ДАМА молчит на БАРАБАНЕ
(вторая часть)
```

#### Пример Д — Числа 582736:

```
58 → Лошадь (персона: Лошадка) + л-ш (действие: лижет) + в/ф (объект: водопад)
27 → Нос + к/г + в → НОС крошит ВАЗУ
36 → М + ж/ш → МУРАШКИ + ЖАРА
→ ЛОШАДКА лижет ВОДОПАД, НОС крошит ВАЗУ, МУРАШКИ жарят...
```

#### Вариация «PAO с кодированием Major» — номер 23 = М (Major) = персона МУРАШКА, действие по следующей цифре 4 = Р (режет), объект 5 = Л (ЛИСТ) → МУРАШКА режет ЛИСТ. 3 цифры = 1 PAO.

#### Вариация «PAO + эмоция» — эмоция персонажа фиксирует сцену: Пират РУБИТ саблей в ярости, Дама ВЕЕТ зельем от тоски. Эмоция персонажа = якорь к сцене.

#### Вариация «PAO + дворец + Major» — 12 цифр: 12(34)56(78)90 → 2 сцены PAO → 2 локуса дворца. Каждая сцена = 6 цифр. Максимальная ёмкость.

#### Вариация «Дворец с нумерацией локусов» — внутри билета локусы пронумерованы (1, 2, 3...) и привязаны к порядку ответа. Если спрашивают «Что второе?» → Locус 2.

### Система тренировки с прогрессией «5 уровней сложности» (для каждой техники)

Уровень 1 — СЛУХОВОЙ: произнесите 3 раза, закройте глаза, вспомните.
Уровень 2 — ЗРИТЕЛЬНЫЙ: закройте глаза, «увидьте» сцену, опишите вслух.

Уровень 4 — ДВИГАТЕЛЬНЫЙ: покажите образ жестами, «простукайте» его (пеги).
Уровень 5 — ЭМОЦИОНАЛЬНЫЙ: проживите сцену с эмоцией (смех, страх, удивление).

> Применяйте все 5 уровней для каждого материала — запоминание ×5.

### Бонусные мини-приёмы (шпаргалка)

#### «Якорь-имя» — запоминание имён:
- **Принцип:** первый звук имени → образ → деталь лица.
- **Пример:** Алексей → АЛЕКС → АЛЕКСАНДР МАДДЕН (Madden) → Алеша Мадден на крыше.
- **Приём:** к имени добавьте профессию/характер (Алексей-строитель, Алексей-врач).

#### «Метка-направление» — запоминание лиц по месту:
- **Принцип:** лицо = образ в локусе дворца, имя = якорь на объекте.
- **Приём:** если 10 лиц на вечеринке → 10 локусов дворца, на каждом — лицо + сцена с якорем имени.

#### «Трюк-3-части» — для длинных списков:
1. Разбейте на 3 чанка (первые 1/3, середина, последние 1/3).
2. Каждый чанк → свой дворец/образ.
3. Чанки → связаны мостом.
4. «Вход» в каждый чанк — отдельный якорь-объект (дверь первого чанка, дверь второго...).

#### «Метод забывания» — целенаправленное «забывание» для прочности:
- После запоминания: НЕ повторируйте 2 дня. Дайте «забыть» до 80% — мозг укрепит след. Повторите через 2 дня, потом через неделю.
- Основано на интервальном повторении с «пропуском».

#### «Якорь-для-события» — запоминание новостей/текущих событий:
- Каждое событие = образ + дата (Major) + дворец.
- Новость дня → образ на «дворец дня» (например, текущая кухня).
- Подходит для новостных сводок, спортивных результатов, погоды.

### Проблемы и решения — подробный справочник

#### Блок А: образ не создаётся

| Проблема | Причина | Решение |
|----------|---------|---------|
| «Невозможно придумать образ» | Перфекционизм, страх абсурда | Примите правило «плохой образ > нет образа». Ошибка бледного образа стоит 0 баллов, ошибка абсурдного = +100% запоминания |
| «Образ есть, но бледный» | Недостаток VIVID | Добавьте 1 параметр: звук, запах, движение, эмоцию |
| «Образ слишком сложный» | Перегруз, >5 деталей | Упростите: 1 объект + 1 действие + 1 эмоция. 3 элемента максимум |
| «Образ не держится 5 сек» | Слабая эмоция | Усильте страх/смех/отвращение/удивление. Добавьте себя в сцену |
| «Образ похож на предыдущий» | Шаблонизация | Смените сенсорику: если прошлый был визуальный — сделайте этот слуховой/тактильным |
| «Не могу визуализировать» | Зрительного образа нет | Используйте слух (озвучка), осязание (простукивание для пегов), движение |
| «Слова абстрактные — не рисуются» | Нет конкретики | Замените абстракцию на конкретный объект: «ответственность» = тяжёлый рюкзак |

#### Блок Б: связь не работает

| Проблема | Причина | Решение |
|----------|---------|---------|
| «Помню образы, но забываю порядок» | Нет связи/контакта | Воткните образы друг в друга, добавьте физический контакт |
| «Связь есть, но слабая» | «Рядом» вместо «в контакте» | Толкните, воткните, склейте, ударьте, залейте |
| «Цепочка рвётся на середине» | >15 элементов | Разбейте на 2 цепочки по 7–8 + мост в середине |
| «В обратном порядке не работает» | Связи односторонние | Создайте двусторонний контакт (образ А БЬЁТ образ Б, образ Б ДЕРЖИТ образ А) |
| «Путаю 2 соседних элемента» | Образы похожи | Сделайте контраст: горячее/холодное, мокрое/сухое, большой/маленький |
| «Забыл, какой объект на каком локусе» | Нет уникальности локуса | Добавьте признак локуса (цвет, звук, движение) |

#### Блок В: забывание после запоминания

| Проблема | Причина | Решение |
|----------|---------|---------|
| «Вспомнил сегодня, забыл завтра» | Нет повтора | Повтор по расписанию: 20 мин → день → неделя → месяц |
| «Повторяю, но всё равно забываю» | Повтор механический, без образа | Каждый повтор = ВОССТАНОВЛЕНИЕ образа, не повторение слов |
| «Забываю после стресса/волнения» | Эмоция вытесняет память | Двойной якорь: образ + эмоция + физическое действие (простукивание) |
| «Забываю конкретную деталь» | Нет полировки | Дословную деталь выучите отдельно чанкингом, приклейте к блоку |
| «Всё забыл после недельного перерыва» | Долгий интервал | Активируйте «входной образ»: дверной образ-крючок запускает всю цепочку |
| «Помню, но не могу вспомнить быстро» | Недостаток скорости | Дриллы на скорость: хронометрированные тесты, «5 секунд» |
| «Помню образы, не могу вспомнить слова/цифры» | Образ→слово не закодирован | Дополнительный слой: образ → Major-код / Keyword-якорь → слово |

#### Блок Г: техника не подходит

| Проблема | Причина | Решение |
|----------|---------|---------|
| «Дворец не строится» | Нет знакомого пространства | Используйте стандартный маршрут (дом → работа → магазин) |
| «Цепочка слишком длинная» | >15 элементов без опыта | Начните с 5, постепенно увеличивайте +1 каждую неделю |
| «Major путает цифры» | Не выучена таблица | Карточки: цифра → звук → 3 слова. До 100% без ошибок |
| «Keyword не работает на языке» | Якорь не созвучен | Берите любой совпадающий звук (даже 1 слог), главное — яркая сцена |
| «Телесные пеги путаются» | Нарушен порядок | Прогоните 1→10→1 ежедневно 3 дня до автоматизма |
| «PAO не запоминается» | Каталог не готов | Составьте каталог 00–25 за неделю, по 3 записи в день |
| «Акроним скучный» | Фраза не смешная | Переделайте фразу, пока не запомнится. Абсурд = запоминание |
| «Слоёный не помогает» | Пропускаете слои | Следуйте строго: каркас → блоки → швы → полировка |

#### Блок Д: прогресс стагнирует

| Проблема | Причина | Решение |
|----------|---------|---------|
| «Прогресса нет 2+ недели» | Нет дриллов | Добавьте 1 дрилл в день по 5 мин, меняйте тип |
| «Всё работает, но медленно» | Нет автоматизма | Дриллы на скорость: «5 секунд», «PIN за 15 сек», «слепой прогон» |
| «Запоминаю, но не могу применить» | Нет переноса | Тренируйте на СВОЁМ материале (учеба, работа), а не на случайных словах |
| «Стройю дворец, но не использую» | Техника не в привычке | Используйте дворец каждый день для списков (покупки, дела) |
| «Смешиваю техники» | Недостаток разделения | Тренируйте каждую технику отдельно 3 дня, потом комбинируйте |
| «Устал от практики» | Перегруз | Сделайте паузу 2–3 дня, вернитесь. Мозг консолидирует во сне |

#### Экстренные решения (когда «ничего не работает»)

1. **Правило 1 минуты:** если не получается — остановитесь на 60 сек. Закройте глаза, подышите, представьте свою квартиру (дворец-корневой). Начните сначала.
2. **Упрощение:** разбейте задачу пополам. Запомните первую половину, потом вторую.
3. **Смена канала:** если визуал не работает → используйте слух (озвучка), осязание (простукивание), движение.
4. **Якорь-«жизненное»:** возьмите своё самое сильное воспоминание и «приклейте» к нему нужный материал.
5. **Двойной якорь:** образ + слово + физическое действие (простукивание точки тела).
6. **Дистанция:** если застряли — отойдите на 10 минут, вернитесь с новым взглядом.
7. **Обратная цепочка:** начните с конца и пойдите к началу — часто это проясняет структуру.
8. **Физическое действие:** встаньте, потянитесь, пройдитесь — память укрепляется при движении.

### Контрольные тесты для каждой техники (примеры)

#### Тест «Цепочка» (5 мин)
Запомните: кошка, дверь, река, зонт, машина, книга, камень, солнце, дождь, мост.
→ Цепочка → прогон → проверьте через 5 мин → воспроизведите 10/10.

#### Тест «Дворец» (10 мин)
Запомните 15 элементов: стол, стул, лампа, книга, телефон, кот, часы, ключ (钥匙), вода, хлеб, яблоко, нож, вилка, тарелка, стакан.
→ Разместите по квартире (15 локусов) → проверьте через 20 мин.

#### Тест «Major» (5 мин)
Закодируйте: 1945, 9240, 7531, 8844, 1023.
→ Образы → цепочка → проверьте через 10 мин.

#### Тест «Keyword» (10 мин)
Запомните 8 английских слов: river, table, light, train, heart, stone, wind, fire.
→ Keyword → сцена → проверьте через 20 мин → переведите обратно.

#### Тест «Слоёный» (15 мин)
Возьмите статью 1 стр. из любой темы → каркас (5 слов) → блоки (3 абзаца) → швы → полировка 1 цитаты → перескажите через 10 мин.

#### Тест «PAO» (10 мин)
6 случайных цифр → PAO-сцена → 12 цифр → 2 сцены → проверьте через 10 мин.

#### Тест «Комбо» (15 мин)
Задание: телефон (12 цифр) + 5 иностранных слов + 1 строка стихотворения.
→ Major + дворец → Keyword → слоёный → сводный контроль через 30 мин.

### Мультисенсорное кодирование: техника «5 каналов»

> **Принцип:** каждый элемент запоминается через 5 каналов восприятия одновременно. Мозг хранит мультисенсорный образ в 5–10 раз глубже, чем визуальный.

| Канал | Вопрос | Пример для слова «КОФЕ» |
|-------|--------|------------------------|
| 👁 Зрение | Что я вижу? | Зёрна кофе бурого цвета, капают |
| 👂 Слух | Что я слышу? | Шипение кофепечи, капля бьёт по чашке |
| 👃 Обоняние | Что я нюхаю? | Аромат свежеобжаренного кофе, тёплый, ореховый |
| 👅 Вкус | Что я пробую? | Горький, насыщенный, с лёгкой кислинкой |
| ✋ Тактильность | Что я трогаю? | Горячая керамическая чашка, шероховатая |

**Алгоритм «5 каналов за 30 секунд»:**

```
1. Выберите элемент (слово, термин, цифру).
2. Пройдите 5 каналов: зрение → звук → запах → вкус → тактильность.
3. На каждый канал — 1 фразу-образ (10 сек).
4. Объедините в сцену: кофе ЗЕРНИТА СИПИТ, ВОРОНКОЙ капает ЗВОНОК, пахнет ОРЕХОМ, горчит КИСЛОТИНОЙ, ПЕЧЬ горячая.
5. Проговорите вслух, закройте глаза.
```

**Применение:** особенно работает для:
- Абстрактных терминов («инфляция» — звук денег, запах горелой бумаги, вкус горечи)
- Иностранных слов (весь канал языка — звук, артикуляция)
- Исторических дат (звук боевого рубила, запах пороха)
- Формул (звук записи, вид формулы, тактильное письмо)

> **Мнемоника-трюк:** если забыли — вспомните любой канал. Заметил запах → вся сцена всплывает. Один канал тянет за собой остальные 4.

### Двойное кодирование с эмоциями

> **Принцип:** каждый образ кодируется ДВУМЯ путями — визуальным и эмоциональным — что создаёт «двойной якорь» в памяти.

**Таблица эмоций для усиления:**

| Эмоция | Сила | Когда использовать | Пример |
|--------|------|-------------------|--------|
| Смех | ★★★★ | Уроки, списки, знакомый материал | Образ бабушки в роли космонавта |
| Удивление | ★★★★ | Важные факты, даты | Дворец взлетает в небо |
| Страх | ★★★★★ | Опасные моменты, критические даты | Образ «следит», «атакует» |
| Отвращение | ★★★★ | Для «красных» элементов | Грязь, запах, ужас |
| Гнев | ★★★ | Спорные факты, «противники» | Образ бьёт, рвёт, топчет |
| Любопытство | ★★ | Для сложных концепц | Загадка, недоразумение |
| Ностальгия | ★★★ | Личные данные, свои вещи | Старая фотография, бабушкин дом |
| Тревога | ★★★ | Экзамены, важные события | Таймер тикает, дедлайн |

**Алгоритм «Эмоция + образ»:**

```
1. Выберите элемент.
2. Придумайте визуальный образ (Закон №1, VIVID).
3. Выберите эмоцию: какой эмоции это «заслуживает»?
4. Наложите эмоцию: образ пАЧИТ, оБЖИГАЕТ, УДИВАЕТ, УСТРАЖИВАЕТ.
5. Добавьте телесное ощущение: дрожь, жар, ком в горле.
6. Проверка: закройте глаза — образ + эмоция всплывают?
```

**Пример двойного кодирования:**

```
Термин «инфляция»:
Визуальный образ: ИНФЛЯционный шар-деньги раздувается над городом
Эмоциональный якорь: УДИВОЛЕНИЕ + СТРАХ (шар лопнет!)
Телесное: сердце бьётся быстрее, руки дрожат от жара
→ Двойной якорь: вижу шар + чувствую жар + слышу гул → заморозка.
```

> **Правило 2 якорей:** если образ не держится — добавьте эмоцию. Если и с эмоцией не держится — добавьте движение. Если и движение не помогает — сделайте образ ЛИЧНЫМ (ваш опыт).

### Шпаргалка памяти-атлета: сокращения и трюки

#### Сокращения и аббревиатуры для техник:

| Сокращение | Значение | Когда использовать |
|------------|----------|-------------------|
| VIVID | Visual, Interaction, Vivid, Incongruity, Dynamics | Оценка силы образа |
| PAO | Persona-Action-Object | Числа 6 цифр, карты |
| LOC | Локус | Точка во дворце |
| PEG | Пег | Крючок (числовой/телесный) |
| VAK | Visual-Auditory-Kinesthetic | Мультисенсорный канал |
| SSS | Sensory-Story-Strong | Создание образа |
| FMP | First Main Point | Главный тезис речи |
| MCP | Main Chunk Point | Центральный чанк |
| ACE | Absurdity-Contact-Emotion | Формула связи |
| ROT | Repeat-Over-Test | Цикл практики |

#### Сокращения для быстрой памяти-диагностики:

```
СПЕЦ — Сила образа = Плюс Эмоция × Контакт × Трафик (абсурдность)
ОЧЕНЬ — Образ, Контакт, Эмоция, Название, Уникальность
ДРОБЬ — Длинный → Раздели → Образи → Фрагменты → Якоря
```

#### Шпаргалка «если не работает одно — делай это» (приоритет действий):

```
1. Не помню → Усиль эмоцию + добавь движение + добавь запах
2. Путаю порядок → Прогон назад + нумерация локусов
3. Перепутал образы → Сделай контраст + добавь уникальный признак
4. Забываешь через день → Повтори сегодня вечером + утром
5. Бледный образ → Увеличь в 10×, добавь абсурд, добавь себя
6. Длинный список → Чанк + дворец + мост
7. Абстракция → Конкретика: замени на физический объект
8. Усталость → Сделай паузу 10 мин, пройдись, вернись
9. Нервозность → Прогон 3 раза до, перед экзаменом, расслабься
10. Не создаётся → Возьми чужой пример → переделай на своё через 5 мин
```

#### «Правило 3×3» для проверки памяти:

```
3 раза проговорить
3 канала задействовать
3 секунды на образ
3 минуты на дрилл
3 дня на закрепление
```

#### «Якорь-взрыв» — приём для срочного запоминания:

```
1. Выделите 3 ключевых элемента задачи.
2. На каждый создайте образ VIVID с эмоцией.
3. Свяжите все 3 образа в единую сцену-взрыв (взрыв, пожар, праздник).
4. Проговорите 3 раза вслух, закройте глаза 10 секунд.
5. Проверьте — 3 элемента всплыли? Если нет — усильте взрыв.
```

#### «Шорткат-имени» — мгновенное запоминание имени человека:

```
1. Услышали имя → найдите якорь (звук).
2. Увидели лицо → отметьте 1 деталь (борода, очки, крупный нос).
3. Свяжите: имя + деталь → сцена с абсурдом.
4. Скажите имя вслух 2 раза, глядя в глаза.
5. Через 2 мин проверьте: имя → деталь → сцена.
```

#### «Лист-мнемоника» — мини-чеклист для срочного запоминания:

```
[ ] Что нужно запомнить? → 3–5 ключевых слов (каркас)
[ ] Визуальный образ? → КАРТИНКА
[ ] Эмоция? → СМЕХ/СТРАХ/УДИВЛЕНИЕ
[ ] Контакт? → ФИЗИЧЕСКИЙ
[ ] Движение? → ДВИЖЕНИЕ
[ ] Связь с другим? → МОСТ
[ ] Повтор? → 20 мин → день → неделя
[ ] Проверка? → 5 мин / час / день
```

### Финальные советы от практиков (мнемонический совет)

1. **«Лучший образ — тот, который вы бы не забыли в жизни»** — используете личный опыт, сильные эмоции.
2. **«Не учите, а строите»** — каждая техника = постройка (дворец, цепь, пег). Вы — архитектор памяти.
3. **«Плохой образ лучше, чем идеального ожидания»** — перфекционизм убивает практику. Делайте → корректируйте → делайте лучше.
4. **«Память — это мышца, а не орган»** — каждый дрилл = отжимание для мозга. 15 мин/день = результат.
5. **«Техника без повтора = пушка без патронов»** — календарь повторений обязательнее техники.
6. **«Комбо даёт ×3, но не ×10»** — ожидайте реалистичного усиления, не магии.
7. **«Учите других — учите себя»** — преподавание закрепляет в 10 раз глубже.
8. **«Сон — часть памяти»** — не учите до полуночи. Ложитесь, мозг консолидирует.
9. **«Ваша первая дворец всегда своя квартира»** — не изобретайте, используйте то, где бывали.
10. **«Страх — ваш союзник»** — если что-то страшно/неожиданно — запоминается лучше. Используйте это.

### 1.2. Формула сильного образа — VIVID

| Буква | Принцип | Вопрос для проверки | Пример слабо → сильно |
|-------|---------|---------------------|----------------------|
| **V** — Visual | Визуальность | Вижу ли я это как кадр из фильма? | «яблоко» → «наливное красное яблоко с каплями, которое лопается» |
| **I** — Interaction | Взаимодействие | Есть ли физический контакт? | «кот и книга» → «кот раздирает книгу когтями» |
| **V** — Vivid | Яркость | Есть ли цвет, звук, запах? | «роза» → «бордовая роза, пахнет резко, шипы царапают» |
| **I** — Incongruity | Абсурд | Это нелогично / смешно / страшно? | «человек на стуле» → «человек приклеен к потолку на стуле» |
| **D** — Dynamics | Движение | Что движется / взрывается / падает? | «мяч лежит» → «мяч подпрыгивает и разбивает окно» |

### 1.3. Таблица усиления

| Параметр | Слабо | Сильно | Приём усиления |
|----------|-------|--------|----------------|
| Эмоция | нейтральная | страх, смех, отвращение, удивление | добавьте лицо, крик, слёзы, хохот |
| Движение | статичная сцена | взрыв, падение, погоня | толкните, бросьте, разбейте |
| Размер | нормальный | гигантский или микроскопический | увеличьте в 10× или уменьшите до горошины |
| Контекст | «просто объект» | объект в незнакомом месте | положите холодильник на крышу |
| Связь | похоже / рядом | физический контакт двух объектов | проткните, свяжите, склейте |
| Сенсорика | только зрение | + звук + запах + вкус + тактильность | добавьте «шипит, воняет, липкий» |
| Персонализация | чужой образ | ваш личный опыт | вставьте себя, маму, друга |

> **Правило 5 секунд:** если образ не всплыл за 5 секунд — он слишком слабый. Переделайте. Если всплыл, но бледный — добавьте одно из VIVID.

### 1.4. Алгоритм создания образа за 10 секунд

```
1. Назовите объект вслух (1 сек)
2. Задайте вопрос: «На что это похоже зрительно?» (2 сек)
3. Добавьте действие: что он ДЕЛАЕТ? (2 сек)
4. Добавьте эмоцию: кому страшно/смешно? (2 сек)
5. Добавьте контакт со следующим объектом (3 сек)
6. Проверка: вижу ли я кадр как в TikTok? Если нет — увеличьте абсурд.
```

### 1.5. Примеры преобразования абстракций → образы

| Абстракция | Слабый образ | Сильный образ |
|------------|--------------|---------------|
| Договор | бумага | ДВА ГОВара бьют друг друга ДОГОВОРом как подушкой |
| Экономика | график | ЭКО-НОМка (гном в зелёном) пересчитывает монеты в огромной банке |
| Демократия | голосование | ДЕМо-КРАТ (демон в кратии) бросает бюллетени как конфетти |
| Фотосинтез | лист | ФОТОаппарат СИНТЕзирует свет в листе, лист светится и шипит |
| Инфляция | деньги | ИНФЛЯционный шар-деньги раздувается и лопается над городом |

### 1.6. Вариации

- **Вариация «Якорь-запах»:** добавьте запах (гниль, духи, бензин) — обонятельная память самая стойкая.
- **Вариация «Звук-мем»:** озвучьте образ фразой-мемом или голосом знакомого персонажа.
- **Вариация «Своё → чужое»:** сначала возьмите чужой пример, затем за 30 сек переделайте под свою жизнь (своя квартира, свой кот).

### 1.7. Типичные ошибки

- **Ошибка 1:** оставлять слово словом («надо запомнить слово справедливость» → не создаёт образ). Лечение: всегда рисуйте.
- **Ошибка 2:** два образа рядом без контакта («яблоко и книга лежат»). Лечение: воткните яблоко в книгу.
- **Ошибка 3:** слишком логичная связь («яйцо рядом с сыром» — мозг не заметит). Лечение: разбейте яйцо о сыр, чтобы желток растёкся.

### 1.8. Дриллы (тренировка образа)

**Дрилл 1 — «5 секунд» (3 мин).** Берёте 10 случайных слов (из [тетради](classic-mnemonics.md) и переделайте: замените персонажа на друга/родственника, место — на свою кухню.

## Техника 1: Цепочка (для списков ≤15)

**Когда:** список покупок, пункты плана, дела на день, тезисы абзаца.
**Срок:** 2 минуты на запоминание 7±2, до 5 минут на 15. Держится день без повтора, неделю — с одним повтором.
**Суть:** связываем каждый элемент со следующим физическим, абсурдным контактом. Вспоминаем, «потянув» за первое звено.

### 1.1. Алгоритм (базовый)

```
1. Прочитайте весь список целиком, не пытаясь учить.
2. Превратите каждый пункт в образ (см. Закон №1).
3. Свяжите 1→2 физическим контактом: 1 ДЕЛАЕТ что-то с 2, результат яркий.
4. Свяжите 2→3, 3→4 и т.д. — каждый раз НОВОЕ действие, не повторяйте «лежит рядом».
5. Пройдите цепочку мысленно 1 раз от начала к концу, проговаривая вслух.
6. Воспроизведите от конца к началу (проверка прочности связей).
7. Отложите на 5 мин, затем вспомните снова.
```

### 1.2. Формула связи

```
ОБЪЕКТ1 + АКТИВНОЕ ДЕЙСТВИЕ + ОБЪЕКТ2 + ЯРКИЙ РЕЗУЛЬТАТ + ЭМОЦИЯ
Пример: БАТОН (1) + КАТИТСЯ + РЕКА ИЗ МОЛОКА (2) + ВРЕЗАЕТСЯ + БРЫЗГИ + СМЕХ
```

### 1.3. Примеры (3 уровня сложности)

**Пример А — Покупки (5): хлеб → молоко → яйца → сыр → яблоки**

```
БАТОН катится по реке МОЛОКА, врезается в ЯЙЦО — яйцо разбивается о СЫР,
сыр плавится и на нём растут ЯБЛОКИ, которые падают вам на голову.
```
Проверка: закройте глаза, «потяните» за батон — всплывает молоко?

**Пример Б — Дела на день (7): позвонить → отчёт → магазин → спорт → книга → уборка → фильм**

```
ТЕЛЕФОН звонит и из трубки выпадает ОТЧЁТ, отчёт падает в МАГАЗИНную тележку,
тележку толкает ШТАНГА из спортзала, штанга падает на КНИГУ, книга открывается и из неё вылетает ПЫЛЕСОС (уборка), пылесос засасывает экран с ФИЛЬМом.
```

**Пример В — Абстрактные тезисы (6): гипотеза → метод → данные → анализ → вывод → внедрение**

```
ГИППО-ТЕЗА (гиппопотам с тезой) держит МЕТОДу (метлу), метла метёт ДАННЫЕ (цифры как мусор),
мусор попадает в АНАЛИЗ-атор (мясорубка), из мясорубки выпадает ВЫВОД (свиток), свиток вставляют в завод — ВНЕДРЕНИЕ (конвейер).
```

### 1.4. Вариации

- **Вариация «Двойная цепочка» (до 30 элементов):** делаете две цепочки по 10–15 и связываете их «мостом» — последний образ первой цепочки бьёт первый образ второй.
- **Вариация «Цепочка-история»:** вместо отдельных контактов — один сюжет с персонажем (вы идёте по цепочке как герой). Лучше для детей и текстов: см. [цепочки и пеги](chains-pegs.md).
- **Вариация «Звуковая цепочка»:** добавляете рифму/ритм («батон-молоко — батон в молоке как в катке»). Помогает на старте.
- **Вариация «Цепочка + тело»:** первые 10 — на телесных пегах, далее — цепочкой от стопы.
- **Вариация «Обратная цепочка»:** учите сразу в обе стороны — после прямой прогоните назад (сыр→яйцо→молоко→хлеб) — прочность +40%.

### 1.5. Типичные ошибки

- **Слабые связи:** «хлеб рядом с молоком». Исправление: хлеб ПЛАВАЕТ в молоке, тонет.
- **Повтор действия:** везде «лежит рядом». Исправление: меняйте глаголы — врезается, протыкает, взрывает, замораживает.
- **Пропуск образа:** пытаетесь связать слова, а не картинки. Исправление: сначала образ, потом связь.
- **Слишком длинная цепочка >15:** рвётся в середине. Исправление: разбейте на две по 7–8.

### 1.6. Дриллы

**Дрилл 1 — «Покупки на скорость» (5 мин).** 5 случайных слов → цепочка → воспроизведение через 2 мин без подсмотра. 3 подхода.

**Дрилл 2 — «Глагольный штурм» (4 мин).** На пару «книга — лампа» придумайте 5 разных действий-связок: книга бьёт лампу, лампа просвечивает книгу, книга горит от лампы...

**Дрилл 3 — «Абстрактная цепочка» (7 мин).** Список: свобода, контроль, риск, баланс, рост. Сделайте образы и цепочку, проверьте через 10 мин.

**Дрилл 4 — «Цепочка наоборот» (5 мин).** Выучите 8 слов цепочкой, затем воспроизведите с конца. Засеките ошибки.

**Дрилл 5 — «Мост» (10 мин).** Две цепочки по 7 слов, свяжите мостом. Проверьте через час. Запишите, где порвалось.

> Прокачка цепочек: [цепочки и пеги](palaces.md).
**Суть:** берёте знакомое пространство, отмечаете точки-локусы в фиксированном порядке, на каждую «ставите» образ. Вспоминание = мысленная прогулка.

### 2.1. Алгоритм

```
1. Выберите здание: квартира, подъезд, путь на работу, вуз, офис — то, где вы бывали ≥20 раз.
2. Определите 10–15 локусов в ЕСТЕСТВЕННОМ порядке движения (по часовой, без прыжков).
   Правило: локус = устойчивый объект (дверь, зеркало, холодильник), а не пустой угол.
3. Пронумеруйте локусы и пройдите 2 раза мысленно — вперёд и назад.
4. Превратите каждый пункт материала в образ (Закон №1).
5. «Поставьте» образ на локус с ВЗАИМОДЕЙСТВИЕМ: образ ломает/пачкает/обнимает локус.
6. Пройдите маршрут 1 раз, озвучивая образы.
7. Проверка: закройте глаза, пройдите и «соберите» образы.
8. Повтор: через 20 мин → день → неделя → месяц.
```

### 2.2. Правила локусов (чек-лист)

- [ ] Локусы идут последовательно, без возвратов.
- [ ] Расстояние между локусами ≥1.5 метра в реальности (чтобы не сливались).
- [ ] Каждый локус уникален: не два одинаковых стула рядом — добавьте признак (красный стул, сломанный стул).
- [ ] Локус освещён и объёмный (не плоская точка на стене).
- [ ] На один локус — максимум 2–3 образа, иначе перегруз.
- [ ] Маршрут замкнутый или с ярким финалом (балкон, выход).

### 2.3. Примеры маршрутов

**Пример А — Квартира (10 локусов, база)**

```
1. Входная дверь — ручка обмотана колючей проволокой
2. Коврик в прихожей — хлюпает
3. Вешалка — куртки шевелятся
4. Зеркало — треснуло
5. Кухня-дверь — скрипит
6. Холодильник — гудит, дверца приоткрыта
7. Плита — конфорка светится
8. Окно — запотело
9. Диван — продавлен
10. Телевизор — экран в пыли
```
Размещение: на двери — ГИГАНТСКИЙ ТОРТ (тезис 1), на коврике — ... и т.д.

**Пример Б — Подъезд → улица (15 локусов, для речей)**

```
1. Лифт 2. Почтовые ящики 3. Дверь подъезда 4. Лавка 5. Дерево 6. Арка
7. Магазин 8. Перекрёсток 9. Остановка 10. Киоск 11. Фонтан 12. Скамейка
13. Библиотека-вход 14. Ступени 15. Колонна
```
Плюс: можно расширять бесконечно, добавляя улицы.

**Пример В — Тело + квартира (комбо для экзамена)**

```
Тело 1–5: макушка, лоб, нос, рот, грудь — вводные тезисы.
Квартира 6–15 — основная часть.
Балкон 16–18 — заключение и выводы.
```
Так не путаете вступление и основную часть.

### 2.4. Размещение образа на локус — 3 приёма

- **Внедрение:** образ ВСТРОЕН в локус (из холодильника вытекает молоко-река).
- **Разрушение:** образ ЛОМАЕТ локус (яйцо разбивает зеркало).
- **Преувеличение:** локус становится образом (диван превратился в сыр).

Выбирайте самый абсурдный из трёх.

### 2.5. Вариации

- **Вариация «Микро-дворец» (5 локусов):** для списка покупок — только кухня. Быстро.
- **Вариация «Мега-дворец» (50–100):** соедините 3–5 квартир/дворов в один маршрут. Для курса: см. [дворцы](palaces.md) — 15 готовых маршрутов.
- **Вариация «Временная линия»:** локусы = часы дня (7:00 — кровать, 12:00 — стол в кафе) — удобно для хронологии.
- **Вариация «Алфавитный дворец»:** 26 локусов на буквы — для списков по алфавиту.
- **Вариация «Дворец-матрешка»:** в одном локусе — дверь в другой дворец (для вложенных тем).

### 2.6. Типичные ошибки

- **Незнакомое место:** взяли дворец из фильма — плохо держится. Берите своё.
- **Хаотичный порядок:** прыгаете с кухни в ванную, потом в прихожую — мозг путается. Идите по порядку.
- **Перегруз локуса:** 5 образов на холодильник — каша. Максимум 2–3, лучше 1.
- **Нет взаимодействия:** просто «положили» образ рядом. Бейте, пачкайте, ломайте.

### 2.7. Дриллы

**Дрилл 1 — «Карта квартиры» (10 мин).** Нарисуйте план квартиры, отметьте 15 локусов, пронумеруйте. Пройдите мысленно 3 раза.

**Дрилл 2 — «10 слов во дворце» (7 мин).** Возьмите 10 случайных слов, разместите по квартире. Воспроизведите через 20 мин.

**Дрилл 3 — «Дворец наоборот» (5 мин).** Пройдите маршрут задом-наперёд (10→1). Замечаете слабые локусы?

**Дрилл 4 — «Пустой прогон» (3 мин/день).** Каждый день 3 мин гуляйте по дворцу без материала — просто освежая локусы. 7 дней.

**Дрилл 5 — «Дворец на 30» (20 мин).** Постройте маршрут на 30 локусов (квартира + подъезд + двор). Проверьте через день.

**Дрилл 6 — «Чужая квартира» (10 мин).** Попросите друга описать его квартиру (5 локусов), попробуйте запомнить там 5 слов — почувствуете разницу «своё/чужое».

> Готовые дворцы и шаблоны: [дворцы](../practical-domains/practice-workbook.md) с. 3–7.

## Техника 3: Major-система (цифры → слова)

**Когда:** любые числа — телефоны, даты, PIN-коды, номера билетов, исторические даты, цены.
**Срок:** выучить таблицу 1–2 дня (по 3 цифры в день), потом навсегда. Основа — фонетический код.
**Суть:** каждая цифра = согласный звук. Цифра → звук → слово → образ. Число → цепочка образов.

### 3.1. Таблица (база)

| Цифра | Звук | Мнемоника | Примеры слов (подберите свои!) |
|-------|------|-----------|--------------------------------|
| 0 | з, с, ц | 0 похож на яйцо/зеро — **З** | звезда, цепь, солнце, заяц, сани |
| 1 | т, д | 1 — **Т**онкая палка | тигр, дом, дуб, яд, дым |
| 2 | н | 2 — **Н** как лебедь | нос, небо, нитка, конь, вино |
| 3 | м | 3 — **М** — три ножки | мыло, машина, месяц, дым, яма |
| 4 | р | 4 — **Р** — флаг | река, рот, рубль, пар, перо |
| 5 | л, й | 5 — **Л** — ладонь | луна, лампа, ёлка, поле, лейка |
| 6 | ж, ш | 6 — **Ж** — жук (6 ножек) | жар, шар, шляпа, нож, душ |
| 7 | к, г | 7 — **К** — коса | кот, гора, ключ, нога, мука |
| 8 | в, ф | 8 — **В** — восьмёрка — **В** | вода, волк, флаг, сова, кофе |
| 9 | п, б | 9 — **Б**/ **П** — пузырь | палец, банан, бык, зуб, суп |

**Правила кодирования:**

- Гласные **а, о, у, и, е, я** — не считаются, они лишь «клей» для слова.
- Удвоенные согласные = одна цифра (ссора = 00).
- **й** после гласной = 5 (майка = 37? м=3, й=5 — но проверяйте по вашему списку).
- Сначала заучите таблицу звуков, потом слова-якоря на каждую цифру (по 3 слова).

### 3.2. Как кодировать число

```
Пример: 9240
9 → п/б → БАнан
2 → н → НОС
4 → р → Река
0 → з/с → Звезда
→ БАНАН-НОС-РЕКА-ЗВЕЗДА (цепочка или дворец)

Телефон 9-2-4-0-7-5-1 → Банан + Нос + Река + Звезда + Кот + Луна + Тигр
Образ: Банан нюхает Реку, из которой падает Звезда на Кота, сидящего на Луне рядом с Тигром.
```

**Длинное число — чанкинг:** 924-075-138 разбиваем на тройки и делаем 2–3 образа на чанк, связываем мостом.

### 3.3. Примеры (4 кейса)

**Кейс А — PIN 4 цифры: 2580**

```
2-н → НОС, 5-л → ЛУНА, 8-в → ВОДА, 0-з → ЗВЕЗДА
Образ: НОС на ЛУНЕ пьёт ВОДУ, в которой отражается ЗВЕЗДА.
Альтернатива: слово на весь PIN: 25=НАЛИЛ (н=2, л=5), 80=ВОЗ (в=8, з=0) → НАЛИЛ ВОЗ воды.
```

**Кейс Б — Дата 1945**

```
1-т → ТОРТ, 9-п → ПИРОГ, 4-р → РОЗА, 5-л → ЛУНА
История: ТОРТ-ПИРОГ с РОЗОЙ на ЛУНЕ — конец войны, праздник.
Короче: 19=ТП (ТаПочек), 45=РЛ (РуЛь) → Тапочек рулит по Луне.
```

**Кейс В — Телефон +7 924 075 13 89**

```
924 → Банан-Нос-Река (банан плывёт по реке, зажав нос)
075 → Звезда-Луна-? (звезда падает на луну)
13? → Тигр-?? — доведите до слова: 1389 → Тигр-Мопс-Вода-Банан
Цепочка: Банан в реке → звезда на луне → тигр с мопсом в воде ест банан.
```
Храните в дворце: прихожая=924, кухня=075, балкон=1389.

**Кейс Г — Цена 12 490 ₽**

```
1-Тигр, 2-Нос, 4-Река, 9-Банан, 0-Звезда
→ Тигр носом нюхает реку, где плавает банан-звезда. Или слово: 12=ТОН (т=1, н=2), 49=РБ (р=4, б=9), 0=с → ТОН РБ с...
Лучше два слова: 124=ТОНР (тонер), 90=БаЗ → Тонер Баз.
```

### 3.4. Каталог 00–99 (фрагмент, полный — в [цепочки и пеги](../practical-domains/practice-workbook.md) с. 12.

### 3.5. Вариации

- **Major + цепочка:** цифры → слова → цепочка (быстро для коротких чисел).
- **Major + дворец:** каждые 2 цифры (одно слово) — на один локус. Для длинных чисел 10+ цифр.
- **Major + PAO:** 6 цифр = персона-действие-объект (см. Технику 9).
- **Свои слова-якоря:** подберите слова, которые вам смешны/личны (имя друга на 22, ваш кот на 77).

### 3.6. Типичные ошибки

- Путать 5 и 6 (л/ш). Заучите фразу: «**Л**уна **Ш**ипит».
- Брать гласные за цифру («аист» ≠ 0). Только согласные.
- Делать длинное слово на 4 цифры цифрами — лучше два коротких.
- Не проговаривать вслух — звуковая система, говорите.

### 3.7. Дриллы

**Дрилл 1 — «Таблица наизусть» (3×5 мин).** Карточки: цифра → звук → 3 слова. До 100% без ошибок.

**Дрилл 2 — «PIN за 15 сек» (10 мин).** Генератор случайных 4-значных чисел → кодируйте → цепочка → проверка через 5 мин. 10 подходов.

**Дрилл 3 — «Телефон друга» (5 мин).** Закодируйте 3 реальных телефона цепочкой + дворцом, проверьте вечером.

**Дрилл 4 — «Дата-история» (7 мин).** 5 дат (1812, 1945, 1961, 1991, 2022) → придумайте историю на каждую.

**Дрилл 5 — «00–99 спринт» (15 мин).** Напишите все 00–99 за 10 мин по памяти (звук+слово). Сверка с [цепочки и пеги](chains-pegs.md).

## Техника 4: Телесные пеги (тело = шкаф для 10 предметов)

**Когда:** быстро запомнить 10 предметов на экзамене/собеседовании/встрече, когда нет времени строить дворец.
**Срок:** 5 минут, работает сразу. Держится 3–6 часов без повтора, сутки — с одним повтором.
**Суть:** используете своё тело как 10 локусов — точки в фиксированном порядке сверху вниз. Каждая точка — крючок.

### 4.1. Локусы на теле (база 10)

| № | Точка | Образ-крючок | Как запомнить | Сенсорика |
|---|-------|-------------|---------------|-----------|
| 1 | Макушка | Корона на голове | представьте тяжёлую корону | давит |
| 2 | Лоб | Лампочка на лбу | лампа мигает | свет, тепло |
| 3 | Глаза | Очки-бинокль | огромные очки | давят на переносицу |
| 4 | Нос | Клоунский красный нос | пищит при нажатии | холодный |
| 5 | Рот | Мегафон во рту | громкий звук | вибрация |
| 6 | Плечи | Рюкзак на плечах | лямки режут | тяжесть |
| 7 | Грудь | Щит на груди | металлический | холод |
| 8 | Живот | Пузо Деда Мороза | большое, трясётся | тепло |
| 9 | Колени | Шарики для боулинга на коленях | катаются | стук |
| 10 | Стопы | Катки/лыжи под ступнями | скользят | холод, скольжение |

**Порядок обязателен:** сверху вниз, чтобы не путаться. Простучите себя 2 раза перед запоминанием.

### 4.2. Алгоритм

```
1. Простучите точки 1→10, называя их вслух.
2. Каждый пункт списка → образ.
3. «Прикрепите» образ к точке С ВЗАИМОДЕЙСТВИЕМ (см. Закон №1).
4. Пройдите 1→10, проверяя.
5. Воспроизведите 10→1 для контроля.
```

### 4.3. Пример: нужно запомнить — вода, книга, ключ, яблоко, телефон, лампа, кот, машина, хлеб, часы

```
1. Макушка → из крана на макушке льётся ВОДА, заливает корону
2. Лоб → на лбу-табло написана КНИГА, страницы шуршат
3. Глаза → в глазах застрял КЛЮЧ, царапает
4. Нос → нос стал ЯБЛОКОМ, кусаете его
5. Рот → из мегафона звонит ТЕЛЕФОН, орёт
6. Плечи → на рюкзаке горит ЛАМПА, жжёт плечи
7. Грудь → на щите спит КОТ, царапает
8. Живот → из пуза выезжает МАШИНА, бибикает
9. Колени → шары-колени — это ХЛЕБные батоны, крошатся
10. Стопы → катки — это ЧАСЫ, тикают под ногами
```

### 4.4. Вариации

- **Расширение до 20:** добавьте 10 точек на спине/руках: затылок, уши, шея, локти, ладони, пальцы, бёдра, икры, пятки. Но лучше — второй круг по одежде.
- **Вариация «Одежда-пеги»:** 10 предметов одежды (шапка, шарф, куртка, ремень, джинсы...). Удобно, когда тело занято.
- **Вариация «Тело + цепочка»:** первые 10 — на теле, следующие — цепочкой от стоп (стопы — мост).
- **Вариация «Тело + Major»:** цифры на теле — для PIN: 1-макушка, 2-лоб и т.д.

### 4.5. Типичные ошибки

- Менять порядок точек — теряете последовательность. Фиксируйте 1→10.
- Класть образ рядом, а не НА точку — нет контакта. Втыкайте, вливайте, приклеивайте.
- Брать похожие образы на соседние точки — сливаются. Делайте контраст: мокрое/сухое, горячее/холодное.

### 4.6. Дриллы

**Дрилл 1 — «Тело на скорость» (3 мин).** 10 слов → тело → проверка через 5 мин. 3 круга.

**Дрилл 2 — «Слепой прогон» (2 мин).** Закройте глаза, дотроньтесь до каждой точки и назовите, что там.

**Дрилл 3 — «10→1» (2 мин).** Воспроизведение в обратном порядке — ловит слабые связи.

**Дрилл 4 — «20 на теле» (10 мин).** 20 слов: 10 на теле, 10 цепочкой от стоп. Проверка через час.

**Дрилл 5 — «Экзамен-симуляция» (7 мин).** 10 терминов из вашего предмета — на тело, затем ответьте устно, «простукивая» точки.

> Прокачка пегов: [цепочки и пеги](../practical-domains/practice-workbook.md) — листы для пегов.

## Техника 5: Keyword-метод (иностранная лексика)

**Когда:** любое чужое слово, которое нужно связать со значением — языки, термины, имена.
**Срок:** 30 секунд на слово, 10 слов → 15 минут с повтором. Отлично для старта, далее — интервальные повторы.
**Суть:** находите созвучное русское слово-«якорь» и связываете его со значением абсурдной сценой.

### 5.1. Алгоритм

```
1. Запишите слово звуками вашего языка (транскрипция на слух, не перевод).
2. Найдите «якорь» — русское слово, похожее по звуку (1–2 слога совпадения достаточно).
3. Свяжите якорь со ЗНАЧЕНИЕМ абсурдной сценой: якорь ДЕЛАЕТ что-то со значением.
4. Представьте сцену ярко 5 секунд (VIVID), проговорите вслух: «слово — якорь — значение».
5. Через 20 мин вспомните, через день — повторите. 3 повтора → в долгую память.
```

### 5.2. Формула

```
ЧУЖОЕ СЛОВО (≈ ЯКОРЬ) + ЗНАЧЕНИЕ = АБСУРДНАЯ СЦЕНА
Пример: pillow [пилоу] ≈ ПИЛ ЛОшадь → ЛОШАДЬ ПИЛИТ ПОДУШКУ (значение — подушка)
```

### 5.3. Примеры (принцип один для любого языка)

**Английский**

```
pillow [пилоу] = подушка → ПИЛ ЛОшадь → лошадь пилит подушку, перья летят
cabbage [кэбидж] = капуста → КЭБ + ИДЖ → кэб (такси) везёт капусту
butterfly [батэфлай] = бабочка → БАТя ФЛАй → батя летит как бабочка
```

**Японский**

```
たべる (taberu) = есть → ТАБелетка → ест таблетку размером с арбуз
ねこ (neko) = кошка → НЕ КОшка? → кошка говорит «не ко»
みず (mizu) = вода → МИЗулина → Мизулина пьёт воду из ведра
```

**Корейский**

```
먹다 (meokda) = есть → МЕДведь → медведь жрёт мёд ложкой
물 (mul) = вода → МУЛ → мул пьёт воду из лужи
책 (chaek) = книга → ЧЕК → чек из книги торчит
```

**Китайский**

```
吃 (chī) = есть → ЧИстая тарелка после еды, которую чистит ЧИп
书 (shū) = книга → ШУба из книг, шуршит
水 (shuǐ) = вода → ШУЙ шумит вода
```

**Испанский**

```
caballo [кабайо] = лошадь → КАБАльо → лошадь в кабаке пьёт
perro [перро] = собака → ПЕРРОн → собака на перроне лает
biblioteca [библиотека] = библиотека → уже якорь — библиотека из книг-библий
```

**Немецкий**

```
Hund [хунд] = собака → ХУНДра → собака-хундра лает
Buch [бух] = книга → БУХ — книга падает с «бух»
Wasser [вассер] = вода → ВАССЕРман пьёт воду
```

> Больше примеров и карточек: [универсальная лексика](../practical-domains/practice-workbook.md) — листы keyword.

### 5.4. Для имён и лиц

```
Имя «Тимур» → ТИМьян + МУРлычет → кот Тимур мурлычет с веточкой тимьяна
Лицо: запоминаете деталь (нос, очки) + якорь имени → очки Тимура из тимьяна.
```

### 5.5. Вариации

- **Вариация «Двойной якорь»:** длинное слово бьют на 2 якоря: *hippopotamus* → ХИППО + ПОТАМ → хиппо в поте.
- **Вариация «Keyword + дворец»:** 10 слов — на 10 локусов дворца, на каждом — сцена keyword. Для урока.
- **Вариация «Keyword + цепочка»:** цепочка из якорей — для связного текста на чужом языке.
- **Вариация «Звук → образ → значение»:** если якорь не находится, берите любой звук слова (суффикс) — «-tion» → «шн» → ШИНель.

### 5.6. Типичные ошибки

- **Якорь без связи со значением:** придумали «пилоу — пила», но не связали с подушкой. Всегда сцена: пила пилит подушку.
- **Слабый якорь:** созвучие на 1 букву («кошка — кошка» — ок, но «mizu — мизинец» — натянуто, но годится, если сцена яркая). Лучше натянутый якорь + яркая сцена, чем точный, но бледный.
- **Не проговаривать:** keyword — звуковой метод, говорите вслух 2–3 раза.
- **Учить без повтора:** keyword даёт быстрый вход, но без интервалов (день-неделя-месяц) выветривается. Ставьте в Anki/тетрадь.

### 5.7. Дриллы

**Дрилл 1 — «10 слов за 15 мин» (15 мин).** 10 новых слов → якорь → сцена → проверка через 20 мин. Цель: 8/10.

**Дрилл 2 — «Якорь-штурм» (5 мин).** На слово *bridge* придумайте 3 якоря: бридж, бриз, бричка → выберите самый яркий.

**Дрилл 3 — «Сцена наоборот» (5 мин).** Дано значение «лошадь» — вспомните чужое слово через якорь (кабайо → кабак).

**Дрилл 4 — «Лица-имена» (7 мин).** 5 фото + 5 имён → якорь на имя + деталь лица → проверка через 10 мин.

**Дрилл 5 — «Keyword-дворец» (10 мин).** 10 слов разместите во дворце (кухня). Пройдите и переведите.

## Техника 6: Акронимы и акростихи (структуры)

**Когда:** запомнить набор терминов, список правил, порядок действий, где важен состав, а не порядок или важен порядок.
**Срок:** 5–10 минут на создание, держится долго, если фраза смешная.
**Суть:** берёте первые буквы элементов → составляете слово (акроним) или фразу (акростих), где каждое слово начинается с нужной буквы.

### 6.1. Акроним (слово из букв)

```
Элементы: К, О, Ж, З, Г, С, Ф (цвета радуги)
→ КОЖЗГСФ → фраза «Каждый Охотник Желает Знать Где Сидит Фазан»
Проверка: К=Красный, О=Оранжевый, Ж=Жёлтый, З=Зелёный, Г=Голубой, С=Синий, Ф=Фиолетовый
```

**Алгоритм:**

```
1. Выпишите первые буквы в нужном порядке.
2. Попробуйте сложить слово (если гласные позволяют) или псевдослово.
3. Если не складывается — добавьте гласные для произносимости.
4. Привяжите слово к теме образом: «КОЖЗГСФ — кожаный заяц золотой...»
5. Проговорите 3 раза.
```

### 6.2. Акростих (фраза/стих)

```
Планеты: Меркурий, Венера, Земля, Марс, Юпитер, Сатурн, Уран, Нептун
→ «Мы Встретимся Завтра, Мой Юный Спутник, У Новой Планеты»
→ М В З М Ю С У Н
```

```
Налоги: НДС, НДФЛ, НП, УСН, ЕНВД
→ «На Диване Ночью Пьют Ужасный Егермейстер»
```

**Алгоритм:**

```
1. Первые буквы → список.
2. На каждую букву придумайте слово (сущ./прил.), чтобы фраза была смешной/абсурдной.
3. Чем абсурднее — тем лучше: «Весёлый Жираф Жрёт Зеленый Салат Феном».
4. Визуализируйте фразу как сцену (жираф с феном).
5. Соедините с дворцом, если нужно долго хранить.
```

### 6.3. Примеры (3 типа)

**Пример А — Порядок действий (авария)**

```
ДТП: Остановиться, Включить аварийку, Выставить знак, Вызвать скорую, Оказать помощь
→ О В В В О → «Олег В Вазе Вырастил Васильки Очень»
Сцена: Олег в вазе с васильками машет знаком аварийной остановки.
```

**Пример Б — Классификация (биология)**

```
Царства: Бактерии, Протисты, Грибы, Растения, Животные
→ Б П Г Р Ж → «Борщ Полюбили Грибы, Рисуя Жирафа»
```

**Пример В — Формула/правило (математика)**

```
Порядок действий: Скобки, Степени, Умножение/Деление, Сложение/Вычитание
→ С С У С → «Слон Съел Ужа С Солью»
```

### 6.4. Вариации

- **Вариация «Акроним + образ»:** слово-акроним превратите в образ (КОЖЗГСФ → кожаный заяц).
- **Вариация «Акростих-дворец»:** каждое слово акростиха — на свой локус. Двойная страховка.
- **Вариация «Обратный акростих»:** учите с конца — для проверки прочности.
- **Вариация «Смешанный»:** часть — акроним, часть — цепочка (для длинных списков >7).

### 6.5. Типичные ошибки

- **Скучная фраза:** «Мама Мыла Раму» — не запоминается, если не смешно. Делайте абсурд.
- **Несовпадение букв:** перепутали порядок — проверяйте по исходному списку.
- **Слишком длинный акростих (>7 слов):** фраза сама забывается. Делайте 2 акростиха по 4–5.

### 6.6. Дриллы

**Дрилл 1 — «Радуга за 2 мин» (2 мин).** Составьте свой акростих на радугу, нарисуйте сцену.

**Дрилл 2 — «5 терминов» (7 мин).** Возьмите 5 терминов из вашей работы → акроним → образ.

**Дрилл 3 — «Чужая фраза → своя» (5 мин).** Возьмите чужой акростих и переделайте под своих персонажей.

**Дрилл 4 — «Акроним-хаос» (5 мин).** Случайные буквы: П Р С Т К → придумайте фразу за 60 сек, проверьте через 10 мин.

## Техника 7: Чанкинг (группировка)

**Когда:** длинные числа, серии данных, списки >7 — разбиваете хаос на блоки.
**Срок:** 30 секунд на группировку, эффект мгновенный. Основано на законе Миллера 7±2.
**Суть:** рабочая память держит 3–4 чанка, а не 10 элементов. Сгруппировали — запомнили.

### 7.1. Принцип

```
Без чанкинга: 9 2 4 0 7 5 1 3 8 9 → 10 элементов → перегруз
С чанкингом: 924 — 075 — 1389 → 3 чанка → легко
Каждый чанк = 1 образ (см. Major) или 1 локус (дворец)
```

**Правила группы:**

- Не больше 3–4 элементов в одной «клетке» памяти.
- Группа должна иметь смысл или образ (924 → «банан-нос-река», а не «девять-два-четыре»).
- Границы чанков — пауза/дефис/цвет.

### 7.2. Примеры

**Числа**

```
Телефон: 924-075-1389
→ 924 (БАН-НОС-РЕКА) → банан в реке
→ 075 (ЗВЕЗДА-ЛУНА) → звезда на луне
→ 1389 (ТИГР-ВЕРБЛЮД-БАН) → тигр на верблюде ест банан
Свяжите три образа цепочкой или разложите по 3 локусам.
```

```
Карта: 4278 1234 5678 9012 → 4 чанка по 4 цифры → 4 образа во дворце (прихожая, кухня, спальня, балкон)
```

**Слова/термины**

```
Список 12 слов: хлеб, молоко, яйца, сыр, яблоки, сок, чай, кофе, сахар, соль, перец, масло
→ Чанк 1 (молочка): хлеб-молоко-яйца-сыр → «завтрак»
→ Чанк 2 (фрукты-напитки): яблоки-сок-чай-кофе → «полдник»
→ Чанк 3 (приправы): сахар-соль-перец-масло → «специи»
3 чанка → 3 образа → 3 локуса.
```

**Буквы/аббревиатуры**

```
IB M C E O F B I → IBM CEO FBI → 3 чанка, каждый — аббревиатура-образ
Без чанкинга — 9 букв, с чанкингом — 3 блока.
```

### 7.3. Иерархический чанкинг (для больших объёмов)

```
12 цифр: 924075138901
→ Уровень 1: 924-075-138-901 (4 чанка по 3)
→ Уровень 2: (924-075) — «первый мегачанк» → образ «банан-звезда» на локусе 1
            (138-901) — «второй мегачанк» → образ «тигр-банан» на локусе 2
Итого: 12 цифр → 2 локуса.
```

### 7.4. Вариации

- **Чанкинг + Major:** цифры → слова → чанки (оптимально для чисел).
- **Чанкинг + дворец:** каждый чанк — на свой локус (для списков).
- **Чанкинг + смысл:** группируйте по смыслу, а не по порядку (молочка/фрукты).
- **Визуальный чанкинг:** выделяйте чанки цветом/шрифтом при записи — мозг любит визуальные границы.

### 7.5. Типичные ошибки

- Чанк 5–6 элементов — всё равно перегруз. Дробите до 3–4.
- Чанки без смысла — «924» как «девять два четыре» — не помогает. Делайте образ.
- Нет связи между чанками — запомнили чанки, но забыли порядок. Свяжите чанки цепочкой/мостом.

### 7.6. Дриллы

**Дрилл 1 — «Телефон-чанки» (5 мин).** 3 телефона → разбейте на тройки → закодируйте Major → проверка.

**Дрилл 2 — «12 слов → 3 чанка» (7 мин).** Список 12 покупок → 3 чанка по смыслу → разместите по 3 локусам.

**Дрилл 3 — «Карта 16 цифр» (7 мин).** Случайные 16 цифр → 4 чанка по 4 → дворец 4 локуса.

**Дрилл 4 — «Иерархия» (10 мин).** 12 цифр → 2 мегачанка → 2 локуса → проверка через час.

## Техника 8: Слоёный метод (для текстов дословно)

**Когда:** речь, экзамен, выступление, стихотворение, определение — нужно близко к тексту, а не только смысл.
**Срок:** 1 час на страницу А4 при подготовке, далее — повторы. Комбинирует дворец + цепочку + чанкинг.
**Суть:** текст учите слоями, от каркаса к деталям, а не зубрёжкой подряд. См. [дословное запоминание](../practical-domains/verbatim-mastery.md).

### 8.1. 4 слоя

```
1. КАРКАС — 3–5 ключевых слов на весь текст (о чём каждый абзац). Это скелет.
2. БЛОКИ — каждый абзац/строфа = 1 образ (смысл блока, а не слова).
3. ШВЫ — связи между блоками (как один блок вытекает из другого).
4. ПОЛИРОВКА — дословные фрагменты только на сложных местах (цитаты, термины, даты).
```

**Порядок заучивания:** Каркас → Блоки → Швы → Полировка. Не наоборот!

### 8.2. Алгоритм

```
1. Прочитайте текст 2 раза, выделите 3–5 ключевых слов (каркас). Запомните их дворцом (5 локусов).
2. Разбейте на блоки (абзацы/строфы). Каждый блок → 1 образ (что происходит?).
3. Свяжите блоки цепочкой/швами: конец блока 1 → начало блока 2 (физический контакт).
4. Пройдите каркас → блоки → швы вслух, пересказывая своими словами (смысл).
5. Выберите 2–3 места, где нужна дословность (определение, цитата) → выучите дословно чанкингом + цепочкой, «приклейте» к блоку.
6. Прогоните 3 раза: своими словами → близко к тексту → дословно где нужно.
7. Проверка: закройте текст, пройдите по дворцу-каркасу, «разворачивая» каждый блок.
```

### 8.3. Пример — стихотворение 8 строк (Пушкин, фрагмент)

```
Текст:
«Мороз и солнце; день чудесный!
 Ещё ты дремлешь, друг прелестный —
 Пора, красавица, проснись:
 Открой сомкнуты негой взоры...»

Каркас (4 слова): Мороз — Дремлешь — Проснись — Взоры
→ Дворец: дверь=МОРОЗ (льдина), прихожая=ДРЕМЛЕШЬ (подушка), кухня=ПРОСНИСЬ (будильник), окно=ВЗОРЫ (глаза)

Блоки:
Блок 1 (строки 1–2): мороз+солнце+чудесный день → образ: СОЛНЦЕ растапливает МОРОЗ, день сияет
Блок 2 (строки 3–4): призыв проснуться → образ: БУДИЛЬНИК орёт «проснись!», срывает одеяло

Шов: солнце из блока 1 светит на будильник блока 2 — связь.

Полировка (дословно):
«сомкнуты негой взоры» → СОМКНУТЫ (сомкнутые ставни) + НЕГА (нега = лень, образ — ленивец) + ВЗОРЫ (глаза)
→ Ставни-глаза, на них спит ленивец. Приклейте к окну дворца.

Прогон: дверь (мороз-солнце) → прихожая (дремлешь) → кухня (проснись) → окно (взо́ры-ленивец).
```

### 8.4. Пример — определение (экзамен)

```
Определение: «Память — это психический процесс запечатления, сохранения и воспроизведения опыта»

Каркас: Память — Процесс — Опыт
Блоки:
- Запечатление → ФОТОаппарат щелкает
- Сохранение → СЕЙФ закрывается
- Воспроизведение → ПРИНТЕР печатает

Шов: фото → в сейф → из сейфа → в принтер (цепочка)
Полировка: дословно «запечатления, сохранения и воспроизведения» — три слова на 3 локуса рядом.
```

### 8.5. Вариации

- **Слоёный + дворец:** каркас — большой дворец (комнаты = главы), блоки — локусы в комнате.
- **Слоёный + цепочка:** внутри блока — цепочка из 3–5 деталей.
- **Слоёный + карточки:** полировку — на Anki/карточки из [тетради](../foundations/textbook.md) гл. 7.

## Техника 9: PAO (персона-действие-объект)

**Когда:** колоды карт, большие числа (12+ цифр), соревнования, запоминание на скорость. Продвинутая техника, требует заготовки.
**Срок:** 1–2 недели на каталог 52 карт / 00–99, потом — мгновенно. Основа — [классический курс](classic-mnemonics.md) §19.
**Суть:** каждая карта/число = персонаж + действие + объект. Комбинируя, из 1–2 карт получаете яркую сцену с 3 элементами.

### 9.1. Принцип

```
Карта/число → Персона (кто?) + Действие (что делает?) + Объект (с чем?)
Туз червей = Роза (персона) + Целует (действие) + Бабочку (объект)
Король пик = Пират (персона) + Режет (действие) + Верёвку (объект)

Сцена из 2 карт: Персона1 + Действие2 + Объект1 → «Роза режет бабочку» — абсурд, запоминается.
Для чисел: 12-34-56 → Персона12 + Действие34 + Объект56
```

### 9.2. Заготовка каталога (пример для карт — сила старшинства)

| Карта | Персона | Действие | Объект |
|-------|---------|----------|--------|
| Туз червей | Роза (девочка) | целует | бабочку |
| Король червей | Король | машет | скипетром |
| Дама червей | Дама | веером | машет |
| Туз пик | Пират | режет | верёвку |
| Король пик | Пират-капитан | рубит | саблей |
| Дама пик | Ведьма | варит | зелье |
| Джокер | Клоун | жонглирует | мячами |

> Для 52 карт — 52 персоны. Начните с 10 любимых персонажей (герои фильмов), добавьте действие/объект, которые им свойственны.

### 9.3. Для двузначных чисел 00–99

```
00 → Солнце → персона: Солнечный человек → действие: светит → объект: луч
12 → Тоня → персона: Тоня → действие: тонет → объект: тон (краска)
34 → Мара → персона: Мара → действие: марает → объект: маркер
56 → Лиса → персона: Лиса → действие: лижет → объект: лист
...
Сцена: 00-12-34 → Солнечный человек тонет в маркере (персона00 + действие12 + объект34)
```

**6 цифр = 1 сцена:** 123456 → Персона12 + Действие34 + Объект56 → «Тоня марает лист».

### 9.4. Примеры

**Пример А — 6 цифр: 924075**

```
92 → Банан (персона: Банановый человек) + действие: падает + объект: ?
24 → Нос → действие: нюхает
07 → Сок
→ Персона92 (Банановый человек) + Действие24 (нюхает) + Объект07 (сок)
→ Банановый человек нюхает сок, чихает.
```

**Пример Б — 3 карты: Туз червей, Король пик, Дама пик**

```
Туз червей (Роза-целует-бабочку) + Король пик (Пират-рубит-саблей) + Дама пик (Ведьма-варит-зелье)
Сцена 1: Роза рубит зелье (Персона Тч + Действие Кп + Объект Дп)
Сцена 2: Пират варит бабочку (Персона Кп + Действие Дп + Объект Тч) — если 6 карт, делаете 2 сцены.
Разместите сцены по 2 локусам дворца.
```

**Пример В — Телефон через PAO (12 цифр → 2 сцены → 2 локуса)**

```
924075 138901
Сцена1 на локусе 1 (дверь): Банановый человек нюхает сок
Сцена2 на локусе 2 (холодильник): Тигр банит (банит?) звезду — дорисуйте логику, главное яркость.
```

### 9.5. Вариации

- **PAO чистый:** 1 карта = 1 сцена (персона+действие+объект одной карты) — просто, но менее ёмко.
- **PAO двойной:** 2 карты = 1 сцена (П1+Д2+О1) — ёмкость ×2, нужно 26 локусов на колоду.
- **PAO-числа + дворец:** каждые 6 цифр — сцена на локус. 30 цифр → 5 локусов.
- **PAO-персонаж свой:** берите друзей/родных как персон — работает сильнее.

### 9.6. Типичные ошибки

- Персона, действие, объект похожи — сцена бледная. Делайте контраст: балерина рубит мясо.
- Забыли каталог — пытаетесь импровизировать. PAO требует заготовки, выучите 00–52 заранее.
- Сцены без взаимодействия с локусом — вылетают. Поставьте сцену НА локус: Роза рубит зелье НА холодильнике.

### 9.7. Дриллы

**Дрилл 1 — «Каталог 10» (20 мин).** Составьте PAO на 10 чисел (00,11,22...99) — персона+действие+объект, нарисуйте.

**Дрилл 2 — «Сцена из 2 карт» (10 мин).** 6 случайных карт → 3 сцены → разместите во дворце 3 локуса.

**Дрилл 3 — «6 цифр → сцена» (10 мин).** 3 числа по 6 цифр → 3 сцены → проверка через 10 мин.

**Дрилл 4 — «Колода 18 карт» (15 мин).** 18 карт → 9 сцен (PAO двойной) → 9 локусов → проверка.

> Готовый PAO-каталог и тренировки: [классический курс](chains-pegs.md) — раздел PAO.

## Техника 10: Дворец для экзамена (билеты)

**Когда:** подготовка к экзамену с билетами, зачёт, собеседование с темами. Самый надёжный способ для «вытянул билет → вспомнил».
**Срок:** 2 часа на весь курс (20 билетов × 6 мин), хранение — до экзамена с повторами. Комбинация дворца + слоёного метода.
**Суть:** каждый билет = комната во дворце, вопросы билета = локусы в комнате, ответы = образы на локусах.

### 10.1. Алгоритм

```
1. Посчитайте билеты (например, 20). Выберите дворец на 20 комнат/зон (квартира 4 комнаты ×5 локусов + подъезд).
2. Пронумеруйте билеты → привяжите к комнатам в порядке экзамена (Билет 1 = прихожая, Билет 2 = кухня...).
3. В каждом билете выделите 3–5 вопросов/пунктов → это локусы в комнате.
4. Каждый пункт ответа → образ (Закон №1), поставьте на локус с взаимодействием.
5. Создайте «вход» в билет: на двери комнаты — яркий образ-тема билета (название).
6. Пройдите билет целиком: вход → локус1 → локус2 → локус3.
7. Симуляция экзамена: закройте глаза, «зайдите» в случайную комнату (билет), воспроизведите.
8. Повторы: все билеты — прогон за день до экзамена, слабые — отдельно.
```

### 10.2. Пример — История, билет «Причины Первой мировой»

```
Комната: гостиная (Билет №5)
Вход (дверь гостиной): на двери — ГИГАНТСКИЙ ПИСТОЛЕТ (выстрел в Сараево — триггер темы)

Локус 1 (диван): на диване сидит ГАВРИЛ ПРИНЦИП, стреляет из пистолета → причина-повод (убийство эрцгерцога)
Локус 2 (телевизор): на экране карта ЕВРОПЫ, разорванная на куски → империализм, передел колоний
Локус 3 (окно): за окном стоят ТРИ СОЮЗА (Антанта vs Тройственный), держатся за руки, потом дерутся → система союзов
Локус 4 (кресло): на кресле — ЗАВОД с трубами, дымит → гонка вооружений
Локус 5 (полка): на полке — КОРОНА кайзера падает → кризис монархий, национализм

Проверка: заходите в гостиную → видите пистолет на двери → диван с Принципом → телевизор с картой → окно с союзами...
```

### 10.3. Пример — Биология, билет «Фотосинтез»

```
Комната: кухня (Билет №12)
Вход: на двери кухни — СОЛНЦЕ с фотоаппаратом (фото+синтез)

Локус 1 (холодильник): на холодильнике — ЛИСТ, светится, из него капает САХАР → световая фаза
Локус 2 (плита): на плите — ХЛОРОФИЛЛ (зелёный человечек) варит суп → хлорофилл, хлоропласты
Локус 3 (окно): за окном — ВОЗДУХ (СО2) влетает в лист → углекислый газ
Локус 4 (стол): на столе — ВОДА (стакан) льётся в лист → вода, фотолиз
Локус 5 (раковина): в раковине — КИСЛОРОД пузырится → выделение О2, глюкоза
```

### 10.4. Шаблоны комнат (на 5 локусов)

```
Стандартная комната:
1. Дверь/вход — тема билета
2. Левый угол/окно — вопрос 1
3. Центр (стол/диван) — вопрос 2
4. Правый угол (шкаф/полка) — вопрос 3
5. Выход/балкон — вывод/формула/дата

Для билета с 3 вопросами — 3 локуса достаточно, не плодите пустые.
Для билета с 7+ пунктов — 2 образа на локус (но не больше 3).
```

### 10.5. Вариации

- **Вариация «Дворец-город»:** каждый предмет = район города, билеты = дома. Для 50+ билетов.
- **Вариация «Билет-цепочка»:** внутри комнаты — цепочка, а не локусы (если комната маленькая).
- **Вариация «Цвет-код»:** каждый тип билета — свой цвет образа (история — красный, формулы — синий) — помогает не путать.
- **Вариация «Экзамен наоборот»:** учите ответы, затем по ответу угадывайте билет — тренирует «вытянул вопрос → нашёл комнату».

### 10.6. Типичные ошибки

- **Билеты без номеров:** не привязали к порядку — на экзамене не найдёте. Пронумеруйте и пройдите 1→20.
- **Одна комната — один образ:** слишком мало, билет пустой. 3–5 образов на билет.
- **Похожие образы в соседних билетах:** путаете. Делайте контраст: в билете 5 — Принцип, в билете 6 — Ленин, не два усатых.
- **Нет прогона вслух:** молча «прошли» — на экзамене не вспомните. Прогоните вслух 2 раза.

### 10.7. Дриллы

**Дрилл 1 — «1 билет за 10 мин» (10 мин).** Возьмите 1 билет (3 вопроса) → комната 5 локусов → образы → проверка через 20 мин.

**Дрилл 2 — «Слепой билет» (15 мин).** 5 билетов → 5 комнат → друг называет номер → вы «заходите» и пересказываете.

**Дрилл 3 — «Карта курса» (30 мин).** Нарисуйте план дворца на 20 билетов, подпишите темы на дверях. Пройдите без образов.

**Дрилл 4 — «Симуляция экзамена» (20 мин).** Перемешайте номера билетов (карточки), тяните случайно, отвечайте с таймером 5 мин.

**Дрилл 5 — «Слабые локусы» (10 мин).** После прогона отметьте 3 самых слабых образа, переделайте их ярче.

> Шаблоны билетов и пример дворца на 30 билетов: [дворцы](../practical-domains/practice-workbook.md) — листы для билетов.

**Быстрый выбор за 10 секунд:**

```
≤7 и порядок не важен? → Цепочка
Нужен порядок / много? → Дворец
Цифры? → Major → чанкинг → дворец
Слова чужие? → Keyword
Структура/список правил? → Акроним
Текст дословно? → Слоёный
Карты/скорость? → PAO
Экзамен-билеты? → Дворец-билеты
```

## 7 законов мнемоники (расширенные)

1. **Образ важнее слова.** Всегда превращайте в картинку. Слово забывается, картинка — остаётся. Проверка: можете ли вы нарисовать это за 5 сек? См. [как работает память](../foundations/how-memory-works.md).

2. **Абсурд сильнее логики.** Чем смешнее/страшнее/противоестественнее — тем крепче. Логичное мозг отбрасывает как «обычное». Добавьте нарушение физики.

3. **Движение лучше статики.** Падающие, бегущие, взрывающиеся, текущие образы. Статичный образ — мёртвый. Толкните его.

4. **Взаимодействие, а не соседство.** Два образа должны касаться, бить, пачкать, протыкать друг друга. «Рядом» = забудете. «Воткнуто» = запомните.

5. **Повторение по расписанию.** Сразу → через 20 мин → через день → через неделю → через месяц. Без повтора любая техника — однодневка. Используйте [тетрадь](../foundations/textbook.md) гл. 2.

> Бонус-закон: **Простота бьёт сложность.** Лучше 2 ярких образа, чем 10 бледных. Упрощайте.


### Контрольные тесты для каждой техники (примеры)

→ Keyword → сцена → проверьте через 20 мин → переведите обратно.

### Финальные советы от практиков (мнемонический совет)

1. **«Лучший образ — тот, который вы бы не забыли в жизни»** — используете личный опыт, сильные эмоции.
2. **«Не учите, а строите»** — каждая техника = постройка (дворец, цепь, пег). Вы — архитектор памяти.
3. **«Плохой образ лучше, чем идеального ожидания»** — перфекционизм убивает практику. Делайте → корректируйте → делайте лучше.
4. **«Память — это мышца, а не орган»** — каждый дрилл = отжимание для мозга. 15 мин/день = результат.
5. **«Техника без повтора = пушка без патронов»** — календарь повторений обязательнее техники.
6. **«Комбо даёт ×3, но не ×10»** — ожидайте реалистичного усиления, не магии.
7. **«Учите других — учите себя»** — преподавание закрепляет в 10 раз глубже.
8. **«Сон — часть памяти»** — не учите до полуночи. Ложитесь, мозг консолидирует.
9. **«Ваша первая дворец всегда своя квартира»** — не изобретайте, используйте то, где бывали.
10. **«Страх — ваш союзник»** — если что-то страшно/неожиданно — запоминается лучше. Используйте это.

### Шпаргалка автономна (итоговая)

> **Быстрый выбор за 10 секунд:**
>
> ≤7 и порядок не важен? → **Цепочка**
> Нужен порядок, много? → **Дворец**
> Цифры? → **Major** → чанкинг → дворец
> Слова чужие? → **Keyword**
> Структура/список правил? → **Акроним**
> Текст дословно? → **Слоёный**
> Карты/скорость? → **PAO**
> Экзамен-билеты? → **Дворец-билеты**
> 10 вещей прямо сейчас? → **Телесные пеги**

> **Принцип шпаргалки:** каждая техника автономна. Можно вырвать один раздел и он будет работать без остальных. Но связка даёт ×3 к эффекту — см. [учебник](../practical-domains/practice-workbook.md).

> **Связки техник (комбо):**
>
> | Комбо | Когда | Как |
> |-------|-------|-----|
> | Цепочка + Дворец | список 20+ | первые 10 — дворец, следующие — цепочка от последнего локуса |
> | Major + Дворец | телефон, дата, 20+ цифр | 2 цифры=слово → слово на локус |
> | Keyword + Дворец | урок 10 слов | каждое слово — сцена на локус |
> | Слоёный + Дворец | речь, экзамен | каркас — дворец, блоки — локусы |
> | Чанкинг + Цепочка | длинный список | чанки по 3–4 → чанки цепочкой |
> | PAO + Дворец | карты, 30+ цифр | сцена PAO (6 цифр/2 карты) на локус |
> | Пеги + Цепочка | быстро 15+ | 10 на теле, 5 цепочкой от стоп |
>
> Начните с 1 техники, добавьте комбо через неделю — см. [учебник](../foundations/index.md) — оглавление всего курса
