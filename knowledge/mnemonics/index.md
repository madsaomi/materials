# Мнемотехника — раздел базы знаний

> **Мнемотехника（記憶術）** — набор приёмов, позволяющих запоминать быстро и надолго: образы, истории, дворцы памяти, интервальные повторения.
>
> Раздел **универсален**: приёмы применяются к языкам, программированию, экзаменам, книгам, именам. Японский используется как основной полигон примеров (см. подразделы), но техники переносимы куда угодно.

## Быстрый старт за 5 минут

1. Прочитайте про **кривую Эббингауза** → поймёте, зачем повторять по интервалам
2. Освойте **формулу сильного образа**: яркость + абсурд + движение + эмоция
3. Попробуйте на 5 словах **keyword-метод**
4. Поставьте **Anki** (или бумажные карточки Лейтнера)
5. Вернитесь к нужному файлу по карте выше

## Золотые правила раздела

1. Мнемоника — костыль: после автоматизации выбрасывайте её
2. Образ должен быть ВАШИМ — чужие работают хуже своих
3. Повторение важнее изобретения: слабый образ с 5 повторениями > гениальный без
4. Одна мнемоника = один якорь; не смешивайте техники в одной карточке
