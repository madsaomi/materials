## 1. Почему лексика — узкое место

Грамматика японского N4 — ~150 конструкций. Лексика для того же уровня — **1500 слов**. Разница в десять раз. Вывод очевиден: скорость освоения языка = скорость освоения словаря.

**Три факта:**

1. Слово без контекста умирает в памяти за сутки（кривая Эббингауза)
2. Слово с ярким образом живёт неделями
3. Слово, употреблённое в своей фразе 5–7 раз, становится вечным

Конвейер этого файла：**звук → якорь → образ → фраза → SRS.**

## 2. Keyword-метод: полный курс

### 2.1 Алгоритм из пяти шагов

```
Шаг 1. Запишите иностранное слово русскими буквами
        猫 → нэко
Шаг 2. Найдите русское слово, СОДЕРЖАЩЕЕ это звучание
        нэ-ко → НЕКОт / КОт на букву Н
Шаг 3. Постройте картинку, где keyword и ПЕРЕВОД взаимодействуют
        Неоновый КОТ светится в темноте
Шаг 4. Произнесите слово вслух, представьте картинку 5 секунд
Шаг 5. Составьте свою фразу со словом（минимум 5 слов длиной)
        面白い猫を見た。— Видел интересного кота.
```

### 2.2 Три типа якорей

| Тип | Пример | Когда использовать |
|-----|--------|--------------------|
| **Прямой** | neko → неКОт | Звучание почти совпадает с переводом |
| **Кривой** | yama（гора) → ЯМА вверх ногами | Прямого нет; абсурд компенсирует |
| **Смысловой** | benkyō（учёба) → «БЕНТо в КЁтo едят на учёбе» | Звук далеко; цепляем через сцену |

### 2.3 Правила качества якоря

- ✅ Якорь содержит перевод или намекает на него
- ✅ Картинка ДВИЖЕТСЯ (не статичный натюрморт)
- ✅ Есть эмоция или абсурд
- ✅ Якорь личный: ваши места, ваши знакомые, ваша еда
- ❌ Не берите якорь, который надо запоминать отдельно («нэко… э… что там?») — такой хуже отсутствия

### 2.4 Что делать с длинными словами

Длинное слово режется на куски:

```
ありがとう（arigatou， спасибо)
→ АРИ-ГА-ТОУ → «АРИСТОКРАТ ГАДАЕТ на ТОузе» — спасибо, аристократ!
おはよう（ohayou， доброе утро)
→ О-ХА-ЁУ → «ОХАют от утренней свежести»
```

Кусков больше двух — стройте мини-сцену из 3 кадров.

## 4. Когнаты и заимствования

Когнаты — слова, похожие в двух языках из-за общего происхождения. Это БЕСПЛАТНАЯ лексика: узнавание вместо запоминания.

### Испанский → русский

| Слово | Перевод | Комментарий |
|-------|---------|-------------|
| familia | семья | очевидно |
| importante | важный | очевидно |
| música | музыка | очевидно |
| problema | проблема | очевидно |
| biblioteca | библиотека | сместился смысл：не книжный магазин! |

### Английский → русский

information, system, music, idea, sport, film — тысячи когнатов. Опасность — false friends（см. §8).

### Японские заимствования из английского

Катакана читается почти как оригинал：

```
コーヒー koohii ← coffee
テレビ terebi ← TV
ホテル hoteru ← hotel
バス basu ← bus
パソコン pasokon ← PC
```

**Стратегия:** сначала выгребите ВСЕ когнаты и заимствования（в японском сотни) — это 10–20% словаря за один вечер. Мнемоники тратьте только на «настоящие» слова.

## 5. Корни вместо слов

Учить корень = учить пачку слов сразу.

### Японский: один кандзи = гнездо

| Корень | Слова |
|--------|-------|
| 食（еда) | 食べる есть · 和食 японская кухня · 食堂 столовая · 食品 продукты · 外食 еда вне дома |
| 動（движение) | 動く двигаться · 自動 автоматический · 移動 перемещение · 動物 животное · 行動 действие |
| 気（дух) | 天気 погода · 元気 бодрый · 気分 настроение · 人気 популярность · 気をつける осторожно |

Один кандзи + правило сборки = 5–7 слов без зубрёжки.

### Латинские корни для английского/англского

| Корень | Значение | Потомки |
|--------|----------|---------|
| port- | носить | transport, portable, портфель, переносить |
| scrib- | писать | describe, manuscript, escribir(исп.), описание |
| dict- | говорить | dictionary, predict, диктант, decir(исп.) |

### Корейский: хада открывает глаголы

하다「делать」превращает существительное в глагол：

```
공부（учёба) + 하다 = 공부하다 учиться
사랑（любовь) + 하다 = 사랑하да любить
요리（кулинария) + 하다 = 요리하다 готовить
```

Выучили хада — открыли сотню глаголов.

## 6. Коллокации сильнее слов

Слово живёт в связках. Учите не «run», а «run a business»; не「電話」а「電話をかける」.

**Почему:** связка содержит грамматику и контекст — слово выпрыгивает готовой конструкцией.

**Формат карточки-коллокации:**

```
Front: делать зарядку（яп.)
Back: 運動をする（うんどうをする)
      毎朝運動をします。
```

**Правило 3+1:** к существительному сразу учите глагол и прилагательное-партнёра:

```
猫（кошка) + 飼う（заводить) + 可愛い（милая)
= 猫を飼いたい。Хочу завести милую кошку.
```

## 7. Тематические гнёзда

Мозг хранит лексику сетями. Учите сценами:

**Сцена «Утро»:**

```
起きる встать → 顔を洗う умыться → 歯を磨く почистить зубы →
朝ご飯 завтрак → 会社へ行く поехать в офис
```

Пять слов связаны последовательностью утра — вспоминаются цепочкой.

**Против списков «100 самых нужных слов» без тем:** список перемешивает несмешиваемое（кот, банк, вкусный, идти). Мозг хранит такое плохо. Гнёзда решают.

**Размер гнезда:** 5–9 слов（лимит рабочей памяти). Больше — делите на подсцены.

## 11. Китайский: тоны и слоги

Главная сложность китайского — тоны. Их тоже мнемонизируем:

| Тон | Образ голоса | Мнемоника |
|-----|--------------|-----------|
| 1 (ровный) | нить натянута высоко | «поём О-о-о ровно» |
| 2 (восходящий) | вопрос «а?» | «ХТО здесь?» голос вверх |
| 3 (нисходяще-восходящий) | пружина вниз-вверх | «ну-у-у ЛАДно» |
| 4 (падающий) | топор рубит вниз | «НЕТ!» резко |

**Пример mā/má/mǎ/mà:**

```
妈 mā мама → тон 1：МАма поёт ровную колыбельную
麻 má конопля → тон 2：МАзать? а что?（вопрос вверх)
马 mǎ лошадь → тон 3：лошадь пружинит рысью
骂 mà ругать → тон 4：МАТчит! ругается топором
```

Четыре слова — один слог. Различаются ТОЛЬКО картинками тонов.

**Слоги через крючки:**

| Пиньинь | Якорь |
|---------|-------|
| xièxie谢谢 спасибо | ЩЕбетать спасибо |
| nǐ hǎo你好 привет | НИть + ХОрохо |
| zàijiàn再见 до свидания | ДЗАЙц + ДЖИнн：за джином увидимся |
| duìbuqǐ извини | ДУЭЛЬ БИть？извините |

## 15. Слово в трёх карточках

Одно важное слово = три карточки разного направления:

**Карточка 1 — узнавание:**

```
Front: 静か
Back: しずか тихий · 静かな部屋
```

**Карточка 2 — воспроизведение:**

```
Front: тихий（яп., на-прил.)
Back: 静か（しずか)· この町は静かです。
```

**Карточка 3 — ситуация:**

```
Front: Опишите библиотеку одним прилагательным
Back: 図書館は静かです。
```

Три направления прочнее одного. Важным словам（топ-300) — всегда три карточки; остальным хватит первой.

## 17. Топ-10 ошибок при изучении лексики

1. **Учить списками без контекста.** Слово вне фразы мертво. Всегда пример.
2. **Игнорировать звучание.** Только зрительное запоминание → не понимаете речь. Проговаривание обязательно.
3. **Все силы — новым словам.** Повторения старых важнее: 60% времени SRS / 40% новое.
4. **Перфекционизм якоря.** Ищете идеальный образ 5 минут → теряете темп. Хороший образ сейчас > идеальный никогда.
5. **Отказ от письма.** Набранное на клавиатуре забывается быстрее написанного рукой.
6. **Одна карточка — одно слово навсегда.** Слово нужно встретить в живом тексте 7+ раз — читайте!
7. **Учить в одном порядке.** Перемешивайте колоду — иначе порядок списка станет костылём.
8. **Пропуск повторений ради нового.** Долги Anki убивают мотивацию; лимит новых слов спасает.
9. **Не отмечать ложных друзей.** Ошибки в них живут годами без отдельной колоды.
10. **Забывать произношение ударений/тонов.** В китайском/японском неверный тон или интонация = другое слово.

## 19. Активное vs пассивное владение

| | Пассив（узнаю) | Актив（употребляю) |
|--|----------------|--------------------|
| Объём | 3000+ слов | 1000–1500 слов |
| Карточки | узнавание（яп→рус) | воспроизводство（рус→яп) |
| Практика | чтение, аудирование | письмо, речь |
| Норма соотношения | 2:1 на старте | к B1 стремитесь к 1:1 |

**Вывод:** не всё нужно в актив. Топ-1000 слов гоняйте в обе стороны, остальное — только узнавание. Это снимает половину нагрузки.

## 21. Спринт «300 слов за месяц»

**База:** 30 дней × 10 новых слов + повторения по SRS.

| Неделя | Фокус | Дневной цикл |
|--------|-------|--------------|
| 1 | Глаголы движения + бытовые существительные | 15 мин новые якори + 10 мин Anki |
| 2 | Прилагательные + еда | то же + фраза на каждое слово вслух |
| 3 | Гнёзда по темам（дом, город, работа) | + мини-текст из 5 слов дня |
| 4 | Повтор всех 300 + тест | 50 слов/день контрольных |

**Правила спринта:**

1. Якорь обязателен только для слов БЕЗ когнатов
2. Каждое слово — в своей фразе минимум дважды за месяц
3. Пропущенный день ≠ два дня нормой; просто продолжайте
4. На 30-й день: контрольные 100 случайных слов — цель ≥85%

**Что дальше:** после спринта лексика переходит в обычный режим SRS (5–10 новых в день), а вы возвращаетесь к грамматике курса.

## 22. FAQ

**Якоря засоряют голову?**
Нет: образ живёт 1–2 недели, потом слово уходит в автоматизм и якорь стирается сам. Это строительные леса.

**Сколько времени на одно слово?**
Новичку ~1 минута（слово+якорь+фраза), опытному 20–30 секунд. Быстрее любых механических повторов при удержании ×3–5.

**Работает ли для абстрактных слов？**
Да, через смысловой тип якоря：свобода（じゆう）→ «ДЗЮдо свободного стиля». Абстракцию изображаем персонажем или сценой.

**Лучше готовые словари мнемоник?**
Для японского — WaniKani（англ.). Для старта берите готовые, но переписывайте под себя: личные детали = прочность.

**Как не путать похожие слова（кот/cut, 猫/寝子)?**
Парные истории о различии（см. [кана-ловушки](kana-japanese.md)) + отдельная красная колода для минимальных пар.

## 25. Слова-связки и паразитеры

Разговорную речь делают НЕ умные слова, а связки. Выучите их в первую очередь:

### Японские

| Связка | Значение | Когда |
|--------|----------|-------|
| えーと | эм-м… | пауза для мысли |
| なるほど | вот как! | понял новую инфо |
| やっぱり | всё-таки | подтвердилось ожидание |
| 本当に | правда? | удивление |
| それで | и что дальше? | развивает тему |
| ところで | кстати | смена темы |
| つまり | то есть | резюмирует |
| 実は | если честно | признание |

**Якорь-история:** えーと = «ЭЙ, ТУт подожди»（пауза); なるほど = «НА РОДину похоже — понял!»

### Русские аналоги для понимания структуры

Связки — 5% слов， но 50% звучания естественности. В любом языке учите их ПЕРВЫМИ после приветствий.

## 28. Речевая активация слов

Якорь даёт узнавание. Активность дают речевые упражнения:

**Метод «История из пяти слов».** Берёте 5 слов дня → сочиняете связный абзац. Абсурд приветствуется:

> Слова：猫、銀行、高い、食べる、嬉しい
> 「Банк выдал коту кредит на дорогого лосося. Кот съел его и обрадовался.」

**Метод «Интервью с собой».** Задайте себе 5 вопросов дня со словами урока и ответьте вслух：

```
今日は何を食べましたか。
どこへ行きましたか。
誰に会いましたか。…
```

**Метод «Пересказ соседу».** Перескажите диалог урока третьему лицу（реальному или игрушечному). Пересказ ≠ чтение：слова активируются.

**Норма:** каждое слово произносится в своей фразе минимум дважды в день изучения + один раз через неделю.

- На каждый：якорь + картинка（15 мин)

- Вслух фразы：「こんにちは、田中さん」×5（5 мин)
- Запись в слово-дневник

**День 2（20 мин):**
- Anki: повтор 10 + новые 10（тема «Местоимения и です」)
- Мини-диалог вслух с новыми словами（5 мин)

**День 3（25 мин):**
- Anki повтор（10 мин)
- Гнездо «Утро» из 6 слов сценой（10 мин)
- История из пяти слов дня письменно（5 мин)

**Дни 4–7:** по шаблону; в день 7 — контрольные 30 слов（цель 27+ правильных).

**Типичные грабли первой недели:**
- Попытка выучить 30 слов за раз → к дню 3 всё забывается → демотивация. Держите норму 10!
- Якорь «потом придумаю» → слова без якорей вылетают первыми. Придумывайте сразу.
- Пропустили день 4 → не «навёрстывайте» двойной порцией, вернитесь на шаг.

**Итог недели:** 50 слов в Anki, 5 гнёзд, 7 мини-фраз вслух. Это ровно темп, который за год даст 2000+ активных слов без выгорания.

## 37. Keyword-метод: глубокое погружение

### 37.1 Почему keyword работает: три опоры памяти

Keyword-метод держится на трёх законах из [Как работает память](how-memory-works.md):

1. **Двойное кодирование (Паивио).** Слово кодируется сразу в двух кодах — вербальном (звук) и образном (картинка). Два следа крепче одного. Поэтому формула «звук → картинка → перевод» бьёт простую зубрёжку в 3–5 раз по удержанию через неделю (см. §9 [там же](how-memory-works.md)).
2. **Эффект генерации.** Образ, который вы придумали САМИ, держится на 30–40% дольше чужого. Чужая картинка «кот-неон» работает, своя «кот соседа Васьки в неоне над подъездом» — ещё лучше.
3. **Отличительность (von Restorff).** Абсурд и движение выделяют образ из фона. Мозг хранит не «кот», а «кот светится, мяукает неоном и падает с балкона».

> Три опоры вместе: вербальный крючок + личный образ + абсурд = вход в долговременную память за одну встречу.

### 37.2 Когда keyword НЕ нужен

Не тратьте якорь, если есть бесплатный путь:

| Ситуация | Что делать вместо якоря |
|----------|------------------------|
| Когнат (familia, information, コーヒー) | Узнавание: просто заметить сходство, карточка «узнаю» |
| Слово уже всплывает из контекста (приветствия после 3 просмотров дорамы) | Сразу фраза-пример, без промежуточного образа |
| Корень уже знаком (食 → 食物, 食品, 食堂) | Учить гнездом корня (§5), а не по одному |
| Слово ультра-частотное и короткое (は, 的, de) | Маскот-частица (§24), а не фонетический крючок |

**Правило:** якорь — для «трудных» 60% словаря. Остальные 40% — когнаты, корни, маскоты.

### 37.3 Тайминг и протокол 60 секунд

Новички тратят 3–4 минуты на якорь и выгорают. Держите протокол:

```
0–10с : Запишите слово + чтение вслух ×2
10–25с: Найдите крючок (если не нашёлся за 15с — берите кривой!)
25–40с: Нарисуйте движущуюся сцену 5 секунд с закрытыми глазами
40–55с: Произнесите слово вслух, наложив сцену
55–60с: Составьте фразу 5+ слов, запишите
```

Если крючок не идёт — не зависайте. «Кривой» якорь сейчас лучше «идеального» никогда (см. §17 ошибка №4). Через 2–3 встречи слово уйдёт в автоматизм, якорь отвалится сам.

### 37.5 Три анти-паттерна keyword

1. **Перегруженный якорь.** «нэко → НЕон КОТ → КОТ на НЕбе → НЕжность КОтика» — слишком много ступеней. Один крючок, одна сцена.
2. **Стерильный якорь.** Картинка без эмоции и движения («кот сидит»). Добавьте действие: «кот светится, падает, мяукает неоном».
3. **Якорь ради якоря.** Слово już знаете? Не стройте якорь. Сразу в фразу и в SRS.

### 37.6 Как понять, что якорь сработал

Через сутки: вспоминаете перевод за ≤3 секунды без подсказки? Якорь сработал. Если тянете 5–7 секунд и сцена всплывает кусками — усилите движение/абсурд и проговорите фразу ещё 2 раза.

## 39. Коллокации: атлас устойчивых связок (глубокий курс)

### 39.1 Почему коллокация экономит грамматику

Одиночное слово: `電話` → надо вспомнить частицу を + глагол かける + вежливость. Коллокация: `電話をかける` — уже готовая рельса. Мозг достаёт блоком, не собирает по винтикам. Поэтому учите не «слово», а «слово + 1–2 партнёра».

**Формула карточки-коллокации (§6 расширено):**

```
Front: звонить по телефону (яп.)
Back:  電話をかける（でんわをかける）
       昨日友達に電話をかけた。
       Партнёры: 電話に出る ответить · 電話を切る повесить трубку
Tags: jp::collocation::phone
```

### 39.6 Как вводить коллокации в SRS

1. Одна карточка = одна связка (не список).
2. Front — русский коллокационный перевод, Back — оригинал + пример + 1–2 соседа.
3. Не учите 20 коллокаций одного гнезда в один день — размажьте на 3 дня, иначе интерференция.

## 40. Тематические гнёзда: 10 готовых сценариев

Каждое гнездо — цепочка 6–8 слов, связанных историей. Учите сценой, вспоминайте цепочкой.

### 40.1 Аэропорт

```
パスポート паспорт → チェックイン регистрация → 荷物 багаж →
搭乗口 выход на посадку → 遅延 задержка → 搭乗 посадка → 離陸 взлёт
```
Корейский: 여권 · 체크인 · 짐 · 탑승구 · 지연 · 탑승 · 이륙  
Китайский: 护照 hùzhào · 登机口 dēngjīkǒu · 行李 xíngli · 延误 yánwù  
Испанский: pasaporte · facturación · equipaje · puerta de embarque · retraso

### 40.2 Ресторан

```
予約 бронь → 案内 провожать к столу → 注文 заказ →
お勧め рекомендация → お会計 счёт → 領収書 чек → ごちそうさま спасибо за угощение
```
**Мини-диалог-гнездо:** 「予約しています。」「何名様ですか。」「注文お願いします。」— три фразы покрывают гнездо.

### 40.3 Больница

```
受付 ресепшн → 診察 осмотр → 処方箋 рецепт → 薬局 аптека →
熱 температура → 咳 кашель → お大事に поправляйтесь
```

### 40.4 Университет

```
授業 занятие → 出席 присутствовать → 欠席 отсутствовать →
提出 сдавать → 締切 дедлайн → 成績 оценка → 留学 обмен
```

### 40.5 Магазин

```
値段 цена → 割引 скидка → レジ касса → 袋 пакет →
返品 возврат → 交換 обмен → 保証 гарантия
```

### 40.6 Транспорт

```
定期券 проездной → 乗り換え пересадка → 時刻表 расписание →
各駅各停 каждая станция → 急行 экспресс → 終電 последний поезд → 始発 первый поезд
```

### 40.7 Отель

```
宿泊 проживание → チェックイン/アウト → 鍵 ключ →
朝食 завтрак → 清掃 уборка → 連泊 несколько ночей → 延泊 продлить
```

### 40.8 Работа

```
出勤 прийти на работу → 会議 собрание → 資料 материалы →

```

### 40.9 Семья и дом

```
掃除 уборка → 洗濯 стирка → 料理 готовка → 食器 посуда →
```

### 40.10 Хобби

## 41. SRS: глубокое погружение — интервалы, настройки, личи

### 41.1 Кривая и интервалы

Без повторения через 1 день остаётся ~30% ([кривая Эббингауза](how-memory-works.md)). С повторениями:

| Повтор | Интервал | Что происходит |
|--------|----------|----------------|
| 1 | через 1 день | закрывает провал суток |
| 2 | через 3 дня | закрепляет на неделю |
| 3 | через 7 дней | переводит в 3 недели |
| 4 | через 21 день | уходит в месяцы |
| 5+ | ×2–2.5 каждый раз | вечное хранение |

Это классический SM-2 (Anki по умолчанию). Не изобретайте свои интервалы — берите готовые.

### 41.2 Настройки Anki для лексики (скопируйте)

```
Новые в день: 10 (не 20!)
Повторы в день: 100–150
Шаги изучения: 1m 10m
Градация: 15m 1d
Интервалы: 1 3 7 21
Личи-порог: 8 падений → действие
Порядок: случайный (не по добавлению)
```

Почему 10 новых? 10 × 30 дней = 300, а повторы не душат. 20 новых = 600 повторов к концу месяца и срыв.

### 41.3 Личи (leeches): когда слово падает 8 раз

Лич — карточка, которую вы забыли ≥8 раз. Обычный повтор её не спасёт.

**Протокол лича:**

1. Поставьте тег `leech` (Anki ставит автоматом)
2. Перерисуйте якорь: добавьте движение/абсурд, сделайте личным
3. Добавьте коллокацию-партнёра (слово без связки падает чаще)
4. Пропишите слово рукой ×5 и произнесите в 2 фразах вслух
5. Сбросьте интервалы карточки (Forget), начните заново с 1 дня

Если падает снова — возможно, слово слишком редкое для вашего уровня: отложите на месяц.

### 41.4 Метрика удержания: как понять, что темп верный

Раз в неделю тест из §34 (30 слов):

| Узнавание (яп→рус) | Воспроизведение (рус→яп) | Диагноз |
|--------------------|--------------------------|---------|
| ≥90% | ≥75% | темп оптимален |
| 80–90% | 60–75% | чуть много нового, снизьте до 7/день |
| <80% | <60% | перегруз: стоп новым, 3 дня только повторы |

Цель — удержание, не скорость добавления.

### 41.5 Ручной SRS без приложения (если Anki надоел)

Бумажный «слово-дневник» из §32 + коробка Лейтнера:

- 4 коробки: 1д, 3д, 7д, 21д.
- Новая карточка → коробка 1.
- Вспомнили → вперёд на следующую. Забыли → назад в коробку 1.
- Проверка коробок по расписанию. Работает без электричества.

## 43. Прогрессия от A1 до B1 через лексику

| Этап | Слов | Что добавляется к якорю | Пример |
|------|------|------------------------|--------|
| A1 (выживание) | 0–500 | только звук+образ | приветствия, числа, еда — максимум крючков |
| A2 (быт) | 500–1200 | образ + коллокация | уже 1 партнёр к слову |
| B1 (общение) | 1200–2500 | образ угасает, остаётся коллокация+гнёзда | синонимы (§27), идиомы (§14) |

К 1500 словам якоря нужны только для 15–20% новых (абстракции, редкие). Остальное — корни, коллокации, контекст чтения.
