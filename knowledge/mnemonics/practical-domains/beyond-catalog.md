# Каталог Beyond 1000: Major 00–99 полный + бинарные числа

> **Мнемонический справочник.** Полный каталог Major-системы (00–99), бинарные числа (0–255), PAO-таблица, рифмованные пеги 1–100, алфавитные пеги A–Z. Всё в одном месте — не нужно никуда листать.
>
> **Использование:** при запоминании любых числовых данных — телефонов, дат, PIN, формул, номеров билетов, бинарных последовательностей.
>
> Связанные материалы: [классический курс §7](../foundations/how-memory-works.md)

---

## Как пользоваться этим каталогом

```
1. Найдите число в каталоге
2. Посмотрите образ-слово для каждой цифры/пары
3. Встретьте образы в цепочке/дворце/PAO
4. Воспроизведите по порядку
```

## Часть IV. Бинарные числа 0–255 через Major

> **Принцип:** каждый бит = позиция, каждая группа 8 бит = десятичное число → Major-образ.

### Таблица битов → десятичных чисел

| Бит 7 (128) | Бит 6 (64) | Бит 5 (32) | Бит 4 (16) | Бит 3 (8) | Бит 2 (4) | Бит 1 (2) | Бит 0 (1) | Десятичное | Major-образ |
|-------------|-----------|-----------|-----------|----------|----------|----------|----------|-----------|------------|
| 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | з-з |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 1 | з-т |
| 0 | 0 | 0 | 0 | 0 | 0 | 1 | 0 | 2 | з-н |
| 0 | 0 | 0 | 0 | 0 | 0 | 1 | 1 | 3 | з-м |
| 0 | 0 | 0 | 0 | 0 | 1 | 0 | 0 | 4 | з-р |
| 0 | 0 | 0 | 0 | 0 | 1 | 0 | 1 | 5 | з-л |
| 0 | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 6 | з-ж |
| 0 | 0 | 0 | 0 | 0 | 1 | 1 | 1 | 7 | з-к |
| 0 | 0 | 0 | 0 | 1 | 0 | 0 | 0 | 8 | з-в |
| 0 | 0 | 0 | 0 | 1 | 0 | 0 | 1 | 9 | з-п |
| 0 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | 16 | т-з |
| 0 | 0 | 1 | 0 | 0 | 0 | 0 | 0 | 32 | н-з |
| 0 | 1 | 0 | 0 | 0 | 0 | 0 | 0 | 64 | ж-з |
| 1 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 128 | т-т-з |

### Быстрый перевод: бинарное → Major → образ

**Пример:** `11001010` (202)

1. Разбиваем на байты: `11001010`
2. Десятичное: 128+64+8+2 = 202
3. Major 2-0-2: н-...-н = **Нан** (202 = н-н)
4. Образ: **Нанос** на набережной

**Пример:** `01010101` (85)

1. Десятичное: 64+16+4+1 = 85
2. Major 8-5: в-л = **Водолей**
3. Образ: **Водолей лопнул**

**Пример:** `11111111` (255)

1. Десятичное: 128+64+32+16+8+4+2+1 = 255
2. Major 2-5-5: н-л-л = **Нелло**
3. Образ: **Нелло на лавочке**

### Цвета RGB через Major

| Цвет | R | G | B | Байт | Десятичное | Major | Образ |
|------|---|---|---|------|-----------|-------|-------|
| Чёрный | 0 | 0 | 0 | 00000000 | 0 | з-з | з-з |
| Белый | 255 | 255 | 255 | 11111111 | 255 | н-л-л | нелло |
| Красный | 255 | 0 | 0 | 11111111 | 255 | н-л-л | нелло (красный!) |
| Зелёный | 0 | 255 | 0 | 11111111 | 255 | н-л-л | нелло (зелёный!) |
| Синий | 0 | 0 | 255 | 11111111 | 255 | н-л-л | нелло (синий!) |
| Фиолетовый | 128 | 0 | 128 | 10000000+10000000 | 128+128=256* | т-т-з + т-т-з | |

> *256 — выходит за рамки 00–99, разделите: 25-6 → н-ж, н-к = Ножник

### Как использовать алфавитные пеги

```
1. Создайте список из 26 элементов (или менее)
2. Для каждого элемента:
   - Найдите букву в алфавитном порядке
   - Вспомните образ-якорь этой буквы
   - Встретьте элемент + якорь в сцене
3. Воспроизведите по порядку букв
```

1. А = АВАРИЯ → Вашингтон в аварии

## Часть XII. Частые ошибки каталога

1. **Путаю звуки Major:** «п» и «б» — уточните таблицу §I
2. **Забываю образ через неделю:** повторите через день, через 3 дня, через неделю
3. **Образы слишком похожи:** перерисуйте абсурднее (правило VIVID)
4. **Смешиваю Major и рифму:** выбирайте одну систему и используйте последовательно
5. **Начинаю с PAO, не выучив Major:** сначала Major 00–99, потом PAO
6. **Не тренирую скорость:** без speed run каталог не автоматизируется
7. **Пропускаю контрольные точки:** всегда проверяйте перед следующим этапом
8. **Использую чужие образы:** создайте свои — они в 2–3 раза крепче
9. **Не повторяю:** 10 минут ежедневно > 2 часа раз в неделю
10. **Перегружаю за раз:** не более 20 новых образов за сессию

## Часть XIV. Психология: почему образы работают

### Dual coding theory (Павио, 1971)

```
Вербальный код    <->    Визуальный код
     |                    |
     +--------+-----------+
              |
         Глубокое кодирование
              |
         Лучшее удержание
```

Два независимых канала обработки информации дают аддитивный эффект — если один канал не работает, другой спасает.

### Level of processing (Крейк и Локхарт, 1972)

| Уровень | Пример | Удержание |
|---------|--------|-----------|
| Структурный | "Слово написано заглавными?" | 15% |
| Фонетический | "Рифмуется ли с...?" | 35% |
| Семантический | "Означает ли...?" | 65% |
| Образный (VIVID) | "Представьте абсурдную сцену" | 90%+ |

### Generation effect (Сладэр, 1978)

> **Самопроизведённый образ в 2-3 раза крепче заимствованного.**

Поэтому: **всегда создавайте свои образы**, даже если каталог предлагает готовые.

## Часть XV. Нейробиология: что происходит в мозге

### Гиппокамп и place cells

Гиппокамп содержит **place cells** (ячейки места) — нейроны, срабатывающие при нахождении в конкретном месте. Метод локусов **эксплуатирует эту же механику**: мы "помещаем" образы в знакомые места, активируя те же нейронные популяции.

### Pattern separation / Pattern completion

- **Pattern separation** — разделение похожих образов (чтобы не путать)
- **Pattern completion** — восстановление целого по фрагменту (вспоминание)

Мнемотехника тренирует **оба** процесса: абсурдные образы улучшают separation, цепочки/дворцы — completion.

### Sleep replay

В глубоком сне (NREM) гиппокамп **повторяет** дневные траектории (replay). Повторение перед сном + качество сна = консолидация.

**Решение:**

## Часть XIX. Финальные рекомендации

### 10 правил мастера

1. **Ежедневность важнее объёма.** 15 минут каждый день > 3 часа в воскресенье.
2. **Слабое звено тренируется вдвойне.** Провалили норматив — вернитесь назад и добавьте 50% повторов именно там.
3. **Замер каждую неделю.** Невидимый прогресс не мотивирует; цифры в журнале — топливо.
4. **Своё лучше чужого.** Чужой образ работает на 30-50% слабее. Всегда заменяйте на свой.
5. **Абсурд сильнее логики.** Чем смешнее/страшнее/удивительнее — тем крепче.
6. **Движение лучше статики.** Падающие, бегущие, взрывающиеся образы.
7. **Повторение по расписанию.** Сразу -> через день -> через 3 дня -> через неделю -> через месяц.
8. **Не перегружайте.** Максимум 20 новых образов за сессию.
4. **Сон = половина результата.** 7-9 часов; глубокие фазы консолидируют факты.
10. **Вернитесь к основам.** Раз в месяц — полный обход основного каталога (Major, PAO, пеги).
