# Рабочая тетрадь по мнемонике

> **Это практикум учебника. Автономен.** Теория — в [классическом курсе](../core-techniques/classic-mnemonics.md), здесь — только упражнения с нарастающей сложностью и полные ответы. Ядро — модули 0–10; остальное — продвинутое и опциональное приложение.
>
> **Правила работы:**
> 1. Делайте письменно или вслух — в голове «прокрутил» не считается
> 2. Ответы открывайте только после честной попытки
> 3. Норматив модуля выполнен → переход дальше; нет → повтор через день
> 4. Отмечайте выполнение в [журнале прогресса](#журнал-прогресса)

## Модуль 1：Закон силы образа

*Теория: [курс §3](../core-techniques/classic-mnemonics.md). Задача — довести генерацию образов до скорости и яркости. Без сильного образа не работает ни цепочка, ни дворец.*

### 1.1. Раскрасьте серое

Превратите статичные картинки в живые（движение+эмоция+звук):

| Дано | Ваша версия | Проверка (есть ли движение/звук/эмоция) |
|------|-------------|---------------------------------------|
| чайник стоит на плите | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| кошка спит | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| письмо лежит в ящике | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| лампочка висит | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| часы тикают | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| кран капает | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| книга лежит на столе | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |
| автобус ждёт | ＿＿＿＿＿＿＿＿＿＿ | движение ☐ звук ☐ эмоция ☐ |

Критерий: в каждой версии минимум 2 канала из 3 (движение/звук/эмоция) + масштаб или абсурд.

### 1.2. Масштабная деформация

Представьте ГИГАНТСКИМ / МИКРОСКОПИЧЕСКИМ:

1. чемодан → ＿＿＿＿＿＿＿＿＿＿
2. муравей → ＿＿＿＿＿＿＿＿＿＿
3. чашка кофе → ＿＿＿＿＿＿＿＿＿＿
4. автомобиль → ＿＿＿＿＿＿＿＿＿＿
5. карандаш → ＿＿＿＿＿＿＿＿＿＿
6. дом → ＿＿＿＿＿＿＿＿＿＿
7. капля воды → ＿＿＿＿＿＿＿＿＿＿
8. яблоко → ＿＿＿＿＿＿＿＿＿＿

Подсказка: гигантское должно пугать/удивлять, микроскопическое — теряться/требовать лупы. Добавьте звук.

### 1.3. Абсурд-конструктор

Соедините пары взаимодействием（не рядом!):

| Пара | Взаимодействие | Сила (1–5) |
|------|----------------|------------|
| зонд + арбуз | ＿＿＿＿＿＿＿＿＿＿ | |
| телефон + медведь | ＿＿＿＿＿＿＿＿＿＿ | |
| ножницы + океан | ＿＿＿＿＿＿＿＿＿＿ | |
| лестница + облако | ＿＿＿＿＿＿＿＿＿＿ | |
| зонт + крокодил | ＿＿＿＿＿＿＿＿＿＿ | |
| гитара + снеговик | ＿＿＿＿＿＿＿＿＿＿ | |
| ботинок + молния | ＿＿＿＿＿＿＿＿＿＿ | |
| ведро + комета | ＿＿＿＿＿＿＿＿＿＿ | |

Правило касания: один объект действует на другой, деформирует, проникает, меняет. «Рядом лежат» = 0 баллов.

### 1.4. Пять чувств

Опишите один объект всеми каналами: вид／звук／запах／вкус／осязание:

```
Объект: торт
Вид: ＿＿＿＿＿＿ Звук: ＿＿＿＿＿＿ Запах: ＿＿＿＿＿＿
Вкус: ＿＿＿＿＿＿ Осязание: ＿＿＿＿＿＿
Эмоция: ＿＿＿＿＿＿ Действие: ＿＿＿＿＿＿
```

Повторите для двух объектов на выбор: лимон, старый портфель, гроза.

```
Объект №2: ＿＿＿＿＿＿
Вид: ＿＿＿ Звук: ＿＿＿ Запах: ＿＿＿ Вкус: ＿＿＿ Осязание: ＿＿＿
Объект №3: ＿＿＿＿＿＿
Вид: ＿＿＿ Звук: ＿＿＿ Запах: ＿＿＿ Вкус: ＿＿＿ Осязание: ＿＿＿
```

### 1.5. Норматив скорости

Засеките время：10 случайных слов → образ на каждое.

Слова（закройте линейкой по одному):

```
окно · поезд · лимон · шляпа · река
кресло · гроза · пирог · глобус · свисток
```

Время: ＿＿＿＿ сек. Цель модуля: ≤ 100 сек суммарно (≤10 сек на образ).

### 1.6. Трансформация абстракций

Абстрактное → конкретный персонаж/предмет/действие. Придумайте мгновенный образ:

| Абстракция | Ваш образ | Почему запомнится |
|------------|-----------|-------------------|
| договор | ＿＿＿＿＿＿ | |
| свобода | ＿＿＿＿＿＿ | |
| экономика | ＿＿＿＿＿＿ | |
| тревога | ＿＿＿＿＿＿ | |
| информация | ＿＿＿＿＿＿ | |
| ответственность | ＿＿＿＿＿＿ | |
| система | ＿＿＿＿＿＿ | |
| результат | ＿＿＿＿＿＿ | |

Критерий: абстрактное стало тем, что можно увидеть, услышать, потрогать, уронить.
Примеры-подсказки: «договор» → два вора жмут руки над бумагой; «тревога» → сирена на голове.

### 1.7. Скоростной спринт образов (3 раунда)

Раунд А — существительные (по 5 сек на слово, вслух описывайте 1 фразой):

```
Раунд А: якорь · барабан · вишня · гитара · дракон
Время: ___ сек. Яркость 1–5: ___
```

Раунд Б — глаголы (сделайте стоп-кадр действия):

```
Раунд Б: бежать · светить · крошить · шептать · взрывать
Время: ___ сек. Яркость 1–5: ___
```

Раунд В — прилагательные/абстракции (персонифицируйте):

```
Раунд В: прозрачный · тяжёлый · срочный · нежный · бесконечный
Время: ___ сек. Яркость 1–5: ___
```

Цель: каждый раунд ≤ 50 сек, средняя яркость ≥4/5.

### 1.8. Двунаправленная проверка

Партнёр (или вы через час) называет ваш образ — вы вспоминаете исходное слово. И наоборот.

| Слово → Образ (вы) | Через час: образ → слово | Удержано |
|---------------|----------------------------|----------|
| окно → ___ | ___ → окно? | ☐ |
| поезд → ___ | ___ → поезд? | ☐ |
| лимон → ___ | ___ → лимон? | ☐ |
| шляпа → ___ | ___ → шляпа? | ☐ |
| река → ___ | ___ → река? | ☐ |

Критерий: образ ведёт обратно к слову без подсказки. Если нет — образ был слишком общим.

### 1.9. Чек-лист качества образа (5 усилителей)

Оцените каждый свой образ 0/1 по пунктам. Сумма ≥3 = сильный.

| Образ | Крупный/яркий | Движение | Абсурд | Эмоция | Сенсорика | Сумма |
|-------|---------------|----------|--------|--------|-----------|-------|
| чайник | | | | | | /5 |
| кошка | | | | | | /5 |
| письмо | | | | | | /5 |
| лампочка | | | | | | /5 |
| чемодан | | | | | | /5 |

### 1.10. Норматив модуля — расширенный

- 10 случайных слов → 10 образов за ≤100 сек
- Каждый образ оценивается ≥3/5 по чек-листу 1.9
- Двунаправленная проверка ≥8/10 через час
- Абстракции 8 шт → мгновенные персонификации без пауз >5 сек

Статус: ☐ выполнен. Дата: ___ Попыток: ___

## Модуль 2：Цепочка ассоциаций

*Теория: [курс §4](../core-techniques/classic-mnemonics.md). Принцип: каждое звено — контактное действие, не «рядом». Тренирует связь, готовит к дворцу.*

### 2.1. Тренировочная шестёрка

Свяжите историей（каждая пара — контакт!):

```
мяч → дождь → пират → будильник → мёд → велосипед
```

Ваша цепочка:

1. мяч＋дождь: ＿＿＿＿＿＿＿＿＿＿
2. дождь＋пират: ＿＿＿＿＿＿＿＿＿＿
3. пират＋будильник: ＿＿＿＿＿＿＿＿＿＿
4. будильник＋мёд: ＿＿＿＿＿＿＿＿＿＿
5. мёд＋велосипед: ＿＿＿＿＿＿＿＿＿＿

Через час воспроизведите список: ___/6
Через сутки: ___/6
Где разрыв (если был): ___

### 2.2. Десятка под контроль времени

10 случайных слов（генератор) → цепочка → цель ≤ 6 минут сборки, ≥ 9/10 припоминания через час.

Фиксация: попытка №___, собрано за ___ мин, вспомнено ___/10, через сутки ___/10
Выборочный набор для старта (если нет генератора):

```
лиса · медведь · ножницы · облако · парашют · ракета · светофор · торт · улитка · флаг
```

### 2.3. Обратная раскрутка

Возьмите свою цепочку 2.2 и восстановите список В ОБРАТНОМ порядке（тренирует двусторонние связи).

Результат прямой: ___/10. Обратный: ___/10. Время обратного: ___ сек.

### 2.4. Выборочный доступ

Пусть партнёр（или таймер+случайное число) спрашивает：「Что было пятым？」「Что между третьим и седьмым？」— 10 вопросов к своей цепочке.

Правильных: ___/10. Время ответа среднее: ___ сек.
Трудные позиции (начало/середина/конец): ___

### 2.5. Норматив модуля

Цепочка из **15 слов**, припоминание ≥ 13/15 сразу и ≥ 12/15 через сутки.

Дневник попыток:

|---------|------|--------------|-------|-------------|--------------|
| 1 | | | /15 | /15 | |
| 2 | | | /15 | /15 | |
| 3 | | | /15 | /15 | |
| 4 | | | /15 | /15 | |

### 2.6. Цепочка на скорость — 6 слов за 90 секунд

Задача: уложиться в 90 сек на сборку 6-ки, затем воспроизвести без пауз.

Набор А: ```хомяк · цапля · чайник · шкаф · щётка · юла```
Набор Б: ```ящерица · компас · маятник · невидимка · окно · поезд```

### 2.7. Цепочка с помехами (интерференция)

Соберите цепочку 10 слов → отвлекитесь 5 мин (посчитайте в уме 100−7, почитайте новости) → воспроизведите.

```
Слова: якорь · барабан · вишня · гитара · дракон · ежевика · жираф · зебра · игла · камень
```

Результат без помех: ___/10. С помехами: ___/10. Потеря: ___
Вывод: если потеря >2 — усиливайте контактность сцен (см. [курс §4](../core-techniques/classic-mnemonics.md)).

### 2.8. Ремонт разрыва — протокол

Найдите своё слабое звено из 2.2/2.5. Переиграйте только его, усилив по формуле:

```

```

### 2.9. Смешанный материал — от слов к делам и тезисам

```

Ваша цепочка (каждое дело — яркий образ-действие): ___/8 через час

**Б. Тезисы доклада 6 пунктов:**

```

```

Свяжите в историю: ___/6

**В. Иностранные слова 6 шт (через якорь):**

```
берите из [universal-vocabulary.md](universal-vocabulary.md) или любые 6 слов
```

Якорь+цепочка: ___/6

### 2.10. Соревнование с собой — прогрессия 10→12→15

## Модуль 3：Дворец памяти

*Теория: [курс §5–6](../core-techniques/classic-mnemonics.md). Дворец — «жёсткий диск» системы. Правила: последовательность, различимость, взаимодействие образа с локусом, два порожних обхода.*

### 3.1. Разметьте дворец квартиры

Выпишите 12 локусов в фиксированном порядке（пример: дверь→коврик→зеркало…):

```
 1. ＿＿＿＿＿＿  7. ＿＿＿＿＿＿
 2. ＿＿＿＿＿＿  8. ＿＿＿＿＿＿
 3. ＿＿＿＿＿＿  9. ＿＿＿＿＿＿
 4. ＿＿＿＿＿＿ 10. ＿＿＿＿＿＿
 5. ＿＿＿＿＿＿ 11. ＿＿＿＿＿＿

## Техника безопасности памяти

| Фактор | Норма | Почему | Что делать при сбое |

### Эталон 1.1（чайник)

❌ Слабо：「чайник стоит」
✅ Сильно：Чайник ЗАКИПЕЛ, свистит так, что стекла дрожат, пар бьёт в потолок и рисует сердечко. Крышка подпрыгивает, вы орёте «тише!» — эмоция.

### Эталон 1.1б (кошка спит)

❌ Кошка лежит.
✅ Кошка-трактор ХРАПИТ на подушке, вибрирует, с неё сыплются искры, вы хохочете, пахнет тёплой шерстью.

### Эталон 1.2（чемодан)

✅ Чемодан размером с девятиэтажку едет по шоссе сам, из него торчат носки-флаги, сигналит.
✅ Или：чемоданчик с напёрсток, муравьи сдают в нём багаж, один муравей-пилот кричит «осторожно!»

### Эталон 1.3（телефон + медведь — контакт!)

❌ Рядом лежат (0 баллов).
✅ Медведь ОТВЕЧАЕТ на звонок, трубка утопает в шерсти, медведь рычит в трубку: «Кто это?» — трубка трещит, вы слышите рык.

### Эталон 1.4 (торт — 5 чувств)

Вид: трёхъярусный, крем течёт, вишенка дрожит. Звук: шипение свечей. Запах: ваниль+шоколад. Вкус: сладко-кисло, крошки липнут. Осязание: холодный крем на пальцах, тяжесть. Эмоция: восторг/вина.

### Эталон 2.1 (шестёрка)

Мяч → дождь: мяч-Кинг-Конг пробивает тучу, из дыры льёт дождь из мячей.
Дождь → пират: пират ловит дождь ртом, захлёбывается, ром вымывает.
Пират → будильник: пират разбивает будильник саблей, будильник орёт.
Будильник → мёд: будильник тонет в мёде, стрелки липнут, жужжат пчёлы.
Мёд → велосипед: велосипед едет по мёду, колёса вязнут, вы буксуете.

Критерий: в каждой паре — касание/деформация/звук. Нет «и рядом стоял».

Локус 3 зеркало — в зеркале вы с телефоном, отражение звонит.
Правило: локус участвует — деформируется, пачкается, звучит.

Оцените себя：у слова есть ЯРКАЯ деталь？ Если просто слово без картинки —— дорисуйте (см. [cheatsheet.md](../core-techniques/cheatsheet.md)).

### Эталон 4.4 (даты)

1861 — «ШуБа (186) + ?» — шуба рвёт цепь крепостного, цепь звенит. Или ТоПы (18) + ШаРиК (61). Главное — сцена с действием.
1961 — «ПоЖар (196) + ?» — пожар на ракете Гагарина, ракета шипит.

### Эталон 5.2 (дело на пеге)

№1 гонец — гонец несёт ваше письмо и орёт «оплатить счёт!», печать шлёпается вам в лицо.
№5 пятно — на пятне растёт огромная «встреча», пятно чавкает.

### Эталон 6.2 (Глин — лысый)

ГЛИН — глина на лысой голове, блестит, бариста лепит из неё кружку, глина хлюпает. Примета: лысина блестит → усиливает.

### Эталон 7.1 (телефон)

Номер 912-34-56 → ПаРуС (91) + ТаЧка (34) + ПиЩа (56) — парус на тачке везёт пищу, всё грохочет по локусу «дверь».

### Эталон 8.2 (тезис → образ)

Тезис «причина — перегрузка информацией» → образ: мозг-губка, из неё льётся вода-информация, вы выжимаете. Локус: раковина.

### Эталон 9.1 (PAO)

♠A — Джон Уик (персона) → стреляет (действие) → из пистолета (объект). Каждая карта — так.
♥Q — Бабушка → печёт → пироги. Действие «печёт» — везде пахнет, шипит.

## Как собрать личную PAO-таблицу за вечер

        ♦ богатые персонажи · ♣ животные/спорт
Шаг 3. Типажи по рангам：A гигант · K правитель · Q леди · J плут
        10 группа людей · 9 спортсмен · 8 врач · 7 художник · 6 силач · 5 ребёнок · 4 старик · 3 близнецы · 2 двойник
