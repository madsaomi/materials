# Часть I. Основания

## 1. Дословно или по тезисам?

| Задача | Режим | Цена ошибки |
|--------|-------|-------------|
| Стих на вечере | дословно | рифма ломается |
| Тост на свадьбе | дословно开头, затем тезисы | запинка заметна |
| Доклад 15 минут | тезисы | можно импровизировать |
| Экзаменационный билет | тезисы + дозированная дословность терминов | термины must быть точны |
| Иностранный текст для экзамена | дословно | преподаватель ждёт форму |
| Лекарственная дозировка | дословно | жизнь зависит |

Выбор режима определяет технику. Путать их — главный источник провалов: учат дословно то, что нужно по тезисам (тратят недели), и наоборот.

## 2. Три памяти текста

**Моторная** — язык и голос помнят движение. Работает при многократном чтении вслух. Держит первые дни, сыплется без смысла.

**Смысловая** — помните идею. Держит каркас, но детали плывут: «около пяти процентов» → «примерно пять» — смысл тот же, слова другие.

**Словесная** — держит точные формулировки. Требует дворец или сшивку блоков.

Дословное запоминание = моторная×2 + смысловая + словесная, сшитые вместе.

## 3. Слоистый метод

Алгоритм, которым пользуются актёры и чемпионские мнемонисты:

```
Слой 1. КАРКАС: перескажите текст своими словами (скелет)
Слой 2. БЛОКИ: разбейте на смысловые куски по 2–4 предложения
Слой 3. ШВЫ: выучите переходы между блоками (именно они рвутся)
Слой 4. ПОЛИРОВКА: прогоны целиком с контролем дословности
Слой 5. ОТРЫВ: от текста к дворцу/якорям для страховки
```

Шов — самое важное: конец блока А + начало блока Б в одной сцене дворца.

Пример: текст о фотосинтезе. Слой 1 — «растения едят свет». Слой 2 — блоки: свет → хлорофилл → глюкоза. Слой 3 — шов «свет ХВАТАЕТ хлорофилл» — образ руки-хлорофилла.

# Часть II. Стихи и рифма

## 4. Метр и ритм как костыль

Стих помнится легче прозы, потому что метр хранит слова:

```
Ямб: ∪ — (слабо-сильно) «Я вас любил: любовь ещё, быть может…»
Хорей: — ∪ «Буря мглою небо кроет»
```

Ритм — это дворец во времени: ударные слоги — локусы звучания. Забыли слово — ритм подскажет количество слогов и ударение.

**Приём:** прохлопывайте ритм ладонью при первом чтении. Тело запоминает метр быстрее головы.

## 5. Стихотворение за час: пошаговый разбор

Берём 12 строк (3 строфы по 4).

**Минуты 0–10: каркас.**
Прочитайте дважды вслух, перескажите прозой по-русски каждая строфа о чём.

**Минуты 10–40: блочное сшивание.**
Разбейте на блоки по 2 строки:
- Блок 1: выучите 2 строки → закройте → воспроизвели
- Блок 2 так же → затем 1+2 вместе без подглядывания
- Блок 3 → 1+2+3 и т.д.
Ключ — сшивать после каждого добавления.

**Минуты 40–55: якори первых слов.**
Каждая строка начинается с опорного слова — положите его во дворец по порядку строк. Забыли строку — локус подскажет первое слово, ритм донесёт остальное.

**Минуты 55–60: два полных прогона.**
Два раза подряд целиком, медленно, с интонацией.

**Вечером:** один полный проход (3 минуты). **Завтра:** ещё один. **Через неделю:** контрольный.

## 6. Длинные поэмы

Поэма 100+ строк = дворец + ритм + якоря:

- **Дворец:** строфа = комната, внутри — строки-локусы.
- **Якори:** первое слово каждой строки в своём локусе.
- **Ритм:** держит строки внутри строфы.
- **Смысловой каркас:** сюжет поэмы как фильм.

Норма: 50 строк в неделю при таком режиме — стабильно, без выгорания.

# Часть III. Речи и презентации

## 7. Дословно или тезисно?

| Критерий | Дословно | Тезисы |
|----------|----------|--------|
| Время подготовки | в 3–5 раз больше | быстрее |
| Красота формулировок | контролируете каждое слово | импровизация |
| Риск провала | застряли → пауза | пропустили тезис → никто не заметил |
| Когда выбирать | тост, цитата, открытие | доклад, лекция, питч |

**Гибрид:** вступление и заключение — дословно (эффект рамки), середина — тезисы.

## 8. Презентация 12 слайдов во дворце

Разбор из каталога дворцов (§5.2) в деталях:

| Локус офиса | Слайд | Сцена |
|-------------|-------|-------|
| Проходная | Проблема | дверь с замком «клиенты не находят нас» |
| Коврик | Масштаб | под ногами карта с горящими городами |
| Зеркало | Решение | в отражении вы с новым продуктом |
| Вешалка | Архитектура | ссылки висят вместо одежды |
| Полка обуви | Конкуренты | кроссовки конкурентов топчутся на месте |
| Холодильник | Кейсы | внутри — довольные клиенты |
| Плита | Метрики | график пламени растёт |
| Стол | Команда | за столом ваша команда машет |
| Окно | План 6 месяцев | за окном строится будущее |
| Диван | Призыв | на диване лежит контракт |
| Полка книг | Вопросы | книги с «?» на корешках |

**Цифры в слайдах:** переводите Major-образами (§7 курса) и ставьте ПЕРСОНАЖЕЙ цифр в сцену слайда.

## 9. Тост, поздравление, стендап за 15 минут

Шаблон речи 2 минуты:

```
1. Приветствие (дословно)
2. Повод (тезис)
3. История-пример (дословно яркая фраза)
4. Пожелание (тезис)
5. Закрытие (дословно)
```

Разложите 5 пунктов по 5 локусам одной комнаты. Дословные куски сшейте блоками.

# Часть IV. Чужие тексты

## 10. Проза: абзацы и главы

Проза без рифмы труднее стихов. Держит каркас смысла:

**Шаг 1.** Выделите абзацы темы. Каждый абзац — локус.

**Шаг 2.** В каждом локусе — 3-5 ключевых слов-скелета (существительные+глаголы).

**Шаг 3.** Перескажите по скелету своими словами, затем сверьте дословность ключевых терминов.

**Пример абзаца учебника:**
> «Фотосинтез — процесс, в котором растения преобразуют свет в глюкозу с помощью хлорофилла.» 
Скелет: процесс → растения → свет → глюкоза → хлорофилл → свет₁→₂. Сцена: лист-фабрика с зелёным хлорофиллом вдавливает свет в глюкозу.

## 11. Иностранные тексты дословно

Трудность — незнакомая фонетика. Решение — двойной слой: смысл + звучание.

```
Шаг 1: локус хранит смысл (картина ситуации)
Шаг 2: в том же локусе висит транскрипция-карточка со звучанием
Шаг 3: карточка как Peg-ярлык: русское похожее слово → образ
```

Пример: фраза “Good morning, ladies and gentlemen.” → в локусе «сцена с кафедрой» стоит джентльмен с табличкой GUD MORNING, гудит как гудок, а дамы-леди машут платочками.

## 12. Диалоги и сценарии

Диалог — это два дворца или один, но с двумя голосами:

```
Локус 1: реплика героя А — голос низкий
Локус 1 (второй слой): ответ Б — голос высокий
```

Тренировка: проговаривайте диалог вслух ролями, меняя тембр. Тело-память фиксирует очередь.

Пример из учебника японского (диалоги уже есть), здесь принцип универсален: пьеса Шекспира, стенограмма собрания, интервью — всё ложится на маршрут.

# Часть V. Экзамены

## 13. Билеты: один билет = один дворец

Идеальная карта: билет №17 → локус №17 дворца «Университет» (аудитория 117). Внутри аудитории — три сцены-тезиса билета + один Major-образ для числовой даты/формулы.

Подготовка за неделю: 40 билетов → 4 комнаты по 10 локусов. Каждый день грузите по 10 билетов, вечером обход.

На экзамене вытянули билет №17 → мысленно вошли в аудиторию 117 → тезисы читаются со стен, доски, парт.

## 14. Даты, термины, списки внутри билетов

Внутри одного билета несколько типов данных — кодируйте по-разному в одном локусе:

```
Дата 1861 → Major-образ «ЧаШка» на парте
Термин «реформа» → ключевое слово-образ «РЕ ФОРМовка глины»
Список 3 причин → три мини-предмета на столе, стуле, подоконнике
```

Каждый тип — своим стилем сцены, не смешивайте: даты — люди, термины — предметы, списки — ряды объектов.

## 15. Формулы и определения как сцены

Формуле дайте сюжет из символов-актёров:

```
E = mc²
→ Энергия — это Мышка (m), разогнавшаяся до скорости Света дважды (квадрат):
мышка носится со световой скоростью и светится — энергия.
Операторы: = — весы, + — соединение рук, √ — корень-дерево, ∑ — змея-сигма.
```

Определению — персонаж-термин держит табличку:

```
Фотосинтез — ЛИСТ-фабрика с зелёным хлорофиллом вдавливает свет в глюкозу.
```

## 16. Конспект-дворец лекции в реальном времени

Слушаете лекцию → тут же раскладываете:

```
Доска — ввод
Окно — первый тезис
Стол — второй тезис с датой-образом
Дверь — вывод
```

Не стремитесь записать дословно услышанное — фиксируйте образ. После лекции один обход аудитории восстановит 80% материала, тогда и запишите конспект словами.

**Правило 3×3 лекции:** не более трёх тезисов на три минуты речи — иначе локусы перегружаются.

# Часть VI. Режим

## 17. План 21 день: от стиха к часовой лекции

**Неделя 1 — стихи:**

| День | Задача |
|------|--------|
| 1–2 | 8 строк (блочное сшивание) |
| 3–4 | 16 строк (дворец строф) |
| 5–6 | 24 строки (ритм + якоря) |
| 7 | Контроль: одно стихотворение целиком |

**Неделя 2 — речи:**

| День | Задача |
|------|--------|
| 8–9 | Тост дословно (10 строк) |
| 10–11 | Речь 5 минут тезисами во дворце |
| 12–13 | Презентация 8 слайдов |
| 14 | Полный прогон речи без бумаги |

**Неделя 3 — учебный текст:**

| День | Задача |
|------|--------|
| 15–16 | Иностранный абзац дословно (двойной слой) |
| 17–18 | Параграф учебника тезисами (3 локуса) |
| 19–20 | 10 билетов по 3 тезиса |
| 21 | Контроль: лекция 20 минут по локусам |

## 18. Ошибки и техника безопасности

| Ошибка | Симптом | Лечение |
|--------|---------|---------|
| Учу только начало | конец сыплется | сшивание: после каждого блока прогон всего с начала |
| Красиво звучит, смысл плывёт | путаете тезисы | каркас см. §3 перед дословностью |
| Локусы путаются | смешали темы в одном дворце | одна тема = один дворец, реестр |
| Слова без ритма | застреваете на середине строки | отбейте метр хлопками |
| Перегруз первые дни | головная боль от локусов | 30% нормы неделю, сон 8ч |
| Зависимость от текста | без бумаги ступор | чередуйте режим: бумага → локусы → только память |

**Техника безопасности памяти — биология:**

| Фактор | Норма | Зачем |
|--------|-------|-------|
| Сон | 7–9 ч | консолидация слоёв |
| Паузы | 5 мин каждые 25 мин | внимание не угасает |
| Вода и движение | прогулка после сессии | гиппокамп активируется |

**Красный флаг:** если после занятий снится содержимое локусов — снизьте темп, мозг перегружен.

## 19. Измерение и соревнование с собой

Еженедельные замеры фиксируйте в журнале:

| Метрика | Старт | Неделя 2 | Неделя 3 | Цель |
|---------|-------|----------|----------|------|
| Строк стиха дословно | 4 | 12 | 24 | 40+ |
| Тезисов доклада | 3 | 6 | 10 | 12+ |
| Иностранный абзац дословно | 0 | 3 предл. | 6 предл. | абзац |
| Билетов по 3 тезиса | 0 | 5 | 15 | 40 |

Рост цифр — топливо мотивации. Соревнуйтесь только с прошлой неделей.

### Игра «Цепная эстафета текста»

Втроём: первый читает строку → второй продолжает без паузы → третий. Пауза >2 секунд — выбыл. Развивает шовную скорость.

## 20. Пять строк раздела

2. Стихи держатся ритмом, речи — дворцом, чужой язык — двойным слоем смысла и звучания

# Часть VII. Библиотека примеров дословных текстов

Каждый пример — полностью разобранный кейс: текст → разметка → сценарии → контроль.

## Пример 1: Пушкин, 12 строк («Я помню чудное мгновенье» — первые 3 строфы)

**Текст:**

> Я помню чудное мгновенье:
> Передо мной явилась ты,
> Как мимолетное виденье,
> Как гений чистой красоты.

**Разметка:**

| Строка | Первое слово-якорь | Локус прихожей |
|--------|---------------------|----------------|
| 1 | Я | входная дверь — вы сами в зеркале |
| 2 | Передо | коврик — «передо мной» расстелен ковёр |
| 3 | Как | зеркало — виденье отражается |
| 4 | Как | вешалка — второй «как» вешает гения |

**Сшивка:** блок 1–2 → закройте → воспроизвели → добавьте 3–4 → прогнали 1–4 целиком. Ритм ямба держит метр: хлопайте «та-ТАМ та-ТАМ».

**Контроль:** через час — 3 полных прогона без запинки.

## Пример 2: Речь Джобса (Stanford, отрывок 150 слов) — тезисная

**Текст-тезисы:** 1) Смерть — лучший советчик 2) Оставайтесь голодными 3) История точек.

**Дворец «Квартира»:** дверь — скелет с советом, коврик — голодный стол, зеркало — точки соединяются линией. Выступление — обход трёх локусов.

## Пример 3: Иностранный абзац (английский, дословно)

**Текст:** “Good morning, ladies and gentlemen. It is a great honor to be here today. We are gathered to celebrate innovation.”

**Двойной слой:**

| Локус аудитории | Смысл | Звуковая карточка |
|-----------------|-------|-------------------|
| Доска | приветствие леди и джентльменов | GUD MORNING — гудок утро |
| Окно | честь быть здесь | ГРЭЙТ ОНОР — великий Оноре |
| Стол | собрались праздновать инновации | ГЭЗЕД ТУ СЕЛЕБРЕЙТ — газетки празднуют |

**Тренировка:** проговорите 5 раз по локусам, меняя интонацию. Запись на диктофон — сверка дословности артиклей.

## Пример 4: Билет «Реформа Столыпина» (3 тезиса + дата)

**Билет лежит в аудитории 204:**

| Тезис | Сцена в 204 |
|-------|-------------|
| 1906 указ | На доске цифра-царь 19-06 раздаёт указы |
| Хутора и отрубы | Парты стали хуторами, разбросанными по аудитории |
| Переселение в Сибирь | Из окна виден поезд на восток, полный крестьян |
| Итог: провал | Поезд буксует — реформу свернули |

Дата 1906 → Major: 19 РаМа (рама) + 06 НоЖницы → Рама, которой режут ножницами указ.

## Пример 5: Формула и определение (физика)

**Формула:** `Q = cm(t₂ − t₁)` — теплота = удельная теплоёмкость × масса × дельта температуры.

**Персонажи-символы:**

| Символ | Актёр |
|--------|-------|
| Q | Королева Тепла |
| c | Удельный человечек с весами |
| m | Мускул-масса |
| t | Термометр-близнецы |

**Сцена в локусе «Плита»:** Королева Q варит суп из Удельного человечка, бросает Мускул-массу в кастрюлю, термометры-близнецы показывают разницу — суп закипает.

## Ежедневный ритуал словесной памяти (15 минут)

**Утро (7 мин):** обход вчерашнего дворца (текст/билеты) — без записей, вслух.

## Практикум словесной памяти — 20 упражнений

Выполняйте письменно или вслух, потом сверяйтесь. Каждый следующий труднее.

**Уровень А: каркас**

1. Прочитайте абзац учебника (200 слов) → перескажите смысл своими словами ×3 предложения. Уложились?
2. Тот же абзац → выделите 5 ключевых слов-скелета.
3. По скелету восстановите абзац по памяти.

**Уровень B: блоки и швы**

4. Стихотворение 4 строки → разбейте на блоки 2+2 → сшейте.
5. Тот же стих → закройте текст, напишите первое слово каждой строки по памяти.
6. Тот же стих → восстановите шов: конец строки 2 + начало строки 3 одной фразой.

**Уровень C: дворец тезисов**

7. Доклад 5 тезисов → разложите по 5 локусам вашей комнаты → 2 обхода → воспроизведите вслух.
8. Тот же доклад → переставьте локусы местами (обход в обратном порядке).
9. Добавьте в каждый локус сцену с датой Major.

**Уровень D: иностранный слой**

10. Иностранный абзац 3 предложения → двойной слой (смысл + карточка звучания) → 3 прогона.
11. Тот же абзац → закройте русский смысл, воспроизведите только звучание по карточкам.
12. Тот же абзац → закройте звучание, воспроизведите смысл.

**Уровень E: проза и лекции**

13. Лекция 10 минут аудио → конспект-дворец из 4 локусов сразу по ходу → перескажите.
14. Тот же конспект → добавьте 3 термина-точки в каждый локус.

**Уровень F: речи**

15. Тост 5 предложений → дословно блок 1–2, тезисно блок 3–5 → прогон.
16. Презентация 6 слайдов → дворец офиса → прогон 3 раза с паузами между слайдами.

**Уровень G: билеты**

17. Один билет (3 тезиса + дата + термин) → один локус → сцена.
18. 5 билетов в один дворец → обход ×2 → воспроизведение вытаскиванием случайного номера.
19. 10 билетов → полный обход ×2 → контроль через сутки.

**Уровень H: полировка**

20. Выберите свой «самый трудный» текст недели → слоёный метод целиком (каркас→блоки→швы→полировка→дворец) → финальный прогон на диктофон.

Каждое упражнение фиксируйте в журнале: дата, текст, время, ошибки — где рвётся.

## Словесная память в профессиях

**Учитель:** 5 типов объяснений одного правила по разным локусам класса — переключение под вопрос ученика.

**Юрист:** статьи кодекса — номер статьи = Major-образ на локусе «полка кодекса», внутри — сцена статьи.

**Актёр:** роль — дворец театра: кулиса → сцена → зрительный зал → гримёрка. Текст пьесы = маршрут за кулисами.

**Врач:** протоколы — дворец отделения: смотровая → процедурная → палата → выписка. Каждый пункт протокола — сцена с пациентом-актёром.

**Продавец:** скрипт — сценарий кафе (см. дворец №14 каталога дворцов), возражения — контраргументы цепочкой.

## Частые вопросы раздела

**Дословно vs близко к тексту — как проверять?**
Запись на диктофон + сверка с оригиналом слово в слово. «Около» не засчитывается — только точность.

**Что если я аудиал, а не визуал?**
Локусы работают и на звуке: каждый локус — свой тембр голоса. Плюс ритмическое прохлопывание и напевание.

**Можно ли учить в транспорте?**
Тезисы — да (обход в голове). Дословные стихи — лучше вслух; шёпот тоже работает.

**Сколько текста можно держать одновременно?**
В активной работе — 40 билетов + 3 стиха + 2 речи. Остальное — в архиве Anki.

## Возраст и словесная память

**Дети (8–12):** ритм и игра важнее дворца. Стихи заучивайте хлопками и прыжками по комнате-локусам. Проза — пересказом с картинками, не дословно.

**Подростки (13–18):** пик моторной памяти — иностранные тексты даются легко. Ставка на иностранный абзац и билеты.

**Взрослые (18–60):** баланс смысла и дворца. Лучший прогресс — тезисные речи + стихи для разминки.

**Пожилые (60+):** дворец держит дольше моторной памяти. Делайте упор на тезисные локусы и ежедневные обходы — они же профилактика деменции (данные исследований: дворцы тренируют гиппокамп).

## История словесной памяти: от аедов до TED

**Античность:** аеды пели «Илиаду» часами без письма — ритм + локусы храма.

**Рим:** Цицерон держал речи по колоннам форума; Квинтилиан учил ораторов строить «архитектуру памяти».

**Средневековье:** монахи заучивали псалмы по кельям монастыря — каждая келья = стих.

**Возрождение:** Джордано Бруно строил театры памяти как машины идей — инквизиция сожгла его, но не технику.

**XX век:** Лурия изучал Шерешевского, помнившего всё и страдавшего от отсутствия забывания — урок: память должна забывать лишнее.

**Наши дни:** TED-спикеры репетируют тезисные дворцы; актёры МХТ учат роли блочным сшиванием.

> Урок истории: техники живут 3000 лет, потому что опираются на архитектуру мозга, а не моду.

## Дословность и импровизация — партнёры

Парадокс: чем лучше выучили дословно, тем свободнее импровизируете.

- Дословный запас даёт точные формулировки в нужный момент
- Тезисный каркас даёт свободу уйти в сторону и вернуться по локусам
- Переключение режимов — навык: репетируйте оба на одном материале

Упражнение на переключение: возьмите речь → прогоните раз дословно, раз тезисно. Заметьте, где дословность мешает интонации — там нужен тезисный режим.

## Расширенный FAQ словесной памяти

**Текст помню, но порядок строк плывёт.**
Не хватает швов (глава 3). Пропишите именно переходы: конец строки 2 + начало 3 как одна сцена.

**Иностранный текст звучит, смысл ускользает.**
Нет смыслового слоя. Сначала каркас — о чём абзац, потом карточки звучания.

**На сцене голос дрожит, забываю даже выученное.**
Адреалин блокирует извлечение. Решение — репетиция в условиях стресса: прогон стоя, с диктофоном, перед другом, с таймером.

**Сколько текста можно держать одновременно в активной работе?**
Около 40 билетов + 3 стиха + 2 речи. Остальное — в архиве Anki/дворцов.

**Можно ли учить в транспорте?**
Тезисы — да (обход в голове). Дословные стихи — лучше вслух; шёпот тоже работает.

**Что если язык текста совсем чужой (арабский, китайский)?**
Тот же двойной слой, но карточка звучания делится на слоги: каждый слог — отдельный крючок (см. библиотеку якорей главы 3 мнемоник).
