# Корейский алфавит через образы: хангыль（한글）

> **Метод:** каждый знак = картинка. Читаете образ → представляете ярко → пишете от руки → знак закрепляется за 2–3 повторения вместо 20 механических.
>
> **Правило:** чужой образ работает на 30–50% слабее своего. Если какая-то картинка «не ваша» — замените её немедленно своей. Файл даёт стартовые заготовки.
>
> **Ключевой принцип хангыля:** форма буквы отражает положение органов речи при произнесении звука! Царь Седжон Великий (세종대왕) создал алфавит в 1443 году, специально спроектировав форму каждого знака по анатомии рта. Мы используем это как основной мнемонический принцип.
>
> **Приложение языковой мнемоники.** Автономный файл — не требует внешних разделов. Не входит в ядро учебника (модули 1–10).
>
> Связанные материалы: [Как работает память](how-memory-works.md) · [Карта раздела](index.md) · [Учебник](textbook.md)

---

## Как заниматься по этому файлу

```
1. Один блок (согласные или гласные) за подход
2. Прочитайте все 5–7 образов, представьте каждый 5 секунд
3. Закройте таблицу → напишите знаки по памяти
4. Сверьте. Ошибочные — перерисуйте образ ярче и ещё раз ×5 прописей
5. Через день — блок повторения; через неделю — контрольный
```

Норма скорости: один ряд в день = весь алфавит за 2–3 недели без спешки.

---

## Как работает хангыль

Корейский алфавит — фонетический. Каждый слог записывается **блоком** из 2–4 букв:

```
[согласная] + [гласная] ± [согласная-батчим] ± [согласная-батчим]
```

Пример: 한 = ㅎ(h) + ㅏ(a) + ㄴ(n) = **han**

Буквы в блоке:
- **Сверху-слева или сверху:** согласная начальная (초성, chosŏng)
- **Справа или снизу-справа:** гласная (중성, chungssŏng)
- **Снизу (опционально):** согласная финальная / батчим (종성, chongsŏng)

Согласные — **угловатые**, гласные — **с чёрточками-סטרьками** (хотя исключения есть).

# Часть I. Базовые согласные (기본 자음)

14 согласных — основа хангыля. Каждая спроектирована по форме рта/языка.

## Ряд ㄱ — Каринальные (гортанные)

| Буква | Чтение | Образ | Якорь-слово |
|-------|--------|-------|-------------|
| ㄱ | **g/k** | Язык прижат к заднему нёбу и «кашляет» вперёд — вид сверху на рот: язык упёрся в горлышко. Напоминает ** candida ** или букву «Г» с загнутым кончиком | **Г**орлышко |
| ㄴ | **n** | Кончик языка касается **н**ёба за зубами — вид сбоку на рот: язык изогнулся дугой к нёбу. Форма = **Н** (перевёрнутая) | **Н**ёбо |
| ㄷ | **d/t** | Язык ударяется по зубам — вид сбоку: язык упёрся в зубы, сверху «крышка» — как буква **Д** с полочкой | **Д**есна |
| ㄹ | **r/l** | Язык делает **л**изнувший жест: кончик касается альвеол, язык волнистый. Форма = волна / зигзаг | **Р**ыбий язык |
| ㅁ | **m** | Губы **м** -нуто сомкнуты — вид спереди: квадрат = замкнутые губы | **М**орда (губы) |
| ㅂ | **b/p** | Губы разомкнулись для **б**уквы — вид спереди: квадрат с «крышкой» сверху = губы, которые плюются | **Б**арабан (губы) |
| ㅅ | **s/sh** | Зубы сжаты, **с**вистит воздух — вид спереди: два зуба торчат. Напоминает ёлочку / перевёрнутую «Y» | **С**вист |
| ㅇ | **ø/ng** | Рот **о**ткрыт кругом — вид спереди: круг = пустой рот (в начале слога не читается, в конце = «н») | **О**ткрытый рот |
| ㅈ | **j** | Язык упёрся в нёбо, но воздух **ж**мёт через нос — вид сверху: как ㅅ, но с «крышкой» сверху | **Ж**мёт |
| ㅊ | **ch** | Как ㅈ, но с **ч**ерточкой сверху = «чих!» — вид сверху: tongue up + взрыв воздуха | **Ч**их! |
| ㅋ | **k** | Как ㄱ, но с **ч**ерточкой = более сильный взрыв — язык упёрся в нёбо и «хлестнул»: аспирированный г | **К**артечь |
| ㅌ | **t** | Как ㄷ, но с чёрточкой = **т**вёрдый «т» — язык упёрся в зубы и «треснул»: аспирированный д | **Т**опор |
| ㅍ | **p** | Как ㅂ, но с чёрточкой = **п**люётся сильнее — губы разомкнулись и «пшикнули» | **П**шик |
| ㅎ | **h** | Рот **х**лопнул — вид спереди: маленький штрих сверху = горлышко, из которого «х» вырвалось | **Х**лопок |

### Детальные мнемоники для each буквы ряда ㄱ

| Буква | Детальный образ | История |
|-------|----------------|---------|
| ㄱ | Представьте язык, который **упёрся в заднюю стенку горла**. Форма ㄱ — это контур языка сбоку: горизонталь = тело языка, загиб вниз = кончик, упёршийся в гортань. При произнесении «г» язык отскакивает от нёба — «嘎!» | Король Седжон: «Форма ㄱ — изображение языка, упирающегося в нёбо» (side view of tongue touching soft palate) |
| ㄴ | Кончик языка **касается альвеол** (бугорков за верхними зубами). Форма ㄴ = язык (горизонталь) + нёбо (вертикаль). Посмотрите на букву сбоку: горизонтальная часть — тело языка, вертикальная — нёбо. | Н — «нос», нёбо; ㄴ = «нёбо-н» |
| ㄷ | Язык **ударяется в зубы**. Форма ㄷ = язык (горизонталь) + зубы (вертикаль) + «крышка» сверху = верхняя губа. При «д» язык «трескает» зубы: «ダ!» | ㄷ = ㄴ + крышка; «крышка» = верхняя губа, которая помогает «треснуть» |
| ㄹ | Язык **лижет альвеолы** — волнистый жест. Форма ㄹ = извилистый язык: горизонталь-волна-горизонталь. Р/л —depends от позиции. | ㄹ = «рыбий язык» — язык «рычит» в начале, «лижет» в конце |
| ㅁ | Губы **сомкнуты** квадратом. Форма ㅁ = квадрат = замкнутый рот. При «м» губы сжимаются и вибрируют: «М-м-м». | ㅁ = «морда» — квадратная морда с замкнутым ртом |
| ㅂ | Губы **разомкнулись** — квадрат с «крышкой» сверху. Форма ㅂ = ㅁ + горизонталь сверху = губы, которые «плюются». При «б» губы разжимаются и «бухают». | ㅂ = «барабан» — губы бьют как барабан |
| ㅅ | Зубы **сжаты**, воздух свистит. Форма ㅅ = два зуба торчат (как ёлочка / перевёрнутая Y). При «с» воздух вырывается через узкую щель: «С-с-с». | ㅅ = «свист» — зубы свистят |
| ㅇ | Рот **открыт кругом**. Форма ㅇ = круг = пустой рот. В начале слога = «ноль» (не читается). В конце = «нг» (носовой звук). | ㅇ = «обруч» — круглый обруч = открытый рот |
| ㅈ | Язык упёрся в нёбо, воздух «жмёт». Форма ㅈ = ㅅ + палочка сверху = усиленный свист. При «дж» язык «жмёт» нёбо: «ДЖ!» | ㅈ = «жук» — жук жмётся |
| ㅊ | Как ㅈ, но с «чёрточкой» = «чих!». Форма ㅊ = ㅈ + взрыв сверху = чих. При «ч» воздух вырывается резко: «Ч!» | ㅊ = «чайник» — чайник свистит/чихает |
| ㅋ | Как ㄱ, но с «чёрточкой» = аспирированный. Форма ㅋ = ㄱ + горизонталь = усиленный взрыв. При «к» воздух вырывается сильнее, чем при «г». | ㅋ = «копьё» — копьё «каркает» |
| ㅌ | Как ㄷ, но с «чёрточкой» = аспирированный. Форма ㅌ = ㄷ + горизонталь = «т» с выдохом. | ㅌ = «тарелка» — тарелка «треснула» |
| ㅍ | Как ㅂ, но с «чёрточкой» = аспирированный. Форма ㅍ = ㅂ + горизонталь = «п» с выдохом. | ㅍ = «палец» — палец «пшикает» |
| ㅎ | Рот «хлопнул». Форма ㅎ = маленький штрих (горлышко) + горизонталь (рот) + вертикаль (нос). При «х» воздух вырывается из горла: «Х!» | ㅎ = «хаос» — хаотичный хлопок |

**Дрилл:**

```
가나다라마바사아자차카타파하
가나　다라　마바　사아　자차
카타　파하
```

**Дрилл-история:** Прочитайте这个词组, представляя образ каждой буквы:

```
강아지 [gangaji] = щенок: 가(горлышко-г) + ㅇ(пусто) + ㄴ(нёбо) + ㅏ(свет) + ㅈ(жмёт) + ㅣ(палочка)
나무 [namu] = дерево: ㄴ(нёбо) + ㅏ(свет) + ㅁ(морда) + ㅜ(земля)
```

## Ряд ㄴ-ㄷ-ㄹ — Язычные (альвеолярные)

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㄴ | **n** | Кончик языка касается **нёба** за зубами — вид сбоку: язык = горка, нёбо = потолок | **Н**ос (носовой звук) |
| ㄷ | **d/t** | Язык **д**ерётся к зубам — вид сбоку: язык = кирпич, упёрся в «стенку» зубов | **Д**убина |
| ㄹ | **r/l** | Язык **л**изнул альвеолы — вид сбоку: язык = волнистая дорожка зигзагом | **Р**ешил |

**Сравнение:** ㄴ — мягкий н, ㄷ — твёрдый д/т, ㄹ — р/л (зависит от позиции).

### Детальные мнемоники для ㄴ-ㄷ-ㄹ

| Буква | Детальный образ | Отличие от соседей |
|-------|----------------|-------------------|
| ㄴ | Представьте **рот сбоку**: горизонтальная линия = язык, вертикальная = нёбо. Кончик языка **поднимается** и касается бугорков за зубами. Звук «н» — носовой, воздух идёт через нос. | ㄴ = «нос» — носовой звук |
| ㄷ | Тот же вид сбоку, но сверху добавлена **«крышка»** (= верхняя губа). Язык **ударяется** в зубы, а губа помогает «треснуть». Звук «д» — взрывной, воздух вырывается резко. | ㄷ = ㄴ + «крышка» = «десна» (язык стучит в зубы) |
| ㄹ | Язык **волнисто движется**: горизонталь-волна-горизонталь. Кончик касается альвеол, язык «лижет» или «рычит». | ㄹ = «рыбий язык» — волнистый, как хвост рыбы |

**Практика:** Произнесите ㄴ-ㄷ-ㄹ рядом, замечая разницу:
```
나 [na] — носовой, мягко
다 [da] — взрывной, резко
라 [ra] — волнистый, текуче
```

# Часть II. Двойные согласные (쌍자음 / 쌍ㄱ)

4 двойные согласные — «твёрдые» версии базовых. Произносятся с напряжением горла (фортис).

| Буква | Чтение | Базовая | Образ | Якорь |
|-------|--------|---------|-------|-------|
| ㄲ | **kk** | ㄱ | **КК** = два горлышка = **КК**репко сжаты | **КК**оробка |
| ㄸ | **tt** | ㄷ | **ТТ** = два языка = **ТТ**вёрдо упёрся в зубы | **ТТ**яп |
| ㅃ | **pp** | ㅂ | **ПП** = две губы = **ПП**лотно сжаты | **ПП**ауза |
| ㅆ | **ss** | ㅅ | **СС** = два зуба = **СС**вистят сильнее | **СС**ылка |
| ㅉ | **jj** | ㅈ | **ДЖЖ** = два языка = **ДЖЖ**мёт крепче | **ЖЖ**арко |

**Как запомнить:** каждая двойная = буква × 2. Видите «близнецов» — значит, звук «твёрже / напряжённее».

### Детальные мнемоники для двойных согласных

| Буква | Детальный образ | История |
|-------|----------------|---------|
| ㄲ | Два горлышка **сжаты**. Форма ㄲ = ㄱ + ㄱ = два горлышка. При «кк» горло напрягается сильнее: «КК!» — как будто два горлышка одновременно стучят. | ㄲ = «крёплкий» — крепко сжатое горло |
| ㄸ | Два языка **ударяются** в зубы. Форма ㄸ = ㄷ + ㄷ = два языка. При «тт» язык «трескает» зубы дважды: «ТТ!» | ㄸ = «ттвёрдый» — твёрдо стучит |
| ㅃ | Две губы **бьют** одновременно. Форма ㅃ = ㅂ + ㅂ = две губы. При «пп» губы «плюются» дважды: «ПП!» | ㅃ = «пっべный» — плюёт дважды |
| ㅆ | Два зуба **свистят** сильнее. Форма ㅆ = ㅅ + ㅅ = два зуба. При «сс» воздух свистит мощнее: «СС!» | ㅆ = «ссильный» — сильный свист |
| ㅉ | Два языка **жмут** нёбо крепче. Форма ㅉ = ㅈ + ㅈ = два языка. При «джж» язык жмёт дважды: «ДЖЖ!» | ㅉ = «жжаркий» — жарко жмёт |

**Дрилл:**

```
까따빠싸짜
까다　따라　빠바　싸사　짜자
까따빠싸짜
```

**Дрилл-сравнение:** Сравните твёрдые и двойные:

```
가 [ga] —嘎! (мягко)        까 [kka] — КК! (крепко)
다 [da] — ダ! (мягко)        뚜 [tta] — ТТ! (крепко)
바 [ba] — バ! (мягко)        빠 [ppa] — ПП! (крепко)
사 [sa] — С! (мягко)         싸 [ssa] — СС! (крепко)
자 [ja] — ДЖ! (мягко)        짜 [jja] — ДЖЖ! (крепко)
```

**Запомните:** двойные = «сжатые горловые». Как будто вы говорите «кх-кх-кх» — горло напряжено.

# Часть III. Базовые гласные (기본 모음)

10 базовых гласных. Ключевая идея: **точка/палочка** = направление взгляда/света, **линия** = горизонт (небо) или вертикаль (земля/человек).

### Принцип
- **ㅏ ㅑ** — свет **справа** (солнце на востоке → «я»)
- **ㅓ ㅕ** — свет **слева** (противоположность → «о/ё»)
- **ㅗ ㅛ** — свет **сверху** (небо → «о»)
- **ㅜ ㅠ** — свет **снизу** (земля/вода → «у»)
- **ㅡ ㅣ** — горизонталь и вертикаль (земля и человек)

---

## Ряд ㅏ — Правосторонние

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㅏ | **a** | Человек стоит (вертикаль **ㅣ**), солнце **справа** (точка): «А!» — рот открыт, свет справа | **А**вгуст (солнце справа) |
| ㅑ | **ya** | Человек стоит, **две** точки справа: «Я!» — больше света = «я» | **Я**ркий (двойной свет) |

**Запомните:** ㅏ = ㅣ + точка справа = «а». ㅑ = ㅣ + 2 точки справа = «я» (больше света = «я»).

---

## Ряд ㅓ — Левосторонние

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㅓ | **ŏ/eo** | Человек стоит (ㅣ), точка **слева**: «О!» — рот открыт влево | **О**ткрытый |
| ㅕ | **yŏ/yeo** | Человек стоит, **две** точки слева: «Ё!» — двойной свет слева | **Ё**лка (свет слева) |

**Сравнение:**
- ㅏ (справа) = «а» — свет на востоке
- ㅓ (слева) = «о/ё» — свет на западе

---

## Ряд ㅗ — Верхние

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㅗ | **o** | Человек лежит горизонтально (ㅡ), солнце **сверху** (точка): «О!» — небо светит сверху | **О**кеан (небо сверху) |
| ㅛ | **yo** | Горизонталь, **две** точки сверху: «Ё!» — двойной свет сверху | **Ё**ж (ёжится под двойным солнцем) |

---

## Ряд ㅜ — Нижние

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㅜ | **u** | Человек лежит горизонтально (ㅡ), точка **снизу** (под землёй): «У!» | **У**литка (ползёт по земле) |
| ㅠ | **yu** | Горизонталь, **две** точки снизу: «Ю!» — двойная глубина | **Ю**ла (крутится внизу) |

**Запомните:** ㅗ (сверху) = «о», ㅜ (снизу) = «у». Зеркально!

---

## Ряд ㅡ-ㅣ — Базовые линии

| Буква | Чтение | Образ | Якорь |
|-------|--------|-------|-------|
| ㅡ | **ŭ/eu** | Горизонтальная линия = **земля** (перевёрнутый человек лежит). Губы растянуты в «улыбку»: «ы-ы» | **Ы**лби (земля) |
| ㅣ | **i** | Вертикальная линия = **человек** стоит (как палочка). Губы растянуты: «и-и» | **И**голка (палочка) |

**Дрилл базовых гласных:**

```
ㅏ야　ㅓ여　ㅗ요　ㅜ유　ㅡ이
아오　어우　오아　우어　이아
```

### Детальные мнемоники для ㅗ-ㅛ-ㅜ-ㅠ-ㅡ-ㅣ

| Буква | Детальный образ | История |
|-------|----------------|---------|
| ㅗ | Человек **лежит** (горизонталь ㅡ), солнце **сверху** (точка). Форма ㅗ = ㅡ + · сверху. При «о» рот открыт, губы округлены: «О!» — как будто смотрите на небо. | ㅗ = «океан» — небо над океаном |
| ㅛ | Горизонталь, **две** точки сверху. Форма ㅛ = ㅡ + ·· сверху. При «ё» рот открыт, «ёжится» под двойным солнцем: «Ё!» | ㅛ = «ёж» — ёжится под двойным светом |
| ㅜ | Человек лежит (ㅡ), точка **снизу** (под землёй). Форма ㅜ = ㅡ + · снизу. При «у» губы вытянуты вперёд: «У!» — как будто ползёте по земле. | ㅜ = «улитка» — ползёт по земле |
| ㅠ | Горизонталь, **две** точки снизу. Форма ㅠ = ㅡ + ·· снизу. При «ю» губы вытянуты, «юлится»: «Ю!» | ㅠ = «юла» — крутится внизу |
| ㅡ | Горизонтальная линия = **земля**. Форма ㅡ = прямая горизонталь. При «ы» губы растянуты в «улыбку», язык внизу: «Ы-ы» — как будто «ылбитесь». | ㅡ = «ылби» — земля (горизонтальная) |
| ㅣ | Вертикальная линия = **человек** стоит. Форма ㅣ = прямая вертикаль. При «и» губы растянуты, язык вверху: «И-и» — иголка стоит. | ㅣ = «иголка» — вертикальная палочка |

**Дрилл-сравнение:** Сравните верхние и нижние (зеркальные):

```
오 [o] — свет сверху, «о!»     우 [u] — свет снизу, «у!»
요 [yo] — два света сверху, «ё!» 유 [yu] — два света снизу, «ю!»
```

**Запомните:** ㅗ (сверху) = «о», ㅜ (снизу) = «у». Зеркально отражение!

# Часть IV. Сложные (составные) гласные (복합 모음)

Составные гласные = **два базовых знака вместе**. Запомните составляющие — и вы прочтёте любую.

---

## Двуточечные: ㅐ ㅔ

| Буква | Чтение | Состав | Образ | Якорь |
|-------|--------|-------|-------|-------|
| ㅐ | **ae/e** | ㅏ + ㅣ | Человек (ㅣ) стоит, солнце справа (ㅏ), и ещё один человек (ㅣ) рядом: **аээ** = «э» | **Э**хо (два человека) |
| ㅔ | **e** | ㅓ + ㅣ | Человек (ㅣ), свет слева (ㅓ), ещё человек (ㅣ): **е** = «э» (почти как ㅐ) | **Э**ль (два + свет) |

**⚠️ Разница:** в современном корейском ㅐ и ㅔ произносятся почти одинаково (оба = «э»). Различайте только по написанию!

---

## Свет + человек: ㅘ ㅙ

| Буква | Чтение | Состав | Образ | Якорь |
|-------|--------|-------|-------|-------|
| ㅘ | **wa** | ㅗ + ㅏ | Солнце сверху (ㅗ) + свет справа (ㅏ): **вааа** = «ва!» | **Ва**у! (двойной свет) |
| ㅙ | **wae** | ㅗ + ㅐ | Небо сверху (ㅗ) + эхо (ㅐ): **вэ** = «вэ» | **Вэ**! (небо + эхо) |

**Сравнение:** ㅘ = «ва» (о + а), ㅙ = «вэ» (о + э). Первое — шире, второе — уже.

---

## Человек + свет: ㅚ ㅟ

| Буква | Чтение | Состав | Образ | Якорь |
|-------|--------|-------|-------|-------|
| ㅚ | **oe** | ㅗ + ㅣ | Солнце сверху (ㅗ) + человек (ㅣ): **ой** = «ой/ö» | **Ой**! (человек под солнцем) |
| ㅟ | **wi** | ㅜ + ㅣ | Земля внизу (ㅜ) + человек (ㅣ): **ви** = «ви» | **Ви**лка (человек на земле) |

---

## Глубинные: ㅝ ㅞ

| Буква | Чтение | Состав | Образ | Якорь |
|-------|--------|-------|-------|-------|
| ㅝ | **wo** | ㅜ + ㅓ | Земля внизу (ㅜ) + свет слева (ㅓ): **во** = «во» | **Во**т! (земля + свет) |
| ㅞ | **we** | ㅜ + ㅔ | Земля внизу (ㅜ) + эхо (ㅔ): **вэ** = «вэ» | **Вэ**! (земля + эхо) |

**⚠️ Разница:** ㅞ и ㅙ звучат одинаково (оба = «вэ»). Различайте по написанию!

---

## Двойное «ы»: ㅢ

| Буква | Чтение | Состав | Образ | Якорь |
|-------|--------|-------|-------|-------|
| ㅢ | **ŭi** | ㅡ + ㅣ | Земля горизонтальная (ㅡ) + человек вертикаль (ㅣ): **ыи** = «ы» + «и» | **Ы** + **И** = ыи |

# Часть V. Батчим (받침 — финальные согласные)

Батчим = согласная **внизу** слогового блока. В конце слога согласные «упрощаются» — 7 звуков.

---

## Правило 7 батчим

| Буква | Звук в батчиме | Образ | Якорь |
|-------|----------------|-------|-------|
| ㄱ ㅋ ㄲ | **[k]** | Горлышко **закрылось**: [k] — тихий стоп | **К**рышка |
| ㄴ | **[n]** | Нёбо **прижалось**: [n] — носовой | **Н**из |
| ㄷ ㅌ ㅅ ㅆ ㅈ ㅊ ㅎ | **[t]** | Язык **упёрся**: [t] — твёрдый стоп | **Т**ормоз |
| ㄹ | **[l]** | Язык **лижет**: [l] — боковой | **Л**изгёт |
| ㅁ | **[m]** | Губы **замкнулись**: [m] — носовой | **М**орда |
| ㅂ ㅍ | **[p]** | Губы **плюнули**: [p] — стоп | **П**люх |
| ㅇ | **[ŋ]** | Рот **открылся**: [ŋ] — носовой «нг» | **Нг**ел |

**Правило упрощения:**
```
ㄱㅋㄲ → [k]    ㄴ → [n]      ㄷㅌㅅㅆㅈㅊㅎ → [t]
ㄹ → [l]        ㅁ → [m]       ㅂㅍ → [p]         ㅇ → [ŋ]
```

---

## Мнемоника «7 ворот»

Представьте **7 ворот** в стене (рот = стена):

```
Ворота 1 (горло): ㄱㅋㄲ = [k] — горлышко закрылось
Ворота 2 (нос):    ㄴ = [n] — ноздри приоткрылись
Ворота 3 (язык):   ㄷㅌㅅㅆㅈㅊㅎ = [t] — язык упёрся
Ворота 4 (бок):    ㄹ = [l] — язык лизнул бок
Ворота 5 (губы):   ㅁ = [m] — губы м-нуто
Ворота 6 (губы+):  ㅂㅍ = [p] — губы п-нуто
Ворота 7 (горло):  ㅇ = [ŋ] — горло звенит «нг»
```

---

## Дрилл батчим

```
한 [han]    집 [jip]    밥 [bap]    님 [nim]    약 [yak]
밥 [bap]    문 [mun]    방 [baŋ]    달 [tal]    숲 [sup]
```

<details>
<summary>Ответы</summary>

한 = корейский · 집 = дом · 밥 = рис/еда · 님 = вы (уважит.) · 약 = лекарство
밥 = рис · 문 = дверь · 방 = комната · 달 = луна · 숲 = лес

</details>

---

## Батчим в сочетаниях (겹받침)

Когда **две** согласные внизу — произносится одна (последняя или определённая):

| Сочетание | Произносится | Образ | Пример |
|-----------|-------------|-------|--------|
| ㄺ | [l] | Лизнул горло | 닭 [тал] = курица |
| ㄻ | [m] | Лизнул морду | 삶 [삼] = жизнь |
| ㄿ | [p] | Лизнул плюх | 삶 [삽] = жизнь |
| ㅄ | [p] | Б + С = плюх | 값 [갑] = цена |
| ㄹ | [l] | Лизнул ёлку | 읽다 [익타] = читать |
| ㄶ | [n] | Н + Х = низ | 많다 [ман타] = много |
| ㄵ | [n] | Н + Ж = низ | 앉다 [안타] = сесть |

**Запомните:** в сочетаниях батчим часто «побеждает» тот звук, который ближе к концу. Но есть исключения — учите по словам.

### Детальные мнемоники для батчим-сочетаний

| Сочетание | Звук | Детальный образ | Пример |
|-----------|------|----------------|--------|
| ㄺ | [l] | Лизнул горло = язык «лижет» горлышко | 닭 [тал] = курица (ㄹigsaw «лизнул» горлышко) |
| ㄻ | [m] | Лизнул морду = язык «лижет» губы | 삶 [삼] = жизнь (ㄹigsaw «лизнул» губы) |
| ㄿ | [p] | Лизнул плюх = язык «лижет» губы-плюх | 삶 [삽] = жизнь (ㅂ «плюхнуло») |
| ㅄ | [p] | Б + С = плюх = губы «плюхнули» | 값 [갑] = цена (ㅂ «плюх» победил) |
| ㄹ | [l] | Лизнул ёлку = язык «лижет» зубы | 읽다 [익타] = читать (ㄹigsaw «лизнул») |
| ㄶ | [n] | Н + Х = низ = нёбо «прижалось» | 많다 [ман타] = много (ㄴ «низ» победил) |
| ㄵ | [n] | Н + Ж = низ = нёбо «прижалось» | 앉다 [안타] = сесть (ㄴ «низ» победил) |

**Правило «победителя»:** В сочетаниях батчим часто побеждает **последняя** согласная. Но ㄺ, ㄻ, ㄿ — исключения (побеждает первая).

**Дрилл-сравнение:** Сравните односложные слова с батчим:

```
밥 [bap] = рис (ㅂ «плюх»)
밤 [bam] = орех/ночь (ㅁ «морда»)
발 [bal] = нога (ㄹigsaw «лизнул»)
밤 [bap] vs 밤 [bam] — разница в батчим!
```

**Мнемоника для исключений:**
```
ㄺ: Лизнул горло = [l] — «Лиз Гнул» = 닭 [тал]
ㄻ: Лизнул морду = [m] — «Лиз Морду» = 삶 [삼]
ㄿ: Лизнул плюх = [p] — «Лиз Плюх» = 삶 [삽]
```

# Часть VI. Формирование слоговых блоков (음절)

---

## Правило 1: Согласная + Гласная

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅏ  │  ← гласная справа
└─────┘
= 가 [ga]
```

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅗ  │  ← гласная снизу
└─────┘
= 고 [go]
```

**Правило:** если гласная с **боку** (ㅏ ㅑ ㅓ ㅕ ㅐ ㅔ ㅘ ㅙ ㅚ ㅟ) — она справа. Если **снизу** (ㅗ ㅛ ㅜ ㅠ ㅡ ㅢ) — она внизу.

---

## Правило 2: Согласная + Гласная + Батчим

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅏ  │  ← гласная справа
│ ㄴ  │  ← батчим снизу
└─────┘
= 간 [gan]
```

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅗ  │  ← гласная снизу
│ ㄴ  │  ← батчим ещё ниже
└─────┘
= 공 [goŋ]
```

---

## Правило 3: Дважды батчим (겹받침)

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅏ  │  ← гласная справа
│ ㄹ  │  ← батчим 1
│ ㅅ  │  ← батчим 2
└─────┘
= 갑 [kap]  (ㄹigsaw падает → читается ㅂ)
```

---

## Правило 4: Двойная начальная (ㄲ ㄸ ㅃ ㅆ ㅉ)

```
┌─────┐
│ ㄲ  │  ← двойная начальная
│ ㅏ  │  ← гласная
└─────┘
= 까 [kka]
```

---

## Визуальная шпаргалка: куда писать гласную

```
Если гласная:    Пишите:
  ㅏ ㅑ           справа
  ㅓ ㅕ           справа
  ㅐ ㅔ           справа
  ㅘ ㅙ           справа
  ㅚ             справа
  ㅟ             справа
  ㅗ ㅛ           снизу
  ㅜ ㅠ           снизу
  ㅡ             снизу
  ㅢ             снизу
```

**Правило:** гласная с **вертикальной** палочкой (ㅣ) → справа. С **горизонтальной** (ㅡ) → снизу.

### Детальные правила формирования блоков

**Правило 1: Куда писать гласную**

```
Гласная с вертикальной палочкой (ㅣ) → ПРАВО:
  ㅏ ㅑ ㅓ ㅕ ㅐ ㅔ ㅘ ㅙ ㅚ ㅟ → справа от согласной

Гласная с горизонтальной палочкой (ㅡ) → ВНИЗ:
  ㅗ ㅛ ㅜ ㅠ ㅡ ㅢ → внизу от согласной
```

**Правило 2: Пропорции блока**

```
┌─────┐
│ ㄱ  │  ← согласная занимает верх-лево
│ ㅏ  │  ← гласная справа (узкая)
└─────┘

┌─────┐
│ ㄱ  │  ← согласная занимает верх
│ ㅗ  │  ← гласная снизу (широкая)
└─────┘
```

**Правило 3: Батчим всегда снизу**

```
┌─────┐
│ ㄱ  │  ← начальная согласная
│ ㅏ  │  ← гласная справа
│ ㄴ  │  ← батчим снизу (под согласной и гласной)
└─────┘
```

**Правило 4: Двойная согласная = одно место**

```
┌─────┐
│ ㄲ  │  ← двойная = одна «ячейка»
│ ㅏ  │  ← гласная справа
└─────┘
```

**Правило 5: Составная гласная = одно место**

```
┌─────┐
│ ㄱ  │  ← согласная
│ ㅘ  │  ← составная = одна «ячейка» (ㅗ + ㅏ)
└─────┘
```

**Дрилл блоков:**

```
나무 [namu] = дерево      바다 [bada] = море
하늘 [haneul] = небо       사람 [saram] = человек
한글 [hangeul] = хангыль   한국 [hanguk] = Корея
```

# Часть VII. Дриллы на чтение

---

## Дрилл 1: Простые слоги (CV)

# Часть VIII. «Ловушки» и сложные буквы (헷갈리는 글자)

---

## Буквы, которые путают новички

### 1. ㅂ vs ㅍ (б vs п)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㅂ | **b/p** | Губы «бухают» — мягче | ㅂ = «барабан» (мягкий) |
| ㅍ | **p** | Губы «пшикают» — твёрже, с выдохом | ㅍ = «палец» (твёрдый, с выдохом) |

**Мнемоника:** ㅂ без «крышки» = мягкий, ㅍ с «крышкой» = твёрдый. «Крышка» = выдох.

### 2. ㄷ vs ㅌ (д vs т)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㄷ | **d/t** | Язык «трескает» зубы — мягче | ㄷ = «десна» (мягкий) |
| ㅌ | **t** | Язык «трескает» с выдохом — твёрже | ㅌ = «тарелка» (твёрдый, с выдохом) |

**Мнемоника:** ㄷ без «крышки» = мягкий, ㅌ с «крышкой» = твёрдый.

### 3. ㄱ vs ㅋ (г vs к)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㄱ | **g/k** | Язык «горлышком» — мягче | ㄱ = «горлышко» (мягкий) |
| ㅋ | **k** | Язык «каркает» — твёрже, с выдохом | ㅋ = «копьё» (твёрдый, с выдохом) |

### 4. ㅅ vs ㅆ (с vsсс)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㅅ | **s** | Зубы свистят — мягче | ㅅ = «свист» (мягкий) |
| ㅆ | **ss** | Зубы свистят крепче — твёрже | ㅆ = «ссильный» (твёрдый, двойной) |

### 5. ㅈ vs ㅊ (дж vs ч)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㅈ | **j** | Язык «жмёт» — мягче | ㅈ = «жук» (мягкий) |
| ㅊ | **ch** | Язык «чихает» — твёрже, с выдохом | ㅊ = «чайник» (твёрдый, с выдохом) |

### 6. ㄴ vs ㄹ (н vs р/л)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㄴ | **n** | Кончик языка касается нёба — «нос» | ㄴ = «нос» (носовой, статичный) |
| ㄹ | **r/l** | Язык «лижет» альвеолы — волнистый | ㄹ = «рыбий язык» (динамический, волнистый) |

**Мнемоника:** ㄴ = «нос» (одно касание), ㄹ = «рыбий язык» (много касаний, волна).

### 7. ㅐ vs ㅔ (э vs э)

| Буква | Чтение | Состав | Как отличить |
|-------|--------|-------|-------------|
| ㅐ | **ae/e** | ㅏ + ㅣ | Свет справа (а) + человек (ㅣ) |
| ㅔ | **e** | ㅓ + ㅣ | Свет слева (о) + человек (ㅣ) |

**Мнемоника:** ㅐ = «а-э» (свет справа), ㅔ = «о-э» (свет слева). В современном корейском звучат одинаково — различайте только по написанию!

### 8. ㅗ vs ㅜ (о vs у)

| Буква | Чтение | Образ | Как отличить |
|-------|--------|-------|-------------|
| ㅗ | **o** | Солнце **сверху** | ㅗ = «океан» (небо сверху) |
| ㅜ | **u** | Солнце **снизу** | ㅜ = «улитка» (земля снизу) |

**Мнемоника:** ㅗ (точка сверху) = «о», ㅜ (точка снизу) = «у». Зеркально!

# Часть IX. Советы по произношению

---

## Твёрдые vs Мягкие

Корейские гласные делятся на **твёрдые** и **мягкие**:

| Твёрдые | Мягкие |
|---------|--------|
| ㅏ [a] | ㅓ [ŏ] |
| ㅗ [o] | ㅜ [u] |
| ㅡ [ŭ] | ㅣ [i] |
| ㅐ [ae] | ㅔ [e] |

**Правило:** после твёрдых гласных ㄹ = [r] (одноударный), после мягких = [l] (лateral).

---

## Позиция ㄹ

```
Начало слога: ㄹ = [r] (как «р» в англском)
Конец слога:  ㄹ = [l] (как «л» в русском)
Середина:     ㄹ = [r] или [l] (зависит от контекста)
```

**Мнемоника:** ㄹ = **р**ыбий язык — в начале «р»ычит, в конце «л»ижет.

---

## Длинные гласные

В современном корейском **длинных гласных нет** (в отличие от японского). Но в позиции **다음 vowel省略** длинные гласные были исторически:

```
ㅏ = короткое «а»
ㅏㅏ = долгое «а» (редко, в старом языке)
```

**Современное правило:** произносите коротко, не растягивайте.

---

## Батчим-сочетания: quick reference

```
ㄺ [l]   ㄻ [m]   ㄿ [p]   ㅄ [p]   ㄹ [l]   ㄶ [n]   ㄵ [n]
```

**Запомните по аналогии:** «Лизнул горло» = ㄺ [l], «Лизнул морду» = ㄻ [m].

# Приложение. Историческая справка

## Создание хангыля

В 1443 году король **Седжон Великий** (세종대왕, 1397–1450) создал хангыль — один из самых научных алфавитов в мире. Он записал принципы в книге **«Хунмин Чŏнъим»** (훈민정음, «Звуки для наставления народа»).

### Принципы Седжона

1. **Форма буквы = форма рта.** Буквы спроектированы по анатомии артикуляции:
   - ㄱ = язык упёрся в горлышко
   - ㄴ = язык касается нёба
   - ㅁ = губы замкнуты
   - ㅅ = зубы сжаты
   - ㅇ = рот открыт кругом

2. **Гласные = философия.** Три элемента:
   - 점 (точка) = небо (天)
   - 선 (линия) = земля (地)
   - 사람 (человек) = человек (人)

3. **Простота.** 24 буквы = все звуки корейского языка. Намного проще, чем китайские иероглифы.

---

## Современный статус

- Хангыль используют **77 млн человек** в Южной и Северной Корее
- UNESCO признал его **самым научным алфавитом** в мире
- В Южной Корее есть **День хангыля** (한글날, 9 октября)

---

## Интересные факты о хангыле

1. **Единственный алфавит, созданный по приказу правителя.** Седжон Великий лично контролировал разработку, чтобы дать народу простую письменность вместо сложных китайских иероглифов.

2. **Первоначально алфавит назывался «Хунмин Чŏнъим»** (훈민정음) — «Правильные звуки для наставления народа». Слово «хангыль» (한글) появилось позже, в XIX веке.

3. **24 буквы = 14 согласных + 10 гласных.** Это один из самых компактных алфавитов в мире. Для сравнения: в японской катакане 46 знаков, в русской азбуке 33.

4. **Хангыль — фонетический алфавит.** В отличие от китайских иероглифов, где один знак = одно слово/понятие, хангыль записывает звуки. Это делает его очень удобным для обучения.

5. **Форма букв основана на анатомии.** Царь Седжон специально спроектировал форму каждой буквы по положению органов речи. Например, ㄱ = язык, упёршийся в горлышко, ㅁ = замкнутые губы.

6. **Гласные отражают философию.** Три элемента гласных — точка (небо), линия (земля) и палочка (человек) — отражают конфуцианскую идею гармонии неба, земли и человека.

7. **Хангыль был запрещён.** После падения династии Чосон (Joseon) в 1910 году японские колонизаторы запретили использовать хангыль, называя его «дикие письмена». Корейцы тайно учили детей хангылю.

8. **День хангыля (한글날)** отмечается 9 октября — в честь даты создания алфавита в 1443 году.

9. **Хангыль в Unicode.** Корейские символы занимают блок U+AC00–U+D7AF ( syllables) и U+1100–U+11FF (consonants), U+3130–U+318F (compatibility jamo).

10. **Корейская вводная раскладка.** На смартфонах используется раскладка ㄷ (дубль) — ㄱ-ㄴ-ㄷ-ㄹ-ㅁ-ㅂ-ㅅ-ㅇ-ㅈ-ㅊ-ㅋ-ㅌ-ㅍ-ㅎ по горизонтали, и ㅏ-ㅑ-ㅓ-ㅕ-ㅗ-ㅛ-ㅜ-ㅠ-ㅡ-ㅣ по вертикали.

# Часть XII. Глубокий разбор батчима (받침 — финальные согласные)

> Батчим — самая сложная тема для русскоговорящих. В конце слога 19 согласных «схлопываются» в **7 звуков**. Это как русское «в» в конце слова → [ф] (велосипед → велосипед**ф**), только в корейском это систематично.

---

## Зачем батчиму «упрощение»?

Корейский — **слоговая** языковая система. Каждый слог = одна «ударная» единица. В конце слога согласные не могут стоять «всякие» — они превращаются в один из 7 финальных звуков. Это аналогично тому, как в русском «в» в конце слова произносится как «ф» (велосипед → велосипед**ф**), только в корейском это жёстче и систематичнее.

---

## Мнемоника «7 царей батчима»

Представьте **7 царей**, каждый стоит у своих ворот:

```
🏰 Царь 1 — [k]:   Горлышко (ㄱㅋㄲ) — царь сидит на троне, горло закрыто засовом
🏰 Царь 2 — [n]:   Нёбо (ㄴ) — царь носит корону, воздух идёт через нос
🏰 Царь 3 — [t]:   Язык у зубов (ㄷㅌㅅㅆㅈㅊㅎ) — царь тормозит язык у зубов
🏰 Царь 4 — [l]:   Бок (ㄹ) — царь лизнул стену бочкой
🏰 Царь 5 — [m]:   Губы (ㅁ) — царь мордой давит, губы замкнуты
🏰 Царь 6 — [p]:   Губы-плюх (ㅂㅍ) — царь плюхнул губами и остановился
🏰 Царь 7 — [ŋ]:   Горло-нг (ㅇ) — царь звенит «нг», как колокол
```

```
Кот нёс тёплую маму плед на ночег
К-Н-Т-Л-М-П-НГ
Все цари спят — батчим закончен!
```

## Правила «превращения» букв в батчим

### Группа [k] — Горлышко

```
ㄱ → [k]    (в конце слога ㄱ читается как «к»)
ㄲ → [k]    (двойная ㄱ = тот же [k], только сильнее)
ㅋ → [k]    (аспирированная ㅋ = тоже [k] в батчиме)
```

**Примеры:**
```
밥 [bap] = рис         (ㅂ → [p], ㅂ → [p])
박 [pak] = вишня        (ㅂ → [p], ㄱ → [k])
값 [kap] = цена         (ㄱ → [k], ㅂ → [p])
```

**Мнемоника:** ㄱ + ㅋ + ㄲ = все **к** ломаются в [k]. Как будто горлышко **к**оролевского замка закрылось.

### Группа [n] — Нёбо

```
ㄴ → [n]    (единственная ㄴ = [n] всегда)
```

**Примеры:**
```
밤 [bam] = ночь        (ㅂ → [m], ㅁ → [m] — подождите! ㅁ → [m])
```

Подождите — тут ошибка! Давайте исправим:
```
손 [son] = рука          (ㅅ → [t], ㄴ → [n])
문 [mun] = дверь         (ㅁ → [m], ㄴ → [n])
```

**Мнемоника:** ㄴ = **н**ёбо, всегда **н**. Как русское «н» в «неси».

### Группа [t] — Язык у зубов

```
ㄷ → [t]    (в конце слога ㄷ → [t])
ㅌ → [t]    (ㅌ → [t])
ㅅ → [t]    (ㅅ → [t] — важное правило!)
ㅆ → [t]    (ㅆ → [t])
ㅈ → [t]    (ㅈ → [t])
ㅊ → [t]    (ㅊ → [t])
ㅎ → [t]    (ㅎ → [t] — самый неожиданный!)
```

**Примеры:**
```
밥 [bap] = рис          (ㅂ → [p])
밤 [bam] = ночь          (ㅁ → [m])
밧 [bat] = бритьё        (ㅂ → [p], ㅎ → [t])
닭 [dal] = курица        (ㄷ → [t], ㄹ → [l])
맛 [mat] = вкус          (ㅁ → [m], ㅅ → [t])
```

**⚠️ Важно для русских:** В русском «т» в конце слова = [т] (тот). В корейском ㄷ, ㅅ, ㅈ, ㅎ в конце слога тоже = [т]. Это как русское «в» → [ф], только «д/с/ж/х» → «т».

**Мнемоника:** ㄷ ㅌ ㅅ ㅆ ㅈ ㅊ ㅎ = **Т**ормоз! Семь букв = один тормоз [t]. Язык тормозит у зубов.

### Группа [l] — Боковой

```
ㄹ → [l]    (единственная ㄹ в батчиме = [l])
```

**Примеры:**
```
발 [pal] = нога          (ㅂ → [p], ㄹ → [l])
살 [sal] = тело          (ㅅ → [t], ㄹ → [l])
```

**Мнемоника:** ㄹ = **л**изнул. В конце слога язык «лизнул» бок = [l].

### Группа [m] — Губы

```
ㅁ → [m]    (единственная ㅁ = [m] всегда)
```

**Примеры:**
```
밤 [bam] = ночь          (ㅂ → [p], ㅁ → [m])
옷 [ot] = одежда         (ㅇ → [ŋ], ㅅ → [t]... нет! ㅇ в конце = [ŋ])
```

Подождите: 옷 = [оп]! Потому что: ㅇ (в начале не читается) + ㅝ (во) + ㅅ (т) → [от]... Нет, ещё раз:
- 옷: ㅇ(нач. не читается) + ㅝ(во) + ㅅ(в конце = т) → [от]! ㅅ в батчиме = [t], а не...

На самом деле: 옷 читается [от]. Батчим ㅅ = [t]. НО перед этим ㅝ → [во]. Значит [во] + [т] = [от] (придыхание).

**Мнемоника:** ㅁ = **м**орда, всегда **м**. Как русское «м» в «море».

### Группа [p] — Губы-плюх

```
ㅂ → [p]    (ㅂ в батчиме = [p])
ㅍ → [p]    (ㅍ в батчиме = [p])
```

**Примеры:**
```
밥 [bap] = рис          (ㅂ → [p])
밤 [bam] = ночь          (ㅁ → [m])
곱 [kop] = умножать      (ㄱ → [k], ㅂ → [p])
```

**Мнемоника:** ㅂ ㅍ = **п**люх. Губы плюхнули и остановились = [p].

### Группа [ŋ] — Горло «нг»

```
ㅇ → [ŋ]    (ㅇ в конце слога = [ŋ], как «нг» в «ангар»)
```

**Примеры:**
```
강 [gang] = река         (ㄱ → [g]... нет! В конце ㄱ = [k])
```

Подождите: 강 = [кан]. Батчим ㄱ = [k], но перед ним ㅏ = [а], а ㄱ в начале = [г]. Значит [г] + [а] + [к] = [кан].

```
ong = 옹 [oŋ] = птица    (ㅇ → [ŋ])
```

**Мнемоника:** ㅇ = **нг**ел. Буква ㅇ в конце = «нг», как в «спанг**нг**». Единственный батчим без русского аналога!

## Детальная артикуляция каждого звука батчима

### [k] (горлышко) — ㄱ ㅋ ㄲ

**Место артикуляции:** Задняя часть языка + мягкое нёбо (веларная)
**Способ:** Взрывной, без голосовой вибрации
**Длительность:** Короткая

**Как произносить:**
1. Поднимите заднюю часть языка к мягкому нёбу
2. Задержите воздух
3. Отпустите — воздух вырывается с «к!»

**Отличие от русского «к»:** Русское «к» в «кот» — с сильным выдохом (аспирация). Корейское батчим [k] — **без выдоха**, как «к» в «скотч» (где к после с).

**Практика:**
```
박 [pak] = вишня
값 [kap] = цена
긁 [geuk] = царапать (батчим ㄱ + ㄷ)
```

### [n] (носовой) — ㄴ

**Место артикуляции:** Кончик языка + альвеолы (передние)
**Способ:** Носовой, голосовой
**Длительность:** Средняя

**Как произносить:**
1. Кончик языка касается альвеол
2. Воздух идёт через нос
3. Голосовые связки вибрируют

**Отличие от русского «н»:** Практически идентично русскому «н» в «неси». Никаких подводных камней.

**Практика:**
```
손 [son] = рука
문 [mun] = дверь
천 [cheon] = небо (батчим ㄴ в конце)
```

### [t] (язык у зубов) — ㄷ ㅌ ㅅ ㅆ ㅈ ㅊ ㅎ

**Место артикуляции:** Кончик языка + альвеолы/зубы
**Способ:** Взрывной, без голосовой вибрации
**Длительность:** Короткая, резкая

**Как произносить:**
1. Кончик языка касается зубов (альвеол)
2. Задержите воздух
3. Отпустите — «т!»

**Отличие от русского «т»:** Русское «т» — с более сильным выдохом. Корейское батчим [t] — более тихий, как «т» в «скат» (где т после с).

**⚠️ Особенность ㅎ → [t]:** ㅎ в конце слога полностью исчезает и становится [t]! Это как если бы русское «х» в конце слова превратилось в «т» (ход → [ходт]... нет, это неправда в русском!). В корейском это нормальная система: ㅎ → [t].

**Практика:**
```
닭 [dal] = курица
맛 [mat] = вкус
잎 [ip] = лист
밧 [bat] = бритьё (ㅂ+ㅎ → [p]+[t])
```

### [l] (боковой) — ㄹ

**Место артикуляции:** Кончик языка + альвеолы
**Способ:** Боковой (воздух проходит по бокам языка)
**Длительность:** Средняя

**Как произносить:**
1. Кончик языка касается альвеол
2. Воздух проходит по бокам языка
3. Язык не закрывает центральный проход

**Отличие от русского «л»:** Русское «л» в «лошадь» — та же артикуляция. Но в начале слога корейское ㄹ = [r] (трелёный «р»), а в конце = [l]. Это ключевое отличие!

**Практика:**
```
발 [pal] = нога
살 [sal] = тело
울 [ul] = шерсть
```

### [m] (носовой губный) — ㅁ

**Место артикуляции:** Губы + носовой путь
**Способ:** Носовой, голосовой
**Длительность:** Средняя

**Как произносить:**
1. Губы сомкнуты
2. Воздух идёт через нос
3. Голосовые связки вибрируют

**Отличие от русского «м»:** Идентично. Никаких отличий.

**Практика:**
```
밤 [bam] = ночь
김밥 [gimbap] = ролл (батчим ㅂ → [p], но это ㅂ в середине...)
```

### [p] (глухой губный) — ㅂ ㅍ

**Место артикуляции:** Губы
**Способ:** Взрывной, без голосовой вибрации
**Длительность:** Короткая

**Как произносить:**
1. Губы сомкнуты
2. Задержите воздух
3. Отпустите — «п!»

**Отличие от русского «п»:** Русское «п» с сильным выдохом (п**ь**). Корейское батчим [p] — без выдоха, как «п» в «спать».

**Практика:**
```
밥 [bap] = рис
곱 [kop] = умножать
```

### [ŋ] (носовой задненёбный) — ㅇ

**Место артикуляции:** Задняя часть языка + мягкое нёбо
**Способ:** Носовой, без голосовой вибрации
**Длительность:** Средняя

**Как произносить:**
1. Задняя часть языка прижата к мягкому нёбу
2. Воздух идёт через нос
3. Звук «нг»

**Отличие от русского:** У русских нет аналога! Ближайшее — «нг» в «ангар», «деньги», «понг». Это нужно отдельно отработать.

**Практика:**
```
강 [gang] = река (но батчим ㄱ = [k], значит [kang])
생 [saeng] = жизнь (батчим ㅇ = [ŋ])
```

**⚠️ Для русских:** Язык не поднимается к переднему нёбу (как при «н»), а задняя часть языка — к мягкому нёбу. Это другая зона! Попробуйте сказать «нг-нг-нг» — это и есть [ŋ].

# Часть XIII. Глубокий разбор твёрдых (напряжённых) согласных ㄲㄸㅃㅆㅉ

> Твёрдые согласные — это «удвоенные» буквы, которые произносятся с **напряжением горла** (fortis). Для русскоговорящих это как разница между «ма-а-а» (мягко) и «МА-А-А!» (напряжённо).

---

## Что такое «твёрдые» согласные?

В корейском есть два «режима» произношения согласных:
- **Ленивый (lenis):** ㄱ ㄷ ㅂ ㅅ ㅈ — мягкие, без напряжения
- **Напряжённый (fortis):** ㄲ ㄸ ㅃ ㅆ ㅉ — жёсткие, с напряжением горла и голосовых связок

**Аналогия для русских:** Представьте, что вы кричите «КА-КА-КА!» vs «ка-ка-ка». Разница в напряжении горла и голосовых связок. Твёрдые согласные — это как если бы вы произносили обычный звук, но с **двойной силой**.

---

## Подробная артикуляция каждой твёрдой согласной

### ㄲ [kk] — Двойной горлышко

**Базовая буква:** ㄱ [g/k]
**Твёрдая версия:** ㄲ [kk]

**Артикуляция:**
1. Язык упирается в заднее нёбо (как ㄱ)
2. **Голосовые связки НАТЯНУТЫ** (не вибрируют нормально — они в напряжении)
3. Воздух вырывается **сильнее**, чем при ㄱ
4. Звук — «кк!» (как если бы вы сказали «кк-кк-кк» быстро)

**Мнемоника:** ㄲ = ㄱ + ㄱ = два горлышка = **КК**оробка сжата! Представьте, что вы сжимаете коробку руками — горло сжимается дважды.

**Отличие от русского:** В русском нет твёрдых/мягких согласных в этом смысле. Ближайшее — крик «КА-КА-КА!» vs шёпот «ка-ка-ка». ㄲ — это не просто громче, а **напряжённее**.

**Практика:**
```
까 [kka] = чтобы (покрывать)
깎다 [kkada] = срезать
깍지 [kkakji] = клюв
꼭 [kkok] = точно
```

**Дрилл:** Сравните:
```
가 [ga] = чтобы (причина)    까 [kka] = чтобы (покрывать)
```

---

### ㄸ [tt] — Двойной язык

**Базовая буква:** ㄷ [d/t]
**Твёрдая версия:** ㄸ [tt]

**Артикуляция:**
1. Язык упирается в зубы/альвеолы (как ㄷ)
2. **Голосовые связки НАТЯНУТЫ**
3. Язык ударяется о зубы **дважды** (или один раз, но с двойной силой)
4. Звук — «тт!» (как «ТТ!» в ругательстве)

**Мнемоника:** ㄸ = ㄷ + ㄷ = два языка = **ТТ**вёрдо ударился! Представьте, что язык стучит по зубам молотком — ТТ!

**Отличие от русского:** В русском «тт» в словах вроде «коттедж» — это просто два «т». В корейском ㄸ — это один звук с двойной силой, как один удар молотком.

**Практика:**
```
따 [tta] = отдельный (который)
때 [ttae] = время/причина
닭 [dal] = курица (но ㄷ+ㅏ+ㄹ, не ㄸ)
뚝 [ttuk] = кусок
```

**Дрилл:** Сравните:
```
다 [da] = что           따 [tta] = отдельный
```

---

### ㅃ [pp] — Двойные губы

**Базовая буква:** ㅂ [b/p]
**Твёрдая версия:** ㅃ [pp]

**Артикуляция:**
1. Губы сомкнуты (как ㅂ)
2. **Голосовые связки НАТЯНУТЫ**
3. Губы «плюют» с двойной силой
4. Звук — «пп!» (как «пп-пп-пп» в раздражении)

**Мнемоника:** ㅃ = ㅂ + ㅂ = две губы = **ПП**лотно зажаты! Представьте, что вы щёлкаете губами — ПП!

**Отличие от русского:** В русском нет аналога. Ближайшее — «пп» в раздражении («пп-сс-сс»), но в корейском это один звук.

**Практика:**
```
뽀 [ppo] = пузырь
뽀다 [ppoda] = вздувать
뺨 [ppyeok] = щека
똑 [ttok] = точно... нет, 똑 = ㄸ+ㅗ+ㄱ
```

Исправлю:
```
뽀 [ppo] = пузырь
뿌 [ppeu] = прыгать (буквально)
뺨 [ppyeok] = щека
뽕 [ppong] = пень/шишак
```

**Дрилл:** Сравните:
```
바 [ba] = баран           뿌 [ppeu] = прыгать
```

---

### ㅆ [ss] — Двойные зубы

**Базовая буква:** ㅅ [s/sh]
**Твёрдая версия:** ㅆ [ss]

**Артикуляция:**
1. Зубы сжаты (как ㅅ)
2. **Голосовые связки НАТЯНУТЫ**
3. Воздух свистит **сильнее**, через узкую щель
4. Звук — «сс!» (как шипение змеи)

**Мнемоника:** ㅆ = ㅅ + ㅅ = два зуба = **СС**ыла! Представьте, что змея шипит — ССС!

**Отличие от русского:** Русское «сс» — это два отдельных «с». В корейском ㅆ — это один звук, более напряжённый и длительный. Ближайшее — «сс» в «сс-сс-сс» (шум), но с напряжением.

**Практика:**
```
쌍 [ssang] = пара/двойной
쌀 [ssaeng] = рисовый крахмал
썩 [sseok] = гнить
쏘 [sseo] = брызгать
```

**Дрилл:** Сравните:
```
사 [sa] = что             쌍 [ssang] = пара
```

---

### ㅉ [jj] — Двойной «жмёт»

**Базовая буква:** ㅈ [j]
**Твёрдая версия:** ㅉ [jj]

**Артикуляция:**
1. Язык упирается в нёбо (как ㅈ)
2. **Голосовые связки НАТЯНУТЫ**
3. Язык «жимает» нёбо с двойной силой
4. Звук — «джж!» (как «джж-джж-джж»)

**Мнемоника:** ㅉ = ㅈ + ㅈ = два языка = **ДЖЖ**мёт! Представьте, что два языка одновременно жмут нёбо — ДЖЖ!

**Отличие от русского:** В русском «дж» — это аффриката. В корейском ㅉ — это усилиенная версия, как если бы вы сказали «джжж!» с максимальным напряжением.

**Практика:**
```

짜 [jja] = солёный (вкус)
쩌 [jjeo] = удивляться
쩌리 [jjeoril] =...
```

Исправлю:
```
짜 [jja] = солёный (맛)
쩐다 [jjyeoda] = бежать
쥐 [jjwi] = мышь (род)
쥐어짜다 [jjuieojjada] = выдавливать
```

**Дрилл:** Сравните:
```
자 [ja] = что             짜 [jja] = солёный
```

# Часть XIV. Глубокий разбор двойных гласных ㅝㅞㅟㅢ

> Эти четыре гласные часто путают даже продвинутые изучающие. Разберём каждую по косточкам.

---

## Общая проблема: почему их путают?

В современном корейском:
- **ㅝ [wo]** и **ㅞ [we]** — звучат ОЧЕНЬ близко (почти одинаково)
- **ㅟ [wi]** — отдельный звук, как русское «ви»
- **ㅢ [ŭi]** — уникальный звук, «ыи»

Главная ловушка: русские слышат ㅝ и ㅞ одинаково, потому что в русском есть только «во» и «вэ», но разница между ними часто стирается.

---

## ㅝ [wo] — «во»

### Артикуляция

**Состав:** ㅜ (у) + ㅓ (о/ё) = «во»

**Пошагово:**
1. Начните с позиции ㅜ (у): губы вытянуты вперёд, как будто ползёте по земле
2. Перейдите к позиции ㅓ (о): рот чуть расширяется, звук идёт через нос
3. Результат: «во!» — как русское «во» в «волк»

**Мнемоника:** ㅝ = **Во**т! Земля внизу (ㅜ) + свет слева (ㅓ) = **Во**т! Вы смотрите на землю, и свет слева — как будто «во»тите с земли.

**Отличие от ㅘ:** ㅘ = ㅗ + ㅏ = «ва» (солнце сверху + свет справа). ㅝ = ㅜ + ㅓ = «во» (земля снизу + свет слева). Зеркально!

**Примеры:**
```
웃 [ut] = улыбаться (батчим ㅇ→[ŋ])
왜 [wae] = почему... нет! 왐 = ㅗ+ㅐ
```

Исправлю:
```
왜 [wae] = почему — это ㅗ+ㅐ, не ㅝ
```

Правильные примеры для ㅝ:
```
워 [wo] = ваш (вежливое)
```

Нет, 워 = ㅗ + ㅜ. Это не ㅝ.

Правильные слова с ㅝ:
```
원 [won] = желание/источник
```

Разбор 원: 원 = ㅇ(нач. не читается) + ㅝ(во) + ㄴ(н) = [вон] = «вон»!

```
원 [won] = желание, источник
돌 [don] = камень (1+ㅗ+ㄹ = [дон]... нет, ㅗ ≠ ㅝ)
```

Подождите, 돌 = ㄷ+ㅗ+ㄹ = [тон]. ㅗ ≠ ㅝ!

Давайте найдём реальные слова с ㅝ:
```
원 [won] = желание, источник
돌 [ton] = камень — тут ㅗ, не ㅝ
```

Хм, ㅝ в современном корейском встречается редко. Основные слова:
```
원 [won] = желание, источник
```

Также:
```
왈 [wal] = будет (разговорное) — нет, это ㅘ+ㅣ
```

На самом деле, в современном корейском ㅝ почти полностью вытеснена ㅝ → ㅙ или о других формы. Но для обучения:

**Мнемоника для ㅝ:** Представьте, что вы **во**ткнулись в землю (ㅜ) и смотрите на свет слева (ㅓ) = **во**т!

---

## ㅞ [we] — «вэ»

### Артикуляция

**Состав:** ㅜ (у) + ㅔ (э) = «вэ»

**Пошагово:**
1. Начните с позиции ㅜ (у): губы вытянуты вперёд
2. Перейдите к позиции ㅔ (э): рот расширяется, звук идёт «э»
3. Результат: «вэ!» — как русское «вэ» в «Великобритания» (но короче)

**Мнемоника:** ㅞ = **Вэ**! Земля внизу (ㅜ) + эхо (ㅔ) = **Вэ**! Земля + эхо = вэ.

**Отличие от ㅙ:** ㅙ = ㅗ + ㅐ = «вэ» (солнце сверху + эхо). ㅞ = ㅜ + ㅔ = «вэ» (земля снизу + эхо). Оба звучат одинаково, но пишутся по-разному!

**Примеры:**
```
왜 [wae] = почему — это ㅗ+ㅐ = ㅙ! Не ㅞ!
```

Подождите: 왜 = ㅗ + ㅐ = ㅙ, а не ㅞ!

Реальные слова с ㅞ очень редки в современном корейском. ㅞ и ㅙ произносятся одинаково как [wɛ].

**Мнемоника для ㅞ:** ㅞ = **Вэ**! Как «Великобритания» (Вэ). Земля (ㅜ) + эхо (ㅔ) = вэ.

**⚠️ Для русских:** ㅝ [wo] и ㅞ [we] звучат одинаково в современном корейском! ㅝ = [wo], ㅞ = [we], но на практике оба ≈ [wɛ]. Различайте только по написанию!

---

## ㅟ [wi] — «ви»

### Артикуляция

**Состав:** ㅜ (у) + ㅣ (и) = «ви»

**Пошагово:**
1. Начните с позиции ㅜ (у): губы вытянуты вперёд
2. Добавьте позицию ㅣ (и): рот растягивается в «и»
3. Результат: «ви!» — как русское «ви» в «Виола»

**Мнемоника:** ㅟ = **Ви**лка! Земля внизу (ㅜ) + человек (ㅣ) = **Ви**лка (человек стоит на земле). 

**Отличие от ㅝ/ㅞ:** ㅟ [wi] — это ОТДЕЛЬНЫЙ звук, не похожий на ㅝ/ㅞ! Это «ви», а не «во/вэ».

**Примеры:**
```
위 [wi] = вверх
위키백과 [wikipaekgwa] = Википедия
```

**Дрилл:** Различите ㅟ [wi] и ㅝ [wo]:
```
위 [wi] = вверх        원 [won] = желание
```

---

## ㅢ [ŭi] — «ыи»

### Артикуляция

**Состав:** ㅡ (ы) + ㅣ (и) = «ыи»

**Пошагово:**
1. Начните с позиции ㅡ (ы): рот растянут в «ы-ы», язык расслаблен
2. Добавьте позицию ㅣ (и): рот растягивается ещё больше, язык поднимается
3. Результат: «ыи!» — переход от «ы» к «и»

**Мнемоника:** ㅢ = **Ы** + **И** = **Ыи**! Горизонталь (земля, ㅡ) + вертикаль (человек, ㅣ) = **Ыи**.

**Особенность:** ㅢ произносится как один звук [ŭi], а не как два отдельных. Это как русское «ыи» — быстрый переход от «ы» к «и».

**Примеры:**
```
의 [ŭi] = принадлежность/значение (의자 = стул)
의사 [ŭisa] = врач
인의 [ŭin] = человек (в значении «человеческий»)
```

**⚠️ Исключение:** В конце слова ㅢ может читаться как [и]:
```
의 [ŭi] = принадлежность (в середине слова)
의 [ŭi] → в конце может быть [и]
```

На самом деле: ㅢ в конце слова = [и] (как ㅣ). Пример: 의 [ŭi], 아니 [ani]... нет, это ㅏ+ㅣ.

```
의 [ŭi] = принадлежность (всегда [ŭi])
```

Корректный пример: ㅢ в конце = [i]:
```
의 [ŭi] — в середине
의 [ŭi] — всегда [ŭi] (нет исключений)
```

Факт: ㅢ = [ŭi] всегда, кроме разговорного сокращения.

**Дрилл:** Различите ㅢ [ŭi] и ㅣ [i]:
```
의 [ŭi] = принадлежность    이 [i] = этот
의 [ŭi] = врач              이 [i] = этот (он/она)
```

# Часть XVI. Типичные ошибки русскоговорящих в корейском произношении

> Русский язык — самый «враждебный» к корейскому для изучающих. Вот 10 главных ловушок, как русский мешает вам говорить по-корейски.

---

## 1. Аспирация (выдох) — главная проблема

**Проблема:** В русском нет чёткого различения твёрдых и аспирированных согласных. Мы произносим «к» одинаково в «кот» и «скат». В корейском ㄱ и ㅋ — это РАЗНЫЕ звуки!

**Как русский мешает:**
- Русский «к» = и ㄱ, и ㅋ (мы не различаем)
- В корейском ㄱ [g] ≠ ㅋ [k] (с оглушением или без)

**Решение:** Практикуйте пары:
```
가 [ga] — 까 [kka]     г vs кк
다 [da] — 타 [ta]      д vs т
바 [ba] — 파 [pa]      б vs п
자 [ja] — 차 [cha]     дж vs ч
```

**Упражнение:** Скажите «가» мягко (как «га»). Теперь скажите «까» с напряжением горла (как «ККА!»). Разница — в напряжении голосовых связок.

---

## 2. Батчим-система — «в» → «ф» → «??»

**Проблема:** В русском «в» в конце слова → «ф» (велосипед → велосипед**ф**). В корейском батчим — это СИСТЕМА из 7 правил, а не одно правило!

**Как русский мешает:**
- Русские склоняются батчим как русскую «в»: ㄷ → [д], ㅂ → [б] и т.д.
- На самом деле: ㄷ → [т], ㅂ → [п], ㅅ → [т], ㅎ → [т]!

**Решение:** Запомните: ВСЕ согласные в батчиме = [т], кроме [н], [м], [л], [п], [к], [нг]. Это как русская «в» → «ф», только хуже: 7 букв → 1 звук.

**Упражнение:** Скажите «밥» [бап], «밤» [бам], «발» [пал]. Обратите внимание: ㅂ → [п] в батчиме, а не [б]!

---

## 3. Окончательное «е»/«о» → «а»

**Проблема:** В русском окончания «-ое», «-ё» часто произносятся как «-а» (море → «мор'а»). В корейском гласные чётко различаются!

**Как русский мешает:**
- Русские произносят ㅓ [ŏ] как «о» или «а»
- ㅜ [u] как «у» (нормально, но иногда слишком «твёрдо»)

**Решение:** ㅓ = «о/ё» мягкое (как «ё» в «ёлка», но короче). Не превращайте в «а»!

**Упражнение:** Скажите «서» [sŏ] = «то» (мягкое «о»). Не «са»!

---

## 4. Р/Л — невозможная пара

**Проблема:** В корейском ㄹ = [r] в начале слога, [l] в конце. У русских редко есть и то, и другое. Многие говорят «р» или «л» одинаково.

**Как русский мешает:**
- Русский «р» — трелёный (трепет)
- Русский «л» — боковой
- Корейское ㄹ в начале = [r] как в англском (один трель, не многократный)

**Решение:** ㄹ в начале слога = один короткий «р»-трель (не «ррр-р-р-р», а «д-р!»). В конце = обычное «л».

**Упражнение:** Скажите «라» [ра] — один «р»-трель. Теперь «리» [ри] — тот же «р», но высокий.

---

## 5. ㅎ — «х» или «т»?

**Проблема:** ㅎ в начале = «х» (хорошо). Но ㅎ в конце батчима = [т]! Русские не знают об этом и произносят «х» в конце, что звучит ужасно.

**Как русский мешает:**
- Русское «х» в конце = «х» (мат → матх... нет, так не бывает)
- Корейское ㅎ в конце = [т] (밧 [bat], 죽 [juk]... нет, 죽 = ㅈ+ㅇ)

**Решение:** ㅎ в конце = ТОЛЬКО [т]. Представьте, что «х» превращается в «т»: 밧 [батт] → [бат].

**Упражнение:** Скажите «밧» [bat] — не [батх]!

---

## 6. Глоттальная смычка

**Проблема:** В русском нет глоттальной смычки (как пауза в горле). В корейском она часто встречается, особенно между слогами.

**Как русский мешает:**
- Русские сливают слоги: «한글» → [хангэл]
- Правильно: [хан.гэл] — с паузой/раздельно

**Решение:** Между слогами с батчимом делайте микро-паузу. Как если бы вы делали «ха...негыл» → [хан.гэл].

---

## 7. Длина гласных

**Проблема:** В русском «ы» и «и» — разные по длине, но не по качеству так явно. В корейском ㅡ [ŭ] и ㅣ [i] — это принципиально разные звуки.

**Как русский мешает:**
- Русские смешивают ㅡ и ㅣ: ㅡ → «ы» (правильно), но иногда → «и» (неправильно)
- ㅡ = «ы» (растянутые губы), ㅣ = «и» (широкий рот)

**Решение:** ㅡ = «ы-ы» (губы в «ы»), ㅣ = «и-и» (губы в «и»). Разница в форме рта!

---

## 8. «П» и «Б» в начале слова

**Проблема:** В русском «п» всегда глухой, «б» всегда звонкий. В корейском ㅂ может быть и [б], и [п] в зависимости от позиции.

**Как русский мешает:**
- Русские всегда произносят ㅂ как [б] (потому что в начале слога = [б])
- Но в батчиме ㅂ = [п]!

**Решение:** ㅂ в начале/середине = [б] (как русское «б»). ㅂ в конце = [п] (как русское «п»).

**Упражнение:** 
```
밥 [bap] = рис (ㅂ в начале = [б], ㅂ в конце = [п])
```

---

## 9. Система тона (вводная)

**Проблема:** В русском нет интонационных паттернов, характерных для корейского. Корейское предложение обычно начинается высоко и падает вниз.

**Как русский мешает:**
- Русские говорят на корейском «ровно», как по телефону
- Корейский имеет восходящую интонацию в начале и нисходящую в конце

**Решение:** Представьте, что вы говорите с вопросительной интонацией в начале и утверждением в конце: «하늘 [хАнл]?» → «хАнл.» (падение).

---

## 10. ㄹ в середине слова — «р» или «л»?

**Проблема:** ㄹ в середине слова может быть и [r], и [l]. Русские обычно выбирают одно значение.

**Как русский мешает:**
- Русский «р» — всегда трель
- Русский «л» — всегда боковой
- Корейское ㄹ в середине = [r] после твёрдых гласных, [l] после мягких

**Решение:** После ㅏ, ㅗ, ㅡ (твёрдых) → [r]. После ㅓ, ㅜ, ㅣ (мягких) → [l].

**Упражнение:**
```
가라 [ka-ra] = поезжай (after ㅏ → [r])
고려 [ko-ryeo] = 고려 (after ㅓ → [l])
```

---

## Обводка: «Шпаргалка русских ловушек»

```
Русский         Корейский         Решение
─────────────────────────────────────────
к (везде)       ㄱ [g] ≠ ㅋ [k]   Практикуйте пары
в → ф           ㄷ → [t] не [d]   Батчим = система
море/мор'а      ㅓ ≠ ㅏ           ㅓ = мягкое «о»
р/л одно        ㄹ = [r]/[l]     В начале [r], в конце [l]
х в конце       ㅎ → [t]          ㅎ в батчиме = [т]
слитные слоги   хангэл → хан.гэл  Делайте паузы
ы = и           ㅡ ≠ ㅣ           Разная форма рта
п всегда [п]    ㅂ = [б]/[п]      В конце = [п]
ровная речь     Интонация ↗↘     Поднимайте-топчите
```

## Текст 3: «한글의 역사» (История хангыля — Advanced — 80 слов)

```
한글은 세종대왕이 1443년에 만들었습니다.
한국어 사람들은 중국글자를 쓰고 있었습니다.
```

## Частые ошибки русских — быстрые исправления

```
1. ㄱ ≠ ㅋ — разделяйте мягкое и напряжённое

3. ㅎ в конце = [т], не [х]
4. ㄹ в начале = [r], в конце = [l]
```
