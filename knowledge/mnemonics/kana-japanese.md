# Кана через образы: хирагана и катакана（かなの記憶術）

> **Метод:** каждый знак = картинка. Читаете образ → представляете ярко → пишете от руки → знак закрепляется за 2–3 повторения вместо 20 механических.
>
> **Правило:** чужой образ работает на 30–50% слабее своего. Если какая-то картинка «не ваша» — замените её немедленно своей. Файл даёт стартовые заготовки.
>
> **Приложение языковой мнемоники.** Автономный файл — не требует внешних разделов.
>
> Связанные материалы: [Как работает память](how-memory-works.md) · [Карта раздела](index.md) · [Кандзи-истории](kanji-stories.md)

---

## Как заниматься по этому файлу

```
1. Один блок (ряд из 5 знаков) за подход
2. Прочитайте все 5 образов, представьте каждый 5 секунд
3. Закройте таблицу → напишите знаки по памяти
4. Сверьте. Ошибочные — перерисуйте образ ярче и ещё раз ×5 прописей
5. Через день — блок повторения; через неделю — контрольный
```

Норма скорости: один ряд в день = обе азбуки за 3 недели без спешки.

# Часть I. Хирагана（ひらがな）

Хирагана плавная, круглая — как женская рука. Образы тоже «мягкие».

## Ряд あ（あ・い・う・え・お）

| Знак | Чтение | Образ | Якорь-слово |
|------|--------|-------|-------------|
| あ | **a** | Человек всплеснул руки крестом и кричит «А-А!» — видна голова сверху | АВАРИЯ |
| い | **i** | Две свечи стоят рядом; задули — «И-и-и» погасли | ИГЛЫ |
| う | **u** | Ухо в профиль: раковина и мочка | УХО |
| え | **e** | Энергичная фигурка бежит, шарф развевается: «Э-эй!» | ЭНЕРГИЯ |
| お | **o** | Рыбак с удочкой: тело + леска справа вниз; поймал О-громную рыбу | ОКУНЬ |

**Мини-дрилл ряда** — прочитайте, опираясь только на образы:

```
あい（любовь）　うえ（верх）　おい（племянник）　あう（совпадать）　いえ（дом）
```

# Часть II. Дакутэн（゛）и хандакутэн（゜）

Две чёрточки = озвончение. Кружочек только для ряда は → ぱ.

## Правило образов

Представьте: знак надел **тёмные очки**（゛）— стал «злой» версией себя, голос огрубел:

| Милый | Очки → Злой | Звук |
|-------|-------------|------|
| か птица | が ворона каркнула громче | ka→ga |
| さ цветок | за сорняком пришёл | sa→za |
| た топор | да — ударил! | ta→da |
| は цветок | ба — бабахнул | ha→ba |
| は + ◦ | па — тихий хлопок мыльного пузыря | ha→pa |

## Таблица с образами

| Ряд | Знаки | Образ-история |
|-----|-------|---------------|
| が行 | がぎぐげご | Ворона（が）села на КИта（ぎ）、Клюв（ぐ）у неё стальной, КЕГЛЮ сбила, КОрзину украла |
| ざ行 | ざじずぜぞ | САд зарос ЗАрослями; Швабра превратилась в Джинна（じ）; СУслик зазевался |
| だ行 | だぢづでど | ТОПОР ударил — «ДА!»; ТЕлеграф сломался — «ДЕ-ДО» |
| ば行 | ばびぶべぼ | Цветок（は）взорвался БАБАХом; ХИхиканье стало БУханьем; ХОтель сгорел |
| ぱ行 | ぱぴぷぺぽ | Мыльные Пузыри: тихий «ПА-ПИ-ПУ» |

**Дрилл:**

```
がっこう　ぎんこう　ごはん
じかん　　でんしゃ　でんわ
たべる　　でかけます
ぱん　　　えんぴつ　さんぽ
```

время · поезд · телефон
есть · выходить
хлеб · карандаш · прогулка

# Часть III. Ёон — маленькие ゃゅょ

Маленький знак = второй этаж слога: きゃ = «кя» одним толчком.

## Образ

Большая や — ЯК на весь экран. Маленькая ゃ — якёнок, прячущийся за спиной первого знака. Слитно!

| Сочетание | Звук | Слово-якорь |
|-----------|------|-------------|
| きゃきゅきょ | kya kyu kyo | きょう「сегодня」— КЁтай на сегодня |
| しゃしゅしょ | sha shu sho | しゃしん「фото」— ЩЕлчок камеры |
| ちゃちゅちょ | cha chu cho | おちゃ「чай」— ЧАЙ |
| にゃにゅにょ | nya nyu nyo | にゃあ「мяу」|
| ひゃひゅひょ | hya hyu hyo | ひゃく「сто»— ХИАКС! сто |
| みゃみゅみょ | mya myu myo | みんな→ミラン？ нет：みょうにち「послезавтра»|
| りゃりゅりょ | rya ryu ryo | りょうり「готовка」— РЁРычит плита |

**⚠️ Большая vs маленькая:**

```
きや（ки-я, два слога） ≠ きゃ（кя, один）
ゆきやま（юки-яма）   ≠ ゆっきゃ ✗
```

Яконок стоит НИЖЕ линии и занимает полклетки.

**Дрилл:**

```
しゅくだい　　でんしゃ　　じゅぎょう
おちゃ　　　　ひゃく　　　りょうり
きょう　　　　しょくどう　ちゅうがっこう
```

<summary>Ответы</summary>

домашнее задание · поезд · урок
чай · сто · готовка
сегодня · столовая · средняя школа

</details>

# Часть V. Ловушки-пары: истории о различии

Пары запоминаются ПАРНЫМИ историями. Читаете историю → взгляд на пару → связь навсегда.

## シ vs ツ

> **ЩИ и ЦУНАМИ.**
> シ — капли ЩИ разлетаются ГОРИЗОНТАЛЬНО (по столу брызнули).
> ツ — капли ЦУНАМИ падают ВЕРТИКАЛЬНО (стена воды).
>
> **Правило взгляда:** у シ штрихи лежат, у ツ — стоят.

```
シーツ（простыня）　ツアー（тур）　おしゃべり（болтовня）　つみ（вина）
```

## ソ vs ン

> **СОус и НОж.**
> ソ：капля СОуса СЛЕВА СВЕРХУ скользит вниз.
> ン：НОЖом стукнули СПРАВА СНИЗУ вверх.
>
> **Правило:** начало движения у ソ — сверху слева; у ン — снизу справа.

```
ソファー（диван）　パン（хлеб）　テスト→ソース（соус）／おんがく（музыка）
```

## ア vs マ

> **АТАКА и МАЧТА.**
> ア — каратист: верхняя черта ОТРЫВАЕТСЯ вправо (удар!).
> マ — мачта: черта ПРИЛИГАЕТ ровно.
>

```

```

## ウ vs ワ

> **УЮТ и ВАУ.**
> ウ — есть КРЫША (уютно).
> ワ — крыши нет, рот открыт шире (вау!).

```

## ル vs レ

> **РЮМКА и РЕКА.**
> ル — две черты: ножка рюмки + стенка.
> レ — одно колено реки.

```

```

## ヌ vs メ

> **НУДЛС и ПРИЦЕЛ.**
> ヌ — палочки тянут лапшу, хвостик свисает.
> メ — прицел: крест без хвостиков.

```
ヌードル（лапша）　メール（почта)　デザイン（дизайн)
```

## ワ vs ク

> **ВАУ и КЛЮВ.**
> ワ — широкий открытый рот без угла.
> ク — клюв с острым углом сверху.

```
ワイシャツ（рубашка)　クラス（класс)　クッキー（печенье)
```

アラーム　マナー　ウール　ワーク
ルビー　レモン　ヌードル　メール
ワイシャツ　クラス
```

<details><summary>Ответы</summary>

шампунь · дерево(дерево-туристич.) · софт/программа · панда
будильник · манеры · шерсть · работа

# Часть VII-bis. Долгие гласные и сокуон через образы

## Долгие гласные

**Образ:** длинная гласная = растянутая резинка. Коротко «обасан»（тётя) — растянули «обаасан»（бабушка) — другой человек!

| Короткое | Длинное | История растяжения |
|----------|---------|---------------------|
| おばさん тётя | おばあさん бабушка | Тётю РАСТЯНУЛИ до бабушки |
| ゆき снег | ゆうき смелость | Снег вытянули в сосульку смелости |
| ここ здесь | こうこう школа | Отсюда до школы — длинная дорога |
| とり птица | とおり улица | Птица летит вдоль всей улицы |
| くろ чёрный | くろう трудности | Чёрную полосу растянули в трудности |

В **катакане** долгота — черта「ー」= линейка:

```
コーヒー　テープ　スーパー　ケーキ　ノート　メール
```

> 💡 Линейкаー = растянуть звук на одну клетку.

## Сокуон っ — кнопка ПАУЗА

Маленькая つ — пауза на пульте: звук замирает, потом продолжается удвоенно.

```
きって = ki + ПАУЗА + te（марка)
がっこう = ga + ПАУЗА + kou（школа)
```

**Пары со смыслом:**

| Без っ | С っ |
|--------|------|
| きて（着て， придя) | きって（切手， марка) |
| おかさん? нет：おかし（сладости) | おっかさん？ нет：がっき（инструмент) |

**Дрилл:** けっこう · しっぱい · いっぱい · もってくる · ちょっと

<details><summary>Ответы</summary>

отлично · провал · полно · приносить · немного

</details>

# Часть VII-e. Частые ошибки при освоении кан

1. **Обе азбуки одновременно с нуля.** Сначала хирагана до автомата, потом катакана.
2. **Читать молча.** Кана = звуки; без проговаривания учится картинка вместо звука.
3. **Зубрить таблицу подряд.** Реальные слова перемешивают ряды — дриллы словами обязательны.
4. **Игнорировать пары.** ル/レ、ぬ/め、シ/ツ валяют экзамен — парные истории мастхэв.
5. **Бросать после «примерно знаю».** Цель — <1 сек на знак.
6. **Прописи без эталона.** Неправильно писать 100 раз = закрепить ошибку.

# Часть IX-bis. Хираганные близнецы

Хирагана тоже имеет пары-ловушки. Каждой — история различия:

## あ vs お

> **АВАРИЯ и ОКУНЬ.**
> あ — руки вскинуты крестом (крик «А!»).
> お — то же тело + УДОЧКА справа (рыбак поймал окуня).
> Ищите удочку!

## さ vs ち

> **САД и ЗЕРКАЛО.**
> さ — цветок растёт ВВЕРХ из земли.
> ち — зеркало лежит, ручка СНИЗУ.
> Направление диагонали: у さ — влево-вниз, у ち — петля.

## は vs ほ

> **ХА и ДОМ.**
> ほ = は + крыша сверху.
> Ищите крышу: есть → ХОтель/книга, нет → смех.

## ぬ vs め

> **НУДЛС и ГЛАЗ.**
> ぬ — нитки лапши СВИСАЮТ вниз за петлёй.
> め — ресничка-точка ВНУТРИ, ничего не свисает.
> Свисает еда? Это нудлс（ぬ）.

## る・れ・ろ (тройня)

> **РУлет · РЕка · РОвная.**
> る — кончик ЗАКРУЧИВАЕТСЯ вниз-внутрь.
> れ — хвост летит ВВЕРХ наружу.
> ろ — обрыв БЕЗ загиба.
>
> Мнемофраза: «Рулон свернули, Река выпрыгнула, Ровно оборвали».

## う vs つ vs ん

> **УХО · ЦУНАМИ · ВОЛНА-Н.**
> う — закрытая форма с чёрточкой сверху (ухо).
> つ — открытая волна вправо.
> ん — почти горизонтальная волна без начала.
>
> Три степени «открытости»: ухо закрыто → цунами открыто → н просто линия.

## ぬ vs わ vs ね (хвосты)

> Три знака с «хвостами»:
> わ — хвост ПРЯМОЙ (вау, удивился просто).
> ね — хвост ЗАВИВАЕТСЯ колечком (кошачий).
> を — через плечо шест (объект).

**Блиц-тест:** назовите знак по описанию:

1. Удочка сбоку → ＿＿
2. Крыша сверху → ＿＿

# Часть XI. Дакутэн и хандакутэн — углубление

## XI.1 Полная таблица озвончения (хирагана)

| Исходный ряд | Озвончённый | Звук | Мнемо-история озвончения |
|--------------|-------------|------|--------------------------|
| か き く け こ | が ぎ ぐ げ ご | k→g | Птица (か) надела тёмные очки — каркнула грубо: «ГА!» |
| さ し す せ そ | ざ じ ず ぜ ぞ | s→z | Цветок (さ) зарос бурьяном — зашипел «ДЗА!» |
| た ち つ て と | だ ぢ づ で ど | t→d | Топор (た) ударил сильнее — «ДА!» с отдачей |
| は ひ ふ へ ほ | ば び ぶ べ ぼ | h→b | Смех (は) превратился в бабаханье барабана |

| Хандакутэн (только は-ряд) | ぱ ぴ ぷ ぺ ぽ | h→p | Тихий хлопок мыльного пузыря «ПА» — кружок-пузырь |

> **Правило очков:** две чёрточки ゛ = голос стал «густым», кружок ゜ = воздух вышел одним толчком.

### Почему じ и ぢ звучат одинаково?

Исторически это разные слоги, но в современном токийском — оба «дзи». Аналогично ず и づ = «дзу». В учебниках оставляют для этимологии:

| Пара | Современное чтение | Где встречается |
|------|-------------------|-----------------|
| じ / ぢ | дзи | じかん (время), ちぢむ (сжиматься) — второе редко |
| ず / づ | дзу | つづく (продолжаться) — сохраняет づ |
| を | о | Частица объекта, пишется を, читается «о» |

## XI.2 Рэндаку — озвончение в сложных словах

Когда два слова склеиваются, начало второго часто озвончается:

| Слово 1 + Слово 2 | Результат | Правило-образ |
|-------------------|-----------|---------------|
| ひと (человек) + ひと (человек) | ひとびと (люди) | Второй человек «огрубел» от толпы |
| かみ (бумага) + いれ (вкладывать) | かみいれ → かみ+びれ? нет: 封筒? проще: おり + かみ = おりがみ (оригами) | Бумага в составе слова озвончается |
| て (рука) + かみ (бумага) | てがみ (письмо) | «Рука-бумага» — письмо |
| さけ (алкоголь) + や (лавка) | さかや (винный магазин) | — |

**Образ:** второе слово надевает очки, когда прячется за первым.

### Когда рэндаку НЕ происходит

1. Если второе слово уже с дакутэн: さけ + ざけ ✗ — не удваивают.
2. Правило Лаймана: если во втором слове уже есть звонкий внутри, озвончение блокируется.

# Часть XII. Ёон — полная карта слияний

## XII.1 Принцип «яконёнка»

Большая や (ЯК) + маленькая ゃ (яконёнок на плечах) = один толчок:

# Часть XIII. Сокуон, тёон, хацуон — три «маленьких»

## XIII.1 Сокуон っ/ッ — пауза-задержка

**Образ:** маленькая つ = кнопка ⏸ ПАУЗА на пульте. На секунду задерживаете воздух, потом выстреливаете удвоенной согласной.

| Без паузы | С паузой | Смысл меняется |
|-----------|----------|----------------|
| きて (придя) | きって (марка) + пауза | — |
| さか (склон?) | さっか (автор) | — |
| かこ (прошлое) | かっこ (скобки) | — |
| きかん (период) | きっかん? нет: きっぷ (билет) | — |

**Как писать/печатать:** удвойте следующую согласную: gakkou → がっこう, kippu → きっぷ.

**Таблица удвоений:**

| Согласная | Пример | Ромадзи |
|-----------|--------|---------|
| k | がっこう | gakkou |
| s | けっせき | kesseki |
| t | きって | kitte |
| p | きっぷ | kippu |
| c | まっちゃ | matcha |

> Исключение: перед n, m — не っ, а ん! (はんぶん, не はっぶん)

**Дрилл сокуон:**

```

ちょっと　もっと　きっと　ずっと　やっぱり

```

## XIII.2 Тёон — долгие гласные (ー в катакане, удвоение в хирагане)

**Хирагана:** добавляется вторая гласная того же ряда:

| Ряд | Долгота через | Пример |
|-----|---------------|--------|
| あ | あ | おかあさん (мама) ← おかさん ✗ |
| い | い | おにいさん (старший брат) |
| う | う | くうこう (аэропорт) |
| え | い / え | せんせい (учитель) — え→い! исключение |
| お | う | おとうさん (папа) — お→う! |

> **Ловушка え/お:** долгие え чаще тянут через い (けいさつ — полиция), долгие お — через う (とおり — улица).

**Катакана:** долгота = черта ー (линейка):

```
コーヒー　ケーキ　ビール　ノート　スーパー　タクシー　メール
ー = растяни на одну клетку
```

**Минимальные пары (смысл меняется!):**

| Коротко | Долго | Перевод |
|---------|-------|---------|
| おばさん (тётя) | おばあさん (бабушка) | — |
| ゆき (снег) | ゆうき (смелость) | — |
| とる (брать) | とおる (проходить) | — |
| ここ (здесь) | こうこう (старшая школа) | — |
| え (картина) | ええ (да) | — |

**Дрилл тёон:**

```
おじさん／おじいさん　　とけい／とうけい　　こうえん／こえん?
ビル／ビール　　カード／カド? нет
```

## XIII.3 Хацуон ん/ン — морa-носо́вая

ん — единственная согласная-морa, занимает целую клетку:

| Правило | Пример | Пояснение |
|---------|--------|-----------|
| ん + гласная = n + апостроф | きんえん (запрет курить) = ki n' en | Чтобы не слилось в ね |
| ん перед p/b/m = «м» | さんぽ (прогулка) звучит «сампо» | Губы готовятся к p |
| ん в конце = лёгкий «н» | にほん (Япония) | Не «нъ», а носовой отголосок |

**Печать:** ん = nn (если дальше гласная) или n (в конце).

**Дрилл ん:**

```

コンビニ　サンドイッチ　インターネット　ワイン　パン
```

# Часть XVI. SRS и интервалы — как повторять кану

## XVI.1 Кривая забывания для каны

Без повторений через 24 часа теряется 60% знаков. С образом — 40%. С прописем — 30%. Поэтому график:

| День | Действие | Время |
|------|----------|-------|
| 0 | Учите ряд (5 знаков) + прописи ×10 | 15 мин |
| 1 | Повтор ряда + диктант | 5 мин |
| 3 | Повтор + дрилл словами | 5 мин |
| 7 | Контрольный тест ряда | 3 мин |
| 14 | Финал — смешанный текст | 5 мин |
| 30 | Проверка автоматизма (<1с) | 2 мин |

> Если ошиблись — сбрасывайте интервал на день 1.

## XVI.2 Карточки Anki для каны (шаблон)

```
Front: あ — образ?
Back:
  Чтение: a
  Образ: человек всплеснул руками «А!»
  Слово: あさ (утро)
  Пропись: 3 черты (небо→человек→замах)
Tags: kana::hiragana::a-row
```

Для катаканы добавьте поле «Ловушка-пара»: シ vs ツ.

## XVI.3 Чек-лист автоматизма (повтор из Части IX)

- [ ] Любой знак <1с без образа
- [ ] Письмо без подсматривания
- [ ] Ловушки シ/ツ, ソ/ン, る/れ/ろ, ぬ/め без паузы
- [ ] Ёон читается одним толчком, не двумя слогами
- [ ] Сокуон — пауза чувствуется
- [ ] Тёон — длина различается (おばさん vs おばあさん)

# Часть XVII. Исторический уголок — откуда взялась кана

Хирагана произошла из манъёганы — скорописного написания кандзи:

| Хирагана | Исходный кандзи (манъёгана) | Как упростили |
|----------|-----------------------------|---------------|
| あ | 安 | Скоропись 安 → あ |
| い | 以 | → い |
| う | 宇 | → う |
| え | 衣 | → え |
| お | 於 | → お |
| か | 加 | → か |
| き | 幾 | → き |
| く | 久 | → く |
| け | 計 | → け |
| こ | 己 | → こ |
| し | 之 | → し |
| す | 寸 | → す |

Катакана — из частей кандзи, взятых как сокращения:

| Катакана | Исходный кандзи | Часть |
|----------|-----------------|-------|
| ア | 阿 | Левый радикал |
| イ | 伊 | Левая часть |
| ウ | 宇 | Верхняя крыша |
| エ | 江 | Правая часть |
| オ | 於 | Часть |
| カ | 加 | Левая часть |
| キ | 幾 | Верх |
| ク | 久 | Весь знак угловато |
| ケ | 計 | Часть |

> Знание происхождения помогает понять, почему хирагана округлая (скоропись кистью), а катакана угловатая (вырезка резцом).

| らりるれろ | ra ri ru re ro | — |

| Цель | Ввод |

| きゃ きゅ きょ | kya kyu kyo |

# Часть XX. Частые ошибки — расширенный разбор

| Ошибка | Почему | Как исправить |
|--------|--------|---------------|
| Учить обе азбуки параллельно | Интерференция — мозг путает образы | Сначала хирагана до <1с, потом катакана |
| Читать молча | Запоминается картинка, не звук | Проговаривайте вслух каждый знак |
| Зубрить столбцами | Реальные слова перемешаны | Учите сразу словами из §XV |
| Игнорировать пары | シ/ツ, ソ/ン валят экзамен | Парные истории §V — обязательны |
| Бросать на 80% | Остальные 20% забываются через неделю | Доведите до 100% + интервалы §XVI |
| Прописи без эталона | Закрепляете ошибку | Сверяйте каждый штрих с §XIV |
| Не писать рукой | Только чтение = медленное узнавание | 5–7 прописей на знак минимум |
| Игнорировать сокуон/тёон | Меняют смысл слова! | Минимальные пары §XIII — отработайте |
