# Кандзи-истории: спектакль из ключей（漢字の物語）

> **Метод:** каждый составной кандзи — маленький спектакль. Ключи-радикалы — актёры. Читаете сюжет → знак собирается сам → чтение и смысл приклеиваются к истории.
>
> **Порядок работы:** сначала выучите труппу актёров (раздел 1) до автоматизма. Потом читайте истории по партиям. Через 40 знаков мозг начнёт собирать новые знаки самостоятельно.
>
> **Приложение языковой мнемоники.** Автономный файл — не требует внешних разделов.
>
> Связанные материалы: [Фундамент памяти](how-memory-works.md) · [Кана](kana-japanese.md) · [Карта раздела](index.md)

---

## Формат записи

```
### Знак（чтения）— значение
Актёры: …
Спектакль: …
Слова: слово1（чтение）· слово2（чтение）
```

| 水/氵 | Водяной брызжущий | 海洗泳 |
| 火/灬 | Огонёк на ножках | 焼灯秋 |

## 2. Партия первая: числа и время

### 一（イチ・ひと）— один
**Актёры:** одна черта.
**Спектакль:** Горизонт — одна линия от края до края.
**Слова:** 一人（ひとり）· 一番（いちばん）

### 二（ニ・ふた）— два
**Актёры:** две линии.
**Спектакль:** Верхняя — небо, нижняя — земля. Между ними всё живёт.
**Слова:** 二人（ふたり）· 二日（ふつか）

### 三（サン・み）— три
**Актёры:** три линии.
**Спектакль:** Небо, люди, земля — три мира.
**Слова:** 三月（さんがつ）· 三人（さんにん）

### 日（ニチ・ひ）— солнце, день
**Актёры:** Солнце-мяч в раме окна.
**Спектакль:** Солнце вставило себя в оконную раму — наступил день.
**Слова:** 日曜日（にちようび）· 日本（にほん）· 毎日（まいにち）

### 月（ゲツ・つき）— луна, месяц
**Актёры:** Луна-серп в том же окне.
**Спектакль:** Ночью в раму заглядывает луна. Один цикл луны = месяц.
**Слова:** 月曜日（げつようび）· 毎月（まいつき）· 一ヶ月（いっかげつ）

### 年（ネン・とし）— год
**Актёры:** Колос риса（禾）+ черта времени.
**Спектакль:** Рис собирают раз в году: колос кланяется — год прошёл.
**Слова:** 今年（ことし）· 毎年（まいとし）· 学生一年生（いちねんせい）

### 時（ジ・とき）— час, время
**Актёры:** Солнце（日）+ храм（寺）.
**Спектакль:** На храмовой стене — солнечные часы: солнце идёт по храму, отбивая время.
**Слова:** 時間（じかん）· 何時（なんじ）· 時々（ときどき）

### 分（フン・わ）— минута; делить
**Актёры:** Восьмёрка（八）+ нож сверху.
**Спектакль:** Нож делит нечто на восемь частей — «восемь долек минуты» (60 мин ÷ 8 ≈ 7,5 — древнее округление).
**Слова:** 五分（ごふん）· 分かる（わかる）понимать · 自分（じぶん）сам

### 半（ハン・なか）— половина
**Актёры:** Бык（原形）, рассечённый восьмёркой（八）.
**Спектакль:** Быка располовинили — каждая половина «хан». Полдень тоже 半：солнце наполовину прошло.
**Слова:** 半分（はんぶん）· 半（はん）полтина · 三時半（さんじはん）

### 毎（マイ・ごと）— каждый
**Актёры:** Мать（母 упрощённая）+ чёрточки.
**Спектакль:** Мать делает одно и то же КАЖДЫЙ день: каждый день, каждый месяц, каждый год.
**Слова:** 毎日（まいにち）· 毎朝（まいあさ）· 毎週（まいしゅう）

### 週（シュウ）— неделя
**Актёры:** Круговорот（周）+ движение（辶）.
**Спектакль:** Дни бегут по кругу — круг замкнулся, неделя готова.
**Слова:** 今週（こんしゅう）· 来週（らいしゅう）· 週末（しゅうまつ）

## 3. Партия вторая: люди и семья

### 人（ジン・ひと）— человек
**Актёры:** сам Человек.
**Спектакль:** Идёт, чуть наклонившись вперёд: вид сбоку — голова, корпус, шагающая нога.
**Слова:** 日本人（にほんじん）· 三人（さんにん）· 人口（じんこう）

### 男（ダン・おとこ）— мужчина
**Актёры:** Поле（田）+ Мускул（力）.
**Спектакль:** Сила в поле — так древние писали «мужчина».
**Слова:** 男の子（おとこのこ）· 男性（だんせい）· 長男（ちょうなん）

### 女（ジョ・おんな）— женщина
**Актёры:** Женщина со скрещёнными руками.
**Спектакль:** Силуэт сидящей женщины: изящный крест рук и складки платья.
**Слова:** 女の人（おんなのひと）· 女性（じょせい）· 長女（ちょうじょ）

### 子（シ・こ）— ребёнок
**Актёры:** Младенец с большой головой.
**Спектакль:** Голова огромная, ручки раскинуты — классический младенец.
**Слова:** 子供（こども）· 女子（じょし）· 字（じ＝ребёнок под крышей — знак)

### 父（フ・ちち）— отец
**Актёры:** Две руки над камином.
**Спектакль:** Папа двумя руками поправляет огонь в очаге. Две одинаковые руки = «папа».
**Слова:** 父（ちち）мой · お父さん（おとうさん）чужой

### 母（ボ・はは）— мать
**Актёры:** Женщина + две точки-грудь.
**Спектакль:** Женщина с двумя точками кормит — мать.
**Слова:** 母（はは)мой · お母さん（おかあさん）чужой · 話：毎（まい）= 母 без деталей — мама каждый день работает

### 友（ユウ・とも）— друг
**Актёры:** Рука（又）+ плуг.
**Спектакль:** Двое вместе держат плуг на поле — настоящие друзья работают в четыре руки.
**Слова:** 友達（ともだち）· 親友（しんゆう）

### 先（セン・さき）— раньше; впереди
**Актёры:** Ноги（儿）+ росток сверху.
**Спектакль:** Кто-то уже прошёл по ростку — он был ВПЕРЕДИ вас. Отсюда 先生 — «рождённый раньше», учитель.
**Слова:** 先生（せんせい）· 先週（せんしゅう）· 先（さき）впереди

### 生（セイ・い/う/き）— жизнь; рождаться
**Актёры:** Росток пробивается из земли.
**Спектакль:** Три черты ростка поднимаются над почвой — рождается жизнь.
**Слова:** 学生（がくせい）· 生きる（いきる）жить · 先生（せんせい）

### 大（ダイ・おо）— большой
**Актёры:** Человек распахнул руки.
**Спектакль:** Человек встал крестом: «Я БОЛЬШОЙ!» — занимает всё небо.
**Слова:** 大きい（おおきい）· 大学（だいがく）· 大丈夫（だいじょうぶ）

### 小（ショウ・ちい/こ）— маленький
**Актёры:** Три крошечных штришка.
**Спектакль:** Большое разделили — остались три малюсеньких крючка.
**Слова:** 小さい（ちいさい）· 小学校（しょうがっこう）

### 名（メイ・な）— имя
**Актёры:** Вечер（夕）+ рот（口).
**Спектакль:** Вечером темно, лица не видно — окликают ПО ИМЕНИ через рот.
**Слова:** 名前（なまえ）· 有名（ゆうめい）известный

## 4. Партия третья: природа и стихии

### 山（サン・やま）— гора
**Актёры:** Три пика.
**Спектакль:** Средний пик выше всех — профиль горной цепи.
**Слова:** 富士山（ふじさん）· 山道（やまみち）

### 川（セン・かわ）— река
**Актёры:** Три потока воды.
**Спектакль:** Берег-берег и вода посередине — все текут вниз.
**Слова:** 小川（おがわ）ручей · 川口（かわぐち）устье

### 田（デン・た）— рисовое поле
**Актёры:** Квадраты полей.
**Спектакль:** Вид сверху на заливные чеки: квадраты разделены дорожками.
**Слова:** 田舎（いなか）провинция · 田園（でんえん）поля

### 空（クウ・そら/あ）— небо; пустой
**Актёры:** Крыша（穴）+ мастерство（工）.
**Спектакль:** Отверстие в небе, сделанное мастером — так выглядит аэропорт 空港（くうこう）.
**Слова:** 空港（くうこう）аэропорт · 空（そら）небо · 空く（あく）освобождаться

### 雨（ウ・あめ）— дождь
**Актёры:** Туча с четырьмя каплями.
**Спектакль:** Окно с занавеской, из-под неё капает: дождь за стеклом.
**Слова:** 大雨（おおあめ）ливень · 梅雨（つゆ）сезон дождей

### 白（ハク・しろ）— белый
**Актёры:** Солнце（日）+ капля.
**Спектакль:** Солнечная капля света — блик чистой белизны.
**Слова:** 白い（しろい）белый · 白紙（はくし）чистый лист

### 青（セイ・あо）— синий; юность
**Актёры:** Молодая луна на горизонте.
**Спектакль:** Юная луна висит над молодым месяцем — цвет юности (у японцев 青 = и синий, и зелёный светофора!).
**Слова:** 青い（あおい）· 青信号（あおしんごう）зелёный свет

### 春（シュン・はる）— весна
**Актёры:** Солнце（日）под тремя людьми.
**Спектакль:** Весна: три человека греются на солнце после зимы.
**Слова:** 春休み（はるやすみ）весенние каникулы

### 秋（シュウ・あき）— осень
**Актёры:** Колос（禾）+ огонь（火）.
**Спектакль:** После урожая поля поджигают — золой удобряют. Осень!
**Слова:** 秋葉原（あきはばら）Акихабара

### 夏（カ・なつ）— лето
**Актёры:** Самоуверенное лицо（自）+ ноги в движении.
**Спектакль:** Летом все куда-то бегают: лицо загорелое, ноги не стоят.
**Слова:** 夏休み（なつやすみ）летние каникулы

### 冬（トウ・ふゆ）— зима
**Актёры:** Два узла на верёвке（夂）+ точки льда.
**Спектакль:** Зимой концы верёвки завязали узлами, чтобы не растрепались на морозе; вокруг — точки снега.
**Слова:** 冬休み（ふゆやすみ）зимние каникулы

### 東（トウ・ひがし）— восток
**Актёры:** Солнце（日）за деревом（木).
**Спектакль:** Солнце встаёт ИЗ-ЗА дерева на востоке.
**Слова:** 東京（とうきょう）Восточная столица · 東口（ひがしぐち)

### 西（セイ・にし）— запад
**Актёры:** Птица в гнезде на закате.
**Спектакль:** На западе солнце садится — птица вернулась в гнездо.
**Слова:** 関西（かんさい）Кансай · 西洋（せいよう）Запад

## 5. Партия четвёртая: действия

### 行（コウ・ギョウ・い）— идти; ряд
**Актёры:** Перекрёсток дорог.
**Спектакль:** Две дороги пересекаются — куда идёшь? Спектакль «пересечение» = движение.
**Слова:** 学校に行く（いく)идти · 銀行（ぎんこう）банк · 行列（ぎょうれつ）очередь

### 来（ライ・く）— приходить
**Актёры:** Дерево с колосьями-руками.
**Спектакль:** Рис «приходит» сам к дому — дерево протягивает зёрна: «пришёл!»
**Слова:** 来る（くる）· 将来（しょうらい）будущее · 来週（らいしゅう）

### 帰（キ・かえ）— возвращаться
**Актёры:** Метель + метла + дом.
**Спектакль:** С метлой метель замела путь — но ты метлой же вымёл дорожку ДОМОЙ. Возвращение.
**Слова:** 帰る（かえる）· 帰国（きこく）вернуться в страну

### 見（ケン・み）— видеть
**Актёры:** Глаз（目）на ногах（儿).
**Спектакль:** Глаз поставили на ноги, чтобы смотрел издалека.
**Слова:** 見ます（みます)смотреть · 見せる（みせる）показывать · 意見（いけん)мнение

### 聞（ブン・き）— слышать; спрашивать
**Актёры:** Ворота（門）+ ухо（耳).
**Спектакль:** Ухо прижато к воротам: подслушивает, что за ними говорят.
**Слова:** 新聞（しんぶん)газета · 聞く（きく)слушать/спрашивать

### 食（ショク・た）— есть
**Актёры:** Крыша + добрый запас риса（良→食).
**Спектакль:** Под крышей — полный котёл: можно ЕСТЬ.
**Слова:** 食べる（たべる)есть · 和食（わしょく)японская кухня · 食堂（しょくどう)

### 飲（イン・の) — пить
**Актёры:** Еда（食)+ нехватка（欠).
**Спектакль:** Когда еды мало（欠), её ЗАПИВАЮТ: питьё восполняет.
**Слова:** 飲みます（のみます)пить · 飲み物（のみもの)напитки · 飲み会（のみかい)пьянка-корпоратив

### 読（ドク・よ) — читать
**Актёры:** Слова（言)+ продавать（売).
**Спектакль:** Чтец на площади ПРОДАЁТ слова вслух — читает громко.
**Слова:** 読みます（よみます)читать · 読書（どくしょ)чтение книг

### 書（ショ・か) — писать
**Актёры:** Кисть， проводящая линию через бумагу.
**Спектакль:** Кисть вертикально чертит по листу — каллиграфия.
**Слова:** 書きます（かきます)писать · 図書館（としょかん)библиотека · 辞書（じしょ)словарь

### 話（ワ・はな) — говорить
**Актёры:** Слова（言)+ язык（舌).
**Спектакль:** Язык производит слова — разговор.
**Слова:** 話します（はなします)говорить · 電話（でんわ)телефон「электро-речь」· 会話（かいわ)диалог

### 買（バイ・か) — покупать
**Актёры:** Сеть（罒)+ ракушки-деньги（貝).
**Спектакль:** Древние ловили сетью раковины-деньги и шли ПОКУПАТЬ.
**Слова:** 買います（かいます)покупать · 買い物（かいもの)шопинг

### 売（バイ・う) — продавать
**Актёры:** Тот же товар на витрине-подставке（士 поверх）.
**Спектакль:** Из покупателя стал продавцом：товар выставлен НА подставку — продаёт.
**Слова:** 売ります（うります)продавать · 売り場（うりば)отдел продаж

### 待（タイ・ま) — ждать
**Актёры:** Перекрёсток шагов（彳)+ храм（寺).
**Спектакль:** Идёшь по дороге мимо храма и ОСТАНАВЛИВАЕШЬСЯ — ждёшь.
**Слова:** 待ちます（まちます)ждать · 待ち合わせ（まちあわせ)встреча по договорённости

### 立（リツ・た) — стоять
**Актёры:** Человек стоит на земле.
**Спектакль:** Вид сверху：ноги расставлены на земле — стоит твёрдо.
**Слова:** 立ちます（たちます)стоять/вставать · 国立（こくりつ)государственный

### 休（キュウ・やす) — отдыхать
**Актёры:** Человек（人)+ дерево（木).
**Спектакль:** Уставший человек прислонился к дереву — отдыхает. Самая наглядная история!
**Слова:** 休みます（やすみます)отдыхать · 休日（きゅうじつ)выходной

### 会（カイ・あ) — встречаться
**Актёры:** Крыша + облака（云).
**Спектакль:** Встреча под облаком на крыше рынка：люди собираются ВМЕСТЕ.
**Слова:** 会います（あいます)встречаться · 会社（かいしゃ)фирма · 会議（かいぎ)совещание

### 社（シャ）— фирма; святилище
**Актёры:** Святилище（ネ)+ земля（土).
**Спектакль:** У святилища на земле собирались общины — так родились «компании» (и 神社 святилища).
**Слова:** 会社員（かいしゃいん)офисный работник · 神社（じんじゃ)святилище

## 6. Партия пятая: места и направления

### 上（ジョウ・うえ）— верх
**Спектакль:** Черта-ЗЕМЛЯ внизу, палец показывает ВЫШЕ неё.
**Слова:** 机の上（つくえのうえ)на столе · 上手（じょうず)умелый

### 下（カ・ゲ・した) — низ
**Спектакль:** Черта-земля СВЕРХУ, всё под ней — низ.
**Слова:** 下手（へた)неумелый · 部屋の下（へやのした)под комнатой

### 中（チュウ・なか) — середина
**Актёры:** Стрелка, пробившая центр мишени.
**Спектакль:** Стрела точно В ЦЕНТР квадрата-мишени.
**Слова:** 中国（ちゅうごく)Китай · 中学校（ちゅうがっこう)средняя школа · 中心（ちゅうしん)центр

### 外（ガイ・そと) — снаружи
**Актёры:** Вечер（夕)+ жезл гадателя.
**Спектакль:** Вечером гадание делают ЗА стенами дома — снаружи.
**Слова:** 外国人（がいこくじん)иностранец · 以外（いがい)кроме

### 国（コク・くに) — страна
**Актёры:** Рамка границ + яшма（玉).
**Спектакль:** Драгоценная яшма заперта внутри границ — вот и страна.
**Слова:** 外国（がいこく)· 国内（こくない)· 中国（ちゅうごく)

### 駅（エキ）— станция
**Актёры:** Лошадь（馬→馬）+ линейка мерила.
**Спектакль:** Старинные «станции» = конные посты через равные отрезки пути. Лошадь + мерило расстояний.
**Слова:** 東京駅（とうきょうえき)· 駅前（えきまえ)

### 車（シャ・くるま) — машина; колесо
**Актёры:** Повозка вид сверху：кузов + ось + два колеса.
**Спектакль:** Вид на телегу сверху：центральная ось и колёса по бокам.
**Слова:** 電車（でんしゃ)поезд · 自転車（じてんしゃ)велосипед · 車道（しゃどう)проезжая часть

### 道（ドウ・みち) — дорога
**Актёры:** Голова（首)+ движение（辶).
**Спектакль:** Головы идут по тропе — дорога для голов.
**Слова:** 北海道（ほっかいどう)Хоккайдо · 道路（どうろ)шоссе

### 店（テン・みせ) — магазин
**Актёры:** Хижина（广)+ доска гаданий（占).
**Спектакль:** В хижине висит вывеска-доска：это ЛАВКА.
**Слова:** 本屋？нет：店員（てんいん)продавец · 営業中（えいぎょうちゅう)открыто

### 家（カ・いえ/うち) — дом
**Актёры:** Крыша + свинья（豕 упрощ.).
**Спектакль:** Дом древнего японца = крыша + свинья в загоне. Дом там, где скотина.
**Слова:** 家族（かぞく)семья · お家（おうち)домик

## 8. Партия N4: продолжение спектаклей

### 動（ドウ・うご) — двигаться
**Актёры:** Тяжесть（重）+ мускул（力).
**Спектакль:** Чтобы сдвинуть тяжёлое, включается сила — движение!
**Слова:** 動きます（うごきます)двигаться · 自動（じどう)автоматический

### 働（ドウ・はたら) — работать
**Формула:** 人＋動.
**Спектакль:** Человек в движении = работает.
**Слова:** 働きます（はたらきます)работать · 働き者（はたらきもの)трудяга

### 習（シュウ・なら) — учиться (у кого-то)
**Актёры:** Крылья（羽)+ белый（白).
**Спектакль:** Птенец БЕЛОГО цвета учится летать — повторяет за мастером.
**Слова:** 習います（ならいます)учиться у кого-то · 練習（れんしゅう)тренировка

### 教（キョウ・おし) — учить
**Актёры:** Знания（孝）+ указка（攵).
**Спектакль:** Учитель с указкой передаёт знания.
**Слова:** 教えます（おしえます)учить/объяснять · 教室（きょうしつ)класс

### 問（モン・と) — вопрос
**Актёры:** Ворота（門)+ рот（口).
**Спектакль:** Стоишь у ворот и спрашиваешь входящего.
**Слова:** 質問（しつもん)вопрос · 問題（もんだい)задача

### 答（トウ・こた) — ответ
**Актёры:** Бамбук（竹)+ соединять（合).
**Спектакль:** Ответы писали на бамбуковых планках и СОЕДИНЯЛИ нитью — свиток-ответ.
**Слова:** 答えます（こたえます)отвечать · 正しい答え（ただしいこたえ)

### 経（ケイ・キョウ・へ) — проходить; экономика
**Актёры:** Нить（糸）сквозь станок.
**Спектакль:** Нити ПРОХОДЯТ сквозь ткацкий станок — время проходит так же.
**Слова:** 経験（けいけん)опыт · 経済（けいざい)экономика

### 験（ケン・ゲン）— испытание
**Актёры:** Лошадь（馬)+ проверка（僉).
**Спектакль:** Лошадь проверяют перед покупкой — испытание.
**Слова:** 試験（しけん)экзамен · 経験（けいけん)опыт

### 意（イ）— намерение; смысл
**Актёры:** Звук（音)+ сердце（心).
**Спектакль:** Истинный СМЫСЛ идёт от сердца через звук.
**Слова:** 意味（いみ)смысл · 意見（いけん)мнение · 注意（ちゅうい)внимание

### 味（ミ・あじ) — вкус
**Актёры:** Рот（口)+ ещё нет（未).
**Спектакль:** Вкус НЕИЗВЕСТЕН， пока не попробуешь ртом.
**Слова:** 味噌汁（みそしる)мисосуп · 意味（いみ)значение

### 数（スウ・かず) — число
**Актёры:** Рисовые зёрна（米)+ женщина（女)+ палочка счёта（攵).
**Спектакль:** Перебирают зёрна и СЧИТАЮТ вслух.
**Слова:** 数字（すうじ)цифры · 数える（かぞえる)считать

## 13. Частые ошибки при использовании историй

1. **Читать истории вместо запоминания знаков.** История — вход, а не место жительства. Через неделю закрывайте её и вспоминайте знак напрямую.
2. **Слишком сложные сюжеты.** История длиннее двух предложений забывает быстрее знака. Компактность!
3. **Игнорировать чтения.** Спектакль дал смысл, но чтения（он/кун) требуют отдельных карточек.
4. **Чужие истории без проигрывания.** Прочитали и пошли дальше = не работало. Представьте сцену ярко.
5. **Путаница похожих актёров.** 土 vs 士， 未 vs 末 — сверьте различия: земля (горизонталь длиннее внизу) vs самурай (вверху), незрелый vs конец.

## 16. Истории + Anki: связка

**Шаблон карточки с историей:**

```
Front: 待
Back (раскрытие по этапам):
  1. Спектакль: перекрёсток шагов + храм → жду.
  2. Значение: ждать
  3. Чтения: タイ／ま-
  4. Слово: 待ちます（まちます)
Tags: jp::kanji::n5::verbs::story
```

**Режим:** первые 3 показа читаете историю целиком; с 4-го — закрываете историю и вспоминаете знак напрямую. Когда вспомнили 5 раз подряд без истории — история уходит из карточки (или помечается серым).

**Почему это работает:** история создаёт «вход» через образное полушарие, а повторные прямые показы переводят знак в автоматическое узнавание. Оба канала задействованы.

## 29. Похожие кандзи — ловушки и разводка

| Пара/тройка | Отличие | Мнемо-разводка |
|-------------|---------|----------------|
| 待 vs 持 vs 時 | 彳 vs 扌 vs 日 | Ждать у храма (彳+寺), держать рукой (扌+寺), время солнца (日+寺) — один храм, три актёра слева |
|  blast? 土 vs 士 | Длина горизонтали | 土 земля — низ длинный (земля внизу), 士 самурай — верх длинный (шляпа самурая) |

| 刀 vs 力 | Изгиб | 刀 нож — острый изгиб, 力 сила — мускулистый изгиб |
| 千 vs 干 | Добавка | 千 тысяча — человек с чертой, 干 сухой — тоже но с другой историей |
| 目 vs 日 | Ширина | 目 глаз — узкий высокий, 日 солнце — широкий квадрат |
| 白 vs 自 | Точка | 白 белый — луч вверху, 自 сам — черта внутри |
| 休 vs 体 | 木 vs 本 | 休 отдых — дерево, 体 тело — корень/основа |
| 晴 vs 清 vs 情 | 日 vs 氵 vs 忄 | 晴 ясно (солнце), 清 чистый (вода), 情 чувство (сердце) — один звук セイ/ジョウ, три стихии |

2 末 верх длинный (=конец/верхушка), 未 короткий
3 待 = 彳 (движение/ожидание), 持 = 扌 (рука)

## 32. Порядок черт — режиссура каллиграфии (расширенно)

### Базовые правила

```
1. Сверху вниз
2. Слева направо
3. Горизонталь → вертикаль → точка
4. Центр → крылья
5. Рамка сначала, потом начинка, потом замыкание
6. Точка/маленький штрих — в конце
```

### Разборы знаков

#### 日 (4 черты) — окно для солнца
```
1. Левая вертикаль |
2. Верхняя горизонталь + правая вертикаль (угол)
3. Средняя горизонталь внутри
4. Нижняя горизонталь — замыкаем
```
Сюжет: строим раму, вставляем подоконник, закрываем.

#### 明 (8 черт) — солнце+луна
```
1-4. 日 как выше
5-8. 月: вертикаль, две горизонтали, замыкание
```
Сюжет: сначала солнце, потом луна рядом — светло!

#### 好 (6 черт) — женщина+ребёнок
```
1-3. 女: кувырок, горизонталь, диагональ
4-6. 子: верх, горизонталь, крюк
```
Сюжет: женщина обнимает ребёнка — нравится.

#### 国 (8 черт) — граница+яшма
```
1. Левая вертикаль границы
2. Верхняя горизонталь
3. Правая вертикаль с крюком (запираем!)
4-7. 玉 яшма внутри: горизонталь, вертикаль, точка, точка
8. Нижняя горизонталь — закрываем сокровищницу
```
Сюжет: яшму прячут в крепости.

#### 曜 (18 черт!) — солнце+крылья
Сюжет: солнце встаёт, крылья раскрываются — дни недели летят.

> Проговаривайте сюжет при каждом написании — рука выучит порядок через историю, а не через зубрёжку.


## 40. Пять строк в конце — повтор мантры

1. Кандзи — не каракули, а спектакль из знакомых актёров-ключей
2. Сначала труппа, потом сюжеты: без актёров истории рассыпаются
3. Чтения приклеиваются звуковыми якорями к сюжету
4. Через 40 историй конструктор работает сам — незнакомые знаки читаются по деталям
5. История — леса: автоматизировали знак — выбросьте историю
