## 1. Три хранилища памяти

```
Сенсорная (0.5–2 сек) → Кратковременная (~20 сек, 4–7 ячеек) → Долговременная (годы)
        ↑                      ↑ повторение + образы                    ↑
     забывается            без обработки — теряется               доступ через связи
```

**Ключевой факт:** кратковременная память держит всего ~4–7 единиц и стирает их за полминуты. Всё, что вы «учите», ещё НЕ выучено — оно в буфере.

**Перевод в долговременную требуют два условия:**

1. **Обработка смысла** — элемент должен быть связан с тем, что уже знаете
2. **Повторение с интервалами** — не подряд, а через растущие паузы

Мнемотехника = промышленные способы сделать условие №1 (образы/истории), а SRS автоматизирует №2.

**Проверьте на себе:** прочитайте ряд `7 4 1 9 2 8 5` и закройте. Сможете? Через минуту — вряд ли. А теперь так же прочитайте `1917-1945-1961`. Те же цифры, но сгруппированные в смыслы живут дольше. Это chunking (§8).

## 2. Кривая забывания Эббингауза

Немецкий психолог Герман Эббингауз (1885) измерял, как быстро стирается бессмысленная информация:

```
100% ┤●
     │  ●___
 60% ┤      ●___
     │          ●____
 40% ┤    через 20 мин ●___
     │                      ●____
 30% ┤   через 1 час              ●____
     │                                  ●____
 20% ┤  через 1 день                          ●______
     │                                                ●________
  0%  └──────┬──────┬──────┬──────┬──────┬──────┬──────
            20мин  1час   9часов  1день  2дня   6дней  31день
```

**Выводы, которые меняют учёбу:**

- Через **сутки** без повторения остаётся ~30% — то есть 70% вчерашнего труда испарилось
- Но! Каждый **своевременный** повтор сбрасывает кривую вверх и делает спад медленнее:

```
После 1-го повторения:  забывание медленнее
После 2-го:             ещё медленнее
После 3–4-х:           знание почти не падает неделями
```

**Отсюда золотые интервалы (для сложного материала):**

| Интервал | Что делаем |
|----------|-----------|
| через 20 мин | быстрый просмотр сразу после изучения |
| через сутки | первый настоящий повтор |
| через 3 дня | второй |
| через неделю | третий |
| через 2 недели | четвёртый |
| через месяц | пятый — материал почти вечный |

SRS-приложения (Anki, Quizlet) делают это автоматически — см. следующий раздел.

## 3. Интервальные повторения и SRS

### 3.1 Как работает алгоритм

Каждой карточке присваивается «лёгкость» и текущий интервал:

```
Правильный ответ легко  → интервал ×2.5 (например 6 дней → 15 дней)
Правильный с трудом     → интервал ×1.2
Ошибка                  → интервал сбрасывается до 10 минут
```

Так карточка с ошибками крутится часто, а выученная уходит на месяцы. Ваше время тратится только на проблемное.

### 3.2 Настройка Anki за 10 минут

1. Новых карточек в день: **10–15** (не больше!)
2. Максимальных повторов в день: **200**
3. Лёгкость новой карточки: 250% (стандарт)
4. Одна карточка = один вопрос = один факт. ❌ «Глагол 行く： чтения, формы, примеры» → ✅ три отдельные карточки

**Форматы карточек для японского (пример):**

| Лицевая | Оборот |
|---------|--------|
| 買う（чтение？） | かう — покупать |
| «покупать» (кандзи？) | 買う |
| 音：おと（перевод） | звук |
| （картинка крана） | 水道水を出す — включить воду |

### 3.3 Бумажная альтернатива: система Лейтнера

Если без телефона: 5 коробок.

```
Коробка 1: каждый день
Коробка 2: через день
Коробка 3: раз в 4 дня
Коробка 4: раз в неделю
Коробка 5: раз в две недели
Правильно ответил → карта переезжает в следующую коробку.
Ошибся → возвращается в коробку 1.
```

## 4. Формула сильного образа

Мозг цепляется за образы по пяти каналам. Чем больше включено — тем крепче след.

```
ЯРКОСТЬ (цвет, размер) +
АБСУРД (нарушение логики) +
ДВИЖЕНИЕ (что-то происходит) +
ЭМОЦИЯ (страх, смех, отвращение) +
МУЛЬТИСЕНСОРНОСТЬ (звук, запах, вкус)
= образ, который сам всплывает
```

**Сравните запоминание слова 猫（ねこ， кошка）:**

- ❌ Слабо: «нэко — это кошка». Просто перевод.
- ✅ Сильно: «Гигантский НЕОНовый КОт светится розовым в темноте и мурлычет громко как дрель». (звуковая опора «нэ-ко» + абсурдный светящийся кот)

**Разбор формулы на примере 食べる（たべる， есть）:**

- Звуковой якорь: «ТАБЕЛь»
- Образ: На огромном ТАБЛЕ написано меню, и вы едите прямо со столешницы
- Эмоция: голод до дрожи, еда пахнет невероятно

Через день вспомните слово «табель» → всплывёт картинка → всплывёт табэру. Цепочка работает задом наперёд.

## 5. Метод связей

Задача: запомнить СПИСОК элементов в порядке. Решение — сшить их одной историей, где каждый элемент «цепляет» следующий.

**Пример: запомнить ряд глаголов движения 行く・来る・帰る・見る・聞く**

История: «Вы ИДЁТЕ (行く) навстречу другу, он ПРИХОДИТ (来る) вам навстречу, потом вы вместе ВОЗВРАЩАЕТЕСЬ (帰る) домой, там СМОТРИТЕ (見る) фильм и СЛУШАЕТЕ (聞く) музыку».

Правила цепочки:

1. История ровно в порядке списка
2. Между звеньями физический контакт (пришёл → вернулись ВМЕСТЕ)
3. Абсурд приветствуется: пусть друг приедет на коте

**Ограничение метода:** до ~15–20 звеньев. Длиннее — история рассыпается; тогда делите список на главы или используйте дворец (§6).

## 6. Дворец памяти

Метод локусов — король мнемоник, ему >2000 лет (Цицерон держал в голове речи по колоннам форума).

### 6.1 Строим дворец за 10 минут

1. Возьмите ЗНАКОМОЕ место: вашу квартиру, дорогу в школу/офис
2. Разметьте **10–15 локусов** в фиксированном порядке:
   - входная дверь → коридор → вешалка → кухня → холодильник → стол → окно → диван → ванная → кровать
3. Пройдите маршрут мысленно 2–3 раза ДО загрузки информации — путь должен стать автоматическим

### 6.2 Загружаем информацию

Каждый элемент кладём в свой локус ярким образом.

**Пример: 10 слов урока 1 (家族， 父， 母， 兄， 姉…)**

| Локус | Слово | Картина |
|-------|-------|---------|
| дверь | 家族（かぞく）| На двери висит табличка «КАЗОК-семья», вся семья выглядывает |
| коридор | 父（ちち）| Папа ЧИСТИТ обувь в коридоре |
| вешалка | 母（はは）| Мама висит на вешалке вместо куртки, машет ХА-ха |
| кухня | 兄（あに）| Старший брат АНИме-голосом поёт на кухне |
| холодильник | 姉（あね）| В холодильнике сидит сестра и АНЕкдоты травит |

Вспоминание: идёте маршрутом → каждая комната выдаёт слово.

### 6.3 Правила эксплуатации

- Один дворец = одна тема. Вторая тема → второй дворец (дом друга, работа, школа)
- 5–7 дворцов хватит надолго; их можно «переиспользовать» после полного стирания старого содержимого
- Обход всегда в ОДНОМ направлении
- Для экзаменов кладите по локусу блок вопросов, а не отдельные факты

### 6.4 Прокачка: миниатюризация

Представляйте предметы ГИГАНТСКИМИ (холодильник размером с дом) или микроскопическими (семья муравьёв в шкафу). Масштабная деформация — усилитель памяти.

## 7. Числа-пеги и Major-система

Числа — худший материал для памяти (абстракция без образов). Решение — превратить цифры в слова-крючки.

### 7.1 Рифмованные пеги (быстрый старт)

| Цифра | Пег | Образ |
|-------|-----|-------|
| 1 | один → ГОНЕЦ | гонец с письмом |
| 2 | два → ДРОВА | полено |
| 3 | три → ТРИко | колготки |
| 4 | четыре → ЧЕТЫРЕ стула | стул |
| 5 | пять → ПЯТНО | клякса |
| 6 | шесть → ШЕСТ | шест |
| 7 | семь → СЕМЬя | семья |
| 8 | восемь → ВОСЕМЬ ног паука | паук |
| 9 | девять → ДЕВЯТЬ планет | планета |
| 10 | десять → ДЕСЯТЬ пальцев | перчатка |

Запомнить список из N пунктов: привяжите пункт №3 к ТРИко («в трико пришёл учитель 読む»).

### 7.2 Major-система (для серьёзных объёмов)

Каждой цифре — согласный звук:

```
0 = с/з    1 = т/д    2 = н    3 = м
4 = р      5 = л      6 = ш/ж/ч
7 = к/г    8 = ф/в    9 = п/б
```

Число → слово из этих согласных + любые гласные:

```
34 → М + Р → «МОРе»     41 → Р + Т → «РАТа»
79 → К + П → «КАПуста»  92 → П + Н → «ПИНа»
```

Теперь год, номер телефона, дата экзамена превращаются в картинку. Японские счётные суффиксы тоже можно так заземлить: 三人（さんにん）→ пег 3 «ТРИко» + «НИть» — в трико запутались трое.

## 8. Акростихи, акронимы, chunking

**Акроним** — слово из первых букв. Японские группы глаголов:

> Группа **1**: う-ряд… запомните фразу «**У**сатый **К**от **Р**оняет **С**тол» = У・К・Р・С ряды うつる / むぶぬ / くぐ / す меняются по группе 1.

**Акростих** — стих, где первые буквы строк дают последовательность. Порядок частиц темы-подлежащего-объекта:

```
Тема всегда первая,
После неё — субъект,
Объект ближе к действию,
Глагол замыкает круг.
```

**Chunking** — группировка. Номер `09012345678` держать невозможно; `090-1234-5678` — легко. Правила:

- Разбивайте на куски по 3–4 элемента
- Давайте каждому куску ярлык (год, имя, действие)
- Учите куски отдельно, потом склеивайте

Пример для японского: спряжение 行く не зубрить списком, а чанками по формам: [て/た] → [ない] → [ば/たら] → [命令].

## 9. Keyword-метод

Главный метод лексики для любого языка:

```
1. Иностранное слово → найти русское похожее ЗВУЧАНИЕ (keyword)
2. Связать keyword и перевод одной картинкой
```

**Примеры (русский → японский):**

| Слово | Звучание | Keyword | Картина |
|-------|----------|---------|---------|
| 猫 neko кошка | «нэко» | НЕКОт | НЕ настоящий КОт, а неоновый |
| 山 yama гора | «яма» | ЯМА | Яма наоборот — торчит горой вверх |
| 駅 eki станция | «эки» | ЕКни | ЕКнул от грохота поезда на станции |
| 目 me глаз | «мэ» | МЭня | МЕНЯ разглядывают глазами |
| 手 te рука | «тэ» | ТЕло | ТЕло заканчивается рукой |
| 口 kuchi рот | «кути» | КУсать ЧИстым | КУсать ЧИстыми зубами ртом |

Подробные таблицы: [universal-vocabulary.md](universal-vocabulary.md) *(в разработке)* и японские приложения: [kana-japanese.md](kana-japanese.md), [kanji-stories.md](kanji-stories.md).

## 10. Применение: программирование

**Синтаксис через истории.** Например Rust borrow checker:

> «Значение — это КОТ. Один хозяин держит кота (ownership). Друзья могут ПОГЛАДИТЬ кота (&borrow), но пока гладят — никто не может забрать кота себе (mutable borrow). Забрать можно только когда все руки убраны». 

**Порядок операций, паттерны, алгоритмы:**

- Бинарный поиск: «БИБЛИОТЕКАРЬ делит шкаф пополам и спрашивает: левее или правее?»
- Хеш-таблица: «ГАРДЕРОБЩИК по номеру жетона мгновенно выдаёт пальто»
- Git rebase: «Вы переписываете историю семьи так, будто все дети родились от новой мамы»

Правило то же: абстракция → знакомый образ с механикой.

## 11. Применение: книги и лекции

**Конспект-дворец:** каждой главе книги — комната вашего жилья. Прочитали главу → разложили 3–5 тезисов по локусам комнаты. Пересказ главы = обход комнаты.

**Фейманов приём** (дополнение): объясните главу воображаемому 12-летнему. Где запнулись — там дыра понимания; туда возвращайтесь.

**Лекции в реальном времени:**
1. Слушаете тезис → мгновенно рисуете мини-образ (2 секунды)
2. Привязываете образ к текущему локусу аудитории (доска → окно → дверь)
3. После лекции — обход помещения восстанавливает 80% материала

## 12. Имена людей

Схема «Лицо → Звук → История»:

1. Услышали имя **田中さん（Танака）**
2. Ищете русское звучание: «ТАНЦуют НА КАчелях»
3. Находите примету лица (большой нос)
4. Склеиваете: «Этот человек с большим носом ТАНЦУЕТ НА КАЧЕЛЯХ»
5. При прощании мысленно повторяете картину

Работает и для терминов: **かたかな（катакана）** → «КАТАется на КАНАте» — катакана скользкая, угловатая.

## 13. Мифы о памяти

| Миф | Реальность |
|-----|-----------|
| «У меня плохая память» | Память — навык. Техники дают +200–500% любому |
| «Лучше учить перед сном много часов подряд» | Зубрёжка подряд даёт кривую Эббингауза без спасения; интервалы решают |

| «Образы — для детей» | Чемпионы мира по запоминанию — взрослые инженеры и врачи |
| «Anki заменит понимание» | SRS хранит факты; понимание строится задачами и текстами. Нужны оба |

## 15. Наука: что происходит в мозге

**Кодирование (encoding).** Информация превращается в нервный след только при внимании. Читаете «вполглаза» — следа нет вообще. Поэтому пассивное перечитывание учебника почти бесполезно: глаза пробежали, след не записан.

**Консолидация.** След стабилизируется во сне (особенно глубокие фазы) — гиппокамп «переигрывает» дневное в кору. Практический вывод: учить перед сном = бесплатная ночная консолидация; всенощные зубрёжки уничтожают сам механизм запоминания.

**Тестирование (testing effect).** Попытка ВСПОМНИТЬ укрепляет след сильнее повторного чтения в 2–3 раза. Отсюда правило Anki: сначала вспомнить, потом перевернуть карточку. И правило учёбы: закрыть конспект → воспроизвести по памяти → сверить.

**Интерливинг (перемешивание).** Блоки «час грамматики → час лексики» хуже, чем чередование каждые 15 минут: смешение типов задач заставляет мозг постоянно переключать контекст, что углубляет обработку.

**Нужная трудность (desirable difficulty).** Если вспоминается слишком легко — пользы мало. Слегка трудное вспоминание (через сутки, а не сразу) даёт максимальный прирост. Не бойтесь, что «уже забываю» — это нормальная рабочая зона.

## 16. Грамматика через образы (японский полигон)

Частицы — вечная боль новичков. Решение: каждой частице — маскот.

| Частица | Маскот | История |
|---------|--------|---------|
| は | ХАЛАТ | Тема надевает халат: «в этом халате сегодня говорим о…» |
| が | ГОЛУБЬ | Голубь ВЫЛЕТАЕТ как субъект действия: 猫が来た — голубь-кот прилетел |
| を | ОСЁЛ | Осёл несёт объект на спине: 本を読む — книга на осле |
| に | НИТЬ | Привязывает к точке: время/место назначения пришиты ниткой |
| で | ДЕЛО | Дело делается ЗДЕСЬ: площадка действия |
| の | НОША | Ноша принадлежит: 私の本 — ноша моя |
| と | ТОПОР | Вместе рубят одним топором: 友達と行く |

Теперь предложение собирается как мультфильм: студент в халате（は）→ голубь-экзамен（が）→ осёл со шпаргалкой（を）→ нитка ко времени（に）→ топор пары（と）.

**Формы глагола — дом этажей:**

```
3 этаж: 〜たら・ば・なら   (крыша — условия)
2 этаж: て・た            (жилая зона — мосты)
1 этаж: う / ます / ない  (фундамент)
```

Спрягая, вы просто поднимаетесь на нужный этаж здания 行く.

## 17. Генератор звуковых якорей: алгоритм

Не приходит образ? Прогоните слово по алгоритму:

```
Шаг 1. Выпишите звучание русскими буквами: ねこ → нэ-ко
Шаг 2. Подберите русские слова, СОДЕРЖАЩИЕ этот звуковой кусок:
        нэ… → НЕбо, НЕКОт, НЕвежда
        …ко → КОшка, КОрона
Шаг 3. Выберите пару слов так, чтобы перевод был внутри:
        НЕКОт (перевод: кот) ✓ идеально
Шаг 4. Если прямого совпадения нет — допустим «кривой» якорь:
        やま（яма）гора → ЯМА, но вверх ногами
Шаг 5. Постройте картинку из keyword + перевода.
```

## 18. Расширенный дворец: полный тур

Дворец из §6 на практике. Загружаем **10 конструкций грамматики N4**:

| Локус | Конструкция | Картина |
|-------|-------------|---------|
| дверь | たら | На двери висит табличка «ЕСЛИ дождь — не входить» |
| коврик | ば | На ковре логическое «если-то» стрелками |
| зеркало | なら | В зеркале отражается тема разговора: «насчёт Киото?» |
| вешалка | ても | На вешалке куртка «ДАЖЕ ЕСЛИ дождь» |
| холодильник | ことがある | Опыт заморожен: «уже ЕЛ такое» наклейка |
| плита | てしまう | Кастрюля убежала — сожаление «съела всё!» |
| чайник | ておく | Чайник кипятится ЗАРАНЕЕ к приходу гостей |
| стол | ようになる | Стол-трансформер: «НАУЧИЛСЯ» читать кандзи |
| окно | そうだ(слух) | За окном сосед кричит: «ГОВОРЯТ, будет дождь!» |
| диван | そうだ(вид) | На диване тортик — ВЫГЛЯДИТ вкусно |

Правило тура: обходить строго дверь→диван, каждый локус = одна вспышка картинки. Через сутки пройдите тур без подсказок; провисший локус — перерисуйте картинку ярче.

## 19. Типичные ошибки новичков

1. **Чужие образы без проработки.** Прочитали готовую мнемонику, не представив картину — эффекта ноль. Образ обязан проиграться в голове.
2. **Слишком длинные истории.** Связка из 30 звеньев рассыпается; режьте списки на куски ≤10.
3. **Мнемоника вместо практики.** Выучили образ слова, но ни разу не сказали его вслух в фразе — язык не заработает. Образ = вход, практика = закрепление.
4. **Перегруз Anki.** 50 новых карточек в день → через неделю тонны просроченных повторов → демотивация → сброс. Норма 10–15.
5. **Одна техника на всё.** Комбинируйте: числа — пеги, список — цепочка, структура — дворец, слово — keyword.
6. **Хранение мусора.** Карточку, которая не нужна для цели («а вдруг пригодится»), удаляйте. Память любит порядок.

## 23. Физиология памяти

Память — биология, а не только техники.

**Сон.** 7–9 часов; глубокие фазы консолидируют факты, REM — навыки и эмоциональную окраску. Учить сложное вечером + утренний повтор = эффективная связка. Недосып 4 часа обнуляет выгоду даже идеальной мнемоники.

**Движение.** 20 минут ходьбы после занятия улучшают запоминание (эффект Блейделя). Карточки можно повторять на прогулке.

**Питание.** Стабильный сахар > энергетики. Омега-3, вода; кофеин — за 20–30 мин ДО сессии, не позже чем за 8 часов до сна.

**Стресс.** Кортизол блокирует гиппокамп: паника перед экзаменом физически мешает вспомнить. Помогают дыхание 4-7-8 и то самое тестирование в спокойных условиях заранее.

**Возраст.** Пластичность сохраняется всю жизнь; меняется только скорость кодирования — взрослым нужно чуть больше повторений, но зато они лучше связывают новое со структурой знаний.

## 26. FAQ

**Сколько времени уходит на придумывание образов?**
Новичку 1–2 минуты на слово, опытному 15–30 секунд. При регулярной практике генерация становится рефлексом.

**Что если образ забывается?**
Значит, он недостаточно абсурден/личен. Перерисуйте: добавьте движение, звук, эмоцию или впишите себя самого в картину.

**Лучше готовые мнемоники или свои?**
Свои сильнее на 30–50% (личный опыт цепляется крепче). Готовые — быстрый старт; свои — долгосрочная стратегия.

**Можно ли мнемоникой выучить язык без грамматики?**
Нет. Мнемотехника ускоряет лексику и знаки; грамматика строится правилами, вводом (чтение/слушание) и практикой речи. Это инструмент №1 из набора, а не весь набор.

**Как часто пересматривать дворцы?**
Первые 3 дня ежедневно, затем интервалы 7 → 21 день. Пустеющий дворец переиспользуйте под новый материал.

**Образы придумывать лень — можно жить без мнемоник?**
Можно, но в 3–5 раз медленнее на фактурном материале (лексика, кандзи, термины). Для понимания тем (грамматика концептуально) техники нужны меньше.

**Сколько карточек оптимально держать в колоде?**
Личный комфорт обычно 500–3000 активных. Дальше растёт ежедневная нагрузка; лучше «выпускать» выученное (suspend) и держать рабочее ядро.

**Мнемоника портит естественную речь?**
Нет: образ нужен только при первом входе слова. После 10–20 живых употреблений слово всплывает напрямую, минуя картинку.

**Что делать при плато прогресса?**
Сменить тип нагрузки: если только карточки — добавить чтение вслух и дворцы; если только ввод — вернуться к тестированию. Плато = сигнал однообразия.

## 30. Метрики прогресса

Как понять, что техники работают? Замер раз в неделю:

| Метрика | Как считать | Цель через месяц |
|---------|-------------|------------------|
| Удержание через 24 ч | выучили 20 новых → вспомнили завтра | ≥80% |
| Скорость генерации образа | секундомер: слово → готовый образ | ≤60 сек |
| Объём Anki-повторов в срок | просроченных карточек | <5% |
| Дворец: полный обход без ошибок | таймер | стабильное прохождение |
| Свободный пересказ файла | 3-минутный рассказ после прочтения | без заглядывания |

Ведите простую таблицу в заметках: дата / метрика / значение. Рост цифр мотивирует лучше любых обещаний.

## 32. Полный разбор: урок японского от и до

Собираем все техники в один конвейер. Задача: выучить материал урока 6 (телефон, ている， приглашения).

**Шаг 0. Подготовка (2 мин).** Откройте диалог урока. Цель сессии: 12 новых слов + 3 грамматики. Больше — не брать.

**Шаг 1. Первый проход со смыслом (5 мин).** Читаете диалог целиком. Не учите! Просто понимаете сцену: Алиса звонит Танаке, договариваются о музее. Сюжет = каркас, на который ляжет всё.

**Шаг 2. Лексика → keyword-образы (10 мин).**

| Слово | Якорь | Картинка |
|-------|-------|----------|
| 掃除（そうじ）уборка | «СОсиСКА» | Вы вытираете пол сосиской вместо швабры |
| 美術館（びじゅつかん）музей | «БИЖУтерия» | Музей, где вместо картин — бижутерия |
| チケット билет | «ТИКет» | Уже есть; билет = тикет |
| 予報（よほう）прогноз | «Ёж ПРОГНОЗирует» | Ёж с синоптической картой |
| 晴れる（はれる）проясниться | «ХА-ЛЕНивый» | Ленивое солнце наконец встало |

Каждую картинку проживаете 5 секунд с эмоцией.

**Шаг 3. Грамматика через маскотов (7 мин).**

- ている → кот СПИТ на коврике (состояние длится): 今、食べている
- ておく → белка ЗАРАНЕЕ прячет орех: 買っておく
- ませんか → официант: «НЕ желаете ли?»

**Шаг 4. Диалог вслух за обоих (4 мин).** Читаете реплики, интонацию копируете. Слова из шага 2 сами встают на места.

**Шаг 5. Дворец (5 мин).** Загружаете 12 слов по маршрутам квартиры. Обход ×2.

**Шаг 6. Карточки Anki (5 мин).** 12 слов + 3 грамматические карточки («заполните пропуск»). Теги: jp::n4::unit06.

**Шаг 7. Активный тест (5 мин).** Закрыли всё. Перескажите сюжет диалога ПО-ЯПОНСКИ максимально примитивно. Запишите себя на диктофон.

**Итого 33 минуты.** Назначены повторы: завтра (карточки), через 3 дня (дворец), через неделю (пересказ). Всё, урок «закатан» по всем канонам этого файла.

**Что НЕ делать:** перечитывать диалог 5 раз подряд; учить слова списком без образов; открывать новые уроки до повторов текущего.

## 33. Экспресс-справка техник (одна страница)

| Техника | Для чего | Якорная фраза |
|---------|----------|----------------|
| Keyword-метод | отдельные слова | «звучание → русское слово → картинка» |
| Метод связей | список ≤15 в порядке | «история-цепочка с контактом звеньев» |
| Дворец памяти | структура, выступления, главы | «маршрут + образ в каждом локусе» |
| Числа-пеги | короткие нумерованные списки | «рифма цифре = крючок» |
| Major-система | телефоны, даты, формулы | «цифра→согласный→слово» |
| Акростих | порядок правил/этапов | «фраза из первых букв» |
| Chunking | длинные последовательности | «группы по 3–4 + ярлык» |
| Кандзи-спектакль | составные иероглифы | «ключи-актёры играют историю» |
| Протеже-эффект | закрепление темы | «объясни утке за 3 минуты» |
| Интерливинг | смешение тем в сессии | «грамматика→лексика→чтение по кругу» |
| Testing effect | закрепление всего | «сначала вспомни, потом проверь» |

## 34. Мнемоника вне учёбы: быт

**Пароли.** Не «P@ss123», а предложение-образ: «3 синих кота пили чай на Фудзи» → `3Kota4ayFuji` (цифры — из истории, слова — с заглавных). Запоминается как сцена, взламывается плохо.

**PIN и короткие коды.** Major-система: 4913 → Р+П+Т+М → «РеПТилии» — картинка рептилии на банковской карте.

**Список покупок без бумаги.** Дворец по маршруту магазина: вход → молоко разлилось у двери; овощной отдел → брокколи-инопланетянин; касса → хлеб-подушка лежит на ленте. В магазине просто идёте своим дворцом.

**Маршруты.** Новая дорога: привяжите 4–5 опорных точек к уже знакомому направлению («светофор = нос дворца»), ошибки навигации исчезают.

**Куда положил ключи.** Кладёте предмет — произнесите вслух действие и представьте ВЗРЫВ взаимодействия: «ключи ПАДАЮТ в миску со звоном». Взрывная картинка утром вспомнится мгновенно.

**Дни рождения.** Месяц = этаж дома (январь — первый), число = пег-цифра на этом этаже. ДР друга 23.07 → третий этаж, у двери сидит ДРАКОН (2+3) с июльским арбузом.

**Иностранные имена коллег.** Лицо → звук → история (см. §12), плюс мгновенное использование имени в ответной реплике («Приятно, Хироси!») — двойное кодирование: слух + речь.

**Речи и тосты.** Каркас выступления = 5 локусов комнаты: вход (приветствие) → окно (зачем собрались) → стол (главный тезис) → шкаф (история-пример) → дверь (призыв к действию). Тост на свадьбе больше не читается с салфетки.

**Списки дел дня.** Утром: 5 дел → цепочка-связка (§5) или 5 пегов (§7). Вечером: обход — что сделано. Забытых дел при этом почти не остаётся, а список в телефоне становится страховкой, а не костылём.

**Учёба в транспорте.** Карточки Anki едут с вами: вибрация «правильно/неправильно» позволяет тренироваться не глядя в экран. 20 минут метро = дневная норма повторов.

**Забыли, зачем пришли в комнату?** Восстановите входную мысль: где стояли, что делали за секунду до (дверь → образ). Дверные проёмы стирают рабочую память — потому и помогает «вернуться к двери».

**Рецепты и последовательности.** Этапы рецепта — дворец по кухне: холодильник (достать) → мойка (помыть) → доска (порезать) → плита (жарить) → стол (подать). Любая инструкция из 5–8 шагов ложится на маршрут без списка.

**Учебные карточки самому себе на день.** Вечером выпишите 3 главных факта дня на 3 стикера, расклейте: зеркало, чайник, дверь. Утром обход — факты ушли в долговременную ещё до Anki.

**Телефонные разговоры.** Договорённости по ходу звонка фиксируйте пегами: «1 — перезвонить (гонец), 2 — счёт (дрова)». После трубки — сразу в список дел, пока цепочка свежа.

**Режим дня без будильника привычек.** Утренний ритуал как дворец из 6 локусов: будильник → вода → зарядка → душ → завтрак → план на день. Через две недели тело идёт маршрутом само — решения не тратятся.

**Экзамены: распределение билетов.** Билеты → дворец по аудитории: каждый локус = один вопрос с тезисом-картинкой. На экзамене мысленно сидите в этой же комнате и читаете ответы со стен.

**Стирка: не забыть вещь.** Забирая бельё, представьте забываемую вещь КРИЧАЩЕЙ в барабане («не забыть носки!»). Голос из стиральной машины вспомнится у двери.

**Лекарства по расписанию.** Таблетка утро/вечер = два пега: гонец на чайнике утром, дрова у кровати вечером. Приняли — картинку «сожгли». Не сожгли — не приняли.

## 35. Гигиена Anki-колоды: источники провалов

| Ошибка | Симптом | Лечение |
|--------|---------|---------|
| Одна карточка = много фактов | постоянные «почти помню» | дробить до одного факта |
| Нет примеров | слово знаете, не используете | поле «пример» обязательно |
| Дубли | отвечаете по соседней карточке | чистка дублей раз в месяц |
| Слишком длинный интервал после угадывания | «выучил», а через неделю пусто | честное «трудно» вместо «легко» |
| Учить чужие готовые колоды целиком | тонна лишнего | брать чужое только под свою цель |
| Пропуск недели | гора просроченных повторов | лимит показа 200/день спасает |

> Метрика здоровья колоды: доля карточек в статусе «зрелые» (интервал >21 день) растёт от недели к неделе. Стоит на месте — вы учите слишком много нового и мало повторяете старого.

## 36. Стихи, цитаты, скороговорки

**Стихотворение наизусть (алгоритм):**

1. Прочитайте вслух целиком 2 раза — общий ритм
2. Первый блок из 2 строк: прочитайте → закройте → воспроизведите по памяти
3. Второй блок так же; затем сшейте блоки 1+2 без подглядывания
4. Добавляйте по 2 строки, каждый раз прогоняя всё с начала
5. Вечером — полный проход; завтра — ещё один

Ключ — «сшивание» после каждого добавления: мозг учит не куски, а переходы.

**Цитаты.** Дворец: каждая цитата живёт у своего локуса («у холодильника — Ницше про бездну»). Автор привязывается к предмету одной буквой.

**Японские скороговорки как тренажёр произношения:**

```
隣の客はよく柿食う客だ
（となりのきゃくは よく かきくう きゃくだ）
«Сосед — гость, который часто ест хурму»
Тренирует: кя/кё, ка/ку, различие слогов.
```

```
赤巻紙青巻紙黄巻紙
（あかまきがみ あおまきがみ きまきがみ）
«Красный свиток, синий свиток, жёлтый свиток»
Тренирует: ака/ао/ки + маки — скоростной переключатель гласных.
```

Режим: медленно ×3 → темп ×3 → максимум скорости ×3. Записывайте себя раз в неделю — прогресс слышен.

**Числа-даты экзаменов.** Major-система: дата JLPT 6 декабря → 6=Ш/Ж, 12=Т+Н → «ШЁЛ ТЫНЬкать декабрём» — картинка: вы идёте вдоль тына с билетом.

## 37. Итоги файла в пяти строках

1. Память любит образы и ненавидит списки — рисуйте, а не зубрите
2. Кривая Эббингауза обманывается только интервалами — настройте SRS
3. Вспоминание сильнее перечитывания — тестируйте себя до сверки
4. Дворец для структуры, цепочка для списков, keyword для слов
5. Сон и движение — половина результата; техники — вторая половина
