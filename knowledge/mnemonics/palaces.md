# Каталог дворцов памяти（10 готовых маршрутов)

> **Зачем каталог:** строить дворец с нуля каждый раз тяжело. Здесь —— десять ГОТОВЫХ размеченных маршрутов с примерами загрузки под разные задачи. Берите как есть или перекрашивайте под себя.
>
> **Формат каждого дворца:** разметка локусов → правила обхода → примеры загрузки（список / структура / факты).
>
> Связанные материалы: [Классический курс §5](classic-mnemonics.md) · [Рабочая тетрадь](practice-workbook.md) · [Главная учебника](index.md)

---

## Правила использования каталога

```
1. Выбирайте дворец под ЗАДАЧУ, а не наоборот（см. таблицу ниже)
2. Прогоните порожняком ×2 ДО загрузки
3. Один дворец = одна тема; не смешивайте
4. После «жизни» контента —— ритуал стирки（§12)
5. Личная перекраска сцен обязательна：готовые сцены —— каркас
```

### Соответствие задача → дворец

| Задача | Рекомендуемый дворец |
|--------|----------------------|
| План недели | №1 Квартира |
| Экзаменационный курс | №3 Учёба |
| Тезисы доклада | №5 Офис |
| Регулярные справочные данные | №4 Маршрут |
| Список покупок | №6 Магазин |
| Имена новых знакомых | любое место встречи! |

# Дворец №1: Квартира（главный)

Самый надёжный маршрут —— знаете его лучше всего. 15 локусов:

## Разметка

```
 1. Входная дверь
 2. Коврик
 3. Зеркало в прихожей
 4. Вешалка с одеждой
 5. Полка обуви
 --- переход на кухню ---
 6. Холодильник
 7. Плита
 8. Обеденный стол
 9. Окно кухни
 --- переход в комнату ---
10. Диван
11. Телевизор / рабочий стол
12. Книжная полка
13. Окно комнаты
14. Балконная дверь
15. Кровать
```

**Обход:** всегда от входа к кровати, по часовой стрелке внутри комнат.

## Загрузка А: план недели（7 дел)

| Локус | Дело | Сцена-образ |
|-------|------|-------------|
| 1 Дверь | оплатить интернет | дверь опутана синими проводами, роутер пищит |
| 2 Коврик | забрать посылку | ковёр = почтовый мешок, из него торчат коробки |
| 3 Зеркало | записаться к стоматологу | зеркало показывает зубную улыбку крупным планом |
| 4 Вешалка | сдать вещи в химчистку | куртки с бирками «химчистка» летают по коридору |
| 5 Обувь | купить кроссовки | полка обуви выросла до потолка |
| 6 Холодильник | сварить суп на неделю | холодильник полон кастрюль с супом |
| 7 Плита | позвонить бабушке | бабушка сидит на плите и болтает по телефону |

Вечером пятницы —— обход: все семь дел всплывают сами.

## Загрузка Б: структура доклада（8 тезисов)

Тема「Почему компании нужен корпоративный блог」:

| Локус | Тезис | Сцена |
|-------|-------|-------|
| 1 Дверь | Клиенты ищут нас в интернете | Из двери вылетает гигантская поисковая строка |
| 2 Коврик | Конкуренты уже пишут | На коврике лежит толстый блог конкурента |
| 3 Зеркало | Блог = доверие | В зеркале мы эксперты в белых халатах |
| 4 Вешалка | SEO бесплатно | Вешалка увешана ссылками вместо одежды |
| 5 Обувь | Контент продаёт сам | Туфли сами рассказывают о скидках |
| 6 Холодильник | Кейсы клиентов | Холодильник полон историй успеха |
| 7 Плита | Метрики роста | На плите график пламени растёт вверх |
| 8 Стол | Призыв: начнём завтра! | На столе подписанный контракт |

# Дворец №2: Дом детства（эмоциональный резерв)

Детские места заряжены эмоциями —— самые прочные якоря. 12 локусов:

## Разметка

```
 1. Калитка / подъезд
 2. Лестница（ступени = подпункты!)
 3. Дверь квартиры
 4. Коридор с ковром
 5. Кухня（запах бабушкиных пирогов)
 6. Ваша детская комната

 8. Подоконник
 9. Родительская спальня
10. Ванная
11. Балкон
12. Тайное место（за шкафом / под кроватью)
```

**Сила дворца:** каждая локация уже пропитана воспоминаниями —— образы цепляются мгновенно.

## Загрузка А：исторические даты

| Локус | Дата/событие | Сцена |
|-------|--------------|-------|
| 3 Дверь | 1147 —— первое упоминание Москвы | На двери висит афиша юбилея（1147 лет!) |
| 5 Кухня | 1703 —— Петербург основан | Бабушка печёт ПЕТРОВСКИЙ пирог в форме кораблика |
| 6 Комната | 1961 —— полёт Гагарина | Над кроватью（детской) висит портрет космонавта |
| 9 Спальня | 1812 —— Бородино | На родительской кровати —— сражение солдатиков |
| 11 Балкон | 1945 —— Победа | С балкона видно салат？ нет —— САЛЮТ Победы |

## Загрузка Б：список литературы на лето

Каждая книга —— автор-персонаж в своём локусе：


# Дворец №3: Школа / Университет（учебный)

Лучший для экзаменационных курсов. Разметьте по аудиториям и кабинетам：

## Разметка（пример университета)

```
 1. Главный вход
 2. Гардероб
 3. Коридор первого этажа
 4. Аудитория 101
 5. Аудитория 102
 6. Столовая
 7. Библиотека
 8. Лестница на второй этаж
 9. Аудитория 201
10. Кабинет декана
11. Спортзал
12. Выход во двор
```

## Загрузка：экзаменационный курс「История」

Каждый билет = аудитория， внутри —— тезисы-картины：

| Локус | Билет | Внутри |
|-------|-------|--------|
| 101 | Реформы Петра I | Император стрижёт боярам бороды ножницами-указами; окно в Европу распахнуто как окно аудитории |
| 102 | Отечественная война 1812 | На доске карта с горящей Москвой; Наполеон убегает на лыжах? нет —— замерзает |
| Столовая | Великие реформы Александра II | За столом освобождённые крестьяне едят борщ свободы（1861) |
| Библиотека | Промышленный переворот | Паровые машины стоят между стеллажей |
| Декан | Революция 1905 | Декан в крови？ нет —— с петицией «Кровавое воскресенье» |

> 💡 **Приём «дверь билета»:** номер аудитории = номер билета（если билетов ≤ числа комнат). На экзамене вытянули №17 → мысленно идёте к комнате 17.

Остановки/станции вашего ежедневного пути = постоянные локусы для справочных данных, которые нужны регулярно.

## Разметка（пример: путь на работу)

```

 6. Парк
 7. Вторая развилка
 8. Школа по пути
 9. Заправка
10. Вход в офис
```

## Загрузка：постоянные данные

**Пример —— план питания на неделю（смотрите каждое утро):**

| Локус | День | Сцена |
|-------|------|-------|
| Дом | Пн | Курица машет крылом с балкона |
| Остановка | Вт | Рыба ждёт автобус |

**Альтернатива —— таблица умножения для ребёнка / спряжения для вас:** каждый локус держит одно правило, ежедневная поездка = бесплатное повторение（эффект интервальности сам собой).

# Как построить свой дворец: чек-лист за 15 минут

```
□ Шаг 1. Место（2 мин)
         Выберите пространство, которое знаете наизусть

□ Шаг 2. Маршрут（3 мин)
         Пройдите его мысленно и выпишите 10–15 точек
         Правило: точки крупные, последовательность естественная

□ Шаг 3. Пустые прогоны（4 мин)
         Два обхода без загрузки —— путь должен стать рефлексом

□ Шаг 4. Тест на стабильность（2 мин)
         Ответьте: что четвёртое? что между седьмым и десятым?
         Если пауза > секунды —— маршрут ещё сырой

□ Шаг 5. Регистрация（1 мин)
         Впишите в реестр: имя дворца, тема, дата

□ Шаг 6. Загрузка（3 мин)
         Первый контент + два полных обхода
```

### Признаки хорошего маршрута

- ✅ Локусы идут «сам собой»（не надо вспоминать порядок)
- ✅ Точки физически различимы（дверь ≠ окно ≠ шкаф)
- ✅ Расстояние между локусами равномерное
- ✅ Есть естественные «подпункты»（полка = 5 ячеек)

# Обслуживание дворцов

## Ритуал стирки

Контент отжил → освобождайте дворец:

```
1. Медленный обход с намерением: «сдуваю каждую сцену»
2. На каждом локусе: представьте, как образ растворяется
3. Один порожний обход после стирки
4. День пустого стояния
5. Новая загрузка
```

## Реестр дворцов（ведите в заметках)

| № | Имя | Тема | Занят до |
|---|-----|------|----------|
| 1 | Квартира | планы недели | каждую пятницу |
| 2 | Дом детства | свободен | — |
| 3 | Университет | курс истории | экзамен |

## Диагностика проблем

| Симптом | Причина | Решение |
|---------|---------|---------|
| Локус пустеет через день | сцена слабая или не проиграна | перерисовать с усилителями §3 |
| Путаю порядок локусов | маршрут сырой | ещё порожних прогонов; привязать к реальному пути |
| Смешиваются темы | один дворец на несколько тем | разнести по дворцам, стереть старое |
| Слишком медленно вспоминаю | редкие обходы | ежедневный утренний проход 2 минуты |

## Кейс 1: Студент —— 40 билетов за неделю

**Задача:** экзамен по истории, 40 билетов.

# Частые вопросы о дворцах

**Сколько всего можно хранить?**
Ограничения практики не известны. Чемпионки держат десятки тысяч единиц в сотнях дворцов. Практично：5–7 своих дворцов покрывают 95% бытовых задач.

**Что если место изменилось（ремонт, переезд)?**
Дворец живёт в памяти, а не в реальности. Ремонт реального жилья не трогает ваш мысленный макет. Но психологически проще строить на стабильных местах.

**Можно ли один локус = несколько образов?**
Да（уплотнение §3.3), но не больше 3–5 деталей на точку, иначе сцена рассыпается.

**Как быстро забывается содержимое?**
Без повторов —— как обычная память（сутки до 70% потерь). С обходами на 1/3/7/14/28 дни —— держится месяцами.

**Можно ли использовать чужие дворцы из интернета?**
Маршруты чужих домов работают плохо：нет личной привязки. Берите ПРИНЦИП разметки, а места —— свои.

| Уплотнение | Несколько деталей в одном локусе |
| Мета-локус | Локус, содержащий собственный мини-маршрут |
| Ритуал стирки | Освобождение дворца от отработанного контента |
| Реестр | Учёт：какой дворец какой темой занят |

---

## Идея на вырост: чемпионские дворцы

Когда базовые 15 надоедят：

- **Дворец-город**（GTA-масштаб)：тысяча локусов для тысяч единиц
- **Тематические вселенные**: вселенная Гарри Поттера под магию терминов， вселенная Marvel под супергероев-формулы
- **Дворец времени**: один маршрут, где каждый обход = один день недели， сцены перезаписываются ежедневно
- **Командные дворцы**: общий дворец команды для совместных презентаций（все знают маршруту)

Чемпионаты мира по памяти проходят именно на таких конструкциях. Ваш потолок —— только фантазия при разметке.

## Как связать каталог с тетрадью и курсом

| Этап учебника | Дворцы из каталога |
|---------------|---------------------|
| Модуль 3（дворец) | №1 Квартира —— первый, главный |
| Модуль 8（речи) | №5 Офис для доклада |
| Модуль 9（колода) | любой， 26+ локусов |
| Модуль 13（продвинутые) | №4 Маршрут + мета-локусы |
| Экзамен учебника | комбинируйте три дворца |

После прохождения курса дворцы переходят в «режим жизни»: план недели в квартире， проекты в офисе， цитаты в библиотеке.

## Дворцы и цифры: гибрид с Major

Самая мощная комбинация：в локусах стоят Major-образы чисел.

```
Задача: запомнить план с точными цифрами
«Продажи выросли на 47%» → локус «плита»: на плите ЧАСЫ（47) показывают рост
«300 клиентов» → локус «стол»: за столом ТЮЛЬпан? нет —— своё слово для 30
«Бюджет 250 тысяч» → локус «окно»: НИПОл? нет —— подберите из каталога §7.3 курса
```

Правило：число всегда превращается в ПЕРСОНАЖА по Major, персонаж играет в сцене локуса. Так цифры перестают сыпаться из памяти.

## Дворцы и здоровье: не перегревайтесь

Признаки того, что вы перестарались:

- Сцены начали путаться между дворцами
- Голова «гудит» после обходов
- Снится содержимое локусов（весёлый признак, но сигнал снизить темп)

Лечение: выходной от дворцов, сон, прогулка. Дворец никуда не денется —— он ваш.
