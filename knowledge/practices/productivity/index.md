# Продуктивность — Полный конспект методов и практик

## Введение

Продуктивность — это не про «делать больше», а про «делать правильное». Современная наука и практика предлагают десятки методов повышения эффективности. Разберём ключевые.

---

## 1. Метод Помодоро

**Автор:** Франческо Чирилло (1980-е)

**Суть:** Работа интервалами по 25 минут с короткими перерывами.

### Протокол

1. Выбери одну задачу
2. Заведи таймер на 25 минут
3. Работай без отвлечений
4. Когда таймер зазвонит — отметь галочкой
5. Перерыв 5 минут
6. После 4 «помодоро» — длинный перерыв 15–30 минут

### Правила

- **25 минут** — фиксированная длительность (не менять)
- **Одна задача** — мультизадачность исключена
- **Отвлечения** — записывать на бумагу, не выполнять
- **Таймер** — обязательный (Phone, Tomato Timer, Toggl)

### Когда использовать

- Задачи с чёткими границами
- Когда нужен фокус
- Когда отвлекаешься
- Для учёбы и написания кода

### Продвинутые варианты

- **Помодоро 50/10** — для глубокой работы
- **Помодоро 15/3** — для мелких задач
- **Не-Помодоро** — работай без таймера, но считай интервалы

## 2. GTD (Getting Things Done)

**Автор:** Дэвид Аллен (2001)

**Суть:** Выгрузить всё из головы в систему, обрабатывать по алгоритму.

### 5 шагов GTD

#### Шаг 1: Захват (Capture)
Записывать ВСЁ: задачи, идеи, встречи, обязательства.
- Внешний мозг: заметки, приложения, блокнот
- Важно: ничего не держать в голове

#### Шаг 2: Ясность (Clarify)
Для каждого пункта:
- Это действие?
- Это проект?
- Это справочная информация?
- Это «когда-нибудь»?
- Это мусор?

#### Шаг 3: Организация (Organize)

| Тип | Куда |
|-----|------|
| Следующее действие | Список @action |
| Проект (2+ действий) | Список проектов |
| Ожидание | Список ожиданий |
| Календарь | Только硬ные дедлайны |
| Когда-нибудь | Список «bucket list» |
| Справка | Архив / заметки |

#### Шаг 4: Обзор (Review)
- **Еженедельный обзор** (Weekly Review): 1–2 часа
  - Проверить все списки
  - Обновить проекты
  - Определить приоритеты на неделю

#### Шаг 5: Вовлечение (Engage)
Выбирать задачу по 4 критериям:
1. Контекст (где я: офис, дом, телефон)
2. Время (сколько есть)
3. Энергия (насколько сил)
4. Приоритет (важно vs срочно)

### Контексты GTD

```
@office — задачи в офисе
@home — задачи дома
@phone — по телефону
@email — по email
@computer — за компьютером
@errands — на выезде
@waiting — ожидание от других
```

### Когда использовать

- Много разных задач и проектов
- Чувство перегруженности
- Нужна система, а не метод

## 3. Time Blocking

**Автор:** Кал Ньюпорт (Deep Work)

**Суть:** Блокировать время в календаре под конкретные задачи.

### Протокол

1. Определить главные задачи на неделю
2. Выделить блоки времени (1–4 часа) в календаре
3. Каждый блок = одна задача
4. Защитить блоки (не отменять, не переносить)
5. Добавить блоки на перерывы, коммуникации, рутину

### Пример недели

```
Понедельник:
09:00–11:00  Deep Work: написание кода
11:00–11:30  Перерыв
11:30–12:30  Email и коммуникации
12:30–13:30  Обед
13:30–15:00  Встречи
15:00–16:00  Deep Work: документация
16:00–17:00  Рутина и планирование завтра
```

### Правила

- **Deep Work** = минимум 90 минут без отвлечений
- **Shallow Work** = email, звонки, администрирование
- **Buffer time** = 25% времени на непредвиденное
- **Ревью** = каждое воскресенье планировать неделю

## 4. Матрица Эйзенхауэра

**Кто:** Дуайт Эйзенхауэр (34-й президент США)

**Суть:** Классификация задач по срочности и важности.

```
              Срочно         Не срочно
Важно    ┌──────────────┬──────────────┐
         │  СДЕЛАТЬ     │  ЗАПЛАНИРОВАТЬ│
         │  (делать     │  (отложить    │
         │   сейчас)    │   на потом)   │
         ├──────────────┼──────────────┤
Не       │  ДЕЛЕГИРОВАТЬ│  УДАЛИТЬ     │
важно    │  (передать   │  (выкинуть)  │
         │   другому)   │              │
         └──────────────┴──────────────┘
```

### Квадранты

| Квадрант | Примеры | Действие |
|----------|---------|----------|
| Важно + Срочно | Кризис, дедлайн, проблема | Делать немедленно |
| Важно + Не срочно | Стратегия, обучение, здоровье | Планировать, защищать время |
| Не важно + Срочно | Звонки, 일부 email, просьбы | Делегировать |
| Не важно + Не срочно | Соцсети, телевизор, мелочи | Удалять |

### Как использовать

1. Записать все задачи
2. Распределить по квадрантам
3. Сфокусироваться на квадранте 2 (проактивная жизнь)
4. Минимизировать квадранты 3 и 4

## 5. Two-Minute Rule (Правило двух минут)

**Автор:** Дэвид Аллен (GTD)

**Суть:** Если задача занимает меньше 2 минут — делай сразу.

**Зачем:** Не тратить время на планирование и откладывание того, что можно сделать быстрее.

**Примеры:**
- Ответить на короткий email
- Убрать со стола
- Записать идею
- Позвонить на 30 секунд

**Ограничение:** Правило работает, если у тебя есть 2 минуты. Если ты в глубокой работе — лучше записать и сделать позже.

## 6. Deep Work (Глубокая работа)

**Автор:** Кал Ньюпорт (2016)

**Суть:** Фокусированная работа без отвлечений — главный навык XXI века.

### Принципы

1. **Работа глубоко** — сложные задачи требуют непрерывного фокуса
2. **Ценность глубины** — всё больше задач требуют глубины
3. **Глубина = навык** — это можно тренировать
4. **Глубина = редкость** — большинство людей работают на поверхности

### Модели глубокой работы

| Модель | Описание | Для кого |
|--------|----------|----------|
| Монах | Полный фокус, минимум отвлечений | Писатели, учёные |
| Ритм | Фиксированные часы глубокой работы | Программисты |
| Журналист | Глубокая работа в любое время | Опытные специалисты |
| Двухнедельная | 2 недели глубокой работы + 2 недели обычной | Проектная работа |

### Стратегии

- **Ритуал:** Фиксированное время, место, правила
- **Грань:** Не работать глубже 4 часов в день
- **Цифровая аскеза:** Убрать соцсети, ограничить email
- **Квантификация:** Считать часы глубокой работы
- **Вечерний ревью:** Анализ следующего дня

### Когда использовать

- Нужно создавать (код, тексты, стратегии)
- Нужно решать сложные проблемы
- Нужно учиться чему-то серьезному

## 7. Atomic Habits (Атомные привычки)

**Автор:** Джеймс Клир (2018)

**Суть:** Маленькие изменения привычек дают огромные результаты.

### 4 Закона поведения

| Закон | Описание | Практика |
|-------|----------|----------|
| 1. Сделай очевидным | Триггер должен быть видим | Положить книгу на подушку |
| 2. Сделай привлекательным | Связать с наградой | Медитация + вкусный кофе |
| 3. Сделай лёгким | Минимум усилий | 2 минуты в день (правило 2 мин) |
| 4. Сделай удовлетворяющим | Награда сразу | Галочка в трекере |

### Инверсия (как избавиться от плохих привычек)

1. Сделай невидимым (убери триггер)
2. Сделай непривлекательным (свяжи с негативом)
3. Сделай сложным (добавь трение)
4. Сделай неудовлетворяющим (отсутствие награды)

### Identity-based habits

- Не «я хочу бегать», а «я бегун»
- Не «я хочу читать», а «я читатель»
- Каждое действие — голосование за тип личности

### Habit Stacking

```
После [текущей привычки] я [новая привычка].

После утреннего кофе я meditate 5 минут.
После обеда я записываю 3 благодарности.
После работы я иду на прогулку 15 минут.
```

## 8. Сравнение методов

| Метод | Лучше всего для | Сложность | Время на внедрение |
|-------|----------------|-----------|-------------------|
| Помодоро | Фокус на конкретных задачах | Низкая | 1 день |
| GTD | Организация большого объёма задач | Высокая | 1–2 недели |
| Time Blocking | Планирование дня | Средняя | 1 неделя |
| Эйзенхауэр | Приоритизация | Низкая | 1 час |
| Deep Work | Создание (код, тексты) | Средняя | 2–4 недели |
| Atomic Habits | Формирование привычек | Низкая | 2 минуты |

### Когда какой метод использовать

| Ситуация | Рекомендация |
|----------|-------------|
| Много мелких задач | Помодоро + Two-Minute Rule |
| Ощущение хаоса | GTD + Time Blocking |
| Нужна стратегия | Deep Work + Time Blocking |
| Хочу изменить привычки | Atomic Habits |
| Много встреч | Time Blocking + GTD |
| Нужно учиться | Deep Work + Pomodoro |

### Комбинация методов

**Пример рабочего дня:**
1. Утро: Time Blocking (план дня)
2. 09:00–11:00: Deep Work (глубокая задача)
3. В процессе: Pomodoro (25-мин интервалы)
4. В течение дня: Two-Minute Rule (мелочи)
5. Вечером: GTD (обработка входящих)
6. Еженедельно: Эйзенхауэр (приоритизация) + Weekly Review

## 9. Научное обоснование

### Что говорит нейронаука

- **Контекстное переключение** стоит 20–40% продуктивности (American Psychological Association)
- **Мультизадачность** — миф; мозг переключается между задачами, не делает их параллельно
- **Пиковая продуктивность** — 4–5 часов в день ( Anders Ericsson)
- **Восстановление** — необходимо после глубокой работы (85/15 rule)

### Что работает на практике

- **Рутинное время** для рутины (автоматизм)
- **Решения утром** (decision fatigue)
- **Окружение** важнее силы воли
- **Трекинг** повышает осознанность
- **Сон, спорт, питание** — база продуктивности

## 12. Методы продуктивности: углублённый разбор 🐸

Методы ниже не попали в первый блок или раскрыты там кратко. Здесь — по теме, как это укладывается в личную систему.

### 12.1 Eat The Frog («Съешь лягушку»)

**Автор:** Брайан Трейси (источник идеи — Марк Твен: «Если твоя работа — съесть живую лягушку, лучше сделать это с утра»)

**Суть:** «Лягушка» — самая неважная... нет, **самая важная и одновременно самая неприятная/откладываемая задача дня**. Её надо сделать первой, пока мозг свежий.

**Протокол:**
1. Вечером выбери 1 кандидата на «лягушку» завтра
2. Утром, до email, соцсетей и коротких созвонов — только она
3. Внимание и дисциплину не тратить на что-либо до этого
4. Сделал → весь день легче («всё уже хорошо, что дальше»)

**Правила Трейси:**
- **Правило 10/90** — первые 10% времени на планирование экономят 90% времени на исполнении
- **Правило трёх** — в любой день есть макс. 3 задачи, которые реально двигают дело
- **Лягушек редко бывает много** — если их 10, у тебя проблема с фокусом, а не с количеством

| Eat The Frog | Pomodoro |
|---|---|
| 1 большая задача | много средних задач |
| Приоритет «что» | приоритет «как удержать фокус» |
| Работает в начале дня | работает весь день |
| Победа = старт | победа = интервалы |

### 12.2 Ivy Lee Method

**Автор:** Айви Ли, консультант по продуктивности (1918). Легендарная история: 15 минут консультации для Чарльза Шваба из Bethlehem Steel за $25 000 — и метод оказался единственным, что ушло в практику.

**Протокол (5 шагов):**
1. В **конце** рабочего дня выпиши на бумагу не более **6** самых важных задач на завтра
2. Расставь по приоритету: 1 — самая важная, 6 — наименее
3. Утром начни с №1 и не переходи к следующей, пока №1 не закончена
4. Незавершённое переноси в начало нового списка
5. Повторяй каждый вечер

**Почему работает:**
- Лимит 6 задач снимает иллюзию «я всё успею»
- Решение принято **до** утра — утро начинается с исполнения, а не выбора
- Сон «перемалывает» план: утром приходит ясность
- Одна задача за раз = ноль переключений

**Отличие от «общего списка»:** список дел — это память; список Айви Ли — это приоритет. Разница в «не более 6» и «строго по порядку».

### 12.3 Правило 80/20 (Закон Парето)

**Кто:** Вильфредо Парето (1896) — заметил, что ~80% земли в Италии принадлежит ~20% населения. Джозеф Джуран обобщил это в «принцип жизненно важного меньшинства».

**Современная формулировка:** примерно 20% причин дают 80% следствий. Доли варьируют (90/10, 70/30), суть — **асимметрия вклада**.

**В продуктивности:**
- 20% задач дают 80% результата
- 20% клиентов дают 80% выручки
- 20% файлов — 80% обращений к ним
- 20% времени — 80% пользы (утренние 2 часа!)

**Как применять:**
1. Выпиши все задачи/клиенты/активности за месяц
2. Спроси: какие ~20% дают тот результат, за который платят и за который уважают?
3. Им — первые часы дня, лучшие блоки, самые свежие силы
4. Остальные 80% — делегируй, объединяй в батчи, упрощай, выкидывай

**Предостережения:**
- 80/20 — компас, не формула точных процентов
- Не применять к обязательным мелочам (налоговая, здоровье)
- Пересматривать ежеквартально — «важное меньшинство» меняется

### 12.4 Seinfeld Strategy («Не разрывай цепочку»)

**Автор:** комик Джерри Сайнфелд (совет молодому коллеге: каждый день работать над материалом и отмечать X в календаре — задача не «написать шутку», а «не разорвать цепочку»).

**Протокол:**
1. Выбери ОДНУ привычку, которую будешь делать каждый день
2. На стене — календарь
3. Выполнил → жирный X
4. Мотивация: «боюсь это себе сломать» (loss aversion)

**Психологический механизм:**
- **Зейгарник** + внешний видимый след прогресса
- **Боязнь потери:** разорвать цепочку «больнее», чем пропустить день
- **Обещание самому себе закрепляется** визуальным артефактом

**Плюсы и минусы:**

| Плюсы | Минусы |
|---|---|
| Идеальна для простых ежедневных действий | Плохо для больших интеллектуальных задач |
| Низкий порог входа | «Явка» ≠ качество (можно «просидеть час впустую») |
| Прогресс виден глазами | Игнорирует восстановление — нет дней отдыха |

**Как обходить минус:** делать «мини-версию» (2 минуты в день — правило Atomic Habits), а не 2 часа.

### 12.5 Parkinson's Law (Закон Паркинсона)

**Автор:** Сирил Норткот Паркинсон (1955), сатирический закон: **«работа заполняет время, отпущенное на неё»**.

**Следствия:**
- Дедлайн — главный двигатель работы
- Дал на задачу 8 часов — она займёт 8 часов (даже если по факту это 40 минут дела)
- Нет дедлайна → задача живёт в списке вечно

**Практическое применение (осознанно):**
1. **Сжатые дедлайны:** честная оценка трудоёмкости × 0,7–0,8
2. **Таймер = мини-дедлайн:** помидор 25 минут, блок 50 минут
3. **Разбиение:** у большой задачи — своя дата у каждой подзадачи
4. **Буфер:** закладывай 25% времени на непредвиденное (в календаре), а не на «растягивание задачи»

**Ловушка:** буфер легко превращается в «заполнение». Держи буфер как *защитный* интервал, а не как продлённый срок задачи.

### 12.6 Two-Minute Rule — расширение

Базовое правило описано в разделе 5. Дополнительно — **вторая версия правила** (из Atomic Habits):

- **Правило старта:** любой большой навык начинается с версии «на 2 минуты»
  - «Почитать» → «прочитать 1 страницу»
  - «Побегать» → «надеть кроссовки»
  - «Медитировать» → «2 минуты тишины»
- Цель — победить **инерцию старта**; остановиться после 2 минут уже не захочется
- Работает вместе с дедлайном Паркинсона: 2 минуты «не раздуваются»

### 12.7 Помодоро-варианты для глубокой работы

| Вариант | Цикл | Когда |
|---|---|---|
| Классический | 25/5 ×4 → 15–30 | Рутина, учёба, срочные правки |
| Помощи глубокий | 50/10 | Вход в состояние — до кода/текста |
| Ультрадианный | 90/20 | Максимум глубины, реальные циклы внимания |
| Батч-шэллоу | 3×25 рутины + 1×25 «открытое окно» | День менеджера |
| Рашемский | 15/3 для рутины | Мелочи, чтобы не «съели» день |

**Правило для глубокой работы:** не более 3–4 «глубоких» помидоров подряд; после 2 циклов 50/10 — длинная пауза. Считай **только реально сфокусированные** интервалы, а не «просиженные».

## 13. Deep Work: блоки, ритуалы, глубина vs поверхность 🧠

Дополняет раздел 6 — там принципы и модели, здесь операционная механика.

### 13.1 Глубина — это состояние, а не занятость

| | Глубокая работа | Поверхностная работа |
|---|---|---|
| Что это | Создание нового: код, тексты, стратегии | Обслуживание: email, созвоны, справки |
| Сложность | Высокая когнитивная нагрузка | Низкая, почти автоматическая |
| Контекст | Один, длинный, без переключений | Много мелких, дробится |
| Ценность | Растёт со временем | Амортизируется мгновенно |
| Когда | Пиковые часы | Полуденные «дыры» |

**Ключ:** разделять эти два вида в **разных блоках**. Побочка «одно превращается во второе» съедает глубину незаметно.

### 13.2 Минимальная единица глубины

- Вход в состояние ≈ 15–25 минут без переключений
- **Минимум 60–90 минут** на один глубокий блок, иначе толку нет
- Дневной потолок для интеллектуального труда ≈ 4 часа (Эрикссон)
- Оптимальная схема: 1 блок утром (2–3 ч) + 1 блок после обеда (1–2 ч)

### 13.3 Ритуал глубины (3 обязательных элемента)

1. **Место** — одно и то же, физическое или цифровое:
   - стол ≠ кровать; один виртуальный «рабочий стол»/профиль
   - телефон в другой комнате или в режиме Do Not Disturb
2. **Правила** — что внутри блока запрещено:
   - «Нет интернета, кроме документа»
   - «Плохие интернет-привычки — сигнал закончить блок нечестно»
   - «Вопросы — в список, не гуглить сразу»
3. **Предел** — время окончания, сигнал выхода:
   - жёсткий конец блока (даже в середине мысли)
   - после блока — явная «распаковка» (записать следующий шаг) + перерыв

### 13.4 Сколько глубокой работы «для жизни»

| Роль | Потребность | Как добирать |
|---|---|---|
| Программист | 3–4 ч/день | утро + после обеда |
| Писатель/учёный | 4 ч/день | один длинный блок |
| Менеджер | 1–2 ч/день | запертый час до встреч |
| Студент | 1–3 ч/день | сессии с повтором |

База: **2 часа в день** — уже больше, чем у 95% офиса. Это уровень «выделяюсь».

### 13.5 Квантификация глубины

- Считай **часы реальной глубины** в конце недели
- Норма для создания «выдающегося» = 3–5 часов × 5 дней
- Если посчитал и получил 0 — разбирайся с отвлечениями, а не с мотивацией

## 14. TimeBlocking / Calendar Blocking: продвинутое 📅

Базовый протокол — в разделе 3. Здесь — уровни, защита блоков, типы людей.

### 14.1 Три уровня планирования

| Уровень | Горизонт | Что блокируем | Когда |
|---|---|---|---|
| Темы дней | месяц | «Четверг — день кода», «Вторник — день встреч» | раз в месяц |
| Недельный | неделя | глубокие блоки + встречи + защита | воскресенье |
| Дневной | день | точные часы + буферы + рутина | вечер накануне / утро |

### 14.2 Maker's schedule vs Manager's schedule

- **Maker (создатель):** нужны длинные блоки 2–4 часа; встреча в 11:00 «убивает» весь блок
- **Manager (менеджер):** живёт по часам, встречи — топливо
- Если ты мейкер — защищай утро; встречи складывай в послеобеденное «окно»

### 14.3 Правила защиты блоков

1. **Не больше 3 жёстких глубоких блоков в день** — иначе распадёшься
2. **Буфер 25%** — физически рисуй в календаре пустые блоки
3. **«Собери мир» блоки** (аналог дней-тем): одна тема на день → меньше переключений + максимальный контекст
4. **Блок «это всё равно придётся сделать»**: почта ×2 в день (11:00 и 16:00), а не 30 заходов
5. **Отложил блок → сдвинь в тот же день** или удали «сознательно», а не молча пропускай

### 14.4 Анти-шаблоны (что не работает)

| Ошибка | Последствие |
|---|---|
| Расписать каждые 15 минут | один сбой рушит весь день → стресс |
| Блоки поверх рутины без буферов | вечные «не успел» |
| Перепланирование посреди дня | теряешь 10–15 мин на каждом цикле |
| Держать блоки «в уме» | утечка: время уходит на вспоминание |

### 14.5 Что класть в календарь, а что — нет

| В календарь (жёстко) | В список (гибко) |
|---|---|
| Встречи, дедлайны | Задачи не с привязкой ко времени |
| Глубокие блоки | Мелочи на Two-Minute Rule |
| Буферы, перерывы | Идеи, «когда-нибудь» |
| Утренний ритуал | Рефакторинг «по желанию» |

## 15. Физиология продуктивности 🫀

Всё выше — методы. Но тело — база: при дефиците сна и плохой биологии методы не работают.

### 15.1 Сон и время подъёма

- Норма **7–9 часов** взрослому; дефицит < 6 часов ≈ состояние лёгкого опьянения когнитивно
- Сон циклами по ~90 минут; просыпаться **в конце цикла** — бодрым, в середине — разбитым
- **Расчёт пробуждения:** ляг в 23:00 + 6 циклов (9 ч) → будильник на 08:00; или 5 циклов (7,5 ч)
- **Стабильное время подъёма** важнее времени засыпания — вставай в одно и то же, включая выходные

### 15.2 Циркадные ритмы

- Главный синхронизатор — **свет** (особенно утренний на улице 10–20 мин)
- Кортизол пик — утром (энергия на старт), мелатонин — вечером
- Пики бодрости у большинства: 09:00–11:00 и 15:00–17:00; провал — 13:00–15:00
- «Планируй задачи по ритму»: сложное в пики, рутину в провалы, встречи в обед

### 15.3 Хронотипы

| Хронотип | Подъём | Пик | Совет |
|---|---|---|---|
| Жаворонок | 05:00–07:00 | утро | сложное до обеда |
| Промежуточный | 07:00–09:00 | 9–11 и 15–17 | два блока глубины |
| Сова | 10:00–12:00 | вечер | не бойся поздней глубины, защищай утро от «жести» |

- Хронотип задан генетикой, но сдвигается привычками: стабильный подъём + свет утром + минимум света вечером
- Не воюй с собой: для совы 06:00 — это не «дисциплина», а болото

### 15.4 Кофеин и часы его действия ☕

- Эффект через 15–45 минут, полураспад ~5–6 часов
- Кофе в 16:00 → к 22:00 остаётся ~25% дозы → нарушает сон
- Правило **«кофеин за 6–8 часов до сна»** — неделя без него улучшит сон заметно
- **Coffee nap:** кофе → сразу 20 мин сна → просыпание на пике кофеина (эффективнее, чем то или другое отдельно)
- Кофеин ≠ энергия; он «снимает тормоза», маскируя усталость. Устал → спать, а не добить стаканом.

### 15.5 Движение и сидение 🪑

- Сидение 8+ часов/день ухудшает метаболизм, фокус и спину — независимо от спорта
- **Микродвижение:** вставать каждые 30–60 минут на 1–2 минуты (голяк: ходьба по комнате, потягивания)
- **NEAT** (не-спортивная активность) — ходьба, лестница, стояние — даёт энергию и лучше, чем «мегатренировка раз в неделю»
- После 90-минутного блока глубины — 10–20 минут прогулки: перезапуск внимания и «фоновое решение» проблем

### 15.6 Перерывы 🕐

| Термин | Что это | Когда |
|---|---|---|
| Микроперерыв | 1–2 мин лёгкого движения | каждые 30–60 мин |
| Перерыв будучи помидора | 5–10 мин | после каждого цикла |
| Длинный перерыв | 15–30 мин | после 4 помидоров / 2 циклов 50/10 |
| Обед как перерыв | 20–60 мин вне экрана | реально восстанавливает |
| Макро-пауза | выходной, отпуск, «цифровой шаббат» | раз в неделю/месяц |

- **Полифазный сон** (несколько коротких фаз вместо ночного) — спорная экстремальная техника; для большинства это дефицит сна под красивым названием. Не гнаться.
- Перерыв ≠ «полистать ленту»: скролл — это нагрузка, а не отдых. Гуляй, смотри вдаль, глаза вверх снимают напряжение.

### 15.7 Питание 🍎

- Мозг ест глюкозу — но стабильнее при **медленных углеводах** и белке, чем от сахарных пиков
- Сахарный пик → провал ≈ лёгкий сонный час (план-провал 13:00 усугубляется)
- Завтрак с белком, обед без тяжести (овершелф: жирная/обильная еда = сон в 14:00)
- **Вода:** дегидратация на 1–2% уже снижает внимание; стакан при провале — самый дешёвый приём
- Не ходи на глубокий блок голодным или плотно наевшимся; норм-уровень — «заправлен», но не обожран

## 16. Когнитивная наука продуктивности 🔬

Почему методы работают (или не работают) — на уровне мозга.

### 16.1 Когнитивная нагрузка

- Рабочая память ≈ **4 ± 1 «чанка»** (Кован, 2001) — не 7±2, как раньше думали
- Сложная незнакомая задача съедает всю память → ошибки, «туплю»
- **Снижение нагрузки:**
  - разбивай задачу на шаги (чанки)
  - выгрузи из головы в список (внешняя память = когнитивный протез)
  - один контекст на блок (не переключай окна/темы)
  - инструкции и дедлайны — письменно на видном месте
- «Умный устаёт потому, что память переполнена», а не потому что «мозг не тянет»

### 16.2 Прокрастинация: экономика момента (Айнсли)

**Кто:** Джордж Айнсли (экономист-психолог), теория **гиперболического дисконтирования**.

**Суть:**
- Мозг обесценивает ценность будущего **нелинейно**: «через год» и «через месяц» для него почти одинаково, а «через 10 минут» резко важно
- В момент выбора «потом» всегда побеждает: награда сейчас (скролл) легче, чем награда потом (доделать)
- **«Хот» (горячие) состояния:** голод, усталость, тревога, раздражение → решения становятся аффективными, импульсивными; в «колд» (спокойном) состоянии мы планируем, в «хот» — откладываем

**Выводы для практики:**
- Не полагайся на силу воли в «хот» моменте — убери соблазн заранее (окружение > воли)
- Принимай решения о труде в «колд» состоянии: план на утро делай вечером (Ivy Lee)
- Сокращай горизонт: дедлайн-завтра работает лучше, чем дедлайн-через-месяц
- Анти-прокрастинация: «просто начни на 2 минуты» — обманывает дисконтирование: старт уже не «потом»

### 16.3 Willpower-теория

- Классика (Баумайстер): самоконтроль — как мышца, устаёт к вечеру (истощение эго)
- Спорно: эффект «истощения эго» плохо реплицируется; но **decision fatigue** (усталость от решений) к вечеру реальна — решения много раз
- Мозг не «тратит волю», если действие **автоматизировано** (привычки) — отсюда сила рутин
- Не борись силой воли с окружением; настрой среду так, чтобы воля была не нужна

### 16.4 Эффект Зейгарник

**Кто:** Блюма Зейгарник (1927), студентка Левина.

**Суть:** незавершённая задача держит мозг в напряжении — она «фонит» в сознании, пока не закрыта. Доказано: официанты помнят только неоплаченные заказы.

**Практика:**
- Не начинай вечером новую большую задачу «совсем чуть-чуть» — она будет жечь весь вечер
- Но для старта она магия: «открыл файл, написал первую строку» → мозг удерживает тему, садишься доработать
- **«Деструктурированное завершение»:** не доделав, запиши следующий конкретный шаг («продолжить с 3-й главы, добавить таблицу») — напряжение переводится в план
- Закрывай день коротким «список на завтра» — Зейгарник отпускает до утра

### 16.5 Ошибка планирования (Planning fallacy)

**Кто:** Канеман и Тверски (1979): люди систематически недооценивают время, стоимость и риск своих проектов — даже когда знают, что другие на таких задерживаются.

**Механизм:**
- «Внутренний взгляд» (проектирую свою идеальную последовательность) вместо «внешнего» (что реально случалось)
- Игнорирование базовой нормы: «обычно такое занимает X»

**Лечение:**
1. **Reference class forecasting:** спроси «сколько занимало то же у меня/у людей в среднем» — и заложи это
2. **Умножай оценку ×1,5–2** для новых задач (для знакомых ×1,2)
3. **Pre-mortem:** «Проект провален на месяц позже — почему?» → выписываешь реальные риски заранее
4. Отделяй «лучший случай» от «реалистичного» и «худшего»

**Связка с дедлайнами:** планирование-ошибка и закон Паркинсона — две противоположные ловушки: первая занижает сроки, вторая раздувает работу под срок. Решение — реалистичная оценка × сжатый дедлайн.

## 17. Окружение и среда 🏠

Ты — сумма среды, которую создал. Слабому окружению воля не нужна.

### 17.1 Дизайн рабочего пространства

- **Зонирование:** умственная работа ≠ место, где спишь/ешь. Кровать для работы — худший друг сна
- **Один экран/одно окно** — контекст: спрячь лишние вкладки, чат без значков
- **Свет:** яркий холодный утром, тёплый вечером; свет от экрана ночью = «ночь» для глаз
- **Порядок = ресурс:** видимый беспорядок нагружает внимание (скрытая многозадачность)
- **Минимум «триггеров лени»** рядом: телефон далеко, кровать не видна

### 17.2 Цифровой детокс и уведомления 📵

- Прерывание → потеря концентрации: нужно **~23 минуты** чтобы вернуться на прежний уровень после отвлечения (Gloria Mark)
- Средний человек проверяет телефон 80–150 раз/день
- **Практика:**
  - уведомления: только у людей и задач первой величины, всё остальное off
  - батчинг: почта/мессенджеры 2 раза в день, в определённые часы
  - телефон в другой комнате на Deep Work блоке (или режим самолёта)
  - «цифровой шаббат» — день без экранов 1× в неделю/месяц
  - экранное время ночью: телефон не у кровати, алко/кофеин не подряд
- Иконка приложений в цвете — тоже триггер; делай всё серым, если хочется меньше тянуться

### 17.3 Дом vs офис

| | Дом | Офис |
|---|---|---|
| + | Свобода, экономия дороги | Контекст «работа», коллеги, без домашнего шума |
| − | Домашние триггеры (диван, холодильник, семья) | Офисные триггеры (болтовня, встречи, как-все) |
| Спасает | Отдельная рабочая комната/угол, жёсткий ритуал старта | Наушники, «закрытая дверь», блоки в календаре |

**Ритуал переключения «дом→работа»:** одеться как «на работу», короткая прогулка до стола, первый блок сразу, кофе как «запуск машины». В офис — наоборот, ритуал выхода (последние 10 минут — разбор вчера/план на завтра).

## 18. Энергия вместо времени ⚡

Время у всех одинаковое (24 часа), энергия — разная. Управляй состоянием, а не только расписанием.

### 18.1 Энергия как ресурс

- Энергия = физический заряд (сон, еда, движение) + эмоциональный (стресс, радость) + когнитивный (нагрузка)
- Уровень энергии падает со стрессом: тревога «съедает» фокус быстрее усталости
- **Утренний здравый сценарий:** физический заряд (сон, вода, свет) → эмоциональный (спокойный старт, без ленты) → когнитивный (сложное первым)
- **Аудит энергии:** неделю записывай, в какие часы «всё легко» и когда «тянучка» — планируй по своим кривым, а не по чужим шаблонам

### 18.2 «Самый важный час» (первый час дня)

- Первые 60 минут задают тон: как начнёшь — так и пройдёт день
- Запрет в первый час: телефон, новости, соцсети, почта (чужие цели) — см. раздел 22 про чек-лист запуска
- Правило: **«сначала свой важный час — потом мир»**: мир подождёт 60 минут
- Вариант для сов: «первый час» = первый час после подъёма, а не календарное 08:00

### 18.3 Утренний ритуал

Мини-проверенный (30–40 минут):
1. Проснулся → свет/воды/потянуться (1 мин)
2. Медвежьи 5–10 минут на воздухе или у окна
3. Один стакан воды, ничего в телефон
4. Записи: 5 светлых строк / план дня (см. дневной шаблон)
5. Глубокая задача «лягушки» (Ivy Lee №1)

**Дополнение — восстановление вечером:** 30–60 мин до сна без экранов, свет приглушён, «экран-без-почты», сон-цикл. Энергия утра начинается вечером.

### 18.4 Эмоциональная регуляция на работе

- Название эмоции снижает её остроту (аффект-лейблинг) — «я раздражён», а не «всё плохо»
- Раздражительность в «хот» состоянии → не писать и не отвечать; отложить 20 минут
- Ошибки → 3 вопроса: «что случилось / что я решу / что забрать» — вместо самобичевания; перфекционизм убивает энергию (см. 21)

## 19. Привычки и рутины: система на автопилоте 🔁

### 19.1 Связка с Atomic Habits (уже разобраны в разделе 7)

- 4 закона — работают в связке: «очевидное → привлекательное → лёгкое → удовлетворяющее»
- Habit stacking — но без перегруза: **максимум 2–3 новых привычки за раз**
- Начни с «мини-версий» (2 мин) и наращивай по 5% в неделю

### 19.2 Хаbit stacking: конкретные связки

```
После [запуска кофемашины] → выписать 3 задачи дня
После [завтрака] → помыть посуду (пред-завтрак ритуал выхода)
После [сесть за стол] → открыть заметку «Сегодня» и ждать 1 мин тишины
После [обеда] → 15-мин прогулка
После [вечернего душа] → 5 строк в дневник
После [лечь] → мысленный Thursday-ритуал «3 хороших»
```

### 19.3 Трекинг привычек 📈

- Правило №4 («удовлетворение»): галочка = микродофамин, укрепляет цепь
- Форматы: бумажный календарь (Seinfeld X), цифровой (Habify/Streaks), свой файл в Obsidian
- **Три правила трекинга:**
  1. Не пропускай 2 дня подряд (пропуск 1 дня — норма, 2 дня — яма)
  2. Трекай только «появление» (сделал/не сделал), не результат
  3. Слишком длинные чек-листы убивают; 3–5 привычек — потолок

### 19.4 Weekly Review (из GTD) — чек-лист

Еженедельно, фиксированно (воскресенье, 30–60 мин):

1. **Захват:** непрочитанные заметки, входящие, идеи из диалогов — всё в инбокс
2. **Просмотр списков** по одному → решение по каждому
3. **Проекты:** прогресс, следующий шаг, что «висит»
4. **Календарь:** прошлая неделя (сдвинутое), следующая неделя (события времени)
5. **Ожидания:** что ты ждёшь от других, что надо напомнить
6. **Разбор «больших картин»:** что из «когда-нибудь» тащить в «сейчас»?
7. **Закрыть** → свежий вид на неделю

### 19.5 Ежедневный триумвират

- Каждое утро выбирай **3 приоритетных действия** (макс.) на день
- Формула: **1 «лягушка» (важнейшее) + 1 продвижение проекта + 1 бытовое/поддерживающее**
- Всё остальное — «если останется время»
- Связка: триумвират ← приоритеты из Weekly Review ← Ivy Lee список

### 20.1 Сравнение приложений

|---|---|---|---|---|
| **Obsidian** | База знаний | Полная свобода, локальные файлы, связи | Кривая настройка, нет встроенных дедлайнов | Заметки, карта знаний, трекинг привычек |

| **Google Calendar** | Календарь | Time Blocking, напоминания | Нет зависимости задач | Планирование блоков |
| **Anki** | Карточки | Интервальное повторение | Не для задач, для запоминания | Учёба, запоминание фактов |
| **Forest** | Фокус | Геймификация, дерево растёт | Поверхностный | Блокировка прокрастинации |

**Мой выбор-база:** Task-решения (Todoist) + календарь (Google) + знания/привычки (Obsidian) + время по Need (Toggl 2 недели в месяц). Не держать 7 инструментов «на всякий».

### 20.2 Канбан и тикеты

- **Канбан-доска:** колонки = Статус (Сделать / В процессе / Буфер / Готово)
- В Obsidian: простой файл-трекер со списками по статусам, либо таблица с полем «статус»
- В командах — тикеты: задачи с номером, описанием, приоритетом, ответственным
- **WIP-лимит:** в «В процессе» — не более 3 задач. Это закон, а не рекомендация

### 20.3 База знаний как инструмент продуктивности

- Файл «Сегодня/Завтра» — дневной узел (см. шаблон 22)
- Файл «Проекты» — статусы и внешние шаги проектов
- Метки для трекинга привычек; «Словарь» (раздел 23) — как шпаргалка
- Связи заметок = фоновый «журнал решений»: «почему я выбрал дорожку Д»

## 21. Ошибки продуктивности 🚫

### 21.1 Многозадачность

- Мозг **не параллелит**: быстрое переключение теряет 20–40% времени (APA)
- «Лёгкая» многозадачность (плейлист + код) — ок; кодинг + чаты — нет
- Скрытая многозадачность = «проверю-телефон-пока-компилируется» — разрывает контекст
- Противоядие: батчинг + один контекст на блок

### 21.2 Перфекционизм

- «Идеально» ≠ «сделано»; перфекционист теряет сроки и энергию
- Правило «достаточно хорошо» + timebox: «40 мин на черновик, потом правки»
- Перфекционизм часто маскирует страх оценки → это не стандарт, это защита
- Практика: «черновик на 80% сегодня > идеальное 100% через неделю»

### 21.3 «Синдром утки» 🦆

- Утка: на поверхности спокойна, под водой отчаянно гребёт
- Проявление: внешне «всё запланировано» (таблицы, доски, трекеры), внутри — хаос и перегруз: план-гигант на 12 задач, 30 открытых вкладок, 5 «почти готовых» проектов
- Диагностика: устаёшь, а результат ≈ 0 из сделанного «на бумаге»
- Лечение: сократи план до триумвирата, WIP-лимит 3, закрывай задачи до новых

### 21.4 Раздувание времени (time inflation)

- Паркинсон в действии: задача растёт под отведённое время даже без причины
- «Вся неделя на отчёт» → отчёт на 5 дней; «2 часа на письмо» → письмо на 2 часа
- Противоядие: **честная оценка, потом сжать** (×0,7), таймер, дедлайн наружу
- Раздувание — хитрая автопрокрастинация: «занят», но не продуктивен

### 21.5 Ложные приоритеты

- **«Ургентность-ловушка»:** срочное всегда громче важного; Quadrant 3 (не важно + срочно) поедает день
- Список «для галочки»: задачи, которые давно не важны, но в списке «живут»
- Проверка приоритета: «если я сегодня сделаю только это — день удался?» (нет → не приоритет)
- Регулярно: пересматривай список раз в неделю (Weekly Review удаляет мусор)

## 22. Личные кейсы и шаблоны 🗂️

### 22.1 Недельный план-шаблон

```
# Неделя W-## [дд.мм — дд.мм]

## Фокус недели (1–2 темы)
- [ ]

## 3 главных результата недели
- [ ] 1.
- [ ] 2.
- [ ] 3.

## Расписание блоков
### Пн [Число]
- [ ] 09:00–11:00 Deep Work: ...
- [ ] 16:00–16:30 Почта
- [ ] Привычки: ...
### Вт [Число]
...
### Вс — Weekly Review ✓

## Ожидания от других
- [ ] ...

## «Когда-нибудь»
- [ ] ...
```

Хак: каждый вечер воскресенья — пятнадцатиминутка «что перенеслось/сдвинулось», а после — свежий понедельник без «вчерашних хвостов».

### 22.2 Дневной шаблон (одна заметка на день)

```
# 📅 ДД.ММ.ГГГГ

## Триумвират дня
1. 🐸 [лягушка]
2. [проект-продвижение]
3. [бытовое/поддержка]

## Таймлайнинг
09:00–11:00  Deep Work:
11:00–11:30  перерыв
...

## Помидоры: 🍅🍅🍅 (счётчик)

## Отвлечения (записать, не выполнять)
- ...

## Вечерний ревью (3 строки)
- Сделал: ...
- Не сделал: ...
- Завтра сначала: ...
```

### 22.3 Чек-лист запуска дня

```
[ ] Встал в одно и то же время
[ ] Свет на улице/у окна 5–10 мин
[ ] Вода → утрево (без телефона 30 мин)
[ ] 1 «внескелетный» жест: потянулся/зарядка 3 мин
[ ] Проверил Weekly Review → выписал триумвират
[ ] «Лягушку» поставил первым блоком
[ ] Телефон → в другую комнату/режим фокуса
```

Форма: утром — 7 галочек подряд = день уже «выигран» до 09:00.

### 22.4 30-дневный план внедрения

| Неделя | Что внедряю | Ключевая практика |
|---|---|---|
| 1 | Утро | чек-лист запуска дня + триумвират |
| 2 | Фокус | глубокий блок 90 мин утром + помидор на мелочах |
| 3 | Система | Weekly Review (воскр.) + Ivy Lee список вечером |
| 4 | Окружение | уведомления off, почта 2×день, канбан WIP 3 |

- Правило «одна новая практика в неделю» — иначе бросишь всё (30 дней умирает в первую неделю)
- В конце каждого дня — ревью: сработало/нет, что убрать (не накапливай «обязаловку» за месяц)
- После 30 дней: оставь 2–3 практики, которые дали >50% эффекта, остальные — «не кандидаты»

### 22.5 Реальный кейс-расписание мейкера

```
06:30 подъём, свет, вода, прогулка
07:00–07:40 утренний ритуал + план дня (без экранов)
07:40–10:30 DEEP BLOCK: «лягушка» (помидоры 50/10)
10:30–10:50 перерыв, движение
10:50–12:00 почта/мессенджеры/командировка-поддержка
12:00–13:00 обед (без экрана) + прогулка 15 мин
13:00–14:00 «провальный» час — рутина, встречи, батчинг
14:00–15:30 DEEP BLOCK 2 (творчество, кодинг)
15:30–16:00 домены/мелочи/закрытие (Two-Minute Rule)
16:00–16:30 планирование завтра (Ivy Lee)
16:30 окончание. Спорт/свет.
22:30 без экранов → 23:00 сон (6 циклов → 06:30)
```

## 24. Самопроверка: 20 вопросов с ответами 🎓

**1. Почему прерывания так дороги?**
🌀 Возврат внимания после отвлечения занимает ~23 минуты (потери на переключении контекстов 20–40%). Поэтому почта — 2 раза в день, а не 30.

**2. В чём суть «лягушки»?**
🐸 Самая важная и неприятная задача дня делается первой, до всего остального, пока свежие силы и нет усталости от решений.

**3. Чем Ivy Lee отличается от обычного списка?**
📝 Ограничением (не более 6), приоритетом и строгим порядком: следующая задача начинается только после завершения предыдущей.

**4. Что такое правило 80/20 и зачем оно?**
⚖️ Примерно 20% причин дают 80% результатов — надо найти свои 20% «золотых» задач и отдать им лучшие часы.

**5. Как работает Seinfeld Strategy?**
📅 Отмечать X за каждый выполненный день; мотивация «не разорвать цепочку» (страх потери) работает сильнее мотивации «награда».

**6. Что говорит закон Паркинсона?**
⏰ Работа раздувается под отведённое время — наоборот, надо сжимать сроки и ставить таймеры (мини-дедлайны).

**7. Сколько реальной глубокой работы человек может сделать в день?**
🎯 ~4 часа для интеллектуального труда (Эрикссон); базовая цель — 2–3 часа. Всё свыше обычно «ложная глубина».

**8. Почему надо вставать в одно и то же время?**
🌅 Циркадный ритм строится на стабильном старте: подъём важнее времени засыпания; сон циклами по 90 минут — просыпайся в конце цикла.

**9. Когда пить кофе, чтобы не портить сон?**
☕ Не позже чем за 6–8 часов до сна (полураспад ~5–6 часов). Кофе в 16:00 = лёгкий бессонный отзвук в 22:00.

**10. Чем помочь себе в «провальный» час после обеда?**
🍚 Не есть тяжело в обед, вода, свет, микродвижение, короткая прогулка; в провал — рутина и встречи, не глубина.

**11. Что за «эффект Зейгарник»?**
🧩 Незавершённое «фонит» в голове — мешает отдыхать, но помогает стартовать: начатая задача сама зовёт вернуться.

**12. Что такое «ошибка планирования»?**
📉 Систематическое недооценка сроков (Канеман/Тверски); лечится умножением оценки на 1,5–2 и учётом прошлого опыта (reference class).

**13. Почему сила воли не работает против соблазна?**
🧠 Решения принимаются в «горячем» состоянии (Айнсли) — выбирается награда сейчас. Настраивай окружение, а не воли.

**14. Что делать с отвлечениями в помидоре?**
✍️ Записать на бумагу и вернуться к задаче — правило «записал → оно подождёт».

**15. Сколько задач должно быть в колонке «В процессе»?**
🚧 Не больше 3 (WIP-лимит). Больше — канбан «не работает», внимание дробится.

**16. Чем канбан-доска полезна в Obsidian?**
🗂️ Видимый статус задач, WIP-лимит, связь с заметками; это «тикеты» без внешней системы.

**17. Как привязать новую привычку надёжно?**
🔗 Habit stacking + мини-версия на 2 минуты + трекер-галочка (4 закона Atomic Habits).

**18. Что такое Weekly Review и зачем он?**
🔍 Еженедельный обзор всех списков и проектов (30–60 мин в воскресенье) — предотвращает «загнивание» системы и даёт чистый понедельник.

**19. Почему перфекционизм снижает продуктивность?**
🎯 «Идеально» откладывает «сделано»; руководствуйся «достаточно хорошо», ставь timebox на черновик.

**20. Что делать, если планов больше, чем жизни?**
🦆 Сократи до триумвирата (3 дела), примени WIP-лимит, убери «ложные приоритеты» на Weekly Review, буфер 25% — и спи спокойно.
