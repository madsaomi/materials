# Meditation — Unit 2: Техники

## Сканирование тела (Body Scan)

Техника: последовательное внимание к разным частям тела.

``` 
1. Лягте или сядьте удобно
2. Закройте глаза, сделайте 3 глубоких вдоха
3. Направьте внимание на стопы
4. Почувствуйте: тепло, холод, пульсация, касание
5. Медленно поднимитесь выше: голени → колени → бёдра
6. Живот → грудь → спина → плечи
7. Руки: пальцы → кисти → предплечья → плечи
8. Шея → лицо → голова
9. Почувствуйте тело целиком
10. 10-20 минут
```

## Метта-медитация (Любящая доброта)

Развитие сострадания.

```
1. Сядьте удобно, закройте глаза
2. Повторяйте мысленно:
   "Пусть я буду счастлив"
   "Пусть я буду здоров"
   "Пусть я буду в безопасности"
3. Затем направьте на близкого человека:
   "Пусть [имя] будет счастлив..."
4. Затем на нейтрального человека
5. Затем на всех живых существ
6. 15-30 минут
```

## Медитация на звук

``` 
1. Сядьте или лягте
2. Закройте глаза
3. Слушайте звуки вокруг без оценки
4. Не ищите звуки — просто замечайте
5. Шум дождя, ветра, машин, тишина
6. 10-15 минут
```

## Медитация ходьбы (Кинхин)

``` 
1. Встаньте прямо, руки за спиной
2. Сделайте медленный вдох
3. На выдохе — шаг правой ногой
4. Почувствуйте: подъём, движение, касание
5. Продолжайте очень медленно
6. Координация: шаг = вдох или шаг = выдох
7. 15-30 минут
```

## Дзадзен (Дзен-медитация)

Практика сидячей медитации в традиции дзен.

```
1. Сядьте в лотос/пол-лотоса
2. Руки в космической мудре (дзэннин-ин)
3. Взгляд опущен (не закрыт) — смотреть на 1 м вперёд
4. Дыхание: медленное, естественное, животом
5. Мысли приходят и уходят — не вовлекаться
6. При отвлечении: "счёт дыхания 1-10", затем снова
7. 20-40 минут
```

## Визуализация

```
1. Закройте глаза
2. Представьте место покоя:
   лес, пляж, горы, комната
3. Детализируйте: цвета, звуки, запахи, ощущения
4. Побудьте в этом месте 5-10 минут
5. Медленно вернитесь
```

## Выбор техники

| Ситуация | Техника |
|----------|---------|
| Ум слишком активен | Дыхание, сканирование тела |
| Грусть, злость | Метта |
| Усталость | Визуализация |
| Бессонница | Body scan лёжа |
| В движении | Медитация ходьбы |
| Ежедневная практика | Дзадзен/дыхание |

## 🧘 Подробный разбор каждой техники

### 1. Сканирование тела — вариации

#### Вариант A: Быстрый скан (5 минут)
```
1. Стопы (30 сек) → голени → колени → бёдра
2. Живот → грудь → спина
3. Плечи → руки → шея → лицо
4. Всё тело целиком (1 мин)
```

#### Вариант B: Глубокий скан (30 минут)
```
1. Лёжа, глаза закрыты, 3 вдоха
2. Левая стопа: пальцы → подошва → пятка (2 мин) — заметить температуру, пульс
3. Левая голень → колено → бедро (по 2 мин)
4. Правая нога — аналогично
5. Таз → живот (дыхание) → грудь → спина
6. Левая рука → правая рука
7. Шея → затылок → лицо → макушка
8. Всё тело как единое поле ощущений (5 мин)
9. Медленный выход: шевельнуть пальцами → открыть глаза
```

#### Вариант C: Скан с дыханием
```
1. На вдохе — внимание в стопы, на выдохе — отпустить напряжение
2. На каждом выдохе — как будто выдыхаете через эту часть тела
3. 10 циклов, затем выше
```

**Частые ошибки:**
- Пытаться «почувствовать что-то особенное» — просто замечайте что есть (тепло/холод/онемение/ничего)
- Засыпать — держите глаза полуоткрытыми, сидите, не лёжа
- Пропускать «нечувствительные» зоны — задержитесь там на 30 сек дольше

**Адаптации:**
- При боли: не избегайте, а мягко направьте туда дыхание: «вдох — в боль, выдох — из боли»
- При бессоннице: делать лёжа в кровати, без цели «заснуть», просто скан
- Для детей: скан-игра «робот сканирует тело» — по 3 сек на зону

### 2. Метта — глубокая практика

#### Традиционная последовательность (25 мин)
```
1. Себе (5 мин): «Пусть я буду счастлив, здоров, в безопасности, свободен от страданий»
2. Благодетель (учитель, близкий) (5 мин): «Пусть [имя] будет счастлив...»
3. Нейтральный (продавец, сосед) (5 мин)
4. Трудный человек (5 мин) — только если готовы; если сопротивление — вернитесь к себе
5. Все существа (5 мин): «Пусть все живые существа будут счастливы»
```

#### Вариации фраз
- Классические Пали: «Aham avero homi...» — можно на русском, главное — искренность
- Короткие: «Счастья тебе», «Мира тебе»
- Свои: придумайте 3–4 фразы, которые отзываются именно вам

#### Когда трудно
- «Пусть я приму себя таким, какой я есть» — если «счастлив» вызывает отторжение
- Начните с нейтрального, если к себе — сложно
- Можно положить руку на сердце, представить свет

**Эффекты:** исследования показывают рост эмпатии, снижение тревожности, улучшение отношений

### 3. Медитация на звук — продвинутый уровень

#### Уровни внимания
```
Уровень 1: Громкие звуки (машины, голоса) — 5 мин
Уровень 2: Тихие звуки (тиканье часов, дыхание) — 5 мин
Уровень 3: Тишина между звуками — 5 мин
Уровень 4: Звук как вибрация в теле (уши → голова → грудь)
```

#### Практика «Всё — звук»
- Любая мысль — тоже «звук в уме» — заметьте и вернитесь к внешним звукам
- Не называйте («это машина»), просто слышьте «зву-ук»
- 15 минут, затем 2 мин тишины

**Где практиковать:** парк, кафе, транспорт — отличная «городская» медитация

### 4. Кинхин (ходьба) — детали

#### Традиционный дзен-кинхин
```
1. Стоя, руки в «сёсю» (левая кисть в правой, большие пальцы касаются) на уровне солнечного сплетения
2. Взгляд — 2 метра вперёд, полуопущен
3. Вдох — оторвать пятку правой, выдох — шаг (15 см), перенести вес
4. Следующий вдох — левая, выдох — шаг
5. Дыхание естественное, не форсируйте; шаг = ~1/2 дыхания
6. Разворот: остановиться, 3 вдоха, развернуться за 4 шага
7. Темп: очень медленно (1 шаг / 5–10 сек) или средний (1 шаг / 2 сек)
```

#### Вариации
- **Быстрая ходьба (15 мин):** обычный шаг, но внимание на стопах: касание → давление → отрыв
- **Лабиринт:** ходить по кругу, спирали, замечая повороты
- **Счёт шагов:** 1–10, затем сначала — якорь от блуждания

**Польза:** заземляет, помогает при тревоге, после долгого сидения

### 5. Дзадзен — глубокое погружение

#### Позы
- **Лотос (кэкка-фудза):** обе стопы на бёдрах — стабильно, но требует гибкости
- **Полулотос (ханка-фудза):** одна стопа на бедре
- **Бирма (бирманская):** обе стопы на полу перед собой, колени на подушке
- **Сэйдза:** на коленях, подушка между ног
- **Стул:** спина прямая, без опоры, стопы на полу, колени 90°

**Подушка (дзафу):** высота — чтобы колени ниже таза; таз слегка наклонён вперёд — естественный прогиб поясницы

**Мудры:**
- **Космическая (дзэннин-ин):** левая ладонь на правой, большие пальцы касаются кончиками, образуют овал — держите на уровне пупка
- **Гассё:** ладони вместе — для поклона

**Глаза:** полуоткрыты, взгляд 1 м перед собой на пол, не фокусироваться, веки расслаблены; если закрывать — сонливость, если широко открывать — напряжение

**Дыхание:** 
- Наблюдайте естественное: вдох — живот расширяется, выдох — сужается
- Не управляйте, просто считайте: вдох-1, выдох-2 ... до 10, затем сначала
- Если потерялись — начните с 1, без самоосуждения

**Работа с мыслями:**
- Мысль пришла → заметить «мышление» → мягко вернуться к счёту/дыханию
- Не отталкивать, не догонять — как облака
- Если сильная эмоция — назовите: «тревога», «планирование», «воспоминание»

**Время:** начинайте с 10 мин, +5 мин в неделю до 25–30; 2 раза в день — утро/вечер

**Кайдза:** вставать медленно: покачаться, размять ноги, сделать поклон

### 6. Визуализация — расширение

#### Сценарии
- **Безопасное место (5–10 мин):** лес/пляж/горы — добавьте 5 чувств: что видите, слышите, нюхаете, чувствуете кожей, вкус
- **Внутренний наставник:** представьте мудрого человека, задайте вопрос, слушайте ответ
- **Исцеление:** свет в области напряжения — на вдохе свет входит, на выдохе — напряжение уходит
- **Будущее «Я»:** представьте себя через 5 лет, здорового, спокойного — что делаете, как дышите

**Для скептиков:** даже если «не видите картинку», просто думайте о месте — эффект тот же

### 7. Дыхательные якори

#### Анапанасати (осознанность дыхания) — 4 ступени
```
1. Длинный вдох/выдох — знать «длинный»
2. Короткий вдох/выдох — знать «короткий»
3. Ощутить всё тело дыхания
4. Успокоить тело дыхания
```

#### Квадратное дыхание (4-4-4-4)
```
Вдох 4 сек → задержка 4 → выдох 4 → задержка 4 → повторить 5 циклов
Используйте при панике, стрессе
```

#### Удлинённый выдох (4-6)
```
Вдох 4 сек, выдох 6 сек — активирует парасимпатику, успокаивает
10 циклов перед сном
```

### 8. Мантра и звук

```
1. Выберите слово: «Ом», «Со-Хам», «Мир», «Спокойствие» или нейтральное «раз-два»
2. Повторяйте про себя в ритме дыхания: вдох — «Со», выдох — «Хам»
3. Когда ум блуждает — мягко к мантре
4. 15–20 мин; можно вслух (джапа) или про себя (аджапа)
```

**Мала:** 108 бусин — для отсчёта, перебирайте по одной на повтор

---

### 9. Открытое осознавание (choiceless awareness)

```
1. Сидите, глаза полуоткрыты
2. Не выбирайте объект — замечайте что приходит: звук → ощущение → мысль → эмоция
3. Просто отмечайте: «слышу», «чувствую», «думаю», «вижу»
4. Не цепляйтесь, не отталкивайте
5. 15–20 мин — как будто сидите у реки, наблюдая проплывающие листья
```

**Когда переходить:** после 2–4 недель базовой практики (дыхание/скан), когда устойчивость внимания ~5 мин без отвлечения

### 10. Работа с трудными эмоциями (RAIN)

```
R — Recognize (узнать): «Сейчас тревога»
A — Allow (позволить): «Можешь быть»
I — Investigate (исследовать): где в теле? как ощущается? что хочет?
N — Nurture (заботиться): положить руку, сказать «Ты в безопасности, я с тобой»
```

**Пример:** злость → заметить жар в груди, сжатые кулаки → позволить → исследовать → положить руку на грудь, вдох в эту зону

---

### 11. Практика благодарности

```
1. Сядьте, 3 вдоха
2. Вспомните 3 вещи, за которые благодарны сегодня (маленькие: кофе, солнце, сообщение)
3. Почувствуйте благодарность в теле (тепло в груди)
4. Поблагодарите мысленно: себя, близких, мир
5. 5–10 мин
```

**Дневник:** вечером записать 3 благодарности — меняет фокус мозга

---

### 12. Сканирование с нотением (Mahasi)

```
1. При каждом ощущении — тихо отмечайте: «подъём», «опускание» (живот)
2. «Слышу», «вижу», «думаю», «чувствую»
3. Темп — 1 отметка в 1–2 сек
4. Помогает при гиперактивном уме
```

---

### 13. Практика пауз (micro-hits)

```
- 1 минута каждый час: 3 вдоха, почувствовать тело, спросить «Как я сейчас?»
- Перед едой: 3 вдоха, почувствовать запах
- Перед встречей: 30 сек на стопы + дыхание
- Красный свет: вместо раздражения — 3 вдоха
```

---

### 14. Ночные практики

#### Для засыпания
```
1. Лёжа на спине, руки вдоль тела
2. Скан тела от стоп к голове (10 мин)
3. Или счёт дыхания 1–10 по кругу
4. Если мысли — пишите «парковку»: блокнот у кровати, записать, вернуться к дыханию
```

#### Осознанные сновидения (подготовка)
```
1. Днём — проверка реальности: «Я сплю?» + посмотреть на руки/часы 5 раз в день
2. Перед сном — намерение: «Осознаю, что сплю»
3. Утром — сразу записать сон
```

#### Правила ретрита
- Без телефона/книг/разговоров (или минимум)
- Блокнот только для практики
- Если трудно — сократите сидения до 15 мин, увеличьте ходьбу

### 17. Частые трудности и решения

| Трудность | Решение |
|-----------|---------|
| Засыпаю | Сидите, глаза полуоткрыты, холодная вода, скан стоя |
| Боль в спине/коленях | Подушка выше, стул, разминка, менять позу осознанно |
| «Нет времени» | 5 мин лучше 0; micro-hits каждый час |
| Скука | Отмечайте «скука» как объект, исследуйте: где в теле? |
| Тревога усилилась | Сократить время, добавить метта/благодарность, не делать ретрит одному |
| «Не получается» | Критерий — не отсутствие мыслей, а заметил → вернулся = успех |
| Мысли «я делаю неправильно» | Это тоже мысль — заметьте и вернитесь |
| Эмоциональный всплеск | RAIN, рука на сердце, сократить сидение, поговорить с учителем |

### 18. Научный базис

- **Внимательность снижает активность DMN (сеть «блуждания ума»)**, усиливает префронтальную кору
- **Метта повышает окситоцин**, улучшает социальные связи (исследования Ричарда Дэвидсона)
- **Скан тела снижает кортизол** — исследование на MBSR (8 недель)
- **Кинхин улучшает интероцепцию** — чувствование тела
- Минимум для эффекта — **8 недель по 20 мин/день** (протокол MBSR Джона Кабат-Зинна)

## 🧪 Лаборатория внимания — упражнения

### Упражнение 1: Монета
```
1. Возьмите монету, рассматривайте 2 мин: вес, температура, грани, блеск
2. Закройте глаза, представьте монету детально
3. Откройте, сравните — что упустили?
Развивает однонаправленность
```

### Упражнение 2: Изюминка (raisin)
```
1. Возьмите изюминку, 5 мин: смотрите, нюхайте, трогайте, слушайте (сожмите у уха), медленно ешьте
2. Замечайте импульс проглотить — не спешите
Классика MBSR — возвращает вкус к простому
```

### Упражнение 3: Слушание партнёра
```
1. Один говорит 2 мин, другой только слушает (без советов, кивков — просто присутствие)
2. Поменяйтесь
3. Обсудите: каково быть полностью услышанным?
```

### Упражнение 4: Письмо от руки
```
1. Пишите 5 мин медленно, чувствуя ручку, давление, движение
2. Замечайте мысли «пишу криво» — вернитесь к ощущению
```

### 22. Продвинутые вариации

#### Метта для трудного человека — ступенчато
```
1. Неделя 1: только себе и благодетелю
2. Неделя 2: + нейтральный
3. Неделя 3: + трудный (начните с «слегка трудного», не с травмы)
4. Если злость — вернитесь к себе, положите руку на грудь
```

#### Тонглен (тибетская)
```
1. Вдох — принимаете боль/тяжесть (чёрный дым)
2. Выдох — отдаёте облегчение/свет
3. Начните с себя: вдох — своя тревога, выдох — спокойствие себе
4. Затем к близкому, затем ко всем
5. 10–15 мин; если тяжело — вернитесь к обычной метте
```

#### Дзадзен с коаном
```
1. Сидите как в дзадзен
2. Держите вопрос без ответа: «Кто я?», «Что такое хлопок одной ладонью?»
3. Не ищите логический ответ — просто держите вопрос, замечайте реакции
4. Только с учителем
```

### 23. Интеграция в жизнь

#### Еда как медитация
```
1. Перед едой — 3 вдоха, благодарность
2. Ешьте медленно, кладите ложку после каждого кусочка
3. Замечайте: вид → запах → вкус → текстура → глотание
4. Замечайте сытость — остановитесь на 80%
```

#### Общение
```
1. Слушайте, не готовя ответ
2. Пауза 1 сек перед ответом
3. Замечайте позывы перебить — вдох, вернуться
```

#### Работа
```
1. Помидоро 25 мин: одна задача, телефон в стороне
2. Между помидорами — 1 мин: потянуться, 3 вдоха
3. Конец дня — 5 мин: что сделал, за что благодарен
```

#### Спорт
```
1. Бег/йога — внимание на дыхание + стопы/тело, а не на музыку/мысли
2. Замечайте «хочу сдаться» — вдох в эту зону, продолжить
```

### 24. Препятствия — 5 помех (nivarana)

| Помеха | Признак | Противоядие |
|--------|---------|-------------|
| Желание (тяга) | «Хочу ещё», фантазии | Замечать как «желание», вернуться, исследовать: где в теле? |
| Отвращение | «Не хочу», раздражение | Метта, RAIN, «позволить быть» |
| Лень/апатия | Тяжесть, сонливость | Встать, открыть глаза, холодная вода, кинхин |
| Беспокойство | Тревога, суета | Удлинённый выдох, счёт 1–10, заземление (стопы) |
| Сомнение | «Это не работает» | Дневник, вспомнить эффект, поговорить с учителем/группой |

### 25. Карта прогресса

```
Стадия 1 (1–2 недели): Ум блуждает 80% времени — нормально. Успех = заметил и вернулся
Стадия 2 (3–4 недели): Замечаете отвлечение быстрее (через 30 сек, а не 5 мин)
Стадия 3 (1–2 месяца): Появляются промежутки тишины 10–30 сек
Стадия 4 (2–3 месяца): Спокойствие остаётся после подушки — в быту
Стадия 5 (3+ месяца): Автоматическая осознанность — замечаете реакцию до действия
```

**Плато — нормально.** Если 2 недели без «прогресса» — меняйте технику, сократите время, добавьте метту

### 26. Безопасность

- **Не используйте медитацию как избегание:** если травма, депрессия — сначала терапия
- **Если накрывает:** откройте глаза, почувствуйте опору (стопы, стул), назовите 5 вещей вокруг, попейте воды

- **Дети:** 1 мин на год возраста (5 лет — 5 мин), игровые формы

### 27. FAQ

**Q: Мысли не останавливаются — я безнадёжен?**
A: Цель — не остановить, а замечать. 100 отвлечений за 20 мин = 100 тренировок внимания — отлично.

**Q: Засыпаю каждый раз?**
A: Практикуйте сидя, утром, с полуоткрытыми глазами, добавьте кинхин перед сидением.

**Q: Когда ждать эффект?**
A: Первые изменения — через 1–2 недели (лучше сон, меньше реактивности). Устойчивый — 8 недель.

**Q: Можно под музыку?**
A: Для старта — лучше тишина. Музыка — объект, а не фон; если с музыкой — слушайте её как медитацию на звук.

**Q: Религия?**
A: Техники — светские (MBSR). Можно практиковать в любой вере или без неё.
