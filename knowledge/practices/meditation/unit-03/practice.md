# Meditation — Unit 3: Продвинутая практика

## График практики

### Начинающий (первые 3 месяца)
- Ежедневно 5-10 минут
- Техника: дыхание или body scan
- Утро — лучшее время

### Средний (3-12 месяцев)
- 15-30 минут ежедневно
- Чередование техник
- Один ретрит на полдня

### Продвинутый (1-3 года)
- 30-45 минут ежедневно
- Своя техника
- Ретриты на 1-3 дня

## Работа с эмоциями

``` 
1. Заметьте эмоцию (гнев, тревога, грусть)
2. Назовите её мысленно: "гнев"
3. Определите ощущение в теле: где? какое?
4. Дышите в это место
5. Не подавляйте, не выражайте — просто наблюдайте
6. Эмоция со временем ослабнет
```

## Интеграция в жизнь

### Майндфулнесс в повседневности

- Еда: ешьте медленно, без телефона
- Мытьё посуды: полностью в процессе
- Ходьба: чувствуйте каждый шаг
- Очередь: дышите, не хватайте телефон

### Стоп-сигналы

Установите триггеры, напоминающие о возвращении в момент:
- Красный свет
- Звук уведомления
- Питьё воды
- Открытие двери

## Ретриты

### Типы ретритов

| Тип | Описание |
|-----|----------|
| Випассана | 10 дней молчания (традиция Goenka) |
| Дзен | Несколько дней в монастыре |
| Йога-ретрит | Медитация + асаны |
| Домашний | Выходные без гаджетов в тишине |

### Рекомендации

- Начните с 1 дня молчания дома
- 3-дневный ретрит — первый опыт
- 10-дневная випассана — золотой стандарт

## Препятствия (Пять помех)

| Помеха | Противодействие |
|--------|-----------------|
| Желание | Наблюдение непостоянства |
| Отвращение | Метта |
| Лень/апатия | Энергичная ходьба, холодная вода |
| Беспокойство | Дыхание животом |
| Сомнение | Изучение текстов, общение с практикующими |

## Джханы (Сосредоточения)

В буддийской традиции — 8 уровней сосредоточения:

1. **Первая джхана** — восторг + счастье + однонаправленность
2. **Вторая** — восторг + счастье (без рассуждения)
3. **Третья** — только счастье + равностность
4. **Четвёртая** — чистая равностность + осознанность
5-8. **Бесформенные сферы** — бесконечное пространство, сознание, ничто, ни-восприятие-ни-невосприятие
