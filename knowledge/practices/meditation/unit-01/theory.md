# Meditation — Unit 1: Основы

## Что такое медитация?

Медитация (лат. meditatio — размышление) — практика тренировки внимания и осознанности. Цель: успокоение ума, снижение стресса, развитие осознанности.

## Основные типы медитации

| Тип | Описание |
|-----|----------|
| Саматха (сосредоточение) | Фокус на одном объекте (дыхание, мантра) |
| Випассана (инсайт) | Наблюдение за потоком опыта |
| Метта (любящая доброта) | Развитие сострадания к себе и другим |
| Дзен (дзадзен) | Сидячая медитация, наблюдение за умом |
| Трансцендентальная | Повторение мантры |

## Поза для медитации

### Основные варианты

``` 
1. Лотос (падмасана) — ступни на бёдрах
2. Пол-лотоса — одна ступня на бедре
3. По-турецки — простой скрещённый вариант
4. На стуле — спина прямая, руки на коленях
5. Лёжа — для продвинутых (легко уснуть)
```

### Ключевые принципы позы

- Позвоночник прямой (но не напряжённый)
- Руки на коленях или в мудре
- Подбородок слегка опущен
- Глаза полузакрыты или закрыты

## Медитация на дыхании (базовая)

``` 
1. Сядьте удобно, выпрямите спину
2. Закройте глаза
3. Направьте внимание на дыхание
4. Просто наблюдайте: вдох, выдох
5. Когда ум отвлёкся — мягко верните внимание к дыханию
6. Начните с 5 минут
```

### Распространённые трудности

| Проблема | Решение |
|----------|---------|
| Ум блуждает | Это нормально. Мягко возвращайте внимание |
| Сонливость | Откройте глаза, выпрямитесь сильнее |
| Беспокойство | Примите это как часть практики |
| Боль в спине | Используйте стул, подушку |
| Мысли не уходят | Цель не убрать мысли, а не вовлекаться |

## Польза медитации (наука)

- Снижение стресса (кортизол)
- Улучшение фокуса и концентрации
- Эмоциональная регуляция
- Снижение тревожности
- Улучшение сна
- Структурные изменения мозга (нейропластичность)

## Практика: первая сессия

Уделите 5 минут:
1. Сядьте удобно
2. Закройте глаза
3. Сделайте 3 глубоких вдоха
4. Дышите естественно, наблюдайте
5. Считайте выдохи (1-10, потом снова)
6. Когда отвлеклись — вернитесь к счёту
7. Через 5 минут откройте глаза

## Вопросы для размышления

1. Какая поза вам удобнее?
2. Легко ли удерживать внимание на дыхании?
3. Какие мысли приходят во время медитации?
4. Чувствуете ли разницу до и после?
