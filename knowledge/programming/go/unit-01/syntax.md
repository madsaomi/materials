## 2. Zero values (значения по умолчанию)

В Go нет «неинициализированных» переменных: любая объявленная переменная сразу получает нулевое значение своего типа.

| Тип | Zero value |
|-----|-----------|
| числовой (`int`, `float64`, `byte`...) | `0` |
| `bool` | `false` |
| `string` | `""` (пустая строка) |
| срез (`[]int`) | `nil` (но `len` и `append` работают) |
| `map` | `nil` (читать можно, писать — panic!) |
| указатель, интерфейс, функция | `nil` |
| структура | все поля заполнены их zero values |

```go
var (
    a int           // 0
    b float64       // 0
    c string        // ""
    d bool          // false
    e []int         // nil
    f map[string]int
    g Person        // Person{Name:"", Age:0, ...}
)

fmt.Println(a, b, c, d)      // 0 0  false
fmt.Println(e == nil)        // true
fmt.Println(f == nil)        // true
append(e, 1, 2, 3)           // с nil-срезом всё работает
```

## 3. Константы

Константы объявляются через `const` и не могут меняться после компиляции.

```go
const Pi = 3.14159
const AppName = "Конспект"

const (
    StatusOK       = 200
    StatusNotFound = 404
)

// iota — счётчик для последовательных констант
const (
    Sunday = iota // 0
    Monday        // 1
    Tuesday       // 2
    Wednesday     // 3
)
```

Пояснения:
- Константы могут быть «нетипизированными» (`Pi = 3.14159`), тогда они подстраиваются под тип при использовании.
- `iota` пересчитывается для каждого блока `const`, сбрасывается в 0.
- `len`, `cap` и простые выражения тоже можно заводить константами.

```go
const MaxItems = 100
const Greeting = "Привет, " + "мир!" // константное выражение
```

## 4. Операторы

### 4.1 Арифметические

| Оператор | Название | Пример | Результат |
|----------|---------|--------|-----------|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (целочисленное!) |
| `%` | остаток | `7 % 2` | `1` |
| `++` | инкремент | `x++` | увеличивает на 1 |
| `--` | декремент | `x--` | уменьшает на 1 |

Важные нюансы:
- `7 / 2` равно `3`, а не `3.5` — если оба операнда целые, деление целочисленное.
- Для настоящего деления нужен float: `7.0 / 2` или приведение типов.
- Остаток `%` берёт знак делимого: `-7 % 2 == -1`, `7 % -2 == 1`.
- `++` и `--` это **инструкции**, а не выражения: их нельзя вставить внутрь других выражений.

```go
a := 7 / 2          // 3
b := 7.0 / 2.0      // 3.5
c := 7 % 2          // 1
d := -7 % 2         // -1
// e := 3 * a++     // ошибка компиляции!
a++                 // теперь 4
```

### 4.2 Сравнения

| Оператор | Смысл | Пример |
|----------|-------|--------|
| `==` | равно | `5 == 5` → `true` |
| `!=` | не равно | `5 != 3` → `true` |
| `<` | меньше | `3 < 5` → `true` |
| `<=` | меньше или равно | `5 <= 5` → `true` |
| `>` | больше | `6 > 5` → `true` |
| `>=` | больше или равно | `2 >= 3` → `false` |

Сравнивать можно только значения одного типа.

### 4.3 Логические

| Оператор | Смысл | Пример |
|----------|-------|--------|
| `&&` | И (оба true) | `true && false` → `false` |
| `\|\|` | ИЛИ (хотя бы один true) | `true \|\| false` → `true` |
| `!` | НЕ (отрицание) | `!true` → `false` |

`&&` и `||` сокращают вычисление: если результат уже ясен, правая часть не выполняется.

### 4.4 Побитовые

| Оператор | Смысл | Пример (`a=6`=`110`, `b=3`=`011`) |
|----------|-------|------------------------------------|
| `&` | И | `6 & 3` → `2` (`010`) |
| `\|` | ИЛИ | `6 \| 3` → `7` (`111`) |
| `^` | XOR / инверсия | `6 ^ 3` → `5` (`101`) |
| `&^` | сброс битов | `6 &^ 3` → `4` (`100`) |
| `<<` | сдвиг влево | `1 << 3` → `8` |
| `>>` | сдвиг вправо | `16 >> 2` → `4` |

```go
fmt.Println(6 & 3)   // 2
fmt.Println(6 | 3)   // 7
fmt.Println(6 ^ 3)   // 5
fmt.Println(1 << 4)  // 16
```

### 4.5 Присваивание и составные

| Оператор | Пример | Равносильно |
|----------|--------|-------------|
| `=` | `x = 5` | присвоить |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `<<=` | `x <<= 2` | `x = x << 2` |
| `>>=` | `x >>= 2` | `x = x >> 2` |
| `&=`, `\|=`, `^=` | `x &= 3` | `x = x & 3` |

### 4.6 Приоритет операторов

От высшего к низшему:

| Уровень | Операторы |
|---------|-----------|
| 1 | `*` `/` `%` `<<` `>>` `&` `&^` |
| 2 | `+` `-` `\|` `^` |
| 3 | `==` `!=` `<` `<=` `>` `>=` |
| 4 | `&&` |
| 5 | `\|\|` |

Пример: `2 + 3 * 4` равно `14`, а не `20`. Для ясности используй скобки — они бесплатны.

## 5. Преобразование типов

В Go преобразования явные, автоматических приведений нет.

```go
var i int = 42
var f float64 = float64(i) // int -> float64
var back int = int(f)      // float64 -> int (дробь отбрасывается)

var r rune = 'A'
s := string(r)             // rune -> string: "A"

// string -> int / float через strconv
age, err := strconv.Atoi("25")      // 25, nil
score := strconv.Itoa(98)           // "98"
dist, err := strconv.ParseFloat("3.14", 64) // 3.14, nil
```

Строка и срез байт легко конвертируются друг в друга:

```go
bytes := []byte("hello")  // [104 101 108 108 111]
text := string(bytes)     // "hello"
```

Ошибка: `var x int = 3; var y int64 = 4; // x + y` — не скомпилируется. Нужно приводить: `x + int(y)`.

## 6. Строки

Строка в Go — это неизменяемая последовательность байт в кодировке UTF-8.

Ключевые факты:
- `len(s)` возвращает **количество байт**, а не символов.
- Индексация `s[i]` возвращает **один байт** (`byte`), а не символ.
- `range` по строке идёт по **рунам** (символам) и возвращает `(индекс_в_байтах, rune)`.

```go
s := "Привет"
fmt.Println(len(s))   // 12 (6 букв по 2 байта!)
fmt.Println(s[0])     // 208 (первый байт буквы 'П')

for i, ch := range s {
    fmt.Printf("%d -> %c\n", i, ch) // 0 -> П, 2 -> р, 4 -> и ...
}

// конкатенация
full := "Go" + " " + "rules"
```

Пакет `strings` — основной инструмент для работы со строками:

| Функция | Что делает | Пример |
|---------|-----------|--------|
| `strings.Contains(s, sub)` | содержит ли подстроку | `Contains("привет", "ив")` → `true` |
| `strings.HasPrefix / HasSuffix` | начинается/заканчивается | `HasPrefix("go", "g")` → `true` |
| `strings.Index(s, sub)` | индекс подстроки (-1 если нет) | `Index("abc", "b")` → `1` |
| `strings.Replace(s, old, new, n)` | замена (n раз; -1 = все) | `Replace("aaa", "a", "b", 2)` → `"bba"` |
| `strings.Split(s, sep)` | разбить на срез | `Split("a,b", ",")` → `["a","b"]` |
| `strings.Join(slice, sep)` | собрать из среза | `Join([]string{"a","b"}, "-")` → `"a-b"` |
| `strings.Fields(s)` | разбить по пробелам/переносам | `Fields("a b  c")` → `["a","b","c"]` |
| `strings.TrimSpace(s)` | убрать пробелы по краям | `TrimSpace("  x ")` → `"x"` |
| `strings.ToUpper / ToLower` | регистр | `ToUpper("go")` → `"GO"` |
| `strings.Repeat(s, n)` | повторить n раз | `Repeat("ab", 3)` → `"ababab"` |

```go
words := strings.Fields("  учить Go  каждый день ")
fmt.Println(len(words)) // 4
line := strings.Join(words, " | ")
```

## 7. fmt и форматирование

Функция `fmt.Printf` форматирует вывод по шаблону (verb — глагол форматирования):

| Verb | Назначение | Пример вывода |
|------|-----------|--------------|
| `%v` | значение по умолчанию | `42`, `hello` |
| `%+v` | структура с именами полей | `{Name:Алиса Age:25}` |
| `%#v` | Go-представление | `main.Person{Name:"Алиса", Age:25}` |
| `%T` | тип значения | `int`, `string` |
| `%d` | целое в десятичной системе | `42` |
| `%b` | в двоичной | `101010` |
| `%o` | в восьмеричной | `52` |
| `%x` | в шестнадцатеричной | `2a` |
| `%c` | символ (rune) | `A` |
| `%f` | float без экспоненты | `3.140000` |
| `%.2f` | float, 2 знака после точки | `3.14` |
| `%e` | экспоненциальный вид | `3.14e+00` |
| `%g` | компактный вид float | `3.14` |
| `%s` | строка | `hello` |
| `%q` | строка в кавычках | `"hello"` |
| `%t` | bool | `true` |
| `%p` | адрес указателя | `0xc0000100a0` |
| `%5d` | ширина 5 (дополнение пробелами справа) | `"   42"` |
| `%-5d` | ширина 5, выравнивание влево | `"42   "` |

```go
fmt.Printf("%s учится %d часа в день\n", "Алиса", 3)
fmt.Printf("Число: %05d\n", 42)          // 00042
fmt.Printf("Пи: %.3f\n", 3.14159)        // 3.142
fmt.Printf("Тип: %T, значение: %v\n", 4, 4)

name := fmt.Sprintf("Привет, %s!", "Мир") // вернуть строку, не печатая
```

`Sprintf` возвращает отформатированную строку, `Fprintf` пишет в переданный поток (например, `os.Stdout` или файл), `Println` печатает через пробел с переводом строки.

## 8. Ввод с клавиатуры

Три основных способа прочитать ввод:

```go
// 1. fmt.Scan — читает значение до пробела
var name string
fmt.Scan(&name)

// 2. bufio.Reader — вся строка до переноса
reader := bufio.NewReader(os.Stdin)
line, _ := reader.ReadString('\n')

// 3. bufio.Scanner — построчное чтение, самый удобный
scanner := bufio.NewScanner(os.Stdin)
scanner.Scan()          // ждёт строку
text := scanner.Text()  // без символа переноса
```

Типичный цикл чтения строк:

```go
scanner := bufio.NewScanner(os.Stdin)
for scanner.Scan() {
    line := scanner.Text()
    if line == "стоп" {
        break
    }
    fmt.Println("Вы ввели:", line)
}
if err := scanner.Err(); err != nil {
    fmt.Println("Ошибка чтения:", err)
}
```

## 9. Условия детально

### 9.1 if / else if / else

Круглые скобки не нужны, фигурные — обязательны.

```go
score := 85

if score >= 90 {
    fmt.Println("Отлично")
} else if score >= 75 {
    fmt.Println("Хорошо")
} else {
    fmt.Println("Пробуй ещё")
}
```

### 9.2 if с инициализацией

Переменная живёт только внутри условия — так нельзя случайно использовать её снаружи:

```go
if age, err := strconv.Atoi("25"); err != nil {
    fmt.Println("не число")
} else {
    fmt.Println("возраст:", age)
}
// здесь age уже недоступна
```

### 9.3 switch (переключатель)

```go
day := "СБ"

switch day {
case "ПН", "ВТ", "СР", "ЧТ":
    fmt.Println("будний день")
case "СБ", "ВС":
    fmt.Println("выходной")
default:
    fmt.Println("такого дня нет")
}
```

- `case` может содержать несколько значений через запятую.
- Проламывания (fallthrough) по умолчанию **нет** — в отличие от C, Go сам делает `break`.
- Блок `switch {}` без выражения работает как цепочка условий:

```go
n := 42
switch {
case n < 0:
    fmt.Println("отрицательное")
case n == 0:
    fmt.Println("ноль")
default:
    fmt.Println("положительное")
}
```

- Есть ещё `switch` по типу (type switch), если тип неизвестен:

```go
var v any = "строка"
switch v.(type) {
case string:
    fmt.Println("это строка")
case int:
    fmt.Println("это число")
default:
    fmt.Println("что-то другое")
}
```

## 10. Циклы детально

### 10.1 Три формы for

```go
// классический трёхчастный
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// аналог while
n := 5
for n > 0 {
    fmt.Println(n)
    n--
}

// бесконечный
for {
    // выход через break или return
}
```

### 10.2 break и continue

```go
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue // пропустить чётные
    }
    if i == 7 {
        break // остановиться на 7
    }
    fmt.Println(i) // 1 3 5
}
```

### 10.3 Метки для вложенных циклов

`break` и `continue` прерывают только текущий цикл. Чтобы выйти из внешнего — нужна метка:

```go
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 1 {
            continue outer // следующий i, пропустить j==1
        }
        fmt.Println(i, j)
    }
}
// печать: 0 0, 1 0, 2 0
```

### 10.4 range для коллекций

| Коллекция | Переменные | Примечание |
|-----------|-----------|------------|
| срез/массив | `index, value` | `value` — копия элемента |
| map | `key, value` | порядок не гарантирован |
| строка | `byteIndex, rune` | индекс — в байтах |
| канал | `value` | до закрытия канала |

```go
for i, v := range []int{10, 20, 30} {
    fmt.Println(i, v)
}
for key := range map[string]int{"a": 1} {
    fmt.Println(key)
}
```

## 11. Функции детально

### 11.1 Именованные возвращаемые значения и naked return

```go
func divMod(a, b int) (quot, rem int) {
    quot = a / b
    rem = a % b
    return // naked return: возвращает quot и rem
}
func main() {
    q, r := divMod(17, 5)
    fmt.Println(q, r) // 3 2
}
```

### 11.2 Вариативные аргументы (variadic)

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

fmt.Println(sum(1, 2, 3))       // 6
fmt.Println(sum(1, 2, 3, 4, 5)) // 15

nums := []int{5, 5, 5}
fmt.Println(sum(nums...))       // распаковка среза: 15
```

### 11.3 Функции как значения и замыкания

```go
// функция-значение
mul := func(a, b int) int { return a * b }
fmt.Println(mul(3, 4)) // 12

// замыкание: функция "запоминает" внешнюю переменную
func makeCounter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

counter := makeCounter()
fmt.Println(counter()) // 1
fmt.Println(counter()) // 2
fmt.Println(counter()) // 3
```

### 11.4 Немедленно вызываемая анонимная функция

```go
result := func(a, b int) int {
    if a > b {
        return a
    }
    return b
}(10, 3)
fmt.Println(result) // 10
```

## 12. defer — отложенный вызов

`defer` откладывает выполнение функции до выхода из текущей функции. Чаще всего используется для закрытия ресурсов (файлы, мьютексы).

```go
f, err := os.Open("file.txt")
if err != nil {
    log.Fatal(err)
}
defer f.Close() // закроется автоматически при выходе из функции
```

Два важных правила:
1. Аргументы вычисляются **в момент вызова** `defer`, а не в конце.
2. Отложенные вызовы выполняются по принципу LIFO — последний объявленный выполнится первым.

```go
func main() {
    x := 1
    defer fmt.Println("x в конце:", x) // выведет 1 (значение уже скопировано)

    defer fmt.Println("вторым")
    defer fmt.Println("первым") // выполнится раньше "вторым"
    fmt.Println("основной код")
    x = 100
}
// вывод: основной код, первым, вторым, x в конце: 1
```

## 13. Срезы детально

### 13.1 make и внутренности

```go
a := make([]int, 5)     // len=5, cap=5, элементы 0..0
b := make([]int, 0, 5)  // len=0, cap=5 (готов под 5 элементов)
c := append(b, 1, 2, 3) // len=3
fmt.Println(len(a), cap(a)) // 5 5
fmt.Println(len(b), cap(b)) // 0 5
```

`len` — сколько элементов сейчас, `cap` — сколько вмещает без перераспределения.

### 13.2 append и копирование

```go
s := []int{1, 2, 3}
s = append(s, 4)     // [1 2 3 4]
s = append(s, 5, 6)  // несколько сразу

// когда cap исчерпан, append создаёт НОВЫЙ массив (обычно в ~2 раза больше)
// когда места хватает — пишет в существующий
```

### 13.3 copy

```go
src := []int{1, 2, 3, 4}
dst := make([]int, len(src))
n := copy(dst, src)
fmt.Println(n, dst) // 4 [1 2 3 4]
```

### 13.4 Слайсинг делит один и тот же массив

```go
x := []int{1, 2, 3, 4, 5}
y := x[1:4]  // [2 3 4] — но это БУКВАЛЬНО те же элементы
y[0] = 99    // теперь x[1] тоже 99!
fmt.Println(x) // [1 99 3 4 5]
```

Поэтому осторожно с `append` на срезе: он может перезаписать соседние элементы исходного среза.

### 13.5 Удаление элемента

```go
idx := 2
s := []int{10, 20, 30, 40}
s = append(s[:idx], s[idx+1:]...) // [10 20 40]
```

## 14. Map детально

```go
m := make(map[string]int)
m["один"] = 1

// создание с литералом
m2 := map[string]int{"a": 1, "b": 2}

// чтение с проверкой наличия (comma-ok idiom)
val, ok := m2["a"]  // val=1, ok=true
val2, ok2 := m2["z"] // val2=0, ok2=false

// удаление
delete(m2, "a")

// длина
fmt.Println(len(m2)) // 1
```

Важные правила:
- Порядок обхода `for range` случайный — не полагайся на него.
- Map нельзя сравнивать через `==` (только с `nil`).
- Запись в `nil` map вызывает panic — всегда создавай через `make`.
- Вложенные map нужно создавать на каждом уровне:

```go
users := make(map[string]map[string]int)
users["Алиса"] = make(map[string]int)
users["Алиса"]["очки"] = 5
```

Частая задача — счётчик вхождений:

```go
counts := map[string]int{}
for _, w := range []string{"go", "go", "java"} {
    counts[w]++
}
fmt.Println(counts) // map[go:2 java:1]
```

## 16. Методы

Метод — функция с получателем (receiver) — типом, над которым она вызывается.

```go
type Rectangle struct {
    W, H float64
}

// value receiver — работает с копией
func (r Rectangle) Area() float64 {
    return r.W * r.H
}

// pointer receiver — меняет оригинал
func (r *Rectangle) Scale(f float64) {
    r.W *= f
    r.H *= f
}

func main() {
    rect := Rectangle{10, 5}
    fmt.Println(rect.Area()) // 50
    rect.Scale(2)            // Go сам понимает, что нужен &rect
    fmt.Println(rect.W)      // 20
}
```

Когда нужен **value**, когда **pointer** receiver:

| Ситуация | Receiver |
|----------|----------|
| метод только читает данные | value |
| метод меняет поле структуры | pointer |
| структура большая (копий дорого) | pointer |
| хочется единообразного доступа | pointer |

## 17. Пакеты и экспорт

```go
// файл: math/ops.go
package ops

// Экспортируется (имя с большой буквы)
func Add(a, b int) int { return a + b }

// Приватная (имя с маленькой буквы)
func secret() {}

// файл: main.go
package main

import "example.com/myapp/math/ops"

func main() {
    fmt.Println(ops.Add(2, 3))
}
```

Правила:
- Видимость за пределами пакета определяется только заглавной буквой.
- Каждая программа имеет `package main` и функцию `main()` — точку входа.
- `go mod init имя.модуля` создаёт модуль, `import` тогда ссылается на путь модуля.
- Импортированные пакетам дают псевдонимы: `import f "fmt"` → `f.Println`.
- `_` в импорте — только ради побочного эффекта: `import _ "net/http/pprof"`.

## 18. Ошибки

В Go ошибка — это обычное значение (интерфейс `error`). Её проверяют явно, а не бросают исключения.

```go
import "errors"

// создать ошибку
err := errors.New("что-то пошло не так")

// ошибка с форматированием
err2 := fmt.Errorf("пользователь %d не найден", 42)

// "обернуть" ошибку (сохранить исходную для errors.Is)
if err != nil {
    return fmt.Errorf("чтение файла: %w", err)
}
```

Шаблон, который используется постоянно:

```go
func parseAge(s string) (int, error) {
    age, err := strconv.Atoi(s)
    if err != nil {
        return 0, fmt.Errorf("некорректный возраст %q: %w", s, err)
    }
    if age < 0 {
        return 0, errors.New("возраст не может быть отрицательным")
    }
    return age, nil
}

func main() {
    age, err := parseAge("abc")
    if err != nil {
        fmt.Println("Ошибка:", err)
        return
    }
    fmt.Println("Возраст:", age)
}
```

Проверка ошибок:
- `err != nil` — ошибка произошла.
- `errors.Is(err, target)` — совпадает ли с известной (или в цепочке `%w`).
- `errors.As` — является ли ошибкой конкретного типа.

## 19. Стиль и инструменты

- Форматирование: `gofmt`, `go fmt ./...` — обязательный стиль, дебатов нет.
- Статическая проверка: `go vet ./...`.
- Имена — camelCase, аббревиатуры заглавными (`userID`, а не `userid`, `APIKey`).
- Экспорт — только если имя нужно снаружи пакета.
- Комментарий к экспортируемому имени должен начинаться с его имени.
- Однострочные `if` без скобок, `switch` вместо длинных цепочек `else if`.

## Типичные ошибки в Unit 1 (их стоит знать заранее)

1. **Неиспользуемая переменная или импорт** — программа не скомпилируется.
   ```go
   x := 5 // declared and not used
   // убрать переменную или использовать: fmt.Println(x)
   ```

2. **`:=` вне функции** — недоступна, нужно `var`.
   ```go
   // package-уровне: name := "A" — ошибка!
   var name = "A" // верно
   ```

3. **`++` внутри выражения** — инкремент это инструкция.
   ```go
   // y := x++ — ошибка
   x++ // отдельной строкой — ок
   ```

4. **Деление целых как вещественных**: `5 / 2` даёт `2`, а не `2.5`.

5. **Смешивание типов**: `int` и `int64` нельзя складывать без приведения.

6. **Сравнение float на равенство** — `0.1+0.2 == 0.3` ложно (погрешность). Сравнивай через разницу `< epsilon`.

7. **`len("Привет")` == 12**, а не 6 — это байты. По символам иди через `range`.

8. **`s[0]` — байт, а не символ**; для кириллицы получишь число, а не «П».

9. **Игнорирование ошибок** через `_` и пустую проверку. Ошибки проверяй всегда.

10. **Запись в nil map** — паника.
    ```go
    var m map[string]int
    m["x"] = 1 // panic: assignment to entry in nil map
    ```

11. **Сравнение срезов через `==`** — не скомпилируется (сравнивай `len` и элементы).

12. **`range` возвращает копию** — изменение `v` не меняет исходный срез.
    ```go
    for _, v := range nums {
        v = 0 // бесполезно
    }
    ```

13. **Shadowing (затенение)**: `:=` внутри блока создаёт новую переменную, скрывая внешнюю.
    ```go
    x := 10
    if x := 20; true { // здесь свой x
        fmt.Println(x) // 20
    }
    fmt.Println(x) // 10
    ```

14. **Позиционный литерал структуры** — порядок полей легко перепутать. Используй именованные.
    ```go
    // p := Person{"2020-01-01", 25} — молча скомпилируется, если совпадут типы!
    p := Person{Name: "Алиса", Born: "2000-05-01", Age: 25}
    ```

15. **`break` во вложенном цикле** выходит только из внутреннего. Для внешнего — метки (см. раздел 10.3).

16. **Массив передаётся по значению (копия)** — функция не изменит внешний массив. Срез — изменяет общие данные.

17. **`append` на слайсе, делящем массив**, может перезаписать соседние элементы (раздел 13.4). Копируй явно, если нужно.

18. **Забыт `default` в switch** — обычно нормально, но при разборе ввода незадачливые значения уйдут незамеченными.

## Вопросы для самопроверки

1. **Вопрос:** какие zero values у `int`, `string`, `bool`, среза и map?
   **Ответ:** `0`, `""`, `false`, `nil`, `nil`. С nil-срезом можно работать, запись в nil map паникует.

2. **Вопрос:** чем отличается `int` от `int64`?
   **Ответ:** `int` платформенно-зависимый (32 или 64 бита), `int64` всегда 64 бита. Без приведения их нельзя сложить.

3. **Вопрос:** почему `7 / 2 == 3`?
   **Ответ:** при делении целых на целые результат целочисленный, дробь отбрасывается. Для 3.5 нужно `7.0 / 2`.

4. **Вопрос:** почему `len("Привет") == 12`?
   **Ответ:** строка хранится в UTF-8 и `len` считает байты; каждая кириллическая буква занимает 2 байта.

5. **Вопрос:** чем массив отличается от среза?
   **Ответ:** массив имеет фиксированную длину, объявляется `[5]int` и передаётся по значению (копируется). Срез — динамическая «надстройка» над массивом, передаётся по ссылке.

6. **Вопрос:** что такое `rune`?
   **Ответ:** синоним `int32`, кодовая точка Unicode (символ). Строки в `range` разбираются по рунам.

7. **Вопрос:** что происходит при `append`, когда ёмкость исчерпана?
   **Ответ:** выделяется новый массив (обычно вдвое больше), элементы копируются, старый массив может быть удалён сборщиком мусора.

8. **Вопрос:** почему `range` по map идёт в случайном порядке?
   **Ответ:** так решено намеренно, чтобы программы не зависели от внутреннего порядка хранения (он не обязан быть стабильным). Сортируй ключи явно, если нужен порядок.

9. **Вопрос:** в чём разница `break` и `continue`?
   **Ответ:** `break` завершает цикл полностью, `continue` переходит к следующей итерации (пропуская остаток тела).

10. **Вопрос:** когда нужен pointer receiver у метода?
    **Ответ:** когда метод должен изменить поля структуры, или структура большая и копировать дорого. Обычно методы пишут именно на указатель.

11. **Вопрос:** как проверить, есть ли ключ в map, не путая с zero value?
    **Ответ:** через comma-ok: `v, ok := m["key"]` — `ok == false`, если ключа нет.

12. **Вопрос:** что делает `defer` и в каком порядке выполняются отложенные вызовы?
    **Ответ:** откладывает выполнение до конца функции; вызовы выполняются в обратном порядке (LIFO). Удобно для `Close()`, `Unlock()`.

13. **Вопрос:** зачем нужны `&` и `*`?
    **Ответ:** `&x` — адрес переменной; `*p` — значение по адресу (разыменование). Указатели позволяют функции менять вызывающий код.

14. **Вопрос:** как превратить строку в число и обработать неудачу?
    **Ответ:** `strconv.Atoi("25")` возвращает `(int, error)`; проверяй `err != nil` и обрабатывай, а не игнорируй.

15. **Вопрос:** почему Go не использует исключения?
    **Ответ:** ошибка в Go — обычное значение, которое видно в сигнатуре функции (`(T, error)`). Так обработка ошибок явная и предсказуемая, ничего не теряется «тихо».

## Глоссарий

| Термин | Определение |
|--------|------------|
| пакет (`package`) | группа связанных файлов с одним именем пакета; `main` — исполняемый |
| модуль (`module`) | набор пакетов с общим `go.mod` |
| точка входа | функция `main()` в пакете `main`, с которой стартует программа |
| переменная | именованное хранилище данных; объявляется через `var` или `:=` |
| константа | неизменяемое значение, объявляется через `const` |
| zero value | значение по умолчанию: `0`, `""`, `false`, `nil` |
| оператор | символ или ключевое слово для операции: `+`, `==`, `&&` |
| инструкция | действие программы: присваивание, `break`, `defer` |
| выражение | то, что вычисляется в значение: `a+b`, `fmt.Sprint(x)` |
| тип | множество значений и операций над ними |
| `string` | неизменяемая последовательность байт (UTF-8) |
| `rune` | синоним `int32`, символ Unicode |
| `byte` | синоним `uint8`, байт |
| массив | фиксированная последовательность элементов `[N]T` |
| срез (`slice`) | динамическая последовательность `[]T` с `len`/`cap` |
| map | словарь «ключ → значение» |
| структура (`struct`) | тип с именованными полями |
| поле | именованная переменная внутри структуры |
| метод | функция с получателем (receiver) |
| receiver | параметр, на котором вызывается метод: `(r Rectangle)` |
| указатель | адрес области памяти; `&` — взять адрес, `*` — разыменовать |
| `defer` | отложить вызов до конца функции (LIFO) |
| `error` | интерфейс ошибок; его проверяют через `err != nil` |
| `gofmt` / `go fmt` | автоформатирование кода в официальном стиле |
| `go vet` | статический анализ на подозрительные места |
| `strconv` | конвертация строк и чисел (`Atoi`, `Itoa`, `ParseFloat`) |
| `iota` | генератор последовательных констант в блоке `const` |
| shadowing | затенение: внутренняя переменная скрывает внешнюю с тем же именем |
