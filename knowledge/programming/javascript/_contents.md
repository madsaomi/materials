# JAVASCRIPT — учебный маршрут

Проходите основы → структуры и практику → углубление. В каждой главе сначала прочитайте учебное ядро, затем решите задачу без ключа. Большой справочник и старый банк решений остаются доступны для расширения темы.

## Последовательность уроков

### Урок 01. Массив и функция без изменения входа

Const запрещает переназначение переменной, но не делает массив неизменяемым. Новый результат можно строить отдельно. For…of получает значения; for…in перебирает перечисляемые ключи и для этой задачи не подходит.

[Объяснение](foundation/unit-01/syntax.md) · [Самостоятельная практика](foundation/unit-01/practice.md)

### Урок 02. Async-функция и явный результат ошибки

Async-функция возвращает Promise. Await внутри try позволяет обработать отклонение. Для учебной проверки передаём загрузчик аргументом, поэтому сеть и браузер не нужны. Проверка структуры данных и обработка отказа — разные обязанности.

[Объяснение](practice/unit-02/syntax.md) · [Самостоятельная практика](practice/unit-02/practice.md)

### Урок 03. Замыкание и независимое состояние

Замыкание сохраняет доступ к лексической среде. Каждый вызов фабрики создаёт отдельное состояние, а функции одного возвращённого объекта обращаются к общей для них переменной.

[Объяснение](advanced/unit-03/syntax.md) · [Самостоятельная практика](advanced/unit-03/practice.md)

## Результат курса

Соберите небольшой проект с явно описанным входом и результатом. Добавьте проверки нормального поведения, пустого входа и ожидаемого отказа. Три учебных ядра не заменяют всего языка и не являются свидетельством профессионального уровня.
