## 1. Словари

```python
person = {
    "name": "Алиса",
    "age": 25,
    "city": "Москва"
}
print(person["name"])       # Алиса
person["job"] = "инженер"   # добавить
for k, v in person.items():
    print(f"{k}: {v}")

# get() — безопасный доступ
print(person.get("phone", "Нет номера"))
```

Словарь (`dict`) хранит пары «ключ → значение». Ключи должны быть **хешируемыми** (неизменяемыми): `str`, `int`, `float`, `tuple`, `frozenset`. Нельзя ключами: `list`, `dict`, `set`.

### Основные методы

| Метод | Что делает | Пример |
|---|---|---|
| `d[k]` | доступ к значению (KeyError, если ключа нет) | `d["name"]` |
| `d.get(k, default)` | доступ без ошибки | `d.get("phone", 0)` |
| `d.setdefault(k, v)` | вернуть значение; если ключа нет — вставить `v` | `d.setdefault("x", [])` |
| `d.pop(k)` | удалить ключ и вернуть значение | `d.pop("age")` |
| `d.popitem()` | удалить и вернуть последнюю пару | `d.popitem()` |
| `d.update(other)` | влить другой словарь/пары | `d.update({"a": 2})` |
| `d.keys()` / `d.values()` / `d.items()` | представления для итерации | `for k in d.keys()` |
| `k in d` | проверка существования ключа | `"name" in d` |
| `del d[k]` | удалить ключ | `del d["city"]` |
| `d.clear()` | очистить словарь | `d.clear()` |
| `d.copy()` | поверхностная копия | `c = d.copy()` |
| `len(d)` | количество пар | `len(d)` |

### Примеры выше базового

```python
d = {"a": 1, "b": 2}

# setdefault — удобно при группировке
d.setdefault("c", 0)     # 0, теперь d = {'a':1,'b':2,'c':0}
d.setdefault("a", 99)    # 1 — ключ уже есть, значение не трогаем

# pop возвращает значение и удаляет ключ
seen = d.pop("b", None)  # 2, "b" больше нет

# Объединение словарей (Python 3.9+)
d1 = {"x": 1, "y": 2}
d2 = {"y": 10, "z": 3}
merged = d1 | d2                    # {'x':1,'y':10,'z':3}
same = {**d1, **d2}                 # то же самое через распаковку

# Dict comprehension
squares = {x: x**2 for x in range(1, 6)}
# {1:1, 2:4, 3:9, 4:16, 5:25}
```

### Когда использовать словарь

- Нужен поиск по ключу за O(1)
- Нужна связь «идентификатор → объект» (база, кэш, счётчики)
- Группировка данных по категории

## 2. Множества

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a & b)   # пересечение: {3, 4}
print(a | b)   # объединение: {1, 2, 3, 4, 5, 6}
print(a - b)   # разность: {1, 2}
```

Множество (`set`) — неупорядоченная коллекция **уникальных** хешируемых элементов. Поиск `in` выполняется за O(1), поэтому множества идеальны для проверки вхождения и удаления дубликатов.

### Операции и методы

| Синтаксис | Метод | Название | Результат (для `a={1,2}`, `b={2,3}`) |
|---|---|---|---|
| `a \| b` | `a.union(b)` | объединение | `{1, 2, 3}` |
| `a & b` | `a.intersection(b)` | пересечение | `{2}` |
| `a - b` | `a.difference(b)` | разность | `{1}` |
| `a ^ b` | `a.symmetric_difference(b)` | симметричная разность | `{1, 3}` |
| `a <= b` | `a.issubset(b)` | подмножество | `False` |
| `a >= b` | `a.issuperset(b)` | надмножество | `False` |
| `a.isdisjoint(b)` | — | нет общих | `False` |

### Изменение множества

```python
s = {1, 2, 3}
s.add(4)             # добавить один
s.update([5, 6])     # добавить несколько
s.remove(2)          # KeyError, если элемента нет
s.discard(99)        # НЕ бросает ошибку, если нет
x = s.pop()          # удаляет случайный элемент
s.clear()            # очистить полностью
```

### Чем полезны

```python
# 1) Удаление дубликатов
words = ["я", "ты", "он", "я", "мы"]
unique = list(set(words))        # порядок НЕ сохранится!
print(unique)

# 2) Быстрая проверка вхождения
banned = {"stop", "exit", "end"}
if word.lower() in banned:
    print("запрещено")

# 3) Set comprehension
squares_of_even = {x**2 for x in range(10) if x % 2 == 0}
# {0, 4, 16, 36, 64}

# 4) Неизменяемое множество — frozenset (можно в ключи словаря)
fs = frozenset([1, 2, 3])
```

> Внимание: `{1, 2, 3}` — это множество, а `{}` — пустой СЛОВАРЬ. Пустое множество — `set()`.

## 3. Генераторы списков

```python
squares = [x**2 for x in range(10)]
evens = [x for x in range(20) if x % 2 == 0]
matrix = [[i*j for j in range(5)] for i in range(5)]
```

Компрехеншены (comprehensions) заменяют цикл `for` + `append` одной строкой и работают быстрее.

### Формы

| Конструкция | Результат |
|---|---|
| `[x**2 for x in range(10)]` | список квадратов: `[0,1,4,9,...]` |
| `[x for x in range(20) if x % 2 == 0]` | только чётные |
| `[x if x > 0 else 0 for x in nums]` | замена значений по условию |
| `[x for x in nums if x > 0]` | фильтрация |
| `[(x, y) for x in range(3) for y in range(3)]` | вложенные циклы |
| `{x % 10 for x in [12, 22, 33]}` | set comprehension: `{2,3}` |
| `{x: x**2 for x in range(5)}` | dict comprehension |
| `(x**2 for x in range(10))` | **генераторное выражение** — ленивое, почти не тратит память |

### Вложенные циклы и матрицы

```python
# Пары без одинаковых индексов
pairs = [(x, y) for x in range(3) for y in range(3) if x != y]
# [(0,1),(0,2),(1,0),(1,2),(2,0),(2,1)]

# Таблица умножения 5×5
table = [[i * j for j in range(1, 6)] for i in range(1, 6)]
# [
#  [1, 2, 3, 4, 5],
#  [2, 4, 6, 8, 10],
#  ...
# ]

# Плоский список из матрицы
flat = [x for row in table for x in row]
```

### Правила хорошего тона

- Не используйте компрехеншены сложнее двух уровней вложенности — станет нечитаемо
- Для побочных эффектов (например, `print`) используйте обычный цикл
- Генераторное выражение `(...)` экономнее списка: передавайте его напрямую в `sum`, `max`, `any`, `all`

```python
total = sum(x**2 for x in range(10**6))   # почти ноль памяти
has_big = any(x > 100 for x in nums)
```

## 4. Lambda-функции

```python
add = lambda a, b: a + b
print(add(3, 5))  # 8

numbers = [1, 5, 2, 8, 3]
sorted_nums = sorted(numbers, key=lambda x: -x)
print(sorted_nums)  # [8, 5, 3, 2, 1]
```

Lambda — анонимная функция из **одного выражения**. Эквивалент:

| Обычная функция | Lambda |
|---|---|
| `def sq(x): return x * x` | `sq = lambda x: x * x` |
| `def last(s): return s[-1]` | `last = lambda s: s[-1]` |

### Применение без присваивания (типичное)

```python
nums = [1, 2, 3, 4, 5]

# map — применить функцию к каждому элементу
print(list(map(lambda x: x**2, nums)))             # [1,4,9,16,25]

# filter — оставить по условию
print(list(filter(lambda x: x % 2 == 0, nums)))    # [2,4]

# key — для сортировки и поиска экстремумов
words = ["яблоко", "ананас", "арбуз", "дыня"]
print(max(words, key=len))           # самое длинное слово
print(min(words, key=lambda s: s.count("а")))   # меньше всего "а"

people = [("Анна", 22), ("Борис", 19), ("Вера", 25)]
print(sorted(people, key=lambda p: p[1]))   # по возрасту
```

### Ограничения lambda

- Только одно выражение: невозможны `if/elif/else` блоки, циклы, `return`
- Тернарник допустим: `lambda x: "да" if x > 0 else "нет"`
- Нельзя аннотации типов
- Нет докстрок, имя в трейсбэках (`<lambda>`)

```python
# Если логика сложнее — лучше обычная def
def classify(score):
    if score >= 90: return "A"
    if score >= 75: return "B"
    return "C"
```

Как только тело lambda перестаёт помещаться в одну строку — заменяйте на `def`. Это не «менее круто», это читаемость.

## 5. Работа с файлами

```python
# Чтение
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
    lines = f.readlines()

# Запись
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, World!\n")

# with — автоматически закрывает файл
```

### Режимы открытия

| Режим | Действие | Файл создаётся? | Позиция |
|---|---|---|---|
| `"r"` | чтение | нет (FileNotFoundError) | начало |
| `"w"` | запись (перезапись!) | да | начало |
| `"a"` | добавление в конец | да | конец |
| `"x"` | создание, ошибка если существует | да | начало |
| `"r+"` | чтение + запись | нет | начало |
| `"w+"` | чтение + запись | да | начало |
| `"a+"` | чтение + запись | да | конец |
| `"rb"/"wb"` | бинарные данные | — | — |

Всегда передавайте `encoding="utf-8"` — иначе на Windows/кодировках возможны `UnicodeDecodeError` и битые русские строки.

### Методы файлового объекта

| Метод | Что делает |
|---|---|
| `f.read()` | весь текст строкой |
| `f.read(n)` | первые `n` символов |
| `f.readline()` | одна строка |
| `f.readlines()` | список строк |
| `for line in f:` | итерация по строкам (экономит память) |
| `f.write(s)` | запись строки, возвращает кол-во символов |
| `f.writelines([...])` | запись списка строк |
| `f.tell()` | текущая позиция |
| `f.seek(n)` | перейти на позицию |
| `f.flush()` | сбросить буфер на диск |
| `f.close()` | закрыть (автоматически в `with`) |

```python
# Итерация по строкам — лучший способ для больших файлов
with open("data.txt", "r", encoding="utf-8") as f:
    for i, line in enumerate(f, 1):
        print(f"{i}: {line.rstrip()}")
```

> `with` гарантирует закрытие файла даже при исключении. Не используйте `f = open(...)` без `with`.

## 6. Обработка ошибок

```python
try:
    x = int(input("Число: "))
    result = 10 / x
    print(result)
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("На ноль делить нельзя!")
else:
    print("Всё хорошо!")
finally:
    print("Блок выполняется всегда")
```

### Семантика блоков

| Блок | Когда выполняется |
|---|---|
| `try` | код, который может упасть |
| `except X` | при исключении типа X |
| `except (A, B)` | при A или B |
| `except:` / `except Exception:` | любой тип (использовать осторожно) |
| `else` | только если не было исключения |
| `finally` | всегда (закрытие ресурсов, лог) |

Если не перехватить — исключение пробрасывается вверх и при отсутствии обработчика прерывает программу.

### Частые типы исключений

| Исключение | Пример ситуации |
|---|---|
| `ZeroDivisionError` | `10 / 0` |
| `ValueError` | `int("abc")`, `int("3.14")` |
| `TypeError` | `1 + "a"` |
| `KeyError` | `d["нет_такого"]` |
| `IndexError` | `lst[999]` |
| `FileNotFoundError` | `open("путь")` без файла |
| `AttributeError` | `None.upper()` |
| `ImportError` / `ModuleNotFoundError` | `import no_such_module` |
| `KeyboardInterrupt` | `Ctrl+C` |

```python
# Перехват нескольких типов одним блоком
try:
    value = input("Число: ")
    print(100 / float(value))
except (ValueError, ZeroDivisionError) as e:
    print(f"Ошибка: {e}")

# Доступ к самому объекту исключения
try:
    1 / 0
except ZeroDivisionError as err:
    print("поймано:", err)
```

> Порядок `except` важен: от специфичного к общему. `except Exception` должен идти последним.

## 8. Коллекции из collections

Модуль `collections` добавляет специализированные контейнеры.

```python
from collections import Counter, defaultdict, deque, namedtuple

# Counter — автоматический счётчик
words = "яблоко груша яблоко слива груша яблоко".split()
cnt = Counter(words)
print(cnt)                     # Counter({'яблоко': 3, 'груша': 2, 'слива': 1})
print(cnt.most_common(2))      # [('яблоко', 3), ('груша', 2)]
print(cnt["ананас"])           # 0 — нет KeyError!
cnt.update(["яблоко"])         # досчитать

# defaultdict — значение по умолчанию при обращении к новому ключу
chapters = defaultdict(list)
for ch, verse in [(1, "a"), (1, "b"), (2, "c")]:
    chapters[ch].append(verse)   # видели: тот же setdefault, но короче
print(chapters)                # defaultdict(<class 'list'>, {1: ['a','b'], 2: ['c']})

# deque — очередь, операции за O(1) с обоих концов
q = deque([1, 2, 3], maxlen=5)
q.append(4)          # справа
q.appendleft(0)      # слева
print(q)             # deque([0, 1, 2, 3, 4], maxlen=5)

# namedtuple — кортеж с именованными полями
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y, p[0])     # 3 4 3 — доступ и по имени, и по индексу
x, y = p                  # распаковка работает
```

| Коллекция | Зачем нужна |
|---|---|
| `Counter` | частоты элементов, топ-N |
| `defaultdict` | группировка без `setdefault` и проверок `if` |
| `deque` | очередь/стек с быстрыми концами |
| `namedtuple` | лёгкие структуры данных без написания класса |
| `OrderedDict` | (редко) словарь с гарантией порядка (обычный dict уже упорядочен) |

## 9. Копирование объектов

Главная ловушка: `b = a` не создаёт копию, а делает вторую ссылку на тот же объект.

```python
a = [1, 2, 3]
b = a                 # НЕ копия — один список на двоих
b.append(4)
print(a)              # [1, 2, 3, 4] — a тоже «изменился»!

# Поверхностные копии (новый верхний слой)
c = a.copy()
d = list(a)
e = a[:]
f = a + []
```

Проблема поверхностной копии — вложенные объекты всё ещё общие:

```python
x = [[1, 2], [3, 4]]
y = x.copy()          # новый внешний список
y[0].append(99)
print(x)              # [[1, 2, 99], [3, 4]] — вложенный список общий!

import copy
z = copy.deepcopy(x)  # полная независимая копия
z[0].append(0)
print(x)              # без изменений
```

| Вид копии | Способ | Поведение |
|---|---|---|
| ссылка | `b = a` | объект один, всё общее |
| поверхностная | `list(a)`, `a[:]`, `a.copy()`, `dict(d)` | верхний слой новый, вложенные — общие |
| глубокая | `copy.deepcopy(a)` | всё полностью независимо |

Для неизменяемых типов (`int`, `str`, `tuple`) копирование не нужно — они всё равно не меняются.

## 10. Сортировка и key-функции

```python
nums = [3, 1, 4, 1, 5, 9, 2]

nums.sort()                  # сортирует на месте (in-place), возвращает None
sorted_nums = sorted(nums)   # возвращает НОВЫЙ список

print(sorted(nums, reverse=True))      # [9,5,4,3,2,1,1]

# key — чем сортировать (не переделывая элементы)
words = ["яблоко", "банан", "арбуз", "дыня"]
print(sorted(words, key=len))                # по длине
print(sorted(words, key=lambda s: s[-1]))    # по последней букве

# Сортировка объектов по полю
people = [("Анна", 22), ("Борис", 19), ("Вера", 25)]
by_age = sorted(people, key=lambda p: p[1])

# Словари как элементы
users = [
    {"name": "Иван", "age": 30},
    {"name": "Аня", "age": 25},
    {"name": "Пётр", "age": 30},
]
users.sort(key=lambda u: u["age"])          # по возрасту

# Несколько критериев: кортеж как ключ — сначала возраст, затем имя
users.sort(key=lambda u: (u["age"], u["name"]))

# Наоборот: второй критерий по убыванию
users.sort(key=lambda u: (-u["age"], u["name"]))
```

### Факты

- `sorted()` работает с любым итерируемым: `sorted(set(...))`, `sorted(d.keys())`
- Сортировка **стабильна**: равные элементы сохраняют исходный порядок
- По умолчанию — по возрастанию; `reverse=True` разворачивает
- `min()` / `max()` тоже принимают `key`

## 11. Распаковка и операторы «звёздочек»

```python
# Множественное присваивание
x, y, z = 1, 2, 3        # кортеж справа
a, b = b, a              # классический swap без третьей переменной

# Расширенная распаковка (* почти всё берёт список)
head, *tail = [1, 2, 3, 4]          # head=1, tail=[2,3,4]
first, *middle, last = [1,2,3,4,5]  # first=1, middle=[2,3,4], last=5
a, b, *rest = range(10)             # rest=[2..9]

# _ — «не интересует»
_, second = (1, 2)
```

### `*` и `**` в вызовах функций

```python
def total(a, b, c):
    return a + b + c

args = [1, 2, 3]
print(total(*args))            # total(1,2,3)

kwargs = {"a": 1, "b": 2, "c": 3}
print(total(**kwargs))         # total(a=1,b=2,c=3)
```

### Слияние словарей через `**`

```python
d1 = {"x": 1, "y": 2}
d2 = {"y": 10, "z": 3}
merged = {**d1, **d2, "w": 0}   # {'x':1,'y':10,'z':3,'w':0}
```

### В параметрах функций

```python
def log(msg, *args, **kwargs):
    print("MSG:", msg)
    print("доп. позиционные:", args)   # кортеж
    print("доп. именованные:", kwargs) # словарь

log("привет", 1, 2, level="info")
```

## 12. enumerate, zip, map, filter, reduce

### enumerate — индекс вместе со значением

```python
name = "Питон"
for i, ch in enumerate(name, start=1):
    print(i, ch)
# 1 П
# 2 и
# 3 т
# 4 о
# 5 н
```

### zip — склейка итерабильных

```python
keys = ["name", "age", "city"]
vals = ["Аня", 30, "Москва"]
d = dict(zip(keys, vals))
# {'name':'Аня','age':30,'city':'Москва'}

left = [1, 2, 3]
right = [10, 20, 30]
for a, b in zip(left, right):
    print(a + b)                 # 11 22 33

# Транспонирование матрицы
matrix = [[1, 2, 3], [4, 5, 6]]
transposed = list(zip(*matrix))  # [(1,4),(2,5),(3,6)]
```

### map и filter

```python
nums = [1, 2, 3, 4]

print(list(map(str, nums)))                    # ['1','2','3','4']
print(list(map(lambda x: x * 10, nums)))       # [10,20,30,40]

print(list(filter(lambda x: x > 2, nums)))     # [3,4]
print(list(filter(str.isdigit, ["1","a","22"])))# ['1','22']

# zipped: квадраты чётных
result = map(lambda x: x**2, filter(lambda x: x % 2 == 0, nums))
print(list(result))                            # [4, 16]
```

### reduce — свёртка (functools)

```python
from functools import reduce

print(reduce(lambda a, b: a * b, [1, 2, 3, 4]))   # 24
print(reduce(lambda a, b: a + b, ["a","b","c"]))  # 'abc'
print(reduce(max, [3, 1, 4, 1, 5]))               # 5
```

| Функция | Действие | Пример |
|---|---|---|
| `enumerate(seq, start)` | нумерует элементы | `for i, x in enumerate(ns):` |
| `zip(a, b)` | попарно склеивает | `dict(zip(keys, vals))` |
| `map(f, seq)` | применяет f ко всем | `list(map(int, ["1","2"]))` |
| `filter(p, seq)` | оставляет | `list(filter(None, data))` |
| `reduce(f, seq)` | накапливает | произведение, сумма |

> `map`/`filter` в Python — ленивые итераторы; оберните в `list()` для материализации.

## 13. Форматирование строк

Современный стандарт — f-строки (Python 3.6+).

```python
price = 1234.5678
print(f"{price:.2f}")      # 1234.57 — два знака после запятой
print(f"{price:,.2f}")     # 1,234.57 — разделители тысяч
print(f"{price:>10}")      # выравнивание вправо до 10 символов
print(f"{price:<10.2f}")   # влево с точностью
print(f"{price:^10.2f}")   # по центру

print(f"{123:04d}")        # 0123 — заполнение нулями
print(f"{255:x}")          # ff — hex
print(f"{0.256:.1%}")      # 25.6% — проценты
print(f"{7_000_000_000:,}")# 7,000,000,000

name = "Аня"
print(f"Привет, {name.upper()}!")   # выражения прямо в строке
print(f"{name = }")                 # name = 'Аня'  (3.8+)

# format() — старый способ, встречается в коде
print("{} + {} = {}".format(2, 3, 5))
print("{0} и {1}, снова {0}".format("яйцо", "мука"))
print("{name}, {age}".format(name="Иван", age=30))
```

### Спецификаторы кодирования

| Спецификатор | Что делает |
|---|---|
| `:d` | целое число |
| `:.2f` | вещественное с 2 знаками |
| `:,.2f` | с разделителями тысяч |
| `.1%` | проценты |
| `:x`, `:o`, `:b` | hex / octal / binary |
| `:>10`, `:<10`, `:^10` | выравнивание |
| `:04d` | ведущие нули |
| `name =` | имя переменной + значение |

> Никогда не склеивайте строки через `+` в f-контексте: `"x = " + str(x) + "!"` — читается хуже и медленнее.

## 15. Исключения: иерархия и свои типы

### Дерево классов

```
BaseException
├── SystemExit
├── KeyboardInterrupt
└── Exception
    ├── ArithmeticError
    │   └── ZeroDivisionError
    ├── LookupError
    │   ├── IndexError
    │   └── KeyError
    ├── ValueError
    ├── TypeError
    ├── AttributeError
    ├── OSError
    │   └── FileNotFoundError
    └── ...
```

`except Exception` ловит почти всё, кроме `SystemExit` и `KeyboardInterrupt` — как раз то, что обычно нужно. Ловля `BaseException` подавляет даже `Ctrl+C` и почти всегда ошибка дизайна.

### Свои исключения

```python
class UnitsError(ValueError):
    """Своя ошибка — наследуем от логически близкого типа."""

def check_units(units):
    if units < 0:
        raise UnitsError(f"unit-count нельзя {units}")
    return units

try:
    check_units(-5)
except UnitsError as e:
    print("Поймал свою ошибку:", e)
except ValueError:
    print("И обычный ValueError тоже обработаю")
```

### `raise ... from` — цепочки причин

```python
try:
    obj = json.loads("не json вовсе")
except json.JSONDecodeError as e:
    raise ValueError("не нашёл конфига") from e   # причина сохранится в __cause__

# raise без аргумента — перевыбросить текущее исключение
```

### contextlib — хелперы для контекстов

```python
from contextlib import suppress, contextmanager

# Подавление конкретных ошибок
with suppress(FileNotFoundError):
    open("нет_файла.txt").read()      # тихо пропустим

# Свой контекстный менеджер-декоратором
@contextmanager
def opened(path, mode):
    f = open(path, mode, encoding="utf-8")
    try:
        yield f
    finally:
        print("закрываю")
        f.close()

with opened("out.txt", "w") as f:
    f.write("пример")
```

## 16. Генераторы и yield

Функция с `yield` — генератор: выполняется лениво, по одному значению за раз.

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)                       # 3 2 1

g = countdown(3)
print(next(g))                     # 3 — значения тянутся по требованию
print(next(g))                     # 2
```

### Генераторные выражения

```python
# Круглые скобки вместо квадратных → лениво, память O(1)
total = sum(x**2 for x in range(10**6))     # 1 млн значений — не строит список

numbers = (x * 2 for x in range(5))
print(list(numbers))                        # [0, 2, 4, 6, 8]
```

### Продвинутое

```python
import itertools

# Бесконечный генератор
def even_numbers():
    n = 0
    while True:
        yield n
        n += 2

first_five = list(itertools.islice(even_numbers(), 5))   # [0,2,4,6,8]

# yield from — делегирование в другой итератор
def chain(*iters):
    for it in iters:
        yield from it

print(list(chain([1, 2], "ab")))    # [1, 2, 'a', 'b']
```

| Генератор | Список |
|---|---|
| `(x for x in ...)` | `[x for x in ...]` |
| ленивый, один элемент в памяти | все в памяти |
| можно итерировать один раз | можно много раз |
| подходит для больших данных | удобен для многократного использования |

> Один проход: генератор «исчерпывается». Не берите повторные итерации из исчерпанного генератора.

## 17. Сравнение структур данных

### Асимптотическая сложность

| Операция | `list` | `set` | `dict` |
|---|---|---|---|
| доступ по индексу / ключу | O(1) | — | O(1) |
| поиск (`in`) | O(n) | **O(1)** | **O(1)** |
| добавление в конец | O(1)* | O(1) | O(1) |
| вставка в начало/середину | O(n) | — | — |
| удаление по значению | O(n) | O(1) | O(1) |
| порядок элементов | есть | нет | порядок вставки (3.7+) |
| дубликаты | возможны | нет | ключи уникальны |

`*` — амортизированно; при исчерпании буфера список пересоздаётся.

### Что выбрать

| Задача | Структура |
|---|---|
| «Проверить, есть ли элемент» десятки тысяч раз | `set` |
| «Подсчитать частоты» | `dict` или `Counter` |
| Порядок + дубликаты + индексы | `list` |
| Пара значений как целое | `tuple` |
| Очередь/SL: работать с обоих концов | `deque` |
| Более 1 млн чисел для арифметики | `numpy.ndarray` |

### Строки особые

Замена символов и срезы строк возвращают **новые** строки — строки неизменяемы. Построение длинной строки в цикле через `+=` — плохо:

```python
# Медленно: строки неизменяемы, каждый += создаёт новую
s = ""
for w in words:
    s += w

# Быстро
s = "".join(words)
```

## 18. Типичные ошибки (20)

| № | Ошибка | Как правильно |
|---|---|---|
| 1 | `b = a` и изменение `b` меняет `a` | копия: `a[:]`, `list(a)`, `copy.deepcopy` |
| 2 | `d["key"]` где ключа может не быть | `d.get("key", default)` |
| 3 | Изменение списка во время `for x in lst:` | итерировать по `list(lst)` или копии |
| 4 | `[1,2]` как ключ словаря → TypeError | заменить на кортеж `(1,2)` |
| 5 | `{}` как «пустое множество» | `{}` = словарь, пустое множество = `set()` |
| 6 | Сравнение строк/чисел через `is` | `is` — для идентичности и None, `==` — для равенства |
| 7 | Изменяемый аргумент по умолчанию `def f(x=[])` | `def f(x=None)` + `if x is None: x = []` |
| 8 | `int("3.14")` | это ValueError — нужен `float("3.14")`, потом `int(...)` |
| 9 | Запись в `"w"` вместо добавления → данные стёрты | `"a"` — добавить в конец |
| 10 | `remove` вместо `pop` / `del` | `remove` — по значению, `pop` — по индексу, `del lst[i]` |
| 11 | `except Exception` раньше `except ValueError` | порядок: частные → общие |
| 12 | `nums.sort()` и использование возврата | `sort()` возвращает `None`; новый список даёт только `sorted()` |
| 13 | `t = (1)` — это int, не кортеж | `(1,)` — обязательна запятая |
| 14 | `lst[500]` за пределы | проверять длину или использовать `lst[-1]` осознанно |
| 15 | Перемешивание `and/or` и `&/|` | `&` `\|` — для множеств и битов, `and/or` — логические |
| 16 | `open(f)` без `encoding` | указывайте `encoding="utf-8"` |
| 17 | Генератор исчерпан, повторный `for` пуст | заведите `list(gen)` заранее |
| 18 | `=` в условии `if x = 5` (SyntaxError) | `==` |
| 19 | Вложенный компрехеншен на 4 уровня | разбивайте на циклы или функции |
| 20 | `input()` считан как число, а нужен `int` | `input()` всегда возвращает строку — приводите явно |

## 19. Вопросы для собеседования (15+)

| № | Вопрос | Ответ |
|---|---|---|
| 1 | Чем `list` отличается от `set`? | list — упорядоченный, допускает дубликаты, `in` за O(n); set — уникальный, неупорядоченный, `in` за O(1) |
| 2 | Что вернёт `d.get("x")`, если ключа нет? | `None`; с `d.get("x", 0)` — значение по умолчанию |
| 3 | Чем `sort()` отличается от `sorted()`? | `sort()` меняет список и возвращает None; `sorted()` возвращает новую отсортированную копию |
| 4 | Какой тип может быть ключом словаря? | любой хешируемый (неизменяемый): str, int, tuple, frozenset |
| 5 | Что такое компрехеншен? | выражение, строящее коллекцию одной строкой: `[f(x) for x in data if cond]` |
| 6 | В чём ограничение lambda? | одно выражение, без блоков/return/аннотаций; для сложного — `def` |
| 7 | Зачем `with open(...)`? | гарантированное закрытие файла ресурсов при любом исходе |
| 8 | Чем глубокое копирование отличается от поверхностного? | у поверхностного вложенные объекты общие, у глубокого — независимые |
| 9 | Чем отличаются `remove`, `pop`, `del`? | remove — по значению; pop — по индексу и возвращает элемент; del — по индексу/срезу/ключу без возврата |
| 10 | Как одной строкой посчитать частоты слов? | `Counter(text.split())` или `{w: text.split().count(w) for w in set(...)}` |
| 11 | Что будет при `int("abc")`? | `ValueError` |
| 12 | Когда кортеж лучше списка? | неизменяемые данные, компактность, ключи словаря |
| 13 | Что такое `key` в `sorted()`? | функция, считающая критерий сортировки: `sorted(data, key=len)` |
| 14 | Как объединить два словаря в 3.9+? | `d1 \| d2` или `{**d1, **d2}` |
| 15 | Когда выполняется `else` в `try`? | только если исключения не было; в `for/while` — при отсутствии `break` |
| 16 | Что делает `Counter.most_common(3)`? | три самых частых элемента в виде списка пар |
| 17 | Чем `frozenset` отличается от `set`? | frozenset неизменяем, может быть ключом/элементом множества |
| 18 | Что такое генератор и чем он выгоден? | функция с `yield`, вычисляет лениво, экономит память на больших данных |

## 20. Глоссарий

| Термин | Определение |
|---|---|
| Коллекция | контейнер для хранения набора значений |
| Итерируемый (iterable) | объект, по которому можно идти `for`: list, tuple, str, dict, set, генератор |
| Хешируемый | объект с неизменным `hash()` — пригоден для ключа dict / элемента set |
| Хеш-таблица | структура данных: поиск по ключу за O(1) |
| Сложность O(1) / O(n) | время операции не зависит / зависит линейно от размера |
| Comprehension | компактное выражение-конструктор коллекции |
| Generator expression | ленивый компрехеншен в круглых скобках |
| Lambda | анонимная функция из одного выражения |
| Key-функция | функция, по результату которой сравнивают элементы при сортировке |
| Кортеж (tuple) | неизменяемая упорядоченная коллекция |
| Множество (set) | неупорядоченная коллекция уникальных элементов |
| Словарь (dict) | маппинг «ключ → значение» |
| Распаковка (unpacking) | извлечение значений коллекции в переменные: `a, b = pair` |
| Исключение (exception) | событие, прерывающее нормальный ход программы |
| Трейсбэк (traceback) | сводный отчёт об ошибке в консоли |
| Копия поверхностная | новый контейнер, вложенные объекты общие |
| Копия глубокая | полностью независимая копия всех уровней |
| Генератор (generator) | функция с `yield`, выдающая значения по одному |
| Исчерпание генератора | генератор отдал последнее значение и больше не даёт данных |
| Стабильная сортировка | равные элементы не меняют исходный относительный порядок |
| Модуль `collections` | набор продвинутых контейнеров стандартной библиотеки |
| Модуль `pathlib` | работа с путями файлов как с объектами |
