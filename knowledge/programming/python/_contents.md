# PYTHON — учебный маршрут

Проходите основы → структуры и практику → углубление. В каждой главе сначала прочитайте учебное ядро, затем решите задачу без ключа. Большой справочник и старый банк решений остаются доступны для расширения темы.

## Последовательность уроков

### Урок 01. Функция, цикл и накопитель

Функция получает данные через параметр и возвращает результат. Локальный счётчик создаётся при каждом вызове. Условие выбирает элементы; действие внутри него определяет, считаем мы их или складываем.

[Объяснение](foundation/unit-01/syntax.md) · [Самостоятельная практика](foundation/unit-01/practice.md)

### Урок 02. Словарь частот и нормализация

Словарь связывает ключ с количеством. Нормализация определяет, какие записи считаются одинаковыми. Здесь убираем крайние пробелы и меняем регистр; это простая политика для учебных слов, а не полный лингвистический анализ.

[Объяснение](practice/unit-02/syntax.md) · [Самостоятельная практика](practice/unit-02/practice.md)

### Урок 03. Объект и инвариант состояния

Корзина хранит количества товаров. Инвариант: добавляемые количества — положительные целые числа. Неудачное действие не должно менять состояние. Подчёркивание в имени атрибута — соглашение, а не защита доступа.

[Объяснение](advanced/unit-03/syntax.md) · [Самостоятельная практика](advanced/unit-03/practice.md)

## Результат курса

Соберите небольшой проект с явно описанным входом и результатом. Добавьте проверки нормального поведения, пустого входа и ожидаемого отказа. Три учебных ядра не заменяют всего языка и не являются свидетельством профессионального уровня.
