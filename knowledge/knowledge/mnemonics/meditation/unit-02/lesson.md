# Meditation — Unit 2: Техники (урок)

> Личный конспект практики. Unit 2 посвящён техникам: сканирование тела (body scan), метта-медитация (любящая доброта), медитация на звук, медитация ходьбы (кинхин), дзадзен (дзен), визуализация. В этом уроке собраны: пошаговые инструкции, подробный разбор затруднений (20+), научная база, шаблоны дневника практикующего, 21-дневный план старта, связь техник с психологией, йогой и философией, экзаменационные вопросы и вопросы для рефлексии.

## Базовые техники юнита (краткая шпаргалка)

## Сканирование тела (Body Scan)

Техника: последовательное внимание к разным частям тела.

```
1. Лягте или сядьте удобно
2. Закройте глаза, сделайте 3 глубоких вдоха
3. Направьте внимание на стопы
4. Почувствуйте: тепло, холод, пульсация, касание
5. Медленно поднимитесь выше: голени → колени → бёдра
6. Живот → грудь → спина → плечи
7. Руки: пальцы → кисти → предплечья → плечи
8. Шея → лицо → голова
9. Почувствуйте тело целиком
10. 10-20 минут
```

## Метта-медитация (Любящая доброта)

Развитие сострадания.

```
1. Сядьте удобно, закройте глаза
2. Повторяйте мысленно:
   "Пусть я буду счастлив"
   "Пусть я буду здоров"
   "Пусть я буду в безопасности"
3. Затем направьте на близкого человека:
   "Пусть [имя] будет счастлив..."
4. Затем на нейтрального человека
5. Затем на всех живых существ
6. 15-30 минут
```

## Медитация на звук

```
1. Сядьте или лягте
2. Закройте глаза
3. Слушайте звуки вокруг без оценки
4. Не ищите звуки — просто замечайте
5. Шум дождя, ветра, машин, тишина
6. 10-15 минут
```

## Медитация ходьбы (Кинхин)

```
1. Встаньте прямо, руки за спиной
2. Сделайте медленный вдох
3. На выдохе — шаг правой ногой
4. Почувствуйте: подъём, движение, касание
5. Продолжайте очень медленно
6. Координация: шаг = вдох или шаг = выдох
7. 15-30 минут
```

## Дзадзен (Дзен-медитация)

Практика сидячей медитации в традиции дзен.

```
1. Сядьте в лотос/пол-лотоса
2. Руки в космической мудре (дзэннин-ин)
3. Взгляд опущен (не закрыт) — смотреть на 1 м вперёд
4. Дыхание: медленное, естественное, животом
5. Мысли приходят и уходят — не вовлекаться
6. При отвлечении: "счёт дыхания 1-10", затем снова
7. 20-40 минут
```

## Визуализация

```
1. Закройте глаза
2. Представьте место покоя:
   лес, пляж, горы, комната
3. Детализируйте: цвета, звуки, запахи, ощущения
4. Побудьте в этом месте 5-10 минут
5. Медленно вернитесь
```

## Выбор техники

| Ситуация | Техника |
|----------|---------|
| Ум слишком активен | Дыхание, сканирование тела |
| Грусть, злость | Метта |
| Усталость | Визуализация |
| Бессонница | Body scan лёжа |
| В движении | Медитация ходьбы |
| Ежедневная практика | Дзадзен/дыхание |

## 1. Пошаговые инструкции

Развёрнутые протоколы. Каждая инструкция построена так, чтобы её можно было выполнить с первого раза, не глядя в конспект.

### 1.1 Подготовка к практике (общий протокол)

| Этап | Что сделать | Время |
|------|-------------|-------|
| 1. Место | Постоянный угол комнаты, коврик или подушка | 1 мин |
| 2. Одежда | Свободная, не сдавливает живот и шею | 1 мин |
| 3. Таймер | Поставить мягкий звон без резкого сигнала | 30 сек |
| 4. Поза | Сесть с прямой, но не жёсткой спиной | 1 мин |
| 5. Настрой | Намерение: «в ближайшие N минут я занимаюсь только практикой» | 30 сек |
| 6. Проверка тела | Мысленно пробежаться: шея, плечи, челюсть — отпустить зажимы | 1 мин |
| 7. Дыхание-разминка | 3 медленных глубоких вдоха-выдоха | 1 мин |
| 8. Начало | Переключить внимание на основную технику | — |

Принцип: подготовка — часть практики, а не потерянное время.

### 1.2 Сканирование тела — детальный протокол

1. Лягте на спину (подушка под головой), руки вдоль тела, ноги на ширине плеч.
2. Закройте глаза. Три глубоких вдоха; на каждом выдохе — «отпускаю день».
3. Направьте внимание в левую стопу. Побудьте там 20–40 секунд.
4. Замечайте любые ощущения: тепло, холод, пульсацию, тяжесть, покалывание, касание.
5. Если ощущений нет — осознайте их отсутствие («здесь ничего не чувствую» — тоже ответ).
6. Левая стопа → левая голень → левое бедро → левый таз.
7. То же по правой стороне: стопа → голень → бедро → таз.
8. Поясница → низ живота → живот → грудная клетка.
9. Грудь: замечайте дыхание — рёбра расширяются и опускаются сами.
10. Спина от таза к лопаткам → позвоночник целиком.
11. Левая рука: пальцы → кисть → предплечье → плечо. То же справа.
12. Шея → горло → лицо: челюсть, губы, щёки, глаза, лоб.
13. Темя → вся голова целиком.
14. Соберите внимание в целостное ощущение всего тела (1–2 минуты).
15. Завершите: пошевелите пальцами рук и ног, потянитесь, откройте глаза.

Правила: не менять ощущения, не «исправлять» боль — только наблюдать. Отвлёкся — вернись к последней точке, на которой закончил.

### 1.3 Метта — детальный протокол

1. Сядьте устойчиво, закройте глаза, рука на груди (опционально — тепло ладони).
2. Представьте себя как маленького ребёнка или лучшую версию себя.
3. Повторяйте мысленно медленно, со смыслом:
   - «Пусть я буду в безопасности»
   - «Пусть я буду здоров»
   - «Пусть я буду счастлив»
   - «Пусть я живу с лёгкостью»
4. Теперь близкий человек (часто — член семьи или друг): вызовите его образ, приятное воспоминание.
   - «Пусть [имя] будет в безопасности»
   - «Пусть [имя] будет здоров»
   - «Пусть [имя] будет счастлив»
   - «Пусть [имя] живёт с лёгкостью»
5. Нейтральный человек: продавец, сосед, кассир (не вызывает ни симпатии, ни раздражения).
6. «Трудный» человек — тот, с кем конфликт. Начните с осторожного «Пусть [имя] будет в безопасности».
7. Все живые существа: безлично — «Пусть все существа будут счастливы, здоровы, в безопасности».
8. Завершите возвращением к себе на несколько вдохов.

Примечания:

- Не форсировать «тепло» — оно появляется с регулярностью, а не по приказу.
- Если сильные эмоции — уменьшить радиус до себя и близких, работу с «трудным» человеком отложить.

### 1.4 Медитация на звук — детальный протокол

1. Удобная поза, глаза можно держать полуоткрытыми.
2. Не настраивайтесь на «тишину» — просто принятие того, что звучит сейчас.
3. Разделите звуки на категории (по желанию):
   - фоновые (шум дороги, вентиляция, холодильник);
   - близкие (собственное дыхание, одежда);
   - внутренние (звон в ушах, пульс) — замечайте без тревоги.
4. Удерживайте фокус на звуке как на объекте; при отвлечении возвращайтесь к слушанию.
5. Не «охотиться» за звуками, не начинать громче слушать — просто оставаться открытым.
6. В конце — минута внимания к тишине или паузам между звуками.

Цель: осознать, что звуки приходят и уходят сами; ум не обязан на них реагировать.

### 1.5 Медитация ходьбы — детальный протокол

1. Найдите прямую дорожку 10–20 метров (комната, коридор, двор).
2. Стойте на одном краю, руки за спиной или свободно вдоль тела.
3. Перенесите вес на правую ногу; медленно поднимите левую пятку.
4. Перенесите вес вперёд, поставьте стопу полностью — «касание».
5. Обратный путь, затем разворот (разворот тоже осознанный: остановка, поворот).
6. Координация с дыханием: шаг на вдохе, шаг на выдохе (или 2–3 шага на фазу).
7. Отмечайте три момента шага: подъём → движение → постановка.
8. Если темп ускоряется — специально замедлитесь вполовину.
9. Через 5 минут добавьте название: мысленно «поднимаю, двигаю, ставлю» (как в випассане).

Ошибки новичков: спешка, взгляд по сторонам, попытка «красиво идти» вместо наблюдения.

### 1.6 Дзадзен — детальный протокол

1. Поза: лотос, полулотос, бирманская, на коленях (сэйдза) или устойчивая на стуле без спинки.
2. Таз выше колен (подушка 5–10 см) — спина выпрямляется сама.
3. Руки: коссёку-инн — левая в правой, большие пальцы слегка касаются, образуя овал.
4. Линия ушей, плеч и бедра — на одной вертикали; подбородок подобран.
5. Взгляд: полуоткрытые глаза, направлены вниз под углом примерно 45 градусов, на 1 метр вперёд.
6. Язык прижат к нёбу; челюсть расслаблена.
7. Дыхание животом (танден): вдох и выдох длинные, естественные. Считать выдохи от 1 до 10, затем снова.
8. Мысли приходят и уходят — не вовлекаться, не продолжать, не оценивать.
9. Если ум улетел: заметить, вернуться к счёту. Возвращение и есть практика.
10. По окончании — глубокий вздох, лёгкая разминка ног (кровообращение после лотоса).

Сaculture установка сото: «не медитирую ради достижения — просто сижу». Риндзай добавляет работу с коаном.

### 1.7 Визуализация — детальный протокол

1. Начните с простого образа: точка света между бровями или тёплое свечение в груди.
2. Расширьте до «места силы» — реального (дача, море) или вымышленного (лес, гора, комната).
3. Детализируйте по каналам чувств:
   - зрение: цвета, свет, детали;
   - слух: звуки (ветер, вода, тишина);
   - обоняние: запахи (лес, соль, трава);
   - осязание: температура, ветер, поверхность.
4. Если образ «размывается» — мягко вернитесь к самому убедительному элементу (например, свету или поверхности).
5. Погрузитесь на 5–10 минут, сохраняя телесное ощущение сидящего тела.
6. Возвращение: «фотоаппарат» образа плавно тускнеет, внимание возвращается в комнату.
7. Откройте глаза через пару осознанных вдохов — без рывка.

Важно: визуализация — не галлюцинация, а мысленный образ; он может быть неярким и это нормально.

### 1.8 Завершение сессии (важная недооценённая деталь)

| Шаг | Действие |
|-----|----------|
| 1 | Сигнал таймера — не открывать глаза мгновенно |
| 2 | Вдох-выдох, заметить состояние: спокойствие, сонливость, раздражение |
| 3 | Мысленно подытожить: «такой была сессия — и это нормально» |
| 4 | Пошевелить пальцами, потянуться |
| 5 | Встать медленно, сохранять осознанность первые минуты после |

Зачем: состояние после практики «просачивается» в день. Резкий разрыв теряет эффект интеграции.

### 1.9 Как выбрать технику под состояние

| Состояние | Первая линия | Почему |
|-----------|-------------|--------|
| Высокая тревога | Сканирование тела лёжа | Возвращает внимание в тело, уводит из «мысленного шторма» |
| Растерянность, хаос в голове | Счёт дыхания до 10 | Простейшая якорная техника |
| Гнев, обида | Метта | Тренирует противоположную эмоцию |
| Усталость, выгорание | Медитация на звук | Мягкая, не требует усилия |
| Бессонница | Body scan лёжа | Снимает тонус, снижает руминацию |
| Работа с телом, боль | Сканирование тела | Учит разделять боль и реакцию |
| Творческий застой | Открытое наблюдение / звук | Расширяет перцептивный фокус |

## 2. Затруднения и их преодоление (20+)

Медитация — не «нирвана с первого раза», а тренировка. Практически все трудности предсказуемы и решаемы. Ниже — карта типичных затруднений: симптом, причина, решение.

### 2.2 Три группы затруднений — глубже

**Группа А. Физиологические (№ 2, 3, 4, 10, 13, 15).**
Тело — первая линия практики. Если физический дискомфорт доминирует, он станет объектом, а не помехой: наблюдайте боль как ощущение (жжение, распирание, ноющая зона) и не спешите вставать. Но при острой боли поза меняется немедленно — боль и осознанность не спорят.

**Группа Б. Аффективные (№ 6, 7, 11, 12, 17, 22).**
Сильные эмоции во время практики — это не поломка, а недогруженная зона психики. Базовая линия реагирования: укоротить сессию, заземлиться (опора стоп, дыхание), переключиться на метту, не остаться с волнением один на один неопределённое время. Повторяющиеся панические реакции — повод для работы со специалистом (классическая випассана не является терапией).

**Группа В. Когнитивные (№ 1, 5, 8, 9, 16, 18, 20).**
Ум будет сомневаться, планировать, спорить. Это его работа. Наблюдайте сомнение как очередную мысль: «возникла мысль-сомнение, ушла». Не поддакивайте и не спорьте с ней. Регулярность (как для мышц) решает больше, чем интенсивность отдельной сессии.

### 2.3 Что делать при срыве графика

1. Не ждать «идеального понедельника» — следующая сессия сегодня, хотя бы 3 минуты.
2. Снизить планку: короткая практика лучше нулевой.
3. Разобрать причину: недосып, перегруз, сопротивление — и адресно поправить.
4. Использовать «два дня подряд» как красную линию: два пропуска подряд означают, что привычка под угрозой.
5. Бытовые техники (осознанная еда, звук, ходьба) как страховка в трудные дни.

### 3.5 Что наука НЕ доказала и ограничения

1. Не существует строгих доказательств «просветления» или сверхспособностей.
2. Плацебо-контроль в медитации методологически труден (нельзя «слепо» медитировать).
3. Многие эффекты корреляционные: практикующие в среднем здоровее по исходным характеристикам.
4. Долгие ретриты (10 дней+) изучены гораздо меньше, чем 8-недельные программы.
5. Есть меньшинство людей с нежелательными эффектами (обострение тревоги, дереализация).
6. Выборка классических исследований часто неоднородна (здоровые, студенты, минимизация).

Вывод для практика: лучшие обоснованные эффекты — снижение стресса и тревоги, внимание, профилактика рецидива депрессии. Держим режим «инструмента, а не панацеи».

## 4. Дневник практикующего

### 4.1 Зачем дневник

1. Видна реальная регулярность (не по памяти, а по записям).
2. Видны закономерности: в какое время практика глубже, от чего срывы.
3. Формируется подкрепление: серия дней подряд — сильный мотиватор.
4. Рефлексия в конце недели показывает прогресс, который «на месте» не замечается.

### 4.2 Ежедневная запись — шаблон

| Дата | Время | Техника | Минуты | Качество (1–5) | Помехи | Инсайт |
|------|-------|---------|--------|----------------|--------|--------|
| __.__ | утро/день/вечер | техника | 0–60 | 1–5 | что мешало | одна фраза-наблюдение |

### 4.3 Пример заполненного дня

| Дата | Время | Техника | Минуты | Качество | Помехи | Инсайт |
|------|-------|---------|--------|----------|--------|--------|
| 09.01 | утро | body scan | 15 | 4 | сел голодный, желудок отвлекал | замечаю, что мёрзну в стопах |
| 09.01 | вечер | метта (1 круг) | 7 | 3 | усталость, начало клонить в сон | к «трудному» человеку холодно |
| 10.01 | утро | дзадзен | 20 | 2 | ум весь в планах на день | вернулся к счёту раз 30 |
| 10.01 | день | звук | 10 | 5 | нет | оказалось, на улице идёт дождь |

### 4.4 Недельная сводка — шаблон

| Неделя | Сессий | Всего минут | Среднее качество | Пропуски | Лучшая техника | Одна мысль недели |
|--------|--------|-------------|------------------|----------|----------------|-------------------|
| 1 | 0 | 0 | 0 | 0 | — | — |

### 4.5 Месячная рефлексия — шаблон

1. Регулярность: сколько дней подряд максимум? Что помогло/мешало?
2. Какая техника даётся легче, какая труднее? Почему?
3. Изменилось ли состояние до/после практики? Примеры из дня?
4. Тело: сон, напряжение, боли — есть ли сдвиги?
5. Память и концентрация: замечаю ли различия в работе/учёбе?
6. Эмоции: на что реагирую спокойнее?
7. Что планирую изменить: время, длительность, набор техник?

| Техника | Лучшая длительность | Качество контакта (1–5) | Когда выбираю | Особые наблюдения |
|---------|---------------------|--------------------------|---------------|-------------------|

| Метта | 7–15 мин | — | Злость, самокритика | Тепло в груди приходит к 5-й минуте |
| Звук | 10 мин | — | Усталость, фон мешает | Лучше всего на балконе |
| Кинхин | 15 мин | — | День без движения | Легко ускоряюсь, следить за темпом |
| Дзадзен | 20 мин | — | Базовое утро | Спина «терпит» до 25 мин |

### 4.8 Советы по ведению

- Время сессии отмечать сразу после; фразу-инсайт — в вечерней пятиминутке, не позже.
- Не превращать дневник в «отчёт об успехах» — честная запись трудной сессии полезнее приукрашенной.
- Раз в неделю считать серии подряд — это усиливает привычку.
- Инсайты помечать отдельно («!») — они потом станут материалом для рефлексии.

## 5. 21-дневный план

### 5.1 Правила плана

1. Не пропускать два дня подряд.
2. Утро — оптимальное окно (до проверки телефона), но главное — стабильная точка.
3. После каждой сессии — строчка в дневнике (даже «5 минут, тяжело»).
4. Срывы не отменяют план: трёхминутная сессия и продолжаем.
5. Каждую неделю — одна короткая рефлексия (пять минут).

|--------|----------------------|----------------|

### 5.4 После 21 дня

- Держать базовое ядро: 15–20 минут ежедневно (дыхание/дзадзен).

- Следующий рубеж — 45-й и 90-й день: повторная таблица показателей (раздел 4.7).
- Рассмотреть: группу, ретрит, учителя — только при устойчивой ежедневной базе.

## 6. Связь с психологией, йогой и философией

### 6.1 Психология

**КПТ (когнитивно-поведенческая терапия).** Медитация тренирует децентрацию — умение видеть мысль как мысль, а не как факт. Это прямой аналог когнитивного переструктурирования: разница в том, что медитация работает не на уровне содержания, а на уровне отношения к менту.

**ACT (терапия принятия и ответственности).** Осознанность — ядро ACT: вместо борьбы с мыслью — признание и прохождение сквозь. Body scan и метта здесь — упражнения на «присутствие» и «наблюдающее Я».

**MBSR/MBCT.** Программы Кабат-Зинна (снижение стресса) и Сегала/Уильямса (профилактика рецидива депрессии) используют именно техники юнита: body scan, метта, осознанная ходьба, медитация на звук/дыхание. Итог 30-летней клинической практики: устойчивость к стрессу и профилактика депрессии — сильнейшие доказанные точки.

**DBT (диалектическая поведенческая терапия).** Навыки «осознанности» (what/skills: наблюдение, описание, участие) почти дословно повторяют протокол випассаны на начальном уровне.

**Нейропсихология.** Связка «внимание (PFC) — эмоции (амигдала)» — то, что медитация усиливает прямыми тренировками, а не только осознанием.

### 6.2 Йога

Восемь ступеней Патанджали («Йога-сутры») прямо картируются на техники юнита:

| Ступень | Сутра-смысл | Соответствие в юните |
|---------|-------------|----------------------|
| 1. Яма | Этические ограничения | Основа для метты (ненасилие начинается с себя) |
| 2. Нияма | Дисциплина, чистота | Дневник, регулярность плана |
| 3. Асана | Устойчивая поза | Дзадзен, позы для медитации |
| 4. Пранаяма | Контроль дыхания | Осознанное дыхание в протоколах |
| 5. Пратьяхара | Отвлечение чувств | Медитация на звук (принятие, не-реакция) |
| 6. Дхарана | Концентрация | Шаматха-ядро (счёт, дыхание) |
| 7. Дхьяна | Медитация (длительное удержание) | Дзадзен, визуализация |
| 8. Самадхи | Созерцание | Вершинная цель, к которой ведут техники |

Дополнительно: крийя-йога (ЙС II.1) — «тапас (усилие), свадхьяя (самоизучение), ишвара-пранидхана (доверие)» — ровно структура ежедневной практики юнита: усилие + дневник + ощущение «не я управляю». Визуализация перекликается с тратака и мантра-дхьяной; кинхин — с аштанга-виньясой как движущей медитацией.

### 6.3 Философия

**Буддизм (основа техник юнита).**

- Сатипаттхана-сутта: четыре основы осознанности — тело, чувства, ум, дхаммы. Body scan — практика первой основы.
- Метта-сутта: доброта как безусловное «пусть будет счастливо», от себя к миллионам существ.
- Три признака существования: анитья (непостоянство), дуккха (неудовлетворённость), анатта (не-Я) — что открывает длительная випассана в любой технике.
- Пять препятствий: желание, недоброжелательность, лень, растерянность, сомнение — ровно карта раздела «Затруднения» выше.

**Дзен.**

- Шикантадза («просто сидеть») — отказ от достижения как метафизический жест.
- Коаны (Мумонкан) — разрыв дискурса через парадокс («Хлопок одной ладони»).
- Медитация ходьбы (кинхин) в дзен идёт между периодами дзадзен — преемственность практики, а не перерыв.

**Стоицизм.**

- Инструментальное родство техник юнита со стоической «дискурсивной» практикой: наблюдение впечатлений без согласия (ассентиментация) — почти буквально описание мета-внимания медитации.
- Memento mori и premeditatio malorum — аналитические аналоги медитации на смерть у буддистов; разница: у стоиков — рассуждение, в буддизме — созерцание с изменением отношения к Я.
- Вечерний «экзамен» стоиков совпадает с дневниковой рефлексией раздела про дневник.

**Западная мысль.**

- Феноменология Гуссерля: «эпохе» (заключение естественной установки в скобки) — философский родственник наблюдающей позиции meditation.
- Монтень, Паскаль (достоинство человека в мышлении) — ранние пробы «интроспективной технологий».
- Спиноза: аффекты, понятые, не мучают — ранняя формула эмоциональной регуляции через наблюдение.

### 6.4 Практические пересечения (сводная таблица)

| Домен | Понятие | Техника юнита | Общий принцип |
|-------|---------|---------------|---------------|
| Психология | децентрация | наблюдение мыслей | мысль ≠ факт |
| Психология | межличностные навыки DBT | метта | я ≠ мои эмоции |
| Йога | пратьяхара | звук, тело | отвлечение чувств не-реакцией |
| Йога | дхарана/дхьяна | дыхание, дзадзен | удержание → поток |
| Буддизм | сатипаттхана | body scan | тело — первый объект осознавания |

## 7. Экзаменационные вопросы (10)

1. **Чем body scan отличается от дыхательной медитации и почему стоит начинать с него при тревоге?**
   Первый — перемещение внимания по телу (заземление в ощущениях), вторая — удержание одного объекта (дыхание). При тревоге сканирование уводит фокус из «мысленного шторма» в телесные ощущения.

2. **Опишите последовательность кругов метты согласно сутте, и почему «трудный» человек идёт не первым.**
   Порядок: я → близкий → нейтральный → трудный → все существа. Трудный первым вызвал бы отпорность и связку с гневом; сначала строится прочная добродетельность к себе и лёгким кругам.

3. **Какие три момента шага отмечаются в кинхин и зачем?**
   Подъём, движение, постановка. Фиксация трёх фаз замедляет автоматизм движения и удерживает внимание в теле.

4. **Что такое коссёку-инн и каково положение больших пальцев?**
   Мудра космоса: левая рука лежит на правой у живота, большие пальцы слегка соприкасаются (горизонтальный овал) — символ равновесия и собранности внимания.

5. **Почему в дзадзен взгляд полуоткрыт и направлен не вверх?**
   Полуоткрытый взгляд совмещает бодрствование и отсутствие внешней стимуляции; направленность вниз (~45°) уменьшает отвлечение на зрительные события, сохраняя интеграцию.

6. **Назовите три главных исследованных эффекта медитации и сопоставьте с техниками юнита.**
   Снижение стресса/тревоги (body scan, метта), улучшение внимания (дыхание, дзадзен), регуляция эмоций (наблюдение, метта). Источники: Хёльцель 2011, Зейдан 2010, Гойал 2014.

7. **Как медитация влияет на амигдалу, префронтальную кору и дефолт-режим сети?**
   Амигдала — снижение реактивности; PFC — рост активности/толщины; DMN — ослабление руминативного «фона» блуждания ума.

8. **Какие доказанные ограничения у исследований медитации?**
   Сложность плацебо-контроля, корреляционный характер ряда эффектов, слабая изученность длинных ретритов, редкие но реальные нежелательные эффекты у меньшинства.

9. **Проекция восьми ступеней Патанджали на техники юнита: приведите три примера соответствий.**
   Пратьяхара ↔ медитация на звук; дхарана ↔ счёт дыхания; дхьяна ↔ дзадзен/визуализация.

10. **Что общего между буддийской именно сатипаттханой и стоической ассентиментацией?**
    Обе указывают на паузу между стимулом и реакцией: наблюдение впечатления/ощущения без автоматического согласия или вовлечения — психологически одно и то же отношение.

## 12. Кейс-разборы: три сценария практики

### 12.1 Сценарий «Нет времени»

- Ситуация: работа/учёба, день забит, «медитировать некогда».
- Ответ: честно посчитать минимально возможную сессию — 3 минуты утром до звонка с телефоном за дверью.
- Последовательность: 3 мин дыхания + STOP-паузы в течение дня + осознанная ходьба по коридору.
- Ошибка, которую избегаем: ждать выходных и делать «марафон» — двухдневная пауза саботирует привычку.

### 12.2 Сценарий «Засыпаю в любой позе»

- Ситуация: хронический недосып; практика превращается в сон.
- Ответ: сначала гигиена сна (сдвинуть отбой), практику перенести на утро после подъёма, поза на стуле без спинки или стоя.
- Последовательность: поза стоя/стул, глаза открыты, во время жары — умыться перед сессией.
- Ошибка: сидеть лёжа и считать сон частью медитации — так теряется тренировочный компонент.

### 12.3 Сценарий «После практики хуже»

- Ситуация: всплывает тревога, гнев или грусть после сессии.
- Ответ: это не регресс, а контакт с материалом, который был подавлен; битва не в том, чтобы не видеть — а в том, как это обслужить.
- Последовательность: укоротить сессию вдвое, перейти на метту, добавить телесное заземление после (душ, прогулка), записать в дневник.
- Ошибка: продолжать в том же режиме «игнорирования» — логично свести практику к минимуму дискомфорта и при необходимости обратиться к специалисту.

## 14. Часто задаваемые вопросы к юниту (10)

1. **Можно ли практиковать два тела-скана в день?** Да, один в комфорт-режиме, второй — с большей детализацией; следить за переутомлением.
2. **Метта обязательна или можно только дыхание?** Достаточно одного ядра; метта пригодится при психологически трудных периодах и самокритике.
3. **Как долго удерживать взгляд в дзадзэн?** В течение сессии естественно полузакрывать/открывать; резкое перемещение — отвлечение.
4. **Что если я не вижу ярких образов в визуализации?** Норма: образ может быть «смысловым» контуром; практика сужает до одного убедительного элемента.
5. **Дышать животом или грудью?** В покое — живот (диафрагма); не насиловать, заметить, где вы дышите, и вернуть мягко.
6. **Можно ли медитировать под музыку?** Для концентарції — лучше тишину/естественные звуки; специальная музыка допустима в релакс-целях.
7. **Что делать с проектом будущих отвлекающих идей?** Запишите в дневник до сессии («парковка задач») — ум легче отпустит.
8. **Как часто смотреть в дневник?** Ежедневно одна строка; недельная сводка — пять минут; месячная рефлексия — полноценная.
9. **Имеет ли значение последовательность техник в неделе?** Да: стройте от стабильности (дыхание) к расширению (body scan/метта), затем к открытым.
10. **Когда идти на ретрит после юнита?** После 2–3 месяцев ежедневного ядра, при устойчивом дневнике и отсутствии острых психологических кризисов.

## 16. Практика в особые дни (детальные протоколы)

### 16.1 День сильной тревоги (весь протокол)

1. Начать не с сидения, а с ходьбы: кинхин 5 минут (заземление через стопы).
2. Выпить тёплого, не есть сладкое резко (скачки сахара усиливают тревогу).
3. Сесть: руки на коленях, стопы на полу — приоритет телесного контакта.
4. Дышание: выдох длиннее вдоха (4 вдох / 6–8 выдох), без задержек.
5. Если мысли разгоняются — вернуться к счёту; если тревога в теле — короткий body scan груди/живота.
6. Метта-завершение: 2–3 фразы к себе.
7. После: дневник, три слова о состоянии, не вытаскивая «итогов».

### 16.2 День бессонницы / накануне важного события

| Минута | Действие |
|--------|----------|
| 0–3 | Лёжа, check-in: где напряжение (челюсть, плечи, живот) |
| 3–10 | Body scan в релакс-варианте (нет акцента на детали) |
| 10–13 | Мягкая метта к себе — одна фраза на выдохе |
| 13–15 | Просто лежать, тело на весу с одеялом |

### 16.3 День гнева и напряжения в отношениях

1. Не практиковать «трудного человека» в метте, пока гнев не остыл.
2. Первые 5 минут — счёт дыхания (стабилизация).
3. Возможно письменная разрядка после сессии (не во время!) — страницу без цензуры.
4. Метта к себе первой, затем короткий круг к близкому.
5. Дневник: отметить триггеры, не превращая запись в обвинительный текст.

### 16.4 День после тяжёлой тренировки / болезни

- Укоротить сессии до 5–7 минут; поза простая (лёжа или стул).
- Техника: body scan мягкий или медитация на звук.
- Нормальна сонливость — не воевать, а лечь и сделать сканирование без внутреннего долженствования.
- Возврат к полному графику только через день восстановления.

## 17. Углубления техник юнита

### 17.1 Body scan до уровня «микро-зон»

После освоения базовых зон (стопы→голова) добавьте детализацию: палец за пальцем, сустав за суставом, слой за слоем (кожа → мышца → кость). Время сессии растёт до 30–45 минут. Наблюдение «звуков внутри» (пульс, шумы) — расширение интерцепции.

### 17.2 Метта с жестами и образом

- На каждую фразу — лёгкое движение: рука на груди (к себе), ладони вверх (близкий), руки вперёд ладонями вниз (все существа).
- Образ: тёплый свет в центре груди расширяется на каждый круг; при затруднении с «трудным» человеком — уменьшить радиус света.
- Ежедневная регулярность важнее длины: 5 минут метты в день стабильнее 30 минут раз в неделю.

### 17.3 Кинхин: от шага к ритму

Освоив одиночный шаг, переходят к синхронизации: 2–3 шага на выдох, остановка-пауза, 2–3 шага на вдох. Затем — обратный порядок (старт на выдохе). Для полного уровня: ходьба кругами в группе кинхин (как в дзен-зале) с поворотом на 90 градусов каждое обращение — практика внимания в движении.

### 17.4 Дзадзен: от счёта к молчанию

Классическая лестница: счёт выдохов → счёт без пауз → наблюдение дыхания без счёта → открытое сидение (шикантадза). Каждая ступень — от 2 до 6 недель. При срыве («ум улетел») возвращаются на ступень ниже временно, без драматизма — это самопроверка.

### 17.5 Визуализация: от статики к процессу

1. Этап «места»: устойчивый образ.
2. Этап «динамики»: ветер, вода, свет меняются — образ живёт.
3. Этап «смысла»: образ несёт намерение (покой, восстановление, ясность).
4. Этап «интеграции»: открытое пробуждение с образом на периферии перед выходом.

## 19. Практические задания юнита (20)

1. Семь дней подряд — дыхание через счёт 1–10, ровно по 5 минут утром, фиксируя строку дневника.
2. Найти свою лучшую точку дня для практики (утро/обед/вечер) по трём неделям записей.
3. Провести body scan три раза на этой неделе; в каждый из них — найти одну «мёртвую» (неощутимую) зону.
4. Практика метты к себе каждый вечер 5 дней; отменить её только при ухудшении настроения.
5. Ввести STOP-паузу минимум 2 раза в день — всего не менее десяти за неделю.
6. Осознанная еда: один приём пищи без экрана и без отвлечений; описать текстуру, вкус, сытость.
7. Кинхин: медленная ходьба 10 шагов туда и обратно, три фазы шага — один раз в день.
8. Медитация на звук: научиться «слушать фон», не начиная искать — 3 сессии.
9. Дзадзен: выстроить позу перед стеной и удержать 10 минут счёта; замечать, куда приходится опора.
10. Визуализация: построить «место силы» и дообустроить его тремя деталями за неделю.
11. Дневник: заполнять каждый день; в четверг зафиксировать один инсайт с пометкой «!».
12. Составить карту своих затруднений из таблицы раздела 2 и выбрать две техники-«лекарства».
13. Срыв графика: сознательно пропустить один день и вернуться — отрефлексировать, как это сделать легче.
14. Метта с «нейтральным» человеком из жизни (кассир, прохожий) в течение четырёх дней.
15. Элемент прощения: короткая метта ко «трудному» человеку (мягкий вариант) без ожиданий изменения его.
16. Практика без счёта: убрать счёт на выдохах на 3 сессии в пользу чистого наблюдения дыхания.
17. Подбор подушки: проверить три варианта высоты опоры под тазом и зафиксировать результат.
18. Прогулка-медитация до места/из места: внедрить осознанность в ежедневный маршрут на 5 дней.
19. Научиться завершать сессии: добавлять минуту «выхода» и отслеживать настроение в первые полчаса.
20. Рефлексия месяца: заполнить таблицу показателей (4.7) и сравнить с началом плана.

## 21. Карта результатов: что проверять на 30-й день

| Область | Что замечать | Ожидаемая динамика |
|---------|--------------|--------------------|
| Регулярность | Дни подряд, % выполненных дней | 80–90% при плане |
| Спокойствие | Частота «телесных» всплесков | Снижение реактивности |
| Внимание | Длина фокуса в работе/чтении | Рост сегмента концентрации |
| Сон | Время засыпания, ночные пробуждения | Улучшение к 3–4 неделям |
| Отношения | Пауза перед ответом, тон речи | Больше выдержки |
| Тело | Напряжение шеи/плеч, боли | Снижение тонуса в покое |
| Самоотношение | Тон внутреннего диалога | Мягче критика |
| Творчество | Свежесть идей после практики | Рост «потока» |

Диагностическая формула: сравнивайте не «сегодня против вчера», а «неделю 1 против недели 4» — срезы на коротких дистанциях обманчивы.

## 22. Практики на 60 секунд (спасательный круг)

| Ситуация | 60-секундная практика |
|----------|----------------------|
| Проснулись | Один вдох-выдох с ощущением стоп на полу |
| Зубы почищены | 3 осознанных вдоха в зеркале, взгляд-контакт |
| Дверь закрыли | Стоп-пауза: что происходит в теле прямо сейчас |
| Сел за стол | Выдох длиннее вдоха, три раза |
| Включили чайник | Звук воды — медитация на звук |
| Поднялись на этаж | Темп дыхания в такт шагам |
| Достали телефон | Вопрос: «Что я на самом деле хочу сейчас?» |
| Перед едой | Первый укус: запах, текстура, вкус |
| Услышали сплетню/жалобу | Вдох — выдох и не-вовлечение в один тон |
| Перед сном | 5 осознанных выдохов в кровати, тело отпущено |
| Почувствовали страх | Руки на груди и животе, 3 вдоха — «что здесь происходит» |
| Раздражение в разговоре | Мысленная пауза до ответа, выдох, короткий шаг внимания |
| Сидите в зале/на паре | Опора стоп и сидячей кости — half body-scan без ухода |
| Поняли, что отвлеклись | «Возврат» без оценки — и сразу снова на дыхание |
| Вернулись домой | Стоп у двери: отметить «я пришёл», переключить внимание |

Идея: микро-практики мостик между сессиями и жизнью — они удерживают «фон» осознанности так, чтобы полные сессии не выглядели изолированным островком.

## Итоги урока

- Техники юнита: body scan, метта, звук, кинхин, дзадзен, визуализация — единая система тренировки внимания и отношения.
- Ключ к успеху — регулярность ядра (10–20 мин ежедневно) и дневник, а не выбор «лучшей» техники.
- Затруднения предсказуемы: карта из 20+ пунктов выше отвечает, что делать в 95% ситуаций.
- Наука подтверждает: стресс, тревога, внимание, профилактика депрессии — обоснованные эффекты при 8+ неделях практики.
- Дальнейшие шаги: углубление одной техники, ретрит, работа с учителем, интеграция в быт (раздел 12 index).

*Личный конспект Unit 2. Расширяется по мере практики.*

- Микро-практики на 60 секунд — самый недооценённый рычаг привычки.
- Сравнивайте неделю 1 с неделей 4, а не день с днём.
