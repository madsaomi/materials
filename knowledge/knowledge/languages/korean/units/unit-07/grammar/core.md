# Unit 07: 할 수 있다 — Грамматика

---

## 1. -(으)ㄹ 수 있다/없다 («Могу / Не могу»)

### Значение

Конструкция **-(으)ㄹ 수 있다** выражает **возможность** или **способность** сделать что-то. **-(으)ㄹ 수 없다** — отрицание: «не могу», «нет возможности».

### Образование

```
Глагол (согласный + 을) +ㄹ 수 있다
Глагол (гласный) + ㄹ 수 있다
Глагол ( batchim) + 을 수 있다
```

| Глагол | Корень | + -(으)ㄹ 수 있다 | Перевод |
|--------|--------|-------------------|---------|
| 먹다 | 먹 | 먹을 수 있다 | могу есть |
| 가다 | 가 | 갈 수 있다 | могу идти |
| 하다 | 하 | 할 수 있다 | могу делать |
| 오다 | 올 | 올 수 있다 | могу прийти |
| 읽다 | 읽 | 읽을 수 있다 | могу читать |
| 쓰다 | 쓸 | 쓸 수 있다 | могу писать |
| 만나다 | 만나 | 만날 수 있다 | могу встретить |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я могу есть острую еду. | 저는 매운 음식을 먹을 수 있어요. | Jeoneun maeun eumsig-eul meogeul su isseoyo. |
| Я не могу идти завтра. | 저는 내일 갈 수 없어요. | Jeoneun naeil gal su eopseoyo. |
| Ты можешь прийти? | 올 수 있어요? | Ol su isseoyo? |
| Я не могу плавать. | 저는 수영할 수 없어요. | Jeoneun suyeonghal su eopseoyo. |
| Мы можем сделать это. | 우리는 이걸 할 수 있어요. | Urineun igeol hal su isseoyo. |
| Ты можешь говорить по-корейски? | 한국어를 할 수 있어요? | Hangugeo-reul hal su isseoyo? |

### Согласование с прилагательными

Для **прилагательных** используется другая конструкция:

```
Прилагательное + -(으)ㄹ 수 있다 (описание состояния)
```

| Прилагательное | Перевод | Пример |
|----------------|---------|--------|
| 뜨겁다 | горячий | 뜨거울 수 있다 — может быть горячим |
| 춥다 | холодный | 추울 수 있다 — может быть холодно |
| 쉽다 | лёгкий | 쉬울 수 있다 — может быть легко |
| 어렵다 | сложный | 어려울 수 있다 — может быть сложно |

## 2. -(으)면 («Если / Когда»)

### Значение

**(으)면** — условное или временное придаточное: «если…», «когда…», «в случае, если…».

### Образование

```
Глагол (согласный) + 으면
Глагол (гласный) + 면
```

| Глагол | Корень | + -(으)면 | Перевод |
|--------|--------|-----------|---------|
| 먹다 | 먹 | 먹으면 | если ешь |
| 가다 | 가 | 가면 | если идёшь |
| 하다 | 하 | 하면 | если делаешь |
| 오다 | 오 | 오면 | если приходишь |
| 비싸다 | 비싸 | 비싸면 | если дорогой |
| 좋다 | 좋 | 좋으면 | если хороший |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Если будет дождь, я не пойду. | 비가 오면 집에 있을 거예요. | Biga omyeon jib-e isseul geoyeyo. |
| Когда ты приходишь, позвони мне. | 올 때 전화해 주세요. | Oal ttae jeonhwa-hae juseyo. |
| Если учишь корейский, будет легко. | 한국어를 공부하면 쉬울 거예요. | Hangugeo-reul gongbuhamyeon swiul geoyeyo. |
| Если дорого, я не куплю. | 비싸면 안 살 거예요. | Bissamyeon an sal geoyeyo. |
| Если свободен, давай встретимся. | 시간이 있으면 만나요. | Sigani isseumyeon mannayo. |

### -(으)면 vs -(으)ㄹ 때

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| -(으)면 | условие (если) | 비가 오면 — если пойдёт дождь |
| -(으)ㄹ 때 | время (когда) | 비가 올 때 — когда идёт дождь |

## 3. 잘 / 못 (Наречия способности)

### Значение

- **잘** — «хорошо», «умело» (положительная оценка способности)
- **못** — «плохо», «не могу», «не умею» (отрицание способности)

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Он хорошо готовит. | 그는 요리를 잘 해요. | Geuneun yori-reul jal haeyo. |
| Она плохо поёт. | 그녀는 노래를 못 해요. | Geunyeoneun norae-reul mot haeyo. |
| Я хорошо плаваю. | 저는 수영을 잘 해요. | Jeoneun suyeong-eul jal haeyo. |
| Я не умею готовить. | 저는 요리를 못 해요. | Jeoneun yori-reul mot haeyo. |
| Ты хорошо говоришь по-японски? | 일본어를 잘 하세요? | Ilbongeo-reul jal haseyo? |
| Я не понимаю. | 저는 못 알아듣겠어요. | Jeoneun mot aradeutgesseoyo. |

### Соотношение с -(으)ㄹ 수 있다

| Форма | Значение | Пример |
|-------|----------|--------|
| -(으)ㄹ 수 있다 | физическая возможность | 갈 수 있다 — могу идти (погода позволяет) |
| 잘 하다 | уровень мастерства | 잘 가요 — хорошо иду (умело, активно) |
| 못 하다 | неумение | 못 가요 — не умею идти (не знаю дорогу) |

---

## 4. Сравнение: -(으)ㄹ 수 있다 vs 하다

| Параметр | -(으)ㄹ 수 있다 | 하다 |
|----------|-----------------|------|
| Значение | возможность, способность | действие, привычка |
| Фокус | на способе/условии | на самом действии |
| Пример | 한국어를 할 수 있어요 — Могу говорить по-корейски | 한국어를 해요 — Говорю по-корейски |
| Отрицание | 할 수 없다 — не могу | 안 해요 — не делаю / 못 해요 — не умею |

---

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 먹을 수 있어요 ✓ | — | Правильное окончание для batchim |
| 갈 수 있어요 ✓ | — | Для гласного: 갈 + 수 |
| 수영을 할 수 있어요 ✓ | — | 하 → 할 (согласный) |
| 잘 할 수 있어요 ✓ | — | совмещение: хорошо + могу |
| 먹으면 수 있어요 ✗ | 먹을 수 있어요 | -(으)면 ≠ -(으)ㄹ 수 있다 |
| 저는 갈 수 있어요 ✓ | — | 정확한 표현 |

## 7. -(으)ㄹ 줄 알다 / 모르다 («Уметь / Не уметь делать»)

### Значение

Конструкция **-(으)ㄹ 줄 알다** означает «уметь, знать, как сделать». **-(으)ㄹ 줄 모르다** — «не уметь, не знать, как». В отличие от -(으)ㄹ 수 있다, здесь фокус не на возможности, а на **навыке и знании способа**.

### Образование

```
Глагол (согласный) + 을 줄 알다 / 모르다
Глагол (гласный) + ㄹ 줄 알다 / 모르다
```

| Глагол | + -(으)ㄹ 줄 알다 | Перевод |
|--------|-------------------|---------|
| 치다 (играть в мяч) | 칠 줄 알다 | уметь играть |
| 하다 | 할 줄 알다 | уметь делать |
| 운전하다 | 운전할 줄 알다 | уметь водить |
| 요리하다 | 요리할 줄 모르다 | не уметь готовить |
| 수영하다 | 수영할 줄 모르다 | не уметь плавать |
| 부르다 (петь) | 부를 줄 알다 | уметь петь |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я умею играть на гитаре. | 저는 기타를 칠 줄 알아요. | Jeoneun gitareul chil jul arayo. |
| Ты умеешь водить машину? | 운전할 줄 알아요? | Unjeonhal jul arayo? |
| Я не умею плавать. | 저는 수영할 줄 몰라요. | Jeoneun suyeonghal jul mollayo. |
| Младшая сестра умеет готовить. | 여동생은 요리할 줄 알아요. | Yeodongsaengeun yorihal jul arayo. |
| Он не умеет петь. | 그는 노래를 부를 줄 몰라요. | Geuneun noraereul bureul jul mollayo. |

### Разница с -(으)ㄹ 수 있다

| Конструкция | Оттенок | Пример |
|-------------|---------|--------|
| -(으)ㄹ 수 있다 | возможность по условию | 시간이 있으면 갈 수 있어요 — если есть время, могу пойти |
| -(으)ㄹ 줄 알다 | навык, «знаю, как» | 운전할 줄 알아요 — умею (знаю, как) водить |
| -(으)ㄹ 줄 모르다 | «не знаю, как», нет навыка | 요리할 줄 몰라요 — не умею готовить (не знаю, как) |

## 8. -아/어 보다 («Пробовать / Иметь опыт»)

### Значение

Добавляется к основе глагола и означает **«попробовать сделать»**. В прошедшем времени (-아/어 봤어요) — «пробовал», «имею опыт».

### Образование

```
Основа глагола + 아/어 보다
하 + 여 보다 → 해 보다
```

| Глагол | + -아/어 보다 | Перевод |
|--------|---------------|---------|
| 먹다 | 먹어 보다 | попробовать поесть |
| 하다 | 해 보다 | попробовать сделать |
| 배우다 | 배워 보다 | попробовать выучить |
| 타다 | 타 보다 | попробовать поехать |
| 만들다 | 만들어 보다 | попробовать сделать |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Попробуй сыграть в футбол. | 축구를 해 보세요. | Chukgureul hae boseyo. |
| Ты когда-нибудь пробовал кимчи? | 김치를 먹어 봤어요? | Kimchireul meogeo bwasseoyo? |
| Давай попробуем вместе учиться. | 같이 배워 봐요. | Gachi baewo bwayo. |
| Я попробую поехать на велосипеде. | 자전거를 타 볼게요. | Jajeongeoreul ta bolgeyo. |
| Она никогда не пробовала играть в теннис. | 그녀는 테니스를 쳐 본 적이 없어요. | Geunyeoneun teniseureul chyeo bon jeogi eopseoyo. |

### Сочетание с темой способностей

- **해 볼게요** — «попробую сделать» (намерение освоить).
- **해 봤어요** — «пробовал», есть опыт.
- В словарях и на курсах часто встречается **-아/어 보다** как способ проверить свою способность.

## 9. -는데요 (Контекст, смягчение)

### Значение

Окончание **-는데요** даёт **контекст или обстоятельства** перед главной мыслью, а в конце фразы — мягко привлекает внимание собеседника. Со способностями используется, чтобы смягченно сообщить о своих умениях.

### Образование

```
Глагол + 는데요: 하다 → 하는데요, 가다 → 가는데요
Прилагательное + (으)ㄴ데요: 좋다 → 좋은데요
있다/없다 → 있는데요 / 없는데요
Прошедшее время: 았/었는데요
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я умею хорошо плавать. | 저는 수영을 잘 하는데요. | Jeoneun suyeongeul jal haneundeyo. |
| Но я не умею готовить... | 그런데 저는 요리를 못 하는데요. | Geureonde jeoneun yorireul mot haneundeyo. |
| Сегодня я устал, поэтому... | 오늘은 좀 피곤한데요. | Oneureun jom pigonhandeyo. |
| Я уже пробовал это. | 저는 그걸 해 봤는데요. | Jeoneun geugeol hae bwatneundeyo. |
| У меня нет времени... | 시간이 없는데요. | Sigani eoptneundeyo. |

## 10. -(으)ㄴ/ㄹ 것 같다 («Кажется, что…»)

### Значение

Выражает **субъективную оценку, предположение**: «кажется, что…». С темой способностей помогает говорить о вероятности: «кажется, смогу».

### Образование

```
Прилагательное (наст.) + (으)ㄴ 것 같다: 어렵다 → 어려운 것 같다
Глагол (действие, наст.) + 는 것 같다: 잘하다 → 잘하는 것 같다
Время / будущее + (으)ㄹ 것 같다: 할 수 있다 → 할 수 있을 것 같다
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Если тренироваться, кажется, получится. | 연습하면 할 수 있을 것 같아요. | Yeonseuphamyeon hal su isseul geot gatayo. |
| Мне кажется, он хорошо готовит. | 그는 요리를 잘하는 것 같아요. | Geuneun yorireul jalhaneun geot gatayo. |
| Корейский кажется трудным. | 한국어는 어려운 것 같아요. | Hangugeoneun eoryeoun geot gatayo. |
| Кажется, я смогу прийти завтра. | 내일 올 수 있을 것 같아요. | Naeil ol su isseul geot gatayo. |
| Кажется, она не умеет плавать. | 그녀는 수영을 못 하는 것 같아요. | Geunyeoneun suyeongeul mot haneun geot gatayo. |

## 11. -(으)ㄹ까요? (Предложение и предположение)

### Значение

Вопросительное окончание **-(으)ㄹ까요?** используется для:

1. **Предложения** совместного действия («давай…?»).
2. **Предположения** с сомнением («сможет ли?», «получится ли?»).

### Образование

```
Глагол (гласный) + ㄹ까요?
Глагол (согласный) + 을까요?
```

| Функция | Пример | Перевод |
|---------|--------|---------|
| Предложение | 같이 배울까요? | Давайте учиться вместе? |
| Предложение | 한번 해 볼까요? | Попробуем? |
| Предположение | 할 수 있을까요? | Сможет ли? Получится ли? |
| Предположение | 잘할 수 있을까요? | Справится ли хорошо? |

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Давайте вместе пойдём на плавание? | 같이 수영하러 갈까요? | Gachi suyeonghareo galkkayo? |
| Получится ли у меня научиться? | 제가 배울 수 있을까요? | Jega baeul su isseulkkayo? |
| Сыграем в теннис? | 테니스 칠까요? | Teniseu chilkkayo? |
| Наверное, он умеет петь. | 그는 노래를 부를 수 있을까요? | Geuneun noraereul bureul su isseulkkayo? |

## 12. -고 있다 (Продолжительность действия)

### Значение

**-고 있다** — «сейчас делаю что-то», процесс длится прямо сейчас. В теме способностей часто описывает **процесс обучения** в данный момент.

### Образование

```
Основа глагола + 고 있다
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|

## 13. -도 되다 / -(으)면 안 되다 (Разрешено / Запрещено)

### Значение

- **-아/어도 되다** — «можно», «разрешено» (просьба и разрешение).
- **-(으)면 안 되다** — «нельзя», «запрещено».

### Образование

```
Основа глагола + 아/어도 되다   (можно делать)
Глагол (согласный) + 으면 안 되다 / (гласный) + 면 안 되다 (нельзя делать)
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Можно сесть? | 앉아도 돼요? | Anjado dwaeyo? |
| Да, конечно можно. | 네, 물론이요. 돼요. | Ne, mulloniyo. Dwaeyo. |
| Нельзя опаздывать. | 늦으면 안 돼요. | Neujeumyeon andwaeyo. |
| Здесь можно фотографировать? | 여기에서 사진을 찍어도 돼요? | Yeogieseo sajineul jjigeodo dwaeyo? |
| Нельзя есть на работе. | 일하는 곳에서 먹으면 안 돼요. | Ilhaneun goseseo meogeumyeon andwaeyo. |

### Связь с вежливостью

Вопросительная форма **-아/어도 돼요?** — вежливый способ спросить разрешение, близкий к «можно ли…». Ответ **-아/어도 돼요** разрешает, **-(으)면 안 돼요** запрещает.

## 14. -(으)ㄹ 수밖에 없다 («Не остаётся ничего другого»)

### Значение

**-(으)ㄹ 수밖에 없다** — «не остаётся ничего другого, кроме как…», «приходится». Выражает вынужденность, отсутствие выбора.

### Образование

```
Глагол (гласный) + ㄹ 수밖에 없다
Глагол (согласный) + 을 수밖에 없다
```

### Примеры

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Приходится сдаться. | 포기할 수밖에 없어요. | Pogihal subagge eopseoyo. |
| Приходится ждать. | 기다릴 수밖에 없어요. | Gidaril subagge eopseoyo. |
| Мне приходится учиться каждый день. | 매일 공부할 수밖에 없어요. | Maeil gongbuhal subagge eopseoyo. |
| Ему пришлось уйти из команды. | 그는 팀을 떠날 수밖에 없었어요. | Geuneun timeul tteonal subagge eopseosseoyo. |
