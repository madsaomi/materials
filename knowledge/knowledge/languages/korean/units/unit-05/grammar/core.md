# Unit 5 — 문법 (Грамматика)

## 1. Выражения погоды

**Структура:** 날씨 + глагол / прилагательное

```
오늘 날씨가 맑아요.          — Сегодня ясная погода.
비가 와요.                   — Идёт дождь.
눈이 와요.                   — Идёт снег.
바람이 불어요.               — Дует ветер.
천둥이 쳐요.                 — Гремит гром.
무지개가 보여요.              — Видна радуга.
```

Прилагательные погоды по сезонам:

```
여름에는 매우 더워요.        — Летом очень жарко.
겨울에는 아주 추워요.        — Зимой очень холодно.
봄에는 따뜻해요.             — Весной тепло.
가을에는 시원해요.           — Осенью прохладно.
```

## 2. -ㄹ 것 같다 (похоже, что...)

**Структура:** [основа глагола/прилагательного] + (으)ㄹ 것 같다

```
오늘 비가 올 것 같아요.      — Похоже, сегодня пойдёт дождь.
내일은 맑을 것 같아요.       — Похоже, завтра будет ясно.
그 영화가 재미있을 것 같아요. — Похоже, этот фильм интересный.
내일 추울 것 같아요.         — Похоже, завтра будет холодно.
비가 올 것 같지 않아요.      — Похоже, дождя не будет.
```

## 3. -고 (соединение: "и")

**Структура:** [основа глагола] + 고 + [глагол]

```
저는 음악을 듣고 운동해요.       — Я слушаю музыку и занимаюсь спортом.
주말에는 등산하고 사진을 찍어요. — По выходным хожу в горы и фотографирую.
날씨가 좋고 바람이 불어요.        — Хорошая погода и дует ветер.
영화를 보고 책을 읽어요.          — Смотрю фильм и читаю книгу.
```

## 4. -지만 ("но")

**Структура:** [основа глагола/прилагательного] + 지만

```
날씨가 춥지만 산책해요.       — Погода холодная, но я гуляю.
저는 축구를 좋아하지만 잘 못해요. — Люблю футбол, но играю плохо.
비가 오지만 우산이 있어요.    — Идёт дождь, но у меня есть зонт.
매우 더우지만 수영을 해요.    — Очень жарко, но я плаваю.
```

## 5. -는데 (фон / мягкий контраст)

**Структура:** [основа глагола] + 는데, [основа прилагательного] + (으)ㄴ데

```
비가 오는데 우산이 없어요.    — Идёт дождь, а у меня нет зонта.
날씨가 좋은데 공원에 가요.    — Погода хорошая, поэтому иду в парк.
주말인데 뭐 하실 거예요?       — Выходной, что будете делать?
너무 더운데 창문을 열어요.    — Очень жарко, поэтому открываю окно.
춥는데 외출을 해요.           — Холодно, но выхожу.
```

## 6. -(으)러 가다 (идти, чтобы сделать)

После гласной: **-러 가다**, после согласной: **-으러 가다**

```
등산하러 가요.                — Иду в горы (в поход).
영화를 보러 가요.             — Иду смотреть фильм.
친구를 만나러 갔어요.         — Ходил встречаться с другом.
책을 읽으러 도서관에 가요.    — Иду в библиотеку читать книгу.
운동하러 체육관에 가요.      — Иду в спортзал заниматься спортом.
```

## 7. 가장 / 제일 (самый)

```
제일 좋아하는 계절은 봄이에요.  — Самое любимое время года — весна.
가장 좋아하는 가수는 누구예요?  — Кто твой самый любимый певец?
이 음악이 제일 좋아요.        — Эта музыка нравится больше всего.
제일 많이 보는 프로그램은 뭐예요? — Какую программу смотрите больше всего?
```

## 8. -아/어도 (даже если)

**Структура:** [основа глагола/прилагательного] + 아/어도

```
비가 와도 등산에 가요.        — Пойду в горы, даже если пойдёт дождь.
추워도 운동해요.              — Даже если холодно, занимаюсь спортом.
바빠도 음악을 들어요.         — Даже если занят, слушаю музыку.
어려워도 포기하지 않아요.     — Даже если трудно, не сдаюсь.
```

## 9. -고 있다 (действие в процессе)

```
웨이터가 음식을 가져오고 있어요. — Официант приносит еду.
손님이 밥을 먹고 있어요.          — Гость ест рис.
비가 오고 있어요.                 — Идёт дождь.
날씨가 추워지고 있어요.            — Становится холоднее.
```

## 10. -고 싶어요 / -고 싶지 않아요 (хочу / не хочу)

```
불고기를 먹고 싶어요.          — Хочу съесть пулькоги.
김치를 먹고 싶지 않아요.       — Не хочу есть кимчи.
콜라를 마시고 싶어요.          — Хочу выпить колу.
한국 음식을 더 먹고 싶어요.     — Хочу ещё есть корейскую еду.
이 레스토랑에 다시 오고 싶어요. — Хочу вернуться в этот ресторан.
주말에 여행하고 싶어요.        — Хочу поехать в путешествие на выходных.
```

## 11. -(으)면 (условие: "если...")

```
배가 고프면 식당에 가요.        — Если проголодаюсь, пойду в ресторан.
추우면 따뜻한 옷을 입어요.      — Если холодно, надену тёплую одежду.
맵지 않으면 잘 먹어요.          — Если не острое, хорошо ем.
시간이 있으면 영화를 볼 거예요. — Если будет время, посмотрю фильм.
비가 오면 택시를 탈 거예요.      — Если пойдёт дождь, сяду на такси.
날씨가 좋으면 등산을 갈 거예요.  — Если хорошая погода, пойду в горы.
```

## 12. -고 계세요 (вежливая форма продолженного действия)

```
웨이터가 기다리고 계세요.        — Официант ждёт (вежл.).
손님이 앉아 계세요.              — Гость сидит (вежл.).
주문이 준비되고 계세요.          — Заказ готовится (вежл.).
날씨가 추워지고 계세요.           — Становится холоднее (вежл.).
```

## 13. -한테 / -에게 (дательный падеж: "кому")

```
웨이터한테 주문을 했어요.       — Сделал заказ официанту.
친구한테 물을 줬어요.            — Дал другу воды.
선생님께 질문을 했어요.          — Задал вопрос учителю (формально).
엄마한테 전화했어요.              — Позвонил маме.
사장님께 감사 인사를 했어요.     — Поблагодарил начальника.
```

## 14. -고 있다 (состояние: "находиться в состоянии")

```
이 음식은 맛있고 있어요.          — Это блюдо вкусное (и остаётся таким).
오늘 날씨가 좋고 있어요.          — Сегодня хорошая погода.
이 식당은 깔끔하고 좋아요.       — Этот ресторан чистый и хороший.
한국 음식은 맵고 유명해요.        — Корейская еда острая и известная.
```

## 15. -니까 (причина: "потому что", "ведь")

```
배가 고프니까 밥을 먹었어요.     — Потому что голоден, поел рисом.
비가 오니까 우산을 가져왔어요.   — Потому что идёт дождь, взял зонт.
한국 음식을 좋아하니까 자주 먹어요. — Потому что люблю корейскую еду, часто её ем.
시간이 없으니까 빨리 가야 해요.   — Потому что нет времени, нужно побыстрее.
날씨가 좋으니까 산책을 해요.     — Потому что хорошая погода, гуляю.
```
