# Unit 06: 전화와 약속 — Грамматика

## 1. -고 있다 (Прошедшее.duration /正在进行 — «Делаю сейчас»)

### Значение

Грамматическое окончание **-고 있다** используется для выражения действия, которое **происходит в данный момент** (длительный вид,.progressive aspect). Аналог русского «сейчас делаю», «в процессе».

### Образование

```
Глагол (корень) + 고 있다
```

| Глагол | Корень | + 고 있다 | Перевод |
|--------|--------|-----------|---------|
| 먹다 | 먹 | 먹고 있다 | ем сейчас |
| 가다 | 가 | 가고 있다 | иду сейчас |
| 읽다 | 읽 | 읽고 있다 | читаю сейчас |
| 하다 | 하 | 하고 있다 | делаю сейчас |
| 자다 | 자 | 자고 있다 | сплю сейчас |
| 보다 | 보 | 보고 있다 | смотрю сейчас |
| 서다 | 서 | 서고 있다 | стою сейчас |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я сейчас ем. | 저는 지금 밥을 먹고 있어요. | Jeoneun jigeum babeul meog-go isseoyo. |
| Он сейчас читает книгу. | 그는 지금 책을 읽고 있어요. | Geuneun jigeum chaeg-eul ilg-go isseoyo. |
| Дети сейчас играют. | 아이들이 지금 놀고 있어요. | Aideuri jigeum nolgo isseoyo. |
| Я сейчас смотрю телевизор. | 저는 지금 텔레비전을 보고 있어요. | Jeoneun jigeum tellibijeon-eul bogo isseoyo. |
| Мы сейчас идём домой. | 우리는 지금 집에 가고 있어요. | Urineun jigeum jib-e gago isseoyo. |

### Вопросительная форма

```
Глагол + 고 있어요?
```

- 밥을 먹고 있어요? — Ты сейчас ешь?
- 뭐 하고 있어요? — Что ты сейчас делаешь?
- 어디에 가고 있어요? — Куда ты сейчас идёшь?

### Отрицательная форма

```
Глагол + 고 있지 않다 / 안 고 있다
```

- 저는 지금 뭐도 안 하고 있어요. — Я сейчас ничего не делаю.
- 그는 지금 일하고 있지 않아요. — Он сейчас не работает.

## 2. -아/어 두다 («Сделать заранее»)

### Значение

Конструкция **-아/어 두다** означает «сделать что-то заранее, «приготовить», «оставить про запас». Действие выполняется **в преддверии** будущей ситуации.

### Образование

```
Глагол + 아/어 + 두다
```

| Глагол | Корень | + -아/어 두다 | Перевод |
|--------|--------|---------------|---------|
| 읽다 | 읽 | 읽어 두다 | прочитать заранее |
| 사다 | 사 | 사 두다 | купить заранее |
| 만들다 | 만들 | 만들어 두다 | сделать заранее |
| 준비하다 | 준비 | 준비해 두다 | подготовить заранее |
| 예약하다 | 예약 | 예약해 두다 | забронировать заранее |
| 저장하다 | 저장 | 저장해 두다 | сохранить заранее |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Купи еду заранее. | 미리 음식을 사 두세요. | Miri eumsig-eul sa duseyo. |
| Я подготовил документы. | 저는 서류를 준비해 두었어요. | Jeoneun seoryu-reul junbihae dueosseoyo. |
| Сохрани номер телефона. | 전화번호를 저장해 두세요. | Jeonhwa beonho-reul jeonhae duseyo. |
| Прочитай текст заранее. | 미리 텍스트를 읽어 두세요. | Miri tekeu-seu-teu-reul ilgeo duseyo. |
| Забронируйте отель заранее. | 미리 호텔을 예약해 두세요. | Miri hotel-eul yeyakhae duseyo. |

### Временные формы

| Форма | Пример | Перевод |
|-------|--------|---------|
| 현재 (настоящее) | 사 두다 | покупать заранее |
| 과거 (прошедшее) | 사 두었어요 / 사 뒀어요 | купил заранее |
| 미래 (будущее) | 사 둘 거예요 | куплю заранее |

## 3. -기 전에 / -기 후에 («До / После того как…»)

### Значение

- **-기 전에** — «до того как…», «перед тем как…»
- **-기 후에** — «после того как…», «после того как…»

### Образование

```
Глагол + 기 전에 / 기 후에
```

| Глагол | + 기 전에 | + 기 후에 |
|--------|-----------|-----------|
| 먹다 | 먹기 전에 | 먹은 후에 |
| 가다 | 가기 전에 | 간 후에 |
| 하다 | 하기 전에 | 한 후에 |
| 자다 | 자기 전에 | 잔 후에 |
| 만나다 | 만나기 전에 | 만난 후에 |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Перед едой мойте руки. | 식사하기 전에 손을 씻으세요. | Sigsa-hagi jeone son-eul ssiseuseyo. |
| После работы я пойду домой. | 일한 후에 집에 갈 거예요. | Irhan hue jib-e gal geoyeyo. |
| Перед уходом выключите свет. | 나가기 전에 불을 꺼 주세요. | Nagagi jeone bul-eul kkeo juseyo. |
| После ужина мы посмотрим фильм. | 저녁 식사 후에 영화를 볼 거예요. | Jeonyeok sigsa hue yeonghwa-reul bol geoyeyo. |
| Перед сном я читаю книгу. | 자기 전에 책을 읽어요. | Jagi jeone chaeg-eul ilgeoyo. |

## 4. Сравнение форм

### -고 있다 vs -고 있는

| Параметр | -고 있다 | -고 있는 |
|----------|----------|----------|
| Значение | Действие в процессе | Действие как характеристика |
| Пример | 저는 지금 밥을 먹고 있어요. (Я сейчас ем) | 먹고 있는 사람을 봤어요. (Я видел человека, который ел) |
| Использование | Описание текущего действия | Определение /修饰 существительного |

### -아/어 두다 vs -아/어 놓다

Обе формы взаимозаменяемы, но:

- **-아/어 두다** — акцент на **цели** (заранее, для будущего)
- **-아/어 놓다** — акцент на **результате** (готово, оставлено)

| Пример | Разница |
|--------|---------|
| 미리 예약해 두었다. | Забронировал заранее (цель — подготовиться) |
| 미리 예약해 놓았다. | Забронировал и всё готово (результат — готово) |

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 저는 지금 먹고 있어요 ✓ | — | Не путайте с 먹고 있는 (для修饰) |
| 저는 먹어 두었어요 ✓ | — | Две формы: 사 두었어요 / 사 뒀어요 (разговорная) |
| 먹기 전에 손을 씻어요 ✓ | — | 기 전에 требует 전치스 + 관형사형 |
| 저는 했고 있어요 ✗ | 저는 하고 있어요 | Корень + 고 있다, а не 형태 변화 |

## 7. -ㄹ까요? («Не хочешь ли…?» — предложение и вопрос о намерении)

### Значение

Окончание **-ㄹ까요?** используется для:

1. **вежливого предложения** что-то сделать («Не хочешь…?», «Давай…?»)
2. **вопроса о совместном решении** (куда пойти, что сделать)
3. **вежливого предположения** о действии

Это одна из самых частых конструкций при назначении встреч по телефону.

### Образование

```
Основа на гласную + ㄹ까요?
Основа на согласную + 을까요?
```

| Глагол | Основа | + -ㄹ까요? | Перевод |
|--------|--------|-----------|---------|
| 만나다 | 만나 | 만날까요? | встретиться? |
| 먹다 | 먹 | 먹을까요? | поесть? |
| 전화하다 | 전화하 | 전화할까요? | позвонить? |
| 보다 | 보 | 볼까요? | посмотреть? |
| 쉬다 | 쉬 | 쉴까요? | отдохнуть? |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Встретимся в субботу? | 토요일에 만날까요? | Toyoil-e mannalkkayo? |
| Позвонить тебе вечером? | 저녁에 전화할까요? | Jeonyeoge jeonhwahalkkayo? |
| Что нам выпить? | 뭐 마실까요? | Mwo masilkkayo? |
| Пойдём вместе? | 같이 갈까요? | Gachi galkkayo? |
| Забронировать столик? | 자리를 예약할까요? | Jarireul yeyak halkkayo? |

### Разница: -ㄹ까요? и -을게요

| Форма | Значение | Пример |
|-------|----------|--------|
| -ㄹ까요? | спрашивает мнение собеседника | 제가 전화할까요? — Позвонить мне? |
| -을게요 | сообщает о своём решении | 제가 전화할게요. — Я позвоню. |

## 8. -(으)려고 하다 («Намереваться, собираться»)

### Значение

Конструкция **-(으)려고 하다** выражает **намерение** или **план** — «собираюсь сделать». В телефонных разговорах часто употребляется с планами на выходные.

### Образование

```
Основа на гласную + 려고 하다
Основа на согласную + 으려고 하다
```

| Глагол | Основа | + -(으)려고 하다 | Перевод |
|--------|--------|------------------|---------|
| 가다 | 가 | 가려고 해요 | собираюсь идти |
| 만나다 | 만나 | 만나려고 해요 | собираюсь встретиться |
| 주문하다 | 주문하 | 주문하려고 해요 | собираюсь заказать |
| 먹다 | 먹 | 먹으려고 해요 | собираюсь есть |
| 듣다 | 듣 | 들으려고 해요 | собираюсь слушать |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| На выходных собираюсь поехать в Намсан. | 주말에 남산에 가려고 해요. | Jumale Namsane garyeogo haeyo. |
| Собираюсь назначить встречу на 10:00. | 열 시에 만나려고 해요. | Yeol sie mannaryeogo haeyo. |
| Собираюсь позвонить после обеда. | 점심 후에 전화하려고 해요. | Jeomsim hue jeonhwa-haryeogo haeyo. |
| Она собирается отменить встречу. | 그녀는 약속을 취소하려고 해요. | Geunyeoneun yaksogeul chwiso-haryeogo haeyo. |
| Я собираюсь купить билеты заранее. | 미리 표를 사려고 해요. | Miri pyoreul saryeogo haeyo. |

### Нюанс

- В разговорной речи часто сокращается до **-(으)ㄹ 거예요** с тем же значением намерения.
- **-(으)려고** может соединяться с «하다», «그러다», «생각하다».

## 9. -(으)ㄴ 것 같다 («Кажется, …»)

### Значение

Конструкция **-(으)ㄴ 것 같다** выражает **предположение** — «кажется, …», «похоже, что …». С прилагательными и глаголами прошедшего/настоящего времени.

### Образование

```
Прилагательное/глагол (прош.) + ㄴ/은 것 같다
Прилагательное (наст.) + ㄴ/은 것 같다
Глагол (наст.) + 는 것 같다
```

| Основа | Форма | Перевод |
|--------|-------|---------|
| 이르다 | 이른 것 같아요 | кажется, рано |
| 늦다 | 늦은 것 같아요 | кажется, поздно |
| 바쁘다 | 바쁜 것 같아요 | кажется, занят |
| (прош.) 가다 | 간 것 같아요 | кажется, ушёл |
| (прош.) 끊다 | 끊은 것 같아요 | кажется, оборвалось |
| (наст.) 하다 | 하는 것 같아요 | кажется, делает |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Кажется, девять — слишком рано. | 아홉 시는 좀 이른 것 같아요. | Ahop sineun jom ireun geot gatayo. |
| Кажется, он сейчас занят. | 그는 지금 바쁜 것 같아요. | Geuneun jigeum bappeun geot gatayo. |
| Кажется, связь оборвалась. | 전화가 끊긴 것 같아요. | Jeonhwaga kkeungin geot gatayo. |
| Кажется, они уже встретились. | 그들은 벌써 만난 것 같아요. | Geudeureun beolsseo mannan geot gatayo. |
| Кажется, сейчас дождь идёт. | 지금 비가 오는 것 같아요. | Jigeum biga oneun geot gatayo. |

### Нюанс

- Для **будущего** используется **-(으)ㄹ 것 같다**: 내일 비가 올 것 같아요. — Похоже, завтра будет дождь.
- Употребляется для смягчения категоричности — важная часть корейского этикета.

## 10. -는 중이다 («В процессе…»)

### Значение

Конструкция **-는 중이다** — «в процессе действия», «сейчас занимаюсь». Похожа на **-고 있다**, но подчёркивает, что действие **в самом разгаре, в процессе**. Идеальна для ответов на звонок.

### Образование

```
Глагол (настоящее) + 는 중이다
Существительное + 중이다
```

| Форма | Пример | Перевод |
|-------|--------|---------|
| 일하다 | 일하는 중이에요 | в процессе работы |
| 통화하다 | 통화하는 중이에요 | разговариваю (на линии) |
| 회의하다 | 회의 중이에요 | на совещании |
| 식사하다 | 식사 중이에요 | за едой |
| 운전하다 | 운전하는 중이에요 | за рулём |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Я сейчас на совещании. | 지금 회의 중이에요. | Jigeum hoeui jung-ieyo. |
| Извините, я сейчас разговариваю по телефону. | 죄송해요, 지금 통화 중이에요. | Joesonghaeyo, jigeum tonghwa jung-ieyo. |
| Он сейчас едет (в поездке). | 그는 지금 이동 중이에요. | Geuneun jigeum idong jung-ieyo. |
| Она готовит ужин (сейчас). | 그녀는 지금 저녁을 준비하는 중이에요. | Geunyeoneun jigeum jeonyeogeul junbihaneun jung-ieyo. |
| Мы ждём автобус. | 우리는 버스를 기다리는 중이에요. | Urineun beoseureul gidarineun jung-ieyo. |

### Нюанс

- `통화 중` (в процессе разговора) — стандартный ответ линии.
- **-는 중** звучит чуть более официально, чем **-고 있다**.

## 11. -고 나서 («После того как…», «потом»)

### Значение

**-고 나서** означает последовательность действий: «сделал А, потом B». В отличие от **-아/어서**, подчёркивает **завершённость** первого действия.

### Образование

```
Глагол + 고 나서
```

| Глагол | + -고 나서 | Перевод |
|--------|-----------|---------|
| 먹다 | 먹고 나서 | поев, … |
| 가다 | 가고 나서 | сходив, … |
| 연락하다 | 연락하고 나서 | связавшись, … |
| 일하다 | 일하고 나서 | поработав, … |
| 확인하다 | 확인하고 나서 | проверив, … |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| После разговора позвоню тебе ещё раз. | 통화하고 나서 다시 전화할게요. | Tonghwahago naseo dasi jeonhwahalgeyo. |
| После ужина посмотрим фильм. | 저녁을 먹고 나서 영화를 봐요. | Jeonyeogeul meokgo naseo yeonghwareul bwayo. |
| После встречи пойду домой. | 친구를 만나고 나서 집에 갈 거예요. | Chingureul mannago naseo jibe gal geoyeyo. |
| Проверив расписание, перезвоню. | 일정을 확인하고 나서 다시 전화할게요. | Iljeongeul hwaginhago naseo dasi jeonhwahalgeyo. |

### Нюанс

- В устной речи **-고 나서** часто сокращается до **-고**.
- Синонимичная форма: **-(으)ㄴ 후에**.

## 12. -(으)ㄴ 적이 있다 / 없다 («Было такое, что…»)

### Значение

Конструкция **-(으)ㄴ 적이 있다** означает **наличие опыта** — «мне доводилось…», «был случай…». **-(으)ㄴ 적이 없다** — «никогда не…». Часто используется про посещённые места и сделанные дела.

### Образование

```
Глагол (прош.) + ㄴ 적이 있다 / 없다
Основа на ㄹ (пропуск ㄴ) + ㄴ 적이 있다
```

| Глагол | Форма | Перевод |
|--------|-------|---------|
| 만나다 | 만난 적이 있어요 | доводилось встречаться |
| 가다 | 간 적이 있어요 | бывал |
| 보다 | 본 적이 있어요 | видел (когда-то) |
| 먹다 | 먹은 적이 있어요 | пробовал |
| 잊다 | 잊은 적이 있어요 | бывало, что забывал |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Ты бывал в Сеуле? | 서울에 가 본 적이 있어요? | Sourre ga bon jeogi isseoyo? |
| Я никогда не опаздывал на встречу. | 약속에 늦은 적이 없어요. | Yaksoge neujeun jeogi eopseoyo. |
| Мне доводилось звонить в ООН. | 유엔에 전화한 적이 있어요. | Yuen-e jeonhwaham jeogi isseoyo. |
| Я много раз пробовал кимчи. | 김치를 많이 먹은 적이 있어요. | Gimchireul mani meogeun jeogi isseoyo. |
| Я не встречал его раньше. | 그를 만난 적이 없어요. | Geureul mannan jeogi eopseoyo. |

### Нюанс

- Часто **가** опускается в речи: 가 본 적 있어요.
- Отвечая, используют **있어요 / 없어요** или полные **있어 본 적이 있어요 / 없어요**.

---

## 13. -기로 하다 («Договориться, решиться»)

### Значение

Конструкция **-기로 하다** означает **решение, договорённость** — «договорились, решили, уговорились». Это ядро темы «약속» (договорённости): сообщаем о согласованном решении.

### Образование

```
Глагол + 기로 하다
```

| Глагол | Форма | Перевод |
|--------|-------|---------|
| 만나다 | 만나기로 했어요 | договорились встретиться |
| 전화하다 | 전화하기로 했어요 | договорились позвонить |
| 가다 | 가기로 했어요 | договорились идти |
| 취소하다 | 취소하기로 했어요 | решили отменить |
| 먹다 | 먹기로 했어요 | решили поесть |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Мы договорились встретиться в субботу. | 우리는 토요일에 만나기로 했어요. | Urineun toyoire mannagiro haesseoyo. |
| Договорились созвониться вечером. | 저녁에 전화하기로 했어요. | Jeonyeoge jeonhwa-hagiro haesseoyo. |
| Решили отменить встречу. | 약속을 취소하기로 했어요. | Yaksogeul chwisohagiro haesseoyo. |
| Решили пойти в ресторан у Намсана. | 남산 근처 식당에 가기로 했어요. | Namsan geuncheo sikdange gagiro haesseoyo. |
| Я решил выучить корейский. | 한국어를 배우기로 했어요. | Hangugeoreul baeugiro haesseoyo. |

### Нюанс

- Отлично сочетается с темой юнита «약속» — договорённости.
- Вежливый вариант: **-기로 하겠습니다**, **-기로 약속했습니다**.

## 14. 시간 표현: ~부터 ~까지 и ~에 (Временные рамки и точки)

### Значение

- **에** — точка во времени: «во столько-то», «в такой-то день»
- **~부터 ~까지** — промежуток: «с … до …»

### Образование

```
Существительное/время + 에
Время + 부터 … Время + 까지
```

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| в 10 часов | 열 시에 | yeol sie |
| в субботу | 토요일에 | toyoire |
| с 3 до 5 часов | 세 시부터 다섯 시까지 | se sibuteo daseot si-kkaji |
| со вторника до пятницы | 화요일부터 금요일까지 | hwayoil-buteo geumy oil-kkaji |
| с понедельника по воскресенье | 월요일부터 일요일까지 | woryoil-buteo iryoil-kkaji |

### Примеры предложений

| Русский | Хангыль | Романизация |
|---------|---------|-------------|
| Встретимся в 10 часов на станции. | 열 시에 지하철역에서 만나요. | Yeol sie jihacheolyeogeseo mannayo. |
| Совещание с 2 до 4. | 회의는 두 시부터 네 시까지예요. | Hoiuineun du sibuteo ne si-kkajieyo. |
| Я позвоню тебе в 9 часов. | 아홉 시에 전화할게요. | Ahop sie jeonhwahalgeyo. |
| Магазин работает с 10 до 8. | 가게는 열 시부터 여덟 시까지 운영해요. | Gageneun yeol sibuteo yeodeol si-kkaji unyeong-haeyo. |
| До пятницы нужно подтвердить. | 금요일까지 확인해야 해요. | Geumy oil-kkaji hwaginhae-ya haeyo. |

### Нюанс

- При указании точки во времени **에** нужно; при **~부터/까지** вторая точка так же требует **까지**.
- **까지** также означает «до» в смысле предела (до пятницы = 데드лайн).
