# Unit 3 — 문법 (Грамматика)

## 1. (으)려면 (если хотите сделать)

**Для глаголов:**
После гласной: **려면**
После согласной: **으려면**

```
가다 → 가려면           — если хотите идти
먹다 → 먹으려면         — если хотите есть
보다 → 보려면           — если хотите посмотреть
타다 → 타려면           — если хотите сесть (на транспорт)
```

```
명동에 가려면 4호선을 타세요.
— Если хотите поехать в Мёндон, садитесь на 4-ю линию.
한국어를 배우려면 열심히 공부해야 해요.
— Если хотите выучить корейский, нужно усердно учиться.
```

## 2. (으)세요 (вежливая просьба)

```
직진하세요.             — Идите прямо.
여기 앉으세요.          — Садитесь здесь.
4호선을 타세요.         — Садитесь на 4-ю линию.
천천히 말씀하세요.      — Говорите медленно, пожалуйста.
```

После гласной: **세요**, после согласной: **으세요**

## 3. 에 있다 / 에 없다 (находиться / не находиться)

```
역은 어디에 있어요?      — Где находится станция?
은행은 저쪽에 있어요.   — Банк вон там.
화장실은 여기에 없어요.  — Туалета здесь нет.
```

## 4. (으)로 (направление / инструмент)

После гласной/ㄹ: **로**
После остальных согласных: **으로**

```
오른쪽으로 가세요.       — Идите направо.
왼쪽으로 도세요.         — Поверните налево.
지하철로 가요.           — Поеду на метро.
버스로 학교에 가요.      — Еду в школу на автобусе.
```

## 5. 에서...까지 (от...до места)

```
여기에서 역까지 걸어서 10분 걸려요.
— Отсюда до станции пешком 10 минут.
서울에서 부산까지 기차로 2시간 반 걸려요.
— От Сеула до Пусана на поезде 2.5 часа.
```

## 6. 아/어도 되다 (можно / разрешается)

```
여기 앉아도 돼요?          — Здесь можно сесть?
사진을 찍어도 돼요?        — Можно фотографировать?
들어가도 됩니다.           — Можно войти.
```

## 7. (으)면 안 되다 (нельзя)

```
여기에서 담배를 피우면 안 돼요. — Здесь нельзя курить.
수업 중에 핸드폰을 사용하면 안 됩니다. — На уроке нельзя пользоваться телефоном.
```

## 8. 아/어 주세요 (сделайте для меня)

```
도와주세요.                — Помогите мне, пожалуйста.
가르쳐주세요.              — Научите меня.
알려주세요.                — Сообщите мне.
```

## 9. 시간이 걸리다 (занимать время)

**걸리다** — «занимать (время)». Обычно с вопросительным 얼마나.

```
얼마나 걸려요?              — Сколько времени займёт?
걸어서 10분 걸려요.          — Пешком займёт 10 минут.
비행기로 2시간 걸려요.       — На самолёте займёт 2 часа.
여기서 너무 오래 걸려요.     — Отсюда слишком долго.
```

- 걸어서 (пешком) + 시간: 걸어서 15분 걸려요.
- (으)로 (на транспорте) + 시간: 지하철로 30분 걸려요.

## 10. 에서 (отправная точка действия)

**에서** после места означает, откуда происходит или начинается действие.

```
여기에서 출발해요.       — Отправляемся отсюда.
학교에서 집에 가요.       — Из школы иду домой.
어디에서 오세요?          — Откуда вы приехали?
```

Отличие от **에** (место/направление):

- 학교에 가요 — иду в школу (направление).
- 학교에서 와요 — прихожу из школы (откуда).

## 11. 까지 / 부터 (до / с)

**부터** — «с, начиная с»; **까지** — «до, включительно».

```
몇 시부터 몇 시까지 일해요?    — С какого по какое время работаете?
아침 9시부터 저녁 6시까지 해요. — С 9 утра до 6 вечера.
역부터 시청까지 걸어요.          — От станции до мэрии иду пешком.
```

С **에** образуют полную конструкцию **에...까지**:

- 여기에서 역까지 (отсюда до станции).

## 12. 첫 번째 / 처음 & 장소 관련 순서 표현

Порядковые счётные выражения (первый, второй...):

```
첫 번째                — первый
두 번째                — второй
세 번째                — третий
왼쪽에서 두 번째 집     — второй дом слева
모퉁이에서 세 번째 건물  — третье здание от угла
```

- 주세요 — вежливая просьба после них:
- 오른쪽에서 첫 번째 건물이 은행이에요.

## 13. -는데 (контекст, «а ведь...»)

**-는데** присоединяется к основе глагола/прилагательного и создаёт фон для следующей фразы (противопоставление или контекст).

```
가까운데 걸어요.              — Это близко, так что иду пешком.
역이 먼데 택시를 타요.         — Станция далеко, поэтому беру такси.
좋은데 돈이 없어요.            — Хорошо бы, но денег нет.
시간이 있는데 같이 갈까요?     — Есть время, пойдём вместе?
```

## 14. 아/어 보다 (попробовать сделать)

Показатель «попробовать» действие.

```
지하철을 타 봐요.           — Попробуй поехать на метро.
한국 음식을 먹어 봤어요.     — Я пробовал корейскую еду.
이 길로 가 봐요.             — Попробуй пойти этой дорогой.
```

- С опытом: **-아/어 본 적이 있다** — есть опыт:
- 한국에 가 본 적이 있어요 — Я был в Корее (букв. имею опыт поездки).

## 15. (으)ㄹ 수 있다 (мочь, быть возможным)

Возможность/способность.

```
지하철로 갈 수 있어요.       — Могу поехать на метро.
표를 살 수 있어요.           — Могу купить билет.
여기에서 사진을 찍을 수 없어요. — Здесь нельзя фотографировать.
걸어서 갈 수 있어요.          — Можно дойти пешком.
```

- После гласной/ㄹ: **-ㄹ 수 있다**
- После согласной: **-을 수 있다**

## 16. 에 따라 (в соответствии с / вдоль)

```
지도를 따라 가세요.            — Идите по карте.
이 길을 따라 직진하세요.       — Идите прямо вдоль этой дороги.
표지판을 따라 오세요.           — Идите по указателям.
```

- **따라가다** — следовать за кем-то:
- 저를 따라오세요 — Следуйте за мной.

## 17. 의 (принадлежность) в навигации

```
이 건물의 주소는 뭐예요?        — Какой адрес у этого здания?
역의 오른쪽에 있어요.           — Находится справа от станции.
시청 앞의 공원에서 만나요.       — Встретимся в парке перед мэрией.
```

## 18. ~쯤 (приблизительно)

Добавляется к числу или месту для указания приблизительности.

```
5분쯤 걸려요.               — Около 5 минут.
역에서 10분쯤 떨어져 있어요. — Расположено примерно в 10 минутах от станции.
오후 3시쯤 만나요.           — Встретимся около 3 часов дня.
```
