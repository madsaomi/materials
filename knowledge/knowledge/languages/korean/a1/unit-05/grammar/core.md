# Unit 5 — 문법 (Грамматика)

## Учебная основа: Погода и вывод: 것 같다, -고, -지만

비가 와요 сообщает, что дождь идёт; 비가 올 것 같아요 выражает предположение о дожде. Второе высказывание не является просто «более вежливым будущим»: говорящий обозначает степень своей уверенности.

### Событие, состояние и время предположения

| Что предполагаем | Пример | Перевод |
|---|---|---|
| Действие происходит | 밖에 비가 오는 것 같아요. | Похоже, на улице идёт дождь. |
| Событие уже было | 밤에 비가 온 것 같아요. | Кажется, ночью шёл дождь. |
| Ожидаем событие | 오후에 비가 올 것 같아요. | Похоже, после обеда пойдёт дождь. |
| Текущее качество | 밖이 추운 것 같아요. | Кажется, на улице холодно. |
| Ожидаем качество | 내일은 추울 것 같아요. | Кажется, завтра будет холодно. |

Для глагола действия: -는 것 같다 сейчас, -(으)ㄴ 것 같다 о завершённом, -(으)ㄹ 것 같다 о предполагаемом. Для прилагательного текущее состояние оформляется -(으)ㄴ: 좋다 → 좋은 것 같아요; 춥다 → 추운 것 같아요. Не выбирайте форму только по русскому «кажется». В 것 и 같아요 сохраняются пробелы.

### Соединить факты или противопоставить

오늘은 춥고 바람이 불어요. — Сегодня холодно и дует ветер: перечисление. 춥지만 산책할 거예요. — Холодно, но я собираюсь погулять: контраст ожиданию. Перед согласным -지만 ㅂ сохраняется: 춥지만. Перед гласным у 춥다 происходит чередование: 추워요.

В последовательном рассказе удобно 밥을 먹고 나갔어요 — «поел(а) и вышел/вышла». Но время перед -고 не запрещено: 어제는 추웠고 오늘은 따뜻해요. — Вчера было холодно, а сегодня тепло. Здесь временная характеристика каждого факта выражена отдельно.

Не используйте культурное обобщение «все корейцы избегают категоричности» вместо правила. 것 같다 отмечает вывод/предположение; уверенный факт вполне можно сообщить напрямую.

### Источники для уточнённых правил

[-ㄹ 것 같다: предположение](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=71833). Статья описывает предположение и окружение формы после гласной/ㄹ; у согласной используется -을.

[국립국어원: время перед -고](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=320471). Ответ от 9 сентября 2025 подтверждает допустимость -었-/-겠- в обеих соединяемых частях.

## 1. Выражения погоды

**Структура зависит от явления:** 날씨가 맑아요 / 흐려요 — о состоянии погоды; 비가 와요 / 눈이 와요 — об осадках; 바람이 불어요 — о ветре. Не подставляйте 날씨 вместо 비 в 비가 와요. [한국어기초사전: 흐리다, значение5](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=89184).

```
오늘 날씨가 맑아요.          — Сегодня ясная погода.
비가 와요.                   — Идёт дождь.
눈이 와요.                   — Идёт снег.
바람이 불어요.               — Дует ветер.
천둥이 쳐요.                 — Гремит гром.
무지개가 보여요.              — Видна радуга.
```

Прилагательные погоды по сезонам:

```
여름에는 매우 더워요.        — Летом очень жарко.
겨울에는 아주 추워요.        — Зимой очень холодно.
봄에는 따뜻해요.             — Весной тепло.
가을에는 시원해요.           — Осенью прохладно.
```

## 2. -ㄹ 것 같다 (похоже, что...)

**Структура:** [основа глагола/прилагательного] + (으)ㄹ 것 같다

```
오늘 비가 올 것 같아요.      — Похоже, сегодня пойдёт дождь.
내일은 맑을 것 같아요.       — Похоже, завтра будет ясно.
그 영화가 재미있을 것 같아요. — Похоже, этот фильм интересный.
내일 추울 것 같아요.         — Похоже, завтра будет холодно.
비가 올 것 같지 않아요.      — Не похоже, что пойдёт дождь.
```

## 3. -고 (соединение: "и")

**Структура:** основа глагола или прилагательного + -고 + следующая часть предложения; для 이다 — 학생이고. Это позволяет соединять не только действия, но и состояния: 날씨가 좋고 바람이 불어요. [한국어기초사전: -고, значение1](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=78583).

```
저는 음악을 듣고 운동해요.       — Я слушаю музыку и занимаюсь спортом.
주말에는 등산하고 사진을 찍어요. — По выходным хожу в горы и фотографирую.
날씨가 좋고 바람이 불어요.        — Хорошая погода и дует ветер.
영화를 보고 책을 읽어요.          — Смотрю фильм и читаю книгу.
```

## 4. -지만 ("но")

**Структура:** [основа глагола/прилагательного] + 지만

```
날씨가 춥지만 산책해요.       — Погода холодная, но я гуляю.
저는 축구를 좋아하지만 잘 못해요. — Люблю футбол, но играю плохо.
비가 오지만 우산이 있어요.    — Идёт дождь, но у меня есть зонт.
매우 덥지만 수영을 해요.    — Очень жарко, но я плаваю.
```

## 5. -는데 (фон / мягкий контраст)

**Структура в настоящем:** глагол действия + -는데, прилагательное + -(으)ㄴ데, существительное + -인데. Есть особенности основ: 춥다 → 추운데, 살다 → 사는데; 있다/없다 → 있는데/없는데. Поэтому 주말인데 в примере ниже содержит именное сказуемое, а не пропущенный глагол действия.

```
비가 오는데 우산이 없어요.    — Идёт дождь, а у меня нет зонта.
날씨가 좋은데 공원에 가요.    — Погода хорошая, поэтому иду в парк.
주말인데 뭐 하실 거예요?       — Выходной, что будете делать?
너무 더운데 창문을 열어요.    — Очень жарко, поэтому открываю окно.
추운데 외출을 해요.           — Холодно, но выхожу.
```

## 6. -(으)러 가다 (идти, чтобы сделать)

После гласной и ㄹ — **-러 가다**: 보다 → 보러 가요; 놀다 → 놀러 가요. После другой согласной — **-으러 가다**: 먹다 → 먹으러 가요. Это цель движения, а не окончание будущего времени. [한국어기초사전: -러](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80300&nation=eng).

```
등산하러 가요.                — Иду в горы (в поход).
영화를 보러 가요.             — Иду смотреть фильм.
친구를 만나러 갔어요.         — Ходил встречаться с другом.
책을 읽으러 도서관에 가요.    — Иду в библиотеку читать книгу.
운동하러 체육관에 가요.      — Иду в спортзал заниматься спортом.
```

## 7. 가장 / 제일 (самый)

```
제일 좋아하는 계절은 봄이에요.  — Самое любимое время года — весна.
가장 좋아하는 가수는 누구예요?  — Кто твой самый любимый певец?
이 음악이 제일 좋아요.        — Эта музыка нравится больше всего.
제일 많이 보는 프로그램은 뭐예요? — Какую программу смотрите больше всего?
```

## 8. -아/어도 (даже если)

**Структура:** [основа глагола/прилагательного] + 아/어도

```
비가 와도 등산에 가요.        — Пойду в горы, даже если пойдёт дождь.
추워도 운동해요.              — Даже если холодно, занимаюсь спортом.
바빠도 음악을 들어요.         — Даже если занят, слушаю музыку.
어려워도 포기하지 않아요.     — Даже если трудно, не сдаюсь.
```

## 9. -고 있다 (действие в процессе)

```
웨이터가 음식을 가져오고 있어요. — Официант приносит еду.
손님이 밥을 먹고 있어요.          — Гость ест рис.
비가 오고 있어요.                 — Идёт дождь.
날씨가 추워지고 있어요.            — Становится холоднее.
```

## 10. -고 싶어요 / -고 싶지 않아요 (хочу / не хочу)

```
불고기를 먹고 싶어요.          — Хочу съесть пулькоги.
김치를 먹고 싶지 않아요.       — Не хочу есть кимчи.
콜라를 마시고 싶어요.          — Хочу выпить колу.
한국 음식을 더 먹고 싶어요.     — Хочу ещё есть корейскую еду.
이 레스토랑에 다시 오고 싶어요. — Хочу вернуться в этот ресторан.
주말에 여행하고 싶어요.        — Хочу поехать в путешествие на выходных.
```

## 11. -(으)면 (условие: "если...")

```
배가 고프면 식당에 가요.        — Если проголодаюсь, пойду в ресторан.
추우면 따뜻한 옷을 입어요.      — Если холодно, надену тёплую одежду.
맵지 않으면 잘 먹어요.          — Если не острое, хорошо ем.
시간이 있으면 영화를 볼 거예요. — Если будет время, посмотрю фильм.
비가 오면 택시를 탈 거예요.      — Если пойдёт дождь, сяду на такси.
날씨가 좋으면 등산을 갈 거예요.  — Если хорошая погода, пойду в горы.
```

## 12. -고 계세요 (вежливая форма продолженного действия)

계시다 относится к человеку, о котором говорят с уважением. В примерах ниже 기다리고 계세요 — процесс ожидания с уважением к официанту; 앉아 계세요 — состояние сидящего гостя (-아 있다). Заказ и погода получают обычное 있어요; их присутствие в списке не делает эти фразы примерами -고 계세요. О различии уважения к субъекту и вежливого 요 см. уточнение ниже.

```
웨이터가 기다리고 계세요.        — Официант ждёт (вежл.).
손님이 앉아 계세요.              — Гость сидит (вежл.).
주문이 준비되고 있어요.          — Заказ готовится.
날씨가 추워지고 있어요.           — Становится холоднее.
```

## 13. -한테 / -에게 (дательный падеж: "кому")

```
웨이터한테 주문을 했어요.       — Сделал заказ официанту.
친구한테 물을 줬어요.            — Дал другу воды.
선생님께 질문을 했어요.          — Задал(а) вопрос учителю (с уважением к учителю).
엄마한테 전화했어요.              — Позвонил маме.
사장님께 감사 인사를 했어요.     — Поблагодарил начальника.
```

## 14. -고 (соединение качеств) и -고 있다 (процесс)

```
이 음식은 맛있어요.              — Это блюдо вкусное.
오늘 날씨가 좋아요.              — Сегодня хорошая погода.
이 식당은 깔끔하고 좋아요.       — Этот ресторан чистый и хороший.
한국 음식은 맵고 유명해요.        — Корейская еда острая и известная.
```

## 15. -니까 (причина: "потому что", "ведь")

```
배가 고프니까 밥을 먹었어요.     — Был(а) голоден/голодна, поэтому поел(а).
비가 오니까 우산을 가져왔어요.   — Потому что идёт дождь, взял зонт.
한국 음식을 좋아하니까 자주 먹어요. — Потому что люблю корейскую еду, часто её ем.
시간이 없으니까 빨리 가야 해요.   — Потому что нет времени, нужно побыстрее.
날씨가 좋으니까 산책을 해요.     — Потому что хорошая погода, гуляю.
```

## Уточнение уважительных форм

-고 계시다 выражает уважение к человеку, о котором говорят; -고 있다 тоже употребляется о людях. Окончание 요 отдельно делает обращение к слушателю вежливым. В начальных нейтральных примерах не возвышаем заказ или погоду: 주문이 준비되고 있어요, 날씨가 추워지고 있어요. [국립국어원: конструкции процесса](https://kli.korean.go.kr/term/trgtWord/indexTrgtWord.do?trgtWordNo=2478026).

한테 и 에게 обозначают, кому адресовано действие; 한테 преимущественно разговорное. 께 — уважительная частица. 씨/님 не заменяют эту частицу: 선생님께 состоит из 선생님 и 께. [한국어기초사전: 한테](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=69714).


## Уточнение форм погоды

춥지만 сохраняет ㅂ перед согласной; 추운데 образуется с изменением перед гласным окончанием. Сравните 덥지만 и 더워요. Форму 추운데 отдельно поясняет [국립국어원](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=316566).
