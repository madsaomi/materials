# Unit 4 — 문법 (Грамматика)

## Учебная основа: Заказать и предложить: 주세요, -고 싶다, -(으)ㄹ까요

«Хочу», «дайте» и «давайте?» решают разные разговорные задачи. В ресторане одного знания слова 비빔밥 недостаточно: грамматическая форма показывает, сообщаете ли вы желание, делаете заказ или предлагаете общий выбор.

| Намерение говорящего | Фраза | Перевод |
|---|---|---|
| Получить предмет | 물 한 잔 주세요. | Дайте стакан воды, пожалуйста. |
| Попросить действие | 천천히 말해 주세요. | Говорите медленнее, пожалуйста. |
| Сообщить желание | 비빔밥을 먹고 싶어요. | Хочу поесть пибимпап. |
| Предложить общий выбор | 같이 비빔밥을 먹을까요? | Может, вместе поедим пибимпап? |
| Предложить свою помощь | 제가 주문할까요? | Мне сделать заказ? |

### Как образуются формы

Существительное + 주세요: 커피 주세요. Глагольная просьба требует -아/어 주세요: 읽다 → 읽어 주세요; 하다 → 해 주세요; 돕다 → 도와주세요. К желанию присоединяйте -고 싶어요 прямо к основе: 먹- + 고 싶어요. Для -ㄹ까요 после гласной добавляется ㄹ, после согласной кроме ㄹ — 을까요: 가다 → 갈까요, 먹다 → 먹을까요, 만들다 → 만들까요.

### Чьё желание и о чём вопрос

저는 쉬고 싶어요. — Хочу отдохнуть. 뭐 먹고 싶어요? — Что хотите поесть? Вопрос адресату естественно использует -고 싶어요. Когда описываете наблюдаемое желание друга, обычно говорите 친구는 쉬고 싶어 해요. Когда передаёте его слова: 친구가 쉬고 싶다고 했어요. — Друг сказал, что хочет отдохнуть. Поэтому правило «о третьем лице только 싶어하다 без исключений» слишком грубое.

비가 올까요? — Как думаете, будет дождь? Здесь -(으)ㄹ까요 спрашивает предположение, а не предлагает дождю что-либо сделать. Установите участников и смысл до перевода.

Фраза 먹고 싶어요 сама по себе сообщает желание. Чтобы однозначно заказать блюдо, используйте название и количество с 주세요: 비빔밥 하나 주세요.

### Источники для уточнённых правил

[-고 싶다: желание действия](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=75269). Статья определяет выражение как желание совершить действие и указывает присоединение к глаголу.

[하다: -어하다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=62888). Значение9 описывает выражение чувства через -어하다; эта модель помогает отличать наблюдаемое состояние другого человека.

Примеры и задания учебного ядра составлены для этой библиотеки.

## 1. -주세요 (вежливая просьба)

**Структура:** предмет + 주세요 — просьба дать предмет: 물을 주세요. Для просьбы выполнить действие используем основу + -아/어 주세요: 읽어 주세요, 기다려 주세요, 해 주세요. У основ с ㅏ/ㅗ обычно -아, с другими гласными -어; 하다 → 해 주세요. Нерегулярные основы проверяем отдельно: 돕다 → 도와주세요. В 물을 주세요 глагол уже 주다; дополнительное -아/어 перед 주세요 не вставляется.

```
물 좀 주세요.                  — Дайте, пожалуйста, воды.
김치찌개 하나 주세요.          — Дайте, пожалуйста, одну кимчичиге.
잠시만 기다려 주세요.          — Подождите, пожалуйста.
맵지 않게 해 주세요.           — Сделайте, пожалуйста, не острым.
계산서 주세요.                  — Дайте, пожалуйста, счёт.
메뉴 좀 주세요.                 — Дайте, пожалуйста, меню.
물 한 잔 주세요.                — Дайте, пожалуйста, стакан воды.
불고기 하나 더 주세요.          — Дайте, пожалуйста, ещё одну порцию пулькоги.
```

**Примечание:** 주세요 — это вежливая форма. Можно также использовать 주세요 после имени и обращения, например: 민수 씨, 물 좀 주세요. (Минсу, дайте, пожалуйста, воды.)

## 2. -고 싶다 (хотеть)

**Структура:** [основа глагола] + 고 싶다

```
불고기를 먹고 싶어요.          — Хочу съесть пулькоги.
한국 음식을 만들고 싶어요.     — Хочу готовить корейскую еду.
물을 마시고 싶어요.            — Хочу пить воду.
김치를 먹고 싶지 않아요.       — Не хочу есть кимчи.
식당에 가고 싶어요.             — Хочу пойти в ресторан.
콜라를 마시고 싶어요.          — Хочу выпить колу.
```

**Примечание:** Чтобы выразить отрицание желания, добавьте -지 않다 после 고 싶다: 먹고 싶지 않아요 (не хочу есть).

## 3. -(으)ㄹ까요? (предложение, вопрос о мнении)

После гласной добавляем ㄹ: 가다 → 갈까요? После согласной кроме ㄹ — 을까요: 먹다 → 먹을까요? У основы на ㄹ сохраняем одну ㄹ: 만들다 → 만들까요? [한국어기초사전: -ㄹ까요](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=82350&nation=eng) · [-을까요](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=82348).

```
뭐 먹을까요?                   — Что будем есть?
불고기 시킬까요?               — Закажем пулькоги?
한 잔 더 마실까요?             — Выпьем ещё по одной?
오늘 뭐 먹을까요?              — Что сегодня поесть?
김치찌개는 어때요?             — Как насчёт кимчичиге?
밥을 좀 더 먹을까요?           — Ещё немного риса?
```

**Примечание:** -ㄹ까요? используется для предложения совместного действия или для того, чтобы спросить мнение собеседника.

## 4. Наречия на -게: 맛있게 먹습니다

**Структура:** [основа прилагательного] + 게 (наречие)

```
맛있게 먹습니다.               — Ем с удовольствием. (Сообщение, не пожелание.)
맵게 해 주세요.                — Сделайте, пожалуйста, поострее.
짜게 하지 마세요.              — Не делайте слишком солёным.
달게 해 주세요.                — Сделайте, пожалуйста, сладким.
차갑게 주세요.                  — Дайте, пожалуйста, холодным.
뜨겁게 주세요.                  — Дайте, пожалуйста, горячим.
잘 먹었습니다.                   — Хорошо поели (выражение благодарности за еду).
```

**Примечание:** В 맛있게 먹습니다 форма 맛있게 описывает, как едят, а -습니다 завершает сообщение. Пожелание адресату можно выразить 맛있게 드세요 — «Приятного аппетита». 잘 먹겠습니다 произносят перед собственной едой как благодарность за угощение; это другая реплика, а не замена любого наречия на -게. [한국어기초사전: -게](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=77326&nation=eng), [-ㅂ니다: сообщение](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=79397&nation=eng).

## 5. 더 / 조금 (ещё / немного)

```
더 주세요.                     — Дайте ещё, пожалуйста.
조금만 주세요.                 — Дайте немного, пожалуйста.
더 먹고 싶어요.                — Хочу поесть ещё.
이 음식은 조금 매워요.         — Это блюдо немного острое.
더 마실까요?                   — Ещё выпьем?
물 좀 더 주세요.               — Дайте ещё немного воды.
음식이 좀 더 필요해요.          — Нужно ещё немного еды.
```

**Примечание:** 더 — «ещё, больше» (сравнительная степень). 조금 — «немного, чуть-чуть». Можно комбинировать: 좀 더 = ещё немного.

## 6. 여기요 / 저기요 (Обращение к официанту)

```
여기요! 계산서 주세요.         — Сюда! Дайте счёт, пожалуйста.
저기요, 메뉴 하나 더 주세요.   — Простите, ещё одно меню, пожалуйста.
여기요, 웨이터!                — Эй, официант!
저기요, 잠깐만요.              — Простите, на секунду.
```

**Примечание:** 여기요 используется, когда нужно привлечь внимание кого-то, кто рядом. 저기요 — когда человек находится дальше, или когда нужно обратиться к обслуживающему персоналу.

## 7. -(으)ㄹ 수 있다 / 없다 (мочь / не мочь)

После гласной добавляем ㄹ (가다 → 갈 수 있어요), после согласной кроме ㄹ — 을 (먹다 → 먹을 수 있어요). У основы на ㄹ дополнительная ㄹ не нужна: 만들다 → 만들 수 있어요. [한국어기초사전: -ㄹ 수 있다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=86664&nation=eng).

```
이 음식을 먹을 수 있어요.        — Я могу съесть это блюдо.
매운 음식을 먹을 수 없어요.      — Я не могу есть острую пищу.
기다릴 수 있어요.               — Я могу подождать.
한국어를 말할 수 있어요.         — Я могу говорить по-корейски.
이 메뉴를 읽을 수 있어요.        — Я могу прочитать это меню.
추워서 밖에 나갈 수 없어요.      — Мне холодно, поэтому я не могу выйти.
```

**Примечание:** -(으)ㄹ 수 있다 выражает способность или возможность. -(으)ㄹ 수 없다 — отрицательная форма.

## 8. -아/어서 (причина: "так как... поэтому")

**Структура:** [основа глагола/прилагательного] + 아/어서 + результат

Для регулярных основ с последней гласной ㅏ/ㅗ обычно **-아서**, с другими гласными **-어서**; 하다 → 해서. Учитывайте изменения основы: 배가 고프다 → 배가 고파서, 맵다 → 매워서. [한국어기초사전: -아서, значение2](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80220&nation=eng).

```
배가 고파서 식당에 갔어요.      — Проголодался, поэтому пошёл в ресторан.
음식이 맛있어서 다 먹었어요.    — Еда была вкусной, поэтому съел всё.
너무 매워서 물을 마셨어요.      — Было слишком остро, поэтому выпил воды.
비가 와서 우산을 가져왔어요.    — Пошёл дождь, поэтому взял зонт.
늦어서 기차를 놓쳤어요.        — Опоздал, поэтому пропустил поезд.
운동하고 나서 샤워해요.        — После тренировки принимаю душ.
```

**Примечание:** Первые пять примеров показывают причину. Последний, 운동하고 나서 샤워해요, содержит другую конструкцию -고 나서: «закончив тренировку, принимаю душ». Не образуйте из него правило для -아/어서.

## 9. -고 있다 / -고 계시다 (действие в процессе)

**Структура:** [основа глагола] + 고 있다 — процесс; 고 계시다 — процесс с уважением к действующему человеку. Это выбор уважения к субъекту, а не простое деление на одушевлённое и неодушевлённое.

```
웨이터가 음식을 가져오고 있어요. — Официант приносит еду.
손님이 밥을 먹고 있어요.          — Гость ест рис.
아기가 울고 있어요.              — Ребёнок плачет.
선생님이 말씀하고 계세요.        — Учитель говорит (с уважением).
```

**Примечание:** -고 있다 описывает продолжающееся действие; в этих примерах оно происходит сейчас. О прошлом можно сказать 먹고 있었어요 — «ел(а) в тот момент». Говоря о человеке с уважением, можно использовать -고 계시다; обычное -고 있어요 тоже вежливо по отношению к слушателю.

## 10. -고 싶어요 / -고 싶지 않아요 (хочу / не хочу)

```
불고기를 먹고 싶어요.          — Хочу съесть пулькоги.
김치를 먹고 싶지 않아요.       — Не хочу есть кимчи.
콜라를 마시고 싶어요.          — Хочу выпить колу.
한국 음식을 더 먹고 싶어요.     — Хочу ещё есть корейскую еду.
이 레스토랑에 다시 오고 싶어요. — Хочу вернуться в этот ресторан.
```

**Примечание:** -고 싶다 выражает желание. Для отрицания добавляется -지: 먹고 싶지 않아요 (не хочу есть).

## 11. -(으)면 (условие: "если...")

**Структура:** [основа глагола/прилагательного] + (으)면

```
배가 고프면 식당에 가요.        — Если проголодаюсь, пойду в ресторан.
추우면 따뜻한 옷을 입어요.      — Если холодно, надену тёплую одежду.
맵지 않으면 잘 먹어요.          — Если не острое, хорошо ем.
시간이 있으면 영화를 볼 거예요. — Если будет время, посмотрю фильм.
비가 오면 택시를 탈 거예요.      — Если пойдёт дождь, сяду на такси.
```

**Примечание:** -(으)면 используется для выражения условия. После гласной или ㄹ добавляется -면, после остальных согласных -으면: 가면, 살면, 먹으면. У некоторых слов есть нерегулярные изменения, например 춥다 → 추우면. Выбор не зависит от чередования ㅏ/ㅗ. [국립국어원](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=327471).

## 12. -고 계세요 (вежливая форма продолженного действия)

**Структура:** [основа глагола] + 고 계세요 (вежливая форма)

```
웨이터가 기다리고 계세요.        — Официант ждёт (вежл.).
손님이 앉아 계세요.              — Гость сидит (вежл.).
주문이 준비되고 있어요.          — Заказ готовится.
```

**Примечание:** 계시다 выражает уважение к действующему человеку; 요 отдельно делает речь вежливой по отношению к слушателю. 기다리고 계세요 описывает процесс ожидания. 앉아 계세요 устроено иначе: -아 있다 передаёт состояние после того, как человек сел. Последнее предложение 주문이 준비되고 있어요 — обычный процесс подготовки заказа без возвышения предмета. Не заменяйте любое 있어요 на 계세요.

## 13. -한테 / -에게 (дательный падеж: "кому")

**Структура:** получатель действия + 한테 / 에게. 한테 преимущественно разговорное, 에게 — нейтральная частица, встречающаяся и в письменной речи. Они сами по себе не выбирают вежливое окончание предложения; уважительная частица к получателю — 께. [한국어기초사전: 한테](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=69714).

```
웨이터한테 주문을 했어요.       — Сделал заказ официанту.
친구한테 물을 줬어요.            — Дал другу воды.
선생님께 질문을 했어요.          — Задал(а) вопрос учителю (с уважением к учителю).
엄마한테 전화했어요.              — Позвонил маме.
사장님께 감사 인사를 했어요.     — Поблагодарил начальника.
```

**Примечание:** 한테 преимущественно разговорное, 에게 — нейтральная частица. 께 — уважительный вариант 한테/에게: 선생님께. 씨/님 — элементы обращения и сами эту частицу не заменяют.

## 14. -고 (соединение качеств) и -고 있다 (процесс)

```
이 음식은 맛있어요.              — Это блюдо вкусное.
오늘 날씨가 좋아요.              — Сегодня хорошая погода.
이 식당은 깔끔하고 좋아요.       — Этот ресторан чистый и хороший.
한국 음식은 맵고 유명해요.        — Корейская еда острая и известная.
```

**Примечание:** соединение качеств выражает -고: 깔끔하고 좋아요. Конструкция -고 있다 передаёт процесс или сохраняющийся результат действия: 책을 읽고 있어요, 안경을 쓰고 있어요. Формы 맛있고 있어요 и 좋고 있어요 не используются для простого значения «вкусно / хорошая погода». [Словарь: -고](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=78583), [словарь: -고 있다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=72238&lang=eng).

## 15. -니까 (причина: "потому что", "ведь")

**Структура:** [основа] + -(으)니까: после гласной -니까, после согласной кроме ㄹ -으니까; ㄹ выпадает: 살다 → 사니까. Для существительного используется -(이)니까.

```
배가 고프니까 밥을 먹었어요.     — Был(а) голоден/голодна, поэтому поел(а).
비가 오니까 우산을 가져왔어요.   — Потому что идёт дождь, взял зонт.
한국 음식을 좋아하니까 자주 먹어요. — Потому что люблю корейскую еду, часто её ем.
시간이 없으니까 빨리 가야 해요.   — Потому что нет времени, нужно побыстрее.
```

**Примечание:** -(으)니까 выделяет основание для следующей мысли или действия; собеседник не обязан уже знать или разделять это основание. Сравните сообщение 비가 와서 우산을 가져왔어요 — «Из-за дождя я взял(а) зонт» и совет 비가 오니까 우산을 가져가세요 — «Раз идёт дождь, возьмите зонт». [한국어기초사전: -니까](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80139&nation=eng).

## 16. -아/어 보다 (пробовать делать)

**Структура:** [основа глагола] + 아/어 보다

```
한국 음식을 먹어 봤어요.        — Я пробовал корейскую еду.
이 메뉴를 한번 주문해 봐요.     — Давай попробуем заказать это блюдо.
불고기를 만들어 볼게요.         — Попробую приготовить пулькоги.
맵지 않은 음식을 먹어 봤어요.   — Пробовал неострую еду.
```

**Примечание:** -아/어 보다 выражает попытку или опыт «пробовать что-то сделать». После а/о — 아 보다, после других гласных — 어 보다, 하다 → 해 보다.

## 17. -는 동안 (в течение, пока)

**Структура:** [глагол] + 는 동안

```
음식을 기다리는 동안 메뉴를 봤어요. — Пока ждал еду, смотрел меню.
밥을 먹는 동안 말하지 마세요.       — Не говорите, пока едим.
요리하는 동안 손님이 기다려요.      — Пока готовят, гость ждёт.
웨이터가 오는 동안 잠시 쉬어요.    — Пока идёт официант, отдохнём минутку.
```

**Примечание:** -는 동안 задаёт период продолжающегося действия, на фоне которого происходит другое. Форма -는 здесь не ограничивает весь рассказ настоящим: 기다리는 동안 메뉴를 봤어요 уже описывает прошлое. При плане возможно 친구가 요리하는 동안 제가 상을 차릴 거예요 — «Пока друг будет готовить, я накрою на стол». Время устанавливается по всему предложению. [한국어기초사전: -는 동안](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=85732&nation=eng).

## 18. -(으)라고 하다 (просьба в косвенной речи)

**Структура:** [основа глагола] + (으)라고 하다

```
웨이터가 맵지 않게 하라고 했어요.  — Официант сказал сделать не острым.
엄마가 빨리 먹으라고 했어요.        — Мама сказала есть быстрее.
친구가 만두를 주문하라고 했어요.    — Друг сказал заказать манду.
주인이 천천히 먹으라고 했어요.      — Хозяин сказал есть не спеша.
```

**Примечание:** -(으)라고 하다 передаёт чужую просьбу или приказ в косвенной речи: «(он) сказал сделать что-то».

## 19. -(으)ㄹ 때 (когда)

**Структура:** [основа глагола] + (으)ㄹ 때

```
배가 고플 때 식당에 가요.         — Когда голоден, иду в ресторан.
밥을 먹을 때 텔레비전을 봐요.     — Когда ем, смотрю телевизор.
손님이 올 때 문을 열어 주세요.    — Когда придёт гость, откройте дверь.
주문할 때 메뉴를 잘 보세요.       — Когда заказываете, внимательно смотрите меню.
```

**Примечание:** -(으)ㄹ 때 выражает время «когда...»: 가다 → 갈 때; 먹다 → 먹을 때. У основы на ㄹ дополнительная ㄹ и 으 не нужны: 만들다 → 만들 때. Эта форма может описывать привычную или ожидаемую ситуацию, а не только будущее.

## 20. -겠어요 (предположение, намерение)

**Структура:** [основа глагола/прилагательного] + 겠어요

```
기다리겠어요.                    — (Я) подожду.
이 음식은 맛있겠어요.            — Это блюдо, наверное, вкусное.
계산은 카드로 하겠어요.          — Оплачу картой.
추울 텐데 따뜻하게 입겠어요.     — Наверное холодно, наденусь потеплее.
```

**Примечание:** -겠어요 имеет два значения: намерение говорящего и предположение о чём-то. В ресторане часто используется для вежливого выражение намерения заказать.

## Уточнение уважительных форм

-고 계시다 выражает уважение к человеку, о котором говорят; -고 있다 тоже употребляется о людях. Окончание 요 отдельно делает обращение к слушателю вежливым. В начальных нейтральных примерах не возвышаем заказ или погоду: 주문이 준비되고 있어요, 날씨가 추워지고 있어요. [국립국어원: конструкции процесса](https://kli.korean.go.kr/term/trgtWord/indexTrgtWord.do?trgtWordNo=2478026).

한테 и 에게 обозначают, кому адресовано действие; 한테 преимущественно разговорное. 께 — уважительная частица. 씨/님 не заменяют эту частицу: 선생님께 состоит из 선생님 и 께. [한국어기초사전: 한테](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=69714).
