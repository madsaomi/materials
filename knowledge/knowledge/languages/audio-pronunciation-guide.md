# 🔊 Аудио-произношение: Интеграция Forvo и ресурсов

> Быстрые ссылки на произношение носителями для ключевых слов.
> Кликните на 🔊 рядом со словом, чтобы услышать произношение.

---

## Как пользоваться

В словарных заметках этого хранилища используйте следующие шаблоны для быстрого доступа к аудио:

### Forvo (все языки)
```
[🔊](https://forvo.com/word/СЛОВО/#ja)   ← японский
[🔊](https://forvo.com/word/СЛОВО/#ko)   ← корейский
[🔊](https://forvo.com/word/СЛОВО/#zh)   ← китайский
[🔊](https://forvo.com/word/СЛОВО/#en)   ← английский
```

### Google Translate TTS (быстро, все языки)
```
[🔊](https://translate.google.com/?sl=ja&tl=ru&text=СЛОВО&op=translate)
```

### OJAD (японский — акценты и интонация)
```
[📊](https://www.gavo.t.u-tokyo.ac.jp/ojad/search/index/word:СЛОВО)
```
