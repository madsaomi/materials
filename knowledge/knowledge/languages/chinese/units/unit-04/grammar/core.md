# Unit 4 — 语法 (Грамматика)

## 1. 一边…一边… (одновременно)

Указывает, что два действия выполняются одновременно. Оба действия относятся к одному подлежащему.

```
我一边吃饭，一边看电视。     — Я ем и (при этом) смотрю телевизор.
他一边听音乐，一边学习。     — Он слушает музыку и учится.
我们一边喝茶，一边聊天。     — Мы пьём чай и болтаем.
```

Второе действие — главное (более важное), первое — фон.

## 2. 有点儿 / 一点儿 (немного)

**有点儿 + прилагательное** — перед прилагательным, выражает "немного, слегка" (часто с оттенком недовольства):

```
这个菜有点儿辣。       — Это блюдо немного острое.
汤有点儿咸。           — Суп немного солёный.
今天有点儿冷。         — Сегодня немного холодно。
```

**一点儿** — после существительного или после прилагательного, обозначает количество ("немножко"):

```
我要一点儿糖。         — Мне чуть-чуть сахара。
请你快一点儿。         — Пожалуйста, побыстрее。
我吃了一点儿米饭。     — Я немного поел риса。
```

## 3. 动词 + 得 + 形容词 (дополнение степени)

Служит для описания того, КАК выполняется действие. Структура: `Подлежащее + Глагол + 得 + Наречие/Прилагательное`.

```
她唱歌唱得很好。         — Она очень хорошо поёт。
他写汉字写得很漂亮。     — Он очень красиво пишет иероглифы。
菜做得真好吃！           — Еда приготовлена очень вкусно！
```

Если у глагола есть дополнение, его можно вынести вперёд:

```
她做菜做得很香。     =  她菜做得很香。    — Она вкусно готовит。
他中文说得很流利。       — Он бегло говорит по-китайски。
```

## 4. 会 / 能 / 可以 (мочь, уметь, можно)

| Слово | Значение | Пример |
|-------|----------|--------|
| 会 | уметь (навык, умение) | 你会做饭吗？ — Ты умеешь готовить? |
| 能 | мочь (возможность, разрешение) | 我现在不能吃辣的。 — Сейчас я не могу есть острое。 |
| 可以 | можно (разрешено) | 我可以进来吗？ — Можно войти? |

Вежливая просьба строится через 可以…吗？ / 能…吗？:

```
可以给我看一下菜单吗？   — Можно посмотреть меню？
你能帮我一下吗？         — Ты не мог бы мне помочь？
请问，我可以坐这儿吗？   — Скажите, можно сесть здесь？
```

## 5. 再来 (ещё раз, добавьте)

Используется при заказе ещё одной порции. 再 = "ещё", 来 = "принесите/дайте"。

```
再来一碗米饭。       — Ещё одну миску риса。
再来一杯茶。         — Ещё чашку чая。
服务员，再来一个饺子！— Официант, ещё один пельмень！
```

## 6. 买单 / 结账 (оплатить счёт)

Оба выражения означают "оплатить счёт"。 买单 — разговорный вариант, 结账 — более официальный。

```
服务员，买单！           — Официант, счёт！
我要结账。               — Я хочу оплатить счёт。
我们买单，一共多少钱？   — Мы платим, сколько всего？
一起买单还是分开买单？   — Платим вместе или раздельно？
```

## 7. 不好意思 (извините / неловко)

Мягкое извинение или выражение смущения。 Слабее, чем 对不起 (серьёзное извинение)。

```
不好意思，请问洗手间在哪儿？   — Извините, где туалет？
不好意思，让你久等了。         — Извините, что заставил(а) вас ждать。
他有点不好意思。               — Ему немного неловко。
```

## 8. 又…又… (и…, и…; одновременно обладает двумя признаками)

Указывает, что предмет или действие обладает двумя признаками одновременно. Структура: `A 又 B 又 C`.

```
这个菜又辣又香。       — Это блюдо и острое, и ароматное。
她又聪明又漂亮。       — Она и умная, и красивая。
他又说又笑。           — Он и говорит, и смеётся。
今天又热又潮湿。       — Сегодня и жарко, и влажно。
```

Можно использовать для описания еды, погоды, людей и т.д.

## 9. 虽然…但是… (хотя…, но…)

Выражает противопоставление. Структура: `虽然 + предложение, 但是 + предложение`.

```
虽然这个菜很辣，但是我很喜欢。   — Хотя это блюдо очень острое, но мне очень нравится。
虽然今天很忙，但是我们还是去了。 — Хотя сегодня мы очень заняты, но всё равно пошли。
他虽然年纪小，但是很懂事。       — Он хотя и молод, но очень сообразительный。
```

Отрицание: `虽然…但是…不…` — "хотя…, но не…":

```
虽然他很忙，但是他不休息。 — Хотя он очень занят, но он не отдыхает。
```

## 10. 因为…所以… (потому что…, поэтому…)

Выражает причину и следствие. Структура: `因为 + причина, 所以 + следствие`.

```
因为今天很冷，所以我穿了羽绒服。   — Потому что сегодня очень холодно, я надел пуховик。
因为菜很好吃，所以我们又点了一盘。 — Потому что еда очень вкусная, мы заказали ещё одну порцию。
他因为生病，所以没有来。           — Он не пришёл, потому что заболел。
```

Можно опустить 所以, если следствие очевидно:

```
因为下雨，我们不出去了。 — Пойдёт дождь, поэтому мы не выходим。
```

## 11. 把字句 (конструкция с 把)

Используется, когда действие направлено на объект. Структура: `Подлежащее + 把 + объект + глагол + дополнение`.

```
请你把菜单给我。       — Дайте мне меню, пожалуйста。
他把钱付了。           — Он оплатил счёт。
我把菜打包了。         — Я заказал еду с собой (упаковал)。
请你把筷子递给我。     — Передайте мне палочки, пожалуйста。
```

Объект перед глаголом подчёркивает, что действие завершено и направлено на конкретный объект。

## 12. 不…不… (не…, не…; отрицание двух признаков)

Указывает, что предмет или действие не обладает ни одним из двух признаков. Структура: `不 A 不 B`。

```
这个菜不辣不咸。       — Это блюдо ни острое, ни солёное。
他不高不矮。           — Он не высокий и не низкий (среднего роста)。
今天不冷也不热。       — Сегодня ни холодно, ни жарко。
这个包不贵也不便宜。   — Эта сумка ни дорогая, ни дешёвая。
```

Часто используется при описании еды, погоды, людей и предметов。

## 13. 从…到… (от… до…)

Указывает на диапазон времени или пространства。 Структура: `从 A 到 B`。

```
从早上到晚上，我都在学习。 — С утра до вечера я учусь。
从餐厅到超市很近。         — От ресторана до супермаркета недалеко。
我们从一点到三点有课。     — У нас занятия с одного до трёх。
```

Можно заменить 到 на 其他 (другой), 中间 (посередине) и т.д.

## 14. 一…就… (как только…)

Указывает, что одно действие сразу же следует за другим。 Структура: `一 + A + 就 + B`。

```
一看到菜单，我就饿了。     — Как только увидел меню, я почувствовал голод。
一吃饭，他就看电视。       — Как только он начинает есть, он сразу смотрит телевизор。
一下雨，我们就待在家里。   — Как только идёт дождь, мы остаёмся дома。
一进门，他就打招呼。       — Как только вошёл, он сразу поздоровался。
```

## 15. 正要…就… (как раз собирался…, когда…)

Выражает, что действие вот-вот должно было произойти, но было прервано。 Структура: `正要 + A, 就 + B`。

```
我正要打电话，你就来了。     — Я как раз собирался позвонить, а ты уже пришёл。
他正要出门，就下雨了。       — Он как раз собирался выйти, а пошёл дождь。
我正要关门，你就回来了。     — Я как раз собирался закрыть дверь, а ты вернулся。
```
