# Unit 14 — 书面语: 书面 vs 口语, 书面词汇, 关联词

## 1. 书面语 vs 口语 (письменная vs устная речь)

### 1.1 Общая характеристика

| Параметр | 书面语 (shūmiànyǔ) | 口语 (kǒuyǔ) |
|----------|---------------------|---------------|
| Сфера | Книги, газеты, документы, лекции | Повседневное общение |
| Стиль | Формальный, строгий | Разговорный, свободный |
| Структура предложений | Длинные, сложные | Короткие, простые |
| Лексика | Книжные слова | Просторечия, сленг |

### 1.2 Соответствия: 口语 → 书面语

| 口语 (устная) | 书面语 (письменная) | Пример 口语 | Пример 书面语 |
|---------------|---------------------|-------------|---------------|
| 的 | 之 | 我的朋友 | 我之好友 |
| 没有 | 未 | 没有来 | 未到场 |
| 还是 | 或 | 去还是不去 | 去或不去 |
| 但是 | 但/然而 | 但是很好 | 但/然而甚佳 |
| 因为 | 因 | 因为下雨 | 因下雨 |
| 所以 | 故 | 所以走了 | 故离去 |
| 现在 | 目前/现今 | 现在几点？ | 目前时辰几何？ |
| 很多 | 诸多/众多 | 很多人 | 诸多人士 |
| 看 | 观/视 | 看电影 | 观影 |
| 说 | 曰/言 | 他说… | 他曰… |
| 叫 | 名曰 | 这叫什么？ | 此物名曰何？ |

### 1.3 Примеры в контексте

| 口语 | 书面语 | Комментарий |
|------|--------|-------------|
| 这本书很好看。 | 此书甚为精彩。 | 的→之, 很→甚, 好看→精彩 |
| 他没来上班。 | 他未到岗。 | 没有→未, 上班→到岗 |
| 因为生病，所以没去。 | 因身体抱恙，故未能前往。 | 因为→因, 所以→故 |
| 我想问你一个问题。 | 我欲请教一问题。 | 想→欲, 问→请教 |

## 2. Письменная лексика (书面词汇)

### 2.1 Соединительные слова (连接词)

| Слово | Пиньинь | Значение | Пример |
|-------|---------|----------|--------|
| 因此 | yīncǐ | поэтому | 他迟到了，因此会议推迟。 |
| 然而 | rán'ér | однако | 他很努力，然而成绩不好。 |
| 此外 | cǐwài | кроме того | 此外，我们还有其他方案。 |
| 总之 | zǒngzhī | в общем, итог | 总之，这个问题很复杂。 |
| 否则 | fǒuzé | иначе | 你要努力，否则会失败。 |
| 既然 | jìrán | раз уж(е) | 既然你决定了，我支持你。 |
| 尽管 | jǐnguǎn | несмотря на то что | 尽管困难，我们继续前进。 |
| 无论 | wúlùn | неважно как/что | 无论怎样，我们都要完成。 |
| 不仅 | bùjǐn | не только | 他不仅聪明，而且勤奋。 |
| 甚至 | shènzhì | даже | 他甚至不吃早餐。 |

### 2.2 Письменные глаголы и фразы

| 口语 | 书面语 | Пример书面ого текста |
|------|--------|----------------------|
| 认为 | 认为/以为 | 我认为这个方案可行。 |
| 需要 | 需/需要 | 此事需进一步研究。 |
| 能够 | 能/得以 | 他得以顺利完成任务。 |
| 开始 | 着手/启动 | 项目已着手进行。 |
| 结束 | 告终/完成 | 会议已告终。 |
| 帮助 | 协助 | 请协助我完成这项工作。 |
| 重要 | 至关重要 | 这一点至关重要。 |

### 2.3 Письменные существительные

| 口语 | 书面语 | Пример |
|------|--------|--------|
| 时候 | 时刻/之际 | 在此关键时刻 |
| 东西 | 物品/事物 | 各种物品 |
| 地方 | 地点/场所 | 重要场所 |
| 事情 | 事宜/事项 | 相关事宜 |
| 人 | 人士/人员 | 相关人士 |

## 3. Сложные связывающие конструкции (关联词)

### 3.1 Основные пары

| Пара | Значение | Пример |
|------|----------|--------|
| 因为…所以… | потому что… поэтому… | 因为下雨，所以我没去。 |
| 虽然…但是… | хотя… но… | 虽然累，但是很开心。 |
| 不但…而且… | не только… но и… | 他不但会说中文，而且会写。 |
| 如果…就… | если… то… | 如果有时间，我就来找你。 |
| 只有…才… | только если…才… | 只有努力，才能成功。 |
| 只要…就… | стоит/достаточно…就… | 只要你来，我就高兴。 |
| 与其…不如… | лучше… чем… | 与其等待，不如行动。 |
| 不是…就是… | или… или… | 不是他，就是她。 |
| 既然…就… | раз уж… то… | 既然你决定了，就去做吧。 |
| 无论…都… | неважно… все равно… | 无论怎样，我都要去。 |

### 3.2 Подробные примеры

**因为…所以…**

- **因为**他是新手，**所以**需要更多时间。 — *Поскольку он новичок, ему нужно больше времени.*

**不但…而且…**

- 他**不但**会弹钢琴，**而且**会拉小提琴。 — *Он не только играет на фортепиано, но и на скрипке.*

**只有…才…**

- **只有**通过考试，**才**能毕业。 — *Только сдав экзамен, можно выпуститься.*

**与其…不如…**

- **与其**抱怨，**不如**想办法解决。 — *Лучше искать решение, чем жаловаться.*

## 4. Маркеры формального стиля

### 4.1 Маркеры начала текста

| Маркер | Использование | Пример |
|--------|---------------|--------|
| 首先 | во-первых | 首先，我要感谢大家。 |
| 其次 | во-вторых | 其次，我们来讨论问题。 |
| 最后 | в-третьих / наконец | 最后，总结一下。 |
| 据报道 | как сообщается | 据报道，会议已结束。 |
| 根据 | согласно | 根据调查，90%的人支持。 |

### 4.2 Маркеры конца текста

| Маркер | Использование | Пример |
|--------|---------------|--------|
| 综上所述 | подводя итог | 综上所述，此方案可行。 |
| 由此可见 | как видно из этого | 由此可见，问题很严重。 |
| 特此通知 | настоящим уведомляем | 特此通知，会议延期。 |
| 请予以考虑 | прошу рассмотреть | 请予以考虑我们的建议。 |

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| ❌ 因为…因此… | ✅ 因为…所以… / 因…故… | 不 смешивайте пары |
| ❌ 不但…还…但是… | ✅ 不但…而且… | 不 ставьте третью часть |
| ❌ 我没有看过此书。 | ✅ 我未曾阅过此书。 / 我没看过这本书。 | 书面语 未曾, а口语 没有 |
| ❌ 他是很聪明的人。 | ✅ 他是一位极为聪慧之士。 | 书面语: 很→极为, 人→士 |

## 7. Структура официального письма (书信格式)

### 7.1 Стандартная композиция

| Часть | Иероглифы | Назначение |
|--------|-----------|------------|
| Обращение | 尊敬的…先生/女士： | Уважаемый… |
| Приветствие | 您好！/ 见信如面 | Здравствуйте |
| Вступление | 兹/特此/来函收悉 | Вступление, подтверждение получения |
| Основная часть | 首先…其次…最后 | Развитие темы |
| Просьба | 敬请/恳请/望… | Просьба |
| Заключение | 此致敬礼/顺祝商祺 | Завершение |
| Подпись | 敬上/谨启 | Почтительно ваш |

### 7.2 Пример полного письма

```
尊敬的张先生：
您好！
来函收悉。我方兹定于本月十五日举行合作洽谈会。
首先，我们将介绍公司背景；其次，商讨合作细节；
最后，签署初步协议。如有疑问，敬请及时告知。
此致敬礼！
某某敬上
```

## 8. Частотные разрешительные и временные конструкции

### 8.1 Конструкции с 非…不可 / 无不

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 非…不可 | непременно, обязательно | 此事非他不可。— Без него это не обойдётся. |
| 无不 | все без исключения | 众人无不赞同。— Все без исключения согласны. |
| 不得不 | вынужден | 我们不得不接受。— Мы вынуждены согласиться. |
| 不由得 | невольно | 见此不由得感动。— Увидев это, невольно тронулся. |

### 8.2 Временные наречия (временные наречия)

| Наречие | Пиньинь | Значение | Пример |
|---------|---------|----------|--------|
| 过去 | guòqù | в прошлом | 过去情况不同。— В прошлом ситуация была иной. |
| 如今 | rújīn | ныне | 如今已大不同。— Ныне всё совсем иначе. |
| 此后 | cǐhòu | после этого | 此后需更加努力。— После этого нужно стараться больше. |
| 起初 | qǐchū | вначале | 起初大家不同意。— Вначале все были против. |
| 随后 | suíhòu | затем, вслед за тем | 随后我们离开。— Затем мы ушли. |
| 即刻 | jíkè | немедленно | 请即刻出发。— Немедленно отправляйтесь. |
| 届时 | jièshí | к тому времени | 届时请准时到场。— К назначенному времени приходите вовремя. |

## 9. Синтаксис: рамочные конструкции (框架结构)

### 9.1 Типичные книжные рамки

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 在…方面 | в аспекте… | 在经济方面，情况良好。— В экономическом аспекте дела идут хорошо. |
| 从…来看 | с точки зрения… | 从长远来看，这是好事。— В долгосрочной перспективе это хорошо. |
| 就…而言 | что касается… | 就此问题而言，尚无定论。— Что касается этого вопроса, окончательного решения ещё нет. |
| 对…来说 | для… | 对我们来说，这很重要。— Для нас это важно. |
| 随着… | по мере… | 随着科技发展，生活改变。— По мере развития технологий жизнь меняется. |
| 在…过程中 | в процессе… | 在工作中进程中，我们学到了很多。— В процессе работы мы многому научились. |
| 至于… | что касается… | 至于价格，我们可再谈。— Что касается цены, можем ещё обсудить. |

### 9.2 Примеры в контексте

**就…而言**

- **就**整体**而言**，方案是可行的。 — *Что касается всего в целом, план осуществим.*

**随着…**

- **随着**经济的增长，人们的生活提高了。 — *По мере роста экономики уровень жизни людей вырос.*

**至于…**

- **至于**预算问题，我们稍后讨论。 — *Что касается проблемы бюджета, обсудим позже.*

## 10. Слова-связки для абзацев (段落连接语)

### 10.1 Введение темы

| Слово | Пиньинь | Значение | Пример |
|-------|---------|----------|--------|
| 首先 | shǒuxiān | во-первых | 首先，我感谢大家。— Во-первых, благодарю всех. |
| 其次 | qícì | во-вторых | 其次，我们讨论问题。— Во-вторых, обсудим вопрос. |
| 然后 | ránhòu | затем | 然后，提出建议。— Затем выскажу предложение. |
| 最后 | zuìhòu | наконец | 最后，总结一下。— Наконец, подведём итог. |

### 10.2 Развитие мысли

| Слово | Пиньинь | Значение | Пример |
|-------|---------|----------|--------|
| 而且 | érqiě | причём | 方案好，而且省钱。— План хорош, причём экономичный. |
| 况且 | kuàngqiě | тем более, к тому же | 况且我们时间有限。— К тому же у нас мало времени. |
| 加之 | jiāzhī | вдобавок | 加之天气恶劣。— Вдобавок плохая погода. |
| 然而 | rán'ér | однако | 然而，并不容易。— Однако это нелегко. |
| 反之 | fǎnzhī | наоборот | 反之，情况更糟。— Наоборот, ситуация хуже. |
| 尽管如此 | jǐnguǎn rúcǐ | несмотря на это | 尽管如此，我们继续努力。— Несмотря на это, мы продолжаем стараться. |

### 10.3 Завершение

| Слово | Пиньинь | Значение | Пример |
|-------|---------|----------|--------|
| 总之 | zǒngzhī | в общем | 总之，此计可行。— В общем, этот план осуществим. |
| 综上所述 | zōng shàng suǒ shù | подводя итог | 综上所述，请批准。— Подводя итог, просим утвердить. |
| 由此可见 | yóu cǐ kě jiàn | отсюда видно | 由此可见，我们必须行动。— Отсюда видно, что мы должны действовать. |
| 归根结底 | guī gēn jié dǐ | в конечном счёте | 归根结底，态度决定一切。— В конечном счёте всё решает отношение. |

## 11. Формальные сокращения (书面缩略)

В официальном стиле часто используют сокращения из двух иероглифов:

| Сокращение | Полная форма | Значение |
|------------|--------------|----------|
| 兹 | 现在 | сейчас (зачин документа) |
| 函 | 信 | письмо |
| 呈 | 递交 | подавать |
| 拟 | 打算 | намереваться |
| 应 | 应该 | должен |
| 须 | 必须 | обязан |
| 予 | 给予 | дать, оказать |
| 否 | 是否 | ли (вопрос) |
| 故 | 所以 | поэтому |
| 若 | 如果 | если |

**Пример:**

- 请贵公司**查收**附件并尽快**回函**。 — *Просим вашу компанию получить вложение и скорее ответить.*
- 我**拟**于下周**呈报**此报告。 — *Я намереваюсь подать этот отчёт на следующей неделе.*
