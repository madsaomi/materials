# Unit 2 — 对话: 买东西 (Покупки)

## 对话

```
售货员: 你好！欢迎光临！你想买什么？
顾客: 你好！我想买一件T恤衫。
售货员: 你喜欢什么颜色？
顾客: 我喜欢蓝色。有没有蓝色的？
售货员: 有。这件怎么样？
顾客: 可以试穿一下吗？
售货员: 当然可以。试衣间在那边。
顾客: 大小很合适。多少钱？
售货员: 一百五十块。
顾客: 太贵了！能不能便宜一点儿？
售货员: 嗯... 给你打个九折。一百三十五块。
顾客: 好吧，我要了。可以刷卡吗？
售货员: 可以。请到收银台付款。
```

# Дополнение — новые диалоги

## 对话 2: 在市场买菜 (На овощном рынке. Торг и взвешивание)

*Ситуация: покупатель берёт овощи, продавец взвешивает по 斤 (цзинь), идёт торг.*

| 中文 | 拼音 | 翻译 |
|------|------|------|
| 老板，西红柿多少钱一斤？ | Lǎobǎn, xīhóngshì duōshao qián yī jīn? | Хозяин, сколько стоит цзинь помидоров? |
| 五块钱一斤。 | Wǔ kuài qián yī jīn. | 5 юаней за цзинь. |
| 太贵了，便宜点儿吧。 | Tài guì le, piányi diǎnr ba. | Слишком дорого, подешевле можно? |
| 这是好西红柿，四块五吧。 | Zhè shì hǎo xīhóngshì, sì kuài wǔ ba. | Это хорошие помидоры, пусть будет 4,5. |
| 好，给我称两斤。 | Hǎo, gěi wǒ chēng liǎng jīn. | Ладно, взвесьте мне два цзиня. |
| 两斤一共九块钱。 | Liǎng jīn yīgòng jiǔ kuài qián. | Два цзиня, всего 9 юаней. |
| 一共九块，给你十块，找一块。 | Yīgòng jiǔ kuài, gěi nǐ shí kuài, zhǎo yī kuài. | Всего 9, даю 10, сдача 1. |
| 收你十块钱，找你一块。 | Shōu nǐ shí kuài qián, zhǎo nǐ yī kuài. | Принято 10, сдача 1. |
| 谢谢老板！ | Xièxie lǎobǎn! | Спасибо, хозяин! |
| 不客气，下次再来！ | Bú kèqi, xiàcì zài lái! | Не за что, заходите ещё! |

### Разбор

- **一斤 = 500 г**: цены на рынке всегда за цзинь (грамматика §10).
- **便宜点儿吧** — побудительное предложение с 吧 (давай-ка подешевле).
- **称 (chēng)** — взвешивать; **找 (zhǎo)** — давать сдачу.
- **给你十块** — букв. «даю тебе десять»; продавец повторяет расчёт.

## 对话 3: 在超市付款 (В супермаркете. Оплата кодом)

*Ситуация: покупатель на кассе, платит по QR-коду.*

| 中文 | 拼音 | 翻译 |
|------|------|------|
| 你好，请问一共多少钱？ | Nǐ hǎo, qǐngwèn yīgòng duōshao qián? | Здравствуйте, сколько всего? |
| 一共七十八块五。 | Yīgòng qīshíbā kuài wǔ. | Всего 78,5 юаня. |
| 这么贵？什么这么贵？ | Zhème guì? Shénme zhème guì? | Так дорого? Что так дорого? |
| 牛奶三盒就三十块了。 | Niúnǎi sān hé jiù sānshí kuài le. | Три коробки молока — уже 30 юаней. |
| 好，可以微信支付吗？ | Hǎo, kěyǐ Wēixìn zhīfù ma? | Хорошо, можно заплатить через WeChat Pay? |
| 当然可以，扫码就行。 | Dāngrán kěyǐ, sǎomǎ jiù xíng. | Конечно, достаточно отсканировать код. |
| 已经付了，你看一下。 | Yǐjīng fù le, nǐ kàn yīxià. | Уже оплатил (а), посмотрите. |
| 好，收到了。这是发票。 | Hǎo, shōudào le. Zhè shì fāpiào. | Хорошо, получил(а). Вот чек. |

### Разбор

- **一共 (yīgòng)** — всего (итоговая сумма).
- **就...了** — подчёркивает, что что-то «уже» достигло величины: 三盒就三十块了.
- **支付 (zhīfù)** — оплата; **扫二维码** — сканировать QR-код (грамматика §…, лексика).
- **已经 (yǐjīng)** — уже (наречие перед глаголом).

## 对话 4: 换一件衣服 (Обмен товара)

*Ситуация: покупатель хочет обменять свитер на размер побольше.*

| 中文 | 拼音 | 翻译 |
|------|------|------|
| 你好，我想换这件毛衣。 | Nǐ hǎo, wǒ xiǎng huàn zhè jiàn máoyī. | Здравствуйте, я хочу обменять этот свитер. |
| 有什么问题吗？ | Yǒu shénme wèntí ma? | Есть какие-то проблемы? |
| 有点儿小，穿着不舒服。 | Yǒudiǎnr xiǎo, chuānzhe bù shūfu. | Маловат, носить неудобно. |
| 发票带了吗？ | Fāpiào dài le ma? | Чек с собой принесли? |
| 带了。能换大一号的吗？ | Dài le. Néng huàn dà yī hào de ma? | Да. Можно поменять на размер больше? |
| 可以，大一号是这件。 | Kěyǐ, dà yī hào shì zhè jiàn. | Можно, больший размер вот этот. |
| 这件颜色一样，好看。我换这个。 | Zhè jiàn yánsè yīyàng, hǎokàn. Wǒ huàn zhège. | Один цвет, красивый. Я беру этот. |
| 好的，不用加钱。 | Hǎode, búyòng jiā qián. | Хорошо, доплачивать не нужно. |
| 谢谢你！ | Xièxie nǐ! | Спасибо! |

### Разбор

- **换 (huàn)** — обменивать; **换大一号** — поменять на размер больше (号 = размер).
- **穿着不舒服** — «носится неудобно»: V + 着 + оценка (см. 着 в index).
- **带 (dài)** — приносить с собой; **加钱 (jiā qián)** — доплачивать.
- Вежливый отказ от доплаты — обязательная реплика продавца в Китае.

## 对话 5: 买鞋 (Покупка обуви)

*Ситуация: покупатель меряет кроссовки, решает вопрос с размером и ценой.*

| 中文 | 拼音 | 翻译 |
|------|------|------|
| 我想买一双运动鞋。 | Wǒ xiǎng mǎi yī shuāng yùndòngxié. | Я хочу купить пару кроссовок. |
| 您穿多大号？ | Nín chuān duō dà hào? | Какой размер вы носите? |
| 四十三号。 | Sìshísān hào. | Сорок третий. |
| 试试这双白色的吧。 | Shì shi zhè shuāng báisè de ba. | Примерьте эту белую пару. |
| 太紧了，有大一点的吗？ | Tài jǐn le, yǒu dà yīdiǎn de ma? | Тесновато, есть чуть больше? |
| 有，试试这双四十四的。 | Yǒu, shì shi zhè shuāng sìshísì de. | Есть, примерьте сорок четвёртый. |
| 这双刚好合适，多少钱？ | Zhè shuāng gānghǎo héshì, duōshao qián? | Эта как раз подходит, сколько стоит? |
| 原价三百九十九，现在八折。 | Yuánjià sānbǎi jiǔshíjiǔ, xiànzài bā zhé. | Стоила 399, сейчас скидка 20%. |
| 八折是多少钱？ | Bā zhé shì duōshao qián? | Сколько это по 20% скидке? |
| 三百一十九块二。 | Sānbǎi shíjiǔ kuài èr. | 319,2 юаня. |
| 好，我买了，能支付宝吗？ | Hǎo, wǒ mǎi le, néng Zhīfùbǎo ma? | Хорошо, беру. Можно через Alipay? |
| 可以，我来扫码。 | Kěyǐ, wǒ lái sǎomǎ. | Можно, я отсканирую код. |

### Разбор

- **双 (shuāng)** — счётное слово для пар: 一双鞋, 一双袜子.
- **号 (hào)** — размер обуви: 四十三号 (43-й).
- **刚好 (gānghǎo)** — как раз, точно впору.
- **八折** — скидка 20% (платите 80%): 399 × 0,8 = 319,2. `原价 - 折 × 0,1`.
