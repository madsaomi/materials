# Unit 06 — Грамматика: Телефон, планы и договорённости

**Фокус юнита:** 正在/在, 将/会, 时间补语, 要/打算

---

## 1. 正在/在 + V —持续体 (действие происходит сейчас)

Конструкция обозначает, что действие происходит **в момент речи** (аналог русского «-ю/-ешь»).

### Структура

```
主语 + 正在 + 动词 (+ 宾语)
主语 + 在 + 动词 (+ 宾语)
主语 + 在 + 动词 + 呢
```

| Форма | Оттенок | Пример |
|-------|---------|--------|
| 正在 | нейтральный, книжный | 他正在看书。 — Он сейчас читает книгу。 |
| 在 | разговорный | 我在吃饭。 — Я сейчас ем。 |
| 在 + V + 呢 | подчёркивает «именно сейчас» | 你干什么呢？ — Что ты делаешь? |

### Примеры

```
妈妈正在做饭。           — Мама сейчас готовит.
弟弟在睡觉。             — Младший брат сейчас спит。
老师在上课呢。           — Учитель сейчас ведёт урок。
我们在开会，等一下。     — Мы сейчас на совещании, подождите.
他正在打电话。           — Он сейчас разговаривает по телефону.
```

### Вопрос: 正在…吗?

```
你在学习吗？             — Ты сейчас учишься?
她正在洗澡吗？           — Она сейчас моется?
```

### Отрицание: 没有 (не 正在)

```
他没有在看电视。         — Он сейчас не смотрит телевизор.
我没有在打电话。         — Я сейчас не разговариваю по телефону.
```

> **Важно:** 正在 используется **только** для действия в настоящем моменте. Для привычных действий используйте 常常, 每天 и т.д.

## 2. 将/会 — Будущее время (будущее действие)

### 2.1. 将 — книжное будущее

将 — формальный маркер будущего времени (в основном в письменной речи и новостях).

```
会议将在下午三点开始。
  — Совещание начнётся下午三点 (в 15:00).

他明天将到北京。
  — Он завтра приедет в Пекин。
```

### 2.2. 会 — прогноз/намерение

会 выражает **предположение о будущем** или **намерение**:

```
明天会下雨。             — Завтра будет дождь.
我会给你打电话。         — Я тебе позвоню.
他不会来了。             — Он уже не придёт.
你会做饭吗？             — Ты умеешь готовить? (= будешь ли готовить)
```

### Таблица: 将 vs 会

| Маркер | Стиль | Значение | Пример |
|--------|-------|----------|--------|
| 将 | книжный, формальный | определённое будущее | 比赛将在明天举行。 |
| 会 | нейтральный | прогноз / обещание | 明天会冷。 |
| 要 | разговорный | намерение / необходимость | 我明天要去上海。 |

### Отрицание

```
他不会来。               — Он не придёт.
将不 — ❌ (не используется, используйте 不会)
```

## 3. 时间补语 — Временное дополнение (V + 了 + время)

Конструкция показывает **длительность действия** или **когда оно произошло**.

### 3.1. Длительность: V + 了 + 时间 + 的 (иногда 的 опускается)

```
我学了三个小时的汉语。   — Я учил китайский три часа.
他等了一个小时。         — Он ждал один час.
我们玩了两个小时。       — Мы играли два часа.
她看了半天的书。         — Она читала книгу полдня.
```

### 3.2. Точка во времени: 时间 + V + 了

```
我昨天去了超市。         — Я вчера ходил в магазин.
他三点到了北京。         — Он приехал в Пекин в три часа.
```

### 3.3. V + 了 + 数量 + V (повтор действия)

```
我看了三次医生。         — Я три раза ходил к врачу.
他来了两次。             — Он приходил два раза.
```

### Вопрос

```
你学了多久汉语？         — Как долго ты учишь китайский?
你等了多长时间？         — Как долго ты ждал?
```

## 4. 要/打算 — Намерение (собираюсь, намерен)

### 4.1. 要 — «собираюсь / хочу»

```
我要去中国旅行。         — Я собираюсь поехать в Китай.
我要买一个新手机。       — Я хочу купить новый телефон.
我要学做饭。             — Я хочу научиться готовить.
```

Отрицание: **不想** (не хочу) / **不要** (не буду, отказ):

```
我不想吃辣的。           — Я не хочу есть острое.
不要在这里抽烟！         — Не курите здесь!
```

### 4.2. 打算 — «намерен, планирую»

打算 более **официальное** и подразумевает **обдуманный план**:

```
我打算明年去日本。       — Я планирую в следующем году поехать в Японию。
我们打算周末去看电影。   — Мы планируем в выходные пойти в кино。
他没打算告诉妈妈。       — Он не планировал рассказывать маме。
```

### Таблица: 要 vs 打算

| Слово | Оттенок | Пример |
|-------|---------|--------|
| 要 | желание, непосредственное намерение | 我要喝水。 |
| 打算 | обдуманный план, расчёт | 我打算下个月搬家。 |
| 想 | мягче, «хочу» | 我想去旅游。 |

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 我正在每天学习汉语。 | 我每天学习汉语。 | 正在 = только в момент речи, не для привычек |
| 我要正在做饭。 | 我正在做饭。 | 要 и 正在 не сочетаются |
| 他将不会来。 | 他不会来。 | 将 не используется с 不 |
| 我学了三小时了汉语。 | 我学了三小时汉语。 | Дополнение ставится после 时间, но 替换 = 我学汉语学了三小时 |
| 我打算想买书。 | 我打算买书。 / 我想买书。 | 打算 и 想 не используются вместе |
| 我要了去中国。 | 我要去中国。 | 要 для будущего не требует 了 |

## 7. 一下 — Смягчение и краткое действие

Частица **一下** (yīxià) после глагола смягчает просьбу и значит «немного, чуть-чуть», «на минутку». Очень важна в телефонных и вежливых разговорах.

### Структура

```
V + 一下
```

### Примеры

```
等一下。                 — Подожди минутку.
请再说一下。             — Пожалуйста, повтори.
我看一下号码。           — Я посмотрю номер.
我们商量一下。           — Давайте посовещаемся.
你确认一下时间。         — Ты подтверди время.
他查了一下电话簿。       — Он заглянул в телефонную книгу.
```

> **Важно:** 一下 после глагола одинаково подходит и для просьб (请...一下), и для прошедшего времени (V了+一下).

## 8. 给 — направление действия (звонить кому-то)

Предлог **给** (gěi) ставит адресата перед глаголом: «кому-л.».

### Структура

```
S + 给 + 人 + V
```

### Примеры

```
我给你打电话。           — Я тебе звоню.
请给王先生留言。         — Пожалуйста, оставьте сообщение господину Вану.
妈妈给爸爸发短信。       — Мама отправила папе смс.
他给我回电话了。         — Он мне перезвонил.
```

### Таблица: 给 vs 跟

| Предлог | Значение | Пример |
|---------|----------|--------|
| 给 | кому-л. (адресат действия) | 我给你打电话。 |
| 跟 | с кем-л. (вместе, общение) | 我跟他商量。 |
| 向 | по направлению, к | 我向他道歉。 |

## 9. 能/可以 — возможность в телефонном контексте

Для «мочь/можно» в звонках и планировании:

| Слово | Оттенок | Пример |
|-------|---------|--------|
| 能 | мочь (физическая/внешняя возможность) | 你能明天来吗？ |
| 可以 | можно, разрешено / подходит | 可以，我们八点见。 |
| 可能 | возможно (вероятность) | 他可能没听到电话。 |

```
你能打过来吗？           — Ты можешь перезвонить?
可以的，没问题。         — Можно, без проблем.
我现在不能接电话。       — Я сейчас не могу ответить на звонок.
```

## 10. 刚/刚刚 — только что

Маркер **刚** (gāng) / **刚刚** (gānggāng) обозначает недавно произошедшее действие (только что).

```
他刚给我打过电话。       — Он только что мне позвонил.
我刚刚发了一条短信。     — Я только что отправил смс.
他刚到北京。             — Он только что приехал в Пекин.
```

### 刚 vs 刚才

| Слово | Употребление | Пример |
|-------|--------------|--------|
| 刚 | ставится перед глаголом, без 了 обычно | 我刚吃完饭。 |
| 刚才 | наречие времени, в начале/перед глаголом | 刚才他打电话了。 |

## 11. Телефонные вежливые формулы (готовые фразы)

Разговорные формулы, которые почти всегда используются целиком.

| Фраза | Пиньинь | Перевод |
|-------|---------|---------|
| 喂，你好！ | wèi, nǐ hǎo! | Алло, здравствуйте! |
| 请问您是哪位？ | qǐngwèn nín shì nǎ wèi? | Простите, кто это? |
| 我就是。 | wǒ jiùshì | Это я. |
| 请稍等。 | qǐng shāo děng | Подождите, пожалуйста. |
| 他在吗？ | tā zài ma? | Он на месте? |
| 他不在。 | tā bú zài | Его нет. |
| 请您过一会儿再打来。 | qǐng nín guò yīhuìr zài dǎlái | Позвоните чуть позже. |
| 我可以留个话吗？ | wǒ kěyǐ liú ge huà ma? | Могу я оставить сообщение? |
| 对不起，我打错了。 | duìbuqǐ, wǒ dǎcuò le | Извините, я ошибся номером. |

> **Культурно:** при звонке на дом/в офис уместно спросить «请问您是哪位?». Не спрашивают прямо «Кто это?» — это считается грубым.

## 12. 得 de (дополнение степени) в контексте планов

Для описания, «насколько долго/хорошо» прошло действие (встреча, разговор):

```
我们聊得很开心。         — Мы поговорили очень весело.
他来得挺准时。           — Он пришёл довольно вовремя.
我们玩得真高兴。         — Мы провели время по-настоящему радостно.
```

### Структура

```
V + 得 + 评价(прилагательное)
```

---

## 13. 就 и 才 — логические связки времени

Маркеры связи событий для планирования.

| Слово | Значение | Пример |
|-------|----------|--------|
| 就 | рано/скоро (меньше ожидаемого) | 我八点就到了。 — Я пришёл уже в восемь. |
| 才 | поздно/только тогда (больше ожидаемого) | 他十点才到。 — Он пришёл только в десять. |
| 才 | только что, лишь | 我刚刚才看到你的短信。 |
