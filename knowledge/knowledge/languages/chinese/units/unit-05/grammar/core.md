# Unit 5 — 语法 (Грамматика)

## 1. Сравнение с 比 (углубление)

Базовая структура: `A 比 B + прилагательное` — "A более…, чем B".

```
今天比昨天冷。         — Сегодня холоднее, чем вчера。
他比我高。             — Он выше меня。
夏天比冬天热。         — Летом жарче, чем зимой。
```

Можно добавить степень различия:

| Структура | Значение | Пример |
|-----------|----------|--------|
| A 比 B + 形容词 + 一点儿 | немного | 今天比昨天冷一点儿。 |
| A 比 B + 形容词 + 很多 | намного | 他比我高很多。 |
| A 比 B + 形容词 + 多了 | гораздо | 北京的冬天比上海冷多了。 |

Отрицание — структура `A 没有 B + 形容词` ("A не так…, как B"):

```
他跑得没有我快。       — Он бегает не так быстро, как я。
冬天没有夏天热。       — Зимой не так жарко, как летом。
```

Сравнение равенства: `A 跟/和 B 一样` — "A такой же, как B":

```
我的爱好和他的爱好一样。   — Мои увлечения такие же, как у него。
```

## 2. 越来越 (всё более…)

Показывает нарастание признака。 Структура: `越来越 + прилагательное/глагол`。

```
天气越来越冷了。       — Погода становится всё холоднее。
他的汉语越来越好。     — Его китайский всё лучше и лучше。
喜欢运动的人越来越多。 — Любителей спорта становится всё больше。
```

## 3. 如果…就… (если…, то…)

Условное предложение: `如果 + условие, 就 + результат`。 就 стоит перед глаголом в главной части。

```
如果明天天气好，我们就去公园。   — Если завтра будет хорошая погода, мы пойдём в парк。
如果下雨，我们就不去了。         — Если пойдёт дождь, мы не пойдём。
如果你有空，就来我家玩。         — Если у тебя будет время, приходи ко мне играть。
```

Можно опустить 如果, если контекст понятен:

```
明天天气好，我们就去公园。 — Если завтра будет хорошая погода, пойдём в парк。
```

## 4. 除了…以外 (кроме…)

Два значения:

1. "Все, кроме…" — с 都:

```
除了我以外，大家都来了。   — Пришли все, кроме меня。
```

2. "Кроме…, ещё и…" — с 还/也:

```
除了中文以外，他还学英语。   — Кроме китайского, он ещё учит английский。
除了跑步以外，我也喜欢游泳。 — Кроме бега, я также люблю плавать。
```

## 5. 喜欢做 / 爱做 (любить делать)

喜欢 — нравится, любить (слабее)。 爱 — любить (сильнее, ближе к "обожать")。

```
我喜欢看书。           — Мне нравится читать。
他爱跑步。             — Он обожает бегать。
我不喜欢下雨天。       — Я не люблю дождливые дни。
```

Отрицание: 不喜欢 / 不爱。 С 爱 к человеку: 我爱我的家人。 — Я люблю свою семью。

喜欢 можно использовать с глаголом + 的: 喜欢 + Глагол + 的, например:

```
我喜欢游泳的感觉。 — Мне нравится ощущение плавания。
```

## 6. 可能 (возможно)

Наречие вероятности, ставится перед глаголом или прилагательным。

```
明天可能下雨。         — Завтра, возможно, будет дождь。
他可能不来。           — Он, возможно, не придёт。
天气预报说可能下雪。   — Прогноз погоды говорит, что, возможно, пойдёт снег。
```

Отрицание: 不可能 — "невозможно, скорее всего не":

```
他不可能来。 — Он, скорее всего, не придёт。
明天不可能下雪。 — Завтра не возможно снег。
```

## 7. 应该 (следует, должен)

Выражает долженствование, рекомендацию。 Отрицание: 不应该。

```
你应该多穿衣服。           — Тебе следует одеваться теплее。
我们应该多运动。           — Мы должны больше заниматься спортом。
天气不好，你不应该出去。   — Погода плохая, тебе не следует выходить。
```

Также можно использовать 应该 + глагол + 吧 для смягчения:

```
你应该去休息一下。 — Тебе следует немного отдохнуть。
你应该多喝水。 — Тебе следует больше пить воды。
```

## 8. 又…又… (и…, и…; одновременно обладает двумя признаками)

Указывает, что предмет или действие обладает двумя признаками одновременно。 Структура: `A 又 B 又 C`。

```
今天又热又潮湿。       — Сегодня и жарко, и влажно。
他又高又瘦。           — Он и высокий, и худой。
她又会唱歌又会跳舞。   — Она и поёт, и танцует。
这部电影又长又无聊。   — Этот фильм и длинный, и скучный。
```

Часто используется для описания погоды, людей и предметов。

## 9. 虽然…但是… (хотя…, но…)

Выражает противопоставление。 Структура: `虽然 + предложение, 但是 + предложение`。

```
虽然他很忙，但是他还是来了。 — Хотя он очень занят, но всё равно пришёл。
虽然今天天气不好，但是我们还是出去了。 — Хотя сегодня погода плохая, но мы всё равно вышли。
她虽然年纪小，但是很懂事。 — Она хотя и молода, но очень сообразительная。
```

Можно опустить 但是, если контраст очевиден из контекста:

```
虽然他很忙，(但是)他没有休息。 — Хотя он очень занят, он не отдыхает。
```

## 10. 因为…所以… (потому что…, поэтому…)

Выражает причину и следствие。 Структура: `因为 + причина, 所以 + следствие`。

```
因为今天很冷，所以我穿了羽绒服。 — Потому что сегодня очень холодно, я надел пуховик。
因为下雨，所以我们取消了野餐。 — Потому что пошёл дождь, мы отменили пикник。
他因为生病，所以没有来上课。 — Он не пришёл на занятие, потому что заболел。
```

Можно опустить 所以, если следствие очевидно:

```
因为下雨，我们不出去了。 — Пойдёт дождь, поэтому мы не выходим。
```

Важно: 因为 и 所以 НЕ могут стоять в одном предложении с обеих сторон от запятой одновременно в одном кличе, если предложение разделено на два.

## 11. 一…就… (как только…)

Указывает, что одно действие сразу же следует за другим。 Структура: `一 + A + 就 + B`。

```
一下雨，我们就待在家里。 — Как только идёт дождь, мы остаёмся дома。
一看到好朋友，他就笑了。 — Как только увидел хорошего друга, он улыбнулся。
我一回家就写作业。 — Как только прихожу домой, сразу делаю домашнее задание。
一听到这个消息，她就很高兴。 — Как только услышала эту новость, она очень обрадовалась。
```

## 12. 不…不… (не…, не…; отрицание двух признаков)

Указывает, что предмет или действие не обладает ни одним из двух признаков。 Структура: `不 A 不 B`。

```
这个天气不冷也不热。 — Эта погода ни холодная, ни жаркая。
他不高不矮。 — Он не высокий и не низкий (среднего роста)。
这部电影不长也不短。 — Этот фильм ни длинный, ни короткий。
她不漂亮也不丑。 — Она ни красивая, ни уродливая。
```

Часто используется при описании погоды, людей и предметов。

## 13. 只有…才… (только…, тогда/когда…)

Выражает необходимое условие。 Структура: `只有 + условие, 才 + результат`。

```
只有努力学习，才能取得好成绩。 — Только усердно учиться, тогда можно получить хорошие оценки。
只有下雨，我才不出门。 — Только когда идёт дождь, я не выхожу。
只有你来了，我们才开始。 — Только когда ты придёшь, мы начнём。
```

## 14. 不管…都… (как бы ни…, в любом случае…)

Выражает безусловность。 Структура: `不管 + условие, 都 + результат`。

```
不管天气好不好，我都要去跑步。 — Какой бы ни была погода, я обязательно пойду бегать。
不管你怎么说，我都不会改变主意。 — Как бы ты ни говорил, я не изменю своего решения。
不管多远，他都坚持每天跑步。 — Как бы далеко ни было, он каждый день бегает。
```

## 15. 不是…而是… (не…, а…; уточнение)

Указывает на корректировку, уточнение первого утверждения。 Структура: `不是 A，而是 B`。

```
我不是不想去，而是没有时间。 — Я не хочу не идти, а у меня нет времени。 (На самом деле я не могу пойти, а не не хочу。)
他不是学生，而是老师。 — Он не студент, а учитель。
这件衣服不是红色的，而是蓝色的。 — Эта одежда не красная, а синяя。
```
