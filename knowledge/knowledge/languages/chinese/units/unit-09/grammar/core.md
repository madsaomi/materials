# Unit 09 — Грамматика: Покупки и сравнения

**Фокус юнита:** 比/更/最, 越来越, 一点/一些

---

## 1. 比 — Сравнение (A более…, чем B)

### Структура

```
A 比 B + прилагательное
```

### Базовые примеры

```
今天比昨天冷。         — Сегодня холоднее, чем вчера.
他比我高。             — Он выше меня.
这个苹果比那个大。     — Это яблоко больше, чем то.
她的头发比我的长。     — Её волосы длиннее, чем мои.
上海比北京热。         — В Шанхае жарче, чем в Пекине.
```

### Степень различия

| Структура | Значение | Пример |
|-----------|----------|--------|
| A 比 B + Adj + 一点儿 | немного | 今天比昨天冷一点儿。 — Сегодня чуть холоднее. |
| A 比 B + Adj + 一些 | несколько | 这件比那件贵一些。 — Это несколько дороже того. |
| A 比 B + Adj + 很多 | намного | 他比我高很多。 — Он намного выше меня. |
| A 比 B + Adj + 多了 | гораздо | 北京比上海冷多了。 — В Пекине гораздо холоднее. |
| A 比 B + Adj + 得多 | значительно | 她比我大得多。 — Она значительно старше меня. |

### Отрицание: 没有 (не 比!)

```
他没有我高。           — Он не такой высокий, как я. (букв. «он не имеет (роста) меня»)
北京没有上海热。       — В Пекине не так жарко, как в Шанхае.
这个没有那个好。       — Это не такое хорошее, как то.
```

> **Важно:** В отрицании используется **没有**, а НЕ **比**! 「他不比我高」 — допустимо, но意味着 «он не выше меня» (=мы примерно одного роста), а 没有 = «он ниже».

### Сравнение равенства

```
A 跟/和 B 一样 + Adj
A 跟/和 B 差不多

我和你一样高。         — Я такого же роста, как ты.
这个跟那个差不多。     — Это примерно такое же, как то.
她和我一样大。         — Мы одного возраста.
```

## 2. 更 и 最 — Степени сравнения

### 2.1. 更 (gèng) — «ещё более / больше»

Сравнивает **два объекта**, но подчёркивает, что один **уже** обладает признаком:

```
他很高，他哥哥更高。   — Он высокий, а его брат ещё выше.
这个贵，那个更贵。     — Это дорого, а то ещё дороже.
我喜欢咖啡，但我更喜欢茶。 — Я люблю кофе, но ещё больше люблю чай.
```

### 2.2. 最 (zuì) — «самый»

Абсолютная степень, выделяет **один** из группы:

```
他是最高的。           — Он самый высокий.
这是最好的办法。       — Это лучший способ.
我最喜欢吃中国菜。     — Больше всего мне нравится китайская еда.
今天是最冷的一天。     — Сегодня самый холодный день.
```

### Таблица: 比 vs 更 vs 最

| Маркер | Структура | Значение | Пример |
|--------|-----------|----------|--------|
| 比 | A 比 B + Adj | A более…, чем B | 他比我高。 |
| 更 | A 更 + Adj | ещё более… | 他更高。 |
| 最 | 最 + Adj | самый… | 他最高。 |

## 3. 越来越 — «всё более / становится всё…»

Показывает **нарастание** признака со временем.

### Структура

```
越来越 + прилагательное / глагол
```

### Примеры

```
天气越来越冷了。       — Погода становится всё холоднее.
他的汉语越来越好。     — Его китайский всё лучше и лучше.
人越来越多。           — Людей становится всё больше。
她越来越漂亮了。       — Она становится всё красивее。
我越来越喜欢他了。     — Я всё больше и больше его люблю。
```

### 越…越… — «чем…, тем…»

```
天气越冷，人越多穿衣服。 — Чем холоднее, тем больше people одеваются.
你越说我越糊涂。       — Чем больше ты говоришь, тем больше я запутываюсь.
他越学越有兴趣。       — Чем больше учится, тем интереснее становится.
```

### Таблица: 越来越 vs 越…越…

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| 越来越 + Adj | нарастание со временем | 天气越来越热。 |
| 越 A 越 B | «чем A, тем B» | 你越跑越快。 |

## 4. 一点/一些 — Количественные модификаторы

### 4.1. 一点 (yì diǎn) — «немного / чуть-чуть»

```
请给我一点儿水。       — Дайте мне немного воды.
便宜一点儿可以吗？     — Можно немного дешевле?
这件大了一点。         — Это на размер больше.
他高了我一点儿。       — Он чуть выше меня. (口语)
```

### 4.2. 一些 (yì xiē) — «несколько / немного»

一些 используется с **исчисляемыми** существительными (более формально):

```
我想买一些水果。       — Я хочу купить немного фруктов.
我有一些问题。         — У меня есть несколько вопросов.
她给了我们一些建议。   — Она дала нам несколько советов.
今天有一些冷。         — Сегодня немного холодно.
```

### Таблица: 一点 vs 一些

| Модификатор | Значение | Пример |
|-------------|----------|--------|
| 一点 | немного (абстрактно / неисчисляемое) | 冷一点儿, 便宜一点 |
| 一点 + N | чуть-чуть чего-то | 一点儿水, 一点儿时间 |
| 一些 + N | несколько штук | 一些苹果, 一些问题 |
| 一些 + Adj | несколько / somewhat | 一些冷, 一些贵 |

### Сравнение с 很

| Модификатор | Степень | Пример |
|-------------|---------|--------|
| 有一点儿 | слабо, еле-еле | 有一点儿冷 — чуть холодно |
| 一点儿 | немного (после Adj) | 冷一点儿 — холоднее на порядок |
| 一些 | несколько | 一些冷 — somewhat холодно |
| 很 | сильно | 很冷 — очень холодно |
| 太 | чрезмерно | 太冷 — слишком холодно |

## 5. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|--------|-----------|-----------|
| 今天比昨天不太冷。 | 今天没有昨天冷。 | В отрицании с 比 используйте 没有 |
| 他比我很高。 | 他比我高很多。 | 很 нельзя ставить между 比 и Adj |
| 他更高比我。 | 他比我更高。 | 比 ставится после подлежащего, до Adj |
| 我最喜欢中国菜，但是比日本菜。 | 我最喜欢中国菜，日本菜也喜欢。 | 最 не используется с 比 |
| 今天比昨天更冷。 | ✅ (верно) | 更 можно использовать для «ещё более» |
| 我想买一一点苹果。 | 我想买一点苹果。 / 我想买一些苹果。 | 一点 + N (без 一) или 一些 |
| 越来越很热。 | 越来越热。 | 很 не используется после 越来越 |

## 7. 极了 — «чрезвычайно / очень-очень»

### Структура

```
Прилагательное + 极了
```

### Примеры

```
便宜极了。               — Очень дёшево.
这家店的东西好极了。     — В этом магазине вещи просто отличные.
这个西瓜甜极了。         — Этот арбуз очень сладкий.
他高兴极了。             — Он очень обрадовался.
衣服合适极了。           — Одежда сидит идеально.
```

> 极了 стоит **после** прилагательного и **не сочетается** с 很/非常/特别. В конце предложения не нужно ставить ещё одно 了: правильнее «便宜极了», а не «便宜极了了».

### Таблица: градация интенсивности

| Маркер | Степень | Пример |
|--------|---------|--------|
| 很便宜 | нейтрально «очень» | 这个很便宜。 |
| 非常便宜 | сильно | 这个非常便宜。 |
| 特别便宜 | особенно | 今天特别便宜。 |
| 太便宜了 | чрезмерно / с восклицанием | 太便宜了！ |
| 便宜极了 | предельно | 便宜极了！ |

## 8. 比 + дополнение количества

Сравнение может включать **конкретную разницу** (число, сумма, возраст).

### Структура

```
A 比 B + Adj + (了) + 数量
```

### Примеры

```
这件衣服比那件贵五十块。       — Эта одежда дороже той на 50 юаней.
他比我大两岁。                 — Он старше меня на два года.
今天比昨天冷了三度。           — Сегодня на 3 градуса холоднее, чем вчера.
这家店比那家便宜一百多块。     — Этот магазин дешевле того более чем на 100 юаней.
我的手机比他的新一年。         — Мой телефон новее его на год.
```

> 了 в «贵了五十块» подчёркивает завершённый факт/результат. С абстрактной характеристикой конкретной цифры нет — 了 не ставится: 这件比那件贵。

### Таблица: степени различия

| Схема | Значение |
|-------|----------|
| A 比 B + Adj | простое сравнение |
| A 比 B + Adj + 一点儿/一些 | небольшая разница |
| A 比 B + Adj + 很多/多了/得多 | большая разница |
| A 比 B + Adj + (了) + 具体数量 | точная разница |

## 9. 除了…以外，还/也/都 — «кроме…»

### Структура

```
除了 + A 以外，还/也 + B     — «кроме A ещё и B» (добавка)
除了 + A 以外，都 + B        — «кроме A, все остальные B» (исключение)
```

### Примеры

```
除了苹果以外，我还买了香蕉。     — Кроме яблок, я ещё купил бананы.
除了价格以外，我也看重质量。     — Помимо цены, мне важно и качество.
除了这家店以外，别的店都关门了。 — Кроме этого магазина, все остальные закрыты.
除了信用卡以外，我还带了现金。   — Помимо карты, я взял ещё наличные.
除了打折的东西，别的我都不买。   — Кроме товаров со скидкой, я ничего не покупаю.
```

> 还/也 = «в добавок, тоже»; 都 = «все (остальные)». 以外 в разговорной речи можно опустить: 除了苹果，我还买了香蕉。— звучит естественнее.

## 10. 如果…就… — «если…, то…»

### Структура

```
如果 + условие + 就 + результат
```

### Примеры

```
如果买两件，就打八折。            — Если купите две вещи, будет скидка 20%.
如果便宜一点的话，我就买。        — Если будет немного дешевле, я куплю.
如果质量好，贵一点也没关系。      — Если качество хорошее, можно и дороже.
如果明天能收到货，我就下单。      — Если завтра привезёшь, я сделаю заказ.
如果没有什么问题，请您签字。      — Если вопросов нет, распишитесь.
```

> 就 стоит **перед** глаголом результата. 的话 («если») может дополнять 如果 или заменять его: 便宜一点的话… / 你愿意的话…
> В разговорной речи 如果 часто опускают, если условие понятно из контекста: 下雨的话就不去了。

## 11. 先…然后/再… — последовательность действий

### Структура

```
先 + действие 1 + 然后/再 + действие 2
```

### Примеры

```
先看看价格，然后再决定。           — Сначала посмотри цену, потом реши.
先付款，然后再取货。               — Сначала оплатите, потом получите товар.
早上先去了超市，下午再去了商场。   — Утром сначала сходил в супермаркет, днём — в торговый центр.
我想先试试这件衣服，然后再买。     — Я сначала примерю, потом куплю.
他先去银行取钱，然后去商场买东西。 — Он сначала пошёл в банк за деньгами, потом за покупками.
```

> 先…再… предполагает план/будущее («второе действие ещё не сделано»), а 然后 просто связывает уже произошедшие или происходящие действия.

## 12. 虽然…但是… — «хотя…, но…»

### Структура

```
虽然 + A + 但是 + B    (B противоречит A)
```

### Примеры

```
虽然贵，但是质量很好。           — Хотя дорого, но качество отличное.
虽然打折，但是我还是不买。       — Хотя и скидка, я всё равно не куплю.
虽然这件衣服很好看，但是太大了。 — Хотя эта вещь красивая, но слишком большая.
虽然付现金便宜一点，但是我用卡。 — Хотя наличными дешевле, я заплачу картой.
虽然不太高兴，但是我还是买了。   — Хотя я был недоволен, всё же купил.
```

> В письменной речи 虽然…但是… — пара; в разговорной 虽然 можно опустить, оставив 但是 (ещё сильнее — конструкция 贵是贵，但是好看).
> Формальный вариант — 尽管…但….

## 13. Повторение глагола (动词重叠) — смягчение просьбы

### Структура

```
VV       — 看看, 试试, 想想 (односложный)
V一V     — 看一看, 试一试
ABAB     — 研究研究 (двусложный)
V一下    — 看一下, 等一下
```

### Примеры

```
我可以看看这件吗？             — Можно посмотреть это?
你试一试这件合不合适。         — Примерь, подойдёт ли.
我们先想想再决定。             — Сначала подумаем, потом решим.
请你等一下，我去拿货。         — Подождите, пожалуйста, я принесу.
奶奶让我在网上找一找便宜点的。 — Бабушка просит поискать в интернете подешевле.
```

> Повторение глагола смягчает просьбу, делает её вежливой и короткой по времени. 一下 — более нейтральный эквивалент.

### Таблица: формы повторения

| Форма | Пример | Оттенок |
|-------|--------|---------|
| VV | 看看 | дружелюбно, кратко |
| V一V | 看一看 | чуть более развёрнуто |
| V一下 | 看一下 | вежливо, нейтрально |
| VV看 | 试试看 | «попробовать на опыте» |

---

## 14. 又…又… — «и…, и…»

### Структура

```
又 + Adj/глагол + 又 + Adj/глагол
```

### Примеры

```
这个包又漂亮又便宜。             — Эта сумка и красивая, и дешёвая.
这件衣服又舒服又耐穿。           — Эта одежда и удобная, и ноская.
这家店的菜又好吃又便宜。         — В этом заведении еда и вкусная, и недорогая.
买东西又花时间又花力气。         — Ходить по магазинам требует и времени, и сил.
这个西瓜又大又甜。               — Этот арбуз и большой, и сладкий.
```

> 又…又… подчёркивает **одновременность** двух качеств/действий. Используется с прилагательными и глаголами, но **не** с существительными.
> Сравните позитив 又便宜又好 и негатив 又贵又不好.

## 15. Типичные ошибки (часть 2)

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| 便宜极了了。 | 便宜极了。 | 极了 уже передаёт завершённость, ещё одно 了 не нужно |
| 我很便宜极了。 | 便宜极了。 | 很/非常 не сочетаются с 极了 |
| 这件比那件贵了。 | 这件比那件贵。 / 这件比那件贵五十块。 | 了 без конкретной разницы звучит странно |
| 除了苹果以外，我都买香蕉。 | 除了苹果以外，我还买香蕉。 | 都 = «все остальные», а тут добавка элемента → 还 |
| 虽然贵，但我还是买。 | 虽然贵，但是我还是买。 | 但是 обязательно при 虽然 (в устной речи допустимо 但) |
| 这个包又贵又便宜。 | 这个包又便宜又好。 | 又…又… должно быть логически совместимо |
