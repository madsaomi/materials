# Unit 1 — 对话: 你好！(Привет!)

## 对话

```
李明: 你好！你叫什么名字？
王芳: 你好！我叫王芳。你叫什么？
李明: 我叫李明。很高兴认识你！
王芳: 我也很高兴认识你！你是哪国人？
李明: 我是中国人。你呢？
王芳: 我是俄罗斯人。我学习汉语。
李明: 你学习汉语多长时间了？
王芳: 我学了半年了。还不太流利。
李明: 你说得很好！你住在哪儿？
王芳: 我住在学校附近。你呢？
李明: 我住在市中心。
王芳: 你的电话号码是多少？
李明: 我的电话是 138-1234-5678。
王芳: 好，我记下来了。再见！
李明: 再见！
```

# Расширение Unit 1 — 对话 (Диалоги)

## 对话 2: 在教室里 (В классе)

```
老师: 大家早上好！今天我们来学习汉语。
学生: 老师好！
老师: 你们昨天学得怎么样？
安娜: 我们昨天学了很多生词，但是还不太会写汉字。
老师: 没关系，慢慢来。现在请打开书，读第三课。
李明: 好的，老师。我不认识这个字，怎么读？
老师: 这个字读"中"，中国的"中"。
安娜: 谢谢老师。我记住了。
老师: 很好！你们真的很认真。下课以后别忘了复习。
李明: 好的，我们一定复习。
```

## 对话 3: 在咖啡厅 (В кафе)

```
服务员: 你好！请问你想喝什么？
顾客:   我要一杯咖啡，谢谢。
服务员: 好。要加糖和牛奶吗？
顾客:   少加一点糖，不要牛奶。
服务员: 没问题。还要吃什么吗？
顾客:   你们这儿有蛋糕吗？
服务员: 有，有巧克力蛋糕和水果蛋糕。
顾客:   那来一块巧克力蛋糕吧。
服务员: 好的。一共是二十五块。
顾客:   给你钱。谢谢！
服务员: 不客气，请慢用！
```

## 对话 4: 打电话 (По телефону)

```
安娜: 喂，是李明吗？
李明: 是我。安娜，你好！
安娜: 你好！明天是星期天，你有空吗？
李明: 有空。你有什么计划？
安娜: 我想去商店买一件衣服，你能陪我去吗？
李明: 当然可以。我们几点见面？
安娜: 上午十点，在商店门口见，怎么样？
李明: 好的。我们在那儿见面。
安娜: 好，那明天见！
李明: 明天见，再见！
```

| 中文 | 翻译 |
|------|------|
| 喂 | алло |
| 是李明吗 | Это Ли Мин? |

| 星期天 | воскресенье |

| 有空 | есть время, свободен |
| 你有什么计划 | Какие у тебя планы? |
