# 🇬🇧 Survival English — Гайд выживания в англоязычных странах

> Практические фразы и сценарии для реальной жизни в США, Великобритании, Канаде и Австралии.
> Полезно как шпаргалка по «живому» английскому для неносителей.

## 🍜 Ресторан / Кафе

| Ситуация | Английский | Перевод |
|----------|-----------|---------|
| Стол | Table for one / two, please | Столик на одного / двоих |
| Меню | Can I see the menu? | Можно меню? |
| Заказ | I'll have this, please | Мне это, пожалуйста |
| Рекомендация | What do you recommend? | Что посоветуете? |
| Аллергия | I'm allergic to ○○ | У меня аллергия на ○○ |
| Без глютена | Do you have gluten-free options? | Есть безглютеновые блюда? |
| Веган | I'm vegan / vegetarian | Я веган / вегетарианец |
| Счёт | Can I get the check / bill, please? | Счёт, пожалуйста |
| Чаевые | Is gratuity included? | Чаевые включены? |
| На вынос | Can I get this to go? | Можно с собой? |

### 🔑 Полезно знать
- **США**: чаевые **15–20%** обязательны в ресторанах.
- **UK**: чаевые **10–12.5%** — по желанию (часто уже в счёте как "service charge").
- **"Check"** — счёт в США, **"Bill"** — в Великобритании.

|----------|-----------|---------|
| Плохо | I'm not feeling well | Мне плохо |
| Голова болит | I have a headache | Голова болит |
| Живот болит | I have a stomachache | Живот болит |

| Рецепт | Do I need a prescription for this? | Для этого нужен рецепт? |

### 🔑 Номера экстренных служб
- **911** — США, Канада (полиция / скорая / пожарные)
- **999** — Великобритания
- **112** — Единый номер ЕС (работает и в UK)
- **000** — Австралия

## 🚃 Транспорт

| Ситуация | Английский | Перевод |
|----------|-----------|---------|
| Маршрут | How do I get to ○○? | Как добраться до ○○? |
| Автобус | Which bus goes to ○○? | Какой автобус до ○○? |
| Билет | Where can I buy a ticket? | Где купить билет? |
| Такси | Could you take me to ○○? | Отвезите меня до ○○ |
| Остановка | Can you drop me off here? | Остановите здесь |
| Uber | I'll request an Uber / Lyft | Я вызову Uber / Lyft |
| Задержка | Is the train / flight delayed? | Поезд / рейс задерживается? |

### 🔑 Полезно знать
- **London:** Oyster Card или contactless-карта. Метро = **Tube / Underground**.
- **NYC:** MetroCard или tap-to-pay. Метро = **Subway**.
- **Uber / Lyft** работают повсюду. В UK популярен **Bolt**.

### 💡 Культурные различия: США vs UK

| Тема | 🇺🇸 США | 🇬🇧 Великобритания |
|------|--------|-------------------|
| Этаж | 1st floor = первый | 1st floor = второй (Ground floor = первый) |
| Чаевые | 15–20% обязательно | 10–12.5% по желанию |
| Счёт | Check | Bill |
| Метро | Subway | Tube / Underground |
| Чипсы | Chips = чипсы | Chips = картошка фри, Crisps = чипсы |
| Квартира | Apartment | Flat |
| Лифт | Elevator | Lift |
| Очередь | Line | Queue |
| Аптека | Pharmacy / Drugstore | Chemist / Pharmacy |
