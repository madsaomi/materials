# Английский · Урок 14 — Прежние привычки: used to / would · дополнительная версия

Этот урок организован вокруг задачи: **прежние привычки: used to / would**. Сначала разберите короткую модель, затем примените её в речи и проверьте себя. Подробная грамматика содержит и дополнительные темы: не обязательно проходить весь справочный объём за один подход.

## Чему вы научитесь

- Объяснять своими словами: Used to + инфинитив подходит для прежних привычек и состояний.
- Разбирать учебный пример по ролям участников и значению формы.
- Самостоятельно решать задачу: Выберите форму для прежнего состояния: I ___ know everyone in that street. (used to / would)
- Применять правило в двух новых фразах, а не только узнавать готовый ответ.

## Что нужно перед началом

Повторите модели предыдущего урока и выпишите одну оставшуюся трудность. Если вы пришли из поиска, используйте содержание уровня, чтобы найти пропущенные темы.

Метка папки — способ организации исходного курса; она не подтверждает полного покрытия экзаменационного или международного уровня.

## Короткое объяснение

Used to + инфинитив подходит для прежних привычек и состояний. Would может описывать повторяющиеся действия при понятном контексте прошлого; для состояния «жил раньше» в таком значении выбирайте used to.

**Пример с разбором.** I used to live near the sea. — Раньше я жил у моря. Every summer we would swim there. — Каждое лето мы там купались. Не путайте used to do с be used to doing — «привыкнуть к».
