# Unit 10 — Грамматика: Условия и опыт

## Учебное ядро: Условие たら, опыт и совет
## Та-форма в трёх конструкциях не всегда сообщает прошлое

駅に着いたら、電話してください。— «Когда приедете на станцию, позвоните». 早く予約したほうがいいです。— «Лучше забронировать заранее». 船に乗ったことがあります。— «Мне доводилось ездить на корабле». Во всех фразах есть た-форма, но первая относится к будущему условию, вторая даёт совет, третья сообщает опыт.

## Как образовать и понять たら

Прибавьте ら к простой прошедшей форме: 行った→行ったら, 食べた→食べたら, しなかった→しなかったら. У прилагательных: 安かったら / 安くなかったら; у существительных и な-прилагательных: 休みだったら, 静かだったら. いい→よかったら.

明日晴れたら、公園に行きます。— «Если завтра будет ясно, пойду в парк». Здесь たら не подтверждает, что погода уже прояснилась. 駅に着いたら、電話します — «Когда приеду на станцию, позвоню» — задаёт последовательность: сначала приезд, затем звонок. У たら есть и другие употребления, включая обнаружение в прошлом; не сводите всю форму к одному времени.

## Опыт и отдельное событие

京都に行ったことがあります — «Бывал в Киото». 昨日、京都に行きました — «Вчера ездил в Киото». В первом сообщении важно наличие опыта, во втором — конкретное событие. Отсутствие опыта: 一度も行ったことがありません — «Ни разу не бывал». Прошедшее ことがありました возможно при подходящей прошлой точке отсчёта; это не запрещённая форма, но для нынешнего опыта без особого контекста выбирайте あります.

## Совет и возможное развитие событий

Утвердительный практический совет обычно имеет вид Vたほうがいい: 早く出たほうがいい — «Лучше выйти пораньше». Отрицательный: Vないほうがいい — 遅くまで起きていないほうがいい «Лучше не бодрствовать допоздна». Это не приказ и не медицинское предписание; решайте, уместно ли советовать в данной ситуации.

遅れるかもしれません — «Возможно, опоздаю» — допускает возможность, а не задаёт математический процент. Нельзя переводить かもしれない обязательной цифрой «50%». Для предложенного варианта: 早く出たらどうですか — «Может, выйти пораньше?»; время здесь тоже не прошедшее.

## 1. Условие たら («если / когда»)

Образуется: та-форма глагола + ら

```
雨が降ったら、出かけません。   — Если пойдёт дождь, никуда не пойдём.
安くなったら、買います。       — Если подешевеет, куплю.
日本に行ったら、京都を見たい。  — Когда поеду в Японию, хочу в Киото.
```

> 💡 たら — самый универсальный условный оператор. Подходит и для «если», и для «когда (в будущем)».

Прилагательные:

- い-прил: 安かったら、買います。
- な-прил/сущ: 静かだったら、いいですね。

## 2. Совет с 〜たらどう / 〜たほうがいい

```
早く予約したほうがいいよ。    — Лучше забронировать заранее.
医者に行ったほうがいいです。  — Тебе лучше сходить к врачу.
```

Отрицание: 〜ないほうがいい (лучше не...):

```
夜ご飯を食べすぎないほうがいい。
```

## 3. Опыт: 〜たことがある

Та-форма + ことがある = «когда-либо делал»:

```
新幹線に乗ったことがありますか。 — Вы когда-нибудь ездили на синкансэне?
寿司を食べたことがない。         — Я никогда не ел суши.
一度富士山に登ったことがある。   — Один раз поднимался на Фудзи.
```

## 4. Может быть: かもしれない

Простая форма без непрошедшего だ у имени / な-прилагательного + かもしれない: «возможно». Форма не задаёт числовую вероятность:

```
富士山が見られるかもしれない。 — Возможно, будет видно Фудзи.
遅れるかもしれないから、先に行って。— Могу опоздать, так что идите вперёд.
```

Шкала вероятности:

| Слова | Уверенность |
|-------|-------------|
| 必ず | уверенное утверждение «обязательно»; не измерение вероятности |
| きっと | уверенное ожидание говорящего |
| だろう／でしょう | предположение; уверенность зависит от контекста |
| かもしれない | допускаемая возможность без заданного процента |

## 5. Похоже на: 〜みたいだ

Существительное + みたい: «похоже, как будто»:

```
ほとんど埋まってるみたい。 — Кажется, всё почти занято.
雨が降ってるみたいです。   — Похоже, идёт дождь.
```

## 6. Даже если: 〜でも

```
雨でも楽しめる。     — Даже в дождь можно весело провести время.
高くても買います。   — Куплю, даже если дорого.
```

## 7. Что взять: ば-условие для советов

Форма еба: 「何を持って行けばいい？」= что взять, чтобы было хорошо?

```
どうすればいいですか。      — Что мне делать?
どこで切符を買えばいい？     — Где купить билет?
```

## 8. Типичные ошибки

❌ 行くたら → ✅ 行ったら (та-форма!)
乗ったことがあります — основная форма для опыта, актуального сейчас. 乗ったことがありました не запрещена: она может относить опыт к прошлой точке отсчёта.
❌ 雨が降るでも → ✅ 雨**が降っ**ても (тэ-форма + も)

## 9. たら в советах и пожеланиях

### 〜たらどうですか（может, стоит...?）
Та-форма + どう:

```
医者に行ったらどうですか。
Может, сходить к врачу?
```

### 〜たらいい（что делать, чтобы вышло хорошо）
Вопрос с interrogative:

```
どこで切符を買ったらいいですか。
Где мне купить билет?
```

Ответ-совет:

```
駅の窓口で買えばいいですよ。
Купите в кассе станции.
```

> **Связка:** вопрос с たらいい → ответ с ばいい. Это устойчивая пара.

### もし＋たら（если вдруг）
もし подчёркивает гипотетичность:

```
もし宝くじが当たったら、世界一周したい。
Если вдруг выиграю в лотерею — вокруг света!
```

## 10. ば-условие: полная таблица образования

| Глагол | Словарная | ば-форма |
|--------|-----------|----------|
| 書く | かく | かけば |
| 読む | よむ | よめば |
| 話す | はなす | はなせば |
| 待つ | まつ | まてば |
| 食べる | たべる | たべれば |
| 見る | みる | みれば |
| する | する | すれば |
| 来る | くる | くれば |
| いい | — | よければ |

Прилагательные:

- い-прил: 安い → 安ければ
- な-прил: 静か → 静かなら（ば）

---

## 11. Четыре условия: итоговое сравнение

| Форма | Функция | Пример | Перевод |
|-------|---------|--------|---------|
| と | автоматизм, каждый раз | 春になると桜が咲く | Как весна — так сакура |
| ば | логическое следствие | 時間があれば行く | Если будет время — пойду |
| たら | конкретный случай | 家に帰ったら電話する | Как вернусь домой — позвоню |
| なら | реакция на тему | 京都なら新幹線だ | Насчёт Киото — синкансэн |

> **Шпаргалка:** советы → たら／ば；законы → と；беседа → なら. Для конкретного будущего условия удобно начинать с たら, проверяя последовательность и смысл. Это не универсальная замена всех условий.

## 12. Опыт + частотные наречия

| Наречие | Значение | Пример |
|---------|----------|--------|
| 一度も…ない | ни разу | 一度も行ったことがない。 |
| 何度も | много раз | 何度も読んだことがある。 |
| ときどき | иногда | ときどき作ることがあります。 |
| あまり…ない | нечасто | あまり食べたことがありません。 |
| 初めて | впервые | 初めて食べました。 |

```
日本食は初めてですか。— Впервые пробуете японскую кухню?
いいえ、何度も食べたことがあります。
Нет, ел много раз.
```

---

## 13. みたい／よう：похожесть и сравнение

Перед みたい имя / основа な-прилагательного идут без の / な: 夢みたい, 静かみたい. Перед следующим существительным добавляется な: 夢みたいな景色.

```
夢みたいな景色ですね。
Пейзаж как во сне.
```

Для образного сравнения с существительным: Nのように; для определения: NのようなN.

```
鳥のように飛びたいです。
Хочу летать как птица.
```

Вывод по признакам (см. также справочник 063):

```
誰もいないようだね。
Кажется, никого нет.
```

<details><summary>Ответы</summary>

## 15. てみる／てみたい — «попробовать сделать»

て-форма + みる = «попробовать что-то сделать» (это очень полезно при планировании поездки):

```
日本料理を食べてみたいです。        — Хочу попробовать японскую кухню.
新幹線に乗ってみたいです。          — Хочу попробовать поездить на синкансэне.
刺身を食べてみてください。          — Попробуйте сашими.
```

> 💡 みる здесь — вспомогательный глагол «смотреть», переносно «проверять на опыте». Это не «смотреть» в прямом смысле.

**Разница:**

| Конструкция | Значение |
|-------------|----------|
| 〜てみる | попробовать сделать, проверяя результат (не обязательно впервые) |
| 〜たことがある | есть ли опыт в прошлом |

```
温泉に入ったことがありますか。      — Вы когда-нибудь были в онсэне? (опыт)
→ いいえ、今度入ってみたいです。    — Нет, хочу попробовать в следующий раз.
```

## 16. 〜ておく — «сделать заранее»

て-форма + おく = «сделать заранее / для будущего использования»:

```
ホテルを予約しておきます。          — Забронирую отель заранее.
切符を買っておいた。              — Купил билет заранее.
```

Отрицание: 〜ておかない

```
予約しておかないと、席がないかも。
Если не забронировать заранее, мест может не быть.
```

> 〜ておかなかった означает, что действие заранее не выполнили, а не что отменили его результат. Следующий пример с てあった, наоборот, описывает уже готовую бронь / покупку:

```
もう切符を買ってあったから、大丈夫。
Билет уже был куплен заранее (кем-то), так что норм.
```

---

## 17. 〜てしまう — «(нечаянно/полностью) сделать»

て-форма + しまう = «закончить сделать» или сожаление «к сожалению, сделал»:

```
スマホの充電がなくなってしまった。  — Зарядка (к несчастью) села.
予約を忘れてしまった。           — (К сожалению) забыл бронь.
```

В разговорной речи стягивается: 〜ちゃう (после て) / 〜じゃう (после で):

```
食べてしまう → 食べちゃう
読んでしまう → 読んじゃう
```

---

## 18. 〜すぎる — «слишком много»

Основа + すぎる = «слишком»:

```
写真を撮りすぎた。                — Сфотографировал слишком много.
高すぎて買えない。               — Слишком дорого, не могу купить.
食べすぎないように気をつけて。     — Старайся не переедать.
```

Прилагательные:

- い-прил: 高い → 高すぎる
- な-прил: 静か → 静かすぎる

## 19. ほうがいい в вопросах и сравнениях

Помимо совета («лучше сделать»), ほうがいい используется в сравнении «X лучше Y»:

```
ホテルより民宿のほうが安いです。    — Гостевой дом дешевле отеля.
電車よりバスのほうが楽です。        — Автобус удобнее электрички.
```

Вопрос о выборе:

```
どちらのほうがいいですか。          — Какой из них лучше?
切符はどこで買ったらいいですか。    — Где купить билет?
```

## 20. もうとまだ — «уже» и «ещё нет»

Важнейшая пара для планирования:

| Слово | Значение | Пример |
|-------|----------|--------|
| もう | уже (сделано) | もう予約しましたか。 — Уже забронировали? |
| まだ | ещё нет | まだです。 — Ещё нет. |

```
もう新幹線の切符を買いましたか。
— はい、もう買いました。
— いいえ、まだ買っていません。
```

> 💡 Ответ «нет» — почти всегда まだ（です）, а не просто «いいえ». Запомните эту пару.

## 21. 〜てもいい／てはいけない — разрешение и запрет

| Конструкция | Значение |
|-------------|----------|
| 〜てもいい | можно сделать |
| 〜てはいけない | нельзя делать |

```
写真を撮ってもいいですか。        — Можно фотографировать?
ここでタバコを吸ってはいけません。 — Здесь нельзя курить.
```

Разговорные варианты: 〜ていい？／〜ちゃダメ？

```
お土産を買ってもいい？            — Можно купить сувенир?
タクシーを使っちゃダメ？          — Нельзя брать такси?
```

## 22. なら для советов по условию

なら — реакция на тему, часто переводится «если речь о..., то»:

```
お寺を見たいなら、清水寺がいいです。  — Если хочешь посмотреть храмы — Киёмидзу-дэра.
疲れたなら、休んだらどうですか。     — Если устал, отдохни.
```

> Важно: なら ставится ПОСЛЕ темы и подчёркивает, что говорится именно об этом предмете.
