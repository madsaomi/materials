# Unit 4 — Текст для чтения

## 私の趣味 (Мои хобби)

```
私の趣味は三つあります。
一番目の趣味は写真です。
特に自然の写真を撮るのが好きです。
週末によく山や海に行きます。
二番目の趣味は料理です。
母からいろいろな料理を習いました。
カレーや餃子を作るのが得意です。
三番目の趣味は読書です。
月に5冊ぐらい本を読みます。
大好きな作家は村上春樹です。
趣味があると生活が楽しくなります。
これからも色々な趣味を増やしたいです。
```

### 単語

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 三つ | みっつ | три (штуки) |
| 一番目 | いちばんめ | первый |
| 特に | とくに | особенно |
| 撮る | とる | снимать, фоткать |
| 習う | ならう | учиться, перенимать |
| 餃子 | ぎょうざ | гёдза (пельмени) |
| 得意 | とくい | хорошо получается |
| 冊 | さつ | счётчик для книг |
| 作家 | さっか | писатель |
| 増やす | ふやす | увеличивать |

### 翻訳

У меня три хобби.
Первое хобби — фотография.
Особенно мне нравится фотографировать природу.
В выходные часто езжу в горы или к морю.
Второе хобби — кулинария.
Я научилась разным блюдам у мамы.
Хорошо получаются карри и гёдза.
Третье хобби — чтение.
В месяц читаю около 5 книг.
Мой любимый писатель — Мураками Харуки.
С хобби жизнь становится веселее.
В будущем хочу увеличить количество хобби.

### 質問

1. 趣味はいくつありますか。
2. 一番目の趣味は何ですか。
3. 写真で何を撮るのが好きですか。
4. 二番目の趣味は何ですか。何が得意ですか。
5. だれの料理を習いましたか。
6. 三番目の趣味は何ですか。どのくらい読みますか。

**Ответы:**

1. 三つあります。
2. 写真です。
3. 自然の写真を撮るのが好きです。
4. 料理です。カレーと餃子が得意です。
5. 母から習いました。
6. 読書です。月に5冊ぐらい読みます。

## テキスト２：しょうがっせいの　おてがみ（Письмо-приглашение от школьника)

```
アリスさんへ

こんにちは。ゆきです。
げつようびの　あさ、メールを　ありがとう。
はい、いっしょに　こうえんへ　行きましょう！

日曜日の　十時に　えきの　まえで
会いませんか。
おべんとうを　持ってきてください。
わたしは　おちゃと　ケーキを
よういします。

あしたは　よていが　ありますから、
返事は　あさっての　ひるまでに
もらえると　うれしいです。

じゃあ、日曜日に！
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| ～へ | — | кому (в письме) |
| いっしょに行きましょう | — | пойдёмте вместе |
| 会う | あう | встречаться |
| 持ってくる | もってくる | принести |
| 用意する | よういする | подготовить |
| 返事 | へんじ | ответ |
| ～ともらえると嬉しい | ～ともらえるとうれしい | буду рад, если… |

### 翻译 (Перевод)

Алисе!

Привет! Это Юки. Спасибо за письмо в понедельник утром.
Да, давайте сходим вместе в парк!

В воскресенье в десять — не встретиться ли перед станцией?
Возьмите с собой бэнто. Я подготовлю чай и тортик.

Завтра у меня планы, так что буду рада получить ответ послезавтра до обеда.

Ну, до воскресенья!

### 質問 (Вопросы)

1. いつ　どこで　会いますか。
2. アリスさんは　なにを　持ってきますか。
3. 返事は　いつまでですか。

**Ответы:**

1. 日曜日の十時に駅の前で会います。
2. おべんとうを持ってきます。
3. あさっての昼までです。

## テキスト３：カラオケの　おさそい（Приглашение в караоке)

```
けんた：アリスさん、こんばんは。
　　　　あしたの　よる、ヒマですか。
アリス：はい、大丈夫ですよ。
けんた：クラスのみんなで　カラオケに
　　　　行くんです。どうですか。
アリス：カラオケ？でも、うたが…
けんた：だいじょうぶですよ。うたが
　　　　下手でも　楽しいです。
　　　　ギターが　できるそうですね。
アリス：少し　しか　できませんが…。
けんた：じゃあ、バンドも　できますね！
　　　　七時に　えきの　まえで
　　　　待っています。
アリス：分かりました。楽しみです！
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 今晩は | こんばんは | добрый вечер |
| 暇 | ひま | свободный (о времени) |
| ～んです | — | объяснение |
| 下手 | へた | неумелый |
| バンド | — | группа, бэнд |
| 待っています | まっています | буду ждать |
| 楽しみ | たのしみ | предвкушение |

### 翻译 (Перевод)

Кэнта: Алиса, добрый вечер. Завтра вечером свободны?
Алиса: Да, всё в порядке.
Кэнта: Мы всем классом идём в караоке. Как насчёт?
Алиса: Караоке? Но я же петь...
Кэнта: Всё нормально! Даже если поёшь плохо — весело. Говорят, ты играешь на гитаре?
Алиса: Только немного...
Кэнта: Значит, и группу можно собрать! В семь жду перед станцией.
Алиса: Договорились! Жду с нетерпением!

### 質問 (Вопросы)

1. いつ　どこへ　行きますか。
2. アリスさんは　なにが　できますか。
3. 何時　どこで　会いますか。

**Ответы:**

1. あしたの夜、カラオケへ行きます。
2. 少しギターができます。
3. 七時に駅の前で会います。

## テキスト４：週末の日記 (Дневник выходных)

```
土曜日の朝、友達のけんと花見に行きました。
上野公園で桜を見ました。桜はとてもきれいでした。
お昼は公園でお弁当を食べました。
ピクニックの後、写真をたくさん撮りました。
午後は美術館に行きました。
夕方、駅の近くの喫茶店でお茶をしました。

日曜日は家でゆっくり休みました。
朝から雨が降ったからです。
夜、来月の旅行の計画を立てました。
京都で紅葉を見る予定です。
今からとても楽しみです。
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 花見 | はなみ | любование сакурой |
| 上野公園 | うえのこうえん | парк Уэно |
| 桜 | さくら | сакура |
| きれい | — | красивый |
| お弁当 | おべんとう | бэнто, коробка с едой |
| 美術館 | びじゅつかん | художественный музей |
| 夕方 | ゆうがた | вечернее время |
| 喫茶店 | きっさてん | кафе |
| ゆっくり | — | неспешно, спокойно |
| 計画を立てる | けいかくをたてる | составить план |
| 紅葉 | もみじ | кленовые листья |
| 楽しみ | たのしみ | предвкушение, радость ожидания |

### 翻訳 (Перевод)

В субботу утром сходил на ханами с другом Кэном.
В парке Уэно посмотрели сакуру. Сакура была очень красивой.
В обед поели бэнто в парке.
После пикника наделал много фотографий.
После обеда пошли в художественный музей.
Вечером попили чай в кафе у станции.

В воскресенье спокойно отдохнул дома,
потому что с утра шёл дождь.
Вечером составил план поездки в следующем месяце.
Планирую посмотреть красные клёны в Киото.
Уже очень этого жду.

### 質問 (Вопросы)

1. 土曜日の朝、どこで何をしましたか。
2. お昼は何を食べましたか。
3. 午後はどこへ行きましたか。
4. 日曜日はどうして家にいましたか。
5. 来月の予定は何ですか。

**Ответы:**

1. 上野公園で花見をしました。
2. 公園でお弁当を食べました。
3. 美術館へ行きました。
4. 朝から雨が降ったからです。
5. 京都へ紅葉を見に行く予定です。

## テキスト５：メール　京都の秋のお誘い (Письмо-приглашение в Киото)

```
件名：京都の秋、いっしょに行きませんか

はるかさん

お元気ですか。ゆいです。
先週のメール、ありがとうございました。
実は、来月の連休に京都へ紅葉を見に行く予定です。
よかったら、はるかさんもいっしょにどうですか。

日程は11月の20日から22日です。
電車のチケットは私が取ります。
ホテルは駅の近くの「さくらホテル」を予約する予定です。
一泊5000円です。

都合が悪かったら、遠慮しないで教えてください。
お返事を楽しみにしています。

ゆい
```

### 単語 (Слова)

| Слово | Чтение | Перевод |
|-------|--------|---------|
| 件名 | けんめい | тема письма |
| 連休 | れんきゅう | длинный выходные, праздничные дни |
| 紅葉 | もみじ | красные клёны |
| よかったら | — | если не против (букв. «если хорошо») |
| 日程 | にってい | сроки, расписание |
| チケット | — | билет |
| 予約する | よやくする | бронировать |
| 一泊 | いっぱく | одна ночь |
| 都合が悪い | つごうがわるい | неудобно |
| 遠慮しないで | えんりょしないで | не стесняйся |
| お返事 | おへんじ | ответ (вежливо) |

### 翻訳 (Перевод)

Тема: Осень в Киото — не поедем ли вместе?

Харука!

Как поживаешь? Это Юи.
Спасибо за письмо на прошлой неделе.
Вообще-то, я планирую поехать на длинные выходные в следующем месяце посмотреть клёны в Киото.
Если не против, поехали вместе?

Сроки: с 20 по 22 ноября.
Билеты на поезд беру я.
Отель планирую забронировать «Сакура-отель» рядом со станцией.
5000 иен за ночь.

Если будет неудобно — не стесняйся, скажи.
Жду твоего ответа.

Юи

### 質問 (Вопросы)

1. ゆいさんはいつ京都へ行きますか。
2. 京都で何を見ますか。
3. チケットとホテルはだれが取りますか。
4. ホテルはどこにありますか。一泊いくらですか。
5. 都合が悪かったら、どうしますか。

**Ответы:**

1. 来月の連休（11月の20日から22日）に行きます。
2. 紅葉を見ます。
3. チケットはゆいさんが取ります。ホテルもゆいさんが予約します。
4. 駅の近くの「さくらホテル」です。一泊5000円です。
5. 遠慮しないで教えます。

## Как работать с текстами урока 4

1. **Письмо (текст 2)** — образец для своего первого настоящего письма-приглашения. Заметьте: ～へ в начале и подпись без фамилии.
2. **Разговорник приглашений:** 行きましょう・ませんか・どうですか — все три в тексте 3!
3. **Мини-задание:** напишите приглашение другу на выходные (5–7 строк) с указанием времени и места встречи.
4. **Эмейл (текст 5)** — для более формальной переписки: тема 件名, вежливое обращение, блок «сроки», блок «кто что берёт на себя», блок «как ответить при отказе».
5. **Дневник (текст 4)** — обратите внимание на связки времени: 朝・お昼・午後・夕方・夜 — это каркас описания любого дня.
