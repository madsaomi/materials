# Unit 12 — Грамматика: 敬語（三種類の敬語)

## 1. Три вида кэйго —— карта

| Вид | Направление | Пример «есть» |
|-----|-------------|----------------|
| 尊敬語（そんけいご) | возвышаю ДРУГОГО | 召し上がります |
| 謙譲語（けんじょうご) | принижаю СЕБЯ | いただきます |
| 丁寧語（ていねいご) | украшаю речь | 食べます |

## 2. 尊敬語: два механизма

**А. Спецслова (запомнить наизусть):**

| Обычный | Уважительный | Значение |
|---------|--------------|----------|
| いる・行く・来る | いらっしゃる | быть/приходить |
| 言う | おっしゃる | говорить |
| 食べる・飲む | 召し上がる | есть/пить |
| 見る | ご覧になる | смотреть |
| 知っている | ご存知だ | знать |
| する | なさる | делать |
| 寝る | お休みになる | спать |
| くれる | 下さる | давать мне |

**Б. Формула お／ご＋основа＋になる:**

```
書く → お書きになります。（Вы пишете)
待つ → お待ちになります。
```

⚠️ Исключения：おっしゃる・いらっしゃる・なさる・下さる・いらっしゃいます（не ～られる!):
❌ いらっしゃられる → ✅ いらっしゃいます

## 3. 謙譲語: два механизма

**А. Спецслова:**

| Обычный | Скромный | Значение |
|---------|----------|----------|
| 行く・来る | 参る（まいる) | идти/приходить |
| する | 致す（いたします) | делать |
| 言う | 申す（もうす) / 申し上げる | говорить |
| 食べる・もらう | いただく | есть/получать |
| 見る | 拝見する（はいけん) | смотреть |
| 会う | お目にかかる | встречать |
| 知っている | 存じ上げる / 存じます | знать |

**Б. Формула お／ご＋основа＋する／いたす:**

```
案内する → ご案内いたします。（я вас провожу)
電話する → お電話いたします。
```

## 4. 丁寧語: お／ご-украшения

Исконные слова + お, китайские заимствования + ご:

```
お金 · お茶 · お名前（исконные)
ご飯 · ご意見 · ご連絡（китайские)
```

⚠️ Исключения на -о：お電話、お勉強（китайские с о).

## 5. Просьбы сверхвежливые

| Форма | Уровень |
|-------|---------|
| ～てください | стандарт |
| ～てもらえますか | мягко |
| ～ていただけますか | вежливо |
| ～ていただけませんでしょうか | максимум |

Ответ клиента на вашу услугу часто「どうも」—— вам отвечают「いえ、とんでもございません」.

## 6. ～ております = ています（скромно)

В сервисе о себе говорите через おります:

```
店長は今、会議中でおります。？ нет—— это про 店長 уважительно：
店長はただいま会議中でございます。
私は山田の部下でございます。
```

## 7. Типичные ошибки

❌ 社長が申しました。→ ✅ 社長が**おっしゃいました**。（申す —— только о себе!)
❌ 私が召し上がります。→ ✅ 私が**いただきます**。
❌ 先生に伺いましたか？（спрашиваете у друга об учителе) → ✅ 先生に**聞きました**か。（伺う только если вы сами шли к учителю)

> 💡 **Главное правило направления:** кэйго «течёт» вверх по социальной лестнице. Уважительное —— к собеседнику/третьему лицу выше вас; скромное —— к своим действиям.

## 8. 特別なお名前（специальные вежливые существительные)

В сервисе вещи не называются напрямую — красивые слова придают уважение:

| Обычное | Вежливое | Значение |
|---------|----------|----------|
| 前（まえ) | お手前 | перед（еда перед гостем) |
| 名前 | お名前 | имя |
| 金 | お金 | деньги |
| 茶 | お茶 | чай |
| 席 | お席 | место |
| 時間 | お時間 | время |
| 荷物 | お荷物 | багаж |
| 一人 | お一人 | один человек |
| 連絡 | ご連絡 | связь |
| 意見 | ご意見 | мнение |
| 家族 | ご家族 | семья（клиента) |

**Правило выбора お/ご:** исконно японские слова（お茶、お名前) берут お; китайские заимствования（ご連絡、ご意見) берут ご. Исключения: お電話、お勉強、お料理 —— китайские, но с お.

## 9. お〜になる vs お〜する —— направление

| Формула | Кого описывает | Пример |
|---------|----------------|--------|
| お読み**になる** | ДРУГОГО（уваж.) | お客様がお読みになります |
| お読み**する／いたす** | СЕБЯ（скромно) | 私がお読みいたします |

> 💡 Запомните пару: **になる** всегда про чужое действие, **する/いたす** всегда про своё. Если сомневаетесь в слове —— используйте спецслова или 〜される（нейтрально-уважительно).

**Нейтральный 敬語 по 〜される:** для глаголов группы 1 и 3 допустимо 〜される:

```
行く → 行かれます
食べる → 食べられます（группа 2 —— осторожно, путается с пассивом)
```

В речи сервиса 〜される звучит проще и вежливо-нейтрально, но для ключевых слов（来る→いらっしゃる) лучше выучить спецформы.

## 10. 謙譲語 приветствий и ухода

Ключевые фразы, которые надо знать наизусть в обе стороны:

**О себе（謙譲):**

| Ситуация | Фраза |
|----------|-------|
| Прихожу | 参ります / 伺います |
| Делаю | いたします |
| Слушаю | 承ります |
| Отвечаю | お答えいたします |
| Ухожу | 失礼いたします |

**О клиенте（尊敬):**

| Ситуация | Фраза |
|----------|-------|
| Пришёл | いらっしゃいました |
| Спрашивает | おっしゃいます |
| Видит | ご覧になります |
| Ест/пьёт | 召し上がります |
| Делает | なさいます |

## 11. いただく как «получать» и «есть»

**いただく — два значения:**

1. **Есть/пить（谦譲 от 食べる・飲む):**

   ```
   お弁当をいただきます。 —— приму еду（перед едой)
   ```

2. **Получать（谦譲 от もらう):** «мне дарят/делают»:

   ```
   ご案内をいただき、ありがとうございます。
   —— спасибо, что проводили меня.
   ```

> ⚠️ Не путайте с 下さる（уваж. «давать мне»). いただく —— со стороны получателя（скромно), 下さる —— со стороны дающего（уваж.)。

## 12. ございます vs あります

**ございます — уважительный вариант あります** (для неодушевленных):

| Обычное | Вежливое |
|---------|----------|
| あります | ございます |
| ありません | ございません |

```
お手洗いは二階にございます。 —— туалет на втором этаже.
申し訳ございません。 —— приношу глубочайшие извинения.
```

> 💡 В сервисе слово ございます почти всегда заменяет あります для предметов клиента: お荷物はこちらにございます。

## 13. でございます —— уважительная связка

**でございます — вежливая форма です** (для себя, своего дела — чуть скромнее):

```
私は受付の者でございます。 —— я работник приёмной.
こちらでございます。 —— вот это（вежливо).
お茶でございます。 —— пожалуйстa, чай.
```

> ⚠️ でございます скромно-уважительно. Для описания действий НАЧАЛЬСТВА используйте なさいます/でいらっしゃいます: こちらが社長でいらっしゃいます。

## 14. Запрет/разрешение вежливо（〜てはいけません/〜てください expansions)

Уровни «можно/нельзя» в сервисе:

| Фраза | Уровень |
|-------|---------|
| 〜てください | нейтрально вежливо |
| 〜なさってください | уважительно（клиенту) |
| 〜していただけますか | вежливо（просьба о себе) |
| 〜いただけないでしょうか | максимально вежливо |
| 〜てもよろしいですか | Можно?（разрешение) |
| 〜てはいけません | нельзя（твёрдо) |

```
店内でお召し上がりいただけます。 —— можно поесть в зале.
写真はご遠慮ください。 —— просим воздержаться от фото.
```

## 15. Несколько 敬語 в одной фразе

Длинные фразы сервиса комбинируют 尊敬 + 謙譲 + 丁寧 одновременно:

```
お席へご案内いたします。
—— Я проведу вас к месту.（謙譲 о себе)
ご注文はお決まりになりましたか。
—— Вы определились с заказом?（尊敬 про клиента)
少々お待ちいただけますでしょうか。
—— Не могли бы вы немного подождать?（谦譲+ТЭИННЭЙ)
```

**Разбор составной фразы:**

```
お 伺い いたします ← 伺う（谦譲) + いたす（谦譲 = удвоенная скромность)
ご 案内 いたします ← 案内 + いたす（谦譲）
```

## 16. Типичные ошибки против кэйго（детально)

| ❌ Неправильно | ✅ Правильно | Почему |
|----------------|--------------|--------|
| 社長がご覧になりましたか？ | 社長がご覧になりましたか？（✓) | ок, а вот свой 見る нельзя |
| 私が参りました←自分だけ | 私が参りました（✓ о себе) | 参る — только про себя |
| 〜られられます（двойной пассив+敬語) | いらっしゃいます | не складывайте кэйго |
| お茶を召し上がります（клиент) ✓ | （自己で)お茶をいただきます | направление важно |
| ご案内になさる（клиент) | ご案内なさる | не смешивайте формулы |
| 伺ってください（уваж. к клиенту) | お越しください | 伺う — только про себя |

## 17. Кэйго в телефонном разговоре

Телефон — отдельная песня. В сервисе отвечают шаблонно:

```
お電話ありがとうございます。もみじでございます。
—— Спасибо за звонок, это «Момидзи».
担当者におつなぎいたします。
—— Соединю с ответственным.
少々お待ちください。お願いいたします。
—— Подождите, пожалуйста.
只今、席を確認いたします。
—— Сейчас проверю наличие мест.
```

**Ключевые телефонные кэйго:**

| Обычное | Телефонное кэйго |
|---------|------------------|
| つなぐ | おつなぎいたします |
| 確認する | 確認いたします |
| 申し訳ない | 恐れ入ります |
| 聞こえる | お聞き取りにくい（плохо слышно) |

## 18. Почтительные слова для дара и услуги

| Обычное | 謙譲（о своём даре) | 尊敬（о чужом даре) |
|---------|---------------------|---------------------|
| あげる | 差し上げる | — |
| もらう | いただく | 下さる |
| 紹介 | ご紹介いたす | — |
| 届ける | お届けいたす | — |
| 見せる | お目にかける | ご覧に入れる |

```
部長に資料を差し上げました。—— отдал документ начальнику.
社長からお言葉をいただきました。—— получил слова от директора.
```

## 19. Сводная таблица направлений（шпаргалка)

| Действие | О себе（謙譲) | О другом（尊敬) |
|----------|---------------|-----------------|
| идти | 参る | いらっしゃる |
| говорить | 申す | おっしゃる |
| есть | いただく | 召し上がる |
| видеть | 拝見する | ご覧になる |
| делать | 致す | なさる |
| знать | 存じる | ご存知だ |
| получать | いただく | 下さる |
| быть | おります | いらっしゃる |

> 💡 **Золотое правило юнита:** 謙譲 —— принижаю своё, 尊敬 —— возвышаю чужое, 丁寧 —— украшаю всё. Кэйго всегда «течёт вверх».
