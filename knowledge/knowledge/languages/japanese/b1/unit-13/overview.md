# Японский · Урок 13 — Условные формы: как выбирать · дополнительная версия

Этот урок организован вокруг задачи: **условные формы: как выбирать**. Сначала разберите короткую модель, затем примените её в речи и проверьте себя. Подробная грамматика содержит и дополнительные темы: не обязательно проходить весь справочный объём за один подход.

## Чему вы научитесь

- Объяснять своими словами: と часто описывает закономерный результат; たら — конкретную условную ситуацию; なら может подхватывать условие из разговора; ば выражает условную зависимость со своими ограничениями.
- Разбирать учебный пример по ролям участников и значению формы.
- Самостоятельно решать задачу: Какую функцию выполняет と в примере с кнопкой: цитирование или условную связь?
- Применять правило в двух новых фразах, а не только узнавать готовый ответ.

## Что нужно перед началом

Повторите модели предыдущего урока и выпишите одну оставшуюся трудность. Если вы пришли из поиска, используйте содержание уровня, чтобы найти пропущенные темы.

Метка папки — способ организации исходного курса; она не подтверждает полного покрытия экзаменационного или международного уровня.

## Короткое объяснение

と часто описывает закономерный результат; たら — конкретную условную ситуацию; なら может подхватывать условие из разговора; ば выражает условную зависимость со своими ограничениями. Не заменяйте все формы одним русским «если» без контекста.

**Пример с разбором.** このボタンを押すと、ドアが開きます。— Если нажать эту кнопку, дверь открывается. Здесь результат описывается как обычная работа механизма.

## Маршрут занятия

1. [Диалог](dialogue.md): сначала найдите участников и цель разговора, затем отметьте изучаемую форму. Чтение диалога само по себе не заменяет аудирование.
2. [Грамматика](grammar/core.md): прочитайте основной блок и сформулируйте правило одним предложением.
3. [Разбор применения](grammar/usage.md): сопоставьте форму со смыслом, решите мини-задачу до открытия ответа.
4. [Словарь](vocabulary/words.md): выберите небольшой набор слов, нужных для ваших примеров. Не пытайтесь выучить весь список за один раз.
5. [Практика](practice/exercises.md): запишите решения отдельно; готовые ответы используйте после попытки.
6. [Чтение](reading.md): перескажите основную мысль и найдите примеры изученной модели.
7. [Тест](test.md): выполните без конспекта, затем объясните каждую ошибку.

## Самопроверка перед практикой

Какую функцию выполняет と в примере с кнопкой: цитирование или условную связь?

<details>
<summary>Ответ — откройте после своей попытки</summary>

Условную связь: нажатие кнопки приводит к открыванию двери. Частица と имеет и другие функции, поэтому рассматривается вся структура предложения.
