# Unit 1 — Грамматика

## Учебное ядро: Именное сказуемое: знакомство, тема и принадлежность
## Как назвать себя и объяснить, что перед вами

В предложении «Я студент» японскому существительному нужен конец сказуемого: 学生です. Частица は, читаемая wa, обозначает тему: 私は学生です — «Что касается меня, я студент». Если понятно, о ком речь, тему можно опустить. При знакомстве リナです — «Я Рина» — достаточно; повторять 私は перед каждой фразой не нужно.

| Что нужно сообщить | Модель | Пример с переводом |
|---|---|---|
| Кто это | Nです | 姉は医者です。— Моя старшая сестра — врач. |
| Кем не является | Nではありません | 私は先生ではありません。— Я не преподаватель. |
| Уточняющий вопрос | Nですか | 留学生ですか。— Вы студент по обмену? |
| Такой же признак | Nも | 弟も学生です。— Младший брат тоже студент. |

В разговоре вместо ではありません употребляют じゃありません / じゃないです. Простое 学生だ отличается от 学生です регистром, а не профессией говорящего. Не стройте 読みますです: у глагола уже есть своё вежливое окончание.

## Предмет, его название и владелец

これ / それ / あれ употребляются самостоятельно: これは辞書です — «Это словарь». この / その / あの требуют существительного: この辞書 — «этот словарь». В простом указании こ- связано со стороной говорящего, そ- — собеседника, あ- — удалённостью от обоих. Общая ситуация и упоминание в разговоре тоже влияют на выбор: расстояние не измеряют механически.

の связывает два существительных: 友達の辞書 — «словарь друга», 日本語の辞書 — «словарь японского языка». Значение бывает принадлежностью, тематикой, отношением; не всякое の переводится «чей».

**Разбор:** これは姉のかばんです。— «Это сумка моей старшей сестры». これ — предмет; は — тема; 姉のかばん — именная группа; です — вежливое завершение. В 誰のかばんですか — «Чья это сумка?» — вопрос касается владельца.

## Тема и ответ на вопрос «кто»

誰が学生ですか。— «Кто студент?» → リナさんが学生です。— «Рина». が выделяет искомого участника. は не означает «я», が не означает «он»; выбор связан с построением сообщения. Ошибки 私はも学生です и このは辞書です исправляются как 私も学生です и これは辞書です / この本は辞書です в зависимости от смысла.

> Ниже сохранены прежние примеры, ссылки и справочные расширения. В этой редакции исправлены отдельные проверенные ошибки, но весь длинный банк не прошёл сплошную языковую проверку. Для первого прохода используйте новый разбор выше.

## 1. AはBです (А — это Б)

```
私は学生です。     — Я студент.
田中さんは先生です。 — Господин Танака — учитель.
これは本です。      — Это книга.
```

**Структура:** [Тема] は [Описание] です

**Отрицание:** では ありません / じゃ ありません

```
学生ではありません。 — Я не студент.
先生じゃありません。 — Я не учитель.
```

## 2. AはBですか (Вопрос)

```
学生ですか。        — Вы студент?
田中さんですか。    — Вы господин Танака?
これは本ですか。    — Это книга?
```

**Ответы:**

```
はい、そうです。     — Да, это так.
いいえ、違います。  — Нет, не так.
いいえ、そうじゃありません。 — Нет, это не так.
```

## 3. Указательные местоимения

| Слово | Значение | Пример |
|-------|----------|--------|
| これ | это (близко) | これは本です |
| それ | то (ближе к слуш.) | それはペンです |
| あれ | вон то (далеко) | あれは山です |
| この[N] | этот N | この本は面白い |
| その[N] | тот N | その人を知っています |
| あの[N] | вон тот N | あの建物は駅です |

## 4. の (притяжательная частица)

```

田中さんの電話 — телефон г-на Танаки
大学の先生  — учитель университета
```

## 9. です vs だ (вежливая и простая форма)

**です** — вежливая форма (используется с незнакомыми, при формальной речи):

```
私は学生です。 — Я студент (вежливо).
```

**だ** — простая/разговорная форма (с друзьями, в письменной речи):

```
私は学生だ。 — Я студент (разговорное).
```

**Негативная форма:**

```
学生ではない。 / 学生じゃない。 — Я не студент.
```

## 10. を (частица объекта)

```
本を読みます。 — Читаю книгу。
日本語を勉強します。 — Учу японский。
```

## 11. に (направление, время, место пребывания)

**Направление:**

```
学校に行きます。 — Иду в школу。
東京に行きます。 — Еду в Токио。
```

**Время:**

```
9時に起きます。 — Встаю в 9 часов。
毎朝7時に起きます。 — Каждое утро встаю в 7。
```

**Местонахождение и место проживания:**

```
家にいます。       — Нахожусь дома.
日本に住んでいます。 — Живу в Японии.
```

В первом примере сказуемое いる, во втором — 住む в форме 住んでいます. Оба обозначают место с に, но это разные глаголы; «живу» не переводится одним います. [TUFS: местонахождение](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/006.html).

## 12. で (место действия, инструмент)

**Место действия:**

```
図書館で勉強します。 — Учусь в библиотеке。
学校で友達と話します。 — Разговариваю с другом в школе。
```

**Инструмент (с глаголами действия):**

```
車で行きます。 — Еду на машине。
電車で行きます。 — Еду на электричке。
```

## 13. 〜ている (текущее действие / результат)

**Действие в процессе:**

```
本を読んでいます。 — Читаю книгу (сейчас).
```

**Результат (состояние):**

```
窓が開いています。   — Окно открыто (состояние после открывания).
日本に住んでいます。 — Живу в Японии (проживание, не действие прямо сейчас).
```

**Отрицание:**

```
勉強していません。 — Не учусь (сейчас).
知りません。       — Не знаю.
```

Не образуйте любое отрицание механически по одной модели: обычный ответ на 知っていますか — いいえ、知りません. [TUFS: состояния и 知りません](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/045.html).

## 14. が (субъект и предпочтения)

В этих моделях が отмечает то, что любят, понимают или хотят, а также участника события. Сказуемые различаются: 好き — な-прилагательное, 欲しい — い-прилагательное, 分かる и 降る — глаголы. Не называйте все эти формы «глаголами чувств»:

```
猫が好きです。      — Люблю кошек.
日本語が分かります。 — Понимаю японский.
水が欲しいです。    — Хочу воды.
雨が降っています。  — Идёт дождь.
```

**が vs は:** は вводит тему, が выделяет субъект/факт:

```
私は学生です。    — Я студент (про себя, тема).
私が学生です。    — Именно я студент (кто именно?).
```

## 15. と (с кем-то, и)

**と** — «с» (совместность) и соединительная частица «и»:

```
友達と話します。    — Разговариваю с другом.
田中さんと映画を見ます。 — Смотрю фильм с г-ном Танакой.
本とノートを買います。 — Покупаю книгу и тетрадь.
```

## 16. Отрицательная форма глаголов (〜ません)

| Вид | Форма | Пример |
|-----|-------|--------|
| Утверждение | 〜ます | 食べます |
| Отрицание | 〜ません | 食べません |
| Прошедшее | 〜ました | 食べました |
| Отриц. прош. | 〜ませんでした | 食べませんでした |

```
お茶を飲みません。   — Не пью чай.
昨日は勉強しませんでした。 — Вчера не занимался.
```

## 17. Прошедшее время: でした / でしたか

**です → でした** (вежливое прошедшее для именных + な-прил.):

```
昨日は日曜日でした。 — Вчера было воскресенье.
田中さんは医者でした。 — Г-н Танака был врачом.
昨日はひまでした。   — Вчера было свободное время.
```

**Вопрос в прошедшем:**

```
きのうは暇でしたか。 — Вчера было свободное время?
いいえ、忙しかったです。 — Нет, я был занят.
```

## 18. い-прилагательные: утверждение/отрицание

В утверждении い сохраняется. Для отрицания и прошлого конечное い заменяется нужным окончанием. Исключение いい использует основу よ-: よくないです / よかったです. きれい — な-прилагательное, поэтому きれいでした, а не きれかったです. [TUFS: формы прилагательных](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/040.html).

| Форма | Пример |
|-------|--------|
| Утверждение | 大きいです |
| Отрицание | 大きくないです |
| Прошедшее | 大きかったです |
| Отриц. прош. | 大きくなかったです |

```
この本は面白いです。   — Эта книга интересная.
この本は面白くないです。 — Эта книга не интересная.
```

## 19. とても / あまり (очень / не очень)

```
とてもおいしいです。    — Очень вкусно.
あまり高くないです。   — Не слишком дорого (досл. «не очень дорого»).
あまり好きじゃありません。 — Не очень люблю.
```

В изучаемой модели あまり〜ない используется отрицание. У あまり есть и другие употребления; не переносите это ограничение на все контексты.

## 20. 〜から (потому что) — в конце предложения

```
時間がないから、行きません。 — Потому что нет времени, не пойду.
好きだから、食べます。      — Люблю, поэтому ем.
```

から ставится после причины. Перед ним возможны простые и вежливые формы: 忙しいから / 忙しいですから.

## 21. どうぞ / ください — просьба и предложение

```
どうぞ。            — Пожалуйста (вот, берите).
水をください。       — Дайте воды, пожалуйста.
ラーメンを一つください。 — Дайте рамэн, один.
もう一度言ってください。 — Скажите ещё раз, пожалуйста.
```

## 22. 〜ますか — вежливый вопрос с глаголом

```
日本語を話しますか。 — Вы говорите по-японски?
コーヒーを飲みますか。 — Выпьете кофе?
今日は何をしますか。 — Что делаете сегодня?
```

Ответ: はい、話します。/ いいえ、話しません。
