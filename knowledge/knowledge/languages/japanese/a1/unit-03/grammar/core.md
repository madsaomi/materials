# Unit 3 — Грамматика: Просьбы, направления, существование

## Учебное ядро: て-форма: просьба, разрешение и местонахождение
## Одна て-форма, разные действия собеседника

て-форма сама по себе не выражает прошедшее время. В просьбе она соединяет действие с ください: 名前を書いてください — «Напишите имя, пожалуйста». В вопросе 写真を撮ってもいいですか — «Можно сфотографировать?» — разрешение просит тот, кто будет фотографировать. 撮ってください означает уже просьбу к собеседнику сделать снимок.

| Исходное окончание | Преобразование | Пример |
|---|---|---|
| う・つ・る группы 1 | って | 買う→買って, 待つ→待って, 帰る→帰って |
| む・ぶ・ぬ | んで | 読む→読んで, 遊ぶ→遊んで, 死ぬ→死んで |
| く / ぐ | いて / いで | 書く→書いて, 泳ぐ→泳いで |
| す | して | 話す→話して |
| る группы 2 | て вместо る | 見る→見て |
| Особые формы | запомнить | する→して, 来る→来て（きて）, 行く→行って |

Для запрета: ここで泳いではいけません — «Здесь нельзя плавать». Для отрицательной просьбы: ここで泳がないでください — «Пожалуйста, не плавайте здесь». Это разные конструкции: не превращайте 泳いで в отрицание добавлением ない.

## Где находится и где происходит

机の上に鍵があります。— «На столе есть ключ». 猫は椅子の下にいます。— «Кошка под стулом». ある обычно описывает предметы, いる — людей и животных; выражение существования не требует «активного движения». Спящий человек всё равно います.

図書館にいます — «Нахожусь в библиотеке»; 図書館で読みます — «Читаю в библиотеке». に обозначает местонахождение при いる, で — место действия при 読む. Для мероприятия с ある возможна модель 会議は二階であります — «Собрание проходит на втором этаже»: это событие, не предмет на полке.

**Разбор маршрута:** 二つ目の角を右に曲がってください。駅は橋の近くにあります。— «Поверните направо на втором перекрёстке. Станция находится около моста». 曲がる→曲がって; に после 右 отмечает направление поворота, а после 近く — местонахождение станции.

## Просьба и отношения участников

ください делает просьбу вежливой по форме, но не гарантирует мягкости в любой ситуации. 指示 «Заполните бланк» и большая просьба к преподавателю требуют разного оформления. Для начала уверенно различайте «сделайте», «мне можно сделать?» и «не делайте».

## 1. 〜てください (просьба)

```
右に曲がってください。    — Поверните направо.
まっすぐ行ってください。   — Идите прямо.
ここに座ってください。     — Садитесь здесь.
待ってください。          — Подождите, пожалуйста.
```

**Образование て-формы:**

**Группа I:**

- く→いて: 書く→書いて
- Исключение: 行く（いく）→ 行って（いって）, а не 行いて. См. [таблицу Japan Foundation](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf#page=70).
- ぐ→いで: 泳ぐ→泳いで
- う/つ/る→って: 会う→会って, 待つ→待って, 帰る→帰って
- ぬ/ぶ/む→んで: 死ぬ→死んで, 遊ぶ→遊んで, 読む→読んで
- す→して: 話す→話して

**Группа II:** る→て: 食べる→食べて

**Группа III:** する→して, 来る→来て(きて)

## 2. 〜てもいいですか (можно?)

```
ここに座ってもいいですか。    — Здесь можно сесть?
写真を撮ってもいいですか。    — Можно сфотографировать?
トイレに行ってもいいですか。  — Можно в туалет?
```

## 3. 〜てはいけません (нельзя)

```
ここでタバコを吸ってはいけません。 — Здесь нельзя курить.
携帯を使ってはいけません。       — Нельзя пользоваться телефоном.
```

## 4. あります / います (быть, находиться)

**あります** — для неодушевлённых предметов:

```
駅の前にコンビニがあります。 — Перед станцией есть магазин.
ここに本があります。        — Здесь есть книга.
```

**います** — для одушевлённых (люди, животные):

```
公園に子供がいます。    — В парке есть дети.
家に猫がいます。       — Дома есть кошка.
```

## 5. に / で (локативные частицы)

**に** — местонахождение (с あります/います):

```
駅の前にコンビニがあります。 — Магазин есть перед станцией.
```

**で** — место действия:

```
図書館で勉強します。 — Учусь в библиотеке.
```

## 6. Вопрос: どこですか / どこにありますか

```
駅はどこですか。              — Где станция?
トイレはどこにありますか。      — Где туалет?
田中さんはどこにいますか。      — Где господин Танака?
```

## 7. どのくらいかかりますか (сколько занимает)

```
駅までどのくらいかかりますか。 — Сколько идти до станции?
10分かかります。              — Займёт 10 минут.
```

**Ответы:**

1. 左に曲がってください。
2. ここに座ってもいいですか。
3. トイレはここにあります。
4. に/が
5. 駅まで5分かかります。

## 8. 〜から / 〜ので (потому что)

**から** явно представляет основание для следующего сообщения. Связка встречается и в разговорной, и в вежливой речи; ですから тоже возможно:

```
暑いから、水を飲みます。 — Потому что жарко, пью воду。
遅いから、急いでください。 — Поздно, пожалуйста, поторопитесь。
```

**ので** представляет причину как объяснение ситуации и часто удобно в вежливой просьбе. Это не гарантия объективности. Непрошедшие существительное и な-прилагательное требуют な: 休みなので / 静かなので; у から будет 休みだから / 静かだから. [TUFS: причина и присоединение](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/081.html).

```
雨が降っているので、出かけません。 — Потому что идёт дождь, не выхожу。
具合が悪いので、休みます。 — Плохо себя чувствую, поэтому отдохну.
```

## 9. 〜ながら (делая что-то одновременно)

```
歩きながら電話をします。 — Разговариваю по телефону, идя。
食べながらテレビを見ます。 — Смотрю телевизор, едя。
```

## 10. 〜てから (после того как)

```
ご飯を食べてから勉強します。 — Учусь после еды。
手を洗ってから寝ます。 — Помою руки, затем лягу спать.
```

## 11. 〜ば (если)

```
出発が早ければ、間に合います。 — Если отправимся рано, успеем.
勉強すれば、わかります。 — Если учиться, поймёшь。
```

## 12. 〜すぎます (слишком)

```
この道は狭すぎます。          — Эта дорога слишком узкая.
駅までは遠すぎます。          — До станции слишком далеко.
電車が混みすぎます。          — Поезд слишком переполнен.
昨日、飲みすぎました。        — Вчера слишком много выпил.
```

**Образование:** у い-прилагательного уберите конечное い и сразу добавьте すぎる: 遠い→遠すぎる, без дополнительного く. У な-прилагательного используйте основу без な: 静か→静かすぎる. У глагола берите основу перед ます: 飲みます→飲みすぎる. [Japan Foundation: образование すぎる, §5](https://ba.jpf.go.jp/wp-content/uploads/2022/03/Akiko6_bunpoo382002.pdf#page=3).

## 13. 〜やすい / 〜にくい (легко / трудно сделать)

```
分かりやすい地図です。        — Понятная карта.
この道は歩きやすいです。      — По этой дороге легко идти пешком.
駅は見つけにくいです。        — Станцию трудно найти.
漢字は読みにくいです。        — Кандзи трудно читать.
```

**Образование:** основа глагола (форма на ます без ます) + やすい / にくい.

## 14. 〜ことができます (уметь, мочь)

```
自転車に乗ることができます。      — Я умею ездить на велосипеде.
地図を読むことができます。        — Я умею читать карту.
ここで切符を買うことができます。    — Здесь можно купить билет.
バスで行くこともできます。        — Можно также поехать на автобусе.
```

**Образование:** словарная форма глагола + ことができます.

## 15. 〜てみます (попробовать сделать)

```
地図を見てみてください。      — Попробуйте посмотреть на карте.
電車で行ってみます。          — Попробую поехать на поезде.
新しい道を歩いてみました。     — Попробовал пойти новой дорогой.
```

## 16. 〜そうです (по виду, похоже)

```
雨が降りそうです。            — Похоже, пойдёт дождь.
駅は混んでいそうです。        — Станция, похоже, переполнена.
この道は近そうです。          — По этой дороге, похоже, недалеко.
```

**Образование:** основа глагола + そう (降りそう); い-прилагательное без い + そう (近そう).

## 17. 〜たらいいですか (как лучше сделать?)

```
駅へどうやって行ったらいいですか。 — Как мне лучше добраться до станции?
どこで切符を買ったらいいですか。   — Где лучше купить билет?
何番線に乗ったらいいですか。       — С какой платформы лучше поехать?
```

## 18. 〜ほうがいいです (лучше сделать)

```
急いだほうがいいです。            — Лучше поторопиться.
早く寝たほうがいいです。          — Лучше лечь спать пораньше.
地図を持って行ったほうがいいです。 — Лучше взять с собой карту.
```

## 19. 〜まえに (перед тем, как)

Противоположность 〜てから:

```
食べるまえに手を洗います。                  — Перед едой мою руки.
切符を買うまえに案内所に聞きました。          — Перед покупкой билета спросил в справочном.
寝るまえに本を読みます。                    — Перед сном читаю книгу.
```

## 20. 〜とき (когда)

```
病気のとき、病院へ行きます。      — Когда болею, иду в больницу.
駅に着いたとき、電話しました。    — Когда приехал на станцию, позвонил.
雨のときは、電車が混みます。      — Когда дождь, поезда переполнены.
バスを待っているとき、人に会いました。 — Когда ждал автобус, встретил человека.
```

## 21. 〜つもりです (намерение)

```
電車で行くつもりです。            — Собираюсь поехать на поезде.
来年、日本へ行くつもりです。      — В следующем году собираюсь в Японию.
タクシーでは行かないつもりです。  — Не собираюсь ехать на такси.
```
