# 🌌 Knowledge Vault

> 🧭 **Главный дашборд хранилища в Obsidian:** [Home.md](Home.md)

Комплексная база знаний для изучения 4 языков (японский, корейский, китайский, английский) с опорой на систему мнемотехники и алгоритмы интервального повторения (FSRS).

## Структура хранилища:
1. **[Home.md](Home.md)** — интерактивная стартовая панель управления и трекер всех 60 юнитов.
2. **`languages/`** — 4 языковых курса по 15 юнитов каждый, словари до 2000+ слов, сленг 2024–2026, гайды по JLPT, HSK 3.0 и TOPIK IBT/Speaking.
3. **`mnemonics/`** — дворцы памяти (15 маршрутов), система Major, PAO, ассоциативные азбуки (кана, хангыль, ключи иероглифов), психология памяти и медитация.
