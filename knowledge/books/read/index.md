# Прочитанные книги — Полный каталог

Этот раздел для списка прочитанных книг с рецензиями, заметками, оценками и цитатами.

---

## 1. Структура записи о книге

```markdown
## Название книги — Автор

**Жанр:** ...
**Год прочтения:** ...
**Оценка:** ⭐⭐⭐⭐⭐ (1–5)
**Формат:** бумажная / электронная / аудио

### О чём книга
Краткий пересказ сюжета или содержания.

### Ключевые идеи
- ...
- ...

### Цитаты
> "..."

### Рецензия
Мои впечатления, анализ, что понравилось, что нет.

### Что вынес для себя
- ...
```
