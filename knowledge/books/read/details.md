# Чтение книг — Микро-детали

## 1. Системы каталогизации

### 1.1 Zettelkasten — метод заметок

**Принципы:**
- Каждая заметка — одна идея
- Связи между заметками (ID → ID)
- Своими словами, не копировать
- Atomicity: одна мысль на заметку

**Структура ID:**
```
YYYYMMDDHHMM-sequential
# Пример: 202407281430-01
```

**Типы заметок:**
- **Fleeting notes** — быстрые, временные
- **Literature notes** — по прочитанному
- **Permanent notes** — вечные, обработанные
- **Structure notes** — оглавления, MOC

### 1.2 Zettelkasten для книг — трёхуровневая система

```
Level 1: Book note
  → summary, key quotes, page refs

Level 2: Idea notes
  → atomic, numbered, linked
  → own words, context

Level 3: Index/MOC
  → hub pages
  → connect ideas across books
```

## 2. Стратегии чтения

### 2.1 Инспекционное чтение (Mortimer Adler)

**Шаг 1: Обзор (5-10 мин)**
1. Название, подзаголовок, аннотация
2. Оглавление — маппинг структуры
3. Предисловие / введение
4. Главы — заголовки и подзаголовки
5. Последние страницы — индекс, выводы

**Шаг 2: Быстрое чтение**
1. Читать первые абзацы глав
2. Читать последние абзацы
3. Смотреть на выделенное, графики, таблицы
4. Отметить 3-5 ключевых страниц

### 2.2 Аналитическое чтение

**4 вопроса:**
1. О чём книга в целом?
2. Что конкретно говорится (основные аргументы)?
3. Вся ли книга верна?
4. Каково значение книги?

**3 стадии:**
1. Найти структуру и план
2. Определить термины и ключевые предложения
3. Оценить аргументацию

### 2.3 SQ3R Метод

| Этап | Действие | Время |
|------|----------|-------|
| **S**urvey | Просмотр структуры | 5 мин |
| **Q**uestion | Сформулировать вопросы | 2 мин |
| **R**ead | Чтение с ответами на вопросы | 30 мин |
| **R**ecite | Пересказ своими словами | 10 мин |
| **R**eview | Повторение | 5 мин |

## 3. Чтение по жанрам

### 3.1 Нон-фикшн — стратегия

1. Читать введение и заключение ПЕРВЫМИ
2. Пропускать примеры, если идея ясна
3. Маркировать: ⚡ ключевая идея, ❓ вопрос, 🔗 связь
4. После главы — записать одной фразой суть
5. В конце: ответить на вопросы Адлера

### 3.2 Философия — стратегия

1. Узнать контекст (когда, в ответ на что)
2. Определить ключевые термины
3. Проследить аргументацию по шагам
4. Схематизировать (mindmap)
5. Сравнить с оппонентами

### 3.3 Техническая литература — стратегия

1. Прочитать задачу/проблему в начале
2. Воспроизвести код/алгоритм руками
3. Не читать подряд — прыгать между теорией и примерами
4. Выполнять все упражнения
5. Учить в контексте проекта

### 3.4 Художественная — стратегия

1. Не анализировать при первом прочтении
2. Отметить сильные сцены
3. После — анализ: темы, персонажи, структура
4. Сравнить с другими произведениями автора

## 4. Трекинг чтения

### 4.1 Ежедневный трекер

```markdown
# Трекер: 2024-07-28

| Время | Книга | Страницы | Время | Заметки |
|-------|-------|----------|-------|---------|
| 08:00 | Книга А | 30-50 | 20 мин | Глава 3 |
| 13:00 | Книга Б | 1-15 | 15 мин | Введение |
| Итого | | 35 стр | 35 мин | |
```

### 4.2 Недельный обзор

```markdown
# Неделя 30

## Прочитано
- Книга А: 150 стр (закончил)
- Книга Б: 80 стр

## Заметки
- 3 literature notes
- 5 idea notes
- 1 MOC

## Выводы
- Лучшее время для чтения — утро
- Слишком много книг в параллель

## План на неделю 31
- Начать Книгу В
- Закончить Книгу Б
```

## 5. Скорочтение — техники

### 5.1 Perceptual expansion

Тренировка: читать группы слов, а не по одному слову.

**Упражнение:**
1. Использовать ручку/палец как ведущую точку
2. Двигаться быстрее комфортного
3. С каждым днём увеличивать скорость
4. Начинать с 200 wpm → цель 400-600 wpm

### 5.2 Subvocalization reduction

- Счёт в уме (1, 2, 3...) во время чтения
- Жевать резинку
- Слушать музыку без слов
- Читать 15 мин в день с максимальной скоростью

**Реальность:** Полностью избавиться от субвокализации невозможно для сложных текстов. Для простых — до 800 wpm достижимо.

## 6. Форматы рецензий

### 6.1 Микро-рецензия (соцсети)

**Формат:**
- 1-2 предложения сути
- Кому рекомендовать
- Оценка ⭐

### 6.2 Стандартная рецензия

**Структура:**
1. Введение — автор, контекст, почему взял
2. О чём — без спойлеров
3. Что понравилось — 2-3 пункта
4. Что не понравилось — 1-2 пункта
5. Кому читать
6. Оценка

### 6.3 Аналитическая рецензия

1. Контекст создания
2. Структура и аргументация
3. Сильные и слабые стороны
4. Связь с другими работами
5. Применимость на практике
6. Ключевые цитаты с анализом
