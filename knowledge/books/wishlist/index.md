# Вишлист книг — Список для прочтения

Личный список «когда-нибудь прочитать». Организован по темам, с приоритетами, аргументами и привязкой к разделам этой базы знаний.

---

## 0. Как пользоваться вишлистом

### 0.1 Правила ведения

- Новые книги добавляются только со строкой «Зачем мне это». Если нет причины — не добавлять.
- Приоритет меняется раз в месяц: что-то поднимается, что-то удаляется.
- После прочтения книга переносится в `books/read/index.md` с заметкой по шаблону `books/notes/template.md`.
- Книги, отменённые после начала чтения (DNF), помечаются `[x]` и выносятся в отдельный блок «Отложено/брошено» с причиной.
- Раз в квартал проводится «чистка»: вишлист не должен расти без пересмотра приоритетов.

### 0.2 Статусы

| Статус | Обозначение | Смысл |
|--------|-------------|-------|
| Ждёт | `[ ]` | В списке, не начато |
| В процессе | `[/]` | Читаю сейчас |
| Прочитано | `[x]` | Закрыто, перенесено в read |
| Отложено | `[x]` + причина | Снято с очереди |

### 0.3 Приоритеты

| Приоритет | Обозначение | Когда читать |
|-----------|-------------|--------------|
| ⭐ Критический | `P0` | Следующая книга из очереди |
| Важный | `P1` | В этом квартале |
| Нормальный | `P2` | В течение года |
| Не срочный | `P3` | Когда дойдут руки |

### 0.4 Привязка к базе знаний

Каждая книга в списке связана с разделом базы знаний, который она усиливает:

| Раздел базы | Ключевые книги в вишлисте |
|-------------|---------------------------|
| 🌍 Языки | Fluent Forever, Remembering the Kanji, Moonwalking with Einstein |
| 🧩 Мнемоника | Moonwalking with Einstein, How We Learn |
| 💻 Программирование | Clean Code, DDIA, System Design Interview |
| 🏛 Философия | Так говорил Заратустра, Бытие и время, Хагакурэ |
| 🧠 Психология | Думай медленно, Скука, Эмоциональный интеллект |
| 🧘 Практики | Поток, Искусство медитации, Четыре соглашения |
| 📚 Книги | Метод заметок Зеттелькастен, Как читать книги |

## 16. Правила принятия решения «читать или нет»

1. Если книга старше 30 лет и до сих пор не «зашла» в списки — проверить, актуальна ли она для моих целей.
2. Любая книга, которая дублирует то, что уже есть в базе лучше и полнее, — пропускается.
3. Книгу по навыку читаем с упражнениями параллельно (язык → Anki, алгоритмы → задачи).
4. Приземление: после каждой прочитанной книги — одна строка в `books/read/details.md` о том, что изменилось.

## 22. Практика: как я беру новую книгу (текущий эксперимент)

### Эксперимент B001: «Книга недели — несколько страниц»

- **Правило:** новую книгу начинаю с 20 страниц за 3 дня.
- **Вопросы:** держит внимание? есть новая информация на странице? хочется вернуться?
- **Решение:** да — в очередь; нет — отложить с пометкой.
- **Метрика:** доля «зашедших» книг, передвинутых в read.

### Эксперимент B002: параллельные потоки

- Один поток — художественная литература (вечер)
- Второй поток — нон-фикшн по теме месяца (утро)
- Третий поток — «служебное» аудио (прогулки)
- Цель — поддерживать мотивацию без выгорания от одной темы.

## 23. FAQ по вишлисту

**Почему книг так много, разве это реалистично?**
Это не обязательство, а полка. Реальная цель на год — 24 книги; список шире, чтобы было из чего выбирать по настроению и темам.

**Почему у части книг приоритет P0, если они не начаты?**
P0 означает «следующий кандидат при выходе свободного слота». Он меняется раз в месяц.

**Что делать, если книга не понравилась на 3-й главе?**
Выносить в «Отложено» с причиной — это не стыдно, это защита времени. Возврат возможен.

**Как связан вишлист с базой знаний?**
Книга, закрытая из вишлиста, становится «сырьём» для разделов: цитаты в заметки, идеи — в нужные разделы, методики — в практики.
