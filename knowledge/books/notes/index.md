# Заметки о книгах

Конспекты, идеи, сравнения и тематические подборки.

## 1. Сравнение книг на одну тему

### "Атомные привычки" vs "Сила привычки"

| Критерий | Атомные привычки (Клир) | Сила привычки (Духигг) |
|----------|------------------------|----------------------|
| Фокус | Индивидуальные привычки | Научное исследование |
| Метод | 4 закона: сделать очевидным/привлекательным/лёгким/удовлетворяющим | Петля привычки (триггер → действие → награда) |
| Стиль | Практичный, пошаговый | Журналистский, с историями |
| Примеры | Спортсмены, бизнес | Инсульт, Febreze, Starbucks |

### "Sapiens" vs "Игра престолов" (историческая перспектива)

Харари объясняет, почему человек стал доминирующим видом — способность к коллективному воображению (деньги, нации, законы).

## 2. Сцены, которые запомнились

### "1984" — Оруэлл
- Комната 101: каждый боится чего-то своего
- "2+2=5" — насилие над реальностью
- Последняя сцена — любовь к Большому Брату

### "Мастер и Маргарита" — Булгаков
- Бал у Сатаны
- Разговор Воланда с Берлиозом
- Полет Маргариты

### "Преступление и наказание" — Достоевский
- Убийство старухи
- Разговор с Порфирием (психологическая дуэль)
- Сон о лошади

## 4. Идеи для применения

### Из книг по саморазвитию

| Книга | Идея | Применение |
|-------|------|-----------|
| Атомные привычки | Закон 1: сделай привычку очевидной | Положить книгу на подушку |
| 7 навыков | Начинай с конца | Определить цели на год |
| Поток | Цель = вызов + навыки | Разбить задачу на уровни |
| Как завоёвывать друзей | Улыбайся, запоминай имена | 3 сек. пауза перед ответом |

### Из научной литературы

- **Эгоистичный ген**: альтруизм — замаскированный эгоизм
- **Думай медленно**: Система 1 (быстрая) vs Система 2 (медленная)
- **Sapiens**: Мы живём в "интерсубъективной реальности"

## 5. Связи с другими книгами

```
Sapiens (Харари)
  → Краткая история времени (Хокинг) — масштаб истории
  → Эгоистичный ген (Докинз) — эволюция как соревнование
  → 1984 (Оруэлл) — контроль через нарративы

Атомные привычки (Клир)
  → Сила привычки (Духигг) — научная база
  → Поток (Чиксентмихайи) — оптимальный опыт
  → Семь навыков (Кови) — система vs привычки
```
