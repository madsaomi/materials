# Разделы, уровни и материалы

Структура одинаково используется в Obsidian и на сайте.

```text
knowledge/
  languages/
    english/
      _contents.md
      a1/
        _contents.md
        unit-01/
          overview.md
          dialogue.md
          grammar/
            core.md
            usage.md
          vocabulary/words.md
          practice/exercises.md
          reading.md
          test.md
        unit-02/ ... unit-05/
      a2/                  # уроки 06–10
      b1/                  # уроки 11–15
      b2/                  # имеющиеся материалы с пометкой B2
      c1/                  # имеющиеся материалы с пометкой C1
      reference/           # общий справочник и материалы нескольких уровней
    chinese/ ... japanese/ ... korean/
  programming/
    python/
      foundation/
      practice/
      advanced/
      reference/
  psychology/
    foundation/ ... practice/ ... advanced/ ... reference/
  mnemonics/ ... philosophy/ ... practices/ ... books/ ... tools/
  knowledge/               # сохранённая дополнительная версия базы
```

Папки уровней создаются по имеющимся материалам. В частности, пустая папка C2 не добавлена: в существующем английском наборе нет отдельного блока C2. У общих справочных тем может быть только `reference/`, если исходный материал не разделён на ступени. Большая статья, охватывающая весь предмет, не объявляется автоматически «начальным курсом».

У языковых уроков используются авторские метки A1/A2/B1; это организация учебного набора, а не подтверждение покрытия CEFR или соответствия JLPT/HSK/TOPIK. Разбиение остальных курсов: основы, практика, углубление, общие справочники. Планы обучения и сравнительные справочники доступны в отдельных разделах.

На сайте: **Библиотека → Языки → Английский → A1 → Урок 01**. Кнопка «Содержание уровня» открывает страницу со всеми уроками и материалами уровня. Внутри урока есть папки грамматики, словаря и практики, а также обзор, диалог, чтение и тест. Материалы можно показывать списком, карточками или таблицей. Хлебные крошки возвращают к папке, уровню и разделу.

## Сохранность и ссылки

Все 1217 исходных заметок сохранены в новых папках. Добавлена 131 страница содержания; всего в `knowledge/` теперь 1348 Markdown-файлов. Содержательные исправления предыдущего этапа сохранены. Незаполненные китайские записи по-прежнему имеют явные редакторские отметки — перенос не означает их восстановления.

Обе версии базы сохранены. В каталоге одинаковый относительный материал показывается одной строкой с отдельной ссылкой на другую версию; тексты не объединяются и не удаляются. Поиск по-прежнему доступен для обеих версий.

Относительные Markdown-ссылки пересчитаны. Старые адреса страниц сайта `/doc/...` перенаправляются через `legacy_paths.json`; параметры продолжения чтения сохраняются. Если изменение относительной ссылки влияло на старый идентификатор заголовка, в заметке оставлен HTML-якорь для совместимости. История чтения распознаёт старые пути при открытии перенесённой заметки.

Резервная копия заметок перед переносом находится в папке результатов этой беседы вне репозитория. Одноразовый скрипт `scripts/organize_knowledge.py` отказывается повторно работать при наличии карты миграции.

## Дальнейшее редактирование

Добавляйте новые заметки сразу в папку нужного уровня. Сайт автоматически обнаруживает папки и файлы. Для обновления существующих страниц содержания выполните из корня:

```powershell
python scripts/refresh_contents.py
```

Если создаёте совершенно новый раздел или уровень, добавьте в него `_contents.md` и запустите эту команду; сайт покажет новую папку и до обновления содержания. `reference/` предназначен для материалов, которые пока нельзя корректно отнести к одному уровню.

Перед публикацией выполните `python verify.py`. Dockerfile включает новый модуль каталога и карту прежних адресов. Git push и размещение сайта в этой работе не выполнялись.
