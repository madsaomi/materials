# Next.js / TypeScript

Переход одобрен пользователем 18 октября 2026 года. Основной сайт теперь работает на Next.js App Router, React и TypeScript; Python для его запуска не нужен. Markdown в `knowledge/` остаётся источником заметок для сайта и Obsidian.

## Запуск

Node.js 22+, pnpm 11.25.0:

```powershell
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Адрес: http://localhost:5000. Production:

```powershell
pnpm typecheck
pnpm verify
pnpm build
pnpm start
```

`PORT` меняет порт production-сервера; `pnpm exec next dev --port 5001` позволяет сравнить версии. В Docker запускается standalone-сборка, healthcheck — `/healthz`. Docker и внешний хостинг проверяются отдельно от локальной production-сборки.

## Устройство

- `app/`: React-страницы, layout, API поиска и предпросмотра.
- `components/shell.tsx`: общий интерфейс и навигация.
- `lib/knowledge.ts`: frontmatter, Markdown, подсветка кода, ссылки, содержание, кэш по mtime/size, полнотекстовый поиск и связанные заметки.
- `lib/catalog.ts`: разделы, уровни, уроки, порядок материалов и версии из обоих хранилищ.
- `public/static/`: актуальные локальные CSS/JS. Шрифты и скрипты не требуют CDN.
- `legacy_paths.json`: постоянные redirects 308 с сохранением query-параметров (Flask использовал 301).
- `scripts/verify-next.ts`: аудит всех 1348 документов, ссылок, якорей, идентификаторов, legacy-целей, иерархии и поиска. Отчёт — `next-verification.json`.

Обычные HTML-ссылки выполняют полную навигацию. Ключи localStorage темы, вида каталога, шрифта и истории чтения сохранены. Добавление или изменение Markdown обнаруживается при следующем запросе (интервал сканирования до 1,5 с). На хостинге с неизменяемым файловым образом после изменения файлов нужна новая публикация.

Сайт использует сервер Node.js: полнотекстовый поиск и обработка Markdown выполняются на сервере. Это не статический экспорт. Первое открытие прогревает кэш; последующие запросы используют разобранные документы.

## Сохранённые инструменты и ограничения

`app.py`, `catalog.py`, `templates/`, `static/`, `verify.py`, `requirements.txt`, `gunicorn.conf.py` сохранены как прежняя реализация для сравнения. Они не участвуют в запуске Next.js. Python-скрипты обслуживания заметок остаются вспомогательными. Однократную реорганизацию папок повторно не запускать.

Markdown-it заменяет Python-Markdown; заголовки и ссылки проверяются по всей базе, отдельные расширения старого парсера могут отображаться иначе. При дальнейших изменениях проверять таблицы, HTML и блоки кода. Содержание заметок при переходе не редактируется. Ранее зафиксированные 1636 незавершённых китайских строк и 120 шаблонных страниц остаются задачами редакторской работы.
