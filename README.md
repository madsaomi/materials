# 知 · Chishiki

Личная библиотека заметок: редактируете Markdown в Obsidian, читаете на сайте.
Flask + Jinja2 + Python-Markdown + Pygments, обычные CSS и JavaScript.
Без Node.js, сборки фронтенда и внешних шрифтов. Интерфейс работает офлайн.

## Локальный запуск

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:5000. Если виртуальное окружение ещё не создано,
сначала выполните `python -m venv venv`.

## Как работать с заметками

1. Откройте папку `knowledge/` как хранилище в Obsidian.
2. Создайте или отредактируйте `.md`-файл и сохраните его.
3. Обновите страницу локального сайта: добавления, правки, переименования и удаления
   обнаруживаются автоматически. Парсинг выполняется только для изменённых файлов.
4. Для опубликованного сайта сделайте commit и push в подключённую ветку GitHub.
   После успешного развёртывания Railway обновите страницу сайта.

Сайт не редактирует файлы и не записывает изменения обратно в Obsidian.
Кэш сайта не равен синхронизации с Git: удалённому серверу нужен новый деплой.

Внутренние ссылки: `[Заметка](../folder/note.md)` и `[Раздел](note.md#заголовок)`.
Сайт сохраняет пути файлов и преобразует эти ссылки в адреса страниц.
Obsidian-ссылки вида `[[Заметка]]`, плагины Dataview и другие расширения Obsidian
не исполняются на сайте. Для переносимости используйте обычный Markdown.

В репозитории сохранены две коллекции: `knowledge/` и вложенная `knowledge/knowledge/`.
Они отображаются в общих тематических разделах. Одинаковые названия не удаляются:
карточки и поиск показывают путь к файлу, карточки также отмечают хранилище.

## Интерфейс

- Единая компактная шапка: библиотека, меню коллекций, поиск и тема.
- Главная: коллекции-вкладки, список заметок с описанием, категорией и временем чтения.
- Сортировка по названию/изменению файла, страницы по 24 заметки.
- Поиск по полному тексту: Ctrl/Cmd K или `/`.
- Продолжение чтения, предпросмотр внутренних ссылок и связанные заметки.
- Страница чтения без большой декоративной обложки; содержание открывается по кнопке.
- Матовые полупрозрачные поверхности, светлая и тёмная темы, системные шрифты.

## Размещение на Railway

Проект подготовлен для сборки через `Dockerfile` (Python 3.12). Railway обнаруживает
его автоматически. В образ входят приложение, оформление и заметки; локальное
окружение, настройки Obsidian и служебные файлы исключены через `.dockerignore`.
Развёртывание в аккаунте Railway пока не выполнено.

1. Отправьте изменения этого проекта вместе с `knowledge/` в GitHub.
2. Создайте в Railway проект: **Deploy from GitHub repo**, выберите репозиторий
   `madsaomi/materials` и ветку `main`.
3. Корень сервиса — корень репозитория. Build Command и Start Command оставьте
   пустыми: сборка и запуск уже заданы в Dockerfile.
4. В настройках Deploy задайте **Healthcheck Path: `/healthz`**,
   **Healthcheck Timeout: `300`** секунд, одну реплику.
5. В Networking нажмите **Generate Domain**. Порт берётся из переменной `PORT`,
   которую выдаёт Railway; вручную указывать 5000 не нужно.
6. Оставьте автоматические развёртывания из `main` включёнными. Фильтр Watch Paths
   можно оставить пустым, чтобы правки заметок тоже запускали обновление.

Сервер использует один процесс и два потока. Перед приёмом запросов он загружает
библиотеку; сообщение `Library ready: ... documents` в логах означает завершение.
На первичную обработку отведено 300 секунд. `/healthz` не пересчитывает заметки.
Если загрузка на выбранном тарифе не успевает, проверьте логи и доступные ресурсы.

После изменения заметок в Obsidian: сохранение → commit → push → успешный деплой.
База данных и постоянный диск не нужны: заметки входят в репозиторий.
Публичный сайт показывает все включённые заметки; вход по паролю не реализован.
История чтения и настройки вида остаются в браузере посетителя.
Сортировка по изменению использует время файлов, которое может меняться при сборке.

Локальная проверка контейнера при установленном Docker:

```sh
docker build -t chishiki .
docker run --rm -p 8000:8000 -e PORT=8000 chishiki
```

После сообщения о готовности откройте `http://localhost:8000/healthz` и главную.
На Windows без Docker продолжайте запускать `python app.py`.

Настройки проверены по документации 30 сентября 2026:
[Dockerfile](https://docs.railway.com/builds/dockerfiles),
[проверка готовности](https://docs.railway.com/deployments/healthchecks).
Новые сервисы больше не используют старые `railway.json` / `railway.toml`:
[Config as Code](https://docs.railway.com/config-as-code).
Условия бесплатного использования проверяйте перед запуском в
[тарифах Railway](https://docs.railway.com/pricing/plans): бесплатная постоянная
работа этим проектом не гарантируется.

## Проверка

```powershell
.\venv\Scripts\python.exe -B verify.py
```

Проверяются основные маршруты, все категории, страницы каталога, локальные ресурсы,
ссылки во всех документах, уникальность HTML-якорей и обновление кэша при изменениях файлов.
Количество документов сверяется с файлами на диске (сейчас 1217), а не с устаревшим числом 642.
Повторяющиеся названия между коллекциями выводятся в отчёте и не считаются потерей данных.
Подробный UTF-8-отчёт сохраняется в `%TEMP%/chishiki-audit.json`.

## Структура

- `app.py` — чтение заметок, категории, маршруты, кэш, поиск.
- `templates/` — страницы и общие компоненты.
- `static/css/style.css` — весь дизайн и адаптивное оформление.
- `static/js/site.js` — поиск, тема и инструменты чтения.
- `knowledge/` — ваши материалы.
- `.agents/` — правила и журнал работы над проектом.

## Поиск и продолжение чтения

Поиск (Ctrl/Cmd K) находит слова в названии, пути и полном тексте заметки.
Результаты содержат отрывок с подсветкой; совпадения в названии идут первыми.
Разделы поиска ограничивают область, запрос может содержать несколько слов.

На главной появляются три последние открытые заметки с прогрессом. Кнопка
«Продолжить» возвращает к месту остановки. При обычном открытии заметки
можно продолжить или начать сначала. История хранит до 20 заметок локально
в этом браузере; её можно очистить на главной. Между устройствами она не синхронизируется.

## Ссылки и связанные заметки

Нажмите круглую кнопку рядом с внутренней ссылкой, чтобы увидеть название,
отрывок и время чтения. Предпросмотр открывается только по запросу,
в том числе на телефоне и с клавиатуры. Сама ссылка по-прежнему сразу открывает заметку.
Предпросмотр закрывается крестиком, Escape, нажатием снаружи или прокруткой.

В конце страницы показаны до четырёх связанных заметок: сначала исходящие
и обратные ссылки, затем соседние материалы раздела. Подпись объясняет связь.
Одинаковые названия в этом блоке объединяются; файлы библиотеки не изменяются.

## Оформление чтения

Заголовок и краткие сведения о заметке расположены прямо на стеклянной поверхности.
Доступны смена шрифта, копирование ссылки и режим чтения. Содержание открывается
отдельным окном. Таблицы и блоки кода прокручиваются по горизонтали на узких экранах.

## Компактный стеклянный режим

На страницах заметок боковая библиотека открывается кнопкой меню, содержание —
кнопкой в компактной верхней панели. Постоянные боковые колонки и футер убраны.
Матовая полупрозрачная поверхность заметки и блоков кода адаптируется к теме.
В коде сохранены подсветка синтаксиса, прокрутка и кнопка копирования.

## Спокойная стеклянная библиотека

Декоративная главная заменена компактным каталогом заметок.
Все коллекции доступны в горизонтальных вкладках и выдвижном меню. Выбранная
вкладка прокручивается в видимую область. Описания и пути помогают различать
заметки с одинаковыми названиями. Прозрачность сохранена; обложки, крупные символы,
кольца и повторяющиеся декоративные карточки убраны.

## Минималистичное оформление

Нейтральный однотонный фон без точек и цветных пятен, матовые поверхности
и тонкие разделители. Декоративные стрелки и постоянные пути файлов в списке
скрыты; путь доступен в подсказке ссылки. Автоматические превью при наведении
отключены — используется кнопка рядом со ссылкой.

## Виды библиотеки

Переключатель «Список / Карточки / Таблица» доступен на главной и во всех коллекциях.
Выбор сохраняется в этом браузере и применяется при смене коллекции, сортировки
и страницы. Таблица показывает название, коллекцию, хранилище и время чтения;
на узком экране прокручивается горизонтально. Сами заметки остаются страницами
для чтения. При недоступном хранилище браузера переключатель работает до перезагрузки.
